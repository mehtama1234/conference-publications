FIRST PRINCIPLE

A Generated Object Has To Live Somewhere

A sentence can be judged by whether it is coherent. A physical object, video, robot plan, molecule, city simulation, or scientific field has a harder requirement: it has to live in a state space with constraints. Objects have depth, pose, contact, dynamics, conservation laws, synthesis routes, uncertainty, and downstream actions. If the model ignores those constraints, the sample can look good while being useless.

That is the center of this lane. The conference is pushing generation from surface realism toward usable structure. Diffusion, flows, autoregressive decoders, world models, robot policies, simulators, reward models, and scientific priors are different approaches to the same problem: make a model produce something that remains valid when inspected, manipulated, simulated, measured, or acted on.

FIELD SHAPE

The Five Pressures Behind The Papers

Geometry
Images, videos, scenes, and robot observations need coordinate systems. Depth, camera pose, 3D Gaussian splats, orthographic views, and spatial language all exist to stop a model from confusing appearance with world structure.
Dynamics
Long video, traffic, weather, continuum fields, and robot control are trajectories. The object is not one frame or one answer, but a state that changes under time, action, and uncertainty.
Constraint
Molecules, proteins, physical fields, and feasible robot motions must obey constraints. The method is only useful if it narrows search without destroying validity.
Grounding
Multimodal models need to know which modality, feature, view, sound, or tactile signal supports a conclusion. Otherwise confidence becomes a fluent story over weak evidence.
Verification
Generation needs outcome checks: physical plausibility, visual consistency, simulation success, reward alignment, synthesis feasibility, and safety/provenance hooks.

SUBTHEME 01

Spatial Grounding

The model has to carry a coordinate system, not only a caption.

Many visual-language systems fail because they treat spatial questions as another text prediction problem. These papers make geometry explicit: cameras, rays, depth, Gaussian splats, 3D views, and scene graphs become part of the representation so the model can reason about where objects are, how views relate, and what action would be possible.

ICLR 2026

Depth Anything 3

Predicts spatially consistent geometry from arbitrary visual inputs, with or without known camera poses. The problem is that image models can recognize objects while still lacking metric structure. By tying depth and ray prediction together, it moves visual understanding toward a representation that can support reconstruction, rendering, navigation, and downstream embodied reasoning.

ICLR 2026

Camera-Aware MLLM

Injects camera parameters and augmentation into multimodal language models so spatial answers are not silently overfit to viewpoint statistics. The key idea is that a model cannot reliably answer geometry questions if the camera is treated as invisible. Camera metadata becomes evidence, not metadata decoration.

ICML 2026

3ViewSense

Gives VLMs canonical orthographic views and separates simulation from reasoning. This attacks a common failure: a single perspective can hide the structure needed for action. The method makes spatial judgment easier by changing the observation into views where geometry is less ambiguous.

ICML 2026

Holi-Spatial

Builds spatial supervision from 3D Gaussian-splatting scenes, including masks, boxes, captions, grounding instances, and spatial question answering. The paper matters because spatial capability is data-hungry: if the supervision only names objects, the model will not learn relations, depth, containment, support, or navigable structure.

ICML 2026

TideGS

Targets billion-scale 3D Gaussian splatting, where scene representation becomes a systems and geometry problem at once. It is not enough to generate a pretty scene; the representation has to be compact, renderable, and stable enough to serve as a world model for later inspection.

ICML 2026

VGGT-Motion

Connects visual geometry with motion estimation, which is the bridge from static reconstruction to action. The model must infer not only what the scene is, but how objects and cameras move through it. That makes it part of the same pressure as robot perception and long-horizon video modeling.

ICML 2026

SpatioLM

Treats spatial layout as language-model-readable structure rather than leaving it buried in pixels. The deeper move is interface design: if spatial state is represented in a form a reasoning model can use, planning and question answering can operate over the same scene facts.

ICLR 2026

DepthLM

Uses VLM machinery to recover metric depth without relying on a conventional dense depth head. It shows how language-supervised models can be pulled toward physical measurement, but only if the training and prompting expose the metric object explicitly.

ICLR 2026

WAFT

Replaces cost volumes with high-resolution warping for dense correspondence estimation. The object is the mapping between two views, not a label attached to one image. This matters because correspondence is the hidden work behind tracking, reconstruction, manipulation, and visual editing: a model has to know which point in one view is the same physical point in another.

ICML 2026

SplAttN

Uses differentiable density splats instead of hard projection for point-cloud completion. Hard projection throws away visual signal when a sparse 3D observation is forced into a brittle representation. Splatted attention keeps uncertainty and density visible, which is closer to how incomplete spatial evidence should be handled.

ICML 2026

SVL

Introduces a spike-driven PointFormer and text-encoder-free inference for zero-shot 3D classification and open-world question answering. It pushes spatial grounding away from only 2D image-language alignment and toward direct 3D signals, where the model can reason over point structure without translating everything through captions.

ICML 2026

UniMapping

Builds neural-descriptor maps from multimodal observations for reusable map-centric embodied perception. A map is the persistent memory of a place. By making the map the central object, the paper connects perception over time to later navigation, localization, and action rather than treating each observation as fresh.

ICML 2026

RelaxFlow

Uses text prompts to steer occluded 3D regions while rigidly preserving observed image evidence. The useful constraint is asymmetric: hallucinate where the scene is hidden, but do not rewrite what was actually seen. That makes generation serve reconstruction rather than overriding measurement.

ICML 2026

FutureCAD

Grounds textual geometric selections to boundary-representation primitives through BRepGround. CAD models are not ordinary meshes; they contain editable design structure. This paper makes language point at the operations and primitives engineers actually manipulate, connecting multimodal grounding to precise geometric editing.

ICLR 2026

Vid-LLM

Processes video with geometric priors for 3D question answering, captioning, and grounding without requiring external 3D data. The method acknowledges that video already contains geometric evidence if the model knows how to read motion, viewpoint, and object persistence as structure.

ICLR 2026

XFactor

Tests whether learned poses from one video sequence can re-render the same camera trajectory in another scene. That is a strong geometry test because it separates camera motion from scene appearance. If the pose representation transfers, the model has learned something closer to physical viewpoint than visual style.

ICML 2026

MFedPBA

Aligns heterogeneous client feature spaces with contrastive and Gromov-Wasserstein objectives. It belongs in spatial grounding because multimodal clients rarely share the same sensor mix or feature geometry. The method tries to align decision structure without pretending every device sees the same world.

ICLR 2026

RULE

Estimates reliability for intra-entity and inter-graph correspondences to reduce noisy fusion and overfitting. Multimodal knowledge graphs fail when an entity, attribute, image, or relation is aligned to the wrong counterpart. RULE makes correspondence uncertainty visible before fusion locks errors into the representation.

ICML 2026

SECNet

Processes event-camera streams as event clouds with structural polarity integration instead of dense frames. Event cameras observe change, not images. Treating events as clouds preserves the spatiotemporal structure of fast motion and avoids forcing asynchronous physical evidence into ordinary video frames.

ICML 2026

AdLift

Alternates lifted projected-gradient steps with image-to-Gaussian fitting for imperceptible safeguards across training and novel views. The spatial issue is view consistency: a safeguard that works from one camera angle is weak if a new view removes it. The method treats 3D representation as the carrier of the protection.

ICML 2026

Diffuse to Detect

Expands point labels into heat-diffusion pseudo-masks for infrared small-target detection. Small targets are hard because the label is sparse and the signal is weak. Diffusion over the image gives the detector a richer spatial training target while preserving the fact that only a small region is truly positive.

ICLR 2026

AnyUp

Improves upsampled feature quality while preserving semantics across feature extractors and downstream tasks. Upsampling is not just making a grid larger; it decides whether fine spatial detail remains connected to the same concept. This matters for dense prediction, editing, and reconstruction tasks where local structure carries meaning.

ICML 2026

DiSCo / Table-GLS

Separates table layout structure from semantic content for efficient LVLM table adaptation. Tables are visual objects with logical geometry. The paper matters because a model must read both where cells are and what they mean; collapsing layout into text loses the structure that makes tables useful.

ICLR 2026

RadioGS

Supervises unobserved-view radiance by matching learned Gaussian primitive radiance to physically based rendered counterparts. It connects 3D Gaussian representation to a real physical signal domain: radio propagation. The key move is that unseen views should obey radiance behavior, not only visual interpolation.

SUBTHEME 02

Worlds And Video

A world model is useful only if its futures remain coherent.

Video and simulation papers are about temporal state. A generated future can drift, forget constraints, break object identity, or become visually plausible but actionally wrong. The serious question is whether generated trajectories preserve enough structure to support planning, editing, evaluation, or closed-loop simulation.

ICLR 2026

Stable Video Infinity

Trains diffusion transformers on self-generated error trajectories so long videos can correct drift instead of compounding it. The failure mode is familiar from autoregressive systems: each plausible step pushes the next step slightly off-manifold. Error recycling turns those failures into training signal for temporal stability.

ICLR 2026

SANA-Video

Uses Linear DiT and block-wise constant-memory state for high-resolution minute-long video generation. This is not only an efficiency trick. Long video requires memory discipline because the model must preserve state over time without making the computation explode.

ICLR 2026

FlashWorld

Appears in both multimodal and generative evidence because it sits at the boundary between video generation and world modeling. The point is to make generated visual futures fast enough to become an interactive substrate, where the next action can depend on imagined state rather than a static prompt.

ICML 2026

SceneSmith

Uses designer, critic, and orchestrator VLM agents to generate dense simulation-ready indoor robot environments. The generated artifact is not an image; it is a usable scene. That makes simulation quality, object placement, functional affordance, and criticism part of the generation loop.

ICML 2026

VectorWorld

Generates streaming vector-graph driving worlds for real-time closed-loop autonomous simulation. Driving simulation cannot be a bag of frames because policy behavior changes the future. The generated world has to expose lanes, actors, timing, and graph structure that can respond to decisions.

ICML 2026

WestWorld

Uses world-modeling structure inside the RL and embodied evidence set. Its importance is that simulated futures become training pressure: an agent needs internal dynamics that let it evaluate consequences before acting, not only imitate actions from past demonstrations.

ICML 2026

Motive

Uses motion-weighted gradients to find fine-tuning clips that improve or degrade temporal dynamics. It treats video data value as motion-specific, which is the right object: a clip with rich temporal change can teach dynamics that a visually rich but static clip cannot.

ICML 2026

VideoFlexTok

Works on adaptive video tokenization, where the model spends representation on the parts of a stream that carry information. This matters because long video cannot keep every pixel equally important; temporal reasoning depends on compressing without erasing the events that explain later state.

ICLR 2026

InfoTok

Allocates discrete video tokens by information richness rather than a fixed rate. The core problem is that video has uneven density: a small motion, contact, or object appearance can matter more than many redundant frames. Adaptive tokenization makes the representation follow event structure instead of clock time.

ICLR 2026

FlashVID

Preserves VLLM performance with a small fraction of visual tokens and enables far more frames under fixed compute. It treats video understanding as a budgeted evidence problem. The model has to decide what visual state survives compression so long-horizon reasoning remains possible.

ICLR 2026

LPWM

Discovers keypoints, boxes, masks, and latent particles from video without supervision. The useful object is an unsupervised particle-like state that can track entities through time. That turns raw pixels into a world representation where motion and object persistence become explicit.

ICLR 2026

RoSE

Uses image-to-video generation to predict shading sequences before recovering surface normals. It turns lighting variation into evidence. A static image hides shape, but a generated or inferred temporal sequence can expose how surfaces respond, letting physical geometry be recovered from appearance changes.

ICLR 2026

VIST3A

Stitches latent video generation to a feedforward 3D reconstruction decoder using a small unlabeled dataset. The approach uses video as a bridge into 3D: generated temporal consistency supplies the structure needed for reconstruction when direct labeled 3D supervision is scarce.

ICLR 2026

EditVerse

Represents text, image, and video as one token sequence for in-context generation and editing. The bigger idea is that editing should not be a separate mode bolted onto generation. If media objects share an interface, the model can condition on examples, modify state, and preserve context across modalities.

ICLR 2026

MotionStream

Belongs to the long-video generation cluster because streaming generation has to preserve temporal identity while producing new motion. The core challenge is not first-frame quality; it is whether the sequence can keep moving without losing object state, style, or physical continuity.

ICLR 2026

LiveMoments

Targets generated or understood media as live temporal moments rather than static clips. Its lane-level role is to make generation responsive to unfolding time, where the model has to maintain context, timing, and event salience while the stream changes.

ICML 2026

PanoWorld-X

Uses panoramic representation and spherical attention to generate explorable 360-degree scene videos. The object is not a rectangular clip but a navigable world view. Spherical attention matters because a panoramic scene wraps around; treating its boundaries as ordinary image edges breaks the geometry of exploration.

ICML 2026

CoEvol-NO

Maintains persistent latent state while co-evolving mesh coordinates through error-driven correction. It belongs with world models because the state and the coordinate system move together. The method keeps the representation tied to evolving physical geometry rather than solving on a fixed mesh forever.

ICML 2026

Generative Filtering

Scales filtering to nonlinear chaotic and atmospheric dynamics by reusing generative system models. Filtering is a live state-estimation problem: observations arrive over time and the model must update belief about the hidden world. Generation becomes a tool for maintaining that belief under difficult dynamics.

ICLR 2026

Cognitive Maps RNN

Links embodied sensorimotor trajectories to the emergence of allocentric representations. It treats a map as something learned from movement, not handed to the model. That connects video, control, and memory: the system builds world coordinates by experiencing transitions through space.

ICML 2026

WLA / ERA5-Latent

Compresses full pressure-variable weather data from hundreds of terabytes to a compact latent space. Weather is a world model at planetary scale. The contribution is not only compression; it decides what atmospheric state survives in the latent interface for forecasting and downstream physical reasoning.

ICLR 2026

PhyWorldBench

Tests whether generated videos obey physical principles, combining human evaluation with zero-shot MLLM checks. It belongs here because long video can look impressive while violating gravity, contact, or object permanence. The benchmark makes physical consistency a first-class evaluation target.

ICML 2026

Flowers

Builds PDE solvers from multihead learned feature warps rather than Fourier, attention, or convolutional spatial mixing. The world-model object is an evolving field. Feature warps let the solver move information through space in a way that can match physical deformation more directly than fixed mixing patterns.

ICML 2026

Lagrangian Action

Learns population dynamics from temporal marginals by minimizing Lagrangian action rather than free energy. The paper treats dynamics as a path principle: among possible transitions, choose the one with physically meaningful action. That makes generated trajectories answer to a variational law rather than only data fit.

SUBTHEME 03

Generative Samplers

Sampling is becoming controlled transport through a state space.

The generative modeling papers are less about one favorite architecture and more about the mechanics of moving probability mass. Diffusion, flows, masked decoding, energy models, reward guidance, and watermarking all ask how to steer samples while preserving the distributional facts that make the generator useful.

ICML 2026

AGSM

Integrates contrastive text-image alignment directions into the diffusion score-matching objective. Instead of bolting guidance on after training, it changes the training target so alignment becomes part of the denoising field. The tradeoff is whether that steering improves prompt faithfulness without narrowing the model's visual support too aggressively.

ICLR 2026

NextStep-1

Pairs a large autoregressive model with a flow-matching head to predict continuous image tokens without vector-quantization loss. The paper attacks a representation bottleneck: if image tokens are too discrete, generation inherits codebook artifacts. Continuous tokens make image generation look more like structured regression over visual state.

ICLR 2026

Energy-Based Transformers

Applies energy-based inference across discrete and continuous modalities. The important shift is that prediction becomes search for low-energy compatibility rather than one pass through a softmax. That gives the model a common language for text, image, and other continuous signals.

ICML 2026

Any-Order GPT

Evaluates masked diffusion models as any-order autoregressive models inside GPT-style architectures. It questions the rigid left-to-right assumption: for some objects, the right generation order may be flexible, learned, or dependent on which parts are most constrained.

ICLR 2026

Spherical Watermark

Embeds watermark information through transformations of Gaussian diffusion noise while preserving the latent distribution. The useful idea is provenance without obvious distribution damage: a watermark should be detectable by the holder and hard to see as an artifact in the generated media.

ICML 2026

Concept Removal Guidance

Estimates unwanted concept presence from diffusion noise predictions and calibrates negative guidance during denoising. It treats safety as trajectory steering rather than full retraining. The risk is over-removal, so the method matters when it suppresses target concepts while preserving benign generation quality.

ICML 2026

Divide-and-Denoise

Splits generation into smaller denoising problems so structure can be controlled locally. The deeper point is decomposition: if a global sample is hard to steer, break the object into pieces whose constraints can be handled more reliably and then compose them.

ICLR 2026

GLASS Flows

Combines efficient ODE-style flow behavior with stochastic evolution for inference-time reward alignment. It belongs in this lane because guidance is treated as a sampler property, not only a reward-model score after the fact.

ICLR 2026

Capacity Manipulation

Identifies majority-class capacity monopolization as a driver of minority-class degradation in diffusion models. The practical lesson is that a generator's capacity is not evenly shared. If common modes occupy the model too strongly, rare modes degrade even when the training set nominally contains them.

ICML 2026

LLapDiff

Handles continuous-time diffusion forecasting and imputation without forcing data onto a rigid grid. The target object is an irregular temporal process: queries can ask for missing values or future horizons. The approach matters because many physical and clinical signals are observed unevenly, not as neat frame sequences.

ICLR 2026

Structured Flow Autoencoders

Use flow structure inside an autoencoding setup so latent variables remain generative and controllable. The paper sits between representation learning and sampling: the hidden space should not merely compress data, it should support movement that decodes into valid outputs.

ICLR 2026

Diffusion Spacetime

Treats diffusion over spacetime rather than isolated samples. The first-principles issue is that events have temporal and spatial coupling. A sampler that ignores that coupling can generate locally plausible fragments that do not cohere as a world.

ICML 2026

Flex-Forcing

Uses flexible forcing in generative training so the model can learn under varying conditioning or rollout pressure. It belongs here because the sampling process is shaped by how much of the future is forced versus generated, which directly affects drift and controllability.

ICLR 2026

LatentFT

Fine-tunes generation through latent-space movement rather than broad pixel-space or full-parameter edits. The useful object is a controllable hidden trajectory: adaptation can be targeted when the latent space already exposes semantic and structural directions.

ICML 2026

Unifying Masked Diffusion Models

Connects masked diffusion variants under a common formulation. That matters because the field has many recipes that look different at the surface. A unified view lets us ask which part of the sampler controls order, uncertainty, and reconstruction rather than treating each model as a separate trick.

ICLR 2026

LPD

Works in the latent probabilistic generation cluster, where the main question is how to sample efficiently while preserving the distribution that downstream tasks depend on. It belongs beside flows and masked diffusion because all three are different ways to control probability movement through hidden state.

ICML 2026

Dimension-Free Diffusion Sampling

Removes explicit ambient-dimension dependence from diffusion sampling bounds except through support radius. The mathematical importance is that high-dimensional generation should not become impossible merely because data live in a large coordinate space. What matters is the effective region where the distribution has support.

ICML 2026

Flow Sampling

Learns diffusion and flow-matching samplers for unnormalized densities from energy-constructed denoising drifts. It targets the hard case where the density is known up to a normalizing constant. The sampler learns how to move through probability mass without requiring exact likelihood normalization.

ICML 2026

Efficient Diffusion Via Landing

Targets molecular, robotics, and engineering generation where samples must satisfy physical, geometric, or safety constraints. The useful idea is to make the sample land inside the valid set rather than generate freely and reject later. Constraint satisfaction becomes part of the sampling path.

ICML 2026

High-Accuracy Sampling

Gives a polylogarithmic-accuracy sampler for general log-concave distributions using gradient evaluations. This sits under many applied generative claims: if sampling from a well-behaved target can be made provably efficient, optimization and uncertainty methods can rely on stronger primitives.

ICML 2026

Local Diffusion Composition

Proves sparse local score dependencies are equivalent to conditional projective composition. It explains when a global diffusion model can be assembled from local pieces. That matters for structured domains where full joint modeling is expensive but local interactions are meaningful.

ICML 2026

Manifold Perturbations

Perturbs equality-constrained data distributions to gain ambient support while retaining manifold geometry. Many real objects live near lower-dimensional constraint surfaces. The method asks how to make those distributions learnable by ordinary samplers without destroying the geometry that defines validity.

ICML 2026

UDM-GRPO

Aligns reinforcement-learning optimization with unified diffusion-model probability paths to improve visual generation metrics. Its role here is sampler-aware post-training: reward optimization should respect the model's generative path instead of pushing against a mismatched objective.

ICML 2026

Reinforced SMC

Connects maximum-entropy RL-trained neural samplers with sequential Monte Carlo proposals and twist functions for unnormalized target sampling. It treats sampling as a sequential decision problem: each proposal changes the quality of future particles, so policy learning can shape the sampler itself.

SUBTHEME 04

Scientific Structure

Scientific generation must satisfy the world it claims to model.

Molecules, proteins, PDE states, weather fields, traffic systems, and biomedical inverse problems expose a stricter version of generative modeling. A sample can be fluent or visually plausible and still violate physics, chemistry, measurement, or synthesis constraints. These papers use priors, samplers, solvers, and uncertainty estimates to make generated scientific objects usable.

ICML 2026

LASER

Combines a latent world model with a POMDP policy to move sensors toward high-information regions of a continuum field. Generation is used for action: the model imagines the field well enough to decide what measurement would reduce uncertainty next.

ICML 2026

Autoregressive Boltzmann Generators

Uses autoregressive modeling for equilibrium sampling. The scientific object is not an image but a distribution over physical states. The method matters when it can cover relevant modes without paying the full cost of traditional simulation for every sample.

ICML 2026

OSM+

Provides city-scale traffic prediction and policy-control datasets. It turns urban mobility into a generative and decision problem: predict evolving state, evaluate interventions, and keep enough structure that policy changes can be studied rather than merely replayed.

ICLR 2026

Prism

Appears in the scientific physical-generation evidence as a structured generation system. Its role in this lane is to connect generated outputs to scientific constraints and evaluation, where the model must produce objects that can be inspected against domain-specific structure rather than generic plausibility.

ICML 2026

Control Consistency Losses

Uses control consistency as a constraint on generated trajectories. The core problem is that a predicted path can look plausible frame by frame while violating the control law that would have produced it. This makes dynamics a training signal instead of an after-the-fact diagnostic.

ICLR 2026

FALCON

Trains flows with accurate likelihoods for molecular equilibrium estimation. Molecules require mode coverage and density accuracy because rare conformations can matter. Flow-based generation becomes scientific only when the likelihood corresponds to the target physical distribution.

ICML 2026

Protein Autoregressive Modeling

Uses hierarchical protein structure to generate backbones coarse-to-fine. The key object is not a sequence alone but a folded 3D structure with constraints across scales. Autoregression is useful when it follows the hierarchy that biology already imposes.

ICML 2026

TEDBench / MiAE

Builds a benchmark around protein-fold similarity and leakage risk. It belongs here because scientific generation needs evaluation that can detect whether a model learned structure or merely benefited from near-duplicate examples in the benchmark.

ICML 2026

SRMC

Improves estimator variance and mode coverage on continuous targets and discrete energy-based models. The scientific point is that missing modes are not cosmetic failures. If a sampler misses rare but important physical states, the downstream estimate can be confidently wrong.

ICML 2026

SDEVI

Improves interpolation, extrapolation, regression, and classification across healthcare, physics, climate, and IoT data. It belongs in this lane because irregular scientific signals require models that can move between observed and unobserved states without pretending the data are complete or evenly sampled.

ICML 2026

Walrus

Pretrains a Transformer on fluid-like physical scenarios spanning multiple scientific domains. The bet is that physical structure can transfer across domains when the model learns reusable dynamics rather than memorizing one simulator. That makes pretraining a bridge between scientific systems.

ICLR 2026

FFDP

Scales multimodal registration by adapting distributed systems to convolution-heavy medical registration pipelines. Scientific modeling often fails at the systems layer: the right method is unusable if native-resolution data cannot fit. Here, infrastructure becomes part of the scientific method.

ICML 2026

Chamaileon

Unifies multi-target and multi-state binder design through contextualized sequence-structure co-modeling. Binder design is not one molecule against one static target. The model has to reason over multiple contexts, target states, and structural constraints at once.

ICML 2026

DeCoDe

Separates binding-position and molecular-conformation diffusion for structure-based drug design. The decomposition matters because where a molecule binds and how it flexes are related but not identical variables. Modeling them separately gives the sampler a cleaner physical object to control.

ICML 2026

DiBO

Uses bidirectional diffusion language modeling and label-improvement reinforcement learning for small-data design optimization. It treats design as a search loop under scarce measurements: generate candidates, improve labels, and bias the model toward better regions without requiring a huge labeled corpus.

ICML 2026

CoCLD

Combines diffusion latent interpolation with neural ODEs for arbitrary-time generation and alignment. The important object is a continuous trajectory through latent state. That makes it useful for scientific processes where the query time is not fixed in advance.

ICLR 2026

OrbEvo

Learns time-dependent electronic wavefunction coefficients under external electric fields. The object is quantum state evolution, not a static molecule. This makes generation and prediction answer to a physical operator over time, where small coefficient errors can change downstream properties.

ICLR 2026

cadrille

Generates editable Python CAD code from point-cloud, image, or text inputs for engineering reconstruction. It converts perceptual evidence into an executable design artifact. That matters because engineers need parametric, modifiable structure, not a mesh that merely resembles the object.

ICML 2026

MERLIN

Learns observation functionals with near-linear progression and resolution-free field reconstruction. The scientific object is a field that can be queried at different resolutions. MERLIN makes measurement design and reconstruction part of one representation rather than fixing a grid first.

ICML 2026

Dirac-Frenkel-Onsager

Injects momentum only along nullspace directions to stabilize nonlinear PDE parameter evolution without residual bias. It is a physics-aware optimization move: accelerate learning while respecting the equations' constraint structure rather than adding arbitrary momentum everywhere.

ICLR 2026

Complexa

Uses Teddymer synthetic binder-target pretraining plus experimental multimers to build a fully atomistic generative prior. The approach combines synthetic scale with experimental grounding, which is the central bargain in scientific generation: broad coverage must still be corrected by real measurements.

ICML 2026

FIDIA

Optimizes inverse-folding policies directly for Best-of-N high-fitness candidate selection. The important detail is the selection objective. Protein design often uses many generated candidates, so the policy should optimize the quality of the best sampled set, not only average likelihood.

ICLR 2026

mCLM

Tokenizes molecules into functional synthesis-compatible building blocks paired with natural-language function descriptions. It links molecular generation to synthesis and intent. The model is not only predicting chemical strings; it is building with units that can plausibly be made and described.

ICML 2026

MORetro*

Generates synthesis-route Pareto fronts over cost, sustainability, toxicity, yield, and user-defined criteria. Retrosynthesis is multi-objective by nature. This paper treats route generation as navigation across tradeoffs rather than a single best path.

SUBTHEME 05

Embodied Action

A robot policy is a generative model whose samples are actions.

Embodied AI makes the cost of invalid generation immediate. A bad action changes the world. These papers focus on perception that survives viewpoint changes, data that factors body from skill, reward signals that come from consequences, and policies that can act with uncertainty rather than only narrate plans.

ICML 2026

SAW-Bench

Reports a large human-model gap in coherent camera-geometry inference from egocentric videos. The benchmark matters because egocentric perception is the robot's native view. If the model cannot infer how the camera moved through space, its visual understanding will not support grounded action.

ICLR 2026

MomaGraph

Builds state-aware spatial-functional scene graphs for mobile manipulation and Graph-then-Plan execution. It converts a scene from pixels into actionable structure: objects have functions, relations, and states that decide what a robot should do next.

ICML 2026

RoboMME

Benchmarks memory-augmented vision-language-action variants across temporal, spatial, object, and procedural memory. The evaluation target is not only whether a robot can imitate one step, but whether it remembers the right kind of state for the task it is doing.

ICML 2026

OXE-AugE

Rebalances robot-arm and gripper diversity to improve unseen-robot manipulation after fine-tuning. The paper treats embodiment as distribution shift: the same skill must survive changes in the body that executes it.

ICML 2026

XR-1

Appears in the embodied evidence as a robot learning and deployment paper. Its lane-level role is to connect perception, action representation, and practical control, where a model has to output behavior under body and environment constraints rather than abstract instructions.

ICML 2026

DreamDojo

Uses generated or simulated practice as part of embodied learning. The important idea is that a robot can improve through worlds it can train in, but those worlds must preserve enough task structure that practice transfers to real action.

ICML 2026

HDFlow

Uses flow-style action modeling inside the robotics evidence set. This matters because high-dimensional action spaces are not well served by single deterministic outputs; a policy often needs to sample feasible motions from a structured action distribution.

ICML 2026

SCALE

Controls vision-language-action inference using the model's own output distribution as a deployment-time signal. It treats confidence and uncertainty as action controls, allowing a policy to regulate behavior without expensive external verifiers on every step.

ICML 2026

BehaviorVLA

Reports strong RoboTwin, LIBERO, CALVIN, and real-world transfer results with less data than comparable VLA training. The lane-level point is data efficiency under embodied variation: a policy has to learn reusable behavior, not memorize one robot, benchmark, or demonstration format.

ICML 2026

EgoTactile

Pairs egocentric video with full-hand pressure supervision for everyday-object grasp modeling. Tactile signals expose contact that vision can miss. This matters because manipulation is not only seeing the object; it is feeling whether the grasp, slip, force, and hand-object relation are physically right.

ICML 2026

PACT

Progressively tightens trajectory constraints while bounding policy shift and preserving manipulation success. The problem is control under correction: a policy must become safer or more constrained without moving so far that learned manipulation behavior collapses.

ICLR 2026

VPRL

Post-trains large vision models with GRPO for visual navigation tasks where text plans are a bottleneck. The method treats navigation as perception-conditioned reinforcement learning, not language-only planning. That is the right pressure when success depends on acting in space rather than explaining a route.

ICML 2026

JoSE

Uses mutual information to discover low-dimensional action manifolds for high-dimensional muscle control. Embodied action often has far fewer meaningful degrees of freedom than the actuator vector suggests. Finding that manifold makes control learnable and transferable.

ICLR 2026

RodriNet

Generalizes Rodrigues forward kinematics into a learnable operator for action processing. The paper brings known geometry into the policy machinery, so rotations and articulated motion are handled as structured transformations rather than generic vectors.

ICML 2026

Latent Action Supervision

Shows discrete latent action-token supervision is especially effective for training vision-language-action models. It argues that the action interface matters: if actions are represented at the right abstraction level, a model can learn behavior more cleanly than from raw low-level controls alone.

ICML 2026

LaST0

Models future visual dynamics, 3D structure, and proprioception in a latent reasoning space for VLA control. The method joins the three things a robot must keep together: what it sees, how the world will move, and where its own body is.

ICML 2026

ScaleMoE

Uses output-level and feature-level expert gating as a scaling axis for robotic and control benchmarks. Embodied tasks are heterogeneous: navigation, manipulation, perception, and control do not need the same expert every step. Gating lets capacity follow the physical subproblem currently active.

ICML 2026

PST Motion Retrieval

Aligns body joints, temporal motion segments, and text tokens through pyramidal Shapley-Taylor learning. Motion retrieval needs credit assignment over both time and body parts. The paper makes the explanation of a motion query decompose across joints, segments, and language rather than treating the sequence as one opaque embedding.

ICML 2026

Unsupervised Partner Design

Reports human-study gains in return, perceived adaptiveness, human-likeness, and reduced frustration. Embodied intelligence often involves another actor, not a static environment. The paper treats partner behavior as a training object, so policies learn to adapt to unseen collaborators rather than one scripted teammate.

ICML 2026

TimeRewarder

Uses real-world human videos as scalable supervision for manipulation reward models. The method turns observed human behavior into temporal reward evidence. It matters because robot reward design is expensive, and videos provide broad examples of what progress, contact, and completion look like.

ICML 2026

HALO

Stabilizes decentralized human-robot policy learning by contracting the rationality gap. Human-robot systems fail when assumptions about the other actor drift apart. HALO treats coordination as a stability problem: learning should reduce the gap between modeled and actual partner behavior.

ICML 2026

Continual VLA Forgetting

Shows large pretrained vision-language-action models can retain prior robot skills with simple experience replay. The embodied lesson is that new physical skills do not have to erase old ones if the replay signal preserves enough action diversity. Continual learning becomes a data-selection problem over embodied traces.

ICML 2026

MSP

Generates long-horizon robotic actions coarse-to-fine while maintaining cross-scale latent consistency. Long tasks need abstraction: the policy should decide broad subgoals before fine control. Cross-scale consistency prevents the detailed action stream from contradicting the high-level plan.

ICML 2026

DroneDINO

Organizes experts into shared, task-specific, and dynamic groups for RGB, infrared, and RGB-infrared detection. A drone perception system faces different sensor conditions and tasks during deployment. Expert routing lets the model use common structure while still specializing for modality and task pressure.

SUBTHEME 06

Human Signals Beyond Images

Grounding includes timing, voice, culture, emotion, and modality credit.

The physical world is not only geometry. Human-facing systems have speech latency, prosody, emotion, multilingual variation, social context, and cross-modal evidence conflicts. These papers widen grounding from "what is in the image" to "which signal supports the answer, and under what human timing or cultural constraint?"

ICML 2026

EEmo-Logic

Uses instruction tuning and task-specific GRPO rewards for multimodal emotion question answering and assessment. Emotion is hard because the evidence is distributed across face, voice, context, and language; the reward has to shape reasoning over those signals rather than a generic label.

ICML 2026

Hibiki-Zero

Trains simultaneous speech translation from sentence-level alignments and optimizes latency with GRPO. It removes the need for word-level alignment while still respecting time, which is central because translation quality is useless if it arrives too late for conversation.

ICLR 2026

EmotionThinker

Grounds speech emotion reasoning in fine-grained acoustic cues. The important shift is from classifying emotion as a label to explaining which vocal evidence supports the judgment, making affective modeling closer to auditable multimodal reasoning.

ICLR 2026

WAVE

Learns instruction-conditioned text-audio-video embeddings. It treats retrieval and grounding as conditional on what the user is asking for, so the same media clip can be organized by different semantic, acoustic, or temporal aspects.

ICML 2026

TokSuite

Tests multilingual tokenizer robustness under native-curated perturbations. The problem is not only language coverage but whether tokenization preserves meaning under real orthographic and cultural variation, especially outside dominant languages.

ICLR 2026

ATLAS

Fits multilingual transfer scaling laws across many training and evaluation languages. It turns cross-lingual data allocation into a measurable transfer matrix: which languages help which others, and where extra data or compute actually buys coverage.

ICLR 2026

FRABench / UFEval

Builds a broad aspect taxonomy and labels to test whether multimodal judges generalize to unseen evaluation criteria. It matters because a judge that only learns familiar rubrics cannot reliably evaluate new visual qualities or social criteria.

ICML 2026

Visual Attribution Streaming

Studies attribution in a streaming visual setting. It asks whether a model can keep track of which visual evidence caused a conclusion as the observation changes over time, which is exactly the kind of trace needed for trustworthy multimodal systems.

ICML 2026

AGREE

Routes gradients through attribute-specific subspaces based on sample-wise aesthetic sensitivity. Aesthetic judgment is not one scalar property: color, composition, subject, style, and artifact sensitivity can pull in different directions. The method treats those attributes as separate learning pressures rather than averaging them away.

ICLR 2026

MetamerGen

Uses same-different human judgments to identify generated images that match latent scene percepts. The paper is about perception as humans experience it, not only pixel distance. A generated image can be equivalent for a viewer even when it is not identical, which makes human judgment part of the measurement object.

ICML 2026

Causal Route Gating

Decomposes attention heads into visual and text routes, then suppresses prior-dominant text paths to reduce hallucination. The failure is modality credit assignment: the model answers from language priors when the image should decide. Gating makes the route of evidence explicit enough to intervene.

ICML 2026

Seizure-Semiology-Suite

Provides dense labels over ILAE semiological features and hierarchical tasks for medical MLLM evaluation. Medical video understanding needs structured clinical concepts, not only generic visual descriptions. The suite tests whether a model can map multimodal evidence into the decision vocabulary clinicians actually use.

ICLR 2026

Active Mind Avatars

Uses MLLM-generated structured semantics to guide expressive avatar animation beyond audio synchrony. The target is not lip sync alone. A believable avatar needs intent, affect, timing, gesture, and semantic state to cohere as one embodied expression.

ICLR 2026

VC-STaR

Uses visually similar VQA pairs to generate less hallucinated rationales for supervised fine-tuning. It attacks a specific weakness: rationales can sound plausible while ignoring the image. Contrastive visual pairs force the explanation to depend on what actually changed in the scene.

ICML 2026

WETR

Suppresses redundant multimodal tokens and reweights sparse emotional cues under frozen MLLM parameters. Emotion and affect often live in weak signals, so the model must avoid drowning them in high-volume but irrelevant visual or textual tokens.

ICML 2026

VideoKR

Uses expert-annotated questions that require genuine video understanding and reduce textual shortcut success. It belongs here because human signal is not only annotation volume. The question design must force the model to use temporal evidence rather than guessing from captions or prior knowledge.

ICLR 2026

TTSDS2

Addresses evaluation difficulty when synthetic speech becomes hard to distinguish from real speech. The problem is that audio generation progress can outrun old detectors. Evaluation has to measure artifacts, speaker identity, prosody, and realism under the assumption that simple real-versus-fake cues are disappearing.

ICML 2026

DLMR

Separates visual memory from reasoning memory and routes between them during long-horizon MLLM inference. Multimodal reasoning fails when evidence storage and symbolic reasoning are conflated. The architecture says visual state and reasoning state should be different memories with explicit routing between them.

ICML 2026

RFCMH

Models noisy cross-modal labels with possibility and necessity measures instead of discarding or smoothing them. Cross-modal labels are often uncertain rather than simply right or wrong. Possibility and necessity let the model represent partial reliability, which is more faithful than pretending every pair is equally trustworthy.

ICLR 2026

Omni-Reward

Trains discriminative and generative reward models on preference and instruction data. It belongs here because multimodal generation increasingly depends on reward models that understand images, video, audio, and instructions. The reward is a grounding layer between user intent and sample selection.

ICML 2026

LIMSSR

Combines uncertainty-calibrated reasoning with cross-modal pattern recovery for incomplete multimodal action-quality assessment. The paper addresses a common real setting: one modality is missing or weak. A useful system should expose uncertainty and infer what can be inferred, not behave as if all evidence is present.

ICML 2026

DAVE

Produces precise attribution maps across supervised, self-supervised, and interpretable vision transformers. Attribution is not decoration here; it is the audit surface for vision systems. If the model's decision depends on the wrong region, downstream multimodal reasoning inherits a false premise.

ICML 2026

VJA

Uses training-free reasoning over visual intent to improve image editing safety without guard models. The safety object is user intent as expressed through visual context. Instead of adding a separate filter, the method reasons about what the edit is trying to do and whether that action should proceed.

ICLR 2026

UALM

Combines audio understanding, text-to-audio generation, text reasoning, and multimodal reasoning in one model. It represents the broader trend in this lane: audio is no longer a side channel. A single system has to understand and produce sound while coordinating that signal with language-level reasoning.

FIELD READ

What This Lane Says About ICML and ICLR

The conference is converging on a practical claim: generation is useful when it becomes a controllable representation of a world. The old surface test was whether an image, video, molecule, or plan looked plausible. The new test is whether the object can be measured, simulated, edited, executed, verified, or used by another system.

This is why the physical/generative lane belongs after safety, agents, and data/systems. Safety asks what evidence should count. Agents ask how actions change state. Data and systems ask what substrate makes capability affordable. Physical and generative modeling asks whether the system can produce structured worlds and objects that remain valid when reality pushes back.
