FIRST PRINCIPLE

A Generated Object Has To Live Somewhere

A sentence can be judged by whether it is coherent. A physical object, video, robot plan, molecule, city simulation, or scientific field has a harder requirement: it has to live in a state space with constraints. Objects have depth, pose, contact, dynamics, conservation laws, synthesis routes, uncertainty, and downstream actions. If the model ignores those constraints, the sample can look good while being useless.

That is the center of this lane. The conference is pushing generation from surface realism toward usable structure. Diffusion, flows, autoregressive decoders, world models, robot policies, simulators, reward models, and scientific priors are different approaches to the same problem: make a model produce something that remains valid when inspected, manipulated, simulated, measured, or acted on.

FIELD SHAPE

The Five Pressures Behind The Papers

Geometry
Images, videos, scenes, and robot observations need coordinate systems. Depth, camera pose, 3D Gaussian splats, orthographic views, and spatial language all exist to stop a model from confusing appearance with world structure.
Dynamics
Long video, traffic, weather, continuum fields, and robot control are trajectories. The object is not one frame or one answer, but a state that changes under time, action, and uncertainty.
Constraint
Molecules, proteins, physical fields, and feasible robot motions must obey constraints. The method is only useful if it narrows search without destroying validity.
Grounding
Multimodal models need to know which modality, feature, view, sound, or tactile signal supports a conclusion. Otherwise confidence becomes a fluent story over weak evidence.
Verification
Generation needs outcome checks: physical plausibility, visual consistency, simulation success, reward alignment, synthesis feasibility, and safety/provenance hooks.

SUBTHEME 01

Spatial Grounding

The model has to carry a coordinate system, not only a caption.

Many visual-language systems fail because they treat spatial questions as another text prediction problem. These papers make geometry explicit: cameras, rays, depth, Gaussian splats, 3D views, and scene graphs become part of the representation so the model can reason about where objects are, how views relate, and what action would be possible.

ICLR 2026

Depth Anything 3

Predicts spatially consistent geometry from arbitrary visual inputs, with or without known camera poses. The problem is that image models can recognize objects while still lacking metric structure. By tying depth and ray prediction together, it moves visual understanding toward a representation that can support reconstruction, rendering, navigation, and downstream embodied reasoning.

ICLR 2026

Camera-Aware MLLM

Injects camera parameters and augmentation into multimodal language models so spatial answers are not silently overfit to viewpoint statistics. The key idea is that a model cannot reliably answer geometry questions if the camera is treated as invisible. Camera metadata becomes evidence, not metadata decoration.

ICML 2026

3ViewSense

Gives VLMs canonical orthographic views and separates simulation from reasoning. This attacks a common failure: a single perspective can hide the structure needed for action. The method makes spatial judgment easier by changing the observation into views where geometry is less ambiguous.

ICML 2026

Holi-Spatial

Builds spatial supervision from 3D Gaussian-splatting scenes, including masks, boxes, captions, grounding instances, and spatial question answering. The paper matters because spatial capability is data-hungry: if the supervision only names objects, the model will not learn relations, depth, containment, support, or navigable structure.

ICML 2026

TideGS

Targets billion-scale 3D Gaussian splatting, where scene representation becomes a systems and geometry problem at once. It is not enough to generate a pretty scene; the representation has to be compact, renderable, and stable enough to serve as a world model for later inspection.

ICML 2026

VGGT-Motion

Connects visual geometry with motion estimation, which is the bridge from static reconstruction to action. The model must infer not only what the scene is, but how objects and cameras move through it. That makes it part of the same pressure as robot perception and long-horizon video modeling.

ICML 2026

SpatioLM

Treats spatial layout as language-model-readable structure rather than leaving it buried in pixels. The deeper move is interface design: if spatial state is represented in a form a reasoning model can use, planning and question answering can operate over the same scene facts.

ICLR 2026

DepthLM

Uses VLM machinery to recover metric depth without relying on a conventional dense depth head. It shows how language-supervised models can be pulled toward physical measurement, but only if the training and prompting expose the metric object explicitly.

SUBTHEME 02

Worlds And Video

A world model is useful only if its futures remain coherent.

Video and simulation papers are about temporal state. A generated future can drift, forget constraints, break object identity, or become visually plausible but actionally wrong. The serious question is whether generated trajectories preserve enough structure to support planning, editing, evaluation, or closed-loop simulation.

ICLR 2026

Stable Video Infinity

Trains diffusion transformers on self-generated error trajectories so long videos can correct drift instead of compounding it. The failure mode is familiar from autoregressive systems: each plausible step pushes the next step slightly off-manifold. Error recycling turns those failures into training signal for temporal stability.

ICLR 2026

SANA-Video

Uses Linear DiT and block-wise constant-memory state for high-resolution minute-long video generation. This is not only an efficiency trick. Long video requires memory discipline because the model must preserve state over time without making the computation explode.

ICLR 2026

FlashWorld

Appears in both multimodal and generative evidence because it sits at the boundary between video generation and world modeling. The point is to make generated visual futures fast enough to become an interactive substrate, where the next action can depend on imagined state rather than a static prompt.

ICML 2026

SceneSmith

Uses designer, critic, and orchestrator VLM agents to generate dense simulation-ready indoor robot environments. The generated artifact is not an image; it is a usable scene. That makes simulation quality, object placement, functional affordance, and criticism part of the generation loop.

ICML 2026

VectorWorld

Generates streaming vector-graph driving worlds for real-time closed-loop autonomous simulation. Driving simulation cannot be a bag of frames because policy behavior changes the future. The generated world has to expose lanes, actors, timing, and graph structure that can respond to decisions.

ICML 2026

WestWorld

Uses world-modeling structure inside the RL and embodied evidence set. Its importance is that simulated futures become training pressure: an agent needs internal dynamics that let it evaluate consequences before acting, not only imitate actions from past demonstrations.

ICML 2026

Motive

Uses motion-weighted gradients to find fine-tuning clips that improve or degrade temporal dynamics. It treats video data value as motion-specific, which is the right object: a clip with rich temporal change can teach dynamics that a visually rich but static clip cannot.

ICML 2026

VideoFlexTok

Works on adaptive video tokenization, where the model spends representation on the parts of a stream that carry information. This matters because long video cannot keep every pixel equally important; temporal reasoning depends on compressing without erasing the events that explain later state.

SUBTHEME 03

Generative Samplers

Sampling is becoming controlled transport through a state space.

The generative modeling papers are less about one favorite architecture and more about the mechanics of moving probability mass. Diffusion, flows, masked decoding, energy models, reward guidance, and watermarking all ask how to steer samples while preserving the distributional facts that make the generator useful.

ICML 2026

AGSM

Integrates contrastive text-image alignment directions into the diffusion score-matching objective. Instead of bolting guidance on after training, it changes the training target so alignment becomes part of the denoising field. The tradeoff is whether that steering improves prompt faithfulness without narrowing the model's visual support too aggressively.

ICLR 2026

NextStep-1

Pairs a large autoregressive model with a flow-matching head to predict continuous image tokens without vector-quantization loss. The paper attacks a representation bottleneck: if image tokens are too discrete, generation inherits codebook artifacts. Continuous tokens make image generation look more like structured regression over visual state.

ICLR 2026

Energy-Based Transformers

Applies energy-based inference across discrete and continuous modalities. The important shift is that prediction becomes search for low-energy compatibility rather than one pass through a softmax. That gives the model a common language for text, image, and other continuous signals.

ICML 2026

Any-Order GPT

Evaluates masked diffusion models as any-order autoregressive models inside GPT-style architectures. It questions the rigid left-to-right assumption: for some objects, the right generation order may be flexible, learned, or dependent on which parts are most constrained.

ICLR 2026

Spherical Watermark

Embeds watermark information through transformations of Gaussian diffusion noise while preserving the latent distribution. The useful idea is provenance without obvious distribution damage: a watermark should be detectable by the holder and hard to see as an artifact in the generated media.

ICML 2026

Concept Removal Guidance

Estimates unwanted concept presence from diffusion noise predictions and calibrates negative guidance during denoising. It treats safety as trajectory steering rather than full retraining. The risk is over-removal, so the method matters when it suppresses target concepts while preserving benign generation quality.

ICML 2026

Divide-and-Denoise

Splits generation into smaller denoising problems so structure can be controlled locally. The deeper point is decomposition: if a global sample is hard to steer, break the object into pieces whose constraints can be handled more reliably and then compose them.

ICLR 2026

GLASS Flows

Combines efficient ODE-style flow behavior with stochastic evolution for inference-time reward alignment. It belongs in this lane because guidance is treated as a sampler property, not only a reward-model score after the fact.

SUBTHEME 04

Scientific Structure

Scientific generation must satisfy the world it claims to model.

Molecules, proteins, PDE states, weather fields, traffic systems, and biomedical inverse problems expose a stricter version of generative modeling. A sample can be fluent or visually plausible and still violate physics, chemistry, measurement, or synthesis constraints. These papers use priors, samplers, solvers, and uncertainty estimates to make generated scientific objects usable.

ICML 2026

LASER

Combines a latent world model with a POMDP policy to move sensors toward high-information regions of a continuum field. Generation is used for action: the model imagines the field well enough to decide what measurement would reduce uncertainty next.

ICML 2026

Autoregressive Boltzmann Generators

Uses autoregressive modeling for equilibrium sampling. The scientific object is not an image but a distribution over physical states. The method matters when it can cover relevant modes without paying the full cost of traditional simulation for every sample.

ICML 2026

OSM+

Provides city-scale traffic prediction and policy-control datasets. It turns urban mobility into a generative and decision problem: predict evolving state, evaluate interventions, and keep enough structure that policy changes can be studied rather than merely replayed.

ICLR 2026

Prism

Appears in the scientific physical-generation evidence as a structured generation system. Its role in this lane is to connect generated outputs to scientific constraints and evaluation, where the model must produce objects that can be inspected against domain-specific structure rather than generic plausibility.

ICML 2026

Control Consistency Losses

Uses control consistency as a constraint on generated trajectories. The core problem is that a predicted path can look plausible frame by frame while violating the control law that would have produced it. This makes dynamics a training signal instead of an after-the-fact diagnostic.

ICLR 2026

FALCON

Trains flows with accurate likelihoods for molecular equilibrium estimation. Molecules require mode coverage and density accuracy because rare conformations can matter. Flow-based generation becomes scientific only when the likelihood corresponds to the target physical distribution.

ICML 2026

Protein Autoregressive Modeling

Uses hierarchical protein structure to generate backbones coarse-to-fine. The key object is not a sequence alone but a folded 3D structure with constraints across scales. Autoregression is useful when it follows the hierarchy that biology already imposes.

ICML 2026

TEDBench / MiAE

Builds a benchmark around protein-fold similarity and leakage risk. It belongs here because scientific generation needs evaluation that can detect whether a model learned structure or merely benefited from near-duplicate examples in the benchmark.

SUBTHEME 05

Embodied Action

A robot policy is a generative model whose samples are actions.

Embodied AI makes the cost of invalid generation immediate. A bad action changes the world. These papers focus on perception that survives viewpoint changes, data that factors body from skill, reward signals that come from consequences, and policies that can act with uncertainty rather than only narrate plans.

ICML 2026

SAW-Bench

Reports a large human-model gap in coherent camera-geometry inference from egocentric videos. The benchmark matters because egocentric perception is the robot's native view. If the model cannot infer how the camera moved through space, its visual understanding will not support grounded action.

ICLR 2026

MomaGraph

Builds state-aware spatial-functional scene graphs for mobile manipulation and Graph-then-Plan execution. It converts a scene from pixels into actionable structure: objects have functions, relations, and states that decide what a robot should do next.

ICML 2026

RoboMME

Benchmarks memory-augmented vision-language-action variants across temporal, spatial, object, and procedural memory. The evaluation target is not only whether a robot can imitate one step, but whether it remembers the right kind of state for the task it is doing.

ICML 2026

OXE-AugE

Rebalances robot-arm and gripper diversity to improve unseen-robot manipulation after fine-tuning. The paper treats embodiment as distribution shift: the same skill must survive changes in the body that executes it.

ICML 2026

XR-1

Appears in the embodied evidence as a robot learning and deployment paper. Its lane-level role is to connect perception, action representation, and practical control, where a model has to output behavior under body and environment constraints rather than abstract instructions.

ICML 2026

DreamDojo

Uses generated or simulated practice as part of embodied learning. The important idea is that a robot can improve through worlds it can train in, but those worlds must preserve enough task structure that practice transfers to real action.

ICML 2026

HDFlow

Uses flow-style action modeling inside the robotics evidence set. This matters because high-dimensional action spaces are not well served by single deterministic outputs; a policy often needs to sample feasible motions from a structured action distribution.

ICML 2026

SCALE

Controls vision-language-action inference using the model's own output distribution as a deployment-time signal. It treats confidence and uncertainty as action controls, allowing a policy to regulate behavior without expensive external verifiers on every step.

SUBTHEME 06

Human Signals Beyond Images

Grounding includes timing, voice, culture, emotion, and modality credit.

The physical world is not only geometry. Human-facing systems have speech latency, prosody, emotion, multilingual variation, social context, and cross-modal evidence conflicts. These papers widen grounding from "what is in the image" to "which signal supports the answer, and under what human timing or cultural constraint?"

ICML 2026

EEmo-Logic

Uses instruction tuning and task-specific GRPO rewards for multimodal emotion question answering and assessment. Emotion is hard because the evidence is distributed across face, voice, context, and language; the reward has to shape reasoning over those signals rather than a generic label.

ICML 2026

Hibiki-Zero

Trains simultaneous speech translation from sentence-level alignments and optimizes latency with GRPO. It removes the need for word-level alignment while still respecting time, which is central because translation quality is useless if it arrives too late for conversation.

ICLR 2026

EmotionThinker

Grounds speech emotion reasoning in fine-grained acoustic cues. The important shift is from classifying emotion as a label to explaining which vocal evidence supports the judgment, making affective modeling closer to auditable multimodal reasoning.

ICLR 2026

WAVE

Learns instruction-conditioned text-audio-video embeddings. It treats retrieval and grounding as conditional on what the user is asking for, so the same media clip can be organized by different semantic, acoustic, or temporal aspects.

ICML 2026

TokSuite

Tests multilingual tokenizer robustness under native-curated perturbations. The problem is not only language coverage but whether tokenization preserves meaning under real orthographic and cultural variation, especially outside dominant languages.

ICLR 2026

ATLAS

Fits multilingual transfer scaling laws across many training and evaluation languages. It turns cross-lingual data allocation into a measurable transfer matrix: which languages help which others, and where extra data or compute actually buys coverage.

ICLR 2026

FRABench / UFEval

Builds a broad aspect taxonomy and labels to test whether multimodal judges generalize to unseen evaluation criteria. It matters because a judge that only learns familiar rubrics cannot reliably evaluate new visual qualities or social criteria.

ICML 2026

Visual Attribution Streaming

Studies attribution in a streaming visual setting. It asks whether a model can keep track of which visual evidence caused a conclusion as the observation changes over time, which is exactly the kind of trace needed for trustworthy multimodal systems.

FIELD READ

What This Lane Says About ICML and ICLR

The conference is converging on a practical claim: generation is useful when it becomes a controllable representation of a world. The old surface test was whether an image, video, molecule, or plan looked plausible. The new test is whether the object can be measured, simulated, edited, executed, verified, or used by another system.

This is why the physical/generative lane belongs after safety, agents, and data/systems. Safety asks what evidence should count. Agents ask how actions change state. Data and systems ask what substrate makes capability affordable. Physical and generative modeling asks whether the system can produce structured worlds and objects that remain valid when reality pushes back.
