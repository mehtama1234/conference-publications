FIRST PRINCIPLE

A Failure Mode Is A Broken Assumption

A method fails mathematically when the object it protects is not the object deployment needs. The benchmark measures the wrong latent variable. The quotient removes a relevant coordinate. The cache keeps common tokens and drops rare evidence. The verifier observes a proxy artifact. The sampler covers attractive modes and misses dangerous modes.

Treating failure modes as objects makes future work concrete. For each paper, ask which assumption breaks first and what evidence would reveal the break before deployment.

Proxy driftThe score, reward, or verifier remains aligned with the real target under optimization.Gradient points toward measured success but away from true success.RLVepsR, TRACE Effort, JudgeBench, WebDevJudge, Omni-Reward.Disagreement audits, proxy-target alignment, reward hacking examples, truncated-process tests.Model the measurement channel and require evidence that the proxy remains aligned after optimization.
False invarianceThe transformation treated as nuisance really preserves the target.Quotienting collapses distinctions that affect downstream behavior.Quotient-Space Diffusion, Camera-Aware MLLM, GraphGlue, protein and molecule models.Transformed-input consistency plus task cases where orientation, labels, or viewpoint should matter.State the group action and test when the transformation stops being invariant.
Missing sufficient stateThe compressed state contains all future-relevant information.Performance holds on common cases but fails on delayed, rare, or dependency-heavy cases.ThinKV, STAR-KV, EntroKV, Skill-Pro, DLMR, VideoKR, Mamba Markov ICL.Rare-fact retention, long-horizon perturbations, full-history comparisons, stale-memory tests.Define the target family for sufficiency and test the state against adversarially delayed evidence.
Bad feasible setThe constraint set matches the real validity boundary.Valid outputs are blocked or invalid outputs remain reachable.CSPO, Pi-net, Copyright-Bench, ReaSyn, MORetro*, Fair OT, PACT.Boundary cases, violation rates, feasible-object recall, false refusals, route-validity tests.Audit both sides of the boundary: false positives and false negatives.
Tail blindnessOrdinary samples reveal the risk that matters.Mean score improves while low-probability harmful mass remains unmeasured.Rare Event Analysis, Tail Risks, Jailbreak Foundry, SandboxEscapeBench, FlowGuard, SRMC.Tail confidence intervals, proposal coverage, near-boundary examples, adaptive attacks.Define event sets explicitly and use proposal or stress distributions with variance checks.
Spectral mirageTop directions are stable and target-aligned.Large singular or eigen directions explain variance but not task behavior.Alignment-Sensitive Rates, BBP Transitions, Low-Rank LM Logits, SVD Interpretability, Jacobian Spectra.Bootstrap stability, target alignment, perturbation sensitivity, held-out behavior preservation.Separate variance explanation from causal or predictive signal.
Wrong update geometryThe metric used in analysis matches the optimizer and deployment behavior.Update looks small in one geometry but damages stiff or hidden directions.Adam Degeneracy, DiReCT, LoRA Theory, Trust-Region RL, Beyond Muon, RAIN-Merging.Curvature energy, off-target capability loss, projected-update comparisons, optimizer ablations.Report movement in the metric that actually governs loss and safety.
Transport support missThe sampler or proposal covers all important modes.Generated artifacts look plausible but omit rare, unsafe, or scientifically important regions.FALCON, SRMC, Cauchy Bridges, Safety-Guided Flow, DMPO, Quantized Diffusion.Mode recall, likelihood calibration, effective sample size, proposal stress, guidance bias.Audit support coverage and path-level error, not only final sample quality.
Identification overclaimThe data and assumptions select one effect, graph, route, or mechanism.Output is more specific than the equivalence class justified by evidence.Distributional Equivalence, Local Covariate Selection, Structure Learning CI, DiCoLa, BRCD.Equivalence classes, non-identification examples, CI power, hidden-confound stress tests.Return identified sets and state which assumptions narrow them.
Verifier mismatchThe verifier observes the artifact where correctness lives.Generated output passes a checker that is not checking the real claim.CyberGym, VERINA, WZ-LLM, PaperBench, WebDevJudge, OmniVerifier.Verifier scope, false positives, execution traces, formal failure logs, human disagreement.Bind the verifier to the native artifact and state the unverified region.
Strategic response gapOther actors do not change behavior in ways outside the model.Mechanism succeeds under static assumptions but fails under adaptation or misreporting.AdvGame, Accuracy Auctions, Data Market Pricing, OMAC, Constrained Nash, Fair Causal Bandits.Adaptive attacks, truthful-report tests, equilibrium distance, payoff sensitivity, collusion checks.Model response dynamics and test incentives under perturbed payoff assumptions.
Entangled latent interfaceThe latent coordinate isolates the intended variable.Steering, decoding, or intervention moves unintended behavior with the target behavior.Steer Like The LLM, The Tell-Tale Norm, MINT, Causal Route Gating, PRISM, Mind-Omni.Off-target audits, layer ablations, counterfactual swaps, transfer tests, route interventions.Measure locality: what else changes when the latent control is moved?
Tradeoff hidingOne scalar objective faithfully represents multiple objectives.Improvement hides loss on safety, cost, fairness, detection, or subgroup value.ParetoPO, SecFid, Catch-22, SafeDPO, VALUEFLOW, Fair OT, LiftQuant.Frontier curves, weight sensitivity, subgroup reversals, false-positive cost, utility loss.Report the frontier before selecting a scalar operating point.
Finite-sample overconfidenceThe sample supports the distribution-level claim.Rankings, certificates, or discoveries reverse under resampling or new environments.Micro-Benchmarking Reliability, Finite Test Certification, ATLAS, Neural Effect Search, UFEval.Bootstrap intervals, held-out environments, multiplicity control, confidence targets.State sample complexity and uncertainty beside the claim.
Finite-machine mismatchThe theorem describes the arithmetic and hardware actually used.Guarantee holds in real arithmetic or ideal memory but fails under quantization, layout, or latency.Floating-Point Neural Networks, QAT Scaling, TetraJet, TileLang, IO-Aware GNN, Quantized Diffusion.Hardware traces, numerical sensitivity, memory bandwidth, timestep error, precision ablations.Include machine assumptions in the mathematical claim.
Artifact decomposition errorSubcomponents can be checked independently without losing claim dependencies.Proof, paper, code, or web artifact has passing parts but broken dependency structure.PaperBench, Bitween, RefineStat, MedAgentGym, WebDevJudge, VERINA.Dependency graph failures, reproduction gaps, invalid citations, component interaction tests.Verify the artifact graph, not only local components.
Modality credit failureThe intended modality caused the answer.The answer stays correct under visual swaps or changes for the wrong channel.VISUALSWAP, MoCA, MINT, Causal Route Gating, Visual Attribution Streaming, LIMSSR.Swap interventions, route ablations, text-prior controls, missing-modality calibration.Use causal interventions over modality channels, not only attention heatmaps.
Plasticity timing missThe model can still learn the structure provided by data or curriculum.Helpful data becomes inert or destructive because it arrives at the wrong phase.Midtraining Bridges, LR Decay, Procedural Pretraining, h1, OpenThoughts, DiReCT.Phase ablations, gradient alignment over time, representation drift, retained general capability.Treat training as a path and evaluate when the same evidence has value.
BIG PICTURE

How This Guides The Next Pass

Future paper expansions should not only add more names. They should ask which failure mode the paper is trying to prevent and whether the evidence actually detects that failure. A safety paper without tail evidence, a benchmark paper without measurement uncertainty, a compression paper without behavior drift, or a causal paper without an identified set is still incomplete at the first-principles level.

The atlas now has a loop: object, proof sketch, equation, evidence, and failure. That loop is the standard for making each remaining paper mathematically legible.
