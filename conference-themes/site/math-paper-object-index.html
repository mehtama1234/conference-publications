Trace, State, And Agent Loops

Controlled Inference

RAGEN-2

People learn multi-step work by first learning the links. A model faces the same issue: if credit only arrives at the end of a long task, it may not know which earlier step mattered. In science, a pretty molecule or state is not enough; its weight in the whole population matters. Trace Dependence And Horizon Credit

RAGEN-2
whether the scratch work reveals the exact question it came from
A generic template can look varied while still ignoring the case in front of it. OpenThoughts

h1
teaching short cause-and-effect links before asking for long work chains
If feedback arrives only after many steps, the learner may not know which earlier move helped. The curriculum grows chain length slowly so local moves still connect to final success. Formal label if needed: a dependency-chain curriculum.

an internal gauge used to decide whether extra thinking is worth trying

whether damaging the claimed reasoning also damages the answer

tau2-bench
one outside task state changed by the user, agent, tools, and rules

Agent Reasoning Evidence Examples: Tools And Mechanisms

These rows treat agents as decision systems under cost, uncertainty, and strategic response. The useful evidence is not that the agent did more work; it is that the extra action changed the frontier or the mechanism in the intended direction.

Tool Use And Executable Certificates

ParetoPO
the set of tool-use plans where no cheaper plan gets the same result
The method works by refusing to collapse tool use into a single reward. A tool call is rational only when the added information or capability is worth latency, money, risk, and extra state. Formal label if needed: an accuracy-cost frontier for tool policies.

CyberGym
an attack that should run before the fix and fail after the fix
A security explanation is not enough. The same proof-of-concept should exploit the vulnerable code, then stop working once the patch is applied. Formal label if needed: a pre-patch/post-patch exploit certificate.

THOR / TerminalTraj-style Agent Infrastructure
tool-use traces that keep the files, commands, environment, and errors that caused success or failure
Tool trajectories are useful training evidence only when they preserve the state variables that mattered. A cleaned trace should not erase the command, file, environment, or error condition that made the step work or fail. Formal label if needed: normalized tool and terminal trajectory state.

ThinkV / EntroKV
kept context entries that still change later decisions
Memory allocation works when retained states are close to enough for future choices. The value of a token or cache entry is whether removing it changes later uncertainty or behavior, not its age or average attention alone. Formal label if needed: future value of retained context or cache state.

OMAC

Several agents help only if the role split creates evidence that one model call would not. The division of labor may change, but the final rule must preserve useful minority evidence instead of averaging it away. Formal label if needed: a collaboration graph over roles and messages.

Rational Agents
asking or acting only when the answer is likely to improve enough to justify the cost
More information is not automatically better. A question is worth asking only if it is likely to change the final decision more than it costs in time, money, or risk. Formal label if needed: expected value of information under action cost.

MASPOB And LatentMAS
hidden team roles that summarize who knows what and who should act

AdvGame / Accuracy Auctions / Mechanism Papers
