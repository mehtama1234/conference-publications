FIRST PRINCIPLE

Depth Means The Claim Survives The Template

A paper is fully deepened only when a reader can recover the problem, state space, thing being measured or changed, preserved quantity, allowed movement, why the method works, evidence check, failure boundary, and cross-paper role. This backlog marks where that full treatment should go next.

Priority is not just popularity. A high-priority paper family either anchors many other papers, exposes a recurring failure mode, connects ICML and ICLR habits, or supplies a reusable object that appears across several lanes.

RAGEN-2 / TRACE EffortP0 reasoningAnchors the claim that reasoning quality is about the work path, not only the final answer.The mix of reasoning routes taught or rewarded, and whether each route still depends on the question.Check the middle work while reward pressure is applied.Change task facts and verify that the work path changes for the right reason.The model keeps the same polished format while the work stops depending on the task.Agents, benchmarks, hidden control signals.
Tell-Tale Norm / Steer Like The LLMP0 reasoningConnects internal warning lights to control while the answer is being made.The size and direction of hidden internal numbers that may mark effort, uncertainty, refusal, or reasoning.Change the inside model state directly instead of only changing prompt wording.Check which layer moved, what else changed, and whether the answer improved for the intended reason.The internal move changes style, uncertainty, or refusal while leaving reasoning untouched.Multimodal routes, safety steering, brain tokens.
h1 / OpenThoughtsP0 reasoningExplains why long work needs lessons in the right order.The chain of smaller tasks where later steps only make sense if earlier steps were done correctly.Make tasks longer a little at a time while keeping the feedback tied to the real job.Remove, move, or scramble parts of the chain and check whether the model notices the broken dependency.Short-task gains do not transfer to real long chains where one early mistake changes the later work.Training phases, data timing, agent planning.
Skill-Pro / terminal trajectoriesP0 agentsShows when an agent can turn past work into a reusable habit.A remembered work recipe, including when it is allowed to start and what counts as being done.Compress checked work records into skills that can be reused only under the right conditions.Move the skill to similar but not identical tasks and check whether old habits still apply.The skill fires in a situation where one of its starting assumptions is false.CyberGym, artifact verifiers, sufficient memory.
ParetoPO / tool-cost policiesP0 agentsForces agent evaluation to count both whether the answer is right and how much work was wasted.The menu of choices where one agent may be more accurate, another cheaper, and neither simply better in every way.Keep every choice that cannot be beaten on both accuracy and cost at the same time.Change the tool budget and check which choices remain worth keeping.One combined score hides an agent that is technically correct but wastes too many actions.Systems compression, safety boundaries, governance tradeoffs.
ATLAS / UFEval / Micro-Benchmarking ReliabilityP0 evaluationShows that a benchmark is a measuring tool, not a fact about the model by itself.The score, the case mix behind the score, and how much the score might move if the test were rebuilt.Audit whether rankings stay stable when items, domains, and small samples change.Resample questions, inspect sensitive items, and test held-out areas that were not used to tune the benchmark.The leaderboard order comes from test noise or a narrow domain artifact rather than real ability.Finite certification, safety measurement, scientific benchmarks.
WebDevJudge / PaperBench / VERINAP0 evaluationShows why judging must touch the actual thing being claimed.The code, proof, paper, or web app state that must run or check out for the claim to be true.Build a checker that inspects the real artifact rather than a summary about it.Run the artifact, record false passes, and check dependencies that could make the result look better than it is.The checker rewards an easy stand-in task instead of the claim the paper says it tests.Scientific agents, theorem transfer, code agents.
RLVepsR / Omni-Reward / JudgeBenchP0 safetyShows what happens when the model learns to chase a reward or judge score.The substitute measurement channel between real quality and the score used for training.Audit the score after training has learned to exploit it.Test score gaming and compare score gains against the real target behavior.The score improves while the behavior people actually wanted gets worse.Verifier gaming, preference training, agent evaluation.
Rare Event Analysis / Tail Risks / SRMCP0 safetyNames how to measure failures that are rare but serious.The chance of the named bad event and the search recipe used to find it.Steer sampling toward the risky region while keeping honest probability accounting.Report how many useful rare cases were actually sampled and how wide the remaining uncertainty is.The sampler almost never visits the dangerous region, so the estimate looks safe by accident.Jailbreaks, generative support, safety boundaries.
CSPO / SafeDPO / SecFidP0 safetyTurns safety into a rule for how the model may change, not just a score after it answers.The allowed region of behavior and how close an update moves the model toward the edge.Improve the model only through changes that stay inside the safety boundary.Test both sides: useful requests that should remain allowed and unsafe requests that should stay blocked.The rule blocks harmless help or lets unsafe behavior pass because the boundary was drawn in the wrong place.Fair matching, PACT, copyright and legal limits.
Midtraining Bridges / LR DecayP0 dataExplains training as a timed lesson path.The sequence of data mixes and the model's remaining ability to move from each lesson.Choose bridge data and timing so the shift is gradual enough to preserve broad skill.Remove or move one training phase at a time, then check target gains and retained broad ability.Good data arrives after the model can barely change from it.Curricula, DiReCT, posttraining behavior.
DiReCT / OPUS / HOBITP0 dataConnects data selection to the model movement each example causes.Whether an example's push helps the target while avoiding fragile directions.Choose late data by benefit and damage risk, not only by topic or source label.Measure useful movement, off-target damage, and what happens when fragile directions are removed.An example improves one validation slice while quietly damaging brittle behavior elsewhere.Adam movement rulers, LoRA theory, RAIN-Merging.
ThinKV / STAR-KV / EntroKVP0 systemsShows long-context compression as a choice about what evidence must be kept for later.The shortened memory record that still has to preserve facts future steps may need.Keep tokens because they are likely to matter later, not because they are nearby or easy to store.Compare against full context on cases where the important evidence is delayed, rare, or far away.The cache drops the exact fact needed later while keeping cheaper but useless context.Agents, video memory, running context state.
LiftQuant / TetraJet / QAT ScalingP0 systemsShows that deployment depends on the numbers the machine can actually store and multiply.The replacement from precise training numbers to cheaper machine numbers.Train or run the model so the cheap-number version preserves the behavior that matters.Inspect hardware traces and test whether answers drift on the target machine, not only in a simulator.A paper guarantee looks correct in ideal arithmetic but fails on the device that serves the model.Quantized diffusion, TileLang, pruning.
Error Propagation in Quantized DiffusionP0 generationConnects cheaper numbers to the whole sample-making path.The error carried from one denoising step into later steps.Spend precision or correction where an early error would spread the most.Check local rounding error and final sample distortion across the full path.A small error at each step accumulates until whole kinds of outputs disappear.Probability movement, finite precision, diffusion RL.
Quotient-Space Diffusion / GraphGlueP0 generationExplains how to ignore differences that should not matter while keeping differences that do.A group of versions that count as the same object, such as the same molecule drawn after a rotation.Generate in a space where harmless redrawings are treated as the same choice.Mark the boundary between harmless changes and meaning-changing changes, then test counterexamples.The grouping throws away a detail the task actually needed.Molecular symmetry, camera-aware models, graph learning.
Safety-Guided Flow / DMPOP1 generationConnects reward and safety to how possible outputs are moved while forming.A sample-making path nudged toward reward or away from unsafe regions.Guide the path before the final output exists, rather than filtering only at the end.Check whether valid variety remains reachable after guidance and reward pressure.Guidance collapses variety or misses rare safe kinds of output.RLVepsR, tail risk, quantized diffusion.
IRNO / RealPDEBenchP1 scienceShows physical prediction as repeated correction, not a single lucky next step.The field being predicted, the mistake left after each step, and the correction applied next.Update predictions in the same physical field where the error shows up.Run many steps forward and check small, fast-changing details that usually reveal drift first.A model that looks stable for one step breaks after the prediction is fed back into itself.Neural operators, video worlds, surrogate benchmarks.
ReaSyn / MORetro*P1 scienceShows that a generated molecule is only useful if there is a real route to make it.The reaction route: starting materials, allowed reaction moves, and the final molecule.Search through chemically valid moves instead of only drawing plausible final structures.Check whether routes are valid and whether the method still finds many makeable target objects.The model proposes impressive-looking molecules that cannot be made by the allowed reactions.Protein generation, allowed sets, planning.
Protein autoregressive modeling / DeCoDeP1 scienceConnects protein text to the physical structure and job of the molecule.The amino-acid sequence, folded shape, surrounding context, and binding state.Generate the next biological part while conditioning on the structure that makes it work.Check fold stability, binding behavior, and broken-rule cases rather than sequence likelihood alone.The sequence looks statistically likely but does not fold or function as needed.Molecular hierarchy, same-object grouping, scientific benchmarks.
Alignment-Sensitive Minimax Rates / BBPP1 theoryExplains when a real signal becomes visible enough to learn.Whether the target pattern sits in strong visible directions or is buried in noise.Study the target signal inside the directions the data can actually reveal.Resample the data and test whether the same target-carrying directions remain stable.A large mathematical direction explains variation, but not the behavior the task needs.Low-rank logits, tiny-change direction maps, kernel learning.
Adam Degeneracy / Beyond MuonP1 theoryExplains trainer behavior through the movement ruler it actually uses.The distance rule created by the training algorithm, not the ordinary distance seen on paper.Measure updates using model knobs that matter for error and stability.Remove or change trainer pieces and check fragile-direction damage.A small-looking update damages a direction where small movement is dangerous.DiReCT, LoRA, trust-region RL.
Transformer Circuits / Single-Head AttentionP1 theoryTurns architecture capability into step-by-step work a layer could actually do.The small internal routine: what information is read, where it is sent, and what decision it supports.Build or identify layer-level routines instead of only saying the architecture is powerful enough.Remove proposed circuit pieces and check behavior on finite data.A hand-built possibility is mistaken for proof that the trained model really learned that routine.Clustering, formal language limits, interpretability.
Finite Test Certification / Micro-benchmarksP1 theoryLinks broad claims to the limited evidence actually tested.The promised error rate and the family of cases the test is allowed to stand for.Bound how often the claim can be wrong under the named test conditions.Report sample size, test-case mix, and how far deployment cases may differ from tested cases.The certificate only covers a narrower case mix than the paper claims.Benchmark reliability, theorem-to-deployment, safety claims.
Same-Data Cause Stories / Structure Learning CIP1 causalityPrevents a paper from claiming one cause story when the data allow several.The set of cause-and-effect graphs that would all produce the same observed patterns.Return every cause story still possible under the stated assumptions.Show examples of tied cause stories and test whether the data have enough power to separate them.The paper reports one graph even though the observations support many.Local covariate selection, DiCoLa, BRCD.
Local Covariate Selection / TRECAP1 causalityShows when an effect estimate is valid for one local comparison.The background facts that must be held steady and the deliberate change being studied.Select variables that block misleading comparison paths.Stress-test hidden causes and check whether the local effect still holds.The chosen background facts remove bias in one region only.Fair causal bandits, robust missing covariates.
Neural Effect Search / HypoSpaceP1 scienceMakes discovery a search over claims that can be rejected, not just attractive patterns.The menu of possible effects and the test record that says which ones survived.Search for candidate effects, refine them, and verify them on evidence kept outside the search.Use held-out tests and account for the many chances the search had to get lucky.The discovery is a pattern found by over-searching rather than a stable effect.Bitween, RefineStat, PaperBench.
VISUALSWAP / MINT / MoCAP1 multimodalShows whether the answer came from the image, the text, or a shortcut between them.The route from each input channel to the final answer.Swap, remove, or directly change channels to see which one carries the needed evidence.Run controlled visual and text swaps, then remove one route at a time.The answer comes from language habit while appearing to use the visual evidence.Causal Route Gating, LIMSSR, visual attribution.
Mind-Omni / PRISMP1 multimodalConnects brain or physiological signal to model working notes.A structured hidden-token bridge between noisy body measurements and image or language tasks.Encode neural signal before cross-modal generation.Swap hidden body-signal notes and check reconstruction controls.The hidden note captures scanner artifact rather than the biological signal.SleepLM, BioX-Bridge, Tell-Tale Norm.
HDFlow / PACT / BehaviorVLAP1 embodiedShows that a robot plan must respect what can physically happen next.The subgoal, contact state, and allowed next action.Represent the task in a state where impossible action sequences can be ruled out.Check contact failures and whether the same action rule transfers across environments.An abstract plan looks reasonable in words but ignores friction, contact, or reachability.Skill-Pro, ReaSyn, robot benchmarks.
Common Corpus / HubbleP2 dataTurns source receipts into part of the data claim.The source mix, permission boundary, duplicate risk, and how much sensitive text can be recovered.Govern and audit corpus composition.Trace sources, run memorization tests, and remove source families one at a time.The dataset improves score while violating source or privacy constraints.Data markets, copyright benchmarks, privacy.
LIMSSR / robust missing-fact decisionsP2 dataForces missing information to remain explicit.The facts observed, the facts missing, and the still-possible completions.Make decisions from partial observations without pretending blanks are known.Test patterned missing fields and whether uncertainty stays honest.The model fills missing state with made-up certainty.Multimodal credit, robust decisions, synthetic repair.
TileLang / DHSA / einxP2 systemsShows systems work as arranging math so the machine can actually run it fast.The number-table program, memory layout, and movement of data through hardware.Match the computation to the machine's memory and parallel-work limits.Inspect kernel traces and test whether speed survives realistic tensor shapes.The speed claim disappears when the shapes or hardware look like production.Finite precision, IO-aware GNNs, deployment transfer.
FOCUS / RePAIRP2 systemsReveals behavior drift that ordinary scores can miss after compression.The repeated-output loop that can appear when model parts are removed or shrunk.Repair compressed models by testing the long-output behavior that tends to break.Audit repetition loops and long generations, not only short benchmark answers.The compressed model scores well but becomes unstable when it has to keep writing.Quantization, benchmark reliability, score-shortcut drift.
VALUEFLOW / welfare rulesP2 governanceConnects preferences to a rule for whose interests count.Which values are strong, weak, or in conflict, and whose welfare the rule counts.Combine preferences while keeping constraints and subgroup effects visible.Check subgroup tradeoff boundaries and sensitivity to value intensity.One number hides who loses.SafeDPO, fair matching, data pricing.
Accuracy Auctions / data market pricingP2 governanceExplains evaluation and data as systems where people react to incentives.Payoffs, reports, and whether honesty is the best response.Design incentives for useful information.Check strategic response, duplicate selling, and collusion.Participants adapt outside the simplified model.OMAC, AdvGame, data value.
Copyright-Bench / legal agentsP2 governanceShows legal rules as boundaries on what an agent may do.The allowed action set under the legal rule.Benchmark constrained behavior and correct refusal.Test boundary cases and count false refusals as well as illegal helpfulness.The agent optimizes helpfulness outside the legal boundary.CSPO, WebDevJudge, source receipts.
VideoKR / Visual Attribution StreamingP2 multimodalLong video requires memory and evidence responsibility together.The time-ordered video evidence and the route by which it supports the answer.Select and route video evidence through time.Delay important evidence, swap frames, and check whether the answer follows the right frames.The model uses nearby text or familiar frame patterns instead of the video evidence.KV caches, deliberate modality tests, DLMR.
SAW-Bench / RoboMMEP2 embodiedShows that embodied benchmarks must observe the task state, not just text about the task.The action taken, what the agent perceived, and what changed in the environment.Measure success across action, perception, and resulting world state.Log state changes and sort failures by the physical step that broke.The benchmark scores language about action instead of the action itself.HDFlow, PACT, artifact verifiers.
Language Generation in the LimitP3 theorySeparates what a model could represent in principle from what it can learn from realistic evidence.The amount and kind of examples needed before the pattern can be learned reliably.Prove that a language can be possible for the architecture but still impossible to learn from practical sample sizes.Show concrete language families and finite-sample limits.The architecture can represent a language, but no realistic training set teaches it reliably.Transformer circuits, finite certification, benchmark limits.
HOW TO USE

Next Iteration Rule

Choose from P0 first

P0 rows anchor multiple other pages. Expanding one of them improves the atlas more than adding another loose paper summary.

Use the nine-slot template

Every selected row should become a full worked card: the problem, the working state, the everyday object, what must stay true, what may change, why the method works, the plain formula, the evidence check, and the cross-paper role.

Fold back into lane pages

After a paper gets full treatment, move the strongest explanation into its lane page so readers starting from themes get the same depth.
