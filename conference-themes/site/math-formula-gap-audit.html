FIRST PRINCIPLE

Coverage Means The Claim Has A Shape

The atlas is not trying to collect paper titles. It is trying to name what each paper changes and what must survive that change. A paper is legible when the reader can answer five questions: where does the method act, what must stay true, what doubt remains, what boundary blocks invalid behavior, and what evidence would make the claim credible.

The shared problem across ICML and ICLR is controlled change. Models change prompts into traces, data into weights, coordinates into worlds, private records into trained systems, and benchmark items into claims about ability. The math works when it chooses the right thing to preserve: dependence on the input, a visible signal above noise, distance to a forbidden boundary, a makeable synthesis route, an action claim forced by evidence, or a finite-test doubt range.

GAP 01

Reasoning Skills And Routing

Agents / Reasoning

Base Models Know How To Reason And Procedural Pretraining

Object. Like a person who knows long division but does not notice when a bill requires it, the model may already have a skill but fail to call it at the right time. What must stay the same is the underlying skill. What may change is the trigger that makes the model enter the step-by-step mode. Formal labels if needed: latent ability means the hidden skill, routing probability means how often the model enters that mode, and mechanism means the start/stop rule that makes it happen.

Why it works. Posttraining helps if it teaches the model when to spend the skill, not merely how to write longer answers. Procedural pretraining helps if it gives the model reusable start, step, and stop patterns before the final reward becomes too delayed to teach anything clearly.

task success depends on calling the right hidden skill, skill quality, and trace cost

Evidence check. Compare base, SFT, and RL traces; test whether middle states become more input-dependent; measure whether the same hidden operation appears before and after posttraining.

Cross-paper role. This connects RAGEN-2, h1, The Tell-Tale Norm, and Skill-Pro: all separate having a capability from knowing when to spend it.

Agents / Systems

ThunderAgent, ADP, ParetoPO, And Tool-Use Cost

Object. Like deciding whether to call a specialist, run a test, or prepare a likely next step while waiting, the object is a work sequence where every outside action has time, risk, and checker cost.

Why it works. The system improves when it treats a tool call as a paid outside action, not as free context. What must stay the same is the task state and the quality of the final decision. What may change is which tool is called, which branch is prepared early, and how much checking is bought. Speculation helps only when saved time exceeds wasted branch execution. ParetoPO helps when accuracy and cost need a visible tradeoff menu instead of one collapsed reward. Formal label if needed: state-dependent cost, meaning the price of an action depends on the current work state, what is still unknown, and what could change the final decision.

choose a tool when expected improvement is larger than compute cost plus risk cost

Evidence check. Report accuracy-cost tradeoff curves, branch acceptance rates, wasted work, checker-call value, and failures where more tool use lowers net value.

Cross-paper role. This is compute allocation as a decision rule, shared by adaptive benchmarks, agent workflows, and conditional model serving.

GAP 02

Evaluation Is A Measurement Channel

Evaluation / Safety

CounselBench And Seizure-Semiology-Suite

Object. Domain-native judgment over the risk or event structure experts actually care about.

Why it works. These tasks fail if the score only measures fluent language. Counseling is not a writing contest; the important thing being judged is risk, escalation need, and professional boundary. Seizure video is not generic video labeling; the important thing is the medical event pattern behind visible movements over time. What must stay the same is the expert-visible risk or event state. What may change is the surface wording, clip, or judge. Formal label if needed: latent variable, meaning a hidden state inferred from visible evidence rather than directly observed.

valid score checks the artifact, evidence, risk state, and professional limits, not text preference alone

Evidence check. Audit expert agreement, risk-category calibration, event-boundary errors, false reassurance, missed escalation, and whether general judges reverse expert rankings.

Cross-paper role. This extends ATLAS, FRABench, WebDevJudge, and MADQA: a benchmark is useful only if its observation channel matches the claim.

Evaluation / Governance

Copyright-Bench, Accuracy Auctions, And Data Market Pricing

Object. An allowed action set shaped by law, consent, incentives, and user-specific usefulness.

Why it works. The decision is not just which output is accurate. A useful answer can still be disallowed, an allowed answer can be low value, and a payment rule can make people hide or exaggerate evidence. What must stay fixed is the boundary of lawful, consented, and honest action. What may change is which useful output, price, or report is chosen inside that boundary. Formal labels if needed: feasible set means the allowed menu, constraint means a rule that cannot be crossed, and mechanism design means building the rule around how people will react to it.

choose an allowed output that helps the user while respecting source records and incentive limits

Evidence check. Test pressured workflows, source recovery, truthful-value reports, strategic misreporting, and whether high-usefulness outputs leave the allowed legal set.

Cross-paper role. This ties safety to governance: the math starts when allowed actions and payoff structure are explicit.

Evaluation / Artifacts

WebDevJudge And MADQA

Object. A task artifact observed in the form where correctness lives: rendered page, interaction trace, retrieved document, oracle evidence, or answer.

Why it works. Judging only the final sentence is like grading a broken website from its source comments. It can hide whether the model failed to retrieve evidence, use it, render the page, or make the final inference. What must stay visible is the part of the work where failure actually happens. What may change is the artifact being checked. Formal label if needed: component-failure identification, meaning separating which part failed instead of collapsing the whole workflow into one score.

score checks rendered state, interaction trace, retrieved evidence, and answer, with component errors kept separate

Evidence check. Report component-level errors, human-oracle gaps, screenshot or DOM checks, retrieval coverage, answer-grounding failures, and rank changes under artifact-native judging.

Cross-paper role. This is checker validity across code, web, documents, robotics, and science: judge the object in the form where failure occurs.

GAP 03

Data And Compute As Controlled Movement

Data / Multilingual

ATLAS Multilingual Transfer And TokSuite

Object. Like translating the same manual across languages and asking which translation teaches another language too, the object is a table of who helps whom under token cost.

Why it works. A token budget is not neutral. If the tokenizer splits one language inefficiently, the model spends more context to carry the same meaning. What must stay the same is the skill or meaning being transferred. What may change is the source language, script, tokenizer, and downstream target. Transfer works when training evidence in one language moves the model in ways another language can use. Formal label if needed: transfer matrix, meaning the language-to-language help table.

value(language i -> j) = task_gain_j per token_i, corrected for tokenizer length and representation overlap

Evidence check. Measure cross-language transfer, token inflation, script-level failures, low-resource gains, and whether shared directions predict downstream improvement.

Cross-paper role. This connects data selection to modality bottlenecks: the cost of evidence depends on the representation interface.

Data / Synthetic

Synthetic Data Selection, FAC, And COMPACT

Object. Filling holes in feature, skill, or evidence-channel coverage under a fixed training budget.

Why it works. Extra examples help like practice questions help a student: they matter when they cover mistakes the student still makes. They hurt when they repeat easy drills or teach habits that differ from the real test. What must stay the same is the target task and its real evidence mix. What may change is which generated examples are added. Formal labels if needed: distribution shift means being pulled toward the wrong example mix, and marginal gain means what one more example teaches beyond the examples already chosen.

add a sample when coverage gained is larger than shift cost plus duplication cost

Evidence check. Report coverage maps, duplicate rates, movement away from the target data mix, low-data regimes, and selected-data removal tests that replace selected synthetic data with random synthetic data.

Cross-paper role. This is the same next-example-value object as Sequential Data Values, BLL-Loss, DiReCT, and OpenThoughts, but applied to constructed data.

Systems / Hardware

TabSwift, FFCC, IO-Aware GNN, And SparseRL

Object. Conditional computation under memory traffic, latency, active parameters, and data movement.

Why it works. FLOPs alone do not identify cost. A method is faster only if the chosen representation matches the machine bottleneck: tables, graph neighborhoods, cache movement, or sparse action updates. What must stay the same is target behavior. What may change is which block runs, which data moves, or which parameter path is active.

execute block b when E[loss_drop_b | state] / (latency_b + memory_move_b) is above threshold

Evidence check. Measure wall-clock latency, memory bandwidth, active-parameter count, accuracy loss, input-conditioned skipping, and whether theoretical savings appear on the target hardware.

Cross-paper role. This unifies model compression, KV-cache retention, speculative agents, and low-bit training as preservation under an execution budget.

GAP 04

Sampling, Molecules, And Physical State

Generative / Sampling

FALCON, SRMC, Cauchy Bridges, And FIDIA

Object. A sample-making path that must preserve common outputs, rare outputs, and large occasional jumps.

Why it works. A sampler is like sending scouts through a landscape and using their reports to estimate what the whole place is like. If all scouts go to the easy central roads, the report misses rare but important places. What must stay the same is the target mix of possible outputs, including the rare ones. What may change is the scouting route used to visit and weigh them. Formal labels if needed: distribution means the target mix, support means the places where outputs are possible, variance means how unstable the estimate is, and estimator means the rule that turns sampled reports into a number.

estimate target behavior using a proposal path; error depends on coverage and stability

Evidence check. Report likelihood calibration, rare-output recall, effective sample size, rare-event intervals, bridge stability, and estimate stability under shifted proposals.

Cross-paper role. This links safety tail risk, molecular equilibrium, diffusion posttraining, and Best-of-N selection through the same sampling-path problem.

Chemistry / Biology

mCLM, ReaSyn, MORetro*, DCFold, And FIDIA

Object. A usable molecular object plus a makeable route or folded structure, not just a valid-looking string.

Why it works. A molecule proposal is not enough if the lab cannot make it, the fold does not hold, or the binding context breaks. The sequence, shape, route, and target must fit together like parts of one recipe. What must stay the same is scientific usability. What may change is which molecule, route, fold, or property tradeoff is explored. Formal labels if needed: feasible state means a candidate that satisfies the needed rules, and constraints means the rules it must obey.

valid candidate needs molecule, route, conformation, and target rules all satisfied

Evidence check. Check synthetic route validity, fold consistency, binding context, property tradeoffs, novelty without invalid chemistry, and whether the search preserves feasibility.

Cross-paper role. This is allowed-set design in a scientific state space, parallel to robotics constraints and legal action constraints.

Physical / Worlds

Camera-Aware MLLM, 3ViewSense, Holi-Spatial, TideGS, And RadioGS

Object. Like seeing the same room through a phone camera, a depth sensor, and a radio-strength map, the object is the hidden room or field behind those readings.

Why it works. Spatial reasoning is impossible if each view is treated as an unrelated image. What must stay the same is the underlying scene or physical signal. What may change is camera position, occlusion, sensor type, or rendering. The model needs a shared record where those changes are different measurements of the same thing. Formal label if needed: shared spatial state.

observations o_v = render_v(S) + noise; infer scene S so predictions are consistent across views v

Evidence check. Test viewpoint changes, cross-sensor consistency, occlusion, field reconstruction, camera-parameter perturbations, and whether answers preserve the same world state.

Cross-paper role. This connects multimodal grounding to physical generation: the object is the world, not the caption.

GAP 05

Theory Objects That Need Direct Evidence

Theory / Expressivity

Softmax Turing, HATSolver, Rational Transductors, And Exact GNN Algorithms

Object. Like asking whether a calculator has enough buttons, memory, and repeated steps to run a recipe, the object is what procedure the architecture can carry.

Why it works. Possible-computation claims are useful only when they say which computation can be represented under finite depth, precision, memory, and input length. What must stay the same is the intended step-by-step rule. What may change is whether attention, recurrence, graph aggregation, or symbolic updates implement it. Formal label if needed: expressivity, meaning what the architecture can represent in principle under the stated resource limits.

architecture realizes a function class only under stated resource bounds

Evidence check. State the constructive simulation, resource scaling, precision assumptions, trainability gap, and examples where the computation exists but learning does not find it.

Cross-paper role. This pairs with Language Generation in the Limit: representation is not the same as finite-evidence proof that training found it.

Theory / Visible Signals

BBP Transitions, Low-Rank LM Logits, And SVD Interpretability

Object. Useful signal becoming visible as stable directions above noise.

Why it works. In a noisy room, a repeated tune becomes useful only when it is loud and stable enough to recognize again. These methods look for repeated ways model behavior changes that keep showing up after resampling or small disturbances. What must stay the same is the real signal. What may change is the sample, prompt, or noise around it. Formal labels if needed: spectral method means sorting repeated directions by strength, eigenvalue or singular value means a direction's strength number, and subspace means the small family of directions kept for analysis.

recover signal when visible direction strength exceeds noise

Evidence check. Report visible gaps, resampling stability, held-out reconstruction, disturbance sensitivity, and whether the kept directions preserve task behavior.

Cross-paper role. This is the same visibility problem behind kernel alignment, attention recovery, LoRA rank, and Jacobian spectra.

Theory / Games

Constrained Nash Equilibria, FTRL Lower Bounds, And Data Markets

Object. Reacting actors with limits, private information, and only finite time to settle.

Why it works. A single score is wrong when other actors can change their behavior in response. A pricing rule, fairness rule, or multi-agent policy must work after people or agents adapt to it. What must stay the same is each actor obeying the shared limits and having no better allowed move under the others' choices. What may change is each report, bid, message, or action. Formal labels if needed: objective means what an actor tries to improve, constraint means a shared limit, equilibrium means a stable set of mutual responses, and mechanism means a rule designed around incentives.

actors should have no better allowed move after accounting for others' responses

Evidence check. Measure truthful-report pressure, boundary violations, last-current-choice behavior, settling time, strategic misreporting, and sensitivity to payoff mistakes.

Cross-paper role. This connects multi-agent collaboration, fairness, auctions, weak-to-strong monitoring, and dataset valuation.

Theory / Systems

Floating-Point Neural Networks, QAT Scaling, And Quantized Diffusion

Object. A cheaper number path that changes stored model numbers, internal number patterns, training pushes, or denoising steps.

Why it works. Rounding a price once may not matter; rounding every step in a long recipe can change the dish. Low precision helps only when the cheaper numbers preserve the behavior the original system used, especially over repeated generation or reasoning steps. What must stay the same is the task-relevant function or sample path. What may change is the number grid, stored internal values, update pushes, or denoising steps. Formal labels if needed: approximation map means the cheaper replacement, activations means internal number patterns, gradients means training pushes, trajectory means the repeated path, and quantization means forcing values onto a smaller numeric grid.

output error grows with sensitivity and accumulated rounding error

Evidence check. Report error propagation, layer and timestep sensitivity, calibration data dependence, stability under long generation, and whether reasoning or repetition changes after compression.

Cross-paper role. This is theorem-to-deployment for finite machines: the guarantee must describe the arithmetic actually used.

GAP 06

Causal, Visual, And Memory Correspondence

Causality / Representation

PSAHS, RULE, Linear Recurrent Memory, And DLMR

Object. A matching rule between observed evidence, hidden working facts, retrieved memory, and the claim being made.

Why it works. A short note is useful only if it keeps the facts needed for the question asked later. Memory and retrieval help when they preserve the action-relevant facts and drop only details that would not change the answer. What must stay the same is the target answer under the full evidence. What may change is the compressed note, retrieved item, or hidden working state used to answer. Formal labels if needed: latent state means hidden working facts, sufficient statistic means a short note that keeps everything needed, counterfactual means the what-if version of the situation, and intervention means the deliberate change being tested.

memory is valid when it gives the same target answer as the full history for the query class

Evidence check. Test memory removal, what-if swaps, stale-memory failures, action-transfer tests, and whether retrieved evidence changes the claimed cause or visual route.

Cross-paper role. This links causal representation learning, routed multimodal memory, and long-context systems: state is useful only when it preserves the right information for the later question.

Multimodal / Attribution

Visual Attribution Streaming, RFCMH, WETR, And AGREE

Object. A source path from sensory evidence to answer, weak label, or generated claim.

Why it works. Multimodal models fail when text habits, weak labels, or cached memories replace current evidence. Evidence-route methods work by exposing whether the output depends on the intended observation rather than a shortcut. What must stay the same is responsibility for the answer. What may change is irrelevant background evidence that should not affect the answer.

answer should change when relevant evidence is deliberately changed, and stay stable when irrelevant evidence changes

Evidence check. Run evidence swaps, streaming responsibility checks, weak-label reliability tests, hallucination correction, and stability tests under irrelevant background changes.

Cross-paper role. This is evidence-channel credit as cause testing, shared by VISUALSWAP, MoCA, MINT, and Causal Route Gating.

Science / Proof

WZ-LLM, VERINA, Bitween, And PaperBench

Object. A generated scientific artifact whose validity can be checked outside the generator: proof, reduction, experiment, code, figure, or paper component.

Why it works. Scientific text is cheap to imitate. A claim becomes stronger when it hands another system something that can pass or fail: a proof step, a reduction, a run, a figure, or a reproduced result. What must stay the same is the claim's required dependency chain. What may change is the proposed artifact or repair. Formal label if needed: verifier, meaning the independent checker that accepts or rejects the artifact.

accept an artifact only if required components pass and claim dependencies are preserved

Evidence check. Report formal checker failures, reproduction success, artifact dependency errors, hallucinated citations, reduction validity, and whether repair preserves the original claim.

Cross-paper role. This closes the loop between agents, science, and evaluation: reasoning matters when it produces checkable structure.

BIG PICTURE

The Overall Problem

The atlas is converging on one problem: how to make an AI system change without losing the thing that made the claim meaningful. Training changes parameters. Reasoning changes state. Compression changes arithmetic. Generation changes samples. Evaluation changes real capability into a score. Governance changes a useful action into an allowed action. The central object is the part that must stay identifiable through that change.

The approaches differ because the preserved object differs. If the object is a trace, test the process. If it is a legal or safe action, state the allowed set. If it is a rare failure, sample toward rare cases and correct the estimate. If it is a molecule, optimize only over route-valid structure. If it is a theorem, state the resource and evidence assumptions. If it is a multimodal answer, test the evidence route that caused it. Across papers, the first move is always the same: name what must be preserved before optimizing what can move.
