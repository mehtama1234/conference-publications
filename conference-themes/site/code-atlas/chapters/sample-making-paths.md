# Sample-Making Paths

## The Big Idea

A generator does not only produce final samples. It follows a path from rough
possibility to finished output. That path matters. It can improve visible
quality while quietly removing valid kinds of output.

A recipe shortcut may make most cookies look cleaner while making one real
style impossible to bake. A generator can do the same thing: better-looking
outputs, less real coverage.

## What Must Stay True

The protected thing is the full family of valid outputs. Quality can improve.
The path can be steered. But rare valid kinds must remain reachable if they are
part of the target.

## The Failure

The hidden failure is path narrowing. The method learns a road that reaches the
common easy outputs and avoids the rare ones. The samples look better because
variety has been silently removed.

This is especially dangerous when people inspect only a few examples. A small
gallery can look excellent while hiding the fact that a whole valid region is
gone.

## Why This Matters Outside The Demo

This matters in image generation, molecule design, architecture, product design,
robot motion planning, scientific simulation, and 3D shape generation. The
question is not only "are the examples nice?" It is also "which valid examples
became hard or impossible to reach?"

In topology, this is direct. A generator may favor smooth common shapes while
losing shapes with holes, handles, branches, disconnected parts, or unusual
boundaries. A healthy path keeps those valid structures reachable.

## What Client Data Makes It Real

Use generated samples, independent validity labels, named output families,
rare-family recall, sample weights, and before/after comparisons. The proof is
that quality improves without erasing valid families.
