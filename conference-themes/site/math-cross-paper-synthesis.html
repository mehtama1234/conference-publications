The same underlying problem keeps reappearing

This page connects the lane-level detail pages. The point is not that all papers use the same method. The point is that many methods become clear once we say what they are trying to preserve while something changes: saved state, measured skill, allowed output, sample-making path, update movement, checker, or safety boundary.

FIRST PRINCIPLE

The Big Problem Is Controlled Change

Across ICML and ICLR, the central problem is no longer only prediction. The systems being studied change state: they reason through traces, call tools, update weights, compress memories, generate paths, adapt to users, and move through physical environments. Once a system changes, the important question becomes what must stay true while it changes.

That is the common spine. A paper is strong when it names the saved facts, checker, allowed region, sample path, movement rule, or boundary that protects the thing the task cannot afford to lose.

CHAIN 01

From Answers To Kept State

RAGEN-2 -> HDFlow -> IRNO -> Mamba Markov ICL

Shared object. A saved middle state that must keep the facts needed by the next step.

Why the connection matters. RAGEN-2 asks whether a reasoning trace still changes with the input. HDFlow asks whether robot action can pass from broad subgoal to local motion. IRNO asks whether a physical solver can repeatedly reduce leftover error. Mamba Markov ICL asks whether a recurrent model keeps the hidden process behind the sequence.

First-principles read. These papers are not about longer text, smoother motion, better PDE loss, or newer sequence blocks in isolation. They all ask whether the current record contains the information required by the next decision. What must stay the same is the next decision the full past would support. What may change is the shorter record. Name used later: Markov state for a record that makes the full past almost unnecessary.

Failure Mode

If the saved state is wrong, errors look independent when they are actually carried forward. Template reasoning, robot drift, leftover physical error, and lost sequence memory are the same structural failure: the system throws away information before the task is done.

state_t -> update -> state_{t+1}; success requires sufficient state, not just a good endpoint
CHAIN 02

From Scores To Instruments

ATLAS -> FRABench -> WebDevJudge -> MADQA

Shared object. A noisy instrument reading for a hidden skill.

Why the connection matters. ATLAS chooses questions that remove doubt. FRABench splits the rubric into parts. WebDevJudge observes the rendered page instead of source text alone. MADQA separates what a human, agent, and oracle could know in document QA.

First-principles read. A benchmark is an instrument. Its question mix, judge channel, and scoring rule decide what hidden skill the score can support. What must stay the same is the skill being estimated. What may change is the question, judge, or artifact channel. Name used later: latent ability for that hidden skill inferred from observed answers.

Failure Mode

A single aggregate score can hide noisy sampling, judge bias, mixed skills, shortcut use, or missing evidence. What must stay visible is how much repeated readings spread before we trust a ranking. Name used later: variance for that spread. These papers work because they redesign the instrument, not because they add more questions.

observed score = latent ability signal + item noise + judge bias + task-mixture artifact
CHAIN 03

From Data To Evidence Mix

DiReCT -> Midtraining Bridges -> Common Corpus -> Sequential Data Values

Shared object. Training data as a timed push on the model.

Why the connection matters. DiReCT selects examples by whether they move the model in useful directions. Midtraining Bridges chooses when specialized data should arrive. Common Corpus makes permission and source receipts part of the evidence mix. Sequential Data Values makes the next example's value depend on what was already selected.

First-principles read. Data does not help by existing. It helps by creating a useful update at a point in training, under legal and statistical constraints, after other data has already changed the model. What must stay the same is the target learning effect. What may change is timing, source, or mix. Name used later: distribution for the mix of examples.

Failure Mode

"More data" fails when examples arrive after the model can no longer move, push through fragile directions, duplicate already-covered evidence, violate source constraints, or hide missing facts as certainty.

utility(example | model_t, optimizer_t, selected set, constraints)
CHAIN 04

From Outputs To Allowed Regions

Copyright-Bench -> Pi-net -> Quotient Diffusion -> Fair OT

Shared object. An allowed search region where invalid outputs should not receive probability mass.

Why the connection matters. Copyright-Bench defines lawful source choice. Pi-net snaps outputs back into numerical constraints. Quotient diffusion groups coordinate copies that describe the same object. Fair OT constrains the matching itself.

First-principles read. Optimizing first and filtering later wastes search on impossible, illegal, unfair, or fake coordinate differences. What must stay the same is validity of the output or match. What may change is which allowed candidate is chosen. Names used later: feasible set for the allowed region, and quotient for same-object grouping.

Failure Mode

A plausible answer can be invalid. A molecule can be the same under rotation. A matching can be cheap and unfair. A neural output can violate hard constraints. These papers work by changing the search space, not only the penalty.

choose x in C, not choose x anywhere and reject after
CHAIN 05

From Samples To Making Paths

DMPO -> FALCON -> Safety-Guided Flow -> GWF

Shared object. A path that moves a cloud of possible samples.

Why the connection matters. DMPO matches reasoning RL to step-by-step diffusion-language generation. FALCON needs molecular samples with correct probability weight. Safety-Guided Flow changes the movement away from unsafe regions. GWF explains how different distance rules move a probability cloud.

First-principles read. A sampler is not just a generator of final objects. The route matters because reward, likelihood, safety, and rare-mode coverage are all properties of how the cloud moves. What must stay the same is the target cloud and the quantities read from it. What may change is the path. Names used later: transport and Wasserstein flow for moving probability mass.

Failure Mode

End-only rejection cannot repair a sampler that spends most mass in the wrong regions. Missing modes, unsafe paths, wrong likelihoods, and mismatched RL updates all come from optimizing the wrong movement of possible samples.

distribution_t -> vector field / denoiser / bridge -> distribution_{t+1}
CHAIN 06

From Gradients To Movement Rules

Adam Degeneracy -> LoRA Theory -> Beyond Muon -> Non-Euclidean EoS

Shared object. A training push measured by the movement rule the optimizer actually uses.

Why the connection matters. Adam changes local coordinates through adaptive scaling. LoRA allows movement only through low-rank factors. Muon-style methods reshape matrix directions. Non-Euclidean EoS says stability must be measured by the optimizer's own ruler.

First-principles read. A gradient is only a push. To know what it does, we must know the movement ruler, smaller allowed family, normalization, and numeric precision. What must stay the same is protected behavior while target loss improves. What may change is the update direction or ruler. Names used later: metric, subspace, and curvature for that ruler, movement family, and bending of the loss.

Failure Mode

The same loss improvement can destroy unmeasured behavior if movement occurs along brittle directions. This is why trust regions, bend-aware data selection, low-rank adapters, and orthogonalized updates belong in one story.

update = preconditioner * gradient, constrained by rank, trust region, precision, and curvature
CHAIN 07

From Size To Same Job

LiftQuant -> TetraJet -> FOCUS/RePAIR -> EntroKV

Shared object. A cheaper computation that must still do the same job.

Why the connection matters. LiftQuant makes precision tunable through lifted codes. TetraJet controls structured low-precision error. FOCUS/RePAIR detects loops caused by pruning. EntroKV compresses cache by future information value.

First-principles read. Compression is not about preserving parameters. It is about preserving behavior under a smaller record or cheaper machine. What must stay the same is task behavior. What may change is bit width, cache, layer count, or readout. Names used later: approximation for replacing the original with a cheaper version, and projection for reading the original through a smaller view.

Failure Mode

Uniform compression assumes errors have equal consequence. They do not. Sampler error accumulates, outlier channels dominate, loops trap generation, and cache states differ in future value.

compressed computation = projection(original computation) with task-sensitive error budget
CHAIN 08

From Claims To Checkable Evidence

CyberGym -> VERINA -> Gaussian Unlearning -> Catch-22

Shared object. Evidence that matches the kind of claim being made.

Why the connection matters. CyberGym demands a runnable exploit. VERINA demands a proof artifact. Gaussian unlearning defines deletion by whether removed-data and never-seen-data worlds are hard to tell apart. Catch-22 defines watermarking by what a detector can and cannot distinguish.

First-principles read. The form of proof must match the risk. Security needs execution, formal reasoning needs a checker, unlearning needs a statistical test, and watermarking needs a detection boundary. What must stay the same is the claim under inspection. What may change is the evidence artifact. Name used later: certificate for a claim tied to checkable evidence.

Failure Mode

Fluent claims are too cheap. A model can describe a vulnerability without exploiting it, write proof-like text without a valid proof, claim deletion when the two worlds are still distinguishable, or watermark text without surviving ordinary transformations.

claim is valid only relative to verifier V and evidence artifact A
CHAIN 09

From One Loss To Reaction Rules

AdvGame -> Fair OT -> Accuracy Auctions -> Data Market Pricing

Shared object. Several actors whose incentives and constraints shape the outcome.

Why the connection matters. AdvGame lets attackers and defenders adapt. Fair OT constrains group matching. Accuracy Auctions weights correctness by private user values. Data Market Pricing models sellers who may act strategically with reusable data.

First-principles read. One optimizer is the wrong picture when other actors respond. The correct object is the rule of the setting: who can act, what they know, what they gain, and what constraints bind them. What must stay the same is acceptable outcome after reaction. What may change is each actor's action rule. Names used later: mechanism and game for these reaction rules.

Failure Mode

Static objectives fail when users, sellers, attackers, monitors, or groups adapt. The model can optimize a metric while the surrounding institution changes what success means. What must stay visible is each actor's response rule. Name used later: policy for an actor's action rule.

policy_i affects payoff_j, constraints, information, and future response
CHAIN 10

From Association To Cause Evidence

CausalGame -> Local Covariate Selection -> OU Identifiability -> Linear Causal Representation Learning

Shared object. The boundary between what data proves and what remains a plausible cause story.

Why the connection matters. CausalGame tests whether agents gather evidence when causes are mixed together. Local Covariate Selection finds which background facts must be matched for one local question. OU identifiability recovers time-process drift from summaries. Linear causal representation learning states which hidden cause stories remain possible under weak environment variation.

First-principles read. Causal and scientific papers are strongest when they say what cannot be known. What must stay the same is the claim across all stories still allowed by evidence. What may change is the cause story. Name used later: identification.

Failure Mode

Prediction can succeed while intervention reasoning fails. A model may forecast observations, fit correlations, or draw a plausible graph without knowing what would happen if a variable changed.

identified claim = what remains invariant across allowed interventions, moments, or environments
CHAIN 11

From Fusion To Evidence Credit

MoCA -> Causal Route Gating -> MINT -> Visual Attribution Streaming

Shared object. A route from evidence channel to output.

Why the connection matters. MoCA separates seeing failure from reasoning failure. Causal Route Gating identifies routes driven by visual evidence or text habits. MINT changes hidden states to locate where modalities fuse. Visual Attribution Streaming tracks visual evidence during long VLM reasoning.

First-principles read. Multimodal correctness means little unless the right channel caused it. These papers turn "the model used the image" into a change test: if the visual evidence changed while text stayed fixed, would the answer move for the right reason?

Failure Mode

A model can answer from language habits, then decorate the answer with visual words. That failure is invisible to endpoint accuracy. Credit-assignment methods work because they measure the path from evidence to output, not only the output.

answer = f(visual route, text route, memory route); diagnosis asks which route matters
CHAIN 12

From Context To Kept Notes

FlashVID -> InfoTok -> EntroKV -> ThinKV -> COMPACT

Shared object. A kept record that should be enough for the future question or action.

Why the connection matters. FlashVID merges video tokens. InfoTok estimates which pieces carry answer-changing information. EntroKV and ThinKV compress cache state by future value. COMPACT keeps long-context state small enough to use.

First-principles read. The question is not "how many tokens can we remove?" It is "after we keep these notes, which old details can no longer change the next decision?" What must stay the same is the prediction or action the full record would support. What may change is the smaller record. Name used later: sufficient statistic.

Failure Mode

Uniform token dropping mistakes small tokens for unimportant tokens. Rare visual events, old tool observations, low-norm cache directions, and table structure can be the whole reason the final answer is correct.

keep s = c(history) such that decision_future is independent of history given s
CHAIN 13

From Judges To Artifact Checks

OmniVerifier -> WebDevJudge -> CyberGym -> Seizure-Semiology-Suite

Shared object. A checker that observes the place where failure actually occurs.

Why the connection matters. OmniVerifier checks generated visual artifacts. WebDevJudge checks rendered web behavior. CyberGym checks executable exploit behavior. Seizure-Semiology-Suite checks clinical video signs with expert meaning.

First-principles read. A judge should inspect the artifact whose correctness matters. Text explanation is a weak substitute for image consistency, website behavior, exploit validity, or medical event recognition. What must stay the same is the claim under the right observation channel. What may change is the artifact being checked. Name used later: verifier.

Failure Mode

A detached judge can score the wrong view. Code can look plausible and fail in the browser. A clinical summary can miss the temporal sign. A visual edit can satisfy wording and violate the picture. What must stay visible is the native state where failure lives. Name used later: projection for reading one view of a richer artifact.

valid score = V(native_state, task_constraint), not V(description(native_state))
CHAIN 14

From Embeddings To Hidden Handles

PRISM -> Mind-Omni -> LatentLM -> Linear Causal Representation Learning

Shared object. A hidden code that is useful because it exposes variables the task can act on.

Why the connection matters. PRISM maps fMRI into object-attribute-relation text. Mind-Omni builds brain tokens. LatentLM uses continuous or shared hidden codes for media generation. Linear causal representation learning asks when hidden cause features can be recovered.

First-principles read. A representation is not good because it is compact. It is good when changing, decoding, transferring, or identifying the useful variable becomes simpler in that coordinate system. What must stay the same is the useful variable. What may change is the hidden code. Name used later: latent.

Failure Mode

An embedding can preserve surface similarity while hiding the variable that matters. Brain reconstruction needs concept structure. Causal discovery needs environment-stable factors. Media generation needs decodable hidden codes. Otherwise the hidden space is only compressed observation, not an interface.

learn z = f(x) so the target operation is simpler in z than in x
CHAIN 15

From Averages To Rare Pressure

Jailbreak Foundry -> HiddenGuard -> VALUEFLOW -> FlowGuard

Shared object. A safety boundary or rare bad case under pressure.

Why the connection matters. Jailbreak Foundry searches for attacks instead of static prompts. HiddenGuard monitors hidden states for unsafe directions. VALUEFLOW measures how strongly values are expressed rather than only which label wins. FlowGuard watches the generation path for abnormal movement.

First-principles read. Safety failures are often rare edge cases. Average behavior says little about what happens when an adversary, strange context, or internal drift pushes the system near a boundary. What must stay the same is the safety rule. What may change is pressure or route. Name used later: tail event for a rare edge-case event.

Failure Mode

A model can be safe on ordinary samples and fail under adaptive pressure. A detector can work at one threshold and collapse when the input mix changes. A value label can look aligned while intensity moves to an unsafe extreme.

risk = probability(state enters bad set under pressure distribution), not average loss alone
CHAIN 16

From Parameters To Visible Directions

Alignment-Sensitive Minimax Rates -> Jacobian Spectra -> LoRA Theory -> Mamba Markov ICL

Shared object. Signal carried by directions the model can recover.

Why the connection matters. Alignment-sensitive minimax rates depend on whether target signal lines up with learned visible directions. Jacobian-spectra work studies which input changes training amplifies. LoRA theory restricts updates to low-rank direction families. Mamba Markov ICL asks whether recurrence recovers the right hidden-state estimator.

First-principles read. Parameter count is a crude proxy. What matters is whether the signal lies in directions the model can represent, update, and recover with finite evidence. What must stay the same is recoverable target signal. What may change is representation, update family, or recurrent state. Name used later: spectra for these visible direction patterns.

Failure Mode

A large model can miss a target if the signal sits in weak directions. A small adapter can work if the task update uses only a small direction family. A recurrence can generalize if its state lines up with the hidden process. The spectrum tells which movements are easy and which are buried.

effective difficulty depends on signal projection onto learnable directions
CHAIN 17

From Datasets To Learning Paths

h1 -> OpenThoughts -> Midtraining Bridges -> LR Decay Wastes Your Best Data

Shared object. A timed path through task difficulty, data mix, and how much the model can still move.

Why the connection matters. h1 composes short tasks into longer horizons. OpenThoughts exposes reasoning traces for learning. Midtraining Bridges times specialized data between pretraining and posttraining. LR Decay Wastes Your Best Data says late high-quality examples may arrive when the learning rate no longer lets them move the model enough.

First-principles read. A dataset is not just a set. It is an ordered intervention on parameters. The same example can be transformative early, useful midstream, or almost inert late. What must stay the same is useful retained behavior. What may change is the lesson timing or step size. Name used later: gradient for the training push an example creates.

Failure Mode

Training can fail because the reward is too sparse, the trace is hidden, the special data arrives outside the learning window, or the learning rate makes important pushes too small to matter.

effect(data_t) depends on parameters_t, optimizer_t, curriculum_t, and remaining plasticity
CHAIN 18

From Stories To Testable Hypotheses

Neural Effect Search -> HypoSpace -> RefineStat -> MedAgentGym

Shared object. A proposed scientific claim that must become testable or executable.

Why the connection matters. Neural Effect Search turns learned features into causal hypotheses with randomized evidence. HypoSpace measures coverage over possible explanations. RefineStat repairs probabilistic programs under statistical checks. MedAgentGym tests biomedical agents through executable data-science tasks.

First-principles read. Scientific language becomes useful only after it maps to a hypothesis space, experiment, program, or workflow that can reject wrong claims.

Failure Mode

A model can produce a persuasive scientific narrative while never producing a discriminating test. These papers work by forcing the claim to expose what evidence would make it fail.

hypothesis h is useful when there exists evidence e such that V(h,e) can reject h
OVERALL

The Unifying Problem

Preserve The Right Information

Every lane asks what information must survive a change. Reasoning preserves task dependence through a trace. Data selection preserves useful training pushes. Compression preserves behavior under a smaller code. Physical generation preserves object-native structure. Evaluation preserves the connection between score and capability.

Remove Fake Variation

Quotient diffusion groups rotated copies of the same object. Fair OT removes unfair matches from the search space. Camera-aware models separate viewpoint from target signal. Common Corpus exposes source receipts in the data mix. Formal checkers remove fluent but invalid proof text from the evidence space.

Name The Boundary

Safety, privacy, unlearning, watermarking, allowed-region optimization, and causal evidence all become clearer when the boundary is explicit: unsafe region, hard-to-tell-apart deletion worlds, detection power, lawful action set, fairness tradeoff, or remaining set of possible cause stories.
