FIRST PRINCIPLE

A Paper Is A Claim About A Move

A paper becomes understandable when it is written as a controlled change. Imagine cleaning a messy desk: you can throw away duplicates, group related papers, keep the receipt you will need later, or lock away anything dangerous. The math version asks the same question: what must stay the same for the work to remain correct, and what can safely change to make the system cheaper, safer, clearer, or more useful?

The row structure below forces every paper to answer that question in plain words first. The formal phrase stays in parentheses only after the everyday meaning is stated: the object is the thing being changed, the approach is the move, the why-column explains the cause-and-effect reason it may help, the assumption says what must remain true, and the failure says how the move can fool us.

IRNOscienceA repeated correction rule for fields such as heat, pressure, or fluid values over space (fixed-point operator for physical fields).Correct the prediction in the native physical form instead of treating it as generic data (native structure and iterative correction).If each correction respects the field's structure, repeated updates can reduce accumulated error instead of creating new artifacts.The correction rule must remain stable, and its error basis must cover the mistakes seen in deployment.The model may ignore the real physical structure or correct in a direction that makes later errors worse.RealPDEBench, MiAE, neural operators.
ReaSyn / MORetro*scienceThe set of chemical routes that could actually be made in a lab (chemical route feasibility).Search only through chemically valid moves instead of free-form molecule guesses (feasible-set movement in structured space).Planning improves when every step respects reaction rules, because invalid branches no longer consume search.The feasibility rules must cover real chemistry without excluding useful routes.The search boundary may be too loose to prevent impossible plans or too tight to find valid ones.Protein autoregressive models, DeCoDe, Chamaileon.

READING PATHS

How To Use The Matrix

Start from a paper

Read across the row: what changes, what move is made, why the move can help, what must stay true, what can break, and which nearby papers use the same idea.

Start from a failure

If a paper seems weak, use the failure column to ask a concrete question: what observation would show that the promised condition is false?

Start from a method

If several papers use the same move, compare what each one keeps fixed and what each one allows to change. The same reason may appear in agents, diffusion, causality, and systems under different later math names.
