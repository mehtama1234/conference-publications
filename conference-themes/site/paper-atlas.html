How to Use This Atlas

A theme page explains a recurring research pressure. A paper-atlas entry explains the concept inside one publication. The useful unit is not the abstract or title. It is the paper's chosen mathematical object: a verifier, a graph, a distribution, a quotient space, a feasible set, a trajectory, an activation direction, a compute budget, or a latent representation.

The same publication can appear in several themes because one technical idea often answers multiple questions. CyberGym is a security benchmark, an agent-process diagnostic, and an executable evaluation method. Quotient-Space Diffusion is a generative model, a geometry paper, and a sampler-correctness paper. The atlas keeps those connections visible while giving each paper one first-principles read.

FAMILY 01

Agents and Executable Evaluation

CyberGym

ICLR 2026

CyberGym's core concept is executable vulnerability evidence. The paper treats a security task as incomplete until an agent produces a proof-of-concept test that distinguishes vulnerable from patched code. The benchmark is therefore not a questionnaire about CVEs; it is a world where code, exploit, patch, and verifier interact.

Mathematical object
A verifier over program versions: exploit passes on pre-patch state and fails on post-patch state.
Approach
Builds 1,507 real-vulnerability tasks across 188 projects and validates generated PoCs by executing them.
Themes
LLM agents and process diagnostics; evaluation and measurement; robustness and security impact.

OpenApps

ICLR 2026

OpenApps' core concept is environment variation as a robustness variable. A UI agent that succeeds on one fixed app instance may be using brittle visual or textual cues. The paper makes the app itself configurable so success measures whether the agent understands the workflow across appearance and content changes.

Mathematical object
A task distribution over app configurations, not a single deterministic UI state.
Approach
Evaluates multimodal agents across thousands of app variants and tracks success swings, loops, and hallucinated actions.
Themes
UI-agent reliability; environment variation; grounding failures under distribution shift.

MedAgentGym

ICLR 2026

MedAgentGym's core concept is biomedical data science as an executable agent environment. The agent must write or modify code, receive feedback, and improve task performance in sandboxed biomedical workflows. The benchmark matters because scientific agents need verifiable work products, not persuasive prose.

Mathematical object
A trajectory of code actions with ground truth, feedback, and task outcome.
Approach
Provides 72,413 sandboxed biomedical coding tasks and trains Med-Copilot with offline and online RL.
Themes
Executable biomedical agents; scientific discovery; healthcare ML.

SandboxEscapeBench

ICML 2026

SandboxEscapeBench's core concept is the sandbox boundary as the object of evaluation. A tool-using model is not only generating text; it may execute commands in a containerized environment. The important question is whether the agent can cross a boundary it should not cross.

Mathematical object
A reachability condition: can the agent obtain host-level evidence such as a protected flag from inside a nested sandbox?
Approach
Covers public escape tasks across misconfiguration, privilege, runtime, orchestration, and host/kernel layers.
Themes
Agent infrastructure risk; CTF-style evaluation; sandbox safety.

EditBench

ICLR 2026

EditBench's core concept is code editing under real context. Code assistants are often evaluated on isolated snippets, but real edits depend on highlighted regions, cursor position, instructions, and surrounding repository state. The paper makes context part of the task rather than noise around it.

Mathematical object
A conditional edit function from instruction and local code context to a patch.
Approach
Evaluates 40 LLMs on 545 wild code-edit tasks and measures how realistic context shifts success.
Themes
Evaluation; coding assistant reliability; developer tools.

OmniVerifier

ICLR 2026

OmniVerifier's core concept is visual outcome verification. A visual model can generate, edit, or reason about images, but the harder question is whether the resulting image satisfies the requested condition. The verifier becomes a reusable scoring object across visual tasks.

Mathematical object
A verification function over image, instruction, and expected visual outcome.
Approach
Builds ViVerBench and OmniVerifier-7B across 16 task categories, then uses verification for iterative refinement.
Themes
Evaluation; test-time scaling; visual verification.

Rational Agents

ICLR 2026

Rational Agents' core concept is information-gain-guided interaction. If an agent can ask questions before acting, the best next move is not necessarily the one that looks closest to the final answer. It is the move that most reduces decision-relevant uncertainty.

Mathematical object
Expected information gain over possible hidden states and future actions.
Approach
Uses Monte Carlo expected-information-gain inference in dialogue-style games such as Battleship and Guess Who.
Themes
Reasoning, planning, tool use; resource-rational dialogue.

TRACE Effort

ICLR 2026

TRACE Effort's core concept is reward hacking detected through reasoning effort. If a model passes a verifier before enough reasoning is present to solve the intended task, the high score may be a shortcut. The paper makes the amount of reasoning itself a diagnostic variable.

Mathematical object
Verifier success as a function of progressively truncated chain-of-thought.
Approach
Flags low-effort verifier-passing behavior by measuring when reward appears along a reasoning trace.
Themes
Reward hacking; process diagnostics; evaluation reliability.

Approach

Structured generative modeling; scientific-domain generation; sampler correctness.

Spherical Watermark

BATCH 02

Data, Safety, Multimodal, and Theory Gaps

Common Corpus

ICML 2026

Common Corpus' core concept is open pretraining data as infrastructure, not as a side input to modeling. The paper treats a language model corpus as a public object whose legal status, provenance, mixture design, filtering, and benchmark behavior determine what kind of research can be reproduced. The first-principles problem is that model claims are hard to compare when the data-generating process is private or legally ambiguous. The approach is to assemble a very large public-domain and openly licensed text corpus, document where it comes from, and study how model quality changes when the data source is constrained by openness rather than maximal scraping.

Mathematical object
A documented training distribution with provenance constraints and mixture weights.
Approach
Builds and evaluates an open corpus so data governance becomes measurable in downstream model behavior.
Themes
Data governance; reproducibility; open foundation-model infrastructure.

OpenThoughts

ICLR 2026

OpenThoughts' core concept is reasoning traces as a public training artifact. The paper starts from the observation that strong reasoning behavior is often transferred through proprietary chains, hidden teacher models, and opaque data recipes. The first-principles problem is how to make reasoning improvement inspectable: what examples are used, what intermediate steps are exposed, and what supervision signal links a final answer to the path that produced it. The approach is to release a large-scale open reasoning dataset and training recipe so the community can test whether explicit traces teach search, decomposition, and self-correction rather than only answer imitation.

Mathematical object
A supervised distribution over problems, intermediate reasoning traces, and final answers.
Approach
Constructs open reasoning data and uses it to study how trace supervision changes downstream reasoning behavior.
Themes
Reasoning data; open science; post-training transparency.

Midtraining Bridges Pretraining and Posttraining

ICLR 2026

The core concept is midtraining as the missing interface between generic next-token learning and instruction or preference tuning. A model leaving pretraining has broad statistical knowledge but no clean behavioral contract; a model entering posttraining is expected to follow instructions, use tools, and solve tasks. The first-principles problem is that jumping directly from one regime to the other can waste capacity and produce brittle alignment. The approach treats midtraining data and objectives as a bridge distribution that reshapes the representation before expensive posttraining asks for agentic or instruction-following behavior.

Mathematical object
An intermediate training distribution that changes representation geometry before alignment objectives.
Approach
Studies curriculum, data mixture, and objective placement between pretraining and posttraining.
Themes
Training pipelines; data as control; foundation-model lifecycle.

BioX-Bridge

Biology rarely gives one clean table: sequence, structure, perturbation, image, phenotype, and textual annotation all describe the same underlying system from different instruments. The first-principles problem is to build a representation that lets evidence from one modality constrain predictions in another without pretending the modalities are interchangeable. The approach builds a bridge model that aligns biological views so downstream tasks can use cross-modal information rather than living inside a single assay silo.

Mathematical object
A shared latent representation over heterogeneous biological modalities.
Approach
Aligns biological inputs so sequence, structure, imaging, and annotation evidence can transfer across tasks.
Themes
Scientific foundation models; multimodal biology; representation interfaces.

MrRoPE

ICLR 2026

MrRoPE's core concept is positional encoding as geometry, not bookkeeping. Transformers need positions so attention can distinguish order, but long-context extrapolation fails when the learned coordinate system is stretched beyond its stable range. The first-principles problem is to preserve relative structure while letting the same model operate across context scales. The approach modifies rotary position encoding so the model sees a more stable positional manifold, reducing the mismatch between training lengths and longer inference-time sequences.

Mathematical object
A rotary positional coordinate transform over attention features.
Approach
Changes the positional geometry used by attention to improve length generalization and stability.
Themes
Long context; sequence geometry; efficient adaptation.

LiftQuant

ICLR 2026

LiftQuant's core concept is quantization as an error-transport problem. Low-bit inference is not simply replacing real numbers with fewer bits; each layer changes how local rounding errors propagate through activations, normalization, and attention. The first-principles problem is to reduce memory and bandwidth while preserving the function computed by the full-precision model. The approach identifies where quantization damage concentrates and applies lifting or correction mechanisms so compressed weights and activations remain close to the original computation where it matters.

Mathematical object
Layerwise quantization error and its propagation through network computation.
Approach
Uses targeted transformations to keep low-bit inference aligned with full-precision behavior.
Themes
Efficient inference; numerical systems; model compression.

SlaClip

SlaClip's core concept is vision-language alignment under a cheaper representation budget. CLIP-style training works by making paired image and text embeddings agree, but the full embedding and contrastive pipeline can be expensive or brittle when transferred. The first-principles problem is to preserve semantic alignment while reducing the computational or architectural burden. The approach changes how image-text information is selected, compressed, or aligned so the model keeps the matching function without carrying unnecessary representation cost.

Mathematical object
A contrastive embedding space relating image representations to text representations.
Approach
Reduces or restructures the alignment machinery while preserving cross-modal retrieval and recognition behavior.
Themes
Vision-language models; efficient adaptation; representation compression.

ETTFS

ICML 2026

ETTFS' core concept is training efficiency as a schedule over which examples deserve gradient budget. Large training runs spend most of their cost repeatedly updating on data whose marginal value changes during learning. The first-principles problem is to decide when an example is still teaching the model something and when it is mostly consuming compute.
