Causality and scientific discovery as evidence boundaries

This page expands the causality and scientific-discovery lane at paper level. The common problem is not prediction. It is deciding what the evidence actually proves: which action would change an outcome, which background facts must stay matched, which causal stories are still possible, which repair point is most likely, which time rule is real, and which scientific claim can be tested and possibly rejected.

FIRST PRINCIPLE

Prediction Is Not Intervention

A predictive model can say which things usually move together. A causal or scientific model must say what would change if one thing were deliberately changed: a treatment, a program component, a service, a prompt route, or an action. That question requires a recipe for what stays matched, what changes, what is observed, and which hidden causes are allowed by the assumptions.

The strongest papers in this lane do not overclaim. They name the boundary of what the evidence proves. Sometimes the right output is a small set of background facts for one effect, not a full causal graph. Sometimes it is the whole set of graphs the data still cannot separate, not one diagram. Sometimes it is a ranked list of likely repair points, not a single blamed service. Sometimes a learned feature becomes scientific only after a test that could have rejected it.

FORMULA PASS

Paper-Specific Math Boxes

Local Covariate Selection

Object. One treatment effect plus the background facts that must be held fixed so the comparison is fair.

Why it works. Full graph recovery is often unnecessary. The method helps when the selected variables block the wrong comparison paths for one intervention claim, so estimation can focus on the effect that matters rather than every arrow in the system.

compare treatment values after holding fixed the background variables that make the comparison fair

Evidence check. Report stability of the chosen background facts, sensitivity to hidden common causes, tests that avoid accidentally opening wrong paths, and whether alternative valid sets give the same effect estimate.

TRECA And Fair Causal Bandits

Object. A decision rule whose action is allowed only when the treatment benefit or fairness claim is stable enough.

Why it works. In high-stakes settings, not knowing is part of the action. Abstention and fairness-aware exploration prevent the learner from turning unproven "what would have happened otherwise" claims into irreversible decisions.

act when the conservative benefit is larger than risk and fairness violation stays below the allowed limit

Evidence check. Measure abstention regions, sensitivity to helper models, regret beside fairness violations, and stability under plausible causal stories.

Unpaired Causal IV

Object. Differences between environments that act like organized tests, even when observations are sparse or unpaired.

Why it works. Environments act like structured nudges. The method extracts causal signal from how data changes across settings, not from observing every unit under every condition.

use environment changes to separate causal signal from background variation when paired samples are missing

Evidence check. Test environment differences, weak-test behavior, sensitivity to unpaired sampling, and whether inferred effects survive held-out environments.

Structure Learning CI And DiCoLa

Object. Evidence about which variables stop moving together after the right background facts are held fixed.

Why it works. Graph learning is only as strong as the tests that decide whether links are absent or present. Divide-and-conquer helps scale the search, but the claim still rests on whether those link tests have the right false-alarm and missed-link rates.

edge decisions come from tests of whether two variables remain related after holding a chosen set fixed

Evidence check. Report false-alarm rates, missed-link rates, sample-size sensitivity, hidden-variable stress tests, false edge and missing edge rates, and whether decomposition preserves guarantees.

Distributional Equivalence

Object. The set of causal graphs that produce the same observed data pattern when hidden variables, cycles, or edge-rank constraints are allowed.

Why it works. When several mechanisms are indistinguishable from observations alone, returning one graph is false precision. The useful output is the remaining set and the features shared by every graph inside it.

return every graph still compatible with the data; trust only claims shared by the whole set

Evidence check. Show which edges or effects are shared, which remain ambiguous, and how assumptions shrink or widen the set.

BRCD And Production Agent Studies

Object. A ranked list of repair points after seeing traces, partial causal structure, and the observed failure.

Why it works. Root cause is not the largest anomaly. It is the place where an intervention would most change the chance of failure. Keeping remaining doubt over the system graph prevents the diagnosis from pretending operations data supports more structure than it does.

rank a cause by how much the failure would change if that cause were fixed

Evidence check. Compare anomaly rank to intervention success, sample compatible graphs, audit missing trace variables, and evaluate whether suggested fixes reduce recurrence.

CausalGame

Object. An interactive environment where an agent must choose measurements or actions that separate possible mechanisms.

Why it works. Causal knowledge is active: the right action can separate two mechanisms that passive observation leaves tied. The benchmark tests evidence acquisition, not just verbal causal explanation.

choose the action that best separates the remaining possible mechanisms

Evidence check. Measure intervention choice quality, reduction in remaining mechanisms, confounding traps, and whether the agent distinguishes correlation from controllable effect.

Latent Hawkes, OU Identifiability, And Power-Law Discovery

Object. Time rules inferred from event triggers, repeated moment patterns, or stable repeated features.

Why it works. Time order helps only when paired with a process model. Hawkes structure gives triggering paths, OU moments constrain drift, and power-law features stabilize noisy time-series evidence before discovery.

temporal claim needs a stable rule for how state changes plus observations that can reveal that rule

Evidence check. Test lag-scale sensitivity, hidden subprocess stress, moment equations, nonstationarity, and whether interventions confirm the inferred temporal direction.

Neural Effect Search

Object. A learned feature converted into a randomized treatment contrast with multiplicity control.

Why it works. Sparse features are only candidate hypotheses. They become scientific when intervention or randomized comparison shows a measured effect that survives correction for the many searched features.

feature f becomes evidence after estimating effect(f) with randomized contrast and multiple-testing correction

Evidence check. Report randomization design, corrected p-values or intervals, feature-label robustness, and replication across held-out data or tasks.

HypoSpace, Bitween, And Consequence-Based Utility

Object. A hypothesis space plus scoring maps for coverage, uniqueness, recovery, verification, and downstream consequence.

Why it works. Scientific generation should be judged as search, not as one fluent answer. These methods reward hypotheses that cover distinct regions and produce consequences that can be checked.

discovery value = coverage(H) + uniqueness(H) + expected evidence gain or verified consequence

Evidence check. Measure duplicate rate, hypothesis recovery, consequence validity, verification success, and whether high-scoring hypotheses are actually rejectable.

RefineStat, MedAgentGym, PaperBench, WZ-LLM, And VERINA

Object. A generated scientific artifact whose validity is checked by execution, data feedback, formal proof, or workflow completion.

Why it works. The generator proposes; the environment or checker accepts. This separation matters because scientific language can be persuasive while the code, statistics, proof, or experiment is invalid.

artifact is admissible only if checker C(artifact, data, proof state, workflow state) passes

Evidence check. Report executable success, semantic repair rate, proof-kernel acceptance, task completion, and where checker scope is narrower than the scientific claim.

DISCO, Fair Posthoc Control, Missing-Covariate Robustness, And Accuracy Auctions

Object. A policy constrained by legitimate what-if comparisons, ambiguity over missing variables, fairness tradeoffs, or social value.

Why it works. A prediction becomes a decision when it changes outcomes for people. These methods modify the objective or allowed set so shortcut variables, incomplete records, and unequal value of correctness are not hidden inside average accuracy.

choose policy that improves welfare while respecting what-if, missing-data, and fairness constraints

Evidence check. Show tradeoff movement, subgroup effects, robustness to missingness assumptions, truthful value reports, and cases where average accuracy hides policy harm.

MINT, Causal Route Gating, Divergent Interventions, And Activation Oracles

Object. A change inside the model that stays near hidden states the model naturally uses.

Why it works. Hidden-state interventions identify internal causes only if the patched state is one the model could naturally occupy. Otherwise the result measures an artificial shock, not the real route used by the model.

internal effect is credible when changing a natural hidden state changes the output in the expected way

Evidence check. Measure patch locality, distance from natural hidden-state behavior, route specificity, behavior change under pressure, and false conclusions from artificial interventions.

OBJECT 01

Local Effects

Local Covariate Selection

Problem. Estimating one causal effect should not require learning the whole causal graph when only a local comparison certificate is needed.

Object. A target treatment-outcome effect plus the background facts that make that comparison valid.

Why it works. The method focuses on blocking the wrong paths for the effect while avoiding variables that open wrong paths. It allows hidden variables and avoids an overly rigid assumption about what had to happen before treatment.

Connection. It is the causal version of allowed-set design: only comparison sets that prove the effect are allowed.

TRECA

Problem. Treatment-responder classification can be unsafe when helper estimates and one-direction treatment assumptions are imperfect.

Object. A causal responder decision with a safe option to abstain and extra attention to rare bad cases.

Why it works. The method treats doubt about treatment response as part of the decision. Abstention is a valid action when the causal claim is too fragile.

Connection. This links high-stakes evaluation to evidence boundaries.

Unpaired Causal IV

Problem. Environments may be numerous while observations per environment are sparse or unpaired.

Object. Causal claims from organized environment variation.

Why it works. The environment index supplies structure that substitutes for dense paired observations. Consistency comes from how variation is arranged, not from seeing every unit under every condition.

Connection. It shows data design can prove causal effects when raw sample count is limited.

Fair Causal Bandits

Problem. Exploration can violate fairness before the learner knows the fairness constraint.

Object. Learning cost plus the risk that an action would be unfair under a different sensitive condition.

Why it works. The algorithm treats fairness as a learned causal constraint during exploration, not as an after-training audit. Actions are judged by reward and what would have happened under another sensitive condition.

Connection. Governance becomes causal when the relevant question is what would have happened under another sensitive condition.

OBJECT 02

Graph Evidence

Structure Learning CI

Problem. Graph recovery can look like algorithmic search while the real bottleneck is statistical testing.

Object. Tests for whether two variables stop being related after the right background variables are held fixed.

Why it works. For some graph families, the difficulty of learning structure reduces to the difficulty of getting these relation tests right. Better graph learning requires better evidence for which links are absent or present.

Connection. It is benchmark validity for causal graphs.

Distributional Equivalence

Problem. With hidden variables and cycles, many causal graphs can imply the same observed data pattern.

Object. The remaining set of graphs that the observed data cannot separate.

Why it works. The method returns what the data can prove instead of pretending one graph is uniquely known. Edge-rank constraints help shrink or widen that remaining set under harder causal structure.

Connection. This is the lane's discipline in one paper: do not state more than the evidence distinguishes.

DiCoLa

Problem. Relation testing for causal discovery must scale and survive hidden-variable pressure.

Object. Dividing the graph search into smaller relation tests without assuming every cause is observed.

Why it works. The method decomposes the search while keeping guarantees about the tests it relies on. Scalability is useful only if the discovered independences remain valid under hidden structure.

Connection. It extends Structure Learning CI from primitive theory toward scalable discovery.

PSAHS And RULE

Problem. Graph data can contain noisy structure, misaligned attributes, and incomplete labels.

Object. Agreement between structural and attribute views, or explicit correspondence constraints.

Why it works. When graph structure and attributes agree, repair is safer; when they diverge, the system should expose broken correspondence rather than force a single fused graph.

Connection. Graph learning inherits the same evidence boundary as causal discovery.

OBJECT 03

Root Cause

BRCD

Problem. In production incidents, many services look abnormal together, but operators need a ranked cause under scarce failure samples.

Object. A ranked list of root-cause candidates while the true service graph is still partly unknown.

Why it works. BRCD starts from partial pre-failure structure, samples compatible directed graphs, and keeps doubt over candidate causes. It does not require pretending the exact graph is known.

Connection. It turns causal inference into operational triage: where should an agent intervene first?

CausalGame

Problem. Agents can gather lots of data and still infer the wrong mechanism under confounding, selection bias, or noisy measurement.

Object. An interactive causal environment where actions create evidence.

Why it works. The benchmark tests whether the agent asks questions and collects data that identify the mechanism, not merely whether it narrates a plausible causal story.

Connection. This is root-cause logic generalized to scientific agents.

MAP And Production Agent Studies

Problem. Deployed agents often fail through workflow state, monitoring gaps, or human handoff rather than isolated answer errors.

Object. Operational traces and practitioner-observed failure modes.

Why it works. Production studies expose which causal variables teams actually need to monitor: action state, tool state, user intent, intervention points, and escalation triggers.

Connection. This grounds causality in deployment, where diagnosis must lead to action.

OBJECT 04

Temporal Mechanisms

Latent Hawkes Causal Discovery

Problem. Event streams can show temporal dependence while hiding the subprocesses that created it.

Object. Observed and hidden triggering processes over time.

Why it works. The method uses a discrete-time limiting view and path-based tests to separate observed causal links from hidden subprocesses. Temporal order alone is not treated as causality.

Connection. It is scientific discovery when only part of the process is visible.

OU Identifiability

Problem. Random time-changing systems may be observed only through long-run summaries and limited interventions.

Object. Linear drift structure known up to scale from observations and interventions.

Why it works. The paper states which summaries distinguish the dynamics. It gives a boundary on what the process reveals without full trajectory control.

Connection. It is physical-operator thinking applied to causal drift.

Robust Causal Discovery With Power-Laws

Problem. Noisy, non-stationary time series can make raw temporal dependence unreliable for causal discovery.

Object. Stable repeated time-pattern features extracted before causal search.

Why it works. Power-law features summarize temporal structure that can survive noise better than raw observations. Discovery is performed on a more robust measurement of the process.

Connection. It links visible time-pattern representation to causal evidence.

Linear Recurrent Memory

Problem. A partially observed decision process needs memory that is sufficient for future action.

Object. Running memory that keeps enough hidden state for the next decision.

Why it works. The recurrence helps only if it preserves the hidden variable that controls the best action. This gives memory a causal role, not just a sequence-modeling role.

Connection. It connects causality to agents and state-space models.

OBJECT 05

Hypothesis Search

Neural Effect Search

Problem. Humans usually choose which treatment effects to test, making scientific search narrow and expensive.

Object. Learned sparse features as candidate scientific measurement units.

Why it works. Foundation-model and SAE features become hypotheses only after randomized treatment evidence and multiplicity control. Interpretability is converted into a tested causal effect.

Connection. It links mechanistic interpretability to statistical discovery.

HypoSpace

Problem. Scientific reasoning is search over possible explanations, not one answer.

Object. An enumerable hypothesis space with validity, uniqueness, and recovery metrics.

Why it works. Measuring a model as a sampler over hypotheses reveals coverage and duplication, not only whether it emits one plausible favorite.

Connection. It is benchmark design for discovery.

Bitween

Problem. Algorithmic discovery needs generated reductions that can be checked beyond one example.

Object. A candidate randomized self-reduction with verification-backed evidence.

Why it works. Regression, symbolic search, and agent proposals generate candidates, but the reduction matters only when verified as reusable structure.

Connection. It is scientific hypothesis search in algorithms.

Consequence-Based Utility

Problem. Some hard scientific or mathematical claims cannot be directly verified by an oracle.

Object. Downstream consequences that become easier to check.

Why it works. A candidate solution is valued by whether it improves related verifiable work. The claim is measured through consequences, not only direct correctness.

Connection. It links weak verification to hypothesis utility.

OBJECT 06

Executable Workflows

RefineStat

Problem. A probabilistic program can run while still using invalid statistical semantics.

Object. Program components with distribution, parameter, and diagnostic constraints.

Why it works. The system repairs priors or likelihoods locally when semantic checks fail. Scientific code generation becomes component-wise refinement under a statistical verifier.

Connection. It is executable evaluation for probabilistic modeling.

MedAgentGym

Problem. Biomedical agents need to act in data-science environments, not only answer biomedical questions.

Object. Executable sandbox trajectories with task specs, feedback, ground truth, and RL data.

Why it works. The environment checks consequences of code and analysis actions. Agent learning gets trajectories whose success is tied to biomedical workflow outcomes.

Connection. It is the scientific equivalent of CyberGym and TerminalTraj.

PaperBench And AI Scientist Workflows

Problem. Scientific work includes literature, experiments, code, figures, and claims that must cohere.

Object. A multi-step research artifact with verifiable components.

Why it works. The benchmark or workflow can check whether the system completes pieces of scientific work rather than only producing a persuasive summary.

Connection. It turns science into an agent environment with evidence hooks.

WZ-LLM And VERINA

Problem. Mathematical discovery or proof generation can sound right while being formally invalid.

Object. Proof artifacts checked by formal systems.

Why it works. The verifier rejects invalid derivations, so generated reasoning must satisfy a formal kernel. Scientific text becomes a checkable artifact.

Connection. Formal verification is one end of scientific evidence.

OBJECT 07

Counterfactual Policy

DISCO

Problem. Models can rely on shortcut variables that predict labels but should not causally drive the decision.

Object. Conditional independence from observed shortcut bias variables.

Why it works. The method encodes an anti-causal assumption and regularizes away the spurious dependence. Robustness comes from removing a path, not from generic noise training.

Connection. It is causal route control for fairness and robustness.

Fair Posthoc Control

Problem. A deployed model may need fairness-accuracy tradeoff adjustment after training.

Object. A controllable frontier over group fairness and accuracy.

Why it works. Representations are learned so post-processing can move along the frontier without retraining. The method keeps the social constraint adjustable.

Connection. It links causal/fairness constraints to mechanism design.

Robust Contextual Optimization With Missing Covariates

Problem. Decisions can become overconfident when missing variables are filled in as if they were facts.

Object. The set of plausible completions for the missing record.

Why it works. The policy is optimized across worlds consistent with the observed partial record. Missingness remains part of the remaining doubt rather than being erased.

Connection. It is what-if caution under incomplete evidence.

Accuracy Auctions

Problem. Correctness has different value for different users or decisions.

Object. A welfare mechanism over private values for correct predictions.

Why it works. The policy objective changes from average accuracy to truthful value-weighted utility. This makes the social consequence of correctness part of the decision rule.

Connection. Causal policy and social welfare meet when decisions affect people unevenly.

OBJECT 08

Hidden-State Interventions

MINT

Problem. Multimodal hallucination often comes from failed fusion, not from vision or language alone.

Object. The internal band where visual evidence and language state are combined.

Why it works. Patching tests whether changing an internal state changes the output. The method identifies where visual information actually affects language generation.

Connection. It estimates causes inside a neural network.

Causal Route Gating

Problem. Vision-language answers can be driven by text-prior routes instead of current visual evidence.

Object. How much the visual route and text route each contribute through attention heads.

Why it works. One forward pass and an update-direction estimate expose routes that drive hallucination, then prior-heavy paths can be suppressed.

Connection. It connects intervention to evidence-channel credit.

Divergent Causal Interventions

Problem. Internal-state interventions can push a model into states it would never naturally use and create misleading causal conclusions.

Object. An intervention that stays near the model's natural hidden-state behavior.

Why it works. The method warns that a causal patch is only meaningful if the patched state remains in a regime the model actually uses. Otherwise the intervention tests an artifact.

Connection. It is the evidence boundary for interpretability interventions.

Activation Oracles And Assistant Axis

Problem. Hidden harmful tendencies or persona drift may not appear in visible text until pressure is applied.

Object. Internal directions whose activity predicts or controls behavior.

Why it works. Monitoring or constraining hidden directions adds an observation channel closer to the cause of unsafe behavior. The intervention matters only when the direction is causal, not a surface correlate.

Connection. Safety monitoring becomes causal representation analysis.

SYNTHESIS

The Cross-Paper Shape

Target Before Graph

Local Covariate Selection, TRECA, Fair Causal Bandits, and robust missing-variable decision rules all begin with the decision or effect. They work because they ask what structure is sufficient for that target rather than forcing a global causal model first.

Remaining Possibilities Before Certainty

Structure Learning CI, Distributional Equivalence, DiCoLa, BRCD, OU Identifiability, and Latent Hawkes Causal Discovery all preserve the remaining doubt about what the data can distinguish. They improve scientific honesty by returning tests, remaining graph sets, ranked likely causes, or bounds instead of a false single answer.

Hypothesis Before Story

Neural Effect Search, HypoSpace, RefineStat, MedAgentGym, Bitween, WZ-LLM, and VERINA turn fluent scientific work into checkable objects. A model can propose, but the claim becomes scientific only when a statistical test, executable environment, proof checker, or recovery metric can inspect it.

FOCUSED CHAIN

Identification Boundaries: What The Evidence Actually Determines

The central question in causal discovery is not whether the model can draw a plausible arrow. It is which "what would happen if we changed this?" claim gives the same answer across all worlds still compatible with the observations and assumptions. That shared answer is what the evidence proves.

The Core Object

Problem. Observational data usually underdetermines intervention. Many mechanisms can produce the same correlations while disagreeing about what would happen after an action.

Object. One target claim, such as an average treatment effect, responder decision, root-cause fix, edge set, drift rule, or fair policy, evaluated over all causal worlds the evidence still allows.

Why it works. A method is valid when every allowed world that matches the evidence gives the same answer for the target. The algorithm does not need to recover all hidden structure; it needs to prove the target answer is unchanged across the remaining doubt.

target is proven when every evidence-compatible world gives the same target answer

Local Covariate Selection, TRECA, And Fair Causal Bandits: Prove The Decision, Not The Whole System

Problem. Full graph recovery is often impossible or unnecessary, but decisions still need causal legitimacy.

Object. A local certificate: a valid comparison set, an abstention region, or a fairness constraint that is sufficient for one decision.

Why it works. These papers reduce the target. Local Covariate Selection asks which variables block the wrong paths for one treatment-outcome pair. TRECA adds abstention when responder status is not stable enough to act on. Fair Causal Bandits treats fairness as a "what would have happened otherwise" constraint inside exploration.

Failure boundary. The certificate fails when hidden common causes, missing fairness variables, selection bias, or weak treatment-direction assumptions allow two possible worlds to agree on data and disagree on the action.

act only when the decision is stable over plausible completions

Structure Learning CI, Distributional Equivalence, And DiCoLa: Return The Remaining Graph Set

Problem. A single learned graph can look precise while the data supports several causal structures.

Object. Evidence from variables that stop being related after background facts are held fixed, plus the remaining graph set that evidence implies under hidden variables, cycles, and edge-rank constraints.

Why it works. Those relation tests are a checkable shadow of causal structure. The papers work by preserving the distinction between observed independence, assumed causal rules, and the graph objects those facts can prove. Returning the remaining set is the correct answer when one graph is not determined.

Failure boundary. Relation tests can be miscalibrated, small samples can hide weak dependencies, and hidden variables can make different mechanisms look the same from observations.

evidence -> independence claims -> graph set, not necessarily one graph

BRCD, CausalGame, MAP, And Production Agent Studies: Diagnosis Is Repair Ranking

Problem. In incidents, agents, and deployed workflows, the goal is rarely a beautiful causal graph. The goal is to know which intervention would change the bad outcome.

Object. A ranked list of intervention points conditioned on traces, partial structure, and observed failures.

Why it works. BRCD keeps doubt over compatible graphs while ranking likely root causes. CausalGame forces agents to collect evidence that separates mechanisms. Production studies name the operational variables that a real diagnosis must include: handoff state, tool state, action history, monitoring gaps, and human escalation.

Failure boundary. If the trace omits the true causal variable, confidence is fake. A confident anomaly score is not a causal diagnosis unless the proposed intervention would change the failure probability.

root cause = repair point likely to change failure, not largest anomaly

Latent Hawkes, OU Identifiability, Power-Law Discovery, And Linear Recurrent Memory: Time Helps Only When It Preserves Mechanism

Problem. Temporal order is useful but not sufficient. Lagged correlation can come from hidden subprocesses, common drive, aliasing, or nonstationarity.

Object. A transition or triggering law whose parameters remain stable enough to recover from time summaries, interventions, or running memory.

Why it works. Hawkes discovery uses event triggering structure; OU identifiability uses moment equations; power-law discovery uses stable temporal features; recurrent memory works when its state is sufficient for the hidden process that controls action. Each method extracts a mechanism from time by adding structure beyond "earlier predicts later."

Failure boundary. Wrong time scale, hidden subprocesses, deployment drift, and insufficient interventions can make prediction strong while the mechanism is wrong.

temporal causality requires stable transition law plus adequate observation scale

The Evidence-Boundary Chain

Across papers. Local effect papers shrink the causal target until it can be certified. Graph papers preserve remaining possibilities instead of inventing certainty. Root-cause papers turn causal inference into repair ranking. Temporal papers use dynamics only when the process assumptions make the mechanism recoverable.

First-principles read. The broad problem is to separate what is predicted from what is controlled. The approach is to define a smaller object whose value is forced by evidence plus assumptions, then refuse to claim more than that object.

Big-picture consequence. Causal ML becomes useful when it names the decision-relevant quantity that must stay unchanged across remaining explanations. It is not a graph-drawing contest; it is a discipline for deciding when an action claim survives alternative explanations.

prediction asks what follows what; intervention asks what changes when we act; evidence boundary asks when observations plus assumptions force the intervention answer
FOCUSED CHAIN

Executable Hypotheses: When A Scientific Claim Becomes Checkable

A scientific model is not finished when it produces an explanation. It is finished only when the explanation is mapped to an object that can fail: a randomized test, a unique hypothesis, a reducible algorithmic claim, a probabilistic program, a biomedical workflow, or a formal proof artifact.

The Core Object

Problem. Language models can generate coherent scientific prose without producing a claim that changes any observable belief.

Object. A set of possible hypotheses with evidence channels: tests, verifiers, execution environments, proof kernels, recovery metrics, and consequence functions.

Why it works. A hypothesis is useful when evidence can reduce the remaining doubt about it. The model may propose candidates, but the scientific content comes from the map between candidate and rejection channel.

a hypothesis is scientific when some evidence could change belief in it

Neural Effect Search: Interpretability Becomes Science Through Randomization

Problem. A sparse feature can look meaningful without proving that the feature has a causal effect on behavior or outcomes.

Mathematical object. A learned feature converted into a treatment contrast with multiplicity-controlled evidence.

Why it works. The method does not stop at naming a feature. It asks whether intervening or grouping by that feature changes a measured outcome in a statistically defensible way. Randomization and correction protect against the fact that many features are searched.

Failure boundary. Feature labels can be post-hoc stories. Without randomized evidence and multiple-testing control, the method can rediscover noise and call it a mechanism.

feature -> candidate effect -> randomized test -> corrected evidence

HypoSpace And Consequence-Based Utility: Search Needs A Space And A Scoring Map

Problem. One plausible hypothesis tells little about discovery ability. A model could repeat near-duplicates, miss whole regions, or optimize for impressiveness instead of testability.

Mathematical object. A hypothesis space with coverage, uniqueness, recovery, and downstream consequence measures.

Why it works. HypoSpace evaluates the model as a sampler over explanations; consequence-based utility scores whether a proposed claim improves easier-to-check downstream tasks. Together they replace "interesting idea" with measurable search behavior.

Failure boundary. The metric can reward easy-to-state hypotheses over important ones, or consequences that correlate with truth without being diagnostic enough to reject false claims.

discovery quality = coverage + uniqueness + evidence value, not fluency

RefineStat And MedAgentGym: Scientific Work Must Change State In An Environment

Problem. Scientific code or biomedical analysis can be syntactically valid while semantically wrong.

Mathematical object. An executable workflow whose intermediate states expose statistical, clinical, or data-analysis failures.

Why it works. RefineStat checks probabilistic-program semantics and repairs local components. MedAgentGym puts biomedical agents inside tasks where code, data, feedback, and ground truth define consequences. Both force claims to pass through an environment where mistakes become observable.

Failure boundary. Execution can still be shallow. A toy environment may validate commands while missing clinical realism, and a statistical repair may make a component legal without supporting the final scientific claim.

claim -> artifact -> execution trace -> domain-specific failure signal

PaperBench, WZ-LLM, VERINA, And Bitween: Artifacts Need Independent Checkers

Problem. Research papers, proofs, and algorithmic reductions can be persuasive while containing hidden invalid steps.

Mathematical object. A composed artifact checked by independent criteria: experiment completion, proof validity, theorem constraints, or reduction verification.

Why it works. The checker separates generation from acceptance. PaperBench asks whether a research workflow assembles evidence-bearing components. WZ-LLM and VERINA rely on formal rejection of bad derivations. Bitween searches for reductions but needs verification before the generated structure counts.

Failure boundary. A checker covers only its formal scope. It can reject malformed proofs while missing irrelevant theorem choice, or verify a component while the end-to-end research conclusion remains weak.

generator proposes artifact; checker defines admissible artifact set

The Executable-Hypothesis Chain

Across papers. Neural Effect Search turns learned features into tested effects. HypoSpace measures hypothesis coverage and duplication. Consequence-based utility uses downstream evidence when direct proof is hard. RefineStat and MedAgentGym make scientific work executable. PaperBench, WZ-LLM, VERINA, and Bitween require independent artifact checks.

First-principles read. The broad problem is that generative models can create descriptions faster than science can reject them. The approach is to attach each description to a mathematical failure channel: statistical test, execution trace, proof kernel, recovery metric, or consequence score.

Big-picture consequence. AI for science becomes credible when it increases the rate of rejectable claims, not merely the rate of fluent proposals. The mathematical advance is the interface between generation and evidence.

proposal rate is useful only when rejection rate and evidence quality scale with it
