READ FIRST

The Big Picture Problem

ICLR 2026 reads like a conference about behavior becoming measurable. Reasoning models need trace recipes and verifiers. Agents need dynamic worlds, asynchronous tasks, UI variation, and scientific workbenches. Multimodal systems need causal maps of fusion, not just image-text scores. Generators need sample spaces that know about scenes, molecules, videos, speech, and safety. Data needs provenance and public recipes. Sequence models need memory mechanisms that scale without treating every token as equally expensive.

The first-principles question is: what structure has to exist before a model can be judged honestly? ICLR's strongest papers often answer by building a new interface around the model: a benchmark environment, a data pipeline, a verifier, a representation, or a constrained generator.

THEME 01

Agents Need Worlds, Not Question Lists

The object is the interaction loop.

CyberGym, GAIA2, OpenApps, ASTABench, MC-Search, SimuHome, and In the Flow all point to the same claim: agent capability appears inside a changing environment. The model has to observe state, choose an action, receive feedback, and decide the next move. A static question can miss whether the agent handles asynchronous updates, UI variation, tool latency, scientific constraints, or cyber exploit verification.

The approach is to build environments where the action is externally checked. In cybersecurity, the proof-of-concept must run against code. In UI work, the page state must change correctly. In multimodal search, retrieval and evidence must support the final answer. In scientific agents, tools, cost, and reproducibility become part of the benchmark.

ICLR 2026

CyberGym

Evaluates cyber agents through real codebases, executable proof-of-concept tests, and pre-patch/post-patch checks. The benchmark turns security ability into observable interaction with software state.

ICLR 2026

GAIA2

Benchmarks agents in dynamic and asynchronous environments. The key idea is that agent reliability depends on timing and state changes, not only final natural-language correctness.

ICLR 2026

OpenApps

Measures UI-agent reliability across environment variations. It tests whether a policy understands the task or has overfit to one fixed app appearance.

ICLR 2026

ASTABench

Builds a scientific-research agent suite with tools, costs, baselines, and reproducible environments. Scientific agency is evaluated as work, not as trivia.

ICLR 2026

MC-Search

Evaluates multimodal agentic search through structured long reasoning chains. It makes retrieval decisions and evidence attribution part of the measured behavior.

ICLR 2026

In the Flow

Optimizes agentic planning and tool use as a system-level workflow. The focus is the organization of actions and checks, not a single model call.

THEME 02

Reasoning Becomes Data, Verification, And Compute Allocation

A reasoning trace is useful only if it carries work.

OpenThoughts treats reasoning examples as recipe infrastructure. Verifying Chain-of-Thought via Computational Graph asks whether the trace implements a valid computation. TRACE effort work detects low-effort reward hacking. The Art of Scaling Reinforcement Learning Compute asks how RL post-training changes with budget. LongWriter-Zero and ThinkV show that long outputs and reasoning caches need targeted allocation, not uniform expansion.

The common approach is to stop treating reasoning length as the signal. The useful variable is whether the process changes uncertainty, preserves dependency structure, uses compute at the right place, and can be checked by a graph, verifier, or environment.

ICLR 2026

OpenThoughts

Builds data recipes for reasoning models. The contribution is not only a dataset; it is a reproducible way to generate and filter the intermediate work that trains reasoning behavior.

ICLR 2026

Verifying Chain-of-Thought Reasoning via Its Computational Graph

Turns a text trace into a dependency graph that can be checked. The method asks whether the reasoning has computational structure, not whether it sounds explanatory.

ICLR 2026

TRACE Effort

Detects implicit reward hacking by measuring how little reasoning is needed to satisfy a verifier. The diagnostic target is cheap success that does not represent real problem solving.

ICLR 2026

The Art of Scaling RL Compute for LLMs

Studies how post-training performance scales with reinforcement-learning compute. The paper treats RL as a budgeted process with curves and tradeoffs, not a recipe copied at one size.

ICLR 2026

LongWriter-Zero

Uses reinforcement learning to master ultra-long generation. The hard part is not length itself; it is maintaining coherent global structure while many local choices accumulate.

ICLR 2026

ThinkV

Compresses reasoning-model KV cache adaptively. It makes hidden reasoning state a resource allocation problem: preserve tokens that still affect the future, discard tokens that no longer pay rent.

THEME 03

Generation Must Use The Right Sample Space

A generator fails when it samples plausible objects in the wrong coordinates.

Quotient-Space Diffusion removes redundant rigid-motion degrees of freedom for molecules and proteins. FlashWorld builds fast 3D scenes around a usable spatial representation. Safety-Guided Flow changes the sampling path so unsafe outputs are pushed away. TRACE turns diffusion attention into instance-boundary supervision. FALCON asks for accurate likelihoods in continuous flows, where scientific estimates need more than pretty samples.

The first-principles approach is to choose the object before the network. If the object is a molecule, rotations should not create new examples. If the object is a scene, geometry must be explicit enough to render and inspect. If the object is safety-constrained generation, the sampler needs a direction away from forbidden regions.

ICLR 2026

Quotient-Space Diffusion Model

Models molecular and protein structures after removing irrelevant symmetry variables, then lifts samples back into coordinates. The contribution is changing the domain of diffusion, not only changing the network.

ICLR 2026

FlashWorld

Generates high-quality 3D scenes quickly. The system-level point is speed plus inspectable 3D structure: a generated world has to be useful as a world, not only as an image.

ICLR 2026

Safety-Guided Flow

Introduces negative guidance for safe generation. It treats safety as a vector field shaping the sample path away from bad regions.

ICLR 2026

TRACE: Your Diffusion Model Is Secretly An Instance Edge Detector

Uses internal diffusion attention as an instance-boundary signal. The model's hidden computation becomes supervision for another perception task.

ICLR 2026

FALCON

Targets accurate likelihoods for continuous flows. For molecular and scientific uses, likelihood estimation is part of the measurement contract, not a side metric.

ICLR 2026

VibeVoice

Uses next-token diffusion for expressive podcast generation. It extends diffusion-style generation into long-form audio where timing, expression, and sequence coherence matter.

THEME 04

Multimodal Models Need Causal Interfaces

Putting pixels and words in one model is not the same as understanding their fusion.

MINT maps where visual and textual signals fuse inside a multimodal decoder. Visual-Symbolic Mechanisms studies emergent symbol processing in vision-language models. fMRI decoding papers translate brain signals through structured representations. Active avatars use cognitive simulation between a prompt and motion. Spatial MLLM work asks whether models generalize beyond surface image-language correlations.

The approach is intervention. Patch hidden states, separate symbol-like variables, expose object-attribute-relation structure, and test spatial behavior directly. The goal is not only better multimodal scores; it is knowing which internal interface failed when the model hallucinated, contradicted the image, or lost spatial grounding.

ICLR 2026

MINT

Causally traces the fusion band where visual and textual signals combine in multimodal LLMs. It turns interpretability into a repair target by finetuning the layer region that caused grounding failures.

ICLR 2026

Visual-Symbolic Mechanisms

Studies emergent symbol processing in vision-language models. The important question is whether symbols are just labels or internal variables that support compositional reasoning.

ICLR 2026

Seeing Through the Brain

Decodes visual stimuli from fMRI and studies what representation bridges brain signals and images. The problem is interface design between measurement space and semantic visual space.

ICLR 2026

Instilling an Active Mind in Avatars

Adds cognitive simulation as an intermediate structure for avatar generation. Motion is guided by inferred internal state rather than direct prompt-to-animation mapping.

ICLR 2026

Spatial Intelligence in MLLMs

Tests whether multimodal models generalize in spatial reasoning. The issue is whether language grounding survives changes in geometry and viewpoint.

THEME 05

Data And Systems Are Behavior Design

The data pipeline and compute substrate decide what behavior can be learned.

Common Corpus treats ethical pretraining data as infrastructure. OpenThoughts makes reasoning data recipes public. Mamba-3 uses state-space principles for long sequence modeling. FlashVID and InfoTok allocate video tokens by information rather than uniform frames. TileLang makes neural kernels programmable. Low-precision transformer work studies when hardware-efficient arithmetic breaks training.

The shared approach is to make constraints explicit. Legal data constraints, long-context budgets, token budgets, kernel performance, and precision limits are not post-hoc engineering. They determine the learning problem the model actually sees.

ICLR 2026

Common Corpus

Builds a large ethical data collection for LLM pretraining. It makes provenance and legality part of the foundation-model substrate.

ICLR 2026

Mamba-3

Uses state-space principles for improved sequence modeling. The mathematical target is efficient state tracking over long sequences without treating full attention as the only memory mechanism.

ICLR 2026

FlashVID

Compresses long videos through tree-based spatiotemporal token handling. It spends model budget where visual information is changing, not uniformly across time.

ICLR 2026

InfoTok

Uses information-theoretic compression for adaptive video tokenization. The representation is selected by expected usefulness under a fixed token budget.

ICLR 2026

TileLang

Bridges programmability and performance in neural kernels. It matters because model methods only deploy if the computation can be expressed efficiently on hardware.

ICLR 2026

Why Low-Precision Transformer Training Fails

Studies FlashAttention failure under low precision. The main point is that numerical shortcuts have behavioral consequences inside training dynamics.

THEME 06

Theory Explains The Shape Of The System

Theory is useful when it tells us what the model can represent, compute, or fail to learn.

Softmax Transformers Are Turing-Complete asks what computation a transformer can simulate. HATSolver uses hierarchical attention for Groebner basis computation. Temporal Superposition studies how recurrent networks pack features under memory demands. Graph gluing papers build shared manifolds across graph domains. Optimizer-state and low-rank papers study which parts of training state matter.

The approach is not theory as decoration. The papers name the object behind a working recipe: computation, algebraic structure, memory geometry, graph manifold, optimizer state, or feature packing. Once that object is visible, engineering choices become arguments rather than habits.

ICLR 2026

Softmax Transformers Are Turing-Complete

Studies general computation in transformer-style models. The paper clarifies the difference between expressive possibility and practical learnability.

ICLR 2026

HATSolver

Uses hierarchical attention for Groebner bases. It connects neural sequence models to formal algebra, where intermediate symbolic structure matters.

ICLR 2026

Temporal Superposition

Explains how RNNs store many temporal features in limited dimensions. Memory is treated as geometry, not a vague hidden state.

ICLR 2026

GraphGlue

Aligns graph domains by gluing local geometries into a transferable representation. The mathematical object is a shared manifold across domains.

ICLR 2026

Taming Momentum

Studies optimizer states through low-rank approximation. It asks which directions in the state actually carry useful training information.

SPINE

What ICLR 2026 Is Saying

Agents need changing worlds

Capability appears when state changes after each action and the system still has to recover, verify, and continue.

Reasoning needs process evidence

Long traces are useful only when they encode dependency, uncertainty reduction, and checkable computation.

Generation needs native structure

Scenes, molecules, speech, video, and safe outputs require sample spaces matched to the object being generated.

Data and compute shape behavior

Public recipes, provenance, precision, tokens, kernels, and memory are part of the method, not implementation leftovers.
