FIRST PRINCIPLE

A Theme Is A Repeated Mathematical Problem

The theme names are not labels for topic areas. They are repeated failure patterns. Reasoning is about preserving task information through a trace. Evaluation is about measuring a hidden target through a noisy channel. Data is about moving parameters with evidence at the right time. Generation is about sampling in the right native state space. Theory is about naming the budget or threshold. Causality is about what evidence identifies. Multimodal work is about assigning credit across channels.

The map below keeps each subtheme in the same shape: problem, mathematical object, approach, representative papers, and cross-theme connection.

THEME 01

Agents And Reasoning

A reasoning trace is useful only if it keeps contact with the task.

The hidden object in reasoning work is not a polished answer. It is the changing internal state that carries evidence from the prompt, tool results, memory, and intermediate deductions toward an action. The mathematical question is whether that state still depends on the actual problem or has drifted into a reusable pattern that merely looks like reasoning.

The reason these methods work is conservation of relevant information under limited budget. A trace, cache, skill, or agent graph helps only when it preserves the facts that future steps need while throwing away repetition, irrelevant history, and expensive dead ends. Longer thought helps when each extra step increases useful conditional information. It hurts when extra steps add noise, self-imitation, tool cost, or coordination error.

THEME 02

Evaluation And Safety

The thing being tested is usually hidden.

A benchmark is a measuring device, not the ability itself. The ability is hidden: can the system reason from the evidence, use the right modality, obey a boundary, execute an artifact, or avoid a rare harmful state? The score is only an observation produced by prompts, tasks, judges, verifiers, users, and sampling rules. Evaluation works mathematically when that observation still carries enough information about the hidden property to separate real capability from noise, shortcuts, memorization, judge preference, and lucky samples.

The hard part is that models are not passive objects. Once a score becomes a training target, a leaderboard target, or a selection rule, the model can move toward patterns that raise the observed score without improving the hidden property. That is why the useful papers in this lane build sharper instruments: adaptive tests that spend questions where the evaluator still cannot tell models apart, domain rubrics that observe the correct state, executable verifiers that test the artifact itself, rare-case estimators that look where average sampling rarely goes, and constrained policies that measure how close the behavior is to a forbidden line.

THEME 03

Data And Systems

Data matters by the movement it causes.

A dataset is not fuel poured into a model. Each example pushes the model, and that push has direction, timing, conflict with other examples, and hardware cost. The hidden object is the model state after training, but the designer only controls which evidence is shown, in what order, at what precision, and through which serving system. The practical question is whether a possible update changes behavior gently, changes nothing useful, or moves through a fragile part of the model where a small push causes a large unwanted effect.

The mathematical reason timing, compression, caches, and provenance matter is that learning and inference are paths, not single events. The same example can help when the model is plastic and do little later. The same low-bit approximation can preserve ordinary outputs but distort rare reasoning paths. The same cache can look small while preserving exactly the state needed for the next token. These papers work when they control the movement of information rather than merely counting examples, parameters, or bytes.

THEME 04

Physical And Generative Models

A generated object has to live in the right state space.

The hidden object in physical and generative work is not a pixel grid, token string, or coordinate dump. It is a world state, molecule, field, trajectory, protein hierarchy, or embodied transition with constraints that existed before the model. The universe gives these methods leverage when they stop asking a generic network to rediscover those constraints from scratch and instead choose coordinates where the constraints are natural.

The mathematical move is usually keeping the real object the same while the description changes. Viewpoint should not change object identity. Time should change a scene by carrying forward the same world, not by drawing unrelated frames. A molecule should satisfy shape and synthesis constraints, not only look molecule-like. A cheap physical model should preserve the rule that governs the real system and the leftover error after the rule is applied. Sampling works when probability mass moves through valid regions of the native space instead of crossing invalid shortcuts hidden by the representation.

THEME 05

Theory And Optimization

Theory is useful when it names the smaller object controlling the behavior.

The point of theory in this atlas is not decoration around empirical work. It says which smaller part of a large system actually determines the outcome: a model-movement direction, a visible signal gap, a rank, an allowed set, a finite test, a game response, or an algorithm that an architecture can simulate.

These papers work mathematically because large systems are not equally sensitive in all directions. Some directions carry signal, some are noise, some are forbidden by constraints, and some are invisible to the available evidence. A theorem helps when it exposes that shape of movement and says what must be true before an engineering recipe transfers to a new model, dataset, machine, or adversary.

THEME 06

Causality And Scientific Discovery

A scientific claim is strong only where the evidence can reject alternatives.

The hidden object in causality and scientific discovery is the rule behind the pattern: what would change if we deliberately changed one thing, which variables carry the effect, which graph still fits the observations, or which hypothesis survives an executable check. Ordinary prediction does not answer that because many different rules can produce the same observed pattern.

The mathematical move is to shrink the list of possible stories without pretending the list is smaller than the evidence allows. Sometimes that means finding the few background facts needed to compare like with like. Sometimes it means reporting the whole set of causal stories the observations still cannot separate. Sometimes it means turning a generated hypothesis into a test that can fail. The real gain is not more confident prose; it is fewer surviving explanations after the right observation or intervention.

THEME 07

Multimodal And Embodied Models

Multiple channels help only when the model uses the right channel for the right part of the claim.

The hidden object in multimodal work is the shared situation behind several kinds of evidence: what in the world, body, video, brain signal, sound, or image caused the answer? Text can often guess the answer without looking, and large context can carry many tokens that do not matter. The mathematical question is which evidence channel deserves credit for which part of the answer under a budget.

The reason these methods work is that they protect the route from observation to decision. Visual swaps ask whether the answer changes when the visual evidence changes. Token bottlenecks ask which pieces are enough for the future decision. Shared interfaces ask what common state can be shared without erasing each modality's native structure. Embodied methods ask whether an action stays feasible under contact, kinematics, and hierarchy. A multimodal model is grounded only where changing the relevant evidence channel changes the output in the way the claim requires.

A common interface can help coordination but can also erase the timing, layout, sound shape, or 3D structure that makes the artifact valid.The object is a shared workbench plus native tools for each medium. The shared state carries intent, while the native decoders preserve acoustic, visual, temporal, or 3D constraints. Latent means hidden: a latent interface is the hidden shared state used before the artifact is decoded into its native form.Use shared generation protocols, iterative editing states, native speech and video representations, renderable 3D fields, and artifact-level reward checks.LatentLM, UALM, NextStep-1, EditVerse, VibeVoice, TTSDS2, VIST3A.Connects shared interfaces to generation paths: generation succeeds when shared control moves through valid medium-specific states.
Human signalsBrain, affect, sleep, speech, and clinical signals are not ordinary labels. They are noisy measurements of body or expert-defined states that cannot be seen directly.The object is a body-signal or expert measurement channel. It must keep the sensor reading, timing, person-to-person variation, expert event language, and remaining doubt connected instead of treating the signal as a clean label.Turn fMRI or biosignals into tokens, decode structured speech and affect, use expert event labels, report doubt, and test whether the representation transfers across people or conditions.PRISM, Mind-Omni, SleepLM, BioX-Bridge, EmotionThinker, Seizure-Semiology-Suite.Connects multimodal learning to measurement instruments: the model observes a trace of the state, not the state itself.
Embodied actionRobots need actions that satisfy what objects allow, body movement limits, contact, hierarchy, and feedback. A language plan can be valid as text and invalid as movement.The object is an allowed movement over body-and-world state. The action must move the body-world system from one valid state to another while respecting contact, joint limits, balance, and feedback.Build affordance graphs, add tactile feedback, learn hierarchical policies, constrain policy updates, and verify actions in embodied benchmarks rather than text rubrics.SAW-Bench, MomaGraph, RoboMME, EgoTactile, HDFlow, PACT, JoSE, RodriNet.Connects robotics to physical allowed sets and agent state control: action is reasoning only when it changes the world along a valid path.

What The Map Adds

The subthemes show that the atlas is not a list of isolated papers. Each subtheme is a change problem with something that must stay the same: a trace must keep task information, a benchmark must keep measurement validity, a dataset must keep useful training movement, a generator must keep native-state validity, a theorem must keep assumptions true under deployment, a causal method must keep the boundary of what the evidence proves, and a multimodal system must keep evidence credit.

That is the practical first-principles reading of the conferences: before asking which method wins, ask which object the paper protects while the system changes.
