Why Exemplars Matter

The shorter atlas cards are useful for coverage. They are not always enough to show why a method works mathematically. These exemplars make the reasoning explicit: what is being estimated, constrained, routed, preserved, or certified, and why that object changes the problem rather than merely changing the implementation.

The shared picture is that modern AI papers are about preserving a claim through a transformation. The transformation may be training, reasoning, compression, sampling, evaluation, intervention, or deployment. The mathematics is the rule that says which transformations are allowed and which evidence proves the preserved claim survived.

A useful paper-level read should not stop at naming the object. It should say what the world is allowed to change without changing the claim, what cannot change without breaking the claim, and which observation proves the difference. That is the deeper pattern below: the method works when it protects the variable that carries truth while ignoring variation caused by format, coordinate choice, sampling accident, timing accident, or measurement noise.

EXEMPLAR 01

RAGEN-2

Reasoning Collapse As Lost Dependence

First-Principles Read

A reasoning trace is useful only if it is a bridge from the particular problem to the particular action. RL can reward the appearance of that bridge: longer text, familiar decomposition, confident intermediate claims. RAGEN-2 asks whether the bridge still carries load. If two different tasks produce the same reasoning skeleton in the places where the tasks differ, the model has not learned a stronger reasoning process; it has learned a ritual that survives the reward function.

Problem

Agentic RL can increase the amount of reasoning text while the reasoning stops depending on the particular input. The visible trace is longer, but the information carried by the trace is lower. This matters because an answer can improve on the training verifier while the process becomes less conditional on the evidence that would support transfer.

State Space

The state is an interaction trajectory: prompt, internal reasoning trace, actions, observations, verifier feedback, and final answer. The important object is the whole path, because the final answer alone cannot show whether the intermediate state used the right evidence.

Object

The mathematical object is conditional dependence between the trace and the task instance. A healthy trace changes when the problem changes in a way that should matter; a collapsed trace is a template whose local words may vary but whose decision-relevant structure ignores the input.

Preserved Quantity

The preserved quantity is task-specific information. Training may change style, length, and policy logits, but it should not erase information from the input that is needed to solve the task. The trace can compress the prompt, but it cannot compress away the facts that decide the next action.

Allowed Movement

RL may move the policy toward higher reward, but only in ways that keep the trajectory conditioned on the environment and not just on the reward model's preferred surface pattern.

Why It Works

The method works mathematically because it tests the invariant that real reasoning should have: changes in problem evidence should cause corresponding changes in the reasoning path. The universe lets this work because information cannot influence a later action unless it is present somewhere in the state that produced that action. If the trace no longer changes with the input, then it cannot be the carrier of the input-specific decision, no matter how sophisticated it sounds.

healthy trace: I(T; X | task) remains high while reward increases; collapse: I(T; X | task) drops

Evidence Check

Perturb the input, hold task format fixed, and measure whether trace structure, action choice, and intermediate claims move with the perturbation. Compare entropy with input-dependence because entropy alone can look healthy while templates persist.

Failure Boundary

The diagnostic can miss collapse if the perturbations do not touch the features the policy actually uses, or if the model preserves shallow input markers while losing the causal reasoning path.

Connection

h1 tries to preserve learning signal across longer horizons; The Tell-Tale Norm turns internal state magnitude into a compute-control signal; ParetoPO asks whether tool use is worth its cost. All are versions of one question: when should a system spend reasoning, and how do we know that spending is still tied to the task?

EXEMPLAR 02

ATLAS

Evaluation As Adaptive Measurement

First-Principles Read

ATLAS starts from a simple fact: capability is not directly visible. The evaluator sees answers to tasks, and those answers are noisy shadows of the capability claim. A good benchmark is therefore closer to a measuring instrument than a school exam. It should spend questions where the answer will most reduce uncertainty about the hidden ability, the way a doctor orders tests that distinguish the remaining diagnoses instead of repeating tests whose result is already obvious.

Problem

A fixed benchmark wastes many items because easy questions do not distinguish strong models and irrelevant questions do not reduce uncertainty about the ability being claimed. It can also overstate rank differences when two models differ by less than the noise of the instrument.

State Space

The state is a belief over model ability, plus an item bank whose questions have difficulty, discrimination, and noise. The evaluator's state changes after each answer because some possible ability levels become less compatible with the evidence.

Object

The mathematical object is a measurement instrument: an item-response model that maps hidden ability to observed answers. The point is not that the model has a single true scalar ability forever; it is that the evaluator must say which capability dimension each item can actually observe.

Preserved Quantity

The preserved quantity is rank or ability information. Evaluation should compress many possible questions into a smaller test without changing the capability claim.

Allowed Movement

The test may adaptively choose the next item based on current posterior uncertainty. It may not choose items that maximize convenience while losing information about the target ability.

Why It Works

Adaptive testing works because not every question can change what we know. A question far below the model's level gives the same answer for many possible abilities. A question far above the level also gives little separation. The useful item is near the boundary where plausible abilities would produce different outcomes. That is the first-principles meaning of information here: an observation is valuable when different hidden states would predict different observations.

choose item i maximizing I_i(theta) = E[(d/dtheta log p(y_i | theta))^2] near the ability region still plausible

Evidence Check

Report posterior intervals, item-information gain, agreement with full-test rankings, sensitivity to starting estimates, and cases where adaptive paths choose different items for different model regimes.

Failure Boundary

The method fails when the item-response model is misspecified, when item banks omit important capability dimensions, or when models exploit item-selection patterns.

Connection

FRABench and UFEval factor scores and uncertainty; Micro-Benchmarking Reliability asks when ranks are statistically stable; CounselBench and WebDevJudge change the observation channel. All say that evaluation is measurement design before it is ranking.

EXEMPLAR 03

Rare Event Analysis And Tail Risks

Safety As Tail Probability

First-Principles Read

Safety is mathematically different from ordinary accuracy because harm is not evenly spread across samples. If one output in ten thousand creates severe damage, an average score can look excellent while the system is unacceptable. Rare-event work asks where the dangerous probability mass is hiding and how to estimate it without pretending that not seeing it in ordinary samples means it is absent.

Problem

Average benchmark behavior can look safe while rare failures dominate deployment harm. Random sampling often misses the events users most need measured, especially when the harmful set is narrow, adversarially selected, or defined by a sequence of steps rather than one answer.

State Space

The state is an output, action, or trajectory distribution with a harmful subset defined by policy, security, physical, or social consequences. The dangerous object is probability mass in that subset, not the average pleasantness of ordinary samples.

Object

The mathematical object is tail probability or tail loss: probability mass inside a harmful event set, sometimes with severity weighting.

Preserved Quantity

The preserved quantity is the deployment-distribution estimate. Sampling may be biased toward failures, but the final estimate must still refer back to the real distribution.

Allowed Movement

The evaluator may sample from a proposal distribution that visits rare regions more often, but must correct for the change of measure.

Why It Works

Importance sampling works because probability can be measured from a different sampling process if we keep track of how the sampling process changed. We deliberately visit the dangerous region more often, then correct the count so it still estimates the original deployment probability. The method is valid only because the correction preserves the reference distribution while the proposal distribution makes the rare region visible.

P(E_bad) = E_Q[1{Y in E_bad} * p(Y) / q(Y)], with Q chosen to cover E_bad

Evidence Check

State the event grammar, report confidence intervals, effective sample size, proposal sensitivity, boundary sensitivity, and examples near the event threshold.

Failure Boundary

The estimate fails if the harmful event set is wrong, if the proposal misses a failure mode, or if likelihood weights have extreme variance.

Connection

CSPO measures distance to violation; SandboxEscapeBench and Jailbreak Foundry apply adaptive pressure; FALCON and SRMC face the same sampling-support problem in molecular and generative settings.

EXEMPLAR 04

Midtraining Bridges

Training As Timed Distribution Movement

First-Principles Read

A model is not equally changeable throughout training. Early on, many representations are still soft; later, the model has already carved a geometry that makes some changes easy and others expensive. Midtraining Bridges treats data as a timed force on that geometry. The same data can be useful when it connects what the model knows to what it will later need, and weak when it arrives outside the window where the representation can still bend.

Problem

Specialized data can help at one training phase and do little or harm at another. Data value depends on where the model currently is, not only on the dataset's standalone quality. The real object is not a pile of examples but the update those examples cause at that moment.

State Space

The state is the model parameters and optimizer state moving through a sequence of training distributions: broad pretraining, specialized bridging data, and posttraining targets. Each phase changes which directions in parameter space are still easy to move.

Object

The mathematical object is a path through distributions. A data mixture is useful when it moves the model toward the target while preserving plasticity and avoiding interference.

Preserved Quantity

The preserved quantity is transferable capability. The model should gain specialized structure without losing the general representation needed for later alignment or task adaptation.

Allowed Movement

The training process may change data mixture weights over time, but the movement should remain inside a region where gradients still produce useful updates.

Why It Works

A bridge distribution works when its examples push the model in directions that the later target will need while the model is still able to absorb that structure. Mathematically, it is a path problem: local updates accumulate. A useful bridge reduces the distance between broad pretraining features and final task features without spending the model's remaining flexibility on a narrow shortcut.

use data D_b at time t when alignment(g_b,t, g_target,t) is high and interference with g_base,t is bounded

Evidence Check

Compare early, middle, and late insertion; measure target gains, general-capability loss, gradient alignment, representation drift, and whether the same data helps under different training states.

Failure Boundary

The bridge fails if it arrives after plasticity has narrowed, if it over-specializes the representation, or if the target distribution was misidentified.

Connection

DiReCT chooses late data by curvature; Sequential Data Values makes marginal data value order-dependent; BLL-Loss and OPUS select examples by optimizer effect. All treat data as movement, not fuel.

EXEMPLAR 05

Quotient-Space Diffusion

Generation Modulo Symmetry

First-Principles Read

The same molecule can be described by many coordinate arrays. If a method treats every rotated copy as a different object, it asks the model to spend learning capacity on a fact the world has already settled: orientation in an arbitrary coordinate frame is not molecular identity. Quotient-Space Diffusion works by building that sameness into the space before learning the distribution.

Problem

Molecular coordinates contain irrelevant degrees of freedom. Rotating or translating the molecule changes coordinates but not molecular identity. A raw-coordinate generator can therefore confuse coordinate description with chemical state.

State Space

The state is a molecular configuration, but the meaningful space is not raw Euclidean coordinates. It is configurations modulo rigid transformations and other symmetries, so many arrays map to the same physical object.

Object

The mathematical object is a quotient space: many coordinate arrays represent the same molecule, and the model should operate on the equivalence class.

Preserved Quantity

The preserved quantity is molecular identity and geometry that affects chemical behavior. Coordinate frame accidents should not alter likelihood, denoising direction, or generated structure.

Allowed Movement

The sampler may move through noisy molecular states, but movement must respect equivalence under symmetry and should not learn artifacts of arbitrary orientation.

Why It Works

Quotient modeling works because it separates two kinds of change: changes that only rename the same object, and changes that alter the object. Learning on equivalence classes forces the model to ignore the first kind and spend probability modeling on the second. The universe lets this work because rigid transformations preserve interatomic distances and chemical relationships; they change the observer's coordinates, not the molecule.

model distribution over configurations x modulo group G: p([x]) where [x] = {g x : g in G}

Evidence Check

Test rotation and translation invariance, molecular validity, energy or property preservation, sample diversity, and whether denoising trajectories remain consistent across equivalent coordinate frames.

Failure Boundary

The approach fails if the quotient removes information that actually matters, or if downstream tasks need orientation relative to a binding pocket, surface, or external field.

Connection

Protein hierarchy papers preserve residue and fold constraints; TideGS and RadioGS preserve physical fields; HDFlow and PACT preserve action feasibility. All start by choosing the native space where validity is defined.

EXEMPLAR 06

Alignment-Sensitive Minimax Rates

Generalization Through Spectral Placement

First-Principles Read

Generalization is not controlled by size alone. A representation can be huge and still hide the target in directions that finite data cannot estimate. Spectral theory says that data sees some directions clearly and others weakly. Alignment-sensitive rates ask whether the task signal lies in the visible part of the representation or in the buried part where noise dominates.

Problem

Two representations can have similar size or kernel complexity but different generalization because the target signal sits in different directions. Counting dimensions misses the fact that some directions are learnable with finite samples and others are effectively invisible.

State Space

The state is a learned feature or kernel space decomposed into spectral directions with different eigenvalues and noise levels. Large-eigenvalue directions are directions the data distribution exposes more strongly; small directions are harder to estimate reliably.

Object

The mathematical object is target alignment with the leading recoverable spectral span. The question is how much of the true task lives in directions that finite samples can distinguish from noise.

Preserved Quantity

The preserved quantity is target signal above noise. Generalization depends on whether the learned representation keeps the task-relevant part in directions that finite data can estimate.

Allowed Movement

Learning may reshape the representation, but useful movement increases target mass in high-signal directions instead of spreading it through noisy components.

Why It Works

The argument works because finite evidence has resolution limits. Repeated data reveals directions that appear often and strongly; it cannot reliably estimate every faint direction in a large space. If the target mostly lives in the visible span, learning has enough evidence to recover it. If the target lives outside that span, more nominal expressivity does not solve the evidence problem.

risk controlled by effective span: sum target_mass_j over directions where lambda_j exceeds noise threshold

Evidence Check

Measure spectral concentration of target signal, sample-size scaling, perturbation sensitivity, and pairs of representations with similar complexity but different alignment.

Failure Boundary

The theory can mislead if the learned spectrum changes during training, if the noise model is wrong, or if downstream tasks rely on nonlinear structure not captured by the spectral basis.

Connection

Single-Head Attention studies spectral recovery in attention; BBP transitions ask when spikes separate from noise; LoRA theory asks whether task movement lives in a low-rank subspace. All are signal-visibility arguments.

EXEMPLAR 07

Distributional Equivalence

Causal Discovery As An Identified Set

First-Principles Read

Many different hidden stories can create the same data. If rain and traffic both change commute time, a table of observations may not tell us which one caused which unless the right variation is present. Distributional Equivalence is valuable because it refuses to pretend that one story has been proven when several stories still fit the evidence. The mathematical win is honesty about what has actually been ruled out.

Problem

Observed data can be compatible with multiple causal graphs, especially with latent variables or cycles. Returning one graph can overstate what the evidence identifies.

State Space

The state is a family of causal graphs and latent structures that imply observable distributions.

Object

The mathematical object is an equivalence class: all causal structures that cannot be distinguished by the observed distribution and stated assumptions.

Preserved Quantity

The preserved quantity is epistemic honesty. The output should preserve the boundary between identified structure and plausible but unverified structure.

Allowed Movement

The algorithm may narrow the graph class using constraints such as edge ranks, independences, and distributional signatures, but cannot choose among indistinguishable alternatives without additional assumptions.

Why It Works

It works because a causal claim is only as strong as the alternatives it defeats. If every still-possible graph says the same thing about a cause, then the claim does not depend on guessing the exact hidden graph. If two still-possible graphs disagree, the method must say "not identified." That refusal is not weakness; it is the exact boundary of what the evidence can support.

claim c is identified if c(G) is the same for every G with P_obs(G) = P_obs and satisfying assumptions A

Evidence Check

Report equivalence-class size, rank-constraint calibration, latent-variable stress tests, false edge and missing edge rates, and examples where the method correctly refuses to identify a unique graph.

Failure Boundary

The output is only as good as the assumptions defining the graph family and the statistical tests used to estimate distributional constraints.

Connection

Local Covariate Selection identifies adjustment for a target effect rather than a whole graph; DiCoLa scales CI evidence; CausalGame gathers interventions to separate mechanisms. All protect the same boundary: what the evidence distinguishes from what a model can narrate.

EXEMPLAR 08

Steer Like The LLM

Prompting As Activation Displacement

First-Principles Read

A prompt works by changing the model's internal state before it answers. The words are not magic; they are a handle that pushes hidden activations into a different region. Steer Like The LLM asks whether we can learn the actual push rather than keep repeating the words. If the same internal movement causes the same behavior across many inputs, then control can happen inside the model state instead of through fragile prompt phrasing.

Problem

Prompt words are an indirect control interface. They may steer behavior, but they also consume context, interact with unrelated instructions, and make the control signal hard to isolate.

State Space

The state is the model's hidden activation trajectory across layers and tokens, plus the output distribution induced by that trajectory.

Object

The mathematical object is an activation displacement: the vector difference between the unprompted hidden state and the hidden state produced by an instruction.

Preserved Quantity

The preserved quantity is the intended behavioral change caused by the prompt, separated from the incidental surface words that produced it.

Allowed Movement

The method may move hidden states along learned steering directions, but should not disturb unrelated latent features or collapse output diversity outside the target behavior.

Why It Works

It works when the prompt has a repeatable physical effect inside the network. If adding an instruction usually moves the hidden state in a similar direction, then a small learned controller can reproduce that movement. The key is separation: keep the intended behavior change, drop the accidental wording, and avoid moving unrelated features that the original prompt happened to touch.

learn delta h ~= h(prompted, x) - h(base, x); apply h' = h + delta h_target

First-Principles Read

A verifier is a teacher only if its mistakes do not point the learner in the wrong direction. Random noise can sometimes average out. Biased noise does not average out; training follows it. RLVepsR matters because it treats verifier feedback as a force on the policy, not just a label. The real question is whether that force pushes toward true success or toward whatever the verifier is fooled by.

Problem

RL from verifier feedback can improve a model only if verifier labels are correlated with the true target. Weak verifiers can produce learning, no learning, or anti-learning depending on their error structure.

State Space

The state is a policy distribution over outputs and a verifier observation channel that maps output artifacts to noisy labels or rewards.

Object

The mathematical object is gradient alignment between the verifier-induced update and the update that would be induced by true task success.

Preserved Quantity

The preserved quantity is target-directed learning signal. The verifier may be cheap or weak, but its reward must point the policy in roughly the same direction as real correctness.

Allowed Movement

The policy may move toward higher verifier reward, but only while verifier reward remains a useful proxy for the target. When false positives dominate, movement should stop or defer.

Why It Works

It works when verifier errors are mostly harmless noise around the right signal. In that case, many updates still point in roughly the right direction. It fails sharply when the verifier has a consistent blind spot, because optimization searches for exactly those blind spots. The model does not know the verifier is a proxy; it only sees that certain outputs get rewarded.

useful RL needs E[grad log pi(y|x) V(x,y)] aligned with E[grad log pi(y|x) T(x,y)]

Sweep verifier false-positive and false-negative rates, measure learn/stall/anti-learn regimes, audit disagreement cases, and compare weak-verifier updates to stronger oracle or human judgments.

Failure Boundary

The method fails when verifier errors are systematic in the same direction the policy can exploit, or when the verifier observes the wrong artifact.

Connection

This is the training version of benchmark validity. It connects JudgeBench, WebDevJudge, CyberGym, formal proof checking, and verifier-gaming chains: the optimization target inherits the measurement channel's errors.

First-Principles Read

DiReCT chooses data by asking where each example would push the model, not by judging the example in isolation.

Problem

Late-training examples can improve validation behavior or damage brittle directions. Data quality alone is not enough; the current curvature of the model decides whether an update is safe.

State Space

The state is parameter space near a trained model, equipped with gradients from candidate examples and validation curvature directions.

Object

The mathematical object is a proposed displacement decomposed into flat and stiff validation-Hessian eigenspaces.

Preserved Quantity

The preserved quantity is validation performance in high-curvature directions. The model can move, but not through directions where small changes cause large loss increases.

Allowed Movement

Select examples whose gradients align with flat useful directions and have bounded energy in stiff harmful directions.

Why It Works

It works because the same-sized update can have very different consequences depending on direction. A move along a flexible direction can add capability. A move across a sensitive direction can undo a lot. Curvature is the map of that sensitivity. Data selection becomes safer when it chooses examples whose push is useful and avoids examples whose push cuts across fragile behavior.

prefer g_x with high ||P_flat g_x|| and low sum_{lambda_j large} lambda_j <g_x, v_j>^2

Measure Hessian-direction energy, validation movement, selected-versus-random data, timing sensitivity, and ablations that use gradient magnitude without curvature.

Failure Boundary

The method fails if the Hessian estimate is noisy, if validation curvature misses deployment failures, or if flat directions encode shortcuts.

Connection

Midtraining Bridges studies when data should arrive; Sequential Data Values studies order-dependent value; LoRA theory studies constrained parameter movement. DiReCT gives the local geometry version of the same idea.

Problem

Imagine hiring an assistant who can answer from memory, open a calculator, search records, or ask another expert. More checking can improve the answer, but each check takes time, costs money, and can introduce a new mistake. A plain accuracy score hides whether the assistant solved the task wisely or just spent heavily.

State Space

The state is everything the agent has already done: its private thinking, each tool call, what the tools returned, the final answer, and the running bill in time, money, and risk.

Object

The object is the list of non-wasteful choices. One agent may be cheap and usually right; another may be slower and slightly more accurate. A choice is wasteful if another choice is at least as correct and costs less.

Preserved Quantity

What must stay the same is useful task performance after the cost is counted. What may change is how often the agent uses tools and how much extra accuracy it buys with them.

Allowed Movement

The agent may spend more calls to get harder answers right, or spend fewer calls when memory is enough. The important rule is that the tradeoff is shown before anyone hides it inside one combined score.

Why It Works

This works because there is often no single best agent for everyone. A hospital, a classroom, and a phone app may choose different points because they pay different prices for delay, money, and mistakes. The formal name is a Pareto frontier: the set of choices where you cannot improve one side without giving up something on another side.

pi is efficient if no pi' is at least as accurate and no more costly, with one side strictly better

Show the cost-versus-correctness curve, per-task tool budgets, the value of one more call, and examples where fewer tool calls give the same right answer. Include the cost of checking the tools, not only the tool price.

The curve misleads if it leaves out human review time, security exposure, bad tool results, or the damage caused when the agent confidently uses the wrong tool.

Connection

VALUEFLOW and SafeDPO ask how usefulness trades against safety. LiftQuant and TetraJet ask how accuracy trades against speed and machine limits. ParetoPO applies the same plain idea to agents: better means better for a visible price.

Why It Works

This works when the translation layer acts like a narrow, disciplined bridge. It is narrow enough that the model cannot ignore the signal and solve the task from context alone. It is disciplined enough that changing the real signal changes the internal code in the expected way. The formal term bottleneck means this narrow bridge: only the information that passes through it can affect the later model.

learn code z from signal so output changes when the real signal changes, not when only scanner noise changes

Connection

State Space

The state is the current knobs of the model, the direction suggested by the error signal, the optimizer's memory of past directions, which directions are sensitive, the next update, and how the model's useful internal features change. The object is the optimizer's movement rule. It decides which directions are cheap to move in, which are expensive, which get amplified, and which get suppressed. Papers may call this an optimizer-induced metric; in plain terms, it is the optimizer's ruler for measuring movement.

This works when the optimizer makes a badly shaped training landscape easier to walk through. Preserved Quantity

What must stay the same is the input-to-output procedure. The exact weights can differ, but the model must still move information through the same kind of steps: read, combine, update, compare, and answer.

The state is the public claim, the larger task world the claim is about, the finite questions actually sampled, the model answers, the grading rule, the score calculation, and the remaining uncertainty. Preserved Quantity

Allowed Movement

This works by replacing a naked score with a score plus a doubt range. More items, cleaner graders, and more stable prompts shrink that range. Problem

A recipe can have few steps and still be slow if every step makes you walk across the kitchen for one spoon. Neural-network code has the same problem. Counting arithmetic operations misses the cost of moving numbers through memory, arranging them for the chip, and launching the small machine programs that do the work.

State Space

The state is the computation the model wants to do, the shapes of the number tables, how those tables are laid out in memory, which chunks are loaded together, which small hardware routine runs, what numeric precision is used, and which chip executes it. A tensor is just a table of numbers, and a kernel is a small low-level routine that runs one repeated piece of the computation.

Object

The object is the same calculation placed onto a real machine. The formal phrase computation graph means the dependency map of which number must be computed before which other number. The systems problem is to place that map into memory and hardware without changing the answer.

Preserved Quantity

What must stay the same is the intended function: for the same inputs, the model should produce the same output up to acceptable rounding. What may change is the order, grouping, layout, or low-level expression of the calculation.

Allowed Movement

The implementation may split tables into tiles, combine kernels, reorder independent work, specialize for common shapes, or write the same equation in another form. It cannot break dependencies, silently change rounding too much, or assume shapes that users will not actually run.

Why It Works

This works because modern chips are often limited by moving data, not by doing arithmetic. Tiling means keeping a small chunk of numbers close to the processor long enough to reuse it. Fusion means doing several operations while the numbers are already nearby. The formal systems idea is memory hierarchy: small fast memory is close to the chip, large slow memory is farther away.

keep the same tensor function while reducing expensive memory movement and unused hardware time

Evidence Check

Report low-level traces, memory bandwidth, hardware occupancy, shape sweeps, backend comparisons, numerical drift, full-model latency, and whether the speedup holds for the model sizes users actually serve.

Failure Boundary

The claim fails when it is fast only for cherry-picked shapes, when compilation overhead eats the win, when small numeric changes alter model behavior, or when one faster routine does not speed up the full pipeline.

Connection

LiftQuant and TetraJet change the numbers the machine stores. ThinKV changes what memory the model keeps. Finite-precision theory asks what computation survives machine limits. TileLang, DHSA, and einx make the machine part of the claim, not an afterthought.

Problem

A tiny change can grow into repetition, topic collapse, or brittle answers after many steps.

The state is the full model, the smaller model, the weights or channels removed, the next-token choices over time, the generated context that feeds back into the model, and behavior measures such as repetition and drift.

Object

The object is a process that changes as it runs. Papers may call this a dynamical system: the next state depends on the current state. In language generation, the next word changes the future context, so the model is not just answering once; it is steering a sequence.

Preserved Quantity

What must stay the same is behavior across a whole generated path, not only the first next-word score. What may change is the number of model parts, as long as repeated generation still stays stable.

The method may remove parameters, repair internal activations, or adjust the smaller model. It must keep the next-step rule from creating traps such as repetition loops. The formal phrase transition kernel means the rule that turns the current context into probabilities for the next token.

Repair works when it finds which removed parts used to keep the sequence stable and restores that effect. The issue is not one small error at one input. The issue is whether that error keeps feeding itself until the model falls into a bad loop.

FOCUS and RePAIR make the same point for compressed language models: preserve the running process, not just the static score.

Problem

State Space

Distribution Transformer And Gaussian Mixture Distances

Updating Beliefs Without Flattening Them

Problem

Imagine sorting reports about an unknown machine fault. Before opening the reports, you may have several live stories: maybe the battery is weak, maybe a sensor is loose, maybe two small problems are interacting. New evidence should make some stories stronger and others weaker. It should not force all uncertainty into one neat answer just because a formula or model wants a single center.

State Space

The state is the set of possible stories before the evidence, how much trust each story gets, the new observations, the possibility that some observations are dirty or misleading, the revised set of stories after seeing the evidence, and the decision that will be made from that revised belief.

Object

The object is a belief-updating machine: it takes a whole cloud of possibilities before the evidence and returns a whole cloud of possibilities after the evidence. The formal version is a map from one probability distribution to another. Distribution Transformer learns this update for mixtures of bell-shaped possibilities (Gaussian mixtures). Gaussian Mixture Distances gives a way to say how far two such belief clouds are from each other.

Preserved Quantity

What must stay the same is the meaning of the separate possibilities. If three explanations were genuinely different before the evidence, the update has to keep track of which explanation gained support, which lost support, and which remains uncertain. The method is not allowed to hide several live explanations inside one overconfident average.

Allowed Movement

What may change is the weight, location, spread, and interaction of the possible explanations. A story can become more likely, less likely, broader, narrower, or connected to another story. It should disappear only when the evidence really rules it out.

Why It Works

It works because the model treats possible explanations as things to be moved and compared, not as a pile of numbers to be crushed into one answer. Attention can look across the separate possibilities and decide how new evidence shifts each one. The distance measure then acts like a ruler for belief clouds: it shows whether the updated belief is still close to the right shape or whether the method silently lost an important possibility. The formal term for the revised belief after evidence is the posterior.

belief before evidence -> observe data -> belief after evidence, while keeping separate possibilities and measuring how much the belief cloud moved

Evidence Check

Check whether the final belief gives honest confidence, recovers the right separate explanations, assigns sensible weights, stays robust when some samples are contaminated, makes good downstream decisions, and keeps two possible answers separate when the evidence does not justify choosing one.

Failure Boundary

The method fails when the allowed family of belief shapes is too limited, when the labels for the separate possibilities stop meaning anything, or when the learned updater has only practiced on clean simulated evidence and then meets messier real evidence.

Connection

CreDRO and CRC keep uncertainty as sets of defensible actions. Mind-Omni builds a translation layer for hidden biological signals. Alignment-Sensitive Rates ask what signal can be found with finite evidence. Distribution Transformer and Gaussian Mixture Distances give the belief version: learning is not only choosing an answer, but moving uncertainty in a way that keeps its shape meaningful.

Problem

Suppose you want a fair picture of a city by visiting neighborhoods. If you only visit the easy streets, your picture is biased. State Space

The state is the thing we want to sample from, the rule for suggesting the next move, any extra helper variables, the path already taken, the rule for accepting or rejecting a move, the cutoff for which choices are allowed, the amount of exploration, and the variety of samples produced.

Object

The object is a path-aware drawing rule. It explores more of the space while still accounting for how each example was produced. The formal family includes Markov chain Monte Carlo with helper variables (Auxiliary MCMC), generation rules that remember the construction path (Path-Dependent DAI), and adaptive cutoff sampling that changes how many low-probability choices remain available (p-less).

Preserved Quantity

What must stay the same is the intended mix of outcomes. Exploration is helpful only if the final pile of samples still represents the target source, or if the method clearly says it is sampling from a changed source.

Allowed Movement

What may change is the route. The sampler can add helper variables, remember earlier steps, raise or lower cutoffs, or take bigger exploratory moves. But every such move has to be paid for in the accounting: the method must know how that route changes the chance of ending at the sample.

Why It Works

It works because the path contains information. A shortcut is not wrong by itself; it is wrong when the sampler forgets that it took one. Helper variables can make hard moves easier. Remembering the path prevents the method from pretending the current state tells the whole story. Changing the cutoff lets the model keep more choices when the situation is uncertain and fewer when the next choice is clear. The plain rule is: explore freely, but keep the receipt for how each sample was made.

valid sampling = proposed example + route information + correction rule, so the final sample pile still matches the intended source

Check whether samples match the intended source, how often proposed moves are accepted, how many genuinely different examples are produced, whether quality and diversity trade off cleanly, what happens when path memory is removed, and whether rare but valid outcomes remain reachable.

Failure Boundary

The method fails when helper variables add noise without reaching new regions, when the needed history is too large to track reliably, or when an adaptive cutoff removes rare words or actions that matter for reasoning, creativity, or safety.

Connection

MAPF moves many agents along paths without collisions. Auxiliary MCMC, Path-Dependent DAI, and p-less make the shared point: the route is part of the evidence, not decoration.

Problem

Suppose one city changes bus schedules and another changes school hours, but you do not have perfect person-by-person records. You still want to know which change affected commute time. The danger is that the cities may differ in many other ways. Causal work starts by asking which differences are useful clues and which differences are distractions.

State Space

The state is the environment where data came from, samples that may not be paired person-by-person, the exposure or treatment, the outcome, the process that selected which cases appear, hidden causes that were not measured, assumptions about which changes are allowed to act as clues, and the causal effect being estimated.

Object

The object is useful natural variation. Some external change can nudge the cause we care about while leaving other routes alone; some repeated selection process can reveal what traits keep surviving. Preserved Quantity

What must stay the same is the meaning of the causal question: what would change if we changed the treatment itself? The environment label or selection process is useful only if it helps isolate that question, not if it merely describes where the data came from.

Allowed Movement

What may change is the environment, the mix of samples, or the selection pressure over time. But the method must say exactly what is assumed: the outside change must affect the outcome through the intended path, it must actually move the treatment, and the underlying relation must stay stable enough to compare.

Why It Works

It works by finding a difference that behaves like a lever. If repeated selection keeps favoring certain traits, then the pattern of survival contains evidence about what mattered. causal answer is credible when the useful outside change moves the cause, leaves other paths alone, and forces compatible stories to agree

Failure Boundary

The method fails when environments directly affect outcomes, when selection changes the mechanism over time, when unpaired samples come from mismatched populations, or when an unmeasured cause can explain the same pattern.

Connection

Problem
