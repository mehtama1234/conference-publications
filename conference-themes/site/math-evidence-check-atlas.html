Evidence checks

What would prove the math is real?

This page maps claims to the evidence that would actually test them. A paper can use the right formal word and still be weak if the evidence watches the wrong thing. These checks ask what must stay true, what is allowed to change, and what observation would prove the method is doing the promised work.

FIRST PRINCIPLE

Evidence Must Observe The Protected Object

If a method claims to keep the right memory, the evidence cannot only report final accuracy. If it claims to measure capability, the evidence cannot only show a higher score on the same easy-to-game number. If it claims a channel caused the answer, the evidence has to change that channel and watch the answer move.

Read each row as a concrete test. What thing is being checked? What should happen when we change the input, remove evidence, stress a boundary, run the artifact, or repeat the sample? What weak shortcut would look impressive while leaving the real claim untested?

APPLICATION

How To Use Evidence Checks In Paper Cards

Write the claim first

State what must stay true while the method changes something. Then choose a check that can observe that promise directly.

Reject weak substitutes

If a paper reports only an average score, surface example, or qualitative output, mark which promised thing remains unobserved.

Connect by evidence type

Papers in different themes can be compared when they need the same kind of proof: input changes, boundary stress, route support, artifact checks, or unresolved-story reports.
