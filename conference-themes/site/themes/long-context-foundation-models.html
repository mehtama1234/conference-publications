Problem

The shared problem is that simple benchmark accuracy no longer explains what is happening. The papers in this group isolate a narrower failure mode, capability, or design constraint.

Approaches

The approaches vary by paper, but the common pattern is to define a sharper object of study, build a method around that object, and test whether it changes behavior under controlled conditions.

Connecting read

Read this page as a map of the local evidence rows, not as a claim that the theme is as central as the largest conference themes.

SUBTHEMES

What the papers are actually about

Abstract operators before knowledge

ICML 2026Procedural Pretraining
Separates reasoning-structure acquisition from semantic corpus learning and improves context recall dramatically.

Adaptive sequence compression

ICML 2026dnaHNet
Reports tokenizer-free latent chunking with quadratic FLOP reductions and over 3x inference speedup over Transformers.

Attention as robust state estimation

ICML 2026Robust Filter Attention
Treats tokens as noisy observations of a latent SDE trajectory and attention weights as precision-weighted consistency.

Content-position disentanglement

ICML 2026PoPE
Separates what and where in positional encodings to improve sequence modeling and zero-shot length extrapolation.

Context as implicit weight patch

ICML 2026Context-Parameter Equivalence
Maps context effects in modern Transformer blocks to rank-1 MLP patches and RMSNorm-scale patches.

Continual post-training capability retention

ICML 2026DiSC
Distills teacher/student distributions conditioned on different context segments without explicit generation during training.

Coupled continuous-time event dynamics

ICML 2026CoCLD
Aligns individual latent trajectories and population distribution shifts under sparse irregular observations.

Efficient multi-token explanation

ICML 2026FlashTrace
Uses span-wise aggregation for over 130x faster attribution on long-context retrieval and reasoning tasks.

Fisher information memory diffusion

ICML 2026Fisher Memory Dynamics
Models recurrent memory as time-resolved Fisher information propagation through interacting subpopulations.

Geometrically conditioned SSM updates

ICML 2026MuonSSM
Stabilizes SSM memory updates with momentum pathways and Newton-Schulz-conditioned low-rank injections.

Hybrid memory-role separation

ICML 2026Expressivity-Efficiency Tradeoffs for Hybrid Sequence Models
Full text proves pure SSMs and pure Transformers face different parameter or working-memory bottlenecks on synthetic sequence tasks.

Interrupt-retrieve-generate control

ICML 2026TG-RAG
Reduces cognitive drift by retrieving procedural directives at reasoning-time rather than relying on static context.

Logical evidence selection over similarity

ICML 2026SCOPE
Identifies semantic submergence when flat similarity filtering misses subtle logically necessary video cues.

Non-autoregressive language generation process design

ICML 2026Unifying Masked Diffusion Models
Treats generation order as part of the model objective rather than a fixed or post-hoc decoding policy.

Observation-dependent duration modeling

ICML 2026RED-HDP-HMM
Extends HDP-HMMs with recurrent explicit durations for more expressive temporal segmentation.

Rewindable head updates

ICML 2026Diffract
Removes up to 60% of head updates without quality loss and improves accuracy by rewinding low-importance heads.

SDE-consistent irregular time-series inference

ICML 2026SDEVI
Performs variational inference over discrete observations while preserving an underlying continuous SDE process.

Single-token numeric representations

ICML 2026BitTokens
Encodes numbers as IEEE 754 floating-point single tokens to reduce reasoning-token overhead for arithmetic.

Stage-wise Transformer training cycles

ICML 2026Focus and Dilution
Uses gradient-flow analysis and experiments on Markovian data, WikiText, and TinyStories to explain recurrent attention cycles.

Streaming tokenizer infrastructure

ICML 2026Incremental BPE
Emits tokens as soon as boundaries are fixed and reduces latency on streaming/pathological inputs.

Text-to-temporal primitive forecasting

ICML 2026TESS
Converts qualitative event text into distribution shift, volatility, shape, and lag primitives for forecasting.

Token-budget adaptive video generation

ICML 2026VideoFlexTok
Enables 10-second video generation with 672 tokens, far fewer than comparable 3D grid tokenizers.

Training-free positional extension

ICLR 2026MrRoPE
Recasts RoPE extension as mixed-radix conversion and reports 128K-context Needle-in-a-Haystack recall without fine-tuning.

Unified continuous-discrete latent interface

ICML 2026LatentLM
Integrates image, audio, video, text, and code generation/understanding through latent language modeling.

Wider token-frontier computation

ICML 2026Recurrent Diffusion Sampler
Preserves recurrent depth while updating a broader front of token positions under fixed wall-clock budget.
