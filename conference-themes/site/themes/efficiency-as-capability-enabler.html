Efficiency as capability enabler, mapped

The central problem is that a method that only works with unlimited compute is not a method for deployment.

Problem

Models are being asked to run longer contexts, video, robot policies, multimodal fusion, and reasoning loops. That turns memory bandwidth, precision, latency, and device limits into capability limits.

Approaches

The papers study low-precision failure modes, quantization, pruning, token merging, sparse experts, efficient optimizers, edge training, low-rank adaptation, and inference schedules that spend compute where it matters.

Connecting read

The big picture is simple: efficiency is not housekeeping. It decides which capabilities can leave the lab.
