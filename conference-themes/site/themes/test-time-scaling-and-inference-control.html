Test-time scaling and inference control

The core question is no longer only how to train a bigger model. It is how to spend compute after the prompt arrives: when to branch, when to verify, when to stop, when to steer, and when extra thinking has become waste or a new source of error.

Problem

Once a model can produce many candidate thoughts, plans, tokens, edits, or actions, inference becomes a resource-allocation problem. The model needs a controller that decides which partial work deserves more compute and which path should be abandoned before it consumes the budget.

Approaches

The papers here turn hidden signals, verifiers, confidence gaps, reward estimates, diffusion schedules, speculative drafts, latent deliberation, and agent workflows into control surfaces. The shared move is to replace fixed decoding with conditional execution.

Connecting read

This theme connects reasoning, generation, agents, robotics, scientific design, and serving systems. In every case, the same production issue appears: more inference compute helps only if the system knows what the compute is buying.

READ

The Big Picture

Training-time scaling made the field comfortable with a simple bargain: spend more during training, get a more capable model afterward. Test-time scaling changes the bargain. It asks whether a fixed model can become more useful by doing more work on a particular instance. That work may look like chain-of-thought sampling, search over plans, verifier-guided refinement, diffusion denoising, latent pondering, speculative decoding, ensemble routing, or repeated interaction with an environment. These are not cosmetic changes to decoding. They move part of intelligence from the model weights into the execution process around the model.

The hard part is control. If the system simply samples more, it can produce more wrong answers, longer loops, slower service, and higher cost. If it verifies everything, the verifier becomes the bottleneck. If it stops early, it may cut off the one trajectory that would have solved the task. If it lets a diffusion language model choose arbitrary token order, it may skip the uncertain pieces that actually matter. This is why the papers are best read as a family of controllers: they decide where compute goes, what signal justifies that decision, and how the system proves that the extra compute improves the final object rather than just producing a longer trace.

STRUCTURE

What Is Being Controlled

Reasoning Budget

Some work tries to decide how many reasoning attempts, latent thought steps, or chain-of-thought branches an instance deserves. The useful signal can be a norm, an attention state, a likelihood landscape, a verifier result, or a learned policy over branches.

Decode Order

Diffusion and non-autoregressive language models make token order a first-class decision. These papers ask which tokens should be refined first, when blocks can be committed, and how to avoid letting flexible order hide unresolved uncertainty.

Verifier Cost

Verification is powerful but expensive. The control problem becomes when to call a strong verifier, when a weak check is enough, and how to rank candidates without exhaustively scoring every path.

Workflow Shape

Agent and multi-agent systems expose higher-level knobs: prompts, roles, plans, skill libraries, semantic gradients, collaboration patterns, and rollout budgets. The controller chooses the workflow, not only the next token.

Latency And Hardware

Serving constraints turn inference control into systems design. Speculative decoding, sparse kernels, cache-compatible schedules, and token routing matter because the best reasoning method still has to run under real throughput and latency budgets.

Physical And Scientific Search

In robotics, molecular design, protein binding, and world models, test-time compute becomes search over possible futures or objects. The important question is how to spend compute on candidates that can be checked against a real objective.

CLUSTERS

The Main Research Moves

1. More thinking needs a stopping rule

The reasoning papers are not simply saying that longer chain-of-thought is better. They are asking when an instance benefits from more deliberation and when the deliberation is already redundant, circular, or drifting. The Tell-Tale Norm uses model-internal norm signals as a training-free way to allocate reasoning effort, treating internal activation geometry as a hint about whether the model has reached a stable answer. ASAG makes the stopping problem explicit by reading attention distributions to decide when further reasoning is no longer buying useful information. Reasoning Loops is the failure-side counterpart: it explains why repeated chains can become self-reinforcing loops through learned action errors and temporally correlated mistakes. Reasoning Dimensionality gives the conceptual bridge, arguing that good reasoning chains can reduce the effective dimensionality needed for a task, which explains why process can substitute for some parameter scale.

2. Search is useful only when selection improves

A large part of test-time scaling is candidate generation plus selection. MaxRL frames the objective itself around available sampling compute, interpolating between reward-seeking and likelihood as the number of samples grows. Reasoning with Sampling asks how much reasoning can be elicited from a base model through MCMC-style sampling without curated data, verifiers, or additional training. NAD attacks the cost problem directly: if correctness can be predicted early in a candidate, the system can prune most trajectories before spending the full token budget. BlitzRank converts ranking into tournament graphs so that k-wise comparisons can produce certifiable top-m choices without an exhaustive all-pairs procedure. Weak-Strong Verification adds the production view: strong checks are scarce, so the system must control acceptance and rejection risk under a limited verification budget.

3. Diffusion language models make order a control variable

Autoregressive decoding hides a major decision by forcing left-to-right order. Diffusion and non-autoregressive language models expose that decision, which creates both speed and risk. Learning Unmasking Policies replaces hand-tuned unmasking heuristics with learned policies for full-diffusion language generation. Prophet asks when a diffusion model can commit early, using confidence gaps to stop refinement on tokens that are unlikely to change. AdaBlock-dLLM controls semi-autoregressive block sizes from confidence dynamics and volatility rather than a fixed schedule. PAPL points out that if inference uses planned non-uniform reverse paths, training should match that planned process instead of optimizing a mismatched objective. JustGRPO is the warning: arbitrary-order diffusion language models can route around uncertain tokens and collapse reasoning coverage too early.

4. Inference control is also a serving system

Some papers treat the model as part of a runtime system whose bottlenecks are cache behavior, memory bandwidth, and batch scheduling. ECHO treats high-concurrency speculative decoding as a sparse-gated super-tree scheduling problem, which is a systems view of candidate acceptance. HSD improves speculative decoding by balancing probability mass across hierarchical drafts so accepted draft tokens increase without changing the final distribution. Global Resolution reduces multi-draft speculative sampling verification to a convex problem, making an otherwise explosive acceptance calculation tractable. WeDLM brings diffusion language decoding closer to production serving by making it prefix-cache compatible. MACKO-SpMV focuses on the hardware floor: if sparse LLM inference is memory-bandwidth bound, the control policy has to respect how kernels actually move data.

5. Steering should be sparse, local, and accountable

Another group of papers tries to intervene during inference without bluntly rewriting the whole generation process. Thinking in Flow uses gates for uncertainty, capacity, and direction so corrections happen only when the trajectory appears to need them. Hierarchical Thinking steers chain-of-thought at sparse sentence boundaries using Q-value activations, which makes the intervention more like course correction than constant control. DecodeShare shows that decode-time steering signals can be more causally relevant than prefill-derived proxies, a useful reminder that the right control signal may appear only after generation starts. Top-W uses Wasserstein geometry in token embeddings to shape truncation sets, while p-less removes a hand-set truncation hyperparameter by deriving thresholds from the current probability distribution. PoLar pushes steering inside the network execution path by skipping or repeating pretrained layers as an input-specific program.

6. Agents turn test-time scaling into workflow optimization

In agents, the object being controlled is larger than a sequence of tokens. Skill-Pro uses semantic gradients and PPO-gated verification to improve behavior without updating model parameters. MASPOB reduces multi-agent prompt and workflow search from a combinatorial problem to smaller linear subproblems, which matters because evaluation budgets are usually tiny. OMAC treats collaboration architecture as a control surface, using specialized actors to optimize individual and joint multi-agent design choices. PLAINTAIN interleaves planning and answering so a system can expose intermediate structure early, receive feedback, and reduce response latency. Skill Neologisms studies whether named skills learned independently can compose zero-shot, which is one path toward reusable test-time behavior libraries instead of one-off prompt hacks.

7. Embodied and scientific systems spend compute on futures

The same control logic appears outside text. WoW! shows that extra planning compute can improve closed-loop world-model performance, which makes inference budget a direct part of embodied competence. SCALE uses a vision-language-action model's own output distribution as a training-free control signal, avoiding external verifiers and multi-rollout test-time scaling. Role of Computation in RL studies how variable policy compute improves longer-horizon generalization, suggesting that larger static policies are not the only way to handle longer tasks. In scientific design, Complexa, Chamaileon, LiDAR Sampling, TD3B, GLASS Flows, and FlowOptimizer all spend inference compute on search over objects or trajectories where the objective can be evaluated more directly than ordinary text quality.
