# Distributional Equivalence Toy

Theme: Causality / Scientific
Subtheme: Same-evidence cause stories
Paper family: Distributional Equivalence style cause-story tests

What it proves: the same observations can fit more than one cause story, so the honest claim may be a set of possible stories.

User knob: background facts held fixed, observation noise, extra assumption.

Failure exposed: the method picks one story when several still fit.

Evidence: all still-possible stories must agree before making a cause claim.

Run: open `../../../../index.html`.
