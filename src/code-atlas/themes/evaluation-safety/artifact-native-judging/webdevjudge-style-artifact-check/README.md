# WebDevJudge Style Artifact Check

Theme: Evaluation / Safety
Subtheme: Artifact-native judging
Paper family: WebDevJudge / PaperBench / VERINA style artifact checks

What it proves: judging the explanation is not the same as testing the actual page, code, proof, or file the user receives.

User knob: artifact defect type.

Failure exposed: prose can sound correct while the real artifact is broken.

Evidence: the checker must run, render, or inspect the artifact directly.

Run: open `../../../../index.html`.
