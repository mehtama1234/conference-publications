# Movement Rulers

## The Big Idea

Training changes a model. A fine-tune, update, merge, or repair step moves the
system from one behavior to another. Raw movement size is not enough to judge
whether the move is safe.

One inch on flat ground is harmless. One inch near the edge of a shelf can knock
something over. The same raw movement can be safe in one direction and damaging
in another. The right ruler measures what the movement can break.

## What Must Stay True

The protected thing is useful existing behavior. The update should improve the
target behavior while keeping the behavior people still need. A movement rule is
good only if it notices fragile directions.

## The Failure

The hidden failure is raw-size blindness. The update looks small by a simple
number, but it crosses a fragile behavior direction. The target task improves,
but another important task gets worse.

This is why a training report that lists only target lift is incomplete. It must
also show what was protected and whether protection held.

## Why This Matters Outside The Demo

This matters in fine-tuning, personalization, continual learning, model merging,
reinforcement learning, and repair after regressions. Any system that learns
from new data can improve one behavior while damaging another.

In topology, a small geometric movement can leave the important structure
unchanged, or it can create or remove a hole if it crosses the wrong boundary.
The question is not just distance. The question is which structure changed.

## What Client Data Makes It Real

Use checkpoints, update summaries, target-task lift, protected regression
suites, fragile-case tests, and comparisons between movement rules. The proof is
that the chosen rule improves the target while preserving named kept behavior.
