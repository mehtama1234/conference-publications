How to Use This Atlas

A theme page explains a recurring research pressure. A paper-atlas entry explains the concept inside one publication. The useful unit is not the abstract or title. It is the paper's chosen mathematical object: a verifier, a graph, a distribution, a quotient space, a feasible set, a trajectory, an activation direction, a compute budget, or a latent representation.

The same publication can appear in several themes because one technical idea often answers multiple questions. CyberGym is a security benchmark, an agent-process diagnostic, and an executable evaluation method. Quotient-Space Diffusion is a generative model, a geometry paper, and a sampler-correctness paper. The atlas keeps those connections visible while giving each paper one first-principles read.

FAMILY 01

Agents and Executable Evaluation

CyberGym

ICLR 2026

CyberGym's core concept is executable vulnerability evidence. The paper treats a security task as incomplete until an agent produces a proof-of-concept test that distinguishes vulnerable from patched code. The benchmark is therefore not a questionnaire about CVEs; it is a world where code, exploit, patch, and verifier interact.

Mathematical object
A verifier over program versions: exploit passes on pre-patch state and fails on post-patch state.
Approach
Builds 1,507 real-vulnerability tasks across 188 projects and validates generated PoCs by executing them.
Themes
LLM agents and process diagnostics; evaluation and measurement; robustness and security impact.

OpenApps

ICLR 2026

OpenApps' core concept is environment variation as a robustness variable. A UI agent that succeeds on one fixed app instance may be using brittle visual or textual cues. The paper makes the app itself configurable so success measures whether the agent understands the workflow across appearance and content changes.

Mathematical object
A task distribution over app configurations, not a single deterministic UI state.
Approach
Evaluates multimodal agents across thousands of app variants and tracks success swings, loops, and hallucinated actions.
Themes
UI-agent reliability; environment variation; grounding failures under distribution shift.

MedAgentGym

ICLR 2026

MedAgentGym's core concept is biomedical data science as an executable agent environment. The agent must write or modify code, receive feedback, and improve task performance in sandboxed biomedical workflows. The benchmark matters because scientific agents need verifiable work products, not persuasive prose.

Mathematical object
A trajectory of code actions with ground truth, feedback, and task outcome.
Approach
Provides 72,413 sandboxed biomedical coding tasks and trains Med-Copilot with offline and online RL.
Themes
Executable biomedical agents; scientific discovery; healthcare ML.

SandboxEscapeBench

ICML 2026

SandboxEscapeBench's core concept is the sandbox boundary as the object of evaluation. A tool-using model is not only generating text; it may execute commands in a containerized environment. The important question is whether the agent can cross a boundary it should not cross.

Mathematical object
A reachability condition: can the agent obtain host-level evidence such as a protected flag from inside a nested sandbox?
Approach
Covers public escape tasks across misconfiguration, privilege, runtime, orchestration, and host/kernel layers.
Themes
Agent infrastructure risk; CTF-style evaluation; sandbox safety.

EditBench

ICLR 2026

EditBench's core concept is code editing under real context. Code assistants are often evaluated on isolated snippets, but real edits depend on highlighted regions, cursor position, instructions, and surrounding repository state. The paper makes context part of the task rather than noise around it.

Mathematical object
A conditional edit function from instruction and local code context to a patch.
Approach
Evaluates 40 LLMs on 545 wild code-edit tasks and measures how realistic context shifts success.
Themes
Evaluation; coding assistant reliability; developer tools.

OmniVerifier

ICLR 2026

OmniVerifier's core concept is visual outcome verification. A visual model can generate, edit, or reason about images, but the harder question is whether the resulting image satisfies the requested condition. The verifier becomes a reusable scoring object across visual tasks.

Mathematical object
A verification function over image, instruction, and expected visual outcome.
Approach
Builds ViVerBench and OmniVerifier-7B across 16 task categories, then uses verification for iterative refinement.
Themes
Evaluation; test-time scaling; visual verification.

Rational Agents

ICLR 2026

Rational Agents' core concept is information-gain-guided interaction. If an agent can ask questions before acting, the best next move is not necessarily the one that looks closest to the final answer. It is the move that most reduces decision-relevant uncertainty.

Mathematical object
Expected information gain over possible hidden states and future actions.
Approach
Uses Monte Carlo expected-information-gain inference in dialogue-style games such as Battleship and Guess Who.
Themes
Reasoning, planning, tool use; resource-rational dialogue.

TRACE Effort

ICLR 2026

TRACE Effort's core concept is reward hacking detected through reasoning effort. If a model passes a verifier before enough reasoning is present to solve the intended task, the high score may be a shortcut. The paper makes the amount of reasoning itself a diagnostic variable.

Mathematical object
Verifier success as a function of progressively truncated chain-of-thought.
Approach
Flags low-effort verifier-passing behavior by measuring when reward appears along a reasoning trace.
Themes
Reward hacking; process diagnostics; evaluation reliability.
FAMILY 02

Inference Control and Alignment

Steer Like the LLM

ICML 2026

The core concept is activation-space steering. Prompting controls behavior through words, but internal activations can expose a more direct control surface. The paper asks whether prompt-induced behavioral changes can be reproduced by learned activation interventions.

Mathematical object
A direction or position-specific coefficient in hidden-state space.
Approach
Trains Prompt Steering Replacement models that mimic prompt effects with interpretable activation interventions.
Themes
Interpretability as intervention; inference-time model control.

The Tell-Tale Norm

ICML 2026

The core concept is an internal scalar as a compute-allocation signal. The hidden-state norm is treated as evidence about reasoning intensity. Instead of asking an external controller how much to think, the method uses the model's own state magnitude to guide recursion, steering, and response selection.

Mathematical object
The L2 norm of hidden states as an endogenous statistic.
Approach
Uses norm signals to allocate or steer test-time computation without additional training data.
Themes
Interpretability; test-time scaling; reasoning control.

Enhancing Reasoning for Diffusion LLMs via DMPO

ICML 2026

The core concept is distribution matching for non-autoregressive reasoning. Diffusion LMs do not expose the same next-token policy path as autoregressive LMs, so RL updates must match a denoising distribution rather than copy standard policy-gradient assumptions.

Mathematical object
A reward-tilted target distribution over diffusion LM outputs and denoising paths.
Approach
Uses distribution matching policy optimization and baseline corrections for small-batch mode-coverage errors.
Themes
Diffusion language models; test-time scaling; RL post-training.

RAGEN-2

ICML 2026

The core concept is reasoning collapse as low mutual information with the task. An agent can produce long reasoning that looks structured but is almost input-agnostic. The paper treats boilerplate reasoning as a measurable collapse mode rather than a stylistic defect.

Mathematical object
A mutual-information proxy between input and reasoning trajectory.
Approach
Explains collapse through weak within-input reward variance and detects template reasoning that entropy misses.
Themes
Agentic RL diagnostics; reward signal quality; process failure.

AuxDPO

ICLR 2026

The core concept is preference optimization under model-class misspecification. DPO can behave incorrectly when the policy class cannot represent the reward structure that generated preferences. The paper reframes preference training as geometry around the local RLHF solution.

Mathematical object
Preference objective geometry and auxiliary variables approximating natural-gradient policy updates.
Approach
Shows DPO can reverse preferences under unrealizable rewards and adds auxiliary variables to correct the update geometry.
Themes
Alignment; preference optimization; theory unifying RLHF practice.

ScaleRL

ICLR 2026

The core concept is predictable scaling for RL post-training. Instead of treating a large RL run as an irreducible experiment, the paper models compute-performance behavior with curves that separate efficiency from asymptotic ceiling.

Mathematical object
Sigmoidal compute-performance scaling curves for validation performance.
Approach
Fits predictive curves and demonstrates extrapolation up to a 100,000 GPU-hour RL run.
Themes
RL scaling; alignment; inference-control recipes.

Gaussian certified unlearning in high dimensions

ICLR 2026

The core concept is deletion as a hypothesis-testing guarantee. If a training point is removed, the post-unlearning model should be statistically hard to distinguish from one trained without that point. The high-dimensional setting changes which noise guarantees are meaningful.

Mathematical object
Epsilon-Gaussian certifiability and hypothesis-testing privacy under calibrated Gaussian noise.
Approach
Uses one Newton step plus noise and measures prediction-level degradation after deletion.
Themes
Certified unlearning; privacy definitions; deployment-driven theory.

Catch-22

ICML 2026

The core concept is the watermarking trilemma. A watermark must survive edits, stay hidden from observers without the key, and remain detectable by the owner. Information-theoretic testing shows these requirements pull against each other.

Mathematical object
KL-based hypothesis testing between watermarked and unwatermarked text distributions.
Approach
Characterizes tradeoffs among robustness, stealth, and reliable verification.
Themes
Watermarking; safety bounds; information-theoretic governance.
FAMILY 03

Generative and Physical Structure

Quotient-Space Diffusion Model

ICLR 2026

The core concept is generation modulo symmetry. A molecule rotated or translated in 3D is the same physical object, but coordinate diffusion can waste probability mass learning those redundant degrees of freedom. The paper puts the generative process on the symmetry-reduced object.

Mathematical object
The quotient space R^{3N} / SE(3).
Approach
Derives lifted quotient-space diffusion and contrasts it with alignment heuristics that may alter the sampling target.
Themes
Structured generative modeling; scientific-domain generation; sampler correctness.

Protein Autoregressive Modeling

ICML 2026

The core concept is coarse-to-fine physical structure generation. Protein backbones have hierarchy: global fold structure constrains local detail. The paper makes that hierarchy part of the generation order instead of asking a flat generator to discover it implicitly.

Mathematical object
A multiscale protein backbone representation with next-scale prediction.
Approach
Combines coarse-to-fine autoregression with a flow-based decoder for robust backbone and motif-conditioned generation.
Themes
Scientific and physical generation; structured generative modeling.

Latent Spherical Flow Policy

ICML 2026

The core concept is sampling feasible structured actions through a solver. In combinatorial RL, the action space is discrete and constrained, so directly sampling arbitrary actions is wasteful. The paper learns a continuous latent distribution and lets a solver map samples into valid decisions.

Mathematical object
A spherical latent flow distribution composed with a combinatorial solver.
Approach
Uses flow matching to learn expressive stochastic policies in compact latent space.
Themes
Hybrid neural-symbolic systems; generative modeling for decision-making.

Spherical Watermark

ICLR 2026

The core concept is watermarking without breaking the latent prior. A diffusion watermark has to encode bits while still looking like valid Gaussian noise, otherwise quality and detectability trade off badly. The paper designs the watermark inside the geometry of the noise distribution.

Mathematical object
Latent Gaussian noise with spherical mapping, orthogonal rotation, and chi-square radius scaling.
Approach
Embeds watermark bits into diffusion latent noise while reconstructing a multivariate Gaussian prior.
Themes
Diffusion media provenance; distribution-preserving watermark design.

FALCON

ICLR 2026

The core concept is likelihood-usable molecular flow sampling. For molecular equilibrium estimation, samples alone are not enough; the model needs likelihoods accurate enough for importance weighting. The paper makes few-step flows useful for thermodynamic inference.

Mathematical object
A continuous flow with invertibility pressure and usable likelihood estimates.
Approach
Trains flows that provide fast samples and likelihoods accurate enough for importance sampling.
Themes
Scientific generation; probabilistic inference; molecular flows.

PRISM

ICLR 2026

The core concept is structured semantic mediation between brain signals and images. Raw fMRI is not directly an image representation; the paper maps brain activity into object-attribute-relation text before visual reconstruction. The latent interface carries human-interpretable structure.

Mathematical object
A structured text latent space of objects, attributes, and relations.
Approach
Projects brain signals into structured text and uses object-centric diffusion to reduce perceptual reconstruction loss.
Themes
Multimodal models; scientific/physical generation; neural reconstruction.

FlashVID

ICLR 2026

The core concept is video understanding as token-budget allocation. Long videos contain redundant spatial and temporal information. The paper asks which visual tokens should survive when compute is fixed and the model needs more frames.

Mathematical object
A representative-token selection and merging operator over spatiotemporal visual tokens.
Approach
Merges video redundancy across space and time, preserving performance with a small fraction of tokens.
Themes
Efficiency; multimodal long-video understanding.

CompSLOT

ICLR 2026

The core concept is object-centric memory for continual learning. Forgetting happens when new tasks overwrite old representations. The paper uses slots and concept structure so memories are compositional rather than one undifferentiated parameter update.

Mathematical object
Object-centric slots, primitive selection, and concept-similarity distillation.
Approach
Adds concept-compositional memory mechanisms to reduce catastrophic forgetting in foundation-model continual learners.
Themes
Continual learning; interpretability as intervention.
FAMILY 04

Causality and Uncertainty

BRCD

ICML 2026

The core concept is root-cause inference under graph uncertainty. In a microservice incident, many components fail together, but operators need to know where to intervene first. The paper treats partial causal structure as usable evidence rather than waiting for a complete graph.

Mathematical object
A pre-failure CPDAG and posterior over compatible DAGs and root-cause candidates.
Approach
Uses Bayesian inference and uniform DAG sampling to rank causes from sparse failure data.
Themes
Causal discovery; software intelligence; production RCA.

Local Covariate Selection

ICML 2026

The core concept is effect identification without global causal discovery. Often the user only needs one causal effect, not the whole graph. The paper asks which local adjustment information is enough to estimate that effect soundly.

Mathematical object
Valid adjustment sets under latent variables and local graph conditions.
Approach
Finds adjustment sets without requiring global causal discovery, pretreatment assumptions, or causal sufficiency.
Themes
Causality; theory unifying practical adjustment.

Structure Learning CI

ICML 2026

The core concept is reducing graph recovery to conditional-independence testing. Instead of treating structure learning as a black-box graph search, the paper identifies the statistical primitive that controls minimax rates in restricted graph families.

Mathematical object
Conditional-independence tests and minimax structure-learning rates for poly-forests.
Approach
Derives optimal rates for Bernoulli, Gaussian, and nonparametric graphical-model settings.
Themes
Causality; theory and optimization.

Latent Hawkes Causal Discovery

ICLR 2026

The core concept is causal discovery when some event-generating subprocesses are hidden. Temporal point processes can look causally connected because unobserved subprocesses drive visible events. The paper asks when causal influences can still be identified.

Mathematical object
Hawkes processes with latent subprocesses and shrinking-interval discrete-time causal representations.
Approach
Establishes identifiability conditions for edge and subprocess recovery under partial observation.
Themes
Scientific discovery; probabilistic inference; temporal causality.

Robust Contextual Optimization with Missing Covariates

ICML 2026

The core concept is decision robustness under incomplete context. Imputing missing covariates can make uncertainty invisible to the optimizer. The paper keeps missingness inside the decision problem by constructing ambiguity sets from partial observations.

Mathematical object
Distributionally robust ambiguity sets conditioned on observed covariate subsets.
Approach
Optimizes directly against uncertainty induced by missing covariates instead of completing the dataset first.
Themes
Robust decision-making; data quality and missingness-aware optimization.

Rare Event Analysis of LLMs

ICML 2026

The core concept is tail behavior as a measurable deployment risk. A bad event may be absent in small development samples but matter at scale. The paper treats rare model behavior as a probability-estimation problem rather than an anecdote.

Mathematical object
Low-probability event estimation with Monte Carlo, MCMC, transition paths, and importance sampling.
Approach
Defines rare-event analysis as event setup, probability estimation, and structure exploration with error analysis.
Themes
Evaluation; robustness; deployment-scale risk.

Micro-Benchmarking Reliability

ICLR 2026

The core concept is ranking confidence under limited evaluation budget. A small benchmark subset is useful only if it preserves the pairwise ranking decisions that matter. The paper asks how much sample size is needed before cheap evaluation becomes reliable.

Mathematical object
Pairwise model ranking reliability as a function of benchmark sample size.
Approach
Meta-evaluates small subsets and finds close model pairs often need around 250 examples.
Themes
Evaluation; measurement; sample-size limits.

DiReCT

ICML 2026

The core concept is data selection as curvature-aware control. Late-pretraining data should not be chosen only by domain labels. The paper treats each sample's gradient as an intervention on validation geometry and chooses data that aligns with flat directions while limiting stiff-direction damage.

Mathematical object
Per-sample gradients projected against validation-Hessian eigendirections.
Approach
Selects annealing samples with constrained gradient energy in stiff directions.
Themes
Optimization dynamics; data governance; data as control.
FAMILY 05

Systems, Optimization, and Representation

Differentiable MPC on GPU

ICLR 2026

The core concept is making a classical control optimizer accelerator-native. MPC is valuable because it reasons over dynamics and constraints, but it must be fast and differentiable to live inside modern learning loops.

Mathematical object
Sequential quadratic programs solved with custom preconditioned conjugate gradients.
Approach
Uses tridiagonal preconditioning and GPU parallelism to speed differentiable MPC for RL and imitation learning.
Themes
Robotics and control; systems infrastructure.

Optimal MoE Sparsity

ICLR 2026

The core concept is sparse scaling as compute allocation. More total parameters do not automatically improve reasoning if too little computation is active or too few tokens train each parameter. The paper studies how sparsity changes what the model learns.

Mathematical object
Active FLOPs and tokens per parameter under a fixed compute budget.
Approach
Analyzes reasoning and memorization performance as sparsity and training-token allocation vary.
Themes
Sparse computation; theory of MoE scaling.

Cost-aware FedOpt

ICLR 2026

The core concept is federated optimization with priced information. Client communication is not free, and clients may be functionally similar. The optimizer should exploit similarity and cost rather than blindly aggregate updates.

Mathematical object
Variance-reduced gradient estimators with client communication costs.
Approach
Prices random, full, and hybrid communication strategies and improves estimators through functional client similarity.
Themes
Federated learning; theory and optimization.

SpineFL

ICML 2026

The core concept is heterogeneous federated architecture. Different clients cannot all afford the same model, but they still need a shared training object. The paper splits each layer into a mandatory shared spine and optional dynamic capacity.

Mathematical object
A layer decomposition into shared backbone neurons and optional dynamic neurons.
Approach
Uses historical activation frequency to select submodels for heterogeneous device constraints while preserving diversity.
Themes
Federated learning; efficient adaptation; device heterogeneity.

Pi-net

ICLR 2026

The core concept is feasibility by construction. If a neural network's output must satisfy convex constraints, checking or repairing the output after prediction is fragile. The paper turns projection into a differentiable layer.

Mathematical object
Operator-splitting projection layers with implicit differentiation.
Approach
Enforces convex output constraints and uses feasible networks as fast constrained optimization proxies.
Themes
Theory and optimization; reinforcement learning; constrained planning.

GraphGlue

ICLR 2026

The core concept is graph-domain transfer as manifold gluing. Different graph datasets can have local geometries that do not align in a shared coordinate system. The paper builds a smooth geometry that connects them.

Mathematical object
A glued Riemannian manifold with adaptive orthogonal frames and EMA prototyping.
Approach
Integrates multi-domain graph data and improves cross-domain graph foundation model transfer.
Themes
Graph learning; representation geometry.

Temporal Superposition

ICLR 2026

The core concept is memory as feature packing. Recurrent networks have limited representational dimensions but must store many temporal features. The paper studies the geometry that emerges when memory demand exceeds simple orthogonal storage.

Mathematical object
Dense and sparse RNN feature-packing regimes with angular phase transitions.
Approach
Links feature geometry and spectral radius to temporal interference and memory capacity.
Themes
Representation geometry; interpretability; recurrent memory.

Why Deep Jacobian Spectra Separate

ICML 2026

The core concept is depth-induced spectral organization. Deep networks can develop low-rank Jacobian structure and separated singular values. The paper explains how depth shapes spectra and when singular-vector alignment emerges.

Mathematical object
Jacobian singular values and singular-vector alignment in fixed-gates masked products.
Approach
Analyzes spectral separation mechanisms that recover deep-linear-like decoupled dynamics.
Themes
Theory and optimization; theory unifies engineering practice.

Softmax Turing

ICLR 2026

The core concept is transformer computation as formal language machinery. The paper asks what chain-of-thought softmax transformers can compute when sequence length generalizes. The result connects positional encoding to computation power.

Mathematical object
CoT C-RASP programs and length-generalizable softmax transformer constructions.
Approach
Proves Turing-completeness and shows relative positional encoding extends universality to arbitrary languages.
Themes
Theory; sequence modeling; computation in transformers.

Language Generation in the Limit

ICML 2026

The core concept is separating formal computability from feasible learning. A generator can be computable in the limit and still require impossible amounts of data. The paper warns that existence results can hide sample complexity barriers.

Mathematical object
Formal-language generation classes under computability and sample complexity constraints.
Approach
Shows regular, context-free, and stricter classes can be sample-infeasible despite computability.
Themes
Theory; evaluation; sequence generation feasibility.

How This Grows to Full Coverage

The MVP covers forty-two papers that anchor the main conceptual lanes. The full atlas should extend this same structure to all 781 named papers in the local evidence map. The critical constraint is not generating more cards; it is keeping each card anchored to the actual paper evidence and writing the concept at the right level of abstraction.

The next batch should fill coverage gaps: healthcare and education agents, more data-governance papers, more numerical-systems papers, more multimodal perception papers, and the remaining theory pages. Once the atlas reaches full coverage, the site can support three readings of the same corpus: themes, mathematical concepts, and paper-level ideas.
