GOAL

The meaty end-to-end goal

Write a first-principles concept layer across the ICML / ICLR 2026 paper map: twenty-five longform articles, each built from the grouped paper categories and subcategories, each explaining one recurring object that appears across many papers.

Each article should answer the same hard questions: what is the real object, what is being changed, what must stay fixed, what evidence would prove the claim, what failure mode would fool a shallow reader, and which paper groups show the idea from different angles.

Acceptance test
A reader should be able to understand the conference's recurring technical problems without reading 781 papers one by one, while still seeing the named paper anchors behind every concept.

EXECUTION

How to pursue the goal

Batch size
Write 3 to 5 articles per pass. Each pass should cover one cluster of related concepts, not random pages.
Source rule
Start from grouped source rows in analysis/themes/theme-index.md, then use the paper atlas for paragraph-level anchors.
Article structure
Use the same spine: core problem, concrete object, anatomy table, paper groups, failure modes, evidence required, and final rule.
Language bar
No vague praise, no field slogans, no unexplained jargon. Every section should name the object, the allowed change, and the evidence.
Linking bar
Each article should link back to the strongest theme pages and forward to the paper atlas. The homepage and coverage matrix should expose the completed set.
Completion test
The 25-article layer is complete when it covers the strongest theme co-occurrences and a reader can move from concept to subtheme to paper without losing the argument.
