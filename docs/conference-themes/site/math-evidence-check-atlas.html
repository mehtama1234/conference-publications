FIRST PRINCIPLE

Evidence Must Observe The Protected Object

If a method claims to preserve state, the evidence cannot only report final accuracy. If it claims to measure capability, the evidence cannot only show a higher score on the same proxy. If it claims causal attribution, the evidence must intervene on the channel. The evidence has to touch the mathematical object the paper says matters.

This page separates result style from evidence type. The right check may be a perturbation, ablation, interval, execution trace, support audit, frontier, equivalence class, hardware trace, or verifier disagreement report. Each asks whether the first-principles object is actually present.

APPLICATION

How To Use Evidence Checks In Paper Cards

Write the claim first

State the mathematical object and the property the method claims to preserve. Then choose an evidence check that can observe that property directly.

Reject weak substitutes

If a paper reports only aggregate score, surface examples, or qualitative output, mark which protected object remains unobserved.

Connect by evidence type

Papers in different themes can be compared when they require the same evidence: frontier curves, perturbation tests, support audits, verifier traces, or identified sets.
