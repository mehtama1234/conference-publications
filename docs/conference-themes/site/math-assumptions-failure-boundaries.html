FIRST PRINCIPLE

Every Method Buys Something By Assuming Something

The clean way to read a paper is not to ask whether it "solves" reasoning, safety, generation, compression, or science. Ask what assumption turns the task into a tractable mathematical object. A verifier assumes the artifact it checks is the relevant one. A quotient model assumes the removed variation is irrelevant. A causal method assumes enough structure to identify an intervention. A compression method assumes discarded state is conditionally irrelevant.

The remaining failure is usually the complement of that assumption. If the verifier is mis-specified, the system learns to pass the wrong test. If the symmetry is false, quotienting erases real signal. If missing variables drive the causal graph, an identified-looking effect may be a story. If a token budget drops rare evidence, the compressed model becomes confidently blind.

BOUNDARY 01

State Sufficiency

RAGEN-2, HDFlow, IRNO, Mamba Markov ICL

Assumption. The retained intermediate state contains the variables needed by the next decision or correction.

Why it works. Once state is sufficient, the method can update locally: reasoning can continue, robot control can refine motion, neural operators can reduce residuals, and recurrence can estimate hidden Markov state.

Failure outside. If the state drops a rare event, contact variable, high-frequency residual, or hidden process variable, later steps cannot recover it without new observation.

success requires P(next decision | retained state) close to P(next decision | full history)
BOUNDARY 02

Trace Dependence

OpenThoughts, h1, T3, CE-Graph, TRACE Effort

Assumption. Intermediate reasoning steps are not merely explanatory text; they influence the final answer or learning signal.

Why it works. Trace data, horizon curricula, prefix utility, and graph checks reduce sparse credit because they make intermediate progress observable.

Failure outside. If traces are post-hoc style, teacher artifacts, or verifier-gaming scripts, optimizing them can make the model better at looking careful while weakening task-conditioned reasoning.

trace is evidence only if intervention(trace) changes outcome for task-relevant reasons
BOUNDARY 03

Verifier Validity

CyberGym, VERINA, OmniVerifier, WebDevJudge

Assumption. The verifier observes the artifact whose correctness defines the task.

Why it works. Execution, proof checking, visual outcome checks, and browser rendering turn a claim into an inspectable state.

Failure outside. If the verifier is incomplete, brittle, or checks a proxy artifact, agents can satisfy the verifier while missing the real outcome. This is not a small implementation issue; it changes the mathematical target.

optimize V(artifact) only when V is a valid measurement of target property
BOUNDARY 04

Benchmark Measurement

ATLAS, FRABench, UFEval, Micro-Benchmarking, MADQA

Assumption. Items, rubrics, judges, and sampling rules identify the latent ability being claimed.

Why it works. Adaptive item selection, factorized rubrics, uncertainty reports, and oracle-gap analysis expose the measurement process behind the score.

Failure outside. A benchmark can be reliable for the wrong variable. It may rank models precisely while measuring shortcut use, judge preference, task-mixture fit, or missing-evidence tolerance.

score = ability signal + sampling noise + judge bias + design artifact
BOUNDARY 05

Tail Coverage

Rare Event Analysis, Jailbreak Foundry, VALUEFLOW, FlowGuard

Assumption. The pressure distribution or rare-event estimator reaches the region where deployment failure lives.

Why it works. Tail estimation, attack harnesses, value-intensity probes, and trajectory monitors move measurement away from average prompts toward boundary behavior.

Failure outside. A new adversary, hidden context, monitoring awareness, or deployment loop can create a different tail. Safety evidence is conditional on the pressure distribution tested.

risk claim is about event E under distribution Q, not all possible pressure
BOUNDARY 06

Feasible Sets

Copyright-Bench, Pi-net, Fair OT, CSPO, PACT

Assumption. The constraint set describes what is actually allowed: lawful source use, hard numerical feasibility, fair coupling, safe policy region, or bounded robot correction.

Why it works. Search inside the feasible set avoids wasting probability mass on invalid outputs and makes constraint satisfaction part of generation or optimization.

Failure outside. If the feasible set is too narrow, it blocks valid solutions. If it is too broad or omits a hidden constraint, optimization can still find invalid actions that look legal to the formal rule.

C must be close to the real allowed set, not only convenient to project onto
BOUNDARY 07

Symmetry

Quotient Diffusion, Camera-Aware MLLM, GraphGlue, Protein Generation

Assumption. The variation removed by the model is nuisance variation: rotation, translation, relabeling, viewpoint, or representation format rather than task signal.

Why it works. Quotienting reduces sample complexity by not asking the model to relearn fake differences.

Failure outside. Some transformations are only nuisance for some tasks. A camera angle may affect action feasibility; chirality may matter chemically; graph labels may encode roles. Removing the wrong variation erases signal.

x ~ g*x only when target(x) = target(g*x)
BOUNDARY 08

Sampling Paths

DMPO, FALCON, Safety-Guided Flow, GWF, Cauchy Bridges

Assumption. The chosen path through probability space preserves likelihood, reward tilt, safety, or mode coverage relevant to the target distribution.

Why it works. Flow, diffusion, bridge, and Wasserstein views control how mass moves, not only where the final sample lands.

Failure outside. If the path overweights easy modes, accumulates numerical error, crosses unsafe regions, or optimizes the wrong reward-tilted target, post-hoc filtering cannot fully repair the distribution.

distribution path matters when constraints and likelihood are path-dependent
BOUNDARY 09

Update Geometry

Adam Degeneracy, DiReCT, LoRA Theory, Trust-Region LLM RL

Assumption. The metric, curvature, rank, or trust region used by the method matches the directions where useful behavior is fragile.

Why it works. Updates become controlled movement: curvature-aware data avoids stiff directions, LoRA restricts rank, adaptive optimizers change coordinates, and trust regions bound policy displacement.

Failure outside. If unmeasured behavior lives outside the protected subspace or the metric misses deployment-relevant sensitivity, an update can improve the target score while damaging capability elsewhere.

safe update requires useful movement and protected invariants in the same geometry
BOUNDARY 10

Compression

FlashVID, InfoTok, EntroKV, LiftQuant, FOCUS/RePAIR

Assumption. Removed tokens, bits, layers, channels, or cache entries are redundant for the future decision or generated trajectory.

Why it works. Compression becomes function-preserving approximation when it protects high-value state and spends error budget where the task is insensitive.

Failure outside. Rare evidence, outlier channels, long-range dependencies, and loop-stability variables can look small until removed. Uniform compression fails because not all approximation error has equal consequence.

discard d only if target is conditionally independent of d given retained state
BOUNDARY 11

Data Value

Sequential Data Values, DiReCT, Midtraining Bridges, Common Corpus, OPUS

Assumption. The value estimate matches the current model, optimizer, selected set, training phase, and governance constraints.

Why it works. Data is treated as an intervention on the learning path. The same example can help, be redundant, or harm depending on timing and context.

Failure outside. Data scores decay when the objective changes, the learning rate closes the plasticity window, provenance is wrong, or examples interact in ways the marginal model did not account for.

value(example) is conditional, not intrinsic
BOUNDARY 12

Identification

Local Covariate Selection, BRCD, OU Identifiability, Latent Hawkes Discovery

Assumption. The graph, moments, environments, interventions, or event structure provide enough information to distinguish the claim from alternatives.

Why it works. The methods state the identifiable object: a local adjustment set, posterior over causes, recoverable drift, or triggering relation.

Failure outside. Hidden confounders, wrong temporal granularity, weak interventions, or observationally equivalent graphs can leave the causal story underdetermined even when prediction is strong.

identified claim = invariant across alternatives allowed by assumptions
BOUNDARY 13

Modality Credit

MoCA, VGS, VISUALSWAP, Causal Route Gating, MINT

Assumption. Interventions or diagnostics isolate the route through which visual, textual, audio, memory, or prior evidence changes the answer.

Why it works. The model can be repaired only when the failing channel is known. Credit assignment separates seeing badly from reasoning badly from overusing a prior.

Failure outside. If channels are entangled too deeply, interventions leave the natural activation distribution, or counterfactuals change more than one cause, the route diagnosis can become a misleading attribution.

grounding requires causal contribution, not co-occurring modality tokens
BOUNDARY 14

Latent Interfaces

PRISM, Mind-Omni, LatentLM, Linear Causal Representation Learning

Assumption. The latent code exposes variables that the downstream operation can decode, intervene on, or identify.

Why it works. Good hidden spaces reduce the problem: brain signals become object-attribute-relation codes, media becomes editable latent state, and causal features become recoverable factors.

Failure outside. A compact embedding can preserve similarity while hiding the variable that matters. If the latent is not aligned with action, decoding, or intervention, it is storage rather than an interface.

z is useful only relative to operation O: decode, control, retrieve, identify, or verify
BOUNDARY 15

Mechanisms

AdvGame, Accuracy Auctions, Data Market Pricing, Fair OT, OMAC

Assumption. The strategic model captures the actors, information, payoffs, and constraints that determine behavior after deployment.

Why it works. Game and mechanism views replace one loss with response dynamics: attackers adapt, sellers shade information, users value accuracy differently, agents coordinate, and fairness constraints shape couplings.

Failure outside. If actors have missing actions, hidden information, collusion, distribution shift, or incentives not in the model, equilibrium behavior may not predict deployed behavior.

mechanism claims are conditional on the action space and information structure
BOUNDARY 16

Scientific Claims

Neural Effect Search, HypoSpace, RefineStat, MedAgentGym, Bitween

Assumption. A generated claim can be mapped to a hypothesis, experiment, program, reduction, or workflow whose failure would be observable.

Why it works. Scientific language becomes useful when it is attached to evidence that can reject it: randomized tests, hypothesis recovery metrics, statistical semantics, executable sandboxes, or verified reductions.

Failure outside. If the claim cannot fail, the system can produce plausible science-shaped text without increasing knowledge. The missing object is not intelligence; it is a rejection channel.

hypothesis h is scientific only when some evidence e can lower belief in h
