FIRST PRINCIPLE

Every Method Buys Something By Assuming Something

The clean way to read a paper is not to ask whether it "solves" reasoning, safety, generation, compression, or science. Ask what assumption turns the task into a tractable mathematical object. A verifier assumes the artifact it checks is the relevant one. A quotient model assumes the removed variation is irrelevant. A causal method assumes enough structure to identify an intervention. A compression method assumes discarded state is conditionally irrelevant.

The remaining failure is usually the complement of that assumption. If the verifier is mis-specified, the system learns to pass the wrong test. If the symmetry is false, quotienting erases real signal. If missing variables drive the causal graph, an identified-looking effect may be a story. If a token budget drops rare evidence, the compressed model becomes confidently blind.

BOUNDARY 01

State Sufficiency

RAGEN-2, HDFlow, IRNO, Mamba Markov ICL

Assumption. The retained intermediate state contains the variables needed by the next decision or correction.

Why it works. Once state is sufficient, the method can update locally: reasoning can continue, robot control can refine motion, neural operators can reduce residuals, and recurrence can estimate hidden Markov state.

Failure outside. If the state drops a rare event, contact variable, high-frequency residual, or hidden process variable, later steps cannot recover it without new observation.

success requires P(next decision | retained state) close to P(next decision | full history)
BOUNDARY 02

Trace Dependence

OpenThoughts, h1, T3, CE-Graph, TRACE Effort

Assumption. Intermediate reasoning steps are not merely explanatory text; they influence the final answer or learning signal.

Why it works. Trace data, horizon curricula, prefix utility, and graph checks reduce sparse credit because they make intermediate progress observable.

Failure outside. If traces are post-hoc style, teacher artifacts, or verifier-gaming scripts, optimizing them can make the model better at looking careful while weakening task-conditioned reasoning.

trace is evidence only if intervention(trace) changes outcome for task-relevant reasons
BOUNDARY 03

Verifier Validity

CyberGym, VERINA, OmniVerifier, WebDevJudge

Assumption. The verifier observes the artifact whose correctness defines the task.

Why it works. Execution, proof checking, visual outcome checks, and browser rendering turn a claim into an inspectable state.

Failure outside. If the verifier is incomplete, brittle, or checks a proxy artifact, agents can satisfy the verifier while missing the real outcome. This is not a small implementation issue; it changes the mathematical target.

optimize V(artifact) only when V is a valid measurement of target property
BOUNDARY 04

Benchmark Measurement

ATLAS, FRABench, UFEval, Micro-Benchmarking, MADQA

Assumption. Items, rubrics, judges, and sampling rules identify the latent ability being claimed.

Why it works. Adaptive item selection, factorized rubrics, uncertainty reports, and oracle-gap analysis expose the measurement process behind the score.

Failure outside. A benchmark can be reliable for the wrong variable. It may rank models precisely while measuring shortcut use, judge preference, task-mixture fit, or missing-evidence tolerance.

score = ability signal + sampling noise + judge bias + design artifact
BOUNDARY 05

Tail Coverage

Rare Event Analysis, Jailbreak Foundry, VALUEFLOW, FlowGuard

Assumption. The pressure distribution or rare-event estimator reaches the region where deployment failure lives.

Why it works. Tail estimation, attack harnesses, value-intensity probes, and trajectory monitors move measurement away from average prompts toward boundary behavior.

Failure outside. A new adversary, hidden context, monitoring awareness, or deployment loop can create a different tail. Safety evidence is conditional on the pressure distribution tested.

risk claim is about event E under distribution Q, not all possible pressure
BOUNDARY 06

Feasible Sets

Copyright-Bench, Pi-net, Fair OT, CSPO, PACT

Assumption. The constraint set describes what is actually allowed: lawful source use, hard numerical feasibility, fair coupling, safe policy region, or bounded robot correction.

Why it works. Search inside the feasible set avoids wasting probability mass on invalid outputs and makes constraint satisfaction part of generation or optimization.

Failure outside. If the feasible set is too narrow, it blocks valid solutions. If it is too broad or omits a hidden constraint, optimization can still find invalid actions that look legal to the formal rule.

C must be close to the real allowed set, not only convenient to project onto
BOUNDARY 07

Symmetry

Quotient Diffusion, Camera-Aware MLLM, GraphGlue, Protein Generation

Assumption. The variation removed by the model is nuisance variation: rotation, translation, relabeling, viewpoint, or representation format rather than task signal.

Why it works. Quotienting reduces sample complexity by not asking the model to relearn fake differences.

Failure outside. Some transformations are only nuisance for some tasks. A camera angle may affect action feasibility; chirality may matter chemically; graph labels may encode roles. Removing the wrong variation erases signal.

x ~ g*x only when target(x) = target(g*x)
BOUNDARY 08

Sampling Paths

DMPO, FALCON, Safety-Guided Flow, GWF, Cauchy Bridges

Assumption. The chosen path through probability space preserves likelihood, reward tilt, safety, or mode coverage relevant to the target distribution.

Why it works. Flow, diffusion, bridge, and Wasserstein views control how mass moves, not only where the final sample lands.

Failure outside. If the path overweights easy modes, accumulates numerical error, crosses unsafe regions, or optimizes the wrong reward-tilted target, post-hoc filtering cannot fully repair the distribution.

distribution path matters when constraints and likelihood are path-dependent
BOUNDARY 09

Update Geometry

Adam Degeneracy, DiReCT, LoRA Theory, Trust-Region LLM RL

Assumption. The metric, curvature, rank, or trust region used by the method matches the directions where useful behavior is fragile.

Why it works. Updates become controlled movement: curvature-aware data avoids stiff directions, LoRA restricts rank, adaptive optimizers change coordinates, and trust regions bound policy displacement.

Failure outside. If unmeasured behavior lives outside the protected subspace or the metric misses deployment-relevant sensitivity, an update can improve the target score while damaging capability elsewhere.

safe update requires useful movement and protected invariants in the same geometry
BOUNDARY 10

Compression

FlashVID, InfoTok, EntroKV, LiftQuant, FOCUS/RePAIR

Assumption. Removed tokens, bits, layers, channels, or cache entries are redundant for the future decision or generated trajectory.

Why it works. Compression becomes function-preserving approximation when it protects high-value state and spends error budget where the task is insensitive.

Failure outside. Rare evidence, outlier channels, long-range dependencies, and loop-stability variables can look small until removed. Uniform compression fails because not all approximation error has equal consequence.

discard d only if target is conditionally independent of d given retained state
BOUNDARY 11

Data Value

Sequential Data Values, DiReCT, Midtraining Bridges, Common Corpus, OPUS

Assumption. The value estimate matches the current model, optimizer, selected set, training phase, and governance constraints.

Why it works. Data is treated as an intervention on the learning path. The same example can help, be redundant, or harm depending on timing and context.

Failure outside. Data scores decay when the objective changes, the learning rate closes the plasticity window, provenance is wrong, or examples interact in ways the marginal model did not account for.

value(example) is conditional, not intrinsic
BOUNDARY 12

Identification

Local Covariate Selection, BRCD, OU Identifiability, Latent Hawkes Discovery

Assumption. The graph, moments, environments, interventions, or event structure provide enough information to distinguish the claim from alternatives.

Why it works. The methods state the identifiable object: a local adjustment set, posterior over causes, recoverable drift, or triggering relation.

Failure outside. Hidden confounders, wrong temporal granularity, weak interventions, or observationally equivalent graphs can leave the causal story underdetermined even when prediction is strong.

identified claim = invariant across alternatives allowed by assumptions
BOUNDARY 13

Modality Credit

MoCA, VGS, VISUALSWAP, Causal Route Gating, MINT

Assumption. Interventions or diagnostics isolate the route through which visual, textual, audio, memory, or prior evidence changes the answer.

Why it works. The model can be repaired only when the failing channel is known. Credit assignment separates seeing badly from reasoning badly from overusing a prior.

Failure outside. If channels are entangled too deeply, interventions leave the natural activation distribution, or counterfactuals change more than one cause, the route diagnosis can become a misleading attribution.

grounding requires causal contribution, not co-occurring modality tokens
BOUNDARY 14

Latent Interfaces

PRISM, Mind-Omni, LatentLM, Linear Causal Representation Learning

Assumption. The latent code exposes variables that the downstream operation can decode, intervene on, or identify.

Why it works. Good hidden spaces reduce the problem: brain signals become object-attribute-relation codes, media becomes editable latent state, and causal features become recoverable factors.

Failure outside. A compact embedding can preserve similarity while hiding the variable that matters. If the latent is not aligned with action, decoding, or intervention, it is storage rather than an interface.

z is useful only relative to operation O: decode, control, retrieve, identify, or verify
BOUNDARY 15

Mechanisms

AdvGame, Accuracy Auctions, Data Market Pricing, Fair OT, OMAC

Assumption. The strategic model captures the actors, information, payoffs, and constraints that determine behavior after deployment.

Why it works. Game and mechanism views replace one loss with response dynamics: attackers adapt, sellers shade information, users value accuracy differently, agents coordinate, and fairness constraints shape couplings.

Failure outside. If actors have missing actions, hidden information, collusion, distribution shift, or incentives not in the model, equilibrium behavior may not predict deployed behavior.

mechanism claims are conditional on the action space and information structure
BOUNDARY 16

Scientific Claims

Neural Effect Search, HypoSpace, RefineStat, MedAgentGym, Bitween

Assumption. A generated claim can be mapped to a hypothesis, experiment, program, reduction, or workflow whose failure would be observable.

Why it works. Scientific language becomes useful when it is attached to evidence that can reject it: randomized tests, hypothesis recovery metrics, statistical semantics, executable sandboxes, or verified reductions.

Failure outside. If the claim cannot fail, the system can produce plausible science-shaped text without increasing knowledge. The missing object is not intelligence; it is a rejection channel.

hypothesis h is scientific only when some evidence e can lower belief in h
PAPER ROWS

Paper-Specific Multimodal Boundaries

Mind-Omni / PRISM

Assumption. The brain-token, object, attribute, and relation interface preserves the concept variables actually present in the measurement channel.

Why it works. fMRI and perception models become tractable when the raw signal is not treated as the object itself. The mathematical move is to choose a middle representation z whose coordinates are closer to concepts than voxels or pixels are, then learn mappings into and out of that representation.

Failure outside. Subject variation, timing mismatch, scanner noise, low-level perceptual detail, or hard tokenization can remove uncertainty that the downstream model should have kept.

Evidence needed. Cross-subject stress tests, interface-variable ablations, uncertainty calibration by concept class, and checks that the same token still predicts under changed visual nuisance factors.

useful z requires I(concept; z) high and I(noise; z) controlled

Hibiki-Zero / VibeVoice / TTSDS2

Assumption. Semantic state and acoustic state can be preserved together under streaming or generation constraints.

Why it works. Speech is not text plus sound. It is a coupled signal where meaning, timing, speaker identity, emphasis, and uncertainty share one temporal path. These methods work when the state carries enough information for both lexical correctness and waveform-level plausibility.

Failure outside. The transcript can be right while prosody, speaker continuity, turn timing, or naturalness is wrong. Low latency can also force a premature decision before the acoustic evidence has disambiguated the utterance.

Evidence needed. Audio-native scores, streaming-delay sweeps, speaker and prosody consistency checks, and human plus automatic multi-aspect evaluation rather than transcript accuracy alone.

speech success depends on P(words, prosody, speaker | acoustic history)

MoCA / VGS / VISUALSWAP / Causal Route Gating / MINT

Assumption. An intervention can isolate the route by which visual, textual, memory, or prior evidence changes the answer without changing hidden difficulty.

Why it works. The problem is causal credit. If two prompts have the same answer format but differ in the evidence route, the model's change in output can identify which channel carried useful information. Repair then targets the channel instead of treating all errors as one loss.

Failure outside. A counterfactual image edit may change more than the intended fact. A hidden-state route may not be localized. A shortcut can disappear in one layer and reappear through another representation.

Evidence needed. Paired counterfactuals, route ablations, hidden-state patching, controlled image edits, and tests where the same fact is moved across modalities.

route claim requires do(channel=c) changes answer through that channel alone

FlashVID / InfoTok / VideoFlexTok / OmniFit / LST

Assumption. The retained tokens form a sufficient statistic for the future query or action under the memory and latency budget.

Why it works. Token selection is a lossy map from full evidence x to retained state r. It helps only when r keeps the variables that will later matter. The mathematical question is not whether the representation is smaller; it is whether the conditional prediction from r is close to the prediction from x.

Failure outside. A rare decisive event can be discarded because it has low average salience. A query may arrive after compression and ask for a detail that looked irrelevant earlier. Cross-modal redundancy may be overestimated when both channels share the same blind spot.

Evidence needed. Deletion and insertion tests, rare-event benchmarks, query-conditioned retention evaluation, and latency-memory curves tied to task loss rather than token count alone.

compress x to r only if P(y | r, q) approximates P(y | x, q)

SAW-Bench / MomaGraph / EgoTactile / HDFlow / PACT / JoSE / RodriNet

Assumption. The representation contains the body and world variables that constrain valid action.

Why it works. Embodied models are governed by feasibility, not only prediction. Contact, pose, affordance, subgoal state, kinematics, and correction limits define the allowed region of action space. A method works mathematically when its state makes invalid actions easier to exclude before execution.

Failure outside. The scene graph can be stale, tactile readings can be miscalibrated, a hierarchy can choose the wrong subgoal, a learned manifold can exclude recovery actions, or kinematics can omit the contact variable that actually decides success.

Evidence needed. Contact, timing, and occlusion stress tests, out-of-distribution object affordances, intervention on constraint variables, and recovery trials after partial failure.

valid action a must lie in C(body, object, contact, time)

VideoKR / Visual Attribution Streaming / DLMR / RFCMH / WETR / AGREE

Assumption. Provenance stays attached to observations, derived memories, retrieved knowledge, modality agreement, and weak labels.

Why it works. The central object is not memory size; it is evidence lineage. A system can revise beliefs only if it knows whether a statement came from direct observation, a previous inference, retrieval, a weak label, or agreement among correlated channels.

Failure outside. A belief can be mistaken for evidence. Agreement across modalities can come from a shared prior rather than independent support. Reliability weights can amplify easy or frequent labels while underweighting rare but decisive observations.

Evidence needed. Source-label audits, memory-write tests, consistency versus observation ablations, weak-label calibration, and temporal checks that old beliefs are corrected when new evidence arrives.

belief update needs source(e), time(e), reliability(e), and dependence(e)

NextStep-1 / EditVerse / LatentLM / UALM / FlashWorld / VIST3A / TideGS / RadioGS / Omni-Reward / UniPercept / MetamerGen

Assumption. A shared generation interface preserves the native constraints of each medium through the decoder, reward, or verifier.

Why it works. Unified generation is a coordinate-change problem. The shared latent or protocol is valuable only if it keeps the invariants that each output space requires: geometry for scenes, timing for video and speech, texture for images, field structure for scientific media, and perceptual indistinguishability for metamers.

Failure outside. A shared latent can erase texture, timing, or geometry. Iterative edits can drift from the target. A reward can ignore the projection where artifacts appear. A field basis can miss boundaries even while the average reconstruction looks strong.

Evidence needed. Edit-invariance tests, artifact-native verifiers, world and view consistency checks, basis stress tests, and reward ablations that expose which output-space constraints are actually enforced.

shared z is valid only if decoder_m(z) preserves constraints C_m for each medium m
PAPER ROWS

Paper-Specific Physical And Generative Boundaries

Quotient-Space Diffusion / Chamaileon / Complexa

Assumption. The representation identifies the same physical object across nuisance pose while preserving the molecular and protein variables that control binding.

Why it works. The mathematical move is to stop treating every coordinate file as a new object. Quotienting removes rigid-body copies, while contextual binder data adds target state, atomistic contact, and complex-level structure. The learner spends capacity on relative geometry and interaction constraints instead of arbitrary frame choice.

Failure outside. A symmetry can be false for the task. Docking orientation, chirality, solvent exposure, local flexibility, allostery, or asymmetric measurement conditions can make a removed coordinate physically meaningful.

Evidence needed. Pose-invariance tests, chirality and pocket stress cases, binding-state ablations, experimental multimer validation, and checks that generated variation remains chemically distinct rather than pose-distinct.

valid identity requires target(x) = target(g*x) for every removed transform g

DeCoDe / mCLM / ReaSyn / MORetro*

Assumption. Binding, conformation, building blocks, and synthesis route can be represented as coupled but separable variables.

Why it works. The problem is not just to sample a molecule with a high score. It is to sample an object plus a path by which the object can exist. Decomposing binding position from conformation reduces entanglement, and route-aware generation turns feasibility into state rather than a filter after generation.

Failure outside. The factorization can split variables that chemistry keeps coupled. A route can be valid on paper but unavailable under real reaction conditions, toxic, low-yield, too expensive, or incompatible with the selected binding pose.

Evidence needed. Route reconstruction tests, reaction-condition checks, Pareto-front audits over yield/cost/toxicity, and paired tests where the same scaffold is evaluated with and without route constraints.

design state = molecule + conformation + route + constraints

FIDIA / SRMC / FALCON

Assumption. The sampler reaches the part of the distribution read by the downstream scientific quantity: rare modes, equilibrium density, or the best candidate from a finite batch.

Why it works. These papers treat generation as estimation. FIDIA aligns training with the maximum selected under budget. SRMC reduces bias from missed modes. FALCON attaches density to samples through change-of-variables accounting. The common object is the functional computed from samples, not the samples alone.

Failure outside. Upper-tail optimization can overfit a partial score. Mode coverage can be visually diverse while missing the high-contribution region. A tractable density can be precise for the wrong flow family.

Evidence needed. Best-of-N calibration, rare-mode held-out tests, effective sample size reports, density checks against known systems, and ablations showing which functional improves.

sampler quality depends on F(P), where F may be mean, tail, density, or max_N

Safety-Guided Flow / Cauchy-Driven Diffusion Bridges / GWF

Assumption. The path through probability space can be shaped without destroying the target distribution variables needed by the task.

Why it works. A sampler is a trajectory, not only a final draw. Safety-guided flows add boundary forces before unsafe samples appear. Heavy-tailed bridges change which jumps are plausible. Wasserstein or flow views make probability transport itself the object of control.

Failure outside. If the unsafe set is wrong, the model steers away from measured harm while entering unmeasured harm. If heavy-tailed jumps are not real structure, the model explains ordinary error as abrupt events. If transport over-smooths modes, final samples can satisfy local rules while losing global mass.

Evidence needed. Boundary misspecification tests, path diagnostics, tail-event replay, mode-preservation audits, and comparisons against post-hoc rejection to prove the path change matters.

controlled sampling modifies dP_t/dt, so path evidence matters

TideGS / RadioGS / LoRFS / Modified SINNs / IRNO

Assumption. The chosen basis, residual norm, and operator constraints match the physical field being modeled.

Why it works. Continuous science problems become learnable when the coordinates expose smoothness, locality, spectral structure, sensor geometry, or residual error. Gaussian primitives make rendering inspectable; separable and spectral bases reduce dimension; physics losses and residual correction make the governing equation part of the update.

Failure outside. A basis can hide sharp boundaries, discontinuities, long-range coupling, high-frequency residuals, or sensor artifacts. A fixed-point correction can converge in the wrong norm while violating the real boundary condition.

Evidence needed. Boundary-condition sweeps, high-frequency residual plots, basis stress tests, sensor-operator ablations, and rollouts that show error contraction under the task-relevant norm.

field claim needs observation = M(basis state) and residual -> 0 in the right norm

FlashWorld / VectorWorld / Stable Video Infinity / dWorldEval / Control Consistency

Assumption. The latent world state contains the variables changed by action and preserves them through time.

Why it works. World generation becomes a transition model. Vector states expose actors and topology; interactive video conditions on actions; self-generated failure training brings the model onto the states it will actually visit; control-consistency checks whether different actions create different futures from the same prior state.

Failure outside. A world state can omit hidden intent, contact, occlusion, stale topology, or physical constraints. Video can remain locally plausible while drifting from the causal action that should have shaped it.

Evidence needed. Counterfactual action tests, long-horizon drift curves, topology and occlusion stress cases, transition consistency checks, and verifiers that inspect state variables rather than frame appearance alone.

world model requires s_t + action -> s_{t+1}, not prompt -> plausible frames

MetamerGen / OmniVerifier / VideoKR / Seizure-Semiology-Suite

Assumption. The verifier observes the projection where the generated or interpreted artifact can fail.

Why it works. Physical and scientific outputs have many projections: perceptual equivalence, instruction satisfaction, temporal order, clinical state, semantic knowledge, and domain rule compliance. Multiple verifiers help when each one measures a different function of the latent object.

Failure outside. A model can pass an image metric while failing clinical meaning, pass a knowledge check while failing temporal evidence, or fool one perceptual route while breaking another. Verification cannot protect a variable it never measures.

Evidence needed. Artifact-native verifier ablations, expert-label audits, cross-projection disagreement reports, adversarial metric tests, and examples where a single verifier passes but the combined check rejects.

certificate is valid only for measured projection phi(object)
PAPER ROWS

Paper-Specific Theory And Optimization Boundaries

Adam Degeneracy / Non-Euclidean EoS / Trust-Region LLM RL

Assumption. The metric used in the argument is the metric followed by the real update.

Why it works. An optimizer is a dynamical system in coordinates. Adaptive scaling, normalized updates, and trust regions change which directions are large, small, cheap, or forbidden. The proof helps when it describes the actual movement of the deployed training loop.

Failure outside. Stale optimizer state, clipping, mixed precision, implementation-specific normalization, or reward channels outside the theorem can change the effective geometry while leaving the written objective unchanged.

Evidence needed. Update-norm traces, KL or policy-distance curves, optimizer-state audits, precision sweeps, and behavior checks on capabilities not named in the reward.

theorem metric G must match realized update delta theta

LoRA Theory / LoRA-Pre / Low-Rank LM Logits / FlexRank

Assumption. The useful task change lies in a low-rank or rank-ordered subspace that training data can identify.

Why it works. Low rank reduces degrees of freedom. If the target behavior changes mainly along a small number of directions, restricting movement can improve memory, stability, and sample efficiency. Mathematically, the adapter is useful because it makes the update class smaller without removing the needed direction.

Failure outside. A task can need high-rank movement, multiple adapters can interfere, rank can be selected on the wrong validation slice, or projected optimizer memory can discard directions that become useful later.

Evidence needed. Rank sweeps, held-out domain checks, adapter composition tests, singular-value energy reports, and ablations comparing full-rank movement to constrained movement.

low-rank helps only if useful delta theta is close to rank-r subspace

Alignment-Sensitive Minimax / Single-Head Attention / Jacobian Spectra / BBP Transitions

Assumption. Signal is recoverable through spectral directions that can be separated from noise in finite evidence.

Why it works. Spectral theory names where learnable signal lives. Risk falls when target information aligns with strong representation directions; attention succeeds when association directions rise above noise; Jacobian spectra explain which perturbations the function amplifies or suppresses.

Failure outside. The observed spectrum can be a dataset artifact, deployment can shift representation geometry, rare behavior can sit in weak directions, or finite samples can make a noisy direction look like signal.

Evidence needed. Spectrum stability across datasets, noise-floor estimates, held-out alignment tests, perturbation probes along weak and strong directions, and finite-sample confidence on recovered components.

generalization depends on signal projection above spectral noise floor

Transformer Clustering Circuits / Softmax Turing / Exact GNN Algorithms / Language Generation In The Limit

Assumption. Representable computation, learnable computation, and executed computation are close enough to support the claim being made.

Why it works. Expressivity results say a model class can contain an algorithm under stated depth, width, precision, or sequence conditions. That matters because it turns architecture into a possible computation. But the theorem is only the first step; finite data and optimization still have to select that computation.

Failure outside. A model can represent an algorithm without learning it. It can learn a shortcut that passes finite tests. A runtime can break the algorithm through limited context, finite precision, memory layout, or changed execution order.

Evidence needed. Algorithmic probes, length extrapolation, finite-precision tests, training-path diagnostics, and adversarial examples that distinguish the real algorithm from a shortcut.

can represent f does not imply trained system implements f

Finite Test Certification / UFEval / Micro-Benchmarking / Benchmarking At The Edge

Assumption. A finite test sample can bound a broader claim under a stated population, distance, and noise model.

Why it works. Evaluation becomes estimation. A test set supports a claim only through an uncertainty statement: which population it samples, how judge noise enters, how far deployment may be from the tested distribution, and how much evidence is needed for the desired confidence.

Failure outside. Leaderboards fail when the test distribution is treated as universal ability. Adaptive benchmark exposure, rubric drift, judge bias, hidden tool differences, or model-version changes can invalidate the finite-test certificate.

Evidence needed. Confidence intervals, item-family audits, judge calibration, model-version locks, bootstrap or hierarchical uncertainty, and explicit distribution-distance assumptions.

score supports claim only with population, uncertainty, and system identity named

Gaussian Certified Unlearning / Exact RL Unlearning / High-Dimensional Gaussian Mechanism / PRISM

Assumption. Privacy, deletion, or influence removal is defined over every artifact where the data could remain.

Why it works. The mathematical object is indistinguishability. If an adversary cannot reliably tell whether the removed data participated, then deletion has operational meaning inside the covered state. In RL, the covered state must include policies shaped by trajectories, not just labels.

Failure outside. Checkpoints, logs, caches, adapters, retrieval stores, evaluation traces, or downstream models can retain information outside the guarantee. An adversary with side information can test a different distinction than the theorem protects.

Evidence needed. Artifact inventory, adversary-model tests, membership and influence audits, checkpoint deletion checks, side-information stress tests, and proof that all deployed state follows the mechanism.

unlearning claim covers state S only; data outside S is outside the theorem

Catch-22 / Spherical Watermark / Ellipse Signatures / WaterSIC / Floating-Point Neural Networks / TetraJet

Assumption. The statistical signal or numerical representation survives the transformations applied in deployment.

Why it works. Watermarking is hypothesis testing under distortion, and finite arithmetic is computation under a changed number system. Both work when the detector or guarantee is stated in the same observation channel and arithmetic regime that production uses.

Failure outside. Paraphrase, translation, truncation, editing, platform formatting, kernel differences, accumulation order, calibration outliers, or mixed precision can erase the signal or change the computed function.

Evidence needed. False-positive and false-negative curves after realistic transformations, production-kernel parity tests, quantization calibration audits, outlier-channel checks, and robustness reports under adaptive attack.

certificate must survive channel T: signal(x) detectable after T(x)
PAPER ROWS

Paper-Specific Evaluation And Safety Boundaries

ATLAS / FRABench / UFEval / Micro-Benchmarking

Assumption. Items, rubrics, judges, and sampling rules identify the latent capability being claimed.

Why it works. Evaluation becomes statistical measurement. ATLAS spends items where Fisher information is high; factored rubrics split one score into dimensions; uncertainty-aware comparison stops small noisy gaps from becoming false rankings. The object is an estimator, not a leaderboard number.

Failure outside. The test can precisely measure the wrong variable: benchmark familiarity, judge preference, task-mixture fit, prompt format, or shortcut use. More items do not fix a wrong measurement model.

Evidence needed. Item-family audits, inter-judge calibration, uncertainty intervals, adversarial item variants, and reporting of what population the score estimates.

observed score = latent ability + item noise + judge bias + design artifact

MADQA / CounselBench / WebDevJudge / Seizure-Semiology-Suite

Assumption. The evaluator observes the domain variable that determines success: evidence access, professional boundary, rendered behavior, or clinical temporal state.

Why it works. High-stakes evaluation needs the right observation channel. Document QA separates oracle access from agent weakness; counseling needs expert risk judgment; web tasks need rendered interaction; seizure video needs laterality, symptom sequence, and timing rather than generic video labels.

Failure outside. A model can answer correctly for the wrong reason, sound safe while missing escalation, pass source checks while failing UI behavior, or name symptoms without preserving clinical order.

Evidence needed. Oracle-gap decomposition, expert adjudication, rendered artifact tests, temporal-label audits, and examples where surface correctness is separated from domain correctness.

valid score must observe phi_domain(output, evidence), not only text(output)

Rare Event Analysis / Tail Risks / CVaR MDPs / UP-OCP / ROCP

Assumption. The tested distribution or uncertainty set reaches the low-probability region where deployment loss lives.

Why it works. Tail safety is about a different functional than average accuracy. Rare-event estimators define the event first; importance sampling searches the dangerous region; CVaR methods make tail loss trainable; conformal and robust sets keep uncertainty alive until the decision.

Failure outside. The true tail may be induced by a new user population, repeated interaction, adversarial search, tool side effect, or feedback loop absent from the estimator. A calibrated average can still hide platform-scale harm.

Evidence needed. Event definitions, tail confidence intervals, pressure-distribution reports, sequential coverage checks, stress prompts, and sensitivity to the chosen uncertainty set.

safety claim is about P(loss in E under Q), not mean loss under ordinary P

Jailbreak Foundry / AdvGame / SecFid / SandboxEscapeBench / CSPO

Assumption. The evaluation pressure matches how a real boundary is attacked, traded off, or approached.

Why it works. Safety is clearest when it names the boundary: a forbidden state, an adaptive attacker, a security-fidelity frontier, or a signed distance to constraint violation. These papers move testing from static examples toward reachable failure regions.

Failure outside. A defense can pass known attacks while failing adaptive combinations. A sandbox can be safe in one configuration and exposed in another. A frontier can omit usability, latency, or hidden side effects that decide deployment viability.

Evidence needed. Reproducible attack harnesses, adaptive red-team rounds, boundary-distance traces, sandbox configuration sweeps, and separate reporting of security and task-fidelity losses.

boundary evidence requires reachable unsafe state plus pressure process

CyberGym / CIRBench / DRPBench / WZ-LLM / VERINA / AlgoVeri / Weak-Strong Verification

Assumption. The certificate checks the artifact whose correctness is being claimed.

Why it works. Executable evaluation removes ambiguity. An exploit must distinguish vulnerable from fixed code; compiler optimization must preserve semantics; proof tasks must pass a kernel; weak verifiers must defer when uncertainty is too high. The verifier is a measurement instrument with cost.

Failure outside. A certificate can be too narrow. The environment, compiler flags, concurrency schedule, proof library version, or weak-verifier calibration may differ from deployment. Passing one checker can still miss a relevant behavior.

Evidence needed. Environment manifests, counterfactual checks, semantic equivalence tests, schedule exploration, proof-kernel logs, verifier calibration curves, and defer-rate reporting.

claim valid only over artifacts and environments inspected by verifier V

Gaussian Certified Unlearning / Exact RL Unlearning / Catch-22 / Spherical Watermark / LM Memorization / PRISM

Assumption. The distinguishability test matches the adversary, channel, and artifacts present after deployment.

Why it works. Privacy and provenance are opposite statistical tasks. Unlearning wants removed-data worlds to be indistinguishable; watermarking wants marked and unmarked outputs to be distinguishable after transformations; memorization benchmarks estimate recoverable training bits. Each claim is a hypothesis test.

Failure outside. Side information, caches, logs, checkpoints, downstream copies, paraphrase, fine-tuning, quantization, or platform transformations can change the test. A guarantee over the model parameters may not cover the full deployed system.

Evidence needed. Artifact inventories, attack-model statements, membership and extraction tests, transformation robustness curves, false-positive and false-negative rates, and deletion checks across logs and adapters.

privacy/provenance claim = error rates of a specified statistical test

VALUEFLOW / SafeDPO / Accuracy Auctions / Fair OT / Data Market Pricing / Omni-Reward

Assumption. The preference, fairness, value, or incentive model captures the actors and stakes whose welfare the system claims to serve.

Why it works. Governance becomes mathematical when the social object is explicit: value intensity, safety-helpfulness frontier, private user values, group couplings, strategic data sellers, or multimodal preference evidence. These methods replace one hidden reward with a structured decision rule.

Failure outside. Values can be unstable, group labels can be incomplete, users can misreport stakes, sellers can collude, and reward models can miss artifact-native evidence. A clean frontier can still be wrong for the population it serves.

Evidence needed. Preference heterogeneity reports, calibration by subgroup, incentive-compatibility stress tests, fairness-frontier audits, artifact-native reward checks, and sensitivity to aggregation rule.

governance score is valid only relative to named actors, values, and aggregation rule
