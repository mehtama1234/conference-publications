SUPPORT LAYERS

How The Non-Lane Pages Fit

Paper To Object Index

Role. Paper-first lookup. It helps when the reader starts with a name and needs the shortest path to the object, reason, and deep page.

Next use. Expand toward the highest-traffic named papers that are still only present in dense atlas paragraphs.

Cross-Paper Synthesis

Role. Object-first connection layer. It shows how the same mathematical object appears in different themes.

Next use. Add narrower chains for theorem-to-deployment, measurement channels, and verifier gaming.

Assumptions And Failure Boundaries

Role. Limits layer. It states what must be true for an object to help and what remains outside the method.

Next use. Add paper-specific boundary rows for the most important papers in each lane.

Theorem To Deployment

Role. Theory transfer layer. It separates mathematical, statistical, and system-level assumptions for guarantees.

Next use. Extend this pattern to safety, scientific discovery, and multimodal measurement claims.

Main Math Atlas

Role. Entry point and concept grammar. It explains the recurring objects before sending readers to lane, index, synthesis, and boundary pages.

Next use. Continue balance passes so the page stays navigational instead of duplicating every child page.
