FIRST PRINCIPLE

A Theme Is A Repeated Mathematical Problem

The theme names are not labels for topic areas. They are repeated failure patterns. Reasoning is about preserving task information through a trace. Evaluation is about measuring a hidden target through a noisy channel. Data is about moving parameters with evidence at the right time. Generation is about sampling in the right native state space. Theory is about naming the budget or threshold. Causality is about what evidence identifies. Multimodal work is about assigning credit across channels.

The map below keeps each subtheme in the same shape: problem, mathematical object, approach, representative papers, and cross-theme connection.

THEME 01

Agents And Reasoning

A reasoning trace is useful only if it keeps contact with the task.

The hidden object in reasoning work is not a polished answer. It is the changing internal state that carries evidence from the prompt, tool results, memory, and intermediate deductions toward an action. The mathematical question is whether that state still depends on the actual problem or has drifted into a reusable pattern that merely looks like reasoning.

The reason these methods work is conservation of relevant information under limited budget. A trace, cache, skill, or agent graph helps only when it preserves the facts that future steps need while throwing away repetition, irrelevant history, and expensive dead ends. Longer thought helps when each extra step increases useful conditional information. It hurts when extra steps add noise, self-imitation, tool cost, or coordination error.

THEME 02

Evaluation And Safety

The thing being tested is usually hidden.

A benchmark is a measuring device, not the ability itself. The ability is a latent property: can the system reason from the evidence, use the right modality, obey a boundary, execute an artifact, or avoid a rare harmful state? The score is only an observation produced by prompts, tasks, judges, verifiers, users, and sampling rules. Evaluation works mathematically when that observation still carries enough information about the hidden property to separate real capability from noise, shortcuts, memorization, judge preference, and lucky samples.

The hard part is that models are not passive objects. Once a score becomes a training target, a leaderboard target, or a selection rule, the model can move toward patterns that raise the observed score without improving the hidden property. That is why the useful papers in this lane build sharper instruments: adaptive tests that spend questions where uncertainty is high, domain rubrics that observe the correct state, executable verifiers that test the artifact itself, tail estimators that look where average sampling rarely goes, and constrained policies that measure distance to forbidden behavior.

THEME 03

Data And Systems

Data matters by the movement it causes.

A dataset is not fuel poured into a model. Each example produces an update, and that update has direction, timing, curvature, conflict with other examples, and hardware cost. The hidden object is the model state after training, but the designer only controls which evidence is shown, in what order, at what precision, and through which serving system.

The mathematical reason timing, compression, caches, and provenance matter is that learning and inference are paths, not single events. The same example can help when the model is plastic and do little later. The same low-bit approximation can preserve ordinary outputs but distort rare reasoning paths. The same cache can look small while preserving exactly the state needed for the next token. These papers work when they control the movement of information rather than merely counting examples, parameters, or bytes.

THEME 04

Physical And Generative Models

A generated object has to live in the right state space.

The hidden object in physical and generative work is not a pixel grid, token string, or coordinate dump. It is a world state, molecule, field, trajectory, protein hierarchy, or embodied transition with constraints that existed before the model. The universe gives these methods leverage when they stop asking a generic network to rediscover those constraints from scratch and instead choose coordinates where the constraints are natural.

The mathematical move is usually preservation under transformation. Viewpoint should not change object identity. Time should change a scene through a transition law, not through unrelated frames. A molecule should satisfy geometry and synthesis constraints, not only look molecule-like. A PDE surrogate should preserve operator structure and residual behavior. Sampling works when probability mass moves through valid regions of the native space instead of crossing invalid shortcuts hidden by the representation.

THEME 05

Theory And Optimization

Theory is useful when it names the smaller object controlling the behavior.

The point of theory in this atlas is not decoration around empirical work. It says which part of a large system actually determines the outcome: a direction in parameter space, a spectral gap, a rank, a feasible set, a finite test, a game response, or an algorithm that an architecture can simulate.

These papers work mathematically because high-dimensional systems are not equally sensitive in all directions. Some directions carry signal, some are noise, some are forbidden by constraints, and some are invisible to the available evidence. A theorem helps when it exposes that geometry and says what must be true before an engineering recipe transfers to a new model, dataset, machine, or adversary.

THEME 06

Causality And Scientific Discovery

A scientific claim is strong only where the evidence can reject alternatives.

The hidden object in causality and scientific discovery is the mechanism: what would change if we intervened, which variables actually mediate an effect, which graph is compatible with observations, or which hypothesis survives an executable check. Ordinary prediction does not answer that because many mechanisms can produce the same observed pattern.

The mathematical move is identification. A paper works when it reduces the set of possible worlds without pretending the set is smaller than the evidence allows. Sometimes that means finding a local adjustment set instead of the full graph. Sometimes it means reporting an equivalence class. Sometimes it means turning a generated hypothesis into a test that can fail. The real gain is not more confident prose; it is fewer surviving explanations after the right observation or intervention.

THEME 07

Multimodal And Embodied Models

Multiple channels help only when the model uses the right channel for the right part of the claim.

The hidden object in multimodal work is shared state: what in the world, body, video, brain signal, sound, or image caused the answer? Text can often guess the answer without looking, and large context can carry many tokens that do not matter. The mathematical question is credit assignment across evidence channels under a budget.

The reason these methods work is that they protect the route from observation to decision. Visual swaps ask whether the answer changes when the visual evidence changes. Token bottlenecks ask which pieces are sufficient for the future decision. Latent interfaces ask what common state can be shared without erasing each modality's native structure. Embodied methods ask whether an action stays feasible under contact, kinematics, and hierarchy. A multimodal model is grounded only where interventions on the relevant evidence channel change the output in the way the claim requires.

BIG PICTURE

What The Map Adds

The subthemes show that the atlas is not a list of isolated papers. Each subtheme is a transformation problem with a preserved quantity: a trace must preserve task information, a benchmark must preserve measurement validity, a dataset must preserve useful gradient movement, a generator must preserve native-state validity, a theorem must preserve assumptions under deployment, a causal method must preserve identification boundaries, and a multimodal system must preserve evidence credit.

That is the practical first-principles reading of the conferences: before asking which method wins, ask which object the paper protects while the system changes.
