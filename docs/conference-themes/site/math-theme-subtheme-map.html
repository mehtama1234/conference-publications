FIRST PRINCIPLE

A Theme Is A Repeated Mathematical Problem

The theme names are not labels for topic areas. They are repeated failure patterns. Reasoning is about preserving task information through a trace. Evaluation is about measuring a hidden target through a noisy channel. Data is about moving parameters with evidence at the right time. Generation is about sampling in the right native state space. Theory is about naming the budget or threshold. Causality is about what evidence identifies. Multimodal work is about assigning credit across channels.

The map below keeps each subtheme in the same shape: problem, mathematical object, approach, representative papers, and cross-theme connection.

BIG PICTURE

What The Map Adds

The subthemes show that the atlas is not a list of isolated papers. Each subtheme is a transformation problem with a preserved quantity: a trace must preserve task information, a benchmark must preserve measurement validity, a dataset must preserve useful gradient movement, a generator must preserve native-state validity, a theorem must preserve assumptions under deployment, a causal method must preserve identification boundaries, and a multimodal system must preserve evidence credit.

That is the practical first-principles reading of the conferences: before asking which method wins, ask which object the paper protects while the system changes.
