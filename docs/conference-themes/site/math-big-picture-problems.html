FIRST PRINCIPLE

The Shared Problem Is Controlled Generalization

Across the conferences, the same mathematical demand keeps returning: make a system change behavior in the right direction while preserving the properties that matter. The system may be a language model, agent loop, diffusion sampler, robot, benchmark, optimizer, causal estimator, or protein generator. The problem is not just prediction. It is controlled generalization under missing state, finite samples, limited compute, strategic pressure, and imperfect measurement.

That is why the papers connect. They choose an object to protect, such as state sufficiency, measurement validity, feasible movement, support coverage, spectral signal, causal identification, or verifier soundness. Then they design an approach that makes that object easier to preserve.

PROBLEMS

Twelve First-Principles Problem Families

01 reasoning

How do we know a model is reasoning rather than replaying a pattern?

Object. A task-conditioned trace: intermediate states must depend on the input and carry information useful for later steps.

Approaches. Trace diagnostics, latent effort signals, horizon curricula, activation steering, and executable verification.

useful trace if I(trace; task) remains high while answer quality improves

Papers. RAGEN-2, Tell-Tale Norm, Steer Like The LLM, h1, Thinking in Flow, TRACE Effort, CyberGym.

Why it works. Reasoning fails when the trace becomes a template. Measuring task dependence turns hidden process quality into an auditable variable.

Failure check. Perturb the task while holding style constant; the trace should change for task reasons, not only length or format reasons.

02 agents

How should an AI system spend action, memory, and tool calls?

Object. A sequential decision state containing observations, tool results, memory, costs, and verifier feedback.

Approaches. State lifting, reusable skills, Pareto tool policies, multi-agent role optimization, executable environments.

choose action a when expected value of information exceeds action cost

Papers. Skill-Pro, ParetoPO, OMAC, ThunderAgent, CyberGym, tau2-bench, ToolRL families.

Why it works. Tool use is useful only when it changes the posterior or feasible action set enough to justify its cost.

Failure check. Measure correctness and cost jointly; extra actions should improve frontier position, not only create longer traces.

03 evaluation

How do we measure capabilities without training systems to exploit the measurement?

Object. A measurement channel with target signal, noise, bias, and gaming pressure.

Approaches. Domain-specific judges, executable tests, benchmark reliability audits, artifact-native scoring, uncertainty intervals.

observed score = true capability + bias + noise + adaptation effect

Papers. ATLAS, JudgeBench, WebDevJudge, PaperBench, UFEval, Micro-Benchmarking Reliability, OmniVerifier.

Why it works. A benchmark becomes useful when it estimates the target property with known error rather than rewarding surface correlates.

Failure check. Optimize against the metric and audit whether target behavior or only metric-facing behavior improved.

04 safety

How do we make safety claims about rare, adaptive, or boundary failures?

Object. Tail event, feasible safety set, pressure boundary, and preference frontier.

Approaches. Rare-event sampling, constrained policy optimization, adversarial stress tests, unlearning indistinguishability, Pareto safety reporting.

safety claim needs P(bad event) and distance to boundary, not just mean score

Papers. Rare Event Analysis, Tail Risks, CSPO, Jailbreak Foundry, SandboxEscapeBench, RLVepsR, SafeDPO, VALUEFLOW.

Why it works. Average performance hides the exact events safety cares about. Tail and boundary methods put probability mass where failure lives.

Failure check. Report tail confidence, adaptive attacks, false refusals, and unsafe acceptances at the boundary.

05 data

When does data actually change what the model can do?

Object. Training path, gradient direction, data value, and distribution bridge.

Approaches. Midtraining bridges, data valuation, gradient alignment, synthetic coverage repair, curriculum timing.

data value at time t depends on gradient alignment with the target path

Papers. Midtraining Bridges, DiReCT, OpenThoughts, BLL-Loss, LALP, Sequential Data Values, NASH.

Why it works. Data is not inert fuel. It changes parameters through the optimizer at a particular time, so timing and alignment determine usefulness.

Failure check. Compare phase ablations and measure whether the same data helps, does nothing, or damages general capability at different times.

06 systems

How can we compress models without changing the function people rely on?

Object. Approximation map, finite arithmetic, sufficient memory, and behavior drift.

Approaches. Quantization, pruning, cache selection, low-rank movement, hardware-aware kernels, repetition repair.

compression works if task behavior remains stable under approximate map q(f)

Papers. ThinKV, STAR-KV, EntroKV, LiftQuant, TetraJet, Error Propagation in Quantized Diffusion, FOCUS, RePAIR.

Why it works. A smaller representation is acceptable only if it preserves the future-relevant information and numerical path that behavior depends on.

Failure check. Test rare-memory retention, repetition loops, hardware arithmetic sensitivity, and path-level error accumulation.

07 generation

How do generative models move probability mass without losing important modes?

Object. Transport path from source noise or base distribution to target structured distribution.

Approaches. Diffusion paths, bridges, reward-tilted sampling, quotient spaces, safety-guided flows.

p0 -> p1 through p_t while preserving support and controlling local error

Papers. Quotient-Space Diffusion, Safety-Guided Flow, DMPO, FALCON, Cauchy Bridges, SRMC, Stable Video Infinity.

Why it works. Local path control turns hard global generation into smaller steps, but only if support and constraints survive the path.

Failure check. Measure mode recall, guidance bias, rare-region coverage, and accumulated sampler error.

08 physical science

What representation makes physical or biological structure learnable?

Object. Native coordinates, symmetry class, molecular route, fixed-point field, or hierarchical biological state.

Approaches. Equivariant or quotient representations, feasibility-constrained generation, neural operators, iterative residual correction.

choose coordinates where valid local moves preserve the object

Papers. IRNO, ReaSyn, MORetro*, protein autoregressive modeling, DeCoDe, Chamaileon, Complexa, RealPDEBench.

Why it works. Scientific objects have structure before the model sees data. Encoding that structure reduces impossible moves and makes useful neighborhoods smoother.

Failure check. Test whether the representation preserves real constraints rather than only improving in-distribution visual or sequence plausibility.

09 theory

Which hidden mathematical quantity explains an empirical trick?

Object. Spectrum, curvature, algorithmic circuit, sample complexity, finite-test certificate, or minimax risk.

Approaches. Spectral analysis, optimizer geometry, constructive circuits, lower bounds, finite-sample certification.

performance depends on recoverable directions, curvature, and evidence size

Papers. Alignment-Sensitive Minimax Rates, Transformer Circuits, Adam Degeneracy, Finite Test Certification, Single-Head Attention, Language Generation in the Limit.

Why it works. Theory helps when it names the smaller quantity controlling the phenomenon: alignment, curvature, circuit primitive, or sample barrier.

Failure check. Verify the named quantity predicts behavior outside the examples used to discover it.

10 causality

What can the evidence identify, and what is still assumption?

Object. Identified effect, equivalence class, intervention target, adjustment set, or temporal mechanism.

Approaches. Conditional independence, instruments, local covariate selection, counterfactual policies, hypothesis tests.

claim is identified if all data-compatible worlds agree on the target

Papers. Distributional Equivalence, Local Covariate Selection, Structure Learning CI, DiCoLa, TRECA, Fair Causal Bandits, Neural Effect Search.

Why it works. Causal methods work by separating what observations determine from what assumptions add.

Failure check. Return equivalence classes or assumption-labeled claims when the data do not choose one mechanism.

11 multimodal

How do we know which modality caused the answer?

Object. Modality-specific causal route, bottleneck, latent interface, and channel credit assignment.

Approaches. Modality swaps, route ablations, missing-channel calibration, token bottlenecks, brain or physiological latent interfaces.

channel m earns credit if intervening on m changes output under controls

Papers. VISUALSWAP, MINT, MoCA, Causal Route Gating, LIMSSR, Mind-Omni, PRISM, VideoKR.

Why it works. Attribution requires intervention. Attention or saliency alone can show where a model looked, not which channel caused the decision.

Failure check. Swap the visual, audio, text, or physiological evidence while holding shortcuts fixed.

12 deployment

When does a mathematical guarantee survive contact with the actual system?

Object. Theorem assumptions plus statistical sampling and machine-level implementation assumptions.

Approaches. Theorem-to-deployment audits, hardware traces, finite-test confidence, verifier scope statements, artifact certificates.

guarantee transfers only if math, data, and machine assumptions all hold

Papers. Floating-Point Neural Networks, QAT Scaling, TileLang, finite-test certification, VERINA, PaperBench, Theorem-to-deployment families.

Why it works. A theorem can be true in the formal model and false for the deployed artifact if arithmetic, data, or verifier assumptions changed.

Failure check. State every assumption layer separately and test the one most likely to break in the real system.

The Next Paper Expansion Rule

For any remaining paper, write the entry by first choosing one of these problems. Then name the mathematical object, the approach pattern, the reason the move should work, the assumption that makes the reason valid, and the failure check. That keeps the atlas centered on first principles instead of conference taxonomy.
