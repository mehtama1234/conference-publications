FIRST PRINCIPLE

An Approach Is A Controlled Change

A paper's method usually changes one of five things: the state the model can condition on, the geometry in which movement is allowed, the distribution used for evidence, the verifier used to measure success, or the representation in which the object becomes simpler. The mathematical question is always the same: what changes, what stays fixed, and why should the changed object be closer to the target?

This is why superficially different papers can share one argument. A robot policy, a reasoning trace, a causal graph, a diffusion sampler, a quantized network, and a benchmark judge all become easier to compare once the method is written as a controlled transformation with an invariant, a loss, and a failure boundary.

PATTERNS

Twenty Reusable Method Moves

state

Lift the state until the decision is Markov enough

Problem. The model is asked to act from an observation that hides variables needed for the next step.

Approach. Add traces, memory, tool output, video evidence, robot subgoals, or latent thought state until the next decision can be approximated from the current state.

Need: P(next | history, action) ~= P(next | state, action)

Why it works. Once the state contains the relevant past, the policy does not need to infer missing causes from surface correlation. RAGEN-2, Skill-Pro, HDFlow, VideoKR, EntroKV, ThinkV, and Mamba Markov ICL all use this move in different forms.

measurement

Turn vague success into an instrumented channel

Problem. A natural-language score or benchmark label is too thin to identify the actual property being claimed.

Approach. Build judges, executable tests, rubrics, process traces, disagreement audits, or artifact-native checks.

Observed score = target signal + bias + noise + gaming pressure

Why it works. Measurement improves when the observed variable has less bias and lower variance relative to the target. ATLAS, JudgeBench, OmniVerifier, WebDevJudge, PaperBench, TRACE Effort, and CyberGym are measurement-channel papers before they are benchmark papers.

constraint

Replace penalty hope with feasible-set movement

Problem. Penalizing invalid outputs after generation does not stop the search from spending mass outside the valid region.

Approach. Define constraints, project onto a valid set, decode only legal objects, or optimize with explicit safety and route conditions.

choose x in C to optimize utility, not choose x anywhere and regret violations

Why it works. If the true answer must lie in C, searching outside C wastes probability and can create false confidence. CSPO, Pi-net, ReaSyn, MORetro*, PACT, Fair OT, SafeDPO, and constrained Nash work through this geometry.

distribution

Change the evidence distribution, not only the model

Problem. Training or evaluation samples come from the wrong regions of the space.

Approach. Reweight, curate, stress-sample, bridge curricula, use rare-event proposals, or generate synthetic coverage for missing cases.

risk_target(f) = E_target loss(f,x), but data arrive from source

Why it works. A learner can only reduce error where it receives usable evidence. Midtraining Bridges, DiReCT, Rare Event Analysis, Tail Risks, SRMC, Data Shapley variants, and synthetic data papers change the distribution so gradients and estimates point at the real target.

geometry

Move in the geometry that governs damage

Problem. A small Euclidean update can be large in the directions that change loss, safety, or capability.

Approach. Use trust regions, curvature-aware selection, natural gradients, low-rank adapters, optimizer geometry, or merge constraints.

harm ~= delta^T H delta, not only ||delta||^2

Why it works. The relevant size of a move depends on curvature and representation. DiReCT, Adam degeneracy work, LoRA theory, RAIN-Merging, Beyond Muon, trust-region RL, and LR decay papers all ask which directions are stiff and which are flat.

quotient

Divide out nuisance coordinates

Problem. The data contain changes that alter encoding but not the object.

Approach. Work in an invariant or equivariant representation: quotient spaces, graph relabeling, camera-aware coordinates, molecular symmetries, or canonical routes.

model object on X/G when transformations in G should not change the target

Why it works. Removing fake degrees of freedom reduces sample complexity and prevents the model from memorizing accidents. Quotient-Space Diffusion, GraphGlue, Camera-Aware MLLMs, protein design, molecular routes, and robotics coordinate papers share this idea.

transport

Build a path between distributions

Problem. The model must generate or adapt from one distribution to another without losing support or accumulating error.

Approach. Learn flows, bridges, samplers, diffusion paths, reward-tilted distributions, or phase curricula.

move p0 to p1 through path p_t while controlling path error

Why it works. A path decomposes a hard global change into local changes whose error can be estimated. Diffusion papers, Cauchy Bridges, FALCON, DMPO, quantized diffusion, safety-guided flows, and midtraining papers all rely on path control.

tail

Estimate the event ordinary sampling will miss

Problem. The important failure has low probability under benign sampling but high consequence under deployment pressure.

Approach. Define the event, bias sampling toward it, estimate tail probability, and control estimator variance.

P(failure) = E[1{X in bad set}], but bad set is rarely sampled

Why it works. Risk is not the same as average score. Rare Event Analysis, Tail Risks, Jailbreak Foundry, SandboxEscapeBench, FlowGuard, SRMC, and security benchmarks become mathematical when they define the bad event and the sampling scheme.

spectrum

Find the directions where signal is visible

Problem. High-dimensional models contain many directions, but only some carry target signal rather than noise or memorized variation.

Approach. Study eigenvalues, singular vectors, low-rank logit structure, Jacobian spectra, kernel alignment, or phase transitions.

target is learnable when signal aligns with stable leading directions

Why it works. Spectra expose which directions can be recovered from finite data and which are noise. Alignment-Sensitive Minimax Rates, BBP transitions, low-rank LM logits, SVD interpretability, and Jacobian spectra papers use this lens.

identification

Return what the assumptions identify

Problem. Data can support a set of causal effects, graphs, routes, or mechanisms, not always one answer.

Approach. State intervention assumptions, conditional independences, instruments, equivalence classes, or local covariate sets.

claim is identifiable if all models matching observations give the same target

Why it works. Identification prevents the method from inventing specificity. Distributional Equivalence, Local Covariate Selection, Structure Learning CI, DiCoLa, BRCD, TRECA, and Fair Causal Bandits are strongest when they expose exactly what the evidence determines.

mechanism

Model the response of other actors

Problem. A policy, auction, benchmark, or multi-agent system changes the incentives of the agents inside it.

Approach. Write payoff functions, equilibrium conditions, truthful-report constraints, role assignments, or adversarial games.

chosen behavior is a response to incentives, not a fixed sample

Why it works. Strategic systems fail when the environment adapts. AdvGame, Accuracy Auctions, Data Market Pricing, OMAC, constrained Nash methods, and governance papers reason about fixed points of behavior under incentives.

latent control

Intervene where the model already represents the variable

Problem. Prompts and labels are indirect controls over internal mechanisms.

Approach. Locate activation directions, routes, norms, modality channels, or brain tokens, then intervene or decode there.

change behavior by moving latent z, while auditing side effects on other variables

Why it works. If a latent coordinate tracks the target mechanism, a direct intervention can be cleaner than more text. Steer Like The LLM, Tell-Tale Norm, MINT, Causal Route Gating, PRISM, Mind-Omni, and activation oracle papers use latent interfaces.

decomposition

Break an artifact into dependency-aware checks

Problem. Complex outputs such as papers, software, proofs, medical workflows, and web apps cannot be judged by one local score.

Approach. Represent the artifact as a graph of claims, code, citations, tests, files, or clinical steps.

valid artifact requires local correctness plus satisfied dependencies

Why it works. A dependency graph reveals failures hidden by local pass rates. PaperBench, Bitween, RefineStat, MedAgentGym, WebDevJudge, VERINA, and WZ-LLM all make the native artifact explicit.

approximation

Compress while preserving the function that matters

Problem. Memory, precision, or latency limits force an approximation of the model or context.

Approach. Quantize, prune, cache, route conditionally, distill, or select a compact sufficient memory.

approximation is acceptable when task loss and behavior drift stay bounded

Why it works. Compression is not about fewer bits alone; it is about preserving the function under deployment inputs. ThinKV, STAR-KV, EntroKV, LiftQuant, TetraJet, QAT scaling, FOCUS/RePAIR, and quantized diffusion expose this constraint.

frontier

Keep the tradeoff surface visible

Problem. A single objective hides conflicts among accuracy, cost, safety, privacy, fairness, and latency.

Approach. Estimate Pareto frontiers, constrained optima, subgroup curves, or threshold tradeoffs before choosing an operating point.

x is efficient if no objective improves without another worsening

Why it works. Many failures are not bugs but hidden tradeoffs. ParetoPO, SecFid, Catch-22, SafeDPO, VALUEFLOW, Fair OT, privacy tests, and low-bit deployment papers need frontier reporting.

certificate

Attach the claim to a checkable witness

Problem. A generated answer can look right without giving enough evidence to verify it.

Approach. Require executable tests, proofs, citations, trajectories, retrieved evidence, formal logs, or reproducible scripts.

claim is useful when verifier(claim, witness) accepts the thing that matters

Why it works. A witness moves trust from surface fluency to checkable structure. VERINA, PaperBench, WZ-LLM, OmniVerifier, Theorem-to-deployment papers, legal benchmarks, and scientific agents use certificates in different media.

curriculum

Choose when evidence enters the training path

Problem. The same data can help or fail depending on the model's current representation and plasticity.

Approach. Insert bridge data, lengthen horizons gradually, tune decay schedules, or select late data by gradient alignment.

effect of data depends on time: delta theta_t = optimizer(theta_t, batch_t)

Why it works. Training is a path, not a bag of examples. Midtraining Bridges, h1, OpenThoughts, LR decay, procedural pretraining, and DiReCT treat timing as part of the mathematical object.

modality

Assign credit to the channel that caused the answer

Problem. Multimodal systems can answer from text priors while appearing to use images, audio, video, or physiology.

Approach. Swap modalities, ablate routes, force missing-channel calibration, or test channel-specific counterfactuals.

credit channel m if intervention on m changes answer while controls do not

Why it works. Attribution needs intervention, not decoration. VISUALSWAP, MoCA, MINT, Causal Route Gating, Visual Attribution Streaming, LIMSSR, and brain-token papers need causal channel checks.

native structure

Use the object's native coordinates

Problem. Generic sequence prediction ignores physical, molecular, spatial, temporal, or relational structure.

Approach. Model constraints in coordinate systems, molecular hierarchy, robot action graphs, neural operators, or structured trajectories.

choose representation where valid local moves preserve object structure

Why it works. The right coordinates make invalid moves harder and useful neighborhoods smoother. IRNO, protein and molecule papers, Quotient-Space Diffusion, robot subgoal methods, Mind-Omni, and scientific surrogate models share this pattern.

uncertainty

Report uncertainty before ranking systems

Problem. Benchmarks, discoveries, and certificates are often built from too few samples for the claim being made.

Approach. Use confidence intervals, bootstrap checks, finite-test certification, held-out environments, or multiplicity control.

difference is meaningful only when estimation error is smaller than the claimed gap

Why it works. Finite samples can reverse rankings and produce false discoveries. Micro-Benchmarking Reliability, finite-test certification, ATLAS, UFEval, Neural Effect Search, and benchmark audit papers make uncertainty part of the result.

USE

How To Apply This To Each Paper

For every remaining paper card, the next expansion should name the approach pattern before adding prose. A useful entry says: this paper changes the state, geometry, distribution, verifier, representation, or feasible set; it preserves this property; it should work because this mathematical condition becomes easier; and it fails when this assumption breaks.

That keeps the atlas from becoming a catalog. The reader should see the common problem underneath the papers: how to make AI systems reason, generate, adapt, and verify under limited information, limited compute, strategic pressure, and imperfect measurements.
