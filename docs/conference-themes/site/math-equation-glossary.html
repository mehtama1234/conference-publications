READ FIRST

The Formula Is A Boundary

In this atlas, a formula usually says where a claim begins and ends. Read it like a rule on a work order: what is being changed, what must not change, what is allowed, what is being measured, and how much doubt remains.

A formula is useful only when the surrounding evidence checks the same promise. If a safety formula names an allowed region, the evidence must test that region. If a memory formula says the short notes are enough, the evidence must show that the missing history would not change the later decision.

FORM 01

Allowed Best Choice

The Best Answer Has To Be Allowed First

maximize reward(x) subject to x in C, or minimize cost(x) subject to g_k(x) <= 0

Plain read. Think of choosing dinner for someone with allergies: the tastiest recipe is irrelevant if it contains the forbidden ingredient. The formula says the system can improve the score only inside the allowed set C: legal actions, safe policies, chemically valid molecules, feasible robot motions, fair matches, or decisions that still work when facts are missing. Name used later: constrained objective, meaning a goal pursued only inside the allowed menu.

Papers

CSPO, Pi-net, Copyright-Bench, Fair OT, ReaSyn, MORetro*, Robust Contextual Optimization, PACT, HDFlow.

Why It Works

The system cannot win by finding a high-scoring forbidden answer and hoping a filter catches it later.

Evidence

Violation rate, distance to the boundary, tradeoff between score and validity, and stress tests near the forbidden line.

FORM 02

Next-Step Rule

Each Step Carries The Next Step's Evidence

state_{t+1} = F(state_t, action_t, observation_t, noise_t)

Plain read. A road trip depends on the current location, the next turn, what the driver sees, and random delays. Model work is similar. Reasoning traces, robot motions, world models, physical solvers, samplers, and agent workflows all depend on whether each step keeps enough information for the next one. Name used later: a state transition.

Papers

RAGEN-2, tau2-bench, HDFlow, IRNO, FlashWorld, VectorWorld, Mamba Markov ICL, Thinking in Flow.

Why It Works

Once the step rule is explicit, drift, stale memory, and leftover physical error become measurable instead of appearing as isolated mistakes.

Evidence

Remove one step, perturb the current state, run long horizons, measure leftover error, and check whether the final outcome changes.

FORM 03

Enough Notes

Short Memory Is Valid Only If The Decision Stays The Same

P(y | history_t) = P(y | s_t)

Plain read. A meeting summary can replace the full transcript only if it keeps every fact needed for the later decision y. The summary s_t is allowed to be shorter, but the answer should be the same as if the system had the full history. Name used later: sufficient statistic or sufficient state.

Papers

ThinKV, STAR-KV, EntroKV, DLMR, Skill-Pro, VideoKR, Mamba Markov ICL, Linear Recurrent Memory.

Why It Works

The method saves memory or compute without erasing the facts that would change the later answer.

Evidence

Compare full-history and short-note decisions, perturb rare evidence, and measure failures caused by dropped information.

FORM 04

Noisy Score

A Score Is A Reading, Not The Thing Itself

score = target signal + item noise + judge bias + shortcut artifact + omitted evidence

Plain read. A bathroom scale gives a reading of weight, but the reading can be distorted by a tilted floor or weak battery. A benchmark score is the same kind of instrument reading: it mixes the hidden target with item choice, judge behavior, shortcuts, and missing evidence. Name used later: a measurement channel.

Papers

ATLAS, FRABench, UFEval, JudgeBench, WebDevJudge, CounselBench, MADQA, Seizure-Semiology-Suite, Omni-Reward.

Why It Works

Better evaluation comes from exposing the noise and blind spots, not from pretending the score is the target.

Evidence

Doubt ranges, item information, expert agreement, rendered-artifact judging, component scores, and ranking stability.

FORM 05

Rare Bad Case

Ordinary Testing Can Miss The Case That Matters

P(E_bad) = E_Q[1{Y in E_bad} * p(Y) / q(Y)]

Plain read. Flood safety cannot be judged from sunny days. The formula says to test the dangerous region more often, then correct the count so the final risk still refers to real deployment. Q is the stress-test sampling rule; P is the real-world rate being estimated. Name used later: tail probability or importance sampling.

Papers

Rare Event Analysis, Tail Risks, Control Consistency Losses, SandboxEscapeBench, Jailbreak Foundry, FALCON, SRMC, FlowGuard.

Why It Works

It spends evaluation budget where failures can show up while keeping the final probability claim tied to deployment.

Evidence

Bad-event definitions, stress-test sensitivity, effective sample size, doubt ranges, and near-boundary examples.

FORM 06

Making Path

The Route Shapes The Final Output

p_t -> p_{t+1} by denoiser, vector field, bridge, proposal, or reward tilt

Plain read. Bread is shaped by kneading, rising, and baking, not only by the final minute in the oven. A generator is similar: the crowd of possible outputs is moved step by step. If the route loses rare possibilities, carries rounding error, or enters unsafe regions, the final artifact inherits that failure. Name used later: transport path, flow, bridge, or sampler path.

Papers

DMPO, FALCON, Safety-Guided Flow, Cauchy Bridges, GWF, MMOT/Schrodinger Bridges, Quantized Diffusion, FIDIA.

Why It Works

Controlling the intermediate route protects diversity, safety, likelihood, and accumulated numerical error more directly than endpoint filtering.

Evidence

Mode recall, likelihood calibration, path stability, guidance bias, and accumulated error across steps.

FORM 07

Visible Direction

The Pattern Must Be Clear Enough To Recover

recover signal when leading singular/eigen direction separates from the noise bulk

Plain read. In a noisy room, the melody is usable only if it stands out from the background. High-dimensional model numbers also have many directions. A direction is useful when it is stable enough to estimate and actually carries the target pattern. What must stay the same is the real signal. What may change is the sample noise around it. Names used later: spectral gap for the visible separation from noise, singular direction for a strong pattern in a rectangular table, and eigen direction for a strong pattern that repeats under the same transformation.

Papers

Alignment-Sensitive Minimax Rates, Single-Head Attention, BBP Transitions, Low-Rank LM Logits, SVD Interpretability, Jacobian Spectra.

Why It Works

Limited data recovers clear directions more reliably. If the target aligns with those directions, the model needs less evidence.

Evidence

Visible gaps, resampling stability, target alignment, perturbation tests, and sample-size scaling.

FORM 08

Movement Ruler

A Training Step Is Safe Only Under The Right Ruler

theta_{t+1} = theta_t - eta * M_t^{-1} g_t, with the step judged by local steepness, optimizer scaling, or a stay-nearby limit

Plain read. One step on flat ground and one step near a cliff are not equally safe. A training push has the same issue: its raw size does not tell us what it will damage. The movement ruler decides which directions are cheap, steep, protected, rounded by hardware, or likely to break behavior. What must stay the same is the behavior the update should preserve. What may change is the ruler used to choose and judge the step. Names used later: update geometry for the shape of allowed movement, metric for the ruler, Hessian for the map of where small pushes change loss sharply, preconditioner for a ruler-changing helper, and KL radius for a stay-nearby limit on behavior.

Papers

Adam Degeneracy, DiReCT, LoRA Theory, Trust-Region LLM RL, Beyond Muon, Non-Euclidean Edge of Stability, RAIN-Merging.

Why It Works

The method permits useful movement while avoiding directions where small changes create large damage.

Evidence

Steepness energy, projected update loss, stay-nearby violations, optimizer ablations, and off-target capability audits.

FORM 09

Small Change Family

Adaptation Works If The Needed Change Is Not Arbitrary

Delta W = A B, rank(Delta W) <= r

Plain read. Adding a new skill may not require changing every knob in the model. It may fit inside a small family of allowed changes, like adjusting only the bass and treble instead of rebuilding a whole stereo. Name used later: low-rank movement or a low-rank update.

Papers

LoRA Theory, FlexRank, RAIN-Merging, Low-Rank LM Logits, COMPACT, LiME, MetaEmbed.

Why It Works

Restricting movement saves memory and reduces overfitting when the task signal is concentrated in a few directions.

Evidence

Energy by allowed direction, projection loss, adapter direction alignment, and performance as the allowed family grows.

FORM 10

Same Object Group

Different Wrappers Should Not Create Fake Objects

[x] = {g x : g in G}; learn p([x]) rather than p(x)

Plain read. The bracket [x] means "the same object after ignoring wrapper changes." The model should not treat every rotated molecule, relabeled graph, or changed camera view as a new object when the task answer should stay the same. Name used later: quotient space or equivalence class, meaning the bundle of wrapper-changed copies that count as one real object.

Papers

Quotient-Space Diffusion, Camera-Aware MLLM, GraphGlue, protein generation, TideGS, RadioGS.

Why It Works

It removes fake choices before learning, so capacity is spent on the real object.

Evidence

Same-object tests, equivalent-input consistency, and downstream validity under transformed coordinates.

FORM 11

Evidence-Limited Claim

Do Not Pick One Story When Several Still Fit

c is identified if c(w) is constant for all w in W(data, assumptions)

Plain read. A wet floor could come from a leak, a spill, or an open window. W is the set of stories still consistent with the evidence and assumptions. A cause claim is justified only when the claim c is the same across all those stories. Name used later: identification.

Papers

Distributional Equivalence, Local Covariate Selection, Structure Learning CI, DiCoLa, Unpaired Causal IV, BRCD, CausalGame.

Why It Works

The method refuses to claim what the evidence cannot separate.

Evidence

Still-possible story sets, valid matching variables, calibrated independence tests, intervention stress tests, and explicit "not enough evidence" cases.

FORM 12

Checkable Artifact

The Claim Has To Survive A Separate Check

V(artifact, assumptions, observation channel) -> pass, fail, score, or uncertainty

Plain read. A receipt is more checkable than "trust me, I paid." V is the separate checking procedure. It may execute code, render a page, check a proof, inspect a visual outcome, or test whether two training histories are hard to tell apart. Name used later: verifier or certificate.

Papers

CyberGym, VERINA, WZ-LLM, PaperBench, WebDevJudge, OmniVerifier, Gaussian Certified Unlearning, Finite Test Certification.

Why It Works

Correctness is harder to fake because the claim must survive a procedure outside the generator's text.

Evidence

Checker scope, false positives, execution logs, formal checker failures, reproduction success, and what an adversary can still see.

FORM 13

Reacting Actors

A Rule Changes The People Or Agents Under It

agent i chooses policy pi_i with payoff u_i(pi_1,...,pi_n), constraints, and information

Plain read. A store policy changes customer behavior. Model rules do the same: attackers adapt, users report private values, data sellers respond to prices, and agents change one another's information. The formula names each actor's rule, payoff, constraints, and information. Name used later: game for a setting where actors react to one another, or mechanism for the rule that shapes what those actors have reason to do.

Papers

AdvGame, OMAC, Accuracy Auctions, Data Market Pricing, Constrained Nash, Fair Causal Bandits, MASPOB, Value of Variance.

Why It Works

The model includes response and incentives inside the problem instead of treating them as background noise.

Evidence

Adaptive attacks, truthful reporting, stable response distance, convergence time, and payoff-sensitivity tests.

FORM 14

Visible Tradeoff

A Single Score Can Hide What Was Paid

frontier = {(a,b): no feasible solution improves a without worsening b}

Plain read. If a phone gets longer battery life by becoming too heavy to carry, the improvement is not free. The formula marks the boundary where one goal cannot improve unless another worsens: accuracy versus tool cost, safety versus helpfulness, security versus fidelity, compression versus quality, or detection power versus false alarms. Name used later: a tradeoff frontier or Pareto frontier.

Papers

ParetoPO, SecFid, Catch-22, SafeDPO, VALUEFLOW, Accuracy Auctions, Fair OT, LiftQuant, FlexRank.

Why It Works

It prevents hidden losses from being averaged away. The reader can see what was paid to improve the reported score.

Evidence

Tradeoff curves, sensitivity to weights, subgroup tradeoffs, false-positive costs, and examples where single-score rankings reverse.

BIG PICTURE

How To Read The Equations

When a formula appears in the atlas, ask what it protects. An allowed-choice formula protects validity. A next-step rule protects history. An enough-notes formula protects memory. A noisy-score formula protects meaning. A rare-case formula protects deployment risk. A making-path formula protects how the output forms. A checkable-artifact formula protects the claim from fluent imitation.

That is the connecting tissue across the conferences: the equations name what must survive while the system reasons, learns, compresses, samples, acts, or gets evaluated.
