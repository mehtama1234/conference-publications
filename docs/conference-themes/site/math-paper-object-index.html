GROUP 17

Causal Identification Evidence Examples

These rows expand the causal lookup entries into the evidence question: what would have to be observed, assumed, or stress-tested before the paper's mathematical object earns trust?

Effect And Policy Certificates

Local Covariate Selection
local adjustment certificate
The object works because the target effect is a functional of a smaller variable set once the wrong backdoor paths are blocked. The mathematical test is not whether the full DAG is correct; it is whether every graph still compatible with the local assumptions gives the same adjusted effect.
Evidence example: perturb the candidate adjustment set, run negative controls, and report when alternate admissible adjustment sets change the estimated effect. Lane detail
TRECA
responder decision with abstention
The method works by adding a third action to causal classification: do not decide when the treatment-response contrast is not stable enough. Mathematically, abstention protects against acting on an unidentified counterfactual sign.
Evidence example: show coverage-risk curves where the accepted cases keep low treatment-response error while abstained cases concentrate near weak or assumption-sensitive effects. Lane detail
Unpaired Causal IV
instrumental variation across environments
The approach works when environment variation shifts treatment-relevant signal without directly shifting the outcome except through the treatment path. The environment index becomes a source of identification rather than a nuisance label.
Evidence example: test instrument strength and exclusion sensitivity across environments, especially whether environment changes predict outcomes after conditioning on the proposed treatment path. Lane detail
Fair Causal Bandits
reward under counterfactual fairness constraint
The bandit objective works only if fairness is represented as a causal condition on actions, not an observed group parity statistic. Exploration is mathematically safe when high-reward actions stay inside the counterfactual legitimacy set.
Evidence example: audit regret and counterfactual violation jointly under misspecified fairness graphs, missing protected variables, and delayed reward. Lane detail

Graph, Root-Cause, And Temporal Evidence

Structure Learning CI
conditional-independence evidence
The graph learner works through the reliability of the independence oracle. If the CI tests are underpowered or miscalibrated, graph search simply organizes bad evidence into a neat diagram.
Evidence example: report CI calibration under sample-size sweeps and show how graph edges change when marginal, conditional, and near-null dependencies are stressed. Lane detail
Distributional Equivalence
graph equivalence class
It works by making non-identifiability explicit. When latent variables or cycles let many structures create the same observed distribution, the correct mathematical output is the class of indistinguishable graphs.
Evidence example: compare returned classes across synthetic graphs with known latent structure and verify that the true graph remains inside the class while unsupported edges are not falsely singled out. Lane detail
BRCD
posterior over root causes
The method works because production diagnosis is a ranking over interventions under graph uncertainty. It is not enough to find a variable that looks abnormal; the candidate must be one whose intervention would reduce the incident probability.
Evidence example: replay incidents with injected causes, measure posterior calibration, and compare the top-ranked cause to intervention outcomes rather than anomaly magnitude. Lane detail
Latent Hawkes / OU Identifiability / Power-Law Discovery
recoverable temporal mechanism
These methods work when time-series statistics preserve the mechanism: triggering paths, drift moments, or stable scale features. Temporal order helps only after hidden processes, aliasing, and nonstationarity are controlled.
Evidence example: run time-scale sweeps, stationarity checks, intervention-moment tests, and latent-process simulations that separate causal triggering from lagged prediction. Lane detail
GROUP 18

Scientific Hypothesis Evidence Examples

These rows expand the scientific-workflow entries into the rejection channel. The shared problem is that a model can generate a good explanation without generating evidence that could make the explanation less believable.

Hypotheses As Testable Objects

Neural Effect Search
learned feature as causal hypothesis
The method works when a representation feature is converted from an interpretation into a treatment contrast. The mathematical move is randomized evidence plus multiplicity control after searching many possible features.
Evidence example: preregister candidate feature groups, randomize interventions or comparisons, correct for feature-search multiplicity, and report null features that fail. Lane detail
HypoSpace
hypothesis space coverage
It works by evaluating discovery as sampling over a space, not as one final answer. A model is better when it covers valid alternatives, avoids duplicates, and recovers hidden target hypotheses under controlled tasks.
Evidence example: measure coverage, uniqueness, and recovery separately; inspect whether added model scale increases new hypotheses or just paraphrases. Lane detail
Consequence-Based Utility
evidence through downstream consequences
The approach works when direct verification is hard but the claim has consequences that are easier to check. Utility becomes the expected information gain produced by downstream tasks, not the surface impressiveness of the claim.
Evidence example: define consequence tasks before generation and test whether proposed claims improve held-out verifiable work compared with matched plausible but false claims. Lane detail
Bitween
verified randomized reduction
Generated reductions matter only when they preserve problem structure across instances. The mathematical object is the reusable reduction, not the text describing it.
Evidence example: verify the reduction on held-out instance families, test failure modes under adversarial inputs, and separate generated candidates from independently checked reductions. Lane detail

Workflows As Checkable Artifacts

RefineStat
probabilistic-program semantic repair
The method works because statistical programs have local semantic constraints: distributions must match support, parameters must be valid, and diagnostics must reveal model-data mismatch. Repair is useful only when the verifier names the statistical violation.
Evidence example: log before/after semantic failures, posterior predictive diagnostics, and cases where syntax-valid programs are rejected for statistical reasons. Lane detail
MedAgentGym
biomedical environment transition
It works by turning biomedical reasoning into actions over data, tools, and feedback. The agent's claim is tested by the state it produces in an executable workflow.
Evidence example: evaluate complete trajectories on held-out biomedical tasks, including code execution logs, data-cleaning choices, clinical target checks, and expert review of failure cases. Lane detail
PaperBench And AI Scientist Workflows
coherent research artifact
A research contribution is a coupled object: question, method, experiment, code, figure, limitation, and claim. The benchmark works when those pieces can be checked for consistency, not when a paper-like document sounds fluent.
Evidence example: score artifact components separately, then test whether the final claim is supported by the produced code and experiments rather than by prose alone. Lane detail
WZ-LLM And VERINA
formal proof artifact
These methods work because proof validity has an external acceptance rule. The proof checker defines the admissible set; language fluency has no authority outside that set.
Evidence example: report proof-kernel acceptance, rejected-step categories, theorem-statement alignment, and cases where natural-language explanations are persuasive but formally invalid. Lane detail
GROUP 19

Multimodal Evidence-Route Examples

These rows expand the multimodal lookup entries into a causal evidence question: did the relevant image, video, speech, brain, tactile, or memory channel actually change the answer?

Which Channel Controlled The Output?

MoCA
perception-reasoning-fusion credit
The method works when failure can be decomposed into the component that lost the needed state. A single reward is too coarse: perception, cognition, and fusion need different repairs.
Evidence example: perturb visual evidence, reasoning state, and fusion routing separately, then verify that the assigned module is the one whose correction changes the answer. Lane detail
VGS And VISUALSWAP
visual counterfactual dependence
Grounding works mathematically when the output is sensitive to the visual fact and insensitive to irrelevant style or language-prior changes. Counterfactual pairs turn grounding from a claim into an intervention test.
Evidence example: hold the text prompt fixed, swap the decisive visual feature, and measure whether the answer moves only with the intended visual variable. Lane detail
Causal Route Gating
internal visual-versus-text route contribution
The approach works if a route through attention heads or fusion layers is causally responsible for unsupported text-prior behavior. Suppression helps only when the route is a cause, not a correlate.
Evidence example: ablate or gate the named route, keep the visual input fixed, and show hallucination falls without destroying visually supported answers. Lane detail
MINT
fusion-band hidden-state intervention
Hidden-state patching works when the patched state lies on the path by which visual evidence enters language generation. The test is causal: replace the internal variable and observe output movement.
Evidence example: patch fusion-band states from matched visual contexts, test natural-activation constraints, and compare output movement against random or off-manifold patches. Lane detail

Measurement Channels And Latent Interfaces

PRISM And Mind-Omni
brain-signal interface variable
These methods work because fMRI is an indirect, noisy, delayed measurement. The intermediate token or object-attribute-relation code separates estimating the latent concept from generating images or text.
Evidence example: evaluate reconstruction and cross-modal retrieval under subject holdout, timing perturbation, uncertainty calibration, and ablations that remove the intermediate code. Lane detail
EgoTactile
contact-state observation channel
Touch helps because it observes hidden variables that pixels project away: pressure, slip, grip, and force transfer. It is not an extra modality by volume; it is a new measurement operator.
Evidence example: compare visually identical manipulation states with different contact outcomes, then test whether tactile calibration and synchronization determine policy success. Lane detail
LatentLM And UALM
shared latent protocol
A shared interface works when it keeps the sufficient state needed for each native decoder while making cross-modal control possible. It fails if the code collapses timing, geometry, texture, or acoustic detail into generic semantics.
Evidence example: test round-trip reconstruction, cross-modal editing, modality-specific detail retention, and whether the same latent supports reasoning without degrading native media quality. Lane detail
TideGS And RadioGS
renderable field basis
Gaussian primitives work when a continuous signal can be approximated by local basis functions that still obey the measurement geometry of rendering, radiance, or propagation.
Evidence example: stress field reconstruction under new views, boundary conditions, occlusions, propagation regimes, and sensor placements outside the training distribution. Lane detail
GROUP 20

Multimodal State, Token, And Embodiment Examples

These rows focus on sufficiency: after compression, memory routing, or action abstraction, does the retained state still contain the variable needed for the next decision?

Video Tokens And Memory Provenance

FlashVID
spatiotemporal merge map
The merge works when removed tokens are conditionally redundant for the task. The mathematical object is not a smaller video; it is a compressed state that preserves event boundaries and answer-changing motion.
Evidence example: evaluate rare short events, long-range references, motion cues, and query-conditioned tasks where uniform downsampling should fail. Lane detail
InfoTok And VideoFlexTok
adaptive token-value allocation
These methods work when token budget follows expected decision value. A token is worth keeping if removing it would change the future answer, action, or verifier judgment.
Evidence example: compare fixed and adaptive budgets under query shifts, event-density changes, and tasks where low-salience frames become decisive after the question is known. Lane detail
VideoKR
video event state linked to knowledge
The benchmark works when external knowledge must be grounded in a particular observed event. Otherwise the model can answer from prior knowledge without using the video.
Evidence example: require event localization, retrieve matched and distractor knowledge, and test whether answers change when the relevant video event is removed. Lane detail
DLMR
provenance-routed multimodal memory
The memory works when it preserves the difference between observed evidence and derived reasoning. This prevents a generated summary from becoming false source evidence later.
Evidence example: audit memory writes, inject unsupported conclusions, and test whether later answers cite observation memory only when the source evidence exists. Lane detail

Embodied Action And Grounded Verification

MomaGraph
affordance graph
The graph works when objects, relations, and states correspond to manipulable possibilities. It should make action search smaller by removing physically meaningless transitions.
Evidence example: test stale-scene updates, object-state changes, relation errors, and whether graph perturbations change planned actions in predictable ways. Lane detail
HDFlow
hierarchical motion distribution
The hierarchy works by separating discrete intent ambiguity from continuous trajectory feasibility. High-level subgoals choose the coarse region; the low-level flow transports motion inside that constraint.
Evidence example: ablate subgoal quality and low-level flow quality separately, then show failures decompose into wrong intention versus infeasible motion. Lane detail
OmniVerifier
artifact-level visual verifier
The verifier works when it measures the produced artifact in the medium where the error appears. Text plausibility is not enough for visual generation; the output image or video must satisfy the constraint.
Evidence example: run iterative edits with visual-only failure cases, instruction conflicts, and verifier-noise tests to see whether corrections improve the artifact rather than the explanation. Lane detail
Seizure-Semiology-Suite
expert event-state labels
The benchmark works when labels name the clinical state that matters, not merely visible motion. The measurement target is the medically meaningful latent event.
Evidence example: compare expert agreement, clinical subevent localization, generic motion baselines, and failure cases where visual activity is high but diagnostic content is absent. Lane detail
