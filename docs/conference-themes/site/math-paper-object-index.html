Causal Identification Evidence Examples

These rows expand the causal lookup entries into the evidence question: what would have to be observed, assumed, or stress-tested before the paper's mathematical object earns trust?

Effect And Policy Certificates

Local Covariate Selection
local adjustment certificate
The object works because the target effect is a functional of a smaller variable set once the wrong backdoor paths are blocked. The mathematical test is not whether the full DAG is correct; it is whether every graph still compatible with the local assumptions gives the same adjusted effect.
Evidence example: perturb the candidate adjustment set, run negative controls, and report when alternate admissible adjustment sets change the estimated effect. Lane detail
TRECA
responder decision with abstention
The method works by adding a third action to causal classification: do not decide when the treatment-response contrast is not stable enough. Mathematically, abstention protects against acting on an unidentified counterfactual sign.
Evidence example: show coverage-risk curves where the accepted cases keep low treatment-response error while abstained cases concentrate near weak or assumption-sensitive effects. Lane detail
Unpaired Causal IV
instrumental variation across environments
The approach works when environment variation shifts treatment-relevant signal without directly shifting the outcome except through the treatment path. The environment index becomes a source of identification rather than a nuisance label.
Evidence example: test instrument strength and exclusion sensitivity across environments, especially whether environment changes predict outcomes after conditioning on the proposed treatment path. Lane detail
Fair Causal Bandits
reward under counterfactual fairness constraint
The bandit objective works only if fairness is represented as a causal condition on actions, not an observed group parity statistic. Exploration is mathematically safe when high-reward actions stay inside the counterfactual legitimacy set.
Evidence example: audit regret and counterfactual violation jointly under misspecified fairness graphs, missing protected variables, and delayed reward. Lane detail

Graph, Root-Cause, And Temporal Evidence

Structure Learning CI
conditional-independence evidence
The graph learner works through the reliability of the independence oracle. If the CI tests are underpowered or miscalibrated, graph search simply organizes bad evidence into a neat diagram.
Evidence example: report CI calibration under sample-size sweeps and show how graph edges change when marginal, conditional, and near-null dependencies are stressed. Lane detail
Distributional Equivalence
graph equivalence class
It works by making non-identifiability explicit. When latent variables or cycles let many structures create the same observed distribution, the correct mathematical output is the class of indistinguishable graphs.
Evidence example: compare returned classes across synthetic graphs with known latent structure and verify that the true graph remains inside the class while unsupported edges are not falsely singled out. Lane detail
BRCD
posterior over root causes
The method works because production diagnosis is a ranking over interventions under graph uncertainty. It is not enough to find a variable that looks abnormal; the candidate must be one whose intervention would reduce the incident probability.
Evidence example: replay incidents with injected causes, measure posterior calibration, and compare the top-ranked cause to intervention outcomes rather than anomaly magnitude. Lane detail
Latent Hawkes / OU Identifiability / Power-Law Discovery
recoverable temporal mechanism
These methods work when time-series statistics preserve the mechanism: triggering paths, drift moments, or stable scale features. Temporal order helps only after hidden processes, aliasing, and nonstationarity are controlled.
Evidence example: run time-scale sweeps, stationarity checks, intervention-moment tests, and latent-process simulations that separate causal triggering from lagged prediction. Lane detail

It works by evaluating discovery as sampling over a space, not as one final answer. A model is better when it covers valid alternatives, avoids duplicates, and recovers hidden target hypotheses under controlled tasks.

The approach works when direct verification is hard but the claim has consequences that are easier to check. Utility becomes the expected information gain produced by downstream tasks, not the surface impressiveness of the claim.

adaptive-coordinate optimizer geometry
The result works because Adam does not move in the same geometry as plain gradient descent. Gradient history rescales coordinates, so a direction that appears flat or degenerate under one metric can remain movable under another.

DiReCT

The method works when late examples move parameters through flat directions that improve validation while avoiding stiff directions where small movement causes brittle loss change. Data value is therefore a curvature-weighted update claim.
Evidence example: estimate validation-Hessian eigendirections, project candidate gradients, and verify that selected data improves target behavior without increasing stiff-direction loss sensitivity. Lane detail
LoRA Gradient Descent / LoRA-Pre

Low-rank adaptation works when the task-relevant update lies mostly in a small subspace and the factorized training path can still descend. The theorem matters because factorization changes the path, not just the parameter count.
Evidence example: compare full-rank update projections to LoRA subspaces, sweep rank, inspect factor imbalance, and test whether projected optimizer memory preserves useful momentum. Lane detail
Trust-Region LLM RL
bounded policy displacement
The trust region works when reward improvement inside a policy neighborhood preserves behavior that made the base model useful. The mathematical claim is about controlled movement, not reward maximization by itself.
Evidence example: track KL or equivalent policy distance, reward gain, retained capability, and failure emergence as the allowed region widens. Lane detail

Evidence example: test controlled problem families that vary hierarchy depth, graph degree, numeric precision, and out-of-distribution size to see where exact recovery breaks. Lane detail
Mamba Markov ICL And Linear Recurrent Memory
recurrent state as estimator
Recurrence works when its hidden state is a sufficient statistic for the source process or decision problem. The mathematical object is the estimator carried forward, not generic memory length.
Evidence example: generate controlled hidden Markov or partially observed environments, inspect whether recurrent state tracks the Bayes/minimax statistic, and ablate memory dimensions. Lane detail

Finite Evidence And Decision Certificates

Power Law Compositional Reasoning
skill-frequency sample-complexity curve
The result works because reusable components need to appear often enough for the learner to estimate them and combine them. Data volume matters through the frequency distribution of parts.
Evidence example: vary component frequencies, composition length, and held-out combinations, then check whether generalization follows the predicted power-law coverage. Lane detail
Finite Test Certification
sample-limited generality certificate
The theorem works by bounding what a finite environment set can certify under a distribution-family radius. It prevents a narrow benchmark from implying a broad deployment claim.
Evidence example: report confidence intervals and required test-set size for each claimed generalization family, not just observed benchmark success. Lane detail
Catch-22
watermark hypothesis-testing frontier
Watermarking works as a statistical test between watermarked and unwatermarked text. The tradeoff exists because making the signal robust and detectable also makes it harder to keep invisible.

QAT Scaling And WaterSIC
finite-precision preserved guarantee

GROUP 23

Data Systems Evidence Examples: Training Path And Provenance

These rows make the data/systems math concrete. A dataset matters through the movement it causes, the evidence it adds, the incentives behind its source, and the constraints that make its use auditable.

Examples As Training Interventions

LR Decay Wastes Your Best Data
optimizer-time data value
The paper works because an example's information is multiplied by the optimizer state. A high-quality example arriving after the learning rate has collapsed can produce almost no parameter movement.
Evidence example: replay the same high-value data at different training times, log gradient norms and effective step sizes, and measure retained downstream skill. Lane detail
Midtraining Bridges
distribution bridge over a parameter trajectory
The method works when specialized data reduces the jump from broad pretraining to narrow post-training while the model is still plastic. The bridge is a path object, not a final dataset label.
Evidence example: sweep insertion time and mixture weight, then evaluate target gains, retained broad capability, and whether later post-training needs less corrective movement. Lane detail
Sequential Data Values And NASH
conditional marginal contribution under decomposed utility
These methods work because data value is conditional on what has already been selected and on which utility component is being credited. Redundancy and complementarity are set properties.
Evidence example: compare independent scoring to sequential selection, report marginal utility decay, utility-component variance, and behavior changes when the selected set order is changed. Lane detail
OPUS
optimizer-shaped update utility
OPUS works when metadata is weaker than the parameter movement an example would induce. The mathematical object is the effective update projected toward a target behavior.
Evidence example: estimate candidate-example gradients, project them onto target and off-target directions, and verify that selected examples produce the intended model movement. Lane detail

Evidence Sources As Governed Objects

Common Corpus
auditable empirical distribution
The corpus works scientifically when origin, permission, filtering, language mix, and code mix are part of the sample definition. Provenance changes the distribution, not only the legal appendix.

Data Market Pricing And Bayesian Truthful Valuation
mechanism over non-rival information
The approach works when pricing rules align seller incentives with true evidence value. Data can be reused without being consumed, so ordinary commodity pricing misses the strategic structure.
Evidence example: test truthful reporting equilibria under simulated sellers, duplicated datasets, correlated sources, and buyers with different downstream utility. Lane detail
ATLAS Multilingual Transfer
language-to-language transfer matrix
The transfer matrix works when one language's data changes another language's performance predictably. Sampling should follow marginal cross-language benefit, not raw token availability.
Evidence example: ablate source languages, measure transfer asymmetry, and compare allocation based on token count versus estimated benefit matrix. Lane detail
Hubble / LM Memorization Capacity / LIMSSR / Synthetic Data Selection
observable leakage, missingness, and coverage structure
These papers work when hidden data conditions become measurable: sensitive insertions reveal memorization, masks preserve missingness, and synthetic selection targets missing covariance directions instead of volume.
Evidence example: run controlled canary insertion, missingness-pattern audits, covariance coverage tests, and held-out risk checks for generated examples. Lane detail
GROUP 24

Data Systems Evidence Examples: Serving State And Compression

These rows ask what survives when the model is served, compressed, cached, quantized, pruned, or scheduled. The mathematical issue is function preservation under physical limits.

Memory Movement And Agent Schedules

DHSA
attention schedule under memory traffic limits
The method works because long context is physically a memory-movement problem. Attention is usable only when the schedule keeps needed blocks reachable within hardware limits.
Evidence example: measure throughput, memory traffic, numerical agreement, and long-dependency accuracy as context length and hardware memory pressure increase. Lane detail
ThinKV / STAR-KV / EntroKV
retained cache as sufficient statistic
KV compression works when the retained state preserves the past information that still changes future tokens. Entropy and low-rank structure are useful only as proxies for future decision value.
Evidence example: test long-range retrieval, multi-hop dependencies, rare evidence retention, and output divergence against full-cache decoding under matched prompts. Lane detail
ThunderAgent And Speculative Actions
stateful workflow schedule with verifier acceptance
Speculation works when likely future actions can be prepared without committing unsafe side effects, and a verifier can reject the wrong branch before it affects the environment.
Evidence example: measure wall-clock gain, branch acceptance rate, side-effect isolation, stale-state failures, and verifier rejection accuracy in tool-heavy tasks. Lane detail
TileLang And einx
explicit tensor and kernel layout semantics
These tools work because shape, layout, tiling, and vectorization are part of the computation. Making them explicit reduces both performance bugs and silent semantic mistakes.
Evidence example: compare generated kernels against reference outputs, inspect shape invariants, and profile whether the declared data movement matches actual memory behavior. Lane detail

Approximation Maps And Behavior Preservation

LiftQuant
quasi-continuous precision map
The method works when lifted binary codes create a finer approximation family than integer bit widths. Precision becomes a tunable geometry rather than a few discrete choices.
Evidence example: sweep memory budgets and lifted-code settings, then measure outlier-channel error, perplexity, reasoning tasks, and deployment latency jointly. Lane detail
TetraJet-v2
structured low-precision error dynamics
Low-precision training works when error modes such as oscillation, bias, and outlier-channel damage are modeled and controlled. Treating quantization noise as harmless independent noise is too weak.
Evidence example: log quantization residuals over training, isolate outlier channels, test reset schedules, and compare long-horizon stability to higher-precision baselines. Lane detail
FOCUS And RePAIR
pruning-induced token-loop dynamics
These methods work because pruning can change the transition system of generation. A model may keep average accuracy while increasing entry into repetition loops or reducing escape probability.
Evidence example: measure loop-entry risk, loop-persistence risk, escape mass near plausible alternatives, and task quality before and after repair. Lane detail
Layer Pruning Reassessment And MoE Compression
conditional computation preservation
Compression works when removed layers or experts are genuinely redundant for the tested function family. The hard object is conditional behavior, because some experts matter only for rare inputs.
Evidence example: evaluate rare capabilities, expert-route coverage, layer-ablation sensitivity, and broad behavioral drift rather than only aggregate benchmark deltas. Lane detail
GROUP 25

Molecule Design Evidence Examples: Identity And Binding

Molecular generation is useful only when the generated object is the same object under nuisance coordinates, physically feasible under local constraints, and meaningful under the selection rule used after sampling.

Structure Before Coordinates

Quotient-Space Diffusion
molecular identity modulo rigid pose
The method works because rotating or translating a molecule should not create a new training example. Dividing out nuisance pose lets the sampler spend probability mass on bond geometry, conformation, clashes, and interaction state.
Evidence example: rotate and translate inputs, verify invariant likelihood or score behavior, then test whether generated structures preserve stereochemistry and docking-relevant orientation when pose becomes physically meaningful. Lane detail
Protein Autoregressive Modeling
coarse-to-fine protein hierarchy
The model works when generation order matches physical dependency. Global fold and motif state restrict local residue choices, so the sampler does not ask each coordinate to solve the full protein at once.
Evidence example: evaluate fold validity, motif preservation, local geometry, and failure under shuffled generation orders that remove the coarse-to-fine constraint. Lane detail
DCFold
dual structural consistency
The method works when two views of the same fold constrain each other. Plausible one-pass structure is not enough; agreement across representations is evidence that the hidden geometry is coherent.
Evidence example: measure disagreement between predicted structural views, correlate consistency with fold quality, and report cases where speed preserves or breaks structural constraints. Lane detail
Chamaileon And Complexa
contextual sequence-structure binder distribution
Binder design works when the feasible set includes target context, multiple states, sequence constraints, atomistic geometry, and measured multimer evidence. The object is not a sequence alone; it is a conditional biological complex.
Evidence example: test target-conditioned specificity, multistate robustness, atomistic clash rates, synthetic-data scaling, and experimental-multimer transfer. Lane detail

Factorized Binding And Selection

DeCoDe
separate binding-position and conformation variables
The factorization works because where a molecule binds and how it flexes are coupled but not identical causes. Splitting them reduces entanglement and gives the sampler two controls instead of one overloaded latent.
Evidence example: perturb binding-site variables and conformational variables separately, then measure whether location, pose, flexibility, and affinity change in the predicted direction. Lane detail
FALCON
density-tracked molecular equilibrium flow
FALCON works when molecular samples have meaningful probabilities. A conformation is scientific evidence only if the sampler tracks density well enough for equilibrium estimates and mode weights.
Evidence example: compare density estimates to known or high-quality reference ensembles, inspect mode coverage, and test whether likelihood errors bias equilibrium observables. Lane detail
SRMC
rare-mode estimator quality
The sampler works when it reduces bias and variance for quantities controlled by rare conformations. Missing a rare mode is not lack of variety; it is a wrong measurement of the target distribution.
Evidence example: use controlled multimodal targets, measure effective sample size and rare-mode mass, and compare estimator error against ordinary sampling. Lane detail
FIDIA
Best-of-N upper-tail design objective
FIDIA works because deployment selects the best candidate from a finite generated set. Training the mean sample can leave the maximum unchanged, while training the upper tail matches the actual downstream decision rule.
Evidence example: report expected best-of-N score, robustness of selected candidates, score-model failure cases, and whether upper-tail gains survive synthesis and biological constraints. Lane detail
GROUP 26

Molecule Design Evidence Examples: Route And Feasible Sets

A molecule is not deployable because its graph is attractive. It becomes part of the real design space when there is a constructive path to make it, score it, and reject bad tradeoffs.

Synthesis As Constructive Evidence

mCLM
building-block constrained molecular language
The method works when generation is restricted by units that correspond to plausible chemical construction. The vocabulary carries feasibility information that raw strings do not.
Evidence example: measure validity, novelty, purchasable or known building-block coverage, and whether generated molecules remain reachable after retrosynthetic checking. Lane detail
ReaSyn
reaction-aware synthesis path
Reaction awareness works because synthetic feasibility is a path constraint. Each step must be chemically valid and must lead toward the target without relying on impossible intermediates.
Evidence example: verify reaction templates or learned reactions step by step, score intermediate plausibility, and compare generated routes against known synthesis or expert rejection. Lane detail
MORetro*
Pareto frontier over retrosynthesis routes
The method works because no single scalar captures route quality. Cost, yield, step count, toxicity, availability, and risk form a tradeoff surface, so useful planning preserves alternatives rather than hiding them in one score.
Evidence example: report non-dominated route sets, stress criteria weights, and test whether selected routes remain feasible when one criterion becomes stricter. Lane detail
TEDBench, MiAE, And FLIP2
structure-sensitive protein evaluation split
These benchmarks work when they block leakage and near-duplicate shortcuts. A model has learned transferable structure only when success survives splits that remove trivial similarity to training examples.
Evidence example: compare random splits to fold-aware and transfer-aware splits, audit near duplicates, and report where scaling helps because structure generalizes rather than memory wins. Lane detail

The Molecular Design Chain

Identity
same molecule across coordinate descriptions
Quotient geometry removes fake variation so the learner sees the physical object instead of arbitrary pose. This is the first filter: define what counts as the same structure.
Evidence example: invariance tests and stereochemical edge cases determine whether the quotient removed only nuisance variation.
Feasibility
structure satisfying local physics and biological context
Hierarchical protein generation, DCFold consistency, contextual binder design, and DeCoDe factorization all work by putting constraints into the state before sampling finishes.
Evidence example: structural consistency, target specificity, binding-site perturbations, and clash/affinity checks show whether generated candidates inhabit the feasible region.
Constructive Route
chemical path proving membership in the design space
mCLM, ReaSyn, and MORetro* make feasibility constructive. A molecule with no plausible route is outside the practical feasible set even if its standalone graph scores well.
Evidence example: route verification, building-block availability, and Pareto route robustness test whether the object can move from design to synthesis.
Selection
finite-batch best candidate under constraints
FALCON, SRMC, and FIDIA remind the atlas that generation is evaluated through a downstream functional: equilibrium estimate, rare-mode contribution, or best-of-N selected design.
Evidence example: the final evidence is not sample beauty; it is whether the selected or estimated quantity remains correct under density checks, rare-mode stress, and synthesis/biology filters.

Agent Reasoning Evidence Examples: Trace And Process

These rows ask whether the reasoning process is doing causal work. A long trace, a polished plan, or a verified final answer is not enough unless the intermediate state remains task-conditioned and changes the outcome.

Trace Dependence And Horizon Credit

RAGEN-2
mutual information between input and trace
The diagnostic works because template reasoning can preserve entropy while losing task dependence. The mathematical object is whether the trace reduces uncertainty about the specific input, not whether it looks varied.
Evidence example: measure trace-input dependence under prompt perturbations, reward-variance filtering, and adversarial tasks where generic templates score poorly. Lane detail
OpenThoughts
reasoning-trajectory distribution
Open trace data works when its source, filtering rule, teacher bias, and domain mix are visible enough to explain what kind of computation it teaches. The dataset is a distribution over paths, not just answer labels.
Evidence example: compare trace recipes by domain transfer, trace length, intermediate validity, teacher source, and whether downstream models inherit brittle teacher habits. Lane detail
h1
dependency-chain curriculum
The curriculum works because direct long-horizon reward is too sparse. Growing chain length keeps credit assignment inside a region where the learner can still connect local moves to final success.
Evidence example: sweep horizon length, measure when outcome-only RL loses signal, and test whether learned short dependencies compose without memorizing templates. Lane detail
The Tell-Tale Norm
hidden-state statistic for reasoning intensity
The norm works only if it tracks a real internal state that predicts useful extra computation. It is an allocation signal: when to recurse, steer, or select an answer.
Evidence example: intervene on recursion decisions using the norm, compare to random or length-based routing, and test whether high-norm states actually benefit from added computation. Lane detail

Process Verification And Shortcut Detection

Verifying Chain-of-Thought
dependency graph of intermediate claims
The method works when prose steps can be converted into nodes and edges whose support relation is checkable. The important object is the dependency structure, not the natural-language style of the trace.
Evidence example: corrupt individual steps, remove dependencies, and test whether the verifier localizes unsupported claims rather than only judging final answers. Lane detail
CE-Graph And TRACE Effort
process-sensitivity signature
These diagnostics work when success depends on the claimed reasoning. If final accuracy survives trace truncation, low-effort substitution, or counterexample pressure, the trace was not the cause of success.
Evidence example: compare full, truncated, shuffled, and low-effort traces while measuring verifier sensitivity and final outcome stability. Lane detail
tau2-bench
shared state transition across user, agent, and tools
The benchmark works because service tasks are not isolated utterances. User actions, agent actions, policy constraints, and tool calls update the same environment state.
Evidence example: audit state diffs after each turn, inject user-side changes, and test whether the agent respects tool state and policy constraints rather than dialogue history alone. Lane detail
Skill-Pro
executable procedure with activation and termination conditions
A skill works when it compresses a trajectory into a reusable policy fragment without firing outside its valid state. Preconditions and termination rules are part of the mathematical object.
Evidence example: replay learned skills across perturbed tasks, measure false activation, successful termination, and whether reuse beats re-deriving the workflow from scratch. Lane detail
GROUP 28

Agent Reasoning Evidence Examples: Tools And Mechanisms

These rows treat agents as decision systems under cost, uncertainty, and strategic response. The useful evidence is not that the agent did more work; it is that the extra action changed the frontier or the mechanism in the intended direction.

Tool Use And Executable Certificates

ParetoPO
accuracy-cost frontier for tool policies
The method works by refusing to collapse tool use into a single reward. A tool call is rational only when its expected information or capability gain is worth latency, money, risk, and state complexity.
Evidence example: plot task success against tool calls, latency, and error cost; inspect cases where fewer calls preserve quality and extra calls produce no frontier improvement. Lane detail
CyberGym
pre-patch/post-patch exploit certificate
CyberGym works because a security claim becomes executable behavior. The counterfactual is built in: a real exploit should work before the patch and fail after it.
Evidence example: execute the proof of concept in controlled pre-patch and post-patch environments, log side effects, and separate exploit success from explanatory prose quality. Lane detail
THOR / TerminalTraj-style Agent Infrastructure
normalized tool and terminal trajectory state
Tool trajectories work as training evidence only when they preserve the state variables that caused success or failure. A normalized trace should not erase the file, command, environment, or error condition that mattered.
Evidence example: replay traces, perturb environment state, audit missing variables, and test whether learned policies transfer to new but structurally similar workflows. Lane detail
ThinkV / EntroKV
future value of retained context or cache state
Memory allocation works when retained states are close to sufficient for future decisions. The value of a token or cache entry is its effect on later uncertainty, not its age or average attention alone.
Evidence example: remove candidate memory entries, measure next-decision divergence, and stress rare long-range dependencies where naive compression discards the decisive evidence. Lane detail

Multi-Agent Mechanism Evidence

OMAC
collaboration graph over roles and messages
OMAC works when role structure changes information flow. Separate agents are useful only if their division of labor, comparison points, and aggregation rule create evidence that one model call would not.
Evidence example: ablate roles and communication edges, test benchmark transfer, and check whether minority correct evidence survives aggregation instead of being averaged away. Lane detail
Rational Agents
expected value of information under action cost
The method works when an agent's question or action is chosen by expected posterior improvement minus cost. More information is not automatically better; it must change the decision enough to pay for itself.
Evidence example: compare predicted information gain to realized error reduction, calibrate uncertainty, and inspect early-stop versus over-query failures. Lane detail
MASPOB And LatentMAS
latent role-conditioned belief and policy
Latent roles work when they compress coordination structure: who observes what, who acts where, and which messages matter. A role is useful only if it improves joint action under partial observation.
Evidence example: perturb role assignments, hide observations, and measure whether inferred roles improve coordination versus symmetric agents with the same information. Lane detail
AdvGame / Accuracy Auctions / Mechanism Papers
response equilibrium under rules and incentives
Mechanism papers work because deployed agents face other actors that adapt. The object is the response path induced by the rules, not the isolated optimum of one model.
Evidence example: simulate strategic users, sellers, evaluators, and attackers; test whether the mechanism remains truthful or robust when actors use actions outside the idealized model. Lane detail
