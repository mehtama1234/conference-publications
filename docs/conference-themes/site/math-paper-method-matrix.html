FIRST PRINCIPLE

A Paper Is A Claim About A Move

A paper becomes mathematically legible when it is written as a move from one object to another: a shorter state, a better measurement channel, a constrained feasible set, a safer sampling path, a more aligned update, a quotient representation, or an identified causal claim. The method is not the name of the architecture. The method is the controlled change.

The row structure below forces every paper to answer the same questions: what object is being changed, why that change should reduce error or risk, what assumption makes the argument valid, what failure mode breaks it, and which other papers use the same move in another domain.

READING PATHS

How To Use The Matrix

Start from a paper

Read across the row: object, approach, why-it-works, assumption, failure, neighbors. That gives the minimal first-principles explanation before reading the longer lane page.

Start from a failure

If a paper seems weak, use the failure column to jump to the failure-mode atlas. The question becomes concrete: what evidence would reveal that this assumption is false?

Start from a method

If several papers use the same move, use the approach-pattern atlas to compare domains. The same mathematical reason may appear in agents, diffusion, causality, and systems under different names.
