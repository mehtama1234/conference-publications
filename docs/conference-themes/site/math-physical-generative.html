FIRST PRINCIPLE

A Generated Object Has To Live In The Right Space

A molecule is not a list of atom coordinates. The same molecule can be translated or rotated without becoming a new molecule. A robot action is not an unconstrained vector; it must pass through joints, contact, timing, and safety margins. A PDE solution is not a picture on a grid; it is a field whose derivatives and boundary conditions matter. A video is not a sequence of independent images; it is a path through a world state.

The strong papers in this lane work by changing the mathematical object before optimizing. They quotient away fake variation, factor variables that should not be entangled, put probability mass on feasible paths, preserve symmetries, or define measurements that expose hidden state. Once the state space is right, learning becomes a smaller and better-posed problem.

OBJECT 01

Coordinate State

Depth Anything 3

Problem. Recognition can succeed while metric geometry is wrong. A model may name objects correctly and still fail at reconstruction, navigation, or manipulation.

Object. A joint depth-and-ray state tied to camera geometry.

Why it works. Depth makes relative layout quantitative, while rays say how pixels correspond to 3D directions. The model is forced to represent the scene as geometry, not only as appearance.

Connection. This is the visual analog of quotient diffusion: remove ambiguity that comes from an under-specified coordinate system.

Camera-Aware MLLM

Problem. A multimodal model can confuse object relations with viewpoint artifacts if the camera is treated as hidden.

Object. Camera parameters as observed variables in the conditioning state.

Why it works. Geometry answers are conditional claims. Left, right, size, distance, and visibility depend on projection. Supplying the camera reduces confounding between scene structure and image formation.

Connection. It matches causal-route papers in spirit: expose the variable that changes the observed signal before asking the model to reason.

3ViewSense

Problem. A single perspective hides occluded surfaces and makes some spatial relations ill-conditioned.

Object. Canonical orthographic views plus a separated simulation-and-reasoning loop.

Why it works. Orthographic views remove perspective distortion and make comparisons closer to Euclidean measurements. The reasoning model sees a representation where the needed relation is easier to infer.

Connection. This is representation preconditioning: the problem is changed into coordinates where the answer is less fragile.

Holi-Spatial

Problem. Spatial language needs supervision over masks, boxes, relations, and question-answer pairs, but hand labels are expensive.

Object. A renderable 3D Gaussian Splatting scene as a data generator.

Why it works. If the scene state is explicit and renderable, labels can be derived from geometry instead of guessed from pixels. The generator becomes a measurement instrument for spatial supervision.

Connection. It links generative scenes to evaluation: the same structured state can create examples and verify answers.

TideGS And RadioGS

Problem. Generic visual fields often look right but miss physical radiance, wave behavior, or time-varying structure.

Object. Gaussian primitives with parameters that can be rendered and inspected.

Why it works. A splat is a compact local basis function. It lets the model approximate a continuous field while preserving a handle on position, extent, opacity, and emitted signal.

Connection. These papers share the same idea as spectral PDE methods: choose basis functions that make the physical signal easier to represent.

WAFT And SplAttN

Problem. Spatial reasoning fails when sparse correspondence uncertainty is collapsed too early.

Object. A distribution over correspondences or splatted attention support.

Why it works. Matching is not a one-label decision when the image is ambiguous. Keeping uncertainty spatially localized lets later evidence resolve it instead of forcing an early brittle assignment.

Connection. This is the same mathematics as sampler mode coverage: do not discard plausible states before the observation has enough information.

OBJECT 02

Temporal World State

Stable Video Infinity

Problem. Long generated videos drift because each locally plausible step shifts the next conditioning state.

Object. Error trajectories produced by the generator itself.

Why it works. Training on self-generated failures changes the model's domain from clean prefixes to the states it will actually visit. Drift becomes a learnable correction field rather than an unobserved accumulation.

Connection. This is temporal residual correction, close in shape to IRNO's iterative error repair for operators.

SANA-Video

Problem. Minute-long high-resolution video needs memory of the past without quadratic growth.

Object. Block-wise constant-memory state inside a linear DiT-style generator.

Why it works. Long video is a state-compression problem. The method preserves enough temporal information for coherence while bounding the cost of carrying state forward.

Connection. It is the generative counterpart to long-context cache allocation: keep the state that still changes future predictions.

FlashWorld And VectorWorld

Problem. A world model must respond to action. Static prompt-to-video is too passive for simulation or driving.

Object. An interactive state transition system, sometimes represented as vector graphs rather than pixels.

Why it works. Graph state exposes lanes, actors, topology, and timing. The model can update a structured world after an action instead of regenerating unrelated frames.

Connection. This is agents in physical form: action changes the state, and the next observation must be conditional on that changed state.

SceneSmith

Problem. Robot environments must be physically and functionally usable, not merely visually dense.

Object. A simulation-ready scene assembled by designer, critic, and orchestrator roles.

Why it works. Generation is decomposed into proposal, critique, and coordination. The artifact is checked for affordances, object placement, and downstream use, so scene validity becomes part of the loop.

Connection. The same control structure appears in multi-agent reasoning: decomposition helps only when critics evaluate the right state variables.

Control Consistency Losses And dWorldEval

Problem. A generated trajectory can look plausible while violating the control signal that supposedly produced it.

Object. Consistency between action, dynamics, and visual future.

Why it works. The model is penalized for paths whose causes do not match their effects. This makes the generated sequence a dynamical claim, not only a visual one.

Connection. It is the world-model version of proof verification: check whether each later state follows from the allowed transition.

OBJECT 03

Sample Paths

Safety-Guided Flow

Problem. A generator can put probability mass near unsafe regions even when samples look high quality.

Object. A vector field modified by attraction toward valid outputs and repulsion from unsafe sets.

Why it works. The sampler's path matters. If the velocity field is changed, probability transport avoids regions that a post-hoc classifier might only reject after generation.

Connection. This is constraint handling inside the dynamics, like Pi-net projects decisions into feasible regions.

DMPO For Diffusion LLMs

Problem. Reasoning RL recipes from autoregressive models do not directly apply when generation is diffusion-style.

Object. A reward-tilted target distribution over denoised language samples.

Why it works. The policy update is matched to the sampler's native trajectory. The model is not forced to pretend that denoising steps are ordinary token actions.

Connection. The lesson is general: optimization must respect the generative process that actually defines the sample.

FALCON

Problem. Molecular equilibrium estimates depend on likelihood and mode coverage, not only visually plausible conformations.

Object. A flow distribution with tractable density for equilibrium states.

Why it works. A normalizing flow can move probability mass while tracking density change. That lets the model estimate physical probabilities rather than only generate candidates.

Connection. It links generative modeling to statistical mechanics: the sample is useful only if its probability means something.

SRMC

Problem. Rare modes can dominate estimates even when most samples look good.

Object. A sampler designed around variance reduction and mode coverage.

Why it works. Estimation error is controlled by which regions of the target distribution are visited and how noisy their weights are. Missing a mode is a biased measurement, not a cosmetic defect.

Connection. This explains why benchmark averages can lie: the tails may contain the scientific quantity of interest.

Cauchy-Driven Diffusion Bridges

Problem. Medical acoustic data can have noise and jumps that Gaussian paths underrepresent.

Object. A bridge process driven by heavy-tailed Cauchy noise.

Why it works. Heavy tails assign more probability to abrupt deviations. The sampler can model corruption regimes that a light-tailed process would treat as impossible outliers.

Connection. The noise law is part of the model's geometry; choosing the wrong one changes which observations are considered plausible.

OBJECT 04

Molecules And Proteins

Quotient-Space Diffusion Model

Problem. Rigid rotations and translations change coordinates without changing the molecule.

Object. A quotient space where equivalent poses represent the same structure.

Why it works. Learning no longer wastes probability mass on fake variants. The denoising process focuses on bond geometry, relative arrangement, and chemically meaningful variation.

Connection. This is the cleanest example of the lane's central rule: first identify what counts as the same object.

state = structure / rigid-body pose

Protein Autoregressive Modeling

Problem. A protein backbone has constraints across local residues, secondary motifs, and global fold.

Object. A coarse-to-fine hierarchy of structure variables.

Why it works. Autoregression becomes useful when the generation order follows the physical hierarchy. Coarse structure constrains local choices, reducing the space of invalid fine-grained completions.

Connection. The same idea appears in HDFlow: solve a high-level shape first, then fill in feasible local motion.

DCFold

Problem. Fast protein prediction can output plausible folds without enough structural consistency.

Object. Dual consistency between predicted structural views.

Why it works. A one-pass prediction is constrained by agreement conditions. If two views of the same fold disagree, the model has exposed a violation of the hidden geometry.

Connection. Consistency is the scientific analog of verifier checks in agents: speed is acceptable only when structural constraints still hold.

Chamaileon And Complexa

Problem. Binder design is not one sequence against one static target.

Object. A contextual sequence-structure distribution over targets, states, and atomistic constraints.

Why it works. Multiple states and targets define the real feasible set. Synthetic scale gives coverage, while experimental multimers anchor the distribution to measured biology.

Connection. This is the data version of quotient geometry: broad generated variation must collapse onto physically valid structure.

DeCoDe

Problem. Binding location and molecular conformation are coupled but not identical.

Object. Separate diffusion variables for binding position and conformation.

Why it works. Factorization reduces entanglement. The sampler can control where the molecule acts and how it flexes without forcing one variable to explain both sources of variation.

Connection. This is the molecular form of decomposed control in agents and robotics.

FIDIA

Problem. Protein design often evaluates the best candidate from a generated set, not the average sample.

Object. A Best-of-N selection objective.

Why it works. The training objective is aligned with deployment. A policy that improves the upper tail of sampled fitness is mathematically different from one that improves mean likelihood.

Connection. This is the same frontier logic as ParetoPO and MORetro*: what matters is the selected feasible outcome under budget.

mCLM, ReaSyn, And MORetro*

Problem. Chemically attractive molecules are not enough if they cannot be synthesized or if their route is too costly or toxic.

Object. Building blocks, synthetic trees, and Pareto fronts over route criteria.

Why it works. Synthesis becomes part of the state space. The model generates paths through chemical operations rather than isolated strings that must be repaired later.

Connection. These papers make feasibility constructive: the route is evidence that the molecule belongs to the real design space.

OBJECT 05

Scientific Fields

IRNO

Problem. Neural operators can accumulate high-frequency residual error over iterative prediction.

Object. A learned fixed-point iteration with residual correction.

Why it works. The model is trained to repair the error left by the current approximation. Prediction becomes convergence toward a solution rather than one isolated regression.

Connection. It shares a mathematical shape with Stable Video Infinity: learn from the states your own model creates.

MERLIN

Problem. Scientific fields are observed through sparse measurements and queried at changing resolutions.

Object. Learned observation functionals and resolution-free field reconstruction.

Why it works. The field is represented independently of a fixed grid. Measurements become linear or nonlinear functionals of the underlying object, so reconstruction can adapt to resolution.

Connection. This is a precise version of multimodal grounding: observations are not the state, they are measurements of the state.

Dirac-Frenkel-Onsager

Problem. Momentum can speed learning but can also push PDE parameters through forbidden constraint directions.

Object. Nullspace directions of the constraint structure.

Why it works. Momentum is injected only where it does not violate the equations' constraints. Acceleration is allowed inside the tangent space of valid motion.

Connection. This is the optimizer form of safe steering: change the state without crossing the boundary that defines validity.

LoRFS And Modified SINNs

Problem. High-dimensional PDEs are too large for naive coordinate-wise fitting.

Object. Spectral or separable basis representations with physics losses.

Why it works. Smooth physical fields often have compressible structure in a suitable basis. Analytic losses penalize violations of the equation itself, not only mismatch to sampled data.

Connection. Basis choice plays the same role as token choice in mCLM: it decides which operations become simple.

ReViT

Problem. Rotated physical fields should obey the same dynamics under transformed coordinates.

Object. Discrete rotational equivariance through canonical bases and attention.

Why it works. The model's output transforms consistently when the input is rotated. It does not need to relearn the same law for every orientation.

Connection. It is the field version of quotient-space thinking: separate real dynamics from coordinate accidents.

Walrus And RealPDEBench

Problem. Simulation-trained scientific models may fail on measured systems.

Object. Cross-domain physical dynamics plus paired real and simulated observations.

Why it works. Walrus searches for reusable dynamic structure across domains; RealPDEBench tests whether that structure survives measurement noise, sensor limits, and real boundary conditions.

Connection. The pair explains why pretraining and benchmarking are inseparable in scientific ML: transfer claims need measured stress tests.

OBJECT 06

Embodied Action

HDFlow

Problem. High-dimensional robot action cannot be represented well by one deterministic output.

Object. High-level diffusion subgoals plus low-level rectified-flow action generation.

Why it works. The model first chooses a coarse region of intent, then samples feasible local motion. This reduces the burden on the low-level policy and keeps multimodal action choices alive.

Connection. It is protein hierarchy applied to control: coarse structure constrains fine motion.

MomaGraph

Problem. Pixels do not directly say what a robot can do with objects.

Object. A spatial-functional scene graph with object states and affordances.

Why it works. Planning becomes graph search over relations and functions instead of brittle prediction over raw images. The graph preserves which objects matter and how they can change.

Connection. It mirrors Graph-then-Plan agent systems, but with physical state rather than web or code state.

EgoTactile

Problem. Vision cannot always observe contact, slip, pressure, or grasp stability.

Object. Egocentric video paired with full-hand pressure measurements.

Why it works. Tactile data reveals hidden physical state. The model can learn contact variables that explain action success even when pixels are ambiguous.

Connection. This is the sensor version of hidden-state diagnostics: add the measurement that makes the latent variable visible.

JoSE

Problem. Muscle and actuator spaces have many dimensions, but useful behavior often lies on a smaller manifold.

Object. A low-dimensional action manifold found through mutual information.

Why it works. The controller searches in coordinates that preserve behavior-relevant variation while removing redundant actuator movement. This makes exploration and transfer easier.

Connection. It is quotient thinking for action: many actuator vectors can express the same functional movement.

RodriNet

Problem. Articulated motion has rotation geometry that ordinary vector layers do not naturally respect.

Object. A learnable operator based on Rodrigues forward kinematics.

Why it works. Known rotational structure is built into the transformation. The model learns residual behavior around a physically meaningful operator instead of rediscovering kinematics from data.

Connection. It belongs with ReViT and Dirac-Frenkel-Onsager: the architecture respects a geometric law before fitting.

MAPF Via MMOT And Schrodinger Bridges

Problem. Multi-robot path finding must coordinate many agents without collisions, often before identities matter.

Object. Markov-structured optimal transport with collision-free bridge constraints.

Why it works. Planning becomes movement of distributions under constraints. The method can coordinate flows of agents while enforcing exclusion, instead of solving many isolated paths.

Connection. It is the embodied counterpart of fair optimal transport and sampler bridge methods.

BehaviorVLA, PACT, And EcoVLA

Problem. Robot policies must transfer, accept new constraints, and run inside wall-clock control loops.

Object. Reusable behavior distributions, bounded policy shift, and latency-aware computation schedules.

Why it works. BehaviorVLA attacks sample efficiency, PACT limits how far a correction can move the policy, and EcoVLA fits computation into unused latency gaps. Each method preserves a different invariant: task behavior, policy proximity, or timing.

Connection. Robotics makes the whole atlas concrete: a policy fails if the math ignores data, constraints, or systems time.

OBJECT 07

Human Signals Beyond Images

Mind-Omni And PRISM

Problem. Brain signals are noisy measurements, not images or text.

Object. Discrete brain tokens or object-attribute-relation representations that bridge neural and visual spaces.

Why it works. The intermediate code gives the model a structured variable between fMRI and media. Reconstruction becomes a problem of estimating latent concepts from measurements, then mapping concepts to images or language.

Connection. This is MERLIN's measurement logic in neuroscience form.

Hibiki-Zero, EmotionThinker, And EEmo-Logic

Problem. Speech and affect depend on timing, prosody, and emotional state, not just transcript content.

Object. Temporal and affective latent variables aligned with language or audio.

Why it works. The model separates what was said from how it was expressed. That separation allows generation and recognition to preserve meaning while controlling rhythm, tone, or affect.

Connection. It is the human-signal version of factorized diffusion: separate variables that are coupled in the observation but distinct in the cause.

DLMR And Causal Route Gating

Problem. Multimodal systems can remember or route through the wrong evidence source.

Object. A memory or routing variable that assigns credit to modalities and intermediate causes.

Why it works. Explicit routing reduces hidden confounding. The system has to decide which signal changed the belief state instead of merging all evidence into one opaque vector.

Connection. This matches Camera-Aware MLLM: expose the causal variable before interpreting the output.

LIMSSR

Problem. Action quality may need multimodal evidence when some modalities are missing.

Object. Conditional sequence-to-score reasoning under missing observations.

Why it works. The model estimates a score from the observed subset while representing uncertainty about missing signals. It does not assume the training-time full modality set will exist at deployment.

Connection. This is partial observability, the same state problem as agents and robotics.

OBJECT 08

Verification And Benchmarks

TEDBench, MiAE, And FLIP2

Problem. Protein benchmarks can reward leakage, near-duplicate memory, or scaling that does not improve the intended generalization.

Object. Evaluation splits and metrics tied to fold similarity and transfer difficulty.

Why it works. The benchmark changes what evidence counts. A model must show structure-sensitive generalization, not only high performance on examples close to training data.

Connection. This is scientific benchmark hygiene: if the split is wrong, the mathematical claim is wrong.

Seizure-Semiology-Suite And VideoKR

Problem. Medical and knowledge-rich video tasks require domain outcomes, not generic visual plausibility.

Object. Task-specific observations, labels, and reasoning checks grounded in expert semantics.

Why it works. The evaluation asks whether the model preserved the clinically or semantically relevant state variable. Surface accuracy is insufficient if it ignores the domain's causal structure.

Connection. This extends control consistency from physics to expert domains: the output must follow the real rules of the system.

MetamerGen And OmniVerifier

Problem. Generated media can fool one perceptual path or one judge while failing broader consistency.

Object. Multiple verifiers over perceptual equivalence, instruction satisfaction, and cross-modal agreement.

Why it works. A single metric sees one projection of the generated object. Multiple checks reduce the chance that the model exploits an evaluation blind spot.

Connection. Verification closes the lane: native state spaces matter because they define what should be checked.

SYNTHESIS

The Cross-Paper Shape

Coordinate To Constraint To Sampler

Depth Anything 3, Camera-Aware MLLM, Quotient-Space Diffusion, DeCoDe, Safety-Guided Flow, and FALCON all show the same sequence. First choose coordinates that identify the real object. Then state the constraints that define valid objects. Then design the sampler so probability mass moves inside that space instead of being filtered after the fact.

World Model To Action To Verification

Stable Video Infinity, VectorWorld, SceneSmith, Control Consistency Losses, MomaGraph, HDFlow, and MAPF papers treat generation as a closed loop. The output is not done when it looks plausible. It must remain valid after an action changes the world and a verifier checks the transition.

Scientific Prior To Measurement To Benchmark

MERLIN, IRNO, ReViT, LoRFS, Walrus, RealPDEBench, TEDBench, MiAE, FLIP2, Mind-Omni, and PRISM connect prior structure to measurement. A useful model says what the hidden state is, how observations are produced from it, and what benchmark would distinguish real structure from memorized surface patterns.

FOCUSED CHAIN

Native State: From Quotient Geometry To Fields To Action

Quotient-Space Diffusion: Remove Fake Coordinates

Problem. A molecule or protein complex has physical identity before it has an arbitrary pose in a coordinate file. Rotating or translating every atom should not create new scientific evidence.

Mathematical object. An equivalence class under a symmetry group: all coordinate descriptions related by rigid motion represent the same structure.

Why it works. The learner stops spending probability mass on nuisance copies of the same object. Denoising can concentrate on bond lengths, relative atom geometry, pockets, clashes, and conformational variation, because pose has been divided out.

Failure boundary. The removed variation must truly be nuisance. Chirality, view-dependent sensors, docking orientation, or asymmetric environments can make a pose-like variable physically meaningful.

structure = coordinates / symmetry group

TideGS, RadioGS, And Spatial Fields: Use A Basis The Medium Understands

Problem. A continuous physical signal is not naturally a flat image. It has locality, smoothness, visibility, attenuation, and measurement geometry.

Mathematical object. A field represented by local primitives, such as Gaussian elements with position, extent, opacity, signal strength, or phase-like parameters.

Why it works. The basis gives the model manipulable coordinates for a continuous medium. Rendering, interpolation, sensor simulation, and spatial reasoning become operations on a field state instead of guesses over pixels.

Failure boundary. A convenient basis can smooth over discontinuities, hard boundaries, long-range coupling, sensor artifacts, or sharp physical events that are not well expressed by local blobs.

observations = measurement operator(field basis state)

IRNO And Scientific Operators: Predict By Residual Correction

Problem. In scientific prediction, a small local error can be amplified by the next step, especially in high-frequency modes or boundary-sensitive regimes.

Mathematical object. An iterative fixed-point state whose update is a learned correction to the current residual.

Why it works. The model is trained on the error left by its own approximation. Instead of pretending that one regression is the solution, it repeatedly measures the gap between current state and governing operator and moves toward consistency.

Failure boundary. A fixed point can be stable and still wrong if the residual is measured in the wrong norm, if the boundary conditions changed, or if the missing physics sits outside the learned correction class.

state[t + 1] = state[t] + correction(residual(state[t]))

HDFlow: Split Global Intent From Local Motion

Problem. Robot action mixes two mathematically different uncertainties: which outcome should be pursued and which low-level trajectory can realize it.

Mathematical object. A latent subgoal distribution coupled to a low-level rectified-flow action path.

Why it works. Global ambiguity and local smoothness are not forced into one vector. The high-level state keeps multiple possible intents alive; the local flow handles continuous feasible motion once an intent is selected.

Failure boundary. A bad subgoal can make the low-level controller precisely execute the wrong plan. Contact timing, friction, occlusion, and actuator limits can still break a locally smooth trajectory.

policy = choose subgoal, then transport action toward it

MomaGraph, EgoTactile, JoSE, And RodriNet: Add The Missing Body State

Problem. Action is not text and not only vision. A valid movement depends on object affordances, pressure, slip, rotations, joints, actuator redundancy, and body-specific constraints.

Mathematical object. Scene affordance graphs, tactile latent states, action manifolds, and kinematic operators.

Why it works. Each representation exposes a variable that raw pixels or token commands hide. Graphs say what can be changed, touch reveals contact state, manifolds remove redundant actuator directions, and kinematic operators preserve rotation structure.

Failure boundary. If the sensor omits hidden physical state, if the graph is stale, or if the learned manifold excludes a needed recovery move, the policy reasons inside the wrong body-world model.

valid action = body state + world relation + constraint-respecting transition

The Native-State Chain

Shared object. A representation whose coordinates match the invariants and constraints of the domain: quotient geometry for identity, field bases for media, residual states for operators, and embodied states for contact.

First-principles read. Learning works best after the valid state has been named. If validity is absent from the representation, the loss must rediscover it indirectly from examples, which makes the method brittle under new poses, resolutions, sensors, bodies, or boundaries.

Across papers. Quotient-Space Diffusion removes fake state. TideGS and RadioGS choose renderable field coordinates. IRNO learns a correction process instead of a one-shot answer. HDFlow splits intent from motion. MomaGraph, EgoTactile, JoSE, and RodriNet add the body variables that make action physically meaningful.

raw observation -> native state -> constrained transition -> verifier
FOCUSED CHAIN

Grounded World Models: Action To Transition To Evidence

The Core Mathematical Problem

Problem. A generated world is useful only if it keeps the same state under action. Looking plausible at each frame is too weak, because independent plausibility does not prove that the later frame follows from the earlier state and chosen control.

Mathematical object. A controlled transition model: current state, action, next state, and an observation map that renders or measures the state.

Why it works. This turns generation into a conditional claim. The model is not asked to make any likely future; it is asked to preserve the consequence of this action in this world.

(state[t], action[t]) -> state[t + 1] -> observation[t + 1]

FlashWorld: Keep Interaction In The State

Problem. A prompt-to-video model can change the scene in ways that ignore the user's intervention, because the prompt is not a physical control variable.

Mathematical object. An interactive latent world state conditioned on user or agent actions.

Why it works. The action is part of the transition, not an after-the-fact caption. This makes the generated continuation depend on the intervention that caused it, so the model has to represent counterfactual sensitivity: different actions should produce different futures from the same state.

Failure boundary. Interaction fails when the latent state does not contain the variables the action actually changes, such as contact, hidden objects, intent, or physical constraints.

VectorWorld: Use State Variables Instead Of Pixels Alone

Problem. Driving and simulation worlds contain lanes, actors, routes, right-of-way, and timing. Pixels show those facts indirectly, often with occlusion and irrelevant texture.

Mathematical object. A vector or graph state for actors, topology, geometry, and motion.

Why it works. The transition is easier when the coordinates already name the things that move and constrain each other. Lane topology can restrict feasible motion; actor state can carry velocity and intent; graph edges can express who can affect whom.

Failure boundary. A graph is only better than pixels if it preserves the relevant world variables. Missing unusual actors, weather effects, construction changes, or hidden intent turns the structured state into a false simplification.

dWorldEval And Control Consistency: Test The Causal Link

Problem. A generated trajectory can match the visual distribution while breaking the action-state relation. It can look like driving while ignoring steering, braking, object persistence, or collision constraints.

Mathematical object. A consistency test over action, transition, and rendered future.

Why it works. The benchmark asks whether the generated future is an admissible consequence of the control. This is a stronger test than frame quality because it checks an invariant: causes should constrain effects.

Failure boundary. The evaluator must know enough about the transition law. If the check only sees superficial motion, the generator can satisfy the metric while violating the real simulator or task dynamics.

valid if observed future is compatible with allowed transition

OmniVerifier And VideoKR: Verify The Right Projection

Problem. A world can be wrong in many projections: visual consistency, instruction satisfaction, object relation, temporal ordering, factual knowledge, or domain semantics. One scalar score rarely sees all of them.

Mathematical object. A family of verifier projections over the generated artifact and its conditioning evidence.

Why it works. Each verifier observes a different function of the latent world state. OmniVerifier asks whether generated media satisfies cross-modal and instruction-level constraints; VideoKR asks whether video reasoning preserves knowledge-rich semantic state. Multiple projections reduce hidden failure modes.

Failure boundary. Verification is only as strong as the projections it measures. A model can still exploit blind spots if no verifier sees the variable that matters for the downstream decision.

The Grounded World-Model Chain

Across papers. FlashWorld puts intervention into the transition. VectorWorld chooses state coordinates that expose actors and topology. dWorldEval and control-consistency losses test whether actions actually constrain generated futures. OmniVerifier and VideoKR broaden the evidence so visual plausibility cannot hide semantic or instruction failure.

First-principles read. A world model is a claim about lawful change under partial observation. The model must choose a state, update it under action, render observations from it, and then face tests that inspect the same variables the task depends on.

Big-picture consequence. The useful direction is not bigger video alone. It is generation with an accountable transition: the future should be traceable to the prior state and the action, and the verifier should observe the part of the future where failure would matter.

state + action -> transition -> observation -> verifier projection
FOCUSED CHAIN

Tail-Sensitive Sampling: Modes, Boundaries, And Selected Outcomes

The Core Mathematical Problem

Problem. Many scientific and safety quantities are controlled by small regions of probability space. Average sample quality can be high while the method misses a rare conformer, crosses an unsafe boundary, underweights an abrupt corruption, or fails to produce one exceptional design in a finite batch.

Mathematical object. A target distribution plus a functional of interest: tail probability, rare-mode mass, boundary crossing, likelihood-weighted expectation, or maximum value among sampled candidates.

Why it works. These papers change what the sampler must preserve. The question is not only whether samples look typical; it is whether probability mass is placed correctly where the downstream estimate, safety event, or selection rule is sensitive.

useful sampling = preserve mass where the task functional is large or fragile

SRMC: Missing A Mode Is Biased Measurement

Problem. If a rare mode contributes strongly to an expectation, a sampler that rarely visits it gives the wrong scientific answer even when common samples are excellent.

Mathematical object. Mode coverage and variance of the estimator induced by the sampling process.

Why it works. SRMC treats sampling as measurement. The estimator depends on which regions are visited and with what weight variance. Improving coverage is not aesthetic diversity; it reduces bias and uncertainty in the quantity being estimated.

Failure boundary. If the method discovers visually distinct but low-value modes while missing the physically important one, apparent coverage still fails the task.

Safety-Guided Flow: Move Mass Before It Reaches The Boundary

Problem. A generator can be safe on most samples yet place enough probability near unsafe regions that rare failures remain likely under pressure or repeated use.

Mathematical object. A probability flow whose vector field is shaped by attraction toward valid regions and repulsion from unsafe sets.

Why it works. The constraint acts during transport. Instead of sampling first and rejecting later, the dynamics changes how mass moves, reducing boundary crossings before they become final artifacts.

Failure boundary. The boundary model must match real harm. If the unsafe set is misspecified, the flow can steer away from measured danger while entering unmeasured danger.

dx/dt = useful direction - boundary repulsion

Cauchy-Driven Diffusion Bridges: Put Probability On Jumps

Problem. Some observation processes contain abrupt deviations. A Gaussian noise law treats large jumps as exponentially implausible, which can make the model smooth away the event it must explain.

Mathematical object. A bridge process with heavy-tailed increments.

Why it works. Heavy tails change the geometry of plausible paths. Large deviations are no longer forced into the category of impossible outlier, so reconstruction can follow corruption regimes with jumps, spikes, or bursts.

Failure boundary. Heavy tails help only when abrupt movement is real structure or realistic noise. If the task needs smooth dynamics, they can over-explain ordinary error as jumps.

FALCON: Density Makes Samples Numerically Meaningful

Problem. A molecular sample can look valid while its probability under the equilibrium distribution is unknown, making physical estimates unstable.

Mathematical object. A normalizing flow with tractable density and change-of-variables accounting.

Why it works. The sampler tracks how volume changes as mass is transported. That turns generated conformations into weighted evidence for equilibrium quantities, not just candidates drawn from an opaque generator.

Failure boundary. A tractable density is useful only if the flow family can represent the target distribution. A wrong density with precise arithmetic is still wrong science.

log p(x) = log p(z) - log |det Jacobian|

FIDIA: Optimize The Candidate That Deployment Selects

Problem. Protein design often samples many candidates and tests the best one. Training for average likelihood can improve the middle of the distribution while leaving the deployable winner unchanged.

Mathematical object. The distribution of the maximum score over N samples.

Why it works. Best-of-N selection changes the objective from mean quality to upper-tail quality under a finite budget. FIDIA aligns training with the statistic that downstream selection actually uses.

Failure boundary. Pushing the upper tail can create brittle candidates if the score is incomplete. The selected best sample is only meaningful when the scoring function sees stability, synthesis, and biological constraints.

deployment value = E[max(score(x1), ..., score(xN))]

The Tail-Sensitive Sampling Chain

Across papers. SRMC preserves rare modes for estimation. Safety-Guided Flow changes transport near unsafe boundaries. Cauchy-driven bridges choose a noise law that can represent jumps. FALCON makes probability density inspectable. FIDIA optimizes the selected upper tail rather than the average sample.

First-principles read. Sampling is a measurement procedure over a probability space. The right method depends on which part of the distribution the task reads: common mass, rare modes, boundary events, abrupt corruption, likelihood-weighted expectations, or the maximum of a finite batch.

Big-picture consequence. The page's broader theme becomes sharper: generative quality is not one property. A sampler is good only relative to the mathematical functional that will be computed from its samples.

distribution -> task functional -> sampler design -> estimator or selected artifact
