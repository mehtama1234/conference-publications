Reinforcement learning

The central problem is learning from consequences rather than labels. The hard part is that consequences are often sparse, delayed, noisy, strategic, unsafe to explore, or produced by imperfect verifiers rather than by the world itself.

Problem

As tasks become interactive, long-horizon, embodied, multi-agent, or verifier-driven, supervised imitation is not enough. But RL can become unstable, reward-hack, anti-learn from bad checks, overfit curricula, or trade off safety against reward.

Approaches

The papers use RLVR, curricula, trust regions, posterior behavioral cloning, world-model rollouts, preference rewards, distributional rewards, safe exploration, option learning, diffusion policies, and game-theoretic equilibria.

Connecting read

RL here is less a single algorithm than a control layer around improvement: define feedback, decide how much to explore, constrain updates, and prove the policy is getting better for the reason you think.

TOPIC 01

The Big Picture

Reinforcement learning is the part of machine learning that becomes unavoidable when the system has to try something and live with the result. That is obvious in robotics and games, but it is now also true for language models, agents, visual reasoning systems, scientific controllers, and preference-trained models. The model has to choose a trajectory, receive a score or verifier signal, and update toward better future behavior. The difficulty is that the feedback is rarely clean. It can be binary, delayed, sparse, biased, noisy, shaped by other agents, or unsafe to collect directly.

The papers on this page are best read as attempts to make consequence-based learning usable under those imperfect feedback conditions. Some work improves the reward signal itself, by redistributing tail-risk rewards, propagating sparse preferences, learning dense progress from video, or diagnosing verifier noise. Some work stabilizes the update, by replacing blunt clipping with variance constraints, sparse KL projection, or closed-form KL-regularized policy steps. Some work improves exploration, by using curricula, curiosity, uncertainty, staged interactions, option hierarchies, or world-model imagination. Some work makes RL respect constraints: safety, fairness, delayed observations, ambiguity, equilibrium behavior, or physical feasibility.

TOPIC 02

The concrete object is the consequence loop

An RL paper is about a loop of action, consequence, feedback, and update: policy trajectory, reward signal, verifier score, exploration rule, world model, constraint set, equilibrium, or action representation.

What must stay fixed is the decision problem the policy is supposed to improve. Reward-quality papers must preserve the real behavior the reward claims to teach. Preference papers must preserve the preference or KL geometry being optimized. Exploration papers must preserve the environment and information objective. Offline-RL papers must preserve behavior support. Safety and fairness papers must preserve constraints, not treat them as post-hoc metrics. Multi-agent papers must preserve the payoff and interaction structure.

What may change is the feedback shaping, update rule, trust region, exploration schedule, posterior imitation distribution, world-model rollout, conservative controller, or equilibrium learner. The method works when the changed loop improves future behavior for the claimed reason without anti-learning, unsafe exploration, support collapse, or constraint violation. The failure boundary is reward illusion: return goes up because the feedback was exploitable, not because the policy learned the intended consequence.

TOPIC 03

What Has To Be Controlled

Reward Quality

RL only improves behavior if feedback points in the right direction. Verifier noise, sparse success, preference labels, process rewards, dense video rewards, and inverse reward distributions define what the policy is actually learning.

Exploration

The learner has to try enough new behavior without drowning in useless or unsafe attempts. Curricula, curiosity, entropy control, uncertainty-guided turns, self-play, and staged environments all address that budget.

Update Stability

Policy updates can destroy useful behavior. Trust regions, KL constraints, variance limits, residual critics, posterior BC, isotropic representations, and data anchors control the update geometry.

World Models

Latent dynamics, sensor imagination, reward-free predictive models, and scalable robotic world models let policies learn from possible futures rather than only from expensive real interaction.

Constraints

Safe deployment, fairness, ambiguity, tail risk, delayed observations, causal constraints, and feasible action sets require guarantees beyond expected reward.

Strategic Interaction

In multi-agent settings, other policies react. Stackelberg games, mean-field games, auctions, human-robot MARL, and inverse games make learning a problem of equilibrium, not just reward maximization.

TOPIC 04

The reward is only useful if it preserves the consequence

The simplest way to understand this cluster is that RL turns feedback into future behavior, so the feedback has to remain attached to the consequence we actually care about.

A verifier score is useful only if it separates correct from incorrect behavior. A preference label is useful only if the update preserves the behavior support that made the model competent. A curiosity reward is useful only if it finds states that improve control. A world model is useful only if imagined futures preserve the real dynamics. A safety constraint is useful only if it stays active while the policy improves. A multi-agent update is useful only if it remains stable when other agents respond.

That is the common object across RLVR, preference RL, world models, offline RL, safe RL, bandits, options, and multi-agent games. Each paper changes one part of the loop, but the consequence being learned must stay fixed enough that higher return still means better behavior rather than a better exploit.

EVIDENCE

What would prove RL improved the consequence loop

The proof has to show that better return came from better behavior under the intended feedback, not from exploiting a weak reward, verifier, simulator, or benchmark.

Reward validity

Verifier, preference, process, dense-video, or distributional rewards should point toward the intended behavior and reveal when they create anti-learning.

Update stability

KL, trust-region, ratio-variance, posterior-BC, and residual-critic methods must improve policy behavior without destroying useful support.

Exploration value

Curiosity, entropy, curricula, self-play, and staged environments should discover states that teach the task, not merely increase novelty.

Support preservation

Offline and imitation-based methods should show that improvement stays grounded in behavior support or a justified extrapolation rule.

Constraint survival

Safety, fairness, ambiguity, tail-risk, feasibility, and delay constraints must stay active during learning, not appear only as after-the-fact metrics.

Strategic stability

Multi-agent methods need evidence that policies improve under other agents' adaptation, equilibrium structure, or incentive constraints.

FAILURE MODES

How RL papers can learn the wrong thing

RL fails when the loop optimizes a proxy consequence while the real task, constraint, or interaction structure has slipped away.

FailurePlain meaningWhere it appears
Verifier anti-learningThe reward checker is wrong often enough that RL trains away from correct behavior.RLVR, critique, process-reward, and reasoning-RL papers.
Reward hackingThe policy finds behavior that scores well but does not satisfy the intended task.Preference rewards, programmatic feedback, dense rewards, and agent environments.
Support collapseThe update moves outside the data or behavior distribution that made the policy competent.Offline RL, behavioral cloning, KL-regularized preference learning, and trust-region methods.

CLUSTERS

The Main Research Moves

1. Verifier and reward quality determine whether RL learns or anti-learns

A major lesson is that a reward signal is not automatically useful because it is scalar. RLVepsR makes this explicit by showing RL with verifiable rewards can learn, stall, or anti-learn depending on verifier quality measured by Youden's index. MaxRL reframes binary terminal-feedback RL as likelihood maximization over correct rollouts, clarifying what terminal success feedback is doing. PG Post-Training treats process rewards as search-space compression, replacing sequence-level coverage dependence with token-level likelihood quantiles. Critique-GRPO improves reasoning by internalizing critique-guided exploration. Ctrl-R steers rollouts toward rare reasoning patterns and corrects learning with importance sampling. Together these papers say RL for reasoning is mostly about constructing feedback that teaches the right latent process, not just rewarding a final answer.

2. Preference and human feedback need policy updates with geometry

Preference RL is an update-geometry problem as much as a data problem. RePO derives a closed-form KL-regularized update for RLHF-style preference learning, and JitRL grounds training-free adaptation in the same kind of KL-constrained policy optimization. Trust-Region LLM RL replaces PPO-style clipping with sparse differentiable KL projection over important token logits. R2VPO replaces hard clipping with policy-ratio variance constraints so high-return gradients are not thrown away unnecessarily. VOTP uses optimal transport in video foundation model space to propagate sparse preference labels across trajectories. These papers are all trying to update strongly enough to learn while preserving the distributional support that made the policy competent.

3. Exploration has to be shaped, not merely increased

More exploration is useful only when it reaches learnable states. SOAR uses asymmetric teacher-student meta-RL to create curricula for hard sparse-reward tasks even when initial success is zero. T2PO controls token- and turn-level exploration in multi-turn agents through uncertainty dynamics and progress resampling. Entropy Control adapts entropy coefficients during LLM RL to balance broad search against convergence. AgentGym-RL stabilizes agent training by expanding from short-horizon to longer environment interactions. GLANCE turns mismatch between linguistic predictions and visual reality into intrinsic reward. ABOM discovers evolutionary search operators from closed-loop population feedback for black-box optimization and UAV path planning. The pattern is that exploration has to be staged, measured, and tied to information gain.

4. Behavior cloning and offline data are useful only if they preserve coverage

Several papers treat supervised pretraining as a starting distribution that can either help or trap later RL. Posterior Behavioral Cloning models the posterior over demonstrator behavior so action coverage survives into RL finetuning. SCIQL optimizes high-quality offline behavior while preserving style supervision from subtrajectory labels. TG-DT aligns task descriptions with behavior trajectories to support zero-shot target-task adaptation without demonstrations. DLM converts heterogeneous multi-agent trajectories into dialogue-style sequence prediction with executable actions. DAWN warms residual RL critics from base-policy transitions to avoid cold-start pathology. The conceptual point is that offline data is not just a dataset; it is the behavior support on which later improvement depends.

5. World models let policies spend compute before acting

Model-based RL appears here as a way to reason about consequences before paying real-world cost. WestWorld pretrains across 89 environments and improves zero- and few-shot prediction plus downstream robotic control. TD-JEPA learns reward-free long-term latent dynamics across policies so arbitrary test-time rewards can be applied later. LASER imagines sensing scenarios with intrinsic rewards for sparse physical-field reconstruction. TimeRewarder learns dense progress rewards from passive video, making human activity footage usable for robotic RL. Role of Computation in RL formalizes policies whose fixed parameters can solve more tasks by spending more computation. In this cluster, capability is not only in the policy weights; it is in the ability to simulate or deliberate over consequences.

6. Safety and fairness change the objective, not just the metric

Constrained RL papers make clear that expected return is often the wrong single target. Reward Redistribution for CVaR MDPs builds dynamic programming and Q-learning algorithms for tail-risk tradeoffs. Conformal Policy Control calibrates how aggressively a new policy can act under a user-declared risk tolerance. Fair Causal Bandits enforces direct, indirect, and spurious fairness-effect constraints during online learning. Adaptive Bias finds explicit exploration incentives reduce unfair task-allocation stratification. Ambiguity-Averse MDPs treats uncertain transitions as random variables and derives Bellman-style algorithms under compatible risk measures. Pi-net uses feasible-by-design neural projection layers as fast constrained motion-planning proxies. These papers put constraints inside learning, not after it.

7. Multi-agent RL is equilibrium learning

When more than one learner acts, the target moves. Structured Stackelberg Games uses predictive context to learn leader policies against follower types. RQE Actor-Critic targets risk-averse quantal response equilibria for globally convergent actor-critic in general-sum Markov games. RSPG extends structural policy gradients to partially observable mean-field games with recurrent policies. NonZero uses local deviation proposals and mixed-difference interaction scores to avoid exponential joint-action enumeration. HALO rectifies decentralized gradients with Lyapunov-style projections to prevent oscillation and divergence. First-Price Auctions proves revenue preservation under no-swap-regret dynamics. The shared issue is that improvement has to be stable under other agents' adaptation.

8. Embodied control needs compact action structure

Robotics and continuous control papers focus on action representations that are small enough to learn and rich enough to execute. Chebyshev Policies use polynomial bases to reduce regret with far fewer parameters in low-dimensional control. JoSE maps latent actions to muscle commands through closed-form precoders under control-affine Gaussian dynamics. MSP combines scale-wise autoregressive conditions with MeanFlow refinement for efficient long-horizon robotic control. ScaleMoE adds expert specialization to actor and critic networks, improving returns as expert count grows. SOL scales hierarchical option learning to tens of billions of NetHack frames. HSR builds temporally abstract successor representations that are robust across policies. The action space is not a given; it is part of the learning problem.

9. Theory supplies regret, delay, and memory guarantees

The formal RL papers sharpen what is possible under limited feedback. BCO Gradient Variation establishes dynamic and universal regret bounds for two-point bandit convex optimization. BFTS uses Bayesian additive regression trees and posterior draws for nonlinear contextual bandits. Delayed-Observation RL combines state augmentation and UCB to get near-optimal regret under random observation delays. Linear Recurrent Memory constructs filters that recover HMM belief logits or reduce state ambiguity in near-deterministic systems. POPGym Arcade provides controlled partially observable environments for diagnosing memory. Feasible Payoffs gives learning-theoretic foundations for inverse games under equilibrium observations. These papers matter because interaction data is expensive, and regret, memory, and delay decide whether learning is feasible.
