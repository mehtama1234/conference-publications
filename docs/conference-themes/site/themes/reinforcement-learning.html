Problem

As tasks become interactive, long-horizon, embodied, or verifier-driven, supervised imitation is not enough. But RL can be unstable, reward-hack, overfit curricula, or trade off safety against reward.

Approaches

The papers use RLVR, safe RL, curricula, policy optimization, world-model rollouts, preference rewards, diffusion policies, and environment-specific credit assignment.

Connecting read

RL is being used less as a generic algorithm and more as a way to make models improve through attempts, feedback, and constraints.

SUBTHEMES

What the papers are actually about

Ambiguity-averse dynamic programming

ICML 2026Ambiguity-Averse MDPs
Treats uncertain transitions as random variables and derives Bellman-style algorithms under compatible risk measures.

BART Thompson sampling

ICML 2026BFTS
Uses arm-wise Bayesian Additive Regression Trees and MCMC posterior draws for nonlinear contextual bandits.

Bandit feedback variation guarantees

ICML 2026BCO Gradient Variation
Establishes gradient-variation dynamic and universal regret bounds for two-point BCO.

Chebyshev low-dimensional policies

ICML 2026Chebyshev Policies
Uses polynomial policy bases to reduce regret while using 277x fewer parameters on low-dimensional control.

Closed-form KL-constrained logit updates

ICML 2026JitRL
Grounds training-free policy adaptation as the solution to a KL-constrained policy optimization objective.

Compute-bounded policy capability

ICML 2026Role of Computation in RL
Formalizes policies whose fixed parameters can solve more tasks by using more computation.

Constrained neural motion-planning proxy

ICLR 2026Pi-net
Uses feasible-by-design networks as fast parametric constrained optimization solvers.

Constrained-order GRPO for dLLMs

ICML 2026JustGRPO
Forgoes arbitrary-order RL complexity while retaining parallel decoding and strong GSM8K performance.

Contextual follower-type learning

ICML 2026Structured Stackelberg Games
Uses predictive context to learn utility-maximizing leader policies in structured Stackelberg games.

Controlled reasoning trajectory exploration

ICML 2026Ctrl-R
Guides rollouts toward rare reasoning patterns and corrects learning with importance sampling.

Counterfactual fair contextual bandits

ICML 2026Fair Causal Bandits
Enforces causal direct, indirect, and spurious fairness-effect constraints during online bandit learning.

Critic-gradient policy smoothness

ICML 2026PAVE
Stabilizes the Q-function action-gradient field to smooth continuous-control policies without actor changes.

DPO-compatible regret minimization

ICML 2026RePO
Derives a closed-form KL-regularized policy update for RLHF-style preference learning.

Data-anchored residual RL critic warmup

ICML 2026DAWN
Uses base-policy transitions as value anchors to avoid cold-start pathology in residual RL.

Decision language model for offline MARL

ICML 2026DLM
Converts heterogeneous multi-agent trajectories into dialogue-style sequence prediction with executable actions.

Distributional inverse RL

ICML 2026Distributional IRL
Recovers reward distributions and distribution-aware policies through FSD violation minimization.

Dynamic exploration-exploitation control

ICML 2026Entropy Control
Adapts entropy coefficients during LLM RL and improves Pass@K on AIME and puzzle tasks.

Exploration incentives for fairness

ICML 2026Adaptive Bias
Finds explicit exploration incentives most robustly reduce unfair task-allocation stratification.

Flow-based hierarchical imitation policy

ICML 2026MSP
Combines scale-wise autoregressive conditions with lightweight MeanFlow refinement for efficient robotic control.

Functional alignment for interleaved reasoning

ICML 2026Faire
Uses RL constraints so generated plots causally support geometric reasoning instead of merely matching trace format.

Hierarchical successor representation

ICML 2026HSR
Builds policy-robust predictive features by incorporating temporal abstractions into successor representations.

High-throughput option learning

ICML 2026SOL
Scales hierarchical policy gradients to 30 billion NetHack frames and about 35x higher throughput.

History-aware structural MFG learning

ICML 2026RSPG
Extends hybrid structural policy gradients to partially observable mean-field games with recurrent policies.

Interaction-guided multi-agent MCTS

ICML 2026NonZero
Uses local deviation proposals and mixed-difference interaction scores to avoid exponential joint-action enumeration.

Isotropic Gaussian RL representations

ICML 2026Isotropic Gaussian RL
Regularizes hidden embeddings toward isotropic Gaussian geometry to stabilize tracking under non-stationarity.

LLM state-value estimation benchmark

ICML 2026Hista/Numca
Diagnoses PPO critic collapse to group-average baselines and evaluates state values inside LLM RL.

Latency-aware closed-loop scientific control

ICML 2026NeuronCtrl
Distills multi-step generative control into single-step policies while preserving action and field safety filtering.

Latent imagination for sensor control

ICML 2026LASER
Simulates what-if sensing scenarios with intrinsic rewards for sparse field reconstruction.

Learning-theoretic inverse game foundations

ICML 2026Feasible Payoffs
Provides minimax-optimal rates for exact and approximate equilibrium play in zero-sum and general-sum games.

Lightweight adaptive policy interfaces

ICML 2026APB
Adapts only pre- and post-backbone linear layers around a frozen policy backbone for task generalization.

Linear recurrent belief-memory filters

ICML 2026Linear Recurrent Memory
Constructs linear filters that recover HMM belief logits or reduce state ambiguity under near-deterministic transitions.

Mask-evolved continual policies

ICML 2026Nevo-CRL
Evolves task-specific activation masks over a fixed policy network to prevent forgetting and reuse prior skills.

Maximum-likelihood RL objective

ICML 2026MaxRL
Reframes binary terminal-feedback RL as likelihood maximization over correct rollouts.

Mean-expansion Q-value sharing

ICML 2026Mean-Expansion Q-Learning
Shares value structure across actions within a state to accelerate Q-learning with a parameter-free layer.

Memory diagnostics for partially observable RL

ICML 2026POPGym Arcade
Provides controlled fully/partially observable Atari-like environments with shared action/observation spaces.

Minimax delayed-observation RL

ICML 2026Delayed-Observation RL
Combines state augmentation and UCB to achieve near-optimal regret under random state-observation delays.

MoE scaling for continuous control

ICML 2026ScaleMoE
Adds expert specialization to actor and critic networks, improving returns as expert count increases.

Model-based control through scalable world models

ICML 2026WestWorld
Pretrains across 89 environments and improves zero/few-shot prediction and downstream robotic control.

No-swap-regret auction revenue guarantees

ICML 2026First-Price Auctions
Proves approximate correlated equilibria under no-swap-regret dynamics preserve revenue near the second-highest value.

OT pseudo-labeling for preference RL

ICML 2026VOTP
Uses optimal transport in video foundation model space to propagate sparse preference labels to unlabeled trajectories.

Optimal precoding for dexterous control

ICML 2026JoSE
Maps latent actions to muscle commands through closed-form precoders under control-affine Gaussian dynamics.

Passive-video dense reward learning

ICML 2026TimeRewarder
Learns frame-wise temporal distance from passive videos to provide dense progress rewards for robotic RL.

Policy-parameter Lyapunov certification

ICML 2026HALO
Rectifies decentralized gradients through quadratic projections to avoid oscillation and divergence.

Posterior coverage for BC pretraining

ICML 2026Posterior Behavioral Cloning
Models the posterior over demonstrator behavior to preserve action coverage for RL finetuning.

Process rewards as search-space compression

ICML 2026PG Post-Training
Replaces sequence-level coverage dependence with token-level likelihood quantiles.

Ratio-variance policy trust regions

ICML 2026R2VPO
Replaces hard clipping with policy-ratio variance constraints to preserve useful high-return gradient signals.

Reverse flow matching for generative policies

ICML 2026RFM
Trains diffusion and flow policies for Q-induced Boltzmann targets without direct target samples.

Risk-averse MARL equilibrium learning

ICML 2026RQE Actor-Critic
Uses risk-averse quantal response equilibria to obtain globally convergent actor-critic for general-sum Markov games.

Safe exploration from deployment

ICML 2026Conformal Policy Control
Calibrates how aggressively new policies can act while respecting user-declared risk tolerance.

Sample-level RL for discrete diffusion

ICML 2026UDM-GRPO
Stabilizes GRPO by treating final clean diffusion samples as actions and reconstructing trajectories forward.

Second-order OT-smoothed planning

ICML 2026SecondOrderSmoothCruiser
Uses optimal-transport Bellman smoothing and quadratic correction for epsilon^-3 planning oracle complexity.

Self-critiquing reasoning improvement

ICML 2026Critique-GRPO
Internalizes critique-guided exploration and improves Pass@1 across Qwen and Llama reasoning tasks.

Self-play curricula at zero success

ICML 2026SOAR
Uses asymmetric teacher-student meta-RL to generate learnable reasoning curricula for hard tasks with sparse binary rewards.

Sparse trajectory reward broadcasting for agent planning

ICLR 2026AgentFlow
Uses Flow-GRPO to convert multi-turn outcomes into stabilized single-turn planner updates.

Staged interaction scaling for agent training

ICLR 2026AgentGym-RL
Expands from short-horizon to longer environment interactions to stabilize RL exploration.

Style-conditioned offline implicit Q-learning

ICML 2026SCIQL
Optimizes high-quality offline behavior while preserving style supervision from subtrajectory labels.

TD-based latent predictive zero-shot RL

ICLR 2026TD-JEPA
Learns reward-free long-term latent dynamics across policies for arbitrary test-time rewards.

Tail-risk reward redistribution

ICML 2026Reward Redistribution for CVaR MDPs
Builds value-iteration and Q-learning algorithms over discretized augmented states for performance-safety tradeoffs.

Text-guided zero-shot Decision Transformers

ICML 2026TG-DT
Aligns task descriptions with behavioral trajectories for target-task adaptation without demonstrations.

Token-level trust-region RL for LLMs

ICLR 2026Trust-Region LLM RL
Replaces PPO-style clipping with sparse differentiable KL projection over important token logits.

Uncertainty-guided agentic exploration

ICML 2026T2PO
Controls token- and turn-level exploration in multi-turn agent RL using uncertainty dynamics and progress resampling.

Verifier-noise phase transition

ICML 2026RLVepsR
Shows RLVR learns, stalls, or anti-learns depending on Youden's index of noisy verifiers.

Visual-linguistic curiosity for VLM agents

ICML 2026GLANCE
Turns mismatch between linguistic predictions and visual reality into intrinsic exploration reward.

Zero-shot evolutionary operator adaptation

ICLR 2026ABOM
Uses closed-loop population feedback to discover search patterns for synthetic BBO and UAV path planning.
