First-principles concept

Scientific generation must preserve the native object

A scientific sample is not just a string, image, or vector. It is a molecule, protein, wavefunction, PDE field, cell image, or physical state with rules that existed before the model.

CORE

The representation must respect the thing being generated

Scientific generation fails when the model solves a convenient proxy while breaking the native object.

A molecule rotated in space is the same molecule. A protein has hierarchy from global fold to local backbone detail. A wavefunction must evolve under physical constraints. A PDE simulation must be checked against real measured systems. A molecule token should carry makeable chemical structure. A microscopy latent should preserve spatial organization, not only pixel reconstruction.

The first-principles question is therefore: what is the native object and what rules make it valid? Quotient-Space Diffusion removes redundant rigid-body degrees of freedom instead of asking the model to learn them. Protein Autoregressive Modeling uses coarse-to-fine structure. OrbEvo preserves equivariant quantum rollout. mCLM tokenizes molecules into synthesis-compatible units. RealPDEBench checks simulation against measured physical data. SI-VAE adds spatial-statistical structure to biological image latents.

Core rule
A scientific generator should be judged by whether the generated object remains valid in the domain's own terms.
FIRST PRINCIPLE

The domain object comes before the model format

Scientific generation is judged by the object science cares about, not by the easiest representation to generate.

A protein is not merely coordinates. A molecule is not merely a string. A PDE field is not merely an image-like grid. A wavefunction is not merely a vector sequence. A microscopy image is not merely pixels. These carriers are useful because models need inputs and outputs, but the domain object has rules that existed before the model: symmetry, conservation, synthesis, hierarchy, measurement, and function.

The danger is proxy success. A model can make a sample that looks plausible to a generic metric while breaking the native object. It can learn coordinate artifacts, local protein fragments without global coherence, molecular tokens without makeability, simulated fields without measured behavior, or image latents without biological organization. The first-principles move is to name the native object before choosing the generator.

First-principles test
Ask what the generated thing is in the domain's own language, then test the rule that would make a scientist reject it.

METHOD

Why native checks beat generic scores

A scientific model should fail where the science would fail it.

Generic likelihood, reconstruction loss, visual realism, or embedding similarity can be useful diagnostics, but they do not define scientific validity. A molecule can have high likelihood and poor synthesis. A generated PDE state can look smooth and violate the measured system. A protein fragment can look locally plausible and fail global folding logic. A brain-to-image reconstruction can look recognizable while the neural evidence bridge is unclear.

The method rule is to test the native rejection conditions. Rotate the molecule and require consistent behavior. Roll out the wavefunction and check error growth. Compare simulation to real measurements. Test chemical makeability. Probe whether microscopy latents preserve spatial point patterns. Scientific generation is not finished until the generated object is valid under the domain rules that would be used outside the model.

FAILURES

How scientific generators fake progress

A generated sample can look plausible while violating symmetry, chemistry, conservation, physical rollout, biological spatial structure, or real measurement behavior. It can score well on a proxy while becoming unusable to a scientist. This is why domain-native checks matter more than surface similarity.

The right abstraction is not always the easiest input format. A molecule string, coordinate cloud, image tensor, or simulation grid may be a convenient carrier, but the scientific object has its own invariants. The model should preserve those invariants directly when possible and test them explicitly when not.

FAILURE MAP

How the native object gets replaced

Coordinate artifact

The generator learns arbitrary orientation or position instead of physical structure.

Proxy molecule

A token string scores well but does not preserve synthesis or useful chemistry.

Local protein

Backbone details look plausible while global fold constraints are broken.

Simulation comfort

The model succeeds on synthetic fields but fails on measured systems.

Rollout decay

A short-step predictor accumulates physical error over time.

Pixel surrogate

A latent reconstructs images but loses biological spatial organization.

CONNECTION

Why this idea cuts across the atlas

Native-object preservation is grounding for scientific domains.

Grounding says the answer must depend on the evidence. Scientific generation says the sample must remain the domain object it claims to be. Modality contracts ask what each signal owns; scientific generation asks what the domain owns. Causality matters when generated objects are meant to change outcomes rather than only resemble data.

The simple rule is to distrust any generated scientific artifact until the native object, native constraints, and native verifier are visible.
