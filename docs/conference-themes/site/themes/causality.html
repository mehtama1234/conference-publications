Theme 43 - ICML 2026

Causality as local structure for decisions

The shared problem is simple to state: prediction tells us what tends to happen together, but many scientific and operational questions ask what would happen if something changed. The papers here push causal learning away from reconstructing an entire hidden world and toward finding the smallest reliable structure needed for the causal question at hand.

FIRST PRINCIPLES

What causality adds beyond correlation

A predictive model can learn that treatment, symptoms, demographics, and outcome move together. A causal method asks a stricter question: if we changed one variable while holding the right parts of the world fixed, what would change downstream? That question cannot be answered from association alone. It needs assumptions about hidden causes, adjustment variables, graph structure, or conditional independences.

The hard part is that the full causal graph is usually not available. Real data can include latent variables, post-treatment covariates, noisy measurements, and too many variables to recover a complete structure. The useful 2026 move is not "learn the whole graph better" in every case. It is to identify when a smaller object is enough: a valid local adjustment set for one effect, or the conditional-independence tests that determine sample complexity for a graph class.

Target quantity

The causal question should come first. Estimating one average treatment effect may need a different structural object than recovering a full Bayesian network.

Identification boundary

A useful causal method should say when the target is identifiable and which assumptions carry that claim, rather than only outputting a plausible covariate list or graph.

Statistical primitive

For structure learning, the bottleneck can reduce to conditional-independence testing. If that primitive is weak, graph recovery is weak too.

BIG PICTURE

The connecting problem

Both papers are about disciplined refusal to overbuild. Local Covariate Selection says that causal effect estimation does not always require global causal discovery. If the target is an average causal effect, the method should find whether an adjustment set exists around the treatment and outcome, including settings with latent variables and without the usual pretreatment restriction. Structure Learning CI makes a parallel theoretical move: rather than treating structure learning as a monolithic graph-recovery problem, it asks which primitive determines the minimax rate, then shows that conditional-independence testing governs the difficulty for poly-forests.

This matters because causal methods often fail by being both too ambitious and too opaque. A global graph can look precise while resting on fragile tests, hidden-variable assumptions, or finite-sample artifacts. A causal estimate can look actionable while depending on an adjustment set whose validity was never established. These papers try to make the load-bearing part visible: the local adjustment boundary in one case, and the CI-testing rate in the other.

CORE

Causal claims have different strengths

The first mistake is to treat every causal-looking sentence as equally strong.

"X predicts Y" is a weak claim. It says two quantities move together. "Changing X would change Y" is stronger. It says an intervention would move the outcome. "We can estimate the size of that change from these observations" is stronger still, because it says the available data and assumptions identify the effect. "We can recover the whole graph" is a different and often harder claim, because it asks for many causal relationships rather than one target effect.

Local Covariate Selection lives in the middle of this ladder. It does not ask for the whole graph if the scientific question is one treatment effect. It asks which covariates, if adjusted for, make that one causal estimate credible. Structure Learning CI lives at the graph-recovery level. It asks how many samples are needed to recover structure in a restricted graph family, and it shows that the answer depends on the difficulty of conditional-independence testing.

TOPIC 01

The target comes before the graph

A causal method should start by asking what causal question needs to be answered.

This is the cleanest way to understand the page. If the question is one treatment effect, the system may not need the whole causal graph. It needs enough structure to justify comparing treated and untreated cases. If the question is graph recovery, the system needs many edge decisions and the statistical machinery that supports them. Those are different jobs.

Local Covariate Selection is important because it refuses to solve a larger problem than the effect estimate requires. Structure Learning CI is important because it studies the larger graph-recovery problem and identifies its bottleneck. Together they teach a simple rule: causal evidence should be sized to the claim being made.

TOPIC 02

Adjustment is a contract about what stays fixed

To estimate an effect, the method has to decide which background facts must be held fixed so the treatment comparison is fair.

A naive comparison asks whether treated and untreated cases have different outcomes. That is not enough, because the groups may differ for reasons that caused both the treatment and the outcome. Adjustment tries to repair the comparison by holding fixed the right covariates. But "right" is the entire causal problem. Adjust for too little and confounding remains. Adjust for the wrong variable and the method can create bias.

Local Covariate Selection treats the adjustment set as the concrete object. The method must preserve the treatment, outcome, estimand, observed variables, and assumptions about latent structure. What may change is which covariates are selected. The selected set is valid only if it makes the causal comparison mean the intervention question the paper claims to answer.

TOPIC 03

Local sufficiency is weaker than causal omniscience

A method can be useful without knowing the whole causal world, as long as it knows enough for the target effect.

This is a practical principle. Real scientific and operational settings rarely provide a complete causal graph. Some variables are latent. Some are measured after treatment. Some are irrelevant to the target. A method that demands complete causal sufficiency or full pretreatment information may be clean in theory but unusable in the setting where the question matters.

The local view says: find the boundary around the treatment and outcome that determines whether adjustment is possible. If the boundary is strong enough, estimate the effect. If it is not, say that the effect is not identified under the assumptions. That refusal is part of the method working, because an unsupported effect estimate is worse than an honest non-answer.

TOPIC 04

Graph learning is built from conditional-independence evidence

When the target really is structure recovery, the hard primitive is deciding which variables become independent after conditioning.

A graph-learning algorithm can look like a global search procedure, but much of its evidence comes from repeated conditional-independence questions: are these variables still related once we condition on this set? If the answer is reliable, the graph learner can remove or orient edges. If the answer is noisy or underpowered, the graph becomes fragile.

Structure Learning CI makes that dependence explicit for poly-forest graphical models. Its minimax message is first-principles useful: the sample complexity of structure learning is controlled by the sample complexity of the independence tests beneath it. The graph is only as trustworthy as the statistical primitive that built it.

TOPIC 05

The honest output may be a boundary, not a story

Sometimes the most causal answer is not "X causes Y." It is "this effect is identifiable under these assumptions" or "this graph cannot be recovered with this evidence."

That is why this page fits the broader first-principles atlas. Causal methods are valuable when they preserve what the evidence can and cannot prove. A local adjustment method should expose the adjustment boundary. A structure-learning method should expose the conditional-independence bottleneck. A scientific agent using these methods should not turn those boundaries into a confident narrative.

The failure mode is causal theater: a model names a cause, draws a graph, or recommends an intervention because that looks useful, while the available evidence supports only association, an underidentified effect, or a fragile graph. The deeper principle is that causal ML is not about sounding explanatory. It is about earning the right to answer an intervention question.

ANATOMY

The concrete object is the causal target

A causality paper is about the object that justifies action: a target effect, adjustment set, conditional-independence test, graph family, equivalence class, or decision-support claim.

What must stay fixed is the causal question. Local Covariate Selection must preserve the treatment, outcome, estimand, observed variables, and assumptions about hidden structure. Structure Learning CI must preserve the graph family, distribution family, sample model, and meaning of conditional independence. If those fixed pieces move, the method may still return a graph or estimate, but it is answering a different causal question.

What may change is the local adjustment set, tested conditioning set, edge decision, or graph recovery procedure. The method works when the changed causal object is strong enough for the claimed action without requiring unnecessary global structure. The failure boundary is causal overclaiming: the system reports a clean cause, graph, or effect while the available evidence only supports association or an underidentified set of alternatives.

METHOD

Why local structure can be enough

A causal problem should be sized to the decision it has to support.

If the question is whether a treatment changes an outcome, recovering unrelated relationships elsewhere in the system may be unnecessary. The key is to block the wrong paths and preserve the right comparison. Adjustment is the act of making the treated and untreated groups comparable with respect to the background facts that would otherwise confuse the effect. The hard part is deciding which background facts are legitimate to hold fixed. Some variables are confounders. Some are consequences of treatment. Some are proxies for hidden causes. Some are irrelevant. Local Covariate Selection is about finding the boundary where adjustment remains valid without demanding a complete global map.

Structure Learning CI teaches the complementary lesson. When the target really is graph recovery, the work reduces to many smaller yes-or-no questions: are two variables independent once we condition on the right set? If those tests are noisy, biased, or sample-starved, the recovered graph inherits that weakness. This is why the paper's minimax result is conceptually useful: it points to the bottleneck. The graph learner is not a mysterious causal oracle. It is a scaffold built out of conditional-independence evidence.

EVIDENCE

What would prove the causal method earned its claim

The proof has to match the strength of the causal sentence. Association needs prediction evidence; an effect estimate needs identification; graph recovery needs reliable conditional-independence evidence.

Target clarity

The paper must name the treatment, outcome, estimand, graph family, or decision target before claiming causal success.

Adjustment validity

For Local Covariate Selection, the selected covariates must satisfy the conditions that make the average causal effect identifiable under the stated latent-variable assumptions.

Local completeness

The method should say not only when an adjustment set works, but when no valid local adjustment set exists under the assumptions.

CI-test calibration

For Structure Learning CI, conditional-independence tests must be calibrated to the distribution family, sample size, and graph class being recovered.

Finite-sample honesty

Graph recovery evidence should expose how sample limits, weak dependencies, and conditioning-set size affect edge decisions.

Uncertainty boundary

A useful causal system should report when the data supports only association, an equivalence class, or an underidentified target rather than a clean intervention claim.

SUBTHEMES

What the papers are actually about

Local covariate selection for a specific causal effect

adjustment

Local Covariate Selection starts from a practical frustration: to estimate an average causal effect, researchers often need to choose adjustment variables, but many existing procedures either assume that all relevant variables are observed, require learning a full global causal graph, or restrict candidate covariates to pretreatment variables. Those assumptions are often mismatched to real data. The paper instead characterizes the local existence boundary of adjustment sets, then builds a local learning method for nonparametric causal effect estimation. The conceptual contribution is that validity can be local: if the downstream question is one treatment-outcome effect, the method should focus on the structural neighborhood that determines whether adjustment is sound, rather than spending all its effort reconstructing unrelated parts of the system.

Paper
Local Covariate Selection
Approach
Characterizes when local adjustment sets exist, then learns covariates for average causal effect estimation while allowing latent variables and removing the pretreatment assumption.
Why it matters
It turns causal effect estimation into a targeted identification problem. The output is not "a graph"; it is the adjustment structure needed to make one causal estimate credible.

Structure learning is only as good as its independence tests

graph recovery

Structure Learning CI looks at causal and graphical structure from the opposite angle. If the goal is to recover graph structure, what determines the best possible sample rate? The paper shows that, for poly-forest graphical models, the minimax optimal rate for structure learning is determined by the minimax rate for conditional-independence testing. That is a clarifying result because it identifies the primitive underneath a large class of graph-learning procedures. A modified PC algorithm can be optimal when the independence tests are calibrated to the distribution family, including Bernoulli, Gaussian, and nonparametric settings. The first-principles lesson is that structure learning is not magic graph search; it is repeated statistical testing under graph assumptions.

Structure Learning CI
Approach
Reduces structure learning in poly-forests to conditional-independence testing, derives minimax rates, and shows modified PC procedures can be optimal.
Why it matters
It tells us where the statistical difficulty lives. Better graph recovery requires better tests, clearer model-class assumptions, and honest finite-sample behavior.
SYNTHESIS

Why this matters for agents, science, and benchmarks

Causality is becoming infrastructure for systems that must act, not only classify. Scientific agents, healthcare assistants, policy tools, and debugging systems all need to distinguish "this variable predicts failure" from "changing this variable would reduce failure." The conference evidence around this page repeatedly shows the same pressure: methods become more useful when they expose the structural object that justifies action. Sometimes that object is a local adjustment set. Sometimes it is a graph equivalence class, a root-cause posterior, or a conditional-independence test family.

The practical implication is that causal tasks need more than prompt, answer, and score. They need the causal target, available observations, assumed hidden variables or sufficiency conditions, allowed interventions, adjustment candidates, and the verifier's criterion. Otherwise a model can produce a fluent causal explanation while never proving that the proposed adjustment or intervention is identifiable.

CONCEPT BRIDGES

Where to read the larger pattern

Causality starts where prediction stops

Prediction can say two things move together. Causality asks what would change if one thing were intervened on, and what assumptions make that answer identifiable.

Uncertainty is a decision object

Causal uncertainty is not decoration around an estimate. It decides whether to intervene, gather more evidence, narrow the graph class, or refuse a stronger claim.

Scientific generation preserves the native object

A causal graph, adjustment set, and effect estimate each has validity rules. The generated explanation is useful only when those native objects stay intact.
