Problem

Human vision is selective: fixation carries detail, while the periphery carries gist. A useful model of perception has to represent that uneven information budget instead of treating the full image as uniformly available.

Approaches

The evidence centers on foveated latent-diffusion generation, where scenes are synthesized to match peripheral scene structure and fixation-level detail.

Connecting read

This theme connects cognitive science to generative modeling by using image synthesis as an experimental instrument for testing what a human percept actually preserves.

READ

The Big Picture

The important idea is that perception is not a photograph stored in the head. People look at scenes through a high-resolution center and a lower-resolution periphery, then act as if they understand the whole scene. That means a cognitive model should not merely ask whether two images are pixel-close or semantically similar. It should ask which changes are invisible to the human visual system because they preserve the structure that perception actually uses.

MetamerGen sits exactly at that boundary. A metamer is a different stimulus that produces the same perceptual response, so the scientific question is not whether the generated image is realistic in the usual image-model sense. The question is whether latent diffusion can produce scenes that keep peripheral gist and fixation detail aligned with what humans report seeing. If it can, the generator becomes a probe: it exposes which visual information is necessary for human scene understanding and which information can vary without changing the percept.

CORE

Same perception does not mean same image

The concrete object is a pair of scenes that look different as pixels but are meant to be equivalent to a viewer under a viewing condition.

This is a useful first-principles idea because human perception is lossy in a structured way. The visual system does not preserve every edge, texture, and object detail with equal priority. It spends high resolution near fixation and accepts compressed information in the periphery. If two scenes differ in details that the viewer would not use, they can be different images but the same perceptual object for that moment.

MetamerGen uses generation to test that boundary. The model is not just making another nice image. It is searching for an image that is allowed to change many low-level facts while keeping the perceptual facts that should matter: peripheral scene gist, fixation-level detail, and the viewer's stable interpretation of the scene. That makes image generation an experimental tool for cognitive science.

TOPIC 01

Perception is compressed on purpose

The visual system does not try to keep a perfect copy of the scene. It keeps the information needed for the current task and viewing condition.

This is the first idea behind MetamerGen. A camera stores pixels uniformly. A person does not. The center of gaze receives high-resolution detail, while the periphery carries lower-resolution structure, motion, layout, and scene gist. That is not a bug. It is the normal information budget of vision.

Once that is clear, image similarity becomes the wrong starting point. Two images can be different in pixels and still preserve the same useful percept. Conversely, two images can have similar textures and still feel like different scenes if they change the structure a viewer used. A cognitive model has to reason about the perceptual compression, not only the image file.

TOPIC 02

A metamer is an equivalence class

A metamer is not just a generated image. It is a claim that two different stimuli land in the same perceptual bucket for a viewer.

The simple mathematical object is an equivalence relation: under this viewing protocol, image A and image B are treated as the same by the human perceptual system. The equivalence is not global. It depends on fixation, display conditions, time, task, and what the viewer is asked to judge.

This is why MetamerGen belongs in cognitive science rather than only generative modeling. The generated sample is evidence about the boundary of a human representation. If the image changes and the percept stays fixed, the method has found something the visual system did not need to preserve. If the percept changes, the method crossed the boundary.

TOPIC 03

Fixation defines which evidence is high resolution

Where the viewer looks changes what counts as preserved information.

A scene metamer cannot be defined only by the image. It also depends on the viewer's fixation pattern. If a person looks at a face, the face carries high-resolution evidence. If the same person looks at the doorway, the face may become peripheral context. The same image pair can therefore have different metamer status under different fixations.

This is why the foveated setup matters. The method splits visual evidence into fixation detail and peripheral gist. That split gives the generator a more human-shaped constraint than a normal caption or embedding. It says: keep the detail where the viewer actually looked, keep the broad structure elsewhere, and see how much of the image surface can change without changing the percept.

TOPIC 04

Generation becomes a probe of hidden representation

We cannot directly read the viewer's scene representation, so the generator proposes tests for it.

The generator is useful because it can search through many plausible full images that might all match the same compressed percept. Each generated scene is a hypothesis: maybe this is another image compatible with what the viewer kept. The human same/different judgment then accepts or rejects that hypothesis.

That gives the paper a general first-principles lesson. Generative models do not only create artifacts. When constrained by the right measurement object, they can create scientific probes. The sample becomes a controlled question about invariance: which details can move, and which details break the human representation?

TOPIC 05

The protocol is part of the claim

A perceptual-equivalence claim is only meaningful when it states whose perception, under what conditions, with what judgment task.

This prevents overclaiming. MetamerGen does not prove that two images are universally the same. It can only support a narrower claim: for a viewer or group of viewers, under a specified fixation and task, the generated scene preserves the relevant perceptual response. Change the task, the display time, the fixation, or the observer, and the equivalence may change.

That boundary is not a weakness. It is what makes the method scientifically clean. Cognitive modeling becomes stronger when it names the measurement condition instead of pretending that "human perception" is one fixed target. The evidence must match the claim: human judgments, fixation sensitivity, semantic alignment, and ablations that show which part of the perceptual channel actually mattered.

WHY IT WORKS

Generation turns an invisible representation into a visible test

We cannot directly inspect a person's latent scene representation, but we can generate candidate images and ask which ones preserve it.

The core trick is inversion through generation. If a person forms a compressed, foveated representation of a scene, then many different full images may be compatible with that representation. MetamerGen searches that compatible set with a latent diffusion model. The foveated input tells the generator what information the viewer had: detailed features from fixated areas and degraded contextual features from the periphery.

The same-different behavioral experiment is what makes this cognitive science rather than only image synthesis. A generic image model can produce plausible images. A metamer generator has to produce images that humans judge as preserving the latent scene percept. The paper's reported finding that high-level semantic alignment most strongly predicts metamerism under viewers' own fixations is important because it says the model is not only matching texture. It is approaching the level of scene meaning that drives human judgments.

The deeper principle is that a generative model can become a probe of a hidden human representation. The generated image is a hypothesis: this is what could have changed while the viewer's scene understanding stayed the same.

EVIDENCE

What would prove perceptual equivalence

The evidence has to come from the perceptual relation the paper claims to model. Realism, likelihood, or caption similarity are not enough.

Human judgment

Participants should judge generated and original scenes as same under the intended viewing setup.

Fixation sensitivity

Conditioning on viewers' own fixated regions should matter if the method is truly modeling foveated scene understanding.

Gist/detail split

Ablations should show that peripheral gist and fixation detail contribute differently to metamer quality.

Semantic alignment

High-level scene meaning should explain same/different judgments better than surface texture alone.

Participant variation

Different viewers may fixate different regions, so the metamer relation can depend on the observer, not just the image.

Protocol boundary

Display time, task framing, fixation measurement quality, and metamer criteria should be explicit because they define the percept being tested.

FAILURE MODES

When the generator stops being a cognitive probe

The method fails when the generated image passes image-model standards but no longer preserves the viewer's scene representation.

One failure is realism without equivalence. The image may look natural, but if people judge it as a different scene, it is not a metamer. Another failure is token-model mismatch: DINOv2 features are useful visual representations, but they are not guaranteed to match human visual processing. A third failure is fixation error. If the measured or assumed fixations do not match where the viewer actually extracted high-resolution evidence, the foveated conditioning may describe the wrong perceptual input.

There is also an observer-dependence boundary. A scene can be a metamer for one viewer under one task and not for another viewer under a different task. That is not a weakness of the concept; it is the point. Human modeling has to specify whose perception, under what viewing condition, with what judgment protocol.

METHOD

Why generation becomes an experiment

A generator can be used to ask a scientific question: which parts of a scene can change while the percept stays the same?

Ordinary image generation asks for a plausible sample. Metamer generation asks for a controlled counterexample to pixel-level sameness. The generated image should be different enough to show that the model is not simply copying, but constrained enough that a human viewer keeps the same perceptual experience. The result is a test of invariance: what visual changes does the human system ignore, and what changes break the percept?

This connects directly to the broader atlas theme of evidence. The evidence is not just a benchmark score. It is a human-facing equivalence test. If the generated image preserves the perceptual response, then the method has found a candidate description of what the visual system represented. If people notice a different scene, then the method changed something that cognition did not treat as irrelevant.

CLUSTER

The Main Research Move

Generation becomes a perceptual experiment

The move is to stop treating human modeling as a loose analogy for neural networks and instead build images whose success is judged by human perceptual equivalence. Foveated generation matters because it encodes a first-principles fact about vision: the observer does not sample the whole field with equal precision. That makes the model useful for cognitive science, because a successful generated scene is evidence about the representation a person is likely using, not only evidence that a diffusion model can make another plausible picture.
