Multimodal models need modality contracts

CORE

Alignment should not erase the native evidence

A multimodal model works when shared representations preserve what each input type is uniquely able to show.

Text can name relations that pixels only imply. Images carry spatial detail that captions may omit. Video carries timing. Audio carries rhythm and signal. fMRI carries brain response. Actions carry commitment. If fusion turns all of these into one flat embedding without a contract, the model may sound grounded while losing the source that made the answer true.

FRABench/UFEval builds aspect-level judging across modalities. Omni-Reward collects free-form preferences across text, image, video, audio, and 3D. PRISM maps fMRI into structured object-attribute-relation text before visual reconstruction. Mind-Omni tokenizes brain signals for multiple brain-vision-language tasks. LIMSSR treats missing modalities as a reasoning and uncertainty problem. Beyond LM studies native multimodal scaling and modality asymmetry.

Core rule
For each modality, name what evidence it owns, what may be shared, and what must not be lost during fusion.
FIRST PRINCIPLE

Each modality carries a different kind of evidence

Fusion is useful only if it preserves what each input type can know better than the others.

A picture is not a caption. A video is not a pile of frames. Audio is not text with timing removed. Brain activity is not an image, even when it can help reconstruct one. An action stream is not a description of intent. Each modality has its own native evidence: spatial layout, temporal order, signal rhythm, neural response, motor commitment, 3D structure, or linguistic relation.

A multimodal model creates risk when it collapses these differences too early. The shared representation may become fluent and convenient while losing the thing that made a modality worth adding. A contract prevents that. It says what the modality owns, what can be translated, what cannot be replaced, how missing inputs should be treated, and which judge can detect failure.

First-principles test
Remove, swap, or corrupt one modality and check whether the answer changes only where that modality carried necessary evidence.

METHOD

Why a shared embedding is not a contract

A common vector space can align signals while hiding what was lost.

Alignment says two representations can be compared. It does not prove that the comparison preserved native evidence. A caption may align with an image while omitting a small object. A brain-derived text bridge may help reconstruction while dropping uncertainty. A reward model may rank a video and an image with one score while missing the temporal property that made the video good. Shared space is useful, but it is not the proof.

The proof comes from interventions. Remove one modality, corrupt only its native evidence, keep the other modalities stable, and measure the change. Give the model incomplete inputs and check calibration. Evaluate by aspect rather than one aggregate score. Build scaling curves by modality instead of assuming the language curve explains all signals.

The contract is met only when the model knows when translation is enough and when the native signal must remain available.

FAILURE MAP

How fusion erases evidence

Caption replacement

The model treats generated text as if it were the original image, video, or signal.

Temporal loss

Video becomes unordered visual content, so timing disappears.

Missingness hallucination

An absent modality is filled with plausible content instead of uncertainty.

Judge collapse

One score hides the aspect where a modality failed.

Scale confusion

The method assumes language data and capacity laws apply to every signal.

Bridge opacity

A translated representation works on average but hides what native evidence was discarded.

A multimodal model should state what each modality promises before it claims they are aligned.
CONNECTION

Why this idea cuts across the atlas

Modality contracts are the native-evidence form of grounding.

Grounding asks whether evidence controls the answer. Modality contracts ask which channel owns that evidence. Compression asks what survives when tokens are reduced; multimodal fusion asks what survives when signals are translated. Scientific generation has the same rule: do not replace the native object with a fluent surrogate.

This lens also makes evaluation sharper. Instead of asking whether the fused model scored well, we ask which modality supplied the decisive evidence, whether another modality contradicted it, and whether the judge could see the difference. A contract turns multimodal performance from one aggregate number into a set of inspectable promises.

The deeper point is that multimodal intelligence is not created by throwing signals together. It is created by preserving each signal’s contribution while making the shared task visible.
