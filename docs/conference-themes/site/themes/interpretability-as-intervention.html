Theme 11 - ICLR 2026: 15 / ICML 2026: 41

Interpretability as intervention, mapped

The central problem is moving from explaining a model after the fact to changing its behavior with internal evidence.

Problem

If an internal feature marks a failure, it should not only produce a nice explanation. It should help detect, steer, repair, or prevent the failure.

Approaches

The papers use activation steering, hidden-state norms, causal features, attribution graphs, concept-level games, probes, and mechanistic analyses of visual and language reasoning.

Connecting read

Interpretability is becoming operational: find the mechanism, then use it as a control surface.
