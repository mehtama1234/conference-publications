Data governance and curation, mapped

The central problem is that data is now a system component with provenance, rights, quality, and optimization behavior.

Problem

Bigger data is not automatically better. Some examples harm learning, some cannot be legally reused, some contaminate evaluation, and some only help when chosen for the phase of training.

Approaches

The papers build open corpora, provenance controls, data recipes, filtering methods, harmful-example analysis, annealing-data selection, split integrity checks, and dataset quality metrics.

Connecting read

This theme says the dataset is no longer a passive pile. It is a controlled input whose source and structure determine what the model becomes.
