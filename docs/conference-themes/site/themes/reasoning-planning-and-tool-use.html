Problem

The shared problem is that simple benchmark accuracy no longer explains what is happening. The papers in this group isolate a narrower failure mode, capability, or design constraint.

Approaches

The approaches vary by paper, but the common pattern is to define a sharper object of study, build a method around that object, and test whether it changes behavior under controlled conditions.

SUBTHEMES

What the papers are actually about

Bayesian experimental design for LM agents

ICLR 2026Rational Agents
Improves question asking and action selection through Monte Carlo expected-information-gain inference.

Circuit-guided reasoning repair

ICLR 2026CRV
Uses attribution-graph analysis to target transcoder-feature interventions that correct faulty reasoning.

Code generation as graph inference interface

ICLR 2026Actions Speak Louder than Prompts
Shows executable code handles long-text and high-degree graph settings better than prompt-only interaction.

Code-spec-proof artifact chain

ICLR 2026VERINA
Shows current LLMs have much lower proof success than code correctness in verifiable programming tasks.

Conceptual retrieval for autoformalization

ICLR 2026CRAMF
Retrieves Mathlib4 definitions for core concepts to ground LLM translation into Lean code.

Continuous latent thought pretraining

ICML 2026PonderLM-2
Adds hidden-state thought steps before token prediction to scale per-token computation without emitted CoT.

Credit assignment through informative prefixes

ICLR 2026T3
Preserves useful exploratory prefixes, improving performance up to 30 percent while cutting rollout tokens by about 25 percent.

Cross-domain metaphor mapping augmentation

ICML 2026MetaphorVU
Uses a metaphor knowledge graph at inference time to improve high-order video understanding.

Cross-modal audio-text intermediate reasoning

ICLR 2026UALM-R1
Uses both text and audio in thinking steps for complex generation tasks.

Decoupled rewards for overthinking reduction

ICLR 2026DECS
Separates redundant-token penalties from essential exploratory reasoning to reduce reasoning length without accuracy loss.

Diversity-preserving inference-time reasoning

ICLR 2026Reasoning with Sampling
Nearly matches or outperforms RL reasoning gains while avoiding multi-sample diversity collapse.

Executable theory induction from observation

ICML 2026L2T
Learns latent programs as explanations for non-textual observations rather than only predicting frames.

Feasible partial-solution generation

ICLR 2026NEXCO
Uses confidence-guided candidate sets and feasibility projection to expand combinatorial solutions under constraints.

Guided-search compositional diffusion planning

ICLR 2026CDGS
Embeds population search, likelihood pruning, and overlap resampling inside diffusion denoising.

Long-context retrieval-reasoning coupling

ICLR 2026LoongRL
Requires models to trace UUID chains, identify the true question, retrieve facts, and recheck answers amid distractors.

Masked diffusion language reasoning

ICLR 2026MDM Reasoning
Shows masked diffusion models match CoT transformer reasoning power via equivalence to padded looped transformers.

Overthinking-aware generation control

ICML 2026ASAG
Improves reasoning accuracy while reducing generated tokens through training-free adaptive generation.

Quantitative diagnostics grounding LLM algorithm control

ICLR 2026AutoEP
Uses real-time search-dynamics feedback to reduce hallucinated optimization strategies.

SSMs as efficient agent backbones

ICLR 2026Tool-Augmented SSMs
Demonstrates length generalization on arithmetic, reasoning, and coding tasks with appropriate tool access and training data.

Stratified reward normalization

ICLR 2026HERO
Bounds reward-model scores inside verifier-defined groups while emphasizing prompts where dense feedback matters.

Teacher-generated reasoning pipeline scaling

ICLR 2026OpenThoughts
Scales a QwQ-32B-generated pipeline to 1.2M examples for math, code, and science reasoning.

Tool-integrated mathematical RL

ICLR 2026THOR
Jointly optimizes episode-level answers and step-level code/tool-call success for math reasoning.

Visual cue grounding through contrast

ICLR 2026VC-STaR
Builds VisCoR-55K by using contrastive examples to force precise visual evidence identification.

Visual-only planning trajectories

ICLR 2026Visual Planning
Uses image sequences as intermediate plans for spatial and geometric reasoning tasks.
