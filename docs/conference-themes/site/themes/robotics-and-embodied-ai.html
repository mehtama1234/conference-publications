Problem

Embodied intelligence has to close the loop between perception and action. A wrong camera geometry, stale memory, narrow demonstration, or slow policy can become a physical failure.

Approaches

The papers build embodied benchmarks, cross-robot data, world models, scene graphs, diffusion planners, preference rewards, VLA architectures, uncertainty controls, and latency-aware inference systems.

Connecting read

The field is shifting from isolated robot policies toward foundation systems that combine perception, memory, embodiment transfer, and deployable control.

FIRST PRINCIPLES

The core problem

A robot learns in a world where observations are partial and actions have consequences. It sees from a moving camera, acts through a particular body, must respect physical constraints, and often needs to recover from earlier mistakes. Embodied AI is therefore not only about mapping pixels to actions; it is about building a representation that stays coherent while the robot changes the scene.

These papers attack that problem from four sides. Some ask whether models can understand views, geometry, and occlusion. Some build data and latent codes that transfer across embodiments. Some use world models, scene graphs, preferences, and generative planners to reason over action consequences. Others make VLA policies stable and fast enough for long-horizon deployment. The shared question is what has to be represented so action can be reliable.

SYNTHESIS

Four embodied AI problems in the paper set

1. Robots need spatial understanding that survives viewpoint changes

geometry and memory

This cluster asks whether embodied models actually know where things are. Egocentric videos, occlusions, long-range motion, and scene graphs expose failures that ordinary image-language benchmarks can hide.

ICML 2026SAW-Bench
SAW-Bench reports a large gap between humans and models in coherent camera-geometry inference from egocentric videos. The benchmark matters because egocentric perception is the robot's native view. If the model cannot infer how the camera moved through space, its visual understanding will not support grounded action.
ICML 20263ViewSense
3ViewSense improves occlusion-heavy counting and perspective consistency by aligning egocentric and allocentric views. It addresses a basic embodied problem: the robot sees from one view but needs a stable world model that would make sense from another. View alignment is a route from image recognition to spatial reasoning.
ICML 2026VGGT-Motion
VGGT-Motion enforces kilometer-scale global consistency with lightweight submap-level pose graph optimization. Long-range spatial work cannot rely on local frame-to-frame correctness alone. Small pose errors accumulate, so the system needs a global structure that keeps motion estimates coherent over distance.
ICLR 2026MomaGraph
MomaGraph reports real-robot active-perception deployment using scene-graph prediction and high-level planning. Scene graphs are useful because they give the robot a manipulable abstraction of objects, relations, and goals. The paper connects perception to planning through a structured world state rather than raw visual features alone.
ICML 2026RoboMME
RoboMME benchmarks temporal, spatial, object, and procedural memory across long-horizon manipulation tasks. It makes memory explicit: a robot must remember where objects were, what was done, what remains, and which procedure it is following. A single success score would hide which memory system failed.
ICML 2026SpatioLM
SpatioLM improves spatial reasoning benchmarks and transfers to embodied manipulation while limiting degradation of general VLM capability. The paper treats spatial intelligence as a specialized capability that should be added without destroying broad language-vision competence. That is important for VLA systems that need both common-sense language and precise spatial control.

2. Embodiment transfer needs data and codes that factor body from skill

cross-robot learning

A policy learned on one body often fails on another. These papers ask how to reuse behavior across robot arms, grippers, camera setups, and tasks without treating every embodiment as a separate world.

ICML 2026OXE-AugE
OXE-AugE augments Open X-Embodiment with nine robot embodiments and millions of trajectories for transfer learning. The point is that embodiment diversity is not decoration; it is the evidence a model needs to separate the task from the body that performed it. More varied robot data can make transfer a learned capability rather than a hand-engineered adapter.
ICML 2026XR-1
XR-1 learns discrete latent codes from visual dynamics and robot motion to guide cross-embodiment VLA pretraining. The latent code is a bridge between what changes visually and what motion caused it. If the code captures shared dynamics, it can help a model move behavior across bodies without copying joint commands directly.
ICML 2026DreamDojo
DreamDojo pretrains a robot world model on tens of thousands of hours of egocentric human videos using continuous latent actions. Human video is abundant but not robot action data. The paper tries to extract action-like structure from human experience so robots can learn world dynamics before seeing large amounts of robot-specific control.
ICML 2026Nevo-CRL
Nevo-CRL freezes useful neurons, reuses semantically similar skills, and prunes inactive connections for continual adaptation. Open-ended robots cannot retrain from scratch for every new skill. The method treats capacity as recyclable: preserve what works, map new skills onto related old ones, and clear unused structure.

3. Planning and reward must model action consequences, not just imitate demonstrations

control and feedback

Robots need actions that work after the world changes. This cluster uses action-centric evaluation, diverse imitation, preference rewards, hierarchical generation, and multi-agent transport to make control more than one-step behavior cloning.

ICML 2026dWorldEval
dWorldEval uses action tokens as first-class causal drivers in a discrete-diffusion world model for robot policy evaluation. The key shift is evaluating whether actions cause plausible future states, not merely whether predicted pixels look good. A robot world model must understand intervention.
ICML 2026Posterior Behavioral Cloning
Posterior Behavioral Cloning improves RL fine-tuning by avoiding overly narrow imitation policies. Demonstrations can teach a brittle average behavior that leaves no room for exploration or correction. A posterior view keeps multiple plausible behaviors alive so RL can refine them under task feedback.
ICML 2026VOTP
VOTP learns offline preference rewards for locomotion, manipulation, and real robot tasks with few labels. Robotics rewards are expensive because humans cannot label every physical rollout. Preference-efficient reward learning gives the policy a usable objective without requiring dense hand-coded reward functions.
ICML 2026HDFlow
HDFlow combines high-level diffusion subgoal generation with low-level rectified-flow trajectory generation for long-horizon robot tasks. The hierarchy matters: high-level plans choose what should happen, while low-level flows produce feasible motion. Long-horizon manipulation needs both abstraction and continuous control.
ICML 2026MAPF via MMOT and Schrödinger Bridges
MAPF via MMOT and Schrödinger Bridges casts anonymous multi-agent path finding as Markov-structured optimal transport with collision-free transports. It treats multi-robot planning as distribution movement under constraints. The formulation gives a way to coordinate many agents without assigning identity-heavy paths too early.

4. VLA deployment is a latency, uncertainty, and temporal-stability problem

deployable policies

A vision-language-action model has to act repeatedly in real time. The papers here focus on inference speed, uncertainty-adaptive perception, and temporal behavior streams that keep long-horizon manipulation stable.

ICML 2026EcoVLA
EcoVLA schedules pruning inside FLOP bubbles, preserving latency while accelerating VLA inference. The systems point is direct: robot policies are constrained by wall-clock control loops. Speedups that disrupt latency predictability can be less useful than scheduling that fits unused compute gaps.
ICML 2026BehaviorVLA
BehaviorVLA uses causal Mamba-based vision, action, and behavior streams with phase-conditioned decoding for long-horizon manipulation. It separates what the robot sees, what it does, and what behavioral phase it is in. That separation helps stabilize policies that must maintain intent across many steps.
ICML 2026SCALE
SCALE uses VLA self-uncertainty to modulate visual-attention temperature and action sampling in a single forward pass. The idea is that a robot should look and act differently when it is unsure. Uncertainty becomes a control knob for both perception focus and action risk, without adding a slow second-stage loop.
FIELD READ

What this theme says about ICML and ICLR

The robotics signal is that embodied foundation models are being judged less by static recognition and more by whether they preserve world structure through action. The recurring objects are viewpoint, memory, embodiment, subgoals, rewards, uncertainty, and deployment speed.

This connects directly to the broader gym work: a robotics benchmark is not just a list of prompts. It needs observations, actions, state transitions, physical constraints, success criteria, and often a verifier that understands geometry or task progress. The more embodied the task, the more the benchmark format has to represent the world, not just the final answer.
