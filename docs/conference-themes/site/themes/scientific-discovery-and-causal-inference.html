Scientific discovery and causal inference as mechanism-preserving AI

The common problem is not that scientists lack predictors. It is that scientific work needs claims about mechanisms, causes, uncertainty, and executable procedures. These papers ask how AI systems can turn messy evidence into checkable objects that support discovery rather than just fluent explanations.

FIRST PRINCIPLES

What makes scientific AI different

A normal prediction system can be useful even if it hides its mechanism. Science usually cannot. If a model says a treatment works, a chemical route is plausible, a time series contains a hidden cause, or a statistical program is valid, the user needs to know what structure makes that claim credible. The answer must survive follow-up questions: what was observed, what was latent, what was randomized, what was identified, what was executed, and what verifier checked the result?

The five papers on this page attack different parts of that pipeline. One turns unstructured trial data into sparse features for causal-effect search. One makes small models synthesize probabilistic programs by enforcing statistical semantics. One characterizes what causal graphs can be identified when latent variables and cycles are allowed. One wraps biomedical data-science tasks into executable agent environments. One learns causal structure in event streams even when hidden subprocesses confound the observations. The shared move is to preserve the scientific object that matters: effect, program, equivalence class, executable task, or temporal mechanism.

Evidence object

The output is not just an answer. It is a causal effect, a valid program, an equivalence class, a sandbox trajectory, or a discovered event mechanism.

Hidden structure

Scientific data often hide the relevant state: latent causes, unobserved subprocesses, implicit statistical assumptions, or biological workflow constraints.

Verification loop

The method must include checks: significance control, semantic diagnostics, identifiability criteria, executable ground truth, or recovery tests.

BIG PICTURE

The connecting problem

The theme is best read as a response to a failure of naive scale. More model capacity can produce better summaries, faster code, or richer embeddings, but scientific discovery breaks if the system cannot say why a result should be trusted. A model that invents a statistical program with an invalid likelihood is not doing science. A causal discovery method that returns a single graph when many graphs are observationally equivalent is overclaiming. A biomedical agent that cannot run code in a controlled environment cannot be trained or measured reliably. These papers all put structure back into the loop.

There are two recurring strategies. The first is representation-to-mechanism: use foundation-model embeddings or sparse autoencoders, but force them to become candidates in a statistical or causal test. The second is process-to-verifier: use language models or agents, but constrain them with executable environments, semantic checks, or identifiability conditions. In both cases, the model is not the final authority. It proposes, searches, repairs, or acts; a structured scientific layer decides what counts.

CORE

Prediction is not discovery

A predictor can be right for the wrong reason. A discovery claim has to survive the question: what would make this claim false?

This is the simplest line through the papers. A model may predict a patient outcome from a feature that is only a proxy. It may find a pattern in trial data after trying many patterns. It may write a probabilistic program that runs but does not describe a valid statistical story. It may infer a causal graph that is only one member of a larger set of indistinguishable graphs. It may solve a biomedical task in prose while never executing the analysis that would prove the result.

Scientific work therefore needs an object stronger than an answer. It needs a hypothesis, an effect estimate, an equivalence class, a program with typed statistical parts, an executable task state, or a temporal mechanism. The model may help form that object, but the object must then be tested by something outside the model's fluency.

That is why these papers belong together even though they look different. Neural Effect Search asks which learned feature deserves a causal test. RefineStat asks whether generated statistical code has valid semantics. Distributional Equivalence asks what causal structure the observations can and cannot distinguish. MedAgentGym asks whether biomedical agents can do work in a checked environment. Latent Hawkes Causal Discovery asks whether event streams hide subprocesses that make observed causes misleading.

ANATOMY

The concrete object is a testable scientific claim

The concrete object is not the model's explanation. It is the artifact that can be checked: a candidate feature, treatment effect, probabilistic program, causal equivalence class, executable biomedical workflow, or temporal causal mechanism.

What must stay fixed is the scientific question and the evidence rule. Neural Effect Search must keep the treatment/outcome meaning and the multiple-testing burden created by feature search. RefineStat must keep the statistical semantics of priors, likelihoods, and inference diagnostics. Distributional Equivalence must keep the observational assumptions that define which graphs are indistinguishable. MedAgentGym must keep the task state, executable code, feedback, and ground truth. Latent Hawkes work must keep the event process and latent-subprocess assumptions.

What may change is the candidate hypothesis, feature, program repair, graph member, agent action, or latent subprocess model. The method works when search expands what can be proposed while the verifier prevents overclaiming. The evidence is not fluent explanation; it is statistical validity, false-discovery control, diagnostic repair, identifiability analysis, executable traces, and held-out scientific checks. The failure boundary is scientific theater: the system sounds plausible while the claim cannot be falsified.

TOPIC 01

Learned features are not automatically scientific variables

A neural feature becomes useful for discovery only when it can enter a scientific test.

Foundation models can expose structure that humans did not predefine. That is powerful, but it creates a trap: a feature that is interpretable enough to name is not automatically a causal variable. It may be a mixture of causes, a proxy for a confounder, a trial artifact, or a convenient compression of several signals. Neural Effect Search is important because it does not stop at "the feature looks meaningful." It uses learned representations and sparse autoencoders to propose candidate units, then routes those candidates into treatment-effect search with statistical controls.

The deeper principle is that representation learning can generate hypotheses, but statistics has to discipline the search. The model expands the menu of possible effects. The scientific layer asks which effects survive the cost of having searched that menu.

TOPIC 02

Scientific code must preserve semantics

A generated probabilistic program can execute and still be scientifically wrong.

Scientific programming has a stricter success condition than ordinary code completion. A script that parses may use the wrong distribution. A likelihood may accept invalid parameters. An inference routine may run while producing nonsense. RefineStat treats those failures as semantic failures, not style errors. It separates the program into prior and likelihood components, checks statistical validity, runs diagnostics, and repairs the part that failed.

This teaches a reusable agent principle. In scientific domains, repair should be typed by the object that broke. If the prior is invalid, repair the prior. If the likelihood is malformed, repair the likelihood. If diagnostics fail, use the diagnostic as evidence for the next edit. The model is useful because it proposes code; the verifier is useful because it understands the scientific meaning of the code.

TOPIC 03

Causal discovery must preserve what remains unidentified

Sometimes the correct scientific answer is not one graph. It is the set of graphs the evidence cannot distinguish.

This is one of the hardest ideas to make intuitive. If two different mechanisms would produce the same observations, then the data alone do not choose between them. A system that reports one clean graph may look more useful, but it is overclaiming. Distributional Equivalence makes this explicit for linear non-Gaussian causal models with latent variables and cycles. It studies which graph structures are distributionally equivalent and how edge rank constraints help traverse the space of compatible mechanisms.

Latent Hawkes Causal Discovery makes the same point in event streams. If hidden subprocesses trigger observed events, then the observed sequence can tell a false causal story. Temporal order helps, but it does not magically reveal hidden sources. The method has to ask what latent subprocess could have generated the pattern before it treats one observed event as the cause of another.

TOPIC 04

Scientific agents need executable environments

A biomedical agent cannot be judged only by whether its answer sounds like a scientist wrote it.

MedAgentGym is the agent version of the same scientific principle. Biomedical data-science tasks require reading a specification, writing code, running analysis, seeing feedback, and comparing against ground truth. If the benchmark only asks for final text, it loses the work path where success or failure actually appears. The agent may write a plausible diagnosis, a plausible Python snippet, or a plausible summary while failing the analysis.

The environment matters because it turns scientific reasoning into state-changing work. The agent makes an artifact. The artifact runs or fails. Feedback changes the next step. The trajectory becomes training data. This is why executable scientific environments are not only benchmarks. They are the format needed to teach agents how scientific work is actually corrected.

TOPIC 05

Discovery is search with receipts

A discovery process has to remember how many things it tried, which evidence selected the winner, and which alternatives remain alive.

This is the common failure behind many impressive model-driven discoveries. If a system searches enough features, programs, causes, prompts, molecules, or hypotheses, it can find something that looks strong by chance. That does not make search bad. It means search needs receipts: the candidate set, the selection rule, the holdout evidence, the false-discovery correction, the diagnostic log, the equivalence boundary, or the executable trace.

Neural Effect Search uses statistical controls because feature search creates multiple-testing pressure. RefineStat keeps repair diagnostics because program search can produce semantically broken code. Distributional Equivalence keeps equivalence classes because graph search can overstate direction. MedAgentGym keeps trajectories because agent search needs state and feedback. Latent Hawkes work keeps latent subprocess conditions because event search can confuse sequence with cause.

TOPIC 06

The verifier must match the scientific object

There is no generic scientific verifier. The check depends on what kind of claim is being made.

For a causal effect, the verifier asks whether the effect survives the statistical design. For a probabilistic program, it asks whether the distributions, parameters, and inference diagnostics are valid. For a causal graph, it asks what is identifiable under the assumed model family. For a biomedical agent, it asks whether the code and environment state match the task. For event causality, it asks whether hidden subprocesses have been accounted for.

This matters because a weak verifier can reward scientific theater. A fluent explanation may pass a language judge while failing a causal test. Executable code may pass syntax while failing statistical meaning. A graph may look neat while hiding unidentifiability. A good scientific AI system routes each claim to the verifier that can actually falsify it.

EVIDENCE

What would prove discovery happened

The evidence must show that the system produced a scientific object that survives the verifier for that object.

Causal survival

A discovered feature or treatment effect should survive the trial design, adjustment rule, multiple-testing correction, and search path that produced it.

Semantic validity

A generated probabilistic program should pass distribution, parameter, likelihood, and inference diagnostics, not only execute without syntax errors.

Identifiability honesty

A causal discovery method should return an equivalence class when observations cannot distinguish one graph from another.

Executable trace

A scientific agent should leave code, state, feedback, errors, repairs, and final artifacts that can be checked against ground truth.

Latent accounting

Temporal-event methods should test whether hidden subprocesses can explain apparent observed causes before declaring a direct link.

Rejected alternatives

A discovery claim is stronger when the page can say which plausible alternatives were ruled out and which remain alive.

FAILURE MODES

How scientific AI becomes scientific theater

The common failure is a system that produces a fluent scientific-looking artifact while changing the evidence standard that would make the artifact true.

A learned feature can look interpretable while still being a proxy, mixture, confounder, or trial artifact. A treatment-effect search can look productive while the multiple-testing burden turns discoveries into luck. A probabilistic program can run while its prior, likelihood, or inference path is semantically invalid. A causal graph can look clean while the observations identify only an equivalence class.

Agents add another failure mode: they can narrate a biomedical analysis without producing a checked trajectory. If code, sandbox state, feedback, and ground truth are missing, the page has only an answer, not scientific work. Event systems add the temporal version of the same problem: sequence can be mistaken for cause when hidden subprocesses generate both events.

The boundary is falsifiability. If no outside check can reject the claim, the model has not discovered something in the scientific sense. It has generated a plausible story. These papers matter because they force the story to become an object that can fail.

SUBTHEMES

What the papers are actually about

Sparse features become scientific hypotheses

causal effect search

Neural Effect Search starts from a bottleneck in randomized controlled trials: humans usually decide which effects to test. That can make analysis expensive and narrow, especially when the observations are unstructured and the interesting effect is not obvious in advance. The paper embeds trial data with foundation models, uses sparse autoencoders to expose interpretable neural features, then recursively searches for treatment effects while handling multiple-testing and entanglement problems through progressive stratification. The conceptual step is important: interpretability is not only used to explain a model after the fact; it becomes an instrument for scientific discovery. The SAE feature is treated as a candidate measurement unit, and the causal test decides whether that feature carries a treatment effect.

Paper
Neural Effect Search
Approach
Foundation-model representations plus sparse autoencoders, followed by recursive progressive stratification to search for significant treatment effects in trial data.
Why it matters
It turns learned representations into causal search surfaces while keeping statistical false-discovery pressure visible.

Probabilistic programs need semantic repair, not just code completion

statistical synthesis

RefineStat addresses scientific code generation where being executable is still too weak. A probabilistic program can parse and run while using invalid distributions, malformed parameters, or unreliable inference constructs. The paper uses smaller language models but wraps them with probabilistic-programmer-style checks: enforce valid distributions and parameters, run reliability diagnostics, and resample the prior or likelihood component when a check fails. This is a first-principles pattern for scientific agents: generation should be local and repairable because the program has typed statistical parts. The system improves not by asking the model to be globally smarter in one shot, but by giving it a domain-specific debugging loop that knows what failure means.

Paper
RefineStat
Approach
Semantic constraints plus diagnostic-aware refinement of prior and likelihood components during probabilistic-program synthesis.
Why it matters
It shows how scientific code generation can be judged by statistical reliability, not only syntax or model-size prestige.

Discovery must say what is identifiable before estimating it

causal equivalence

Distributional Equivalence focuses on a core causal-discovery limit. With latent variables and cycles, observed data may be compatible with many causal graphs. If the method does not know the equivalence class, it can mistakenly present an unidentifiable direction as a discovered fact. This paper characterizes distributional equivalence for linear non-Gaussian causal models with arbitrary latent structure and cycles, using edge rank constraints as a new tool. The method then traverses equivalence classes and recovers models from data up to that equivalence. The big-picture contribution is intellectual honesty: in causal science, the right output may be a class of indistinguishable mechanisms rather than a single satisfying graph.

Paper
Distributional Equivalence
Approach
A graphical equivalence criterion for linear non-Gaussian models with arbitrary latents and cycles, using edge rank constraints and equivalence-class traversal.
Why it matters
It makes identifiability the starting point of causal discovery instead of an afterthought once a graph has already been selected.

Biomedical agents need executable scientific workspaces

agent environment

MedAgentGym shows why biomedical data science is not a static question-answering task. The work often requires reading task specifications, writing code, running analysis, interpreting feedback, and checking against ground truth. The paper packages 72,413 tasks across 129 categories from 12 real biomedical scenarios into executable sandbox environments with feedback and verifiable annotations. That makes offline and online reinforcement learning possible because the agent can produce trajectories whose success is measured by environment consequences. The deeper lesson is that domain agents need domain-shaped evidence loops, not generic benchmark prompts.

Paper
MedAgentGym
Approach
Executable biomedical coding sandboxes with task specs, feedback, ground truth, trajectory generation, and RL training for Med-Copilot.
Why it matters
It turns biomedical reasoning into verifiable action data, which is exactly the format needed for serious agent evaluation and training.

Temporal event data require hidden subprocess discovery

Hawkes causality

Latent Hawkes Causal Discovery studies systems where events trigger later events, but not every source of influence is observed. If hidden subprocesses are ignored, observed event streams can make the wrong causal relationships look plausible. The paper connects continuous-time Hawkes event sequences to a limiting discrete-time causal model, establishes necessary and sufficient identifiability conditions for latent subprocesses and causal influences, then proposes a two-phase iterative algorithm. It alternates between learning relationships among discovered subprocesses and uncovering new latent subprocesses, guided by path-based conditions. The first-principles lesson is that temporal dependence is not automatically causality; event discovery needs an account of what hidden process could have produced the pattern.

Paper
Latent Hawkes Causal Discovery
Approach
Uses a discrete-time limit view of Hawkes processes plus path-based identifiability conditions to iteratively infer observed causal links and latent subprocesses.
Why it matters
It handles scientific and operational event streams where missing causes are part of the system, not a nuisance to average away.
SYNTHESIS

The deeper principle

Scientific AI is not mainly about producing more possible answers. It is about keeping the right thing fixed while the system searches.

In ordinary generation, the model can change the wording until an answer looks plausible. In scientific discovery, that freedom has to be narrowed. The treatment assignment must stay fixed while the method searches for effects. The statistical meaning of the program must stay fixed while code is repaired. The observed distribution must stay fixed while the causal method lists compatible mechanisms. The task environment and ground truth must stay fixed while a biomedical agent tries actions. The event timestamps must stay fixed while the Hawkes method asks which hidden subprocesses could explain them.

That is the first-principles pattern across the five papers: discovery is controlled search. Something may change: a candidate feature, a program component, a graph, an action trajectory, a latent event process. Something must not change: the evidence contract that makes the claim meaningful. The method works when it explores the changing part without breaking the fixed part. It fails when it silently changes the evidence standard, overclaims a single answer, or rewards a fluent story that no external check could reject.

This also explains why these papers matter beyond science. Modern AI systems increasingly act in domains where the output is not just text but a claim about the world. The right question is not "did the model sound smart?" It is "what object did the model produce, what constraint did it preserve, and what evidence would prove that the object is real?"

CONCEPT BRIDGES

Where to read the larger pattern

Causality starts where prediction stops

A causal claim begins where prediction leaves more than one possible story. The method must say which intervention, mechanism, or equivalence class the evidence supports.

Scientific generation preserves the native object

Scientific outputs must preserve the native object, not just look plausible. A molecule, proof, program, graph, or treatment effect carries its own validity rules.

Uncertainty is a decision object

Scientific uncertainty matters when it changes the next experiment, intervention, or claim. The system should preserve what is still unknown instead of hiding it in a fluent answer.
