Theme 35 - ICLR 2026

Scientific discovery and causal inference as mechanism-preserving AI

The common problem is not that scientists lack predictors. It is that scientific work needs claims about mechanisms, causes, uncertainty, and executable procedures. These papers ask how AI systems can turn messy evidence into checkable objects that support discovery rather than just fluent explanations.

FIRST PRINCIPLES

What makes scientific AI different

A normal prediction system can be useful even if it hides its mechanism. Science usually cannot. If a model says a treatment works, a chemical route is plausible, a time series contains a hidden cause, or a statistical program is valid, the user needs to know what structure makes that claim credible. The answer must survive follow-up questions: what was observed, what was latent, what was randomized, what was identified, what was executed, and what verifier checked the result?

The five papers on this page attack different parts of that pipeline. One turns unstructured trial data into sparse features for causal-effect search. One makes small models synthesize probabilistic programs by enforcing statistical semantics. One characterizes what causal graphs can be identified when latent variables and cycles are allowed. One wraps biomedical data-science tasks into executable agent environments. One learns causal structure in event streams even when hidden subprocesses confound the observations. The shared move is to preserve the scientific object that matters: effect, program, equivalence class, executable task, or temporal mechanism.

Evidence object

The output is not just an answer. It is a causal effect, a valid program, an equivalence class, a sandbox trajectory, or a discovered event mechanism.

Hidden structure

Scientific data often hide the relevant state: latent causes, unobserved subprocesses, implicit statistical assumptions, or biological workflow constraints.

Verification loop

The method must include checks: significance control, semantic diagnostics, identifiability criteria, executable ground truth, or recovery tests.

BIG PICTURE

The connecting problem

The theme is best read as a response to a failure of naive scale. More model capacity can produce better summaries, faster code, or richer embeddings, but scientific discovery breaks if the system cannot say why a result should be trusted. A model that invents a statistical program with an invalid likelihood is not doing science. A causal discovery method that returns a single graph when many graphs are observationally equivalent is overclaiming. A biomedical agent that cannot run code in a controlled environment cannot be trained or measured reliably. These papers all put structure back into the loop.

There are two recurring strategies. The first is representation-to-mechanism: use foundation-model embeddings or sparse autoencoders, but force them to become candidates in a statistical or causal test. The second is process-to-verifier: use language models or agents, but constrain them with executable environments, semantic checks, or identifiability conditions. In both cases, the model is not the final authority. It proposes, searches, repairs, or acts; a structured scientific layer decides what counts.

SUBTHEMES

What the papers are actually about

Sparse features become scientific hypotheses

causal effect search

Neural Effect Search starts from a bottleneck in randomized controlled trials: humans usually decide which effects to test. That can make analysis expensive and narrow, especially when the observations are unstructured and the interesting effect is not obvious in advance. The paper embeds trial data with foundation models, uses sparse autoencoders to expose interpretable neural features, then recursively searches for treatment effects while handling multiple-testing and entanglement problems through progressive stratification. The conceptual step is important: interpretability is not only used to explain a model after the fact; it becomes an instrument for scientific discovery. The SAE feature is treated as a candidate measurement unit, and the causal test decides whether that feature carries a treatment effect.

Paper
Neural Effect Search
Approach
Foundation-model representations plus sparse autoencoders, followed by recursive progressive stratification to search for significant treatment effects in trial data.
Why it matters
It turns learned representations into causal search surfaces while keeping statistical false-discovery pressure visible.

Probabilistic programs need semantic repair, not just code completion

statistical synthesis

RefineStat addresses scientific code generation where being executable is still too weak. A probabilistic program can parse and run while using invalid distributions, malformed parameters, or unreliable inference constructs. The paper uses smaller language models but wraps them with probabilistic-programmer-style checks: enforce valid distributions and parameters, run reliability diagnostics, and resample the prior or likelihood component when a check fails. This is a first-principles pattern for scientific agents: generation should be local and repairable because the program has typed statistical parts. The system improves not by asking the model to be globally smarter in one shot, but by giving it a domain-specific debugging loop that knows what failure means.

Paper
RefineStat
Approach
Semantic constraints plus diagnostic-aware refinement of prior and likelihood components during probabilistic-program synthesis.
Why it matters
It shows how scientific code generation can be judged by statistical reliability, not only syntax or model-size prestige.

Discovery must say what is identifiable before estimating it

causal equivalence

Distributional Equivalence focuses on a core causal-discovery limit. With latent variables and cycles, observed data may be compatible with many causal graphs. If the method does not know the equivalence class, it can mistakenly present an unidentifiable direction as a discovered fact. This paper characterizes distributional equivalence for linear non-Gaussian causal models with arbitrary latent structure and cycles, using edge rank constraints as a new tool. The method then traverses equivalence classes and recovers models from data up to that equivalence. The big-picture contribution is intellectual honesty: in causal science, the right output may be a class of indistinguishable mechanisms rather than a single satisfying graph.

Paper
Distributional Equivalence
Approach
A graphical equivalence criterion for linear non-Gaussian models with arbitrary latents and cycles, using edge rank constraints and equivalence-class traversal.
Why it matters
It makes identifiability the starting point of causal discovery instead of an afterthought once a graph has already been selected.

Biomedical agents need executable scientific workspaces

agent gym

MedAgentGym is the most direct bridge to our gym work. Biomedical data science is not a static question-answering task; it often requires reading task specifications, writing code, running analysis, interpreting feedback, and checking against ground truth. MedAgentGym packages 72,413 tasks across 129 categories from 12 real biomedical scenarios into executable sandbox environments with feedback and verifiable annotations. That makes offline and online reinforcement learning possible because the agent can produce trajectories whose success is measured by environment consequences. The paper reports large gains for Med-Copilot from both offline and online RL, which supports the larger thesis that domain agents need domain-shaped environments, not generic benchmark prompts.

Paper
MedAgentGym
Approach
Executable biomedical coding sandboxes with task specs, feedback, ground truth, trajectory generation, and RL training for Med-Copilot.
Why it matters
It turns biomedical reasoning into verifiable action data, which is exactly the format needed for serious agent evaluation and training.

Temporal event data require hidden subprocess discovery

Hawkes causality

Latent Hawkes Causal Discovery studies systems where events trigger later events, but not every source of influence is observed. If hidden subprocesses are ignored, observed event streams can make the wrong causal relationships look plausible. The paper connects continuous-time Hawkes event sequences to a limiting discrete-time causal model, establishes necessary and sufficient identifiability conditions for latent subprocesses and causal influences, then proposes a two-phase iterative algorithm. It alternates between learning relationships among discovered subprocesses and uncovering new latent subprocesses, guided by path-based conditions. The first-principles lesson is that temporal dependence is not automatically causality; event discovery needs an account of what hidden process could have produced the pattern.

Paper
Latent Hawkes Causal Discovery
Approach
Uses a discrete-time limit view of Hawkes processes plus path-based identifiability conditions to iteratively infer observed causal links and latent subprocesses.
Why it matters
It handles scientific and operational event streams where missing causes are part of the system, not a nuisance to average away.
FIELD READ

What this means for the benchmark and gym project

This theme gives a concrete standard for our agent-data normalization work. A scientific-discovery gym should not flatten everything into prompt, answer, and final score. It needs fields for the scientific object being manipulated: trial units and treatment labels for causal-effect search, program components and diagnostic checks for probabilistic synthesis, equivalence-class assumptions for causal graphs, executable biomedical sandboxes for agent trajectories, and event subprocesses for temporal causal discovery. The verifier must match the object. Some tasks need deterministic code execution, some need statistical validity checks, some need identifiability criteria, and some need ranked recovery metrics.

The reason this is useful is that it prevents a benchmark from rewarding scientific theater. An agent can write a persuasive explanation of a treatment effect without controlling false discoveries. It can write plausible probabilistic code that is statistically invalid. It can name a root cause or causal graph that the data cannot identify. A good gym makes those failures visible by forcing the agent's action to land in a structured environment with a verifier that knows what scientific success means.
