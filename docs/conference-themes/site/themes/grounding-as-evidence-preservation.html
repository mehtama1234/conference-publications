First-principles concept

Grounding as evidence preservation

Grounding means the answer depends on the evidence it claims to use. If the visual cue, sensor event, document fact, or world state changes, the answer should change for that reason.

CORE

Grounding is a dependency claim

A grounded answer is tied to a source of evidence, not just compatible with it.

A model can mention objects in an image without using the object that decides the answer. It can produce a clinical video report while missing the timing of symptoms. It can describe a room while losing which object affords which action. It can appear safe while fused multimodal evidence hides an attack. Grounding fails when the answer is plausible but not caused by the right evidence.

The first-principles test is direct: change the deciding evidence and keep irrelevant surface features stable. If the answer should change and does not, grounding failed. If the answer changes when irrelevant style changes, grounding also failed. The preserved object is the evidence path from source to claim.

Core rule
A grounded model must preserve the evidence that makes the answer true, through representation, reasoning, and output.
FIRST PRINCIPLE

Evidence must control the answer

A model is grounded when the deciding evidence has power over the output.

The word grounding can sound like a broad virtue, but the plain object is narrower. There is some source outside the answer: an image patch, a video moment, a document sentence, a sensor reading, a graph edge, a room state, or a clinical event. The answer makes a claim about that source. Grounding asks whether the claim is controlled by the source or only decorated by it.

This distinction matters because modern models can produce convincing language from weak contact with evidence. They can infer a likely relation from common training patterns, fill in a missing step from prior knowledge, or write a fluent explanation after the decision has already been made. None of that proves grounding. The answer has to move when the evidence moves, stay stable when irrelevant style moves, and expose enough of the evidence path that a reviewer can see why the answer followed.

First-principles test
Hold the surface fixed, change the deciding evidence, and ask whether the answer changes for the right reason.

PAPER MAP

Grounding appears in several forms

Contrastive cue

VC-STaR uses visually similar question-answer pairs so the answer must rely on the cue that changed.

Attribution over time

Visual Attribution Streaming tracks which image regions support evolving reasoning without rerunning a costly full attribution step.

Doubt

DOUBT separates object recognition from relation reasoning before estimating whether a multimodal answer should be trusted.

Safety

FlowGuard treats internal cross-modal consistency as evidence for whether a multimodal input is benign or adversarial.

Medicine

Seizure-Semiology-Suite checks whether reports preserve temporal clinical features instead of broad video impressions.

Embodied action

MomaGraph makes a scene graph before planning, so the plan is forced through task-specific spatial and functional evidence.

METHOD

Why swaps and perturbations matter

Grounding is not proved by a correct answer; it is proved by the right sensitivity.

A grounded system should be sensitive to the evidence that decides the claim and insensitive to features that should not decide it. This is why contrastive pairs, visual swaps, temporal edits, region masking, state changes, and adversarial modality checks are so useful. They do not ask whether the model can speak well. They ask whether the model’s answer is attached to the thing it claims to know.

The same principle applies across domains. In vision, change the object relation while keeping the question style. In medicine, change the order of events while keeping the diagnosis vocabulary. In robotics, move an object or block an affordance and see whether the plan changes. In multimodal safety, perturb one modality and check whether the fused state notices the disagreement. The test is always the same: the evidence path should bend when the source bends.

FAILURES

How grounding breaks

Grounding breaks when text replaces vision, labels replace measurements, a caption replaces a signal, a scene description replaces action affordances, or a reasoned answer replaces the evidence that would justify it. The model may still sound correct. The failure is that the answer no longer depends on the source it cites.

Grounding also breaks through compression. Video token merging, omnimodal token reduction, and long-context compression can save compute while dropping the cue that mattered. This is why grounding and compression have to be read together: a smaller state is useful only if it preserves the evidence needed for the next decision.

FAILURE MAP

The common ways evidence gets lost

Prior answer

The model answers from what is usually true and treats the evidence as confirmation.

Wrong region

The model notices an object but misses the local detail or relation that decides the answer.

Temporal flattening

A video event becomes a bag of visible facts, so order and timing disappear.

Modality laundering

One modality is wrong or attacked, but fusion makes the final answer look coherent.

Attribution theater

A heatmap or rationale is produced after the answer and does not show causal use.

Compression loss

The system saves tokens or memory by dropping the rare cue needed for the hard case.

CONNECTION

Why this idea cuts across the atlas

Grounding is the evidence side of many other concepts.

Evaluation needs grounding because an evaluator must check whether the answer touched the real task object. Multimodal contracts need grounding because each modality carries a different kind of evidence and a different way to lie. Compression needs grounding because the removed tokens may be exactly where the evidence lived. Robotics needs grounding because an action commits the system to the physical state it inferred.

The deeper concept is not limited to images. Any AI system that claims to know something about the world must preserve the evidence that makes the claim true. When that path is broken, correctness becomes coincidence.
