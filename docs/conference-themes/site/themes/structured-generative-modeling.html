Problem

A valid protein or molecule is not just a bag of points. It has local geometry, global structure, and invariances to rotation and translation that naive generation can violate.

Approaches

The evidence covers hierarchical protein autoregression for coarse-to-fine backbone generation and quotient-space diffusion over molecular/protein geometry modulo SE(3).

Connecting read

This theme is about choosing the right sample space before sampling: the generator should operate on physical structure, not on coordinate artifacts.

READ

The Big Picture

Generative modeling becomes harder when the output is a physical structure rather than an image or a sequence of words. The same molecule rotated in 3D is still the same molecule. A protein backbone has local constraints and long-range organization. If the model ignores those facts, it wastes capacity learning coordinate accidents and can generate structures that look plausible numerically but violate the object being modeled. Structured generative modeling starts from the opposite premise: define the geometry, hierarchy, and invariances first, then build the generator around them.

Protein Autoregressive Modeling uses hierarchical protein structure to guide next-scale prediction and robust backbone generation. Its core idea is coarse-to-fine synthesis: generate structure at a scale where global organization can be controlled, then refine details. Quotient-Space Diffusion Model takes the geometric route, deriving lifted quotient-space diffusion for R^{3N} / SE(3) and applying it to molecules and proteins. The shared point is that physical generation improves when the model's sample space matches the equivalence classes and structure of the real object.

TOPIC 01

The first choice is the space you sample in

A generator can be powerful and still fail if its sample space treats fake differences as real or hides real constraints.

For molecules and proteins, raw coordinates are often the wrong starting point. Rotating a molecule changes the numbers in the file but not the molecule. Moving the origin changes every coordinate but not the physical object. A protein backbone also has structure across scales: broad fold, motifs, chain order, local geometry, and residue-level constraints. If the model samples as if all coordinate details were equally meaningful from the start, it must rediscover the object through noise.

The two paper anchors solve this at the level of representation. Protein Autoregressive Modeling makes generation follow structural scale. Quotient-Space Diffusion makes generation ignore rigid coordinate wrappers. Both say the same thing in different language: before sampling, name the object that should stay the same.

TOPIC 02

Hierarchy keeps local detail from contradicting global form

A protein is easier to generate when the broad shape constrains the small pieces that must fit inside it.

Protein Autoregressive Modeling is not just ordinary next-token prediction applied to biology. The useful idea is next-scale prediction. The generator first represents structure at a scale where global organization is visible, then predicts finer structure that should be compatible with that organization. This matters because protein validity is not local only. A residue-level choice can be individually plausible while making no sense inside the larger fold.

The method works when coarse choices narrow the later menu without locking the model into a bad scaffold. Evidence should therefore test both sides: whether global fold information improves local generation, and whether local refinements preserve rather than merely decorate the larger structure.

TOPIC 03

Symmetry removal stops the model from learning observer accidents

If two coordinate files describe the same physical structure, the generator should not spend probability mass treating them as different scientific outcomes.

Quotient-Space Diffusion makes this explicit. The physical object is a configuration up to rigid motion. The coordinates live in R^{3N}, but the scientific object lives after grouping rotations and translations that do not change molecular identity. Diffusing in the wrong space forces the model to learn nuisance copies. Diffusing over the quotient space directs learning toward relative shape, geometry, and physically meaningful variation.

The important caution is that symmetry removal is only valid when the removed coordinate really is irrelevant. Docking orientation, handedness, sensor direction, or asymmetric environments can make a pose-like variable meaningful. A good quotient method must therefore prove that it removed fake variation without erasing task-relevant signal.

TOPIC 04

Physical validity is stronger than plausibility

A generated structure can look reasonable to the model while failing the object’s native rules.

This is why structured generation needs external checks. A sample can have smooth coordinates but broken local geometry. It can have plausible local neighborhoods but incoherent global organization. It can be invariant to rotation yet chemically useless. It can satisfy a generic score while missing the motif, scaffold, or downstream condition that made the generation task meaningful.

The evidence for these papers should therefore be object-native. Test fold consistency, local backbone validity, same-object behavior under rigid motion, conditional preservation, and downstream scientific utility. Likelihood or sample aesthetics are not enough because the failure lives in the physical structure.

TOPIC 05

The method works by removing the wrong degrees of freedom

Structured generation improves when the model is free to change candidate structures but not free to change the definition of the object.

Protein hierarchy removes an ordering mistake: it stops the generator from treating every fine coordinate as independent before the global form is known. Quotient-space diffusion removes a coordinate mistake: it stops the generator from treating arbitrary pose as scientific variation. Both methods reduce the search space in a principled way. They do not make generation easier by ignoring physics; they make generation easier by respecting physics earlier.

That is the transferable lesson for the atlas. A generator should be judged by what it preserves while it samples. What may change is the path, resolution, coordinate representative, or candidate detail. What must stay fixed is the same-object identity and the domain validity rule.

CORE

Generate the object, not the coordinate accident

A valid physical structure is not defined by one arbitrary coordinate listing. It is defined by relationships that remain true across rotations, translations, and levels of detail.

This is the simplest way to understand the two papers. A protein backbone has global fold, local geometry, chain order, and scale-dependent constraints. A molecule or protein in 3D can be rotated or translated without becoming a new scientific object. If a generator treats every coordinate frame as different, it spends learning capacity on meaningless variation. If it samples fine coordinates before controlling coarse structure, it can lose global validity.

Structured generation therefore begins by asking what should count as the same object. Once that is clear, the model can choose the right generation path: coarse-to-fine hierarchy for proteins, or quotient-space diffusion for structures whose coordinate frames should not matter.

METHOD

Why hierarchy and quotient spaces are different fixes

Both papers repair the same failure, but at different levels of the generative process.

Protein Autoregressive Modeling repairs the scale problem. A protein should not be generated as unrelated atom positions. Global organization constrains local detail, and local detail must refine rather than contradict the global form. A next-scale prediction setup lets the generator first capture coarse structure, then add finer backbone information in a controlled way.

Quotient-Space Diffusion repairs the symmetry problem. The same configuration under a rigid rotation or translation should not be treated as a different sample. Modeling over R^{3N} / SE(3) tells the generator to operate on the equivalence class: the physical arrangement up to rigid motion. That is why the mathematical object matters. It removes fake distinctions before they become learning burden.

EVIDENCE

What would prove the sample space is right

The evidence should show that the generator improved because it respected the object, not merely because it had a stronger network or more sampling budget.

Validity

Generated structures should satisfy the local physical constraints expected of the molecule or protein backbone.

Coherence

Fine detail should refine the coarse structure rather than contradicting the global fold or scaffold.

Equivariance test

Rotating or translating the input or sample frame should not change the underlying distribution over physical structures.

Conditional control

When asked for motifs, scaffolds, or constraints, the model should preserve those requested objects while filling in valid structure around them.

Ablation

Removing hierarchy or quotient-space handling should measurably hurt the properties those mechanisms were designed to protect.

Scientific utility

Generated candidates should remain useful under downstream structure checks, not only under the model's own likelihood or sample score.

FAILURE MODES

How structured generation still breaks

A method can name the right structure and still fail if the preserved object is too weak, too coarse, or only mathematically convenient.

Coordinate leakage

The model claims symmetry handling, but samples or scores still change when the same structure is rotated or translated.

Coarse lock-in

The early global structure is wrong, and later refinement can only decorate that mistake instead of repairing it.

Local invalidity

The global sample looks plausible, but neighborhoods, backbone detail, or physical constraints are broken.

Mode narrowing

The hierarchy or quotient construction removes fake variation but also suppresses real structural diversity.

Metric mismatch

The model improves a geometric score that does not correspond to usable biochemical or physical function.

Condition drift

The generator satisfies general structure quality while ignoring the motif, scaffold, or condition that made the sample useful.

INSIGHT

The sample space is a modeling choice

A generator inherits the mistakes of the space it samples in.

If the space treats equivalent structures as different, the model learns spurious diversity. If the space hides hierarchy, the model has to rediscover scale from raw coordinates. If the space ignores physical constraints, the model can produce samples that look numerically plausible but fail as molecules or proteins.

The deeper principle is reusable across generative AI: before asking how to sample, ask what object is being sampled. For physical and scientific domains, the native object often has symmetries, constraints, and hierarchy that should be built into the generation path.

CLUSTERS

The Main Research Moves

Generate structure across scales

Protein autoregression becomes more natural when the model can move from coarse organization to finer backbone detail. That mirrors the object: proteins are not independent coordinate predictions, they are structured chains with geometry that emerges across levels. A next-scale prediction setup gives the model a way to preserve global form while adding local resolution.

Remove coordinate artifacts from the sample space

Quotient-space diffusion attacks the symmetry problem directly. If rotating or translating a structure should not change the underlying object, the generative process should not treat those transformations as distinct scientific outcomes. Modeling over R^{3N} / SE(3) expresses that idea mathematically: sample the physical configuration up to rigid motion, not the arbitrary coordinate frame.

CONCEPT BRIDGES

Where to read the larger pattern

Scientific generation preserves the native object

Structured generation fails when it treats physical or geometric constraints as decoration. The native object defines which samples are legal.

Spectra, rank, and subspaces are working objects

Quotient spaces, symmetries, and geometric coordinates are working objects because they remove changes that should not count as different structure.

Grounding preserves evidence

A generated structure is grounded when the output remains tied to the evidence or constraint that made it valid, not only to a familiar surface form.
