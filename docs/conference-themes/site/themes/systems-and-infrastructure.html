Problem

The shared problem is that simple benchmark accuracy no longer explains what is happening. The papers in this group isolate a narrower failure mode, capability, or design constraint.

Approaches

The approaches vary by paper, but the common pattern is to define a sharper object of study, build a method around that object, and test whether it changes behavior under controlled conditions.

Connecting read

Read this page as a map of the local evidence rows, not as a claim that the theme is as central as the largest conference themes.

SUBTHEMES

What the papers are actually about

Accelerator-native optimal control loops

ICLR 2026Differentiable MPC on GPU
Speeds RL and imitation-learning training by making differentiable MPC practical on GPUs.

Anchor-guided heterogeneous federated learning

ICML 2026FedARC
Aligns clients with semantic anchors while preserving client-specific local/global embedding fusion.

Anytime tabular foundation inference

ICML 2026TabSwift
Adds adaptive layer-wise early exit for latency-sensitive classification and regression serving.

BERT-style entity relation modeling for dispatch

ICLR 2026Triple-BERT
Reuses parameters and attention over driver/order pools, improving served orders and pickup time on Manhattan data.

Commodity long-context inference

ICML 2026DHSA
Runs 100K context on a single 24GB GPU and accelerates prefill through memory-efficient tiled backends.

Compiler-generated edge activation approximations

ICML 2026FFCC
Lowers costly Swish/GELU-like functions into fast floating-point reinterpretation instruction sequences.

Compression best-practice benchmarking

ICLR 2026Layer Pruning Reassessment
Uses large-scale benchmarks and gradient-flow analysis to reassess LLM pruning and post-pruning fine-tuning.

Computationally efficient optimal bandits

ICML 2026Rare-Update Bandits
Removes G-optimal design bottlenecks while keeping optimal regret in linear and generalized linear settings.

Distributed orthogonalized optimizer scaling

ICML 2026NorMuon
Implements scalable Muon-style orthogonalization under FSDP2 across devices.

Efficient topological residual architecture

ICML 2026mHC
Combines diversified residual connectivity with infrastructure optimization for scalable training.

Elastic dynamic tensor operations

ICML 2026CONTINUUM
Supports zero-copy topological aliasing and dynamic memory behavior through PyTorch-level Elastic Tensors.

Formal math knowledge-base construction

ICLR 2026CRAMF
Indexes over 26,000 definitions and 1,000 concepts with query augmentation and hybrid reranking.

GPU-friendly matrix sign optimization

ICLR 2026Polar Express
Designs minimax adaptive matrix-sign iterations using only matrix multiplications for high-throughput accelerators.

Head-level compression sensitivity

ICML 2026EntroKV
Retains high-entropy attention heads while aggressively compressing low-entropy heads at serving time.

Hierarchical MoE embedding interoperability

ICML 2026Embedding Translation
Uses localized expert adaptation and confidence metrics across 90 pairwise model translation settings.

High-throughput vector similarity search

ICLR 2026Probabilistic Angle Kernels
Applies the kernels to ANNS and reports 2.5x-3x higher QPS than HNSW.

Human-governed short-horizon production agents

ICML 2026MAP
Finds production agents mostly use prompting, human evaluation, and short workflows before intervention.

IO-aware GNN kernel families

ICML 2026IO-Aware GNNs
Groups GNN layers by SpMM, reduction, and attention kernels to reduce memory traffic and improve locality.

IO-aware gigavoxel image registration

ICLR 2026FFDP
Uses non-GEMM fused kernels and distributed sharding to register native-resolution human-brain MRI volumes.

Interoperable tool-use and browsing trajectories

ICLR 2026ADP
Unifies 13 agent datasets and reports around 20 percent average gains across coding, browsing, tool-use, and research benchmarks.

Joint MoE pruning and quantization

ICML 2026MoE Compression
Combines structural pruning with 4-bit quantization to reduce Qwen3-30B-A3B memory footprint by 5.27x.

Lossless speculative execution for AI agents

ICLR 2026Speculative Actions
Predicts likely agent actions with faster models so multiple API calls can run in parallel without changing accepted behavior.

Low-power cumulative memory RNNs

ICML 2026CMRU
Restores gradient flow in analog-friendly bistable recurrent units through cumulative temporal updates.

Low-rank-aware KV quantization kernels

ICML 2026STAR-KV
Combines hybrid low-rank decomposition, mixed precision quantization, and Triton kernels for faster generation.

MoE harmonization of modality asymmetry

ICML 2026Beyond LM
Uses sparse experts to provide language capacity while accommodating vision's data-hungry scaling.

PagedAttention memory reuse for reasoning caches

ICLR 2026ThinKV
Reuses evicted KV-cache slots to avoid compaction overhead and improve reasoning throughput.

Program-aware agentic inference

ICML 2026ThunderAgent
Schedules LLM and tool resources with workflow-level knowledge of KV caches, states, and external assets.

RL-generated sparse CUDA kernels

ICLR 2026SparseRL
Treats CUDA generation as a stochastic policy conditioned on sparse matrix nonzero indices.

Recurrent LLM scaling through solver reformulation

ICLR 2026FlashRNN
Trains 7B-parameter LSTM/GRU-style models with perplexity comparable to similarly sized Transformers and Mamba2.

Single global merging for decentralized learning

ICLR 2026Global Merging
Shows late fully connected merging can improve generalization under severe data heterogeneity.

Sparse capacity allocation under fixed budgets

ICLR 2026Equal-Resource MoE
Trains hundreds of 2B/7B models and identifies a consistent optimal activation-rate region.

Stabilized 2D-3D scientific pretraining

ICML 2026Walrus
Combines harmonic-analysis stabilization, load-balanced distributed training, and compute-adaptive tokenization.

Task-discriminative expert routing

ICML 2026DroneDINO
Uses auxiliary task recognition to counter dominant-task overactivation in unified drone detectors.

Test-time repair dynamics for verification

ICML 2026AlgoVeri
Measures whether models can exploit verifier feedback rather than saturating after early attempts.

Tile-level neural kernel DSL

ICLR 2026TileLang
Exposes memory placement, data movement, and scheduling primitives for fused neural kernels.

Universal tensor notation via vectorization

ICLR 2026einx
Reduces tensor APIs to declarative expressions grounded in consistent vectorization rules.
