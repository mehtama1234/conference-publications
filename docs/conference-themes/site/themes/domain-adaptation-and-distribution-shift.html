Domain adaptation and distribution shift when the source data is gone

The core problem is deployment under a changed data distribution. A model trained in one domain must work in another, but privacy, licensing, storage, or institutional rules may prevent access to the original source data. This page focuses on a sharper case: source-free adaptation for regression, where target labels are continuous and pseudo-labels are uncertain.

FIRST PRINCIPLES

Why distribution shift is not one problem

Distribution shift means the world at deployment is not the same as the world used to train the model. But the right fix depends on what changed and what evidence remains available. If source data is still available, the model can compare source and target distributions directly. If source data is unavailable, the model has to adapt from the trained source model and unlabeled target examples alone. That is source-free domain adaptation.

Regression makes this harder than classification. In classification, a pseudo-label is a class and the class distribution gives a natural discrete structure. In regression, the target is ordered and continuous. A bad pseudo-label may be close, far, biased in a region, or uncertain in a way that a single scalar cannot express. Under shift, treating every target prediction as a point estimate can make the model reinforce its own mistakes.

No source data

The source distribution cannot be replayed during adaptation, so the method must respect privacy and data-access constraints while still improving target behavior.

Continuous targets

The label space has order and distance. Adaptation should know that nearby values are related rather than pretending every label is a separate class.

Uncertain pseudo-labels

Target predictions are training signals only if the method tracks how much to trust them and how their local density should shape refinement.

TOPIC 01

Source-free means the old world cannot be replayed

The model has a memory of the source domain in its weights, but not the source examples themselves.

That changes the adaptation problem. If source data were available, the method could compare source and target examples, estimate the shift directly, and regularize against forgetting the original task. In source-free adaptation, those direct checks are gone. The system starts with a trained model and unlabeled target data. It has to improve in the new domain without seeing the old examples that originally anchored the task.

This makes every target-domain training signal risky. The source model may still contain useful structure, but its target predictions are not ground truth. They are guesses made by a model trained under a different distribution. The adaptation method has to use those guesses while remembering that the very reason for adaptation is that the guesses may now be biased.

TOPIC 02

Regression shift has geometry that classification shift does not

For regression, labels live on an ordered measurement scale, so wrong answers have distances and directions.

A classification pseudo-label says "this example is probably class A." The main question is whether the class is right. A regression pseudo-label says "this example is probably around 7.2." That number can be slightly low, slightly high, badly biased, uncertain because the input is ambiguous, or unreliable because the target region is sparse. Treating it like a hard label loses the structure that makes regression different.

DDG-SFDA's density idea matters because it keeps more of that measurement structure alive. Instead of using one point as the whole supervision signal, the method gives the target label a local shape. Nearby values can be related, uncertainty can be represented, and target examples can organize the feature space around a distribution rather than a brittle scalar.

TOPIC 03

Pseudo-labels can amplify the model's own mistakes

Self-training is useful only when the model knows which of its own predictions deserve trust.

The simplest failure loop is easy to see. The source model predicts a value for an unlabeled target example. The adaptation method treats that value as a label. The updated model becomes more confident in the same value. If the first prediction was wrong because of distribution shift, the training loop has converted an error into supervision.

Uncertainty-aware refinement is the guardrail. It asks the method not to treat all pseudo-labels equally. Dense, consistent regions of target evidence can receive more confidence. Sparse, unstable, or shifted regions should stay uncertain. The deeper principle is that adaptation under missing labels needs calibrated doubt; otherwise the model trains on its own hallucinated certainty.

TOPIC 04

Density is a substitute for missing labels, not a replacement for them

A density-shaped signal can make unlabeled target data usable, but it does not magically prove the true target labels.

The density object is useful because it gives the model structure: which values are nearby, which regions look coherent, and where target examples cluster. But density is still inferred from unlabeled data and source-model predictions. If the source model is wrong in a systematic way, the density can be centered around the wrong values. If the target sample is sparse, the density can look smoother than the evidence deserves.

That is why the proof must include ablations and stress tests. The paper has to show that density supervision is doing more than adding a convenient auxiliary loss. It should improve continuous target error, organize target features, tolerate perturbations, and fail gracefully when target evidence is weak.

SUBTHEME

Density-guided regression SFDA

DDG-SFDA gives regression adaptation a usable target geometry

regression shift

DDG-SFDA Regression starts from a gap in source-free domain adaptation. Classification SFDA has made progress because class labels provide a discrete structure for pseudo-labeling, confidence estimation, and representation alignment. Regression lacks that scaffold: the output is a continuous number, so a model adapting on unlabeled target data has to decide not only which value to assign, but how uncertain that value is and how nearby values should influence the representation. The paper's move is to convert continuous labels into instance-dependent, discretized density-informed supervisory signals. That gives the adaptation process a distributional shape around the target prediction rather than a brittle scalar target.

The method uses uncertainty-aware pseudo-label refinement and auxiliary discretized distribution learning. Conceptually, it borrows some of the stabilizing benefits of classification without throwing away regression's ordered label structure. The learned density signal makes target-domain features more compact and structured, and the paper reports a theoretical robustness result showing that the induced density structure can tolerate perturbations. Experiments across multiple benchmarks validate improved continuous-label prediction under source-free shift. The important lesson is that adaptation works better when the target object is represented faithfully: not as "a number from the old model," but as a local density with uncertainty and neighborhood structure.

CORE

A pseudo-label is not evidence unless its uncertainty is visible

The concrete object is a target-domain supervisory signal built from unlabeled examples when the source data is unavailable.

That object is fragile. The model is using its own predictions to teach itself in a new domain. If those predictions are treated as hard truth, early mistakes become training data and the model can confidently move in the wrong direction. In classification, confidence and class structure give a partial guardrail. In regression, a single predicted number hides how wrong it might be, whether nearby target examples agree, and whether the local region is dense or sparse.

DDG-SFDA's first-principles move is to give the continuous target a shape. Instead of adapting from a brittle scalar, the method builds a discretized density-informed signal around each target prediction and refines pseudo-labels with uncertainty. The target supervision becomes a local distribution: this value is plausible, nearby values have related meaning, and some regions deserve less trust. That is why the method belongs with the broader scientific-measurement pages: it preserves uncertainty in the object being used as evidence.

WHY IT WORKS

Regression needs a geometry for self-training

Self-training needs a way to decide which wrong answers are slightly wrong, which are dangerously wrong, and which regions are too uncertain to trust.

A hard pseudo-label throws away that structure. Suppose the old source model predicts 7.2 for a shifted target example. If the adaptation objective treats 7.2 as truth, then the next model is trained to imitate the old model's uncertainty as if it were a label. If 7.2 is close, that may help. If it is biased because the target domain moved, the error becomes self-reinforcing.

A density-shaped pseudo-label says something more useful: there is a center, a spread, nearby values have graded support, and the model should treat the signal as uncertain evidence rather than ground truth. Discretization gives the training objective a set of neighboring buckets to learn from; density makes those buckets unequal; uncertainty-aware refinement decides how much confidence the model should place in the current signal. That gives regression some of the stabilizing scaffolding that classification gets from classes, while preserving the fact that the output is continuous.

The deeper principle is simple: when labels are missing, the substitute label must carry the structure of the original measurement. For classification, that structure is class membership. For regression, it is order, distance, density, and uncertainty.

EVIDENCE

What would prove the paper's claim

The evidence has to show more than target-domain improvement. It has to show that the density object is the reason adaptation becomes more reliable.

Target accuracy

Continuous-label error should improve across shifted regression adaptation benchmarks, not only on source-style validation data.

Density ablation

Removing discretized density supervision or uncertainty-aware refinement should weaken adaptation if those pieces are doing real work.

Feature structure

Target features should become more compact and organized around useful continuous-label neighborhoods.

Perturbation robustness

The reported theory says the induced density structure tolerates perturbations; empirical stress tests should match that story.

Sensitivity checks

Bin count, uncertainty estimator, sparse target regions, and severe source-model bias are the places where the method could look strong but be brittle.

Source-free audit

The adaptation protocol should not quietly depend on source examples, source statistics that would violate the constraint, or hidden access to target labels.

FAILURE MODES

Where the idea can break

The method is strongest when the source model is wrong enough to need adaptation but still right enough to provide useful target evidence.

If the initial source model is badly biased in the target domain, density refinement may organize the wrong region of label space. If the target domain is sparse, local density can become a hallucinated structure: the model sees a pattern because the objective asks for one, not because target evidence supports it. If discretization is too coarse, the method loses the fine differences that made regression valuable. If discretization is too fine, the density signal may become noisy and hard to learn.

The privacy motivation also has a boundary. Removing source data from the adaptation loop helps, but it does not automatically prove that the source-trained model leaks no source information. Source-free adaptation is a data-access constraint, not a complete privacy certificate. That distinction matters because the page's broader lesson is controlled change under constraints: the constraint has to be named precisely.
