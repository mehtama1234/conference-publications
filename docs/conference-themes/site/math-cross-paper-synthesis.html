FIRST PRINCIPLE

The Big Problem Is Controlled Change

Across ICML and ICLR, the central problem is no longer only prediction. The systems being studied change state: they reason through traces, call tools, update parameters, compress memories, generate trajectories, adapt to users, and move through physical environments. Once a system changes state, the important question becomes what should be preserved while it changes.

That is the common mathematical spine. A paper is strong when it identifies a state variable, a measurement, a feasible region, a distribution path, an update geometry, or a verifier that preserves the quantity the task cannot afford to lose.

CHAIN 01

From Prediction To State Control

RAGEN-2 -> HDFlow -> IRNO -> Mamba Markov ICL

Shared object. A state transition whose intermediate state must preserve task-relevant information.

Why the connection matters. RAGEN-2 asks whether a reasoning trace still depends on the input. HDFlow asks whether robot action can pass from subgoal to local motion. IRNO asks whether a neural operator can iteratively reduce residual error. Mamba Markov ICL asks whether a recurrence implements the right estimator for a hidden Markov source.

First-principles read. These papers are not about longer text, smoother motion, better PDE loss, or newer sequence blocks in isolation. They all ask whether the next state contains the information required by the next decision.

Failure Mode

If the state is wrong, errors look independent when they are actually propagated. Template reasoning, robot drift, operator residuals, and lost sequence memory are the same structural failure: the system projects away information before the task is done.

state_t -> update -> state_{t+1}; success requires sufficient state, not just a good endpoint
CHAIN 02

From Scores To Instruments

ATLAS -> FRABench -> WebDevJudge -> MADQA

Shared object. A noisy measurement process for latent ability.

Why the connection matters. ATLAS chooses items by information. FRABench factors the rubric. WebDevJudge observes rendered artifacts instead of source text alone. MADQA separates human, agent, and oracle gaps in document QA.

First-principles read. A benchmark is an estimator. Its item distribution, judge channel, and scoring rule decide what hidden variable the score can support. Without that measurement model, a leaderboard number can be precise and still meaningless.

Failure Mode

A single aggregate score can hide sampling variance, judge bias, ability mixtures, shortcut use, or missing evidence. These papers work because they redesign the instrument, not because they add more questions.

observed score = latent ability signal + item noise + judge bias + task-mixture artifact
CHAIN 03

From Data To Distribution Design

DiReCT -> Midtraining Bridges -> Common Corpus -> Sequential Data Values

Shared object. Training data as a control variable over the learning trajectory.

Why the connection matters. DiReCT selects data by curvature-aware parameter movement. Midtraining Bridges chooses when specialized data should arrive. Common Corpus makes permission and provenance constraints part of the empirical distribution. Sequential Data Values makes the next example's value depend on the selected set.

First-principles read. Data does not help by existing. It helps by creating a useful update at a point in training, under legal and statistical constraints, after other data has already changed the model.

Failure Mode

"More data" fails when examples arrive after plasticity is gone, move the model in stiff directions, duplicate already-covered evidence, violate provenance constraints, or hide missingness as certainty.

utility(example | model_t, optimizer_t, selected set, constraints)
CHAIN 04

From Outputs To Feasible Sets

Copyright-Bench -> Pi-net -> Quotient Diffusion -> Fair OT

Shared object. A constrained search space where invalid outputs should not receive probability mass.

Why the connection matters. Copyright-Bench defines lawful source choice. Pi-net projects outputs into convex constraints. Quotient diffusion removes rigid-pose degrees of freedom. Fair OT constrains the transport coupling itself.

First-principles read. Optimizing first and filtering later wastes search on impossible, illegal, unfair, or coordinate-fake outputs. The better move is to define the feasible set before optimization begins.

Failure Mode

A plausible answer can be invalid. A molecule can be the same under rotation. A matching can be cheap and unfair. A neural output can violate hard constraints. Feasible-set papers work by changing the space, not only the penalty.

choose x in C, not choose x anywhere and reject after
CHAIN 05

From Samples To Transport Paths

DMPO -> FALCON -> Safety-Guided Flow -> GWF

Shared object. A path that moves probability mass through a distributional geometry.

Why the connection matters. DMPO matches reasoning RL to diffusion-language trajectories. FALCON needs likelihood-correct molecular equilibrium samples. Safety-Guided Flow changes the vector field away from unsafe regions. GWF explains how divergences induce Wasserstein flows.

First-principles read. A sampler is not just a generator of final objects. It is a transport process. The path matters because reward, likelihood, safety, and mode coverage are all properties of how mass moves.

Failure Mode

Post-hoc rejection cannot repair a sampler that spends most mass in the wrong regions. Missing modes, unsafe paths, wrong likelihoods, and mismatched RL updates all come from optimizing against the wrong distributional movement.

distribution_t -> vector field / denoiser / bridge -> distribution_{t+1}
CHAIN 06

From Gradients To Geometry

Adam Degeneracy -> LoRA Theory -> Beyond Muon -> Non-Euclidean EoS

Shared object. An update vector measured in the geometry of the optimizer.

Why the connection matters. Adam changes local coordinates through adaptive scaling. LoRA restricts movement to low-rank factors. Muon-style methods reshape matrix directions. Non-Euclidean EoS says stability must be measured in the optimizer's own geometry.

First-principles read. A gradient is not meaningful until the metric, subspace, normalization, and precision of the update are named. Optimizers work when their geometry matches the fragile directions of the objective.

Failure Mode

The same loss improvement can destroy unmeasured behavior if movement occurs along brittle directions. This is why trust regions, curvature-aware data selection, low-rank adapters, and orthogonalized updates belong in one story.

update = preconditioner * gradient, constrained by rank, trust region, precision, and curvature
CHAIN 07

From Size To Preservation

LiftQuant -> TetraJet -> FOCUS/RePAIR -> EntroKV

Shared object. A task-sensitive approximation map.

Why the connection matters. LiftQuant makes precision tunable through lifted codes. TetraJet controls structured low-precision error. FOCUS/RePAIR detects pruning-induced loop dynamics. EntroKV compresses cache by future information value.

First-principles read. Compression is not about preserving parameters. It is about preserving function under a smaller representation. The hard part is deciding which directions, states, and transitions must remain recoverable.

Failure Mode

Uniform compression assumes errors have equal consequence. They do not. Sampler error accumulates, outlier channels dominate, loops trap generation, and cache states differ in future value.

compressed computation = projection(original computation) with task-sensitive error budget
CHAIN 08

From Claims To Certificates

CyberGym -> VERINA -> Gaussian Unlearning -> Catch-22

Shared object. A certificate matched to the claim.

Why the connection matters. CyberGym demands executable exploit evidence. VERINA demands formal proof artifacts. Gaussian unlearning defines deletion through indistinguishability. Catch-22 defines watermarking through detection-theoretic limits.

First-principles read. The form of proof must match the risk. Security needs execution, formal reasoning needs a checker, unlearning needs a statistical test, and watermarking needs a detection frontier.

Failure Mode

Fluent claims are too cheap. A model can describe a vulnerability without exploiting it, write proof-like text without a valid proof, claim deletion without indistinguishability, or watermark text without surviving transformations.

claim is valid only relative to verifier V and evidence artifact A
CHAIN 09

From One Loss To Mechanisms

AdvGame -> Fair OT -> Accuracy Auctions -> Data Market Pricing

Shared object. Multiple actors whose incentives and constraints shape outcomes.

Why the connection matters. AdvGame lets attackers and defenders adapt. Fair OT constrains group couplings. Accuracy Auctions weights correctness by private user values. Data Market Pricing models strategic sellers of reusable data.

First-principles read. A single optimizer is the wrong abstraction when other actors respond. The correct object is a mechanism or game with payoffs, information, constraints, and response dynamics.

Failure Mode

Static objectives fail when users, sellers, attackers, monitors, or groups adapt. The model can optimize a metric while the surrounding institution changes the meaning of success.

policy_i affects payoff_j, constraints, information, and future response
CHAIN 10

From Association To Identification

CausalGame -> Local Covariate Selection -> OU Identifiability -> Linear Causal Representation Learning

Shared object. The boundary between what data identifies and what remains a plausible story.

Why the connection matters. CausalGame tests whether agents gather evidence under confounding. Local Covariate Selection finds local adjustment certificates. OU identifiability recovers stochastic dynamics from moments. Linear causal representation learning states equivalence classes under weak environment variation.

First-principles read. Causal and scientific papers are strongest when they say what cannot be known. They preserve the boundary between identified mechanism and underdetermined explanation.

Failure Mode

Prediction can succeed while intervention reasoning fails. A model may forecast observations, fit correlations, or draw a plausible graph without knowing what would happen if a variable changed.

identified claim = what remains invariant across allowed interventions, moments, or environments
OVERALL

The Unifying Problem

Preserve The Right Information

Every lane asks what information must survive a transformation. Reasoning preserves task dependence through a trace. Data selection preserves useful gradient movement. Compression preserves function under a smaller representation. Physical generation preserves native structure. Evaluation preserves the connection between score and capability.

Remove Fake Variation

Quotient diffusion removes pose. Fair OT removes unfair couplings from the search space. Camera-aware models remove viewpoint confounding. Common Corpus removes hidden provenance from the training distribution. Formal verifiers remove fluent but invalid proof text from the evidence space.

Name The Boundary

Safety, privacy, unlearning, watermarking, feasible optimization, and causal identification all become clearer when the boundary is explicit: unsafe region, deletion indistinguishability, detection power, lawful action set, fairness frontier, or equivalence class of mechanisms.
