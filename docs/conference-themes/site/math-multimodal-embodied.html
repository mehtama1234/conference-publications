FIRST PRINCIPLE

A Modality Is A Measurement Channel

A modality is not a file type. It is a way of measuring the world, and every measuring tool leaves something out. Image patches show surfaces from one viewpoint. Audio records pressure over time. fMRI gives a delayed blood-flow clue about neural activity. Robot sensors measure pose, contact, and force with timing delay. A text answer is valid only if these channels are combined without throwing away the fact needed for the decision.

The center of the math is a shared working state: a record of what is known, which channel showed it, when it was seen, what viewpoint or body constraint shaped it, and what doubt remains. The papers below work when they make one hidden part of that state explicit: which evidence route changed the answer, which video pieces still matter, which world change is allowed, which body movement is feasible, which human signal is being inferred, or which checker can inspect the produced artifact.

FORMULA PASS

Paper-Specific Math Boxes

MoCA, VGS, And Causal Route Gating

Object. A record of which route actually made the answer: image evidence, language habit, fusion, or later reasoning.

Why it works. A correct answer is not proof that the model looked at the right evidence. If changing the image would not change the answer, the answer came from some other route. These methods send reward, diagnosis, or suppression toward the route that caused the failure. Name used later: causal credit.

credit(channel k) = output change when route k is changed while other routes stay fixed

Evidence check. Run route ablations, paired visual/text controls, module-specific error labels, and update tests showing repair lands on the failing component.

VISUALSWAP And MINT

Object. A controlled test where one visible fact or one internal fusion state is changed while the rest stays fixed.

Why it works. If two images differ only on the asked-about fact, the answer should move with that visual fact. If it does not, the model is leaning on language habit. MINT does the same test inside the model by replacing the hidden fusion state and checking whether the answer changes. These are counterfactual and patching tests, but the plain idea is: change one cause and see whether the claim follows it.

valid grounding needs y(image A, text) != y(image B, text) when A and B differ on the queried fact

Evidence check. Use minimally different image pairs, inspect output movement, test patch locations, and report cases where attention appears visual but the answer does not move.

DOUBT And LIMSSR

Object. A working belief that keeps track of missing or conflicting channels instead of pretending the input is complete.

Why it works. When a camera view, audio stream, or body sensor is absent, the model should become less certain about the facts that channel would have checked. What must stay the same is honest doubt about facts the available evidence cannot settle. What may change is which channels are present. Name used later: posterior for the belief after seeing the available evidence.

predict from P(y | observed channels, mask), not from P(y | hallucinated complete input)

Evidence check. Vary missingness masks, conflict channels, and ambiguity levels; measure calibration, abstention quality, and hallucinated-modality dependence.

FlashVID, InfoTok, And VideoFlexTok

Object. A shorter video record that still keeps the moments that could change the answer.

Why it works. Most video frames repeat setting, but a few frames decide the event, order, or object change. Token methods help only when they compress repeated evidence and keep the decisive pieces. Sufficient means the shorter record still supports the same downstream decision.

keep token i when expected answer damage from dropping i is larger than its compute cost

Evidence check. Test rare events, temporal order questions, long videos, token-budget sweeps, and whether dropped segments later become query-relevant.

OmniFit, LST, COMPACT, And LiME

Object. A limited memory channel that decides how much of each modality, stream summary, or adaptation direction can be kept.

Why it works. Context is scarce. The model should spend it on evidence another channel cannot recover, on unresolved doubt in a live stream, and on task-relevant update directions. What must stay the same is the decision the full stream would support. What may change is the shorter summary. Name used later: sufficient statistic.

compressed state r is valid when decision(r) stays close to decision(full multimodal stream)

Evidence check. Report modality budget sweeps, latency curves, downstream decision drift, and tasks where cross-modal redundancy is false.

MetaEmbed And TACO

Object. An input translation that keeps table rows, columns, types, keys, units, and relations available.

Why it works. Flattening a table into plain text can destroy the operations the task asks for: lookup, comparison, aggregation, joining, or type checking. A better embedding is a coordinate map that keeps the input's structure usable by attention and retrieval.

embedding phi(x) should preserve operations: lookup, compare, aggregate, join, type-check

Evidence check. Test row/column perturbations, unit changes, key joins, aggregation questions, and whether answers survive serialization changes.

LatentLM, UALM, And NextStep-1

Object. A shared control code for instructions and plans, connected to native image, audio, or video state.

Why it works. A unified generator should not force every medium into text. It should use one planning interface while leaving each output in the form that preserves its own constraints. What must stay the same is the editable state each medium needs. What may change is the hidden working code used to plan across media. Name used later: latent code.

instruction -> shared hidden code z -> native decoder state x_m -> next conditioning state

Evidence check. Test cross-modal edits, continuation consistency, modality-specific validity, and whether generated artifacts remain controllable after multiple steps.

EditVerse, VIST3A, TideGS, And RadioGS

Object. Media state that knows what may change and what must stay the same across edits, views, sensors, or fields.

Why it works. An edit should change the named target while preserving object identity and unchanged context. A 3D scene should look different from a new camera without becoming a different scene. A physical field should render through sensors as one maintained signal, not as independent pictures. What must stay the same is the underlying scene or signal. What may change is the edit, view, sensor, or coordinate readout. Names used later: invariants, geometry, and field coordinates.

valid artifact = render(native state, view or sensor); edits constrain which coordinates may change

Evidence check. Run view-consistency tests, edit-locality tests, field reconstruction checks, and invariant preservation across repeated transformations.

VibeVoice, TTSDS2, Hibiki-Zero, And WAVE

Object. Speech/audio as timed acoustic state rather than transcript text.

Why it works. Meaning, speaker identity, prosody, rhythm, and latency are coupled in the waveform. Audio-native modeling preserves variables that disappear when speech is treated only as words.

audio state a_t carries semantic content, speaker/prosody variables, and timing under latency budget

Evidence check. Measure intelligibility, speaker fidelity, prosody, translation delay, temporal event accuracy, and failures where transcript quality hides bad audio.

EmotionThinker, EEmo-Logic, Active Mind Avatars, And MetaphorVU

Object. Social meaning as the hidden situation behind words, expression, pose, gaze, context, and metaphor.

Why it works. Emotion and metaphor are not labels stuck to one phrase. They are explanations that must fit several cues at once: what happened, what was implied, how the person reacted, and what response would make sense. Name used later: latent social state.

infer hidden social state c from multimodal cues, then predict response y from P(y | c, context)

Evidence check. Use cue-conflict tests, cultural/context shifts, metaphor perturbations, and cases where text sentiment disagrees with visual or social evidence.

PRISM, Mind-Omni, SleepLM, And BioX-Bridge

Object. Body and brain sensor streams as indirect clues about a biological condition, concept, or event.

Why it works. fMRI, sleep signals, and biosensors do not show the target directly. They show delayed, noisy traces. Intermediate tokens or structured codes let the model first estimate the hidden biological state, then use that estimate for media generation or clinical prediction. What must stay the same is the biological state supported by the sensor evidence. What may change is the noisy stream or code used to infer it. Name used later: posterior for the revised belief over that state.

sensor stream b ~ P(b | hidden biological state c); downstream task uses revised belief over c

Evidence check. Test subject variation, temporal delay, sensor noise, code ablations, and whether decoded concepts match independent measurements.

SAW-Bench, RoboMME, MomaGraph, And EgoTactile

Object. The body-world state a robot needs: scene relations, what can be done with objects, remembered procedure, and contact evidence.

Why it works. A robot decision is valid only if the body can carry it out and the world changes as intended. Graphs expose objects and relations that can be manipulated, memory benchmarks isolate which kind of memory is needed, and tactile signals reveal contact that vision may miss.

policy needs state = world graph + body pose + memory variable + contact state

Evidence check. Test temporal/spatial/procedural memory separately, stale graph failures, contact slips, and tasks where language planning succeeds but execution fails.

HDFlow, PACT, JoSE, RodriNet, And BehaviorVLA

Object. Action as an allowed world change: choose a goal, trace a feasible motion, keep close to trusted behavior, obey body rotation, and preserve reusable skill.

Why it works. Embodied policies improve when high-level intent is separated from low-level motion the body can actually perform. Updates should change uncertain actions without wandering outside safe behavior. What must stay the same is physical feasibility and trusted behavior. What may change is the chosen motion inside that smaller allowed movement space. Name used later: action manifold.

choose subgoal z, generate feasible action path a(t), constrain policy update distance from trusted behavior

Evidence check. Measure subgoal correctness, path feasibility, allowed-movement violations, transfer behavior, and degradation under policy correction.

VideoKR, Visual Attribution Streaming, DLMR, WETR, And AGREE

Object. Provenance-aware memory that separates observations, derived beliefs, retrieved knowledge, and weak labels.

Why it works. Grounded memory fails when conclusions are stored as if they were evidence. Routing preserves source labels, attribution tracks visual support over time, and reliability weights scale noisy labels by evidence quality.

belief is valid when supported by observation memory plus provenance, not by recycled model inference

Evidence check. Audit memory writes, retrieved versus observed support, attribution over time, weak-label reliability, and hallucinations that persist through memory.

OmniVerifier, FlowGuard, DAVE, VC-STaR, And HALO

Object. A checker that sees the artifact, generation path, visual evidence, corrected trajectory, or policy update.

Why it works. A grounded verifier must observe the medium where failure happens. Endpoint checks catch visible errors; trajectory checks catch abnormal paths; update checks catch unstable policy movement before deployment. Projection here means the checker reads the part of the native artifact or path relevant to the task.

accept output only when checker V(native artifact, path, evidence, update) satisfies task constraints

Evidence check. Compare text-only and artifact-native judging, monitor intermediate states, test self-correction quality, and measure verifier gaming under repeated optimization.

OBJECT 01

Modality Credit

MoCA

Problem. A multimodal agent can fail because it saw the scene badly, reasoned badly, or combined the two badly.

Object. A failure-route record that says which component should receive blame or training signal.

Why it works. Feedback is useful only if it reaches the part that caused the mistake. MoCA makes the route visible, so an update can repair visual grounding or reasoning instead of mixing both errors into one noisy reward. What must stay the same is the actual source of the mistake. What may change is where the training signal is sent. Name used later: credit assignment.

Connection. It is RAGEN-style trace diagnosis for multimodal state.

VGS

Problem. Visual grounding can be overestimated when the answer is correct for language-prior reasons.

Object. A score for whether visual evidence supports the generated content.

Why it works. The method asks whether the visual channel reduces uncertainty about the answer. If removing or changing the image would not change the output, the answer was not visually grounded in the mathematical sense.

Connection. It turns grounding into an evidence contribution problem.

Causal Route Gating

Problem. Large vision-language models can answer from text habit while appearing to look at the image.

Object. A map of internal routes that carry visual evidence versus routes that carry language prior.

Why it works. Like testing which wire changes a radio's sound, the method asks which internal route would change the answer if moved. What must stay the same is the image question and the expected visual fact. What may change is the route being suppressed or strengthened. Name used later: gradient for a local nudge estimate, and causal intervention for changing one route to test its effect.

Connection. It is route repair inside the fusion layer.

VISUALSWAP

Problem. VLMs can ignore fine visual changes when language context stays stable.

Object. Counterfactual image perturbations that preserve text while changing the visual truth.

Why it works. Swapped visual evidence creates paired examples where the correct answer must move with the image. The test isolates visual dependence by holding the shortcut channel fixed.

Connection. It is an experimental design for modality causality.

DOUBT

Problem. Multimodal systems often answer even when the image, audio, text, or sensor evidence is incomplete or contradictory.

Object. A record of whether the available channels justify commitment.

Why it works. Doubt is useful only when it points to a concrete missing or conflicting channel. The model improves by separating "I did not observe it" from "I observed the opposite." What must stay visible is the set of plausible answers left by the evidence. What may change is which channel is missing or conflicting. Name used later: ambiguity set.

Connection. This is remaining-doubt reasoning in multimodal form.

MINT

Problem. Hallucination can originate in a narrow fusion band hidden inside the network.

Object. A causal patch over hidden states where image evidence enters language generation.

Why it works. Hidden-state patching changes an internal variable and observes whether the output changes. That gives a causal test for fusion, not only an attribution heatmap.

Connection. It links interpretability intervention to modality credit.

OBJECT 02

Token Bottlenecks

FlashVID

Problem. Long video creates more visual pieces than a model can carry at full detail.

Object. Like condensing security-camera footage into notes, the object is a shorter record that keeps the moment a door opens, a tool is picked up, or an object changes place.

Why it works. Most neighboring frames repeat the same room, background, and slow motion. What must stay the same is the event evidence that could change the later answer. What may change is how many nearby patches and frames are merged. FlashVID helps when it collapses repeated evidence while preserving short decisive events. Name used later: spatiotemporal token merge map for the rule that says which video pieces across space and time can be combined.

Connection. It is systems efficiency as information selection.

InfoTok

Problem. Fixed video token budgets waste compute on repeated background and can miss the one moment that decides the answer.

Object. A value estimate for each video piece: would removing this piece change a later answer or action?

Why it works. Compression is guided by decision value instead of uniform downsampling. Tokens survive because they reduce future doubt. What must stay the same is the later answer or action. What may change is which video piece is kept. Name used later: information density.

Connection. It is active measurement selection for video context.

VideoFlexTok

Problem. Video tasks differ in how much temporal detail they need.

Object. Like taking more notes during the key play in a match and fewer notes during pauses, the object is how much token budget each video segment receives.

Why it works. What must stay the same is the event, motion, or order needed for the later answer. What may change is how many visual tokens each segment gets. The model avoids treating every video as the same sampling problem: it spends more where motion or event order matters and fewer where static context is enough. Name used later: flexible visual token budget.

Connection. This matches adaptive compute in reasoning models.

OmniFit

Problem. A multimodal model has limited context and cannot spend the same amount on every channel.

Object. A rule for how much memory each modality gets.

Why it works. The method succeeds when each channel keeps the facts only it can provide. Compression is harmful when it removes evidence that no other channel can reconstruct. What must stay the same is the decision supported by the full evidence. What may change is the smallest summary kept for each channel. Name used later: minimal sufficient statistic.

Connection. It is feasible-state construction under memory constraints.

LST

Problem. Speech and multimodal streams need quick responses before the full future is available.

Object. Like taking notes during a live call, the object is a running summary that can be updated now while still leaving room for later correction.

Why it works. What must stay the same is the ability to decide or revise when later evidence arrives. What may change is the small note kept at each moment. LST helps when the live state keeps unresolved facts instead of collapsing them too early. Name used later: streaming token state for this running record.

Connection. It connects multimodal modeling to control-loop timing.

COMPACT And LiME

Problem. Long-context use and multimodal adaptation can become expensive because the model keeps too many notes or changes too many knobs.

Object. Like keeping only the meeting notes and control knobs that can still change the outcome, the object is the smaller memory or smaller update handle that remains useful for the task.

Why it works. What must stay the same is the target answer or behavior. What may change is how much state is carried and which update directions are allowed. COMPACT keeps state that changes outputs; LiME limits adaptation to the few directions needed by the task. Names used later: compressed retained state and low-dimensional adaptation interface.

Connection. This is the shared math behind context compression and adapter efficiency.

MetaEmbed And TACO

Problem. Tables, structured records, and nonstandard inputs lose meaning when flattened into ordinary text.

Object. A translation that preserves rows, columns, types, joins, and relations.

Why it works. The model should not have to rediscover structure after the input format erased it. Better embeddings keep the operations the task needs available to attention and retrieval. What must stay the same is lookup, comparison, aggregation, joining, and type meaning. What may change is the coordinate format. Name used later: representation map.

Connection. It is tokenization as choosing the right coordinate system.

OBJECT 03

Unified Generation

NextStep-1

Problem. Multimodal generation should support the next edit, not only the first sample.

Object. A generation interface where each output remains usable as the next input state.

Why it works. Editing and continuation require the generated artifact to keep object identity, layout, timing, or other state the next step must condition on. The output is a new state, not the end of computation. What must stay the same is the editable state needed by the next step. What may change is the produced artifact. Name used later: representation.

Connection. It is agent trajectory logic applied to media generation.

EditVerse

Problem. Image editing fails when instructions are not tied to the editable parts of the scene.

Object. An edit state with targets, constraints, and unchanged context.

Why it works. Like changing a shirt color in a photo while keeping the person, pose, and room the same, the method names the allowed change before generating. What must stay the same is object identity and untouched context. What may change is the instructed target. Name used later: invariant for a fact that should survive the edit.

Connection. It is feasible-set design for generated media.

LatentLM And UALM

Problem. Text, images, and audio have different native forms, but agents need one place to plan across them.

Object. A shared hidden working code that each native decoder can read.

Why it works. Like a project brief that a writer, designer, and audio editor can each use without losing their own craft rules, the hidden interface connects media without forcing every detail into words. What must stay the same is the structure each decoder needs to make valid media. What may change is the hidden code and the next generated step. Names used later: latent for hidden code, and autoregressive for step-by-step generation.

Connection. This is protocol design: choose the hidden record that lets each medium keep what makes it valid.

VibeVoice

Problem. Speech generation must preserve what is said, who sounds like they said it, timing, and prosody together.

Object. A hidden audio state where meaning and sound shape constrain each other.

Why it works. Speech is not a transcript plus decoration. The generator works when timing, pitch, rhythm, and speaker character are part of the state before audio is produced, so voice quality is controlled rather than repaired afterward. What must stay the same is the coupled meaning, speaker, timing, and prosody. What may change is the hidden sound state used to generate it. Name used later: audio latent.

Connection. It is the audio version of native-state generation.

TTSDS2

Problem. Text-to-speech evaluation can miss naturalness, intelligibility, speaker fidelity, or task-specific defects.

Object. Like listening to a recording and grading whether the words are clear, the speaker still sounds right, the rhythm fits, and the audio is usable, the object is the produced sound plus separate checks for each way it can fail.

Why it works. What must stay the same is the speech quality the user actually hears. What may change is the generated waveform, speaker style, timing, or task setting. TTSDS2 helps because it judges the medium where the error appears instead of pretending the text prompt contains the whole task. Name used later: multi-aspect scoring function for those separate audio checks.

Connection. It ties generation to grounded verification.

FlashWorld

Problem. World generation must react to actions and maintain scene continuity.

Object. Like a simulator where pushing a door should change the room shown next, the object is a visual world that updates after an action.

Why it works. What must stay the same is the underlying scene and the action's consequence. What may change is the next visual state. The model conditions the next state on the previous state and action, preventing plausible-looking frames from drifting away from one world. Name used later: interactive visual world transition.

Connection. It is video generation as a simulator for action consequences.

VIST3A

Problem. 3D-aware generation can lose object identity when each view is treated like a separate 2D picture.

Object. A scene record that ties appearance to camera position and 3D shape.

Why it works. Moving the camera should change the observed pixels without changing the object. The model improves by preserving the coordinate relation across generated views. What must stay the same is the scene. What may change is the camera view. Name used later: representation.

Connection. This links unified generation to spatial grounding.

TideGS And RadioGS

Problem. Some signals are spread through space instead of stored as separate pictures: water height, radiance, or radio strength can be measured from many positions.

Object. Like covering fog or radio strength with many small soft patches, the object is a hidden field that can be viewed or measured from different places.

Why it works. What must stay the same is the underlying signal the sensor would observe. What may change is the viewpoint, sensor position, or rendering. The small patches let the model keep a physical state it can render, edit, and check. Name used later: Gaussian primitives for the soft local patches used to approximate the continuous field.

Connection. It is native-state generation for physical media.

Omni-Reward, UniPercept, And MetamerGen

Problem. Generated media can satisfy the words in a prompt while still looking wrong, sounding wrong, or disagreeing across channels.

Object. Feedback functions that inspect the artifact where the failure appears.

Why it works. A reward model moves sampling toward artifacts that pass the measured constraints. Metamer-style tests matter because two outputs can look the same to one feature record and different to a person or another channel. What must stay the same is sameness for the observer that matters. What may change is the feature record or channel view. Name used later: perceptual equivalence.

Connection. It is alignment as measurement over native artifacts.

OBJECT 04

Human Signals

Hibiki-Zero

Problem. Speech translation must preserve meaning while respecting latency and spoken timing.

Object. Like interpreting a live conversation while the speaker is still talking, the object is the partial speech record carried forward from moment to moment.

Why it works. What must stay the same is meaning, timing, tone, and enough context to continue translating. What may change is the partial audio already heard or the words emitted so far. The model cannot wait for full text in live speech, so it keeps a compact state that preserves prosody and timing. Names used later: semantic variables for meaning and acoustic variables for sound shape.

Connection. It is online inference under human communication constraints.

EmotionThinker

Problem. Emotion recognition fails when emotion is treated as a label attached to text alone.

Object. The hidden emotional situation inferred from context, expression, and language.

Why it works. Like understanding whether a short reply is anger, fear, grief, or joking by using the surrounding situation, affect is inferred from several clues at once: what happened, what the person said, how they looked, and what response followed. What must stay the same is the emotional cause supported by the evidence. What may change is the wording, expression, or context clue. Name used later: latent variable for this hidden cause behind several observations.

Connection. It is hidden-state modeling for social signals.

EEmo-Logic

Problem. Emotional reasoning can become arbitrary when a model jumps from one phrase straight to an emotion label.

Object. Like deciding whether someone is angry, embarrassed, joking, or afraid by looking at what happened first, how they reacted, and what response would make sense, the object is the step-by-step social situation behind the label.

Why it works. What must stay the same is the story the evidence supports: event, interpretation, feeling, and response. What may change is the wording, face cue, or context clue. The method helps because the model has to keep the middle explanation visible instead of treating one emotionally loaded word as enough. Name used later: appraisal chain.

Connection. It brings reasoning-trace math into affective computing.

WAVE

Problem. Audio models can miss timing patterns that are obvious in the waveform.

Object. A sound record that keeps what happened at each time, including rhythm, frequency, and event timing.

Why it works. Waveform evidence is ordered and continuous. The model needs filters or tokens that preserve sound changes over time rather than only transcript-like summaries. Spectral means frequency-based; it is useful only because frequency helps describe the sound event.

Connection. It is frequency and time-state modeling for human signals.

TokSuite And ATLAS

Problem. Tokenizers and tests can hide cultural or linguistic failures behind one average accuracy number.

Object. Small input changes and selected test items that reveal where measurement breaks.

Why it works. TokSuite tests whether the input code preserves native linguistic structure. ATLAS chooses questions that teach the evaluator the most about the model's hidden ability. High information means the answer reduces a lot of uncertainty.

Connection. It links tokenizer design to benchmark economics.

Seizure-Semiology-Suite

Problem. Clinical video understanding requires domain events, not generic motion recognition.

Object. Expert-defined semiology labels grounded in medical observation.

Why it works. The benchmark measures whether the model preserves clinically meaningful state variables. Ordinary visual similarity is insufficient when small temporal signs change diagnosis.

Connection. It is high-stakes evaluation for non-text human signals.

Active Mind Avatars And MetaphorVU

Problem. Human communication includes pose, gaze, metaphor, and social intent that are not reducible to literal text.

Object. Like understanding that crossed arms, eye contact, and a metaphor can change what a sentence means, the object is the social situation carried by several channels.

Why it works. What must stay the same is the intended social meaning. What may change is pose, gaze, wording, metaphor, or expression. The model needs records for what is shown, what is implied, and how expression changes meaning; treating all cues as captions removes the relations that make them meaningful. Name used later: multimodal social state.

Connection. It is grounding beyond literal language.

SleepLM And BioX-Bridge

Problem. Biosignals are noisy, indirect measurements with domain-specific timing.

Object. The hidden physiological condition inferred from sensor sequences.

Why it works. Like reading a heart monitor, the raw wiggles matter only because they point to a body condition. What must stay the same is the condition supported by the signal. What may change is the sensor channel, timing noise, or summary code. Name used later: physiological latent state.

Connection. It is scientific measurement modeling inside multimodal AI.

PRISM And Mind-Omni

Problem. Brain signals cannot be treated as images or text, yet they need to connect to both.

Object. An interface code between noisy neural measurements and concepts a media model can use.

Why it works. Like translating smudged notes before writing a clean report, the model first turns brain evidence into a usable concept record. What must stay the same is the concept the brain signal supports. What may change is the noisy measurement or the media generated from that concept. Name used later: representation.

Connection. It is multimodal grounding with the measurement channel made explicit.

OBJECT 05

Embodied Action

SAW-Bench

Problem. A robot benchmark can reward language understanding while missing whether the agent can act in a changing world.

Object. Like asking someone to set a table after objects move around, the object is the task state the body must use: where things are, what action is possible, and whether the world changed as expected.

Why it works. What must stay the same is the intended physical result. What may change is scene layout, object position, action order, or interruption. The benchmark matters because a correct sentence is not a completed action; the decision must survive contact with the environment. Name used later: embodied state.

Connection. It is outcome verification for physical agents.

MomaGraph

Problem. Raw pixels do not directly tell a robot what can be moved, opened, stacked, held, or used.

Object. Like a kitchen map that says the cup is on the counter, the drawer can open, and the handle can be pulled, the object is a record of objects, their relations, their current states, and the actions they allow.

Why it works. What must stay the same is the physical relation that makes an action possible. What may change is the robot's plan, object positions, or object states. The graph helps because the robot plans over usable relations instead of treating every pixel as an unrelated visual fact. Name used later: scene graph and affordance.

Connection. It is agent planning with physical state rather than web state.

RoboMME

Problem. Robot memory is not one capability; temporal, spatial, object, and procedural memory fail differently.

Object. A memory taxonomy for VLA behavior.

Why it works. The benchmark asks which memory variable the task needs. A model with good object recall can still fail procedural continuation, so memory must be measured by function.

Connection. It is benchmark validity for embodied state.

HDFlow

Problem. Long robot movements are hard to choose as one flat sequence of motor commands.

Object. A hidden high-level goal choice plus a lower-level feasible motion path.

Why it works. Like first choosing which shelf to reach and then planning the exact arm motion, the method separates aim from movement. What must stay the same is progress toward a physically reachable outcome. What may change is which coarse goal is explored and which smooth path gets used. Name used later: latent subgoal for the hidden goal variable.

Connection. It is hierarchical generation under action geometry.

EgoTactile

Problem. Vision cannot always observe contact, pressure, slip, or grip stability.

Object. Egocentric video paired with hand pressure state.

Why it works. Tactile sensors reveal hidden physical facts that explain action success. Two grasps can look similar in pixels while one is slipping and the other is stable. The model gains evidence that vision alone cannot provide.

Connection. It is missing-modality repair through a better measurement channel.

PACT

Problem. Test-time correction can improve a policy but also move it outside known safe behavior.

Object. A constrained policy update around the current action choices.

Why it works. Like correcting a driver without telling them to leave the road, the method allows useful local correction while staying close to trained behavior. What must stay the same is safe, familiar action style. What may change is the uncertain choice being corrected. Name used later: distribution shift for movement into a different action pattern than training covered.

Connection. It is feasible-set control for robot inference.

JoSE

Problem. A robot may have many muscles or actuators, but only a smaller family of coordinated movements matters for the task.

Object. A smaller allowed action space that keeps behavior-relevant variation and drops redundant motor changes.

Why it works. Like steering a hand by useful motions such as reach, turn, and grip instead of every motor twitch, the search becomes smaller and more meaningful. What must stay the same is the behavior that changes the task outcome. What may change is the raw actuator setting. Names used later: manifold for the smaller movement surface, and mutual information for keeping coordinates because they still tell us about behavior.

Connection. It is same-action grouping for control.

RodriNet

What must stay the same is the answer, action, or generated artifact supported by the full evidence. What may change is how many tokens are carried. Name used later: sufficient statistic for the kept summary.

The policy acts through body shape, contact, memory, and timing delay. Those facts must be part of the state before training or test-time updating begins.

FOCUSED CHAIN

Measurement Channels: Hidden State Through Noisy Evidence

The Core Mathematical Problem

Problem. Multimodal systems fail when they treat each input as a completed fact. fMRI, speech, video, touch, and clinical labels are noisy views of hidden facts such as perceived object, intention, affect, contact, action quality, or medical event.

Plain object. Like several witnesses describing the same event from different distances and delays, each channel gives partial evidence about the situation underneath.

Why it works. The model becomes an evidence system instead of a concatenation system. What must stay the same is the underlying fact being inferred. What may change is the channel, noise, delay, sampling rate, or missingness. Names used later: latent state and observation operator.

hidden state -> channel-specific measurement -> compressed evidence -> decision

Mind-Omni And PRISM: Brain Signals Need An Interface Variable

Problem. fMRI is delayed, noisy, indirect evidence about neural activity. Mapping it straight to an image or sentence makes the model clean the measurement and reconstruct meaning at the same time.

Plain object. Like translating a blurry medical scan into a structured note before writing a report, the system first builds a bridge between neural measurements and media.

Why it works. What must stay the same is the concept actually carried by the neural signal. What may change is whether the final output is image, text, or another medium. The intermediate variable separates estimating the signal from generating the artifact. Name used later: interface code.

Failure boundary. The interface helps only if it preserves the concept actually measured by the neural signal. A neat token code can still discard timing, uncertainty, subject variation, or low-level perceptual detail.

Hibiki-Zero: Speech Is Meaning Plus Time

Problem. Live speech translation cannot wait for a finished transcript, and a transcript alone loses prosody, rhythm, turn timing, and partial commitment.

Plain object. Like interpreting someone while they are still speaking, the system must keep both what has been said and how the timing is unfolding.

Why it works. What must stay the same is enough meaning and timing to produce the next spoken output. What may change is how much of the future has not arrived yet. The model carries a partial state forward instead of waiting for a finished transcript. Name used later: streaming speech state.

Failure boundary. If the retained state overcompresses prosody or uncertainty, the translation can be semantically correct but pragmatically wrong: late, flat, interrupted, or misaligned with the speaker's intent.

audio prefix -> partial semantic state + prosody state -> spoken output

EgoTactile: Touch Measures What Vision Cannot

Problem. Pixels often hide the fact that decides whether an action is working: pressure, slip, grip stability, contact patch, or force transfer.

Plain object. Like knowing a cup is slipping because you feel it before you see it fall, touch supplies evidence that vision can miss.

Why it works. What must stay the same is the contact fact that changes the action. What may change is the mix of video and touch measurements. The fused state can distinguish visually similar scenes that have different action consequences. Name used later: tactile latent state.

Failure boundary. Tactile evidence must be synchronized and calibrated. If pressure readings are delayed, sparse, or mismatched to the hand geometry, the added channel can create false confidence.

LIMSSR: Missing Modalities Are Unobserved Variables

Problem. Real assessment often lacks one or more channels that were present during training. Filling them in as if they were observed creates fake evidence.

Plain object. Like grading a lab report when one instrument reading is missing, the score must use what was observed and keep doubt about what was not.

Why it works. What must stay the same is honest uncertainty about the missing channel. What may change is which channels are present. The model estimates from available evidence while treating absence itself as evidence when absence is meaningful. Names used later: marginalizing and conditioning on missingness.

Failure boundary. This works only when missingness is modeled honestly. If a channel is missing for reasons correlated with quality, treating absence as random can bias the score.

score = E[target | observed channels, missingness pattern]

Seizure-Semiology-Suite And VideoKR: Labels Must Name The State That Matters

Problem. Video labels can be visually convenient but medically or semantically irrelevant. A model can track motion while missing the event state that changes diagnosis or knowledge reasoning.

Plain object. Like labeling a medical video by the symptom pattern a clinician uses, not just by visible motion, the label has to name the fact that changes the decision.

Why it works. What must stay the same is the event or knowledge fact the task depends on. What may change is the visual scene or query. Seizure semiology checks clinical event variables; VideoKR checks visual events linked to external knowledge. The label is a measurement target, not just a category.

Failure boundary. If labels are underspecified or inconsistent, the benchmark measures annotator artifacts rather than domain state. Expert naming is part of the mathematical instrument.

The Measurement-Channel Chain

Across papers. Mind-Omni and PRISM build interface variables for brain measurements. Hibiki-Zero keeps streaming speech state instead of collapsing audio to text. EgoTactile adds contact evidence missing from vision. LIMSSR reasons under absent channels. Seizure-Semiology-Suite and VideoKR define labels around the domain state that matters.

First-principles read. A modality is useful when it reduces doubt about the fact that controls the decision. The right fusion rule depends on each channel's noise, delay, what changes should not matter, and which readings are missing. More modalities help only when they add relevant evidence rather than duplicate or corrupt the state. Name used later: invariance for changes that should not alter the underlying answer.

Big-picture consequence. Multimodal intelligence is not about attaching more sensors to a language model. It is about building an evidence model: what hidden state exists, which channel observes which part of it, what gets compressed, and what remains uncertain at the moment of decision.

hidden state + channel model + missingness model -> calibrated multimodal decision
FOCUSED CHAIN

Modality Credit: Which Evidence Route Changed The Answer

The Core Mathematical Problem

Problem. A multimodal answer can be correct for the wrong reason. The language prior, memory summary, or reasoning module can produce the right text while the image, video, or sensor channel had little causal effect.

Plain object. Like changing only the photo in a question while keeping the words fixed, the test asks whether the answer follows the evidence channel that should control it.

Why it works. Grounding becomes a cause question, not a correlation question. What must stay fixed is the rest of the problem. What may change is one evidence channel. The model has demonstrated use of a modality only when changing that modality changes the answer in the expected direction. Name used later: route dependence.

credit(channel) = output(original) - output(counterfactual without channel evidence)

MoCA: Send Learning Signal To The Failing Module

Problem. A multimodal agent can fail because perception missed the object, cognition drew the wrong conclusion, or fusion joined the evidence incorrectly. A single reward cannot say which part to repair.

Plain object. Like diagnosing whether a camera, translator, or decision-maker failed, the method sends blame to the part whose repair would change the answer.

Why it works. What must stay the same is the failed example and its correct target. What may change is which module receives the update. Perception errors can train visual grounding, reasoning errors can train inference, and fusion errors can train the connection between them. Name used later: credit assignment.

Failure boundary. If the decomposition is wrong, credit is misassigned. The system may update the reasoning module for a perception failure or vice versa, making the next behavior less grounded.

VGS And VISUALSWAP: Test Dependence With Counterfactual Evidence

Problem. A model can answer from text priors while appearing visually grounded. Attention to an image is not evidence that the image controlled the answer.

Plain object. Like asking the same question after swapping the decisive image fact, the answer should change only when the visual truth changes.

Why it works. What must stay fixed is language context and irrelevant style. What may change is the visual fact that should decide the answer. VGS scores whether visual evidence supports the content; VISUALSWAP builds paired examples where the shortcut channel cannot explain the required change. Name used later: counterfactual evidence.

Failure boundary. Counterfactual tests need clean interventions. If the swap changes style, difficulty, or hidden context along with the target fact, the test may measure distribution shift instead of visual dependence.

visual grounding holds when answer(image A) != answer(image B) for the right visual change

Causal Route Gating And MINT: Intervene Inside The Fusion Layer

Problem. The external input can be correct while hidden routes carry the wrong evidence into generation. The model may route through text-prior heads or hallucination-prone fusion states.

Plain object. Like testing one wire in a radio while the rest stays assembled, the method changes one internal route and watches whether the output changes for the claimed reason.

Why it works. What must stay the same is a believable working state for the model. What may change is one route, gate, or patch. Gating suppresses routes that carry unsupported prior signal; MINT-style patching asks whether replacing a hidden fusion state changes the hallucinated answer. Name used later: activation.

Failure boundary. Internal interventions are meaningful only if the replaced variable is localized enough. Distributed representations can make one route look innocent while the same shortcut reappears through another path.

Visual Attribution Streaming: Estimate Route Dependence During Reasoning

Problem. Long visual reasoning cannot afford exhaustive counterfactual tests at every step, but ungrounded intermediate reasoning still needs to be detected.

Plain object. Like checking each claim in a visual explanation against the picture as the explanation is written, the method watches whether image evidence is still supporting the trace.

Why it works. What must stay the same is the claim's dependence on visual evidence. What may change is the step of the reasoning trace. Attribution becomes a time-indexed diagnostic, not a post-hoc decoration. Name used later: streaming attribution.

Failure boundary. Approximate attribution can lag or smooth over sudden failures. A trace can appear grounded overall while one decisive step used unsupported text prior.

DLMR: Keep Observations Separate From Derived Memory

Problem. Memory can erase the distinction between what was seen and what was inferred. Once a summary overwrites raw evidence, later reasoning cannot tell whether a claim came from observation or from the model's own language state.

Plain object. Like keeping raw lab notes separate from later conclusions, memory should preserve whether a fact was observed or inferred.

Why it works. What must stay the same is the source of each claim. What may change is whether the fact is stored in observation memory or reasoning memory. Later answers can condition on the source of the information rather than a single mixed record. Name used later: routed multimodal memory.

Failure boundary. Routing helps only if memory writes are disciplined. If unsupported conclusions are stored as observations, the system has made hallucination persistent.

memory = observed evidence store + derived reasoning store + routing rule

The Evidence-Route Chain

Across papers. MoCA assigns update credit to perception, cognition, or fusion. VGS and VISUALSWAP test whether answers move with visual counterfactuals. Causal Route Gating and MINT intervene inside the fusion computation. Visual Attribution Streaming tracks evidence contribution over time. DLMR preserves source provenance in memory.

First-principles read. A multimodal system is grounded only if the right observation is causally upstream of the answer. The central object is not an attention map; it is a controlled difference between outputs when an evidence route is changed.

Big-picture consequence. This turns multimodal evaluation into a causal experiment: hold the problem fixed, change the evidence route, inspect the output movement, and update the component that actually failed.

intervene on evidence route -> observe answer movement -> assign repair target
FOCUSED CHAIN

Token Sufficiency: What Can Be Dropped Without Changing The Decision

The Core Mathematical Problem

Problem. Multimodal streams contain more raw evidence than the model can carry. The hard question is not how to make the context shorter; it is which discarded information would have changed the answer, action, or generated artifact.

Plain object. Like shortening meeting notes while keeping every decision-changing fact, the compressed state must still support the later choice.

Why it works. Compression is safe only when the kept record preserves the facts the downstream computation will use. What must stay the same is the decision the full evidence would support. What may change is memory size, latency, or parameter budget. Name used later: sufficient representation.

compressed state is useful when decision(raw input) ~= decision(compressed state)

FlashVID: Merge Repeated Spacetime Evidence

Problem. Long video repeats backgrounds, objects, and small motions across many frames. Processing every patch as equally valuable spends context on evidence that may be conditionally redundant.

Plain object. Like combining repeated notes about the same scene while keeping the one moment where the action changes, the merge must not erase event boundaries.

Why it works. What may change is how many video pieces are stored. What must stay the same is the object change, motion cue, or short event needed later. Nearby tokens can be merged when they carry the same decision-relevant state. Name used later: spatiotemporal token merge map.

Failure boundary. Rare events are easy to erase. If a short gesture, clinical sign, or object interaction is merged into background context, the compressed state is no longer sufficient.

InfoTok And VideoFlexTok: Spend Tokens Where Information Has Value

Problem. A fixed token rate assumes every segment of a video has the same value for every question. That is false: some intervals decide the answer, while others only maintain setting.

Plain object. Like taking detailed notes during the decisive play and sparse notes during the quiet parts, token budget should follow decision value.

Why it works. What must stay the same is the evidence that could change the future decision. What may change is how many tokens each frame or region receives. InfoTok estimates which tokens matter; VideoFlexTok varies budget with task and sequence structure. Name used later: information density.

Failure boundary. The value model must anticipate the task. A token that looks low-information before the query can become decisive after the query changes.

keep token if expected decision change from removing it is high

OmniFit: Allocate Context Across Modalities

Problem. Image, audio, video, table, and text channels compete for one finite context. Equal treatment wastes capacity and can suppress the channel that contains the key evidence.

Plain object. Like packing different tools for a job, each medium gets space according to what only that medium can tell you.

Why it works. Each channel has different redundancy and different irrecoverable facts. What must stay the same is enough evidence from each channel to answer the task. What may change is the token share assigned to image, audio, video, table, or text. Name used later: modality-specific context allocation.

Failure boundary. Cross-modal redundancy can be overestimated. If the system assumes text summarizes an image or audio stream when it does not, the compressed context loses grounding.

LST: Sufficiency Under Online Latency

Problem. Streaming speech and multimodal interaction cannot wait for the full future before deciding what state to keep. The filter must act before later evidence arrives.

Plain object. Like taking notes during a live call before knowing what the next sentence will be, the system keeps a small running summary plus unresolved doubt.

Why it works. What must stay the same is the ability to revise or decide when later evidence arrives. What may change is the local state at each moment. The retained summary must carry uncertainty, not just the current best guess. Name used later: online filtering.

Failure boundary. Early compression can make later correction impossible. If ambiguity is collapsed too soon, later evidence cannot recover the dropped alternatives.

state[t] = update(state[t - 1], new tokens, latency budget)

COMPACT And LiME: Compress State Or Update Direction

Problem. Long-context use and adaptation are expensive because the model may carry too many activations or update too many parameter directions for the actual task.

Plain object. Like keeping the few notes or control knobs that actually change the outcome, the system keeps only the state or update directions the task needs.

Why it works. What must stay the same is the target behavior. What may change is context size or adapter movement. COMPACT keeps information that changes outputs; LiME restricts movement to target-relevant directions. Name used later: low-dimensional adaptation subspace.

Failure boundary. Low-dimensional structure can be task-local. A subspace that is sufficient for one domain can erase evidence or adaptation directions needed by another.

MetaEmbed And TACO: Do Not Flatten The Algebra Away

Problem. Tables and structured records lose row, column, type, and relation information when serialized as plain text. More tokens cannot fully repair a bad coordinate choice.

Plain object. Like preserving rows, columns, keys, and units in a spreadsheet instead of pasting it as a paragraph, the input map must keep the operations the task will need.

Why it works. What must stay the same is lookup, comparison, aggregation, type constraints, and relation traversal. What may change is the embedding format. Attention can then operate on structure instead of rediscovering it from punctuation and order. Name used later: structure-preserving embedding map.

Failure boundary. The embedding must preserve the right algebra. If it keeps superficial layout but loses units, keys, provenance, or relational constraints, the model can answer fluently from a broken table state.

The Token-Sufficiency Chain

Across papers. FlashVID merges repeated spacetime evidence. InfoTok and VideoFlexTok spend tokens where the answer may change. OmniFit distributes context across modalities. LST makes the problem live under timing delay. COMPACT and LiME compress state or update directions. MetaEmbed and TACO preserve structured input operations.

First-principles read. Token efficiency is a claim about what still matters after compression. The compressed record should keep the facts the task may ask for. The right question is always what useful evidence is lost, not how many tokens were removed. What must stay the same is the decision the full stream would support. What may change is the stored record. Name used later: sufficient representation for a kept summary that still supports the decision.

Big-picture consequence. Efficiency becomes part of correctness. A smaller context is better only when the dropped evidence would not change the decision; otherwise it is a hidden measurement failure disguised as a cheaper system.

raw stream -> sufficient compressed state -> decision under budget

Problem. A robot policy does not output an answer; it changes the world through a body. The action is valid only if it respects geometry, contact, memory, timing, actuator limits, and task constraints.

Plain object. Like deciding whether this hand can move this object from this scene to the next one, the policy must know which state changes are physically possible.

Why it works. What must stay the same is feasibility of the world-body transition. What may change is the action. Embodied methods improve when they name the state variables that make movement possible and constrain the policy to stay inside that relation. Name used later: feasible transition relation.

(world state, body state, action) -> valid next state

Problem. A robot benchmark can overrate language competence while missing whether the agent remembers, acts, and recovers in a changing scene.

Plain object. Like testing whether a worker remembers object locations, follows procedure, and recovers after a change, the benchmark names the body-world fact needed for success.

Why it works. What must stay the same is the required state variable. What may change is scene, action, memory type, or procedure. SAW-Bench checks whether the decision survives execution; RoboMME asks which memory function supports the policy.

MomaGraph And EgoTactile: Expose Affordance And Contact

Plain object. Like knowing a drawer can be opened and feeling whether your grip is slipping, the policy needs both object-use facts and touch facts.

action choice depends on affordance graph + contact state

HDFlow: Separate Intent Geometry From Motion Geometry

Plain object. Like first choosing which shelf to reach for, then planning the arm motion, the method splits the goal choice from the body movement.

Why it works. What may change is the exact motion path. What must stay linked is the chosen goal and physical feasibility. The high-level state chooses a region or outcome; the low-level rule fills in a possible motion path. The split reduces ambiguity because each level answers a smaller question. PACT, JoSE, And RodriNet: Constrain The Update Space

Problem. Test-time correction, exploration, and articulated motion can move the policy into invalid regions even when the intended task is clear.

Plain object. Like letting a robot correct itself only within movements its body can safely make, the update is fenced by trusted behavior, useful action coordinates, and body-rotation rules.

Why it works. What must stay the same is safe physical behavior. What may change is the correction or exploration move. PACT limits distance from known behavior; JoSE searches smaller useful coordinates; RodriNet builds body rotation into the transformation. Names used later: action manifold and kinematic operator.

allowed update = task improvement within policy, manifold, and kinematic constraints

Problem. A policy must transfer behavior, learn from synthetic practice, and adjust at test time without unlimited real-world trials.

Plain object. Like practicing in simulated rooms before acting in a real room, the policy needs evidence that practice behavior still transfers to deployment.

Why it works. What must stay the same is action-relevant world state. What may change is the practice world, task, or self-control signal. BehaviorVLA preserves reusable behavior variables, DreamDojo creates action-relevant worlds, and SCALE regulates deployment-time behavior using the model's own uncertainty.

Failure boundary. Simulated or self-evaluated evidence must match the deployment state. If synthetic worlds omit contact, timing, or object diversity, the policy can overfit to a false action space.

The Embodied-Constraint Chain

Across papers. SAW-Bench and RoboMME define which body-world facts are being tested. MomaGraph and EgoTactile expose what objects allow and whether contact is working. HDFlow decomposes goal and motion. PACT, JoSE, and RodriNet restrict allowed movement. BehaviorVLA, DreamDojo, and SCALE connect reusable behavior, simulated practice, and deployment-time self-control.

Big-picture consequence. The central question is no longer whether a model can describe an action. It is whether it can choose a feasible transition under partial observation, update safely, and produce evidence that the physical state changed as intended.

measure state -> choose feasible action -> constrain update -> verify physical transition

Why it works. What must stay the same is the medium-specific state needed for correctness. What may change is output type or decoder. The model should unify control, not erase the structure that makes an output correct. Name used later: shared conditioning interface.

instruction state -> shared interface -> native media state -> verifier

NextStep-1 And EditVerse: Output Becomes The Next State

Problem. One-shot generation treats the produced artifact as the end. Editing, refinement, and agent workflows need the artifact to remain conditionable after each operation.

Plain object. Like editing a project file where each version becomes the starting point for the next edit, the artifact remains a state, not just a finished sample.

Why it works. What must stay the same is object identity, unchanged context, and editable targets. What may change is the requested edit. NextStep-1 keeps generation open to the next operation; EditVerse separates what should change from what should remain fixed. Name used later: stateful generation trajectory.

Failure boundary. If the editable state does not preserve object identity, spatial relations, or unchanged context, iteration compounds errors even when each single edit is plausible.

artifact[t] + edit instruction -> artifact[t + 1] with invariants preserved

LatentLM And UALM: Build A Protocol, Not A Flattened String

Problem. Forcing image, audio, and other media into plain text makes the interface easy for language models but weak for reconstruction and control.

Plain object. Like using one production plan for text, audio, and images while each workshop keeps its own tools, the system shares the instruction layer without flattening the medium.

Why it works. What may change is the output type. What must stay reconstructable is the timing, texture, geometry, sound detail, or other native evidence the decoder needs. The hidden layer can connect modalities at the level needed for reasoning while leaving decoders to enforce native media structure. Name used later: latent protocol. Autoregressive means the protocol can be read or written step by step.

Failure boundary. A shared code can become a bottleneck. If it is too semantic, it loses texture, timing, geometry, or acoustic detail; if it is too low-level, it stops being useful for reasoning.

VibeVoice And TTSDS2: Speech Must Be Generated And Judged As Audio

Problem. Speech is not a transcript rendered with decoration. Meaning, speaker identity, timing, prosody, intelligibility, and naturalness are coupled in the waveform.

Plain object. Like judging a spoken sentence by listening to it, the system must carry and score the sound itself, not only the words.

Why it works. What must stay the same is meaning plus voice, timing, and naturalness. What may change is the generated waveform. VibeVoice models acoustic-temporal variables; TTSDS2 evaluates the produced audio where errors occur. Name used later: audio latent.

Failure boundary. A speech system can satisfy text meaning while failing turn timing, speaker consistency, or perceptual quality. The verifier must see those audio-specific variables.

FlashWorld And VIST3A: Generated Media Must Keep World Geometry

Problem. Video and 3D generation can look plausible frame by frame while losing continuity, viewpoint consistency, or action dependence.

Plain object. Like filming the same room from different angles after something moves, the media must keep one world state behind the rendered views.

Why it works. What must stay the same is the world geometry and transition. What may change is action, camera, or viewpoint. FlashWorld conditions the future on previous state and action; VIST3A couples appearance to camera and geometry. Name used later: world-transition state.

Failure boundary. The state must include the variables that change under action or viewpoint. Hidden objects, occlusion, contact, and camera calibration can still break continuity.

TideGS And RadioGS: Fields Need Renderable Coordinates

Problem. Some generated outputs are continuous physical fields, not arrays of independent pixels. A field has locality, smoothness, propagation, occlusion, attenuation, and measurement geometry.

Plain object. Like representing fog or radio strength with many local patches, the state stores pieces that can be measured or rendered from different positions.

Why it works. What must stay the same is the underlying field the sensors would observe. What may change is the view or measurement operator. Editing and verification operate on the physical signal rather than only on images. Name used later: field representation.

Failure boundary. Local pieces can miss discontinuities, long-range interactions, boundary effects, or sensor regimes that are not well represented by the chosen basis.

field state -> measurement/rendering operator -> observed artifact

Omni-Reward, UniPercept, And MetamerGen: Reward Must See Native Failure

Problem. A generated artifact can satisfy an instruction in one projection while failing perception, cross-modal agreement, or artifact-level quality.

Plain object. Like judging a picture by looking at the picture, the feedback must inspect the medium where the failure appears.

Why it works. What must stay the same is the user or domain criterion. What may change is the generated medium or observer channel. These methods define feedback where failure appears and reveal when two outputs match one feature record but differ in another. Name used later: perceptual equivalence.

Failure boundary. Reward is another measurement channel. If it ignores a relevant projection, training can make artifacts that satisfy the reward while failing the real user or domain constraint.

The Unified-Generation Chain

Across papers. NextStep-1 and EditVerse make generation iterative. LatentLM and UALM define shared protocols. VibeVoice and TTSDS2 keep speech native. FlashWorld and VIST3A preserve world and view state. TideGS and RadioGS choose field coordinates. Omni-Reward, UniPercept, and MetamerGen close the loop with artifact-level measurement.

First-principles read. A unified generator works when it separates control interface from output structure. The interface should carry instruction and cross-channel state; the native media state should preserve the constraints that make the artifact valid.

Big-picture consequence. The right question is not whether one model can emit every modality. It is whether the model can maintain a state that remains editable, causally connected, physically or perceptually valid, and measurable after each generation step.

shared control + native state + artifact verifier = usable multimodal generation

Memory And World State: Provenance Before Belief

The Core Mathematical Problem

Problem. A multimodal model can confuse what was observed, what was inferred, what was retrieved, and what was weakly labeled. Once those sources are mixed, later reasoning cannot tell whether a claim has evidence or only momentum.

Plain object. Like keeping margin notes that say "seen directly," "inferred," "retrieved," or "weak label," the belief state must carry source and trust.

Why it works. Memory is useful only when it preserves source and uncertainty. What must stay the same is the evidence status of each claim. What may change is whether the claim comes from a frame, attribution trace, generated summary, retrieved fact, or noisy label. Name used later: belief state with provenance.

belief = observed evidence + derived state + retrieved knowledge + source reliability

VideoKR: Bind Video Events To Query-Relevant Knowledge

Problem. Knowledge-rich video questions can be answered from language priors unless the task forces outside knowledge to meet visual evidence at the right event.

Plain object. Like tying a history fact to the exact scene where it matters, the model must connect retrieved knowledge to the observed video event.

Why it works. What must stay the same is event identity, timing, and visual support. What may change is the retrieved fact or query. The answer is valid only if both the video state and knowledge state participate in the inference. Name used later: video event state.

Failure boundary. Retrieval can dominate observation. If the model answers from common knowledge without locating the video evidence, the benchmark measures prior recall rather than grounded video reasoning.

Visual Attribution Streaming: Track Evidence While Reasoning Evolves

Problem. A reasoning trace can start grounded and later drift into unsupported claims. Post-hoc inspection may miss where the support disappeared.

Plain object. Like checking each step of a visual explanation while it is being written, the diagnostic asks whether the picture still supports the step that changed the answer.

Why it works. What must stay the same is evidence support at the decisive steps. What may change is the current reasoning step. The diagnostic turns grounding into a sequence property rather than only a final-answer check. Name used later: time-indexed visual contribution.

Failure boundary. Streaming attribution is approximate. If it smooths over a brief but decisive unsupported step, the trace can look grounded while the conclusion rests on a shortcut.

grounded trace requires evidence contribution at the steps that change belief

DLMR: Separate Observation Memory From Reasoning Memory

Problem. A single memory store can convert an inferred summary into apparent evidence. Later generations then cite the model's own conclusion as if it were an observation.

Plain object. Like keeping raw footage separate from an editor's summary, the memory route preserves which claims were observed and which were derived.

Why it works. What must stay the same is provenance. What may change is the memory store used for a claim. Visual memory can preserve source evidence, while reasoning memory can preserve conclusions and plans. Name used later: routed multimodal memory.

Failure boundary. If routing is loose, unsupported inferences can be written into the observation store. That makes hallucination persistent and harder to detect.

RFCMH: Consistency As A Memory Repair Signal

Problem. Cross-modal hallucination appears when one modality's output stops being constrained by the others or by source evidence.

Plain object. Like comparing a caption, image, and source note to find which one lost support, disagreement becomes a repair signal.

Why it works. What must stay the same is source-grounded consistency. What may change is which modality gets corrected. The system can identify which claim lacks support and route correction toward the unsupported modality. Name used later: reliability and consistency state.

Failure boundary. Agreement is not truth. Multiple modalities can agree because they share the same wrong prior or inherited error, so consistency must be tied back to observations.

WETR And AGREE: Weak Labels Need Reliability Weights

Problem. Partial or weak labels can encode the wrong relation between observation and concept. Treating every label as equally true writes noise into the model's memory of the task.

Plain object. Like trusting a careful measurement more than a guessed label, the training signal should move the model more when evidence is stronger.

Why it works. What must stay the same is the relation between observation and concept. What may change is label strength or completeness. Reliability weights scale the update by evidence quality, applying provenance during training. Name used later: reliability-weighted supervision.

Failure boundary. Reliability estimates can inherit bias. If the weighting rule trusts the easiest or most frequent labels, it can suppress rare but correct evidence.

update size = label signal * evidence reliability

The Memory-Provenance Chain

Across papers. VideoKR links visual events to knowledge. Visual Attribution Streaming tracks evidence during reasoning. DLMR separates observations from derived memory. RFCMH uses cross-modal consistency to repair unsupported claims. WETR and AGREE weight weak labels by reliability.

First-principles read. Memory is not just longer context. It is a state estimator with source labels. The system must preserve where a belief came from, how reliable that source is, and whether later evidence still supports it.

Big-picture consequence. The common failure is treating belief as evidence. The stronger design keeps provenance alive from training labels through memory writes, reasoning traces, retrieval, generation, and final verification.

observation -> provenance-aware memory -> supported belief -> grounded answer
