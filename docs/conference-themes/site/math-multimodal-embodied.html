FIRST PRINCIPLE

A Modality Is A Measurement Channel

A modality is not a file type. It is a measurement channel with its own noise, sampling rate, invariances, missingness, and causal relation to the world. Image patches measure projected surfaces. Audio measures pressure over time. fMRI measures delayed blood-flow proxies for neural activity. Robot sensors measure pose, contact, and force under latency. A text answer is valid only if these channels were compressed and fused without erasing the variable needed for the decision.

The mathematical center is a joint state: a structured variable that says what is known, from which channel, at what time, under which viewpoint or body constraint, and with what uncertainty. The papers below work when they make one hidden part of that state explicit: a visual route, a token bottleneck, a world transition, an action manifold, a human-signal latent, or a verifier over the grounded artifact.

OBJECT 01

Modality Credit

MoCA

Problem. A multimodal agent can fail because it perceived badly, reasoned badly, or fused the two badly.

Object. A credit assignment variable over perception and cognition modules.

Why it works. Reinforcement signal is useful only if it reaches the failing component. MoCA makes the failure route observable, so updates can repair visual grounding or reasoning instead of mixing both errors into one noisy reward.

Connection. It is RAGEN-style trace diagnosis for multimodal state.

VGS

Problem. Visual grounding can be overestimated when the answer is correct for language-prior reasons.

Object. A score for whether visual evidence supports the generated content.

Why it works. The method asks whether the visual channel reduces uncertainty about the answer. If removing or changing the image would not change the output, the answer was not visually grounded in the mathematical sense.

Connection. It turns grounding into an evidence contribution problem.

Causal Route Gating

Problem. Large vision-language models can hallucinate by routing through text-prior paths while appearing to attend to the image.

Object. Attention-head route contributions split by visual and textual cause.

Why it works. The gradient estimate identifies routes whose change would alter the output. Suppressing prior-heavy routes is mathematically different from asking the model to be careful: it changes the internal path by which evidence reaches the decoder.

Connection. It is causal intervention at the fusion layer.

VISUALSWAP

Problem. VLMs can ignore fine visual changes when language context stays stable.

Object. Counterfactual image perturbations that preserve text while changing the visual truth.

Why it works. Swapped visual evidence creates paired examples where the correct answer must move with the image. The test isolates visual dependence by holding the shortcut channel fixed.

Connection. It is an experimental design for modality causality.

DOUBT

Problem. Multimodal systems often answer when the evidence is partial, ambiguous, or contradictory.

Object. An uncertainty state over whether available modalities justify commitment.

Why it works. Doubt is useful when it is tied to missing or conflicting evidence, not when it is generic hedging. The model improves by separating absence of evidence from negative evidence.

Connection. This is ambiguity-set reasoning in multimodal form.

MINT

Problem. Hallucination can originate in a narrow fusion band hidden inside the network.

Object. A causal patch over hidden states where image evidence enters language generation.

Why it works. Hidden-state patching changes an internal variable and observes whether the output changes. That gives a causal test for fusion, not only an attribution heatmap.

Connection. It links interpretability intervention to modality credit.

OBJECT 02

Token Bottlenecks

FlashVID

Problem. Long video creates more visual tokens than a model can process uniformly.

Object. A spatiotemporal token merge map.

Why it works. Frames contain redundant evidence at different spatial and temporal scales. FlashVID works when merging preserves tokens whose removal would change the answer or event state while collapsing repeated background evidence.

Connection. It is systems efficiency as information selection.

InfoTok

Problem. Fixed video token budgets waste compute on low-information segments and miss rare decisive events.

Object. An information-density estimate over video tokens.

Why it works. The compression is guided by expected decision value, not by uniform downsampling. Tokens survive because they carry information about future queries or actions.

Connection. It is active measurement selection for video context.

VideoFlexTok

Problem. Video tasks differ in how much temporal detail they need.

Object. A flexible visual token budget matched to task and sequence structure.

Why it works. The model avoids treating every video as the same sampling problem. It can spend more tokens where motion or event order matters and fewer where static context is enough.

Connection. This matches adaptive compute in reasoning models.

OmniFit

Problem. A multimodal model must fit heterogeneous inputs into a finite context without treating all channels equally.

Object. A context allocation rule over modality-specific tokens.

Why it works. The method succeeds when it preserves the minimal sufficient statistics for each modality. Compression is harmful only when it removes evidence that another channel cannot reconstruct.

Connection. It is feasible-state construction under memory constraints.

LST

Problem. Speech and multimodal streams need low-latency processing while preserving long-range evidence.

Object. A streaming token state with local updates and retained summary.

Why it works. Latency turns tokenization into online filtering. The state must be small enough to update now and rich enough to keep information needed later.

Connection. It connects multimodal modeling to control-loop timing.

COMPACT And LiME

Problem. Long-context and multimodal adaptation can become expensive because the model carries too much state or updates too much parameter mass.

Object. A compressed retained state or low-dimensional adaptation interface.

Why it works. Both methods rely on the same principle: many coordinates are redundant for a target task. The challenge is to remove coordinates without removing the ones that carry task evidence.

Connection. This is the shared math behind context compression and adapter efficiency.

MetaEmbed And TACO

Problem. Tables, structured records, and nonstandard inputs are poorly served by raw text serialization.

Object. A representation map that preserves row, column, type, and relation information.

Why it works. The model should not have to rediscover structure after it is flattened. Better embeddings keep the algebra of the input available for attention and retrieval.

Connection. It is tokenization as choosing the right coordinate system.

OBJECT 03

Unified Generation

NextStep-1

Problem. Multimodal generation should support the next edit, not only the first sample.

Object. A stateful generation interface where outputs remain conditionable.

Why it works. Editing and continuation require the generated artifact to remain in a representation the model can condition on. The output is a new state, not the end of computation.

Connection. It is agent trajectory logic applied to media generation.

EditVerse

Problem. Image editing fails when instructions are not tied to the editable parts of the scene.

Object. An edit state with targets, constraints, and unchanged context.

Why it works. The method separates what should change from what should remain invariant. That turns editing into constrained transformation rather than unconditional resampling.

Connection. It is feasible-set design for generated media.

LatentLM And UALM

Problem. Text, image, and audio generation live in different native spaces, but agents need one reasoning interface.

Object. A shared latent or unified autoregressive interface over heterogeneous outputs.

Why it works. A latent interface can align modalities without forcing every detail into words. It works when the shared code preserves enough structure for each decoder to reconstruct valid media.

Connection. This is representation learning as protocol design.

VibeVoice

Problem. Speech generation must preserve content, speaker character, timing, and prosody together.

Object. An audio latent where semantic and acoustic variables can constrain one another.

Why it works. Speech is not a transcript plus noise. The generator works when it models temporal acoustic structure as part of the state, so voice quality is controlled rather than postprocessed.

Connection. It is the audio version of native-state generation.

TTSDS2

Problem. Text-to-speech evaluation can miss naturalness, intelligibility, speaker fidelity, or task-specific defects.

Object. A speech artifact plus a multi-aspect scoring function.

Why it works. The benchmark observes the generated audio, not only the text prompt. Its value comes from scoring the medium where the error appears.

Connection. It ties generation to grounded verification.

FlashWorld

Problem. World generation must react to actions and maintain scene continuity.

Object. An interactive visual world transition.

Why it works. The model must condition the next visual state on the previous state and action. That prevents independent plausible frames from drifting away from one underlying world.

Connection. It is video generation as simulator math.

VIST3A

Problem. 3D-aware generation can lose view consistency when trained as separate 2D images.

Object. A representation that couples appearance to camera and geometry.

Why it works. View changes should transform the observation without changing object identity. The model improves by preserving the coordinate relation across generated views.

Connection. This links unified generation to spatial grounding.

TideGS And RadioGS

Problem. Some signals are fields, not pictures: time-varying surfaces, radiance, or radio propagation.

Object. Gaussian primitives that approximate continuous fields.

Why it works. A Gaussian splat is a local basis function with position, scale, opacity, and signal parameters. It lets the model render observations while keeping a manipulable field state.

Connection. It is native-state generation for physical media.

Omni-Reward, UniPercept, And MetamerGen

Problem. Generated media can satisfy a prompt while violating human perception or cross-modal consistency.

Object. Reward and perceptual-equivalence functions over generated artifacts.

Why it works. A reward model changes the sampling distribution toward artifacts that satisfy perceptual constraints. Metamer-style tests matter because two samples can match one representation while differing in another.

Connection. It is alignment as measurement over native artifacts.

OBJECT 04

Human Signals

Hibiki-Zero

Problem. Speech translation must preserve meaning while respecting latency and spoken timing.

Object. A streaming speech-to-speech state with semantic and acoustic variables.

Why it works. The model cannot wait for full text if the task is live speech. It works by maintaining enough partial state to translate without erasing prosody and timing.

Connection. It is online inference under human communication constraints.

EmotionThinker

Problem. Emotion recognition fails when affect is treated as a label attached to text alone.

Object. A latent affect state inferred from context, expression, and language.

Why it works. Affect is a hidden variable that explains several observations at once. Reasoning helps only when it separates evidence about emotional cause from stereotypes or surface sentiment.

Connection. It is latent-variable modeling for social signals.

EEmo-Logic

Problem. Emotional reasoning can become arbitrary when the model lacks an explicit chain from event to appraisal to response.

Object. A structured reasoning path over emotional cues and inferred appraisal.

Why it works. The method makes emotion prediction depend on intermediate variables instead of one direct label jump. That reduces shortcut dependence on single words.

Connection. It brings reasoning-trace math into affective computing.

WAVE

Problem. Audio models can miss temporal patterns that are obvious in waveform dynamics.

Object. A time-indexed acoustic representation.

Why it works. Waveform evidence is ordered and continuous. The model needs filters or tokens that preserve frequency, rhythm, and event timing rather than only transcript-like summaries.

Connection. It is spectral and temporal state modeling for human signals.

TokSuite And ATLAS

Problem. Tokenizers and tests can hide cultural or linguistic failures behind aggregate accuracy.

Object. Perturbation and item-selection processes that reveal where measurement fails.

Why it works. TokSuite tests whether the input code preserves native linguistic structure. ATLAS selects items that carry high information about latent ability. Both treat measurement as the object, not a passive report.

Connection. It links tokenizer design to benchmark economics.

Seizure-Semiology-Suite

Problem. Clinical video understanding requires domain events, not generic motion recognition.

Object. Expert-defined semiology labels grounded in medical observation.

Why it works. The benchmark measures whether the model preserves clinically meaningful state variables. Ordinary visual similarity is insufficient when small temporal signs change diagnosis.

Connection. It is high-stakes evaluation for non-text human signals.

Active Mind Avatars And MetaphorVU

Problem. Human communication includes pose, gaze, metaphor, and social intent that are not reducible to literal text.

Object. Multimodal social state with embodied and figurative variables.

Why it works. The model needs variables for what is shown, what is implied, and how expression changes meaning. Treating all cues as captions removes the relations that make them meaningful.

Connection. It is semantic grounding beyond literal language.

SleepLM And BioX-Bridge

Problem. Biosignals are noisy, indirect measurements with domain-specific temporal structure.

Object. A physiological latent state inferred from sensor sequences.

Why it works. The model must learn the measurement grammar of the signal before it can produce useful summaries or predictions. Bridging helps when it maps raw channels into structured medical variables.

Connection. It is scientific measurement modeling inside multimodal AI.

PRISM And Mind-Omni

Problem. Brain signals cannot be treated as images or text, yet they need to connect to both.

Object. Discrete brain tokens or object-attribute-relation codes between neural measurements and media.

Why it works. The intermediate representation absorbs measurement noise and exposes structured variables that a foundation model can use. Reconstruction becomes estimation of latent concepts followed by generation.

Connection. It is multimodal grounding with the measurement channel made explicit.

OBJECT 05

Embodied Action

SAW-Bench

Problem. A robot benchmark can reward language understanding while missing whether the agent can act in a changing world.

Object. Embodied tasks with scene, action, and world-state constraints.

Why it works. The benchmark observes whether decisions survive contact with the environment. A correct description is not enough if the action fails.

Connection. It is outcome verification for physical agents.

MomaGraph

Problem. Raw pixels do not directly encode what a robot can do with objects.

Object. A spatial-functional scene graph of objects, relations, states, and affordances.

Why it works. Planning becomes graph search over manipulable relations. The graph preserves which objects can change and which actions are meaningful.

Connection. It is agent planning with physical state rather than web state.

RoboMME

Problem. Robot memory is not one capability; temporal, spatial, object, and procedural memory fail differently.

Object. A memory taxonomy for VLA behavior.

Why it works. The benchmark asks which memory variable the task needs. A model with good object recall can still fail procedural continuation, so memory must be measured by function.

Connection. It is benchmark validity for embodied state.

HDFlow

Problem. High-dimensional robot trajectories are hard to sample as one flat action sequence.

Object. High-level latent subgoals plus low-level rectified-flow motion.

Why it works. The method separates global ambiguity from local smooth control. Coarse subgoals keep multiple plans alive; the lower flow fills in feasible motion.

Connection. It is hierarchical generation under action geometry.

EgoTactile

Problem. Vision cannot always observe contact, pressure, slip, or grip stability.

Object. Egocentric video paired with hand pressure state.

Why it works. Tactile sensors reveal latent physical variables that explain action success. The model gains evidence that pixels alone cannot provide.

Connection. It is missing-modality repair through a better measurement channel.

PACT

Problem. Test-time correction can improve a policy but also move it outside known safe behavior.

Object. A constrained policy update around the current action distribution.

Why it works. The update is useful when it changes uncertain actions while preserving proximity to trained behavior. The constraint prevents correction from becoming uncontrolled distribution shift.

Connection. It is feasible-set control for robot inference.

JoSE

Problem. Muscle or actuator spaces are high dimensional, but useful movement often lies on a lower-dimensional manifold.

Object. A latent action manifold tied to mutual information with behavior.

Why it works. Exploration becomes easier in coordinates that preserve behavior-relevant variation and drop redundant actuator movement. The policy searches the space of functional actions, not raw motor commands.

Connection. It is quotient-space thinking for control.

RodriNet

Problem. Articulated motion has rotation geometry that generic vector layers do not respect.

Object. A learnable operator based on Rodrigues forward kinematics.

Why it works. Known rotation structure is built into the model before fitting residual behavior. The network learns around a lawful transform rather than rediscovering kinematics from scratch.

Connection. It is architecture as a physical prior.

BehaviorVLA

Problem. Vision-language-action policies need reusable behavior, not only instruction following on seen demonstrations.

Object. A behavior distribution conditioned on visual state and language intent.

Why it works. The policy improves when it represents actions at the level where tasks transfer. It should preserve the behavior invariant while adapting to objects, poses, and instructions.

Connection. It is representation learning for embodied generalization.

DreamDojo And SCALE

Problem. Robots need training signals and test-time control without endless real-world rollouts.

Object. Simulated or self-evaluated action state.

Why it works. DreamDojo expands experience through generated worlds, while SCALE uses the model's own output distribution as a control signal. Both reduce dependence on expensive external feedback by making action uncertainty measurable.

Connection. It ties world models to deployment-time control.

OBJECT 06

Memory And World State

VideoKR

Problem. Knowledge-rich video tasks require visual evidence and outside knowledge to meet in time.

Object. A video state linked to query-relevant knowledge.

Why it works. The benchmark reduces language-prior shortcuts by asking for answers whose support must be found in the video. The model must keep event state long enough to combine it with knowledge.

Connection. It is retrieval-augmented reasoning over visual trajectories.

Visual Attribution Streaming

Problem. Exhaustive visual attribution is too expensive for thinking VLMs, but ungrounded reasoning must still be detected.

Object. A streaming estimate of which visual evidence drives intermediate reasoning.

Why it works. The method approximates causal contribution without repeatedly rerunning all perturbations. It gives a practical evidence route during long reasoning.

Connection. It is trace diagnostics for visual thought.

DLMR

Problem. One memory store can mix visual facts and reasoning summaries until neither is reliable.

Object. Routed multimodal memory with separated evidence roles.

Why it works. Visual memory should preserve observations; reasoning memory should preserve derived state. Separating them prevents a language summary from overwriting the evidence it depends on.

Connection. It is memory architecture as causal bookkeeping.

RFCMH

Problem. Cross-modal hallucination appears when generated content is not constrained by source evidence.

Object. A reliability or consistency state across modality outputs.

Why it works. The method works by making disagreement measurable. If image, text, or audio claims diverge, the model can route correction to the unsupported part rather than treating all generations as equally likely.

Connection. It is verifier logic inside multimodal generation.

WETR And AGREE

Problem. Weak or partial labels can teach the wrong alignment between observations and concepts.

Object. A reliability-weighted training signal over incomplete multimodal labels.

Why it works. The learning update should trust labels in proportion to the evidence they provide. Reliability weighting reduces the influence of noisy supervision that would otherwise become hallucinated structure.

Connection. It is data-value math for multimodal supervision.

OBJECT 07

Grounded Verification

OmniVerifier

Problem. Iterative visual generation needs a judge that checks the produced artifact, not only prompt plausibility.

Object. A verifier over visual outcome, instruction satisfaction, and iteration state.

Why it works. The verifier creates feedback in the same space where the error occurs. It can reject outputs that sound correct in text but fail visually.

Connection. It is executable evaluation for multimodal media.

FlowGuard

Problem. Abnormal generation or cross-modal inconsistency can appear as a distributional flow problem before the final output is obviously wrong.

Object. A monitored flow of intermediate states.

Why it works. The defense checks whether the generation path stays in expected regions. It treats safety as trajectory monitoring, not just endpoint classification.

Connection. It links safety tail detection to sample-path control.

DAVE, VC-STaR, And HALO

Problem. Multimodal and embodied decisions need verifiers that judge evidence, self-correction, or action stability under pressure.

Object. A verifier or correction rule coupled to the produced answer or policy update.

Why it works. DAVE-style diagnostics inspect visual evidence; VC-STaR-style self-training uses corrected trajectories; HALO-style constraints stabilize multi-agent or decentralized updates. Each works by checking movement, not only final claims.

Connection. It is the same verifier object across perception, reasoning, and control.

FRABench And UFEval

Problem. A single preference score can hide whether a multimodal output failed relevance, factuality, format, or perceptual quality.

Object. A factorized evaluation instrument.

Why it works. Breaking the score into aspects makes the measurement interpretable. The benchmark can say which latent quality variable changed rather than reporting one opaque number.

Connection. It is measurement design for generated artifacts.

OBJECT 08

Latent Interfaces

LIMSSR

Problem. Action-quality assessment often has missing modalities at training or test time.

Object. A conditional sequence-to-score latent that works under partial observation.

Why it works. The score should be estimated from the evidence that is actually available, with uncertainty about missing channels left in the state. This avoids hallucinating complete observations.

Connection. It is missing-data inference for embodied assessment.

Visual Symbolic Mechanisms

Problem. Some visual reasoning tasks need discrete relations that raw embeddings blur.

Object. A symbolic or relational latent extracted from visual evidence.

Why it works. Discrete relations make counting, comparison, and compositional reasoning explicit. The model no longer has to represent every relation as an uninspected vector similarity.

Connection. It is representation choice as mathematical simplification.

Camera-Aware MLLM

Problem. A scene looks different under different cameras, but the underlying object state may be the same.

Object. Visual state conditioned on camera pose and projection.

Why it works. The model separates viewpoint variation from scene variation. Camera variables tell the model which pixel changes are measurement changes, not object changes.

Connection. It is quotient geometry for multimodal perception.

DepthLM And Depth Anything 3

Problem. Depth is hidden behind 2D projection but essential for action and spatial reasoning.

Object. A depth field aligned with image evidence.

Why it works. Estimating depth adds the missing coordinate that makes occlusion, reachability, and object relation interpretable. The model moves from pixels to scene geometry.

Connection. It is latent-state recovery from projected measurements.

SYNTHESIS

The Cross-Paper Shape

Evidence Route Before Answer

MoCA, VGS, Causal Route Gating, VISUALSWAP, MINT, Visual Attribution Streaming, and DLMR all say the same thing in different forms: a grounded answer must expose which evidence path changed the output. Correctness without route dependence is a shortcut, not a demonstrated multimodal capability.

Token Budget Before Context

FlashVID, InfoTok, VideoFlexTok, OmniFit, LST, COMPACT, LiME, MetaEmbed, and TACO treat context as a scarce state variable. The mathematical question is which compression preserves the sufficient statistic for the task. Efficiency is valid only when discarded tokens are conditionally irrelevant to the decision.

Action State Before Policy

SAW-Bench, MomaGraph, RoboMME, HDFlow, EgoTactile, PACT, JoSE, RodriNet, BehaviorVLA, DreamDojo, and SCALE show why embodied AI cannot be reduced to language planning. The policy acts through body geometry, contact, memory, and latency. Those variables must be part of the state before optimization begins.
