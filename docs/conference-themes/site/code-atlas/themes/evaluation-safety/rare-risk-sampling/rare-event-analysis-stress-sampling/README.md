# Rare Event Analysis Stress Sampling

Theme: Evaluation / Safety
Subtheme: Rare-risk sampling
Paper family: Rare Event Analysis style stress sampling

What it proves: ordinary testing can miss the rare path that creates most of the real danger.

User knob: bad-case rarity, stress sampling, test budget.

Failure exposed: the benchmark reports safety because it almost never visits the dangerous region.

Evidence: the sampler must reach the bad region often enough to estimate risk.
