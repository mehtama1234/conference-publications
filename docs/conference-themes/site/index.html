READ FIRST

The Big Picture

The simplest way to read these pages is to start from the pressure that created them. The old benchmark story was: train a model, measure its accuracy, compare it to another model. The conference evidence here is working on a harder object. A useful AI system has to choose actions, inspect evidence, use tools, adapt under constraints, survive distribution shift, respect data rules, and produce outputs in domains where structure matters. That turns machine learning from a prediction problem into an operating problem.

The themes therefore connect in layers. At the top are agents, reasoning, and inference-time control: how a trained model decides what to do now. Around that are evaluation and diagnostics: how we know whether the behavior is real, robust, or a shortcut. Beneath that are data, systems, and efficiency: what material and hardware conditions make the behavior possible. Alongside it are safety, governance, and alignment: what happens when the system is deployed with incentives, adversaries, privacy requirements, or legal constraints. Finally, the scientific and physical-domain themes show the same shift in harder sample spaces: molecules, proteins, robots, PDEs, time series, brains, and structured data.

Family 01

Agents, Reasoning, and Inference Control

The common problem is that a model answer is no longer the whole product. The model has to plan, call tools, inspect state, revise, ask questions, steer behavior, and keep working over long contexts. This family is about the moment after training: what control surfaces exist at inference time, and how an agent uses them to produce reliable work.

Reasoning, planning, and tool use

Turns reasoning into a procedural object: decomposed plans, tool calls, Bayesian question selection, circuit-guided repair, and teacher-generated reasoning pipelines.

Subthemes: tool-use scaffolds, experimental design agents, verifier-guided repair, reasoning-data pipelines.

LLM agents and process diagnostics

Looks inside agent traces to detect template collapse, low-effort verifier passing, UI loops, reward-signal weakness, and context-sensitive coding behavior.

Subthemes: process collapse, reward quality, agent robustness, intermediate artifacts, partner curricula.

Test-time scaling and inference control

Treats inference compute as an allocatable resource: more thinking, recursive search, verifier refinement, long-horizon curricula, and reasoning mechanisms activated without full retraining.

Subthemes: norm-guided recursion, verifier loops, diffusion reasoning, scalable RL recipes.

Inference-time model control

Separates the task prompt from the control signal by steering internal activations during generation.

Subtheme: activation steering for persona and instruction-following control.

Long-context foundation models

Studies how position, memory, and retrieval behave when the model's usable context window becomes an engineering target.

Subthemes: RoPE extension, long-context recall, context budgeting.

Long-context and long-horizon generation

Connects long context to long outputs, where coherence must survive many steps rather than a single answer.

Subthemes: long-form generation, horizon extension, sequence-level control.

Software and code intelligence

Moves coding evaluation from toy completion to code edits, program reasoning, repair, and real developer context.

Subthemes: code-edit benchmarks, program synthesis, repository-aware assistance.

Developer tools and reliability

Asks whether code assistants remain useful when the task includes cursor state, highlighted regions, instructions, and realistic project context.

Subthemes: context-sensitive editing, reliability measurement, practical assistant failures.

Program synthesis and verification

Treats generated code as something that must be checked, repaired, or formally constrained, not merely sampled.

Subthemes: synthesis, verification, executable correctness, statistical code generation.

Multi-agent systems

Studies systems where behavior emerges from multiple agents, constraints, debate, variance, and game structure.

Subthemes: constrained equilibria, debate calibration, disagreement and confidence signals.

Healthcare and education agents

Frames agents as tutors or clinical assistants that must model users, teach groups, and operate under domain-specific evaluation.

Subthemes: clinical teaching simulation, group belief states, biomedical task agents.

Agent infrastructure risk

Looks at the security boundary around tool-using agents: sandbox escapes, hidden channels, and activation-level monitoring.

Subthemes: container escape, hidden safety bypasses, monitoring attack surfaces.
Family 02

Evaluation, Diagnostics, and Reliability

The evaluation pages all push against the same weakness: a scalar benchmark score can hide why a system passed. The conference evidence moves toward executable tests, micro-benchmark reliability, visual verification, tail-risk estimation, process diagnostics, and measurements that distinguish true capability from shortcut behavior.

Evaluation, benchmarks, and measurement

Collects work where evaluation itself is the research object: executable security tasks, micro-benchmark reliability, rare-event analysis, and multimodal judges.

Subthemes: dynamic evaluation, ranking reliability, tail risk, visual verification, human-calibrated judges.

Foundation model evaluation

Asks how broad models should be measured when one model spans modalities, tasks, and use cases.

Subthemes: aspect-level judging, benchmark transfer, broad capability measurement.

Interpretability as intervention

Uses internal structure not only to explain models but to change them: activation steering, concept slots, norm signals, causal feature recovery, and mechanistic repair.

Subthemes: activation mechanisms, concept-level supports, feature interventions, circuit-guided correction.

Representation geometry

Studies the shape of learned representations: superposition, exchangeability, camera geometry, feature transfer, and spectral organization.

Subthemes: geometric transfer, temporal packing, cross-camera generalization, graph coordinates.

Retrieval and information access

Connects long-context and retrieval systems to the question of which information reaches the model at the moment it matters.

Subthemes: retrieval quality, access patterns, model-context interfaces.
Family 03

Safety, Alignment, and Governance

This family is about what breaks when AI leaves the lab. Safety is not only refusal behavior. It includes privacy, unlearning, watermarking, preference misspecification, rare deployment behavior, data legality, robustness to shifts, and security-relevant agent capabilities.

Alignment, preference optimization, and feedback

Studies how preference training succeeds or fails when rewards are misspecified, policy classes are limited, or objectives need to teach new reasoning paths.

Subthemes: DPO misspecification, token-level preference control, RL scaling, one-to-many alignment.

Robustness, safety, privacy, and unlearning

Connects certified unlearning, watermarking, privacy, deepfake detection, safe diffusion, jailbreak-style risks, and rare deployment failures.

Subthemes: certified deletion, provenance, privacy-preserving training, safety guidance, adversarial fine-tuning.

Robustness and distribution shift

Tracks methods that survive shifted domains, missing modalities, OOD deepfakes, and real deployment variation.

Subthemes: cross-domain robustness, multimodal uncertainty, shifted UI environments.

Robust optimization and decision-making

Focuses on making decisions when the context is incomplete, especially missing covariates that should remain visible to the optimizer.

Subtheme: distributionally robust ambiguity sets from partial observations.

Societal impacts and governance

Frames governance as a design constraint that affects data, evaluation, deployment, and accountability.

Subthemes: compliance, public-interest evaluation, transparency and accountability.

Data governance and curation

Looks at open reasoning data, checkpoint trajectories, and legally usable corpora as infrastructure for reproducible training.

Subthemes: open data recipes, merge-duration control, compliant corpora.

Data quality, governance, and curation

Asks which examples help, which hurt, and how data choice becomes a controlled optimization variable.

Subthemes: harmful contrastive examples, missingness-aware optimization, annealing sample selection.

Open science infrastructure

Treats open pretraining data as a condition for reproducibility, entrepreneurship, and legal compatibility.

Subtheme: open compliant corpora for LLM pretraining.
Family 04

Data, Systems, and Efficient Adaptation

These themes explain the practical substrate. A model method changes when memory is scarce, precision is low, data cannot move, devices differ, or deployment cost dominates. Efficiency is not only compression; it decides which capabilities can exist in the first place.

Efficiency as capability enabler

Connects low-precision stability, quantization, token merging, neuromorphic training, pruning dynamics, and alternative compute substrates.

Subthemes: low precision, edge training, fractional bits, video token merging, solver replacement.

Systems and infrastructure

Focuses on the infrastructure layer that makes training, inference, evaluation, and deployment feasible.

Subthemes: runtime systems, benchmark infrastructure, compute-aware design.

Numerical ML systems

Looks at numerical stability and kernel-level details where exact-arithmetic equivalence can fail under real precision.

Subthemes: BF16 stability, DP-SGD clipping, hardware-budget fitting.

Efficient adaptation

Studies ways to adapt models without full retraining: bridges, test-time updates, parameter-efficient methods, and modality transfer.

Subthemes: cross-modal bridges, lightweight tuning, target-domain adaptation.

Adaptation and continual control

Collects methods for changing behavior after deployment, including test-time training, reward adaptation, prompt search, and domain adaptation.

Subthemes: inference-time adaptation, user-specific rewards, graph support examples, model merging.

Continual learning

Asks how models remember new concepts without overwriting old ones.

Subthemes: object-centric memory, concept distillation, catastrophic forgetting.

Deployment constraints reshape methods

Shows how privacy, energy, memory, and edge-device limits change the training algorithm itself.

Subtheme: on-device transformer training through subspace optimization.

Federated and distributed learning

Studies learning across clients with different costs, data, and hardware rather than a single centralized dataset.

Subthemes: cost-aware FedOpt, router-like shared spines, heterogeneous devices.

Domain adaptation and distribution shift

Focuses on target-domain learning when source data, labels, or distributions do not match deployment.

Subthemes: source-free adaptation, density-guided regression, shifted distributions.

Optimization and training dynamics

Explains training behavior through gradients, Hessians, curvature, checkpoint averaging, and late-stage data selection.

Subthemes: curvature-aware data, posterior correction, learning-rate decay as merging.
Family 05

Generative Modeling and Structured Outputs

Generation is spreading into domains where validity is not just visual realism or fluent text. A generated object may need to satisfy physical symmetry, biological hierarchy, safety constraints, decision feasibility, speech timing, or non-autoregressive reasoning dynamics.

Generative modeling

Collects broad advances in diffusion, flow, 3D scene generation, speech generation, safety guidance, and quantized denoising.

Subthemes: 3D scenes, safe denoising, speech tokens, watermark-preserving noise, diffusion error dynamics.

Generative modeling for decision-making

Uses generative policies to sample structured actions while respecting combinatorial or feasibility constraints.

Subtheme: latent flow policies mapped through solvers into valid actions.

Diffusion language models

Explores non-autoregressive language generation where RL and reasoning updates have to match a denoising distribution.

Subthemes: DMPO, reward-tilted distributions, mode-coverage correction.

Structured generative modeling

Builds generators around physical structure, including protein hierarchy and quotient spaces modulo rigid motion.

Subthemes: protein autoregression, quotient-space diffusion for molecules and proteins.

Scientific and physical-domain generation

Applies generative modeling to proteins, molecules, avatars, brain signals, scientific structures, and physical sample spaces.

Subthemes: multiscale proteins, object-centric reconstruction, Boltzmann flows, quotient-space models.

Sequence modeling

Looks at positional encodings, recurrent memory, long sequences, and formal sequence-generation limits.

Subthemes: positional computation, sequence universality, memory capacity, autoregressive structure.

Foundation models beyond text

Moves foundation-model interfaces into sleep signals and tabular workloads where the raw data is not a sentence.

Subthemes: physiological captioning, retrieval, event localization, tabular inference efficiency.

Foundation model evaluation

Measures broad models across modalities and criteria rather than only single-task text performance.

Subthemes: aspect taxonomies, multimodal judges, evaluation transfer.
Family 06

Multimodal, Embodied, and Physical AI

This family ties models to perception and action. The key question is what representation lets a model move from pixels, audio, brain signals, scene graphs, or robot trajectories into decisions that stay grounded in the world.

Multimodal and embodied models

Connects visual, audio, brain, action, and scene representations into models that can perceive, reason, and act.

Subthemes: scene graphs, avatars, fMRI decoding, spatial MLLMs, long-video token budgets.

Robotics and embodied AI

Studies robot policies, world models, subgoal generation, behavior representations, and real-robot transfer.

Subthemes: hierarchical planning, behavior streams, mobile manipulation, sim-to-real transfer.

Robotics and control

Focuses on differentiable GPU model-predictive control as a fast, structured planner inside learning systems.

Subtheme: SQP, preconditioned conjugate gradients, tridiagonal preconditioning.

Graph and relational learning

Studies graph representations where relationships, topology, and cross-domain transfer matter more than independent examples.

Subthemes: graph foundation models, relational transfer, graph retrieval.

Graph learning

Focuses on graph domain adaptation, exchangeability, in-context alignment, and geometric graph representations.

Subthemes: manifold gluing, exchangeable coordinates, modality-free graph adaptation.

Cognitive science and human modeling

Uses generative models to probe human scene perception: what detail is kept at fixation, and what gist is preserved in the periphery.

Subtheme: foveated metamer generation for human scene understanding.

Neuroscience and cognition

Uses fMRI predictivity to ask when model scale stops improving alignment with human language comprehension signals.

Subtheme: brain-encoding scale saturation.
Family 07

Science, Causality, and Dynamical Systems

The scientific themes treat ML as a way to make decisions about mechanisms, not just to fit curves. They ask how to discover causal effects, model partially observed processes, simulate physical systems, forecast dynamics, and build tools that scientists can actually use.

Scientific discovery and causal inference

Links foundation-model representations, causal search, biomedical agents, statistical code synthesis, and partially observed event processes.

Subthemes: sparse effect search, MedAgentGym, Hawkes causal discovery, statistical code repair.

Causality

Studies local adjustment, conditional-independence testing, and structure learning without requiring the whole causal world to be known.

Subthemes: local covariate selection, poly-forest CI rates, causal effect identification.

Causality and causal discovery

Applies causal reasoning to production root-cause analysis under partial graph knowledge and scarce failure data.

Subtheme: Bayesian root-cause discovery for microservice incidents.

Scientific and healthcare ML

Works on biosignals, brain modeling, neurostimulation, biomedical data-science agents, and clinical education systems.

Subthemes: biosignal transfer, brain tokens, biophysical digital twins, clinical tutors.

Scientific computing and hardware

Connects physical dynamical solvers, frozen PINNs, neural operators, neuromorphic coding, and differentiable simulators.

Subthemes: PDE solvers, physical compute, simulation-based inference, fixed-point refinement.

Time series and dynamical systems

Studies temporal modeling where the system evolves, history matters, and state-space assumptions shape prediction.

Subthemes: dynamical solvers, temporal structure, physical system evolution.

Time series and forecasting

Focuses on practical forecasting under changing regimes, limited data, and temporal uncertainty.

Subthemes: forecasting reliability, uncertainty, structured temporal prediction.

Probabilistic inference and uncertainty

Collects methods that need calibrated uncertainty, likelihoods, posterior reasoning, or sampling guarantees.

Subthemes: molecular flows, thermodynamic estimation, Bayesian posterior correction.
Family 08

Theory, Optimization, and Representation

The theory pages are not separate from engineering. They explain why deployed methods behave the way they do: when transformers can implement algorithms, how spectra govern generalization, when sample complexity makes formal possibility irrelevant, and why post-training objectives differ from pretraining objectives.

Theory and optimization

Spans mixture recovery, clustering circuits, Jacobian spectra, formal-language feasibility, minimax rates, and attention theory.

Subthemes: SDP relaxations, transformer circuits, spectral separation, sample complexity barriers.

Theory unifies engineering practice

Shows how theoretical lenses explain RoPE extension, RLHF geometry, quotient diffusion samplers, checkpoint merging, and feature-learning rates.

Subthemes: theory-backed recipes, sampler correctness, natural-gradient alignment, spectral scaling.

Theory follows deployment needs

Develops theory around practical failure modes: privacy definitions, watermark bounds, objective mismatch, and high-dimensional certification.

Subthemes: unlearning privacy, information-theoretic safety, post-training objectives.

Reinforcement learning

Studies RL objectives, constrained control, feasible neural layers, and policy behavior beyond simple reward maximization.

Subthemes: safe RL, constrained planning, feasible projection networks.

Reinforcement learning and control

Connects RL to control theory, constraint sensitivity, recovery dynamics, and long-horizon decision-making.

Subthemes: constraint-sensitive policy updates, control-aware RL, recovery behavior.

Hybrid neural-symbolic systems

Combines neural models with solvers, algebra, symbolic mechanisms, and classical algorithms that impose structure on output or reasoning.

Subthemes: solver-induced policies, Groebner bases, transformer algorithm circuits.

Sparse and modular computation

Studies MoE routing, expert specialization, active FLOPs, and how sparse computation scales reasoning under fixed compute.

Subthemes: expert-router coupling, MoE sparsity scaling, active compute allocation.
SPINE

What Holds the Map Together

Inference is becoming a control problem

Prompting, steering, test-time compute, verifier loops, and agent tools are all different ways to control a trained model at the moment of use.

Evaluation is becoming executable

The strongest benchmarks run code, vary environments, inspect traces, estimate tail probabilities, and verify outcomes rather than grade static answers.

Data is becoming governance

Data choices now encode legality, reproducibility, optimization geometry, missingness, privacy, and the ability to reproduce or audit model behavior.

Structure is becoming the sample space

For proteins, molecules, graphs, scenes, time series, and robots, the right model starts by respecting geometry, hierarchy, constraints, and symmetries.
