Handwritten field survey - ICML / ICLR 2026

Conference themes, not leaderboard noise

This page ignores the gym project and treats the conference corpus as a field signal. The question is: what problem is the field trying to solve now? The answer is not one algorithm. It is the move from isolated models to systems that must perceive, act, adapt, prove, compress, govern, and survive contact with users and infrastructure.

The big picture

The old story was simple: train a larger model, test it on a benchmark, report the score. The ICML/ICLR 2026 theme index says that story is no longer enough. Models are being asked to use tools, watch video, edit code, reason over long traces, operate in simulated or physical worlds, respect safety boundaries, run cheaply, and learn from curated data whose origin matters.

That changes the central scientific problem. The field is no longer only asking, "Can the model predict the next token?" It is asking, "Can a learned system keep a stable grip on the world while constraints change?" The world can be a browser, a robot scene, a molecule, a long context, a privacy request, a compiler, a hospital workflow, or a user applying pressure. The shared problem is reliable behavior under structure.

The approaches fall into a few deep moves: build richer representations of the world; use verifiers instead of vibes; learn from consequences, preferences, and traces; make training data accountable; compress systems enough to deploy; and inspect internals when behavior becomes too complex to judge from outputs alone.

The twelve major themes

01. Multimodal and embodied models

115 rows

The first-principles problem is that the world does not arrive as a clean sequence of words. It arrives as images, camera motion, sound, objects, actions, physical layout, partially observed scenes, and time. A model that can caption a picture but cannot preserve object identity, spatial relationships, or temporal continuity is not grounded enough for real tasks.

The papers in this theme attack that gap from several sides. Some build better spatial substrates: scene graphs, camera-aware VLMs, depth-aware representations, 3D reconstruction, optical flow, SLAM, and orthographic views. Others compress long video or audio streams so the important parts survive the context budget. A third group turns perception into action: VLA systems, robot world models, embodied memory, and closed-loop planning.

World structure
Scene graphs, camera intrinsics, depth, motion, and 3D geometry make perception less like captioning and more like maintaining a model of a changing world.
Temporal memory
Video and robot tasks require memory over many frames, not isolated recognition. Token compression and behavior streams are attempts to keep long-horizon evidence alive.
Action grounding
Embodied papers ask whether a visual model can support decisions: navigation, manipulation, subgoal selection, and real-time world-model rollout.
Spatial grounding
This subtheme asks whether a model has a usable internal account of where things are. Papers such as Camera-Aware MLLM, SpatioLM, 3ViewSense, Depth Anything 3, VGGT-Motion, and MomaGraph all attack the same failure: language can describe space loosely, but action needs camera geometry, depth, allocentric relations, and persistent object structure.
Temporal and embodied memory
BehaviorVLA, RoboMME, DreamDojo, WoW!, and long-video papers treat time as a first-class problem. The question is not whether the model can recognize one frame; it is whether it remembers enough about previous frames, task phase, and action consequences to make the next decision coherent.
Compression without amnesia
FlashVID, InfoTok, OmniFit, VideoFlexTok, and related token-budget papers are trying to compress sensory streams without deleting the evidence needed later. The deeper problem is selective memory: a system must forget most pixels while preserving the few facts that will determine future reasoning or action.
World models as test beds
DreamDojo, WoW!, HDFlow, FlashWorld, and embodied world-model work use learned prediction not only to generate media but to ask "what happens if I act?" This is the bridge from multimodal understanding to planning: a world model is valuable when it improves downstream decisions, not only visual realism.
MomaGraph
ICLR 2026
MomaGraph turns household manipulation into a scene-graph problem because the task is not merely to recognize objects. A useful agent must know which object is where, what it affords, how it relates to other objects, and how those relations matter for the goal. The first-principles contribution is the claim that planning improves when the model is forced to construct an intermediate world representation instead of jumping from image to language plan.
BehaviorVLA
ICML 2026
BehaviorVLA treats robot behavior as coordinated streams: vision, action, and behavior phase. That is important because long-horizon manipulation is not a sequence of independent reactions. The policy has to know whether it is reaching, aligning, grasping, transporting, or recovering. The paper represents the broader move from image-conditioned actions to temporally organized behavior representations.
HDFlow
ICML 2026
HDFlow separates high-level subgoal generation from low-level trajectory generation. The principle is that long tasks need more than one planning scale: high-level structure keeps the system pointed at a feasible future, while low-level flow handles continuous contact and motion. It connects generative modeling to robotics by using generation as a way to propose both where to go and how to move.
DreamDojo
ICML 2026
DreamDojo uses human egocentric video as a source of world knowledge for robot prediction and planning. The conceptual bet is that human video contains transferable regularities: hands approach objects, tools change state, rooms constrain motion, and actions have visible consequences. It is not just a video model; it is an argument that unlabeled human experience can become a substrate for embodied control.
Camera-Aware MLLM, SpatioLM, 3ViewSense
ICLR / ICML 2026
These papers share one diagnosis: current multimodal models often reason about spatial scenes using language priors and surface cues, not stable geometry. Their approaches differ, but the aim is the same: add camera intrinsics, pseudo-depth, orthographic views, or canonical spatial decompositions so the model can reason about the same world across viewpoints. The big picture is that spatial intelligence needs coordinate discipline.
FlashVID, InfoTok, OmniFit
ICLR / ICML 2026
This cluster handles the cost side of multimodality. Long video, audio, and omnimodal streams contain far more tokens than a model can afford to process naively. The papers are not only making inputs smaller; they are asking which visual or temporal details carry future value. In that sense, compression becomes a theory of attention over evidence: preserve what later decisions will need, discard what will not change the answer.

02. Robustness, safety, privacy, and unlearning

104 rows

The first-principles problem is boundary control. Once models can write code, use tools, answer medical questions, generate media, browse systems, or be fine-tuned by outsiders, the question becomes: what can the model do when conditions are adversarial, ambiguous, or legally constrained?

This theme is not one safety problem. It is a family of boundary problems: delete data without wrecking the model; watermark generated media without making it easy to detect or remove; stop hidden unsafe behavior; measure rare dangerous events; detect fine-tuning attacks; contain tool-using agents; and preserve privacy while adapting models.

Formal boundaries
Certified unlearning and privacy work try to define what can be proven after data deletion or private training, rather than trusting policy statements.
Adversarial pressure
Pressure tests, malicious fine-tuning, steganographic attacks, and sandbox escapes ask what behavior emerges when the system has reason to hide or bypass constraints.
Monitoring internals
Activation probes and internal consistency signals appear because surface text can be made benign while internal intent or capability remains dangerous.
Deletion and privacy
Certified unlearning, DP-SGD clipping, high-dimensional Gaussian mechanisms, and private adaptation papers all ask what it means to make a model respect a data boundary after training. The core problem is not sentiment about privacy; it is whether a downstream party can verify that removal or protection had the intended effect.
Hidden unsafe behavior
Invisible Safety Threat, Trojan-Speak, activation-level safety auditing, and pressure benchmarks study behavior that surface checks can miss. The shared concern is that capable systems may learn representations or communication channels that pass ordinary filters while still preserving unsafe intent or capability.
Infrastructure risk
SandboxEscapeBench, CyberGym, and related agent-security rows treat the runtime as part of the safety problem. Once agents can use terminals, browsers, files, code, or containers, safety is no longer only about text refusal; it is about bounding real actions in real systems.
Provenance and authenticity
Watermarking, deepfake detection, media provenance, and cross-modal consistency papers ask whether generated or manipulated artifacts can be recognized after distribution. The problem is adversarial evidence: once content leaves the model, the system still needs a way to reason about origin and trust.
Gaussian certified unlearning
ICLR 2026
This paper reframes data deletion as a hypothesis-testing problem. That matters because informal unlearning claims are easy to make and hard to verify. The first-principles question is: after a deletion request, can an observer distinguish the updated model from one trained without the deleted data? By making the guarantee statistical and explicit, the paper turns privacy into a measurable contract rather than a process claim.
SandboxEscapeBench
ICML 2026
SandboxEscapeBench studies whether tool-using agents can cross a containment boundary. The important point is that the object of evaluation is not a harmful answer; it is an infrastructure event. If an agent can escape a container, read a host flag, or exploit a misconfiguration, the safety failure exists even if the transcript sounds technical and neutral. This is the conference theme at its sharpest: safety is behavior in a system.
CyberGym
ICLR 2026
CyberGym shows that evaluation can be dual-use because a good cyber benchmark may produce working vulnerability artifacts. The paper's role in the safety theme is not only that it evaluates security capability. It demonstrates that benchmark design changes the world it measures: generated PoCs can expose real bugs, incomplete patches, and new operational risk. That forces governance around the evaluator, not only the model.
Invisible Safety Threat and Trojan-Speak
ICLR / ICML 2026
These papers attack the assumption that unsafe behavior must appear plainly in surface text. One studies harmful content hidden through steganographic behavior after malicious fine-tuning; the other studies fine-tuned models that preserve harmful internal representations while evading classifiers. Together they connect safety to representation and monitoring: if the dangerous state is internal or encoded, output-level moderation is a weak instrument.
Pressure Reveals Character
ICML 2026
Pressure Reveals Character treats model behavior as conditional on social and task pressure. A model that is honest under a clean instruction may behave differently when asked repeatedly, threatened with failure, rewarded for persuasion, or pushed into a conflict between helpfulness and safety. The paper belongs in this theme because it expands safety evaluation from "will it refuse a bad prompt?" to "what does it do when the interaction becomes difficult?"
Catch-22 and Spherical Watermark
ICML / ICLR 2026
The watermarking papers expose a real tradeoff: a mark should survive edits, remain hard for outsiders to detect or remove, and still be reliably verifiable by the right party. Those goals fight each other. The first-principles contribution is not merely a new watermark; it is making media provenance legible as a constraint triangle where robustness, stealth, and verification cannot all be maximized independently.

03. Evaluation, benchmarks, and measurement

104 rows

The first-principles problem is epistemic: how do we know what happened? A model answer is evidence, but weak evidence. If the system edits code, operates tools, reasons over images, interacts with users, or claims to solve a scientific task, the evaluation has to inspect consequences, not only text.

The field is moving toward executable and calibrated measurement. Executable means the task changes a system and a verifier checks the state. Calibrated means the judge, metric, or benchmark has known behavior: human agreement, rare-event confidence intervals, noisy-verifier limits, or task-family certification bounds.

Executable checks
Run code, check browser state, verify compiler equivalence, test PoCs, inspect generated UI, or evaluate a world-model in a loop.
Judge calibration
When exact checking is impossible, papers use human-calibrated LLM judges, pairwise ranking, subjective construct modeling, or visual verification benchmarks.
Failure exposure
Rare-event analysis, pressure tests, degeneration diagnostics, and tail-risk estimates target failures that ordinary benchmarks miss.
Executable evaluation
CyberGym, SandboxEscapeBench, CIRBench, EditBench, VERINA, WebDevJudge, and compiler/code benchmarks replace answer matching with consequences. The system writes code, changes state, produces an artifact, or runs in an environment; the evaluator then checks the result.
Verifier and judge reliability
OmniVerifier, FRABench/UFEval, Pressure Reveals Character, VALUEFLOW, weak-strong verification, and human-calibrated judges focus on the evaluator itself. The core question is whether the scoring mechanism is stable enough to trust, especially when exact truth is unavailable.
Rare and hidden failures
Rare Event Analysis, FOCUS/RePAIR, TRACE Effort, reward-hacking diagnostics, and pressure benchmarks look for failures that average-case benchmarks hide. The shared approach is to measure tails, shortcuts, degeneracy, and suspicious success rather than only mean accuracy.
Dynamic task worlds
Gaia2, AstaBench, SimuHome, CausalGame, dWorldEval, and closed-loop world-model evaluation treat a benchmark as an interaction. The object of measurement is a trajectory through a changing task, not a static question.
CyberGym and SandboxEscapeBench
ICLR / ICML 2026
These are executable security evaluations. They do not ask whether a model can explain a vulnerability or describe a sandbox. They ask whether a controlled environment reaches a concrete state: a generated PoC works, a patched version resists it, or a sandbox boundary is crossed. The conceptual importance is that the benchmark is grounded in operational evidence rather than persuasive text.
WebDevJudge and OmniVerifier
ICLR 2026
These papers deal with outputs that cannot be reduced to a single gold token. A web page can be semantically correct but visually broken; an image edit can satisfy some constraints while violating others. WebDevJudge and OmniVerifier are part of the push to build evaluators for artifacts, where success depends on structure, appearance, intent, and downstream usability.
EditBench, CIRBench, VERINA, AlgoVeri
ICLR / ICML 2026
This cluster makes code and formal reasoning measurable in stronger ways. EditBench tests realistic code-edit context; CIRBench checks compiler transformations through semantic and performance constraints; VERINA and AlgoVeri evaluate verifiable code or proofs across toolchains. The shared principle is that executable semantics beat surface similarity when the domain has a real notion of correctness.
Rare Event Analysis of LLMs
ICML 2026
Rare Event Analysis starts from a deployment fact: events that never appear in a small benchmark can still occur at scale. The paper's first-principles move is to treat rare behavior as an estimable probability with methods such as Monte Carlo, MCMC, transition path sampling, and importance sampling. It shifts evaluation from "did we see the bad event?" to "how likely is the bad event under use?"
Pressure Reveals Character
ICML 2026
As an evaluation paper, Pressure Reveals Character asks how to measure model behavior under realistic social pressure. The benchmark is not only checking whether an answer is correct; it is checking honesty, non-manipulation, safety, corrigibility, and robustness under multi-turn pressure. That requires calibrated judging because the relevant behavior is a pattern across an interaction, not a single exact-match answer.
Gaia2, AstaBench, SimuHome
ICLR 2026
These papers represent dynamic agent evaluation. Gaia2 emphasizes action-level verifiers in asynchronous environments; AstaBench controls tools and cost while evaluating scientific agents; SimuHome measures smart-home agents where latency and environment awareness matter. Together they show why the new measurement unit is often a run trace: task, observations, actions, state changes, verifier result, and cost.

04. Efficiency as capability enabler

103 rows

The first-principles problem is that compute is part of the method. A system that needs unlimited memory, perfect precision, huge token budgets, and loose latency is not a deployed system. This is why efficiency appears as a capability theme, not just an engineering cleanup theme.

The papers divide into two styles. Some diagnose why cheap computation breaks: low-precision attention instability, quantized diffusion error propagation, compression-induced repetition. Others design methods that spend computation more intelligently: token merging, pruning, fractional bit-widths, low-rank adaptation, early exits, sparse experts, edge-cloud splits, and on-device training.

Numerical failure
Low-precision training, BF16 attention, quantized diffusion, and floating-point-aware theory all ask why apparently harmless arithmetic changes can destroy behavior. The point is that model capability rests on numerical pathways, not just architecture diagrams.
Memory and context pressure
KV-cache compression, token merging, video-token pruning, and tabular context compression all address the same bottleneck: the model sees too much. These papers try to preserve the high-value evidence while shrinking what must be stored or attended to.
Deployable adaptation
LoRA-style methods, sub-model extraction, PEFT, rank-wise assembly, and edge/on-device training ask how a model can be specialized without paying the full cost of updating or serving the whole model.
Why Low-Precision Transformer Training Fails
ICLR 2026
This is a first-principles efficiency paper because it explains failure rather than only reporting a faster setting. The paper traces flash-attention instability to low-rank attention representations and biased BF16 rounding behavior, especially around softmax pathways. Its broader lesson is that precision is not a passive implementation detail; the arithmetic can change the effective learning dynamics.
LiftQuant, CAT-Q, STAR-KV, EntroKV
ICML 2026
These papers attack the deployment envelope. LiftQuant explores fractional effective bit-width; CAT-Q and related post-training quantization work tries to keep extreme low-bit models usable; STAR-KV and EntroKV compress the memory-heavy attention cache. The common problem is not making models small for its own sake. It is preserving reasoning or multimodal capability when hardware forces lower precision and smaller memory footprints.
FlashVID, OmniFit, TACO
ICLR / ICML 2026
These papers treat context as a scarce resource. FlashVID merges redundant video tokens, OmniFit dynamically allocates token budgets across modalities and layers, and TACO compresses tabular context. The first-principles question is what evidence has marginal value for the task. Good compression is not deletion; it is preserving the information that will change the model's decision.
LoRA-Pre, FlexRank, SpineFL, LiME
ICLR / ICML 2026
The adaptation papers assume full retraining is usually the wrong unit of work. LoRA-Pre and related methods look for cheaper trainable subspaces; FlexRank and SpineFL select or assemble smaller useful components; LiME applies efficient modulation in multimodal MoE-style settings. The shared approach is to identify the part of the model that actually needs to move and leave the rest alone.
EcoVLA and SVL
ICML 2026
Embodied and 3D systems expose why efficiency is a capability question. A robot policy that reasons correctly but too slowly misses the moment; a 3D understanding model that needs too much power cannot run where the sensor data is produced. EcoVLA schedules pruning around real-time VLA inference, while SVL uses spike-based 3D vision-language pretraining to reduce energy cost. Both link compute budgets to action in the world.

05. Representation geometry

95 rows

The first-principles problem is that learned systems have internal structure, and that structure determines what they can generalize. If features are entangled, unstable, or poorly aligned with the task, the model may look strong on familiar data but fail under recombination, long context, new camera views, or causal shifts.

This theme is the bridge between theory and diagnosis. Papers study singular spectra, low-rank structure, latent manifolds, graph coordinate exchangeability, feature superposition, causal latents, activation norms, and representational phase changes. The goal is not only to describe geometry. It is to explain behavior that ordinary metrics miss.

Spectra and rank
Attention spectra, Jacobian spectra, low-rank logits, phase-retrieval dynamics, and spectral recovery papers ask which directions in representation space carry signal. This is the geometry of capacity: what the model can represent, recover, or ignore.
Latent structure
Causal representation learning, latent Fourier transforms, manifold gluing, quotient spaces, and object-centric latents try to recover variables that correspond to stable structure rather than accidental correlations.
Geometry as diagnosis
Hidden-state norms, temporal superposition, representation-coordinate exchangeability, and geometry-performance disentanglement use internal shape to explain behavior. The goal is to make model failure legible before it appears as a benchmark miss.
Temporal Superposition
ICLR 2026
Temporal Superposition studies how recurrent systems pack memories into representation space. The useful abstraction is that memory is not just stored or forgotten; it is arranged geometrically, sometimes densely and sometimes sparsely, with phase transitions as demand changes. That turns a vague question about "capacity" into a concrete question about feature angles, packing, and interference.
GraphGlue and GNN Exchangeability
ICLR 2026
Graph representation papers expose a basic difficulty: graph embeddings must remain meaningful even when node ordering, coordinate frames, or domains change. GraphGlue tries to integrate multiple local graph geometries into a smooth manifold; GNN Exchangeability studies invariance in trained embeddings. Both are about making representation spaces comparable rather than merely high-performing on one graph instance.
Linear Causal Representation Learning
ICML 2026
This paper uses environment heterogeneity to recover latent causal structure. The first-principles distinction is between representations that cluster observations and representations that separate causes. For deployment, the causal version matters more: when the environment changes, a model needs variables that track why outcomes happen, not only variables that correlated in the training distribution.
Single-Head Attention in High Dimensions
ICML 2026
This paper treats attention as a spectral object whose learned query-key structure determines generalization. Instead of using attention as a magic module, it asks which singular directions are recovered, in what order, and how that recovery affects test error. It is part of a broader conference move to explain scaling and generalization through representation geometry rather than only empirical curves.
The Tell-Tale Norm
ICML 2026
The Tell-Tale Norm shows how an internal magnitude can become a control signal for reasoning. Hidden-state L2 norm is used to guide recursion, steering, or response selection. The point is not that norm is a universal explanation; it is that internal geometry can provide operational signals unavailable from the output alone.

06. Scientific and physical-domain generation

79 rows

The first-principles problem is constrained creation. A generated protein, molecule, PDE field, physical video, or weather state is not useful because it is plausible to a neural net. It is useful only if it respects the rules of the domain well enough to survive downstream tests.

The approaches combine generative models with structure: symmetries, quotient spaces, coarse-to-fine physical descriptions, differentiable simulators, likelihood-correct flows, inverse-problem priors, and domain-specific validation. The deeper aim is to make generation a search instrument for science: propose candidates where brute-force enumeration or lab experimentation is expensive.

Symmetry and constraints
Quotient-space diffusion, molecular flows, feasible-set generation, and constrained engineering design all start from the same principle: the sample space should respect the invariances and restrictions of the object being generated.
Scientific solvers
PDE, neural operator, physical dynamical system, and differentiable simulator papers try to learn or accelerate the laws that govern a system. The target is not an image; it is a state trajectory, likelihood, or physically meaningful solution.
Search over hypotheses
Protein, molecule, binder, pathway, rare disease, and hypothesis-space papers use generation to search large scientific spaces where experiments are expensive. The model proposes; domain constraints and validation decide whether the proposal matters.
Protein Autoregressive Modeling
ICML 2026
Protein Autoregressive Modeling uses biological hierarchy as part of the generator design. Proteins are not flat token strings; they have coarse structural organization and fine geometric detail. The paper's conceptual move is to generate across scales, using coarse-to-fine prediction and a flow-based decoder so the method reflects the structure of the object being built.
Quotient-Space Diffusion Model
ICLR 2026
Quotient-Space Diffusion removes rigid-body symmetries from the learning problem. A molecule translated or rotated in space is not a different molecule, so a generator should not waste capacity modeling those degrees of freedom as if they were meaningful. This is a strong example of scientific inductive bias: define the correct sample space before training the model.
Frozen-PINN and IRNO
ICLR / ICML 2026
These solver papers attack the cost and stability of scientific computation. Frozen-PINN separates spatial random features from temporal coefficient solving to speed PDE training, while IRNO treats neural-operator inference as iterative residual refinement. Both show the same pattern: learned solvers must respect causal, spectral, and numerical structure or they become fast but scientifically weak.
PhyWorldBench
ICLR 2026
PhyWorldBench evaluates whether generated videos obey physical realism. That is important because a text-to-video model can produce visually impressive output while violating basic dynamics. The paper gives this theme a measurement anchor: physical generation should be judged by whether the output behaves like a world, not only whether frames look plausible.
HypoSpace, FIRE, TD3B, ReaSyn
ICML / ICLR 2026
This cluster points toward generative models as scientific search engines. HypoSpace samples underdetermined hypotheses, FIRE handles multi-fidelity regression, TD3B designs transition-directed binders, and ReaSyn refines synthesizable molecule pathways. The common pattern is propose-and-filter: use neural generation to navigate a vast space, then use scientific constraints to decide what is worth taking seriously.

07. Data governance and curation

78 rows

The first-principles problem is that data is no longer a neutral input. It has origin, rights, contamination risk, distributional bias, training-phase value, and failure modes. Once models become expensive and widely deployed, "we trained on a pile" stops being acceptable science.

This theme has two sides. Governance asks whether data can be used: provenance, license, privacy, filtering, split integrity, export permissions. Curation asks whether data should be used: which examples help, which harm, which bridge training phases, which produce robust reasoning, and which merely inflate scale.

Legality and provenance
Common Corpus, ADP-style trajectory provenance, copyright compliance, memorization suites, and privacy adaptation rows ask whether a dataset can be traced, justified, and reused. The problem is institutional as much as statistical: models inherit the legal and ethical status of their sources.
Data as training control
DiReCT, midtraining bridge work, annealing selection, repeated-data scaling, and reasoning recipe experiments treat data choice as an intervention on optimization. An example's value depends on training phase, model state, and objective, not just label correctness.
Quality over volume
Difficult-example analysis, harmful-example removal, dataset fidelity metrics, structural tabular measures, and contamination controls reject the naive assumption that more data is always better. The question is which examples improve the model's future behavior.
Common Corpus
ICLR 2026
Common Corpus is the governance branch of the theme. It treats an open pretraining corpus as infrastructure whose sources, licenses, filters, and provenance have to be documented. The paper's first-principles contribution is that a dataset is not only a statistical sample; it is an artifact with rights, traceability, and reproducibility obligations.
OpenThoughts
ICLR 2026
OpenThoughts represents data curation as controlled recipe design. Reasoning examples are generated, filtered, compared, and scaled across many experiments. The point is not that reasoning data exists; it is that the production process shapes the model. The dataset becomes a pipeline with knobs, ablations, and quality checks.
Difficult Examples Hurt Unsupervised Contrastive Learning
ICLR 2026
This paper directly challenges the idea that every hard example is valuable. Under a particular unsupervised contrastive objective, difficult examples can worsen generalization, and removing them can improve downstream performance despite reducing dataset size. The broader lesson is that data quality is objective-dependent: an example can be informative for humans and harmful for a training signal.
DiReCT and Midtraining Bridges Pretraining and Posttraining
ICML 2026
These papers treat data as an optimization control surface. DiReCT selects annealing data using gradient and Hessian geometry; Midtraining Bridges asks when specialized data helps bridge pretraining and posttraining targets. Both replace domain-filtering folklore with a sharper idea: data should be chosen for the transition it causes in the model.
OXE-AugE
ICML 2026
OXE-AugE shows the same governance and curation problem in robotics. Robot datasets are not interchangeable piles of trajectories; they encode embodiment, gripper type, camera configuration, task family, and demonstration balance. The paper's reported gains from rebalancing embodiment diversity make a concrete point: data composition determines transfer, especially when the deployment robot differs from the training robots.

08. LLM agents and process diagnostics

74 rows

The first-principles problem is that an agent is a trajectory. It observes, plans, acts, calls tools, receives feedback, retries, and sometimes learns the wrong lesson. A final answer collapses all of that into one bit. The conference evidence says that is no longer enough.

The key approaches are diagnostic: detect template collapse, measure reward signal quality, identify low-effort verifier passing, inspect planning artifacts, compare tool-use loops, and study modular agent architectures. This theme is about making process visible so that success and failure can be explained rather than merely counted.

Collapse and shortcut signals
RAGEN-2, TRACE Effort, reward-hacking rows, and reasoning-effort diagnostics ask whether the agent is solving the task or producing behavior that only looks like solving. The field is trying to separate genuine process from verifier-passing theater.
Tool and environment loops
AstaBench, Gaia2, AgentFlow, Browser and security rows, and production-agent studies treat tool use as a structured loop: observe, choose, act, receive feedback, repair. The failure surface includes bad observations, wrong tools, loops, environment errors, and cost.
Agent architecture
Planner-executor-verifier systems, memory modules, reflection loops, and rational question-asking papers imply that agent behavior is easier to improve when the internal roles are visible and separately testable.
RAGEN-2
ICML 2026
RAGEN-2 identifies template collapse in agentic RL: the agent produces reasoning-looking text that becomes input-agnostic boilerplate. The important distinction is between entropy in outputs and information about the specific input. A trace can look busy while carrying little task-specific signal. That makes process diagnostics necessary even when reward curves appear to improve.
TRACE Effort
ICLR 2026
TRACE Effort asks whether verifier success arrives before the reasoning trace contains enough work to plausibly solve the task. It is aimed at detecting low-effort success and implicit reward hacking. The paper fits this theme because it treats success as suspicious until the process provides enough evidence that the model solved the intended problem rather than finding a shortcut.
AgentFlow
ICLR 2026
AgentFlow decomposes live tool use into planner, executor, verifier, generator, and memory modules. The conceptual bet is that agent failure becomes diagnosable when these roles are separated: did the plan fail, did execution fail, did verification miss something, or did memory corrupt the next step? It is an architecture paper, but its deeper contribution is observability of process.
AstaBench
ICLR 2026
AstaBench evaluates scientific research agents with controlled tools, costs, interfaces, and baselines. It belongs in process diagnostics because a research-agent run is shaped by tool access and workflow, not only model intelligence. The benchmark asks whether the agent can use search and scientific tools in a reproducible way while controlling confounders that would otherwise make model comparisons meaningless.
Rational Agents
ICLR 2026
Rational Agents models question asking and action selection through expected information gain. This is a process paper because exploration is not treated as a vague behavior; it is a decision problem under uncertainty. The agent should ask or act when the expected value of information justifies the cost, which connects human-like exploration to a measurable computational principle.

09. Alignment, preference optimization, and feedback

66 rows

The first-principles problem is learning from imperfect signals about what humans or task verifiers want. Feedback is sparse, noisy, inconsistent, expensive, and often easier to exploit than to satisfy. The field is trying to build objectives that preserve the intent of feedback as models become more capable.

The approaches include reward models, direct preference optimization variants, semi-supervised preference learning, hybrid sparse-verifier plus dense-reward systems, one-to-many teaching alignment, scaling laws for RL, and capability-conditioned objectives. The shared tension is between correctness and preference: hard checks are reliable but sparse; dense scores are useful but easier to misread.

Sparse truth plus dense feedback
HERO, RLVR, verifier-reward hybrids, and reward normalization papers try to combine hard correctness with softer shaping signals. The core challenge is preventing dense reward from overriding the sparse check that actually defines success.
Preference noise
DPO variants, semi-supervised preference optimization, ordinal reward learning, and human-feedback interpretation papers confront the fact that preferences are limited, biased, and inconsistent. The approach is to model the feedback channel rather than pretending labels are clean.
Context-specific alignment
Clinical teaching, one-to-many alignment, safety DPO, capability-conditioned SFT, and pressure-alignment work show that desired behavior depends on user state, task domain, and model strength.
HERO
ICLR 2026
HERO combines sparse correctness checkers with dense reward-model scores. The paper sits at the center of the alignment tradeoff: hard verifiers define real success but provide limited learning signal, while dense reward models provide gradients but can drift away from correctness. HERO's stratified normalization is an attempt to let dense feedback help inside verifier-defined groups without letting it redefine the task.
ScaleRL
ICLR 2026
ScaleRL treats LLM reinforcement learning as a predictable scaling problem rather than a bag of recipes. By fitting compute-performance curves, it asks how post-training gains depend on budget and whether improvements come from better compute efficiency or higher asymptotic performance. That matters because alignment methods will be deployed under fixed training budgets, not idealized unlimited RL.
Beyond Log Likelihood
ICML 2026
Beyond Log Likelihood argues that the right objective depends on model capability. A weak model may need standard likelihood training to imitate the supervision, while a strong pretrained model may be harmed by over-weighting low-probability noisy tokens. The first-principles point is that post-training is not generic imitation; it is steering an existing model with its own prior and competence.
ClinTutor-R1
ICML 2026
ClinTutor-R1 shows alignment in a clinical teaching setting, where the right behavior is not simply answering a medical question. The model must track individual trainee beliefs, group consensus, and the pedagogy of Socratic instruction. This is a useful reminder that alignment often means fitting behavior to a role and relationship, not maximizing a universal helpfulness score.
Semi-supervised preference optimization papers
ICLR / ICML 2026
The semi-supervised preference papers attack the cost and sparsity of human feedback. The challenge is to let a small amount of labeled preference information shape a larger unlabeled or weakly labeled distribution without amplifying annotation noise. Conceptually, these papers treat feedback as a limited measurement channel that must be modeled and extended carefully, not as an infinite supply of ground truth.

10. Reinforcement learning

64 rows

The first-principles problem is learning when examples are not enough. If a model must solve long-horizon tasks, interact with environments, improve through attempts, respect safety constraints, or learn from verifiable rewards, then the training signal comes from consequences.

The field is not returning to old RL in a simple way. It is mixing RL with language models, verifiers, curricula, diffusion policies, world models, preference rewards, and safety constraints. The hard part is credit assignment: which part of a long process caused the outcome?

Verifier-driven RL
RLVR, HERO, noisy-verifier studies, and reasoning curricula use checkable outcomes as rewards. The core issue is whether the verifier teaches the intended skill or merely creates a game the model can exploit.
Long-horizon credit
h1, HDFlow, safe RL recovery, partner curricula, and embodied-control papers all wrestle with delayed consequences. The reward arrives late, so the method needs a way to identify which choices created success or failure.
Generative policies
Diffusion policies, flow policies, latent action models, and world-model rollouts treat action generation as structured sampling. Instead of selecting from a small action set, the policy generates feasible behavior under constraints.
h1
ICML 2026
h1 uses long-horizon reasoning curricula built from dependency chains and outcome-only rewards. The central question is whether RL can teach new reasoning paths or only pull out capabilities already latent in the base model. The paper matters because it treats reasoning as a trainable process over horizon length, not just as a prompt style.
DMPO for diffusion LLMs
ICML 2026
DMPO adapts reinforcement learning to diffusion language models, whose generation process is not left-to-right autoregression. That changes the policy object and the update path. The paper's broader role is to show that post-training algorithms cannot be assumed to transfer unchanged across model families; the generative process itself determines what RL should optimize.
CSPO
ICML 2026
CSPO is safe RL focused on recovery dynamics, violation frequency, and reward preservation near constraints. The important idea is that safety is not captured by final return alone. A policy may eventually satisfy a constraint but spend too much time violating it, or it may recover safely while destroying task reward. CSPO measures the path back to safety as part of the objective.
Unsupervised Partner Design
ICML 2026
Unsupervised Partner Design frames ad-hoc teamwork as a curriculum problem. The learner improves by facing partners generated and selected for learnability, not by training against a fixed population. The broader principle is that the environment includes other agents, and the right training distribution may be one that changes in response to the learner.
Diffusion policy and generative RL papers
ICLR / ICML 2026
The generative RL cluster treats policies as samplers over structured behavior: trajectories, subgoals, latent actions, feasible combinatorial choices, or continuous controls. This is different from old discrete-action RL. The policy has to generate something valid in a constrained space, and learning must shape the distribution of possible futures rather than only choose the next token or action.

11. Interpretability as intervention

56 rows

The first-principles problem is control through understanding. It is not enough to explain a model after it fails. If an internal signal identifies a failure mode, the field now wants to steer, repair, detect, or prevent that failure using the signal.

The approaches include activation steering, hidden-state norm control, attribution-graph verification, concept-level evidence, probes for unsafe internal states, mechanistic VLM failure tracing, and causal feature recovery. The theme is practical interpretability: mechanisms become handles.

Internal control signals
Hidden-state norms, activation steering, prompt-effect distillation, and model diffing all ask whether internal states can guide inference or behavior. The mechanism becomes a runtime input, not merely an explanation after failure.
Reasoning repair
CRV, attribution-graph methods, concept-verifier games, and circuit-guided interventions use internal structure to identify and fix reasoning errors. This turns interpretability into a repair loop.
Safety and perception auditing
Visual-symbolic mechanism studies, activation oracles, deepfake reasoning, and multimodal consistency work show that internal analysis can reveal failures hidden by fluent outputs or plausible images.
The Tell-Tale Norm
ICML 2026
The Tell-Tale Norm uses hidden-state L2 magnitude as a signal for reasoning intensity and response selection. The first-principles move is to look for a model-internal quantity that correlates with when more computation or different steering is useful. This turns interpretability into inference control: the model's own state helps decide how the model should be run.
Steer Like the LLM
ICML 2026
Steer Like the LLM distills prompt-induced behavior into activation interventions. Instead of repeatedly using a natural-language prompt to create a behavioral shift, the method learns the internal change associated with that prompt. The conceptual question is whether prompt steering can be made more direct, inspectable, and controllable by operating at the activation level.
CRV
ICLR 2026
CRV verifies chain-of-thought reasoning through computational graphs and then uses circuit-guided repair. The point is that a reasoning trace should have structural fingerprints of a valid computation. If the graph shows a faulty pattern, the intervention can target the mechanism rather than rewriting the whole output. This is interpretability as a debugging tool for reasoning.
Visual symbolic mechanisms
ICLR 2026
This work traces visual-language binding errors to internal mechanisms for object identity and spatial position. It matters because multimodal failures often look like semantic mistakes but originate in how visual tokens are bound or retrieved. The paper makes interpretability concrete by connecting a visible VLM bug to a mechanism that can be studied and potentially fixed.
Activation Oracles and Trojan-Speak
ICML 2026
These papers use internal activations for safety auditing when surface behavior may be misleading. Trojan-Speak studies models that evade content classifiers after adversarial fine-tuning; activation-level methods look for harmful representations underneath benign outputs. The shared principle is that monitoring text alone is not enough when the model can separate internal state from external presentation.

12. Generative modeling

51 rows

The first-principles problem is controllable synthesis. Generation has expanded from text and images into 3D scenes, videos, speech, molecules, proteins, physical trajectories, and decision policies. The model must not only produce something likely; it must produce something usable under constraints.

The approaches are diverse: diffusion, flows, autoregression, next-token image/video models, structured latent spaces, watermark-preserving noise, few-step likelihood-correct samplers, safety guidance, and geometry-aware sample spaces. The connecting thread is control over what is generated and how it can be verified.

World and media generation
FlashWorld, VibeVoice, EditVerse, NextStep-1, long-video systems, and speech/audio-language models broaden generation from isolated artifacts to coherent scenes, conversations, edits, and temporal media.
Likelihood and inference
FALCON, flow models, reversible solvers, and Boltzmann-generator work ask whether generated samples can support probability estimates, thermodynamics, or inference, not just visual inspection.
Safety and controllability
Spherical Watermark, SGF, safe denoising, concept suppression, and constrained diffusion work embed control into the generation process itself so unsafe or unverifiable outputs are less likely to appear.
FlashWorld
ICLR 2026
FlashWorld moves from 2D or multiview image generation toward direct coherent 3D scene representations. The important shift is that a generated world must be consistent across views and usable as a scene, not merely impressive as a collection of images. It represents the branch of generative modeling where the output is a spatial substrate for later perception, editing, or action.
VibeVoice and UALM
ICLR 2026
VibeVoice and UALM show generation extending into long-form speech and unified audio-language systems. The hard part is not producing sound in isolation; it is maintaining speakers, turns, semantics, and multimodal reasoning over time. These papers broaden generation from a single artifact to a structured communicative process.
FALCON and flow-model papers
ICLR / ICML 2026
FALCON and related flow papers try to make generated samples useful for probabilistic inference. A beautiful sample is not enough if the likelihood is wrong and downstream thermodynamic or molecular estimates become biased. This subtheme ties generation to quantitative science: samples should carry probabilities accurate enough to support estimation, not only inspection.
Spherical Watermark and SGF
ICLR 2026
These papers put control inside the generation process. Spherical Watermark embeds provenance into diffusion latent noise while trying to preserve the prior, and SGF uses guidance to push generation away from unsafe regions. The first-principles idea is that safety and provenance are stronger when they are part of sampling, not bolted on as after-the-fact filters.
Protein and molecule generators
ICLR / ICML 2026
Protein and molecule generation papers represent the scientific edge of generative modeling. They cannot be judged by resemblance alone because the output must fold, bind, synthesize, or satisfy chemical constraints. This pushes generative modeling toward domain-grounded validity: the generated object has to survive tests imposed by biology, chemistry, and physics.

What the remaining themes add

Theory and optimization

The largest long-tail cluster. It supplies the mathematical language for why methods work: high-dimensional certification, minimax rates, Jacobian spectra, posterior correction, feasible projections, and transformer algorithm circuits.

Systems and infrastructure

This is where models become machinery: tensor DSLs, sparse CUDA kernels, KV-cache reuse, speculative agent execution, tool-use trajectory formats, production-agent governance, and serving constraints.

Long context and inference control

These papers treat inference as an active allocation problem: where to spend compute, how to extend position encodings, how to cache reasoning, when to stop, and how to use model-internal signals.

Reasoning, planning, and tool use

Separate from agent diagnostics, this cluster asks what capabilities a model needs: asking useful questions, using tools, repairing reasoning, retrieving across steps, and composing short tasks into long chains.

Software and code intelligence

Small in row count but strategically important: CVE generation, compiler optimization, synchronization reasoning, jailbreak automation, and root-cause discovery show code as an executable domain, not a text domain.

Scientific and healthcare ML

These papers bring the same system pressures into medicine, biosignals, brain modeling, clinical education, and biomedical reasoning: accuracy matters, but so do provenance, safety, and domain validation.

The conference read in one paragraph

ICML/ICLR 2026, through this local index, reads like a field leaving the clean-room era. The center of gravity is not a single model family. It is the engineering and science of making learned systems hold together when the task has structure: visual structure, physical structure, data provenance, safety boundaries, feedback loops, hardware limits, long-horizon processes, and verifiable outcomes. The papers differ, but the shared movement is from "make a model that predicts" to "make a system whose behavior can be grounded, checked, compressed, governed, and improved."
