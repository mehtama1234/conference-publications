FIRST PRINCIPLE

A Method Works When It Removes The Right Difficulty

A good explanation starts like a repair job. If a door will not close, the useful explanation is not "new hinge module"; it is whether the door is warped, the frame is crooked, the latch is blocked, or the screws are loose. Math papers work the same way. The method helps only if it removes the real obstacle.

Each sketch below names one recurring obstacle in plain words first: fake differences, impossible choices, missing memory, noisy scores, rare bad cases, hidden signal, dangerous movement, bad sample paths, uncertain causes, unchecked claims, people reacting to rules, or hidden control handles. The formal label appears after the everyday idea is already clear.

SKETCH 01

Same Thing, Different Wrapper

Everyday problem. A chair is still the same chair if you move the camera, rotate the photo, or rename the file. A learner wastes effort if it treats those wrappers as different objects.

What stays the same. The object identity and the answer should stay fixed. Only the wrapper changes: viewpoint, position, node names, prompt wording, or coordinate frame.

Move. Group all wrapper-changed copies together and learn from the group as one thing. The formal name is invariance; the group is an equivalence class or quotient space.

if y(x) = y(gx) for g in G, learn on quotient space X / G instead of X

Why It Works

The model stops spending examples on fake differences. One example can teach every wrapper of the same object, so evidence goes further.

Papers

Quotient-Space Diffusion, Camera-Aware MLLM, GraphGlue, protein generation, transformer clustering circuits, TideGS/RadioGS.

Breaks When

The wrapper is not fake. Orientation may matter near a binding site; viewpoint may matter when camera geometry is part of the task.

SKETCH 02

Allowed Choices Change The Search

Everyday problem. If you are planning dinner for someone with allergies, the best-tasting recipe is not enough. The recipe has to be allowed before taste matters.

What stays the same. The output must remain legal, safe, physically possible, chemically makeable, fair under the chosen rule, or executable by the robot.

Move. Search only inside the allowed set instead of searching everywhere and filtering afterward. The formal name is feasibility or constrained optimization.

solve maximize reward(x) subject to x in C, not maximize reward(x) then filter invalid x

Why It Works

The system cannot win by finding a high-scoring forbidden answer. The forbidden area is removed from the search itself.

Papers

Pi-net, CSPO, Copyright-Bench, ReaSyn, MORetro*, Fair OT, Robust Contextual Optimization, PACT, HDFlow.

Breaks When

The allowed set is drawn wrong: too loose, too strict, or written in a description that misses the real-world rule.

SKETCH 03

Kept Notes Preserve The Next Decision

Everyday problem. You do not need an entire meeting transcript if a short action list keeps every fact needed for tomorrow's work.

What stays the same. The future decision must be the same as it would have been with the full history.

Move. Replace the long history with saved notes, cache, memory, trace summary, or hidden code that keeps the needed facts. The formal name is sufficiency or sufficient state.

P(y | history) = P(y | state); then history can be replaced by state for target y

Why It Works

The system spends less memory and compute while keeping the facts that would change the next answer or action.

Papers

ThinKV, STAR-KV, EntroKV, DLMR, Skill-Pro, VideoKR, Mamba Markov ICL, RAGEN-2, IRNO.

Breaks When

The notes keep common facts but drop the rare clue that matters later.

SKETCH 04

A Score Has To Still Mean The Target

Everyday problem. A bathroom scale is useful only if it is actually measuring weight, not a tilted floor or a weak battery.

What stays the same. The score must continue to reflect the hidden thing we care about: skill, safety, factuality, usefulness, expert correctness, or artifact quality.

Move. Treat the benchmark, judge, rubric, expert label, or artifact check as a measuring instrument with noise and blind spots. The formal name is a measurement channel.

observed score = target signal + noise + judge bias + task artifact

Why It Works

The evaluation can say what it actually saw and how much doubt remains instead of pretending the number is direct truth.

Papers

ATLAS, FRABench, UFEval, JudgeBench, WebDevJudge, CounselBench, MADQA, Seizure-Semiology-Suite.

Breaks When

The measuring tool watches the wrong thing, blends unlike skills into one average, or rewards a shortcut that looks like ability.

SKETCH 05

Tail Sampling Makes Rare Risk Visible

Everyday problem. A city cannot judge flood safety by looking only at sunny days. The dangerous day is rare, but it is the day that matters.

What stays the same. The final risk estimate must still describe real deployment, not an artificial stress test by itself.

Move. Visit the dangerous region more often, then correct the count back to the real-world rate. The formal name is tail sampling or importance sampling.

P(E) = E_Q[1{Y in E} * p(Y) / q(Y)]

Why It Works

Testing time is spent where failures can actually appear. The correction step keeps the final number tied to the real world.

Papers

Rare Event Analysis, Tail Risks, Control Consistency Losses, SandboxEscapeBench, Jailbreak Foundry, FALCON, SRMC.

Breaks When

The stress test looks in the wrong dangerous place, misses another failure route, or uses correction weights so unstable that the risk number cannot be trusted.

SKETCH 06

Useful Signal Must Rise Above Noise

Everyday problem. In a crowded room, you can follow a song only if the melody is louder or clearer than the background noise.

What stays the same. The useful pattern must remain visible when the data changes slightly, rather than being a random quirk of one sample.

Move. Break the model's numbers into main directions and check whether the target pattern lives in directions that stand apart from noise. The formal name is spectral visibility; the directions are singular or eigen directions.

recover signal when leading direction separates from noise bulk by a stable gap

Why It Works

Limited data can recover clear patterns more reliably than buried ones. If the target lives in the clear pattern, the model needs less evidence to learn it.

Papers

Alignment-Sensitive Minimax Rates, Single-Head Attention, BBP Transitions, Low-Rank LM Logits, SVD Interpretability, DiReCT, LoRA Theory.

Breaks When

The visible direction changes under small data changes, or the loudest direction is only a dataset artifact.

SKETCH 07

Training Movement Needs The Right Ruler

Everyday problem. One step on a flat sidewalk and one step near a cliff are not equally safe, even if the step length is the same.

What stays the same. The model should move enough to learn the target behavior while preserving capabilities that must not be damaged.

Move. Judge training movement by the ruler the optimizer and deployment system actually use: which directions are steep, fragile, cheap, low-rank, rounded by hardware, or protected by a trust region. The formal name is update geometry.

theta_{t+1} = theta_t + Delta theta, with the step limited by a movement ruler M, a small allowed update family r, local steepness H, or a stay-nearby KL radius

Why It Works

The method can allow useful movement while blocking movement through fragile directions.

Papers

Adam Degeneracy, DiReCT, LoRA Theory, Trust-Region LLM RL, Beyond Muon, Non-Euclidean Edge of Stability, RAIN-Merging.

Breaks When

The ruler is wrong: it misses deployment risk, overreacts to noisy steepness estimates, or protects the wrong behavior.

SKETCH 08

The Making Path Shapes The Output

Everyday problem. Bread is not judged only at the end. The kneading, rising, and baking path decide whether the loaf works.

What stays the same. The final output should keep the intended quality, diversity, safety, likelihood, or scientific quantity.

Move. Control the route taken while samples are being formed, not only the finished sample. The formal name is transport, flow, bridge, or sampler path.

p_t evolves by vector field, denoising update, bridge, or reward-tilted transition toward p_target

Why It Works

Bad routes can lose rare possibilities, enter unsafe areas, or carry early numerical mistakes into the final output. Controlling the route catches those failures earlier.

Papers

DMPO, FALCON, Safety-Guided Flow, Cauchy Bridges, GWF, MMOT/Schrodinger Bridges, Quantized Diffusion.

Breaks When

The route no longer leads to the intended target, skips valid kinds of outputs, or hides growing errors until the endpoint.

SKETCH 09

Cause Claims Must Not Outrun Evidence

Everyday problem. If a wet floor could come from a leak, a spilled bucket, or an open window, the puddle alone does not prove which story happened.

What stays the same. The claim must be true across every story the evidence has not ruled out.

Move. Say only what all still-possible stories agree on, or report the set of stories still possible. The formal name is identification; the unresolved set is an equivalence class or identified set.

claim c is identified if c(w) is constant for all w in W(data, assumptions)

Why It Works

The method separates what the evidence proves from the story we wish were true.

Papers

Distributional Equivalence, Local Covariate Selection, Structure Learning CI, DiCoLa, Unpaired Causal IV, BRCD, Latent Hawkes, CausalGame.

Breaks When

An assumption is wrong, the test is too weak, or the method quietly chooses one story even though several still fit.

SKETCH 10

A Claim Needs Something Checkable

Everyday problem. A receipt is more useful than someone saying "I paid." It gives another way to check the claim.

What stays the same. The claim must survive a check outside the model's own fluent explanation.

Move. Attach the answer to something that can be inspected or run: code execution, a proof, a rendered page, a deletion test, or a finite-sample uncertainty report. The formal name is verification or certification.

accept claim only if verifier V(artifact, assumptions, observation channel) passes

Why It Works

The evaluator does not have to trust persuasive text. It can reject the artifact where failure would actually show up.

Papers

CyberGym, VERINA, WZ-LLM, PaperBench, WebDevJudge, OmniVerifier, Gaussian Certified Unlearning, Finite Test Certification.

Breaks When

The checker watches the wrong object, is too narrow, is easy to game, or certifies a stand-in condition instead of the real claim.

SKETCH 11

Rules Change How People Act

Everyday problem. If a store changes its return policy, customers and employees change behavior. The rule is part of the system, not an afterthought.

What stays the same. The desired outcome should remain acceptable after people, agents, attackers, markets, or groups react to the rule.

Move. Model the actors, what they know, what they want, what actions are allowed, and how they respond. The formal name is a game or mechanism.

choose mechanism M so responses pi_i form acceptable outcomes under incentives and constraints

Why It Works

The method does not pretend everyone stays still. It designs for the responses the rule will create.

Papers

AdvGame, OMAC, Accuracy Auctions, Data Market Pricing, Fair Causal Bandits, Constrained Nash, MASPOB, Value of Variance.

Breaks When

The actors want different things, know different facts, coordinate secretly, or adapt faster than the design expects.

SKETCH 12

A Hidden Handle Can Make Control Easier

Everyday problem. It is easier to adjust room temperature with a thermostat than by opening walls and moving wires. The thermostat is a compact handle for a hidden system.

What stays the same. The handle must still control the intended concept when the topic, person, image, task, or environment changes.

Move. Find an internal code, token, slot, brain-signal translation, or model direction that changes the intended behavior locally. The formal name is a latent interface or activation direction.

find z = f(x) so target-relevant changes are sparse, stable, or causal in z

Why It Works

When the right handle is exposed, the system can be steered without rewriting the whole input or retraining the whole model.

Papers

Steer Like The LLM, The Tell-Tale Norm, MINT, Causal Route Gating, Mind-Omni, PRISM, CompSLOT, LatentLM, UALM.

Breaks When

The handle changes several things at once, works only in the training setting, or tracks an easy shortcut instead of the intended concept.

BIG PICTURE

How To Use These Sketches

When reading any new paper, ask the plain question first. What is being kept the same? What is being changed? What exact difficulty is being removed? Only after that should the formal label matter.

The approach is credible when the evidence tests the exact promise used by the sketch. Otherwise the paper may still be useful, but the reason it works has not been shown.
