Preserve and Sculpt: Manifold-Aligned Fine-tuning of Vision-Language Models for Few-Shot Learning

MPS-Tuning fine-tunes a vision-language model for few-shot classification while explicitly preserving the original pattern of distances and directions between features, then sharpening class separation inside that preserved structure.

Paper explainersAll themesOther

Few-shot transfer starts from a pretrained vision-language model such as CLIP because the pretrained features already encode broad visual semantics. The difficulty is that ordinary fine-tuning can damage that structure quickly when only a handful of labeled examples are available. This paper treats the pretrained pattern of pairwise feature relations as the object that must be protected during adaptation. MPS-Tuning does two jobs at once: it preserves the large-scale and local relations among features before and after fine-tuning, and it reshapes image-text similarities so classes become easier to separate. The result is a fine-tuning procedure that improves task accuracy because it keeps the pretrained relations that support transfer instead of letting the small dataset rewrite them freely.

Zero assumption version

Few-shot fine-tuning often damages the pretrained feature structure

A pretrained vision-language model maps images and text into a shared feature space where semantically related items already sit in useful relative positions. In few-shot classification, the training set for the new task is tiny, so each example carries a large share of the update signal and the model can overreact to those few examples. A standard fine-tuning loss mainly rewards correct class decisions on the support set. That objective can move features enough to fit the small dataset while distorting the broader semantic organization learned during pretraining.

That distortion matters because classification in a low-data regime depends on more than the boundary between the labeled classes. The model also needs the neighborhood relations among examples, the distances between coarse semantic groups, and the consistency between image and text representations. If those relations drift, the model may fit the seen samples but lose the general structure that supports transfer.

The paper's move. Constrain fine-tuning so the pattern of distances and directions between features stays aligned before and after adaptation, then optimize image-text similarities to make classes more separable inside that preserved structure.

The algorithm as a flow

What it actually does

Extract pretrained features before adaptation.

Compute image and text feature outputs from the original model so they serve as the reference pattern during fine-tuning.

Form Gram matrices at multiple scales.

Build pairwise inner-product summaries that capture how examples relate to one another globally and locally in feature space.

Fine-tune while aligning those Gram matrices.

Penalize deviations between the pretrained and tuned pairwise relations so the adapted features do not drift arbitrarily.

Optimize paired image-text similarities.

Use cross-modal pairing to increase within-class agreement and reduce confusion between different classes.

Use the adapted features for few-shot classification.

Class predictions come from a representation that changed enough to fit the task but not enough to lose its pretrained organization.

What the paper changes

What the paper changes

The paper changes the fine-tuning objective. Instead of optimizing only task discrimination, it adds an explicit preservation term based on matching Gram matrices, which are tables of pairwise feature inner products, and a class-sculpting term based on image-text pair similarities.

The hidden quantity

The hidden quantity

measured quantity  =  the pattern of feature relations that survives adaptation

The hidden quantity is the structure of pairwise relations among features. A classifier only exposes final class scores, but transfer quality depends on whether the adapted feature space still preserves which examples are close, which groups are far apart, and how image and text feature outputs line up.

MPS-Tuning monitors that hidden quantity through pairwise-relation tables called Gram tables. A Gram table is a table of pairwise inner products among feature lists. If two feature sets have similar Gram tables, they preserve similar relational structure even if the coordinates themselves shift. By aligning Gram tables before and after fine-tuning, the method constrains both coarse topology and local neighborhood relations. The paper further argues that this alignment approximates an upper bound on Gromov-Wasserstein distance, which is a way to compare relational structure across spaces.

Why it works

Why preserving feature relations plus class sculpting works

Few-shot fine-tuning fails when the optimization uses a tiny labeled set to rewrite a representation that was learned from a much broader pattern of data variation. Alignment of Gram tables resists that rewrite because it adds a cost whenever tuning changes many pairwise relations at once. Since pairwise inner products summarize angles and relative placement among features, matching those summaries limits destructive drift in the representation.

That alone would preserve the old space but might not improve the new task enough. The second part of the method addresses that issue by optimizing paired similarities between image and text features. Positive pairs from the same class are encouraged to agree more strongly, while mismatched pairs are separated. This reshapes the representation in a targeted way: the adjustment is driven by label information and cross-modal semantics, but it happens inside the geometric constraints imposed by the alignment term.

The two terms therefore play complementary roles. The preservation term maintains the broad semantic organization that supports transfer. The sculpting term uses the scarce labels efficiently by spending the allowed movement on class-relevant directions rather than arbitrary drift. That combination is exactly what few-shot adaptation needs.

Math after the picture

Preserve relations, then sharpen classes

First in words:

The objective combines task discrimination, Gram-matrix preservation, and paired similarity sculpting. The preservation term compares pairwise relations before and after tuning, while the sculpting term strengthens matched image-text pairs and weakens mismatched ones.

Then the compact form:

L_total = L_task + lambda_g * ||G_pre - G_tuned|| + lambda_s * L_pair

Every symbol:

L_taskthe ordinary few-shot classification objective on the labeled support set
G_preGram matrix built from pretrained features before adaptation
G_tunedGram matrix built from tuned features during adaptation
||G_pre - G_tuned||a measure of how much pairwise feature relations changed
L_pairthe term that increases similarity for matched image-text pairs and decreases it for mismatched pairs
lambda_g, lambda_sweights that balance relation preservation against class sculpting
A tiny worked example
Suppose a pretrained model maps six bird images and six text prompts into features where two sparrow examples already sit close together, and sparrows sit farther from owls.
Naive few-shot tuning on four labeled bird images improves the support-set accuracy but moves one sparrow closer to the owl cluster because the small training set overfits.
With MPS-Tuning, the Gram table records that the two sparrows were strongly aligned before tuning, so separating them now adds preservation loss.
At the same time, the paired similarity term increases agreement between each sparrow image and the sparrow text prompt while reducing agreement with the owl prompt.
The final features keep the original neighborhood pattern and still make the class boundary sharper for the new task.

The exact paper objective may use multiple Gram terms for different scales, but the central idea is that adaptation is rewarded only when it preserves relational structure and improves class discrimination together, because either goal alone is insufficient in the few-shot setting.

What can go wrong

What can go wrong

Preserving too much can block useful adaptation. If the relation-preservation weight is set too high, the model may stay too close to the pretrained representation and fail to learn the new task adequately.
A poor pretrained relation pattern is still a poor starting point. The method assumes the original feature space is worth preserving. If pretraining encoded the target domain badly, keeping that relation pattern can limit downstream performance.
Pairing quality matters. The sculpting term relies on correct image-text pairing or prompt design. Weak prompts or ambiguous pair construction reduce the benefit of the class-separation step.
Done right. Use the preservation term to prevent drift, then tune the pairing term so the representation changes mainly along directions that are genuinely helpful for the target classes.
What a runnable demo should prove

What a runnable demo should prove

Take a pretrained CLIP-style model and a few-shot image classification benchmark with prompt text for each class. Compare three settings: zero-shot prediction, ordinary fine-tuning on the few-shot support set, and MPS-Tuning with preservation of Gram tables plus paired similarity sculpting.

The demo should record not only classification accuracy but also how much the pairwise feature relation pattern changed before and after adaptation. A convincing result shows that MPS-Tuning improves task accuracy because it changes class-relevant similarities while keeping the feature relation matrices much closer to the pretrained ones than ordinary fine-tuning does.
