Scalable Correlation Modeling for Link Sign Prediction

Model which edges in a signed graph point to positive or negative relationships by representing edge-edge dependencies as a compact matrix of edge embeddings, not an intractable full correlation table.

Paper explainersAll themesGraph & Geometric Learning

In networks where relationships can be positive (friendly, similar) or negative (rival, opposite), predicting whether a new edge will be positive or negative is harder than standard link prediction. Signed graphs break the usual graph assumption that neighbors are alike. Modeling how edges relate to each other can reveal these sign patterns, but naively tracking all edge-to-edge connections becomes computationally impossible even on moderate graphs. This paper makes it tractable by representing the correlation table as a compact product of learned edge numbers (a Gramian).

Zero assumption version

Predicting edge signs in networks where similarity breaks down

In a standard social network, linked people tend to be similar: friends have similar interests, neighbors share similar beliefs. Graph neural networks use this homophily assumption (adjacent nodes are alike) to predict missing links or link properties. But in signed networks, the opposite can matter: rivals and enemies are linked precisely because they differ or oppose each other.

A naive approach adds negative edges to the graph and trains a standard graph model. It fails because the model expects neighbors to agree, so it struggles to make accurate predictions when negative edges break that pattern. To fix this, you could track how edges relate to each other — if many edges point away from a central node, maybe the next edge is negative — but computing edge-to-edge correlations for a graph with millions of edges becomes intractable.

In one sentence. The paper represents millions of edge-to-edge correlations as a compact matrix of learned numbers (edge embeddings), making it fast enough for real graphs while preserving the correlation information.

What the paper changes

What the paper changes

The paper replaces the naive full correlation matrix with a factored approximation built from edge embeddings (a Gramian matrix — the product of embeddings with themselves). This is the single structural change.

the object it moves  =  edge-to-edge correlation representation
The hidden quantity

Edge-to-edge correlation: what links depend on each other

measured quantity  =  edge-to-edge correlation strength

In a signed network, whether a new edge is positive or negative depends partly on the signs of nearby edges. Two edges that point from similar nodes (or to similar nodes) tend to have similar signs. The correlation strength between two edges measures how much their signs move together. A strong positive correlation means they tend to point the same direction; strong negative correlation means they oppose.

The paper estimates this correlation by learning a small vector (embedding) for each edge. If two edges have similar embeddings, the model believes their signs are correlated. The full correlation matrix is the outer product of all embeddings — conceptually, a table where entry (i, j) tells you how much edge i and edge j correlate.

Why it works

Why factoring the correlation matrix works

Modeling edge-to-edge correlations via a full correlation table requires storing and updating a matrix with one row and column per edge — quadratic in the graph size. For a million edges, that is a trillion numbers, infeasible.

Here is how factoring solves it: if you represent each edge as a small learned list of numbers (say 50), the correlation matrix is built by multiplying these lists together. Multiplying two 50-number lists to get one correlation value takes 50 multiplications, not a trillion lookups. During training and prediction, you only compute the correlations you need, on-the-fly, using the compact edge numbers. The proof shows that this factored form converges linearly (the loss drops at a constant rate per iteration), matching or beating the speed of baselines that do not model correlations at all.

Why this works for link sign prediction: whether an edge is positive or negative depends on the pattern of nearby edge signs (correlation context). By compressing correlations into embeddings, the model learns which edges matter for predicting a new edge's sign, without the memory and time overhead of a full correlation table.

Math after the picture

The factored correlation matrix

First in words:

The full correlation matrix is the outer product of edge embedding vectors. Each edge i has an embedding e_i. The correlation between edge i and edge j is the dot product of e_i and e_j.

Then the compact form:

Correlation_ij = e_i · e_j, where e_i is the learned embedding for edge i.

Every symbol:

Correlation_ijhow much the sign of edge i predicts the sign of edge j
e_ithe learned embedding vector for edge i (a list of k numbers)
e_jthe learned embedding vector for edge j
· (dot product)multiply matching positions and sum: e_i · e_j = e_i[0]*e_j[0] + e_i[1]*e_j[1] + ... + e_i[k-1]*e_j[k-1]
A tiny worked example
Suppose edges have 3-dimensional embeddings.
Edge 1 embedding: [1.0, 2.0, 0.5]
Edge 2 embedding: [2.0, 1.0, 1.5]
Correlation(1,2) = 1.0*2.0 + 2.0*1.0 + 0.5*1.5 = 2.0 + 2.0 + 0.75 = 4.75
Correlation(1,1) = 1.0*1.0 + 2.0*2.0 + 0.5*0.5 = 1.0 + 4.0 + 0.25 = 5.25
Edge 1 correlates more strongly with itself (5.25) than with edge 2 (4.75), as expected.

The paper also reformulates how the model uses these correlations to avoid assembling the full matrix explicitly, keeping all calculations proportional to the number of edges, not edges squared.

What can go wrong

What can go wrong

Embedding dimension too low. If the list of learned numbers per edge is much shorter than needed, the factored matrix cannot capture all the edge-to-edge dependencies that matter. Some real correlations get lost.
Highly disconnected graphs. If the graph has isolated components or very sparse regions, the edges in different regions have few correlations. The factored model may waste capacity on modeling weak, irrelevant correlations.
Extreme class imbalance in signs. If most edges are positive (or most are negative), the model may default to predicting the majority sign, using correlations only for tie-breaking. The learned embeddings may not fully capture minority-class patterns.
Embedding dimension well-chosen. When embeddings are large enough relative to the graph structure, the Gramian approximation closely matches the true correlations, and the reformulated likelihood converges quickly.

What a runnable demo should prove

Build a small synthetic signed graph (say, 200 nodes, 500 edges, randomly split 70% positive, 30% negative). Train the model to predict held-out edge signs. Track three metrics: (1) time per epoch, (2) memory used, (3) held-out accuracy. Compare against a baseline that models the full correlation table or uses a simpler graph neural network that ignores edge correlations entirely.

held_out_accuracy = (correct_sign_predictions) / (total_held_out_edges); convergence_speed = epochs_to_reach_90_percent_training_accuracy; memory = peak_memory_in_GB

The demo must show that the factored model is faster and uses less memory than the full-correlation baseline because it avoids storing and computing all edge-pair correlations, while maintaining competitive accuracy on held-out edges.
