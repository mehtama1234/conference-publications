DeFacto: Counterfactual Thinking with Images for Enforcing Evidence-Grounded and Faithful Reasoning

DeFacto trains a multimodal model to keep its answer and its cited image evidence consistent by rewarding it only when both stay correct under targeted visual changes.

Paper explainersAll themesMultimodal

A multimodal language model can answer a visual question correctly for the wrong reason. It may point to the wrong region, rely on a language shortcut, or produce a chain of thought that never needed the decisive pixels. DeFacto attacks that failure directly. It builds training examples where the evidence is edited or masked, teaches the model to react differently when the decisive evidence changes, and then uses reinforcement learning to reward three things together: correct answers, structured reasoning, and correct evidence selection.

Zero assumption version

A right answer is not enough if the evidence is wrong

Visual question answering usually scores only the final answer. That lets a model succeed even when its visual evidence is wrong. If the question is 'what animal is jumping' and the image contains a dog in the center and a cat in the corner, the model might answer 'dog' because dogs are common in such prompts, not because it actually grounded the answer in the center region.

The problem gets worse when the model also explains itself. A fluent explanation can hide the fact that the cited region and the answer do not depend on each other. If the answer stays the same after the decisive region is masked or replaced, the model was never truly using that evidence. DeFacto is designed around this test: the answer should change when the evidence changes, and it should stay stable when irrelevant regions change.

Core problem. Evidence-grounded reasoning means the chosen answer and the chosen image region must stand or fall together.

The algorithm as a flow

What it actually does

Construct evidence-aware data

Use language guidance to locate answer-relevant regions, then generate positive, counterfactual, and random-mask training examples.

Show the model all three views

The original image teaches what should support the answer; edited evidence teaches when the answer should change; random masking teaches what should not matter.

Ask for answer, rationale, and evidence

The model must output not just the answer, but also a structured reasoning trace and region choice.

Score with three rewards

Compute reward for answer correctness, reward for good reasoning format, and reward for evidence-answer consistency.

Update with GRPO

Use GRPO, which is a reinforcement-learning update based on relative reward rankings inside a batch of sampled outputs, to shift the model toward consistent behaviors.

What the paper changes

What the paper changes

The paper changes supervision from answer-only training to intervention-based training. It does not merely ask whether the answer is correct on the original image. It asks whether the answer reacts correctly when the supporting evidence is deliberately changed.

the object it moves  =  evidence-answer consistency under image intervention
The hidden quantity

The hidden quantity: evidence-answer consistency

measured quantity  =  evidence-answer consistency

Evidence-answer consistency measures whether the selected evidence actually controls the answer. A model has high consistency when two conditions both hold: first, the model chooses the right region on the original image; second, when that region is changed in a counterfactual image, the model changes its answer in the way the edited evidence requires.

This quantity cannot be read from answer accuracy alone. A shortcut-based model may answer correctly on the original image and still ignore the decisive region. DeFacto exposes that by comparing behavior across matched image variants. Consistency is high only when the answer is stable under irrelevant masking and sensitive under relevant evidence edits.

Why it works

Why counterfactual views fix the shortcut

The method works because it turns grounding into a causal test. On an original image alone, a model can hide a shortcut. Once you also show a matched image where only the decisive evidence has changed, that shortcut is exposed. If the answer does not change when the relevant region changes, the model was not using that region. If the answer changes when only an irrelevant region is masked, the model is unstable for the wrong reason.

The three training views each remove a different loophole. Positive examples teach what correct evidence looks like. Counterfactual examples teach that the answer must depend on the decisive region. Random-masking examples teach that the model should ignore non-decisive regions. This separation matters because each view isolates one rule the model must obey, rather than hoping answer-only supervision will teach all three at once.

Reinforcement learning then turns those rules into behavior. The reward for answer correctness keeps task performance from collapsing. The reward for structured reasoning keeps the output readable and checkable. The reward for evidence consistency couples the answer to the region choice. GRPO is useful here because several sampled outputs can be compared directly, so outputs with better joint behavior receive more weight than outputs that are correct only by luck.

Math after the picture

Three-part reward

First in words:

The training reward adds answer quality, reasoning quality, and evidence consistency so the model cannot win by optimizing only one of them.

Then the compact form:

total_reward = answer_reward + reasoning_reward + evidence_consistency_reward

Every symbol:

answer_rewardreward for choosing the correct final answer
reasoning_rewardreward for producing the required reasoning structure
evidence_consistency_rewardreward for matching answer behavior to evidence interventions
total_rewardthe score used by the reinforcement-learning update
A tiny worked example
Output A answers correctly on the original image, picks the right region, and changes the answer correctly on the counterfactual image.
Give Output A scores 1.0 for answer, 0.8 for reasoning, and 1.0 for evidence consistency. Total reward is 2.8.
Output B answers correctly on the original image but points to the wrong region and keeps the same answer after the decisive evidence is edited.
Give Output B scores 1.0 for answer, 0.8 for reasoning, and 0.0 for evidence consistency. Total reward is 1.8, so the update prefers Output A because it is correct for the right reason.

The extra reward term matters because answer accuracy alone cannot distinguish a grounded answer from a shortcut answer.

What can go wrong

What can go wrong

Evidence localization is wrong. If the evidence-construction pipeline identifies the wrong region, the model is trained against a false target. Then the consistency reward pushes the answer to depend on the wrong pixels.
Counterfactual edits leak artifacts. If edited images contain obvious synthetic traces, the model may learn to detect the edit itself rather than reason about changed evidence. That breaks the intended causal test.
Reward balance is off. If answer reward dominates, the model can drift back toward shortcut answering. If evidence reward dominates too strongly, the model may become conservative and change answers too often. The reward terms must be tuned so each rule still matters.
Done right. The method is strongest when evidence regions are accurate, counterfactual edits preserve image realism, and evaluation checks answer changes under both relevant and irrelevant interventions.
What a runnable demo should prove

What a runnable demo should prove

Build a small visual question-answering benchmark where each question has a known decisive region. Create two extra versions of each image: one where that region is altered to change the answer, and one where a non-decisive region is masked. Train one model with answer-only supervision and one with the DeFacto reward. On the test set, measure original answer accuracy, region selection accuracy, answer change rate under relevant edits, and answer stability under irrelevant masks.

consistency_score = fraction of cases where the answer changes under relevant edits and stays fixed under irrelevant masks

The demo should make clear that DeFacto is not just another accuracy booster. Its value is that the model's answer becomes tied to the evidence in a way you can test by intervention.
