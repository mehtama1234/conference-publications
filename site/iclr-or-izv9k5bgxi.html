Global and Local Topology-Aware Graph Generation via Dual Conditioning Diffusion

Generate realistic graphs by teaching a diffusion model to jointly learn the small local patterns and the big overall shape through dual conditioning.

Paper explainersAll themesGraph & Geometric Learning

Generating graphs (networks of connected nodes) is hard because they have multiple scales of structure: tiny local patterns like triangles of friends, and broad global shapes that span the entire network. Most generative methods focus only on one scale and miss the other. This paper builds a diffusion model (a method that adds noise and learns to reverse it) that sees both scales at once, conditioning on local and global information separately and letting them talk to each other, to generate graphs that match reality.

Zero assumption version

Why graph generation is stuck

A graph is a network: circles (nodes) connected by lines (edges). Graphs show up everywhere—social networks, molecules, proteins, road maps. Generating a realistic graph means building one that not only has the right small-scale structure (e.g., triangles where three people all know each other) but also the right large-scale shape (e.g., groups of tight clusters linked by a few bridges).

Most existing methods work node-by-node, predicting one node and its edges at a time. This is like building a city by deciding on one person's house, then the next person's house. You miss the fact that neighborhoods cluster, that highways connect them, that the whole thing has a grand layout. So you end up with disconnected spaghetti instead of a sensible structure.

In one sentence. The paper generates graphs by diffusion, seeing both the tiny local patterns and the vast global topology at the same time.

What the paper changes

The single thing the paper changes

The paper changes what information the diffusion model receives while denoising. Instead of a single flat input, it now gets two streams: one encoding the local structure (the shape of neighborhoods), one encoding the global structure (the skeletal layout). The model must negotiate between them.

the object it moves  =  the conditioning input to diffusion
The hidden quantity

The hidden quantity: structure awareness score

measured quantity  =  structure alignment between scales

This is the invisible thing the paper must measure to know if it is working: how well do the small local patterns and the large global shape fit together when we generate a graph? If local patterns contradict the global backbone (e.g., a tight cluster placed where the backbone says there should be a bridge), the graph falls apart. The paper implicitly tracks this by checking whether, after denoising, the generated graph's local substructures align with its global topology. It estimates this by looking at the final graph and checking: do the dense regions appear where the backbone clusters? Do the bridges appear between global components? The dual conditioning mechanism keeps this alignment tight because the model must satisfy both paths simultaneously.

Why it works

Why dual conditioning solves the multiscale problem

A diffusion model learns by watching noise turn into real data, then practices the reverse: take noise and denoise it step by step. Normally, a graph diffusion model sees only the graph itself, so it has no way to remember: is this a cluster graph or a mesh? Is it sparse or dense globally?

The paper gives the model two extra clues. As the model is denoising, it receives a local-structure clue (e.g., which groups of nodes tend to form tight subgraphs) and a global-structure clue (e.g., how the network's biggest connected pieces link together). Neither clue tells the model what to build—only what the real-world constraints are at each scale. The model learns to build a denoise step that satisfies both constraints. This forces the model to learn how local and global are coupled: if you build a dense cluster locally, it has to sit where the global backbone says clusters live. If you build a bridge edge, it has to connect two of the global components. The model cannot ignore either scale because it gets graded on both. This is why it works: multiscale thinking is built in.

A beginner might try giving the model only one clue. Say, only the global backbone. Then it builds a network with the right large shape but gibberish local structure. Or only local neighborhoods—then it builds perfect tiny clusters that do not connect sensibly. Dual conditioning forces the model to see the tight constraint between scales and learn the glue that binds them.

Math after the picture

The structure-alignment loss

First in words:

Total loss equals the denoising error plus a penalty that grows with how misaligned local and global information are. The local path pushes the model one way, the global path pushes another; the weight between them controls how much each scale matters.

Then the compact form:

L_total = L_denoise + lambda * ( L_local_divergence + L_global_divergence )

Every symbol:

L_denoisethe usual diffusion denoising error—how far the model's predicted next step is from the truth
L_local_divergencepenalty for not matching the local-neighborhood clues; higher when the model builds subgraphs inconsistent with them
L_global_divergencepenalty for not matching the global-backbone clues; higher when the model violates global structure constraints
lambdathe balance knob—how much to weight structure alignment versus pure denoising
L_totalthe final loss to minimize during training
A tiny worked example
Suppose the model is denoising step 15 of 20. L_denoise = 0.8 (already pretty good at predicting noise). L_local_divergence = 0.2 (a node is being placed outside its expected cluster). L_global_divergence = 0.1 (the backbone says two clusters should be far apart; the model is bringing them closer). Lambda = 0.5.
L_total = 0.8 + 0.5 * (0.2 + 0.1) = 0.8 + 0.15 = 0.95.
If lambda were 0 (ignoring structure alignment), the model would happily ignore the local and global clues and overfit to denoising alone. If lambda were 5, the model would be forced to ignore denoising errors to satisfy structure. Lambda = 0.5 balances: both matter, neither dominates.

The total loss makes the model learn to navigate between two constraints—local details and global shape—so that generated graphs are realistic at both scales.

What can go wrong

What can go wrong

If lambda is too small. Structure alignment is barely enforced. The model denoises correctly but ignores the local and global clues, generating graphs that have the right noise-reduction profile but wrong topology.
If lambda is too large. The model is forced so hard to match structure clues that it cannot learn to denoise cleanly. Generated graphs have the right abstract structure but are noisy, with false edges and missing edges.
If local and global clues contradict. If the extracted local neighborhoods and global backbone are incompatible (e.g., one says a pair of clusters should be far apart, the other says they should be neighbors), the model is caught in an impossible constraint. It generates nonsense or fails to converge.
Done right. Lambda is tuned (e.g., via held-out validation) so that structure alignment and denoising are equally weighted. Local clues and global clues are extracted from real graphs and are always consistent. The model learns to generate graphs that are clean and plausible at every scale.
What a runnable demo should prove

What a runnable demo should prove

Write a small script that trains a dual-conditioning diffusion model on a toy dataset of 50 simple graphs. Each graph has about 20 nodes and is either a ring, a grid, or a star shape (clear local and global patterns). Extract local neighborhoods (e.g., by clique detection) and global backbones (e.g., by finding connected components and their bridges). Train with a few different lambda values: 0 (no structure), 0.5 (balanced), 2 (structure-heavy). After training, generate new graphs with each lambda and measure: local clustering coefficient (whether triangles appear), global diameter (whether the spanning distance makes sense). Plot the two metrics against lambda.

realism_score = 0.5 * (local_clustering_accuracy) + 0.5 * (global_diameter_accuracy)

The demo must show that realism_score peaks at an intermediate lambda value (around 0.5), proving that you need both scales: ignore structure and realism drops; over-enforce and realism drops too.
