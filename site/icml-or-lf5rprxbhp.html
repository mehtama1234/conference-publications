Function-Valued Causal Influence in Nonlinear Time Series

Causal discovery collapses complex nonlinear relationships into single numbers, hiding how effects actually change across different contexts and magnitudes.

Paper explainersAll themesTime Series & Sequential

When you train a neural network to predict how one time series affects another, it learns a complex pattern that changes depending on the situation. Today most tools squeeze that pattern into a single score. This paper shows that this bottleneck destroys information: two edges with identical scores can have completely opposite behaviors—one steady, one thresholded, one flipping sign.

Zero assumption version

One number hides the whole picture

In time series, one variable often influences another. A single number—say, 0.8 or 0.3—appears to answer: what is the strength of that influence? But if you train a nonlinear neural network on the relationship, the model learns that the effect is not constant. It changes based on how large the input is, what regime the system is in, or what other variables are doing. A neural network can learn that below a threshold, a variable has no effect, but above it, the effect explodes. Or that the effect is monotonic in one context but saturates and flattens in another. A single edge score loses all of this. Two edges with the same score could be doing opposite things: one steady and proportional, one sign-reversing, one all-or-nothing at a cutoff.

When you compress learned dynamics into a scalar, you conflate two sources of variation: the true state-dependent behavior the model learned, and random noise. A big edge score could mean the relationship is always strong, or it could mean it is strong in a rare context but weak everywhere else. You cannot tell.

In one sentence. Instead of one number per causal edge, estimate the full shape of how the effect changes across different input values and contexts.

The algorithm as a flow

What it actually does

Take a trained additive network

A neural model that predicts one time series from lagged history of all others.

Pick a source and target pair

Ask: how does the lagged history of variable A influence variable B?

Intervene: freeze source at different values

Clamp A's history to a fixed value, run the model, see how B's prediction changes.

Repeat across a range

Sweep the frozen value from low to high and collect B's responses.

Plot the response curve

That curve is the true causal function—monotonic, thresholded, saturating, or sign-flipping.

What the paper changes

The hidden quantity

The function-valued causal response

measured quantity  =  causal response curve

A causal response curve is the shape of how a target variable reacts as you vary the source variable. For example, if you slowly increase a country's judicial constraints from 0 to 10, how does electoral quality respond? Steadily? Not at all until a threshold? Or does it rise then saturate? A curve with a threshold implies a regime shift—below the threshold the effect is zero, above it the effect turns on, because crossing a critical point changes how the system behaves; a flat curve means the causal variable is inert, having no effect on the target in this context; a sign-reversing curve means more is sometimes better and sometimes worse, creating opposite effects at different magnitudes. This is the hidden quantity the paper measures.

The paper estimates it using individual conditional expectation—a controlled experiment: freeze the source variable at low, medium, and high levels and record the model's predicted change in the target. This reveals what the trained network actually learned about how one variable influences another across the state space.

Why it works

Why this reveals hidden structure

A neural additive model learns separate subnetworks for each input-to-output relationship. Each subnetwork outputs a contribution—how much that input affects the prediction. Because the network is trained to minimize prediction error, each contribution is shaped by what it actually learned: if the true relationship is threshold, the network learns a threshold. If it is asymmetric, the network learns asymmetry. A scalar edge score is a summary statistic—typically the average or variance of that contribution. Averaging a threshold at 0.3 and other values produces something flat-looking in aggregate, erasing the true structure.

Individual Conditional Expectation (ICE) recovers the full learned function by intervening: it freezes the input at a single value, asks the network what the prediction is, then repeats for the next value, tracing out the complete response curve. This operation directly exposes what the network learned without losing information to summarization. Two networks with identical average contributions will produce different curves if one truly learned a threshold and the other a slope. The curve is the ground truth; the scalar is just one projection of it.

The causal response function

First in words:

For a source variable i and target j, the causal response is the output change g_ij(x) when you hold the entire lagged history of i constant at value x. The paper estimates this by freezing the input, computing predictions, and measuring differences.

Then the compact form:

g_ij(x) = E[ prediction_j | X_i^lagged = x ] - E[ prediction_j | X_i^lagged = 0 ]

Every symbol:

g_ij(x)the causal response of j to source i at value x
X_i^laggedthe history of source i in the recent past
prediction_jthe model's prediction for target j
E[·]the average or expected value
xa single value you intervene to (low, medium, or high)
A tiny worked example
Train a model to predict next-day stock return from lagged interest-rate history.
Intervene 1: freeze interest rate at 1.0%, model predicts return +0.8%. Baseline (rate = 0) predicts +0.0%. Response: g(1.0) = +0.8%.
Intervene 2: freeze interest rate at 5.0%, model predicts return -1.2%. Response: g(5.0) = -1.2%.
Intervene 3: freeze rate at 10.0%, model still predicts -1.2%. Response: g(10.0) = -1.2% (saturation—no further change).
Curve: +0.8% at 1%, -1.2% at 5%, -1.2% at 10%. This is sign-reversing and saturating—the scalar summary (average ≈ -0.2%) hides both.
A different model's curve: +0.1% at 1%, +0.2% at 5%, +0.3% at 10% (proportional). Same average ≈ +0.2%, but completely opposite shape and interpretation.

The function g_ij(x) is what the paper recovers; scalar edge scores are coarse summaries that lose information about shape, threshold, saturation, and sign-reversal.

What can go wrong

What can go wrong

Inputs beyond the training range. When you intervene on inputs far outside the values seen during training, the model may be fed input combinations it has no experience with. In those sparse regions where training data is thin, the estimated curve can be biased or unreliable.
Computational cost. ICE requires running the model once for each intervention value at each time step. For large datasets and many edges, this can be slow.
Scale sensitivity. If you intervene on a variable at scales very different from training, the model can behave unpredictably. Normalization must match training exactly.
Done right. Stay within the observed data range, use the same normalization as training, and interpret sparse regions cautiously. The method itself is sound and reveals heterogeneous causal effects.
What a runnable demo should prove

What a runnable demo should prove

Simulate a toy time series where one variable has a truly nonlinear effect on another. For example, create a data-generating process where variable A influences B only when B is in a high state (a regime-specific threshold effect), or where A's effect flips from positive to negative (a sign-reversing effect). Train an additive neural network on this data. Then apply two methods: (1) report the scalar edge score; (2) estimate the causal response curve using the paper's ICE approach. Show that both methods assign similar or identical scalar scores, but the curves are visibly different, recovering the true nonlinear shapes that the scalar summary erased. Compute a metric like regime-recovery accuracy—what fraction of regime switches and threshold crossings does the curve capture compared to the ground truth?

regime_recovery = count_correct_thresholds / total_thresholds × 100%

The demo must make it impossible to miss: identical scalar scores came from opposite shapes, and only the full curve revealed what the model learned.
