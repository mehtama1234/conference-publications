CARL: Preserving Causal Structure in Representation Learning

CARL keeps causal relationships intact when compressing multimodal data into shared representations.

When you combine video and text, or X-ray and medical notes, you need a single unified description that captures the key facts. Current methods compress these different data types into a compact list of numbers, but they ignore one critical thing: which variables actually cause which other variables. CARL fixes this by explicitly protecting causal relationships while doing the compression.

Zero assumption version

Multimodal Compression Erases the Causal Map

Imagine a patient's fundus image (photograph of the back of the eye) and their blood pressure reading. A doctor knows the eye vessels reflect cardiovascular health: the vessels in the image are caused by the patient's heart condition. When you feed both the image and the measurement to a neural network, the network compresses them into a compact shared representation—say, 128 numbers describing both data types at once. But the network does not care about causality. It optimizes only for predicting one modality from the other.

A beginner would say: just make the representations similar. But similarity is blind to cause. The network might notice that when blood pressure is high, certain patterns appear in the eye image. It captures this correlation. But it could accidentally flip the causality (making the image seem to cause the pressure), or it could erase a critical mediator (the actual biological mechanism). The learned representation becomes unreliable for answering causal questions like: if I intervene on the vessel structure, will the patient's cardiovascular outcome change?

The problem in one sentence. Compressing multiple data types into one representation loses the causal structure that connects them.

What the paper changes

The One Thing Changed: Causal Constraints in the Loss Function

The paper modifies what the network is rewarded for. Instead of merely matching representations from the two modalities, the network is now rewarded specifically for preserving the conditional independence relationships that define causality. If the true causal structure says A and B are independent when you know C, the representation must obey that fact.

The hidden quantity

The Hidden Quantity: Conditional Independence Patterns

measured quantity  =  Conditional independence preservation

Conditional independence is the skeleton of a causal diagram. It means: two variables are unrelated given what you know about a third. For example, a patient's eye vessels might be independent of their diet given their blood pressure—the pressure is the causal link. If you compress the data but lose this independence, you have lost the causal structure.

CARL estimates these independence patterns in the original data (by measuring correlations conditional on other variables), and then the loss function penalizes the representation if it violates these patterns. The higher the penalty, the more the representation is forced to preserve which variables are truly independent.

Plain reading. Conditional independence is a fact about which variables become uncorrelated when you control for a third variable. Preserving these facts means the compressed representation still encodes which variable points to which.
Paper reading. CARL introduces conditional independence preservation loss and Markov boundary preservation loss to maintain identifiability conditions (backdoor, frontdoor, instrumental variable criteria) in the shared representation space.
Why it works

Why It Works: Locked Relationships Stay Locked

Normally, when the network compresses two modalities, it only cares that the compressed versions are similar. There is no constraint on whether the details of the compression preserve causality. A weight can shift by a large amount, as long as the final lists of numbers are close.

CARL adds explicit penalties. If compressing the data would violate a conditional independence pattern, the loss function punishes that weight change. The penalty is proportional to how badly the independence is violated. The network is reluctant to break causality because training adjusts weights to minimize total loss—if a weight change that saves similarity also destroys an independence (a large penalty), the direction-of-improvement (the gradient) points away from that change, so the network leaves the weight alone. It is like adding springs that resist certain directions of movement.

The information bottleneck part of the loss enforces a second principle: compress the data to the smallest size that still preserves the conditional independence patterns. This prevents the network from hoarding unimportant details while forgetting causal facts. Combined with alignment loss (which ensures semantic similarity maps to representation distance) and Markov boundary preservation (which locks in which variables are direct neighbors in the causal graph), the three losses together ensure that the final representation is both compact and causally faithful.

Math after the picture

The Loss Function That Guards Causality

First in words:

Total loss = similarity between representations + lambda1 times violation of conditional independence + lambda2 times violation of information bottleneck + lambda3 times violation of monotonic alignment + lambda4 times violation of Markov boundaries

Then the compact form:

L_total = L_sim + lambda_ci * L_ci + lambda_ib * L_ib + lambda_align * L_align + lambda_markov * L_markov

Every symbol:

L_simhow different the compressed representations are from each other
L_cipenalty for violating conditional independence patterns measured in input data
L_ibinformation bottleneck penalty (compression vs. information retention trade-off)
L_alignpenalty if semantic similarity does not match representation closeness
L_markovpenalty for violating Markov boundary structure
lambda_ci, lambda_ib, lambda_align, lambda_markovweights controlling how much each penalty matters relative to similarity
A tiny worked example
Suppose the true data has: eye vessels independent of diet given blood pressure.
Initial representations: image list has distance 0.8 from pressure list. Diet list has distance 1.2 from pressure.
Without CARL: network shifts image toward pressure (distance 0.2), reducing similarity loss. But this destroys the independence.
With CARL: the conditional independence violation loss penalizes this move heavily (penalty 50 * 0.8^2 = 32). Similarity loss only saves 0.6 (0.8 - 0.2). Net: losing the conditional independence costs 32 points; saving similarity gains 0.6 points. Network leaves the number lists alone.
Result: vessels and diet stay independent (causality preserved), and representation size is smaller because information bottleneck removes non-causal noise.

Each loss term pulls the network in a direction; together they ensure compression that respects causality.

What can go wrong

What can go wrong

Misidentified ground-truth causality. If the conditional independence patterns measured from the input data are wrong, CARL will preserve the wrong structure. The method is only as good as the causal facts it is given.
Too many lambda weights. Balancing four loss terms (similarity, CI preservation, information bottleneck, alignment, Markov) requires tuning five hyperparameters. Choosing them wrong can make the representation either too large or too loose on causality.
Nonlinear causal relationships. The method assumes causality can be captured via conditional independence. For highly nonlinear mechanisms, this may miss important structural details.
Done right. Start with a smaller dataset where causal ground truth is known (synthetic or curated). Validate that the learned representation preserves the causal facts. Then scale to larger real-world data with pre-computed conditional independence estimates.
What a runnable demo should prove

What a runnable demo should prove

Build a synthetic dataset with a known causal graph: three variables A, B, C where A causes B, B causes C, and A and C are independent given B. Compress two versions of this data (images of one variable, numbers of another) using a standard multimodal encoder (without causal constraints), then with CARL. For each method, test whether the learned representation preserves: (1) the independence of A and C when you know B, (2) the causal order (A before B before C), (3) the ability to answer counterfactual queries (what if A changed?).

causal_fidelity = (preserved_independences / total_independences) * (correct_causal_order_queries / total_queries)

The demo must show that naive compression fails on counterfactual queries (predicting what happens if you intervene) while CARL succeeds because it kept the causal map intact.
