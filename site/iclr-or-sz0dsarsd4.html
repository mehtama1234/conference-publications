CogFlow: Bridging Perception and Reasoning through Knowledge Internalization for Visual Mathematical Problem Solving

Force a multimodal model to turn visual facts from a math diagram into internal working knowledge before it starts reasoning, so later steps stay tied to the actual figure.

Paper explainersAll themesMultimodal

Visual math problems are hard for multimodal language models because success requires three distinct operations. The model must read symbols and diagram structure from the image, it must convert those visual facts into an internal representation that the reasoning process can use, and it must build a solution chain that continues to respect those facts. Many earlier systems only strengthen the first operation. They try to extract better visual cues, but they do not check whether those cues survive into the reasoning stage, which means the solver can still ignore them later. CogFlow addresses the full pipeline. It trains perception with visual rewards, inserts an internalization stage with a reward model that checks whether the extracted visual facts were faithfully absorbed, and then runs policy optimization with a visual gate that favors reasoning traces grounded in that absorbed knowledge. This matters because in visual mathematics, the right answer often depends on one symbol, one angle mark, or one positional relation. If that detail is read but then dropped before reasoning, better perception alone does not solve the task because the missing fact never reaches the step where the answer is computed.

Zero assumption version

Reading the figure is not enough if reasoning ignores what was read

A visual mathematics problem may include equations, axis labels, geometric marks, or shapes whose arrangement determines the solution. A model can fail in two different ways. It can misread the visual input, such as missing a minus sign or confusing two line segments. Or it can read the figure correctly but fail later, because the reasoning trace does not actually use the extracted facts.

Many prior methods only attack the first failure. They reward better perception, which helps when the issue is poor symbol recognition or weak diagram parsing, because the model then reads more of the figure correctly at the start. But they leave the second failure untouched. The reasoning module may still produce a fluent but unsupported chain of steps, because nothing in training forces the intermediate representation to keep the visual evidence available and active.

The paper's move. Insert an explicit internalization stage between seeing and reasoning, then score that stage directly, because the model must retain visual facts before it can reason from them.

The algorithm as a flow

What it actually does

Perceive the figure

Read symbols, diagram structure, and question text from the visual input.

Apply visual rewards

Train the model to extract those cues more accurately in both fine detail and higher-level meaning.

Internalize the visual facts

Convert the extracted cues into an intermediate knowledge state intended to support later reasoning.

Score the bridge

Use a visual-anchored reward model to check whether the knowledge state and the developing reasoning trace remain faithful to the visual evidence.

Optimize reasoning with a visual gate

Raise the probability of solution paths that use the internalized visual knowledge and suppress paths that sound coherent but ignore the figure.

What the paper changes

What the paper changes

CogFlow changes the interface between perception and reasoning. Instead of letting extracted visual features pass informally into the decoder, it inserts a supervised internalization stage and then trains the reasoning policy to stay conditioned on that stage.

the object it moves  =  visual knowledge retention across the reasoning chain
The hidden quantity

The hidden quantity: retention of visual evidence

measured quantity  =  How much of the figure survives into the reasoning trace

The central quantity is not just perception accuracy and not just final-answer accuracy. It is retention: whether the visual facts that were extracted remain available and influential when the model begins to reason. If the model reads 'AB is parallel to CD' but later reasons as if the lines were unrelated, retention was poor even if perception was correct.

CogFlow measures this indirectly with a visual-anchored reward model. The reward is high when the intermediate state and subsequent reasoning steps agree with the figure, because that indicates the bridge from perception to reasoning remained intact. The reward is low when the reasoning chain introduces steps that are not supported by the visible symbols or diagram relations.

Why it works

Why the extra stage matters

A single end-to-end model can, in principle, learn to go from image to answer directly. In practice, that path hides where failure occurs. If the answer is wrong, the update only says the whole process failed. It does not say whether the model misread the figure, forgot the visual facts, or reasoned badly from correct facts. CogFlow separates these failure sources by assigning a training signal to each stage.

The internalization stage is the new part that changes the learning dynamics. It forces the model to form a working representation of the extracted visual facts before symbolic reasoning expands. That matters because mathematical reasoning often unfolds over many written steps. Without an explicit bridge, small early visual details can be overwritten by later language patterns. By scoring internalization directly, the paper teaches the model that preserving those details is itself a requirement.

The visual-gated policy optimization stage then uses that bridge during reasoning. A policy update can otherwise reward any trace that lands on the right answer, even if intermediate steps are visually unsupported. The gate suppresses that shortcut because it favors traces whose actions remain compatible with the internalized visual facts. As a result, the model gets reward for solving the math problem through a route that still references the figure, not merely for arriving at the endpoint.

The training equation

First in words:

The objective adds separate terms for perception, internalization, and reasoning, so the model is rewarded at each stage of the visual-to-math pipeline.

Then the compact form:

L = L_perception + alpha * L_internal + beta * L_reason

Every symbol:

Lthe full loss used during training
L_perceptionthe loss driven by visual rewards, which improves extraction of symbols and diagram structure
alphathe weight on the internalization term
L_internalthe loss or reward term that checks whether visual facts were faithfully absorbed into the intermediate knowledge state
betathe weight on the reasoning term
L_reasonthe policy optimization term that rewards solution traces grounded in the internalized visual knowledge
A tiny worked example
Suppose the diagram marks two equal angles and the question asks for a third angle.
Perception succeeds if the model reads both angle marks correctly.
Internalization succeeds if the intermediate state explicitly carries the fact that those angles are equal.
Reasoning succeeds if the later steps use that equality when computing the unknown angle.
CogFlow trains all three checkpoints because a final correct answer alone cannot reveal which of these links was missing.

The main point is stage-specific supervision. Each term protects a different part of the path from the figure to the final proof.

What can go wrong

What can go wrong

The reward model judges grounding poorly. If the visual-anchored reward model cannot tell whether a reasoning step is truly supported by the figure, incorrect chains may still be rewarded because they look mathematically fluent.
The internal state is too weak. If the intermediate representation does not store enough detail, the bridge exists in name only. Later reasoning will still fall back to generic language patterns because the needed visual facts are not present in usable form.
The dataset overrepresents simple cases. If training examples rarely require long visual dependence, the model may appear grounded while only handling short chains. Hard problems expose whether internalization actually survives across many reasoning steps.
Done right. Use a dataset where solutions depend on specific diagram facts, a reward model that checks those facts carefully, and policy updates that value grounded intermediate steps as much as final answers.
What a runnable demo should prove

What a runnable demo should prove

Construct a small visual mathematics benchmark with annotated visual facts such as symbol identities, equalities, geometric relations, and the reasoning steps that should consume them. Compare three systems: a plain multimodal solver, a solver with stronger perception only, and CogFlow, because that comparison separates gains from better reading against gains from better retention. For each problem, score whether the model read the key visual facts, whether those facts appear in the intermediate knowledge state, and whether later steps actually use them. The demo should show that CogFlow raises the survival rate of visual facts across the whole solution chain.

retention_rate = visual_facts_used_in_reasoning / visual_facts_extracted

The essential check is not only whether the answer is right. It is whether the answer was reached by carrying the figure's information through the intermediate reasoning process.
