Representation & Self-Supervised Learning

How can models learn good representations from unlabeled data, and what patterns do they actually discover?

← All themes explainedField mapMathematicsAll explainers
What this whole area is about

Most machine learning today relies on hand-labeled training data. Someone sits down and marks thousands of images as 'cat' or 'dog', or listens to audio and types out transcripts. But the world has vastly more unlabeled data than labeled data — billions of videos on the internet, petabytes of text, hours of sensor recordings from factories. The core question here is: how can we train effective models without waiting for expensive manual labeling?

This is genuinely hard because there is no ground truth telling the model what to learn. Normally, if you show a model an image and tell it 'this is a dog,' the model adjusts itself to predict that label. Without labels, there's no signal to aim for. Researchers have discovered that you can create signals yourself by treating the data cleverly: hide part of an image and train the model to predict it from what's visible, or show two slightly different versions of the same image and teach the model they should look similar to each other. But these proxy tasks have to be designed carefully — if the task is too easy or too generic, the model might learn surface patterns (like textures in an image) instead of conceptual patterns (like objects or scenes) that transfer to other problems downstream.

This theme covers multiple research directions. Some papers focus on the core self-supervised training methods: what proxy tasks work best, how to set them up so they produce useful representations. Others dig into understanding what representations the model has actually learned — they analyze the internal structure and organization to see if the model has picked up interpretable features. Many papers tackle the practical challenge of combining different data types: if you have both images and text describing them, how do you learn representations that work across both? There is also the continual learning problem: as new data arrives, how do you incorporate it without forgetting what you already know? And there are papers on making these methods efficient: compressing large models, using specialized architectures for different tasks, and building the mathematical theory to predict which methods will work.

This matters because labeled data is expensive and often biased toward the industries that can afford to label it. Self-supervised learning gives researchers access to competitive models — a researcher with a laptop and internet access can now train good models on their own unlabeled data. It also touches every application domain: NLP, computer vision, speech, robotics, medical imaging, scientific discovery. The methods emerging here have already reshaped the field.

First-principles map

Representation as choosing what matters

A model learns a useful view of the world by deciding which differences to preserve, which differences to erase, and which missing structure it should be able to recover.

Raw data has too many details. An image has pixels, lighting, shadows, viewpoint, background, texture, object shape, object identity, and camera noise. A sentence has words, style, grammar, topic, speaker intent, and accidental phrasing. A video has frames, motion, events, timing, objects, and scene changes. The model needs a smaller internal view that keeps the differences that matter and throws away differences that only distract.

That smaller internal view is the representation. If two things are meaningfully different, the representation should keep them apart: dog versus cat, tumor versus normal tissue, walking versus falling, correct proof step versus invalid proof step. If two things are different only in a harmless way, the representation should treat them as the same: brighter light, different crop, background clutter, font style, small noise, speaker accent, or a wording change that leaves the meaning intact.

Masking and contrastive learning ask two different questions

Masking asks: what structure lets me recover what is missing? Hide a word and the model must use sentence structure. Hide image patches and it must use object and scene structure. Hide video frames and it must use motion. Hide graph nodes and it must use relations. The supervision comes from the data itself because the hidden part is the target.

Contrastive learning asks: what should stay the same across two changed views? If the same image is cropped, color-shifted, or lightly distorted, the model is pushed to keep the same object or meaning. If the example is actually different, it should stay apart. The pressure is not just similarity. It is a decision about which changes are real signal and which changes are nuisance.

masking: visible context -> missing piece contrastive learning: changed view A -> same underlying thing as changed view B representation learning: preserve useful difference, erase useless difference, recover hidden structure

Same, different, and predictably changed

The deeper question is: same for what purpose, different for what purpose? A dog in bright light and the same dog in dim light should stay the same for identity. A dog and a cat under the same light should be different. If an object moves right in an image, its location should move right too. Some facts should stay unchanged; some should change in a predictable way.

This is where invariance and equivariance enter in plain language. Invariance means a change happened in the input but the thing we care about should stay the same. Equivariance means the input changed and the representation should change with it in a known way. The model is learning which kind of change each difference belongs to.

Geometry and topology are the shape of the learned view

Once the model turns data into representations, the examples become points in a learned space. The shape of that space matters. Similar things should be nearby. Meaningfully different things should be separated. Smooth changes should move smoothly. Valid paths should stay on the data surface instead of cutting through impossible examples.

Geometry asks about distance, direction, curvature, neighborhoods, and useful paths. Topology asks about the larger shape: connected pieces, loops, holes, branches, bottlenecks, and whether a continuous process has been torn into false clusters. Persistent homology is one way to check that larger shape across scales. It asks which connected parts or loops survive as you zoom out, rather than trusting one arbitrary distance threshold.

A representation can look good locally while breaking the global shape. It can put neighbors near each other but split one continuous process into fake islands. It can collapse rare but important bridges. It can erase a loop that was real in the data. That is why representation quality is not only about accuracy. It is about whether the learned map keeps the structure needed for later prediction, search, transfer, and control.

The connection to science and statistical physics

This is not only an ML idea. Much of science is the search for the right representation. A gas has too many molecules to track one by one, so physics keeps temperature, pressure, density, energy, and entropy. A falling object becomes easier to understand when represented by position, velocity, acceleration, and force. A patient becomes easier to reason about when symptoms and lab values are represented as a hidden disease process and its trajectory.

Statistical physics is especially close because it asks how useful large-scale order appears from many small details. Coarse-graining means replacing many tiny details with a larger summary that still preserves the behavior we care about. Renormalization asks what changes and what stays the same when we look at a system at a larger scale. Representation learning is making the same kind of move on data: many pixels, words, frames, or signals become a smaller view that keeps the stable pattern and drops detail that washes out.

The shared question is simple: what can be forgotten, what must be preserved, and what stable pattern appears at the next scale? A good representation keeps what causes change, what predicts future behavior, what transfers across settings, and what lets us intervene. A bad representation keeps surface noise, accidental correlation, measurement artifacts, or labels without mechanism.

Deeper conceptual connection

Learning as finding the right state description

Learning is not only fitting answers. It is finding a description of the situation that makes the world easier to predict, compress, compare, control, or explain.

A useful representation often tries to uncover hidden variables behind messy measurements. In an image, the hidden variables may be object, pose, lighting, background, material, and camera noise. In speech, they may be words, speaker, emotion, rhythm, and room noise. In video, they may be identity, motion, event, cause, and timing. In medicine, they may be symptoms, disease process, risk, and patient trajectory. The raw data mixes these together. A good representation separates the parts that need to be used differently.

State variables

Science becomes easier when it finds the right variables. Physics does not reason only from raw motion traces; it uses position, velocity, force, and energy. Medicine does not reason only from lab numbers; it looks for the disease process those numbers reveal. In this sense, learned representations are data-driven state variables. They are the model's attempt to name the useful state of the world.

Sufficient summaries

A summary is good if it keeps what is needed for the question and drops what is not. Too much compression loses meaning. Too little compression keeps noise. Self-supervised learning lives in that tension: keep enough structure to predict, compare, or reconstruct; throw away enough detail that the model does not become trapped by surface clutter.

Cause versus shortcut

A representation should separate causes from accidental correlations. If a model learns snow means wolf, it has learned a shortcut. If it learns animal shape, fur, face, and body, it has learned something closer to the object. The strongest test is intervention: change lighting only and identity should stay; change the object and identity should change; change the disease process and symptoms should change in the expected direction.

Transfer and action

A representation is valuable when it survives a new use. It should help on tasks that were not exactly the pretraining game. It should make retrieval easier, clustering cleaner, generation more stable, and decisions less brittle. That is why this theme connects to almost every other theme: agents need state, long-context models need memory summaries, scientific models need hidden variables, and safety work needs to know whether the model learned the real feature or a shortcut.

messy measurement -> useful state description -> easier prediction, comparison, transfer, or control

The deepest line is simple: representation learning is the search for variables that make the world behave simply.

Paper treatment template

Questions each paper needs to answer

Each paper should be read as a choice about what the model should preserve, erase, recover, stabilize, or reshape.

The shallow version says a paper uses masking, contrastive learning, JEPA, topology, invariance, or a teacher-student setup. The deeper version asks what pressure the method puts on the representation. A paper deserves its own treatment when it changes the answer to one of these questions.

1. What raw mess is the paper starting from?

Name the messy thing before the method touches it: pixels, video frames, audio, graphs, time series, text, multimodal pairs, tabular records, molecular structures, or model weights. Then say what is mixed together inside that raw data. For images it may be object, pose, lighting, texture, background, and camera noise. For video it may be body, action, timing, viewpoint, and event state. For audio it may be speaker, emotion, words, pitch, room noise, rhythm, and instrument texture.

2. What hidden structure is the paper trying to recover?

This is the central question. Masking papers recover missing structure. Contrastive papers recover what stays stable across changed views. Topology papers recover the larger shape of the data. Equivariance papers recover how a change in the world should move the representation. Teacher-student papers recover a stable target that a smaller or newer model can learn from.

3. What should stay the same?

Every representation makes a promise about sameness. Two crops of the same image may need the same object identity. Two neighboring video frames may need the same behavior state. Two sensors seeing the same event may need the same event representation. The paper should say what sameness it is enforcing and why that sameness is useful for later tasks.

4. What should stay different?

A bad representation erases differences that the task needs. A paper has to protect real differences: cat versus dog, walking versus falling, one disease process versus another, one graph role versus another, one time order versus another. For contrastive papers this means asking whether negatives are real differences or accidental ones. For masking papers it means asking whether prediction forces semantic structure or only local texture.

5. What should change in a controlled way?

Some changes should not vanish. If an object moves right, its position changed. If a body turns, pose changed. If a sound gets louder, intensity changed. If a molecule rotates, geometry changed in a lawful way. This is the plain meaning of equivariance: the representation should move with the world rather than pretending nothing happened.

6. What is the paper's training pressure?

The method works only through pressure. Ask what makes the lazy shortcut fail. Masking pressures the model to complete missing parts. Contrast pressures it to identify stable identity across views. Temporal contrast pressures it to respect event flow. A frozen teacher pressures the student toward a stable target. Persistent homology pressures the learned space to keep durable connected structure instead of only satisfying pairwise distances.

7. What shortcut would the model learn without this method?

This is where the real insight usually appears. The model might learn texture instead of object, background instead of class, local continuity instead of event, a batch artifact instead of similarity, a collapsed prototype instead of many useful states, or a noisy hard negative instead of a real distinction. A strong paper is often a paper that blocks one specific shortcut.

8. What object does the method manipulate?

Do not describe the method only by name. Say what object it moves: a masked patch target, a positive pair, a negative pair, a teacher output, a prototype, a latent variable, a graph neighborhood, a topology constraint, a projection head, a token budget, or a representation geometry. This makes the paper concrete.

9. What shape should the learned space have?

Some papers care about local neighborhoods. Some care about clusters. Some care about paths, loops, hierarchy, curvature, or connected components. Geometry asks whether distances and directions are useful. Topology asks whether the larger shape survives. Persistent homology asks what structure remains when the viewing scale changes.

10. What does success prove?

Accuracy alone is not enough. A paper may prove that the model transfers with few labels, survives new domains, avoids collapse, keeps rare structure, learns faster, needs less compute, gives a more stable loss, or preserves the data's shape. The success claim should connect back to the representation pressure: the result matters because the model learned the right thing to keep and the right thing to ignore.

11. What would break the method?

Every method has a world where its assumption fails. Temporal contrast fails if nearby frames are not semantically close. Masking fails if local texture is enough to predict the missing part. Contrastive learning fails if negatives are false negatives or batches are skewed. Topology constraints fail if the measured shape is noise. A frozen teacher fails if the teacher gives bad targets. This failure case tells us what the paper really assumes about the data.

12. What is the one-line first-principles statement?

End each paper treatment with one simple line. For BEAST: useful video representation needs both appearance and motion. For SALT: stable targets make self-supervised video learning easier to trust and scale. For topology-aware contrastive learning: a representation should preserve the durable shape of the data, not only pairwise similarity. For invariance papers: learning is controlled forgetting, and forgetting the wrong difference destroys the task.

paper treatment = raw mess -> hidden structure -> preserved differences -> erased differences -> controlled changes -> training pressure -> shortcut blocked -> proof of success -> failure case

Subtheme

Learning from unlabeled data without labels

The core insight is simple in concept but tricky in practice: if you have a piece of data, you can treat parts of it as a learning signal for other parts. Imagine a video — you hide one frame and train the model to predict it from the surrounding frames. Or an image where you mask out part of the picture and train the model to fill it in. These proxy tasks create a supervisory signal without any human having to label anything. The model learns to encode visual structure, temporal dynamics, or context because it needs those patterns to solve the reconstruction task.

The challenge is that proxy tasks can be gamed. A model could learn to predict masked pixels by memorizing local texture patterns without understanding objects or scenes. Researchers have discovered that contrastive methods work especially well: show the model two slightly different versions of the same image (by cropping, color shifting, rotating), and teach it that their representations should be similar, while random different images should be dissimilar. This forces the model to capture stable, semantic features rather than superficial details. But even this requires careful tuning — the temperature of the similarity comparison, the size of the batch, whether you use a memory buffer of past examples — all of these affect what the model learns.

Across the 115 papers in this subtheme, researchers explore variations: different proxy tasks (masking, contrastive, rotation prediction, clustering consistency), different architectures (CNNs, vision transformers — neural networks designed to process spatial images — and multimodal encoders), and different ways to combine tasks. Some papers ask whether you need pretraining at all versus just training on downstream tasks, or whether combining self-supervised pretraining with a small amount of labeled data beats either alone. The practical impact is large: models pretrained this way now outperform supervised learning on many benchmarks when downstream labels are scarce, because they have already discovered the foundational patterns in unlabeled data that don't require manual annotation.

Subtheme

Understanding what neural networks actually learn

A trained neural network is a black box: it takes data in and produces predictions, but what is it really capturing? Are the learned representations organized? Do they encode interpretable ideas? These questions matter because if you understand what a model has learned, you can diagnose failures, design better architectures, and predict when transfer to a new task will work. Papers in this subtheme are detective work: they develop tools and experiments to peer inside the model's learned representations.

The difficulty is that representations are high-dimensional (often hundreds or thousands of numbers per input), which is hard to visualize or analyze directly. Researchers use several techniques: they measure how similar the internal representations are for similar inputs, they project high-dimensional spaces down to 2D or 3D for visualization, they check whether you can linearly separate different categories in the learned space, they measure information content — how much of the input information has the model preserved or discarded. Some papers use adversarial perturbations to understand if small intentional changes break the model. Others analyze what individual neurons or layers are sensitive to. The results often reveal that models learn hierarchically: early layers capture textures and edges, middle layers capture parts, and late layers capture whole objects.

Across 64 papers, researchers explore what self-supervised models have learned, what makes representations good for transfer learning, how different pretraining methods produce different structural organizations, and whether interpretable features emerge naturally. This work is foundational for building intuition about why these methods work, and it often reveals surprising failures: models sometimes learn spurious shortcuts or miss important dimensions entirely. Understanding these patterns helps design better pretraining objectives because researchers can target the proxy tasks and architectures that naturally encourage the kinds of structure that downstream tasks need.

Subtheme

Bridging different types of data together

Real-world data often comes in multiple forms: an image with a caption, a video with audio and text, a medical scan with a patient history. Humans understand how these pieces connect because our brains naturally link different types of input — reading the caption enriches what we see in the image, hearing speech narrows down what we notice in a video. But for a machine to learn from this, representations of images, text, and audio need to be in a shared space where they can be compared and aligned. If you train separately, each modality lives in its own world and they never communicate with each other.

The difficulty is that different modalities have different structures. An image is a spatial grid of pixels, text is a sequence of words, audio is a sequence of waveforms. They are not naturally comparable. Researchers address this by learning alignment: train a model so that an image's representation and its caption's representation are close together in a shared number-space, while mismatched pairs are far apart. This is conceptually similar to contrastive learning, but applied across modalities. The challenge is ensuring alignment happens at the right level: a model might trivially solve this by learning that if an image contains a dog and the text says 'dog,' they match, without learning anything deeper about visual or linguistic structure.

Across 63 papers, researchers develop methods for image-text (like CLIP), audio-text, video-text, and even rarer combinations. The payoff is large: models trained to align vision and language have become the foundation for visual question answering, image search, and text-guided image generation. Papers explore different loss functions, different sampling strategies for constructing positive and negative pairs, and how to handle missing modalities or noisy alignment labels. The success of these methods has shown that self-supervised multimodal learning often works better than any single-modality approach because each modality provides complementary information — text grounds the visual content in language meaning, and images constrain the many possible meanings of text.

Subtheme

Keeping knowledge as data changes over time

In the real world, data arrives continuously. A factory's production process shifts, social media trends change, new species of plants appear in ecology datasets. When a model is trained once and deployed, it sees data it was never trained on, and its performance decays — a phenomenon called distribution shift or domain adaptation. Simply retraining the model from scratch on new data is expensive and often causes catastrophic forgetting: the model forgets everything it learned before and has to relearn it all. The goal is to learn from new data without erasing old knowledge.

This is genuinely hard because neural networks are prone to interference: fitting new patterns can mechanically overwrite the weights that encoded old patterns. Continual learning researchers explore several strategies: maintain a buffer of past data and mix it with new data when training, learn in a way that is less destructive to old knowledge (like constraining weight changes), develop architectures that isolate new tasks in dedicated pathways, or learn features that are more stable across domains. The tradeoff is always the same: if you are too conservative with old knowledge, you learn slowly from new data; if you are too aggressive, you forget. Finding that balance is the core research question.

Across 57 papers, researchers tackle continual learning, domain adaptation, and few-shot learning (learning from very few examples of a new domain). Some papers ask what the theoretical limits are: is it possible to never forget? Others build practical systems: test-time adaptation methods that adjust the model slightly as it encounters new data, or meta-learning approaches that train the model to learn quickly from new examples. The applications are critical: robots deployed in the real world need to adapt, medical AI systems need to handle new patient populations, and recommendation systems need to track evolving user preferences.

Subtheme

Grouping similar things without being told how

Humans naturally cluster things: we recognize that apples and oranges are both fruits, or that a bicycle and a skateboard are both personal transport. Computers don't have this intuition. Clustering — grouping similar items without being told the categories upfront — is a fundamental task. Many real datasets have natural structure: similar documents cluster together, customer purchase behaviors group into profiles, proteins fold into families. If a model can discover these clusters without labels, it captures something real about the data's structure.

The challenge is defining 'similar' and 'cluster' without human guidance. Local clustering (grouping nearby points) is easy but fragile. Deep clustering tries to learn representations where clusters emerge naturally, but the model can collapse into trivial solutions: putting everything in one cluster, or creating many micro-clusters that do not reflect true structure. Papers use prototype learning (learn a set of cluster centers that represent the data) combined with self-supervised learning: the model compares each sample to prototypes, assigning it to the closest one, and simultaneously learns representations that make clusters more crisp. Some methods use consistency: if you apply different augmentations (slight changes) to the same image, the model should assign both to the same cluster.

Across 33 papers, researchers develop clustering objectives that avoid collapse, study how many clusters naturally exist in different datasets, and explore whether unsupervised clusters align with human-defined categories. Papers also ask how to update clusters over time as new data arrives, and how to handle data where there are many equally valid clusterings (e.g., images could be grouped by object type, color, or photographer style). The practical applications are strong: unsupervised data exploration, anomaly detection (points far from all clusters), and bootstrapping labels for downstream tasks.

Subtheme

Distilling and transferring what models learn

Large models trained on billions of weights are effective but expensive to run. A smartphone or an edge device cannot run a model that requires gigabytes of memory and thousands of arithmetic operations per prediction. Knowledge distillation is the answer: train a small 'student' model to mimic a large 'teacher' model, capturing the essential patterns in a compact form. The teacher model is often self-supervised pretrained on huge unlabeled datasets, and the student inherits that knowledge without ever seeing the original data — the teacher has already distilled the patterns into its weights.

The difficulty is that small models cannot physically represent everything a large model knows. A 1-million-weight model cannot learn as much as a 1-billion-weight model. So the distillation process involves strategic choices: what information from the teacher is most important to preserve? How should the student's output distribution be compared to the teacher's? Should you distill layer by layer or just final outputs? Diffusion models add another dimension: some papers use diffusion-based distillation, where the student learns to denoise in a different way than the teacher, or where distillation itself becomes a denoising process. The quality loss is unavoidable, but well-done distillation can recover 80-95% of the teacher's performance in a model 10x smaller.

Across 17 papers, researchers develop distillation techniques for self-supervised models, study what knowledge transfers and what does not, and explore whether distillation across domains or architectures is possible. Papers also study domain transfer: can a model trained on general internet images learn representations that transfer to a specific domain like medical imaging or satellite photos? The practical value is clear: it enables on-device AI by reducing memory footprint, reduces computational costs because prediction becomes faster, and makes good representations accessible to resource-constrained applications like mobile phones or IoT sensors that could never run a model with billions of weights.

Subtheme

Making models work with partial or noisy information

Real data is messy. Sensors fail and produce incomplete readings, labels are imperfect or crowdsourced with disagreement, images are corrupted or occluded. A reliable model should not assume perfect data. When you have multiple incomplete views of the same object — like a video frame with one camera broken, or a medical scan missing one modality — the model needs to extract the signal while working around missing or contradictory information. Information theory and optimal transport provide mathematical frameworks to reason about this.

The challenge is that standard learning assumes all data points are equally reliable. When information is noisy or partial, the model can fit the noise instead of the signal, or it might overweight the few complete examples and miss patterns in partial data. Information-theoretic approaches ask: what is the minimum amount of information needed to solve this task? Optimal transport asks: how can I match partial observations in a way that minimizes the cost of transformation? These tools help design loss functions and algorithms that degrade gracefully when data is incomplete — the model continues to learn from what is available rather than collapsing into failure because some pieces are missing.

Across 16 papers, researchers develop methods for learning from multi-view data where some views are missing, noisy labels where annotators disagree, weak supervision where labels are indirect or imperfect, and corrupted inputs. Some papers focus on reliability: training in a way that does not overfit to artifacts in the data. Others develop theoretical bounds: proving that even with 30% missing data, certain algorithms will still find the true structure with high probability. The applications include medical imaging where patients may not have all scans, sensor networks with device failures, and learning from crowd-sourced annotations.

Subtheme

Structure and shape in representation spaces

When a model learns representations, they live in some mathematical space. That space has structure: some points are close together, others far apart, and there may be natural directions or symmetries. A classic observation is that word encodings (dense vectors representing words) have structure — the direction from 'king' to 'queen' mirrors the direction from 'man' to 'woman,' which means the vector space has absorbed linguistic relationships. This is true in learned representations of images and other data too. Rather than treating representations as unstructured high-dimensional numbers, some papers exploit their structured properties to build better models because the structure encodes information the model has already learned about relationships in the data.

Real-world data has hidden structure: hierarchies (animals, then mammals, then dogs), symmetries (rotating an image should correspond to rotating its representation by the same amount), or continuous change (moving through representation space smoothly transitions between related objects). Standard Euclidean space (where distance is straight-line) may not be the best fit. Hyperbolic space (like the curved surface of a saddle) naturally encodes hierarchies — it has room in the center and expands exponentially at the edges. Manifolds (curved surfaces where the intrinsic structure is not flat) offer another option. Using these structured spaces, models can enforce natural relationships: a dog representation stays close to other dogs but far from cats, and small animals are hierarchically nested inside larger categories.

Across 16 papers, researchers explore hyperbolic number-spaces, manifold-based representations, circular coordinates for angular relationships, and other structured constructions. Some papers study symmetry groups and how networks learn them. Others apply these ideas to link prediction in knowledge graphs or hierarchical clustering. The payoff is that these structures often improve generalization and interpretability because the model respects the natural structure of the data instead of trying to force it into arbitrary geometric arrangements, which means the learned patterns transfer better to new data that has the same structure. Applications span hierarchical data (protein families, organizational hierarchies, image taxonomies) and domains where symmetry matters (physics-informed learning, equivariant neural networks).

Subtheme

Specialized models for specialized tasks

A general-purpose model tries to do everything well but often does nothing optimally. Specialized models — one for speech, one for images, one for patient demographics — can be tuned and scaled for their specific problem. But training ten separate models is expensive and wasteful; parts of the problem are similar across domains. Mixture of experts is a technique where a single model contains multiple specialized pathways (experts), and a router decides which expert to use for each input. This lets the model specialize where it counts while sharing infrastructure. Federated learning tackles a different specialization problem: when data is distributed across devices or organizations that cannot share raw data, how can models learn from everyone's data simultaneously?

The difficulty in mixture of experts is ensuring experts actually specialize instead of learning redundantly. A naive mixture might have all experts learn the same thing, or the router might always choose one expert and ignore others. Load balancing is essential: you want work distributed across experts so they develop different skills. Federated learning faces privacy and communication challenges: you cannot send raw data, so you must send model updates instead, but updates are large and noisy. The model must learn coherently across many partial, asynchronous updates.

Across 14 papers, researchers develop routing mechanisms that encourage specialization, sparsity (using only a few experts per example to be efficient), and ways to balance load. Federated learning papers tackle communication efficiency (sending smaller updates), privacy preservation (ensuring central servers cannot infer individual data), and learning with heterogeneous data (different devices have different data distributions). The applications are strong: multimodal routing in large models, efficient scaling to billions of weights, and collaborative learning across medical institutions, banks, or mobile devices where data cannot leave the original organization.

Subtheme

Why self-supervised methods work: the math underneath

Why does contrastive learning work? What guarantees does a representation satisfy? How many unlabeled examples do you need before representations converge to the truth? These questions live in theory. Papers here provide mathematical foundations: probabilistic frameworks explain why certain training goals lead to good representations, the mathematics of curved spaces shows how space shape affects what patterns can be encoded, information theory bounds how much data you need and predicts which methods should work best. Theory does not always lead to practical improvements, but it builds intuition and can reveal failure modes.

Theoretical work is hard because neural networks are nonconvex and complex — most analysis requires approximations or focuses on simpler settings (linear networks, infinite width limits, or highly structured data). Researchers study what properties a 'good' representation should have: sufficient information (capturing everything relevant for downstream tasks), disentanglement (different factors of variation are separable), or invariance (insensitivity to irrelevant transformations). Some papers prove that certain algorithms converge to true solutions or characterize the sample complexity: how the number of examples needed scales with dimension, number of classes, or noise level.

Across 11 papers, researchers build theoretical foundations for contrastive learning, self-supervised clustering, multimodal alignment, and continual learning.
