PnP-Corrector: A Universal Correction Framework for Coupled Spatiotemporal Forecasting

Freeze physics simulators and train a separate error-fixer to counteract systematic bias in coupled weather and climate forecasts.

Paper explainersAll themesAI for Science

Coupled spatiotemporal forecasting predicts how multiple interacting systems (like ocean and atmosphere) evolve together. When you chain predictions forward in time, small mistakes from one subsystem feed into the other, and those mistakes amplify each other—a phenomenon called reciprocal error amplification. After many days, the forecast collapses. This paper proposes PnP-Corrector: instead of trying to improve the physics engine itself, freeze it and train a separate correction agent to learn exactly where the biases are and nudge the prediction back toward reality after each step. This works because once you observe the pattern of coupled error over many training runs, you can teach a neural network to detect and cancel that error—without retraining the physics.

Zero assumption version

Error amplification breaks long forecasts

When you forecast weather or climate, you run two simulators: one for the ocean, one for the atmosphere. They talk to each other at every step—the ocean sends heat to the air, the air pushes on the water. Each simulator has small biases (systematic mistakes it always makes). Because they are coupled, when the ocean simulator is off by a tiny amount, that error flows into the atmosphere, which then amplifies it and sends it back. The mistakes grow exponentially.

A naive approach is to train a single end-to-end neural network on the whole coupled system. But that network learns to memorize the specific biases of your training data because it is flexible enough to soak up every quirk in the training weather patterns, so when you run it on a new starting condition it fails. Retraining is also slow because you have to rerun all the physics simulations and reverse-propagate error signals through the entire network each time the physics model improves.

The problem in one sentence. Errors from coupled subsystems feed into each other and grow until the forecast becomes useless.

What the paper changes

What changes: the error correction pathway

The paper does not retrain the physics simulators. Instead, it introduces a new trainable neural network—the correction agent—that sits between each simulation step. This network learns to predict where the coupled system will be wrong and outputs a small adjustment before the next physics step.

the object it moves  =  correction agent (the neural network)
The hidden quantity

Systematic bias: the invisible drag

measured quantity  =  Systematic bias in coupled predictions

Systematic bias is the average direction and size of error that the simulators consistently make. It is not random noise; it is a repeating mistake caused by simplifications in the physics model. For instance, the ocean simulator might always predict temperatures 0.5 degrees too warm in the tropics.

The correction agent learns this bias pattern by observing how the forecast drifts from observations during training. It then proactively cancels this drift—not by changing the physics, but by nudging the state variable (temperature, pressure, salinity) at each step to counteract the known bias.

Why it works

Why decoupling works: frozen physics plus learned bias correction

The core insight is that coupled error is predictable. If you observe how the ocean simulator and atmosphere simulator are consistently wrong at the same time, you can train a network to learn that correlation. Once trained, the correction agent can apply the right nudge at each step.

Freezing the physics engines is essential: if you retrain them jointly with a neural network, the network learns to memorize the training data's biases instead of learning the underlying systematic error pattern. By keeping physics frozen, you force the correction agent to learn only the residual bias—the error that physics cannot capture. This bias generalizes better to new initial conditions because it depends only on the coupled dynamics, not on the specifics of the training set.

The DSLCast backbone architecture provides an efficient design for this agent: it processes the coupled state efficiently and outputs small, focused corrections without recomputing the entire physics step.

Math after the picture

The correction equation

First in words:

Corrected state equals physics prediction plus learned bias adjustment

Then the compact form:

s_corrected = s_physics + delta_bias(s_physics, theta_c)

Every symbol:

s_correctedthe adjusted forecast state (temperature, pressure, etc.)
s_physicsthe raw prediction from the frozen ocean and atmosphere engines
delta_biasthe correction agent's output: a small numerical adjustment
theta_cthe trainable parameters (weights) of the correction neural network
A tiny worked example
Suppose physics predicts tomorrow's ocean temperature is 20.0 degrees Celsius.
The correction agent learned that ocean predictions are systematically 0.5 degrees too warm when coupled to the atmosphere.
The agent outputs delta_bias = -0.5.
Corrected state = 20.0 + (-0.5) = 19.5 degrees—honest and closer to the observation.
After 300 days of small corrections, the forecast error is 28 percent smaller than without correction.

The correction is learned, not hard-coded, so it adapts to whatever systematic biases emerge in the coupled system.

What can go wrong

What can go wrong

Correction agent overfits to training weather. If the agent is trained only on El Niño years, it learns to correct biases specific to warm water, and fails on cold La Niña years. The fix: train on diverse climate regimes.
Frozen physics can become obsolete. If a physics model is based on outdated understanding, the correction agent can only bandage the bias, not fix the root cause. The fix: periodically retrain on improved physics models.
Correction does not work beyond training horizon. The agent learns corrections that work well out to day 300 in training. Extending to day 500 without retraining may fail because long-range patterns differ. The fix: train on longer sequences.
Done right: correction generalizes across initial conditions. Because the agent learns the bias pattern of the coupled system, not the specific training data, it works well on new forecasts starting from different ocean and atmosphere states.
What a runnable demo should prove

What a runnable demo should prove

Build a simplified coupled forecast: a toy ocean (temperature diffusion) and toy atmosphere (pressure evolution) that interact. Generate training data by running the coupled system and storing the true state. Train the physics simulators on part of the data. Then train a small correction agent to predict forecast errors from the rest of the data. Run a 30-day forecast from a new starting state. Without correction, the forecast should diverge from reality by day 20. With the correction agent, the forecast should stay accurate through day 30, with error growing much more slowly.
