SemGrad: Uncertainty from Semantic Gradients

A language model can tell you how confident it is by watching how its output predictions change when you rephrase the input in a semantically identical way.

Paper explainersAll themesInterpretability

Language models often sound confident even when they are wrong—a problem called hallucination. Right now, the best way to check how sure a model really is requires sampling many different outputs, which is slow and costly. This paper proposes a faster method: SemGrad, which avoids sampling by computing gradients instead. Gradients can be calculated in one pair of forward-backward passes—you run the model twice, once forward to compute the output, once backward to find the gradient. Sampling, by contrast, requires running the model hundreds of times to get enough variety in outputs. Instead of sampling, it watches how stable the model's predictions are when you rephrase the input without changing the meaning. If the outputs stay the same across paraphrases, the model is confident. If they bounce around, the model is uncertain. The paper measures this stability using gradients (which direction the predictions lean) computed in semantic space—the space where meaning lives—rather than in the model's internal weights (the numerical values that define how the model works).

Zero assumption version

Uncertainty is expensive to measure

Today's large language models are like overconfident students. Ask them a question, and they give you an answer with absolute authority, even if they are making it up. A person who does not know the answer should say so, but a language model does not flag its own doubts.

The existing solution is sampling: ask the model the same question many times, in slightly different ways, and see how much the answers vary. High variation means low confidence. But asking the model hundreds of times is slow. For a model with a vocabulary of tens of thousands of words, the number of possible outputs is astronomically large, so you need many samples to cover the true spread. This is computationally expensive and often produces noisy estimates.

A person might instead notice: does the model's answer change if I rephrase the question but keep the meaning the same? If the answer is stable, the model is probably confident. If it bounces around, the model is probably unsure. The naive approach is to manually create paraphrases and run the model again—still expensive. The paper asks: can we measure this stability mathematically without sampling?

The paper's insight in one sentence. Watch how the model's output predictions tilt when you perturb the input semantically, not by sampling but by computing gradients in the space where meaning is encoded.

The algorithm as a flow

What it actually does

Find the semantic layer

Which layer in the model best preserves the meaning of the input? Not the first (lexical only) or the last (too late).

Create semantic twins

For each input, generate paraphrases that mean the same thing but are phrased differently.

Compare hidden states

At the semantic layer, compute how similar the model's internal representations are for the original and each paraphrase.

Compute gradients in semantic space

Find the direction in which the output probabilities lean, with respect to changes in that semantic layer.

Read off the uncertainty

Large stable gradients across paraphrases mean the model is confident. Fragile or bouncy gradients mean it is unsure.

What the paper changes

What the paper changes

Instead of computing gradients with respect to the model's parameters (the numbers that define how the model works), SemGrad computes gradients with respect to the model's hidden states (the internal representations the model builds as it reads the input). Specifically, it targets the layer and token position that best preserve semantic meaning. This one change makes the uncertainty signal faster, because parameter gradients require working backward through every weight in the model, while semantic-layer gradients stop early at the target layer. It makes the signal more reliable for free-form generation, because free-form text has many valid answers, so parameter gradients (which optimize for one training target) produce noisy estimates, whereas semantic gradients capture the true variability in what the model can plausibly output.

The hidden quantity

The hidden quantity: Semantic Preservation Score

measured quantity  =  Semantic Preservation Score (SPS)

The SPS measures how faithfully a layer in the model preserves the input's meaning. At each layer, the model builds a hidden representation (an internal list of numbers encoding what it has read so far). Some layers are noisy and discard semantic content; others capture meaning well. The SPS computes this by checking: for each input query, generate paraphrases (rephrasings) with the same meaning. Forward both the original and each paraphrase through the model. At layer l, compare how similar the hidden representations are between the original and the paraphrase. Layers with high SPS keep the representations similar—they preserve meaning. Layers with low SPS let them drift—they lose meaning or mix in noise.

The paper uses SPS to identify which layer to use for computing gradients. Intuition: if you compute gradients with respect to a layer that discards semantics, the gradient signal will be noisy and unstable. If you use a layer with high SPS, the signal is clean. Experiments confirm that layers with high SPS produce the best uncertainty estimates.

Why it works

Why stable outputs reveal confidence

Here is the intuition: if a language model has truly learned the right answer to a question, that answer should stay consistent. Imagine a human expert. Ask them the question in plain English, then ask again in a more formal tone, then in a casual tone—the expert's answer should be essentially the same, because they understood the concept, not just a particular phrasing. A language model that is merely memorizing or hallucinating, by contrast, easily breaks. Tiny changes in phrasing push it off the memorized path.

The paper operationalizes this as follows: compute the gradient of the output probabilities with respect to the hidden states at the semantic layer. A gradient is a compass needle pointing in the direction where the output error goes uphill—it tells you which direction to nudge the hidden states to change the output. If the model is confident, this gradient should be stable across paraphrases. Why? Because the hidden states at the semantic layer all encode the same meaning, so the lever-arms for changing the output are proportional. If the gradients wildly change between paraphrases, it means the model's output is fragile—small shifts in how the semantic meaning is encoded cause large shifts in the output probabilities. That fragility is a symptom of low confidence.

The uncertainty signal

First in words:

uncertainty_score = mean of gradient magnitudes across semantic-equivalent inputs, weighted to suppress linguistic noise

Then the compact form:

UQ = (1/K) * sum_{k=0}^{K} ||gradient(output_prob, h_semantic) @ paraphrase_k||_2

Every symbol:

UQUncertainty quantification score (higher = lower confidence)
KNumber of paraphrases generated for the input
gradient(output_prob, h_semantic)How much output probabilities lean with respect to changes in the semantic layer's hidden state
h_semanticHidden state at the layer with high Semantic Preservation Score
||·||_2Length of the vector (Euclidean norm)
@For each
A tiny worked example
Input: 'What is the capital of France?'
Paraphrase 1: 'What city is the capital of France?'
Paraphrase 2: 'Name the capital of France.'
Forward through model, extract gradients at the semantic layer (layer 8 of 12, identified by high SPS).
Gradient norm at paraphrase 1: 2.3 (how much outputs lean if we perturb layer 8 for version 1)
Gradient norm at paraphrase 2: 2.1 (similar norm for version 2)
Gradient norm at paraphrase 3: 2.4 (version 3 also similar)
Mean = (2.3 + 2.1 + 2.4) / 3 = 2.27
Low variation (2.1 to 2.4) means stable output across paraphrases → high confidence.
Now try: 'Is Paris the capital of France?' (ambiguous—could be a trick question).
Gradient norm paraphrase 1: 0.8 (weak lean when perturbed)
Gradient norm paraphrase 2: 3.2 (strong lean for a different phrasing)
Gradient norm paraphrase 3: 1.5 (inconsistent)
Mean = (0.8 + 3.2 + 1.5) / 3 = 1.83, but high variation (0.8 to 3.2) → model is uncertain, outputs fragile.

The math formalizes the intuition: if a model is confident, the gradient it computes should be stable (similar size and direction) when you feed it semantically equivalent inputs. Fragile gradients reveal brittle, low-confidence outputs.

What can go wrong

What can go wrong

Paraphrase generation is imperfect. If your semantic-equivalent paraphrases are not actually equivalent (they drift in meaning), the SPS will misidentify the semantic layer, and the uncertainty estimate will be wrong. The method is only as good as the paraphrases.
Single-answer questions fool the method. For questions with only one correct answer, the model's parameter gradients (old-school) align perfectly with its training objective and produce sharper uncertainty signals than semantic gradients. SemGrad shines on open-ended or multi-answer problems, not on factoid lookup.
Low-randomness regimes lose signal. When the ground-truth answer is highly certain (only one clearly right answer), there is less inherent randomness to measure, and semantic gradients add numerical noise because they are measuring shifts in a space where very little shifts. In these regimes, parameter gradients work better, because they are aligned with the model's training objective (which optimized for the single correct answer).
Done right: hybrid approach. The paper proposes HybridGrad, which blends semantic and parameter gradients, taking the best of both worlds. This hybrid works well across diverse question types.
What a runnable demo should prove

What a runnable demo should prove

Build a simple demo that shows: given a language model and a question with multiple valid answers (e.g., 'Name a city in France'), run SemGrad to compute an uncertainty score. Then sample 20 outputs from the model. Count how many of those samples are correct. The uncertainty score should predict this: high uncertainty means low fraction correct (because high uncertainty indicates the model's outputs are scattered across paraphrases, a sign it is not confident in any one answer), and low uncertainty means high fraction correct (because low uncertainty means the outputs stay consistent across paraphrases, indicating the model has locked onto a reliable answer). Additionally, time how long it takes to compute SemGrad vs. sampling 20 times. SemGrad should be 10 to 100 times faster because it uses a single pair of forward-backward passes, while sampling requires 20 separate forward passes.

Prediction accuracy = fraction of paraphrases where high SPS layer gradients anticorrelate with ground-truth answer variance; Speed ratio = time_for_sampling / time_for_SemGrad

The core insight should be undeniable: when a model is truly confident, its outputs are stable across paraphrases (because a confident model understands the meaning and gives the same answer regardless of wording), and gradients capture that stability without sampling, because they measure how fragile the output is to perturbations in semantic space.
