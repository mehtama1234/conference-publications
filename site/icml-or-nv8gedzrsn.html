V-LynX: Token Interface Alignment for Video+X LLMs

Use the internal visual-token interface already learned by a Video LLM as the integration target for a new modality, so extra sensors can join the model through lightweight alignment instead of a heavy paired encoder.

Paper explainersAll themesMultimodal

Adding a new modality to a Video LLM is usually expensive because the standard recipe trains a dedicated encoder for that modality and then learns a strong paired mapping into the language model's input space. That requires large paired datasets and substantial compute. V-LynX argues that a trained Video LLM already contains a useful internal interface: visual tokens, meaning the code units produced for video content, inside the model behave as a stable representation that downstream components know how to process. Rather than rebuild the entire pipeline for each new modality, the paper introduces a lightweight auxiliary pathway that learns to produce tokens compatible with that internal interface. The method aligns the new pathway with the frozen video model using attention-response matching, meaning matching how later layers focus on tokens, and distribution matching, meaning matching the overall statistical shape of the representations, on unpaired unimodal data. The core idea is that if the new modality can generate token patterns that the Video LLM treats the same way it treats native visual tokens, then the model can inherit existing reusable video knowledge without requiring full paired supervision.

Zero assumption version

Why adding modalities to Video LLMs is so costly

A Video LLM already knows how to process video frames into token sequences that interact well with the language model. When researchers add audio, 3D information, multi-view video, or other sensory inputs, they often start by building a modality-specific encoder and then train it with paired supervision so the produced feature lists line up with what the rest of the model expects.

That approach has two weaknesses. First, it is expensive in data because paired examples across modalities are difficult to collect at scale. Second, it underuses the internal structure of the trained Video LLM. The model has already learned a representation format, attention pattern, and downstream interface for visual tokens. Throwing that away and learning a fresh modality mapping from scratch creates unnecessary work.

The paper's key observation is that visual tokens are not just transient outputs from a vision encoder. Inside the Video LLM they act as standalone entities that participate in a continuous representational interface. If a new modality can land in that interface, the rest of the model can process it with minimal changes.

The main change. Treat the visual-token interface of a frozen Video LLM as the target representation for new modalities, then learn a lightweight alignment path into that interface using unpaired data.

The algorithm as a flow

What it actually does

Freeze the native Video LLM pathway.

Keep the original vision encoder and downstream language components fixed so their learned video knowledge is preserved.

Add an auxiliary modality path.

Build a lightweight encoder or adapter for the new modality in parallel with the frozen vision encoder.

Target the internal token interface.

Train the auxiliary path to produce tokens that are compatible with the internal representation the Video LLM already expects.

Align internal behavior.

Match attention responses and feature statistics between native visual tokens and the new modality tokens using unpaired unimodal data.

Run multimodal reasoning.

Use the aligned tokens in downstream tasks such as audio-visual question answering or multi-view reasoning without retraining the full model.

What the paper changes

What the paper changes

The paper changes the integration target for new modalities. Instead of aligning a new modality directly to labels or to the language model from scratch, it aligns the new modality to the Video LLM's existing internal token interface.

the object it moves  =  the representation interface used to add a new modality to a Video LLM
The hidden quantity

The hidden quantity

measured quantity  =  interface compatibility between new-modality tokens and native visual tokens

The decisive hidden quantity is whether the tokens generated from the new modality behave the way native visual tokens behave inside the model. Compatibility here is not only about matching raw feature values. It includes whether downstream attention layers respond to those tokens similarly and whether the tokens occupy a similar statistical region of the learned representation space.

V-LynX estimates that quantity indirectly through alignment objectives. If the auxiliary tokens trigger comparable attention patterns and follow similar distributional structure, the frozen downstream layers can process them without large mismatch. This allows the model to transfer reusable video knowledge to the new modality even when the training data for the new modality is unpaired with video, because the supervision comes from matching internal model behavior rather than from matched video-new-modality examples.

Why it works

Why interface alignment is enough

A trained Video LLM has already learned several expensive things: how tokenized visual evidence should be structured, how attention layers react to those tokens, and how downstream language reasoning turns them into task answers. V-LynX treats that internal machinery as an asset. The new modality does not need to relearn the entire multimodal stack if it can enter at the point where the rest of the model already knows what to do.

The auxiliary pathway stays lightweight because it is only responsible for interface compatibility, not for rebuilding the full representational hierarchy of the original vision tower. Attention-response alignment matters because downstream reasoning is sensitive to how tokens drive attention, not only to their raw coordinates. Statistical distribution alignment matters because even if a token encodes the right information, large distribution mismatch can cause the frozen layers to process it unreliably.

The use of unpaired unimodal data is important because it removes a major practical bottleneck. The method does not require synchronized video-audio or video-3D examples for every new modality. Instead, it learns compatibility from the internal behavior of the frozen model, which is a much cheaper supervision source because those signals come from the model's own native video pathway rather than from new human-labeled cross-modal pairs.

A compact alignment objective

First in words:

Train the auxiliary pathway to minimize the mismatch between native visual-token behavior and new-modality-token behavior, measured through attention and distribution terms.

Then the compact form:

L = L_attn + lambda * L_dist

Every symbol:

Ltotal interface alignment loss
L_attnloss that matches attention responses induced by native and auxiliary tokens
L_distloss that matches statistical distributions of the token representations
lambdaweight balancing distribution alignment against attention-response alignment
A tiny worked example
Suppose the frozen Video LLM gives strong attention to motion-related visual tokens when answering a question about an action.
The auxiliary audio pathway should produce tokens that trigger a similar downstream attention focus when the sound pattern carries the same action evidence.
If the auxiliary tokens also occupy a similar representation distribution, the frozen layers can process them without reconfiguration.
Reducing both attention mismatch and distribution mismatch makes the new tokens more usable for the existing reasoning stack.

The paper's central claim is that matching internal interface behavior is a sufficient integration target for adding new modalities efficiently.

What can go wrong

What can go wrong

The new modality may contain information video tokens cannot express well. If the modality carries task-critical structure outside the expressive range of the visual-token interface, forcing compatibility may discard useful information.
Attention matching can be superficial. Two token sets can induce similar attention patterns while still differing in deeper semantics, so response matching alone may not guarantee reliable understanding.
Frozen components limit adaptation. Preserving the original Video LLM avoids catastrophic drift, but it also prevents the downstream model from adjusting if the new modality requires fundamentally different reasoning behavior.
Done right. The method is strongest when the new modality is complementary to video and its relevant information can be expressed through the existing token-processing interface.
What a runnable demo should prove

What a runnable demo should prove

Take a pretrained Video LLM and add a new modality such as audio through two routes: a heavy paired encoder baseline and the V-LynX auxiliary pathway. Train V-LynX with unpaired audio and unpaired video data using the interface-alignment losses. Evaluate both systems on a task where the new modality matters, such as audio-visual question answering.

The demo should show that the lightweight path reaches competitive or better task performance with less paired supervision, because it reuses the frozen model's existing interface instead of learning a full new paired tower. It should also inspect internal attention maps or token statistics to verify that the auxiliary tokens become compatible with the frozen visual-token interface.

interface_gap = attention_mismatch + lambda * distribution_mismatch

A convincing result is lower interface_gap together with strong downstream accuracy, because that shows the new modality was integrated by fitting the existing internal interface rather than by brute-force retraining.
