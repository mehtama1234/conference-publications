Learning from the shape and structure of data

Papers that use geometric and topological ideas like symmetries, manifolds, and higher-dimensional shapes to help models understand data structure more deeply.

All themesField mapMathematicsAll explainers
What this is

Beyond just connections, data often has hidden structure—symmetries, shapes, patterns that repeat in predictable ways. A molecule looks the same if you rotate it or reflect it, so the model should learn the same representation regardless of how the atoms are drawn on paper, because the molecule hasn't changed. A social network has community structure: groups of people who are tightly connected internally but loosely connected to other groups. High-dimensional data often lives on lower-dimensional manifolds, curved surfaces in space. These geometric and topological ideas—which is fancy language for 'symmetries and shapes'—can help models learn more efficiently because the model doesn't waste capacity learning the same pattern multiple times.

The challenge is that standard neural networks don't inherently respect these symmetries and structures. If you rotate a molecule's coordinates, the model might give a different answer even though the molecule didn't change. This wastes the model's learning capacity: it has to learn the same pattern multiple times for each rotation. Similarly, if you know data lives on a 2D surface in 3D space, treating it as full 3D data is wasteful.

Researchers tackle this by building models that are equivariant—meaning if you transform the input (rotate a molecule, permute nodes), the output transforms in the same predictable way. They use Riemannian spaces—curved surfaces where distance is measured differently—and hyperbolic spaces—weird surfaces where distances work differently—to reflect the actual structure of the data. They learn manifolds—the underlying low-dimensional shapes where data actually lives. These approaches make models more sample-efficient because they respect these structures instead of making the model learn them by accident.

How the work breaks down

This subtheme splits into five directions: building equivariant networks that respect symmetries, using curved spaces like hyperbolic distance to capture hierarchical structure, reconstructing 3D shapes correctly from raw data, transferring graph knowledge across tasks and domains, and discovering or enforcing geometric structure through learning. These split because different types of data have different geometric properties—molecules have rotational symmetry, hierarchies benefit from hyperbolic distance where space expands exponentially and captures parent-child relationships naturally, point clouds need correct topology, and abstract graph tasks benefit from geometric foundations.

Equivariant Networks: Respecting Symmetries

When you rotate a molecule or permute the nodes in a graph, the underlying data hasn't changed—only its representation on paper has. Standard neural networks don't understand this: they treat a rotated molecule as brand new and learn the same pattern multiple times. This wastes the model's learning capacity. Equivariant networks solve this by building in symmetry awareness: if you transform the input in a specific way, the output transforms in a predictable way too, following the same mathematical rules.

Adaptive Canonicalization solves a classic problem: a model with universal approximation (meaning it can theoretically learn any function) normally needs data augmentation, where you feed in rotated copies to teach the network the symmetry. This paper skips data augmentation yet still achieves universal approximation because the architecture itself encodes the symmetry (the model is designed so rotating inputs produces rotated outputs automatically), and this approach beats both standard equivariant networks and hand-crafted canonicalization on molecules, proteins, and point clouds. Equivariant Neural Networks for General Linear Symmetries achieves similar performance to strong baselines but uses far fewer weight values (parameters) and less computation, working across diverse symmetry groups like rotations and reflections, so you don't need as large a model to respect symmetry. Any-Subgroup Equivariant Networks handles the harder case: a single network that respects multiple different symmetry types at once, outperforming separate specialized models on tasks where you need to switch between symmetry types. RECON learns to discover pose—how a molecule sits in space—without any labels, so it finds the orientation automatically, then can detect rotations the model never saw during training and improve pre-trained models without retraining, making old models work on new rotations. Reducing Symmetry Increase in Equivariant Neural Networks proves theoretically that stacking equivariant layers can accidentally grow the symmetry group in ways you don't want, explains why this happens based on the feature space structure, and validates the prediction on real molecular data.

These papers agree on the core idea: symmetry is a constraint the model should learn to respect, not a pattern it should discover by accident. They compete on how to build the equivariance efficiently and what symmetries to handle—some focus on continuous rotations and reflections, others on discrete permutations, others on multiple types at once.

Hyperbolic Spaces: Capturing Hierarchies

In regular Euclidean space, distance works the way you're used to: it follows straight lines and flat surfaces. But hierarchical data—trees, taxonomies, code structure—lives naturally in hyperbolic space, where distances expand exponentially as you move away from the center. A hyperbolic space offers exponentially more room at larger radii, so children spread out from parents easily while staying close to other children, matching how hierarchies look in trees. Standard Euclidean models waste capacity trying to cram hierarchy into flat space.

Intrinsic Lorentz Neural Network beats other hyperbolic models while using less computation, and consistently beats Euclidean models on image classification (CIFAR-10/100) and genomic data, proving hyperbolic approaches work on diverse tasks. Hyperbolic Representation Learning for Program Reasoning demonstrates that program structure fits hyperbolic space because code has a tree hierarchy—the model beats a Euclidean baseline called GraphCodeBERT on code clone detection (finding copied functions), code completion, and link prediction, with the biggest wins on tasks requiring deep tree structure understanding in the codebase, because hyperbolic distances expand exponentially and match how code branches spread. HVAE uses hyperbolic space in a variational autoencoder to separate user intents across multiple domains, working better when you have long-tail distributions (many rare categories) and little overlap between domains, because hyperbolic space naturally preserves the tree-like distances in skewed data. Hyperbolic Representations of Training Dynamics studies how network structure emerges during training by using hyperbolic representations over time, revealing why neural networks self-organize the way they do during training.

These papers agree that hyperbolic space naturally fits hierarchical and tree-like data, competing on how to implement hyperbolic operations efficiently and what downstream tasks benefit most.

Shape Reconstruction from Scattered Points

When you scan a 3D object with a laser or depth camera, you get a scattered cloud of points. Reconstructing a clean mesh (a surface made of triangles) from this noisy point cloud is hard: you need to infer which points should connect, handle noise and outliers, and guarantee the surface is topologically correct—no holes, tears, or self-intersections. Standard mesh reconstruction methods often fail on these guarantees.

Guaranteed Simply Connected Mesh Reconstruction solves this by adding topological guarantees: the mesh is guaranteed to be simply connected (one surface with no holes) and approximates the input points correctly on both real scans and synthetic data. SE(n)-Invariant Flow Matching tackles a related problem: shape reassembly, like 3D jigsaw puzzles where fractured pieces need to snap together. The trick is to not learn global position and rotation at each step of the diffusion process (the model factors them out), so instead the model focuses on how pieces align locally to each other. By removing the global pose from what the model needs to learn, accuracy improves on both 2D polygonal jigsaw puzzles and 3D fracture reassembly, because the model respects the symmetry that the same shape looks identical no matter where or how it's rotated.

These papers address the same challenge—inferring 3D structure from incomplete information—but target different problems: one focuses on surface topology from point clouds, the other on rigid reassembly. Both respect spatial symmetries to learn efficiently.

Graph Foundations: Transfer and Scale

Modern machine learning needs models that transfer: a model trained on one domain should work on another with little retraining, or combine knowledge from multiple tasks without relearning. For graphs, this is hard because different tasks use different graph structures and different features. Researchers are building graph foundation models—large pretrained models like BERT or GPT-2 but for graphs—that learn reusable structure.

G-Merging shows how to merge multiple graph models trained on different tasks into one model without losing performance. The trick is treating weight values as objects that can be combined carefully, achieving efficiency close to individual finetuned models while sharing 70-80% of weight values across tasks. Multi-Domain Transferable Graph Gluing validates a principle: larger datasets make models transfer better across domains, proving this pattern holds for graphs and demonstrating superior performance on diverse graph tasks by treating graph similarity as a distance that can be measured. Are Common Substructures Transferable asks: do subgraph patterns like triangles or cliques transfer across different graphs? The paper uses a framework (GAUGE) based on Riemannian spaces and vector bundles (a mathematical tool to track how local information changes), and the model beats baselines when the goal is predicting new links or determining if two graphs have the same structure (zero-shot link prediction and graph isomorphism). Structure-Centric Graph Foundation Model models graphs as metric measure spaces (spaces where you can measure distance and size between all pairs of points) and introduces learnable geometric bases, a shared coordinate system that helps the model understand new graphs structurally by representing graph structure as coordinates in that space.

These papers all agree on the goal—reusable, transferable graph models—and compete on how to represent graph structure and merge knowledge efficiently.

Discovering and Using Symmetries and Topology

Sometimes the geometric structure isn't given in the data; the model has to discover it or work with the curved spaces that natural data inhabits. This includes finding symmetry groups hidden in data, learning on curved surfaces instead of flat spaces, and using topological features (like connected components and cycles) to understand graphs.

Equivariant Neural Networks for General Linear Symmetries achieves competitive performance with fewer weight values by building symmetry discovery into the architecture for groups like rotations and reflections across diverse tasks. Discovering Symmetry Groups with Flow Matching introduces LieFlow, which finds both continuous symmetries (like rotations) and discrete symmetries (like reflections) in one unified approach, beating earlier methods on both synthetic and real-world data by a large margin. Fast Mixture of Curvature-Aware Experts applies Riemannian math (the mathematics of curved spaces) to graph attention: it learns which part of the graph should work on which curved surface, achieving 27.5% speedup and 52.6% memory reduction because different parts of a graph naturally fit different curved spaces more efficiently than flat space. Interpretable Discovery of One-parameter Subgroups finds continuous symmetries directly from data with guaranteed correctness, handling elliptic, hyperbolic, and parabolic regimes (different types of rotation group symmetries). TopoFormer combines topological features with attention-based learning for graphs, performing as well as pure GNN models or topology-only models while keeping computation predictable and efficient. VBA learns geometric representations using vector bundles (a mathematical tool to encode local curvature and direction), achieving 3-5% higher accuracy than attention-based models on single-cell RNA sequencing because the curved representation fits biological cell structure better, and shows better performance on spatial transcriptomics and 3D point clouds.

These papers split between discovering hidden structure and learning on curved surfaces that naturally fit the data, agreeing that topology and curved spaces are more efficient than flat-space learning because they match the actual structure of the data.
