CogMoE: Signal-Quality-Guided Multimodal MoE for Cognitive Load Prediction

Estimate how trustworthy each physiological stream is, repair damaged parts, and route each segment to the expert best suited for clean, noisy, or reconstructed signals before predicting cognitive load.

Paper explainersAll themesOther

Cognitive-load prediction from EEG, ECG, EDA, and gaze data is hard outside the lab because those signals arrive with motion artifacts, dropouts, and timing drift. Many multimodal models fuse all streams as if they were equally clean, which lets a bad stream pollute the rest. CogMoE starts by measuring signal quality and repairing damaged regions. It then uses a mixture-of-experts block, meaning a model with several specialized submodels and a gate that decides which one to trust, to send clean regions to a light expert, noisy regions to a noise-tolerant expert, and recovered regions to a cross-modal refinement expert. The whole system is trained with a loss that combines task accuracy, recovery quality, and balanced gate usage.

Zero assumption version

Why multimodal fusion fails on messy physiological data

Real physiological data are uneven. A segment of EEG may be clean while gaze is missing, or ECG may be usable while EDA is dominated by artifacts. A model that merges all streams with one fixed rule assumes equal trust in every input, so one bad stream can drag the fused representation away from the real mental state.

There is also a timing problem. Different sensors drift, arrive at different rates, or lose chunks of data. If the streams are not aligned, the model can combine values from different moments and learn a false relation between physiology and label.

The paper treats signal quality as a first-class input. Before prediction, it asks which regions are clean, which are missing, and which can be repaired from the other streams.

The paper's move. Use a two-stage pipeline: first align and repair multimodal signals with quality masks, then route each fused segment through experts chosen by measured signal quality.

The algorithm as a flow

What it actually does

Convert streams into aligned feature maps

Apply a time-frequency transform to each modality so that transient structure and rhythm are easier to compare across sensors.

Estimate quality and missingness

Build quality masks that mark clean, noisy, and missing regions by comparing streams and measuring signal-to-noise indicators.

Recover damaged regions

Use low-rank completion, meaning reconstruction from shared low-dimensional structure, to fill corrupted patches with support from the other modalities.

Fuse and route

Encode recovered features, mix cross-modal context, and let a gate choose among three experts according to quality scores.

Train with a joint loss

Optimize task prediction together with noise suppression, refinement, and balanced expert usage so that the gate does not collapse onto one branch.

What the paper changes

What the paper changes

The paper changes fusion from modality-first to quality-first. The main decision is no longer which sensor a segment came from, but how trustworthy that segment is.

The hidden quantity

The hidden quantity

measured quantity  =  Per-segment trust in each modality

The class label is visible, but the useful hidden state is reliability: how much the model should trust each stream at each moment. Two windows can have the same raw EEG values and still deserve different treatment if one was recorded cleanly and the other contains motion noise or missing chunks.

CogMoE estimates that hidden reliability with quality scores and masks. Those scores do not directly predict cognitive load. They control which parts of the fused signal should be copied, denoised, or reconstructed before the final decision.

Why it works

Why quality-aware routing helps

The first stage reduces damage before fusion. Converting each stream into a time-frequency view makes local corruption easier to isolate, because an artifact often affects a bounded region rather than the whole window. Cross-modal alignment then compares sensors at matching moments, so recovery uses information that is relevant in time rather than pulling from a shifted segment.

The second stage separates cases that need different computation. Clean segments do not need heavy denoising, so the high-fidelity expert can preserve detail with a short path. Noisy segments need normalization and residual correction, so the noise-resilient expert is built for that regime. Recovered or masked regions need information from other streams, so the contextual refinement expert uses cross-modal mixing to infer what the damaged stream likely should contain.

The loss matters because routing alone can become unstable. If the gate sends everything to one expert, specialization never forms. The paper adds gate regularization, meaning a penalty on unbalanced expert use, and reconstruction terms so the model has a reason to spread traffic according to quality and a reason to make the repaired regions consistent with the clean evidence around them, because those penalties directly raise the cost of expert collapse and poor repair.

The routing signal and training loss

First in words:

Each modality gets a quality score built from signal-to-noise ratio, missingness, and auto-correlation reliability. The gate uses that score to weight the experts. Training then adds task loss, noise loss, refinement loss, and a balance penalty so one expert does not absorb all traffic.

Then the compact form:

L = L_task + gamma * L_noise + lambda * L_refine + beta(t) * L_gate

Every symbol:

L_taskprediction loss for cognitive-load labels
L_noisepenalty for leaving noise artifacts in recovered features
L_refinepenalty for poor reconstruction of damaged regions
L_gatepenalty when expert usage becomes too uneven
gamma, lambda, beta(t)weights that control the strength of those penalties over training
A tiny worked example
Suppose a window has clean EEG, noisy ECG, missing gaze, and usable EDA.
The quality scores push most clean segments toward the high-fidelity expert.
The noisy ECG segment gets higher weight on the noise-resilient expert.
The missing gaze region is reconstructed and then gets higher weight on the contextual refinement expert.
The total loss falls only if the final label is right and the gate keeps these specialists active rather than sending every case to one branch.

The loss joins prediction and routing because the model should not only classify the label, it should also use signal quality to decide how each segment is processed.

What can go wrong

What can go wrong

Quality estimates can be wrong. If the gate thinks a damaged segment is clean, it sends that segment through the wrong expert, so the model can preserve noise instead of correcting it because the clean-data branch is designed to keep detail rather than remove corruption.
Recovery can invent structure. Low-rank completion fills missing regions from shared patterns across streams. If the true event is rare or modality-specific, the repair step can overwrite it with a more common pattern.
Expert collapse can still happen. If one expert starts winning too often early in training, the others receive too little traffic to specialize, which weakens the point of the mixture design.
Done right. The approach is useful when signal quality varies a lot over time, because it lets the model change how it fuses information instead of treating all windows as equally trustworthy.

A good run shows clean windows going mostly to the high-fidelity expert, noisy windows to the noise-resilient expert, and reconstructed regions to the contextual expert. That trace matters because the main claim is not only better accuracy but better use of unreliable data.
