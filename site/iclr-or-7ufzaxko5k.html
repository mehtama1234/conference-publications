Two-Way Is Better Than One: Bidirectional Alignment with Cycle Consistency for Exemplar-Free Class-Incremental Learning

When a class-incremental learner cannot keep old data, old class summaries drift as new classes arrive. This paper adds two transport maps and a round-trip check so old and new feature spaces stay mutually compatible.

Paper explainersAll themesOther

Class-incremental learning adds new classes over time. In the exemplar-free setting, the learner is not allowed to keep old training examples. That makes forgetting severe, because the internal feature space keeps moving while the stored summaries for old classes stay behind. Many methods try to patch this with a one-way transport map from one feature space to another. This paper argues that one-way transport is not enough, because it can line up one direction while still breaking the return trip. The proposed fix is to learn two transport maps together, one from old to new and one from new to old, and to penalize disagreement after a full round trip.

Zero assumption version

Why old classes vanish when the feature space moves

A class-incremental learner sees tasks one after another. After task one, it may know cats and dogs. After task two, it must add cars and planes. If the system cannot keep old images, it has to rely on stored class summaries from earlier tasks.

The trouble is that the internal feature space changes each time the model learns a new task. A stored summary for cats was created in the old space, but the classifier now reads points in the new space. If those spaces no longer match, the old summary lands in the wrong place and the model forgets old classes.

A one-way correction map can push old summaries into the new space, but it may still distort distances and class boundaries because nothing checks whether the new space can map back consistently.

Core issue. Old class summaries fail not because they disappear, but because the coordinate system around them changes. The paper keeps the old and new coordinate systems compatible in both directions.

The algorithm as a flow

What it actually does

Store old class summaries.

After each task, keep class means and related statistics instead of raw old examples.

Learn the next task in a new feature space.

As the model adapts to new classes, its internal coordinates change.

Train two transport maps.

One map sends old summaries into the new space, and the other sends new features back toward the old space.

Penalize round-trip mismatch.

A point that goes forward and then back should return close to where it started, because that forces both maps to agree on the same relative layout.

Classify with aligned summaries.

Use the transported summaries for old classes together with the new classes, so old decisions remain stable while new learning continues.

What the paper changes

What the paper changes

The paper changes the drift-repair step in exemplar-free class-incremental learning. Instead of fitting a one-way correction from old features to new features, it learns a coupled pair of maps tied together by a round-trip consistency loss.

the object it moves  =  the drift-compensation map between old and new feature spaces
The hidden quantity

The hidden quantity

measured quantity  =  round-trip distortion between the old and new feature spaces

The hidden quantity is round-trip distortion. Start from an old feature point, move it into the new space, then move it back. If the result shifts a lot, the two spaces disagree about where that point belongs.

That matters because class summaries are useful only if their neighborhoods survive the move. Small round-trip distortion means old summaries keep roughly the same relations after transport, so the classifier can still separate old classes.

Why it works

Why the two-way check protects old classes

A one-way map can succeed at sending one set of stored points into the new space while still warping distances in a way that hurts classification. That is possible because the map is judged only on one trip. The paper adds the return trip, which puts pressure on the pair of maps to preserve more of the original structure.

That helps old classes because class summaries are not isolated points. They stand for regions in space. If the transport keeps means and spread closer to their old arrangement, old class score gaps change less, so the old winner is less likely to flip after learning new tasks.

Math after the picture

Two maps plus a round-trip penalty

First in words:

The method learns a forward map from the old space to the new space and a backward map from the new space to the old space. Training penalizes a point if a trip forward and back does not return close to the start.

Then the compact form:

total_loss = task_loss + alignment_loss + cycle_loss, where cycle_loss penalizes old_point != backward(forward(old_point)) and new_point != forward(backward(new_point))

Every symbol:

task_lossthe usual loss for learning the current task
alignment_lossthe part that aligns old class summaries with the new space
cycle_lossthe penalty for failing to return close to the starting point after a round trip
forwardthe map from old features into new features
backwardthe map from new features back into old features
A tiny worked example
Suppose an old class mean sits at location 10 in the old space.
A one-way map sends it to 18 in the new space.
If the backward map sends 18 back to 9.8, the round-trip error is small and the pair is consistent.
If it sends 18 back to 6, the pair is inconsistent and the cycle loss is large.
Training prefers the first case because small round-trip error means old summaries keep their original placement more faithfully.

The paper's full analysis studies how this penalty pulls the transport toward near-length-preserving behavior, which in turn keeps old class decisions more stable.

What can go wrong

What can go wrong

The stored summaries may already be too crude. If class means and spread do not describe the old classes well, transport cannot fully recover what was lost because the method never sees raw old examples.
The maps may be too weak or too rigid. If the transport family cannot express the true drift, alignment stays poor. If it is too flexible, it may fit the cycle check without preserving the class structure the classifier needs.
Round-trip consistency does not guarantee perfect classification. A small round-trip error helps, but class boundaries can still move in harmful ways because keeping points close after a round trip is only a proxy for keeping all decision gaps intact.
Done right. The method works best when old classes are summarized well enough and the transport maps are expressive but controlled, because then the cycle penalty guides them toward structure-preserving alignment instead of arbitrary matching.
What a runnable demo should prove

What a runnable demo should prove

Train a small class-incremental image learner on a sequence of class blocks. After each block, keep only class summaries and forbid replay of old images. Compare three systems: no drift repair, one-way repair, and the paper's two-way repair.

Measure old-class accuracy after each task, plus a direct round-trip error score for stored class means. The demo should show that the two-way method keeps old-class accuracy higher because the round-trip score stays lower as more tasks arrive.

forgetting_after_t = best_old_accuracy_before_t - current_old_accuracy_at_t

The key result is not only higher old-class accuracy, but the link between that accuracy and smaller round-trip distortion, because that shows why the method works.
