Teaching robots to see and act from images

Papers developing vision-language-action models that let robots understand images and photos to perform manipulation and navigation tasks—the core challenge is predicting what action to take from visual input alone.

All themesField mapMathematicsAll explainers
What this is

The most direct way to teach a robot is to show it images or videos and let it learn the pattern: 'when you see this scene, do this action.' This is vision-language-action learning. A robot sees an image of a table with blocks. It learns to recognize the scene and decide: 'I should grasp the red block' or 'I should move left.' The appeal is obvious—we teach humans the same way, by showing and demonstrating. But this turns out to be extremely hard in practice because the robot has to compress everything about a scene into one decision. The scene contains infinite visual details, but only a few of them matter for the task. Lighting changes, the camera angle shifts, the size of the object varies, yet the action should stay roughly the same. How does the robot learn which details to ignore and which to attend to?

The core difficulty is that predicting an action from a single image requires the robot to hallucinate what will happen next. If the robot grasps a soft object, it will deform differently than if it grasps a rigid one. If it places an object on a slanted surface, it might roll. The robot cannot 'see' this without reaching into the future. Traditional computer vision alone is not enough—the model has to develop an intuition for physics, the consequences of motion, and how the world will respond. Building this intuition only from images is like learning to drive a car from photographs.

Papers in this area use several approaches. Some train large neural networks (inspired by large language models) on many robot videos, teaching them to predict not just what the robot should do, but also to understand what is happening in the scene. Others combine visual learning with language—so a human can say 'pick up the small red cube' and the robot learns to translate language to action. Some add reasoning steps in between: the robot first understands the scene, then reasons about what to do, then predicts the action. The best results come from training on diverse, large-scale data—watching thousands of hours of robot demonstrations and learning the patterns.

How the work breaks down

The work in this subtheme splits along five natural directions: (1) building foundation models that reason about scenes and predict actions end-to-end, (2) coordinating multiple arms or whole-body movement in a single policy, (3) understanding spatial relationships and grounding language to 3D space, (4) giving robots memory so they can recall past steps and learn from long task sequences, and (5) enabling robots to learn by doing through autonomous interaction instead of human supervision. Each direction tackles a different bottleneck in the pipeline from seeing an image to commanding the robot's body.

Foundation models with reasoning and task diversity

The core challenge here is building a single vision-language-action model that can handle many different tasks and understand what is happening in a scene well enough to predict the right action. Unlike narrow task-specific policies, these models need to compress visual understanding and reasoning into one forward pass, then output a valid command for the robot's joints. The problem is hard because different tasks demand different attention patterns—grasping a tiny object requires pixel-level precision, while navigating a room requires understanding scene structure—yet the model must handle both.

Embodied-R1 takes this on by running multiple reasoning steps at test time before the model commits to an action, letting it think through the problem rather than predicting instantly. It achieves 56% success on simulation benchmarks and 87.5% on real robot tasks, a 62% jump over baselines, because the extra thinking step lets the model catch and correct mistakes. OneTwoVLA tackles the opposite problem: it builds a unified architecture that excels at long-horizon planning (make a hotpot, mix a cocktail), error detection, and human-robot interaction, showing that a single model can handle complex multi-step tasks if designed to adapt its reasoning on the fly. Sim2Real VLA focuses on the transfer problem—synthetically generated training data from simulation often looks different from real cameras, lighting, and materials. It demonstrates that a carefully trained VLA can transfer bimanual and dexterous skills to real robots, even on long-horizon tasks, if the model learns to ignore visual noise and focus on actionable features. VLM4VLA reveals a surprising bottleneck: it shows that a large vision-language model's general knowledge (recognizing animals, describing images) is a poor predictor of success on robot tasks. Instead, the visual-perception component—the part that sees the image—is the critical constraint, which means that improving how the robot perceives the scene matters far more than adding language understanding.

Multi-arm and whole-body coordination

A major leap in robotics is moving from single-arm manipulation to coordinated multi-limb control. When a robot has two arms or a humanoid body with locomotion, the action space explodes—more joints, more possible ways to fail, more need for symmetry and balance. The challenge is whether a large VLA model designed for single-arm tasks can be adapted or composed to handle embodiments with fundamentally different morphology.

TwinVLA solves this for bimanual tasks by using two single-arm models instead of one large model. Rather than retraining from scratch, it runs two smaller, pretrained policies in parallel—each commanding one arm independently—and trains a lightweight coordinator to synchronize them. This approach is data-efficient because reusing pretrained arm models avoids the need to collect massive new datasets, so it outperforms larger single models while using less training data. By composing existing pieces rather than building from scratch, modularity beats trying to scale one monolithic model for high-dimensional control. WholeBodyVLA tackles the even harder problem of humanoid loco-manipulation—a robot that must walk, balance, and manipulate simultaneously on a humanoid platform (AgiBot X2). By creating a shared internal representation where locomotion and manipulation share learned patterns, it achieves 21% better success than earlier methods because the same visual features that help balance also help grasp—showing that whole-body reasoning can be learned end-to-end from images if the visual component is trained to extract features useful for both walking and grasping.

Visual scene understanding and spatial grounding

A robot that sees an image must decide: what objects are where, and what can I manipulate? This requires binding language (a human's instruction like 'pick up the small red cube') to pixels, and then understanding how 3D space is laid out so the robot can move toward a target or avoid obstacles. The hard part is that a single image doesn't fully reveal 3D space, depth, or occlusions, yet the robot must act anyway.

Interleave-VLA improves generalization to unseen objects by mixing image pieces and text words during training, letting language and vision influence each other early rather than combining them late. This doubles out-of-domain performance and lets the model interpret hand-drawn sketches as instructions at test time, which means early mixing trains the model to bind language and pixels together in ways that survive distribution shifts. RoboInter establishes a benchmark of embodied question-answering (VQA) tasks—can the model answer questions like 'is there a red cube?' after seeing a robot-camera view? By testing 28 categories of spatial reasoning, it shows that today's VLMs often fail at embodied perception, identifying a bottleneck that earlier methods missed. Towards Physically Executable 3D Gaussian for Embodied Navigation uses 3D Gaussian representations (a recent technique from computer vision) to represent the robot's environment. Although harder to train than 2D images, this 3D approach generalizes 31% better on unseen navigation scenarios because the explicit 3D geometric structure gives the robot a way to reason about depth, occlusions, and camera angles that 2D methods cannot capture, so the robot understands and navigates rooms it has never seen before.

Memory and temporal reasoning for long tasks

Long-horizon tasks—ones that take minutes and involve many steps—require the robot to remember what it has done and what it has seen. A standard VLA predicts the next action from one image, forgetting everything that came before. But if a robot tries to assemble an object, it needs to recall that it already placed a piece somewhere, or remember the goal it was given. Memory lets the robot avoid repeating mistakes and recover from failures.

Hybrid Training for Vision-Language-Action Models (HyT) solves a key tension: reasoning makes policies more accurate but makes the robot slower at execution time because the extra thinking takes computation. HyT trains a large reasoning model on the full dataset, then compresses it into a smaller model that mimics the reasoning without the computational cost, so the robot gets the accuracy gains while staying fast. MemoryVLA goes further by giving the robot a persistent memory of what it perceives and understands. It uses a dual-stream design: one stream processes the current image to predict immediate actions, while another stream builds a time-indexed memory of prior observations and task context. Across four benchmarks (SimplerEnv, LIBERO, Mikasa), it outperforms baselines by up to 26% because memory especially helps on tasks where partial visibility or temporary obstacles require the robot to remember what it saw earlier or steps that must be undone.

Autonomous learning and self-supervised collection

The biggest data bottleneck in robot learning is collecting demonstrations, because a human or a teleoperator has to manually guide the robot through each task, which is slow and expensive. Can robots instead learn by exploring on their own and collecting their own data? This requires the robot to generate successful motion sequences, evaluate them, and improve without human feedback, which means the robot must decide on its own what counts as success and when to try something different.

AutoFly addresses autonomous navigation for drones by building a dataset of continuous planning and obstacle avoidance, then training a VLA that navigates in the wild without pre-specified waypoints. Rather than waiting for human pilots, it learns by synthesizing trajectories from diverse scenarios. Autonomous Play with Correspondence-Driven Trajectory Warping (Tether) takes a different approach: it lets a robot play with objects unsupervised for hours, collecting over 1000 expert-level trajectories automatically. By learning correspondences between different plays (noticing that the same motion works on similar objects), it warps trajectories to new contexts, turning unstructured play into training data competitive with human-curated demonstrations. Human-Object Interaction via Automatically Designed VLM-Guided Motion Policy (BiBo) uses a pretrained VLM to propose plausible motions, then refines them with a policy model. It shows that a large VLM can seed motion generation before task-specific learning, achieving natural human-like motion synthesis across single and multi-task scenarios without manual annotation.
