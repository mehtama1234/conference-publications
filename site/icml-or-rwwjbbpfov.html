Action-Sufficient Goal Representations

In hierarchical goal-conditioned learning, goal representations that preserve information for value prediction can still fail for action selection—so train them with the actor policy instead.

Paper explainersAll themesReinforcement Learning

When a robot learns long-horizon tasks, it often uses a two-level hierarchy: a high-level brain picks subgoals, and a low-level controller executes actions toward each subgoal. The shared language between them is the goal representation—a compact encoding of what the subgoal looks like. The paper shows that existing approaches derive this encoding from value functions (predictions of expected rewards), but this can fail. Two goal states might be equally valuable yet require completely different actions. The paper introduces a formal condition called action sufficiency—encoding that preserves all information needed to pick the right action—and shows that actor-based training satisfies this because the actor policy's loss directly penalizes representations that fail to distinguish action-relevant differences. When the low-level actor has access to a representation that truly separates goals by their action signatures, it can learn to reach each subgoal correctly, yielding higher overall control success.

Zero assumption version

Two levels, one language—chosen wrong

In hierarchical learning, the high-level planner assigns subgoals (like 'reach the corner'). The low-level actor executes actions to reach them (like 'turn left, move forward'). They communicate through a shared code: the goal representation. A good encoding compresses the subgoal into a list of numbers that the low-level actor can use.

Existing methods train this encoding alongside a value function—a number that predicts how rewarding a state is. The assumption is: if the encoding preserves information needed to predict value accurately, it preserves enough for correct action selection. This sounds plausible but fails. Two goal states might have the same expected reward yet demand opposite actions. In a maze, for instance, the corner entrance and corner exit are both dead ends (same value), but the actor must move differently depending on which is the current goal.

The fix in one sentence. Train the goal encoding jointly with the actor policy itself, not the value function, so it learns to preserve only information the actor needs to choose actions correctly.

What the paper changes

What changes: the goal encoder

The paper modifies the goal representation function. Instead of optimizing it to minimize errors in value prediction (the old approach), it trains the encoder jointly with the low-level policy by minimizing the negative log-likelihood of action given goal and state. This is a simple switch in the training objective, but it forces the representation to preserve action-relevant structure.

The hidden quantity

Action sufficiency: the missing quantity

measured quantity  =  action sufficiency

A goal representation has action sufficiency if it preserves all the information needed to predict the optimal action for any state. Formally, this means the mutual information (a measure of how much one thing tells you about another) between the true optimal action and the goal representation is as large as the mutual information between the optimal action and the full goal state. In plain words: if two goals demand different actions from some state, the encoding must distinguish them.

The paper estimates action sufficiency on small discrete problems by computing the exact optimal policy via breadth-first search, then measuring conditional mutual information—how much the encoding tells you about the action, given the current state. On real tasks, the paper observes it indirectly by noting that actor-trained encodings yield higher control success than value-trained ones.

Paper reading. Mathematically, action sufficiency holds when the conditional mutual information I(a* | z, s) between the optimal action a* and the representation z, conditioned on state s, equals the mutual information between a* and the full goal g conditioned on state—i.e., no action information is lost.
Why it works

Why it works: the path from training to action

The core mismatch is what the two levels need. The value function asks: 'How much cumulative reward will I get from this state to the goal?' This is a single number per state-goal pair. The actor asks: 'What action moves me closer to this goal from this state?' This requires distinguishing between goals that have identical expected rewards but differ in their action signatures.

When the encoder is trained to minimize value prediction error, the training algorithm adjusts the numbers to encode features that predict cumulative reward. If two goal states have the same value, the encoder is free to compress them together without penalty. But the low-level policy still sees both and must output different actions—an impossible conflict. Training the encoder alongside the actor policy creates a different pressure: now the encoder is penalized if the actor's action probability (under log-likelihood loss) is low. If two goals require different actions, the actor's loss for the compressed encoding stays high, forcing the encoder to separate them. This happens automatically because the log-likelihood loss propagates backward into the encoder, making it sensitive to action-relevant structure that the value loss ignored.

The mechanism works because log-likelihood training pulls the encoder toward action-sufficient structure without explicitly computing mutual information. The actor's policy network acts as a measurement device: it 'votes' for which goal features matter by assigning high loss to compressed representations and low loss to ones that distinguish action-relevant differences.

The training objective

First in words:

Minimize the negative log-likelihood of the action under the actor's policy, where the policy conditions on the encoded goal and current state

Then the compact form:

L_actor = negative log pi_ell(a_t | s_t, phi_A(s_t, g)) summed over trajectory pairs

Every symbol:

pi_ell(a|s,z)the low-level policy, a probability distribution over actions a given state s and encoded goal z
phi_A(s,g)the actor-derived encoder: takes state s and goal g, outputs the representation z
a_tthe action at time t in a demonstration trajectory
s_tthe state at time t
gthe goal state the trajectory reaches
negative log pi_ell(...)the log-likelihood loss: penalizes when the policy assigns low probability to the demonstrated action
A tiny worked example
Suppose two goals, A and B, both have value 50 but require different actions from state s.
A value-trained encoder might encode both as [0.5, 0.5] (identical).
When the actor tries to choose an action, the policy network cannot distinguish A from B, so it outputs average action probabilities: [turn-left: 0.4, turn-right: 0.4, wait: 0.2].
For demonstrated action 'turn-left': log-likelihood loss = log(0.4) ≈ -0.92 for both A and B.
An actor-trained encoder, by contrast, might encode A as [0.7, 0.2] and B as [0.2, 0.7].
The actor learns to output [turn-left: 0.9, ...] for [0.7, 0.2] and [turn-right: 0.9, ...] for [0.2, 0.7].
For A: log-likelihood loss = log(0.9) ≈ -0.11; for B with 'turn-right': log-likelihood loss = log(0.9) ≈ -0.11.
Same action, but the actor-trained encoder gets much lower loss because it preserves action information. The training algorithm keeps adjusting the encoder that way because it keeps lowering loss.

The log-likelihood loss penalizes compressed representations and rewards ones that distinguish actions, steering the encoder toward action sufficiency without explicitly computing mutual information.

What can go wrong

What can go wrong

Actor-based encoding may overfit to training demonstrations. If the actor encoder learns spurious action patterns in the training data, it could fail to generalize to new goals or states. The paper verifies this does not happen on their benchmarks, but dataset quality matters.
Value prediction becomes secondary. By optimizing for actions, the encoder may lose information useful for other downstream tasks (like long-term planning) that value functions capture. The trade-off is intentional but not always beneficial.
Small action difference, large encoding cost. If two goals differ in action by a small amount (low-probability actions), the log-likelihood loss remains high, forcing unnecessary separation in the encoding. This can waste representational capacity.
Done right: test on hierarchical tasks. Test the actor encoding by measuring control success on long-horizon benchmarks where the low-level policy must actually reach subgoals set by the high-level planner, not just on value-prediction metrics.
What a runnable demo should prove

What a runnable demo should prove

Build a simple hierarchical goal-reaching task (e.g., a 2D gridworld where an agent must reach colored squares). Train the high-level planner offline from a dataset to set subgoals, and train two versions of the low-level policy: one with a value-derived goal encoding and one with an actor-derived encoding. Measure success rate on held-out hierarchical tasks (goals the planner picks that are not in the training data). The actor-derived encoding should reach more subgoals correctly. Then inspect the learned encodings: goals with identical values but different action signatures should be visibly separated in the actor encoding but overlapped in the value encoding.

success_rate = (trajectories_reaching_goal) / (total_trajectories). Report separately for value-derived and actor-derived encodings.

The actor-derived encoding should outperform value-derived on control success because the log-likelihood training specifically rewarded it for preserving action-relevant distinctions that value training skipped. The visualization should show that goals requiring different actions are separated in the actor encoding but collapsed in the value encoding.
