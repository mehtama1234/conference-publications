Fair Conformal Classification via Learning Representation-Based Groups

Instead of forcing the same confidence level for all people, learn which hidden groups are getting unfairly narrow predictions and give them wider sets.

Paper explainersAll themesAlignment, Safety & Fairness

A classifier trained to recognize cancer or judge loan risk will work well for some kinds of patients or applicants, but unfairly narrow its confidence margins for others — leaving them with prediction sets so tight they're nearly useless. Conformal prediction (a method that wraps any classifier to give statistically honest confidence margins) normally treats everyone the same: it picks a single margin width that guarantees roughly the same coverage for all. But that margin is too tight for some groups and wastefully wide for others. This paper introduces a method that learns which hidden groups are unfairly served, then adjusts each group's margins to achieve truly equal coverage without losing precision.

Zero assumption version

Standard conformal prediction ignores hidden bias

A classifier is a black box: feed it an image or application, get back a prediction. But we want to know how confident it is. Conformal prediction wraps any classifier to produce not a single guess, but a prediction set—a range of possible answers that the method guarantees will contain the truth at least 90% of the time (or whatever confidence level you set).

The catch: those guarantees are marginal. They hold on average across everyone. But the classifier works better for some groups than others because it learned from lopsided training data. A medical classifier trained mostly on younger patients will be overconfident on older patients (fewer examples taught it what old-patient features look like). A loan classifier trained on affluent applicants will be unfairly uncertain about applicants from other backgrounds (it has no clear patterns for those cases). When conformal prediction picks a single margin width to hit that 90% target, it's computing an average—meaning some groups get coverage below 90% and others get useless prediction sets that are too wide.

A beginner might try training the classifier fairly first, or checking that the margin works for each group separately. But training fairness doesn't automatically give fair prediction sets: two things that look similar to the classifier might belong to wildly different sub-populations. And checking each group separately means you need to enumerate all the ways people can be grouped (by age, ZIP code, medical history, loan-size ranges, and combinations thereof) before you start—usually impossible.

In one sentence. The method learns unfair subgroups automatically from data, then adjusts prediction margins for each group separately so all groups get equally honest and accurate confidence sets.

The algorithm as a flow

What it actually does

Step 1: Run the existing classifier on calibration data.

Get its predictions and measure how wrong it is on known examples.

Step 2: Build an encoder-decoder pair.

Encoder compresses each input into a compact list of numbers; decoder guesses group membership and reconstructs the input from that list.

Step 3: Optimize the decoder to find groups with low coverage.

The loss pushes the decoder to identify subgroups that the conformal margin misses—groups where coverage drops below the fairness target.

Step 4: Compute group-specific margins.

For each learned group, calculate how much extra (or less) margin is needed to hit 90% coverage for that group alone.

Step 5: Wrap new predictions with adaptive margins.

When predicting on a new sample, assign it to its learned group and apply that group's personalized margin.

What the paper changes

What changes: the prediction margins

Conformal prediction produces a set of possible answers, bounded by margins (how far from the classifier's top guess is the set allowed to reach). The paper's core change: instead of one fixed margin for all samples, compute a different margin for each hidden group, learned from the data.

This is a shift from marginal fairness (average coverage) to conditional fairness (coverage within each discovered subgroup).

the object it moves  =  prediction margins
The hidden quantity

The hidden quantity: group-wise coverage gap

measured quantity  =  coverage gap

The paper measures a hidden quantity: for each subgroup, how much does actual coverage fall short of the fairness target (90%, or whatever is set)? A group with 85% coverage has a 5-point gap; a group with 88% has a 2-point gap; a group with 92% is slightly over.

The method estimates this by running the classifier on each group and counting how many true answers fall inside the predicted set. Groups with large gaps are exactly the ones the standard method is shortchanging. The paper's encoder-decoder learns to find (and highlight) these low-coverage subgroups automatically by building a loss function that penalizes any group that dips below the target coverage.

Why it works

Why it works: learning where to look

Fairness problems are not random—some subgroups are consistently unfairly served, but those subgroups may not be obvious. The paper's solution is to automatically search the data space for the subgroups that get narrow prediction sets.

Here's the causal chain: The method builds an encoder (a learnable neural network that compresses each input into a list of numbers). It also builds a decoder (another network that looks at that list and guesses whether a sample belongs to a low-coverage group). The decoder is trained to find groups with coverage gaps by minimizing a loss function with three parts: (1) coverage loss (penalty if a group has coverage below the target), (2) reconstruction loss (penalty if the decoder can't reconstruct the original input, which means the number-list must hold all important information), and (3) KL divergence (a penalty that keeps the number-list centered around zero and spread out evenly, ensuring the space stays smooth and generalizable). Because reconstruction matters, the encoder must learn representations where group membership is visible—which forces it to highlight the data features that predict low coverage.

Why does this work? Because the decoder's sole job is to spot low-coverage groups, it naturally learns to separate easy-to-classify samples from hard ones, young patients from old, and other patterns that drive coverage gaps. Once groups are identified, the method computes a personalized margin for each group (computed via constrained optimization: find the margin width that hits the coverage target for that group specifically). Applying group-specific margins instead of a global margin eliminates the fairness gap: no group is unfairly tight, and no group wastes precision with overly wide sets.

Math after the picture

The optimization objective

First in words:

total loss equals coverage loss plus reconstruction loss plus KL divergence, each weighted by a balance parameter

Then the compact form:

L = L_CC + beta * L_MSE + L_KL

Every symbol:

L_CCcoverage loss: penalty if group coverage falls below target delta
L_MSEreconstruction loss: how hard to recover the input from the latent vector
L_KLKL divergence: penalty for straying from a standard normal distribution
betabalance parameter: how much to weight reconstruction vs. coverage finding
A tiny worked example
Suppose a sample has coverage loss 0.5 and reconstruction loss 0.3, with beta = 2.0.
KL divergence contributes 0.1.
Total loss = 0.5 + 2.0 * 0.3 + 0.1 = 0.5 + 0.6 + 0.1 = 1.2.
If we change beta to 0.5, total loss = 0.5 + 0.5 * 0.3 + 0.1 = 0.75—lower because reconstruction matters less.
Higher beta forces the encoder to learn cleaner group separations; lower beta allows more freedom.

The three-part loss ensures the latent space finds low-coverage groups (coverage loss) while staying smooth and reconstructive (KL and MSE).

What can go wrong

What can go wrong

The encoder gets stuck on spurious patterns. If the training data has a useless correlation (e.g., all low-coverage samples have red pixels), the encoder might learn to separate by color instead of by true algorithmic bias. To check this has not happened, validate learned groups on held-out data by measuring whether margins actually achieve fair coverage on new test samples, not just on the calibration set used to train the encoder.
Groups are too small to estimate coverage reliably. If the encoder splits the data into 1,000 subgroups but each has only 10 samples, coverage estimates for each group will be noisy. Random variation in a small sample can produce misleading estimates: true coverage might be 88% but a tiny sample might show 70%. When coverage estimates are wrong, the margins computed from them will also be wrong, causing the learned groups to fail on new data. To fix this, limit the number of groups or require each group to be large enough (e.g., at least 50 samples) for stable estimates.
The method overfits to the calibration set. The encoder-decoder is trained on the same data used to calibrate the margins. This can lead to tight groups that look fair on that data but fail on new samples because the learned group structure was tailored to that specific batch. To prevent this, hold out a separate calibration set for training the encoder-decoder and use a third held-out test set to validate fairness on new data.
Done right: independent calibration and test sets. Split data into three parts: train the classifier, calibrate margins on a second set (on which the encoder-decoder is also trained), and test fairness on a third held-out set. This ensures group discovery generalizes to new data.
What a runnable demo should prove

What a runnable demo should prove

Build a synthetic classification task (e.g., predicting whether a loan will default) where a simple classifier is overconfident on some sub-population and underconfident on others. Train a basic classifier on all data. Apply standard conformal prediction and measure coverage within each true group. Then train the encoder-decoder to find low-coverage groups, compute group-specific margins, and re-measure coverage. The demo should show: (1) standard conformal prediction achieves 90% average coverage but 70% for one group and 98% for another, (2) the encoder learns to identify the two groups, (3) adaptive conformal achieves 90% coverage within all groups.

fairness = min(coverage_group_A, coverage_group_B, coverage_group_C); a min of 85 becomes 89+ after adaptation

The demo must show that one margin fits nobody fairly, but learning hidden groups and personalizing margins fixes that for everyone.
