Test-Time Adaptation for Bioactivity Prediction Without Source Data

When you predict how molecules will bind to proteins but your training data is secret, guide the model at test time using pairs of the same molecule altered in different ways.

Paper explainersAll themesAI for Science

Predicting how strongly a drug molecule will bind to a protein is core to discovering new medicines. But models trained on one type of protein or one company's data often fail when tested on completely different proteins or data from another lab due to privacy or intellectual property rules. This paper solves the impossible-sounding problem: adapt the model at test time (when it is answering new questions) without ever seeing the training data, using a simple trick of matching the model's internal representation across transformed copies of each molecule.

When training data is locked away

Bioactivity prediction trains deep neural networks (collections of interconnected mathematical knobs) on molecules and proteins, learning to predict how tightly they bind. The knobs work great on molecules similar to the training set but fail catastrophically on new types of molecules or new protein families. A naive approach is to retrain on fresh data, but in drug discovery, the original data often cannot be touched because of privacy laws, company secrets, or regulatory restrictions.

A second-naive idea is to use old adaptation methods that retrain the knobs slightly, but all existing methods assume you still have the original training data nearby to compare against. Without it, the model has no anchor, and the knobs drift randomly.

In one sentence. Fix out-of-domain predictions without the training data by matching the model's internal features across different versions of each new molecule.

What the paper changes

What the paper changes

The paper adjusts the model's internal representation (also called features or embeddings: the list of numbers that the model creates inside itself as it processes a molecule) during test time only, without touching the learned weights (the knobs controlling the model's behavior). This is unusual because it keeps the knob settings fixed while steering what the model thinks about each molecule.

the object it moves  =  test-time representations
The hidden quantity

The hidden quantity: feature alignment

measured quantity  =  how aligned are the internal features

The paper measures a quantity that never appears in standard bioactivity prediction: how close are the internal representations of two slightly different versions of the same molecule? The closer they are, the more the model has learned to ignore spurious noise and focus on true binding interactions. The paper estimates this by computing the direct distance (technically, the Euclidean distance: the straight-line gap between two points in the feature space) between the two versions after processing them through the model.

A high distance means the model treated small changes to the molecule as if they changed the essential truth, which is bad. A low distance means the model saw past the noise and locked onto what really matters for binding.

Why it works

Why matching representations works

When two versions of the same molecule are forced to have nearly identical internal features, the model is forced to find a representation that works across variations. If the representation relied on noise or spurious patterns, the two versions would naturally have different features, and the loss would spike. To minimize this loss, the model must learn which parts of the molecule truly matter for binding.

The contrastive component (pulling different molecules apart in feature space) ensures that the model does not collapse all features to the same point, which would be useless. Together, these two forces — push similar molecules together, push different molecules apart — teach the model to carve out distinct regions in feature space, with each region reflecting real binding chemistry rather than training-data artifacts. Since this learning happens at test time on real molecules, it adapts without ever consulting the original training data.

The core equations

First in words:

total loss = consistency loss on the same molecule plus contrastive loss on different molecules, both weighted by uncertainty

Then the compact form:

L_total = sum_i w_i * L_consist_i + lambda * L_contrast L_consist_i = distance( repr(x_i), repr(aug_x_i) ) L_contrast = sum_i sum_j_neq_i -log( exp( sim(repr_i, repr_j) / tau ) / sum_k exp( sim(repr_i, repr_k) / tau ) )

Every symbol:

w_iconfidence weight for sample i, high if the model is sure about its prediction
L_consist_iconsistency loss for sample i, penalizes large feature distance between original and augmented
x_ithe test molecule i
aug_x_ian augmented (noise-added) version of molecule i
repr(x)the internal features the model creates for molecule x
distance(...)Euclidean distance between two feature vectors
L_contrastcontrastive loss, pulls representations of different molecules apart
sim(...)similarity between two feature vectors, typically cosine
tautemperature, controls how sharp the separation is
lambdaweight controlling how much contrastive loss matters
A tiny worked example
Molecule A and its noisy copy have representations [0.1, 0.2, 0.3] and [0.15, 0.21, 0.31]. Distance = sqrt((0.05^2) + (0.01^2) + (0.01^2)) = sqrt(0.0027) ≈ 0.052.
Model confidence on molecule A is 0.9. Uncertainty weight w_A = 0.9. Consistency loss contribution = 0.9 * 0.052 = 0.047.
Molecule B has a different representation [0.5, 0.6, 0.7]. Cosine similarity with A is 0.98 (almost identical, bad). Contrastive loss penalizes this similarity.
After one gradient step, representations drift: A stays [0.1, 0.2, 0.3], B shifts to [0.5, 0.0, 0.1]. New similarity is 0.5 (molecules are different). Contrastive loss decreases.

Higher confidence samples guide the adaptation more, because confident predictions are more likely to be correct and worth preserving.

What can go wrong

What can go wrong

Overconfidence in bad predictions. If the model is confidently wrong about a new molecule, uncertainty weighting will amplify the mistake. The solution: clip weights to a reasonable range so no single bad prediction takes over.
Augmentation does not create useful noise. If the random noise added to features is too small, both versions are already almost identical and there is nothing to learn. If it is too large, it breaks the molecule. The right noise level is data-dependent and must be tuned.
Contrastive loss can collapse. If the batch of test molecules is too small, the contrastive loss has few negatives to push apart, and representations can still collapse to a single point. A large buffer of past representations helps, because it gives the contrastive loss more pairs of different molecules to learn from, providing enough signal to keep regions separated.
Done right. Use honest confidence estimates, tune augmentation strength, and maintain a queue of diverse test examples so contrastive learning has enough signal.
What a runnable demo should prove

What a runnable demo should prove

Take a pretrained bioactivity model trained on one company's proprietary protein targets. Freeze its weights. At test time, run it on a new protein family, apply the paper's consistency and contrastive losses, and check that prediction correlation with ground truth improves measurably, because the losses teach the model to align representations around true binding patterns rather than noise. Do this twice: once with the original test data (sanity check), and once on a held-out set that the model has never seen in any form. The demo must show that the model adapts within a few optimization steps (small nudges to the representations), without touching the training data.

improvement = (correlation_after_adaptation) - (correlation_before_adaptation) on unseen protein family

The single most revealing metric: does Pearson correlation jump by 5-10% after test-time adaptation, and does it stay high on a second hold-out protein family that the model has never encountered?
