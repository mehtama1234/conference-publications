Understanding how models process language internally

These papers study how models work internally—looking at attention patterns, hidden representations, and activation steering to improve performance and explain behavior.

All themesField mapMathematicsAll explainers
What this is

Language models work by processing text through layers of neural networks, where information flows through billions of parameters and computations happen inside a black box. Papers in this area open the black box by studying attention patterns—which words the model focuses on when processing each token—and hidden representations—what patterns the model has learned to recognize at each layer. Some papers use neuron-steering, where researchers modify what individual neurons are computing mid-process to change the final output, which reveals what each neuron controls. The goal is to understand how models work and use that understanding to improve them, because you cannot fix systems you do not understand.

The challenge is that billions of parameters make it hard to figure out which ones matter for specific behaviors. A single neuron rarely does one thing—its behavior emerges from complex interactions. Papers study this by looking at examples: for a specific task, which patterns of neuron-firing appear? Do attention patterns make intuitive sense? Can you predict what a model will do based on its internal states? Some papers do ablation studies where they remove or modify specific components and measure the impact. The work is technically difficult because you need careful experimental design to isolate causation from correlation.

The payoff is that understanding internals enables better design because precise knowledge beats guessing. If you know that a model is using an attention pattern that makes sense but is slightly wrong, you can try to steer it toward better patterns by nudging the neurons, which improves performance surgically because you target the real problem. If you discover that certain layers are redundant, you can remove them to save computation. Some papers find that models learn interpretable features—like individual neurons that respond to specific concepts—which helps with debugging because you know what went wrong, and with safety because you can predict failure modes. This research area also answers scientific questions about what it takes for a system to learn language patterns, which has implications for understanding biological brains because the same principles might apply.

How the work breaks down

Research in this area splits along two main directions: studying what the model has learned by watching which words it focuses on during processing and what patterns it stores in hidden layers, and actively steering the model's behavior by modifying what its neurons compute. The split exists because these are different ways to answer the core question—how does a language model actually work?—and each approach reveals different pieces of the puzzle.

Focus Patterns and Sparse Processing

Focus (or attention, the mechanism of deciding which words matter) is how a language model decides which parts of the input text to focus on when processing each word. The problem is that standard focus-tracking looks at every word in relation to every other word, which gets very expensive when texts are long because the computation grows as the square of the text length. Models need ways to process long texts quickly without looking at every possible pair of words.

DSSA (Dense-Sparse Switchable Focus) solves this by letting the model decide when to use full focus-tracking on everything and when to use a faster sparse pattern that only looks at nearby words, achieving 4x speedup while keeping 98% of performance. Long-Context Generalization with Sparse Attention introduces ASEntmax, which uses a different sparse pattern and can extrapolate to texts 1000 times longer than what the model was trained on. ProxyAttn (Guided Sparse Focus via Representative Heads) speeds up focus-tracking by having a few representative focus-heads guide which words matter, then skipping expensive calculations, gaining 10x acceleration and 2.4x speedup in prefilling. Scaling Attention via Feature Sparsity recognizes that not every neuron in the focus layer matters equally, so it zeroes out the unimportant ones and achieves 2.5x speedup with half the memory for storing past key-value pairs. Understanding and Improving Length Generalization in Hierarchical Sparse Attention Models breaks the record for length extrapolation by training models on 4000-word sequences and then making them work on 32-million-word sequences, showing that hierarchical sparse patterns scale to extreme lengths. These papers converge on the same insight: sparse focus-tracking works because language has local structure—nearby words matter most—and by exploiting that, the model can run much faster.

Steering Model Behavior Through Internal Neuron Control

Once you understand what a model's neurons do, the next question is: can you change what they compute to improve behavior, because if you can steer it, you turn understanding into power. Neuron steering (or activation steering, reaching into the middle of a model during computation and nudging certain neurons) is the practice of pushing the output in a desired direction. The challenge is that steering requires precision—if you nudge too much in the wrong place, you might break the model's reasoning entirely, and if you nudge the wrong neurons, nothing happens.

Activation Steering with a Feedback Controller introduces PID Steering, which borrows from engineering control theory to steer the model smoothly and reliably, using feedback to adjust how hard to push based on whether the steering is working. Fine-Grained Neuron Steering (AUSteer) tackles precision by steering individual layers rather than entire blocks, because different layers handle different kinds of information and a single block-level nudge is too coarse. Local Linearity of LLMs enables a method where researchers build a mathematical model of how each neuron affects the output and use that model to calculate the exact steering needed, which gives formal guarantees that the steering will work as intended because the math shows which neurons control which behaviors. Enhancing Instruction Following via Activation Steering with Dynamic Rejection combines steering with a rejection filter that detects when steering is pulling the model off-track and backs off automatically, improving instruction-following accuracy by 6.5% while keeping the generation quality intact. Together, these papers show that neuron steering works best when it is precise, uses feedback, and adapts to what the model is actually doing.

Understanding What Models Learn About Language

A deeper question underneath interpretability is: what patterns does a model actually learn? Do individual neurons represent specific concepts? What causes a model to overthink or make systematic errors? The challenge is that modern models have billions of numbers controlling behavior and it is unclear which patterns emerge from learning and which are accidents of training.

LLM Pretraining with Continuous Concepts proposes training models to learn concepts explicitly—thought-like units that stand for recognizable ideas rather than scattered patterns across millions of numbers—and shows this improves how fast the model learns from examples because explicit units are easier to train than diffuse patterns, and makes the model's reasoning easier to trace and verify. Universal Properties of Activation Sparsity shows that across all modern large language models, only a small fraction of neurons fire for any given input; this sparsity gets stronger and more useful as models get bigger, suggesting that sparsity is fundamental to how language models compress information and pointing toward ways to make models faster without losing capability. The First Impression Problem reveals that reasoning models have a systematic flaw: their earliest internal computations bias later reasoning, which causes them to overthink problems because they lock in to an initial wrong direction; this demonstrates that the bias causes the overthinking (not just a coincidence) by showing that many reasoning failures trace back to this single internal bias, though current fixes remain incomplete. These papers reveal that model internals are not random—they have structure that mirrors learning, and understanding that structure is the key to improvement.

Speed and Memory: Approximation Methods

Generating text from a language model is expensive because the model has to run many times in sequence, once for each new word. Each step requires storing information from previous steps and recomputing information about all past words. The bottleneck is that efficient inference demands using approximations—methods that skip some computation without hurting the final answer too much.

Draft-based Approximate Inference for LLMs presents SpecKV and SpecPC, which predict which past key-value pairs the model will need to attend to and skip recomputing the ones it won't, maintaining accuracy while cutting memory and latency. AdaRoPE (Not All Attention Heads Should Rotate and Scale Equally) observes that when extending a model to handle longer texts, not all focus-heads need the same adjustment; some heads handle local patterns and should stay unchanged, while others handle long-range patterns and need different rotation scaling, preserving short-context performance while enabling longer contexts. Decoupling The "What" and "Where" with Polar Coordinate Positional Encoding separates the problem of knowing what words are from knowing where they are in the sequence, using polar coordinates instead of standard position encoding, which improves zero-shot length extrapolation because the separation lets each dimension scale independently and works across music, genetics, and language. These papers improve speed and memory usage by either skipping needless computation or rethinking the core encoding scheme to handle variable lengths without compromise, which is essential because longer texts let the model solve harder problems.

Precise Attention and Resistant Behavior

Beyond speedups and steering, a separate thread of work fixes specific attention mechanisms or makes models more resistant to damage. This includes methods that refine how attention gates information and methods that check whether a model can handle slightly corrupted input.

CLUE (Conflict-guided Localization for LLM Unlearning) identifies which neurons are actually responsible for harmful knowledge by finding neurons that disagree when shown conflicting examples, then removes that knowledge surgically by targeting those exact neurons, preserving the model's other capabilities. FiX (Introducing Fine-grained Forget Gate into Normalized Focus Scoring, a method that ranks values) improves focus-tracking by letting each focus position decide how much of past information to keep versus forget, treating each position individually rather than with a single global gate, outperforming older approaches on both short and long texts. Understanding the Ability of LLMs to Handle Character-Level Perturbation checks what happens when input text is slightly corrupted (words spelled wrong, letters swapped) and finds that models remain surprisingly resistant to severe damage, revealing both architectural strengths and potential misuse risks where models might hide failures. This group focuses on making focus-tracking more precise so that models become more controllable, and systems better able to handle real-world conditions where text is never perfect.
