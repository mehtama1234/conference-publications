From Associations to Activations: Comparing Behavioral and Hidden-State Semantic Geometry

Behavioral tests on language models can recover hidden patterns if you ask the right questions.

Paper explainersAll themesInterpretability

When you test an AI model by asking it questions, you learn about how it behaves on the surface. But inside the model, the numbers that actually think are arranged in a specific pattern (how things are arranged), like how cities are laid out on a map. This paper asks: if you run enough behavioral tests, can you recover what the internal pattern (how things are arranged) actually looks like?

Zero assumption version

The invisible interior

A language model is a black box: you feed words in, words come out. Researchers want to know what is happening inside. But you cannot simply look at the inner numbers (called activations) for every test—you need tens of millions of tests to see the patterns, and running them is slow. So the question becomes: can behavioral tests from the outside tell you something real about the invisible pattern (how things are arranged) inside?

A beginner might try: run one similarity test (like, are banana and apple more alike than banana and car?) and assume the answers reflect how the model's inner numbers are organized. This breaks because one test per word pair is noise. A single answer is unreliable. You need many trials.

The method. Run millions of forced-choice and free-association trials (like a psychology experiment) and see if the resulting behavior-only similarity map matches the inner hidden-state pattern (how things are arranged).

The paper measures the relationship between two geometries: the pattern (how things are arranged) the model reveals through its behavioral answers, and the pattern (how things are arranged) hidden inside the model's numbers. The key move is treating behavior as a window into the interior.

This paper names and measures one key quantity: semantic pattern (how things are arranged) alignment, the degree to which an LLM's behavioral responses on similarity tasks line up with how the internal numbers are actually organized. In everyday terms: if you ask the model many questions and build a map from the answers, does that map look like the real internal map?

The paper estimates this using a statistical method called representational similarity analysis, which compares two pattern (how things are arranged)-shaped data tables without caring about the exact numbers, only the patterns. It asks: is the order of closeness the same in both maps?

Why it works

Why forced-choice behavior predicts inner pattern (how things are arranged)

When you ask a model which is more similar: banana-to-apple or banana-to-car, you are probing whether the model's thinking numbers treat banana and apple as close neighbors in the number-space. Forced-choice forces the model to commit; it cannot hedge or drift across runs. Free association (like, name things similar to banana) is noisier because the model can say many things, and people fill in the answers inconsistently.

The mechanism is straightforward: if the model's thinking numbers arrange banana, apple, and fruit as a tight cluster, then the model's behavior will reliably show banana and apple as similar when asked directly. The internal pattern (how things are arranged) determines the similarity; behavioral tasks measure that determination. The reason forced-choice outperforms is that it carves the decision space sharply. The model must pick; there is no room for drift.

Math after the picture

The similarity formula

First in words:

For each pair of words, compute an alignment score by ranking how similar they are in behavior, then ranking how similar they are in the model's inner numbers, then measuring how much the two rankings agree.

Then the compact form:

rho = rank_correlation( behavioral_similarity_matrix, activation_similarity_matrix )

Every symbol:

behavioral_similarity_matrixA table where row i, column j is how often the model rated word-i and word-j as similar in tests
activation_similarity_matrixA table where row i, column j is how geometrically close word-i and word-j are in the model's inner numbers
rhoRank correlation: a number from -1 to 1 measuring how much the two tables' orderings agree
A tiny worked example
Suppose 5,000 behavioral tests rate: banana-apple = 92, banana-orange = 88, apple-orange = 85.
And activations at layer 5 show distances: banana-apple = 2.1, banana-orange = 2.5, apple-orange = 2.8.
Ranking behavioral by closeness: 1st=banana-apple, 2nd=banana-orange, 3rd=apple-orange.
Ranking activations by closeness: 1st=banana-apple, 2nd=banana-orange, 3rd=apple-orange.
Rankings match perfectly -> rho = +1.0. If rankings were opposite -> rho = -1.0.

The correlation score tells you whether the behavioral map and the inner pattern (how things are arranged) tell the same story about which words are close to which.

What can go wrong

What can go wrong

Behavioral tests are slow. Running 17.5 million trials takes weeks even with parallel computing. If you cannot afford that cost, this method does not work for you. The paper needed massive compute just to collect one dataset.
Free association introduces inconsistency. People and models both give varied answers when asked open-ended questions. One person says banana is similar to yellow; another says nutrition. This noise drowns out the pattern (how things are arranged) signal, so forced-choice is mandatory.
Alignment does not mean understanding. Even if behavioral pattern (how things are arranged) perfectly matches inner pattern (how things are arranged), that does not prove the model understands semantic meaning. It only shows a measurement correlation.
Done right. Use forced-choice tasks, run enough trials that randomness is drowned out, and test on held-out words to confirm the pattern is real, not overfitting.
What a runnable demo should prove

What a runnable demo should prove

Start with a small language model and a vocabulary of 100 words. Run 50 forced-choice trials per word pair (that is 50 times 5000 questions). Build the behavioral similarity matrix. Extract the model's layer-5 activations (the inner numbers) and compute their pattern (how things are arranged). Use rank correlation to compare the two geometries. A good demo shows the correlation is positive and above random chance, meaning behavior does predict interior structure.

alignment_score = spearman_rho( behavioral_ranks, activation_ranks )

If alignment_score > 0.5, then forced-choice behavior is a credible window into what the model thinks on the inside.
