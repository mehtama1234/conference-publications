A-TPT: Angular Diversity for Trustworthy Vision-Language Model Predictions

When you spread class-label prompts evenly around a sphere, the model's confidence scores become honest.

Paper explainersAll themesAlignment, Safety & Fairness

Large vision-language models (trained on 400 million images and captions) can answer questions without labeled examples. But their confidence scores often lie: the model claims 95 percent certain when it should say 60 percent. A-TPT fixes this by rearranging the class-label text prompts so they sit uniformly spaced on an imaginary sphere, which forces the model to be more truthful about uncertainty.

Zero assumption version

Confidence scores from vision-language models are unreliable

A large vision-language model can recognize images without training on examples. You show it a photo, describe what it might be (via text prompts for each class), and the model picks the closest match. The problem: the model also outputs a confidence score (how sure it is). But this score is often wrong. When the model says 90 percent sure, it actually gets it right only 70 percent of the time. This is called miscalibration, and it breaks trust in the model's predictions.

Why does this happen? The text prompts for different classes get pushed around during training. Some crowd near the center. Others spread out too far or too close together. This lopsided arrangement of class prompts tricks the model into overconfident scores. A beginner might try spreading the prompts evenly, but current methods only push them away from the center or force them to be perpendicular (at right angles). They still miss uniform separation.

The core issue. Text prompts for classes are arranged randomly, not evenly spaced. When some classes cluster close together and others sit far apart, the model learns to favor the clustered ones, so it outputs inflated confidence scores for them.

The algorithm as a flow

What it actually does

Extract text features

For each class, the learnable prompt generates a text feature (a point in space).

Measure angles between them

Compute how far apart each pair of class prompts sits (angular distance on the sphere).

Find the worst pair

Identify the two classes that are closest together (smallest angular distance).

Push them apart

Adjust all prompts to maximize that minimum distance, spreading them evenly.

Retrain prompts

Repeat until class prompts sit uniformly on the sphere and confidence becomes honest.

What the paper changes

What the paper changes

A-TPT modifies the learnable prompts that describe each class. Traditional methods nudge these prompts to scatter away from the center or to be perpendicular. A-TPT instead nudges each prompt so that all class prompts end up uniformly spaced on the surface of an imaginary sphere. This uniform spacing is the key: it removes geometric bias.

the object it moves  =  class-label prompts
The hidden quantity

The hidden quantity: minimum pairwise angular distance

measured quantity  =  minimum pairwise angular distance

This is the smallest angle between any two class prompts. When prompts sit randomly, some are clustered (small angle), others far apart (large angle). The minimum is the bottleneck. When the minimum is small, the model cannot distinguish those two classes well, so confidence becomes unreliable.

A-TPT measures this quantity by computing the angle between every pair of class prompts and taking the smallest. Then it adjusts the prompts to maximize that minimum angle. A bigger minimum angle means the classes are spread more evenly, and calibration improves. The paper estimates this by examining the actual text features generated by the tuned prompts and measuring angular separation on the unit hypersphere (an imaginary ball where all points sit at the same distance from the center).

Why it works

Why uniform angular spacing fixes calibration

When class prompts sit randomly in the model's internal space, some classes are dominant: they occupy more of the space. The model's scoring function (which picks the closest prompt to each image) then favors those dominant classes, outputting overconfident predictions for them. Uniform spacing on a sphere removes this bias because every class occupies exactly the same region of space.

The mechanism works because of how the model scores a new image. It measures distance from the image to each class prompt. If the prompts are lopsided, distances to dominant classes look artificially small, and the confidence score becomes inflated. But when all prompts are evenly spaced on a sphere, distances are balanced and equal. When you spread prompts uniformly, every class is treated the same way, and the model's confidence score now truly reflects how rare or common the image is compared to the learned category boundaries. The paper shows this by measuring expected calibration error, the gap between claimed confidence and actual accuracy. Smaller ECE means the model's confidence is honest.

The optimization objective

First in words:

Maximize the minimum pairwise angular distance between all pairs of normalized text features.

Then the compact form:

max_prompts min_i,j (arccos(e_i · e_j) for i ≠ j)

Every symbol:

e_inormalized text feature for class i (a point on the unit sphere)
e_jnormalized text feature for class j
e_i · e_jdot product, which equals cosine of the angle between them
arccos(...)the angle in radians or degrees
min_i,j (...)the smallest angle over all pairs
A tiny worked example with 3 classes
Suppose we have 3 class prompts. Current angles: Class A to B is 40 degrees, B to C is 30 degrees, A to C is 50 degrees.
The minimum angle is 30 degrees (the bottleneck).
A-TPT adjusts all prompts. New angles: A to B is 45 degrees, B to C is 45 degrees, A to C is 90 degrees.
The minimum angle is now 45 degrees (improved 50 percent). The prompts are more evenly spread.
Expected calibration error drops from 0.18 to 0.08 because confidence scores now match true accuracy.

The formula pushes all prompts apart uniformly, focusing on the closest pair first. When all pairwise distances are large and equal, every class sits equally far from every other class, and the model stops outputting overconfident scores.

What can go wrong

What can go wrong

Too many classes on a small sphere. If you have 1000 classes, even uniform spacing on a sphere leaves them too close. The prompts run out of room, and calibration hits a ceiling. A-TPT works best when the number of classes is smaller than the dimension of the feature space.
Overfitting at test time. A-TPT tunes the prompts on test data (without labels, using only the model's own predictions). If the test set is very small or unrepresentative, the learned spacing may not generalize to the next batch of images.
Trade-off with accuracy. Uniform spacing is good for calibration but may slightly lower raw accuracy in edge cases, because you are forcing symmetry even when the true class boundaries are asymmetric.
Done right. A-TPT maintains comparable accuracy while dramatically improving calibration across diverse datasets, including medical images, because it respects the trade-off: it spreads prompts enough to be honest without removing the model's ability to discriminate.
What a runnable demo should prove

What a runnable demo should prove

Build a minimal version: take a pre-trained CLIP model (or any vision-language model), pick 5-10 classes, run test-time prompt tuning on a small unlabeled dataset. Measure expected calibration error (ECE): for each confidence level, compute the gap between claimed confidence and actual accuracy. Compare a baseline TPT method (e.g., random prompts or average-dispersion prompts) with A-TPT (uniform angular spacing). The demo should show that A-TPT reduces ECE while maintaining or slightly improving accuracy.

Expected Calibration Error = mean over all confidence levels of (claimed_confidence - actual_accuracy)
