Helping models know what they don't know

Building systems that estimate how confident they are and admit uncertainty rather than guessing when they're unsure.

All themesField mapMathematicsAll explainers
What this is

A neural network trained to classify images usually gives a confidence score for each class. But this score does not reflect true uncertainty. If the model has never seen an image like the input before, it might still confidently misclassify it. In high-stakes applications — medical diagnosis, autonomous driving, security — confidence without calibration is dangerous. How can you make a vision model admit when it is uncertain, or when the input is far outside its training distribution? How do you know when to trust the model and when to escalate to a human?

The problem is that standard training makes models overconfident. A neural network trained on ImageNet can classify any image — it must pick a label even when none of the labels make sense. A deepfake detector trained on one generation method fails on videos from a newer model, but confidently guesses anyway. Uncertainty is a learned behavior, not automatic. To solve this, researchers use several strategies. Bayesian approaches treat neural network weights as probability distributions, so predictions come with uncertainty intervals. Ensemble methods train multiple models and measure disagreement as uncertainty. Calibration techniques adjust the confidence scores after training so they match true accuracy. Out-of-distribution detection methods learn to spot inputs that are far from the training distribution. Some approaches combine multiple signals: use the network's own confidence, measure input similarity to training data, check for logical consistency, and aggregate these clues.

Papers in this area focus on making vision models more trustworthy. Some develop new architectures that naturally produce calibrated uncertainty. Others propose post-hoc methods that can be applied to any pre-trained model. Some use self-supervised learning on large unlabeled datasets to learn what 'normal' data looks like, so anomalies stand out. Others use test-time approaches: when the model encounters an uncertain case, it can request more information or ask a human. The goal is simple: models that know the limits of their own knowledge and fail gracefully rather than confidently making wrong calls. This matters because wrong confident predictions erode trust faster than honest uncertainty — once users learn a system lies with confidence, they stop using it entirely.

How the work breaks down

Work in uncertainty and calibration splits into three directions: detecting and handling data the model has never seen before, improving the reliability of confidence scores through augmentation and semantic alignment, and building systems that gracefully handle degraded or incomplete sensory input.

Recognizing unknown classes and new data

A fundamental challenge in deployed vision systems is that new classes appear. A model trained to classify animals might encounter a new species it was never shown. How do you detect that the input belongs to an unknown class rather than forcing the model to pick from its known labels? This is the problem of generalized category discovery: the model must not only classify known objects but also flag which ones are new, and count how many unknown types are present.

CoGe-GCD tackles this by using compositional generalization. Instead of learning rigid class boundaries, it learns to build class concepts from smaller composable pieces. When a new unknown object arrives, the model can still decompose it into familiar components even if the combination has never been seen before. The paper improves accuracy on all known classes, correctly estimates the number of unknown classes in the input, and produces better geometric clusters of the data. This matters because in medical imaging, security screening, or autonomous systems, confidently labeling an unknown case is worse than admitting uncertainty.

Calibrating confidence through augmentation

A model's confidence scores are often miscalibrated: the percentage the network outputs as confident does not match how often it is actually right. A model trained only on common images might output 95% confidence on a rare example it has never seen, even though it is wrong. How do you fix this without retraining from scratch? One direct approach is to augment the training data in ways that preserve the semantic meaning but vary the appearance, forcing the model to learn that similar images should have similar confidences regardless of visual noise.

SCalDA improves calibration by using semantics-guided augmentation: it augments images while keeping semantic meaning aligned, then uses diffusion models to generate variations that are recognizably the same category but look different. This teaches the model to output consistent confidence for the same semantic object even when the image is transformed. The method works across fine-grained tasks (distinguishing between two similar birds) and general tasks (is this a car or a dog). By calibrating on both easy and hard examples, the model learns when to be confident and when to admit uncertainty.

Handling incomplete or degraded sensory input

Real-world sensors are unreliable. Cameras get dirty, night-vision is grainy, weather blocks the view. A vision system deployed in autonomous vehicles or robotics cannot simply fail when the input is degraded. It must estimate how much noise or missing information it is dealing with and adjust its predictions accordingly. The challenge is that some spatial and temporal patterns in the data might be real signal while others are just artifacts of degradation.

VGGT-Motion addresses this in the context of camera pose estimation: when tracking a camera's motion through space with a single image feed, motion blur or missing frames create uncertainty. Instead of requiring precise camera calibration before use, this approach is calibration-free: it learns to handle motion ambiguity directly. The system achieves long-range consistency over entire kilometers of video by adapting to the quality of each frame as it arrives.

NeuroMamba approaches the same challenge for general spatial and temporal perception by learning which features matter across different sensor quality levels. When a sensor stream is severely degraded (like low-resolution thermal imaging or high-noise radar), the system preserves high-fidelity spatial relationships by separating what it can trust from what is ambiguous. Both papers solve the core problem: systems that gracefully degrade rather than failing suddenly when inputs are uncertain or incomplete.
