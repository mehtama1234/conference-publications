Stopping models from making things up

Preventing models from confidently stating false information when they process images and text, checking against what they actually see.

All themesField mapMathematicsAll explainers
What this is

A model trained to describe images or answer questions about them sometimes generates output that sounds confident but is not grounded in reality. A model might say a person is holding a banana when they are holding an apple, or claim a chair is red when it is blue. It is making things up — hallucinating details that are not in the image. This happens because the model has learned to generate plausible-sounding text from its training data, but plausible-sounding does not mean true. A model trained on millions of images and captions has absorbed patterns and associations: if it sees a kitchen, it might generate 'there is a refrigerator' because fridges are common in kitchens, even if this particular kitchen image does not show one. The model is not trying to lie; it is just pattern-matching.

The problem is serious in practice because users trust AI systems to describe reality accurately, and they make decisions based on that trust. When an AI hallucinates, those decisions cause real harm. A doctor uses a multimodal AI to help interpret medical images, trusting it because it has high accuracy overall. The AI confidently claims 'this patient has a tumor' when the image actually shows no tumor. Based on this false claim, the doctor starts aggressive treatment: surgery, chemotherapy, radiation. These treatments damage the patient's healthy body and cause suffering, all based on the AI's hallucination. A person who is blind relies on an AI to describe images because they trust it to report what is there. The AI invents details: 'there is a red car in the parking lot' when the image shows empty space. Based on this false description, the person builds incorrect beliefs about the world. Hallucination happens because the model learns two separate things: how to perceive images (building a representation of what is in them) and how to generate text (learning language patterns). These two can drift apart — the text generation learns to fill in plausible details rather than staying faithful to the perception. Some hallucinations are clear (inventing objects that are not there), but some are subtle: a slight exaggeration of size, a misidentified color, a missing context that changes the meaning.

Research on reducing hallucination tackles the problem from several angles. Some work focuses on training methods: if you penalize the model when it generates text that is not supported by the visual content, it learns to be more faithful. Some approaches use constrained decoding — when the model is generating text, you check at each step whether the next word is justified by the image, and only allow words that are supported. This works because you stop the model before it makes something up by blocking implausible words at generation time. Others build models that explicitly reason about uncertainty — if the model is not sure about something, it should say so rather than guess. Some work trains models with special symbols (called tokens, which are one chunk of text the model reads) that mean 'I cannot see this clearly' or 'this is partially obscured.' Some focus on building better visual representations by using multiple levels of detail, so the model has both coarse and fine-grained information about what is in the image. And some work trains the model to explicitly cite which part of the image supports each claim in the description — if the model says 'there is a dog,' it should point to where the dog is.

How the work breaks down

Research on stopping models from hallucinating splits into five main directions based on where in the model the problem occurs and how to fix it. Some work targets the attention mechanism—the part that decides what to look at in the image—because distracted attention causes the model to miss details. Others use constrained decoding, where you check each word the model generates to make sure it matches what is actually in the image. A third group focuses on making better visual representations so the model sees the image more clearly, which means it has richer data to work from and does not need to guess. A fourth trains models to reason about uncertainty and cite visual evidence. A fifth targets the specific case of video and multi-turn conversations, where hallucinations can snowball over time.

Fixing attention to ground output in images

The core problem these papers solve is that models sometimes look at the wrong part of an image or miss important details because their attention—the internal focus mechanism—gets distracted. When the attention is noisy or scattered, the model generates text that does not match what it actually saw, making false claims confidently. Fixing attention at the source means the model sees the image correctly from the start, so the text it generates is actually grounded in reality.

AFIP (the first paper) reduces hallucinations by identifying parts of the attention system across multiple layers that cause the model to blur or misinterpret visual input, then corrects them. This works on multiple model types and benchmarks, so it is a general fix. DEGAP (the second paper) tackles different types of hallucinations—object hallucinations, where things are invented, and attribute hallucinations, where properties are wrong—by guiding the attention mechanism more carefully during decoding, the process where the model picks the next word. It achieves strong results across seven different benchmarks while keeping the model good at general visual question answering. The Causal Route Gating paper (the third one) identifies which pathways in the model are causing hallucinations and blocks or weakens them when you are using the model to make predictions (called inference—the moment the model generates output). This is efficient because it adds only modest overhead. SHIELD (the fourth paper) focuses on the encoder—the part that reads the image—and finds biases and vulnerabilities in how it represents images that lead to hallucinations. By defending against these vulnerabilities, it reduces object hallucinations across many models without hurting their ability to answer other questions well. These four papers all work by making attention more accurate and focused, so the model's text matches what it actually sees in the image.

Complete image data prevents hallucination

A second approach is to give the model richer, more detailed information about what is in the image. If the visual features—the data the model extracts from an image—are incomplete or coarse, the model fills in the blanks by guessing, which causes hallucination. These papers build better ways to extract and represent images so the model has clearer signals from the visual data itself. When the model has complete information about what is in an image, it does not need to guess and so it hallucinates less.

ScreenParse (the first paper) builds dense visual representations of user interface screens, providing complete pixel-level labels of every component rather than sparse annotations of just a few objects. This teaches the model to ground its understanding in fine details, not guesses. It shows that models trained this way massively outperform larger foundation models at dense parsing tasks and transfer well to other benchmarks. The ExpAlign paper (the second one) tackles open-vocabulary detection—recognizing objects that the model has never explicitly seen named during training—by aligning visual features more carefully with language. It uses lightweight methods, so it runs fast. The Learning Attribute-Affordance paper (the third) builds hierarchical visual representations that capture what objects can do and how they relate to each other. By organizing visual information this way and training on counterfactual examples—images where things are slightly different—it teaches the model to ground affordances (what you can do with something) in what is actually there, not in default assumptions. Together, these papers show that models hallucinates less when they extract richer, more structured visual information from the start.

Training with visual contrastive learning and evidence

A third direction trains models by showing them what not to hallucinate. During training, you show the model images with correct descriptions and incorrect ones, and you train it to rank the correct ones higher. You also explicitly train it to point to which parts of the image support which claims. This is called evidence-grounded training because the model learns that every claim should be tied to visual evidence.

RUDDER (the first paper) uses steering—nudging the model's internal states during decoding—to reduce hallucinations while keeping the model running at full speed. It works across four different model families because it targets a fundamental mechanism. DeFacto (the second paper) trains models with counterfactual thinking by showing them images alongside plausible but wrong claims about those images. The model learns to reason about why those claims are wrong and to prefer evidence-consistent answers instead. It also introduces a new benchmark specifically for measuring whether answers match visual evidence. The paper about inter-layer visual attention (the third one) notices that different layers of the model pay attention to different things, and sometimes one layer sees something the others missed. By comparing these attention patterns and flagging discrepancies, you can fix hallucinations without retraining—a plug-and-play approach that works on five different model architectures. IRIS (the fourth paper) trains models to sift through their own internal states using implicit feedback, learning which parts lead to correct answers and which to hallucinations, using only 5.7 thousand training examples. IC-VCO (the fifth) shows contrastive pairs of images—one correct, one subtly wrong—so the model learns to see fine differences and builds consistency between multi-image training and single-image use, which means the model generalizes better because it trained on more realistic conditions. PostAlign (the sixth) treats multimodal grounding as a corrective lens, explicitly aligning visual and textual representations after the model is trained, reducing hallucinations noticeably across multiple benchmarks. All six papers teach models to respect visual evidence by making evidence alignment and contrastive ranking central to how they learn.

Handling grounding in video and multi-turn dialogue

When models process video or carry on conversations across multiple turns, hallucinations become harder to control because the model must track information over time and remember what it said before without contradicting itself. These papers tackle the temporal and memory dimensions of hallucination.

Bridging the Grounding Gap in VideoQA (the first paper) grounds video question answers by maintaining a typed memory of the video's content—facts organized by type—and reasoning about them explicitly. This runs much faster than processing every frame densely while staying accurate. TriCD (the second paper) learns to decode video descriptions by training on compositional hallucination patterns—cases where the model mixes up objects or attributes in complex scenes—and improves accuracy by over 10 percent on a video hallucination benchmark. MACD (the third) uses counterfactual video data—videos where objects are removed or occluded—to train the model to be more careful about what it claims to see, especially for small or hidden objects. MM-Snowball (the fourth) identifies a specific problem: in a multi-turn conversation, if the model hallucinates in response one, it carries that false claim into response two, and the hallucination compounds. It builds methods to stop this snowballing. STVG-R1 (the fifth) trains video grounding using reinforcement learning, rewarding the model when it correctly grounds reasoning to specific instances in the video and penalizing false claims. MedScope (the sixth) incentivizes models to cite which moments in medical videos support their clinical reasoning, making hallucinations obvious because unsupported claims stand out. VideoSEAL (the seventh) improves answer accuracy and evidence alignment in long videos by decoupling where the answer comes from—separating what the model actually saw from what it is reasoning about—and supports adding better models later without retraining. These seven papers all recognize that video and dialogue require temporal grounding, where the model must justify claims at specific moments and stay consistent across turns.

Medical AI with explicit tool use and grounding

In medical domains, hallucinations are especially harmful because doctors and patients make life-or-death decisions based on the model's claims. These papers train medical AI models to think visibly: they must show their reasoning step by step and cite which image regions or measurements support each conclusion.

MedScope (the first paper) teaches models to reason about clinical videos by explicitly calling tools—like zooming, measuring, or highlighting regions—as they explain their thinking. This forces the model to ground every claim in temporally localized visual evidence, making hallucinations impossible to hide. Ophiuchus (the second paper) combines three training stages: a cold-start phase where the model learns basics, a self-reflection phase where it checks its own work, and an agentic phase where it uses tools to verify claims. It outperforms both proprietary and open-source medical AI across diverse tasks—visual question answering, object detection, and reasoning-based segmentation—because the tool-use pipeline prevents the model from making unsupported claims. Both papers recognize that medical AI requires not just reducing hallucinations but making the reasoning completely transparent and verifiable.
