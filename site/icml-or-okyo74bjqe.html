Progressive Graph Structure Adjustment for Homophily Shift Adaptation

When a graph changes how likely connected nodes are to belong to the same class, a new method fixes source and target graphs step by step, alternating between edge reweighting and representation alignment.

Paper explainersAll themesGraph & Geometric Learning

You train a model to classify nodes in a network where nodes of the same class tend to cluster together (called homophily). You deploy it on a new network where nodes scatter across class lines instead of clustering. The model fails because the pattern changed. This paper proposes PSAHS, which explicitly measures and fixes this mismatch by progressively reweighting graph edges and refining the target graph, running these fixes in lockstep with representation learning to make transfer reliable under limited labels.

Zero assumption version

Graph networks break when clustering changes

A graph network classifies nodes by looking at the node's own features and its neighbors' classes. This works well when nodes with the same class cluster together (high homophily). But when you move to a new graph where nodes scatter (low homophily), the learned patterns collapse.

A naive approach treats graphs as separate learning problems: train on the source graph, then fine-tune on the target. But with few target labels, the model overfits or drifts. It does not fix the underlying root cause: the graph structure itself has changed, and the learned edge weights no longer fit.

Graph domain adaptation must bridge two problems at once: mismatched graph structure (the connections) and mismatched representations (the learned numbers attached to each node). Ignoring either one fails.

In one sentence. The paper reweights edges to match homophily across source and target, then refines the target graph conservatively, alternating with representation alignment.

The algorithm as a flow

What it actually does

Measure homophily on source

Count how often connected nodes share a class label.

Reweight source edges

Increase weights between nodes of the same class, decrease weights between different classes, reaching a target homophily level.

Predict conservatively on target

Use both a graph neural network (reads the graph structure) and a plain feature model (ignores graph) to classify; refine target edges only where predictions agree.

Align representations

Train a domain discriminator to push node numbers from source and target together, removing domain-specific biases.

Iterate

Repeat structure adjustment and representation alignment, each run using better node numbers that reduce domain mismatch because closer alignment lowers domain-adversarial loss.

What the paper changes

What the paper changes

The paper modifies two things in tandem: the edge weights in both graphs, and the node representations. The critical observation is that edge structure drives the problem—fixing edges enables better representation learning because better structure provides clearer neighborhood signals, which in turn enables safer edge refinement in the target graph because the model can distinguish real patterns from noise.

the object it moves  =  Edge weights and structure
The hidden quantity

Homophily: the clustering tendency

measured quantity  =  Homophily ratio

Homophily is the fraction of edges that connect nodes of the same class, divided by the total edges. A value of 0.9 means 90 percent of edges are intra-class; a value of 0.3 means most edges cross class boundaries. When a model is trained on high homophily (0.8) but deployed on low homophily (0.3), its learned patterns do not transfer.

The paper measures homophily explicitly on source and target, then adjusts the source graph to reach a prescribed level (bridging the gap), and conservatively refines the target graph by checking agreement between two models—one that reads the graph, one that does not. Only predictions both models agree on update the target structure, preventing error propagation.

Why it works

Why progressive structure adjustment works

The core insight is a feedback loop: mismatched graph structure causes mismatched node numbers. By fixing the structure first (reweighting source, refining target), the learned node numbers become more aligned. Those better node numbers then enable safer structure refinement in the next iteration. This is why the method alternates rather than doing all structure work upfront.

In the source graph, homophily correction is direct: boost intra-class edge weights, dampen cross-class weights, until homophily reaches a target level (e.g., match the source data pattern to the target), because stronger intra-class connections guide the model toward valid patterns in the target domain. In the target graph, homophily refinement is conservative: only trust pseudo-label predictions from the current model when both a graph-aware classifier (the GNN) and a graph-agnostic classifier (the MLP) agree, because two independent models are unlikely to converge on the same error, reducing false pseudo-labels. Domain-adversarial training then aligns the learned node representations across source and target, removing domain-specific biases that arose from the structural mismatch, because when a domain discriminator cannot tell which domain a node came from, the learned numbers contain shared structure rather than domain artifacts.

Why this order works: early iterations have weak representations but can still reweight the source (labels are available). As representations improve, target refinement becomes reliable because both models have learned better shared patterns. Final iterations benefit from both a matched structure and aligned representations.

Math after the picture

Homophily-corrected loss

First in words:

Total loss is: GNN classification loss on source plus MLP classification loss on source plus domain-adversarial loss between source and target embeddings plus a reweighting penalty that encourages edges within the same class and discourages edges across classes.

Then the compact form:

L_total = L_GNN(source) + L_MLP(source) + L_adv(source, target) + lambda * sum_e (w_e - homophily_target)^2

Every symbol:

L_GNN(source)loss from the graph neural network on labeled source nodes
L_MLP(source)loss from the plain feature model on labeled source nodes
L_adv(source, target)domain-adversarial loss: tries to make a discriminator unable to tell which domain a node embedding came from
w_eweight of edge e after reweighting
homophily_targetthe desired homophily level (e.g., 0.7)
lambdahow strongly to encourage the target homophily level
A tiny worked example
Suppose source homophily is currently 0.5 and target homophily is 0.2. Set homophily_target = 0.3 (a middle ground).
Intra-class edge: reweighting increases its weight from 1.0 to 1.2 -> penalty = lambda * (1.2 - 0.3)^2 = lambda * 0.81.
Cross-class edge: reweighting decreases its weight from 0.5 to 0.1 -> penalty = lambda * (0.1 - 0.3)^2 = lambda * 0.04.
Intra-class edge is penalized more, so training preserves them; cross-class edges are relaxed, so they decay, raising overall homophily gradually.

The penalty term drives the graph structure toward a balanced homophily level because the cost of deviation grows with the square of the difference, and repeating this process with better representations each iteration converges to a transfer-friendly structure because improved node numbers allow the model to identify correct edges more reliably.

What can go wrong

What can go wrong

Pseudo-labels build on pseudo-labels. If the model is wrong in early iterations, target pseudo-labels may encode those errors. The conservative refinement (requiring agreement) mitigates this but does not eliminate it if both GNN and MLP converge to the same mistake.
Homophily target is set by hand. The paper proposes a target homophily level manually or by matching the source data pattern. If chosen poorly, the reweighted source may not align with the target, leaving a gap.
Label scarcity can starve refinement. The GNN and MLP must both be confident on the same target nodes to trigger refinement. With very few labels, confidence may never align, and the target graph remains unrefined.
Done right. Use a held-out validation set on the target domain to choose homophily_target, validate agreement rates during refinement, and stop early if pseudo-label accuracy drops below a threshold.
What a runnable demo should prove

What a runnable demo should prove

Build a synthetic graph domain adaptation scenario: create a source graph with high homophily (nodes of the same class cluster tightly, e.g., 80 percent intra-class edges) and a target graph with low homophily (e.g., 30 percent intra-class edges). Use 200 nodes per class, 4 classes, sparse features (10 dimensions), and label only 20 target nodes. Train a baseline GNN on source, evaluate on target. Then run PSAHS: reweight source edges to match 50 percent homophily, train both GNN and MLP, refine target edges where both agree, align representations, and iterate 5 times. Measure target accuracy after each iteration and compare to the baseline.

Target accuracy after transfer = (correct target predictions) / (total target nodes); compare baseline to PSAHS at iteration 1, 3, 5.

The demo must show that PSAHS target accuracy rises across iterations (20 percent -> 35 percent -> 50 percent) while naive fine-tuning drops (92 percent -> 48 percent), proving that structure adjustment + representation alignment unlock transfer under label scarcity.
