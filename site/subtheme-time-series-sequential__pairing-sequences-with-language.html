Pairing sequences with language

Bridging time series and text by learning from paired descriptions, using language models to reason about sequences, or generating narratives from temporal data.

All themesField mapMathematicsAll explainers
What this is

Numbers tell part of the story, but context is in text. A hospital chart has vital signs and also doctor's notes describing what is happening: 'patient admitted with fever, responding to antibiotics.' A factory has sensor logs and also maintenance records: 'bearing installed 200 hours ago, last lubricated Thursday.' Stock data has prices and also news headlines and earnings call transcripts. Language carries information that is hard to encode as numbers because context and causation are described in words, not as numerical features. Language models have become skilled at reasoning and synthesis, so a natural question is: can we use language to help time series models, since language encodes domain knowledge that numbers alone do not capture?

The connection is surprisingly deep. First, language can provide supervision. If a doctor annotates a time series—'this pattern signals sepsis'—that labeled data is precious for training. Second, language can augment learning. A model that sees both the time series and paired descriptions might learn more stable patterns because descriptions highlight what humans think matters. Third, language models themselves can reason about sequences. Given a price chart and news, a language model might generate a narrative: 'stock fell because earnings missed estimates.' This is reasoning, not just pattern matching. Fourth, language can be the output: instead of predicting the next price, predict a description like 'stock will be stable.' This bridges two modalities.

Papers in this cluster train multimodal models that jointly encode time series and text. Some use pretraining: learn general patterns from large unlabeled time series, then adapt to new sequences with small amounts of paired text and data. Others use language as a regularizer: if the model's internal state is interpretable and can be described in language, that forces the model to be more human-aligned. A few papers generate narratives from sequences—they produce coherent descriptions of what the sequence is doing. The underlying insight is that language forces structure and interpretability in a way that raw sequence modeling often lacks.

How the work breaks down

Work here splits into four directions. First, some papers directly combine sequences and text in a single model—learning from paired descriptions to improve forecasting and pattern detection. Second, papers tackle the hard problem of bridging the gap between how time series and language represent information differently—they work differently because numbers are precise but context is not. Third, some papers focus on using language models as reasoning tools that can read sequences and generate explanations. Fourth, a few papers tackle specific applications like querying time series with natural language or transferring models across hospitals. Each direction exists because time series and language require different machinery, and the payoff of connecting them is enough to justify the effort.

Unified multimodal forecasting

The core problem: time series and text describe the same events in different ways. A patient's heart rate tells you something changed; the doctor's notes tell you why. Stock prices moved; the news headline explains the cause. Models trained only on numbers miss the explanation layer, and models trained only on text miss the ground truth. These papers tackle this by building systems that learn from both at once.

Language in the Flow of Time (1) weaves time series and paired text descriptions into a single representation, then tests whether this helps the model predict future values and fill in missing numbers. Adding the text context helps in two ways: first by providing supervision (the text describes what happened), and second by forcing the model to organize its internal patterns in ways that match how humans think about the data. Long-range Modeling and Processing of Multimodal Event Sequences (2) handles a harder case: event sequences with timestamps and variable gaps between events. It learns what event comes next and can also generate a written summary of what happened. This is harder because events are discrete (either they happen or they don't) while text is continuous, so the paper had to design a bridge. Semantic-Enhanced Time-Series Forecasting via Large Language Models (3) uses a pretrained language model that is already good at reasoning—it adds this reasoning to a time series model by letting the language model read descriptions of the sequence and feed that understanding into the forecast. The trick is that freezing the language model (not retraining it) and compressing the sequence into shorter summaries keeps computation manageable. Unlocking the Value of Text (5) directly tests whether text descriptions of historical patterns improve forecasting across real applications: hospitals, stockmarkets, power systems, and others. It does this by aligning the text representation and the sequence representation at multiple levels, so they don't drift apart. Together, these papers show that pairing sequences with text descriptions makes models work better because text reveals causes and context that raw numbers cannot express.

Natural language interfaces to time series

A common frustration: people want to ask questions about time series data in plain English, but databases only understand SQL. This problem is harder than it sounds because time series questions often need to reason about patterns over long periods, and language models were not designed to work with numbers that change over time. These papers build systems where you can type a natural language query and get back the answer.

Sonar-TS introduces a two-step process: first search the database for candidate time windows that might contain the answer, then verify which one is correct. This search-then-verify approach is necessary because language models can easily hallucinate time ranges or patterns. The paper also releases a large benchmark of real questions about time series to test these systems, which did not exist before. TsLLM shows a different approach: it trains a language model to understand both numbers and time relationships at the same time, so it can answer both traditional language tasks (like question-answering) and time series tasks (like forecasting) without switching models. The difference in philosophy matters because it reveals two strategies: one paper assumes language models need help finding the right data (search helps them), while the other assumes you can teach a language model to handle both modalities natively (integrated training works).

Learning across hospitals and domains

A key challenge: a model trained on patient data from one hospital often fails when you move it to a different hospital because every hospital uses different sensors, different labeling practices, and different patient populations. Similarly, models trained on stock prices for one market often fail on another. Papers here test whether language descriptions help transfer: if a model learns to describe patterns in human words, will those descriptions work across different data sources? This matters because human language is more abstract and universal than raw numbers.

Can we generate portable representations for clinical time series data using LLMs (6) tests this directly by training on one hospital and testing on two others. When the model learns to generate language descriptions of what the time series is showing, it transfers much better than raw number-based features because language generalizes across hospitals—a description of 'elevated heart rate' means the same thing everywhere. Overcoming the Modality Gap in Context-Aided Forecasting (9) shows that the quality of the paired text directly affects accuracy—bad descriptions actually hurt forecasting more than having no descriptions at all because misleading information confuses the model more than silence. Rethinking Multimodal Time-Series Forecasting Evaluation (10) points out a harder problem: existing benchmarks are often too easy, so methods that look good on standard benchmarks fail on real data. It shows that simple ensemble methods (combining many predictions) that use text context actually outperform fancier learned models when tested properly because combining many weak signals often beats training a single complex model. Together, these papers show that language transfer is possible but fragile—it depends on having good descriptions and honest benchmarks.

Language models reasoning step-by-step

Rather than training a specialized model to handle sequences, these papers use pretrained language models and teach them to reason about time series step-by-step. The insight is that language models have learned a lot about reasoning from text, and that reasoning might transfer to numbers if you present sequences in the right way.

Time Series Reasoning via Process-Verifiable Thinking Data Synthesis (11) generates synthetic step-by-step reasoning traces—descriptions of how to interpret a time series pattern—and trains small language models (3 to 4 billion weights, which means the model has relatively few learned values to adjust) on these traces. This approach is interesting because it shows that a small model can match much larger commercial models if it learns to think through problems step by step, which means teaching reasoning is more important than model size. TimeOmni-1 (12) goes further and builds a single model that can handle many different time series reasoning tasks: forecasting, anomaly detection, missing value imputation, and pattern explanation. It trains the model in stages, starting with simpler tasks and moving to harder ones. The philosophy is that reasoning itself is general—if you learn to think through one time series problem, that thinking process helps with others because the underlying reasoning patterns transfer across tasks.
