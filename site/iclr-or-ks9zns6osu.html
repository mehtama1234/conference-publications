Reconstruct Anything Model: A Lightweight Foundation Model for Computational Imaging

A single lightweight model solves many different image reconstruction problems by baking physics-aware information directly into its weights, with no need to retrain from scratch.

Paper explainersAll themesRepresentation & Self-Supervised Learning

When a camera takes a blurry photo or an MRI machine reads your head, you get degraded data. A computer can try to fix it by working backwards from the physics of how the data was captured. Existing methods either run slow iterative math loops or require building and training a separate custom model for each type of problem. This paper builds one foundation model that handles deblurring, medical imaging, inpainting, and super-resolution all at once, can adapt to new problems with just a handful of examples, and works on images of any size.

The two dead ends

Image reconstruction means fixing corrupted or incomplete pictures. A camera motion blur, an MRI scanner noise, missing pixels from inpainting—all are inverse problems (working backwards from a degraded image to the true one). Every problem has its own physics: the blur applies a sliding-window filter, the MRI samples in frequency patterns, the inpainting leaves random holes.

Today's approaches split into two camps. Iterative methods (like diffusion denoisers) run the same computation loop many times, slowly refining the image. They are general but glacially slow. Unrolled architectures lock you into one problem at build time—you design a neural network shaped specifically for deblurring or CT imaging, train it on that problem alone, and throw it away if you need to solve a different one.

A beginner would try: build a separate specialist for each problem. This works but wastes compute and data (learning the same representations over and over). Or run a slow iterative method and wait. Neither scales.

In one sentence. A single lightweight neural network learns to solve many image reconstruction problems at once, storing physics knowledge in its weights so it needs almost no computation at test time.

What the paper changes

What the paper changes

The paper replaces iterative loops and problem-specific training with a single shared neural network whose weights encode knowledge of the imaging physics (the forward operator). This one foundation model handles diverse inverse problems without retraining.

the object it moves  =  Forward operator knowledge (baked into initialization and training)
The hidden quantity

The adaptive capacity of each weight

measured quantity  =  Problem-specific importance of each weight

As the model trains on different imaging problems, each weight contributes differently to each task. Some weights matter a lot for deblurring but little for CT; others are critical for super-resolution. The paper measures how much each weight is used for the current problem. This importance score guides adaptation when fine-tuning on a new task.

The paper estimates this by tracking which weights are activated most strongly during training on a given inverse problem. Weights that are always near zero are free (low importance); weights that swing up and down are hot (high importance for that problem). At test time on a new problem, this importance tells the model which weights to adjust carefully and which can move freely.

Why it works

Why baking in physics works

Traditional inverse problem solvers run a loop: start with the broken image, apply a denoising step based on the physics, check if it is better, repeat. This is slow because every loop iteration requires a full neural network evaluation. The paper's insight is to move all that work into the weights during training, so inference is just one shot.

To do this, the model must learn what happens when you apply the forward operator (e.g., the blur, the MRI sampling) and its inverse (the unblurring, the reconstruction). By training on many different problems at once, the weights learn shared features (common patterns in images) and problem-specific features (how to invert each particular operator). When a new problem arrives, the model already has a good foundation; only a few weights need to change.

Few-shot adaptation works because the model has learned which weights matter for which problems. A new problem is not a complete mystery—it is a small adjustment to an existing solution. The paper uses self-supervised learning (measuring loss without ground-truth targets) to guide this adjustment, so you need only a handful of examples from the new problem to fine-tune.

The adaptation mechanism in one equation

First in words:

Loss equals reconstruction error plus weighted penalty on weight change, where the weights are those that matter most for this problem

Then the compact form:

L = ||y - f(x; theta)||^2 + lambda * sum_i alpha_i * (theta_i - theta0_i)^2

Every symbol:

ythe true reconstructed image
f(x; theta)the model's output for input x with weights theta
theta_icurrent value of weight i
theta0_iinitial weight value before fine-tuning
alpha_iimportance score of weight i for this problem
lambdahow much to discourage weight change
A tiny worked example
Problem: adapt to a new CT imaging task with 5 training images.
Weight w1: importance 4 (critical for CT), initialized at 0.5. Error pushes it to 0.6. Penalty: 4 * (0.6 - 0.5)^2 = 0.04. Stays near initial.
Weight w2: importance 1 (generic), initialized at 0.3. Error pushes it to 0.8. Penalty: 1 * (0.8 - 0.3)^2 = 0.25. Can move freely.
Same loss from both weights, but w1 is anchored by its high importance, protecting the CT-specific knowledge. w2 adjusts quickly because it is generic.

The importance score alpha_i acts as an anchor, preventing problem-specific weights from drifting while letting generic weights adapt.

What can go wrong

What can go wrong

New problem is completely different. If the new problem's physics is radically different (e.g., adapting to a microscopy task when trained only on photos), the model has no good foundation, and few-shot fine-tuning will fail. The weights do not know where to go.
Not enough diversity in training. If training data comes from only one imaging modality, the shared representations are weak, and the model over-fits to that one problem. Generalization to new problems suffers.
Noise in the fine-tuning examples. The self-supervised fine-tuning relies on the model's own loss to steer adaptation. If the few examples are noisy or biased, the update goes in the wrong direction and degrades reconstruction.
Done right. Train on a diverse set of imaging problems (medical, natural, low-photon) so shared features emerge. Validate the model on held-out problems before deployment. Use confident fine-tuning examples or gently steer weight updates to prevent noisy drift.
What a runnable demo should prove

What a runnable demo should prove

Build a toy version: train a small neural network on two different corruptions (blur and noise) together. Measure how fast the model adapts to a third corruption (inpainting) with only 10 examples and no ground truth. Compare wall-clock time and reconstruction error against a specialist model trained only on inpainting. The foundation-model approach should adapt nearly as well as the specialist (within 5% PSNR) while being 50-100x faster, because the shared foundation weights already encode good image features and only the task-specific adjustment layer needs learning.

Adaptation speed = (wall-clock seconds to convergence on new task) and Quality drop = (PSNR on new task) minus (PSNR of specialist model on same task)

If the demo fails to show fast adaptation with minimal quality loss, the physics-aware initialization was not strong enough or the importance-weighting scheme was not selective enough. Success means you can solve a new imaging problem faster than retraining a specialist, without ground-truth labels, because the model's shared representations already capture most of the solution and only need fine-tuning, not relearning from scratch.
