Olivia: Harmonizing Time Series via Spectral Alignment

Time series models learn better from diverse data by reshaping how each dataset's repeating patterns look in frequency space, so they all match a shared shape.

Paper explainersAll themesTime Series & Sequential

When a time series model trains on many different datasets at once, it sees wildly different repeating patterns (some data wobbles fast, some slow). Olivia aligns these patterns by working in frequency space (how often things repeat), so the model learns smoothly instead of getting confused. It does this by finding a shared low-dimensional space where all datasets look similar.

Zero assumption version

Many datasets, clashing patterns

Time series foundation models try to learn from huge piles of different datasets at once: stock prices, temperature readings, sensor data, heartbeats. Each dataset has its own rhythm.

A naive approach is to just throw all the data at the model and hope it learns something general. But this fails because the datasets fight each other. If one dataset has sharp spikes and another is smooth, the model's learning signals pull in opposite directions. The gradients (learning directions) become noisy and the model never settles into a good shared understanding.

In one sentence. Reshape each dataset in frequency space so they all look alike, then the model can learn smoothly.

What the paper changes

The one thing that changes

Olivia changes how the model sees time series by reshaping each incoming sequence in a learned way. A module called Harmonizer rotates the raw time series into a shared space where all datasets look similar in frequency content.

the object it moves  =  How time series are rotated into a shared space
The hidden quantity

The hidden quantity: spectral alignment

measured quantity  =  Spectral alignment across datasets

Power spectral density is a measurement of how much 'energy' (strength) each frequency carries in a time series. A smooth dataset has energy in low frequencies (slow changes); a spiky dataset has energy in high frequencies (sudden jumps). When datasets' power spectral densities differ wildly, the model's learning signals contradict.

Olivia measures and aligns these spectral densities implicitly. It does not compute PSD explicitly; instead, it reshapes the time series so that their second-order correlations (the way values relate to each other over time) become aligned. This rearrangement is mathematically equivalent to moving each dataset's spectral shape to a shared target shape.

Why it works

Why it works: the causal chain

When you train a model on many datasets at once, each batch carries a mini version of that dataset's spectral character. If dataset A has spiky frequency patterns and dataset B has smooth patterns, their gradients (the nudges that update weights) point in incompatible directions. This noise destabilizes learning.

Olivia fixes this by rotating each dataset so all have the same spectral shape before the model even sees them. This reparameterization is learnable (the Harmonizer learns how to rotate each dataset), so during training the model can quietly find the best shared rotation. Once the data arrives at the attention mechanism (which combines information by comparing each position to key mediators), it all carries the same frequency signature. The gradients from one dataset reinforce the gradients from another, not fight them.

The model does not then use dense all-to-all attention (every token talking to every other token), which would be expensive and noise-prone anyway. Instead, HarmonicAttention projects tokens into a small 'harmonic space' and uses a few key mediators called resonators. Each resonator handles one frequency band (a range of repeating speeds). Tokens interact through these resonators, which is fast and coherent because the resonators naturally match the shared spectral structure.

Math after the picture

The equation: spectral consistency

First in words:

The training objective (before simplification) minimizes the Jensen-Shannon divergence between the power spectral densities that the model produces from different datasets, forcing them to match. After simplification, this becomes a shared reparameterization via an orthogonal rotation matrix applied to the temporal correlation structure.

Then the compact form:

theta_star = arg min_theta sum_over_Di_Dj [ JSD( P_Di(omega), P_Dj(omega) ) ]

Every symbol:

theta_starthe optimal model weights
JSDJensen-Shannon Divergence, a measure of how different two distributions are (values from 0 to 1)
P_Di(omega)the power spectral density of dataset Di at frequency omega (how much energy at each frequency)
P_Dj(omega)the power spectral density of dataset Dj at frequency omega
sum_over_Di_Djsum this divergence over all pairs of datasets
A tiny worked example
Dataset A has energy mostly at low frequencies (slow changes); its PSD peaks at 0.8 at low omega, 0.2 at high omega.
Dataset B has energy at high frequencies (spiky); its PSD peaks at 0.2 at low omega, 0.8 at high omega.
JSD between them: both are far from the middle (0.5/0.5), so JSD ≈ 0.5 (high divergence, bad).
After Harmonizer reshapes both datasets, their PSDs both peak at 0.5/0.5 everywhere (identical).
JSD after: 0.0 (zero divergence, perfect alignment). Training is now stable because gradients reinforce each other.

The actual optimization never computes PSD explicitly; instead it learns the Harmonizer rotation that makes the correlations align, which mathematically guarantees spectral alignment.

What can go wrong

What can go wrong

Harmonizer learns the wrong rotation. If the shared subspace is not constrained properly, the Harmonizer might memorize a rotation specific to a few datasets instead of learning a true universal reparameterization. Fix: use the theoretical orthogonal basis (from Proposition 1 in the paper) to guide the projection.
Datasets truly have incompatible dynamics. Some datasets may have fundamentally different temporal structure that no single rotation can harmonize. Example: financial time series are trend-driven; weather data are seasonal. A global Harmonizer might smooth over these real differences. Fix: use adaptive Harmonizers per dataset family, or include task metadata.
Resonator bottleneck loses signal. HarmonicAttention uses only a few resonators (frequency bands) as mediators. If the interaction pattern does not align with resonator structure, the model may lose information. Fix: increase resonator count or use selective dense attention for critical layers.
Done right. Harmonizer is learned end-to-end, resonators are tuned to the task, and validation confirms that spectral alignment improves accuracy on the original training datasets and on new datasets it has never seen, because when all datasets have matching frequency signatures the gradients point the same direction and the model learns a unified representation instead of fighting itself.

What a runnable demo should prove

Build a synthetic time series dataset: create three sequences, one with energy at low frequencies (smooth), one at high frequencies (spiky), one mixed. Train a standard attention-based baseline on all three without Olivia. Then train Olivia on the same data. Measure both the spectral divergence (how different the learned representations' PSDs are) and the cross-domain forecast accuracy (train on datasets A+B, test on dataset C).

cross_domain_accuracy = accuracy_on_C_after_training_on_A_plus_B_with_Olivia minus accuracy_on_C_after_training_on_A_plus_B_without_Olivia

The demo must make it impossible to miss: Olivia's cross-domain accuracy gain comes from spectral alignment (you can plot the PSD before and after Harmonizer and see they converge), not from any other trick.
