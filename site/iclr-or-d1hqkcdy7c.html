Directional Sheaf Hypergraph Networks

A method that represents directed group interactions using complex-valued math that encodes which direction information flows.

Paper explainersAll themesGraph & Geometric Learning

Neural networks usually assume similar things connect to each other (homophily), but real data often has entities connected by oriented relationships—chemical reactions, disease pathways, causation. Previous methods either throw away the directionality or fail when similar things should NOT act alike. This paper builds a framework using cellular sheaves, a concept from topology that lets each node and hyperedge maintain separate views of each other, with asymmetric connections that honor direction. The result is a learnable architecture (DSHN) that uses complex numbers to encode which direction information flows, beating 13 baselines by 2–20% on real datasets.

Zero assumption version

When direction matters but networks pretend it doesn't

A hypergraph is a way to represent many things interacting at once. Instead of just pairs connecting (like person A knows person B), you can show groups (person A, B, C all attended a meeting). But real hypergraphs are often directed: a chemical reaction has reactants (inputs) and products (outputs); a metabolic pathway flows from substrate to product; a disease passes from one organism to many others in a chain. Current neural networks built for hypergraphs treat edges symmetrically—they ignore which direction things flow.

The second problem is homophily assumption: most networks assume similar nodes should connect and send similar signals. But in heterophilic data (like citation networks, where newer papers often cite older foundational work, or social influence, where different people influence each other), this assumption breaks the model. A beginner might try symmetrizing a directed hypergraph (ignoring arrows) to use existing methods, but that erases half the information.

The paper's move in one sentence: Assign complex-valued asymmetric connections between nodes and hyperedges, where the real and imaginary parts encode flow direction, so that source and target nodes contribute differently to each hyperedge and the model does not incorrectly assume all nodes must act alike.

The algorithm as a flow

What it actually does

Define directed hyperedge structure

Each hyperedge has a source (tail) set and target (head) set, explicitly encoding which nodes feed in and which receive.

Assign lists of numbers to nodes and edges

Each node and each hyperedge gets its own list of numbers, like holding private state for that node or edge.

Learn asymmetric restriction maps

For each directed hyperedge, learn complex-valued linear transformations from each node's space to the hyperedge's space, where phase encodes direction.

Build the complex Laplacian

Combine all these complex-valued maps into a single complex-valued grid of numbers operator (the Directed Sheaf Hypergraph Laplacian) that respects spectral theory.

Update node representations

Use the Laplacian in a neural network layer to propagate signals along directed edges, letting nodes learn that direction and dissimilarity both matter.

What the paper changes

What the paper changes

The paper changes the restriction maps—the learnable transformations connecting nodes to hyperedges. Instead of learning real-valued symmetric maps (treating all edges the same regardless of direction), the method learns complex-valued asymmetric maps. The complex plane (real plus imaginary axis) naturally encodes both magnitude and phase; the paper uses phase to capture direction. This is the ONE structural change that enables handling directed, heterophilic hypergraphs because asymmetry lets the network learn that source and target nodes play different roles, while complex numbers provide enough degrees of freedom to encode orientation without introducing extra table operations.

the object it moves  =  Restriction maps (from real-valued to complex-valued and asymmetric)
The hidden quantity

The hidden quantity: directional flow encoding

measured quantity  =  Phase angle in complex restriction maps

The paper measures and uses an implicit quantity: the phase angle of each complex-valued restriction map. Phase is the angle a complex number makes in 2D space—if a complex number is real, phase is 0; if purely imaginary (pointing up), phase is 90 degrees. In the method, phase encodes which direction information should flow along a hyperedge: a different phase for the source-to-hyperedge map vs the target-to-hyperedge map means the network can learn asymmetric contributions.

The paper does not measure phase directly as a separate quantity (like 'what is the phase of edge e?'), but rather learns complex restriction matrices end-to-end. The phase arises automatically: the network discovers that assigning different phases to source and target nodes helps the loss drop faster on heterophilic data, because then nodes can develop different roles (source vs target) within each hyperedge.

Why it works

Why it works: the causal chain

In undirected methods, a node has one representation no matter which edge it sits in—it sends the same signal to all neighbors. But in a directed hypergraph, a node should behave differently when it is a source (producer) vs a target (consumer). For example, in a chemical reaction where A and B become C, the restriction map from A and B to the reaction should encode that A and B are inputs; the restriction map from the same reaction to C should encode that C is an output. Symmetric undirected methods cannot distinguish these roles.

By using complex-valued asymmetric restriction maps, the network learns two separate complex numbers for each directed hyperedge: one for each source node's contribution and one for each target node's contribution. The phase (angle) of these complex numbers is free to differ, allowing the network to encode that source and target are structurally different. Because the complex numbers are learned during training, the network only assigns different phases when doing so reduces the prediction error—i.e., when the data is actually directed and directed-ness matters. On heterophilic data (where similar nodes should not act alike), this flexibility lets the network learn that roles differ even among similar nodes, avoiding the oversmoothing and incorrect-similarity assumptions that plague traditional methods.

The Directed Sheaf Hypergraph Laplacian preserves spectral properties (real nonnegative eigenvalues), so it can be used directly as a convolutional operator in neural networks. This means the complex-valued asymmetry does not break optimization or standard deep learning practice; it just enriches the expressiveness of the representation.

Math after the picture

The equation: building the complex Laplacian

First in words:

For each pair of a hyperedge and a node, compute the complex-valued restriction map transformation; assemble all of them into one big matrix (the incidence matrix) and combine it with itself to form the Laplacian.

Then the compact form:

L = B†B, where B is the complex-valued incidence matrix with entries B_e,u = Φ_u⊴e for edge e and node u, and Φ_u⊴e is a learnable complex linear map.

Every symbol:

BIncidence matrix: rows = hyperedges, columns = nodes, entries = learned complex restriction maps
B†Hermitian conjugate of B (transpose + complex conjugate)
Φ_u⊴eLearnable complex-valued linear map from node u into hyperedge e
eA directed hyperedge with source and target sets
uA node
phase(Φ_u⊴e)Angle in the complex plane, encodes directionality
A tiny worked example
Suppose hyperedge 1 connects source node A (produces) to target node B (receives).
Restriction map for A→edge1 is a complex number: 3 + 2i (magnitude ~3.6, phase ~33°).
Restriction map for B→edge1 is a complex number: 2 + 1i (magnitude ~2.2, phase ~27°).
Phase difference is 33° − 27° = 6°, showing A and B have different roles (asymmetry).
If A and B had the same phase (e.g., both 0°, both real), edge would be treated as undirected.
The network learns these phases only if directed edges help predict the task; on undirected data, phases converge to the same value.

The construction assembles B and its Hermitian conjugate into a single grid; what is new is that B is complex-valued and asymmetric, encoding direction in phase.

What can go wrong

What can go wrong

Overparameterization if restriction maps are unconstrained. Complex numbers are twice as expressive as real numbers. If the network has no gentle steering or structural constraint, it may learn unnecessary complexity. The paper avoids this by ensuring the Laplacian remains Hermitian (symmetric under conjugate transpose), which enforces spectral properties and prevents spurious degrees of freedom.
Computational cost in large hypergraphs. Building and factorizing complex matrices is about twice as expensive as real matrices (grid multiplication involves real parts, imaginary parts, and cross terms). On hypergraphs with millions of hyperedges, memory and training time grow. The paper does not address scaling beyond the 7 datasets tested.
Overfitting if directionality is a red herring. If the true data has no real directional asymmetry (e.g., the hypergraph is genuinely undirected), the network may still learn spurious complex phases on small datasets, hurting generalization. Cross-validation and held-out test sets catch this, but practitioners should check whether direction is real before using DSHN.
Done right. DSHN works best when hyperedges are explicitly oriented (chemical reactions, causality, metabolic networks), when data violates homophily, and when you have enough samples for the model to discover asymmetry is real and not noise. On such data, the complex-valued weights are an asset, not a liability.
What a runnable demo should prove

What a runnable demo should prove

Build a small directed hypergraph dataset (e.g., a toy causal system: A and B cause C, C causes D; a classification task predicts the class of each node). Implement DSHN and a baseline method that symmetrizes hyperedges (treats all directions the same). On the directed dataset, plot the learned phase angle (complex argument) of each restriction map for each hyperedge. The demo should make it visually obvious that DSHN assigns different phases to source vs target nodes, while the baseline either fails or learns nothing. Then show that on a truly undirected control dataset (e.g., co-authorship hypergraph), both methods assign similar phases, demonstrating DSHN adapts to the data.

directed_accuracy_gain = (DSHN accuracy on directed data) − (baseline accuracy on directed data)

The key observation: on directed data, DSHN's learned phases are visibly asymmetric across source and target nodes, while baseline phases are symmetric or undefined. This visual phase asymmetry is the mechanism. On undirected data, both methods' phases converge, showing DSHN is not wastefully overparameterizing.
