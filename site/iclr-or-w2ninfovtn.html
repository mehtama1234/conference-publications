VSF: Negative Guidance by Flipping Attention Values

VSF steers few-step image generation away from undesired content by dynamically flipping the sign of attention values computed from negative prompts.

Paper explainersAll themesGenerative Models & Diffusion

When you ask an image model to generate a sunset but say you do not want cars, the model sometimes ignores that no-cars instruction. Traditional methods like CFG (a rule that blends positive and negative predictions) fail in fast models that run in only 4 steps. VSF fixes this by reaching into the model's internals and flipping the sign of attention (the part that decides which parts of your words matter most) tied to negative words, making their pull reverse direction at just the right strength for each position in the image, layer in the model, and generation step.

Zero assumption version

Negative guidance breaks in fast models

Image models work in steps: starting from pure noise, each step refines the image closer to your request. A traditional negative prompt tells the model what NOT to draw. In slow models (50 steps), the model has time to steer away from undesired content by shaping each intermediate step. But few-step models (1–8 steps total) are so rushed that negative guidance fails.

The standard fix, CFG (classifier-free guidance), blends two predictions: one conditioned on the positive prompt (what you want) and one on the negative prompt (what you do not want). The final prediction is: positive plus a scale factor times (positive minus negative). This works when you have many steps, because the subtraction term has time to take effect. But when you compress 50 steps into 4, the model never sees the negation clearly enough—the undesired content still leaks in.

The paper's move in one sentence. Instead of blending entire predictions (CFG), VSF reaches inside the model's attention and flips the sign of the negative prompt's contribution before it is combined with positive, so each word-position in the image can be adapted per layer and per step.

The algorithm as a flow

What it actually does

Embed both prompts

Convert positive words and negative words to number lists (embeddings).

Compute positive and negative attention maps

See which tokens in the image align with positive words; separately, which align with negative words.

Calculate a dynamic weight per token

How much should positive vs. negative pull on this token? Use the ratio of positive attention to total attention.

Flip the sign of negative attention values

Multiply negative contribution by negative one, so it repels instead of attracts.

Blend: positive plus flipped-negative with adaptive weight

Combine them: take positive, add (adaptive weight times flipped negative), then pass to the next layer.

What the paper changes

The one thing it changes

VSF changes the sign (positive to negative, negative to positive) of the contribution from negative prompt attention values deep inside the model, per layer and per image position. It does not alter the positive prompt, the model weights, or the training process. It intercepts the negative signal and reverses it on the fly.

the object it moves  =  Negative attention values
The hidden quantity

The adaptive weight: how much negative to flip

measured quantity  =  Dynamic suppression weight

Each image region and each step needs a different amount of negation: if the model has already steered away from cars (by accident), too much flipping can overdo it and create artifacts. If the model is still headed toward cars, flipping must be strong. VSF measures this with a weight calculated from the attention maps themselves.

The weight W for each token is computed as: (sum of positive attention) divided by (sum of positive attention plus sum of negative attention). When positive is strong, W is close to 1, so negative gets flipped but not amplified. When negative is strong, W is close to 0, so the flip is gentle. This self-adjusts per layer, per step, and per token—unlike CFG, which uses the same strength everywhere.

Why it works

Why it works: reaching inside attention for precise control

Attention is the part of the model that decides what to pay attention to. When the model processes the image, it calculates how much each pixel cares about each word in your prompt. Traditional CFG happens after all that attention is done—it tries to fix the final prediction, which is too late and too crude for few-step models. By the time CFG tries to undo the negative, the model's entire pipeline has already moved the image in that direction.

VSF intercepts the negative prompt's attention values before they are combined with everything else. At that earlier stage, flipping the sign is surgical: it makes the negative words push the image away instead of toward. Because the weight is calculated fresh per position in the image and per layer, it automatically gets stronger in places where the negative prompt is most active and weaker where it is not. This happens at each of the 4 generation steps, and each time the model is running the generation process anew, it corrects what the previous step misdirected—allowing multiple chances to steer away from the unwanted content. A few-step model does not have enough time for gradual correction; it needs precision from step one.

The method also uses attention masking: when the negative signal is applied, it only touches image tokens (not the negative prompt tokens themselves), preventing a feedback loop. This keeps the generations stable even under aggressive guidance.

The equation: blending with adaptive negative weight

First in words:

Final attention = positive attention values minus (adaptive weight times negative attention values). The adaptive weight is positive attention sum divided by (positive plus negative sum).

Then the compact form:

Z = Z_+ - W * Z_-, where W = sum(A_+) / (sum(A_+) + sum(A_-))

Every symbol:

ZFinal combined attention output (what the model uses to update the image)
Z_+Attention values computed from positive prompt words
Z_-Attention values computed from negative prompt words
WAdaptive weight, ranges from 0 to 1
A_+Softmax attention weights from positive prompt (before output values)
A_-Softmax attention weights from negative prompt (before output values)
Tiny worked example: three tokens in one layer
Token 1: positive attention 0.8, negative attention 0.2. Weight W = 0.8 / (0.8 + 0.2) = 0.8. Flipped contribution = 0.8 * 0.2 = 0.16. Strong suppression because positive dominates.
Token 2: positive attention 0.3, negative attention 0.7. Weight W = 0.3 / (0.3 + 0.7) = 0.3. Flipped contribution = 0.3 * 0.7 = 0.21. Weak suppression because negative is already strong.
Token 3: positive attention 0.5, negative attention 0.5. Weight W = 0.5 / (1.0) = 0.5. Flipped contribution = 0.5 * 0.5 = 0.25. Balanced suppression.
Same negative signal, but each token receives suppression scaled by its context—stronger where the positive is winning, gentler where negative is already winning.

W ensures the flip adapts per token: aggressive in regions the model is already steering toward positive, gentle in regions the negative prompt is strong, preventing over-suppression and artifacts.

What can go wrong

What can go wrong

Over-suppression creates artifacts. If W is tuned too high uniformly, the negative signal flips too strongly and the model over-corrects, generating weird textures or distorted shapes. Because VSF adapts per token, this is rare—but a manually boosted guidance scale can trigger it.
Conflicting prompts confuse the weight. If positive and negative prompts both strongly align with the same concept (e.g., positive: sunset with clouds, negative: grey clouds), the weight calculation cannot neatly separate them. The model has to guess which to amplify.
Few-step constraint remains hard. VSF is surgical, but it still has only 4 steps to work with. A very complex negative (remove every red object except fire) is harder than a simple one (no cars).
Done right: measure and tune per use case. VSF's adaptive weight handles most conflicts gracefully. For known problem cases, a per-layer guidance scale (not a single global scale like CFG) lets you tune each layer independently.
What a runnable demo should prove

What a runnable demo should prove

Implement VSF in a 4-step diffusion model and generate images from paired prompts (e.g., positive: beach sunset, negative: people). Record the generated image. Run the same prompt using CFG at an equivalent scale and using NASA/NAG for comparison. Measure how well the negative prompt is honored using a classifier that detects the unwanted concept (e.g., a people detector for the beach example). Compare adherence scores: VSF should score higher (fewer unwanted objects) than CFG and older few-step methods, while keeping the image quality high and the positive prompt well-respected.

Negative adherence = (no unwanted objects detected) / (total images); Image quality = human or LPIPS score for realism; Positive adherence = classifier confidence the positive concept is in the image.

VSF proves that reaching into attention and flipping the sign—not globally but per token and per step—unlocks negative guidance in few-step models without the computational cost of running two full predictions.
