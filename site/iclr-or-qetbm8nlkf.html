PYRREGULAR: Unified Framework for Irregular Time Series

A single standardized format and benchmark lets researchers compare methods for predicting patterns in time series data where measurements arrive at uneven intervals and times.

Paper explainersAll themesTime Series & Sequential

Real-world data often arrives at irregular intervals: a patient's blood pressure is checked at random times, traffic sensors miss readings, climate stations record on different schedules. Different research fields have invented fragmented solutions, making it hard to compare methods or apply lessons across domains. PYRREGULAR solves this by creating one universal format and a repository of datasets so researchers can benchmark classifiers on equal ground.

The fragmentation problem

When a sensor records data at irregular intervals — say, a hospital monitoring a patient's heart rate, or a weather station logging rainfall on days it rains — existing methods struggle. A naive approach is to ignore the irregular spacing and treat all measurements equally, which loses critical information about WHEN events happened. Another common trick is to fill in missing values by guessing what would have happened in between, but guessing can corrupt the data with false patterns.

Worse, researchers in different fields have each invented their own ad-hoc solutions. A healthcare researcher writes code for medical time series; an environmental scientist writes separate code for climate data. The same classifier ideas are never compared fairly across domains because datasets and formats don't match. No one can agree on what 'irregular time series classification' even means.

In one sentence. PYRREGULAR creates one shared data format and benchmark so all researchers can test and compare irregular time series classifiers on the same datasets.

The algorithm as a flow

What it actually does

Defines one common data format

Timestamps and values in a standard array, usable by all domains.

Collects 34 public datasets

From healthcare, climate, mobility, and other fields with real irregular measurements.

Implements 12 diverse classifiers

Methods from different research communities that claim to handle irregular data.

Runs all classifiers on all datasets

Each classifier predicts the label (e.g., 'healthy' or 'sick') for each time series.

Reports transparent scores

Which method wins on which dataset, so researchers see real strengths and weaknesses.

What the paper changes

What changes

Before PYRREGULAR, each research community stored irregular time series in its own format (one used sparse arrays, another stored gap-lengths, a third interpolated values). No two looked alike. PYRREGULAR's move is to settle on one shared format: (timestamp, value) pairs in a standard array structure. This simple unification is the paper's core contribution — not a new algorithm, but a common language.

the object it moves  =  data format + dataset repository
The hidden quantity

The hidden quantity: classification accuracy under irregular spacing

measured quantity  =  per-classifier accuracy score

The paper measures one core quantity for each classifier on each dataset: what fraction of the time series it correctly predicted the label. This is the classic accuracy metric — count correct predictions, divide by total. But the hidden insight is that the paper reveals which classifiers handle irregular spacing well (high accuracy despite gaps and uneven timing) versus which ones do not. A naive method that ignores the irregular intervals should score lower than a method that respects timing.

Each of the 12 classifiers gets tested on all 34 datasets. The paper reports an accuracy score for every combination, creating a grid of 12 by 34 numbers. A researcher looking at this grid can see: does this classifier work best on medical data? Is it hopeless on climate data? Do timing-aware classifiers always win, or sometimes does a simple baseline surprise everyone? These patterns are hidden in the grid until someone runs the full benchmark.

Why it works

Why this works: the power of a shared benchmark

The core mechanism is simple: when multiple methods compete on the same dataset with the same metric, the best one emerges because there is nowhere to hide. A classifier that works in healthcare might fail on climate data because climate events have different patterns. A method that ignores timing will lose to one that respects it, if the irregular intervals truly matter. Before PYRREGULAR, each research community published results on its own datasets with its own metrics, so no one could see these real differences. A healthcare researcher would report 92% accuracy on their dataset and declare victory; a climate researcher would do the same on theirs. Were the methods equally good, or was one dataset just easier? Nobody knew.

PYRREGULAR creates a level playing field. Every classifier sees the same data, the same rules, the same metric. This forces the true rankings to surface. Moreover, the shared repository means new researchers can add their own classifiers to the benchmark without collecting data from scratch — they inherit 34 datasets instantly. This accelerates progress because researchers spend time on methods, not data collection.

The measurement equation

First in words:

For each classifier on each dataset, accuracy equals the count of correct label predictions divided by the total count of time series in that dataset.

Then the compact form:

accuracy_c_d = (# correct predictions by classifier c on dataset d) / (# total time series in dataset d)

Every symbol:

cthe classifier (e.g., attention-model, recurrent-model)
dthe dataset (e.g., medical heartbeat, climate rainfall)
# correct predictionscount of time series where the predicted label matched the true label
# total time seriescount of all sequences in the dataset
A tiny worked example
Dataset: 100 medical time series, each labeled 'healthy' or 'diseased'.
Classifier A guesses 78 correctly, 22 wrongly. Accuracy = 78 / 100 = 0.78 (78%).
Classifier B guesses 85 correctly, 15 wrongly. Accuracy = 85 / 100 = 0.85 (85%).
On this dataset, Classifier B is better; but PYRREGULAR tests both on 34 datasets, so we see if B stays strong everywhere or if A is better on climate data.

The paper repeats this calculation for all 12 classifiers and 34 datasets, building a grid of 12 by 34 accuracy numbers that reveals which methods handle irregular timing best.

What can go wrong

What can go wrong

Bias toward one domain. If 30 of the 34 datasets are medical and only 4 are climate, a method tuned for medical data will look artificially strong in the benchmark. The paper should report per-domain breakdowns.
Labeling errors in the repository. If a dataset's labels are mislabeled (a 'healthy' patient marked 'diseased'), all classifiers will train and test on corrupted ground truth, leading to meaningless scores.
Different classifiers tuned differently. If one classifier had its hyperparameters (learning rate, number of layers) carefully tuned on these specific datasets and others did not, the tuned one will score higher for a shallow reason, not superior method.
Done right. PYRREGULAR provides code and a public repository, so other researchers can verify results, add new classifiers, and extend the benchmark fairly. Transparency and reproducibility prevent most gaming.
What a runnable demo should prove

What a runnable demo should prove

A convincing demo takes PYRREGULAR's public repository, picks three classifiers (e.g., naive baseline, weighted-focus, recurrent), downloads a few of the 34 datasets, runs each classifier on each dataset, and plots accuracy scores. The demo should show that different classifiers score differently, and that at least one classifier's strength or weakness is visible across multiple datasets (not a fluke on one dataset). This proves that the benchmark successfully measures real differences in how well methods handle irregular time series.

accuracy_per_classifier = mean( [# correct / # total for dataset 1, # correct / # total for dataset 2, ...] )

The demo makes impossible to miss: with a shared format and benchmark, you can finally see which classifier truly handles irregular timing best, instead of guessing from three separate papers.
