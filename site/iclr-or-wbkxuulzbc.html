Beyond Grid-Locked Voxels: Neural Response Functions for Continuous Brain Encoding

Instead of treating each brain voxel as an independent number, NRF models brain activity as a smooth continuous surface over anatomical space, so it works across subjects and at any resolution.

Paper explainersAll themesAI for Science

Brain imaging (fMRI) measures activity as tiny cube-shaped voxels arranged in a 3D grid, but every subject has a different grid size. Conventional models flatten this 3D grid into a 1D list and treat each voxel as an isolated number, throwing away spatial context. NRF changes this: it predicts brain activity as a smooth continuous function over anatomical space, like a terrain map instead of a grid of separate points. This move makes the model portable across subjects and lets you ask about activity anywhere, not just at training voxels.

Zero assumption version

The voxel grid trap

Brain imaging gives us a 3D volume of voxel measurements—tiny cubes of activity at fixed locations. The standard approach: flatten this 3D volume into a long 1D list and train a model to predict each voxel's activity as if it were independent. This works but has a fatal flaw.

First, each brain has a different grid size, so the model's output layer must match one subject's voxel count—if Subject A has 13,000 voxels and Subject B has 14,500, the model's final layer has different sizes, making them incompatible; switching to a new subject means the old model is useless and training starts from zero. Second, by ignoring the spatial layout of voxels in 3D space, the model misses a huge signal: voxels next to each other almost always respond similarly, but treating them as isolated numbers wastes this correlation. Third, data is expensive; a typical study has only a few hundred images per subject, but flattening wastes that signal on a model that must relearn everything for each new brain.

In one sentence. Current models flatten brain voxels into 1D, toss spatial structure, and require retraining for every new subject.

The algorithm as a flow

What it actually does

Extract image features

Feed each image through AlexNet or CLIP to get a compact representation of what the image shows.

Encode coordinates

Convert the 3D brain coordinate (x, y, z) into a list of sinusoids (Fourier features) at multiple frequencies, which lets the model naturally learn smooth functions because sinusoids are inherently continuous—it can learn high frequencies for fine detail and low frequencies for broad trends.

Merge and process

Combine the image features with the encoded coordinates and pass through an 8-layer neural network.

Predict activity

Output a single number: the predicted brain response at that location.

Adapt to new subject

Take the pretrained model and fine-tune it on a small dataset from the new subject, learning subject-specific weights via least-squares regression.

What the paper changes

What changes: from discrete grid to continuous surface

The paper changes the output representation: instead of predicting a single number for each voxel in a flat list, the model now predicts a continuous function. Given an image and any 3D location, it outputs the response at that spot. This single change ripples through everything: the model no longer depends on voxel count, spatial structure is native, and pretraining becomes portable.

The hidden quantity

Local smoothness: the quantity NRF exploits

measured quantity  =  spatial correlation of voxel responses

Brain voxels that sit next to each other almost always respond the same way to the same image. This is called local smoothness. If a voxel at (10, 20, 15) fires strongly to a dog photo, the voxel at (10.5, 20, 15) almost certainly fires strongly too. Conventional flattened models treat all voxels as independent and miss this signal entirely.

NRF estimates local smoothness by modeling the voxel response as a continuous function. Where the function is smooth (changes gradually), the model learns from one voxel and automatically predicts its neighbors accurately. This is why NRF needs far fewer training images to reach high accuracy: instead of learning separately for each voxel, it learns the smooth pattern once and predicts at all other locations automatically.

Why it works

Why continuous representations fix the problem

The core mechanism is simple: a smooth function learned once can be evaluated anywhere. When you train on Subject A's voxel grid and switch to Subject B, you are not retraining; you are just asking the same smooth surface at new grid points. The Fourier feature encoding of coordinates (sinusoids at different frequencies) lets the MLP learn smooth mappings naturally—high frequencies capture fine detail, low frequencies capture broad structure.

Second, within a single subject, local smoothness means one voxel's response teaches you about its neighbors. Conventional models train a separate parameter for each voxel and miss this correlation. NRF captures it structurally: the same continuous function governs all voxels, so learning one's response constrains the neighbors. This is why NRF with only 200 images beats baselines trained on 800 images—the model is leveraging implicit spatial redundancy rather than memorizing isolated voxel responses.

Cross-subject adaptation works because anatomical space is a shared coordinate system (MNI standardized space). Pretraining on Subject A learns how brain responses vary smoothly over this shared anatomy. Fine-tuning on Subject B then amounts to a lightweight adaptation—learning a few subject-specific weights via least-squares, not rebuilding the entire model. This works because the underlying smooth function (how stimulus features map to brain responses in standard space) is largely shared across subjects.

Math after the picture

The equation: predicted response as a continuous function

First in words:

The model predicts brain response as a function of image features and 3D coordinate. The coordinate is encoded as sinusoids (Fourier features) at different frequencies. The image features and encoded coordinate are merged and passed through an 8-layer MLP to produce a scalar response prediction. At inference, a new subject's voxel-specific weights are learned by least-squares regression on the limited fine-tuning data.

Then the compact form:

r_hat = MLP_8( concat( image_features, fourier_encode(x, y, z) ) ); fine_tune: w_v = argmin_w sum_i (r_hat_i - r_i)^2

Every symbol:

r_hatpredicted fMRI response at coordinate (x,y,z)
image_featurescompact representation from AlexNet or CLIP
fourier_encode(x,y,z)sinusoidal encodings of 3D coordinates at multiple frequencies
MLP_88-layer neural network with 4096 hidden units and ReLU activations
w_vlearned subject-specific weight for voxel v (computed via least-squares on new subject data)
r_iground-truth fMRI response (observed brain activity)
A tiny worked example
Subject A (training): image features [0.5, 0.3, -0.2] + coordinate (10, 20, 15) encoded as Fourier [0.8, 0.2, -0.5, ...]. MLP outputs 0.7. Actual response: 0.65. Loss is squared error: (0.7 - 0.65)^2 = 0.0025.
Subject B (fine-tuning): same brain location (10, 20, 15), same image, Subject-A model predicts 0.68. Actual response: 0.72. Subject-specific weight w_v is tuned via least-squares: w_v = 1.05 (scaling factor). New prediction: 0.68 * 1.05 ≈ 0.71, much closer to 0.72.
Key insight: we reuse the learned smooth function from Subject A. We only learn a lightweight scale factor for Subject B. No full retraining needed.

The Fourier encoding lets the MLP learn smooth functions (high frequencies for detail, low frequencies for global trends); least-squares fine-tuning keeps adaptation fast and data-efficient.

What can go wrong

What can go wrong

Extreme resolution mismatch between subjects. If one subject's brain is anatomically very different (stroke, surgery, severe atrophy), MNI alignment breaks down. The pretrained model no longer captures that anatomy, and fine-tuning cannot fix it without enough data.
Coordinate encoding failure. If the Fourier features do not encode the right spatial scales (frequencies too coarse or too fine), the MLP cannot learn smooth mappings. The model may overfit to training coordinates and fail to interpolate.
Not enough fine-tuning data. On a truly new subject with only 50 images, even lightweight fine-tuning may not find good subject-specific weights. The least-squares fit becomes noisy.
Done right. With 200 well-sampled images from a new subject, pretraining + fine-tuning reliably beats training from scratch, even on subjects far outside the pretraining set.
What a runnable demo should prove

What a runnable demo should prove

Build a minimal NRF encoder that takes (image, x, y, z coordinate) and predicts fMRI response. Train it on Subject A's data (500 images, ~13,000 voxels). Then fine-tune on Subject B (200 images only) using least-squares weight learning. Measure prediction accuracy as correlation between predicted and actual voxel responses across Subject B's held-out test images. Compare against a baseline NRF trained from scratch on Subject B's 200 images with no pretraining. The demo should show the pretrained model winning by at least 5-10 percentage points correlation, proving that spatial continuity and anatomical alignment make pretraining portable.

prediction_accuracy = mean( correlation(predicted_response, actual_response) ) across all test voxels

The single most important observation: a model pretrained on one brain's continuous anatomy outperforms a model trained from scratch on a different brain, even though the two brains have different voxel grids and different data sizes, because anatomical space is shared (MNI coordinates are universal) and spatial smoothness is universal (neighboring brain tissue is correlated in all brains)—continuous representations in a shared coordinate system exploit this universality, making pretraining portable in a way that grid-locked discrete models cannot.
