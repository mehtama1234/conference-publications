Directional Convergence and Benign Overfitting in Leaky ReLU Networks

Neural networks can memorize noisy data perfectly yet still sort new data correctly when trained with gradient descent on natural mixtures.

Paper explainersAll themesLearning Theory

Neural networks sometimes memorize their training data completely, fitting every noise point exactly. Normally this is bad—an overfit model forgets how to handle new, unseen data. But this paper proves a surprising exception: on real-world data (mixture data, not specially cleaned data), certain two-layer networks can memorize training noise and still generalize well. The key is directional convergence: the network's weights move in a stable direction even as they swallow the noise.

Zero assumption version

Overfitting usually means forgetting

Overfitting is the classic nightmare in machine learning: you train a model on data that includes random noise (measurement errors, mislabeled examples, flukes). The model memorizes every noise point, getting 100% accuracy on the training data. But then you test it on new data, and it fails badly because the noise was not real—it was not there to be learned.

For many years, even mathematicians assumed this had to be true. The math they built said: if you fit all the noise, you lose the signal. So everyone trained smaller models, used regularization (penalties on big weights), and tried to stop before memorizing noise. But recently, labs discovered something weird: sometimes bigger networks DO memorize the noise and still generalize. How?

The puzzle. When do networks memorize training data perfectly and still guess new data correctly?

What the paper changes

What the paper changes

The paper proves a property of the network's weights themselves: that they converge toward a stable direction as training progresses. Previous work only proved this for gradient flow (an idealized, frictionless version of training). This paper proves it for gradient descent—real training with discrete steps—on natural mixture data (real data where different classes overlap).

the object it moves  =  Weight convergence direction
The hidden quantity

The hidden quantity: directional stability

measured quantity  =  Alignment of weights to the signal direction

Directional convergence is the idea that as the network trains, its weight vectors point more and more consistently in one direction—like a compass needle slowly settling. It does not mean the magnitude (the length of the weight vector) stays fixed; it means the angle, the direction it points, becomes stable.

The paper measures this by watching the angle between the current weight vector and a fixed reference direction (the true signal direction). If weights are directionally converging, this angle shrinks. The paper proves that on mixture data, this angle shrinks reliably even as the weights grow large.

Why it works

Why directional convergence saves generalization

Here is the paradox: the network memorizes noise, so individual weight values become large and unstable. But the angle—the direction the weights point—stays locked onto the true signal. When a new example arrives, that stable direction is what matters for the prediction. The noise-fit weights point at the real pattern anyway.

Mathematically, leaky ReLU networks have a property: the decision boundary is determined mostly by the direction of the weights, not their absolute size. So a weight vector that points north but becomes ten times longer still cuts the data the same way. The network can scale itself up to memorize noise (large values fit more detail) while keeping its decision boundary (the angle) anchored to the true signal. This is why overfitting does not break generalization here.

The classification error bound

First in words:

Classification error on new data is bounded by how far the converged weight direction drifts from the true signal, times a factor that depends on how much noise was memorized and the strength of the true signal.

Then the compact form:

err_test <= C1 * angle_drift + C2 * (noise_magnitude / signal_strength)

Every symbol:

err_testClassification error rate on new test data
C1, C2Constants depending on network width and data size
angle_driftHow far actual weight direction deviates from true signal direction
noise_magnitudeSize of the random errors in training data
signal_strengthHow far apart the two classes are in the data
Tiny example: binary classification
Suppose angle_drift = 0.05 radians (weights point almost at signal), C1 = 0.2, C2 = 0.1.
Suppose noise_magnitude = 1 (small random errors), signal_strength = 10 (classes are far apart).
err_test <= 0.2 * 0.05 + 0.1 * (1 / 10) = 0.01 + 0.01 = 0.02.
Even with memorized noise, the error bound is 2%, because the angle stayed aligned.

When the angle drift is small and the signal is strong, test error stays low even if training data was memorized perfectly.

What can go wrong

What can go wrong

Unmixed or adversarial data. If data is not a natural mixture (e.g., classes are scattered in weird clusters), directional convergence may fail and memorization breaks generalization as expected.
Signal too weak. If noise magnitude is comparable to class separation, the bound grows large even with aligned weights. Weak signal plus heavy noise defeats the mechanism.
Very deep networks. This result is for two-layer networks only. Deeper networks have more complex decision surfaces and may not preserve directional stability.
Done right: tight alignment. When weights stay tightly aligned to the true signal direction and noise is modest relative to class separation, benign overfitting holds.
What a runnable demo should prove

What a runnable demo should prove

Build a two-layer leaky ReLU network on a simple two-class data set (e.g., two Gaussian clusters mixed with noise). Train it to 100% accuracy. Plot the weight vector direction over training steps. Measure how much the direction angle shrinks. Then test on new data drawn from the same source and record test accuracy. Repeat with different noise levels and class separations.

benign_overfitting = (training_accuracy >= 95%) AND (test_accuracy >= 80%) AND (angle_drift <= 0.1 radians)

The demo should show: as training progresses, weight direction converges to a stable angle, and despite perfect training-set memorization, test accuracy stays high on new data.
