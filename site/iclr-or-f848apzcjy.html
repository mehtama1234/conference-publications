Dyna-Mind: Teaching Agents to Simulate

Teach language-model agents to mentally preview multiple futures before acting, then strengthen that ability with feedback from real rollouts.

Paper explainersAll themesAgents & Tool Use

AI agents are good at narrow tasks like math problems but fail at complex interactive tasks such as navigating a website or controlling a phone. The missing piece is the ability to mentally play out different actions and see where each leads before committing — what humans call vicarious trial and error. Dyna-Mind teaches agents this skill in two stages: first by showing them reasoning traces built from expanded search trees gathered from real environment interactions, then by reinforcing their simulation ability with feedback signals from actual outcomes.

Zero assumption version

Agents reason narrowly and cannot plan ahead

Today's language-model agents (models that read a situation and write an action, like a browser controller or phone-use AI) work well when the answer is close and visible. Math problems, coding questions, fact lookups — these the agent can reason through in one or two steps. But interactive tasks like web navigation or computer control require many steps, and the agent must anticipate what will happen after each action to choose wisely.

A beginner tries to train the agent purely from examples: show it successful paths through web forms, phone screens, or game boards, and it learns to imitate. The problem: the agent has no internal model of how the world responds. It cannot preview consequences. When it reaches a situation not in the training examples, it guesses blindly instead of thinking ahead.

The paper's move in one sentence. Teach the agent to construct and reason about branching futures during planning, then strengthen that simulation ability by training on both final outcomes and intermediate states from real rollouts.

The algorithm as a flow

What it actually does

Stage 1: Collect reasoning with simulations

Gather real environment interactions and expand them into search trees, then write out the full reasoning that ties the tree to an action choice.

Stage 1: Train by imitation

Show the agent reasoning traces and teach it to generate that same structured simulation-based reasoning directly, without needing the search algorithm.

Stage 2: Collect rollouts and real outcomes

Run the trained agent in the environment and record both what happens (the final success or failure) and the intermediate states it passes through.

Stage 2: Train with outcome and state signals

Use reinforcement learning to nudge the agent's reasoning and action-choosing, rewarding it when the simulated futures match what actually happened.

Result: agent reasons via simulation

The agent can now mentally branch futures, and its simulations grow more accurate through real-world feedback, because each real rollout shows exactly where predictions diverged from reality and the reinforcement learning stage uses that difference to tune the model.

The hidden quantity

The simulation fidelity — how well the agent's predictions match reality

measured quantity  =  simulation fidelity: how far ahead the agent can forecast accurately

A language-model agent reasons by predicting the next state after each action. Simulation fidelity is how accurate those predictions are — does the agent correctly anticipate what the screen will look like after it clicks a button, or after it fills a form field? Higher fidelity means the agent's mental preview aligns with real outcomes.

The paper measures this implicitly: it trains the agent on reasoning traces built from real search trees (so the predictions come from genuine consequences), then tunes the model using reinforcement learning signals from actual rollouts. As the model improves, its predictions get more faithful to how the world actually responds, because the reinforcement learning stage explicitly penalizes predictions that do not match observed outcomes and rewards predictions that align with real states.

Why it works

Why teaching simulation helps planning

An agent that can only imitate past examples is blind to consequences. But if the agent can predict future states, it can reason about which action is likely to lead to the goal. The mechanism works in two parts.

First, Reasoning with Simulations (ReSim) anchors predictions to real futures. Instead of guessing what will happen, the algorithm builds a search tree by trying multiple actions in the real environment, then asks the language model to synthesize that whole tree into a single reasoning response that explains how the best path leads to success. Training on these responses teaches the model the relationship: if you take action A, then action B, then action C, the world state evolves this way and you reach the goal. The model learns not just imitation but causal structure.

Second, Dyna-GRPO strengthens those predictions with reinforcement learning feedback. When the agent generates actions in real rollouts, the algorithm observes both the final outcome (success or failure) and the intermediate states along the way. It then trains the agent to predict those intermediate states and choose actions that move through predicted high-value states. Because the predictions are grounded in real outcomes, the agent's simulations become more faithful and its planning more accurate.

Math after the picture

Training loss that grounds simulation in real outcomes

First in words:

The loss combines imitation learning (match the agent's reasoning to demonstration traces) and reinforcement learning (reward simulations that lead to high-value real outcomes).

Then the compact form:

L_total = L_imitation + lambda * L_RL

Every symbol:

L_imitationloss from comparing agent's reasoning trace to the demonstration trace built from search tree
L_RLreinforcement learning loss that rewards actions leading to real task success
lambdaweight controlling how much to prioritize RL refinement over imitation
A tiny worked example
Agent reasoning: 'From state S, if I click button X, I will see form. Then if I type name, screen shows confirmation. Best path is X then type.'
Demonstration from search tree: 'From state S, action X leads to form (real outcome). Action type leads to confirmation (real outcome). This path succeeds.'
Imitation loss: difference between agent's prediction and observed outcome is 0.5 (agent predicted wrong details). L_imitation = 0.5.
Real rollout: agent takes the action sequence, reaches success. Reward = +1.0. L_RL = 0 (no penalty, because outcome was correct).
L_total = 0.5 + 0.1 * 0 = 0.5. On the next attempt, agent learns to refine its simulation.

The two losses pull together: imitation grounds the agent in real-world cause and effect, and reinforcement learning refines the predictions to match actual outcomes.

What can go wrong

What can go wrong

Simulation gets out of sync with reality. If the agent's predictions drift away from how the world actually responds (e.g., it thinks clicking button A opens menu, but it opens a modal), planning will lead to wrong actions. The model needs constant feedback from real rollouts to recalibrate.
Search tree collection is expensive. Building reasoning traces requires running multiple rollouts from each state to construct the search tree. This is much more costly than simple imitation. If environment interaction is expensive (e.g., interacting with a real website), collecting enough data becomes prohibitive.
Agent hallucinates plausible but false futures. A language model can always generate text that sounds reasonable. If the training data has gaps or the model has poor inductive bias, it may predict futures that sound coherent but do not match the real environment, leading to planning failures.
Done right: simulation grounded in real outcomes. When the training data comes from genuine environment interactions (not synthetic or hallucinated) and the reinforcement learning stage continuously updates predictions against real feedback, the agent's simulation becomes trustworthy and planning improves, because the model learns the true causal structure of the world rather than plausible-sounding but false patterns.
What a runnable demo should prove

What a runnable demo should prove

A minimal demo should show that an agent trained with Dyna-Mind can solve a multi-step task by reasoning about futures. Use a simple grid world (like Sokoban: push a box to a goal in a small room) or a text-based task (like a form-filling chain). Train two versions: one with imitation-only, one with Dyna-Mind (ReSim + Dyna-GRPO). The key test is to give both agents a puzzle they have never seen during training (a different room layout or form structure). The imitation-only agent should fail or choose suboptimal actions because it cannot reason ahead. The Dyna-Mind agent should branch futures mentally, predict which action leads closer to the goal, and solve the task. Measure success rate and average number of steps to completion.

success_rate = (tasks_solved / total_tasks) * 100%; avg_steps = sum_of_steps_to_goal / tasks_solved

The demo must make clear that only when the agent simulates futures does it solve unfamiliar multi-step tasks reliably.
