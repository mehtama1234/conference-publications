Graph foundation model with cross-modal fusion

The paper learns universal patterns in multimodal graphs by separately encoding each data source then routing each dimension to specialized experts that fuse information across text, images, and structure.

Paper explainersAll themesGraph & Geometric Learning

Real-world networks contain structures (connections between things) alongside information in different forms: text descriptions and images. Existing graph models treat only one type of information at a time. This paper shows how to build a model that learns patterns by taking in all forms together, learning which parts of the information matter for which decisions, and aligning the different views so they reinforce each other.

Zero assumption version

Single-view models miss the full picture

A social network has structure (who follows whom), text (what people write), and images (what they post). Current graph models pick one view: either they learn from connections alone, or they add text features in, or they add images in. But they do not learn to use all three at once.

A naive first attempt might just concatenate all features together and send them through the same neural pathway. This fails because text and images have different meanings: the same dimension might capture color in images but tone in text, yet the model tries to treat it the same way in both. Dimensions that matter for text get drowned out by dimensions that matter for images, and the model never learns to use each modality where it is strongest.

The paper's answer in one sentence: Generate a separate graph representation for each modality, then route each dimension to a specialist expert that decides how to combine that dimension across all three modalities based on what the data actually needs.

The algorithm as a flow

What it actually does

Separate encoding

For each modality (structure, text, images) run a model to turn raw data into intermediate feature lists.

Dimension-wise routing

For each position in the feature list, decide which expert should handle that dimension's fusion across all modalities.

Expert fusion

Each expert takes its assigned dimensions from all modalities and blends them into a single value.

Cross-modal alignment

Use a contrastive loss to pull similar items (same node seen from different modalities) close together in the final representation.

Single output

All nodes now have one shared representation combining structure, text, and image information intelligently.

What the paper changes

What the paper changes

The paper replaces a single shared pathway with a set of specialized pathways (experts) that each handle a different subset of dimensions. Instead of one neural layer processing all features the same way, the model routes dimension 1 to expert A, dimension 2 to expert B, and so on. Each expert can learn different fusion rules for its dimensions.

the object it moves  =  routing destination (which expert)
The hidden quantity

The hidden quantity: dimension-wise routing scores

measured quantity  =  How much each expert is trusted for each dimension

The model must decide, for each dimension, which modality or combination of modalities to rely on. Does dimension 17 come mostly from text, or from images, or should both be blended equally? The routing score is a number between 0 and 1 for each (dimension, expert) pair that says how much to use that expert's view of that dimension. A score of 0.8 means 'use this expert's decision 80% of the time' and 0.2 means 'use it less often'.

The paper learns these routing scores from the data by trial and error. During training, the model watches which routing choices lead to correct predictions. When a node is correctly predicted because dimension 17 was routed to the text expert, the text expert's score for dimension 17 goes up slightly. When a prediction is wrong, that score may go down. Over thousands of steps, the model discovers which expert suits which dimension.

Why it works

Why it works: matching experts to modality strength

The core insight is that different parts of the feature space are better at different jobs, because each modality measures the world differently. Some dimensions carry clear text information (e.g. 'sentiment' appears explicitly in descriptions) but noisy image information (color varies for many reasons unrelated to emotion — lighting, material, subject — so it gives false signals), so text is better for that dimension. Other dimensions work the opposite way (e.g. 'shape' is directly visible in images but nearly impossible to capture with words). A single shared fusion rule for all dimensions would average these out and lose both signals, forcing the model to learn a mediocre compromise. Instead, routing lets the model ask: 'for THIS dimension, which modality is most informative?' and use only that modality's expert, preserving the genuine strength each modality has.

Cross-modal contrastive learning reinforces this by pulling representations of the same node together across modalities. If the network sees node X from the structure view, text view, and image view, the model trains so all three produce similar representations. This acts as a soft constraint: the routing must produce consensus, not contradictions. A dimension that contradicts across modalities gets penalized, forcing the router to either specialize it to one modality (where it is consistent) or blend it carefully (where all three modalities agree).

The result is that each expert learns to fuse only its assigned dimensions competently, rather than every expert trying to fuse everything and interfering with each other. Text expertise stays sharp for text-heavy dimensions; image expertise stays sharp for image-heavy dimensions; structure expertise handles topology-only signals. The model can use all three modalities' knowledge without their noise diluting each other.

Math after the picture

The fusion equation with symbol table

First in words:

For each dimension d, compute a weighted average of the three modalities using learned routing scores. Then, add a penalty that pulls representations from the same node closer together across modalities.

Then the compact form:

output_d = sum_m router_m(d) * expert_m(feature_m_d) + lambda * sum_nodes distance(repr_struct(node), repr_text(node)) + distance(repr_text(node), repr_image(node))

Every symbol:

output_dthe fused value for dimension d
mmodality index: structure (1), text (2), or image (3)
router_m(d)learned score saying how much to trust expert m for dimension d (between 0 and 1)
expert_m(feature_m_d)expert m's output when given dimension d of modality m's features
lambdastrength of the alignment penalty (how much to pull nodes together)
repr_x(node)representation of a node from modality x
distancehow different two representations are (larger = more different)
Tiny worked example with real numbers
Suppose node 5 has structure feature (score 2.0), text feature (score 7.0), and image feature (score 4.0) for dimension 3.
Routing scores for dimension 3: structure gets 0.1, text gets 0.7, image gets 0.2 (sum to 1.0).
Expert outputs: structure expert outputs 2.0*0.1=0.2, text expert outputs 7.0*0.7=4.9, image expert outputs 4.0*0.2=0.8.
Fused dimension 3 = 0.2 + 4.9 + 0.8 = 5.9 (mostly text, some image, little structure).
Alignment penalty: if this node's text representation is (5.9, 3.2, ...) and image representation is (6.1, 3.1, ...), distance = 0.04; penalty = lambda * 0.04 (small, because they already agree).

The router learns to send each dimension to the expert that best understands it, and the contrastive penalty makes sure all experts agree on what matters.

What can go wrong

What can go wrong

Routing collapse. If the contrastive loss is too strong, all experts learn to produce nearly identical outputs, making routing meaningless. The model stops specializing and reverts to a single shared pathway.
Imbalanced expert usage. If one modality is much richer than others (e.g. huge labeled image datasets but tiny text), the router may assign most dimensions to the image expert. Text and structure experts stay weak and never develop real expertise.
Alignment contradictions. If the three modalities genuinely disagree on what a node represents (e.g. image pixels resemble a dog but text tags it as 'cat'), the contrastive loss fights the router, and neither learns well. The model oscillates between fitting one modality and pulling them into false consensus.
Done right. Tune lambda carefully (too high causes collapse, too low means no alignment); collect diverse multimodal datasets where modalities complement rather than contradict; monitor expert usage histograms to catch imbalance early.
What a runnable demo should prove

What a runnable demo should prove

Build a small heterogeneous network (e.g. product reviews: nodes are products, structure is co-purchasing links, text is review summaries, images are product photos). Train CAME on this network for a task like 'predict product category'. Then run ablations: (1) remove routing and use uniform expert weights; (2) remove the contrastive loss and train only the fusion experts; (3) keep only one modality at a time. The demo should show that CAME beats all three ablations.

multimodal_accuracy = (correct_predictions_from_all_3_modalities) / (total_predictions)

The demo shows that routing + contrastive alignment together beat any single piece alone because routing specializes each expert to what it sees best, and alignment makes sure all experts agree on the important parts, eliminating the compromise that would happen if they all tried to handle every dimension equally.
