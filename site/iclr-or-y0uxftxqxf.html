What matters for Representation Alignment: Spatial Structure over Global Performance

Spatial structure in image patches matters more than overall accuracy when copying knowledge from a vision model into a diffusion model.

Paper explainersAll themesGenerative Models & Diffusion

When training a diffusion model (a model that generates images by gradually removing noise), researchers often use knowledge from a pretrained vision model (a model that recognizes objects in images). The common assumption is that a vision model with higher accuracy — better at recognizing objects on standard tests — should make a better source, because it has learned richer, more reliable features. This paper asks: is that true? The surprising answer is no. What actually matters is the spatial structure: the patterns in how similar nearby patches are to each other, because diffusion learning reasons about neighboring pixels and learns faster when that structure is already in the teacher. The paper proposes iREPA, a simple tweak using local neighborhood blending (mixing each patch with its neighbors) instead of global multiplication, that lets diffusion models use this spatial knowledge directly without scrambling it.

Zero assumption version

The assumption that breaks

Diffusion models generate images by starting with pure noise and slowly removing it in steps, like developing a photograph in reverse. To speed up training, researchers copy knowledge from a pretrained vision model — one already trained to recognize objects in photos, because it has learned patterns (edge detection, shape recognition, texture) that are useful for understanding images. The common idea: a model that is really good at spotting dogs in ImageNet (a standard photo collection) should be a good teacher for the diffusion model.

But here is the puzzle: among 27 different vision models tested, the ones with the highest accuracy scores did not always produce the fastest or best diffusion training. This suggests the conventional wisdom — higher accuracy equals better teacher — is backward or incomplete, because accuracy only measures whether the model guesses the right label, not whether it preserves the structure of the image itself. A model can guess dog-labels correctly while scrambling neighborhood patterns, which hurts diffusion learning.

The assumption. A vision model's accuracy on ImageNet (how many photos it labels correctly) predicts how well it will help train a diffusion model, because we assume that learning to recognize objects requires understanding images deeply.

What the paper changes

The one thing the paper changes

In standard representation alignment, features from the vision model are mixed using a simple projection: multiply each number by a weight, add them up. This flattens all spatial information — it treats the top-left patch and bottom-right patch as if they were interchangeable.

iREPA replaces this multiplication step with neighborhood blending (a technique called convolution), which mixes each patch with its neighbors rather than treating all patches as separate. This is a local, spatially-aware mixer.

the object it moves  =  the projection from global multiply to local convolution
The hidden quantity

The hidden quantity: spatial coherence

measured quantity  =  spatial coherence

Spatial coherence is how much patches near each other in an image have similar features. When you look at a photo, pixels that are close together usually mean similar things — the left side of a dog's face is similar to the right side. A vision model trained on object recognition naturally learns this: its internal representations show high similarity between neighboring patches.

The paper measures spatial coherence by taking two nearby patches (e.g., from a given image), passing them through the vision model, and computing how similar their outputs are (using cosine similarity, which gives a number from 0 to 1, where 1 means identical). High similarity means strong spatial coherence. The paper shows that vision models with high spatial coherence, rather than high overall accuracy, teach diffusion models faster because diffusion learning inherently reasons about local neighborhoods and can directly use models whose features already preserve spatial patterns.

Why it works

Why spatial structure works

A diffusion model learns to denoise images step by step. At each step, it looks at a slightly-noisy image and predicts what to remove. To learn well, it needs to know what should be similar — what pixel patterns tend to appear next to each other. A teacher that preserves this neighborhood logic directly translates to faster learning, because the model does not have to re-discover it.

When you use multiplication (standard projection), you scramble this information: weight 1 of patch A affects the output equally as weight 1 of patch B, even if they are far apart. Local neighborhood blending (convolution), by contrast, is inherently local — each output value depends on a neighborhood of inputs, respecting the image structure. This matches how diffusion learning works: it reasons about local context to denoise. Therefore, using a teacher whose knowledge is already organized spatially (high coherence) and mixing that knowledge spatially (via neighborhood blending) creates a straight pipeline with no information loss.

The alignment equation

First in words:

loss = mean squared error between target patch features and diffusion model features, computed locally via convolution

Then the compact form:

loss = (1/N) sum_{i=1}^{N} (Conv(F_target[i]) - F_diffusion[i])^2

Every symbol:

losstraining error to minimize
Nnumber of patches in the image
F_target[i]feature vector from vision model for patch i
F_diffusion[i]feature vector from diffusion model for patch i
Conv(F_target[i])local convolution mixing patch i with its neighbors
A tiny worked example
Imagine a 2x2 image (4 patches). Vision model outputs are [8, 7, 7, 6] (features per patch).
Diffusion model predicts [9, 6, 8, 5] for the same patches.
Convolution mixes neighbors: top-left patch sees (8+7+7)/3 = 7.3, top-right sees (8+7+6)/3 = 7.0, etc.
Error per patch: (7.3 - 9)^2 = 2.89, (7.0 - 6)^2 = 1.0, (7.0 - 8)^2 = 1.0, (6.3 - 5)^2 = 1.69.
Total loss = (2.89 + 1.0 + 1.0 + 1.69) / 4 = 1.645.
Convolution forces the diffusion model to learn that neighboring patches should have similar outputs, matching the structure in the vision model.

The loss combines each patch with its neighbors (via convolution), so the diffusion model learns to produce locally coherent outputs, just as the vision model does.

What can go wrong

What can go wrong

Choosing a vision model by accuracy alone. If you rank models by ImageNet accuracy and pick the top one as your teacher, you may get slower diffusion training than a model with lower accuracy but better spatial structure, because diffusion learning cares more about neighborhood patterns than about overall accuracy. Always measure spatial coherence.
Neighborhood blending with too-large regions. If the neighborhood is too large, it mixes distant patches that should be independent, blurring important details. Use small neighborhoods (typically 3x3 grids of patches) to respect local structure only.
Spatial normalization applied incorrectly. If spatial normalization is not aligned with the image resolution or patch grid, it can introduce artifacts. Apply it after convolution, respecting the patch structure.
Done right. Choose vision models by spatial coherence, use small-neighborhood blending (3x3 regions), and apply spatial normalization consistently. Training converges 1.5–2 times faster than standard REPA across all tested encoders and model sizes because the spatial structure is preserved and usable.
What a runnable demo should prove

What a runnable demo should prove

Train a small diffusion model (e.g., a toy 10-step diffusion on CIFAR-10, a small image dataset) using two different teachers: (1) a vision model with high ImageNet accuracy but low spatial coherence (e.g., a model optimized for object recognition alone), and (2) a vision model with moderate accuracy but high spatial coherence (e.g., a model trained with contrastive loss that emphasizes patches). Using iREPA (neighborhood-blending projection), the second teacher should produce a faster-converging diffusion model, even though the first has higher accuracy, because diffusion training directly uses spatial patterns. Measure convergence as the number of training steps until the generated images visually improve (lower noise, clearer shapes), because this directly reflects how quickly the diffusion model learns to denoise, which is the core task.

convergence_speed = steps_to_50pct_quality_standard / steps_to_50pct_quality_iREPA

If iREPA with a spatially-coherent teacher converges 1.5–2 times faster than standard REPA with an accurate-but-incoherent teacher, the mechanism is proven: spatial structure, not accuracy, drives fast diffusion learning because diffusion's neighborhood-aware learning directly uses spatially coherent representations.
