Beyond Correctness: Distance-Based Social Dynamics of Multi-Agent Debate

Measure how far each debated answer is from the right answer so you can see whether discussion pulls workers closer to the target or pushes them away from it.

Paper explainersAll themesAgents & Tool Use

Most debate studies ask only whether the final answer is right. That hides the fine structure of what discussion does. An answer can stay wrong yet move much closer to the truth, or a correct answer can be pushed off target by persuasive but slightly wrong peers. This paper studies that movement directly on a benchmark where answers live on two-dimensional grids, so the distance from one answer to another can be measured exactly.

Zero assumption version

Why right-versus-wrong misses the real debate dynamics

Suppose three workers answer a puzzle and then see each other's replies. If one worker changes from a very wrong answer to a nearly right answer, a binary score still says wrong both times. That loses information about whether discussion helped. The same problem appears when a correct worker changes to a slightly wrong answer after seeing peers. Binary scoring marks only the final mistake, not the social pressure that caused it.

To understand multi-worker debate, you need to track movement in answer space. That means asking how far each answer is from the truth before and after discussion, because change in distance reveals whether the interaction improves the solution, freezes it, or slowly degrades it.

The paper's move. Replace a pure correctness score with a distance view, because discussion can change answer quality long before it changes the final right-or-wrong label.

The algorithm as a flow

What the analysis actually does

Choose a task with measurable answer distance

Use a grid-reasoning benchmark where two candidate answers can be compared cell by cell so that movement toward the truth is measurable.

Control the peer context

Show a target worker specific peer answers so that the study can isolate how different social situations change revision behavior.

Measure starting distance

Compute how far the worker's original answer is from the truth, because revision behavior depends strongly on that starting point.

Measure revised distance

Record whether the worker changes the answer and whether that change moves the answer closer to or farther from the truth.

Summarize the revision pattern

Analyze how often workers revise and in which direction, because that reveals when debate helps and when it harms.

The hidden quantity

The hidden quantity

measured quantity  =  distance contraction toward the true answer

The key hidden quantity is contraction: after seeing peers, does a worker's answer move closer to the true answer or farther away? Contraction matters because two wrong answers are not equally wrong. One may miss by one cell while another misses by many cells.

The paper tracks contraction by comparing the worker's distance to the truth before and after revision. A positive contraction means the revised answer is closer to the truth. A negative contraction means social pressure caused regression.

Why it works

Why peer pressure creates structured movement

Workers do not revise at random. When a worker starts far from the truth, many visible mismatches remain between that answer and stronger peer answers because the wrong cells are easier to expose through comparison. That creates more room for correction, so revision is more likely and often moves inward. When a worker starts at the truth, the answer is already at a fragile optimum. A slightly wrong peer answer can still look appealing because it shares many visible parts with the truth while offering a different local pattern.

This is why distance matters. Debate does not simply flip answers between right and wrong. It reshapes them step by step. Measuring distance reveals that wrong answers often contract toward the truth because discussion exposes local defects, while correct answers can regress because close-but-wrong peers create persuasive alternatives that are hard to reject from the visible surface alone.

Math after the picture

Measure the change in distance

First in words:

Compute the distance from the original answer to the truth and subtract the distance from the revised answer to the truth. Positive values mean debate moved the answer closer.

Then the compact form:

contraction = d(answer_before, truth) - d(answer_after, truth)

Every symbol:

contractionhow much the revised answer moved toward the truth
d(.,.)a distance between two grid answers, such as cell mismatch count
answer_beforethe worker's answer before seeing peers
answer_afterthe worker's answer after discussion
truththe correct grid answer
A tiny worked example
Before discussion, a worker's grid differs from the truth in 6 cells.
After discussion, the revised grid differs in 2 cells.
Contraction is 6 - 2 = 4.
That means the worker stayed wrong if 2 cells still differ, but the answer still improved a lot.
If a correct answer starts at distance 0 and shifts to distance 1, contraction is 0 - 1 = -1, which marks regression.

This one number separates improvement from regression even when both states remain inside the same binary correctness bucket.

What can go wrong

What can go wrong

The task must admit a clear distance. If answers do not live in a space where closeness is measurable, then contraction loses value because there is no reliable way to say whether one wrong answer is closer than another.
Near-correct peers can still mislead. A worker may follow a peer whose answer is only slightly wrong because the visible overlap with the truth makes that peer look trustworthy.
Averaging can hide subgroup behavior. If you summarize only the mean contraction, you may miss that some workers improve sharply while others collapse, because the average can cancel both patterns.
Done right. The analysis is most useful on tasks with a clear answer distance and controlled peer exposure, because then the measured movement can be tied to specific social conditions.
What a runnable demo should prove

What a runnable demo should prove

Build a small grid puzzle with a known correct answer and three candidate workers. Give each worker an initial grid with a measured distance to the truth. Then reveal selected peer answers and allow one revision round so that you can observe whether peer exposure changes the direction of the answer. Record whether the worker changes the answer and whether the new answer moves inward or outward.

The demo should show cases where binary correctness says nothing changed while the distance score shows strong inward motion, and cases where a correct answer is overturned by a near-correct peer.

mean_contraction = average(distance_before - distance_after)

A convincing demo must show that discussion changes answer quality before it changes correctness, because that is the paper's main claim.
