DisTaC: Conditioning Task Vectors via Distillation for Robust Model Merging

DisTaC pre-conditions task vectors using knowledge distillation before merging them, so models that would normally fail to combine can now be merged successfully.

Paper explainersAll themesOther

Suppose you have three models, each trained separately to do one task—write poems, solve math, fix code. You could combine them into one model by averaging their weights together. But if the three models were trained using different settings, their internal numbers might differ wildly in size, and the averaging fails. DisTaC rescales those number-sets before averaging them, using distillation to make sure the rescaling doesn't break what each model learned.

Zero assumption version

Combining separate models breaks when they're not identical

In the real world, you often have models trained separately for different tasks. You might have one model tuned for image recognition, another for image captioning, a third for image retrieval. Averaging their weights together (called merging) lets you combine their skills into a single model without retraining from scratch.

But here is the problem: if those three models were trained using different random seeds, different learning rates, or different amounts of training, their internal weights end up at very different scales. One model's weights might range from 0.001 to 0.5; another's from 0.1 to 50. When you average them, the large-scale model drowns out the small-scale one. The merged model loses skills, sometimes catastrophically.

A beginner tries this: just average all the weights. It fails. Then they try: scale everything to the same range first. It still fails, because scaling alone loses the detailed knowledge each model learned.

The fix in one sentence. Rescale each weight-set to the same size, then run a gentle knowledge-distillation step to restore what was lost by the rescaling.

The algorithm as a flow

What it actually does

Measure the problem

Check if the three weight-sets have wildly different sizes (norm disparities) or if the original models aren't confident in their predictions.

Rescale each weight-set

Divide or multiply each weight-set by a scaling factor so all three are the same size.

Set up a student model

Make a new copy of one model, starting with the rescaled weights.

Distill from the original

Train the student model using unlabeled data, learning from the original model's soft predictions (not hard labels).

Merge all three

Once distillation is done, average the three conditioned weight-sets; the result keeps all three models' learned skills.

What the paper changes

The one thing it changes

DisTaC changes the task vectors—the difference between a model's pre-trained weights and its fine-tuned weights—before merging happens. A task vector is like a recipe: it says how much to nudge each weight from its starting point to accomplish one specific task. The paper rescales these recipes to a common size.

the object it moves  =  Task vectors (weight-difference recipes)
The hidden quantity

Task vector norm: the invisible size that breaks merging

measured quantity  =  Task vector norm (total weight-change magnitude)

When a model trains on a task, not all of its weights change equally. Some weights move a lot, others barely move. The norm is the total size of all those movements combined—like the length of an arrow pointing from the start to the final point. If one model's task vector has norm 50 and another's has norm 5, averaging them gives a merged model that is mostly the first one.

DisTaC estimates this norm for each task vector and rescales all of them to the same target norm before merging. The paper measures how different the norms are across source models (the disparities) and shows these disparities are what causes merging to fail.

Why it works

Why rescaling + distillation works

Imagine a seesaw balanced between two weights. If one weight is much heavier, the seesaw tilts and breaks. Rescaling makes them equal in weight. But when you rescale, you accidentally lose some of the original weight's internal detail—its texture, its precise shape. Distillation restores that texture: you teach the rescaled weight to mimic the original weight's behavior on unlabeled examples, so it keeps the same internal knowledge even though it weighs the same as the others.

The paper runs distillation by minimizing two losses at once: a standard classification loss (on unlabeled data, just using hard labels to make sure the model still works) and a knowledge-distillation loss (making the rescaled model's soft predictions match the original model's soft predictions—the detailed confidences, not just right-or-wrong). The soft predictions are like dark knowledge—the fine relationships the original model learned between categories. This dual loss restores what the raw rescaling erased.

Math after the picture

The distillation objective

First in words:

Total loss equals standard classification loss plus a weighted knowledge-distillation loss. The classification loss trains on unlabeled data using hard labels. The distillation loss measures how different the student's soft predictions are from the teacher's, scaled by temperature to soften both.

Then the compact form:

L_total = L_CE(theta, y_hard) + beta * KL(softmax(p_teacher / T_teacher), softmax(p_student / T_student))

Every symbol:

L_CEstandard classification loss on unlabeled data
thetathe student model's weights being trained
y_hardthe unlabeled data's hard labels (not from teacher)
betahow much weight to give distillation vs classification
p_teacherthe original model's prediction logits (raw scores)
p_studentthe rescaled model's prediction logits
T_teachertemperature for the teacher (usually 1)
T_studenttemperature for the student (e.g., 4, softens both)
KLKullback-Leibler divergence (how different two distributions are)
A tiny worked example
For a 3-class problem: teacher predicts (0.7, 0.2, 0.1) for classes A, B, C.
Student predicts (0.6, 0.25, 0.15) — slightly different.
L_CE on hard label C: -log(0.15) ≈ 1.9
Soft distillation: KL divergence between teacher and student ≈ 0.05
Total loss = 1.9 + 0.5 * 0.05 = 1.925 (beta = 0.5 is example only).
Update (nudge) the student's weights toward matching the teacher's soft predictions while keeping hard-label accuracy.

The two losses work together: the hard-label loss keeps the merged model useful on the original task; the soft-distillation loss keeps it remembering what the original model knew about relationships between classes.

What can go wrong

What can go wrong

Rescaling without distillation still loses knowledge. If you only rescale the weights without running distillation, the rescaled model becomes just a shrunken or stretched copy of the original—it no longer predicts well on the task. You must follow rescaling with distillation to restore the learned relationships.
Distillation converges too slowly. If you don't run distillation long enough, the student never fully recovers the teacher's soft predictions. In practice, a few hundred training steps on unlabeled data is usually sufficient, but the paper shows you need at least 100 steps to see clear recovery of the knowledge.
Low-confidence source models still hurt even after distillation. If the original model was trained to be overconfident (e.g., with high temperature or label smoothing disabled), its soft predictions are sharp and unreliable. Distilling from it can teach the student the same overconfidence. You must calibrate the source model or apply calibration to the merged result to fix this.
Done right. Choose a reasonable target norm (e.g., the median of all source norms), rescale each task vector to that target, run 300–500 steps of distillation on unlabeled task data with a moderate beta (0.5–1.0), then merge. The result preserves all three models' skills.
What a runnable demo should prove

What a runnable demo should prove

Build a small experiment with three toy models, each fine-tuned on a different subset of a standard image dataset (e.g., CIFAR-10: one model trained only on dogs, one on cats, one on birds). Measure task vector norms—they should differ (e.g., 4.2, 1.8, 3.1). Merge them naively and record accuracy on each task. Then pre-condition with DisTaC: rescale all norms to 3.0, run 200 steps of distillation on unlabeled CIFAR-10, then merge. Re-measure accuracy on each task.

Forgetting per task = (accuracy before merge) - (accuracy after merge). DisTaC reduces forgetting from 30+ points to under 10 points per task.

The demo must show that naive merging causes severe accuracy loss on the smaller-norm and medium-norm tasks, while DisTaC keeps all three tasks' accuracy within 5 points of the original.
