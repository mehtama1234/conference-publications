Continuum Transformers Perform In-Context Learning by Operator Gradient Descent

Continuum transformers—a type of model that takes infinite-dimensional function inputs like PDEs—learn new operators inside their forward pass by performing gradient descent on a Hilbert space, and the operator they learn in-context is proven to be the best-possible predictor.

Paper explainersAll themesLearning Theory

Standard transformers handle lists of numbers (called tokens). But some problems need to learn from entire functions—like predicting how a physical system evolves (a PDE surrogate). Continuum transformers extend the idea to handle function inputs. This paper proves that when a continuum transformer learns a new operator from in-context examples, it is not just pattern-matching—it is literally performing the same algorithm used in training (gradient descent: repeatedly measuring error and nudging to reduce it), but inside the forward pass. In the infinite-depth limit, the learned operator is provably the statistically best predictor possible.

Zero assumption version

Transformers can learn inside the context window, but only for finite inputs

When you give a standard transformer a task (like a math problem) in its input window along with the answer, it can use those examples to predict the next answer correctly without updating any weights. This ability is called in-context learning. It works well for traditional problems with finite-dimensional inputs (lists of tokens).

But many real problems need to learn from entire functions—not just lists of numbers. For example, if you want to predict how heat spreads through a room (a differential equation, or PDE), you feed in the initial shape (a function) and want the model to predict the final shape. A naive approach treats the function as a finite list of sample points. This breaks down quickly: you lose information about the function's structure, and the model must memorize every detail of every example instead of learning the underlying pattern.

Continuum transformers were designed to handle these infinite-dimensional functions. They work well in practice. But no one had proven WHY they can learn new operators from in-context examples, or what guarantees the learned operator would be any good.

The problem in one sentence. Continuum transformers exhibit in-context learning for function inputs but lack theoretical proof that the learned operator is statistically optimal.

What the paper changes

The thing that changes

The paper changes how we understand the learned operator—the function inside a continuum transformer that it learns from context. Instead of treating it as a mysterious pattern the model discovered, this work shows it is literally the result of gradient descent iterations over a Hilbert space of functions (a mathematical space where you can measure distances between functions and compute averages).

the object it moves  =  the learned operator (in a Hilbert space)
The hidden quantity

The hidden quantity: the operator in Hilbert space

measured quantity  =  operator distance in Hilbert space

The paper measures how far the learned operator sits from the true operator that best explains the context examples. This distance is not physical—it is mathematical. The authors use a Hilbert space metric, which means they can compute distances between functions by treating them as points and measuring the straight-line distance. A Hilbert space is just a high-dimensional vector space where you can add functions together and measure their length (much like how you measure the length of a vector in ordinary 3D space).

The paper shows that each layer of the continuum transformer takes one gradient descent step in this space—reducing this distance. By the end of all layers, the learned operator is proven to be as close as possible to the true best operator, which is called the Bayes Optimal Predictor.

Why it works

Why it works: gradient descent in function space

The core idea is that a continuum transformer's layers are structured so that each one performs a gradient descent step on an operator in a Hilbert space. Here is the mechanical chain: the model receives context examples (pairs of input functions and output functions). It then repeatedly asks: what operator would best predict the outputs from the inputs? Gradient descent is the standard answer—start with a guess and nudge it in the direction that reduces error.

What is new here is that the transformer can do this nudging entirely inside its forward pass, without updating weights. Each layer applies transformations that correspond to one step of gradient descent in the operator space. The paper uses a specific proof technique—a generalized representer theorem—to show that this is exactly what is happening mathematically.

In the limit where the transformer has infinite layers, the learned operator provably reaches the Bayes Optimal Predictor: the single operator that has the lowest expected error on all possible unseen examples from the same distribution. This is the gold standard in statistics—you cannot do better than this, because it is the answer that comes from knowing the true underlying process and optimizing directly against it.

Math after the picture

The equation: one gradient descent step in operator space

First in words:

operator at layer k plus one equals operator at layer k minus learning rate times gradient of loss with respect to operator, where loss is how badly the current operator fits the context examples

Then the compact form:

O_{k+1} = O_k - alpha * grad_O L(O_k)

Every symbol:

O_kthe learned operator after layer k
alphalearning rate (how big each step is)
grad_O L(O_k)gradient of the fitting error with respect to the operator
L(O_k)loss (how badly O_k predicts the context outputs)
A tiny worked example
Suppose we have one context example: input function f produces output g. Our operator O tries to predict g from f.
We measure error as the squared distance from O(f) to g. Error starts at 2.5 (O(f) is way off).
Gradient tells us: nudge the operator in direction v by roughly 0.1 to reduce error. Learning rate alpha = 0.05.
New operator O_1 = O_0 - 0.05 * (direction v) = O_0 - 0.05 * v. Error drops to 2.3.
Next layer computes O_2 = O_1 - 0.05 * v. Error drops to 2.1. Repeat until convergence.

Each transformer layer carries out one of these steps, so a 12-layer transformer takes 12 gradient descent steps—moving the learned operator closer and closer to the best operator.

What can go wrong

What can go wrong

Depth matters. The theoretical guarantee requires infinite layers. A shallow continuum transformer (few layers) performs only a few gradient descent steps and may not reach the optimal operator. In practice, finite depth is an approximation.
Hilbert space assumption. The proof requires that the true operator lives in a reproducing kernel Hilbert space (RKHS)—a specific kind of function space. If the true operator does not have this structure, the theoretical guarantee breaks down.
Limited context size. Gradient descent converges better with more examples. If context is too small, the learned operator will be noisy and suboptimal, because there is not enough signal to reliably estimate the gradient.
Done right. When the true operator is in the RKHS, has enough context examples, and the transformer is deep enough, the learned operator provably converges to the Bayes optimal solution—the best possible prediction rule.
What a runnable demo should prove

What a runnable demo should prove

Build a simple PDE surrogate task: given a low-resolution initial state of heat diffusion, predict the final state. Collect context examples by solving the PDE at a few random starting configurations. Train a continuum transformer (with increasing numbers of layers) to perform in-context learning on these examples. Measure how well the learned operator predicts the output on held-out unseen input functions. Also measure the distance between the learned operator and the true optimal operator (if known analytically). The demo should show: (1) more layers lead to lower error (more gradient descent steps), (2) error asymptotes toward the theoretical optimum, (3) the learned operator generalizes well to new inputs, not just memorizing the context.

generalization error = mean absolute difference between predicted and true output on unseen test functions

The demo makes clear that in-context learning is not magic—it is verifiable gradient descent happening inside the model, and we can track it converging to the proven optimal operator.
