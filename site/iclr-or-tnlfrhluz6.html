Compose Your Policies: Better Robot Control by Mixing Pre-trained Models

Combine multiple pre-trained robot control models at test time to get better performance than either alone, without any new training.

Paper explainersAll themesRobotics & Control

Building a good robot control system normally requires collecting huge amounts of interaction data and months of training. This paper discovers that you can improve performance just by intelligently combining multiple pre-trained models at the moment of use, with no retraining. By mixing the internal predictions from different models in the right proportions, the paper shows the composed system can outperform every individual model.

Zero assumption version

Training Good Robot Models Is Expensive

A robot needs to learn to perform tasks like picking up objects or pushing things. Usually, this means collecting thousands or millions of real robot interactions (each one costs time and risksbreaking things), then training a model for weeks using all that data.

One naive approach: just pick the best single pre-trained model you can find and use it. The problem: that single model was trained on one type of data with one style of training. It will make certain kinds of mistakes consistently. If you have multiple models available (say, one trained on videos, one trained on real robots, one with a different network architecture), you would normally need to retrain everything from scratch to combine them, which is expensive.

The paper's move in one sentence. At the moment you use the model to control the robot, mix the predictions from multiple pre-trained models in the right proportions, and the combination is better than any single model alone, because each model's errors are partially different and averaging cancels some of those errors out.

What the paper changes

What Changes: The Prediction Scores

The method modifies one specific thing: the score each model computes when deciding which action to take. Instead of using one model's score alone, it replaces that score with a weighted mixture of scores from multiple models. This is the ONE change the paper makes.

the object it moves  =  prediction scores
The hidden quantity

The Hidden Quantity: Score Alignment

measured quantity  =  distance from true optimal score

The hidden quantity the paper measures is how far off each model's score is from the genuinely optimal action score. Each pre-trained model makes errors — it predicts scores that are not quite right. These errors come from the model being trained on incomplete data or with a particular bias.

The paper estimates this by comparing the composed score (the mixture) against the original individual scores using a mathematical proof. If you mix two imperfect scores correctly, the mixture can be closer to the true answer than either original score was alone.

Why it works

Why It Works: The Composition Principle

Here is the causal chain. A diffusion-based robot control model outputs a score for each possible action at each step. This score is meant to be high for good actions and low for bad ones. But because the model was trained on limited data, its scores are slightly wrong — sometimes favoring bad actions, sometimes penalizing good ones.

The mathematical trick: if you have two imperfect score estimates, and you combine them by taking half of one plus half of the other, the combined score sits between them. Here is the key: if both scores are on the same side of the true optimal score (for example, both too high), then averaging them pulls you closer to the truth, because the average is farther from both original biases. If they are on opposite sides, averaging cancels the errors because one overshoots up while the other overshoots down. Either way, the mixture is more accurate than a random guess. The paper proves that the best weighted mix can be strictly better than either individual score, not just in one step but across the entire action sequence, because using a more accurate score at each step means each successive action is aimed better, and these small improvements compound over the full trajectory.

This propagates: when you use this better combined score at each step of the robot's action trajectory, the small improvement at each step compounds, leading to a noticeably better final behavior. The robot picks up objects more reliably because the combined predictions filter out each model's systematic mistakes.

Math after the picture

The Composition Equation

First in words:

The combined score at step t equals the sum over all models i of weight w_i times that model's score s_i at step t, where all weights sum to one and are between zero and one.

Then the compact form:

s_comp(τ_t,t) = sum_i w_i * s_θ(τ_t,t,c_i), where sum_i w_i = 1, w_i in [0,1]

Every symbol:

s_compthe combined score for action τ at step t
s_θ(τ_t,t,c_i)the score from model i when conditioned on state/modality c_i
w_ihow much weight (trust) to assign to model i
τ_tthe action at step t in the trajectory
tthe timestep (from 1 to trajectory length)
c_ithe condition for model i (e.g., visual modality, architecture)
A tiny worked example
Say Model A scores the left-turn action as 0.8. Model B scores it as 0.6. Model C scores it as 0.9.
True optimal score (unknown) is probably around 0.75.
If you use only Model A: error = |0.8 - 0.75| = 0.05.
If you use only Model B: error = |0.6 - 0.75| = 0.15.
If you mix with w_A=0.4, w_B=0.4, w_C=0.2: combined = 0.4*0.8 + 0.4*0.6 + 0.2*0.9 = 0.32 + 0.24 + 0.18 = 0.74.
Combined error = |0.74 - 0.75| = 0.01. The mixture is closer than any single model.

This equation shows that mixing scores via convex combination can yield a better score than any single model, because each model's errors are partially uncorrelated and the weighted average pulls toward the truth, and this local improvement at each step accumulates across the full trajectory because a better score guides every future decision.

What can go wrong

What can go wrong

Weights chosen poorly. If you assign very high weight to a model that is actually bad on this task, the combined score is pulled toward the bad prediction. The method relies on picking reasonable weights at test time.
Models trained on fundamentally incompatible data. If one model was trained to push and another to grasp, mixing their predictions can create nonsensical actions. The models need to share enough common ground.
Action sequence mismatch. If one model predicts 3 actions per step and another predicts 5, directly mixing scores fails. The paper handles this by padding shorter sequences, but misalignment can hurt performance.
Done right. When models are diverse but trained on related tasks, and weights are tuned via test-time search, composition consistently beats any single model and adapts to new situations.
What a runnable demo should prove

What a runnable demo should prove

Build a demo that loads two pre-trained robot control models (e.g., one trained on simulation, one on real robot data). At inference time, without retraining, compose their predictions with equal weights (0.5 each) and test on a new robot task (e.g., pushing an object to a target). Measure success rate (did the task complete?) on both the single best model and the composition. The composition should win.

Improvement = success_rate(composed) - success_rate(best_single_model)

The demo makes it impossible to miss: the mixture of imperfect models outperforms the best single model without any new training or data, because each model has learned a partial view of the task and combining them captures both views.
