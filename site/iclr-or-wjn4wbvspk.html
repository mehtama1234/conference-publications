CAPSUL: A Comprehensive Human Protein Benchmark for Subcellular Localization

CAPSUL adds 3D protein shape data to location prediction, letting models learn from structure instead of just sequence.

Paper explainersAll themesDatasets & Benchmarks & Evaluation

Where in a cell does a protein end up? This matters for drug design and understanding what proteins do. Before this paper, the only benchmark had protein sequences but not their 3D shapes, even though shapes are central to how proteins work. CAPSUL fixes that by building a dataset of 20,000 human proteins with both their 3D structures and where they actually go in the cell.

Zero assumption version

The missing piece in protein prediction

Predicting where a protein goes in a cell matters for finding drug targets and understanding what a protein does. For decades, biologists did this by hand in the lab, which is slow and expensive.

When machine learning showed up, researchers built a shortcut: given just the sequence of amino acids (the genetic text), predict the location. One benchmark, DeepLoc, contains protein sequences and location labels but nothing else. The problem is that a protein's shape dictates how it behaves and where it ends up in the cell, yet DeepLoc never shows the model any shape information at all.

In one sentence. The dataset only has sequences, not the 3D protein shapes that determine where a protein actually goes.

The algorithm as a flow

What it actually does

Collect and clean

Grab 20,504 human protein structures from AlphaFold2 (a tool that predicts 3D shape from sequence).

Annotate location

Domain experts label each protein: does it go to the nucleus, mitochondria, Golgi, etc.? Twenty compartments total.

Encode structure three ways

For each protein, represent its shape as a graph (bonds), tokens (fingerprints), or raw coordinates.

Train and test models

Run both sequence-only and structure-aware models; measure which learn location better because structure lets the model see the real physical clues cells use.

Interpret with attention (focus weights)

When structure helps, look at which parts of the shape the model focused on because high attention means the model learned that part predicts location. Found alpha-helix regions drive Golgi targeting.

What the paper changes

What the paper changes

The paper adds 3D protein structure data to the benchmark, alongside the sequence and location label. Where the old dataset was just (sequence, location), the new one is (sequence, 3D structure in three forms, location).

the object it moves  =  3D structural information
The hidden quantity

The hidden quantity: Structure importance

measured quantity  =  How much each part of the shape matters for location

A protein is a 3D folded chain; each atom has a position in 3D space. When a model reads the shape via attention (a neural mechanism that learns to focus on important parts), it assigns a weight to each amino acid residue: high weight means this part determines the location prediction. The paper extracts these attention weights after training to see which structural patterns predict localization.

The paper measures this by training a graph model (like a network that treats the protein as a connected graph) with added Transformer layers (a module designed to focus on the most important pieces). It then reads off which residues got the highest attention scores, revealing the structural pattern the model discovered.

Why it works

Why structure helps locate proteins

A protein sequence is a 1D string, but the protein folds into a specific 3D shape. That shape determines what the protein bumps into, where it sticks, and how the cell recognizes it. The cell's machinery reads the shape to sort proteins to the right place.

Models trained on sequence alone must guess the shape from the text. Models trained on both sequence and structure see the real shape directly, so they learn faster and more accurately. Because the model can now see how atoms are arranged—which atoms are close, which parts stick out, which regions are tight or loose—it learns which structural features predict each location. The paper shows that when you add a Transformer layer to a graph encoder, the model learns to focus on the most decisive structural parts (like alpha-helix regions for Golgi), which matches what biologists already know and opens a path to discover new patterns.

Math after the picture

The loss function for focal and contrastive learning

First in words:

loss_total = focal_loss + lambda * contrastive_loss, where focal_loss weights hard-to-classify locations more heavily and contrastive_loss pulls together proteins that go to the same place

Then the compact form:

L = w_focal * L_focal(y, pred) + lambda * L_contrastive(pos_pairs, neg_pairs)

Every symbol:

w_focalweight from focal loss, higher for rare or hard locations
L_focal(y, pred)focal loss: penalizes wrong predictions more when the location is rare
lambdamixing weight, how much contrastive learning helps overall
L_contrastive(pos_pairs, neg_pairs)pulls proteins to same location closer together, pushes different locations apart
A tiny worked example
Suppose a protein should go to the nucleus (location A). The model says 'Golgi' (location B) with 60% confidence.
Focal loss spot-check: if the nucleus is common (w_focal = 1.0) and the model is wrong, penalty is 1.0 * large_value = large.
If the nucleus is rare (w_focal = 3.0), same wrong prediction gets 3.0 * large_value = 3x worse penalty.
Contrastive loss: pair this nucleus protein with 10 other nucleus proteins; push their number lists closer together. Penalty shrinks as they cluster.
Pair a nucleus protein with a Golgi protein; pull them apart. Penalty grows if they stay close.
Total: L = 3.0 * 0.8 + 0.2 * 0.15 = 2.4 + 0.03 = 2.43. Focal term dominates because the nucleus is rare.

Focal loss makes the model try harder on rare locations; contrastive loss naturally separates proteins by location in the number-list space, so the classifier gets cleaner clusters to work with.

What can go wrong

What can go wrong

AlphaFold2 structures can be wrong. The 3D shapes come from AlphaFold2, which predicts structure from sequence. If the prediction is poor, the model trains on wrong atomic positions. The paper does not validate all structures against real experiments.
Rare locations stay hard. Focal loss helps but does not fully fix the core problem because if only 5% of proteins go to the nucleus, the model gets 95 examples of other locations for every 5 nucleus examples—the sheer volume of wrong-place examples drowns out the signal. Contrastive loss helps by clustering, but focal weights alone cannot overcome this severe class imbalance because the problem is not penalty size but data volume.
Attention patterns may not be causal. When the model pays attention to alpha-helices, it might mean alpha-helices drive localization, or it might mean alpha-helices happen to be nearby and correlate with the real signal. The paper shows correlation, not proof of causation.
Done right. When structure is included, experts validate a sample of predictions. The paper does a case study on Golgi and confirms that the discovered alpha-helix pattern matches known biology.
