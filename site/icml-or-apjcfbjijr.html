Not All Answers Are Contextually Persuadable: Inference Dynamics in Large Language Models under Contextual Influence

Repeated assertions in a prompt do not keep adding force forever; the model's internal predictive state often settles into a stable regime that either does or does not cross the boundary needed to change the answer.

Paper explainersAll themesOther

Prompting often assumes that enough repeated context can push a language model toward a target answer. This paper studies that assumption at the level of inference dynamics, meaning how the model's internal predictive state evolves during answer generation under repeated contextual assertions. The main result is that repetition is not unbounded evidence accumulation. For a given query, the internal state tends to converge to a stable regime. If that stable regime remains on the original side of the decision boundary, repetition may never flip the answer no matter how many times the assertion is repeated. If the stable regime lies on the other side, a flip becomes unavoidable. The paper therefore characterizes contextual influence as a bounded dynamical process, not as linear accumulation.

Zero assumption version

Why output-level prompt analysis is incomplete

A common way to study prompting is to check whether the final answer changed after adding context. That hides an important question: how did the model move internally while reading repeated assertions? Two prompts can produce the same final answer even if one barely moved the model's predictive state and the other pushed it close to a change point.

The usual intuition is accumulation: repeat an assertion often enough and the model will eventually give in. The paper argues that this picture is wrong for many queries. The response process can settle into a stable pattern where additional copies of the same contextual statement produce almost no further movement. In that case the answer becomes resistant to repetition even though the prompt keeps getting longer.

The conceptual shift. Treat repeated context as a dynamical system with fixed-point behavior, because the key question is where the internal predictive state converges, not how many repeated statements were supplied.

What the paper changes

What the paper changes

The paper changes the unit of analysis for prompt influence. Instead of treating each extra assertion as one more piece of evidence, it studies the repeated update rule that drives the model's predictive state toward a stable regime.

The hidden quantity

The hidden quantity

measured quantity  =  the stable predictive regime for a query

The decisive hidden quantity is the limit point of the model's internal predictive state under repeated contextual assertion. A query is persuadable only if that limit point lies in the region where another answer becomes dominant. If the limit point stays in the original region, repeating the same cue more times cannot force a change because the state has already settled.

This reframes repetition. The important fact is not the count of repeated statements by itself. The important fact is the update map induced by the model and the query. Some maps have a stable point close to the original answer, and others have a stable point beyond the switch boundary. The observed answer behavior follows that structure.

Why it works

Why repetition does not act as unlimited evidence

A repeated assertion does affect the model, but it does so through the model's update rule at inference time. After each repetition, the model recomputes a new predictive state from the previous one and the next contextual token, meaning the basic text unit the model processes. If that update rule is contractive around a stable point, successive repetitions create smaller and smaller changes. The process saturates instead of growing without bound.

Answer change then becomes a boundary question. The model's current predictive state may favor answer A over answer B. Repetition moves the state toward its stable regime. If that regime remains in answer A's region, the answer is resistant: the system converges without crossing the decision boundary. If the regime lies in answer B's region, the boundary is crossed after enough repetitions and the answer eventually flips. This explains why some repetition-based prompts always work on certain queries and never work on others.

The contribution is therefore twofold. It provides a theoretical language for describing bounded contextual influence, and it gives a practical warning for prompt design: repeating a claim is useful only when the query-model pair admits a stable regime that supports the desired answer. Otherwise, longer prompts add cost without changing the limit behavior.

A simple repeated-update view

First in words:

Each repetition applies the same update map to the current predictive state, and repeated prompting changes the answer only if the limit of that sequence crosses the decision boundary.

Then the compact form:

state_next = F(state_current, repeated_context)

Every symbol:

state_currentthe model's current predictive state for the query
repeated_contextthe repeated assertion added to the prompt
Fthe update rule induced by the model during inference
state_nextthe predictive state after one more repetition
A tiny worked example
Suppose the current state favors answer A, and the switch to answer B occurs at threshold 0.50.
After one repetition the score moves from 0.20 to 0.35.
After two repetitions it moves to 0.43.
After three repetitions it moves to 0.47.
If the stable regime is 0.48, the answer never flips because the updates saturate before the threshold.
If a different query has stable regime 0.62, enough repetitions will eventually cross the threshold and force answer B.

The exact state is higher dimensional in the paper, but the threshold picture captures why a stable regime can block or force persuasion.

What can go wrong

What can go wrong

The theory can miss behavior outside the modeled regime. If prompt formatting changes the update rule itself instead of only repeating the same contextual signal, the observed dynamics may depart from the simple repeated-map analysis because the underlying process is no longer stationary.
A stable regime may be hard to estimate from outputs alone. Two queries can show the same short-run answer pattern while converging to different limits, so limited observation can misclassify a query as resistant or persuadable.
Real prompts combine several influence channels. Repetition often appears together with examples, instructions, and formatting cues, so the net effect can reflect more than the repeated assertion itself.
Done right. Use the framework on prompts where the repeated cue is isolated, estimate whether the answer trajectory is saturating, and stop adding repetitions once the observed changes shrink toward zero.
What a runnable demo should prove

What a runnable demo should prove

Choose a small set of question-answer pairs and a repeated assertion that pushes toward one target answer. Query a language model with 0, 1, 2, 4, 8, and 16 repetitions while recording both the final answer and a score for the target answer if the API exposes token-level probabilities, meaning the model's per-token predicted likelihoods.

The demo should surface two groups of queries: one where the target-answer score rises and then levels off below the switch threshold, and one where it rises past the threshold and the answer flips. That split is the observable signature of query-dependent stable regimes.

persuasion_gap = stable_target_score - answer_switch_threshold

A convincing demo should show positive persuasion_gap for inevitably persuadable queries and negative persuasion_gap for repetition-resistant ones.
