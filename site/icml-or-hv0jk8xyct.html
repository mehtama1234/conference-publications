Neuro-evolutionary Continual Reinforcement Learning

A robot learns new tasks one at a time by selectively activating neurons with masks, reusing proven neurons and freezing old ones to avoid forgetting.

Paper explainersAll themesRobotics & Control

Robots in the real world face a problem: they must learn one new task after another while keeping their old skills intact. A naive approach trains separately on each task, but that wastes what the robot already knows. A better approach tries to add new knowledge to the existing model, but after a few tasks the model starts breaking the old skills (called catastrophic forgetting). This paper presents Nevo-CRL, which keeps the same network size while learning many tasks by turning neurons on and off per task.

Zero assumption version

Why robots get stuck learning many tasks

A robot starts with no skills. Each time it encounters a new task (pick up a ball, push a button, grasp a tool), its neural network learns the right numbers to solve it. But after learning the third or fourth task, something breaks: when the robot tries the first task again, it has forgotten how to do it. The new task erased the old one.

A beginner might try storing a completely separate copy of the network for each task. That works perfectly but wastes memory and computation because most of what the robot learned in task one is useful for task two. A smarter beginner tries retraining the single network to hold all tasks at once, but the network is not big enough to hold the full recipe for ten different tasks. The network is full.

In one sentence. The method uses masks to turn different neurons on for different tasks, keeps important neurons frozen after each task, and recycles old neurons when possible.

The algorithm as a flow

What it actually does

Create a mask

For a new task, build a population of masks (which neurons turn on or off for this task).

Train the mask

Run the task with each mask active, collect rewards, and grade each mask by how well the robot performs.

Improve masks

Blend the best masks together (crossover) to create new ones, then test them again.

Freeze the winner

Pick the best-scoring mask, lock its activated neurons in place so they never change.

Reuse for the next task

When task two arrives, check which old neurons are similar in what they do, reuse them in the new mask, and leave the rest free to learn new patterns.

What the paper changes

What the paper changes

The paper changes which neurons fire for each task. Instead of retraining the entire network, it keeps the same neurons but switches different subsets on and off per task by using a mask (a list of which neurons are active).

the object it moves  =  masks that turn neurons on or off
The hidden quantity

Task similarity: how much do old neurons help the new task?

measured quantity  =  Task semantic similarity

After the robot masters task one, it stores the winning mask. When task two arrives, the key question is: can the same neurons help, or are they too specialized? The paper measures how similar two tasks are by checking if neurons that fired a lot in task one also fire a lot in task two. This is semantic similarity—the overlap in what each task needs from the neurons.

High similarity means reuse old neurons directly. Low similarity means the new task needs its own fresh neurons. The paper computes this overlap and uses it to decide whether to keep an old neuron active in the new mask or to freeze it and add a new one.

Plain reading. Similarity is just: if neurons 1 and 3 helped a lot in task one, do they also help a lot in task two? If yes, similar (because the same neurons matter for both), so reuse them. If no, different, so freeze the old ones and train new ones.
Paper reading. The paper infers semantic similarity between tasks by measuring which neurons fire (turn on) in response to similar situations across task pairs and uses it to guide which old neurons to reuse versus freeze.
Why it works

Why freezing neurons and reusing them stops forgetting

Catastrophic forgetting happens because training on task two wiggles all the network numbers, including the ones that task one relied on. Nevo-CRL solves this by locking the winning neurons in place after each task. Once a neuron is frozen, the training algorithm cannot touch it, so task-two training cannot erase task-one's recipe.

But just freezing everything would make the network useless for new tasks. Nevo-CRL solves this by keeping a pool of free (unfrozen) neurons. When task three arrives, the method checks which old neurons are similar (fire in response to similar situations), and it reuses those without changing them. For the parts of task three that are different, it uses the free neurons. Only the free neurons get trained on task three, so the frozen neurons from tasks one and two stay intact. After task three, the best free neurons get frozen, and the cycle repeats.

Math after the picture

The mask equation and how it protects old knowledge

First in words:

For each neuron i and each task t, a mask M_{i,t} is either 1 (neuron is active) or 0 (neuron is silent). The network output for task t is: the sum over all neurons of (if mask is 1, include this neuron, else ignore it). After task t finishes, the best mask M_{best,t} is saved and its active neurons are locked by setting them in a frozen set F_t. When task t+1 arrives, any neuron in F_t cannot be trained—its value stays fixed. The loss function for task t+1 only trains masks and free neurons.

Then the compact form:

output_t = sum_i M_{i,t} * neuron_i(x) [M_{i,t} in {0,1}] ; if i in F_t then neuron_i is read-only

Every symbol:

M_{i,t}Mask: is neuron i active in task t? (1=yes, 0=no)
neuron_i(x)The firing rate of neuron i given input x
F_tThe set of neurons frozen after task t
output_tThe robot's action for task t
A tiny worked example
Task 1: Train a mask M_1 = [1, 0, 1, 0, 1] and freeze neurons {1, 3, 5} in F_1.
Task 2: Neurons 1, 3, 5 are locked (read-only). The mask-learning algorithm only tunes neurons {2, 4} and creates mask M_2 = [1, 1, 1, 1, 0]. Neuron 1 stays the same value—no forgetting.
Task 3: Neurons 1, 3, 5 from task 1 and neurons 2, 4 from task 2 are now locked. Only neurons outside these sets can be trained, or new neurons allocated.

Locked neurons act as memory: once frozen, they cannot be rewritten by training on future tasks, so the robot keeps its old skills.

What can go wrong

What can go wrong

All free neurons are used up. After many tasks, the pool of free (unfrozen) neurons runs out. The method prunes low-activity connections to recycle neurons, but if tasks are very different, this prune-and-reuse may not free enough neurons.
Similarity metric picks the wrong neurons to reuse. If task three is deceptively similar to task one in raw neuron firing patterns but asks for a different strategy, reusing those neurons could lock in a wrong pattern for the new task.
Mask search gets stuck. The method evolves masks via crossover (blending the best masks), which can converge to a local best that misses a better mask, because the random blending process might explore only a small corner of all possible masks.
Done right. When tasks share structure, the method reuses neurons and learns fast. When tasks are different, frozen neurons stay safe and free neurons adapt. The network stays the same size throughout.
What a runnable demo should prove

What a runnable demo should prove

Build a small robotic simulator with five simple sequential tasks: grasp a ball, push a button, pull a lever, rotate a knob, and carry an object. Train Nevo-CRL on task one until it succeeds, then move to task two without retraining task one's neurons. Measure the success rate on all five tasks after each new task is learned. The demo must show that old-task performance does not drop when new tasks are learned.

Forgetting = performance_task_i_before_task_j - performance_task_i_after_task_j (should stay close to zero)

The unmissable outcome: task-one success rate stays above 85 percent even after tasks two through five are fully trained.
