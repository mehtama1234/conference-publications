TAMMs: Time-Aware Understanding for Satellite Change and Forecasting

Join two separate satellite tasks by teaching a language model to understand time itself, so its change knowledge guides image forecasting.

Paper explainersAll themesMultimodal

Satellite scientists face two separate problems: describing what changed in an image sequence, and predicting what will happen next. Until now, these tasks worked independently. TAMMs joins them by first teaching a frozen language model to understand long-term time patterns, then using that understanding to guide a diffusion model that generates future images. The clever bit: instead of retraining the language model from scratch, you add small adapters that explicitly tell it which time gaps matter.

Zero assumption version

Two unconnected satellite tasks

Satellite image sequences span years. Scientists need two things: first, a clear description of what changed between early and late images (did forests shrink? Did buildings appear?). Second, a prediction of the next image in the sequence.

The naive approach: train one model to describe changes, another to forecast. The problem: each model independently learns time patterns, throwing away half the information. A model that deeply understands historical change should make better forecasts — because if you know why things changed in the past, you predict the future more consistently.

The core idea. Teach a language model to understand satellite time patterns, then have it coach a image-generation model to produce forecasts that match the change story it just described.

The algorithm as a flow

What it actually does

Feed the language model images and time gaps.

The model sees satellite images paired with the time intervals between them.

Adapters encode time explicitly.

Small trainable modules convert raw numbers (2 years, 5 years) into lists of numbers the language model understands.

Language model describes changes.

It produces plain text: what changed and why, informed by time context.

Control injection fuses guidance.

The change description is split into structural (visual motion) and semantic (meaning) paths, both feeding the diffusion model.

Diffusion model generates forecast.

Step by step, it assembles a next image that matches both the visual trend and the semantic story.

What the paper changes

The single change

The paper modifies one thing: it adds small learnable adapters to a frozen language model. These adapters, called Temporal Adaptation Modules, inject explicit awareness of time intervals. They sit between the image features and the model's routing system (the part that decides which features matter most), so when the model processes satellite images, it simultaneously reads the time gap between them. That is the whole innovation on the language-model side: not retraining the model, just grafting in time-aware glue.

the object it moves  =  Temporal adapters
The hidden quantity

The hidden quantity: Temporal Consistency

measured quantity  =  Temporal Consistency Score

This is the heartbeat of the paper's contribution: a single number that measures whether a predicted satellite image stays true to the historical change pattern. Not whether it is perfectly realistic — whether it is consistent with what happened before. If forests in the satellite sequence grew 5% per year, a forecast predicting them shrinking violates temporal consistency.

The paper defines Temporal Consistency Score (TCS) as a metric (in the appendix) that compares a predicted image against the historical rate of change. The higher the TCS, the more the forecast respects the past. Neither baseline model (change description alone, nor forecasting alone) explicitly measures this. Only the joint framework can measure it, because only the language model's understanding of change can anchor the forecasting model to historical rates.

Why it works

Why it works: the causal chain

Here is the deep why. A language model does not automatically understand time. If you show it image A and image B, it can describe the difference, but it does not measure the time between them. So when forecasting, it might predict a change that took 5 years to happen, in just 2 years. Temporal Adaptation Modules solve this by converting raw time numbers (2 years, 5 years) into learned lists of numbers that sit in the routing system — the part of the model that decides which features matter most. Now when the model processes images, it sees the time gap. Its description of change becomes time-aware.

The second layer: this time-aware change description becomes a control signal for the diffusion model. Diffusion models generate images iteratively, adding noise then subtracting it. Without control, they wander. With semantic control (the change story from the language model), they have a North Star. The paper splits this control into structural (how pixels move) and semantic (what changes mean). The structural path learns the raw visual dynamics first (frozen), then the semantic path learns to translate the language model's narrative into pixel-level nudges. The result: a forecast that contradicts the change story less often, because the story was burned into the generation process.

Why does this beat specialists? A change-description model alone can describe the past accurately but miss the future. A forecasting model alone can generate plausible images but ignore historical consistency. Joint training with temporal control makes the two reinforce each other: accurate change descriptions improve forecast consistency (because a precise story constrains the diffusion model), and consistent forecasts improve the language model's understanding of long-range time (because it learns which change patterns are real enough to predict).

The composite loss

First in words:

Training loss is a weighted sum of text accuracy and temporal alignment. Text loss penalizes wrong change descriptions. Temporal loss penalizes forecasts that violate historical patterns.

Then the compact form:

L = lambda_text * L_text + lambda_temp * L_temp

Every symbol:

Loverall training loss
lambda_textweight controlling how much to care about accurate change descriptions
L_texterror in the language model's text output versus correct captions
lambda_tempweight controlling how much to care about temporal consistency
L_temperror in the diffusion model's forecast versus historical rate of change
A tiny worked example
Imagine a satellite sequence over 10 years. The forest area decreased by 2 percent per year, consistently.
Forecast A predicts 15 percent decrease in 3 years (matches the rate). Forecast B predicts 8 percent decrease in 3 years (too slow).
If lambda_text = 2.0 and text error is 0.5, then lambda_text * L_text = 2.0 * 0.5 = 1.0.
If lambda_temp = 3.0 and temporal error is 0.4 (Forecast B violates the pattern), then lambda_temp * L_temp = 3.0 * 0.4 = 1.2.
Total loss = 1.0 + 1.2 = 2.2. If we retrain with stronger temporal weighting (lambda_temp = 5.0), temporal loss becomes 5.0 * 0.3 = 1.5 (model learns faster), pushing Forecast B toward Forecast A.

The two losses pull in opposite directions; balancing them ensures the model learns both to explain change accurately and to forecast consistently.

What can go wrong

What can go wrong

Overfitting to training-set time patterns. If a particular satellite site had three years of drought followed by two years of flooding, the model may memorize that exact rhythm and fail on a new site with different patterns. The fix: train on multiple geographies with diverse climate histories.
Catastrophic forgetting during semantic refinement. When training the semantic path second (after structural learning), the model can accidentally unlearn the visual motion patterns it just learned. The paper prevents this by freezing the structural path weights during semantic training. If you skip that freeze, forecasts become incoherent.
Temporal weighting imbalance. If lambda_temp is too high, the model sacrifices forecast realism to chase consistency, producing bland generic images. If too low, it ignores history. The paper tunes this hyperparameter per dataset; there is no one-size-fits-all.
Well-tuned joint training. When structural and semantic paths are decoupled but coordinated, and temporal weighting is carefully balanced, the model learns to describe change accurately and forecast consistently without contradiction.
What a runnable demo should prove

What a runnable demo should prove

Build a satellite forecasting system on a small real dataset (e.g., a single site over 8 years). First, train a specialist change-description model on the first 6 years; train a specialist forecaster on the same 6 years. Then, train TAMMs jointly on the same data. Test all three on year 7 and 8. Measure three things: (1) accuracy of change descriptions, (2) realism of forecasted images, (3) temporal consistency — how often the forecast violates the historical rate of change.

Temporal Consistency Score = fraction of forecast pixels where change rate stays within one standard deviation of historical rate

TAMMs' forecasts should show dramatically fewer contradictions to the historical record than either specialist baseline. If they do, you have proved the core claim: joint training with temporal understanding improves consistency because the language model learns what changes matter over time, and passes that knowledge to the forecasting model.
