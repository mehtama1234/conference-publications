CLEAR: Calibrated Learning for Epistemic and Aleatoric Risk

A method to combine two sources of prediction error into more honest confidence intervals for regression.

Paper explainersAll themesOther

When a model makes a prediction, it is wrong in two ways: (1) real randomness in the world (like measurement noise), and (2) gaps in what the model has learned. Existing methods measure one or the other, but rarely both fairly. CLEAR balances them, producing narrower and more honest confidence intervals.

The two kinds of wrongness

A regression model predicts a number (like tomorrow's temperature). But it is never exactly right. The error comes from two sources: (1) the world is noisy — a thermometer jitters, measurements vary — this is called aleatoric uncertainty (from randomness in the data itself). (2) The model has never seen enough similar cases to be fully confident — this is called epistemic uncertainty (from the model's incomplete knowledge).

Existing methods measure aleatoric uncertainty (how much to expect the data to wiggle) or epistemic uncertainty (how much the model doubts itself), but rarely both at once in a fair way. A naive attempt: treat them as separate, measure each one, add them together. This breaks because the two sources interact — a noisy dataset teaches the model less, but a poorly-trained model also struggles more when the data is noisy. No single simple sum captures that.

The method in one sentence. CLEAR learns two separate scaling knobs (one for noise, one for model doubt) that combine aleatoric and epistemic uncertainty fairly to produce narrower, more honest confidence intervals.

What the paper changes

What the paper moves

The paper changes how two uncertainty estimates are combined. Instead of treating aleatoric (noise) and epistemic (model doubt) as independent and simply adding them, CLEAR learns separate calibration scales (tuning knobs) for each one.

the object it moves  =  calibration scaling knobs
The hidden quantity

The hidden quantity: interval coverage

measured quantity  =  conditional coverage

A prediction interval is a range the model gives as its best guess plus a buffer. For example, 'tomorrow's temperature is 72°F plus or minus 5 degrees' gives the interval [67, 77]. The interval 'covers' the truth if the real answer (say, 74°F) falls inside it. Coverage is the fraction of predictions whose intervals contain the truth. Good coverage means the model is honest about its uncertainty: if it says 95% confidence, roughly 95% of its intervals should cover the truth.

CLEAR measures this on held-out data (examples the model never saw during training) and tunes the two scaling knobs to keep coverage at the target level while making intervals as narrow as possible.

Why it works

Why it works: fair blending of two error sources

The core insight is that aleatoric and epistemic uncertainty do not scale the same way on all datasets. A dataset with high measurement noise (aleatoric) teaches the model less, so epistemic uncertainty rises too. A poorly-trained model doubts itself more even on clean data. These interact in ways a simple formula cannot capture.

CLEAR's move: learn ONE scaling factor (gamma_1) for the noise estimate and a DIFFERENT scaling factor (gamma_2) for the model-doubt estimate. These are tuned on held-out data to hit a target coverage level (e.g., 95% of intervals contain the truth) while shrinking the interval width as much as possible. This is fair because each source gets its own knob, and the knobs are calibrated to the specific dataset's structure, not assumed.

The result: narrower intervals that stay honest. Instead of playing it safe and inflating both uncertainty sources (wasting the model's knowledge), CLEAR learns how much safety margin is actually needed for this data and this model.

The blending formula

First in words:

interval_width = gamma_1 times noise_estimate plus gamma_2 times doubt_estimate

Then the compact form:

width = gamma_1 * aleatoric + gamma_2 * epistemic

Every symbol:

widththe half-width of the confidence interval (e.g., ±5 in 72±5)
gamma_1the scaling knob for measurement noise, learned from data
gamma_2the scaling knob for model doubt, learned from data
aleatoricthe estimated noise in the data (from quantile regression)
epistemicthe estimated model doubt (from ensemble disagreement)
A tiny worked example
Dataset 1: aleatoric=2.0, epistemic=1.5, gamma_1=0.8, gamma_2=1.2 -> width = 0.8*2.0 + 1.2*1.5 = 1.6 + 1.8 = 3.4
Dataset 2 (noisier): aleatoric=4.0, epistemic=2.0, gamma_1=0.9, gamma_2=0.9 -> width = 0.9*4.0 + 0.9*2.0 = 3.6 + 1.8 = 5.4
Same formula, but gamma_1 and gamma_2 are tuned for each dataset to keep coverage honest. In Dataset 1, the noise (aleatoric=2.0) dominates, so gamma_1 is smaller. In Dataset 2, both sources are large, and they scale differently.

The two gammas capture how much each uncertainty source matters on this specific dataset and how much the model's training inflated or deflated confidence.

What can go wrong

What can go wrong

Not enough held-out data. The method learns gamma_1 and gamma_2 by tuning on a validation set. If that set is too small, the learned scales will overfit and fail on truly new data.
Aleatoric and epistemic estimators conflict. If the quantile regression estimate of noise is wrong (e.g., constant noise assumed but the data varies), or the ensemble disagreement estimate is biased (e.g., ensemble members are too similar), the scales cannot fix it. Bad inputs stay bad.
New data with different noise structure. If a new dataset has much higher measurement noise or a different model is used (different ensemble), the learned gammas from old data do not transfer. The method must recalibrate.
Done right. With sufficient validation data and reasonable uncertainty estimators, CLEAR produces intervals that are narrower and more honest than treating uncertainty sources separately.
What a runnable demo should prove

What a runnable demo should prove

Build a regression task (e.g., predict house prices from features, or predict a function value from noisy samples). Train a model (or an ensemble of models). Compute aleatoric uncertainty using quantile regression (by predicting multiple quantiles: 10th, 50th, 90th percentile, and the width is 90th minus 10th). Compute epistemic uncertainty from ensemble disagreement (how much the predictions spread across models). Then: (1) Combine them naively (add the two widths). (2) Apply CLEAR (learn gamma_1 and gamma_2 on a validation set to maximize coverage while shrinking width). Measure both methods on a test set.

interval_coverage = (number of test examples where truth falls in predicted interval) / (total test examples); interval_width = average of (upper_bound - lower_bound)

The key proof: CLEAR's intervals are narrower than the naive sum while covering the truth at the same or higher rate. The narrowing comes from learning that on this dataset, one source of uncertainty is less important, so we scale it down without losing honesty.
