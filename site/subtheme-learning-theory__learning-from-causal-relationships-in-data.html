Learning from causal relationships in data

Papers using causal reasoning to identify true cause-and-effect relationships in data, avoiding spurious correlations and enabling more reliable decision-making.

All themesField mapMathematicsAll explainers
What this is

A medical study finds that people who take vitamin supplements have lower heart disease rates. Does this mean supplements prevent disease? Or do health-conscious people take supplements and exercise more? The correlation between supplements and low disease exists, but the causation is unclear. Standard machine learning models learn correlations — they extract patterns that hold in the data. But correlation is not causation, and when you act on a false correlation, you waste resources or harm people. This subtheme tackles learning the true causal structure of data: what actually causes what.

The difficulty is that observations alone cannot determine causation. You can collect petabytes of data showing that rain tends to occur when the barometer drops, but the barometer drop does not cause rain — falling atmospheric pressure causes both. Without intervention, you cannot tell. Real causal reasoning requires understanding the underlying mechanisms. Additionally, causal relationships are often hidden or complex. Many variables influence each other: education affects income, but education quality depends on family wealth, and family wealth also affects income independently. Untangling these chains of causation is hard because you cannot run experiments on every human's life.

Researchers use causal graphical models — diagrams showing which variables directly influence which others — to reason about causation. They develop techniques to estimate causal effects from observational data by adjusting for confounding factors (variables that influence both cause and effect). They study when and how causal models can be inferred from data and assumptions. Some work uses structural assumptions about how variables relate (e.g., if A causes B and B causes C, then A indirectly influences C) to narrow down plausible causal structures. The field also applies these ideas to machine learning: training on causal relationships rather than spurious correlations leads to models that generalize better when the world changes, because the true causes remain stable even if surface patterns shift.

How the work breaks down

Work on learning from causal relationships splits into five main directions. First, researchers ask: how can we discover the causal structure of a system from data alone? Second, they ask: given we know or assume a causal structure, how do we estimate what happens when we change one variable? Third, how do we handle hidden confounders (unmeasured factors that influence multiple variables at once)? Fourth, how do we decide what experiments or interventions to perform to learn efficiently? Fifth, how do these methods extend to systems that change over time?

Discovering causal graphs from data

The central challenge in causal discovery is that the same data patterns can arise from different underlying causal structures. For example, if A and B are correlated, we cannot tell from correlation alone whether A causes B, B causes A, or some hidden third variable C causes both. Standard machine learning ignores this problem because it only cares about prediction. But when you want to understand or intervene in a system, you must know which relationships are truly causal.

Causal Discovery in the Wild tackles this by building an ensemble of discovery algorithms and using voting theory to combine their answers wisely—the insight is that different algorithms make different assumptions and catch different mistakes, so the right mix of algorithms (varied in competence and trained on diverse data subsets) outperforms any single method. Causal Equivalence in Linear Non-Gaussian Latent-Variable Cyclic Models takes a different approach: it proves the first theoretical guarantees about which causal structures remain indistinguishable even with hidden variables and cycles (feedback loops), and uses this to build a discovery algorithm that requires no hand-tuned structural assumptions. Frequency-Domain Better than Time-Domain shows that for network systems where variables feed into each other over time, measuring correlations in the frequency domain (via Fourier transform) reveals the true causal structure more reliably than the obvious time-domain approach, because different time lags and dependencies become visible in different frequency bands.

Query-Specific Causal Graph Pruning observes that in large graphs, many edges are irrelevant to the question you want to answer—it shows how to use partial knowledge (tiered assumptions about which nodes definitely cannot influence each other) to skip learning edges you do not need, achieving exponential speedup. Theoretical Guarantees for Causal Discovery on Large Random Graphs proves that on random graphs (common in real networks like social graphs), false-discovery rates vanish reliably, and heterogeneous networks (where nodes have very different numbers of connections) naturally constrain the problem and make it easier. A Recursive Decomposition Framework speeds up all discovery algorithms by decomposing the problem: infer which groups of variables can be solved independently, then combine results—maintaining soundness and completeness. Causal discovery for time series with endogenous context variables adds a soundness guarantee for sequential data where the system's own previous outputs feed back as inputs to later steps. Coarse-to-Fine Learning of Dynamic Causal Structures extends to systems where the causal graph itself changes over time, by learning at multiple temporal scales. On the identifiability of causal graphs with multiple environments shows that if you observe the same system across multiple conditions (e.g., different countries or time periods), you can recover the full causal graph with only two or three environments and nonlinear relationships, where a single environment could not distinguish the structure.

Estimating what changes when we intervene

Once you know (or assume) a causal structure, the next practical question is: what is the causal effect of intervening on one variable? If a doctor prescribes medication to a patient, how much does that medication (and not other factors) improve their health? This is different from correlation: among people who choose to take medication, health might be better, but that could mean healthy people choose medicine because they are more health-conscious (selection bias), or that the medicine works, or both. Causal effect estimation aims to isolate the true effect of the intervention itself by filtering out these confounding explanations.

Efficient and Sharp Off-Policy Learning under Unobserved Confounding addresses a hard case: you have only observational data (no experiments), and there may be hidden confounders you cannot measure. The method uses bounds on how much confounding can exist to still identify the true effect (so if confounding exceeds the bound, you know your answer is unreliable), and provides policy selection that is guaranteed optimal given those bounds—it outperforms naive plug-in methods on healthcare and policy decisions because it works within known constraints rather than pretending confounders don't exist. Overlap-weighted orthogonal meta-learner for treatment effect estimation over time uses orthogonal statistical learning to estimate heterogeneous effects (how the effect varies across patients) even when the overlap—the range of covariate values in treated and untreated groups—is poor, making standard methods fail. A Relative Error-Based Evaluation Framework of Heterogeneous Treatment Effect Estimators solves a measurement problem: how do you fairly compare different effect estimators when they make different trade-offs? It proposes a metric that combines both existing estimators and newly learned intermediate variables to achieve good performance.

Estimating Continuous Treatment Effects with Two-Stage Kernel Ridge Regression handles treatments that are not binary (all-or-nothing) but continuous (dose-dependent): it achieves optimal learning rates without needing to estimate the conditional treatment density—a hard intermediate step. Optimization-Based Causal Tree Ensembles builds heterogeneous effect estimators using boosting (iteratively improving weak learners) over trees, substantially outperforming neural networks and earlier tree methods by giving each leaf of the tree ensemble its own update step. Overlap-Adaptive Regularization for Conditional Average Treatment Effect Estimation improves CATE (conditional average treatment effect) estimation in low-overlap regimes by adjusting how much smoothing to apply based on local overlap—regions with few treated and untreated subjects need more smoothing. Rank-Learner: Orthogonal Ranking of Treatment Effects solves the problem of ranking units by how much they benefit from treatment while remaining accurate even if you make mistakes in estimating intermediate variables. Topological Causal Effects extends causal effect inference to complex outcome spaces (not just numbers) using an estimator that combines two independent approaches so failures in one are caught by the other, valid across diverse topologies, with formal hypothesis tests.

Learning mechanisms and dynamic causal systems

Many real systems are dynamic: the world state at time t depends on the state at time t-1, and the causal relationships can shift over time. Chemical reactors, climate systems, and neural circuits all exhibit this temporal causality. Standard causal discovery methods assume the system is static or unchanging, which fails on these systems.

Learning Dynamic Causal Graphs Under Parametric Uncertainty via Polynomial Chaos Expansions tackles chemical reactor data where thousands of variables interact and the causal structure itself evolves. The method achieves 90.9% F1-score (nearly double baselines) by using polynomial chaos—a way of handling uncertainty in parameters—to represent how causes and effects change. Power-Boosted Granger-Causal Discovery for Large Heterogeneous Panel Data extends Granger causality (a time-series technique where A causally influences B if past values of A help predict B better than past values of B alone) to large datasets where different groups behave differently, providing theoretical guarantees on type-1 error and power. Influence without Confounding: Causal Discovery from Temporal Data with Long-term Carry-over Effects extends the static case by accounting for effects that linger: a variable at time t-1 might influence outcomes much later, not just at t. Causal discovery for time series with endogenous context variables adds soundness to time-series discovery when the system's own outputs feed back as inputs—a common pattern in feedback control.

Handling hidden confounders and unobserved variables

A fundamental problem in causal inference is confounding: unmeasured variables that influence both the cause and the effect. In the vitamin supplement example from the explain section, health consciousness (unmeasured) influences both supplement use and disease. Most datasets are incomplete—you cannot measure everything. Methods must either avoid the problem or quantify how badly unmeasured confounding could affect conclusions.

Causal Equivalence in Linear Non-Gaussian Latent-Variable Cyclic Models proves that even with hidden variables, you can identify unique causal structures if the noise is non-Gaussian (not normal-like). This removes the need for hand-tuned structural assumptions. Learning Exposure Mapping Functions for Inferring Heterogeneous Peer Effects handles the case where your treatment effect depends on your neighbors (in social networks or geography), and unknown peer effects could confound. It learns a reliable map from local context to heterogeneous effects, outperforming naive graph neural networks. Addressing Instrument-Outcome Confounding in Mendelian Randomization through Representation Learning solves a genomics problem: genetic variants (instruments) are supposed to influence health only through a specific pathway, but sometimes they have side effects. The method learns representations that filter out invalid pathways, validated on biobank data.

Causal Effect Identifiability in the Presence of Latent Confounders Without Auxiliary Variables establishes when causal effects are recoverable without measuring confounders, by distinguishing between censoring patterns and defining the solution space for unidentifiable cases. Conditional Independent Component Analysis For Estimating Causal Structure with Latent Variables proves identifiability for linear non-Gaussian models with hidden variables and provides algorithms grounded in theory. Stochastic Neural Networks for Causal Inference with Missing Confounders (CI-StoNet) learns leading-edge causal effect estimates by using stochastic neural networks to handle missing confounders adaptively, working on benchmarks and proxy variable scenarios. Comprehensive Understanding of Selection Bias for Causal Effect Identification unifies several frameworks for handling selection bias and confounding, using strictly weaker conditions than earlier approaches. When Shift Happens - Confounding Is to Blame proves that when models fail after the data changes, adding informative non-causal covariates can mitigate the problem even in the presence of hidden confounding shifts.

Choosing what to measure: active and adaptive learning

In the real world, you cannot measure everything, and experiments are expensive. If you must estimate a causal effect or discover a causal graph, you should choose your measurements or interventions wisely to minimize cost or uncertainty. This is the active learning problem: given a budget, what should you measure next?

ActiveCQ: Active Estimation of Causal Quantities uses information gain and variance reduction to decide which experiments to run in order to estimate a specific causal quantity most efficiently. It substantially outperforms baselines by choosing measurements that reduce what you don't know most. Journey to the Centre of Cluster: Selecting Interior Nodes for A/B Testing under Network Interference tackles the practical problem of online A/B testing in platforms with network effects (users influence each other). Selecting interior nodes in social networks reduces variance because these nodes have many neighbors to compare against, giving you more signal about treatment effects, and semi-supervised learning helps manage bias from underrepresented groups by inferring their outcomes from the represented neighbors.

A Minimax Approach for Optimal Intervention Policy Learning with Two-Stage Outcomes handles interventions where the effect has two stages (e.g., a treatment's short-term benefit versus its long-term side effects), which matters because a naive approach that only looks at immediate outcomes will make wrong decisions. It provides theoretical guarantees that its allocation strategy is optimal given both stages. Budgeted Active Experimentation for Treatment Effect Estimation from Observational and Randomized Data mixes observational data (cheap, potentially biased) with experiments (expensive, unbiased) under a fixed budget, achieving near-optimal sample efficiency with finite-sample deviation bounds and asymptotic normality. Many Experiments, Few Repetitions, Unpaired Data, and Sparse Effects proves that you can still learn causal effects when you run many different experiments but on few subjects each (unpaired), and when true effects are sparse (most variables have no effect). Regret-Based Federated Causal Discovery with Unknown Interventions (I-PERI) discovers causal structure while keeping data private across multiple parties, with theoretical convergence and privacy guarantees.
