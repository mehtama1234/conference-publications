Discovering Symmetries from Agent Interaction

An agent can automatically discover what types of moves exist in its world by watching how those moves change what it sees, then use that discovery to build separate mental buckets for each type of change.

Paper explainersAll themesRepresentation & Self-Supervised Learning

When you learn about a new place, you naturally notice patterns: pushing left undoes pushing right; spinning clockwise is the opposite of spinning counterclockwise. This paper shows how a machine learning model can discover these movement patterns on its own, without being told what they are. Instead of asking a human to define the symmetries (a rotating group, a shifting group, etc.), an embodied agent figures them out by trying actions and watching the results. The paper also proves this discovery is actually possible and builds a clean representation where each type of movement gets its own mental slot.

Zero assumption version

The robot has no instruction manual

When a robot is placed in a new world, it needs to understand what moves are possible. A simple approach: do random actions and watch what changes. But this is slow and disorganized. A human could tell the robot which types of moves exist — rotations, translations, scaling — and group actions by type. The robot would then know which actions are similar.

The catch: humans do not always know the structure of the world. In an alien environment, what if actions form a different group structure than we expected? A naive embodied agent has no internal blueprint for symmetries. It discovers them or it struggles.

In one sentence. An agent learns to group its actions into types by watching how each action changes what it sees, without being told the types in advance.

The algorithm as a flow

What it actually does

Step 1: Learn entangled response

Train a compressor (encoder) to convert what the agent sees into a list of numbers, and also track how actions change that list, without separating action types yet.

Step 2: Cluster actions by effect

Look at pairs of actions. If both pairs produce nearly the same change in the representation, put them in the same group. Grow groups until all actions are sorted.

Step 3: Separate the slots

Rebuild the representation so each group has its own dedicated mental slot (dimension), with one number per slot per action.

Step 4: Enforce clean axes

Gently push each dimension to specialize: encode one type of action and ignore the rest.

Step 5: Verify with prediction

Test: given an observation and a sequence of actions, can the agent predict the outcome? Long sequences expose if disentanglement truly works.

What the paper changes

What the method changes

The paper moves from a tangled representation (where all information about all actions is squashed together) to a disentangled one (where each action type gets its own mental dimension). This separation is discovered automatically from interaction, not imposed by hand.

The hidden quantity

The group decomposition

measured quantity  =  which actions belong together

Every embodied agent lives in a world where actions have structure. Some actions are inverses (push left, then push right returns you). Some actions commute (spin twice clockwise is the same as spin twice clockwise at any time). This structure forms a group (in the mathematical sense: a set with a rule for combining elements). The paper's core hidden quantity is: what is the true group decomposition — how does the symmetry group G break into independent subgroups G1, G2, ..., Gk?

The paper estimates this by clustering actions: if action g1 and action g2 produce nearly identical changes to the agent's view, they belong to the same subgroup. The algorithm does not need to be told how many subgroups exist or what they represent. It discovers the boundaries by measuring action similarity.

Why it works

Why discovering structure works

The mechanism is built on a single principle: actions that belong to the same symmetry subgroup produce the same change to the world. If you push left and your friend pushes left, both results are identical displacements. If you rotate 90 degrees and I rotate 90 degrees, we both see the same 90-degree rotation.

The agent exploits this: it learns a representation (a mental model) where applying action g1 and applying action g2 produce the same list-of-numbers change if g1 and g2 are in the same subgroup. By measuring these changes directly, the agent can cluster actions. Once actions are grouped, the agent builds a new representation where each group gets a dedicated mental slot, so predictions and generalization become accurate.

Why does this fix the original problem? A robot that lumps all actions together will confuse rotation with translation: its mental model will be tangled, and predicting long action sequences will fail (errors compound). A robot that knows which actions are which can keep track of each dimension separately: rotate this way, translate that way, and the model stays accurate even for long chains of actions.

Math after the picture

The equation for action clustering

First in words:

Distance between action g and action g-prime is the difference between how they transform the representation, averaged over all examples

Then the compact form:

d_G(g, g') = sum_x ||rho(g) * mu(x) - mu(T_g(x)) - (rho(g') * mu(x) - mu(T_g'(x)))||^2

Every symbol:

d_G(g, g')distance between actions g and g-prime (small = same type)
rho(g)how action g transforms the representation (learned matrix)
mu(x)the representation of observation x (output of encoder)
T_g(x)the observation after applying action g
||...||^2sum of squared differences (measures total mismatch)
Tiny worked example: comparing two push actions
Observation 1: scene is disk at position (0, 0). Encoder outputs [3.0, 5.0].
Action push-left: disk moves to (-1, 0). Encoder outputs [2.0, 5.0]. Difference: [-1.0, 0.0].
Action push-left-copy (identical push): same difference [-1.0, 0.0].
Distance between push-left and push-left-copy: |(-1.0 - (-1.0))|^2 + |(0.0 - 0.0)|^2 = 0.0.
Now try push-right: disk moves to (1, 0). Encoder outputs [4.0, 5.0]. Difference: [1.0, 0.0].
Distance between push-left and push-right: |((-1.0) - 1.0)|^2 + |(0.0 - 0.0)|^2 = 4.0.
Clustering rule: if distance < threshold (e.g., 0.5), put actions in same group. push-left and push-left-copy stay together. push-left and push-right separate.

The distance measures whether two actions produce the same effect on the world view. Small distance means same subgroup type.

What can go wrong

What can go wrong

Incomplete action coverage. If the training data never includes a certain action (e.g., jumping), the algorithm cannot cluster it. The method assumes all actions appear in the dataset.
Hidden state collapse. During training, the disentanglement loss can prematurely force some dimensions to zero, erasing useful information. The paper solves this with a gradually-softened target (not starting at zero but easing toward it), but tuning is needed.
Non-factorizable groups. If the true symmetry group cannot be broken into independent subgroups (a product structure), the method will struggle. The paper assumes independent subgroups that work together.
Done right. Collect diverse interaction data, include all action types, gradually ease from high to low specialization during training, and verify predictions on held-out action sequences.
What a runnable demo should prove

What a runnable demo should prove

Build a simple simulation: a disk on a 2D grid that responds to push-left, push-right, push-up, push-down actions (two independent translation groups). Train the algorithm on random action sequences. Extract the learned group decomposition. Then test: (1) can the model predict where the disk will be after a long sequence of actions? (2) are the learned dimensions cleanly separated (one dimension for left-right, one for up-down)?

accuracy = (number of correctly predicted final positions) / (total sequences tested)

The demo must show that the unsupervised algorithm discovers the two-group structure and makes accurate predictions on long action sequences it has never seen before, without being told anything about groups.
