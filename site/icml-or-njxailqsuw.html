BrainJanus: A Unified Model for Understanding and Generation across Brain, Vision, and Language

Map neural recordings, images, and text into one token space so a single next-step sequence model can both predict brain activity from stimuli and generate images or text from brain signals.

Paper explainersAll themesMultimodal

Brain modeling usually splits into two separate tasks. Encoding predicts neural activity from external stimuli such as images or text. Decoding goes in the opposite direction, reconstructing stimuli or semantic content from neural activity. Treating those directions separately leaves a large amount of shared structure unused, because the same correspondence between brain signals and sensory or linguistic content is being learned twice under different sets of model weights. BrainJanus merges those directions into one model. It first converts continuous neural dynamics into discrete tokens, meaning code units produced by a tokenizer, using a unified brain tokenizer aligned with visual and language tokens in a shared representation space. It then trains one next-step sequence model, meaning a model that predicts the next token from earlier tokens, over all modalities, allowing any-to-any generation such as image-to-brain, text-to-brain, brain-to-image, and brain-to-text. The result matters because it treats brain activity as part of a common predictive sequence model rather than as a special isolated regression target.

Zero assumption version

Why separate brain encoding and decoding is limiting

Neural recordings are continuous, high-dimensional, and noisy. Images and text are discrete or can be tokenized into discrete units. Most existing systems connect these worlds with specialized pipelines: one model maps images to brain responses, another model maps brain responses back to images or captions. Those pipelines are optimized for their own direction and often rely heavily on external reusable knowledge from vision or language models.

This separation wastes shared information. If the system learns that a certain pattern of neural activity corresponds to a visual object or linguistic concept, that correspondence should help in both directions. A unified model can exploit this by learning one set of cross-modal associations that supports prediction and generation jointly.

The technical obstacle is representation mismatch. Brain signals are continuous time-varying measurements, while modern multimodal generative systems operate naturally on token sequences. A unified system therefore needs a way to convert brain activity into tokens that preserve useful neural structure and can interact with vision and language tokens in one model.

The main change. Convert brain dynamics into a shared discrete space and train one next-step sequence model over brain, image, and text tokens so the same model handles both encoding and decoding.

The algorithm as a flow

What it actually does

Convert neural activity into code units.

Use a unified brain tokenizer to convert continuous neural recordings into discrete tokens, meaning code units, that preserve important temporal and biological structure.

Align token spaces.

Map brain, image, and language tokens into one shared multimodal representation space.

Build mixed-modality sequences.

Arrange tokens from different modalities into training sequences so the model sees matched examples across directions, such as image followed by brain activity or brain activity followed by text, because those pairings tell the model which token patterns should predict each other.

Train one next-step sequence model.

Optimize next-token prediction over those sequences so the model learns conditional generation for any source-target modality pair, because the next token must be predicted from context that can come from a different modality.

Run any-to-any generation.

At test time, provide tokens from one modality and ask the model to continue the sequence in another modality.

The hidden quantity

The hidden quantity

measured quantity  =  shared cross-modal structure underlying neural activity

The central hidden quantity is the common semantic and perceptual structure that appears in brain recordings, images, and text in different forms. A neural activity trace does not directly state "face," "dog," or "red object," but it may contain a reproducible pattern associated with those concepts or perceptual features. The model needs to infer that hidden correspondence from paired data.

BrainJanus exposes that structure by forcing neural activity into discrete tokens that can participate in the same predictive process as image and language tokens. If the tokenizer preserves useful neural variation, then next-step sequence training can use co-occurrence and context to discover which brain token patterns correspond to which visual or linguistic tokens. That shared structure then supports both encoding and decoding without training separate systems.

Why it works

Why tokenization plus next-step sequence modeling works

The tokenizer is the first essential piece because next-step sequence models need discrete units or at least a discrete interface. Continuous brain recordings are too unconstrained to plug directly into the same machinery used for language or image tokens. By converting neural dynamics into recurring token patterns, the model creates a manageable vocabulary of neural states. This vocabulary must be expressive enough to preserve semantics and structure, but compact enough to support sequence modeling.

The shared token space is the second essential piece. Once brain tokens occupy a common representational space with image and text tokens, the model can learn cross-modal conditionals by standard next-token prediction. A sequence may start with image tokens and continue with brain tokens, or start with brain tokens and continue with text tokens. Because the training objective is the same in every case, knowledge transfers across directions instead of being trapped in one specialized encoder-decoder pair.

The autoregressive formulation, meaning prediction of the next token from earlier tokens, matters because it turns cross-modal correspondence into conditional generation. Rather than learning separate losses for every pair of directions, the model learns one sequential rule: predict the next token given the previous context. If the training data covers multiple modality orderings, that single rule becomes a general any-to-any mechanism. The reported zero-shot behavior follows from that shared training setup rather than from manually engineering each transfer path.

The core training rule

First in words:

Train one model to maximize the probability of the next token given all previous tokens in a sequence that may contain brain, image, and language tokens.

Then the compact form:

maximize sum_t log p(x_t | x_<t)

Every symbol:

x_tthe token at position t, which may come from brain, image, or language streams
x_<tall earlier tokens in the sequence
log p(x_t | x_<t)the log-probability assigned to the correct next token
sum_tsum over positions in the training sequence
A tiny worked example
Suppose a training sequence starts with image tokens for a face and continues with the brain tokens recorded while a subject viewed that face.
The model learns to predict the next brain token from the earlier image tokens and previous brain tokens.
In another sequence, the input starts with brain tokens and the target continuation is a text caption such as 'person viewing a face.'
Because both sequences use the same next-token objective, the model learns one shared set of cross-modal dependencies rather than separate task-specific mappings.

The paper's main contribution is the shared tokenization and training setup that make this standard next-token objective applicable to brain data.

What can go wrong

What can go wrong

Neural tokenization can discard important detail. If the tokenizer is too coarse, subtle but useful neural variations may collapse into the same token and become unrecoverable.
Alignment may lean too heavily on external reusable knowledge. If the shared space is dominated by vision or language structure, brain tokens may be forced into a representation that hides brain-specific information.
Data scarcity remains a serious constraint. Paired brain-stimulus datasets are small relative to internet-scale image or text corpora, so the model may still struggle to learn rare concepts reliably because it sees too few examples of them.
Done right. The method is strongest when the tokenizer preserves biologically useful structure and the training data covers enough paired situations for the shared next-step model to learn stable correspondences.
What a runnable demo should prove

What a runnable demo should prove

Create a small paired dataset with images, short text descriptions, and synchronized neural recordings. Train one baseline with separate image-to-brain and brain-to-text modules, and train one unified token-based next-step model. Test four directions: image-to-brain, text-to-brain, brain-to-image retrieval, and brain-to-text generation.

The demo should show that the unified model improves at least one direction without sacrificing the others, and that it can perform a transfer direction that was not given a dedicated task-specific architecture, because the same token space and next-step rule are reused across tasks. It should also visualize whether neural tokens preserve interpretable structure such as stable spatial or temporal organization.
