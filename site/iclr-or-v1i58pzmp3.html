Optimal transport unlocks end-to-end learning for single-molecule localization

Replace non-differentiable NMS with optimal transport to train microscopy models end-to-end on overlapping fluorophores.

Paper explainersAll themesAI for Science

Single-molecule microscopy reconstructs tiny cell structures by pinpointing individual tagged molecules. Current methods require molecules to emit one at a time (non-overlapping), which takes hours and freezes live cells. Deep learning can handle denser signals, but relies on NMS, a brute-force culling step that throws away real detections and cannot learn, because NMS is a hard keep-or-discard decision. This paper replaces NMS with a smooth, learnable optimal-transport loss that matches predicted dots to ground-truth dots, enabling faster imaging of living cells because smooth costs let every prediction contribute a learning signal during training.

Zero assumption version

The bottleneck: non-overlapping fluorophores lock out live-cell imaging

Fluorescence microscopy lights up molecules inside cells to see structures too small to photograph directly. But the cheaper the equipment, the worse it scrambles overlapping light signals. Current gold-standard methods (single-molecule localization microscopy, or SMLM) solve this by ensuring only one molecule emits at a time — imaging the same specimen hundreds of times, pausing between frames to let the signal clear. For living cells, this approach is fatal: it takes hours, and cells move and die.

A beginner might try: train a neural network to predict where molecules are, then run non-maximum suppression (NMS) — a post-processing filter that deletes nearby predictions, keeping only the strongest. But NMS is a hard, discrete operation: it either keeps or deletes, with no in-between. Networks cannot learn through it because the output does not change smoothly when predictions move by tiny amounts (gradients cannot flow backward), so the model is trained on a fake task (predicting high scores to win the competition) that differs from what users actually need (accurate positions even if multiple predictions are close).

In one sentence. The paper replaces the hard, non-learnable NMS culling with a smooth optimal-transport cost that can guide training directly.

What the paper changes

The one thing that changed

The paper replaces the training objective. Instead of predicting locations, then running a hard binary keep-or-discard step, it reformulates the whole task as a set-matching problem: given a predicted set of molecules and a true set, find the assignment that minimizes total distance. This is a smooth, continuous cost, and every prediction contributes a gradient.

the object it moves  =  training loss (hard NMS to smooth optimal transport matching)
The hidden quantity

The hidden quantity: assignment cost

measured quantity  =  optimal transport distance

The paper introduces a hidden quantity nobody measured before: the cost of matching every prediction to a true molecule (or to a dummy 'ghost' for unmatched predictions). This is not accuracy, because accuracy counts only right or wrong; this metric captures how far the predictions sit from ground truth, in a way that allows many-to-one and one-to-many mappings, because optical blur sometimes makes one ground-truth molecule appear as multiple nearby predictions, and the assignment algorithm knows this and can match multiple predictions to the same ground truth.

The method estimates this by solving a linear-assignment problem (Sinkhorn algorithm, a classical technique from optimal transport theory). For each predicted position, it computes the distance to each ground-truth position, then finds the pairing that minimizes total cost. This cost flows backward as a gradient, so the network learns to predict positions that lower it.

Why it works

Why gradients can now flow: smooth costs instead of hard gates

The bottleneck was NMS: it is a discrete operation (keep or delete), so its output does not change smoothly with tiny input changes. A network tuning its predictions by 0.01 pixels still gets the same binary result and zero gradient signal.

Optimal transport solves this by computing a smooth cost for every possible assignment, not just the winner. When a prediction moves closer to a ground-truth position, the matching cost decreases smoothly, and that decrease becomes a gradient that steers the network. The Sinkhorn algorithm (used here) is differentiable: the gradients flow backward all the way from the matching cost to the network weights.

Additionally, the paper adds an iterative optical module that learns the blur pattern and refraction of the microscope itself. This encodes physical knowledge (how light spreads and distorts) directly into the network, so it learns not just to detect but to invert the optics.

Math after the picture

The smooth cost function

First in words:

Loss equals the sum of distances between each prediction and its matched ground-truth position, found via optimal assignment. No predictions are discarded; unmatched ones incur a fixed penalty.

Then the compact form:

L = min_{assignment} sum_{i} d(pred_i, matched_gt_i) + lambda * (false_positives + false_negatives)

Every symbol:

d(pred_i, matched_gt_i)Euclidean distance from prediction i to its assigned ground-truth position
matched_gt_iThe ground-truth position that prediction i is paired to
lambdaPenalty weight for unmatched predictions (false positives) and missed ground truth (false negatives)
assignmentThe one-to-one pairing that minimizes total cost (found via Sinkhorn)
A tiny worked example
Suppose we have 2 predictions and 2 ground-truth positions.
Prediction 1 is at (10, 20), Prediction 2 is at (30, 40).
Truth 1 is at (11, 21), Truth 2 is at (25, 38).
Option A: match Pred1->Truth1, Pred2->Truth2. Distances: 1.4 + 7.1 = 8.5.
Option B: match Pred1->Truth2, Pred2->Truth1. Distances: 15.0 + 22.4 = 37.4.
Optimal transport picks Option A (cost 8.5). Network learns: move both predictions slightly closer to their matched partners.
If lambda=2 and one prediction were unmatched, add penalty 2.0 to total; network learns to keep predictions only when they match the data.

Unlike hard NMS (keep vs. delete), every prediction contributes a smooth gradient proportional to its distance from the ground truth, so the network learns to predict positions that minimize assignment cost.

What can go wrong

What can go wrong

False assignment when truth is missing. If ground-truth annotation is incomplete (a true molecule was not labeled), the network can predict it without penalty, and gradients mislead training. Validation data must be fully labeled.
Sinkhorn algorithm slow on dense predictions. If the network predicts far more points than exist (massive false positives), the assignment problem scales quadratically. Computational cost can explode.
Optical model overfits to training scope. The iterative optical module learns microscope-specific blur. If tested on a different microscope, the learned optics do not transfer. Generalization across instruments requires retraining.
Done right. Use fully annotated synthetic data to initialize the optical module. Set lambda high enough that unmatched predictions are penalized. Validate on held-out dense-emission test data.
What a runnable demo should prove

What a runnable demo should prove

Implement the optimal-transport loss (Sinkhorn algorithm) in a PyTorch training loop. Use a simple convolutional network predicting (x, y, intensity) for each molecule. Train on synthetic microscope images with known ground-truth positions, varying the fluorophore density from low (easy, one per frame) to high (crowded, 10+ per frame). Log both the training loss and test accuracy (fraction of ground-truth molecules correctly localized within 50 pixels) at each density regime.

localization_error = mean_distance(predicted_positions, ground_truth_positions); false_positive_rate = unmatched_predictions / total_predictions

At high density, the optimal-transport model's error and false-positive rate must stay low, while an NMS-based model's accuracy must collapse. This proves that smooth gradients through optimal transport enable learning in crowded conditions where NMS fails, because smooth gradients let the network tune each prediction based on its distance to ground truth, while NMS only rewards the absolute winner in each region and discards all others regardless of whether they point to real molecules.
