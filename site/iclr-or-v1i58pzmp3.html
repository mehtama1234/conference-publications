Optimal transport unlocks end-to-end learning for single-molecule localization

Replace non-differentiable filtering with optimal transport loss to enable end-to-end learning for dense fluorescence microscopy.

Paper explainersAll themesAI for Science

Single-molecule localization microscopy (SMLM) reconstructs tiny cellular structures by finding thousands of tagged molecules in images. Current methods rely on non-differentiable layers that discard molecules, breaking the training pipeline. This paper uses a mathematical tool called optimal transport to match predicted and real molecules end-to-end, enabling training at high densities where molecules overlap.

Zero assumption version

The microscope sees crowded molecules but training breaks

A fluorescence microscope tags molecules with glowing dyes, then images them. Each glowing spot reveals a molecule's position. To get accurate positions, microscopes wait until most dyes are dark and only a few are glowing at once, then fire the camera. This produces slow, non-overlapping images.

A beginner might think: train a neural network directly on the raw microscope image to predict molecule positions everywhere at once. The problem is that the network is trained by comparing its predicted positions to the ground-truth positions, but the training objective only looks at individual pixels—it does not care about matching predicted molecules to real molecules. Then at inference time, the code uses a handcrafted filter called non-maximum suppression (NMS) to pick the strongest spots and discard overlapping ones. NMS is not differentiable—it is a hard decision gate that does not feed learning signals back into the network weights. This breaks end-to-end learning. And because NMS discards any detection too close to a stronger neighbor, it can discard real molecules.

In one sentence. Replace the pixel-wise training loss and the non-differentiable NMS filter with a differentiable loss that directly matches predicted and real molecules.

What the paper changes

What the paper changes

The hidden quantity

The assignment cost: which predicted spot is which real spot

measured quantity  =  optimal assignment distance

The paper measures a hidden quantity: the total distance cost of the best one-to-one matching between predicted molecules and real molecules. This is not pixel overlap or per-pixel error; it is the sum of distances in the assignment that minimizes total travel. For example, if you predict spots at positions 1, 5, and 9, and the real molecules are at positions 2, 6, and 10, the optimal matching pairs each prediction to its nearest real molecule: prediction 1 to real 2 costs distance 1, prediction 5 to real 6 costs distance 1, prediction 9 to real 10 costs distance 1, for a total cost of 3. A different pairing, like prediction 1 to real 6, prediction 5 to real 2, prediction 9 to real 10, would cost 5 plus 3 plus 1, which totals 9, so the algorithm avoids it.

The paper estimates this using the Sinkhorn algorithm, a smooth iterative procedure that solves the assignment problem while keeping all derivatives alive. During training, the network learns to place predictions that minimize this total distance, automatically learning the best strategy for overlapping molecules.

Why it works

Why end-to-end learning now works

The old approach broke because it trained pixel-by-pixel (each location independent) but tested with a global filter (NMS, which depends on neighbors). The network had no way to learn what the filter would do.

This paper uses optimal transport to make training and testing speak the same language. During training, the loss measures: given my predicted set of molecule positions, how far is it from the ground-truth set? The answer is the minimum cost to pair them up. This cost is computed using the Sinkhorn algorithm, a smooth iterative method that preserves gradients all the way back to the network weights. At inference, the network simply outputs its predicted positions and a threshold filters by confidence—no NMS needed, no gradient break.

Math after the picture

The differentiable matching loss

First in words:

loss equals the inner product of the optimal assignment and the distance cost matrix, where the assignment solves a regularized transport problem using the Sinkhorn algorithm

Then the compact form:

L = trace(Gamma_star^T * C), where Gamma_star solves: arg min_Gamma [trace(Gamma^T * C) - epsilon * H(Gamma)]

Every symbol:

Gamma_starthe optimal assignment matrix (rows = predictions, columns = real molecules; exactly one 1 per row and column)
Ccost matrix where C[i,j] = distance from predicted spot i to real spot j
trace(Gamma^T * C)sum of all matched distances
H(Gamma)entropy of the assignment (encourages smoothness, not hard 0-1)
epsilonregularization strength that trades off optimality for smoothness (higher epsilon means smoother gradients)
A tiny worked example
Say the network predicts spots at positions [0, 5] and real molecules are at [1, 6].
Cost matrix C = [[1, 6], [5, 1]]. (distance from pred-0 to real-1 is 1, to real-6 is 6, etc.)
Optimal assignment: pair pred-0 with real-1 (cost 1) and pred-5 with real-6 (cost 1). Total cost = 2.
Wrong assignment: pair pred-0 with real-6 (cost 6) and pred-5 with real-1 (cost 5). Total cost = 11.
The algorithm avoids the wrong pairing. The loss L = 2 tells the network to keep outputting positions close to [1, 6].

The Sinkhorn algorithm solves this efficiently in a few iterations, and every iteration is differentiable, so gradients flow back through the matching decision.

What can go wrong

What can go wrong

False negatives if smoothing is too weak. If the smoothing strength is set too low, the Sinkhorn algorithm finds a hard assignment too quickly. The network learns to output only the closest spots and ignores distant molecules, which the loss then penalizes. Setting smoothing too high smooths away the distinctions. Trade-off required.
Ghost predictions when molecule count is uncertain. The loss assumes the network knows exactly how many real molecules are in the frame. If the network outputs more or fewer predictions than there are ground-truth molecules, the optimal transport will match some predictions to nothing or some real molecules to nothing (padded with a fixed-cost dummy slot). The paper does not fully address how to learn the molecule count from data.
Computational cost of iterative refinement. The paper proposes iterating the encoder-decoder K times, refining predictions each iteration. This is expensive at inference. For real-time live-cell imaging, a simpler single-pass variant may be needed.
Done right: end-to-end learning works. When the network knows the frame size and the ground-truth molecule count, optimal transport directly trains it to place predictions close to real molecules. No hand-crafted filters, no gradient breaks.
What a runnable demo should prove

What a runnable demo should prove

Build a toy microscope simulator that renders overlapping glowing spots at known positions. Train a small encoder-decoder network using the optimal transport loss (not pixel-wise loss, not NMS). At inference, output positions and filter by confidence. Compare accuracy on dense frames (many overlapping molecules) to a baseline that uses pixel loss and NMS.

accuracy = (number of correctly paired predictions) / (total real molecules). Test on high-density frames where molecules overlap.

The demo must show that optimal transport learns to resolve overlapping molecules where NMS fails, and that gradients flow end-to-end without freezing at a filter.
