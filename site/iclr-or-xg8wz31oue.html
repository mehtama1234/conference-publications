Small Drafts, Big Verdict: Information-Intensive Visual Reasoning via Speculation

Several small vision-language models each draft a reasoning path over a dense image, then one stronger model reads only the best-supported drafts and issues the final answer.

Paper explainersAll themesMultimodal

Dense charts, infographics, and annotated diagrams force a model to do two things at once: find the right visual fragments and combine them across several reasoning steps. A single large vision-language model often misses one of those fragments, then the whole answer fails. Speculative Verdict splits the job. Small draft experts each produce a candidate reasoning path with localized cues, and a stronger verdict model reads those paths, keeps the parts that agree, and writes the final answer. The method is training-free, so it changes inference (the process of producing an answer from a trained model) rather than changing model weights.

Zero assumption version

Why dense visual question answering breaks

Information-intensive images pack many small pieces of evidence into one page: labels, numbers, arrows, legends, and small plotted marks. To answer a question, the model must first localize the right pieces, then connect them across several steps. If it reads the wrong legend entry or misses one annotation, the remaining reasoning path is built on a false premise.

A direct call to one large model often fails because the model spends a large amount of computation on a single reasoning path. That path may be fluent but still wrong if the first localization step drifted. In dense layouts, there are usually several plausible cue locations, so one path is a brittle plan.

The paper's move is to spend a small amount of computation on many draft paths first. This helps because different small experts make different localization errors, so the correct cue often appears in at least one draft even when no single draft is fully correct.

The fix. Generate several cheap reasoning drafts, filter them by agreement on the visual evidence, and let one stronger model combine only the supported drafts into the final answer, because agreement makes it more likely that the forwarded cues are real rather than one-off mistakes.

The algorithm as a flow

What it actually does

Run several draft experts

Prompt multiple small vision-language models on the same image and question. Each one writes a reasoning path that names visual cues and uses them to propose an answer.

Extract candidate evidence

Read each draft path and pull out the claimed cue locations or cue descriptions: which legend item, which value, which region, which relationship.

Score agreement

Compare the drafts and keep the paths whose evidence overlaps with others. A path is forwarded when enough other drafts support the same cues or the same answer.

Call the verdict model

Send only the filtered draft paths to a stronger model. The verdict model reads them as structured evidence and writes one final answer, which lets it spend its computation on combining supported cues instead of searching through many weak paths.

Return the answer with lower cost

Most of the searching was done by small models, so the expensive model only performs the final synthesis step.

What the paper changes

What the paper changes

The paper changes the unit of computation from one monolithic answer attempt to a two-stage process: draft reasoning paths first, verdict second. That matters because dense visual reasoning usually fails during evidence search, not during sentence generation. By externalizing several candidate paths before the expensive model answers, the method creates a pool of evidence that the final model can cross-check.

The hidden quantity

The hidden quantity: agreement on evidence

measured quantity  =  Consensus score over draft paths

The central quantity is not just whether two drafts give the same final answer. It is whether they cite the same underlying evidence. A consensus score measures how often a cue in one draft is supported by cues in other drafts. High agreement means several independent draft paths converged on the same visual fragment, which reduces the chance that the fragment was hallucinated.

This score matters because the verdict model is only useful if its input set already contains the right pieces. If low-agreement drafts are forwarded, the final model must sift through many false trails. If high-agreement drafts are forwarded, the final model spends its budget combining cues instead of repairing cue search errors.

Why it works

Why speculation helps on dense images

Dense visual tasks are search-heavy. The expensive part is often locating the right cues among many nearby distractors, not expressing the answer in text. Small draft experts are good enough to propose candidate cues, even when each one is only partly correct. Running several of them broadens the search because each expert explores a different path through the image.

The verdict stage then corrects partial mistakes by composition. One draft may identify the right legend entry but the wrong bar; another may identify the right bar but miss the axis condition. The final model can recover the answer because the correct pieces are present across drafts. This works by turning one fragile end-to-end chain into a set of reusable evidence fragments.

The core selection rule

First in words:

Keep a draft path when enough other draft paths support its evidence, then ask the verdict model to answer from the kept set.

Then the compact form:

S_i = sum_j Agree(r_i, r_j), keep r_i if S_i >= tau, answer = V({r_i : S_i >= tau})

Every symbol:

r_idraft reasoning path i
Agree(r_i, r_j)how much the evidence in draft i overlaps with the evidence in draft j
S_iconsensus score for draft i
tauthreshold for forwarding a draft path
Vthe verdict model that reads the kept drafts and answers
A tiny worked example
Draft A says the question depends on the blue bar for 2023 and the top legend entry.
Draft B says the question depends on the blue bar for 2023 and the same legend entry.
Draft C says the green bar for 2022 is relevant.
Agreement scores become A=2, B=2, C=0 when only matching cue pairs count. With tau set to 1, A and B are kept and C is dropped.
The verdict model then reads A and B, resolves small wording differences, and outputs the final answer from the supported cue pair.

The point of the rule is to spend the strongest model's budget on synthesis after search, not on exploring every possible cue path itself.

What can go wrong

What can go wrong

All draft experts share the same blind spot. If every small expert misses a tiny label or misreads the same region, consensus will amplify that mistake because agreement is only useful when errors are not perfectly correlated.
Consensus can drop rare but correct paths. A correct cue may appear in only one draft when the evidence is subtle. If the threshold is too strict, the filter removes the one path that had the answer.
The verdict model can still overtrust noisy drafts. Filtering reduces noise, but it does not prove that every surviving path is correct. The final answer can still fail if the verdict model does not separate strong evidence from repeated paraphrases of the same mistake.
Done right. Use diverse draft experts, keep the consensus threshold moderate, and pass the verdict model drafts that expose explicit cue references rather than only short answers. That gives the final stage material it can actually cross-check.
