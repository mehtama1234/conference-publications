FACT: First-Principles Features at Convergence

Instead of guessing what features a network learns, derive it mathematically from the stopping point where training finishes.

Paper explainersAll themesLearning Theory

Neural networks learn features by slowly adjusting millions of numbers until answers match the data, because each adjustment that makes answers better is kept. But which numbers end up mattering most? A guess called the Neural Feature Ansatz tries to explain this but is unproven. This paper replaces it with FACT, a math-based rule: when training stops, the network is stuck at a resting point where tiny nudges make things worse. That resting-point condition determines which weights must be large and which can be small. FACT predicts learned features more accurately than the old guess, explains why that guess usually works, and captures surprise cases like grokking.

Zero assumption version

We guess at how networks learn, but the guess is unproven

A deep network — a chain of numbers that turns an image into a label — learns patterns called features. Early layers might learn edges; deeper ones might learn eyes or paws. But we don't truly know what rule decides which features pop up.

The leading answer is the Neural Feature Ansatz: networks separate into two phases. First, they learn a low-noise 'core' that summarizes the input. Then they refine class-specific details on top. This guess matches what we see in experiments.

But it is just a guess. We don't know when it breaks. We can't prove why it works. When a network suddenly 'groks' — jumps from random guessing to perfect understanding — the old guess fails to explain it.

In one sentence. The paper replaces the Neural Feature Ansatz guess with FACT: a math-based rule that says networks converge to a resting point where small weight moves make the loss grow.

The hidden quantity

The hidden quantity: Convergence resting points

measured quantity  =  resting-point structure from optimality

A resting point is where training stops: the loss is low and tiny weight nudges make it worse (or stay flat). Not every point is a resting point; only special ones are. The paper measures this by using a rule from calculus: at a true resting point, the gradient — the direction of steepest loss increase — must be zero (or must stay zero after projection to allowed weight changes).

The paper solves the optimality conditions: it asks 'what weights satisfy the resting-point property?' The answer is a set of equations. Solving those equations tells you which weights MUST be large and which can be small. These size patterns are the features the network learned.

Why it works

Why it works: the causal chain

Training is a slow hill-walk toward lower loss. When it stops, the network sits at a resting point. At that point, one of two things is true: either the loss cannot drop further (a true local minimum), or the solver has hit a boundary and must stop.

Optimality says: at a resting point, the force pulling weights downhill (the gradient) is either zero or points outward (cannot drag the weight further in its allowed range). This is a hard rule from calculus that every resting point obeys.

The paper writes this rule as an equation. Solving that equation tells you the structure: which weights must be large (or face a penalty) and which can be small. The large weights encode the features the network found useful to solve the task. Large weights in specific patterns mean 'this layer detects eyes' or 'this combination responds to cars.' Small weights mean 'this connection was not useful' and can be trimmed.

FACT works because the optimality rule is iron-clad: every network training run ends at a resting point, so the math prediction must hold there. It predicts better than the old guess because it uses the math's constraints instead of a guess built from observation, and the math is provably sound.

Math after the picture

The resting-point equation

First in words:

At a resting point, the gradient (the direction of steepest loss climb) equals zero, or the weight is pushed against a constraint, or the weight update is zero because progress has stalled.

Then the compact form:

∇_W L(W) = 0 at convergence, or W remains fixed when ∇_W L(W) does not shrink the loss further

Every symbol:

∇_W L(W)the gradient: how much nudging each weight up/down changes the loss
Wthe network weights
L(W)the loss: how far the predictions are from correct answers
= 0no improvement from any tiny weight change
A tiny worked example
Suppose a two-weight network has loss = (w1 - 3)^2 + (w2 + 1)^2. The gradients are ∇w1 = 2(w1 - 3) and ∇w2 = 2(w2 + 1).
At convergence, both must be zero: w1 = 3 and w2 = -1.
The resting point is w1=3, w2=-1. Any tiny move from here makes loss grow. This is what the network converges to.

The optimality rule says: when training stops, the weights have settled into a shape where moving any of them makes the loss worse. FACT finds that shape by solving the math.

What can go wrong

What can go wrong

Saddle points instead of minima. Sometimes training stops at a saddle point — a flat spot that is not a true valley. The optimality rule still holds, but the weight structure may be unstable.
Overparameterized networks (more weights than data). When the network has far more knobs than necessary, many resting points exist with wildly different weight patterns. FACT predicts all of them, so you need extra hints to pick which one training actually reached.
Non-convex loss (many valleys). In real deep networks, the loss has thousands of bumpy spots and valleys. Optimality still defines resting points, but training might settle in a valley far from the best possible solution. FACT's predictions are correct for that local valley, but not guaranteed to be the global best.
Done right: use FACT where training fully converges. FACT shines when training runs long enough to reach a true resting point (low gradient magnitude). For networks that train to low loss on the data, FACT accurately predicts the feature structure.
What a runnable demo should prove

What a runnable demo should prove

Train a small neural network on a task (e.g. learning to add two numbers modulo 97, which exhibits grokking). Let it train until loss is very low. Then extract the weights. Use FACT's optimality equations to predict which weights should be large. Measure how closely the predicted large-weight positions match the actual trained weights. Compare to the Neural Feature Ansatz prediction: FACT should be much more accurate, especially in grokking regimes where the old guess fails, because the math rule applies to every resting point whereas the old guess is just a pattern observed from data.

accuracy = (number of top weights correctly predicted) / (total predictions)

The demo must show FACT correctly spotting which weights matter even when the old guess misses them, especially in sudden-learning regimes.
