Learning Exposure Mapping Functions for Inferring Heterogeneous Peer Effects

Instead of guessing how peer influence works, a graph neural network learns the exposure mapping function that captures complex peer effects from data.

Paper explainersAll themesLearning Theory

Peer effects (when your friends' choices affect your outcomes) shape people's lives, but measuring them requires knowing exactly how one person's peer exposure works: how many friends matter? Which friends matter most? Does your friend's distance in the network change their influence? Today, scientists guess these rules manually. This paper replaces the guessing with a neural network that learns the rules automatically from data, discovering heterogeneous peer influence mechanisms that fixed formulas would miss.

Zero assumption version

Peer effects hide inside unknown mappings

When scientists want to measure peer effects (how your friends' behaviors affect you), they must specify an exposure mapping function: a rule that says 'add up peer treatments this way.' A typical rule might be 'count the number of treated peers' or 'average your peers' outcomes.' But the true rule is hidden. If you guess wrong, your estimates become systematically biased: you measure the wrong effect.

A beginner might use the same formula for every network and every dataset: 'always count fraction of treated friends.' This breaks when peer influence depends on who your peers are (their features), how close they sit to you in the network, or the edges between your peers. You end up with a one-size-fits-all rule applied to heterogeneous (varied) mechanisms.

The problem in one sentence. True peer influence mappings are unknown and highly context-dependent; guessing them wrong produces biased causal effect estimates.

The algorithm as a flow

What it actually does

Extract ego networks

For each person, cut out their local neighborhood (ego network): themselves, their friends, friend-of-friend structure.

Encode neighborhood context

Measure who each friend is (their features), how close they sit to the ego, and edges between peers.

Learn weighted aggregation

A learnable mask layer assigns a weight to each friend; people far away or irrelevant get low weights automatically.

Count structural patterns

The network learns to find small repeated patterns (motifs) in the ego's neighborhood that signal influence.

Estimate heterogeneous exposure

The learned mapping becomes person-specific and data-specific; each person's peer influence rule adapts.

What the paper changes

The single object changed: the exposure mapping function

The paper's core move is replacing a hand-coded exposure mapping function with a learnable neural network function. Instead of writing 'add up 1s for treated peers,' you train a graph neural network to discover 'weight each peer by their features, my features, and our network distance, then add.' The object being changed is the function itself.

the object it moves  =  exposure mapping function
The hidden quantity

The hidden quantity: local structural context weights

measured quantity  =  per-peer influence weights

The paper introduces a new measurable quantity: for each peer in your neighborhood, a learned weight that says 'this peer matters X fraction of my exposure.' A close friend with similar features gets a high weight; a distant, dissimilar peer gets a low weight. These weights are not set by the scientist; they are learned from data.

The paper estimates these weights using a masked fully connected layer that takes as input each peer's features, their treatment status, the edge attributes (how you are connected), and your own features. The output is a weight for that peer, normalized so all weights for one person sum to 1.

Why it works

Why learning the mapping function works

A fixed formula like 'count treated peers' fails because real peer influence is heterogeneous (different for different people and structures). EgoNetGNN solves this by making the exposure mapping function adaptive. Here is the causal chain: (1) Each person's ego network is extracted and their peers are described by features and edge metadata. (2) A neural network layer applies learned weights to each peer, high weights for informative peers, low weights for noise. (3) These weights are regularized to be sparse (few large weights, many zeros) and binary-like (close to 0 or 1), so the learned function remains interpretable and reliable. (4) A graph neural network aggregates information across the network layers, allowing the exposure mapping to account for second-order effects (your friend's friends matter). (5) The learned exposure mapping is unique to each node and each network dataset, so it adapts to the true underlying influence mechanism. Because the mapping is learned, not guessed, systematic bias drops and causal effect estimates become more accurate.

The trick is that a neural network is expressive: it can represent any differentiable function, including arbitrarily complex exposure rules. But it is also regularized: sparsity losses and entropy losses (which penalize weights sitting between 0 and 1) push the learned weights to be simple and sparse, avoiding overfitting and keeping the mapping interpretable. The result: expressive enough to fit true heterogeneous mechanisms, but constrained enough to remain valid.

Math after the picture

The learned aggregation equation

First in words:

For each node, compute a weighted sum of peer treatments and features. The weights are learned by a masked fully connected layer that takes node attributes, feature distance, and edge attributes as input. Sparsity losses (which push weights toward 0 or 1) and entropy losses (which penalize weights that sit between 0 and 1) regularize the weights.

Then the compact form:

h_agg_j = Xbar_j || c_ij || h_j^L; weights = softmax(W_mask * [node_attrs || feature_distance || edge_attrs]); peer_exposure = sum_j( weight_j * treatment_j )

Every symbol:

h_agg_jaggregated features for peer j in ego network
Xbar_jnode attributes (features) of peer j
c_ijencoded distance between ego i and peer j
h_j^Llearned hidden representation of peer j after L layers
W_masklearnable matrix that computes per-peer influence weights
weight_jnormalized weight for peer j (sums to 1 across all peers)
treatment_jtreatment status of peer j (0 or 1)
A tiny worked example
Suppose ego node i has 4 peers. Peer A is close and similar (features): W_mask outputs high score, weight_A = 0.50. Peer B is far and dissimilar: low score, weight_B = 0.10. Peers C and D are medium: weights 0.25 and 0.15.
Suppose treatments are t_A=1, t_B=0, t_C=1, t_D=0.
Old method: Naive peer exposure = 2/4 treated = 0.50.
EgoNetGNN: Learned exposure = 0.50*1 + 0.10*0 + 0.25*1 + 0.15*0 = 0.50 + 0.25 = 0.75.
The learned mapping up-weights Peer C because of local structure; the true mechanism emphasizes Peer C; so learned exposure is more accurate than naive count.

The mask layer is the key: it learns to assign high weights to peers who truly influence the ego outcome, removing irrelevant noise.

What can go wrong

What can go wrong

Overfitting learned weights to noise. If training data is small relative to network size, the learned mask layer may memorize spurious patterns. Sparsity and entropy losses prevent this, but they must be tuned.
Structural identifiability assumptions violated. The method assumes that causal structure can be inferred from observational network data; unobserved confounders (hidden variables affecting both treatment and outcome) break causal identification even with a perfect learned mapping.
Computational cost with large networks. Extracting ego networks for every node and learning weights scales with edge density and average degree. On very dense networks, this becomes expensive.
Done right. With sufficient data, sparsity regularization tuned well, and causal identifiability assumptions held, the learned mapping recovers heterogeneous peer exposure accurately and causal effect estimates become less biased.
What a runnable demo should prove

What a runnable demo should prove

Build a small synthetic network with a known true exposure mapping rule (e.g., 'ego and structurally similar peers have high weight, others have weight 0.1'). Simulate outcomes by applying this rule. Train EgoNetGNN on the network without telling it the rule. Compare: (a) the learned weights to the true weights, (b) causal effect estimates from the learned mapping versus naive methods.

recovery_error = mean_absolute_error(true_weights - learned_weights); bias = mean( effect_estimate_learned - true_effect ) - mean( effect_estimate_naive - true_effect )

The demo must show: learned weights are close to true weights (recovery is accurate), and bias in causal effect estimates is much lower than naive methods, especially on heterogeneous networks.
