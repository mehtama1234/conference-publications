EigenBench: Measuring Value Alignment Without Ground Truth

When there is no right answer for what values a model should hold, use models judging each other to find which ones agree most.

Paper explainersAll themesAlignment, Safety & Fairness

You want to know if a language model shares your values. But some values are subjective — no one has a clean right answer. EigenBench solves this by having a group of models judge each other's outputs, then tallying which models other models trust most, like a peer-review score. The result is a single honest number for each model showing how aligned it is to a value system.

Zero assumption version

Why you cannot simply grade value alignment

When a model answers a question, we often know if it is factually right or wrong — we can check against reality. But when a model demonstrates a value like fairness or honesty, there is no objective ground truth to check against. Different people disagree on what counts as fair.

A beginner would try: pick some human raters, have them grade every model's outputs yes-or-no, and average the scores. This seems simple. But it breaks when raters themselves have different values. One rater might think a model is fair; another thinks it is not. Whose judgment do you trust?

The core problem. You need a score for each model's values, but no one agrees on what the right answer is, so you cannot just average human votes.

The algorithm as a flow

What it actually does

Step 1: Set up the jury

Gather a group of language models and a written constitution (a description of the values you want to measure).

Step 2: Generate scenarios and outputs

Each model answers the same scenario questions using the constitution as a guide, producing candidate outputs.

Step 3: Run the peer panel

For each scenario, every model judges every other model's output: does this align to the constitution, yes or no?

Step 4: Aggregate trust

Count up who said yes to whose outputs. Build a table of how often each model's judgment agreed with others.

Step 5: Compute consensus scores

Use a math method called EigenTrust to find which models are trustworthy judges, then use their votes to score each model's alignment.

What the paper changes

What the paper changes

Instead of hiring human raters to score models on value alignment, EigenBench uses the models themselves as judges and lets their peer votes create the score. No human labels needed, because the models' judgments are the only ground truth you have.

the object it moves  =  who judges value alignment
The hidden quantity

The hidden quantity: trustworthiness

measured quantity  =  trustworthiness of a model's judgment

Trustworthiness is a single number for each model that says how much other models should trust this model's judgment when it evaluates alignment. A model with high trustworthiness is one whose yes-or-no votes agree with the votes of other trustworthy models.

The paper estimates trustworthiness by looking at the pattern of who agreed with whom. If a model's votes align with what other reliable models voted, that model's trustworthiness score rises. It is a recursive definition: you trust a model because other trusted models agree with it.

Plain reading. Trustworthiness measures whose opinion most models converge on. A model whose yes-or-no votes match other models' votes gets a high trustworthiness score.
Paper reading. EigenTrust computes an eigenvector (a stable pattern in how models vote for each other) where each model's score reflects weighted agreement with high-trustworthiness judges.
Why it works

Why this finds honest consensus without labels

Trustworthy judges do not need to agree with some external ground truth — they just need to agree with each other. If you have a group of models, the ones whose judgments most overlap are likely the ones making honest, thoughtful calls.

Here is the causal chain: When each model rates every other model's outputs, you get a table of yes-or-no votes. Now you rank which models are trustworthy by checking: whose votes did other trustworthy models also make? Models that voted the same way as other reliable judges get higher trustworthiness. Finally, to score each model's overall alignment, you take a weighted average of all the yes votes it received, but you weight each yes-vote by how trustworthy that judge is. Trustworthy judges' votes count more than unreliable ones. The result is a single alignment score for each model that reflects the consensus of the models the group trusts most.

Why does this work? Because there is a stable equilibrium: if most models have similar values, then the models whose judgments align with the group will be ranked as trustworthy, and their votes will reinforce their own high alignment scores. The system pulls toward a consensus without needing any external ground truth.

The alignment score formula

First in words:

Each model's alignment score equals the weighted average of how often other models said its output was aligned, where each judge's weight is their trustworthiness score.

Then the compact form:

alignment_j = sum_i ( trustworthiness_i * votes_i_to_j ) / sum_i trustworthiness_i

Every symbol:

alignment_jthe alignment score for model j
trustworthiness_ihow much you should trust judge i's opinion (computed from consensus)
votes_i_to_jfraction of yes-votes judge i gave to model j's outputs
sum_iadd up over all judges
A tiny worked example
Suppose four judges all rate model X.
Judge A (trustworthiness 0.8): said yes 90 percent of the time to X. Contribution: 0.8 * 0.9 = 0.72
Judge B (trustworthiness 0.6): said yes 70 percent of the time to X. Contribution: 0.6 * 0.7 = 0.42
Judge C (trustworthiness 0.3): said yes 50 percent of the time to X. Contribution: 0.3 * 0.5 = 0.15
Judge D (trustworthiness 0.3): said yes 30 percent of the time to X. Contribution: 0.3 * 0.3 = 0.09
Sum of trustworthiness: 0.8 + 0.6 + 0.3 + 0.3 = 2.0
Sum of contributions: 0.72 + 0.42 + 0.15 + 0.09 = 1.38
Model X alignment score: 1.38 / 2.0 = 0.69
Result: Model X aligns with the constitution 69 percent of the time, according to trustworthy judges.

Trusted judges' votes count more, so the final alignment score reflects the values of the models the ensemble agrees are most thoughtful.

What can go wrong

What can go wrong

All models have the same values. If every model in the ensemble has nearly identical values, they will all agree with each other, and no model will stand out as more trustworthy. The method finds consensus, but the consensus might be narrow and not representative.
The constitution is vague or contradictory. If the written value system has unclear rules, judges will disagree on interpretation, not because they have different values but because the spec is ambiguous. This noise breaks the trustworthiness signal.
Collusion or group-think in the ensemble. If some models have been fine-tuned together or trained on the same data, they might have artificially similar judgments even if they are not correct. The trustworthiness computation will favor them falsely.
Done right: diverse ensemble, clear constitution. When you have models with genuinely different training, and the constitution is specific and unambiguous, the trustworthiness scores stabilize, and the alignment rankings reflect real differences in values.
What a runnable demo should prove

What a runnable demo should prove

Build a small ensemble of three to five language models. Write a simple, clear constitution describing one concrete value, like honesty (the model must not make up facts). Create ten scenarios where the models answer a question, and you can clearly see which answer is more honest. Have each model judge every other model's output against the constitution. Run the EigenBench algorithm: compute trustworthiness for each model based on agreement patterns, then compute each model's alignment score weighted by trustworthiness.

Agreement with humans = number of times EigenBench ranking matches human ranking / total number of models

The demo succeeds when the EigenBench scores spread the models into a clear ranking that aligns with what a human would predict about their values, without ever showing the human judgments to the algorithm.
