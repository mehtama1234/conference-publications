LRF-Dyn: Localized Attention for Spiking Transformers

Spiking Transformers can match regular neural networks in accuracy while using far less memory by focusing attention on nearby tokens and simulating biological neuron firing instead of storing giant matrices.

Paper explainersAll themesEfficiency & Systems

Spiking neural networks send discrete pulses like biological brains, using much less energy than regular neural networks. But when you try to add the attention mechanism (the part that lets the model focus on the most relevant pieces of input) to these networks, you run into a trap: you have to store enormous two-dimensional number grids in memory, and the attention gets scattered across all pieces instead of focusing on nearby ones. LRF-Dyn fixes this by making attention focus only on neighbors and replacing grid storage with the simple on-off dynamics of biological neurons.

Zero assumption version

The trap in spiking attention

Standard neural networks use continuous numbers flowing through layers. Spiking neural networks mimic biology: each neuron either fires a spike (1) or stays silent (0) at each time tick, using far less energy. But to make spiking networks work as well as standard networks, researchers added attention—the mechanism that lets each token ask other tokens for the information it needs. A naive approach: treat spiking attention just like regular attention. For each token, compute a similarity score against every other token, store all those scores in a grid, apply a sharpening step (which converts raw scores into fractions that add up to 1), and use the result to combine information from all tokens. The problem: that grid is enormous. If you have N tokens and each token has D numbers (how much information you can pack into one token), you must store an N-by-N grid of attention scores, then an N-by-D grid of values. That is a memory size that grows with N times N and computation that grows the same way—for every time step. On edge devices with little memory, this is a dead end.

A beginner might try: just use attention but make the numbers smaller. That helps a little, but the real problem is that you still need to look at everything. Making numbers smaller does not change how much memory you use or how many comparisons you make, because you still compute attention between every pair of positions. In biology, vision neurons do not look everywhere equally—they have a limited view. They focus on neighbors. Standard image-processing networks do the same implicitly through training; spiking networks lose this because without a sharpening step to highlight important positions, attention spreads uniformly across the whole image. The model wastes computation on distant, irrelevant positions.

The core problem in one sentence: Spiking Transformers must choose: either store giant attention matrices (killing memory efficiency) or lose the ability to focus on what matters (killing accuracy).

The algorithm as a flow

What it actually does

Step 1: Localize the receptive field

Add a local spatial filter to spiking attention so nearby tokens get higher weights than distant ones.

Step 2: Model attention as neuron charging

Instead of using a sharpening step and storing a grid, model the attention result as the membrane charge of a spiking neuron.

Step 3: Spike when charged above threshold

When the charge reaches a threshold, the neuron fires a spike (outputs 1), then resets to zero, just like a real neuron.

Step 4: Use spikes to gather information

Spikes trigger value aggregation: which spikes fire tells you which tokens to pull information from.

Step 5: No matrix lives in memory

Memory holds only the current spike state and charge, not the full attention matrix, saving quadratic space.

What the paper changes

What the method changes

LRF-Dyn modifies two things. First, it changes how the attention mechanism allocates weights: instead of spreading attention uniformly across all tokens, it biases the mechanism to give higher weight to tokens that are spatially close (in nearby image regions or positions). Second, it replaces the storage of an explicit N-by-N attention matrix with a small set of neuronal state variables (charge, spike time, reset voltage) that evolve moment by moment, mirroring the biophysics of a real spiking neuron.

The hidden quantity

The hidden quantity: localization strength

measured quantity  =  attention weight concentration on neighbors

Standard spiking attention scatters focus almost uniformly across all pieces because it skips the sharpening step (which normally highlights what matters by making small differences bigger). LRF-Dyn measures a new quantity: how concentrated the attention weights are on nearby pieces versus far pieces. The paper calls this the tightness of the attention distribution—tight means strong focus on neighbors, loose means spread-out attention. This matters because in vision, objects and patterns cluster in space. If a piece attends equally to every pixel, it gets noise and loses the signal. If it focuses on neighbors, it extracts clear local features.

LRF-Dyn estimates this concentration by comparing the attention grid that would be computed (for analysis only) versus the result of the LRF-modified mechanism. The spatial filter amplifies weight differences, making some neighbors stand out and distant pieces fade. The paper proves mathematically that this produces attention distributions that match biological vision and standard neural networks, not the flat distribution of basic spiking attention.

Why it works

Why it works: the causal chain

Standard spiking attention skips the sharpening step (to save computation), but this breaks focus. Without sharpening, small differences in attention scores do not get magnified—a score of 0.9 versus 0.8 for nearby and distant tokens stays almost equal after the operation. So attention spreads uniformly.

LRF-Dyn inserts a local spatial filter before attention is computed (this filter is like a localized detector that looks at small image patches). This filter acts like a neighborhood spotlight: it boosts signal from nearby pieces and suppresses signal from far pieces because it is designed to respond strongly to neighbors (high weights for close positions, zero weights for far positions). By the time the attention mechanism sees its input, nearby pieces already have higher values. Even without sharpening, the attention scores favor neighbors simply because their inputs are larger.

But that only solves the focus problem. Memory still explodes if you store an N-by-N grid of attention scores. So LRF-Dyn replaces grid storage with neuron dynamics. Here is how: in a real spiking neuron, charge accumulates over time. When charge crosses a threshold, the neuron fires (outputs a spike, which is 1). Immediately after, the neuron resets to a lower voltage and starts charging again. LRF-Dyn models the attention aggregation step as this charge-fire-reset cycle. Mathematically, the attention result (which values to blend and how much) is rewritten as a rule describing how charge grows and shrinks. The cell body integrates signals from input branches, each branch representing a local neighborhood. This integration is the attention aggregation. Spikes tell you which information to extract. Because spikes are binary (0 or 1 at each tick), you only need to store the current spike state, not a large grid. Memory drops from needing to store a grid with size N times N down to storing just a few numbers per token, one or two per position, instead of an entire row of the attention grid.

Math after the picture

The equation: attention as neural dynamics

First in words:

Membrane charge grows over time, equals the sum of weighted inputs from local regions. When charge exceeds a threshold, fire a spike and reset. The spike triggers value aggregation.

Then the compact form:

dC/dt = (lambda * sum_neighbor(score_neighbor * input_neighbor)) - (alpha * spike)

Every symbol:

Cmembrane charge (accumulated potential) in one neuron
dC/dtrate of change of charge over time
lambdahow fast charge accumulates from input
score_neighborattention weight for a neighboring token
input_neighborhidden vector from a neighboring token
alphareset strength (how much charge drops after a spike)
spikebinary (0 or 1) output when charge exceeds threshold
A tiny worked example with three tokens
Token at position 2 receives input from neighbors at positions 1, 2, 3.
Attention scores from local convolution: score_1=0.3, score_2=0.8, score_3=0.5 (center token highest).
At time t, membrane charge C=0. Input vector sizes: 1.0, 2.0, 1.5.
Charge accumulation: dC/dt = 0.9 * (0.3*1.0 + 0.8*2.0 + 0.5*1.5) = 0.9 * (0.3 + 1.6 + 0.75) = 0.9 * 2.65 = 2.385.
After one time step: C = 0 + 2.385 = 2.385.
Threshold = 2.0. Since 2.385 > 2.0, the neuron fires a spike (output=1).
After firing, reset: C = 2.385 - alpha*1 = 2.385 - 0.9 = 1.485.
Next time step: charge grows again from 1.485, adding the new accumulated input.
Contrast: a naive spiking attention would have given equal weight 0.33 to all three neighbors (uniform), and charge would grow as 0.9*(0.33*1.0 + 0.33*2.0 + 0.33*1.5) = 1.26, smaller and less informative.

The formula shows why LRF-Dyn saves memory: instead of storing all attention scores and intermediate grids, only the current membrane charge C and spike state are kept at each time step for each position, because the charge value summarizes all past influence and can be updated with one arithmetic step (add new input, subtract reset), eliminating the need to remember entire rows of old attention matrices.

What can go wrong

What can go wrong

Receptive field too small. If the local convolution window is too narrow (only looks at 3 immediate neighbors), the model cannot capture long-range patterns like object boundaries or global structure. It loses accuracy on large objects.
Neuron charge dynamics tuned to one architecture. The threshold, reset strength, and time constant must be tuned to each model size and layer depth. Copy a model to a new task or dataset and these constants may no longer be optimal, requiring retraining or redesign.
Spiking noise during low-charge periods. If the membrane potential drifts near the spike threshold due to noise or random events, the neuron may fire incorrectly, producing wrong attention spikes. This requires careful initialization and normalization of input sizes.
Done right: tune window size for your data. For images, use a window size matching the smallest important object size. For faces use 7 pixels wide, for full scenes use 15 pixels wide. Test the threshold on a held-out validation set. Normalize inputs before the local filtering step.
What a runnable demo should prove

What a runnable demo should prove

Build a tiny spiking Transformer on a toy vision task (CIFAR-10 or a single-class subset). Train two models side by side: one with standard spiking attention (uniform), one with LRF-Dyn. Measure three things: peak memory usage during inference, end-to-end accuracy, and wall-clock inference time. The goal is to show that LRF-Dyn uses less than half the memory of standard attention while maintaining or exceeding accuracy.

memory_saved = (memory_standard - memory_lrf) / memory_standard; accuracy_gap = accuracy_lrf - accuracy_standard

The demo must make it impossible to ignore that localized attention plus neuronal dynamics does not trade accuracy for efficiency—it gains both.
