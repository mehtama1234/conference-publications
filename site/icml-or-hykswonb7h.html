DRL-STAF: Deep Reinforcement Learning for State-Aware Forecasting

A method that predicts future values in time series AND figures out hidden states by using deep learning for numbers and reinforcement learning for state picking, avoiding explosion when handling many dimensions at once.

Paper explainersAll themesTime Series & Sequential

In weather forecasting, you see today's temperature and humidity, but you don't directly see whether a cold front is moving in. That unseen condition (the cold front) is a hidden state, and it changes what the next day's weather will be. Traditional models either ignore the hidden states (missing that they matter), or model them as fixed rules that break under complex, changing patterns. This paper combines the pattern-learning power of deep learning with reinforcement learning's ability to pick the right hidden state at each moment, without having to predefined all the state rules up front.

Zero assumption version

The stuck choice between two bad options

Time series forecasting (predicting the next value in a sequence) comes with a hidden problem: the future doesn't just depend on the numbers you see now, it also depends on invisible conditions you never get to measure directly. In weather, that invisible condition is whether a cold front is nearby. In traffic, it's whether a major event is happening. In finance, it's market sentiment. These invisible conditions are called hidden states, and they shape what comes next.

Today's methods face an ugly choice. Option 1: ignore hidden states entirely and just learn patterns from the visible numbers using a deep neural network. This works okay for many cases, but it misses a key fact: tomorrow's value really does depend on which invisible state you're in right now. Option 2: use a Hidden Markov Model, which explicitly tracks discrete states and the rules for how they change. But HMMs assume you know exactly how many states there are and assume simple math for how measurements come from states — they break down when measurements are wildly nonlinear or when you have many dimensions (many different numbers being measured at once). In a real multivariate time series with dozens of measurements, the number of possible state combinations explodes, making HMMs impossibly slow.

In one sentence. The paper uses deep learning to predict the numbers and reinforcement learning to pick hidden states, avoiding the need to predefined fixed state rules or blow up in complexity.

What the paper changes

What the paper changes

The paper changes how hidden states are estimated. Instead of using fixed mathematical rules (like HMM transition matrices), it trains a reinforcement learning agent to learn which hidden state is most likely at each moment based on the visible data it observes.

Why it works

Why it works: learning states instead of building them by hand

The core insight is that hidden states don't need to be defined upfront with fixed rules. Instead, you can train a learning algorithm to discover which hidden state makes sense at each moment. This works better because a learning algorithm adapts as it sees new data, whereas fixed rules are locked in forever and can't adjust when real patterns are more complex than you expected.

A traditional Hidden Markov Model asks you to write down the rules: 'Here are the possible states, and here are the probabilities of moving from one to another.' This works fine if the rules are simple and you know them in advance. But when measurements are wildly nonlinear (a 10-degree temperature drop doesn't lead predictably to the same next day), and when you have dozens of measurements that interact in complex ways, writing down the rules becomes impossible, and enumerating all possible combinations of states causes an explosion.

DRL-STAF sidesteps this. A deep neural network learns a flexible function that maps today's visible measurements to tomorrow's predictions (it captures the nonlinear patterns without needing to name every rule). Separately, a reinforcement learning agent learns which hidden state to assign at each time step. This RL agent sees the visible data and proposes a state. When the true next measurement arrives, the agent learns whether that state choice was good (it led to an accurate prediction) or bad (the prediction missed). Over many sequences, the agent figures out which patterns in the visible data reliably point to which hidden state.

This design avoids both problems. The deep net handles nonlinearity and complex interactions between measurements without exploding in size. The RL agent learns state logic without predefinition and without having to enumerate all combinations. The two work together because when the RL agent picks the correct hidden state, the deep net can make more accurate predictions (it knows which regime it is in), and when predictions are accurate, the RL agent knows the state choice was right and gets a clear learning signal. Both improve because accurate predictions reinforce correct state choices, and correct state choices help the network zero in on the true patterns within each state's regime.

The learning objective

First in words:

Total loss = prediction error + a penalty for picking unlikely states

Then the compact form:

L_total = E[||y_t - y_hat_t||^2] + beta * (negative reward for state choice)

Every symbol:

y_tthe actual measurement at time t
y_hat_tthe predicted measurement at time t
betaa weight controlling how much state choice matters
E[...]the average over all time steps in the training sequence
A tiny worked example
Time step 1: actual temperature 72, network predicted 71. Error = (72 - 71)^2 = 1.
RL agent chose state 'cold front'. That state later proved right (next day was cold). Reward = +2.
Time step 2: actual temperature 58, network predicted 60. Error = (58 - 60)^2 = 4.
RL agent chose state 'warm ridge'. That was wrong (kept predicting high but temps dropped). Reward = -1.
Total loss at step 1: 1 + 0.5 * (-2) = 0.
Total loss at step 2: 4 + 0.5 * (1) = 4.5.
The network and agent both improve to reduce these errors in the next training pass.

The network learns patterns that make accurate predictions; the RL agent learns which hidden state assignments lead to the best predictions, gradually discovering what each state really means.

What can go wrong

What can go wrong

Too many hidden states chosen. If the RL agent is rewarded for every high-confidence state guess, it may overfit and assign a different state to every time step, destroying interpretability. The method requires tuning how much to penalize overly confident state assignments.
Hidden states drift over time. The RL agent's learned state logic can shift as it trains, so a state that meant 'cold front' at week 1 might drift to mean something else by week 4. Sequences need to be grouped by era if the underlying process changes fundamentally.
Deep network overfits to spurious patterns. If sequences are short or noisy, the deep network may learn coincidental correlations that don't transfer to new data. Standard regularization (limiting model size, adding noise) is still needed.
Done right. With proper regularization, clear feedback signals, and consistent state semantics within each batch of sequences, DRL-STAF learns both accurate predictions and interpretable hidden states that generalize to held-out data.
What a runnable demo should prove

What a runnable demo should prove

Build a synthetic time series where you define a few hidden states yourself (e.g., 'state A' means weather is warm and stable; 'state B' means storms are approaching). Generate observations where the next value depends both on the current observation and on which hidden state is active. Then train DRL-STAF on this data. After training, show that: (1) the network's predictions are accurate on a held-out test set, and (2) the RL agent has learned to assign the correct hidden states to sequences, recovering the true states you planted. Compare against a baseline that ignores states and a baseline that uses a fixed HMM.

Prediction MSE = mean((predicted - actual)^2), State recovery accuracy = (# correct state assignments) / (total time steps)

If DRL-STAF works, it will predict as accurately as any deep model AND recover the hidden states you defined, something neither pure deep learning nor fixed HMMs can do together.
