Matrix multiplication

Transform one list of numbers into a different one using a table of numbers.

In plain terms

Imagine you have a recipe with five ingredients and you want to know how much of each output dish you can make. The recipe is a table: each row is an output dish, each column is an input ingredient, and each cell tells you how much of that ingredient goes into that dish. To make one batch of output, you take your ingredient amounts, look at the recipe, multiply each ingredient by what the recipe says, add them up, and get one output dish amount. Matrix multiplication is exactly this: you have a table of rules (the matrix) and a list of ingredient amounts (the vector), and you produce a new list of output amounts.

The problem matrix multiplication solves is about scaling and combining information. In machine learning, data moves through layers of a neural network—each layer transforms the data using learned rules. A photo becomes numbers, those numbers get transformed into different numbers by the first layer (which is a big table of learned rules), then transformed again by the next layer, and so on. Each layer is a table multiplied by the current data. Without matrix multiplication, you cannot build deep networks or large models. Without it, you cannot train models efficiently on GPUs (graphics processors that excel at doing many multiplications at once). Every modern AI system relies on matrix multiplication as its core operation because neural networks are built from it.

The formula captures one row of the output. You have a table (call it W—the weights or rules), you have a list of input numbers (call it x—the data), and you produce one number in the output (call it the i-th output). To get that number, you take the i-th row of the table, multiply each entry by the corresponding input number, then add all those products together. Do this for every row of the table and you get the full output list. The reason this operation shows up everywhere is that multiplying and adding is the fastest operation computers can do—you can multiply millions of numbers in parallel, which is why GPUs accelerate matrix multiplication to speeds that make deep learning feasible.

The equation
(Wx)_i=\sum_j W_{ij} x_j
WA table of numbers (called a matrix)—the rules or learned parameters that transform input into output.
xA list of input numbers (called a vector)—the data being transformed.
(Wx)_iOne number in the output list—specifically, the i-th entry after multiplying the table by the input.
W_{ij}One entry in the table—the rule at row i, column j that connects input j to output i.
x_jOne input number—specifically, the j-th entry in the input list.
\sum_jSum over all columns j—add up all the products W_{ij} * x_j for every column.
Worked example
Recipe with two ingredients, three dishes
Recipe (table W): Dish 1 needs 2 units of A + 3 units of B. Dish 2: 1 unit A + 4 units B.
Ingredients (x): We have 5 units of A, 2 units of B.
Dish 1 output: 2×5 + 3×2 = 10 + 6 = 16 units.
Dish 2 output: 1×5 + 4×2 = 5 + 8 = 13 units.
Result: [16, 13]—two outputs from two inputs using the recipe table.
Why it shows up

Matrix multiplication appears in 35 papers across the corpus because it is the fundamental operation of neural networks. Every time a model transforms data through a layer, it multiplies a weight matrix by the input vector. Transformer models (the architecture behind modern language models) build attention mechanisms (systems that let the model focus on relevant data) out of matrix multiplications. Diffusion models use matrix multiplications to apply learned noise patterns. Graph neural networks multiply adjacency tables (which encode how nodes connect) by node features. Efficient systems papers focus on speeding up matrix multiplication through low-rank approximations, quantization (storing numbers with fewer bits), or sparse patterns (skipping zero entries). Linear algebra methods like SVD (singular value decomposition) exploit matrix structure to compress models. Every theme in this corpus—from efficiency optimization to representation learning—depends on matrix multiplication as the irreducible unit of computation.

The reason matrix multiplication dominates machine learning is algorithmic inevitability. A layer in a neural network must compute outputs from inputs using learned parameters (the numbers the model adjusts during training). Linear algebra guarantees that the most general, learnable way to do this is matrix multiplication: one output equals a weighted sum of all inputs. Once you scale beyond a few parameters to billions, the only way to train fast enough is parallel hardware (GPUs, TPUs) that specializes in matrix operations. This creates a virtuous cycle: matrix multiplication is the bottleneck, so hardware optimizes for it, so models are built to use it more, so it becomes more optimized. Understanding matrix multiplication is understanding the foundation of modern AI.
