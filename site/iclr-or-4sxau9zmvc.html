JAPAN: Density-based Conformal Prediction with Normalizing Flows

Build prediction sets by learning the true shape of the distribution instead of assuming it is a box centered at the mean.

Paper explainersAll themesLearning Theory

When you ask a model to predict, you need to know not just the answer but how confident it is. Conformal prediction is a way to build sets of possible answers that are guaranteed to contain the right one a certain fraction of the time. But most methods assume the set is shaped like a box or circle centered at what the model thinks the answer is, which wastes space when the true answer likes to cluster in weird shapes. JAPAN learns the actual shape using flow-based models, so the sets are tight and can even split into multiple disconnected islands when that fits the data better, because it thresholds the learned probability hills instead of enforcing a rigid geometric rule.

Zero assumption version

Prediction sets waste space when they follow rigid rules

Conformal prediction starts with a problem: how do you tell a person not just that a model predicts a value, but that the right answer almost certainly lies within a range. The guarantee is formal and holds no matter what the data looks like.

Existing methods compute a score for each training example (usually how far off the model was), then set the boundary so that roughly 90% of training points fall inside. But they pick boundaries using simple rules: a fixed distance from the predicted point, like a circle or a box. This works if answers cluster in a ball-shaped blob around the mean. It fails badly when the distribution has two separate clumps (multimodal), or a ring shape, or any unusual form.

The method in one sentence. JAPAN replaces distance-based boundaries with learned-density-based boundaries so the prediction set naturally stretches and shrinks to fit whatever shape the data actually has.

The algorithm as a flow

What it actually does

Split the data

Divide examples into train and calibration (held-out to measure the method).

Learn the conditional distribution shape

Train a normalizing flow (a flexible neural model that learns to describe shapes) on training pairs to estimate the probability density of outputs given inputs.

Score each calibration point

For each held-out example, ask the flow: how likely is the true answer under this learned distribution?

Find the threshold

Sort those scores and pick a cutoff so the 90th percentile of training outputs fall above it.

Build the set

For a new input, include all possible outputs where the learned density exceeds that threshold. This forms the prediction set.

What the paper changes

What the method changes: the conformity score

Old methods use residuals (how far off the model was) to score points. JAPAN replaces that with the log-density under the learned distribution. Instead of asking how far is the point from the mean, it asks: how probable is this point given the distribution I just learned from the training data.

the object it moves  =  Conformity score (density-based instead of residual-based)
The hidden quantity

The hidden quantity: Predictive density at the true answer

measured quantity  =  log-density of the true output under the learned conditional distribution

The paper estimates the (conditional) density at each point — the height of the probability hill at that location. High density means it is a likely output; low density means the flow model thinks it is rare.

The flow estimates this by learning a reversible neural transformation that maps the output space into a simple standard normal distribution (like a bell curve). Wherever the map says the output is rare, it assigns low density. JAPAN uses the log-density (the logarithm of this probability) as the conformity score so that scoring differences matter equally whether densities are high or low.

Why it works

Why it works: density shapes match the data

The core reason JAPAN is tighter than distance-based methods is that it learns the actual shape of the distribution instead of guessing it. A normalizing flow is a neural function that is reversible (invertible) and can be written as a chain of simple maps, each with a known formula for how it stretches space. This means the flow can describe any smooth shape of distribution, including multiple clumps, rings, or elongated clouds.

When you threshold on learned density, you automatically get regions that hug the high-probability areas and exclude the low-probability gaps. If the true outputs cluster in two islands, the flow learns two separate hills. Thresholding at a fixed height cuts away both the peaks and the flat desert between them, leaving two islands. A box or circle cannot do this — it must cover the space between the islands too.

The finite-sample coverage guarantee (90% of new test points will fall inside the set) still holds because the threshold is set using the calibration set, which is mathematically independent of the flow training. The flow can overfit or underfit; the calibration step will still ensure that the frequency of containment matches the target.

Math after the picture

The equation: thresholding the learned density

First in words:

The prediction set includes all outputs y such that the log-density under the learned flow is greater than or equal to the threshold. The threshold is chosen so the measured proportion of calibration examples inside the set is at least 1 minus the target error rate.

Then the compact form:

Gamma_epsilon(x) = { y : log p-hat(y | x) >= tau_epsilon }

Every symbol:

Gamma_epsilon(x)The prediction set for input x at error level epsilon
log p-hat(y | x)The learned log-density: how probable output y is given input x, according to the trained normalizing flow
tau_epsilonThe threshold, chosen so that the frequency of containment on calibration examples is at least 1 - epsilon
epsilonThe target error rate, e.g. 0.1 for 90% coverage
A tiny worked example
Suppose we train a flow on 100 examples and calibrate on 20 held-out points.
The flow assigns log-densities: [2.1, 1.8, 2.3, 1.2, 2.0, 0.5, 1.9, 2.2, 1.1, 2.4, 1.5, 2.1, 0.8, 2.0, 1.7, 2.2, 1.3, 1.9, 2.0, 1.6].
Sorting: [2.4, 2.3, 2.2, 2.2, 2.1, 2.1, 2.0, 2.0, 2.0, 1.9, 1.9, 1.8, 1.7, 1.6, 1.5, 1.3, 1.2, 1.1, 0.8, 0.5].
For epsilon = 0.1 (90% coverage), we want at least 18 out of 20 inside. The 18th highest score is 1.8.
Set tau_epsilon = 1.8. For a new input, include all outputs y where log p-hat(y | x) >= 1.8.
This forms the prediction set, which will contain the right answer roughly 90% of the time on new data.

The threshold tau divides high-probability regions (included in the set) from low-probability regions (excluded). The learned density does the work of adapting the shape; the threshold just picks the volume.

What can go wrong

What can go wrong

Flow overfits to training data. If the flow memorizes noise in the training data instead of learning the true distribution, it will assign high density to fluky outliers. The threshold will then include too much space. Fix: use holdout calibration, which catches this overfitting (the set will be too large on calibration points, forcing a higher threshold).
Flow underfits and misses the shape. If the flow is too simple (few layers, small hidden dimension) it cannot learn complex distributions with many clumps or ringed shapes. The learned density will be a blob instead of multiple peaks. Fix: use a larger or more expressive flow model; the paper tests continuous normalizing flows and flow-matching variants.
Calibration set is too small. If you hold out very few examples for calibration, the threshold estimate is noisy. You may set tau too high or too low, missing the coverage target. Fix: use a reasonable calibration fraction (e.g., the paper uses roughly 20% held-out).
Multimodal distribution with very different peak heights. If the data has one huge peak and one tiny peak, and you set a threshold midway, you might include a lot of empty space around the small peak. The set gets bigger. Fix: the paper addresses this by using adaptive thresholds (different tau per context or region); density-based methods naturally handle this better than rigid geometric constraints.
Done right: density learning + calibration thresholding. Train the flow carefully on the full training set, hold out calibration examples, compute their scores, and set the threshold by looking at the actual data. This guarantees coverage regardless of whether the flow is perfect, because the calibration step is independent of flow quality.
What a runnable demo should prove

What a runnable demo should prove

Build a toy regression task where outputs cluster in two separate regions (e.g., a function that outputs 2 or 8 depending on the input, plus noise). Train a standard regression model (e.g., linear or shallow neural net) so it predicts the average output (around 5). Implement both old conformal prediction (residual-based, using a fixed distance radius) and JAPAN (train a normalizing flow to estimate output density, then threshold it). Generate 200 test points. For each, compute the prediction set and check if it contains the true output. Plot the prediction sets: the old method should show fat circles around 5; JAPAN should show two tight islands at 2 and 8. Measure coverage (fraction of test points inside) and average set size. The demo makes it impossible to miss that JAPAN's sets are smaller while keeping coverage, because thresholding the learned density naturally carves out high-probability regions while excluding the low-probability gap in the middle.

Coverage = (count of test points where true answer is inside set) / (total test points). Average set size = sum of (upper bound - lower bound) for each test set / number of test points. Tightness = average set size; lower is better.

JAPAN is visibly tighter, splits into islands, and keeps coverage. A residual-based method stays conservative (large sets) to ensure coverage.
