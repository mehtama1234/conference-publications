Dual-Scale World Models for LLM Agents in Hard-Exploration Problems

An LLM agent learns to explore text-based games by remembering good discoveries globally while trying variations locally, using progress signals to guide what to try next.

Paper explainersAll themesAgents & Tool Use

LLM-based agents (language models that interact with environments to accomplish goals) struggle in hard-exploration tasks where they must discover and learn new knowledge through trial-and-error. This paper introduces GLoW, which solves this by maintaining two memory systems: one that tracks high-value discoveries across many attempts, and another that learns from immediate local experiments. The agent uses progress signals to decide what to explore next.

Zero assumption version

LLM agents get stuck in exploration

An LLM agent working in a text-based game where you move through rooms, pick up objects, and talk to characters faces a hard choice: it must discover the right sequence of actions to reach a goal it has never seen before. It cannot memorize the answer because each game is new. The naive approach is to try actions at random and learn from what happens. But text-based games have enormous possible states: hundreds of rooms, objects, and NPCs that can be combined in many ways. Random tries are too slow. In the Jericho benchmark (a standard test suite of text-based games), an LLM agent needs thousands of environment interactions to find winning paths that a good reinforcement-learning method finds with hundreds.

The core stuck-point: the agent explores locally (trying one thing, observing, trying another nearby thing) and forgets the big picture. It re-tries paths it has already learned are dead ends. It does not accumulate and rank highly its best discoveries. An ordinary LLM, even one trained on text of past games, comes with knowledge frozen from its training data and cannot adjust that knowledge to new game mechanics it has never encountered.

The method. Keep a memory of the best things discovered across all past attempts, and use a progress signal to decide which local areas to explore next.

The algorithm as a flow

What it actually does

Maintain global frontier

Store the best game states and paths ever discovered across all exploration runs.

Local multi-path exploration

From the current state, generate multiple possible next actions and try them in parallel.

Measure progress

For each attempted path, score how close it moves to the goal (or a high-value state).

Reflect on advantage

Compare each path's progress to the average progress in this region; high-advantage paths are worth repeating.

Refocus exploration

Feed advantage signals back to the LLM to steer the next attempts toward high-progress regions.

What the paper changes

The one thing the paper changes

Most LLM agents treat exploration as a simple loop: generate an action, observe the result, repeat. GLoW changes the memory system: instead of forgetting each attempt, it accumulates and rank highlys high-value discoveries. It also changes the signal the agent uses to decide what to try next: not random, but advantage-based (paths that make unexpected progress in their region).

the object it moves  =  Exploration memory and progress signals
The hidden quantity

The hidden quantity: Advantage-based progress

measured quantity  =  Regional advantage score

The hidden quantity is a progress signal the paper infers: for each attempted path, the score measures how much closer that path moves to the goal compared to the typical progress in that same region of the game state space. An action that reaches a state worth 8 points when the region averages 5 points has high advantage; an action that reaches 6 points in a region that averages 5 is low advantage. The agent cannot see advantage directly; it must infer it from the rewards (goal closeness) it has collected.

GLoW estimates this regional advantage by grouping past attempts by which part of the game they explored, computing the average outcome in each part, and then scoring new attempts as beats vs. that baseline. High-advantage paths are marked and rank highlyd, so the agent tries variations of them next.

Why it works

Why it works: global anchor plus local refinement

The mechanism has two layers. First, the global frontier (a list of the best states and paths found so far) gives the agent a permanent map of winning regions. When local exploration gets stuck, the frontier serves as a reachable target: the agent can always regenerate a path back to a known-good state, then branch off in new directions. This prevents the catastrophic forgetting that plagues naive LLM exploration.

Second, the advantage signals tell the agent which directions to branch. Without them, the agent would explore uniformly at random or follow its initial training knowledge (which knows nothing about this new game). With advantage signals, the agent learns: paths that outperform their local baseline indicate direction toward the goal, because in a well-designed game, progress compounds—a path that reaches farther into the game world than nearby attempts has likely discovered new connections, items, or knowledge that unlock more of the game. By repeating and varying high-advantage paths, the agent builds on these discoveries rather than re-trying stale directions. This focuses the search on high-signal regions. The combination—global reachable anchors plus locally-guided variation—reduces the number of trials needed because the agent never fully re-explores dead regions and always has a fallback to known progress.

Math after the picture

The equation: weighted exploration

First in words:

Advantage is the observed reward minus the regional median reward. Paths with high advantage get resampled more often.

Then the compact form:

advantage_t = return_t - median_return(region(s_t))

Every symbol:

return_tcumulative reward for the path taken at step t
region(s_t)the cluster of past game states most similar to the current state s_t
median_return(region)the typical return value for paths in that cluster
A tiny worked example
Region A (early dungeon) has visited 10 paths with returns: 2, 2, 3, 3, 3, 4, 4, 5, 5, 6. Median is 3.5.
New path in region A reaches return 5. Advantage = 5 - 3.5 = 1.5 (above average; explore similar moves).
Another new path in region A reaches return 2. Advantage = 2 - 3.5 = -1.5 (below average; do not resample).
The high-advantage path is flagged and used to seed the next batch of LLM generations.

High advantage means the agent discovered something better than typical in this region, so it refocuses search on that direction.

What can go wrong

What can go wrong

Regional clustering fails when state representation is noisy. If the agent cannot clearly identify which part of the game it is in, it will group unrelated paths together. The median return becomes meaningless, and advantage signals point in wrong directions.
Global frontier becomes a trap. If the highest-value states in the frontier are all local maxima (dead ends with high immediate reward but no path to the goal), the agent will keep returning to them and never explore genuinely winning paths.
Advantage reflection is expensive. Computing advantage requires clustering past paths and computing medians; if the agent accumulates thousands of trajectories, this overhead can exceed the savings from focused exploration.
Done right: learn what regions matter. If the state representation clearly separates game regions and the frontier stores reachable waypoints (not traps), advantage signals will steer exploration toward unexplored, high-promise branches that lead to the goal.
What a runnable demo should prove

What a runnable demo should prove

Build a small text-based game with 5 rooms and a hidden goal. Implement three agents: (1) a baseline LLM that acts by sampling random actions, (2) an LLM with only the global frontier, and (3) GLoW with both frontier and advantage signals. Run each agent for a fixed budget of 100 environment interactions. Measure the number of times each agent reaches the goal and the average number of moves taken when it does.

Success rate = wins / 100 trials; Efficiency = average moves when winning

The demo must show that GLoW wins more often and in fewer moves than the baseline and the frontier-only variant, proving that advantage signals focus exploration.
