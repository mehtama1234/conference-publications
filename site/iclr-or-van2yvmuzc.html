StPR: Spatiotemporal Preservation and Routing for Exemplar-Free Video Class-Incremental Learning

StPR learns new video action classes over time without storing old examples by preserving stable frame-level semantics and routing time patterns through specialized experts.

Paper explainersAll themesOther

Video class-incremental learning asks a model to learn new action categories one stage at a time without forgetting older ones. That is harder for video than for still images because the model must preserve both frame-level meaning and the way motion unfolds across time. This paper proposes StPR, an exemplar-free method that avoids storing old videos. It preserves stable frame semantics through selective distillation and routes different motion patterns through specialized experts, so the model can add new classes while keeping previously learned knowledge because old frame meaning is protected while new motion patterns get their own processing paths.

Zero assumption version

Continual video learning forgets both appearance and motion

In class-incremental learning, new classes arrive in stages. After learning the next stage, the model should still recognize classes learned earlier. Many methods fight forgetting by storing old examples and replaying them during training, but that consumes memory and can create privacy problems.

Video adds another layer of difficulty. The model must remember not only what a frame contains, but also how the action changes over time. A method copied from image learning may preserve frame appearance while still forgetting the motion pattern that distinguishes one action from another.

The hard part. A video learner must preserve stable frame semantics and temporal structure at the same time, without replaying old videos.

The algorithm as a flow

What it actually does

Detect stable frame semantics

Identify the channels whose frame-level meaning remains important for earlier classes.

Preserve them during new-stage training

Use selective distillation so those important channels do not drift too far when new classes are learned.

Decompose motion patterns

Split temporal behavior into components that can be handled by different experts.

Route videos through temporal experts

Let a routing module choose which experts should process the current video's motion pattern.

Predict without task IDs or replay

At test time, the system recognizes all learned classes directly, without needing stored old examples or stage labels.

What the paper changes

What the paper changes

The paper changes what gets preserved during continual learning. Instead of trying to freeze whole model blocks, it preserves only the frame-semantics channels that matter most and lets specialized temporal experts handle changing motion patterns.

The hidden quantity

The hidden quantity: stable semantic channels

measured quantity  =  which channels carry reusable frame meaning across learning stages

Not every internal channel is equally important for retaining old knowledge. Some channels carry stable frame semantics that remain useful even when new classes arrive. Others can change more freely. StPR tries to find the stable set so it can preserve what truly matters instead of overconstraining the whole model.

The paper estimates this hidden set by combining channel sensitivity with class contribution. If changing a channel strongly harms earlier predictions and that channel contributes a lot to earlier classes, it should be preserved. This selective preservation helps because it protects old knowledge while still leaving room for adaptation.

Why it works

Why selective preservation plus temporal routing reduces forgetting

The first part of StPR protects earlier knowledge where it is most concentrated. Instead of freezing broad parts of the model, it preserves the channels that still matter for earlier classes. That is more flexible because unimportant channels remain free to adapt to new classes.

The second part handles time structure explicitly. Different actions share frame content yet differ in how motion evolves. By routing temporal patterns through specialized experts, the model can represent several kinds of motion behavior without forcing one shared pathway to absorb everything. This reduces interference between old and new actions because different temporal structures can use different experts.

Together, these two pieces solve complementary problems. Selective preservation keeps old frame semantics alive, and temporal routing gives the model enough specialized motion capacity to learn new actions without overwriting the old ones.

Math after the picture

The preservation score equation

First in words:

Give each channel a preservation score by combining how sensitive old predictions are to that channel with how much that channel contributes to old classes.

Then the compact form:

preserve_score(c) = sensitivity(c) * contribution(c)

Every symbol:

preserve_score(c)importance of preserving channel c
sensitivity(c)how much earlier predictions change when channel c changes
contribution(c)how strongly channel c supports earlier classes
A tiny worked example
Suppose channel 5 changes older predictions a lot, so sensitivity = 0.8.
Suppose channel 5 also contributes strongly to earlier classes, so contribution = 0.9.
Then preserve_score(channel 5) = 0.8 * 0.9 = 0.72.
A channel with sensitivity 0.2 and contribution 0.3 would get 0.06 and would be much less protected.
This selective rule helps because it preserves what matters most while leaving low-value channels free to adapt.

The exact paper machinery is richer, but the central idea is to preserve channels only when they are both important and vulnerable.

What can go wrong

What can go wrong

Wrong channels preserved. If the channel-selection signal is noisy, the method may protect the wrong channels and leave truly important old knowledge exposed.
Routing collapses to a few experts. If most videos are sent through the same temporal experts, the model loses specialization and interference can return.
Large domain shift in video style. If later stages look very different from earlier ones, preserving old semantics becomes harder because even high-value channels may need strong adaptation.
Done right. When stable channels are identified well and routing remains diverse, StPR reduces forgetting because it protects earlier frame meaning while giving new motion patterns their own processing paths.
