Triangle Multiplication is All You Need for Biomolecular Structure Representations

Strip out expensive triangle attention from protein-folding models, replace it with simple pair mixing, and run 4x faster while keeping the same accuracy.

Paper explainersAll themesAI for Science

AlphaFold-style models predict how proteins fold by reasoning about relationships between every pair of amino acids. But they use a computationally expensive operation called triangle attention (the model tries to understand each pair by looking at all other pairs, repeatedly, which is very slow). Pairmixer replaces this expensive step with a direct blend of pair signals (a fast row-column mixing operation), preserving the model's ability to understand 3D shape while cutting runtime in half and training cost by a third.

Zero assumption version

Protein folding is slow when it needs to run at scale

AlphaFold-style models predict 3D protein structures by building up a representation of how each pair of amino acids relates to each other. They start with simple guesses about relationships, then refine these guesses by asking: for each pair, how does it connect through all the other pairs? This is a form of attention (the model looks at many things and decides which matter most).

The problem: triangle attention requires many expensive lookups (one for each amino acid, for each layer, for each refinement pass). On a protein with 1000 amino acids running through 48 layers, this is thousands of separate comparisons. For large-scale applications—folding entire protein complexes, screening millions of drug candidates, designing new proteins—this computational burden becomes prohibitive.

The bottleneck. Triangle attention is fast for small proteins but becomes prohibitively slow for large proteins or high-throughput screening.

The algorithm as a flow

What it actually does

Input: pair representation

Start with a table of relationship values between all amino acid pairs.

Triangle multiplication

Blend all pair signals together in one operation to mix each pair's influence through all others.

Add sequence bias

Optionally bias the result by sequence-level features for extra context.

Feed-forward refine

Pass each updated pair value through a small neural network to compress/sharpen.

Repeat

Stack 48 of these layers. Diffusion module then converts final pair values into 3D atoms.

What the paper changes

What changed: replace triangle attention with pair blending

The paper removes triangle attention (expensive look-up) and replaces it with triangle multiplication (fast blending operation). Both operate on the same pair representation (the table of amino acid relationship values), but the computation is fundamentally different: attention requires comparing every pair separately, while multiplication blends all pairs at once.

The hidden quantity

The hidden quantity: computational cost per layer

measured quantity  =  Attention operations per layer

Triangle attention's cost grows with the number of amino acids. For each row in the pair table, it runs a full attention operation (comparing each position to all others). That is many separate lookups per layer. Triangle multiplication, by contrast, performs one blending operation regardless of how many amino acids there are.

The paper does not explicitly report a computational cost score, but it measures the proxy via training time (GPU-days on the RCSB dataset) and inference time (milliseconds on long sequences). Faster runtime shows fewer separate lookups per forward pass, because one blend step replaces many attention steps.

Why it works

Why it works: blending preserves pairwise reasoning

Both triangle attention and triangle multiplication are ways to mix information across the pair representation. Triangle attention explicitly looks at each pair and asks: which other pairs matter most? Triangle multiplication implicitly answers this by blending all pairs together at once: each output pair is a weighted blend of all input pairs (the weights are learned by training). The blended result carries the same relevant information, just computed differently.

Why the swap works: the diffusion module (the part that turns pair values into 3D atoms) does not care how the pair values were computed, only that they are accurate. Blending produces equally accurate pair values, just faster. The model can still express fine-grained constraints between amino acid triplets, because blending can learn any linear combination of input pairs (enough to encode spatial relationships).

Why it is faster: attention requires many individual lookups (one for each amino acid, for each pair, per layer), and each lookup itself is a comparison step. Blending does all that mixing in one fast operation on modern hardware, because processors are built to do a single pass over data quickly. Many separate lookups stall the processor; one blend keeps it busy doing useful work throughout.

Math after the picture

The equation: triangle multiplication as a blending operation

First in words:

For each layer, the pair representation is updated by multiplying the pair matrix by itself and optionally adding a bias from sequence features, then passing each pair through a feed-forward network.

Then the compact form:

z_new = FFN(z @ z.T + alpha * s @ s.T)

Every symbol:

zthe pair representation (L rows, L columns, C values per cell)
z @ z.Tmatrix multiply: pair times pair transpose
ssequence feature vector (L elements, one per amino acid)
s @ s.Toptional bias from sequence similarities
alphastrength of sequence bias (hyperparameter)
FFNfeed-forward network applied to each updated pair value
A tiny worked example
Suppose z (pair matrix) is 3x3: [[2,1,3], [1,4,2], [3,2,1]].
Multiply z @ z.T: first row of output = 2*2 + 1*1 + 3*3 = 4+1+9 = 14. Second row = 1*2 + 4*1 + 2*3 = 2+4+6 = 12. Third row = 3*2 + 2*1 + 1*3 = 6+2+3 = 11.
Result: [[14, ?, ?], [12, ?, ?], [11, ?, ?]] (simplified). Each cell now mixes all pairs through the matrix multiply. Then FFN sharpens each value.

Matrix multiplication is faster than attention because modern hardware optimizes it as one bulk operation, whereas attention requires L separate comparisons.

What can go wrong

What can go wrong

Sequence bias is optional but fragile. If the alpha (sequence bias strength) is set too high, the model over-trusts sequence similarity and misses spatial constraints encoded only in pairs.
Triple interactions are implicit, not explicit. Blending mixes pairs globally, but the original triangle attention was designed to reason explicitly over triples (amino acid triplets). If a benchmark requires fine-grained triple reasoning, Pairmixer might underperform.
Other parts of the model still use attention. Pairmixer only replaces the backbone layer; other parts (which convert pairs to 3D atoms) still use expensive lookups. Speed gains come only from the backbone.
Done right. Pairmixer works well when pair reasoning is sufficient (most structure prediction tasks). Train carefully on each domain (AlphaFold databases, ligand docking, de novo design) to tune alpha and layer counts for your task.
