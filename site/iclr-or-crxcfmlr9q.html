Triangle Multiplication is All You Need for Biomolecular Structure Representations

Pairmixer replaces expensive triangle attention with a simpler method that reasons about protein-atom pairs as fast, letting protein designers work at scale.

Paper explainersAll themesAI for Science

Protein structure prediction models like AlphaFold are slow at massive scale. When scientists want to screen millions of drug candidates or design new proteins, the model becomes the bottleneck. Pairmixer removes the expensive part of the calculation—triangle attention—and replaces it with an equally smart but much faster method for understanding which atoms should interact, making large-scale protein engineering finally practical. It works because the reasoning about atom interactions is mostly local and can be done in a single fast step instead of three slow ones.

Zero assumption version

Expensive reasoning about which atoms touch

Protein structure prediction models reason about pairwise distances: which atoms are close to each other, and how do they constrain each other's position? The standard way to do this—triangle attention—is a three-step dance: look at each pair of atoms, look at their neighbors, combine the information.

A naive attempt: just ask the model directly "which atoms should be nearby?" Works, but misses the spatial relationships. When you have millions of atoms across many proteins, triangle attention becomes a time and memory wall. Training takes weeks. Prediction (when the finished model runs on a new protein) takes minutes. Drug screening, impossible at scale.

The bottleneck. Pairmixer removes triangle attention and reasons about atom pairs in a single, efficient sweep.

The algorithm as a flow

What it actually does

Input atoms and distances

The model reads a protein: atoms, their rough positions, and residue names.

Pair-wise reasoning

For each atom pair, compute a feature vector (a list of numbers) capturing how they interact.

Single efficient sweep

Apply one transformation to all pairs at once, instead of iterating three times like triangle attention.

Collect geometric context

Each pair's feature vector now includes hints from nearby atoms, learned to preserve 3D geometric logic.

Predict structure

Use the enriched pair features to predict final 3D positions of all atoms.

What the paper changes

The thing that changes

The paper replaces triangle attention—a three-step pairwise reasoning procedure—with a single-pass method that computes pair features efficiently. The geometric information (how atoms constrain each other in 3D space) is still learned, but extracted differently.

The hidden quantity

Pairwise geometric importance

measured quantity  =  Pairwise geometric importance

Pairwise geometric importance is the degree to which knowing one atom's position constrains another atom's position in 3D space. In AlphaFold, this is computed implicitly through triangle attention: by checking how each pair relates to its neighbors. Pairmixer estimates the same quantity but in a single calculation instead of three.

The paper measures this indirectly by checking whether the final predicted structure matches known structures (the benchmark accuracy). If Pairmixer preserves structure quality while cutting computation, the hidden geometric importance is still being captured.

Pairmixer computes pair embeddings (feature vectors for each atom pair) that implicitly encode higher-order geometric reasoning via a learned linear transformation, achieving the same information flow as triangle attention but in quadratic time (pairs of atoms) instead of cubic time (three-way checks).
Why it works

Why it works: from three sweeps to one

Triangle attention works by three passes: first, attend within atom pairs; second, update based on triangles (three atoms at a time); third, integrate the result. Each pass is expensive when you have tens of thousands of atoms.

Pairmixer compresses this into a single matrix operation: a learned linear transformation (a set of weights) applied to all pairs at once. The trick is that the weights are learned from data to capture the same geometric patterns that triangle attention would discover through three passes. The model learns: which neighboring atoms matter most? How should a pair's feature vector change based on nearby pairs?

This works because geometric logic in proteins is mostly local: atom A constrains atom B, and atom B constrains atom C, so atom A indirectly constrains atom C. A single well-designed linear step can propagate these constraints efficiently. The three-pass pyramid was overkill.

The pair transformation

First in words:

new_pair_features = learned_weights * old_pair_features + bias

Then the compact form:

p'_{i,j} = W * p_{i,j} + b

Every symbol:

p_{i,j}feature vector for the pair of atoms i and j (input)
Wlearned weights that encode geometric reasoning
bbias vector added to every pair
p'_{i,j}new enriched feature vector for the pair (output)
A tiny worked example
Suppose atoms (1,2) have a raw feature vector p = [1.0, 0.5, 2.0].
The learned weight matrix W is [[2.0, 0.1, 0.3], [0.2, 1.5, 0.4], [0.5, 0.2, 1.2]]. Bias b = [0.1, 0.1, 0.1].
p' = W * p + b = [[2.0*1.0 + 0.1*0.5 + 0.3*2.0], [0.2*1.0 + 1.5*0.5 + 0.4*2.0], [0.5*1.0 + 0.2*0.5 + 1.2*2.0]] + [0.1, 0.1, 0.1]
p' = [[2.0 + 0.05 + 0.6], [0.2 + 0.75 + 0.8], [0.5 + 0.1 + 2.4]] + [0.1, 0.1, 0.1] = [2.75, 1.85, 3.1]
This single multiplication replaces three cascading attention passes and runs instantly on all atom pairs simultaneously.

One matrix multiply per pair, applied to all N squared pairs at once, replaces three nested loops—this is why Pairmixer is 4x faster.

What can go wrong

What can go wrong

Losing geometric subtlety. If the learned weights W do not capture all the three-way geometric constraints that triangle attention finds, the model might miss subtle atom-atom conflicts. A poorly trained Pairmixer could predict atoms too close together. Fix: use real structures (labeled data) during training so the weights learn the true geometric patterns.
Scaling to very long sequences. Even though Pairmixer is quadratic in atoms, proteins can be thousands of atoms long, so the number of pairs grows to millions. Memory still becomes a problem. Fix: use sparse attention or chunking—process small sections of the protein at a time and stitch them together.
Overfitting the training set. A single-pass model might fit training structures perfectly but fail on new proteins with unusual geometries. Fix: use strong regularization (gently steer the weights) and diversify the training set with structures from many organisms and conditions.
Done right. When Pairmixer is trained on diverse high-quality structures and validated on held-out folds, it generalizes as well as triangle attention because the model learns to capture the same geometric patterns in a single pass, and runs orders of magnitude faster because one matrix multiply beats three cascading attention passes.
What a runnable demo should prove

What a runnable demo should prove

Build a small protein (50 atoms) with a known 3D structure from the Protein Data Bank (a public database of real protein structures). Train a tiny Pairmixer model (one pair-transformation layer) on a dataset of 1,000 similar small proteins. Then use the trained model to predict the 3D coordinates of the test protein (one you held out during training) and measure how close the prediction is to the real structure.

RMSD = square root of (mean squared distance between predicted atoms and true atoms in angstroms); lower is better; RMSD < 2 angstroms means accurate prediction

The demo should show that a single-pass Pairmixer predicts the test structure within 2 angstroms of ground truth, proving that the geometric reasoning survived the simplification. It should also measure wall-clock time to confirm that the speedup is real—one pass is faster because there are fewer operations to run.
