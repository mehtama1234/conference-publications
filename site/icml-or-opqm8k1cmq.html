Breaking Information Self-Locking in LLM Agent Reasoning

When LLM agents learn by trial and error to solve reasoning tasks, they get stuck because weak evidence-gathering starves belief updates and weak belief updates hide why evidence matters—until you reallocate credit directly within trajectories.

Paper explainersAll themesAgents & Tool Use

LLM-based agents learn to act and reason by trying things, getting results, and adjusting. But in active reasoning—where agents must ask questions or gather new information to solve a task—standard outcome-based reward learning fails catastrophically. Agents neither learn to gather useful information nor learn from the information they find. This paper identifies the root cause: two learning problems feed each other in a vicious cycle that locks the agent's mind shut.

Zero assumption version

The trap: two broken capabilities feed each other

Consider an agent trying to figure out a hidden fact—say, whether a person likes coffee. The agent can ask questions and watch the person's reactions. Outcome-based reward learning (the standard approach) says: if your final guess was right, every action that led to it gets credit. If you guessed wrong, every action shares the blame.

This breaks down when the agent must actively gather evidence. Here is why: the agent has two jobs. First, action selection—deciding which questions to ask (does the person wake early? do they have coffee stains on their shirt?). Second, belief tracking—updating what it thinks based on answers (the person said they hate mornings, so they probably skip coffee). Standard reward learning gives credit only for the final outcome. A weak belief-tracker does not learn from evidence well, so the reward signal does not show that certain questions were actually valuable. Meanwhile, weak action selection sends chaotic signals to belief tracking—sometimes smart observations, sometimes noise. Each capability starves the other of a usable learning signal. The agent ends up asking random questions and forgetting what it learned, cycle after cycle.

The trap in one sentence. When outcome-based reward is too coarse to show that gathering evidence matters, agents stop gathering evidence and stop learning from it.

What the paper changes

What the paper changes

Standard outcome-based learning spreads credit from the final outcome backward equally to every action. This paper changes that by using directional critiques—easy-to-get labels that say whether each belief step moved toward or away from the truth—to reallocate credit unevenly within a single trajectory. Steps that move the right way get boosted; steps that move the wrong way get reduced.

the object it moves  =  credit allocation inside trajectories
The hidden quantity

The hidden quantity: directional signal

measured quantity  =  direction agreement

At each step in an agent's reasoning, the agent updates its belief about the hidden fact. The question is: does this update move the agent's estimate toward the true answer? That yes-or-no signal is the directional agreement. It is not the final outcome (which comes at the end); it is a step-by-step signal that says whether the agent is on the right track.

The paper uses these directional signals to fix credit allocation. If an action led to a belief update that agreed with the true direction, that action shaped a good step and earns higher credit. If the belief update moved away from the truth, the action's credit drops. Without directional signals, the agent only sees whether the final guess was right or wrong—too coarse to learn which questions mattered.

Why it works

Why reallocating credit unblocks both loops

The paper identifies a bidirectional bottleneck. Action selection (choosing good questions) suffers because belief tracking is weak and does not clearly learn from evidence. Belief tracking (learning from observations) suffers because action selection sends chaotic questions. Standard outcome-only learning cannot separate these: it gives credit for any action in a successful trajectory, even useless questions that happened to precede a lucky final guess.

AREW breaks both loops at once using directional critiques. A directional critique is simple: for each step, a light external signal says whether that belief update moved toward the true answer (call it +1) or away (call it 0 or -1). This is easy to get because it only requires knowing the true answer at the end—no heavy supervision.

When the agent retrains, steps that aligned with the true direction get their credit boosted; misaligned steps get reduced. Now action selection learns: if I ask question X, the belief will update in a direction that agrees with where the truth actually was. So X was a smart question. Belief tracking also benefits: it no longer has to guess which updates were good; the directional signal shows it. Both loops now have clear feedback, and they can stop starving each other.

Math after the picture

The credit-reweighting formula

First in words:

adjusted learning weight for each step equals its original importance times an agreement bonus that is high when the step moved toward the true answer and low when it moved away

Then the compact form:

w_t = w_t_original * (1 + alpha * d_t)

Every symbol:

w_tlearning weight (importance) at step t
w_t_originalthe weight before adjustment
d_tdirectional agreement at step t: plus-one if belief moved toward truth, minus-one if away
alphahow strongly to boost agreeing steps (a tuning knob)
A tiny worked example
Step 1: agent asks smart question, belief updates correctly. d_1 = +1. w_1_original = 0.5. With alpha = 1.0: w_1 = 0.5 * (1 + 1.0 * 1) = 0.5 * 2.0 = 1.0. Credit doubled.
Step 2: agent asks random question, belief updates wrongly. d_2 = -1. w_2_original = 0.5. w_2 = 0.5 * (1 + 1.0 * (-1)) = 0.5 * 0.0 = 0.0. Credit zeroed.
Same original importance, but d_t flips the signal: agreement is rewarded, disagreement is suppressed.

The formula shows that steps aligned with the ground truth get amplified learning weight, while misaligned steps lose credit, unblocking both action selection and belief tracking.

What can go wrong

What can go wrong

If directional labels are unreliable The method relies on knowing the true answer at the end. If ground truth is noisy or mislabeled, directional signals will mislead the agent. The method works best on tasks with clear, unambiguous right answers.
If the true answer is hidden until the very end AREW needs step-level directional feedback. On tasks where you only learn the true answer after many episodes (e.g., a long dialogue where you cannot verify intermediate claims), the method has no signal to work with.
If belief tracking is structurally broken AREW reallocates credit, but it does not fix a belief-tracking mechanism that is fundamentally incapable of learning from evidence. If the agent's internal model cannot represent updates (for example, if all belief states collapse to the same representation), directional bonuses cannot create learning signals from scratch.
Done right On tasks with step-wise ground truth (e.g., intermediate fact-checking, supervised dialogues, reasoning benchmarks where you can verify intermediate answers), AREW unblocks fast learning on both action selection and belief tracking.

What a runnable demo should prove

Build a simple question-answering task: a hidden fact (e.g., a person's hobby, a hidden number, a true-false statement). The agent can ask up to five yes-or-no questions, after which it guesses. The agent's learning system tries to learn both which questions are informative and how to update beliefs correctly from answers. Implement two learners: one with only final-outcome reward (standard), one with AREW directional reweighting. Run both for 500 episodes on 20 random hidden facts.

accuracy after N episodes = fraction of final guesses that match the true answer; compare standard vs AREW

The demo proves the core claim: AREW agents quickly figure out which questions expose the hidden fact because directional guidance unblocks both loops, while standard learners ask random questions and plateau near random guessing because they cannot separate informative from worthless questions.
