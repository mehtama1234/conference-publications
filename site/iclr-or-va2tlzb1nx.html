Concept-Agnostic Attention Module Discovery

Find which parts of a transformer handle a given concept by measuring how each attention head matches the concept's pattern, then control those parts with a single number.

Paper explainersAll themesInterpretability

Transformers are black boxes — you give them text or an image and get an answer, but you cannot see how they think. This paper opens a window by finding exactly which attention heads (the parts that let the model focus on relevant pieces of its input) handle specific concepts like safety or reasoning. Once you find those heads, you can dial them up or down with one number to amplify or suppress that concept.

Zero assumption version

The attention heads are a mystery

Transformers rely on attention heads — parts of the model that learn to focus on relevant pieces of the input. But today we cannot point to a specific head and say what it does. We can see that removing an entire layer hurts performance, but not which individual heads matter for which concepts.

A beginner might think: remove each head one at a time, measure what breaks, and infer what each head does. That works, but it is slow — a transformer with many layers and heads requires thousands of experiments. We need a fast way to find the heads without trial and error.

The method in one sentence. Represent a concept (like safety or reasoning) as a pattern, measure which attention heads match that pattern best, group those heads as a module, and adjust them all with one dial.

The algorithm as a flow

What it actually does

Encode the concept

Average the model's internal activations on examples that show the concept (e.g., safe responses) to get one pattern (a list of numbers).

Score each head

For each attention head in each layer, measure how similar its output is to the concept pattern by checking if they point in the same direction.

Pick the best heads

Select the K heads with the highest similarity scores across all layers — they form the concept module.

Control the module

Multiply the outputs of just those heads by a dial number: use 0.5 to weaken them, 1.0 for normal, or 2.0 to strengthen them. The model recomputes with the adjusted heads.

Observe the effect

See how dialing the concept up or down changes the model's behavior on downstream tasks.

What the paper changes

The object: attention head importance

The paper changes which attention heads get adjusted during intervention. Instead of retraining the whole model or steering the entire hidden state, it isolates a small set of heads that handle one concept and dials those up or down.

the object it moves  =  attention head selection
The hidden quantity

The hidden quantity: concept-head similarity

measured quantity  =  Directional match score between concept and head

A concept (like safety) leaves a fingerprint in the model's activations — a specific pattern. Each attention head also produces a pattern. The method measures how much the head's pattern matches the concept's pattern by checking if they point in the same direction.

The paper estimates this similarity by running the model on a dataset of examples that showcase the concept, collecting the output from each attention head, and computing the mathematical similarity between that output and the averaged concept pattern.

Why it works

Why it works: the causal chain

Attention heads specialize during training. A head learns to focus on certain word pairs or patterns because they help the model make better predictions. Over time, heads that contribute to the same concept converge on similar patterns. So if you measure which heads are similar to a concept, you are finding the heads that learned to handle that concept.

When you adjust those heads with a dial number (multiply by 0.5 to weaken, 2.0 to strengthen), you are changing their influence on the internal state that flows to the next layer. Amplifying the safety heads makes the model more cautious; suppressing them makes it easier to jailbreak. The reason this works is that each head's contribution is additive — turning down the safety heads removes their voice without breaking the computational flow of the rest of the model.

The equation

First in words:

For each attention head in each layer, compute the cosine similarity between the head's output and the vectorized concept. Select the K heads with the highest similarity. For intervention, multiply the selected heads' contributions by a scalar factor.

Then the compact form:

similarity(h) = (concept . head_h) / (||concept|| * ||head_h||) module = TopK heads by similarity(h) adjusted_output = sum over selected heads (s * head_contribution) + sum over other heads (head_contribution)

Every symbol:

conceptthe averaged pattern of the concept, as a list of numbers
head_hthe output of attention head h, as a list of numbers
.dot product: multiply corresponding numbers and add them up
||...||length of the list (how far it stretches in space)
similarityhow much two lists point in the same direction, from 0 to 1
sthe scalar dial: 1.0 = normal, 0.5 = weaker, 2.0 = stronger
TopKthe K heads with the highest similarity scores
A tiny worked example
Concept vector (safety): [0.8, 0.6, 0.4, 0.2]
Head 3 output: [0.7, 0.5, 0.5, 0.1] -> dot product = 0.8*0.7 + 0.6*0.5 + 0.4*0.5 + 0.2*0.1 = 0.56 + 0.30 + 0.20 + 0.02 = 1.08
||concept|| = sqrt(0.8^2 + 0.6^2 + 0.4^2 + 0.2^2) = sqrt(0.64 + 0.36 + 0.16 + 0.04) = 1.0
||head_3|| = sqrt(0.7^2 + 0.5^2 + 0.5^2 + 0.1^2) = sqrt(0.49 + 0.25 + 0.25 + 0.01) = 1.0
similarity(head_3) = 1.08 / (1.0 * 1.0) = 1.08 (clamped to 1.0 in practice: very high match)
With dial s=0.5, head 3 contributes only half as much to the next layer.

The directional match captures how aligned two patterns are; higher means the head is more central to that concept. The dial number scales that head's strength proportionally.

What can go wrong

What can go wrong

Interference between concepts. If two concepts share heads, adjusting one affects the other. The paper does not fully address crosstalk between overlapping modules.
Concept pattern is fragile. The concept pattern is built from a small reference dataset. If the dataset does not represent the concept well, the whole method fails silently.
Layer-specific effects only. The method finds heads at one layer that match the concept. It may miss important contributions from other layers if they process the concept differently.
Done right. Use a diverse, representative dataset for the concept. Pick K (the number of heads) large enough to capture the full module but small enough to avoid noise. Validate by checking that the intervention actually changes behavior as expected.
What a runnable demo should prove

What a runnable demo should prove

Build a simple transformer on a toy task (like sentiment classification). Pick a clear concept (e.g., positive vs negative words). Run SAMD to find the heads that match that concept pattern. Then use SAMI to dial those heads up and down and watch the model's predictions flip accordingly. Log which heads were selected and verify they stay consistent if you train the same model twice.

module_stability = fraction of selected heads that are the same across two independent runs concept_effect = sentiment accuracy with dial=2.0 minus sentiment accuracy with dial=0.5

The core claim: the same small set of heads reliably handles one concept, and you can control them with a single number without retraining.
