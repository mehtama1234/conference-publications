Causal Graphs with Latent Confounders and Post-treatment Selection

The paper shows how to recover the true causal links when both hidden confounders and selective filtering after interventions are present.

Paper explainersAll themesOther

Finding causal links (what causes what) is hard. Intervention experiments help by creating changes you control, which reveal causation. But in the real world two hidden traps exist: unmeasured factors that influence multiple variables simultaneously, and selective filtering of samples after the experiment runs (a biologist keeps only healthy cells; a trial keeps only compliant subjects). The filtering trap is often overlooked. This paper introduces a new way to spot and separate causal links from selection bias, allowing recovery of the true graph structure despite both traps, by watching how each mechanism reacts differently to interventions.

Zero assumption version

Two hidden traps in causal discovery

When scientists run experiments (called interventions), they often filter the data afterward. A biologist measures gene expression, but only keeps cells that meet quality thresholds. A medical trial runs, but only healthy enough subjects complete it. This post-treatment filtering is invisible in the data, yet it fools causal discovery algorithms.

The naive approach: look at which variables change when you intervene on one variable, then infer causation. But filtering creates spurious patterns that look like causation. If the filter favors high values, and a hidden factor pushes values up, changing one variable seems to change another, even though there is no direct causal link between them.

Existing methods cannot tell the difference between a true causal link and a false one created by selective filtering after intervention. They also struggle with unmeasured confounders (hidden factors that influence multiple variables simultaneously).

In one sentence. Selective filtering after intervention creates spurious dependencies that masquerade as causal links.

What the paper changes

What the paper changes

Traditional causal discovery algorithms orient edges based solely on conditional independence patterns in data. This paper augments the graph model to include an explicit selection variable that represents post-treatment filtering, then uses differential reactions to intervention to distinguish true causal links from selection-induced spurious ones.

The hidden quantity

The hidden quantity: distribution shift type

measured quantity  =  Intervention fingerprint type

When you intervene on a variable, the distribution of each other variable changes. But the TYPE of change differs. A true causal child of the intervened variable changes its overall distribution (its center, spread, or shape). A variable linked only through selection changes in a narrower way: it gets filtered, but not fundamentally reshaped.

The paper estimates this by comparing conditional independence (which combinations of variables are independent of each other, given what you already know) before intervention versus after. True causal effects preserve certain independence patterns in one direction; selection effects preserve them differently. By tracking these patterns under multiple interventions, the algorithm infers which structure created them.

Why it works

Why it works: structural asymmetry under intervention

A true causal link means intervening on one variable directly changes another. A hidden confounder means two variables jump together because an invisible third variable pushes both. Post-treatment selection means the sample set itself changes after intervention, creating false associations.

These three mechanisms have different structural signatures. When you intervene on a variable, a true child responds because of the direct path. A selection variable responds only if it depends on the intervened variable through other paths, creating a different pattern in the conditional independence tests. The algorithm captures these patterns from data, uses them to constrain which edge directions are possible, then applies rules that check: does this edge direction match how the actual values changed under the observed interventions? If yes, keep it; if no, flip it or mark it as selection-related.

The algorithm works in two stages. First, build an undirected skeleton using all data and a standard conditional independence test (e.g., testing if two variables remain independent given a third). Second, orient edges and add marks using rules that incorporate intervention fingerprints and selection indicators. The marks (tail, arrowhead, square for selection, circle for ambiguity) encode the equivalence class precisely.

Math after the picture

The core equation and worked example

First in words:

When variable XA is independent of XB given (XC and selection indicator S), record that independence. Under intervention on variable XI, check if the same independence holds in the new distribution p(k). If true causes are present but selection is not, certain independencies survive intervention; selection-only connections break.

Then the compact form:

For any k in [K], if XA ⊥ XB | {XC, S} in observational p(0), then check if XA ⊥ XB | {XC, S} holds in p(k). Mismatch indicates selection effect.

Every symbol:

XA, XB, XCobserved random variables
Sselection indicator (1 if sample kept after filtering, 0 if discarded)
p(0)observed data distribution before intervention
p(k)data distribution after intervening on variable k
⊥statistical independence (two things do not predict each other)
|given (conditioning on known values)
[K]set of all possible interventions
A tiny worked example
Observational data: X1 and X2 appear independent when we know sample quality is high. This pattern is recorded.
Intervene on X1 (force it to increase). In the new data: if there is a real causal link, both X1 and X2 jump together, breaking the independence. Record this change.
If selection alone created the link, then intervening on X1 only changes which samples the quality filter keeps, not X2 directly. The independence pattern changes differently.
Orientation rule: the independence breaks under intervention indicates causation. The independence breaks in a different way indicates selection. Real causal effects remain predictable through selection changes; selection effects are unpredictable.

The independence tests detect which graph structures could have generated the observed data; the intervention fingerprints pin down which structures actually did.

What can go wrong

What can go wrong

Selection filter is unobserved. If the filtering rule is completely hidden and independent of causal structure, no algorithm can recover it from data alone. F-FCI assumes the selection rule is not adversarially hidden.
Insufficient interventions. If you only intervene on a few variables, you miss fingerprint patterns that distinguish selection from causation because the algorithm relies on comparing how patterns change across multiple intervention types. Each intervention creates a new fingerprint; more interventions build a richer signature that only true causal structures can match.
Large hidden confounder networks. If many latent confounders exist and are densely connected, the equivalence class (set of possible graphs) grows large. The method may identify multiple structures that fit equally well.
Done right. With observational data plus multiple interventions and reasonable selection structure (e.g., selection depends only on observed variables or the intervened one), F-FCI recovers the true graph up to the fine-grained equivalence class.
