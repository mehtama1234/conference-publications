Continuous learning and adaptation

Papers on how models can learn over time without forgetting old knowledge, and how to update models when the world changes without retraining from scratch.

All themesField mapMathematicsAll explainers
What this is

Retraining a large model from scratch takes weeks and costs thousands of dollars in computing. Yet the world changes — new data arrives, old patterns become irrelevant, and new patterns emerge. You need models that learn continuously, updating themselves as new information comes in, without forgetting everything they already know. This is the opposite of how most machine learning works today, where you train once on a big dataset and then deploy a static model.

The challenge is catastrophic forgetting: if you just train the old model on new data, it forgets the old patterns. Imagine teaching someone to play piano, then only training them on violin — they forget piano. You need to balance learning new things without erasing old knowledge. You also need to handle distribution shift, where the nature of the data changes over time (for example, if a model for medical diagnosis was trained on data from one hospital, it must adapt when it is deployed in a different hospital where patients and equipment are different). All of this must happen without constant retraining.

Researchers develop methods for continual learning. Some use memory buffers, keeping a small set of old examples so that when training on new data, the model still sees reminders of what it learned before. Some penalize large changes to the parameters that mattered for old tasks, making the model resist forgetting. Some use mixture-of-experts, where different specialized models handle different scenarios or time periods. Some design models that can quickly adapt to new domains with just a few examples, borrowing knowledge from similar domains they have seen before.

How the work breaks down

Continuous learning splits into five main directions. First, preventing catastrophic forgetting when learning new tasks — how to keep old knowledge intact as you add new things, because otherwise the model erases what it learned before. Second, maintaining plasticity — the ability to learn — while staying stable, so that the model can pick up new patterns without its learning ability freezing up. Third, adapting at test time without retraining, when you encounter data the model hasn't seen before, because retraining from scratch is too slow and expensive. Fourth, handling domain shift and multi-source adaptation, where the nature of the data changes over time or across different sources, so models must work with data that looks different from what they trained on. Fifth, continual learning in multimodal systems, where models must learn new concepts across images, text, and other data types simultaneously, because real-world systems need to handle multiple types of information at once.

Memory and replay for avoiding forgetting

The core problem: when you train a model on new tasks or new data, it forgets what it learned before. This catastrophic forgetting happens because the model's internal weights shift to fit the new data, and those shifts erase the knowledge stored in the old weights. The simplest way to fight this is to keep a small memory buffer of examples from old tasks, then mix them into training on new data — so the model sees reminders of the past and doesn't overwrite old patterns, which means old knowledge survives.

Forget Forgetting: Continual Learning in a World of Abundant Memory shows that simple memory replay works extremely well and can outperform much more complex approaches, while costing less to compute, which means the simple solution is often the best. What matters is that if you have enough room to store old examples, memory-based learning beats trying to do clever tricks with penalties on weights or other indirect methods, because the direct reminder is stronger than abstract constraints. Two-Way Is Better Than One: Bidirectional Alignment with Cycle Consistency for Exemplar-Free Class-Incremental Learning proves mathematically that bidirectional alignment — learning from both old-to-new and new-to-old directions at the same time — shrinks the forgetting problem by a large margin, because alignment from both directions creates a stronger tug-of-war that preserves both old and new knowledge, even without storing old examples. XIL: Cross-Expanding Incremental Learning extends this further, allowing models to learn new classes while handling domain drift, the shift in what the data looks like over time, which lets the model stay current as conditions change. These three papers show that different angles on memory and alignment all reduce forgetting: direct storage, learned alignment constraints, and domain-aware expansion.

Stability and plasticity through controlled weight updates

A model has two opposite needs: it must stay stable (not forgetting old knowledge) and remain plastic (able to learn new things). When you change weights to learn something new, you risk undoing old learning. The deep papers in this group solve this by controlling which weights change and how much they change, directing changes along specific paths in weight space — the mathematical directions in which weights can move.

Spectral Collapse Drives Loss of Plasticity in Deep Continual Learning identifies a specific problem: when you train continually, the model's learned features become correlated in a way that stops new learning. The fix is to add two regularizers (penalty terms) that push the model away from this collapsed state, keeping it flexible. SplitLoRA: Balancing Stability and Plasticity in Continual Learning Through Gradient Space (the directions in which weights can shift) Splitting solves the problem differently, by splitting weight-change space — the space of possible weight changes — into two parts: one for stability (protecting old knowledge) and one for plasticity (learning new things). This partitioning delivers the best results because it directly targets where forgetting happens. KeepLoRA: Continual Learning with Residual Gradient (weight-change direction) Adaptation balances all three goals — learning new data, remembering old data, and keeping the model's base knowledge intact — by making only the weight changes that matter. Together, these show that controlling how and where weights change is the key to handling both stability and plasticity.

Test-time adaptation without retraining

Once a model is deployed, you can't afford to retrain it from scratch every time the data shifts. Test-time adaptation solves this by adjusting the model on the fly, the moment you see new data at deployment time. The challenge is making these adjustments fast and with minimal computation, using only the new samples you see.

When and Where to Reset Matters for Long-Term Test-Time Adaptation shows that sometimes it helps to reset certain parts of the model as it adapts, but only the right parts, only at the right times — if you reset everything, you lose beneficial knowledge and the model must relearn from scratch, but if you reset nothing, you get stuck and can't adapt, so selective resets find the middle ground. IMSE: Intrinsic Mixture of Spectral Experts Fine-tuning for Test-Time Adaptation uses a mixture-of-experts approach, where different expert models handle different scenarios, and they're combined with 2,000 times fewer parameters (the internal weights that define what the model does) than full retraining, making it extremely cheap to run because you're only updating a tiny fraction of the model. NEO — No-Optimization Test-Time Adaptation through Latent (hidden-layer) Re-Centering achieves strong results without even optimizing; instead, it shifts the internal representations — the learned features inside the model — to match the new data being seen, which means the model adjusts without learning new patterns. Test-time Domain Generalization for Image Super-resolution applies the same idea to image enhancement, showing that feature alignment works across very different network types and data changes, which suggests the approach is general. These four papers show that test-time adaptation can happen without heavy computation — either by selective resets, mixture models, or representation shifts.

Domain shift and multi-source adaptation

Real-world data is never clean. Data comes from different sources, changes over time, and sometimes the sources are contradictory. A model must adapt when data from a new hospital looks different from training data, or when new classes appear that weren't present before. This is data shift, and it breaks models trained on old data.

Multi-source Unsupervised Domain Adaptation (the first paper in this group) tackles the hardest case: you have data from many sources but no labels, and you don't know which source is most reliable. The method handles this efficiently and works especially well when you have very little target data. ICYM2I: The illusion of multimodal informativeness under missingness addresses a different kind of shift: sometimes in real data, some information goes missing (for example, a medical scan might be missing, or a sensor breaks). The framework shows that simply ignoring the missing modality or pretending it's not missing both fail — you need to explicitly account for the missingness itself, which changes what the data looks like. Source-Free Open-World RF Fingerprint Identification handles both old-class retention (remembering to identify old wireless devices) and new-class discovery (learning to identify new devices), without access to the source data. This group shows that data shift comes in many forms — multiple sources, missing data, and new classes appearing — and each requires recognizing the specific kind of shift.

Continual learning in vision-language models

Vision-language models learn from both images and text, and they need to adapt and learn new concepts without forgetting old ones. The challenge here is different: these models are often already trained on massive datasets and locked in their knowledge, so adapting them without breaking existing capabilities is delicate.

AREA: Attribute Extraction and Aggregation for CLIP-Based Class-Incremental Learning works with CLIP, a widely-used vision-language model, and learns new visual classes by extracting text attributes and combining them smartly, rather than retraining the whole model. Memory-Free Continual Learning with Null Space Adaptation for Zero-Shot Vision-Language Models preserves the model's zero-shot capability — its ability to classify things it has never seen before — while learning new classes, using a technique that adapts only in directions that don't break existing knowledge. SCNS: Continual Personalization of Diffusion Models via Submodular Concept Neuron Selection personalizes a diffusion model (a type of generative model) by modifying only 0.41% of parameters per new concept, allowing the model to learn many new ideas without catastrophic forgetting or needing to combine old and new models. Together, these show that vision-language adaptation succeeds by finding small, safe corners of the model where you can make changes — either through attribute extraction, null-space alignment, or selective neuron modification — leaving the core knowledge untouched.
