SciNet: Relation-Aware Scientific Literature Retrieval

A dataset that forces AI retrieval agents to find papers by tracing how ideas flow and cite each other, not just matching keywords.

Paper explainersAll themesAgents & Tool Use

When scientists search for papers, they do not just want the closest semantic match to a query — they want to understand how ideas build on each other, which studies agree or disagree, and how a concept evolved over time. Current retrieval agents see papers in isolation, matching only by keywords or semantic fingerprints (a vector, which is just a list of numbers, capturing what a paper is about). SciNet is the first dataset that grades agents on whether they understand the relational network of scientific papers: finding papers that introduced new ideas, identifying which ones cite or contradict each other, and reconstructing the lineage of a field. The paper shows current agents score below 20% on these tasks. But when agents are trained on SciNet's relational tasks, they improve by 25% on real literature review work, because they now retrieve papers in sensible reading order and from the right causal chains, not random clusters.

Zero assumption version

Today's agents see papers as isolated islands

A scientist searching for papers today uses tools like Deep Research, which employ retrieval agents built on keyword or embedding similarity. These agents treat each paper as independent — they score a paper high if its words or semantic fingerprint match the query, and that is the end of the story.

But scientific papers form a dense network of relationships. Paper A cites paper B because B proved a foundational result. Paper C cites both A and B but disagrees with how B applies the idea. Paper D inherits the lineage (B, then C, then A, then D), tracing decades of evolution. A naive keyword match will miss all of this structure. A retrieval agent will find semantically close papers but will fail to recognize that the most important result is a paper that disrupted the field three years ago, or that the query should be answered by tracing a chain of citations forward through time. The agent returns fragmented, unordered lists. Scientists have to manually assemble the story.

In one sentence. Current retrieval agents match papers by words or semantic fingerprints alone, missing the relational network of citations, papers that introduce ideas nobody thought of before, and scientific lineage.

What the paper changes

What the paper changes

The paper introduces a dataset of relational retrieval tasks. Instead of treating papers as independent points to be matched by keyword or semantic fingerprint, the dataset assigns each task a relational structure: which papers introduce ideas nobody thought of before, which papers cite or contradict each other, and which papers form a causal path through scientific history. Agents must retrieve papers based on this network logic, not semantic similarity alone.

the object it moves  =  Retrieval evaluation: from flat keyword-matching to relational-network-aware tasks.
The hidden quantity

The hidden quantity: relational structure understanding

measured quantity  =  Fraction of relational logic captured

Current agents do not explicitly measure or track relational structures in scientific papers. SciNet introduces a proxy: how well an agent reconstructs the correct set of papers when the ground truth is defined by network properties (whether a paper introduces new concepts, citation sentiment, temporal lineage). A paper is 'correct' not because it has high keyword overlap, but because it stands in the right relational position — it is cited by others, it disrupts earlier work, or it is on the causal path of idea evolution.

The paper estimates this quantity by measuring accuracy on three relational query types. Idea-originality and disruption scores (ego-centric) quantify whether a paper introduces structurally new concepts. Citation sentiment (pairwise) quantifies whether a paper agrees or disagrees when citing another. Consistency and coherence (path-wise) quantify whether a set of papers forms a coherent temporal sequence. Together, these three dimensions measure how much relational structure an agent has actually understood.

Why it works

Why it works: forcing evaluation to reveal the gap

Semantic fingerprints and keyword matching are stateless: each paper is scored in isolation. A query comes in, the agent computes a similarity score for every paper using pre-trained semantic fingerprints (vectors, which are just lists of numbers) or keyword overlap, and returns the top K. This works fine for shallow semantic closeness, but it fails when the ground truth is relational. An old, foundational paper might have low keyword overlap with a query about a recent method, yet it is the source that makes the method possible. A disruptive paper might use entirely new terminology, earning a low semantic score from a query phrased in the old language. A paper that strongly disagrees with the query's premise is still highly relevant — it is exactly the paper the scientist needs to read — but keyword similarity does not capture disagreement.

SciNet creates an evaluation regime that cannot be gamed by keyword or semantic fingerprint alone. If an agent wants high scores on the ego-centric task, it must learn to identify papers that introduce genuinely new concepts (papers whose references cover new conceptual ground) or disruptive (papers whose future citations break with earlier assumptions). This requires reasoning over the citation graph. If an agent wants high scores on the pairwise task, it must understand citation sentiment (recognizing when a citation is confirmatory, critical, or extending earlier work). If it wants high scores on path-wise retrieval, it must reconstruct a causal sequence through time — not just grab a cluster of semantically similar papers. By building a dataset where the ground truth is relational, the paper forces agents to internalize that structure, or their scores stay low.

Math after the picture

The evaluation equation

First in words:

Accuracy on relational task equals the number of papers agent retrieved that match the ground-truth relational structure, divided by the total ground-truth papers in that category. Three categories: ego-centric (idea-originality and disruption), pairwise (citation sentiment), path-wise (sequence coherence).

Then the compact form:

Accuracy_relational = |Retrieved_papers ∩ Ground_truth_papers| / |Ground_truth_papers|

Every symbol:

Accuracy_relationalFraction of correct papers retrieved, where correct means satisfies a relational property (not similarity)
Retrieved_papersPapers the agent selected based on its retrieval method
Ground_truth_papersThe real set of papers that satisfy the relational task (e.g., papers that cite the query paper with agrees sentiment)
|Set|Count of papers in that set
A tiny worked example
Query: Find papers that extend the ideas in paper X (i.e., cite X but also introduce new next steps).
Ground truth: Papers A, B, C all extend X (ground-truth count is 3).
Agent retrieves: Papers A, B, D. Papers A and B are in ground truth, but D does not extend X (it merely mentions X). Retrieved count matching ground truth is 2.
Accuracy is 2 divided by 3, which is 0.67 or 67 percent. The agent got two-thirds of the relational answer right; it missed the actual next-step paper C and wrongly included D.

The key shift: ground truth is no longer high semantic similarity but satisfies a relational property in the citation network. An agent optimizing for semantic distance will fail.

What can go wrong

What can go wrong

Defining ground truth is subjective. Whether paper A 'disrupts' the field or 'extends' it is not always obvious. SciNet uses human annotators and citation graph statistics (e.g., how many future papers cite A versus its predecessors). If human judgment is inconsistent, the ground truth is noisy.
Recent papers have sparse citation history. A paper published two months ago that introduces new concepts has no citation data yet, so it is hard to measure its disruption or future impact using the relational structure. SciNet must wait for citations to accumulate or rely on expert prediction, both of which introduce error.
Citation sentiment is ambiguous. When paper B cites paper A, an LLM must judge whether the citation is supportive, critical, or extending. Context matters (the same paper might support A's method but question its assumptions). A simpler heuristic (count of citations means importance) loses nuance.
Done right: use SciNet as a benchmark, not a final judge. SciNet reveals which agents lack relational reasoning. An agent that scores well on SciNet but fails on a new field has not truly learned generalized network reasoning. Combine SciNet evaluation with expert review of retrieved papers and downstream task performance (e.g., does the retrieved set actually support a good literature review?).
What a runnable demo should prove

What a runnable demo should prove

Build a mini retrieval agent and a small benchmark. Start with a corpus of 500 papers in one field (e.g., machine learning), manually annotate which pairs have citation relationships and which papers are disruptive (e.g., papers that spawned a new subfield). Create 10 retrieval tasks: 3 ego-centric (retrieve papers more disruptive than a given threshold), 4 pairwise (retrieve papers that cite this paper with a specific sentiment), 3 path-wise (retrieve a temporal sequence from classical to modern). Implement two retrieval methods: (1) embedding similarity baseline and (2) a network-aware baseline that re-ranks retrieved papers by their citation properties. Plot accuracy on relational tasks for both. The gap between the two will visualize why SciNet is necessary.

Relational accuracy = (papers retrieved that satisfy the network property) / (total ground-truth papers for that property). Compare embedding-only vs network-aware.

The demo must make it impossible to miss this truth: keyword and embedding similarity alone leave relational structure invisible. An agent that ignores the citation network will score low on all three task types.
