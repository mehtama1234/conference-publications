Shapley Regularized Neural Granger Causality

Find which past time-series values actually caused future ones by measuring each variable's true global importance, not just local changes.

Paper explainersAll themesInterpretability

When you watch a time series unfold — stock prices, weather, a patient's vital signs — some past events really do cause future ones. A neural network can predict what comes next, but it does not say which variables actually drove the outcome. This paper asks a precise question: if I erase a variable's past values, how much would the prediction get worse? The answer reveals the true causal chains, not just correlations.

Zero assumption version

Predicting is not explaining

A neural network trained to forecast the next value in a time series can be very accurate. But accuracy hides a mystery: which past values actually mattered? A naive approach measures each variable's local gradient — how much a tiny change to one input would nudge the prediction. This picks up immediate, direct effects but misses the full picture. In a real time series, causality is tangled: variable A influences B, which then influences the output, so A's global importance is much larger than its local gradient suggests. Local measures blind you to the true causal paths.

Without knowing the real causal structure, you cannot intervene correctly. You cannot say: stop recording this variable because it does not matter. You cannot warn: watch out, this one drives everything. You are stuck.

The method in one sentence. The paper measures each past variable's global importance by asking: how much worse would the entire prediction become if that variable had never existed? This reveals true causal chains.

The algorithm as a flow

What it actually does

Train the neural network

Build a model that predicts the next timestep from past values of all variables.

Measure importance by removal

For each past variable, ask: if this variable had zero values at all past times, how much worse does the prediction become?

Weight the network by importance

Multiply each weight in the neural network by its global importance score so the network learns to rely on truly causal variables.

Suppress spurious relationships

Penalize variables that look important by local measures but contribute little to prediction, forcing the network to drop them.

Iterate and converge

Train the weighted network until importance scores stabilize and truly causal variables stand out.

What the paper changes

What the paper changes

Instead of using simple local gradients to assess causality, the paper uses a global measure called the Information-Theoretic Shapley value. This value asks: how much worse is the prediction when this variable is absent, averaged fairly across all possible scenarios? The network's weights are then adjusted based on this true global importance, not local changes.

the object it moves  =  causal importance weights
The hidden quantity

The hidden quantity: global causal importance

measured quantity  =  Information-Theoretic Shapley value

The Shapley value is a number between 0 and 1 assigned to each past variable. It answers a concrete question: if you randomly removed this variable from the time series data, how much would the prediction error increase? A value of 1.0 means the variable is essential; 0.0 means removing it does not matter. It is computed by testing the model on all possible subsets of variables and averaging the variable's contribution fairly.

The paper estimates this value by running the neural network many times, each time with different variables set to zero, and measuring how much prediction accuracy drops each time. This cost is high but gives the true global importance.

Why it works

Why it works: from local to global

Neural networks naturally learn complex nonlinear causal chains. Variable A at time t-2 might influence B at time t-1, which influences output at time t. A local gradient only sees the A-to-output connection directly, missing the chain through B. But the Shapley value forces the network to answer: what if A never existed at all? That counterfactual question traces all paths, direct and indirect.

The network is then trained with a penalty: when the Shapley value says variable X is truly important but the weights connected to X are small, the network is nudged to fix the weights. Conversely, if X looks locally important but globally it is not (spurious), the penalty forces the weights down. This aligns learning with causality because the penalty directly rewards weights that match true global importance and punishes weights that chase spurious patterns, so the network must eventually choose the causal path to minimize loss. The regularizers (penalty terms) prevent the network from cheating — for instance, learning indirect correlations that look like causality but vanish under intervention.

Math after the picture

The penalty equation

First in words:

loss equals prediction error plus a penalty term: the squared difference between each weight and its target importance, summed over all weights.

Then the compact form:

loss_total = loss_prediction + lambda * sum_i (weight_i - importance_i)^2

Every symbol:

loss_predictionerror when the network predicts the next value
weight_ithe connection strength for variable i
importance_ithe Shapley value (global importance) of variable i
lambdathe regularization strength, a knob from 0 to 1
A tiny worked example
Time series has three variables: temperature, humidity, rainfall.
True causal structure: temperature and humidity drive rainfall.
Shapley values computed by removal: temperature 0.9, humidity 0.7, rainfall 0.1.
Network weights learned initially: temperature 0.4, humidity 0.8, rainfall 0.6.
Mismatch penalties (lambda = 1.0):
Temperature: (0.4 - 0.9)^2 = 0.25
Humidity: (0.8 - 0.7)^2 = 0.01
Rainfall: (0.6 - 0.1)^2 = 0.25
Total penalty: 0.51. Network is nudged to increase temperature weight and decrease rainfall weight on next iteration.
After retraining, weights align: temperature 0.85, humidity 0.72, rainfall 0.15.
New penalty: (0.85-0.9)^2 + (0.72-0.7)^2 + (0.15-0.1)^2 = 0.0025 + 0.0004 + 0.0025 = 0.005.
Much smaller — the network has learned true causal structure.

The penalty pulls each weight toward its true importance. High lambda means the penalty dominates; low lambda means prediction error still dominates. The mechanism aligns learning with causality.

What can go wrong

What can go wrong

Computational cost explodes. Computing Shapley values requires testing the model on many subsets of variables. For 100 variables, this becomes prohibitive. The paper is most practical for moderate-sized time series (tens of variables, not thousands).
Spurious relationships that are highly predictive. Sometimes a variable is not causal but is so correlated with true causes that erasing it still hurts prediction badly. Shapley will rank it high. The regularizers help by penalizing weights that chase spurious patterns; however, if the spurious correlation is extremely strong and training data is small, the penalty might be outweighed by how much prediction error drops when the network uses the spurious relationship, so the network might still lean on it to minimize total loss.
Neural network must be differentiable. The method works only if you can compute gradients. Non-differentiable architectures (decision trees, genetic algorithms) cannot use this regularizer.
Done right: clear causal recovery. On synthetic datasets where the true causal structure is known, the method reliably recovers which variables are truly causal and ranks them by strength. Intervention experiments on real systems confirm the recovered structure.

Compute how accurately each method ranks the three variables from most to least causal. The Shapley method should rank temperature and humidity at the top and rainfall at the bottom.
