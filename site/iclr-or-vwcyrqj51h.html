On the Bayes Inconsistency of Disagreement Discrepancy Surrogates

When training models to disagree more under shifted data, existing loss functions can silently fail to do what they promise because they are built on a bad approximation.

Paper explainersAll themesLearning Theory

When a model sees new, shifted data in the wild, it often fails. One way to catch and fix this is to train two models together and measure how much they disagree when the data shifts — more disagreement signals something is wrong. But the math for this disagreement measurement uses a piece that computers cannot optimize. This paper proves that the practical replacements everyone uses are broken: they can lie about disagreement. It then builds a better one that keeps its promise, because it is designed so that optimizing it is mathematically guaranteed to maximize the real goal.

Zero assumption version

The disagreement measurement is built on math that won't optimize

In the real world, data changes. A model trained on photos of cars in sunny weather might crumble when it sees the same cars in snow. One defense is to train two separate models side by side and watch how much they disagree on each input. When the data shifts, disagreement should spike — a signal that something is broken.

The true math for this disagreement uses a rule that says: if the two models disagree, the loss is 1, if they agree, the loss is 0. This is called the zero-one loss. But computers cannot take gradients (tiny nudges in the right direction) through zero-one walls — it is either 0 or 1, never in between. So every practical method switches to a smooth stand-in: a pretend loss that the computer can optimize.

The trap is this: just because you optimize a smooth stand-in does not mean you actually maximize the true disagreement. The paper proves that all common stand-ins can lie — you can reach the best score on the fake loss and still be nowhere near the best disagreement in reality.

In one sentence. Build a smooth loss function that keeps its promise: when it reaches its best score, disagreement actually goes up.

What the paper changes

The piece the paper changes

The paper swaps out the smooth disagreement loss function. The old versions are not Bayes consistent; the new one is. When you use the new disagreement loss paired with cross-entropy (which measures how often the primary model is correct), you are now guaranteed that optimizing it will actually maximize true disagreement under the real zero-one loss.

the object it moves  =  disagreement loss
The hidden quantity

Bayes consistency: does the fake loss stay true to the real one?

measured quantity  =  Bayes consistency

Bayes consistency is a theoretical property: it says that when you optimize a smooth stand-in loss over all possible functions, the best function under the stand-in is also the best function under the true loss. In other words, the fake loss is faithful to the real goal. If a loss is not Bayes consistent, it can reach its best score while the true goal remains mediocre — the promise is broken.

This paper proves whether each surrogate loss preserves the true objective. The authors extend the standard framework for checking Bayes consistency (which was built for simple classification) to work for disagreement discrepancy, which is more complex: it is a difference of two risks, not a single one. They compute excess loss (how far any given prediction is from the best possible under each loss) and check: if you minimize the surrogate, does the difference between the two models stay true to the real disagreement? If yes, the loss is consistent. If no, it lies.

Why it works

Why a consistent loss matters: the chain of trust

The core problem is that the true disagreement goal uses a zero-one loss (1 if models disagree, 0 if they agree). This cliff — hard 1 or 0, nothing in between — means gradients (the nudges that drive optimization) are zero almost everywhere. The computer cannot optimize it directly.

Every practical method switches to a smooth surrogate: a pretend loss that rises and falls smoothly, so gradients exist. The hope is that optimizing the smooth version pushes you in the right direction for the true goal. But that hope is only valid if the surrogate is Bayes consistent.

When a surrogate is not consistent, its best score can occur at a completely different solution than the true goal's best score. You could train for hours, reach the global minimum of the fake loss, and discover the two models actually disagree far less than they would under a better solution, because the fake loss was measuring something orthogonal to true disagreement and happened to peak at a different place in weight-space. You were optimizing a lie.

The paper's new surrogate pairs a disagreement loss (specifically designed for this task) with the standard cross-entropy loss (which counts how often the primary model is right). Together, they form a surrogate that is Bayes consistent: the optimizer of this surrogate provably optimizes the true disagreement discrepancy. The training is now faithful.

The new surrogate that keeps its promise

First in words:

Total surrogate loss = alpha times cross-entropy on the reference model plus the new disagreement loss

Then the compact form:

L[cross_entropy, disagreement_loss] = L[ℓ_ce, ℓ_dis_new], where ℓ_dis_new pairs with ℓ_ce to form a Bayes-consistent surrogate for maximizing disagreement under distribution shift.

Every symbol:

ℓ_cecross-entropy loss; measures how often the reference model is right
ℓ_dis_newnew disagreement loss; designed to pair with cross-entropy so both together are Bayes consistent
αa weighting parameter; higher values prioritize disagreement more strongly
Sthe source (training) distribution of data
Tthe target (shifted) distribution of data
A tiny worked example
Scenario: on source data S, reference model (R) gets 90% right, critic model (C) agrees with R. On shifted target data T, R drops to 60%, C predicts differently on 70% of disagreements.
Old surrogate (not consistent): might score 8.5/10 by rewarding only the cases where the fake loss is low, ignoring whether C actually disagrees on the right examples.
New surrogate (Bayes consistent): scores based on true cross-entropy (measuring R's accuracy on source + target) paired with the new disagreement loss (directly rewarding when C and R output different classes). The best possible score is now aligned with the best true disagreement.

The surrogate combines two pieces: one ensures the reference model learns the source task, the other ensures the critic model diverges in the right ways under shift — together they form a Bayes-consistent objective.

What can go wrong

What can go wrong

Finite sample size bleeds in. Bayes consistency is an asymptotic guarantee (assumes infinite data). With finite data, the models trained on the new surrogate will still be somewhat off the true optimum. The bounds on this gap (proved in the paper) quantify how much finite data hurts.
Model class mismatch breaks the promise. The new surrogate is consistent over all measurable functions. But you restrict to a fixed model class (e.g., neural networks of a certain size). If the true optimum lies outside your model class, even the consistent surrogate cannot reach it — the theory only promises the best your model class can do.
Disagreement alone does not guarantee the predictions are right. High disagreement when the data shifts (changes its pattern) is a signal that something changed, but it does not automatically make predictions safer or more accurate, because disagreement just means the two models took different paths; whether both paths are wrong, one is right, or both are right is a separate question. The paper measures disagreement faithfully; how you use that disagreement (as a rejection threshold, a reweighting signal, an alarm) is a separate design decision.
Used correctly. When the paper's surrogate is used in practice, optimization is now guaranteed (asymptotically, in expectation) to maximize true disagreement. You get the signal you promised yourself you were optimizing for.
What a runnable demo should prove

What a runnable demo should prove

A demo would train two neural networks on a standard benchmark (CIFAR-10 to CIFAR-10-C with corruption, or a WILD dataset with domain shift) using the new disagreement surrogate loss. It would record both the smooth surrogate loss and the true disagreement discrepancy (computed via zero-one loss on a held-out shifted test set) after each epoch. The demo would show that as the surrogate loss decreases, the true disagreement increases — not randomly, but faithfully. It would also compare the trajectory to a baseline using an old, non-consistent surrogate, showing that the old method can reach a great surrogate-loss score while disagreement stagnates, because the old surrogate was optimizing a different objective and lucky alignment between the surrogate and the goal was never guaranteed, whereas the new method makes both improve together because the surrogate is provably consistent.

faithfulness = correlation(surrogate_loss_trajectory, true_disagreement_trajectory) over epochs; should be > 0.85 for new method, < 0.40 for old methods

The demo must make it impossible to miss: optimizing the new surrogate pulls the true disagreement up reliably, while optimizing old surrogates can leave disagreement flat even when the fake loss looks great.
