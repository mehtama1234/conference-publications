AQER: Scalable Quantum Data Loading

AQER loads classical data into quantum computers by systematically untangling the information, making data loading scalable and efficient.

Paper explainersAll themesOther

Quantum computers promise to solve problems no classical machine can touch, but they have very few qubits (quantum memory slots). Feeding classical data into quantum circuits wastes those precious qubits through unnecessary complexity. AQER systematically reduces the entanglement (the way different qubits are twisted together) in the target state, creating loading circuits that are both accurate and use fewer quantum gates. This scales to 50 qubits with real quantum many-body data.

Zero assumption version

Why loading data into quantum circuits is hard

Quantum computers have only a few qubits (quantum memory bits). Each qubit can hold a tiny piece of information, but n qubits can represent 2 to the power of n different states at once (all layered on top of each other at the same time). So a 10-qubit machine has 1,024 possible states overlaid together.

Naively, you might try to build a circuit (a sequence of quantum gates) that directly creates the target state in all its complexity. But most natural data distributions tangle qubits together in ways that require deep circuits—many gates applied in sequence—to build. More gates mean more noise from hardware errors. On today's noisy quantum machines, a deep circuit fails before it finishes. So the naive approach creates circuits too deep to run reliably on real hardware.

In one sentence. AQER builds shallower loading circuits by first reducing how tangled the data is, then creating the simplified state, and finally filling in the rest.

The algorithm as a flow

What it actually does

Measure entanglement

For each pair of qubits, calculate how much their states are linked together.

Identify high-entanglement pairs

Find the qubits that are most tangled and contribute most to circuit depth.

Peel off entanglement

Build a simpler intermediate state by removing the strongest tangles one at a time.

Create the simple state

Use a shallow circuit to build the reduced state, measuring the error introduced.

Add back the complexity

In a second shallow pass, restore the removed tangles, keeping total circuit depth low.

What the paper changes

The one thing AQER changes

AQER changes how the loading circuit is structured: instead of trying to build the full tangled state in one go, it breaks the job into two shallow steps—first building a simplified state with fewer tangles, then adding back the complexity. The two-step approach keeps the circuit shallow enough to run on noisy hardware.

The hidden quantity

Entanglement entropy: the hidden quantity

measured quantity  =  entanglement entropy across subsystems

Entanglement entropy is a number that measures how tangled a quantum state is. If qubits are independent (not tangled), the entropy is zero. If they are heavily linked, the entropy is high. For n qubits, the maximum entropy is n bits.

AQER measures this quantity for every subset of qubits and uses it to guide which tangles to peel off first. The paper proves that the error in the final loaded state scales linearly with this number—if you can reduce the entropy of the target state, you can build a shallower circuit. Because circuit depth grows with entanglement, and AQER reduces entanglement before building the full state, the total circuit needed is much shallower than building the tangled state from scratch.

Plain reading. Entanglement is how much two qubits depend on each other. If you measure one qubit, it affects the answer you get when you measure the other. A high-entanglement state has many such dependencies. AQER peels off the strongest dependencies first, leaving a simpler state that is cheaper to build on a quantum computer, because building a state with fewer dependencies requires fewer quantum gates—and fewer gates means the circuit finishes before errors from noise destroy the answer.
Paper reading. The paper establishes information-theoretic bounds showing that the achievable infidelity scales linearly with the total entanglement entropy across subsystems when the loading circuit is applied to the target state. This theoretical result motivates the design of AQER: construct the circuit by systematically reducing entanglement in target states.
Why it works

Why it works: the causal chain

A quantum circuit is a sequence of quantum gates. Each gate is fast (takes one time step), but if two qubits are entangled, you must apply gates to both of them to handle the entanglement correctly. A state with high entanglement requires many gates to build accurately. AQER breaks this bottleneck by recognizing that entanglement is the root cause of circuit depth.

Here is the key: instead of building the full entangled state directly, AQER first builds a simplified version of the state that has much lower entanglement. This simpler state needs fewer gates. Then, in a second shallow pass, AQER adds back the entanglement that was removed. By splitting the work into two stages, the total depth stays shallow enough to run reliably on noisy quantum hardware, even though the final state is fully complex. The paper proves mathematically that this strategy works: the error in the loaded state depends only on how much entanglement was present, not on how many ways you could have built it.

Math after the picture

The approximation error equation

First in words:

The error in the loaded state grows linearly with the total entanglement entropy; error = c times entanglement_entropy, where c is a constant that depends on the circuit construction.

Then the compact form:

infidelity <= c * sum_S H(S)

Every symbol:

infidelitythe probability the loaded state differs from the target state
ca constant depending on how the loading circuit is built
H(S)entanglement entropy of subsystem S (in bits)
sum_Ssum over all possible subsystems (all subsets of qubits)
A tiny worked example with 3 qubits
Suppose the target state has entanglement entropy H = 1.5 bits (some qubits are tangled, others are independent).
AQER measures and identifies the dominant entangled pairs. It builds an intermediate state with H = 0.4 bits (most tangles removed).
Using the bound infidelity <= c * H, the intermediate state can be built with error at most c * 0.4.
When AQER adds back the 1.5 - 0.4 = 1.1 bits of entanglement it removed, the total error is still bounded by c * 1.5.
For comparison, building the full state directly would require a circuit of depth ~2^1.5 = 2.8x gate depth; AQER reduces this by the factor of entanglement it can identify and defer.

The linear relationship means that peeling off entanglement layer by layer keeps the circuit shallow—you avoid the exponential blow-up of naively building a highly entangled state from scratch.

What can go wrong

What can go wrong

Very low-entanglement states. If the target state has almost no entanglement to begin with, AQER and naive methods perform similarly, because there is no entanglement to reduce. AQER is most beneficial when the target has strong, complex entanglement.
Overhead of measuring entanglement. Computing entanglement entropy for all possible subsystems (there are 2 to the power of n of them) is expensive classically. For large numbers of qubits, this preprocessing cost can become prohibitive unless approximations are used.
Two-pass approach mismatch. The strategy assumes you can split the circuit into two stages: reduce entanglement, then restore it. If the hardware supports only one continuous circuit, the two-stage advantage is lost.
Done right. AQER works best on moderate-sized quantum processors (10-50 qubits) with realistic entanglement structure and hardware that tolerates shallow multi-stage circuits.
What a runnable demo should prove

What a runnable demo should prove

A demo should load a small dataset (e.g., 8x8 grayscale images or a synthetic probability distribution) into a 5-10 qubit quantum circuit using both naive loading and AQER. Measure the fidelity (how close the loaded state is to the target) and the circuit depth (number of gates). Plot both metrics for increasing target entanglement. The key observation: as entanglement grows, naive loading requires exponentially deeper circuits, while AQER's depth grows much more slowly because it amortizes the entanglement reduction across two stages.

fidelity = 1 - infidelity; circuit_depth = total gates used; depth_ratio = naive_depth / AQER_depth (should grow with target entanglement)

The demo must show that AQER uses a shallower circuit for the same accuracy. Each quantum gate (operation) introduces errors due to hardware noise. A 100-gate circuit will accumulate roughly 2x the errors of a 50-gate circuit. By cutting circuit depth in half, AQER lets the circuit finish with lower total error.
