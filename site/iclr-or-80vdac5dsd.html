Causal Discovery via Quantile Partial Effect

Identify which variable causes which by examining how one variable's distribution changes at different values of another, skipping the need to model what causes what internally.

Paper explainersAll themesOther

Finding causal direction (does X cause Y or does Y cause X?) usually means building a model of how one variable depends on the other — a hard, error-prone guess. This paper finds cause and effect by looking only at the raw observed data itself: it measures a hidden shape property that tells cause from effect, without ever building an internal model. The measure is called Quantile Partial Effect, or QPE.

Zero assumption version

Cause vs effect is hard to tell from data alone

When you see two variables that move together — say, ice cream sales and sunburn cases — you know one affects the other. But which way? Does warm weather drive ice cream sales, or does selling more ice cream somehow make it warmer? To answer this, scientists usually guess a model: assume ice cream sales depend on temperature plus some random noise, then check if that model is plausible. The problem is these guesses are fragile. Pick the wrong functional form (maybe the relationship is curved, not linear) or ignore an unmeasured confounder (both variables rise because summer is coming), and your causal direction flips.

A beginner might try fitting both directions and picking the one with better fit. But that fails because both a model of Y depending on X and a model of X depending on Y can achieve equally good fit to the same data — fitting does not reveal which dependency is causal. Adding unmeasured confounders (hidden variables that influence both X and Y) makes the problem even more ambiguous. The core obstacle is that fitting the data tells you how the variables correlate, but not which one is the root cause.

The method in one sentence. Instead of guessing the causal mechanism, measure an asymmetry property (Quantile Partial Effect) directly from the observed data distribution, which points to the true cause.

The algorithm as a flow

What it actually does

Step 1: Observe the raw data.

Collect measurements of X and Y together, no models.

Step 2: Estimate conditional quantile curves.

At each value of X, find the quantiles (0.1th, 0.5th, 0.9th percentile) of the Y values.

Step 3: Measure Quantile Partial Effect.

Compute how the quantile curves change across X values; this is QPE, a shape property of Y given X.

Step 4: Test if QPE lies in a finite basis.

Check if QPE can be written as a weighted combo of known basis functions; if yes, X causes Y.

Step 5: Identify causal direction.

The direction where this basis property holds is the true cause; the other is the effect.

What the paper changes

What the paper changes

Instead of guessing internal mechanisms (how one variable depends on another plus randomness), the paper measures a pure distribution property: Quantile Partial Effect, or the shape of how the outcome's percentiles vary with the input. This QPE lives entirely in the observed data, independent of any assumed model.

The hidden quantity

Quantile Partial Effect: the shape fingerprint

measured quantity  =  Quantile Partial Effect (QPE)

Quantile Partial Effect measures the slope of the conditional quantile curves — that is, how the 10th, 50th, and 90th percentiles of an outcome change as an input variable changes. It is a pure property of the observed data distribution, requiring no guess about internal causality or noise.

The paper uses QPE to test whether cause and effect are identifiable: it assumes that the QPE curves lie within a finite linear span (can be written as a weighted sum of known basis functions). When X causes Y, this constraint on QPE holds; when X is the effect, the constraint fails. By testing which direction satisfies this property, the algorithm identifies the causal direction.

Why it works

Why measuring shape discovers cause and effect

When X causes Y, the distribution of Y at each X value has a specific structure: the quantiles (percentiles) of Y curve in a way that can be written as a weighted sum of basis functions. This is not an accident; it follows from the asymmetry of how causes flow into effects through data.

When Y causes X instead, the Quantile Partial Effect of Y on X does not have this finite-span property. The constraint fails. This asymmetry — one direction satisfies the basis constraint, the other does not — arises purely from the shape of the observed distribution, without needing to guess or model any internal mechanism, noise, or causality assumption. The paper proves this mathematically and uses basis function testing to detect which direction has the constraint, thus identifying the true cause.

Math after the picture

One readable equation and its meaning

First in words:

For each variable X and outcome Y: if the Quantile Partial Effect psi can be written as a weighted sum of basis functions (lies in span of phi), then X causes Y.

Then the compact form:

psi_Y|X(y|x) = sum_j c_j * phi_j(y) implies X -> Y

Every symbol:

psi_Y|X(y|x)Quantile Partial Effect: how Y's percentiles curve with X
c_jweight on the j-th basis function
phi_j(y)known basis function (e.g., polynomial, spline)
span(phi)all possible weighted combinations of the basis functions
X -> YX is the cause, Y is the effect
Tiny worked example: two basis functions
Suppose we observe X (temperature) and Y (ice cream sales).
At X = 60F: Y's 10th percentile = 20, 50th = 100, 90th = 180 units.
At X = 80F: Y's 10th percentile = 30, 50th = 150, 90th = 270 units.
The QPE (how these percentiles change per degree) varies smoothly.
Test: can QPE be written as 0.5*polynomial(y) + 0.3*spline(y)? YES for X->Y.
Test the reverse (Y->X, predicting temperature from sales): NO, the basis fit fails.
Conclusion: X (temperature) causes Y (sales).

The basis-span constraint on QPE is the asymmetry that lets us identify cause from effect in pure data.

What can go wrong

What can go wrong

QPE does not lie in the assumed basis. If the true Quantile Partial Effect cannot be written as a weighted sum of your chosen basis functions (polynomials, splines, etc.), the test fails. Choosing a richer basis (more basis functions) helps because it can express more complex shapes, but adds computational cost when fitting more functions to the data.
Unmeasured confounders that affect both X and Y. If a hidden variable U causes both X and Y, the observational distribution is warped. The paper assumes no such latent confounders (causal sufficiency); if they exist, the method may misidentify direction.
Finite sample noise in quantile estimation. Estimating quantiles from data requires many samples per region of X. With sparse data, quantile curves are noisy, and the QPE may not cleanly fit the basis, leading to wrong causal direction.
Done right. With enough samples, a well-chosen basis, and no latent confounders, the Quantile Partial Effect test reliably identifies the true causal direction, because the basis constraint is fundamentally asymmetric between cause and effect.
What a runnable demo should prove

What a runnable demo should prove

Generate synthetic data where X causes Y via a nonlinear relationship (e.g., a curved or wavy dependency with added noise). Also generate the reverse where Y causes X. For each pair, estimate the Quantile Partial Effect at a grid of X (or Y) values. Fit basis functions (e.g., polynomial or spline basis) to the QPE curves in both directions. Check: does the basis fit succeed in the true causal direction and fail in the reverse direction?

accuracy = (correct_direction_basis_fit & wrong_direction_basis_fails) / num_pairs

The demo must show that only the true cause has QPE that fits the basis, reliably distinguishing cause from effect on data where the true causal graph is known.
