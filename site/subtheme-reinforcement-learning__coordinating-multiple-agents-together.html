Coordinating multiple agents together

Teaching groups of agents to work together, communicate, or compete, where each agent learns how to interact with the others and adapt to their behavior.

All themesField mapMathematicsAll explainers
What this is

Most real problems involve multiple actors. In a warehouse, several robots move packages; each one has to know what the others will do. In traffic, each vehicle makes independent decisions, but the traffic flow depends on all of them coordinating. In a team sport, players have to anticipate each other. Multi-agent reinforcement learning asks: how do agents learn to cooperate or compete when what's optimal for one agent depends on what others do?

This is fundamentally harder than single-agent learning because the rules keep changing. If one robot learns a picking strategy, another robot adapting to that strategy changes what's optimal for the first robot. It's like chess against an opponent who is also learning — you can't plan ahead because the board state depends on moves you haven't predicted yet. Papers tackle this by teaching agents to model what other agents will do, to communicate their intentions, or to learn policies that still work when other agents change their strategies.

Multi-agent coordination matters wherever systems need to work together at scale: swarms of drones, game-playing teams, economic market simulations, and collaborative human-AI teams. Getting it right means avoiding deadlocks, redundant work, and conflicts.

How the work breaks down

Work in this subtheme splits into five directions: teaching agents to learn joint value functions in ways that scale to many agents; building agents that coordinate through communication and shared understanding; making multi-agent teams survive adversarial changes and missing agents; learning from offline data where agents cannot freely experiment; and enabling agents to adapt dynamically as other agents change their behavior.

Value Decomposition for Scalable Cooperation

In multi-agent learning, agents must coordinate while each makes its own decisions. The challenge is computing how much credit each agent should get: if a team wins, did agent A win it, or agent B, or the fact that they worked together? In large teams, checking all possible combinations of actions becomes impossible—with 10 agents and 20 actions each, that is over 10 trillion combinations.

The Value Factorization paper uses value factorization—breaking the group value into separate pieces for each agent—and adds guarantees that it will work even when the test situation differs from training. Factored Value Functions for Graph-Based MARL takes this further by using the structure of which agents actually interact with which other agents: if agent A only touches packages in the left corner and agent B only works on the right, their actions don't depend on each other, so the value function can stay local. This cuts computation by 11% compared to checking everything. HPS resolves a different problem: when agents operate at different scales—some controlling single objects, others controlling groups—the learning rates conflict. Their method maps all agent scales onto the same geometric space, so all agents learn at a compatible speed. Potentially Optimal Joint Actions Recognition directly attacks the credit problem by learning which combinations of actions are actually good together, then building the value function only from those promising combinations. Together, these papers show that to scale to many agents, you cannot compute everything centrally; instead, you have to exploit the structure of which agents actually interact with which others.

Coordination Through Communication and Convention

Some coordination problems cannot be solved by just watching what others do—agents need to explicitly tell each other their plans. Imagine two robots at a narrow doorway: if neither communicates, both might rush through at once and collide. If they can say 'I am going first' or 'you go ahead,' they solve it instantly. The hard part is learning what to communicate and when, without being told by a human how to do it.

EvoCF uses a technique called counterfactual planning: agents imagine what would happen if they tried different messages and actions, then evolutionarily select the best combinations. It learns to shift from exploring many options early to settling on stable conventions—the team gradually agrees 'we do this thing this way'—and it works across three different team tasks. IEC adds spectral consensus, a mathematical way to measure when agents have become aligned in their understanding, combining this with a reward structure that gradually pushes exploration down as consensus rises, automating the shift from trying different strategies to running the one that works. Multi-agent Coordination via Flow Matching uses a newer neural network technique (flow matching) instead of diffusion models to generate coordinated action sequences, so it computes the predictions 14.5 times faster while keeping the same quality—speed matters for real-time systems where faster predictions mean a robot can actually execute the plan before the situation changes. Automata-Conditioned Cooperative MARL teaches agents to follow task-specific rules (like a traffic system that says 'stop at red') and discovers that task-relevant multi-step behaviors emerge naturally—agents learn multi-action sequences that make sense together. Correlated Policy Optimization in Multi-Agent Subteams proves mathematically that when you organize agents into loosely-coupled subteams (each subteam handles one part of the problem), you can find near-optimal policies, and experiments confirm subteams adapted per task beat fixed groupings. These papers show that explicit or implicit coordination—through communication, shared conventions, or task structure—beats having agents act blindly.

Surviving Adversaries and System Failures

Real multi-agent systems fail in unexpected ways. A teammate might be compromised by an attacker, communication might drop, or a different team might actively work against you. The question is how to build agents that stay effective when things go wrong—not just when everything works as designed.

AdvEvo-MARL defends against adversarial attacks by evolving agents to survive attacks and simultaneously evolving attacks to find new weaknesses, much like a security researcher trying to break their own system. This co-evolution keeps attack success rates below 20% while keeping task accuracy as high as or higher than the original, showing that defended agents still perform their primary job well. The Bayesian approach (BATPAL) uses probabilistic reasoning to handle uncertainty about what the adversaries will do—instead of assuming the worst, it builds a weighted collection (a 'distribution,' which means a list of possibilities with their likelihoods) over possible attack types and optimizes against all of them simultaneously. BATPAL outperforms older baselines across diverse attack strategies, showing that hedging against many threats beats preparing for just one worst case. Interaction-Breaking Adversarial Learning Framework deliberately breaks the communication between agents during training so they learn to be less dependent on specific teammates—if agent A can only work with agent B and agent B fails, agent A breaks. By training agents to survive without their normal partners, they become antifragile, gaining 44.6% more defensive capability in one benchmark. Secure MARL for Service Systems with Byzantine Nodes handles a provable guarantee: even if some agents are 'Byzantine'—meaning they lie or do nothing—the cooperative team will still converge to a good policy. Vulnerable Agent Identification spots which agents are weakest in large teams, using decomposition that preserves the team's solution quality while finding the fragile points. Learning Multi-Agent Policies via Selective Adversarial Fault Induction trains on deliberately broken versions of individual agents, discovering which faults matter most, and achieves defensive gains up to 116.7% in complex benchmarks because the team learns to work around each failure. Together, these papers show that defending against failure in multi-agent systems is not about one defense but about building agents that anticipate failure and learn to compensate.

Learning from Limited Data and Partial Observability

In practice, multi-agent systems rarely have unlimited data to learn from. Robots are expensive to operate; real traffic cannot be stopped for experiments; past logs of behavior are all the team has to learn from. Additionally, each agent usually sees only part of the world—a robot on one side of a warehouse cannot see what robots on the other side are doing. Learning from this partial, limited view is much harder than learning when you see everything and can try anything.

Structured Policy Initialization for large action spaces pre-trains a model of which actions are valid together, then freezes that structure and only learns what to do with valid pairs, cutting training time because the agent avoids wasting computation on impossible combinations. GlobeDiff addresses the opposite problem: when each agent sees only part of the state, how can the team estimate the full global state? By using diffusion models to fill in the unseen parts, it provides error bounds for how wrong the estimate can be, ensuring agents plan based on reasonably accurate information even with limited views. HyPOLE adds formal specifications—rules like 'if agent A is at location X, agent B must be at location Y'—which guides learning in partial observability, and it beats baselines on messy real-world scenarios because the formal rules anchor what matters. Offline Multi-Agent RL via Sequential Score Decomposition learns from past logs without access to new interactions, and it handles multimodal scenarios where the data contains multiple different strategies. By coordinating exploration in high-value regions of the offline data, it outperforms older methods that either explored everywhere or nowhere. Offline MARL via Skill Partition and Reuse learns skills from offline data, then continually expands the skill library as new tasks arrive, avoiding negative transfer where skills learned for old tasks actively harm learning on new ones. STAIRS-Former tackles multi-task offline learning by using a transformer with interleaved recursive structure—processing time, space, and task relationships together—reaching top performance on complex benchmarks like StarCraft by learning to reuse patterns across tasks. Sample-Efficient Divergence-Aware MARL finds optimal policies that work even when the true world is slightly different from the training world, and does it from limited online interaction—the agent learns a policy that works across many scenarios without needing to explore exhaustively. Who Matters Matters (OMCDA) solves a fairness problem in offline MARL: when learning from past logs, some agents appear more than others, which creates bias in credit assignment. By identifying which agents truly matter for the task versus which are just there, it learns fair policies. Together, these papers show that learning from partial views and limited data requires structure—either pre-computed models, formal rules, or careful exploitation of which data points actually matter.

Continuous Adaptation and Emergent Behavior

The core difficulty of multi-agent coordination is that the world is constantly changing—when one agent learns a new strategy, what was optimal for another agent might no longer be optimal. This moving target is what makes multi-agent problems fundamentally different from single-agent learning, where the rules stay fixed. Papers in this group tackle how agents can adapt to shifting optima and build stable coordination even as the game changes.

Inter-Agent Relative Representations for Multi-Agent Option Discovery learns reusable multi-step behaviors (options) between pairs of agents by focusing on how one agent relates to another rather than absolute states. This makes options transferable across different teams and scenarios—an option that worked with partner A might work with partner B. Safe Continuous-time MARL via Epigraph Form keeps multi-agent teams safe by using mathematical structures (epigraph forms) that naturally lead to smoother value estimates and more stable training, outperforming older safe MARL methods because continuous structures match how the real world works. SocialJax is a benchmark for measuring multi-agent learning in social dilemmas—scenarios where individual incentive and team incentive collide, like the tragedy of the commons. It verifies behaviors using Schelling diagrams, which measure whether agents have actually shifted their strategy or just stumbled into it. Test-Time Adaptation for LLMs shows that in partially observable multi-agent settings, agents can learn during execution—observing results and adjusting—without retraining, which matters for real-world systems where you cannot stop and retrain. Improving Human-AI Coordination through Adversarial Training learns to predict human behavior by simulating many humans and training against their unpredictability, achieving top performance on real Overcooked tasks with real human partners by adapting to their style on the fly. Negotiated Reasoning addresses relative over-generalization, where agents learn to ignore features that sometimes matter because those features are correlated with the other agent's behavior—imagine learning 'blue objects don't matter' when in fact the opponent just happened to ignore them. SVNR provably sidesteps this by building in reasoning about what makes an agent's decision better than alternatives. Provably Convergent Actor-Critic for MARL through Risk-Aversion adds a preference for predictability to the learning objective—agents prefer policies that stay good even if other agents deviate slightly, which mathematically guarantees convergence and generates emergent strategies that are more stable. Retaining Suboptimal Actions to Follow Shifting Optima discovers that the best policy in a changing multi-agent world is sometimes to keep trying 'bad' actions, because what is suboptimal now might become optimal when other agents adapt. Towards Complete Multi-Agent Coordination via Denoising Maximum Entropy Optimization balances exploration (trying new things) with exploitation (using known good strategies) through a denoising process, achieving both good sample efficiency and convergence to true optimal policies. Unsupervised Partner Design learns to generate synthetic partners whose behavior covers a wide range of strategies, enabling an agent to practice against many types of teammates, and this zero-shot approach beats supervised baselines when the agent faces new unknown humans. Together, these papers show that stable multi-agent coordination emerges when agents can adapt to shifting optima, learn from limited examples, and explicitly reason about how their behavior affects others.
