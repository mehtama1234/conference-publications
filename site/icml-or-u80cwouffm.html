OmniVL-Guard: Towards Unified Vision-Language Forgery Detection and Grounding via Balanced RL

OmniVL-Guard detects forged multimodal content and points to the forged region by rebalancing training so the easy classification task does not drown out the harder grounding task.

Paper explainersAll themesMultimodal

Real misinformation often mixes text, images, and video in one stream. A useful detector must answer two questions together: is this content forged, and where is the forgery evidence? OmniVL-Guard tackles both in one model. The paper identifies a common optimization failure: the binary detection task is easier, so its gradient, which is the direction used to update model weights, dominates training and the fine-grained grounding task lags behind. OmniVL-Guard first creates reasoning traces to avoid a weak starting point, then uses adaptive reward scaling to keep training pressure focused on the harder grounding objective when needed.

Zero assumption version

Detection is easier than localization, and that imbalance breaks joint training

A unified forgery model must classify whether multimodal content is fake and also ground the evidence by marking the manipulated region, frame, or text-image mismatch source. These two tasks share input, but they do not have the same difficulty. A coarse yes-or-no decision can often be learned from broad cues, while accurate grounding requires much finer reasoning.

When both tasks are trained together with ordinary weighting, the easy task can dominate. The detector quickly learns a rough decision boundary, receives large reward often, and keeps steering the update. The grounding head then improves slowly because its weaker signal is buried. The result is a model that can say 'forged' without showing where the proof is. OmniVL-Guard is built to prevent that failure by making task weighting change over training instead of staying fixed.

Core problem. Joint forgery detection fails when the easy classification task takes most of the learning signal and leaves too little pressure for fine-grained grounding.

The algorithm as a flow

What it actually does

Create a unified multimodal input format

Represent interleaved text, images, and video so one model can process all channels in one reasoning path.

Generate initial reasoning supervision

Use self-evolving chain-of-thought construction to synthesize stepwise forgery rationales and evidence references.

Train for detection and grounding together

Ask the model to output both a veracity label and localized forgery evidence.

Scale rewards adaptively

Use ARSPO, which is Adaptive Reward Scaling Policy Optimization, to change reward size and task weights based on current difficulty.

Keep pressure on the hard task

When classification becomes easy, shift more learning signal toward grounding so the model keeps improving where it is still weak, because otherwise the easy task keeps collecting reward without fixing localization.

What the paper changes

What the paper changes

The paper changes multi-task optimization from static weighting to difficulty-aware weighting. It treats the joint forgery task as a moving target where the model should spend more update effort on the parts that remain underfit.

the object it moves  =  difficulty-aware balancing of detection and grounding
The hidden quantity

The hidden quantity: task difficulty bias

measured quantity  =  task difficulty bias

Task difficulty bias is the gap in learning speed between classification and grounding. If classification accuracy rises early while localization quality stays low, the model starts receiving most of its positive signal from the easy task. That skews later updates toward what the model can already do.

The paper treats this bias as the central failure mode of unified forgery detection. It is not enough to know that one task is easier in principle. You need to track when that ease starts distorting optimization. ARSPO responds by changing reward scales and task weights so the slower task regains influence on the update.

Why it works

Why adaptive reward scaling helps

The method works because multi-task reinforcement learning follows the reward signal that is easiest to earn. In this setting, a broad forgery verdict is often easier than precise localization, so a static objective lets detection dominate. Once that happens, the model can keep improving its overall score without learning better evidence maps. Adaptive scaling breaks that loop by raising the value of grounding improvements when grounding is behind.

The self-evolving reasoning pipeline matters for a separate reason: early reinforcement learning is brittle if the model starts with poor rationales and poor evidence references. Synthetic stepwise traces give the model a usable starting behavior before adaptive reward optimization begins. That reduces the cold-start problem, because the model is not trying to discover both reasoning format and localization rules from sparse reward alone.

ARSPO then keeps the joint objective aligned with the true product requirement. Detection without grounding is incomplete, and grounding without detection is not enough either. By modulating task rewards over time, the method makes the update follow whichever part of the joint skill is still lagging. That is why the model can improve localization without giving up veracity classification.

A tiny worked example
Early in training, suppose detection is still weak and grounding is very weak. Use weights 1.0 for detection and 1.0 for grounding.
Later, suppose detection becomes easy and often correct while grounding still misses the manipulated region. Raise the grounding scale to 2.0 and lower detection to 0.6.
A sample with detection reward 1.0 and grounding reward 0.3 then gives total reward 0.6 + 0.6 = 1.2.
Without scaling, the same sample would give 1.0 + 0.3 = 1.3 and still mostly reward easy classification. The adaptive version narrows that gap so grounding improvements matter more.

The exact schedule can vary, but the principle is fixed: when one task becomes easy, stop letting it monopolize the update.

What can go wrong

What can go wrong

Difficulty estimates are noisy. If the system misreads temporary variance as real task difficulty, reward scaling can oscillate. Then training chases noise instead of genuine underperformance.
Synthetic reasoning traces are low quality. If the self-evolving rationales contain wrong evidence links, the model starts from a distorted supervision signal and may learn to justify the wrong region.
Unified input formatting loses cross-modal cues. If the representation of text, images, and video hides the timing or alignment between channels, the model may miss mismatch evidence that lives only in their interaction.
Done right. The method is strongest when difficulty tracking is stable, the initial reasoning traces are filtered for quality, and evaluation measures localization rather than accepting a correct label alone.
What a runnable demo should prove

What a runnable demo should prove

Build a small multimodal forgery benchmark with paired tasks: binary real-versus-fake detection and region or frame localization of the manipulated evidence. Include samples where only text-image alignment is forged and samples where the image or video itself is edited. Train one model with fixed task weights and one with adaptive reward scaling. Measure classification accuracy, localization overlap, and the fraction of cases where both are correct on the same example.

joint_success = fraction of examples where the model predicts the correct veracity label and also localizes the decisive forged evidence

The demo should show that adaptive scaling mainly changes the hard part of the problem: it raises grounding quality without sacrificing the easier veracity decision.
