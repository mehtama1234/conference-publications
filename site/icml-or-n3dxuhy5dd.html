Agent Learning via Early Experience

This paper trains agents from their own early interactions, even before reward-driven learning becomes practical.

Paper explainersAll themesAgents & Tool Use

Many agents learn from expert demonstrations because direct reward-driven training is expensive or impossible in real web and tool settings. This paper studies a middle stage called early experience: let the agent act, keep the resulting future states, and learn from those states before full reward optimization becomes workable.

Zero assumption version

Agent training often sees only polished expert paths and misses the wider environment

Expert demonstrations show what a skilled path looks like, but they do not show many of the wrong turns, recovery states, and odd page conditions that appear in real use. An agent trained only on polished paths can fail when the environment looks slightly different from the narrow examples it saw during training.

Direct reward-driven learning is also hard in many settings. Some tasks have no clean automatic score, and some tasks require very long action chains before any final signal appears. The paper asks whether there is a useful training stage between expert imitation and full reward optimization.

The idea in one sentence. Use the agent's own early interactions as supervision, because those interactions expose a broader set of environment states than expert-only data does.

The algorithm as a flow

What it actually does

Collect early interaction data

Let the current agent act in the environment and record what future states appear after each action.

Learn environment grounding

Train the agent to connect its action choices to later page or tool states so that it gains a clearer sense of environment dynamics.

Learn self-reflection

Expose the agent to its own weak choices and revised choices so that it learns how to recover from suboptimal decisions.

Mix with existing supervised data

Combine early experience with expert data so that clean demonstrations and broader environment coverage both influence training.

Use reward training later when possible

Treat early experience as a bridge stage because it prepares the policy before costly reward optimization begins.

What the paper changes

What the paper changes

The paper changes what counts as useful supervision. Instead of waiting for expert labels or final reward signals only, it uses the future states caused by the agent's own early actions.

the object it moves  =  the source of training supervision
The hidden quantity

The hidden quantity: state coverage before reward learning

measured quantity  =  how many useful environment situations the agent sees during pre-reward training

The paper argues that early training quality depends on the spread of states the agent experiences, not only on whether the actions were perfect. A narrow training set may produce a polished policy that breaks when the page layout, tool result, or task order changes.

Early experience raises state coverage because the agent encounters its own mistakes and partial progress states. Those states are useful because they reveal the environment that the agent will later face at test time.

Why it works

Why early experience can help

Early experience can help because the next observed state is a free supervision signal. When the agent clicks a control, opens a page, or calls a tool, the resulting state shows what that action caused. Training on those cause-and-effect links gives the policy a more grounded picture of the environment.

Self-reflection matters because many failures are not random. They follow recurring weak decisions, such as opening the wrong panel or following the wrong subgoal. If the training data includes both the weak move and the later recovery, the policy can learn a correction pattern before full reward learning begins.

Math after the picture

The core equation

First in words:

Useful pre-reward learning grows when broad state coverage and good correction learning both rise, because each covers a different weakness of expert-only training.

Then the compact form:

early_learning_value = state_coverage * correction_skill

Every symbol:

early_learning_valuehow useful the early experience stage is for later task performance
state_coveragehow much of the real environment state space the agent sees during early training
correction_skillhow well the agent learns to recover from weak early choices
A tiny worked example
Suppose expert-only training covers 4 out of 10 important state types, while early experience covers 7 out of 10.
Suppose the agent learns a useful recovery pattern on 8 out of 10 common mistake cases, so correction_skill is 0.8.
Then early_learning_value under this rough view is 0.7 times 0.8, which is 0.56.
That means the early stage gives useful preparation on about 56 out of 100 important situations.
The example shows why broader state coverage matters because recovery cannot help on situations the agent never saw.

The equation is a teaching summary. The paper's main lesson is that state coverage and recovery learning support each other.

What can go wrong

What can go wrong

Early experience is too noisy. If the initial agent acts almost randomly, many collected states may be low-value clutter, so the policy spends capacity learning from poor signals.
The collected states are broad but shallow. If the agent reaches many pages without learning what caused each transition, the data volume rises but the cause-and-effect lesson stays weak.
Self-reflection becomes self-confirmation. If the agent simply repeats its own mistaken explanation, the reflection stage can preserve a weak pattern instead of correcting it.
Done right. The method works when the early policy is strong enough to reach informative states and the training objective ties each action to the future state it created.
What a runnable demo should prove

What a runnable demo should prove

Build a web or tool-use environment where expert demonstrations exist but cover only a narrow set of task orders. Train one agent on expert data only and another on expert data plus early self-generated interaction data. Measure coverage of intermediate states, recovery success after a planted wrong move, and final task completion on held-out tasks.

The demo proves the paper's point if the early-experience agent handles more held-out situations, because it learned from a wider range of environment states before any full reward stage was needed.

generalization_gain = held_out_success(expert_plus_early_experience) - held_out_success(expert_only)

A convincing result should include at least one recovery-heavy task where expert-only training stalls and early experience carries the agent through.
