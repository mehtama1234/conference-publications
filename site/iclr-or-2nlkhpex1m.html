Adaptive Visual Token Pruning with Image Awareness

The paper discovers that vision-language models should prune image tokens differently depending on image complexity: use attention-based pruning for simple images and diversity-based pruning for complex ones.

Paper explainersAll themesComputer Vision

Vision-language models (large AI systems trained on both images and text) process images by breaking them into many small patches (each patch becomes a token, or a list of numbers representing what is in that patch). Processing all patches is slow and expensive. The paper reveals a key insight: simple images with a single clear subject should be pruned by attention (keeping patches the model pays attention to), while complex images with many distributed details should be pruned by diversity (keeping varied patches). This adaptive approach cuts computation while reducing the false claims models make up.

Zero assumption version

Vision-language models waste computation on redundant tokens

A vision-language model takes an image, breaks it into hundreds of small overlapping patches (called tokens), processes each one through layers of computation, and sends the results to the language model. On a complex image, this means processing thousands of tokens even though many are redundant (nearby patches showing the same texture, for instance).

Researchers built two ways to throw away redundant tokens: (1) attention-based: keep only the tokens the model pays attention to, assuming those carry the important information; (2) diversity-based: keep tokens that are different from each other, assuming variety means you capture more of the image. Both strategies cut computation. But researchers noticed the diversity-based methods sometimes made the models hallucinate (confidently describe objects that were not actually in the image). And no one knew which strategy should be used on which image.

The paper measures image complexity and adapts the pruning strategy per image. For simple images (single clear subject), prioritize attention. For complex images (many details), prioritize diversity.

The algorithm as a flow

What it actually does

Step 1: Measure image complexity

Compute how many distinct patterns exist in the image tokens using effective rank (a number that grows when token patterns are varied, stays low when similar).

Step 2: Score tokens by attention

The model attends differently to each token. Extract the attention scores from the model's internal computation.

Step 3: Score tokens by diversity

Measure how different each token is from others. Tokens with rare patterns get higher diversity scores.

Step 4: Blend based on complexity

If image complexity is low, weight the attention scores heavier. If high, weight diversity heavier. Combine the two into one final score per token.

Step 5: Keep top-scored tokens

Prune (discard) the bottom-scoring tokens. Pass only the survivors to the language model.

What the paper changes

What the paper changes: the pruning decision

The paper changes how the model decides which image tokens to discard. Instead of using a fixed rule (always attention, or always diversity), it adapts the decision based on the image.

the object it moves  =  pruning strategy (attention vs. diversity blending)
The hidden quantity

Image complexity: the hidden quantity

measured quantity  =  effective rank (how varied the image patterns are)

Effective rank is a number (between 1 and the total number of patches) that measures how many distinct patterns appear in the image patches. A uniform texture has low effective rank. A detailed scene with many objects has high effective rank. The paper measures it by breaking down the patch data mathematically: when more distinct patterns exist, more components carry significant weight.

The paper estimates effective rank from the patch embeddings (the internal list of numbers representing each patch). A standard math technique called singular value decomposition extracts a set of numbers that reveal pattern richness. If the largest few numbers dominate, the image is simple. If many numbers matter equally, it is complex. This hidden quantity predicts which pruning strategy will work best for that specific image.

Plain reading. Effective rank tells you whether an image is simple (few patterns, low rank) or complex (many patterns, high rank).
Paper reading. The paper computes effective rank from singular values of the patch embedding matrix. The computation goes: take all singular values, sum them and square the result, then divide by the sum of each squared singular value. Larger effective rank means more spread-out patterns.
Why it works

Why it works: the adaptation trade-off

Attention-based pruning works well on simple images because a simple image has one main subject the model rightly pays attention to. Discarding the patches the model ignores removes noise without losing the image's meaning. But attention-based methods miss details scattered across a complex image; they keep only the concentrated high-attention patches, throwing away valid supporting details.

Diversity-based pruning keeps patches that look different from each other, ensuring no two kept patches are redundant. On a complex image, this preserves distributed details the attention mechanism missed. But on a simple image, forcing diversity means keeping low-attention noise patches, introducing false details the model then falsely describes as objects (hallucination).

The paper's move: measure image complexity first, then steer the final patch score toward whichever strategy matches that image. Low complexity (simple image) emphasizes attention. High complexity (complex image) emphasizes diversity. This trade-off picks the right tool for each image, cutting patches while avoiding unnecessary hallucination.

The blending equation and worked example

First in words:

For each token, combine attention score and diversity score using a weight that depends on image complexity. If complexity is low, weight attention more. If high, weight diversity more. The final score guides which tokens to keep.

Then the compact form:

score_i = (1 - w) * attn_i + w * div_i, where w = min(1, erank / erank_threshold)

Every symbol:

score_ifinal importance of token i (used to rank tokens for pruning)
attn_iattention score of token i (how much model focuses on it, 0 to 1)
div_idiversity score of token i (how unique compared to others, 0 to 1)
wblending weight (0 = pure attention, 1 = pure diversity)
erankeffective rank of image (pattern richness, measured from tokens)
erank_thresholdcutoff value separating simple from complex images
A tiny worked example: simple vs. complex image
Simple image (erank = 2, threshold = 5): w = min(1, 2/5) = 0.4
Token A: attn = 0.9 (model focused), div = 0.3 (common pattern)
score = (1 - 0.4) * 0.9 + 0.4 * 0.3 = 0.6 * 0.9 + 0.4 * 0.3 = 0.54 + 0.12 = 0.66 (kept)
Token B: attn = 0.2 (model ignored), div = 0.8 (unique pattern)
score = (1 - 0.4) * 0.2 + 0.4 * 0.8 = 0.6 * 0.2 + 0.4 * 0.8 = 0.12 + 0.32 = 0.44 (pruned)
Complex image (erank = 8, threshold = 5): w = min(1, 8/5) = 1.0
Same Token B: score = (1 - 1.0) * 0.2 + 1.0 * 0.8 = 0 + 0.8 = 0.8 (now kept!)
On simple images, attention dominates; unique-but-ignored tokens are removed. On complex images, diversity gets full weight; unique tokens are preserved even if the model ignores them.

The linear blend moves the decision from pure attention on simple images to pure diversity on complex images, adapting the strategy without retraining.

What can go wrong

What can go wrong

Threshold mismatch. If the erank_threshold is set wrong for your domain, the model may over-weight diversity on images that are actually simple, or vice versa. Different datasets (photos vs. diagrams vs. medical scans) may need different thresholds.
Hallucination reintroduction. On naturally simple images, diversity-based pruning tries to keep varied patches to improve recall (the fraction of real objects caught). But this forces the model to keep noise patches too, because noise is different from the main object. The language model then sees these noise patches and mistakes them as real objects, describing things that do not exist. This happens because the language model is trained to describe whatever image information it receives; if you feed it noise, it invents descriptions to match. The trade-off is unavoidable: catching more real objects requires keeping more patches, and some will be noise.
Attention collapse. On some images, the model's attention may concentrate on a single artifact or watermark instead of the actual content. Pruning based on this collapsed attention will remove important details. The method assumes attention is informative.
Done right. Pre-compute the appropriate erank_threshold on your target dataset. Test on a validation set mixing simple and complex images to confirm the split is sensible. Monitor hallucination rates and recall separately.
What a runnable demo should prove

What a runnable demo should prove

Build a minimal end-to-end test: load a vision-language model (e.g. LLaVA), take 3-5 images spanning simple (a single object on white background) to complex (cluttered scene with many objects), run the full pipeline (compute erank, score tokens, blend, prune), measure (1) how many tokens remain, (2) whether the model's answer is still correct, (3) hallucination rate (false objects claimed in CHAIR dataset or manual count).

speedup = (original tokens processed) / (pruned tokens processed); hallucination = (false objects claimed in pruned model) / (false objects in full model)

The demo must show that a carefully pruned image gives both fewer tokens and fewer hallucinations compared to the base method, while maintaining the same factual accuracy on real objects.
