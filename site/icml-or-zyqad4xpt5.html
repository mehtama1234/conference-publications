HieRD: Hierarchical Relational Distillation for Vision-Language Embedding Models

Distill a large vision-language retriever into a smaller one by matching not only whole-image and whole-text embeddings but also object-level and phrase-level relations.

Paper explainersAll themesMultimodal

A vision-language embedding model turns an image and a sentence into embeddings, which are lists of numbers used for retrieval, so matching items land near each other in the learned space. In practice, a small student model often copies only the teacher's final global embeddings. That preserves coarse similarity but loses finer structure: which phrase maps to which object, which objects are close together, and which spatial relations matter. HieRD argues that this missing structure is why compact students underperform on retrieval and downstream tasks. The method distills relations at multiple levels by clustering visual feature units, where each unit comes from one image patch, into object-like groups and aligning them with phrase-level text features, not only with the single whole-example representation.

Why ordinary distillation misses retrieval structure

A global embedding can tell you that an image of a dog on a couch is broadly related to the sentence 'a dog resting indoors.' It says much less about whether the student retained the teacher's internal object structure, such as the dog region, the couch region, and the relation between them. For retrieval, those details matter because many candidates share the same global theme but differ on one object or one phrase.

If the student is trained only to mimic the teacher's final representation, which is one list of numbers summarizing the whole example, the easiest strategy is to preserve coarse category information and ignore fine-grained cross-modal correspondences. That gives a compact model that retrieves roughly correct items but misses precise matches, because the internal alignment needed for discrimination was never transferred.

The paper's move in one sentence. Distill the teacher's structure at several levels at once: whole-example alignment, clustered visual parts, phrase-level text units, and the relations among them.

The algorithm as a flow

What it actually does

Run the teacher on image-text pairs.

Extract global embeddings plus intermediate patch-level features from the larger teacher model.

Cluster visual patch units.

Group image patch features into object-like regions so the student can learn structure above the raw patch level.

Build phrase-level text units.

Split text into phrase-aligned features rather than using only one sentence-level representation because many retrieval errors come from one missed phrase.

Match multi-level relations.

Train the student to align global image-text pairs, local part-phrase pairs, and the relations among parts within and across modalities.

Deploy the compact student.

Use the smaller model for retrieval and downstream tasks after it has inherited the teacher's hierarchical structure.

What the paper changes

What the paper changes

The paper changes what is transferred during knowledge distillation. Instead of copying only the teacher's final embedding, it transfers hierarchical correspondences and relational structure across image and text features.

the object it moves  =  the supervision signal used to train the student embedding model
The hidden quantity

The hidden quantity

measured quantity  =  cross-modal relational structure inside the teacher

The hidden quantity is the teacher's internal relational map: which image regions correspond to which phrases and how those units relate to each other. That structure is usually not supervised directly by the dataset. It emerges inside the large teacher because the teacher has enough capacity to organize objects, phrases, and their relations.

HieRD exposes that structure in a transferable form. It clusters visual patch features, where each feature is one local list of numbers produced from a patch or region, into larger groups that approximate object parts. It also builds phrase-level text units. Distillation then compares not just individual units but also their pairwise and cross-modal relations, so the student is trained to preserve the teacher's fine discrimination cues.

Why it works

Why hierarchical relational distillation works

Global alignment alone is too weak because many different pairs can share a similar sentence-level meaning. For instance, two images may both match 'a person holding a cup' while differing in background, object count, or spatial arrangement. A student trained only on the final embedding is free to compress away those details because the distillation target never checks them.

Clustering visual patch features raises the supervision level from raw patches to semantically larger units. That matters because a single patch may contain too little context, while an object-like cluster can support stable links to phrases such as 'red cup' or 'left hand.' Phrase-level text features do the same on the language side by isolating the parts of the sentence that identify objects and relations.

Relational matching is the key extra step. The student is not only told that one image part matches one phrase. It is also told how the image parts relate to each other and how the phrase units relate to each other. That lets the small model preserve ordering, co-occurrence, and spatial cues that drive exact retrieval. The result is a compact student that remains discriminative because its internal space still carries structured correspondences instead of only broad category overlap.

Combine global and relational distillation losses

First in words:

A simple summary is that the student minimizes one loss for whole-example alignment and another for the local and relational structure copied from the teacher.

Then the compact form:

L = L_global + lambda * L_rel

Every symbol:

Ltotal distillation loss
L_globalloss that aligns the student's global embeddings with the teacher's global embeddings
L_relloss that aligns local part-phrase correspondences and their relations
lambdaweight placed on the relational part of the objective
A tiny worked example
Suppose two candidate images both match the sentence 'a child holding a kite.'
Global-only distillation may place both images near the sentence because both contain a child and a kite.
Relational distillation adds pressure for the student to preserve which region corresponds to the kite phrase and how that region is positioned relative to the child region.
That extra pressure moves the correct image closer and the near-miss farther away in the student's retrieval space.

The paper uses a richer multi-granular objective, but the core tradeoff is captured by this split between coarse global copying and finer relational copying.

What can go wrong

What can go wrong

Clusters may not line up with true objects. If the visual patch-feature clusters split one object into several groups or merge unrelated regions, the local distillation targets become noisy because the student is asked to match unstable part definitions.
Phrase extraction can miss the decisive text unit. If the text side fails to isolate a key phrase such as a relation or attribute, the student may still lose the cue that separates the correct retrieval target from a near miss.
Relational losses can be expensive. Matching many local units and pairwise relations increases training cost because the student must compare far more structure than in global-only distillation.
Done right. The method works when visual clusters are semantically stable, phrase units capture the main object and relation cues, and the relational loss is strong enough to matter without overwhelming the student's limited capacity.
What a runnable demo should prove

What a runnable demo should prove

Build a teacher-student retrieval setup on image-caption pairs with many hard negatives that share the same broad category. Distill one student with global embedding matching only and another with added object-cluster and phrase-level relational targets. Evaluate not just top-level retrieval but also hard-negative rejection where two candidates differ by one object or one relation.

The demo should show that the relationally distilled student rejects near misses more often, because it preserved the internal correspondences needed to distinguish fine details rather than only topic-level similarity.

hard_negative_gap = recall_with_HieRD - recall_with_global_only

A strong result is a wider hard-negative gap than overall retrieval gap, because that indicates the extra supervision improved fine discrimination instead of only shifting all scores upward.
