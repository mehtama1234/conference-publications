CONSIGN: Spatial Groupings for Honest Uncertainty

When a segmentation model tags every pixel, CONSIGN wraps its guesses in spatially-aware confidence regions that are honest about uncertainty without being wastefully large.

Paper explainersAll themesOther

Segmentation models chop images into regions and assign a class label to each pixel. Those labels come with a confidence score—a guess at how likely the prediction is right. The problem: those scores are often pure heuristic, not actually reliable. And even if you fix that, treating each pixel in isolation ignores a big structural fact about images: nearby pixels almost always belong to the same region. CONSIGN fixes both: it takes any segmentation model, converts its heuristic scores into rigorous, calibrated uncertainty sets, and uses the pixel-to-pixel correlations to shrink the size of the uncertainty without losing the guarantee.

Zero assumption version

Models guess, but don't admit when they're unsure

Segmentation is the task of coloring each pixel in an image with a class label—sky, grass, person, car. A neural network trained on labeled images learns to do this, pixel by pixel. It outputs a confidence score for each pixel: how sure it is that the color is right.

The catch: that confidence score is just a number the network learned to produce. It is not a real probability—it does not rigorously say how often the model is right. In medical imaging, self-driving cars, and other high-stakes domains, you need to know: if the model says this tumor boundary is a prediction set of {tumor, unclear}, is that set actually correct at least 95% of the time?

A naive fix: apply conformal prediction, a method that calibrates any model's guesses into statistically valid uncertainty sets. But conformal prediction typically treats each prediction separately. For segmentation, that means each pixel's uncertainty set is built independently. This is wasteful: in reality, if pixel (i, j) is in a cow, then pixel (i+1, j) is almost surely also in a cow. By ignoring that correlation, the sets become so huge they are useless.

The tension. Make uncertainty sets statistically honest without ignoring the spatial structure that pixels share.

The algorithm as a flow

What it actually does

Step 1: Sample the model multiple times

Run the segmentation model multiple times (with dropout, or an ensemble) to get N different guesses at the segmentation, all slightly different.

Step 2: Find the spatial basis

Use SVD (a standard math technique) to decompose the differences between those sample segmentations into a small set of directions that capture where uncertainty lives.

Step 3: Estimate bounds on the directions

For each direction, measure how far its weight can range (using quantiles) and set symmetric bounds around that range, scaled by a tuning value.

Step 4: Calibrate to hit your target error rate

Tune the calibration value so that when you form prediction sets by combining directions within bounds, the ground truth is inside at least 95% (or your chosen rate) of the time.

Step 5: Prediction sets respect the spatial structure

Because you built sets from shared directions, nearby pixels get correlated uncertainty. Sets are smaller and smoother than pixel-wise conformal.

What the paper changes

The thing that changes: decomposition basis

Conformal prediction normally produces sets C(x) for each input x, containing plausible class labels at each pixel. Standard conformal builds these independently per pixel, ignoring the spatial pattern.

CONSIGN changes the basis for building those sets. Instead of tuning bounds separately for each pixel, it extracts a small set of spatial directions (via SVD) that describe where the segmentation is uncertain, then builds bounds on the coefficients of those shared directions. The result: nearby pixels inherit the same bounds, so their uncertainty sets are correlated and coherent.

The hidden quantity

The hidden quantity: uncertainty direction strength

measured quantity  =  the principal component coefficient range

When you decompose uncertain segmentations via SVD, you get a set of rank-1 directions (matrices) and a set of singular values (numbers) that tell you the strength of each direction. Each direction is a pattern of where the model is confused.

CONSIGN uses the singular values as the hidden signal. A large singular value means that direction carries a lot of variance in the model's guesses—it is a real source of uncertainty. A small value means that direction barely matters. The paper estimates how far the coefficient along each direction can range, then builds bounds that scale with the singular value—important directions get tighter constraints to ensure coverage guarantees hold.

Why it works

Why it works: spatial structure shrinks uncertainty without losing guarantees

Here is the causal chain. First, a segmentation model's predictions have internal spatial structure—nearby pixels almost always agree. When you draw multiple sample predictions (by running the model with dropout or ensembling), the deviations from the mean are not random noise scattered everywhere. They cluster in spatial patterns: boundary regions where the model is confused, interior regions where it is sure. Those patterns can be captured by a small number of dominant directions via SVD.

Second, standard conformal prediction calibrates uncertainty by asking: if I build a prediction set for each pixel independently, how large must the sets be to guarantee that the ground truth falls inside, say, 95% of the time? The answer depends on how uncertain each pixel is. But pixel-by-pixel calibration ignores the spatial correlation: if pixel (i, j) is in a cow and pixel (i+1, j) is also in a cow, their uncertainties should be correlated, not independent. Treating them separately forces each set to be so large that 'pixel (i, j) is one of {cow, grass, sheep}' and 'pixel (i+1, j) is one of {cow, grass, sheep}' together cover the truth 95% of the time. That is inefficient.

CONSIGN exploits spatial structure by building sets from shared directions. Instead of calibrating independent bounds for each pixel's labels, it calibrates bounds on the coefficients of the dominant spatial directions. Because every pixel's uncertainty depends on a small shared set of directions, nearby pixels inherit correlated bounds. The set of plausible segmentations shrinks dramatically—instead of independently choosing labels at each pixel, you move along a few spatial 'knobs,' and each knob is constrained tightly. The statistical guarantee still holds because the calibration procedure (quantile-based bounds on coefficients) is designed to hit the target coverage rate, and the theory says that if you calibrate on a hold-out set, your bounds will hold on the test set.

Math after the picture

The core equation

First in words:

prediction set = all segmentations y where each principal component coefficient stays within its calibrated bounds

Then the compact form:

C_lambda(X) = { Y : exists c in K_times[A_k, B_k] such that Y_beta = P(mu(X) + sum_k c_k u_k(X)) }

Every symbol:

C_lambda(X)the prediction set for image X (a set of plausible segmentations)
lambdathe calibration tuning parameter (higher = smaller sets, stricter bounds)
mu(X)the mean segmentation from all N sample predictions
u_k(X)the k-th spatial direction (principal component) from SVD
c_kthe coefficient (weight) on direction k
A_k, B_kthe lower and upper bounds for coefficient k (calibrated using quantiles and singular value Sigma_k)
Pthe quantization step that converts continuous activations to discrete class labels
Y_betathe final segmentation mask after quantization
A tiny worked example
Suppose SVD extracts 2 directions: u1 (boundary uncertainty) and u2 (region merging).
Singular values: Sigma_1 = 8.0 (u1 is important), Sigma_2 = 2.0 (u2 is weak).
From the calibration set, quantile bounds on c1 coefficients: [-0.4, +0.4]. Quantile bounds on c2: [-0.2, +0.2].
With lambda=1.0, the algorithm sets A1 = -0.4, B1 = +0.4 (u1 bounds unchanged).
For u2 (Sigma_2 smaller), the algorithm scales: A2 = -0.1, B2 = +0.1 (u2 bounds tighter).
Prediction set includes all segmentations y reachable by combining the mean with 0.4*u1 + c2*u2, where c2 is in [-0.1, +0.1].
Result: u1 can vary across its full range (boundary can move), but u2 is clamped (merging is forbidden). The set is smaller than allowing both directions free play.

The bounds on the principal component coefficients (which scale with the singular values) replace independent per-pixel bounds, shrinking the prediction set while preserving the coverage guarantee.

What can go wrong

What can go wrong

Pathological singular values. If the SVD directions have zero or nearly-zero singular values, or if the principal components are poorly aligned with the actual segmentation boundaries, the algorithm may fail to converge. The paper notes that in rare cases lambda can grow unboundedly without achieving the target coverage.
K is too small. If you keep only 2 or 5 dominant directions but the real uncertainty lives in higher-order modes, your bounds on those K directions will be too loose to capture the full variability. The sets will be larger than necessary.
Model does not produce coherent samples. CONSIGN requires the model to generate multiple plausible segmentations (via dropout, ensembles, or Bayesian variants). If the model outputs are all nearly identical, or if the samples are incoherent noise rather than structured variations, the SVD basis does not capture the real spatial structure.
Done right. Use an ensemble or Bayesian model with reasonable diversity. Verify that the K dominant directions capture most of the variance (check singular values drop sharply). Calibrate on a held-out set and test on a disjoint set to ensure the coverage guarantee holds.
What a runnable demo should prove

What a runnable demo should prove

Take a pre-trained segmentation model (e.g., U-Net on medical imaging data). Run it 20 times with dropout enabled, or use an ensemble of 20 models. Compute the mean segmentation and the deviations.

Apply CONSIGN: extract 3 principal component directions via SVD, estimate quantile bounds on their weights, and calibrate a single tuning value on a hold-out calibration set so that the predicted sets contain the ground truth at least 95% of the time.

Compare against the pixel-wise conformal baseline: for each method, measure (1) coverage (fraction of test images where the ground truth segmentation is inside the prediction set, should reach 95%), (2) set volume (mean count of plausible segmentations per image; lower is better because it means the uncertainty is tighter), (3) boundary smoothness (standard deviation of label transitions between adjacent pixels; higher means smoother, more coherent sets because nearby pixels share the same bounds).

The key result: CONSIGN achieves the same coverage (95%) as the baseline but with substantially smaller set volume and smoother label boundaries.

set_volume = log( count_of_reachable_segmentations ); smoothness = mean_variance_of_adjacent_labels; coverage = count_images_with_truth_in_set / total_images

Show that accounting for spatial correlation shrinks the uncertainty without violating the statistical guarantee.
