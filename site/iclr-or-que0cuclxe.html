Bootstrapping MLLM for Weakly-Supervised Class-Agnostic Object Counting

A visual model learns to count any object type using only image-level counts instead of marking each object, by breaking counting into simpler dialogue steps and fusing local and global predictions.

Paper explainersAll themesComputer Vision

Object counting (estimating how many of something appear in an image) normally requires laboriously marking every single object by hand. This paper shows how a visual model can learn to count from much weaker labels: just the total count per image, not the location of each object. It works by asking the model to think aloud through dialogue, rank images by their counts, and combine nearby and full-image counting strategies.

Zero assumption version

Counting costs too much to annotate

To teach a model to count, you normally point at each object in every training image. For a photo with fifty people, that is fifty clicks. For datasets with millions of images, this is months of human labor.

A beginner might hope to teach a model by just showing it images and their counts (fifty people in this photo, thirty in that one), without marking each one. The model should infer how many is in the picture. But naive visual models struggle: they learn shortcuts like 'image brightness is linked to density' rather than learning to actually spot and tally objects. They fail on new datasets where the shortcut breaks.

In one sentence. The paper teaches a visual model to count using only the image-level total count as supervision, not the location of each object.

The algorithm as a flow

What it actually does

Divide-and-discern dialogue

Model asks is the count 0-50 or 50-100? Narrows range each round.

Compare-and-rank learning

Train model to rank image pairs: if image A has more objects, rank it higher.

Local counting on patches

Split image into overlapping tiles, count objects in each.

Global full-image counting

Estimate count from entire image at once.

Fuse local and global

Average or weight local tile predictions with global prediction for final count.

What the paper changes

What the paper changes

Instead of adding point-level location labels (which is expensive), the paper changes how the model is trained: it uses three simple strategies that turn counting into easier sub-tasks, and trains the model to solve those instead.

The hidden quantity

Counting confidence: what the model is really learning

measured quantity  =  relative-rank confidence

The paper introduces a hidden quantity: how confident is the model that image A has more objects than image B? This is not the count itself, but a ranking signal (A > B, B > C). Training on this ranking is easier than predicting the exact number, because it forces the model to extract the visual features that actually distinguish high-density from low-density regions.

The paper measures this by comparing predictions on image pairs: when the model sees two images, does it correctly say which one is denser? That accuracy is the hidden ranking-confidence score. In the dialogue strategy, a hidden quantity is also the narrowing of the range each round: after each question, how much smaller is the remaining possibility? Tighter bounds mean higher confidence.

Why it works

Why the method works: three simpler puzzles instead of one hard one

Predicting the exact count from weak labels is hard because the model must reverse-engineer the object locations from only a total number. Instead, the paper breaks it into three easier puzzles, and the model learns all three.

First, dialogue narrows the search space: asking 'is it 0-50?' is a yes/no question, much easier than guessing 47 exactly. Each round cuts the range in half, and the model gradually homes in. This works because the visual features that distinguish sparse from dense are learned in parallel.

Second, comparing images teaches the model what density looks like: if A has 80 objects and B has 20, the model must learn visual patterns of crowding. Ranking does not require the model to know the exact count, only which is more crowded. This is a simpler task than finding the exact number.

Third, local and global predictions are fused: some objects cluster in image corners (local detection catches them), while the full image gives context for overall density (global detection). Neither alone is perfect. Averaging them smooths out each predictor's mistakes because they fail in different places. A corner patch misses global trends, and a global view misses small clusters, but together they cover the blind spots.

Math after the picture

Ranking loss: learning relative density

First in words:

penalty = compare-and-rank margin loss; for each pair of images with known ordering, penalize the model if it predicts the wrong rank order, weighted by how far the counts are in the pair

Then the compact form:

L_rank = sum over (image_i, image_j) where count_i > count_j: max(0, margin - (pred_i - pred_j))

Every symbol:

pred_imodel's predicted count for image i
pred_jmodel's predicted count for image j
count_iground truth count for image i
marginminimum gap the model must achieve (e.g., 5 objects)
L_rankthe ranking penalty for this pair
A tiny worked example
Image A: true count 80, model predicts 75. Image B: true count 30, model predicts 40.
Since A has more objects (80 > 30), we require model prediction A > B, i.e., 75 > 40. This holds.
Margin = 5. Gap achieved = 75 - 40 = 35. Penalty = max(0, 5 - 35) = 0 (model did well).
Image C: true count 60, model predicts 55. Image D: true count 50, model predicts 58.
C should rank higher (60 > 50), but model says D > C (58 > 55). Wrong order.
Penalty = max(0, 5 - (55 - 58)) = max(0, 5 - (-3)) = 8 (model is penalized).

The margin prevents lazy predictions; the model must confidently rank denser images higher, which forces it to learn real visual crowding cues.

What can go wrong

What can go wrong

Dialogue gets stuck at coarse ranges. If the model's binary questions are poorly tuned (e.g., always asking 0-50 vs. 50-100), it does not refine well. Adaptive range selection is needed—the dialogue must adjust based on what earlier questions revealed.
Ranking signal is weak on similar images. When two images have very similar object counts (78 vs. 80), the compare-and-rank loss gives little gradient—the model does not learn much from that pair because the gap is small. Training on diverse count ranges helps, because large gaps (e.g., 20 vs. 80) produce strong rank signals that teach the model clear crowding patterns.
Local and global predictions conflict. If local patches cluster detection in one corner and global sees a uniform image, fusing them by averaging can yield a count between two wrong answers. Adaptive weighting (trust local in dense regions, global in sparse) is better than simple averaging because each method's strength complements the other: local detectors excel at tight clusters but miss spread-out objects, while global detectors catch overall density but blur fine structure. Weighting each by where it succeeds avoids the compromise of averaging two weak estimates.
Done right. Dialogue uses adaptive ranges; training pairs span low to high counts; local and global predictions are learned jointly so they complement rather than contradict.
What a runnable demo should prove

What a runnable demo should prove

A minimal demo should start with a small image dataset where you know the true object counts (e.g., 20 images of scattered dots, with counts 5-95). Train the three-strategy model on only the image-level counts. Then measure: (1) can it rank image pairs by density correctly? (2) do the local and global count predictions agree roughly? (3) is the final fused count close to the true count? Plot the model's predicted counts against true counts; the points should lie near the diagonal, not scattered.

ranking_accuracy = fraction of image pairs where model predicts higher count for the denser image; count_error = mean absolute difference between predicted and true counts

If ranking accuracy exceeds 90% and count error drops below 10% of the average count, the paper's strategy is working: the model learned to spot density without point labels.
