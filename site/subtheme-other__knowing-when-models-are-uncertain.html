Knowing when models are uncertain

Papers studying how to measure and communicate what a model doesn't know—calibration, uncertainty bounds, and confidence scores that readers can trust.

All themesField mapMathematicsAll explainers
What this is

A model that always outputs a guess, even when it has no confidence, is dangerous. If a medical AI diagnoses disease with the same certainty for a clear X-ray and a blurry one, doctors can't know which diagnosis to trust. If a self-driving car is equally sure about the distance to an obstacle whether the camera is clear or obscured by rain, it will crash. The solution is uncertainty quantification — making the model express how confident it is, not just what it thinks the answer is.

The challenge is that confidence is not obvious from a model's output. A neural network might output the same probability for a prediction whether it has seen similar examples a thousand times or never at all. Real uncertainty has many layers: uncertainty about what the input actually is (the rain on the camera), uncertainty about whether the model has learned the right pattern (did it learn the real rule or memorize examples), and uncertainty about the world itself (the thing you are trying to predict is inherently noisy or random). You need techniques to capture all of these kinds of uncertainty, not just report a single confidence number that could be meaningless.

Researchers build uncertainty estimates using multiple approaches. Some train many models and look at how much their predictions disagree — if they all agree, probably they are right, if they all disagree, probably the input is ambiguous. Some use probability theory to model not just what the prediction should be but how much uncertainty there is around it. Some measure calibration — whether a model that says it is 90% confident really is correct 90% of the time. The goal is a confidence score that a human can actually act on.

How the work breaks down

Measuring what a model does not know splits into five directions. Some papers train many models to see how much they disagree, since disagreement signals when the input is hard. Others build prediction sets that promise to contain the right answer so humans can trust the bounds. More papers improve calibration—making confidence scores match reality so a 90% confidence prediction is actually right 90% of the time, which means doctors or engineers can act on the score without second-guessing. Some tackle specific problems like segmentation or long-tailed data where standard methods break. And some use probabilistic theory to model uncertainty directly to capture all kinds of unknowns at once.

Calibration: match confidence to truth

A model can output probabilities without them meaning anything real. If a model says it is 90% confident but is only right 70% of the time, those numbers lie. The core problem is that training a model to minimize prediction error does not automatically make it well-calibrated—the model learns what the answer is, not how sure it should be about each kind of input.

CLEAR directly optimizes both calibration and the width of confidence intervals across 17 different datasets, improving interval width by 28% on average while keeping the coverage promise of "this interval contains the right answer 90% of the time". The nonparametric regression approach to re-calibration rebuilds confidence estimates after the model is trained by learning from the model's own mistakes to fix its overconfidence—it does this without assuming anything about what the error patterns look like, which means it works on any kind of data. GEM-FI (Gated Evidential Mixtures) improves calibration through single-pass inference (computing the output in one forward pass) that gates evidence from multiple sources and uses Fisher modulation to smooth the estimates so they become more truthful, raising accuracy on standard benchmarks while reducing the Brier score (a measure of calibration quality). Together these papers show that calibration is a learnable skill that can be added to any model after training, so even models trained without uncertainty in mind can be fixed.

Prediction sets: guaranteed coverage

Sometimes the right answer is not a point but a set. Instead of guessing "the disease is tuberculosis," the model outputs "the disease is one of: tuberculosis, pneumonia, or bronchitis," and promises that its guess is in the set with 90% probability. This approach, called conformal prediction, trades precision for honesty—the set might be large when the input is ambiguous, but the coverage guarantee holds even when the model is wrong.

CONSIGN applies conformal prediction to segmentation, where every pixel must be assigned to a class. The challenge is that pixels are not independent; predicting one pixel affects how you think about neighbors. CONSIGN uses spatial grouping to decompose the segmentation problem and maintain high-probability error guarantees across medical and common object images. Conformal Prediction for Long-Tailed Classification solves a different hard case: when some classes have thousands of examples and others have only ten, the model is tempted to ignore the rare classes. Conformal methods guarantee marginal coverage (across all classes equally) even on 1000-class datasets like Pl@ntNet-300K. Flow-based Conformal Prediction for Multi-dimensional Time Series extends the idea to sequences where the next value depends on the past, keeping sets small while maintaining coverage. Spatial Conformal Inference through Localized Quantile Regression handles geographic data where predictions should be smooth across space. Together these papers show that coverage guarantees can work on real, complex, structured data.

Bayesian uncertainty: probability over the full picture

Instead of a single point prediction with a confidence number, Bayesian methods model the whole probability distribution over possible answers. This captures all flavors of uncertainty at once: aleatoric (the world is inherently random), epistemic (the model has not seen enough data), and approximation (the learning algorithm is imperfect). The hardest part is computing these distributions without taking forever.

The End-to-End Probabilistic Framework for Learning with Hard Constraints handles a practical case: when you know the answer must satisfy constraints (like a differential equation), computing probabilities over possible answers subject to those constraints is expensive. This paper builds a framework that learns uncertainty while respecting constraints in PDEs and time-series forecasting without assuming the noise has any particular shape. Variational Routing: A Scalable Bayesian Framework for Calibrated Mixture-of-Experts Layers applies Bayesian thinking to modern large models by treating Mixture-of-Experts layers (where different parts of the model activate for different inputs) as uncertainty decisions; the routing itself becomes probabilistic so the model expresses doubt by being uncertain which expert to ask. Distribution Transformers: Fast Approximate Bayesian Inference speeds up the usual slow Bayesian computation from minutes to milliseconds by learning to adapt starting assumptions (priors) on-the-fly, making Bayesian methods practical for real-time applications. Gaussian Mean Field Variational Inference can Overestimate Predictive Variance shows a subtle trap: the most common way to approximate Bayesian posteriors (mean-field variational inference) has weird quirks and can output overconfident intervals that temperature adjustment can fix. These papers build the computational and theoretical tooling to make uncertainty estimates practical.

Disagreement and ensemble uncertainty

If you train many models on the same data, they will make different mistakes because they start from different random seeds and learn different patterns. The amount they disagree is a signal: high disagreement means the input is ambiguous or out-of-distribution; low disagreement means the models are confident. Ensemble uncertainty is fast and intuitive, but the challenge is that disagreement alone misses some kinds of uncertainty.

The paper on identifying which neural pathways stay reliable uses few-shot adversarial mask tuning to find which parts of a vision-language model work well across different test distributions, showing which learned patterns will transfer to new situations. Complementing Self-Consistency with Cross-Model Disagreement improves uncertainty by combining two signals: how much a single model agrees with itself on slightly different runs (self-consistency) and how much different models disagree (cross-model disagreement). Together these catch more failing predictions than either signal alone and flag confident failures that disagreement by itself would miss. Post-hoc Probabilistic Vision-Language Models provides calibrated uncertainty by wrapping existing models (which were trained without any uncertainty objective) with a probabilistic layer that learns from the model's residuals. This approach gives practitioners a way to add confidence scores that actually correspond to accuracy to models that are already deployed, which is valuable for safety-critical vision tasks like medical diagnosis.

Uncertainty for data: detection, active learning, and data quality

Uncertainty is useful not just for understanding model predictions but for deciding which data to collect next, detecting when data is corrupted, and knowing when a model is out of its training distribution. These papers tackle practical questions: how to recognize bad or out-of-distribution data, how to pick which examples to label first, and how well uncertainty estimates hold up when the data changes.

Beyond Magnitude: Scale-Invariant Evidential Fusion identifies a flaw in how existing uncertainty methods fuse information from multiple views: they confuse how far the model committed (logit magnitude) with how right it is (semantic confidence), letting bad data fool the model through semantic hijacking. This paper fixes evidential fusion by making it scale-invariant so only the direction of evidence matters. Efficient Credal Prediction through Decalibration enables uncertainty on models that were never designed for it, like CLIP and TabPFN, by learning to undo their calibration failure after training—so prediction sets now work on vision-language models. Frozen Priors, Fluid Forecasts uses the model's expectations from pretraining (priors) as a fixed anchor and builds uncertainty estimates for the next word in the sequence on very small datasets, achieving 90% coverage on held-out test sequences with just 20 samples. Models That Predict Sequences Well Handle Low-Quality Data shows that models that predict sequences word-by-word stay accurate with bad data while diffusion models (which build images by gradually removing noise) fail catastrophically, linked to how much conditioning information they use. Uncertainty Estimation via Hyperspherical Confidence Mapping provides interpretable, deterministic uncertainty by mapping predictions onto a hypersphere where distance encodes confidence—competitive with ensembles but faster to run. Together these papers show uncertainty is not just about the model's predictions but about the data and the model's relationship to it.
