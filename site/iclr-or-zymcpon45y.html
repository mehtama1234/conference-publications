Through the Lens of Contrast: Self-Improving Visual Reasoning in VLMs

VC-STaR improves visual reasoning by generating rationales from paired, visually similar questions so the model must focus on the small visual differences that actually determine the answer.

Paper explainersAll themesMultimodal

Self-improvement works well in language tasks because a model can often check whether its own reasoning text is internally consistent. Visual reasoning is harder. A fluent rationale can mention objects or details that are not in the image, and the model has no easy way to catch that from text alone. VC-STaR uses contrast to create a stricter check, because a rationale now has to explain why two similar cases lead to different answers. It pairs two similar images with synonymous questions and asks the model to explain each one while considering the pair together. The pair forces the model to focus on the visual differences that separate the answers, which reduces hallucinated rationale steps and produces better supervision data for later fine-tuning because shared or invented details no longer explain the answer gap.

Zero assumption version

Why self-improvement is hard in visual reasoning

In text-only reasoning, a model can often revise a flawed explanation by checking whether the steps contradict each other. In image reasoning, the main failure is different: the rationale may refer to a visual detail that never existed. Once that hallucinated detail enters the explanation, later reasoning can remain internally neat while still being false.

Training on such rationales is dangerous because the model is rewarded for sounding grounded without actually being grounded. A large visual reasoning dataset built from unverified rationales can therefore teach the model to repeat the same false cue patterns.

The paper's observation is that models identify visual cues more precisely when they are shown a contrastive pair. This helps because the model is pushed to state what differs between the two images rather than freely narrating whichever detail first comes to mind.

The fix. Create pairs of similar visual question answering samples, generate rationales with both items visible at once, and use the pairwise contrast to keep the rationale tied to the discriminating visual cues.

The algorithm as a flow

What it actually does

Curate contrastive pairs

Collect visual question answering examples that are similar in both image content and question meaning, but whose answers depend on a small visual difference.

Prompt the model with the pair

Show both items together and ask for rationales that explain each answer while noting the discriminating cues.

Keep grounded rationales

Use the contrastive setup to filter for explanations that point to the actual difference between the pair instead of generic scene descriptions.

Build a reasoning dataset

Aggregate the accepted rationales into VisCoR-55K, a supervision set for later training.

Fine-tune downstream vision-language models

Train new models on the contrast-grounded rationales so the improved cue selection transfers to ordinary single-image reasoning.

What the paper changes

What the paper changes

The paper changes how self-generated supervision is created. Instead of asking a model to explain one image in isolation, it asks for an explanation in the presence of a matched comparison item. That changes the pressure on the rationale: useful steps are the ones that separate the pair, while irrelevant or hallucinated details become less useful because they do not explain why the answers differ.

The hidden quantity

The hidden quantity: discriminating visual cue strength

measured quantity  =  How strongly a rationale is tied to the pair's real differences

The relevant quantity is discriminating cue strength. A rationale has high strength when its key steps refer to image details that distinguish one item in the pair from the other. It has low strength when the explanation leans on details that both images share or on details that neither image clearly shows.

This quantity matters because the goal is not merely to produce long explanations. The goal is to produce explanations whose decisive steps would fail if the wrong visual difference were removed. Pairwise contrast exposes that dependence directly.

Why it works

Why contrast reduces hallucinated rationales

A hallucinated cue is hard to detect when one image is viewed alone because the model can always weave that cue into a plausible story. In a contrastive pair, the explanation must account for why the answers differ across two nearly matched cases. If a cue is shared by both images, it cannot explain the difference, so it loses explanatory value immediately.

That changes the learning signal in two places. During rationale generation, the model is pushed toward cue selection that is specific to the answer difference. During later fine-tuning, the new dataset teaches future models that a useful rationale is one whose critical steps are visually discriminative. This works by making grounding part of the supervision source, not only part of the downstream evaluation.

Math after the picture

The pairwise rationale objective

First in words:

Prefer rationales that support the right answer for one image while staying inconsistent with the other image when the crucial visual difference is absent.

Then the compact form:

Score(r) = Fit(r, I_1, q_1, a_1) + Fit(r, I_2, q_2, a_2) - lambda * SharedOnly(r)

Every symbol:

ra candidate rationale
I_1, I_2the two images in the contrastive pair
q_1, q_2their synonymous or closely matched questions
a_1, a_2the target answers
Fithow well the rationale supports the correct answer on each image
SharedOnly(r)penalty for rationale content that only describes what both images share
lambdahow strongly shared, non-discriminating content is penalized
A tiny worked example
Image 1 shows two red cups; Image 2 shows one red cup. Both questions ask for the number of cups.
Rationale A says, 'The cups are on a table.' That fits both images but does not explain the answer difference, so its shared-content penalty is high.
Rationale B says, 'Count the visible cups: there are two in the first image and one in the second.' That directly fits the pairwise difference.
The scoring rule therefore keeps Rationale B and drops Rationale A, even though both are fluent and visually plausible.

The precise implementation can vary, but the central pressure is always the same: reward answer-relevant differences and downweight shared filler.

What can go wrong

What can go wrong

The pair is not truly contrastive. If the two items differ in many unrelated ways, the model has too many possible explanations and the contrast no longer isolates the answer-critical cue.
Question meanings drift. The method depends on synonymous or closely matched questions. If one question asks about count and the other asks about color, the pair no longer supports a clean contrast.
Grounded rationales can still be incomplete. A rationale may cite the right visual difference but omit an extra step needed for the final answer. The pair reduces hallucination pressure, but it does not guarantee full logical completeness.
Done right. Use tightly matched pairs, keep only rationales that explicitly mention the answer-determining difference, and fine-tune on that filtered set rather than on raw self-generated explanations.
What a runnable demo should prove

What a runnable demo should prove

Create a small paired benchmark from ordinary visual question answering data by matching similar images and closely matched questions. Generate rationales once from single images and once from contrastive pairs. Then fine-tune the same base vision-language model on each rationale set and compare downstream performance and rationale grounding quality.

Answer accuracy, rationale grounding rate, and frequency of shared non-discriminating rationale steps

The demo should show that the pairwise supervision set is stronger because it teaches the model to name the visual difference that controls the answer, not just to produce longer explanations.
