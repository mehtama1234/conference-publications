Quantifying Long-Range Interactions in Graph Neural Networks

A new dataset and measurement technique reveal how far graph neural networks can actually see and learn from distant nodes.

Paper explainersAll themesGraph & Geometric Learning

Most graph neural networks learn by passing information between nearby nodes, like friends whispering to friends. But in large real-world networks (like city road maps), important decisions often depend on nodes that are very far away. This paper introduces City-Networks, a new dataset of massive real-world road networks, and a technique to measure how much a node's decision actually depends on distant neighbors.

Zero assumption version

Why we don't know if graph models see far

Graph neural networks come in two flavors. Local models pass information only between adjacent nodes, one neighbor at a time, with each intermediate node adding its own signal. Global models (transformers) let every node directly consider every other node at once. The question is: do we actually need the global view, or can local models see far enough?

The old datasets don't answer this. They are small (thousands of nodes) and artificial, built for quick training tasks. In real networks (like the roads in a city), you have hundreds of thousands of nodes and distances that matter. A local model might need to pass information through many hops to reach a distant node. The old benchmarks never test whether models learn information that comes from far away or whether they lose the signal after a few steps.

The problem. We need a real, large dataset where the answer actually depends on nodes that are many hops away, and a way to measure how much each model uses those distant connections.

What it actually does

Build City-Networks dataset

Use real road networks from cities; annotate each node with the farthest road in its eccentricity neighborhood.

Define the learning task

Given a node's local neighbors, predict a property that only makes sense by knowing distant nodes.

Train graph models

Train both local (message-passing) and global (transformer) models on the task.

Compute Jacobian sensitivities

For each prediction, measure how much each node's input changed the output, grouped by distance.

Compare influence by distance

See which models actually use information from distant nodes and which stop after a few hops.

What the paper changes

What the paper moves

The paper does two things. First, it creates a new dataset (City-Networks) where success requires learning from far away. Second, it introduces a measurement (Jacobian-based influence) that quantifies how much a model's decision actually depends on nodes at each distance.

the object it moves  =  Distance-aware influence measurement
The hidden quantity

The influence gradient: how much each distance matters

measured quantity  =  Influence by hop distance

The hidden quantity is: for a single prediction, how much does changing the input of a node at distance k change the model's final answer? This is called the Jacobian derivative. A Jacobian (a matrix of how much each input affects each output) tells you the influence of each neighbor. By grouping neighbors by their distance from the target node, the paper measures influence as a function of distance.

The paper estimates this by taking the gradient of the model's prediction with respect to input features of nodes at each hop. A large gradient means changing that node's input would change the output a lot; a tiny gradient means the model ignores that node. By averaging these Jacobians across many examples, the paper shows which distances matter.

Why it works

Why far distances matter for this task

In a road network, the farthest road from an intersection is a global property of the network topology, not something nearby. If you stand at one intersection and only look at your neighbors, you don't know if you're in a suburb or a sprawling downtown. You need to know the overall shape of the network, which means propagating information through many hops.

A local message-passing model can only combine information from neighbors one hop at a time. After k layers, it has seen up to k hops away. But if the farthest relevant node is 50 hops away, the local model needs 50 layers just to receive the signal. Deep models become unstable (over-smoothing: all nodes' representations blend into the same average). So local models either run out of depth or gradually forget the distant signal because noise and averaging wash it out.

A global (transformer) model lets every node directly consider every other node in one step. It can directly measure the distance from each node to the farthest neighbor, without having to propagate through intermediaries. The influence stays crisp even from far away, because the model's weights (numbers being learned) are not reused through hops; they compute a direct link from input to output.

Math after the picture

Measuring influence: the Jacobian at each distance

First in words:

For a model that outputs a prediction from a node's neighborhood, the influence of distance k is the sum of squared derivatives of the output with respect to features of all nodes at distance k, averaged over examples.

Then the compact form:

influence(k) = mean over examples [ sum over nodes at distance k of ( d(output) / d(node_input) )^2 ]

Every symbol:

outputthe model's prediction (e.g., predicted distance to farthest node)
node_inputthe features of a single node at distance k
d(output) / d(node_input)how much the output changes if this node's input changes
distance kthe number of hops from the target node
A tiny worked example
For one example, node at 1 hop has gradient magnitude 0.8; node at 2 hops has gradient 0.3.
d(output) / d(node1_input) = 0.8 -> squared = 0.64
d(output) / d(node2_input) = 0.3 -> squared = 0.09
Average over 100 examples: influence(1 hop) = 0.64, influence(2 hops) = 0.09.
This model cares 7x more about 1-hop neighbors than 2-hop neighbors (0.64 / 0.09 = 7.1).

Larger squared gradients mean the model pays more attention to nodes at that distance; zero gradient means the model ignores that distance completely.

What can go wrong

What can go wrong

Jacobian bias from model size. Larger models have larger gradients by default. Comparing raw Jacobians across differently-sized models misleads you. Normalize by model capacity first.
Over-smoothing hides the signal. If a local model has too many layers, all node representations become nearly identical and the Jacobian drops to zero everywhere. The model did not learn the task; it gave up. You must check validation accuracy alongside influence.
Dataset biases influence distances. If the road network has clusters (neighborhoods separated by highways), nodes at distance 20 within a cluster might be more relevant than nodes at distance 5 in another cluster. Eccentricity-based labeling should account for network community structure.
Done right. Control model size, check task accuracy, and separately verify that influence correlates with task difficulty (nodes that need distant information should show high influence from distance).
What a runnable demo should prove

What a runnable demo should prove

Build a tiny demo: take a real road network of 500-1000 nodes, choose 3-5 nodes at different eccentricities (near the center vs. at the periphery), train a local 3-layer message-passing model and a global transformer model on predicting eccentricity, and compute the Jacobian influence histogram for each model. The demo must show: (1) the transformer's influence stays above zero for large distances because it computes a direct link to every node in one step; (2) the local model's influence drops sharply after hop 3 because each hops adds mixing and noise from intermediate nodes, degrading the signal; (3) the transformer achieves higher accuracy on peripheral nodes because it correctly integrates information from all distances.

accuracy_far = (correct predictions on nodes with eccentricity > median) / (total nodes with high eccentricity)

The visualization must make impossible to miss: global models truly access information from far away in ways local models cannot, and the Jacobian measurement honestly reflects this difference.
