Swordsman: Entropy-Driven Adaptive Block Partition

Instead of breaking text into fixed-size chunks before generating it, Swordsman watches for natural sentence boundaries by measuring uncertainty and splits there.

Paper explainersAll themesLLMs & Foundation Models

Diffusion models generate text by starting with all words hidden and revealing words in parallel groups called blocks. But they split text into rigid, fixed-size blocks, slicing through the middle of thoughts. Swordsman splits at the places where uncertainty drops sharply (the natural boundaries between phrases), because at those boundaries the model exits a constrained region and enters a looser one, making decoding faster and keeping meaning intact.

The rigid block problem

Diffusion language models work backward from complete confusion to clear text. Imagine all words are hidden behind cards, then you flip cards one at a time until you can read the sentence. To speed this up, instead of flipping one card per step, you flip many cards per step in parallel batches called blocks. But the blocks are cut at fixed sizes — every 32 words, no matter what.

The problem: real sentence boundaries do not line up with every-32-words. If a block boundary cuts through the middle of a phrase like 'run-ning water' or 'can-not fail', the model has to guess at incomplete pieces. Those incomplete guesses create error that never recovers.

In one sentence. Swordsman cuts blocks at places where uncertainty drops naturally, not at arbitrary fixed intervals.

The algorithm as a flow

What it actually does

Start fully masked

All positions hidden. Compute first uncertainty score per token.

Measure the shifts

Compare uncertainty between each pair of adjacent tokens. Mark where it drops sharply.

Find the break point

Locate the strongest drop in uncertainty. That is the block boundary.

Unmask the block

Reveal tokens in this block in parallel, but ease the confidence bar over time.

Repeat for the tail

Unmask next block. Remeasure uncertainty, find next break. Stop when clear.

What the paper changes

What the paper changes

The paper moves the block boundaries. Instead of cutting every 32 tokens (a fixed schedule), it finds where uncertainty drops between adjacent tokens and cuts there. It also changes the unmasking threshold — the bar for 'is this token confident enough to reveal' — making it looser as more tokens are revealed.

the object it moves  =  block boundaries
The hidden quantity

Entropy shifts: where the ground moves

measured quantity  =  entropy shift between adjacent tokens

When a model reads text token by token, each token has some uncertainty — a score from 0 (certain) to high (confused). Within a single phrase, that uncertainty stays similar because adjacent words share grammar and meaning constraints. But at a phrase boundary, the uncertainty often drops sharply because the model exits the constrained region and enters a different one.

Swordsman measures this shift: how much does uncertainty change when you look at the next token. A sharp drop (a large shift) signals a boundary. The paper estimates entropy shifts by computing the highest-probability token at each position, taking the log of that probability, and comparing neighbors.

Why it works

Why monitoring uncertainty shapes the right blocks

When a language model generates text, it is constrained by grammar and meaning. Within a phrase like 'running water', adjacent tokens are heavily linked: 'running' is almost certainly followed by something describable, and 'water' is almost certainly a noun. Those tight constraints keep the model's uncertainty low and stable within the phrase.

At a phrase boundary, the tight constraints break. The model exits the 'phrase A' mental state and enters 'phrase B', which has looser early predictions. That discontinuity shows up as a sharp drop in uncertainty. By detecting these drops, Swordsman finds the natural seams in the text. Then it can decode each phrase in one parallel batch, and the next phrase in the next batch, without fragmenting meaning.

The confidence drop formula

First in words:

entropy shift equals log of max-probability token at position i minus log of max-probability token at position i+1

Then the compact form:

∆H_i = log(max_v p(v|pos_i)) - log(max_v p(v|pos_i+1))

Every symbol:

lognatural logarithm (base e)
A tiny worked example
Position 7 (inside phrase, 'running'): max score 0.92. log(0.92) = -0.083
Position 8 (boundary, 'water'): max score 0.45. log(0.45) = -0.799
Entropy shift ∆H = -0.083 - (-0.799) = 0.716 (large, boundary detected)
Position 9 (inside phrase, 'flows'): max score 0.88. log(0.88) = -0.128
Position 10 (inside phrase, 'down'): max score 0.85. log(0.85) = -0.163
Entropy shift ∆H = -0.128 - (-0.163) = 0.035 (small, no boundary)

A sharp drop in confidence signals a phrase boundary where the model transitions between constrained regions.

What can go wrong

What can go wrong

Over-splitting at the tail. Once uncertainty converges to near-zero, every position looks like a boundary. Swordsman sets a minimum shift threshold (0.1) to stop splitting once text is nearly resolved.
Poorly calibrated confidence scores. If the model's highest scores are artificially inflated or flat, entropy shifts are noise. The method assumes the model is well-trained and produces reliable probability estimates.
Threshold rigidity. The dynamic threshold adjustment relies on block-level average entropy. If entropy is deceptive (e.g., model is equally uncertain about many tokens), the threshold may not relax enough.
Done right. Swordsman assumes a trained diffusion model with reliable confidence scores and runs forward pass per block to compute fresh entropy. Semantic constituent boundaries are real statistical discontinuities in the data, not learned features, so the method generalizes.
What a runnable demo should prove

What a runnable demo should prove

Build a simple code-generation task (HumanEval or similar). Generate a function body using a pretrained diffusion model with three methods: fixed 32-token blocks, random blocks, and Swordsman. Measure code correctness (does it run without error and pass test cases), decoding speed (tokens per second), and semantic fragmentation (how many token sequences cross into unrelated keywords). Show that Swordsman achieves higher correctness at similar speed, and dramatically fewer semantic breaks.

correctness_delta = (correctness_swordsman - correctness_fixed_blocks) / correctness_fixed_blocks

A demo makes unavoidable the fact that block boundaries matter, and entropy shifts are a cheap, training-free way to find them.
