LLM2Fx-Tools: Tool Calling for Music Post-Production

LLM2Fx-Tools turns music post-production into a step-by-step tool plan that chooses effects, orders them, and sets their controls so the output sound matches the goal.

Paper explainersAll themesAgents & Tool Use

Music post-production is a sequence decision problem. You do not just choose one effect; you choose several effects, place them in an order, and set their controls so the final sound reaches a target style. LLM2Fx-Tools frames that process as tool calling. The system reads audio, plans an effects chain step by step, and emits executable effect calls with settings. That makes the result inspectable because a producer can see exactly which tools were chosen and why.

Zero assumption version

Why audio effect chains are hard to automate

A finished track often depends on several audio effects acting together. Equalization may remove mud, compression may control loud peaks, reverb may create space, and saturation may add bite. The order matters because each effect changes the sound that the next effect receives. The settings matter because the same effect can either help or ruin the track depending on the control values.

Most automatic systems simplify the job too much. They predict one effect at a time without modeling the whole chain, or they output a final sound without exposing the steps that created it. That hides the reasoning and makes the result hard to edit. In real post-production, a producer needs a chain that can be inspected, changed, and reused on new material.

The paper's move. Represent post-production as a sequence of tool calls so the system must choose effect type, order, and control values explicitly.

The hidden quantity

The hidden quantity: chain fit

measured quantity  =  how well the full chain matches the target sound

One effect can sound right in isolation and still be wrong in the whole chain. The important quantity is chain fit: after all chosen effects and settings have been applied in order, how close is the output to the desired sound?

The paper makes chain fit easier to learn because the chain is generated step by step. Each new effect is chosen in the context of the earlier ones, so the system can learn that some effects only help after a previous cleanup step, while others should be omitted because they push the sound away from the target.

Why it works

Why it works

Post-production has strong order dependence. Compression before equalization can produce a very different result from equalization before compression. A step-by-step tool plan captures that dependence because each decision conditions on the chain built so far.

The explicit tool format also matters for control. A producer can inspect the chosen chain, replace one effect, or change a single control without throwing away the rest of the work. That is useful because real production often needs partial adjustment rather than a full rewrite.

The paired-audio and style-transfer settings both benefit from the same structure. In paired audio, the system can infer which chain turns the dry sound into the processed sound. In style transfer, it can separate effect style from musical content, then reuse the chain on new material so that the target character carries over.

Math after the picture

The chain objective

First in words:

Choose the effect chain that makes the processed output sound close to the target while penalizing unnecessary steps.

Then the compact form:

score(chain) = match(target_sound, apply(chain, input_sound)) - step_penalty(chain)

Every symbol:

chainthe ordered list of effect calls and control values
input_soundthe dry or source audio
apply(chain, input_sound)the audio produced after running the chain on the input
match( , )a similarity measure between produced sound and target sound
step_penalty(chain)a penalty for adding extra effects that do not help
score(chain)the value used to compare candidate chains
A tiny worked example
Chain A uses equalization, compression, and reverb in that order.
Chain B uses only reverb and saturation.
Chain A removes excess low buildup before compression, so its output is much closer to the target sound.
Chain B adds color but leaves the original imbalance untouched, so the match stays weaker.
The score therefore favors Chain A even though it has more steps, because each step contributes to the final sound.

The method is useful when the added steps each serve the target sound; the penalty exists so the system does not add effects that do not help because extra effects can move the output away from the target while making the chain harder to edit.

What can go wrong

What can go wrong

Wrong effect order. A chain can fail even when every individual effect choice looks reasonable, because some effects only work after another effect has already cleaned or reshaped the sound.
Control values do not transfer. A setting that works on one singer or instrument may fail on another because the source audio can differ in level, tone, and dynamics.
Reasoning trace sounds good but chain is weak. Readable planning text is not enough. The real test is whether the executed effect chain improves the sound, because a plausible explanation can still describe a poor recipe.
Done right. The method works when the chain is judged by executed audio output and when effect order and control values are both conditioned on the current sound.
What a runnable demo should prove

What a runnable demo should prove

Take a small bank of dry audio clips and matching processed targets. Ask the system to predict effect chains for each pair, then run those chains in an audio engine and compare the output to the target. Also test style transfer by extracting a chain from one source-reference pair and applying it to a new dry clip. Human listeners should be able to hear that the predicted chain moves the output toward the target style while staying editable.

chain_match = similarity(executed_output, target_output); transfer_match = similarity(stylized_new_output, reference_style_output)

The demo should show that explicit tool calls matter because they make the sound change both audible and editable.
