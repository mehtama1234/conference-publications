T1: Channel-Head Binding for Time Series with Missing Data

A hybrid of CNNs and attention that pairs each attention head with a single CNN channel, so corrupted data streams can be downweighted while good ones flow through.

Paper explainersAll themesTime Series & Sequential

Filling in missing values in time series is hard because holes corrupt patterns. When you try to send information across variables using learned attention (a scoring system that picks which other variables to copy from), you cannot tell which pathways got broken by missing data and which are still reliable. T1 solves this by tying each attention head to a single CNN channel, so each head can learn which data streams to trust.

Zero assumption version

Why filling gaps is stuck

Imagine a chart with rows (time steps) and columns (different measurement types—temperature, humidity, pressure). Missing values poke holes in the grid. A naive approach fills each column separately, ignoring that temperature and humidity usually go together. A better approach uses learned scoring (a system that ranks which other columns to copy from) to borrow patterns from complete columns and fill the broken ones. This works because when one column is mostly intact it has a real, measurable signal—actual time steps showing actual values—and copying real signal is more accurate than guessing per-column without help.

But learned scoring has a fatal flaw: when it looks at a broken column to borrow information, it reads corrupted patterns baked into the broken column itself—patterns that were never there before the holes opened up. For example, if 70% of column 2 is missing, the learned filter trains on only 30% of the real pattern plus whatever phantom pattern it built to fill the gaps. That distorted signal poisons the entire transfer process because other columns borrow from this phantom pattern, copying artifacts instead of real correlations.

The core problem. Attention cannot tell the difference between a reliable pattern and a phantom pattern born from missing data.

The algorithm as a flow

What it actually does

Embed the input

Encode time steps and observation mask into dense lists of numbers using small learned filters.

Extract temporal features per variable

Deep learned filters build consistent patterns within each variable from sparse observations only.

Bind channels to heads

Create exactly as many scoring heads as learned-filter channels; head K always reads channel K only.

Down-weight corrupted pathways

Each head learns from observation patterns which variables are reliable; corrupted ones get low scoring weight.

Reconstruct missing values

Combine selective cross-variable borrowing (from heads with high scores) to fill gaps with only trustworthy patterns.

What the paper changes

What the paper changes

Traditional attention in time series imputation connects any attention head to any CNN channel. This gives the model flexibility but also lets corrupted patterns leak through.

T1 enforces a fixed one-to-one mapping: the c-th attention head always pulls from the c-th CNN channel, and no other. This constraint sounds restrictive but it buys something: each head becomes a specialist in one data pathway, so it can learn whether that pathway is poisoned or clean.

the object it moves  =  Channel-head binding (the fixed one-to-one pairing)
The hidden quantity

The hidden quantity: Attention strength by pathway

measured quantity  =  Attention weight (how much each variable borrows from each other)

When attention looks at variable X to borrow information for variable Y, it assigns a weight—a number from 0 to 1. High weight means 'Y trusts X; copy its patterns.' Low weight means 'X is corrupted or irrelevant; ignore it.'

T1 measures this by tracking attention weights as missing ratio increases. When variable X has 70% missing data, its attention weight drops sharply in shallow layers (46% decline) but stays stable in deep layers (6% decline) because earlier layers partially reconstruct X, giving later layers cleaner patterns to work with.

Why it works

Why channel-head binding works

The mechanism has two parts. First, learned filters (small mathematical operations that operate on time windows) extract temporal features within each variable from incomplete observations only. A depthwise filter operates on one variable at a time, building consistent patterns even when some time steps are missing, because the filter trains on what it can see without guessing.

Second, channel-head binding ensures that each scoring head draws from a single learned-filter channel. This creates feature-specific pathways: if channel 3 (variable 3's filter output) is corrupted by 70% missingness, then scoring head 3 learns from the data what it sees and lowers its weight on that channel, because the partial signal it reads teaches it that channel is unreliable. Meanwhile, heads 1 and 2 (feeding on cleaner channels) remain high-weight. By isolating pathways, each head learns independently whether its input stream is trustworthy. If you let any head read any channel (vanilla architecture), a poisoned channel corrupts multiple heads at once because all heads trust all channels equally.

The binding and attention formula

First in words:

For each channel c from 1 to C, the c-th scoring head computes scores using only the c-th learned-filter channel. The output for channel c is the input plus the rescaled scoring output and cross-channel mixing.

Then the compact form:

Z_attn = Z + LayerNorm(PWConv(O)) where O is the scoring output from head c reading channel c only

Every symbol:

Zcurrent state (list of numbers per time step)
Z_attnoutput after scoring and residual connection
LayerNormrescale each number to mean 0, standard deviation 1
PWConvpointwise filter: mix information across variables without changing channel count
Oscores: how much to borrow from each variable
cchannel index from 1 to C (one per scoring head)
A tiny worked example
Setup: 3 variables, 2 are clean (90% observed), 1 is broken (30% observed).
CNN extracts 3 channels. Head 1 reads channel 1 (clean). Head 2 reads channel 2 (clean). Head 3 reads channel 3 (broken).
Head 1 learns: variable 1 is reliable, variable 2 is reliable -> high attention weight to both (0.8, 0.7).
Head 2 learns: variable 2 is reliable, variable 1 is reliable -> high weights (0.75, 0.8).
Head 3 learns: variable 3 is sparse, phantom patterns unreliable -> low weight to itself (0.2), borrows sparingly from 1,2 (0.3, 0.25).
Result: heads 1 and 2 dominate the reconstruction; head 3's corrupted pathway is muted. Without binding, head 1 could read channel 3 and get poisoned too.

Each head's attention weight is learned independently from its assigned channel, so corrupted channels automatically down-weight themselves.

What can go wrong

What can go wrong

If all variables are equally corrupted. Channel-head binding assumes some variables are cleaner than others. If every variable has 90% missing data, each head has no clean reference and all pathways are equally unreliable because there is no signal to learn from. The model cannot separate real patterns from phantom ones.
If temporal patterns are truly independent per variable. The model assumes variables are correlated and benefit from cross-variable borrowing. If temperature, humidity, and pressure have no relationship—that is, changes in one do not predict changes in the other—then learned scoring cannot help fill gaps in one from another, because copying unrelated variables introduces error instead of fixing it. Domain knowledge about correlation matters.
If missing values are not random. If missingness is systematic—for example, a sensor always fails at dawn—then the learned-filter temporal patterns are biased. A gap coinciding with a real pattern (dawn means temperature drops) becomes hard to distinguish from a gap caused by sensor failure (dawn means sensor is offline). The model reads both and learns a phantom 'dawn pattern' that it copies incorrectly to other variables.
Done right. T1 works best when some variables are mostly complete, missing patterns are somewhat random, and variables have real correlations. The model then learns to route information through clean pathways and ignore corrupted ones.
What a runnable demo should prove

What a runnable demo should prove

Build a synthetic time series with 5 variables that are correlated (temperature drives humidity; humidity drives pressure). Introduce missing data at random. Run T1 and compare reconstruction error (how far imputed values sit from the ground truth) at different missing ratios: 10%, 30%, 70%. Also measure attention weight drop per variable: does attention to a 70%-missing variable actually shrink compared to a complete one? Plot both.

Reconstruction Error = mean squared error between imputed values and held-out ground truth. Attention Drop = (attention weight at 0% missing) minus (attention weight at 70% missing), per variable.

If channel-head binding works, attention weight should drop proportionally to missingness (high drop for broken variables, low drop for complete ones) and reconstruction error should stay low even at 70% missing.
