TN-SHAP-G: Graph-Structured Tensor Network Surrogates for Shapley Values

Learn a compact factorized model that mirrors a graph's wiring to compute feature importance scores without enumerating exponentially many subsets.

Paper explainersAll themesInterpretability

Figuring out which input features matter most for a model's prediction is hard when there are many features. A standard method called Shapley values awards each feature a fair credit score by checking how much the prediction drops when that feature is masked out — but you have to check exponentially many combinations, which becomes impossible for even modest-sized inputs. TN-SHAP-G learns a lightweight approximate model that respects the graph structure of the input, then extracts all the credit scores from this learned model without extra work.

Zero assumption version

Why fair credit is hard to compute

Imagine you have a trained model that predicts whether a molecule will dissolve in water. You feed it a molecule (a graph of atoms and bonds) and it outputs a yes or no. Your boss asks: which atoms or bonds matter most for that prediction?

A fair way to assign credit is a voting game: for every possible subset of features, ask what the model predicts if only those features are present and the rest are masked out. Then use the pattern of predictions to score each feature. This method, called Shapley values, gives each feature a score that is provably fair — no feature can complain about its score. But there's a catch: the number of subsets explodes exponentially. With 20 atoms, there are over a million subsets. With 100 atoms, there are more subsets than atoms in the universe. A beginner would naively try to compute all subsets anyway, and run out of time or memory almost immediately.

The problem. Computing Shapley values for graph-structured inputs requires evaluating exponentially many subsets, making it impossible for realistic problems.

The algorithm as a flow

What it actually does

Sample coalitions

Pick M random subsets of features (way fewer than 2^n).

Query and label

For each subset, run the real model on the masked input, record the output.

Build surrogate

Learn a compact tensor-network model that fits those M labeled subsets.

Derive credit scores

Take mathematical derivatives of the surrogate to extract Shapley values.

Repeat for interactions

Reuse the same surrogate to also compute higher-order feature interactions.

What the paper changes

What the paper changes

Instead of asking the model which subsets matter, the paper learns a cheap substitute model — a tensor network — that mimics the model's behavior on masked inputs. The tensor network's topology is designed to match the input graph's wiring.

The hidden quantity

Bond dimension: how tightly features can couple

measured quantity  =  Bond dimension (χ)

A tensor network is a web of connected numerical arrays (cores). Each connection between cores is called a bond, and it has a width or capacity, called the bond dimension. A small bond dimension means nearby features interact only weakly (because the bond can carry only a little information about their relationship), while a large bond dimension allows stronger local coupling (because it can carry more information). The paper uses the graph structure to decide where bonds should be wide and where they can be narrow.

The paper figures out the right bond dimension by observing: if you want a tensor network to approximate a function on a graph, you need wider bonds at the choke points where one region of the graph connects to another. The tighter the coupling between those regions (the more the model's predictions depend on their interaction), the wider the bond must be to capture that. The algorithm learns this by training the tensor network and checking how well it approximates the masked-input behavior.

Why it works

How a graph-aligned tensor network recovers Shapley values

Shapley values come from a mathematical identity: the multilinear extension. This is a function that, for any input feature pattern, outputs a number that equals the average model prediction over all ways to turn that pattern on or off. Critically, if you build a function (like a tensor network) that fits all coalition values correctly, you can recover Shapley values by taking mathematical derivatives of that function.

A tensor network is a product of small arrays (cores), one per node, connected by indices. Instead of computing predictions for each of the exponential subsets, you learn a compact tensor network that approximates the pattern, using far fewer queries. Once learned, you can extract Shapley values by mathematical operations (derivatives and contractions) without querying the model again. The graph structure of the input means you can make the tensor network topology match the graph — wide bonds between nearby nodes, narrow bonds elsewhere — so the learned network stays compact.

Math after the picture

The multilinear extension and tensor contraction

First in words:

Shapley value for feature u is the derivative of the multilinear extension (coalition tensor) with respect to feature u. The surrogate tensor network approximates the coalition tensor via contraction of cores aligned to the graph. Once trained, derivatives are computed by selector operations without additional model queries.

Then the compact form:

φ_u = ∂/∂z_u (sum over s: T[s] * prod_v z_v^s_v * (1-z_v)^(1-s_v))

Every symbol:

φ_uShapley value (credit score) for feature u
T[s]Model output for coalition s (subset of features)
z_vInterpolation variable for feature v, ranges 0 to 1
s_vBinary indicator: 1 if feature v is in coalition s, 0 otherwise
∂/∂z_uRate of change with respect to z_u
Tiny worked example with 4 atoms
Imagine a molecule with atoms A, B, C, D. From just 5 carefully chosen subsets, the method trains a tensor network.
Subset {}: model outputs 0.2
Subset {A}: model outputs 0.3
Subset {B}: model outputs 0.25
Subset {A,B}: model outputs 0.5
Subset {A,B,C,D}: model outputs 0.8
The tensor network learns to fit this pattern with order n^2.3 work (instead of 2^4=16 subsets). Then taking ∂/∂z_A at z=(0.5,0.5,0.5,0.5) extracts A's Shapley value ~0.25 without any more model queries. Repeating for B, C, D costs O(n^0.57) total.

The derivative of the learned surrogate gives exact Shapley values if the surrogate fit perfectly, and approximate Shapley values otherwise, with error bounded by the surrogate fit error.

What can go wrong

What can go wrong

Small graph domain. The method learns a fixed masking scheme (how you set masked features to zero or a baseline). If the model's behavior changes under different baselines, the learned surrogate may not transfer, and Shapley values will differ.
Tensor-network approximation error. If the coalition values cannot be well-approximated by any tensor network with the chosen bond dimension, the surrogate will fit poorly, and the extracted Shapley values will be inaccurate. Wider bonds fix this but add training cost.
Graph structure must be stable. The method bakes the input graph structure into the tensor topology. If the graph changes (edges appear or disappear), you must retrain the surrogate.
Done right. Choose bond dimensions to balance expressiveness and cost, verify the surrogate fit on held-out subsets, and use the same baseline masking scheme at prediction time.
What a runnable demo should prove

What a runnable demo should prove

Build a surrogate on a small molecular graph with 10–20 atoms. Train it on a random subset of coalitions (e.g., 100 samples instead of checking all combinations). Then extract Shapley values for all atoms and all pairs of atoms. Compare the extracted values to (a) the exact Shapley values computed by trying all combinations on the same small graph, and (b) Monte Carlo samples from a standard library. The demo should show that the extracted values match the exact values to high precision, while Monte Carlo has noise, and that extracting all pairs of interactions costs much less than running Monte Carlo for each pair separately.

Shapley error = sum_u |φ_u_exact - φ_u_estimated| / num_features. Query budget = number of model calls to build surrogate + extract all Shapley values.

The demo must make it impossible to miss that the surrogate-based method is both more accurate (because it is deterministic, not random) and more efficient (because one learned surrogate extracts all interaction orders, while sampling-based methods need separate budgets for each) than sampling, especially for higher-order interactions.
