SEMA: Scalable Attention via Token Localization

A vision model that focuses on nearby image patches (token localization) instead of treating every patch equally, then fills in global patterns with a simple average.

Paper explainersAll themesComputer Vision

Vision transformers (models that learn which things to focus on, applied to images) read images as a grid of small patches and decide which patches matter for each patch. Full attention (comparing every patch to every other) slows down quadratically as images grow. Linear attention is faster, but because it simplifies the scoring rule, it assigns nearly equal weight to all patches and loses the ability to pick out nearby patterns. SEMA fixes this by only looking at a tight circle of nearby patches, keeping the sharp scoring, then adds back global patterns through arithmetic averaging.

The attention scaling crisis

A vision transformer divides an image into patches (like tiles on a grid) and asks: for each tile, which other tiles matter? This is attention. Vanilla attention compares tile A to all other tiles by scoring how similar they are and then turning those scores into fractions that sum to one, with the most similar tiles getting much bigger fractions. That comparison costs time proportional to the square of the number of tiles. A small grid of four tiles is manageable; a large grid of sixty-five thousand tiles explodes in cost.

A beginner tries linear attention: instead of computing fractions that highlight the top scorers sharply, use a simpler scoring rule that costs time proportional linearly to the number of tiles. But now tile A assigns nearly equal weight to all tiles. The model loses its ability to say 'these three nearby tiles matter most; the rest are background.' It forgets to focus.

In one sentence. SEMA looks only at nearby tiles (localization) to keep focus, then averages globally to catch patterns everywhere.

The algorithm as a flow

What it actually does

Divide the image

Split into overlapping local windows of nearby patches.

Localize attention

Inside each window, score only those nearby patches; set others to zero.

Compute local focus

Turn scores within window into fractions that highlight the top scorers sharply.

Add global average

Take the mean of all patch values across the image; treat it as a global fallback.

Combine and output

Mix local-focused result with global average in fixed ratio; send to next layer.

What the paper changes

What the paper changes

The paper changes the scoring rule for attention. Instead of comparing a patch to all N patches (full) or to all N with equal blurry weights (linear), SEMA compares a patch only to patches in a local window, then mixes in a global average signal.

The hidden quantity

Attention focus: keeping nearby strong

measured quantity  =  sharpness of local focus

Full attention achieves focus through softmax, which turns large score gaps into sharp weight differences (fractions that sum to one, with the top scores much bigger than the rest). Linear attention loses this sharpness because all weights converge to nearly equal. SEMA's hidden quantity is the ratio of local-window attention to global-average attention. When this ratio is high, the model has found sharp local patterns. When low, it must rely on global averaging because no local pattern dominates.

The paper estimates this by measuring entropy, which is a number that tells you how spread-out or uniform the weights are. A uniform distribution (all weights identical) has maximum entropy; a sharp distribution (one big weight, rest near zero) has low entropy. The goal is to keep entropy low within the local window.

Why it works

Why localization and averaging fix the focus problem

Full attention achieves focus because softmax creates sharp, sparse weights when score gaps are large. For nearby patches that share texture or edges, the scores differ dramatically; softmax gives them high weight and far patches near-zero. But the cost grows quadratically, which is prohibitive.

Linear attention runs fast but breaks the sharpness. It replaces softmax with a simple kernel function (like an exponential) that does not create sparse weights. Result: every patch gets comparable weight, focus dissolves, and the model conflates nearby signal with noise.

SEMA solves this by restricting the comparison to a local window. Within that small window (say, seven-by-seven patches instead of two-hundred-fifty-six-by-two-hundred-fifty-six), softmax still creates sharp weights because nearby patches have large score gaps. The computational cost drops from proportional-to-square-of-all-patches to proportional-to-patches-times-window-size.

But a small window cannot see global patterns. Two patches far apart but encoding the same object (e.g., the same face at two image corners) should influence each other. SEMA adds this signal through arithmetic averaging: the mean of all patch features acts as a global backbone that every patch attends to. This average captures what is common across the image — low-frequency structure, repetition — without requiring expensive comparisons. The final output is a blend: local-sharpness scores (which tile matters most nearby) plus global-average scores (what is true everywhere).

The attention blend formula

First in words:

Output for patch i equals: alpha times the softmax-weighted sum of nearby patches, plus one-minus-alpha times the global average of all patches.

Then the compact form:

out_i = alpha * softmax_local(score_i) @ V_local + (1 - alpha) * mean(V)

Every symbol:

out_ithe attention output for patch i
alphaa fixed blend weight between 0 and 1 (e.g., 0.8)
softmax_localsoftmax applied only to patches in the local window
score_idot product of patch i with nearby patches
V_localvalues of nearby patches only
Vvalues of all patches in the image
mean(V)arithmetic average of all patch values
A tiny worked example
Suppose alpha = 0.8 (80 percent local, 20 percent global).
Local-window output for patch i: softmax gives weights [0.6, 0.3, 0.1] to three nearby patches with values [10, 5, 2] → output = 0.6*10 + 0.3*5 + 0.1*2 = 6.0 + 1.5 + 0.2 = 7.7.
Global average of all patch values: mean(V) = 4.0.
Final output: 0.8 * 7.7 + 0.2 * 4.0 = 6.16 + 0.8 = 6.96.
The model keeps 80 percent of the sharp local signal (7.7) while tempering with 20 percent global context (4.0).

The blend weight alpha is fixed or learned during training, controlling how much the model trusts local focus versus global average.

What can go wrong

What can go wrong

Window size too small. If the local window excludes important nearby context (e.g., a window of only three-by-three patches for small objects), focus becomes too local and global patterns are lost. Arithmetic averaging cannot fully compensate.
Blend weight alpha poorly tuned. If alpha is too high, global information is drowned out and the model misses image-wide patterns. If alpha is too low, local focus is wasted and the model becomes a global-average model again (back to linear-attention blur).
Long-range dependencies at image corners. A patch at the image edge may have no nearby patches. The local window only looks inward, so edge patches see fewer neighbors and have less sharp focus. Arithmetic averaging is their only link to the rest of the image.
Done right. Window size matched to the texture and object scales in the task, alpha tuned via validation, and edge handling (e.g., padding or modular architecture) ensures every patch has enough local context.
What a runnable demo should prove

What a runnable demo should prove

Build a toy vision transformer on CIFAR-10, a standard image dataset with thirty-two-by-thirty-two-pixel images, which equals sixty-four patches if you split each into four-by-four blocks. Implement three attention types: (1) full softmax attention, (2) linear attention with a simple kernel, and (3) SEMA with a five-by-five local window and arithmetic averaging. Train each for fifty epochs on the same small dataset. Measure: per-layer attention entropy (low entropy in SEMA's local window proves it keeps sharp focus, while linear attention has high entropy everywhere); per-image final accuracy (to show SEMA stays accurate because it combines local focus with global averaging); and wall-clock time per batch (to show SEMA is faster than full, because it only compares each patch to a small window, not all patches).

Attention focus = negative of entropy(softmax weights); higher is sharper. Speed gain = (full attention time) / (SEMA time). Accuracy difference = SEMA accuracy minus linear attention accuracy.

The demo must show that SEMA is faster than full attention (because windowing reduces comparisons), keeps sharper local focus than linear attention (because scoring within a window creates large gaps, which turn into sharp weights), and achieves comparable or better accuracy to full attention even on small images where full attention should dominate (because the global average signal compensates for any missed far-away patterns).
