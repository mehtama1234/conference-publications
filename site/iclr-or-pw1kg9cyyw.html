L1 Latent Distance for Continuous-Time Graphs

Use L1 distance instead of squared L2 distance to represent how graph nodes move through a latent space over time, preserving true geometric relationships.

Paper explainersAll themesGraph & Geometric Learning

When you track how connected things evolve over time — like who talks to whom in a social network or how proteins interact in a cell — you need a space where you can embed the nodes and measure distances between them. Current methods use squared L2 distance, which breaks a fundamental rule: the shortest path between two points should go direct, never cost more if you take a detour. This paper proposes using L1 distance instead, which always keeps paths cost-consistent (because the sum of absolute differences always respects the triangle inequality, no matter how you arrange the coordinates) and computes faster (because the integral of the hazard function has a closed-form solution, unlike squared L2).

Zero assumption version

Why squared L2 distance distorts node positions

When nodes in a social network or biological system evolve over time, you need to embed them in a continuous space — assign each node a list of numbers (its coordinates in latent space) — and measure how far apart they are. The standard way is to use squared L2 distance: take the differences in coordinates, square each one, add them up. This gives a single number that tells you how dissimilar two nodes are at a moment in time.

But squared L2 distance has a fatal flaw: it violates the triangle inequality, which is the rule that the direct path between two points must cost less than taking a detour. If you go from node to node in sequence and then measure the total cost, it should never be less than the direct cost. When you use squared L2, this rule breaks — sometimes a detour actually costs less than the direct path. That means the latent space does not represent the actual relative positions of your nodes faithfully — some nodes get twisted out of their true places relative to each other.

In one sentence. Squared L2 distance warps node positions because it violates the triangle inequality, making social and collaboration networks harder to model accurately.

What the paper changes

What the paper changes

The paper swaps out the distance metric — the way you measure how far apart two nodes are in latent space (a coordinate space where nodes are represented as lists of numbers). It changes from squared L2 distance (which breaks the triangle-inequality rule) to L1 distance (which preserves it).

the object it moves  =  the distance metric
The hidden quantity

The hidden quantity: how long a relationship lasts

measured quantity  =  survival curve shape in latent space

The paper measures a quantity that is not explicitly stated but is central to its mechanism: the hazard function, which tells you at each moment in time how likely it is that a relationship (an edge in the graph) will end. Closer nodes in latent space are more likely to stay connected, so the function estimates risk of disconnection from the distance.

The paper estimates this hazard by integrating the distance over time using a mathematical curve that depends only on L1 distance, yielding a closed-form piece-wise exponential function. This function is computable efficiently, unlike the integral of L2 distance, which has no closed form.

Why it works

Why L1 distance fixes the placement problem

Here is the causal chain: squared L2 distance violates the triangle inequality, so the latent space becomes distorted. When you use a warped space to model a social network, nodes end up in the wrong relative positions, and the model makes poor predictions about which edges will persist. L1 distance obeys the triangle inequality always — no matter where you place three nodes, the direct distance-cost is never more than the detour-cost. This means the latent space stays true to the actual relationships between nodes.

The paper then solves a second problem: the L1 norm is not smooth (it has a sharp corner at zero), so you cannot compute a gradient in the usual way. The paper proves that even without a true gradient, you can find a descent direction — a direction that reliably moves parameters to lower loss — using the subdifferential of the L1 norm. This descent direction works with standard learning algorithms, so you can train the model end-to-end on real data.

Math after the picture

The L1 hazard integral

First in words:

survival of an edge is an exponential decay in L1 distance: exponential of negative L1 distance between two nodes

Then the compact form:

survival_prob(t) = exp(-distance_L1(node_a(t), node_b(t)))

Every symbol:

survival_prob(t)probability the edge still exists at time t
distance_L1(a,b)sum of absolute differences in coordinates: sum_i |a_i - b_i|
node_a(t)coordinates of node a at time t
node_b(t)coordinates of node b at time t
A tiny worked example
Suppose node A is at coordinates [1.0, 2.0] and node B is at [3.0, 1.5] at time t=5.
L1 distance = |1.0 - 3.0| + |2.0 - 1.5| = 2.0 + 0.5 = 2.5.
Survival probability = exp(-2.5) = 0.082 (about 8%).
With squared L2: distance = (1.0 - 3.0)^2 + (2.0 - 1.5)^2 = 4.0 + 0.25 = 4.25, survival = exp(-4.25) = 0.014 (1.4%).
L1 gives an 8% survival chance; squared L2 gives 1.4% — very different predictions from the same nodes.

L1 distance always satisfies the triangle inequality, so node placements faithfully represent their relationships; squared L2 does not, so nodes get warped.

What can go wrong

What can go wrong

Non-smooth optimization L1 norm has a sharp corner at zero, so standard gradient descent does not work directly. The paper solves this by finding a descent direction from the subdifferential, but some optimizers or fine-tuning routines may not handle this correctly.
High-dimensional latent space L1 distance becomes less distinctive in very high dimensions (a phenomenon called the curse of dimensionality) — many pairs of nodes end up with similar L1 distances, making it harder for the model to tell them apart.
Dense graphs with rapid edge turnover If edges appear and disappear very quickly relative to the node placement, the hazard function may not have time to learn stable positions, and the model can become unstable.
Done right On sparse social, contact, and collaboration networks where edges are relatively stable and the graph structure is clear, L1 distance delivers faithful node placements and accurate predictions of which edges will survive.
What a runnable demo should prove

What a runnable demo should prove

Build a simple continuous-time graph with three to five nodes and edges that appear or disappear at known times. Embed the nodes using both squared L2 and L1 distance. Measure how well each distance metric preserves the triangle inequality: for every triplet of nodes (A, B, C), check whether distance(A, C) is less than or equal to distance(A, B) + distance(B, C). Count violations. L1 should violate never or almost never; squared L2 should violate frequently. Then train a small graph model on each metric and measure accuracy on a held-out test set of edges. L1 should win.

triangle_violations = count of triplets where distance(A,C) > distance(A,B) + distance(B,C); test_accuracy = fraction of held-out edges correctly predicted

L1 distance should obey the triangle inequality every time, while squared L2 violates it often. On real edge prediction, L1 should be noticeably more accurate because it gives the model a true-to-reality picture of node positions, so it learns the real patterns of which edges survive.
