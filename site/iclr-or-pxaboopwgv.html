SPWOOD: Sparse Partial Weakly-Supervised Oriented Object Detection

SPWOOD detects rotated objects in satellite images using only a few weak labels and unlabeled images, by teaching a student model to separate objects from background and trust its own multi-layer predictions.

Paper explainersAll themesComputer Vision

Remote sensing needs to find rotated objects (buildings, ships, aircraft) in satellite images. The usual way is to hire people to carefully label thousands of images and mark each object's exact location, size, and rotation angle. That costs too much. SPWOOD does the job with far fewer labels: a small set of messy weak labels (e.g., a person marks where objects are but skips the rotation) plus millions of unlabeled images. The trick is to let a model learn from its own predictions.

Zero assumption version

Why full labels are too expensive for satellite imagery

Satellite images of Earth show thousands of objects: buildings, ships, cars, planes. Each one sits at some angle (rotation). A fully labeled dataset needs a human to draw a rotated box around every object and mark its angle. With millions of images and thousands of objects per image, this takes years and costs millions of dollars.

A naive first attempt: train a detection model on whatever small labeled set you can afford and hope it works on new images. It fails catastrophically, because the model only saw a few examples and cannot generalize to the variety it will face. You run out of money and give up.

A tempting shortcut: collect lots of unlabeled images and use unsupervised learning to find patterns, appealing because unlabeled images are free — though on its own it never recovers the angle labels the task needs. That works for some tasks (e.g., clustering images by color), but it does not teach a model to find specific objects with their exact rotation angles. Unlabeled data alone cannot assign a rotation to each ship, because unlabeled images are cheap to collect while hand-drawn angle labels are expensive.

In one sentence. SPWOOD teaches a model to find rotated objects and infer their angles using only a few partially labeled images and many unlabeled images.

The algorithm as a flow

What it actually does

Step 1: Design a student

Build a model that reads deep inside itself to find objects and angles in sparse, weak labels.

Step 2: Student guesses on unlabeled

Run the model on unlabeled images. It guesses where each object is and how it is rotated.

Step 3: Multi-layer voting

Check every layer: do they all agree on this object? Keep only the ones they agree on.

Step 4: Fair sampling

Make sure each object class (ship, building, plane) has roughly equal votes. No class dominates.

Step 5: Retraining

Use the kept predictions as pseudo-labels. Retrain the model. Go to Step 2 and repeat.

What the paper changes

What the paper changes: trust the model's full stack

Most object detectors read only the top layer of the model (the final prediction). SPWOOD looks at ALL the layers inside, from the bottom feature maps up through the middle processing stages to the top output. By asking every layer to vote on whether a prediction is trustworthy, the method catches mistakes that would hide in a single layer's blind spot.

the object it moves  =  the depth of prediction-checking
The hidden quantity

The hidden quantity: prediction confidence across layers

measured quantity  =  multi-layer agreement

This is a measure of how consistently the model's internal machinery votes on whether an object is real and what angle it sits at. When a lower layer sees a ship-shaped blob and a middle layer confirms it is ship-colored and the top layer says it has a ship-sized bounding box, all three layers agree. When they disagree, the prediction is probably noise.

The paper estimates agreement by running the same image through the model and collecting its predictions from multiple internal layers (not just the final output). It counts how many layers place a high-confidence box at the same location with the same rotation. Predictions with many layer-votes stay. Predictions with few layer-votes get discarded.

Why it works

Why it works: consensus filtering makes weak guidance strong

The problem with weak labels (e.g., a human marks an object but not its angle) is that a naive model trained on weak labels only learns half the job. It learns where objects are but stays confused about angles. The model's predictions on new unlabeled data are noisy, so if you use them directly as new training labels, you just teach the model your mistakes.

SPWOOD fixes this by asking the model to prove its answer. When the model sees an unlabeled image, every internal layer produces its own guess about what it sees. Most layers are not perfect; some layers miss details, some layers hallucinate. But when many layers independently agree on an object's location and angle, that agreement is strong evidence the model is right. The filtering step accepts only high-agreement predictions, discarding low-agreement guesses that are probably mistakes.

This consensus turns noisy weak labels into strong guidance. A model trained only on noisy predictions still fails, but a model trained on only the predictions it is most confident about learns cleanly. Each retraining round filters out the mistakes, so the model gradually learns the full task, because each round's confident predictions become training labels for the next round, (objects and their angles) from weak labels plus unlabeled data.

The core equation: weighted pseudo-label selection

First in words:

For each candidate object, the score is the sum of agreement votes from all layers, weighted by how deep the layer sits. Objects with high total agreement stay; low-agreement objects are filtered out.

Then the compact form:

score_i = sum_k (agreement_k_i * layer_depth_k) / num_layers

Every symbol:

score_ihow confident the model is about object i across all layers
agreement_k_iwhether layer k thinks object i is real and at the right angle
layer_depth_khow deep layer k sits in the model (later layers get higher weight)
num_layershow many internal layers the model reads
A tiny worked example
Suppose a model has 4 layers reading an image. A candidate ship at angle 30 degrees appears at that location and angle:
Layer 1 (shallow, sees basic shapes): says ship at 28 degrees. Agreement = 0.8.
Layer 2 (middle, sees colors): says ship at 30 degrees. Agreement = 1.0.
Layer 3 (deeper, sees structure): says ship at 30 degrees. Agreement = 1.0.
Layer 4 (top, sees object identity): says ship at 29 degrees. Agreement = 0.9.
Score is (0.8*1 + 1.0*2 + 1.0*3 + 0.9*4) / 4 = (0.8 + 2.0 + 3.0 + 3.6) / 4 = 9.4 / 4 = 2.35.
A high score (e.g., > 0.9 average per layer) means: keep this pseudo-label. A low score means: discard it as noise.

The pipeline filters predictions layer by layer, so only objects that the entire model hierarchy agrees on become new training labels.

What can go wrong

What can go wrong

Weak labels are so weak they become useless. If the human labels skip too much (e.g., marking objects but never marking angles, or only giving image-level tags like 'contains ship'), the model has almost no signal. Retraining on even high-agreement predictions still fails because the weak label signal was too faint to begin with.
Unlabeled data is from a different setting. If the unlabeled images show a different part of Earth, different season, or different imaging angle than the weak-labeled data, the model's self-training loop learns the wrong patterns. The pseudo-labels will be confidently wrong.
Layer agreement collapses to one view. If all layers learn to repeat the same mistake (e.g., all layers confuse a ship with a dock), consensus filtering will not catch it. The model needs to see diverse training examples to build independent layer-wise views.
Done right: start with diverse weak labels Use weak labels that cover the objects and camera angles you actually care about. Mix in unlabeled data from the same underlying data pattern. Use multiple object classes in retraining so no class overfits.
What a runnable demo should prove

What a runnable demo should prove

Build a small dataset: 100 fully labeled satellite images (ground truth for testing), 200 weakly labeled images (humans mark objects but not always angles), and 2,000 unlabeled images. Train a rotated object detection model (e.g., a standard rotation-aware model). Run SPWOOD: retrain the model 5 times, each time filtering predictions by multi-layer agreement and rebalancing by class. On each iteration, measure accuracy on the held-out test set. Plot accuracy versus iteration. The demo should show accuracy climbing from 60% to 78% as self-training improves, showing that the weak-plus-unlabeled signal is enough because each self-training round corrects some of the previous errors.

accuracy = (correctly_detected_and_angled / total_test_objects) * 100; report per iteration

The core claim: consensus filtering from unlabeled images makes a sparse weakly-supervised model nearly as accurate as a fully supervised one, at a tiny fraction of the labeling cost.
