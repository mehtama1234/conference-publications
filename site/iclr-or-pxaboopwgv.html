SPWOOD: Sparse Weakly-Supervised Rotated Object Detection

Use a trusted copy of your model to label unlabeled images, then teach the main model to believe those labels, so you can detect rotated objects in satellite imagery with almost no human effort.

Paper explainersAll themesComputer Vision

Detecting rotated objects in satellite images normally demands expensive pixel-by-pixel labels. SPWOOD cuts the cost by having the model label its own unlabeled images through a trusted copy (teacher), then training the main model (student) to match those predictions. It handles three kinds of data at once: a tiny pile of fully labeled images, many images with weak labels (just a simple box, not the rotation), and a huge pile of completely unlabeled images.

Zero assumption version

Labeling rotation takes forever

In satellite imagery, objects like buildings and ships sit at all angles. A simple box outline is not enough — you need the rotation angle too. Marking that by hand on thousands of images costs a fortune.

A naive fix: train on whatever weak labels you have (just boxes, no angles) and hope the model figures out rotation. It does not. The model sees conflicting signals: the same object at different angles looks like different things, but the label says it is all one class. The model gets confused and stays weak.

The insight. Use a stable copy of your model (called the teacher) to guess labels for unlabeled images, then teach your main model (the student) to match those guesses.

The algorithm as a flow

What it actually does

Start with a student model

Train it on the few fully-labeled images and any weakly-labeled ones.

Freeze a teacher copy

Copy the student's weights into a teacher model that will not change yet.

Teacher guesses labels

Run unlabeled images through the teacher; collect predictions.

Filter the guesses

Use predictions from many layers to spot the teacher's confident guesses; discard uncertain ones.

Student re-trains

Train the student on the kept guesses plus the original labeled data. Slowly copy weights back to teacher.

What the paper changes

What the paper changes

The paper changes which images and labels the student model trains on. Instead of only learning from a tiny labeled pile, it now learns from that pile plus thousands of confident guesses made by its own teacher copy. This lets the same model see way more training examples without hiring labelers.

The hidden quantity

The hidden quantity: Teacher confidence

measured quantity  =  Which pseudo-labels are trustworthy

A pseudo-label is a guess the teacher model made instead of a human. The question is: which guesses should you actually teach the student to believe? If you believe all of them, the teacher's mistakes pile up and confuse the student. If you believe none, you learn nothing from unlabeled data.

SPWOOD estimates confidence by looking at predictions from many layers inside the teacher — if early layers, middle layers, and late layers all agree, the prediction is trustworthy; if they disagree, something is uncertain. The paper then uses a different confidence threshold for each layer, because early layers and late layers operate on different scales of information.

Plain reading. If the model's early detectors, middle detectors, and final detectors all say the same thing about an object, trust it. If they disagree, throw it away.
Paper reading. Multi-level Pseudo-label Filtering (MPF) uses predictions from the backbone, neck, and head of the detection network; dynamically adjusts the confidence threshold per layer based on how spread out the layer's prediction scores are (e.g., if most predictions cluster at 0.9 confidence, set the threshold high; if they spread from 0.5 to 0.99, set it lower).
Why it works

Why it works: The teacher-student loop

The core trick is that a frozen teacher copy is more stable than a constantly-changing student. If the student judged unlabeled images while learning, it would second-guess itself constantly — this week's guess would train it, then next week's improved version would contradict that, then the week after it would swing back. A frozen teacher is consistent: it gives the same prediction every time, so the student can reliably learn from those guesses.

The student then slowly copies weights back into the teacher using an Exponential Moving Average. This is like a weighted blend: the teacher becomes 99 parts old + 1 part new on each update. This slow refresh keeps the teacher stable while letting it gradually inherit the student's improvements. The student sees new pseudo-labels, trains, improves, feeds back a little improvement, trains again on better guesses — a flywheel that works because each tiny update to the teacher produces slightly better guesses, which train the student slightly better, which sends slightly better weights back.

The multi-layer confidence check catches a second failure mode: a model can be confidently wrong. By requiring agreement across layers (early detectors and late detectors must both say yes), the method avoids trusting a coincidental high score from one layer while another layer was skeptical.

The student training equation

First in words:

Total loss = (weight for class) times (class prediction loss) plus (weight for center) times (center loss) plus (weight for box) times (box loss) plus (weight for angle) times (angle loss) plus (weight for scale) times (scale loss).

Then the compact form:

L_total = w_cls * L_cls + w_cen * L_cen + w_box * L_box + w_ang * L_ang + w_scale * L_scale

Every symbol:

w_clshow much to care about class (object type) errors
L_clshow wrong the predicted class is vs the label
w_cenweight for center-point accuracy
L_cenhow far off the center point is
w_boxweight for box size
L_boxhow wrong the box dimensions are
w_angweight for rotation angle
L_anghow wrong the angle is
w_scaleweight for object scale
L_scalehow wrong the scale prediction is
A tiny worked example
Say the teacher's pseudo-label says: class=truck, center=(100,200), rotation=45°, size=3.5m.
The student predicts: class=truck (correct), center=(102,198) (off by 2), rotation=43° (off by 2°), size=3.6m (off by 0.1m).
Class loss L_cls = 0 (correct). Center loss L_cen ≈ 0.05 (tiny error). Angle loss L_ang ≈ 0.1 (small error). Scale loss L_scale ≈ 0.002 (tiny).
If all weights are 1.0, total loss = 0 + 0.05 + 0.5 + 0.1 + 0.002 = 0.652. Student nudges weights to reduce each part.

Each piece of the label (class, center, angle, size) has its own loss, so the student learns to predict all five aspects at once.

What can go wrong

What can go wrong

Teacher overfits to its own mistakes. If the teacher makes a systematic error (e.g., always rotating boxes 5 degrees clockwise), it will keep making that error consistently. The student learns it as truth. Slow weight copying helps but does not fully fix this because the student trains on the teacher's guesses, improves on those same mistakes, and feeds them back, so both models drift in sync — you still need a small pile of truly correct labels to break this loop and re-center both models.
Unlabeled images contain objects the model has never seen. If satellite images suddenly include a ship design or building style that was rare in the labeled pile, the teacher will not recognize it confidently, will filter it out, and the student never learns to detect it.
Confidence thresholds are brittle. If you set the multi-layer agreement threshold too high, you throw away most unlabeled data (no benefit). Too low, and you train on the teacher's mistakes. The paper uses layer-specific thresholds, but these still require careful tuning.
Done right: use reliable labeled data + careful threshold tuning. Keep a small human-labeled validation set to spot when pseudo-labels start degrading. Use multiple weak label types (horizontal boxes, points) to constrain the teacher's freedom to be wrong.
What a runnable demo should prove

What a runnable demo should prove

Build a tiny satellite-image dataset: 50 fully labeled images (rotation + box), 200 weakly labeled (box only), and 2000 unlabeled raw satellite crops. Start SPWOOD with just the 50 fully labeled, then add pseudo-labels from the unlabeled set in a loop. Measure angle error (degrees off from true angle) and detection rate over iterations.

The demo must show angle error shrinking and detection rate staying high as the student trains on more pseudo-labeled data, proving that the teacher's guesses were good enough to teach the student.
