VideoAnchor: Anchoring Visual Cues Across Frames

When a vision-language model watches a video, anchor its attention to visual cues that appear consistently across frames instead of always listening to the words.

Paper explainersAll themesMultimodal

A vision-language model (a system that reads images and understands text together) struggles with video questions because language tokens (words) drown out visual tokens (image pieces). VideoAnchor finds which visual pieces show up in similar places across frames, then makes those consistent pieces louder in the attention mechanism — the process by which the model decides what to focus on — without retraining anything.

Zero assumption version

Words drown out pictures in video

Vision-language models (systems that see images and read text) can answer simple questions about a single picture. But with video—multiple frames of the same scene—they hit a wall. When the model tries to answer a spatial question like 'What is next to the sofa?', the language tokens (the words in the question) are so loud in attention (the process of deciding what to focus on) that the visual tokens (the picture pieces) get ignored. The model keeps re-reading the question instead of carefully tracking the sofa across frames.

A naive fix would be to force the model to look at each patch (a small square of the image) separately. But that treats each patch as an island; it never notices that the sofa looks the same in frame 1, frame 2, and frame 3. The model needs to see not just individual pixels, but the fact that certain visual chunks belong to the same object or region across time.

In one sentence. VideoAnchor finds visual pieces that stay consistent across video frames and tells the attention mechanism to trust them more than it trusts the language tokens.

The algorithm as a flow

What it actually does

Visual tokens arrive from the encoder

The image is chopped into pieces; each piece becomes a token (a list of numbers).

Compute self-expressiveness for each visual token

Ask: can this token be built from other visual tokens in the same frame or across frames? Strong tokens can; weak ones cannot.

Convert expressiveness into scalers

Turn the expressiveness scores into weights — numbers between 0 and 2 that multiply the attention scores.

Amplify attention for visual anchors, dampen for language tokens

When computing which tokens to focus on, multiply the scores by the scalers: consistent visual tokens get boosted, language tokens get quieted.

Generate the answer

With visual anchors now louder, the model concentrates on spatial relationships: 'the lamp is next to the sofa.'

What the paper changes

What changes: the attention scalers

VideoAnchor does not retrain the model or change the weights. Instead, at test time (when answering a question), it inserts scalers—small numbers that multiply the attention scores. A scaler of 1.2 makes a visual token's score 20% louder; a scaler of 0.8 makes a language token 20% quieter. The scalers are computed on the fly from the visual tokens themselves.

The hidden quantity

The hidden quantity: self-expressiveness

measured quantity  =  self-expressiveness score

Self-expressiveness is a single number for each visual token that says: 'How much can this token be built from the other visual tokens in the same subspace?' A sofa token that looks the same across frames gets a high score—maybe 0.9 out of 1.0—because it is stable. A random noise token gets a low score—maybe 0.1—because it is unique and unrepeatable.

The paper estimates this using sparse subspace clustering: a technique that reorganizes tokens into groups where tokens in the same group can express each other. Within each group, calculate how much of token A can be written as a sum of other tokens in the group. That fraction is the self-expressiveness score.

Plain reading. Self-expressiveness is how much a visual piece resembles the other visual pieces near it in the subspace. The sofa always looks like a sofa; the noise never looks the same twice.
Paper reading. Sparse subspace clustering constructs a self-expression matrix where entry (i,j) measures the strength with which token i can be linearly reconstructed from the subspace neighbors. The diagonal of this matrix (how much token i expresses itself via others in its cluster) is the self-expressiveness score.
Why it works

Why it works: consistent visual cues matter more

The core idea: if a visual token can be expressed as a combination of other visual tokens—especially across multiple frames—then it belongs to a stable, persistent structure in the video (like a sofa or a face). Tokens that matter are self-expressive; tokens that are random or spurious are not.

In the attention mechanism, the model computes scores for each pair of tokens—how much should token A attend to token B? Normally, language tokens (words) get high scores because they are frequent and specific. VideoAnchor multiplies these scores by the self-expressiveness scalers: high-scoring visual tokens go higher still; low-scoring language tokens go lower. This forces the model to concentrate on the stable visual structures instead of the words.

Why does this fix spatial reasoning? Because spatial reasoning depends on tracking objects across frames. The sofa in frame 1 and frame 2 are the same object, and they cluster together in the subspace. By amplifying self-expressive tokens, the model learns to glue them together in its reasoning.

Math after the picture

The scaler equation

First in words:

For each token, the attention scaler equals one plus the self-expressiveness score times a strength parameter.

Then the compact form:

scaler_i = 1 + alpha * expressiveness_i

Every symbol:

scaler_ithe multiplier for token i in attention
expressiveness_ithe self-expressiveness score for token i, between 0 and 1
alphathe strength knob: how much to amplify high-expressiveness tokens (e.g., 1.5 or 2.0)
A tiny worked example
Sofa token: expressiveness = 0.9, alpha = 1.5 -> scaler = 1 + 1.5 * 0.9 = 2.35
Lamp token: expressiveness = 0.6, alpha = 1.5 -> scaler = 1 + 1.5 * 0.6 = 1.90
Noise token: expressiveness = 0.1, alpha = 1.5 -> scaler = 1 + 1.5 * 0.1 = 1.15
Language token: expressiveness = 0.05, alpha = 1.5 -> scaler = 1 + 1.5 * 0.05 = 1.075
Result: sofa's attention score is multiplied by 2.35; language token by 1.075. Sofa is now 2x louder relative to words.

The scaler amplifies visual anchors proportional to their stability in the video, making the model focus on what stays the same across frames instead of being distracted by question words.

What can go wrong

What can go wrong

Subspace clustering fails when tokens do not cluster neatly. If the video is chaotic (rapid cuts, dynamic lighting, many moving objects), tokens do not form clean subspaces, and self-expressiveness scores become noisy. The scalers amplify noise instead of signal.
The scaler strength alpha is a hyperparameter. If alpha is too high (say, 5.0), language tokens are nearly silenced and the model cannot answer non-spatial questions. If alpha is too low (say, 0.2), the fix has no effect.
VideoAnchor is test-time only, so it cannot learn the right subspace structure for a specific domain. If a domain has visual patterns not seen during pretraining (e.g., infrared video, medical scans), the clustering may not find the right structure.
Done right: on clear, well-lit videos of natural scenes where objects have consistent appearance, VideoAnchor reliably anchors spatial reasoning to visual evidence. The benchmarks (VSI-Bench, Video-MME) show consistent gains across models (InternVL2-8B, Qwen2.5VL-72B), confirming the fix works in its intended domain.
What a runnable demo should prove

What a runnable demo should prove

Build a small script that takes a 3-frame video of a simple scene (e.g., a room with a sofa, lamp, and bookshelf), encodes the frames into visual tokens, runs sparse subspace clustering to compute self-expressiveness scores, and applies the attention scalers. Ask the model: 'What is next to the sofa?' Measure whether the model's attention map (a heat map showing which tokens it focused on) locks onto the sofa region in all three frames, and whether the text-to-image attention (how much the model attended to words versus images) shifts from 65% words to 40% words.
