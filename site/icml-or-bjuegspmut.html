Policy-Reward Co-Pretraining for Faster Imitation Learning

To teach a robot from expert examples faster, pretrain both the policy and the reward function together using the same behavioral cloning data.

Paper explainersAll themesReinforcement Learning

When learning from an expert's demonstrations, a robot faces a two-part problem: figuring out what to do (the policy) and figuring out what the expert values (the reward). This paper shows that pretraining both parts together, rather than just the policy, cuts the total learning time in half. The paper discovers that the expert's own behavior carries a hidden reward signal that can be extracted cheaply.

Zero assumption version

Why learning from examples is painfully slow

Suppose you want to teach a robot to pick up a cup. You film a human doing it perfectly 100 times. Now the robot has two jobs: copy the motions (learn what to do) and learn what the human is actually optimizing for (a reward function that scores each action). Behavioral cloning—training the robot to predict the next move given the current state—solves the first job quickly. But then you hit a wall: the robot's estimate of what the human values (the reward function) is still terrible, because cloning just learns to match positions, not to understand value. So when the robot does online learning (trying moves and getting feedback), it wastes months exploring things the human would never do.

The intuitive fix is to pretrain just the policy (using behavioral cloning), then fine-tune with online learning (adversarial imitation learning). But this backfires: the pretrained policy degrades immediately when you switch to online learning, because the reward estimate is so wrong that the online learner wastes its first thousand episodes undoing good behavior from pretraining. The reward error is the killer.

The hidden trap. Pretraining the policy alone leaves the reward function broken, so fine-tuning starts with a wrong compass.

The algorithm as a flow

What it actually does

Collect expert demos

Film a human doing the task perfectly 100 times.

Train a behavioral cloning policy

Teach the robot to predict the expert's next move given the current situation.

Extract the hidden reward

Steal the expert's implicit reward: use how confident the behavioral cloning policy is (how likely it thinks the move is) as a reward signal.

Pretrain the reward function

Train the robot to predict rewards by matching this log-likelihood signal from behavioral cloning.

Fine-tune with online learning

Let the robot loose to explore, using the pretrained reward to guide learning. Fewer than half the episodes needed.

What the paper changes

What the paper changes

Standard adversarial imitation learning pretrains only the policy before online learning begins. This paper adds a second pretraining: a reward function, bootstrapped from the behavioral cloning model's own log-likelihood.

The hidden quantity

The hidden quantity: how wrong the reward function is

measured quantity  =  Reward error (distance from expert's true values)

The expert has a true reward function r-star: it assigns a score to each move based on real values. The learner must estimate this reward from examples. Reward error is how far the learner's reward estimate strays from the expert's true one. It measures whether the robot understands what the human actually cares about.

The paper estimates reward error by looking at value differences—how much a bad reward estimate changes the predicted quality of a trajectory. Without pretraining, reward error dominates the learning budget. With the paper's reward pretraining, the error shrinks before online learning even starts, leaving more episodes for policy refinement instead of reward reconstruction.

Paper reading. The paper analyzes imitation gap as the sum of policy error and reward error. It proves reward error is the dominant term, and that pretraining the reward via log-likelihood initialization shrinks it by a factor proportional to expert dataset size.
Why it works

Why extracting the reward from behavioral cloning works

Behavioral cloning trains a model to predict the expert's next move. In doing so, it learns to assign high probability to expert moves and low probability to non-expert moves. This probability ranking is exactly the ranking the expert's true reward function induces: the expert does high-reward moves and avoids low-reward ones. So the behavioral cloning model's log-likelihood (how confident it is) is a dense, accurate signal of expert values—it already encodes what the human cares about.

The paper initializes the adversarial reward function as log-likelihood of the behavioral cloning policy. This gives the online learner a head start: instead of guessing from scratch, the reward function already points toward high-probability expert regions. During online learning, the reward can still adapt, but it starts with the expert's implicit preferences already built in. This cuts down on the error the online learner must correct.

Math after the picture

The initialization formula

First in words:

The pretrained reward for a state-action pair is the log-likelihood assigned by behavioral cloning: how confident the behavior model is that this is an expert move.

Then the compact form:

r_pretrain(s, a) = log pi_BC(a | s)

Every symbol:

r_pretrainThe initialized reward for state s and action a
logNatural logarithm (turns probabilities into scores)
pi_BCThe behavioral cloning policy (predicts expert moves)
a | sAction a given state s (the situation)
A tiny worked example
Expert grabs cup gently. Behavioral cloning assigns it probability 0.8 (confident).
log(0.8) = -0.22 (negative because log of a fraction < 1).
Robot grabs cup violently. Behavioral cloning assigns it probability 0.05 (not expert-like).
log(0.05) = -2.99 (much more negative, strong penalty).
When the reward function is trained to predict these log-likelihoods, it learns that gentle moves reward-signal at -0.22 (decent) and violent moves at -2.99 (bad). The online learner starts with this ranking already in place.

The formula says: pretrained reward equals the log-odds the behavioral cloning model assigns, rewarding confidence and penalizing moves unlike the expert.

What can go wrong

What can go wrong

The behavioral cloning policy itself is biased. If the expert demos are all lefthand grasps, behavioral cloning learns lefthand-only. The pretrained reward inherits this bias. The paper's theory assumes the BC policy is reasonably accurate in the regions where the expert actually operated.
The expert is not actually optimal. If the human demonstrates sloppy technique, behavioral cloning ranks sloppy high. The online learner then struggles to improve past the expert's actual performance because the pretrained reward penalizes betterments.
The online learner over-fits to the pretrained reward. If the pretrained reward captures dataset quirks rather than true expert values, the online learner can lock onto those quirks and waste episodes exploiting artifacts.
Done right. Behavioral cloning data is large and diverse, the expert is demonstrably good, and the online learner gently steers the reward function away from pretraining only when necessary. The theory holds and learning is fast.
What a runnable demo should prove

What a runnable demo should prove

Build a simple robot reaching task (e.g., move a gripper to a target position). Generate expert demos by running a good policy 50 times. Train behavioral cloning on those demos. Separately pretrain a reward function to predict behavioral cloning log-likelihood. Then run adversarial imitation learning (using any standard AIL algorithm) starting from both the pretrained policy and pretrained reward. Compare to a baseline that starts from only the pretrained policy (reward is random or zero). The metric: after the same number of online episodes, the co-pretraining version should reach expert-level performance faster (within 1000 episodes; the baseline takes 2000+) because the pretrained reward already points toward expert behavior, so the online learner skips the first 1000 episodes spent correcting a broken reward estimate.
