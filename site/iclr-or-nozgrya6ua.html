References Improve LLM Alignment in Non-Verifiable Domains

Using reference outputs from better models helps weaker LLM judges score alignment quality accurately, even when there is no ground-truth answer.

Paper explainersAll themesAlignment, Safety & Fairness

Normally, training language models to be helpful and safe uses a reward model that knows the right answer. But for alignment—making LLMs honest and fair—there is no single right answer. This paper shows that when a weaker judge sees examples of good outputs from a stronger model, its internal patterns shift to match what quality looks like, so it learns to grade new outputs accurately without needing an oracle.

Zero assumption version

The judge problem: grading without an answer key

When you want to teach a model to write good emails, you can check the emails against ground truth—word-for-word in translation, or correctly-solved in math. A beginner tries: build a simple grader that checks 'is this answer right?', then feed that grader's scores back to improve the model. This works because the grader has a clear target to measure against.

But alignment is different. There is no single right way to be honest or respectful. Different people prefer different tones. A grader trained on examples of bad alignment catches obvious toxins but struggles with subtle judgment calls. A weaker judge (from a smaller model) just guesses wildly and gives false positives and negatives.

The bottleneck. Without examples of good alignment, a weaker judge has no patterns to learn from, so its internal weights stay random and it cannot reliably score new outputs. If you feed random scores back to train your model, the model learns nothing useful or learns wrong things.

The algorithm as a flow

What it actually does

Pick a reference source

Gather good example outputs—either from human experts or a frontier model.

Train the weak judge

Show the weak judge pairs: output + reference. Its weights shift to match patterns in reference.

Judge new outputs

The retrained weak judge scores new model outputs, now recognizing quality markers it learned.

Use weak judge as trainer

Feed its scores back into the model, because high scores now reflect genuine quality, not random noise.

Repeat

Model improves because it gets rewarded for outputs the judge approves of, which the judge learned from references.

What the paper changes

What the paper changes

The paper changes what the judge sees during training. Instead of judging in isolation, the weak judge now sees reference outputs side-by-side with candidate outputs. This teaches it to recognize the features of good alignment.

the object it moves  =  Judge's training examples
The hidden quantity

The hidden quantity: judge alignment to expert

measured quantity  =  Expert-judge agreement score

The paper measures one central thing: how often does the weak judge agree with the strong judge on the same outputs? Call this the agreement score. Without references, agreement is barely above random guessing (maybe 52%). With references, agreement jumps to 78%.

The paper estimates this by running both judges on the same test set—a frontier model's outputs and human-written outputs—then counting matches. High agreement means the weak judge has learned the strong judge's reasoning pattern.

Why it works

Why references teach a weak judge

A judge is a classifier—a small machine inside the main model that learned to output one number between 0 and 1 (the score). When you show it text, it looks for patterns it saw during training. A weak judge trained on random examples has no signal; its weights (internal patterns) stay near zero because nothing made sense.

When you show the weak judge a reference output from a strong judge and ask it to compare, suddenly there is a clear signal. The strong judge's output has properties: longer sentences, more nuanced language, fewer logical gaps. The weak judge's internal weights shift to detect these features, because it learns which patterns map to high reference scores. On the next batch of test outputs, those weights fire correctly. Agreement climbs because both judges now look for the same quality markers.

This works only if the references are genuine—real good outputs, not noise. Bad references teach bad patterns because the judge learns to replicate whatever the bad references contain, and then grades new outputs according to those corrupted patterns. The paper shows that stronger-model references help more than random outputs, because they contain richer patterns and clearer contrasts, and human-expert references help even frontier-model judges because they contain nuances the frontier model had not learned yet.

The scoring equation

First in words:

The judge's score is a weighted sum of text features, plus a penalty when it disagrees with the reference judge.

Then the compact form:

score = sum_i w_i * f_i(text) - lambda * D(judge_score, reference_score)

Every symbol:

w_iweight on feature i in the judge's internal model
f_i(text)feature i extracted from the text (e.g. sentence length, semantic coherence)
lambdahow strongly to punish disagreement with reference
D(judge_score, reference_score)the disagreement: how far apart the two scores are
sum_iadd up across all detected features
A tiny worked example
Reference output gets score 0.9 from strong judge (very good).
Weak judge initially scores it 0.4 (missed the quality markers).
Disagreement distance D = |0.9 - 0.4| = 0.5.
With lambda = 10, penalty = 10 * 0.5 = 5.0.
Weights w_i get nudged to recognize features that fix this gap.
On the next output, weak judge scores it 0.85 (much closer to reference).
Disagreement shrinks, penalty shrinks, weights stabilize at a better solution.

As the weak judge's weights learn to match the reference judge, disagreement drops to zero, training converges, and agreement stays high.

What can go wrong

What can go wrong

Bad references corrupt the judge. If your reference outputs are mediocre or contain biases, the weak judge learns to replicate those mistakes. A judge trained on human-biased references amplifies those biases.
Reference quality is a hard ceiling. The weak judge can only learn patterns that exist in the references. If your frontier-model references are weak or only slightly better than the model being trained, the judge has barely any signal to learn from, so it stays near random.
Different input types break the judge. If test outputs look very different from reference examples (different prompt style, different topic, different length), the patterns the judge learned do not apply. Its internal weights were tuned for one kind of text, so on new kinds it cannot recognize quality.
Done right. Choose references from models noticeably better than your target, because the judge can only learn from clear contrasts, or from human experts who understand alignment deeply, because they can encode subtle preferences. Keep test outputs in the same style as references. Measure agreement on a held-out set before trusting the judge to train your main model, so you catch failures early.
What a runnable demo should prove

What a runnable demo should prove

Build a tiny self-improvement loop: Take a small language model (like Llama-3-8B). Collect 100 outputs from a stronger reference model on a fixed prompt set (e.g., answering truthfulness questions). Train a weak judge to grade by showing it pairs of reference outputs and random candidate outputs. Then generate new outputs from the smaller model, score them with the weak judge, and use those scores to fine-tune the model on high-scoring outputs. Measure alignment before and after on a separate test set.

alignment_gain = (accuracy_after - accuracy_before) compared to (accuracy_with_finetuned_reward_model)

The demo proves that a weak judge taught by references can guide self-improvement as well as an oracle reward model, because references let it learn to recognize the same quality patterns.
