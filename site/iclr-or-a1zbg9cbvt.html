Texts as Time Series: Weaving language into numerical patterns

When text describes a time series (like news headlines about stock prices), the text itself repeats patterns at the same rhythm as the numbers—treat it as just another signal.

Paper explainersAll themesTime Series & Sequential

When you have time series data with paired text (like monthly sales numbers paired with headlines), today's models use the numbers and ignore the text. This paper shows that the text actually has rhythm too—it repeats patterns on the same schedule as the numerical data. By treating paired text as an auxiliary time series channel, any existing numerical-only model can be plugged in and enhanced to use both modalities without rewriting the model itself.

Zero assumption version

Text and numbers are today kept separate

Modern time series models (systems that predict what happens next in a sequence) work only with numbers. If you have a dataset where every month's sales are paired with a news headline or a description, the models throw away the text and use only the numbers.

A naive approach would be to turn the text into a single number (like a sentiment score from negative to positive) and feed it in. This fails because it collapses all the details in the text down to one number, losing context about what is actually being described—for example, if one headline describes a supply shock and another describes a demand surge, both negative-sentiment scores look identical to the model.

The core problem: Text that describes a time series is ignored by numerical models, even though it may contain patterns that align with the numerical rhythm.

What the paper changes

What the paper changes

The paper treats paired text not as separate words to ignore, but as an auxiliary time series channel—another sequence of numbers that represents the text, aligned in time with the numerical data.

the object it moves  =  Text representation (from ignored to periodic)
The hidden quantity

Periodic alignment between modalities

measured quantity  =  Cross-modal rhythm match

The hidden quantity is the degree to which text descriptions repeat patterns on the same schedule as the numerical data. If sales spike every quarter, the text (news, reports, descriptions) also follows quarterly rhythm.

The paper measures this by observing that when you encode the text as a sequence, its periodic properties (the time gaps at which patterns repeat) closely mirror those in the numerical time series. This alignment helps forecasting because when two channels of data are already synchronized at the periodic level, the model can detect patterns faster—if a quarterly peak is coming, hints of it will appear in both the numbers and the text simultaneously, giving redundant signals that are easier to learn from.

Why it works

Why periodic text helps forecasting

The mechanism is simple: time series patterns repeat because real-world cycles (seasons, quarterly earnings, weekly rhythms) drive both the numbers and the language used to describe them. When you feed the model two channels of data that are already somewhat synchronized at the periodic level, the model can detect patterns faster because it has redundant signals—if a quarterly peak is coming, both the numerical trend and the paired text will have hints of it.

By treating text as an auxiliary time series (instead of squashing it to a single score), the model preserves that periodicity. The existing forecasting machinery (whatever neural network or statistical method) can then use both channels in parallel, learning to weight the text contributions naturally through training. Because the text and numbers are already somewhat aligned in phase, the model does not have to learn their relationship from scratch—it inherits the alignment for free.

The auxiliary variable framework

First in words:

The prediction loss for time point t is the error in predicting the next value, with an optional penalty term that nudges text-channel weights if they drift too far from their initialization.

Then the compact form:

loss_total = loss_forecast + lambda * sum_c weight_decay(text_channel_c)

Every symbol:

loss_forecastError in predicting the next numerical value (e.g., mean squared error)
weight_decay(text_channel_c)Penalty if the text channel weights in the model stray too far from start
lambdaStrength of how much the text helps (tuning dial: 0 = text ignored, high = text emphasized)
sum_cSum over all text channels (e.g., one per type of paired description)
A tiny worked example
Suppose you forecast one month ahead. Numerical data alone gives error 5.2 (squared error on the numbers).
Text channel 1 (quarterly reports) has decoded weight 0.8, tuned weight 0.75, so weight_decay = (0.8 - 0.75)^2 = 0.0025.
Text channel 2 (news sentiment) has decoded weight 0.3, tuned weight 0.32, so weight_decay = (0.3 - 0.32)^2 = 0.0004.
With lambda = 10, total loss = 5.2 + 10 * (0.0025 + 0.0004) = 5.2 + 0.029 = 5.229.
The text penalty is tiny but nudges the model to trust text channels that stay close to their learned importance. The main signal is still the forecast error; text helps in the background.

The key is that text is not a standalone prediction target—it is an auxiliary channel. During training, the model learns how much to trust each text channel by minimizing forecast error, so text weights are set by whether they reduce prediction mistakes, not by a separate objective.

What can go wrong

What can go wrong

Text with no periodic structure. If the paired text is random or truly asynchronous (arrives at unpredictable times), treating it as periodic will hurt. The paper assumes text and numbers share rhythm.
Overfitting to text noise. If the text description is noisy or contains misleading labels, the model may learn to trust text more than it should. Regularization (the lambda term) mitigates this but does not eliminate the risk.
Encoding text poorly. The paper converts text to a sequence of numbers. If this encoding discards important semantic details or introduces artifacts, the auxiliary channel degrades the forecast.
Done right. When text and numbers truly co-occur on the same schedule and the text encoding preserves key patterns, TaTS substantially improves predictions without modifying the underlying forecaster. This works because the existing model's learning machinery can automatically discover which text patterns are predictive; no special handling is needed once the text is fed in as numbers.

Encode the text using embeddings or keyword frequency aligned in time. Train the model twice: once on numbers only, and once using TaTS (numbers plus encoded text as an auxiliary channel). Measure forecast error (mean absolute error or root mean squared error) on a held-out test period. The demo succeeds if adding text via TaTS reduces error by at least 10–20% without any change to the base forecasting architecture.
