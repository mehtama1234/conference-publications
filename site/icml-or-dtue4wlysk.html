Zeus: Tuning-Free Foundation Model for Time Series Analysis

A single time-series model that works on forecasting, gap-filling, and summarization without retraining for each task.

Paper explainersAll themesTime Series & Sequential

Time series models are typically trained from scratch or heavily fine-tuned for each specific task (forecasting the next value, filling in missing values, or detecting patterns). Zeus is a foundation model that learns once and then solves all these different tasks without any retraining. It does this by using two key ideas: a multi-scale architecture that can handle both fine details and long sequences efficiently, and a masking strategy that lets the same model learn the patterns needed for different task types.

Zero assumption version

Retraining for every new task

Before Zeus, time-series foundation models could do zero-shot forecasting (predict future values without retraining) but struggled on other tasks like filling gaps or detecting outliers. If you wanted the same model to do something new, you had to retrain it on labeled examples of that task.

A beginner would try to train one model on many mixed tasks at once and hope it learns all of them. This fails because the tasks pull in different directions: forecasting needs to see the past clearly, gap-filling needs to reconstruct patches anywhere in a sequence, and pattern recognition needs a compressed summary. The model ends up mediocre at all three.

In one sentence. One model solves forecasting, gap-filling, and pattern-detection on time series without retraining for any of them.

What the paper changes

The one thing that changes

Instead of training separate models or retraining the same model for each task, Zeus trains one set of weights to handle three different masking patterns in the same forward pass.

The hidden quantity is the specific mask—which values the model is allowed to see and which it must predict. For forecasting, the mask hides all future values. For gap-filling, the mask hides values in missing positions. For pattern abstraction, the mask hides local details but reveals the overall shape. The same weights learn to extract the right information under any of these masks.

The paper measures success by checking whether the trained model produces accurate predictions under each mask type without any retraining. A truly unified model will learn internal numbers (representations) where the same learned values are equally useful under all three masks.

Plain reading. A mask is a binary choice for each number: visible or hidden. The model learns to predict what is hidden based on what is visible. Different tasks use different masks (hide future, hide gaps, hide details), but the same trained weights work for all of them.

Why it works

Why one model can handle many tasks

Time-series tasks fail when the model is pulled in conflicting directions. Forecasting says predict the future; gap-filling says reconstruct the middle; pattern detection says compress the whole sequence. A naive multi-task model ends up mediocre at all three because the updates (nudges that change the internal values) push different weights in opposite directions.

Zeus solves this with two moves. First, it uses a multi-scale Transformer: each time-series number becomes a learned value (a list of numbers). Fine-grained numbers flow through a full U-shaped hierarchy (up, through the middle, back down), so the model sees fine details early (because each number is processed individually at the start), coarse patterns in the middle (because later layers combine information from nearby numbers), and reconstructs details at the end (because the upward and downward paths preserve fine-grained information). This matches what different tasks need: forecasting benefits from seeing fine-grained history so it can spot exact change points; pattern detection benefits from seeing the whole-sequence summary so it can recognize long-term trends. Second, instead of training on all three tasks at once with conflicting goals, Zeus uses Multi-Objective Temporal Masking: it trains on all three masking patterns in the same batch. The mask hides different values for each task type. This way, the updates for forecasting and gap-filling and pattern abstraction all reinforce the same underlying weights—the weights learn to extract context that works for any mask. A single set of learned weights becomes useful for all three problems.

Math after the picture

Balancing three tasks with one loss

First in words:

The total loss combines three masking objectives: L_total = L_forecast + L_fill + L_abstract, where each L measures error on its specific masking task.

Then the compact form:

L_total = L_forecast(mask_future) + L_fill(mask_gaps) + L_abstract(mask_details)

Every symbol:

L_forecasterror when predicting future values (next values in the sequence)
mask_futurewhich positions are hidden (future) and which are visible (past)
L_fillerror when reconstructing missing values inside the sequence
mask_gapswhich positions are the gaps to fill
L_abstracterror when compressing the sequence to a summary representation
mask_detailswhich values are fine details (to hide) and which are structural (to show)
A tiny worked example
Imagine training on a 10-step time series for one batch:
- Forecast task: hide steps 9-10, visible are 1-8. Predict 9-10. Error L_forecast = 0.15.
- Fill task: hide step 5, visible are 1-4,6-10. Predict 5. Error L_fill = 0.22.
- Abstract task: hide local jitter, visible is the trend. Predict jitter. Error L_abstract = 0.08.
- Total loss for this batch: L_total = 0.15 + 0.22 + 0.08 = 0.45.
- Gradients (nudges) from all three tasks update the same weights, so they converge to a shared representation that works for any mask. A model trained only on forecasting would get L_forecast = 0.12 but fail on gaps; Zeus trains all three together and gets L_forecast = 0.14 on both forecasting and gap-filling tasks.

The same learned values are updated by losses from all three task types, so they learn to represent context that works under any mask without retraining.

What can go wrong

What can go wrong

Long sequences explode in compute. If the sequence is too long and you tokenize every single value at full resolution, the U-shaped hierarchy becomes expensive. The paper solves this by using point-wise tokenization (sparse, efficient tokens) and skipping coarse scales to middle layers, but if the sequence length grows 100x, even this can strain memory.
Task masks must be defined correctly. If the mask for one task is wrong (e.g., hiding too much or the wrong positions), that task's updates become misleading and all three tasks suffer. The model can only be as good as the worst mask definition.
Transfer to wildly different domains fails. Zeus is trained on diverse time-series datasets (stock prices, sensor readings, weather). If you apply it to a time series with a fundamentally different structure (e.g., seismic data with very sparse events), the pre-trained masks may not match, and the model reverts to poor zero-shot performance.
Done right. When masks are aligned with actual task structures and sequences are fed at the resolution the model was trained for, Zeus solves forecasting, gap-filling, and pattern detection without retraining because the unified masking strategy lets updates reinforce shared representations.
What a runnable demo should prove

What a runnable demo should prove

Build a small time-series dataset with three tasks: (1) forecast the last 10% of a sequence given the first 90%; (2) remove random 15% of values and reconstruct them; (3) compress a 1000-step sequence to a 100-step summary. Train Zeus on all three tasks together using Multi-Objective Temporal Masking. After training, show that the same model answers all three tasks without retraining, and measure accuracy on a held-out test set for each task separately. Compare against a naive multi-task baseline that trains on all three tasks with equal weight but no masking strategy.

accuracy_forecast + accuracy_fill + accuracy_abstract (sum across three tasks; higher is better)

The demo must make it impossible to miss that one trained model, with one set of weights, solves three different tasks correctly without retraining.
