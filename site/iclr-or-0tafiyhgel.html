Unlocking the Value of Text: Event-Driven Reasoning for Time Series Forecasting

Combine text descriptions with LLM reasoning and historical examples to forecast time series more accurately by fusing textual insights with numerical patterns.

Paper explainersAll themesTime Series & Sequential

Predicting what happens next in a sequence (stock price, weather, traffic) is hard when you only look at the numbers themselves. Real-world patterns often have text clues that numbers alone miss: news about an earnings report, a hurricane warning, or a policy change. This paper shows how to use a language model (a system that understands written words) to read event descriptions and reason about their impact on future values, then combine that textual reasoning with traditional numerical forecasting to beat either method alone.

Zero assumption version

Numbers alone miss half the story

When you forecast a time series (predicting stock prices, rainfall, website traffic), you normally feed historical numbers into a model and ask it to guess the next value. But real-world sequences respond to events: earnings announcements spike stocks, hurricanes flood rainfall, new product launches spike traffic. A naive approach feeds only numbers to the model, so the model has to infer what caused each bump or dip from patterns in the numbers alone — like trying to predict a friend's mood just by watching their heart rate, without hearing about their day.

Some recent methods try adding text (news articles, descriptions) to numerical models, but they either treat the text as a thin garnish (not using much of its content) or extract raw text features without reasoning about what the text actually means for predicting the future. A language model (the kind that powers chatbots) is built to understand words and reason about their implications, but these systems are rarely asked to do the reasoning work — they sit on the sidelines while simpler statistical models make the actual forecast.

In one sentence. Existing forecasters ignore textual clues or fail to reason about them; we ask a language model to interpret event descriptions and reason about their impact.

The algorithm as a flow

What it actually does

Gather event text with history

Input: historical time series values plus text describing events that happened (earnings calls, announcements, external reports).

Find similar past events

Search historical records: given the current event text, find previous similar events and their outcomes.

LLM reasons with examples

Feed the language model the current event plus in-context examples (what past similar events led to); it predicts the directional impact.

Numerical model predicts independently

Separately, a standard time series model (not seeing text) forecasts based on recent numbers alone.

Fuse at the frequency level

Decompose both forecasts into frequency components (slow trends vs fast wiggles), blend them adaptively, and recombine into final forecast.

What the paper changes

What the paper changed: reasoning paths and fusion targets

Instead of squeezing text into the same numeric space as numbers, this paper moves two things. First, it routes the language model to perform reasoning (not just converting words to numbers): given an event and historical examples that look similar, the model produces a verbal prediction of impact, which is then converted into a forecast. Second, it shifts the fusion point from the high-level feature layer (where most multimodal work happens) to the frequency domain (the oscillations and trends that make up the signal), so that numerical patterns and text-based predictions work on a level playing field.

The hidden quantity

Event impact alignment across time and frequency

measured quantity  =  Event relevance score and frequency alignment

The paper measures how well textual events align with actual numerical changes in the time series. It does this in two ways: first, it computes a score for each historical event to decide which past events are most similar to the current one (so the language model gets good in-context examples); second, it measures whether the text-derived forecast peaks at the same frequency components (fast oscillations or slow trends) as the numerical forecast so they can intelligently fuse rather than cancel out.

At the representation level, the paper uses Endogenous Text Alignment: it extracts text that is embedded within or tightly coupled to the time series (e.g., news tagged with exact times) and aligns its semantic features (meaning) with the corresponding time series values. At the prediction level, it measures and adapts the frequency components of the text prediction and numerical prediction, blending them by how confident each signal is at each frequency. If the text model strongly predicts a fast oscillation but the numerical model expects a slow trend, this adaptive fusion avoids cancellation and preserves complementary signals.

Why it works

Why text reasoning lifts numerical forecasts

Numerical models learn patterns from data: if stock prices have historically risen after earnings announcements, the model learns to detect the shape of rising numbers and predict more rise. But the model does not understand why (earnings signal profit expectations). A language model, trained on billions of words, already knows abstract causal links: it knows earnings announcements, CEO news, and product launches have different typical effects. So when you give a language model the current event and remind it of similar past events (in-context examples), it can reason: this event resembles past situation X, which led to outcome Y, so this will probably lead to something like Y. This reasoning is faster because the language model has already learned general world knowledge during training and just applies it to the current event, rather than waiting for the numerical model to observe many new examples of the same pattern and gradually adjust its weights to detect it.

The two approaches have complementary strengths. The numerical model is good at finding precise quantitative trends (the stock rose 2.3% every Tuesday in Q3), which the language model misses. The language model is good at semantic reasoning (understanding that product delays hurt but guidance increases help). By fusing their predictions at the frequency level rather than at the feature level, each signal stays intact: the numerical model's fine-tuned trend forecasts can coexist with the language model's coarser directional reasoning. Adaptive frequency fusion means fast oscillations and slow drifts can be weighted independently, so if text dominates the trend but numbers dominate high-frequency noise, the final forecast respects both.

Math after the picture

Adaptive frequency fusion equation

First in words:

The final forecast is a weighted combination of the text-based forecast and the numerical forecast at each frequency level, where the weights depend on the confidence or energy of each signal at that frequency.

Then the compact form:

F_final(w) = alpha(w) * F_text(w) + (1 - alpha(w)) * F_numeric(w)

Every symbol:

F_final(w)the final fused forecast at frequency w
F_text(w)the language model's forecast decomposed at frequency w
F_numeric(w)the numerical model's forecast decomposed at frequency w
alpha(w)adaptive weight for the text signal at frequency w, ranges 0 to 1
wa frequency component (slow trend = low w, fast jitter = high w)
Tiny worked example: fusing at two frequencies
Suppose the numerical forecast shows a big slow trend (low frequency) value of 100 units but tiny fast jitter (high frequency) value of 2 units.
The text model (reading event news) predicts a moderate trend of 40 units and high jitter of 15 units (excitement/uncertainty).
At low frequency (trends): alpha(low) = 0.2 (trust text less on trends), F_final(low) = 0.2*40 + 0.8*100 = 8 + 80 = 88.
At high frequency (jitter): alpha(high) = 0.7 (trust text more on event-driven volatility), F_final(high) = 0.7*15 + 0.3*2 = 10.5 + 0.6 = 11.1.
The final forecast recombines: 88 (trend) + 11.1 (jitter) = 99.1, closer to textual insight than pure numbers alone.

By blending at each frequency separately, the method avoids cancellation (when one signal is strong where the other is weak) and preserves the unique value of each: numbers win on precision, text wins on semantic understanding of events.

What can go wrong

What can go wrong

Text description is absent or uninformative. If a critical event has no written description (or the description is vague like just a date with no context), the language model cannot reason about impact and degrades to numerical-only forecasting, because reasoning requires semantic content (meaning) to ground causal thinking. Datasets without documented events do not benefit because adaptive fusion has no text signal to blend: the fusion weight alpha(w) for the text branch stays near zero, so the forecast relies only on numbers, making the added complexity pointless.
Historical examples do not match current event. If the current event has never happened before or has no similar past cases, in-context learning fails (the language model recalls irrelevant examples). The adaptive fusion will learn to downweight the text signal, but the forecast for that event remains uncertain. Unprecedented events require either manual annotation or synthetic historical reasoning.
Events have indirect or delayed effects. Some events impact the sequence not immediately but weeks later. If the forecast horizon is short, the language model's reasoning about event impact will mismatch the actual change, and fusion can hurt. The method works best when text events and numerical changes align closely in time.
Done right: text is ground-truth and events align with outcomes. When event descriptions are comprehensive, historical precedents exist (so in-context examples apply), and impacts occur on the forecast horizon (so text reasoning matches the time window), the language model's causal reasoning aligns with what the numerical model sees, and adaptive fusion chooses each method's strength at each frequency. The paper validates this across 10 real-world domains with datasets that include many documented events.
