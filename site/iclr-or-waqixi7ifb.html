Learning Admissible Heuristics for A*

A* search needs heuristics that never overestimate distance; this paper enforces that constraint directly during training.

Paper explainersAll themesLearning Theory

When a robot searches for the shortest path, it uses a heuristic: a quick guess at how far the goal is from each state. A good heuristic makes the search fast. But it must satisfy one hard rule: never guess too high, or the algorithm will think it found a shortcut when it did not. This paper trains neural networks to learn heuristics that obey that rule, and shows mathematically why this works on unseen states.

Zero assumption version

Why naive training fails

A* search works like this: at each step, pick the state that looks closest to the goal (by the heuristic guess), explore it, and mark it done. If the heuristic ever overestimates how close you are, A* might skip the true shortest path and return a suboptimal route. Researchers know this rule—a heuristic must never overestimate, called admissibility—but traditional learned heuristics, trained as simple prediction tasks, ignore this constraint. They guess the true distance as closely as possible, which often means they sometimes guess too high. A neural network trained with standard prediction loss will minimize error on average, but that does not prevent occasional overestimates.

What a beginner tries first: train a neural network to predict true shortest-path distances using standard training loss (the difference between predicted distance and true distance, squared). The network minimizes average error, but individual states can still see predictions that are too high. This breaks optimality.

The paper's move in one sentence. Add a penalty to the training loss that specifically punishes overestimates, stronger than underestimates. This forces training to steer weights away from high-guess regions, because overestimate errors create much larger backward nudges than underestimates.

The algorithm as a flow

What it actually does

Train on admissible examples

Use states where you know the true shortest distance (from a small dataset).

Apply asymmetric loss

Penalize overestimates much more harshly than underestimates during each training step (when weights are nudged down the error slope).

Learn low-biased predictions

Training nudges (the slope down the error hill) steer weights away from high-guess regions, learning conservative estimates.

Test on unseen states

On new states never seen during training, the learned heuristic remains admissible.

Run A* with learned heuristic

Since the heuristic almost never overestimates, A* is allowed to skip the true optimal path only if it has already committed to a worse route; the admissible heuristic is honest enough that A* reaches the true best path.

What the paper changes

What the paper changes

The paper changes the training loss function. Instead of standard prediction loss (which treats all errors equally), it uses a new loss called Cross-Entropy Admissibility (a loss is the number the network tries to minimize during training) that heavily penalizes overestimates and tolerates underestimates. This asymmetry steers the learned network weights toward producing conservative, honest heuristic values.

the object it moves  =  training loss function
The hidden quantity

The admissibility violation rate

measured quantity  =  fraction of overestimating predictions

Every heuristic predicts a distance. Some predictions are honest (underestimate or equal the true distance); some are overestimates (the heuristic claims you are closer than you really are). The hidden quantity is how often a trained heuristic makes overestimating mistakes. Standard training achieves roughly 1 overestimate per million predictions; CEA achieves roughly 1 per billion, a thousand times better, because the asymmetric penalty makes every overestimate create many times more backward weight-nudging than underestimates.

The paper measures this by running the network on all states in a test set where the true shortest distance is known, and counting how many times the prediction exceeds the true distance. This fraction is the admissibility violation rate. The paper also uses this quantity theoretically: their generalization proof (showing the heuristic works on unseen states) depends on how tightly the violation rate is bounded.

Why it works

Why asymmetric penalty works

Neural networks learn by computing how wrong each prediction is, then nudging the weights in the opposite direction (a training step). If you care only about average distance error, the network balances high guesses and low guesses. But if you penalize overestimates much more severely than underestimates, the nudges become one-sided: every overestimate creates a strong downward nudge to the relevant weights, while underestimates barely nudge at all. This asymmetry forces the network into a low-biased region of weight-space where overestimating is rare.

Why does this work on unseen states? Because the property a network learns (the bias toward underestimation) is not a coincidence specific to the training set; it is a direct consequence of the loss function shape. Any state fed through the network will activate the same weights that have been repeatedly nudged downward. The asymmetry in the loss is baked into the learned weights themselves, so it transfers to new states automatically.

Math after the picture

The asymmetric loss equation

First in words:

For each state, if the network guesses higher than the true distance (overestimate), apply a penalty proportional to how much it overestimated. If the network guesses lower (underestimate), apply a smaller penalty proportional to some fractional power of the error.

Then the compact form:

CEA(h, x) = max(0, h(x) - d(x))^2 + lambda * max(0, d(x) - h(x))

Every symbol:

h(x)the heuristic network's prediction of distance for state x
d(x)the true shortest distance for state x
max(0, h(x) - d(x))^2penalty squared if prediction is too high, zero otherwise
lambdaa small weight (e.g. 0.1) applied to underestimate penalty
A tiny worked example
State A: true distance is 10, network predicts 12 (overestimate by 2). Penalty is (12-10)^2 = 4.
State B: true distance is 10, network predicts 8 (underestimate by 2). Penalty is 0.1 * 2 = 0.2.
Same size error (2), but overestimate is penalized 20x harder. Gradients will push weights away from high-guess behavior much faster than toward low-guess behavior.
Over millions of steps, this asymmetry accumulates: weights drift into regions that almost never produce overestimates.

The square on overestimate makes large overestimates hurt quadratically; underestimates hurt only linearly and are weighted down by lambda.

What can go wrong

What can go wrong

Too-conservative heuristic. If lambda is set too high, every underestimate is penalized as harshly as overestimates, negating the asymmetry. The network becomes too timid and makes guesses far below the true distance, wasting A* search steps on unlikely states.
Not enough training data. If training set is too small or does not cover the real pattern of states in the world well, the learned weights may work poorly on new unseen states. The asymmetry in loss helps, because it pushes weights away from high-guess regions, but it cannot invent patterns about distances it never saw in training.
Broken network architecture. If the neural network is too small (too few numbers it can learn and tune), it cannot learn complex distance patterns even with perfect loss function. The asymmetric penalty will steer it to underestimate, but at coarse accuracy.
Done right. Tuning lambda to balance admissibility (near-zero overestimates) and usefulness (heuristic values close enough to true distance to guide search), training on a representative dataset, and using a network with sufficient capacity yields learned heuristics that are almost always admissible and as informative as hand-crafted ones.
What a runnable demo should prove

What a runnable demo should prove

Build a small puzzle domain (a 15-puzzle is classic; Rubik's Cube is in the paper) where you can compute the true shortest distance to the goal for every state in a small subset. Train two neural networks on this subset: one with standard prediction loss, one with CEA loss. Both networks see the same training data and architecture. Test both on a held-out set of states and measure (1) the fraction of overestimating predictions and (2) the average distance prediction error. Run A* on a few random start states using each learned heuristic, and count how many states A* expands before finding the goal. A* with CEA should expand far fewer states because its heuristic is more often admissible.

admissibility_violation_rate = (number of states where h(x) > true_distance) / (total test states); A*_expansion_count = number of states examined before reaching goal

The demo must make it impossible to miss: standard loss violates admissibility thousands of times; CEA almost never does. And when the heuristic is admissible, A* reaches the goal efficiently.
