Mutual Information Unlearnable Examples

Protect your data by poisoning it in a way that reduces mutual information, making it impossible for unauthorized models to extract useful patterns no matter how deep they are.

Paper explainersAll themesAlignment, Safety & Fairness

When you share images online, you want to keep them private. Bad actors can download your pictures and train a model to recognize you, your home, or your medical data. This paper proposes unlearnable examples (poisoned images with tiny imperceptible changes) that wreck a model's ability to learn anything useful from that data. The trick: make all images of the same class become identical to each other inside the model's mind, so there is no variation for the model to learn from—when all dogs look identical and all cats look identical, a neural network cannot figure out what makes a dog different from a cat.

Zero assumption version

How do you stop a model from learning?

Imagine you post a photo of yourself online. A data miner scrapes it, trains a deep neural network on thousands of such photos, and builds a model that recognizes your face. Your privacy is gone. To fight back, researchers have proposed adding imperceptible noise to images before sharing them, hoping models will learn nothing useful. The most intuitive idea: trick the model by adding noise that makes every example look wrong, so training loss never drops and the model gives up.

But here is the catch: a linear model (a model with no hidden layers) trained on the same poisoned data achieves 30% accuracy on CIFAR-10, way better than random guessing. This means the poisoned images still contain a predictable pattern a simple model can grasp because a linear model can detect a direction or offset in the feature space even if there is no variation. Yet a deep neural network trained on the same images reaches only 10% accuracy, essentially random guessing, because deep networks build class boundaries by learning from many different examples that show how each class varies—with zero variation, they have nothing to generalize from. So the poison is not just making images unpredictable; it is doing something specific that deep networks cannot exploit.

The core fix. Push poisoned images of the same class as close together as possible in the model's feature space (the learned representation), so the model cannot tell them apart, because a classifier learns by studying how examples within each class vary and differ from other classes; when all examples of a class look identical, the model sees zero variation to learn from.

What the paper changes

What the paper changes

Instead of adding random noise to each image independently, MI-UE adds carefully designed perturbations that make all images of the same class converge toward the same point in the model's feature space (the internal learned representation).

the object it moves  =  intra-class feature clustering
The hidden quantity

The hidden quantity: mutual information between clean and poisoned features

measured quantity  =  mutual information reduction

Mutual information is a number that measures how much knowing one thing tells you about another. For this paper, it measures: if I see a poisoned image, how much does that tell me about the clean version of that image? High mutual information means the poison is predictable from the clean data. Low mutual information means the poison has scrambled the signal irreversibly.

The paper uses a neural network called MINE (Mutual Information Neural Estimation) to compute mutual information from data. MINE trains a separate small network to estimate the true mutual information value between the clean and poisoned feature representations.

Why it works

Why it works: the covariance collapse

Here is the core mechanism. Mutual information between two things is high when they vary together in diverse ways. When the poisoned images of one class are spread all over the feature space (high covariance, many different directions), the model learns which variations matter and which do not. But if you force all same-class examples to converge to a single point (zero covariance within the class), the model has no variation to learn from. It sees class A as always identical, class B as always identical, and cannot discover any rule that separates them.

A deep network works by learning increasingly abstract features in each layer. Early layers detect edges and colors, middle layers detect shapes, deep layers detect objects. If the features at every layer are indistinguishable within a class, then no layer can learn anything useful, and the network's test accuracy collapses to random guessing. Shallow models like linear classifiers can still perform reasonably because they can find direction in the feature space (even if variance is low, a mean direction still exists), but deep networks need varied examples from each class to build trustworthy class-specific decision rules.

The equation: minimizing intra-class covariance

First in words:

The loss function for MI-UE: for each class, maximize the average cosine similarity (dot product after normalization) of all pairs of poisoned examples in that class.

Then the compact form:

L_mi = sum_c sum_i sum_j (1 - cos_sim(f_i, f_j)) for i, j in class c

Every symbol:

L_mithe poisoning loss
ca class label
f_ithe feature representation of poisoned image i
cos_sim(f_i, f_j)cosine similarity: 1 means identical direction, 0 means orthogonal
sum_c sum_i sum_jsum over all classes and all pairs within each class
A tiny worked example
Class A has three poisoned images with features f1, f2, f3, each normalized to point in a unit direction.
Directional alignment (dot product of normalized vectors) between f1 and f2: 0.98 (pointing nearly the same way).
Directional alignment between f1 and f3: 0.97.
Directional alignment between f2 and f3: 0.96.
Loss = (1 - 0.98) + (1 - 0.97) + (1 - 0.96) = 0.02 + 0.03 + 0.04 = 0.09 (very small, high alignment).
Compare with naive random poison: alignments might be 0.1, 0.2, 0.3, giving loss 0.9 + 0.8 + 0.7 = 2.4 (ten times larger).
Smaller loss means features point in the same direction, so the network cannot distinguish examples within a class.

Maximizing directional alignment within each class directly minimizes how spread out the features are, which reduces mutual information and breaks deep learning.

What can go wrong

What can go wrong

Defense by stronger data augmentation. If a defender applies aggressive data augmentation (rotating, cropping, color shifts), the forced alignment within classes may break apart, and the model regains ability to learn.
Defense by adversarial training. If the victim model trains on a mix of clean and poisoned data, the model learns to ignore the poison and extract clean patterns. MI-UE works well but is not unbeatable under this defense.
Computational cost of MI estimation. Computing mutual information via MINE requires training an auxiliary neural network, adding overhead to the poison generation process.
Done right: aligned poison. MI-UE remains effective even on unseen architectures, because the principle (zero intra-class variance) is architecture-agnostic.
What a runnable demo should prove

What a runnable demo should prove

Generate unlearnable examples via MI-UE on CIFAR-10: for each class, add carefully designed perturbations that maximize the directional alignment (how much same-class features point the same way) among same-class features. Train a ResNet-18 on the poisoned data. Measure both test accuracy (should be near 10%, random guessing) and mutual information between clean and poisoned features (should be very low, near zero). Also verify that a linear model achieves only 28% accuracy, confirming that the poison works uniformly across model depths.

test_accuracy = correct_predictions / total_predictions; unlearnability = 100 - test_accuracy; MI = MINE(clean_features, poisoned_features)

The demo should show that poisoned images look nearly identical to human eyes (imperceptible changes) yet render the trained model useless, achieving maximal unlearnability with minimal pixel changes.
