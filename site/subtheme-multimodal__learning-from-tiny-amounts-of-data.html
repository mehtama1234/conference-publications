Learning from tiny amounts of data

Training models that work well even when given very few examples, so they can adapt to new tasks quickly without massive datasets.

All themesField mapMathematicsAll explainers
What this is

Most multimodal models are trained on enormous datasets — millions or billions of image-text pairs scraped from the internet, or massive video corpora. But in the real world, labeled data is often scarce. You might have a hundred examples of chest X-rays labeled with diagnoses, but you need a model that works reliably. You might have a specific type of satellite imagery and only fifty examples, but you need to detect changes. In these situations, training a huge model from scratch is impossible — you do not have enough data. Instead, you take a model trained on large public data and adapt it to your specific task with only a few examples. This is called few-shot learning or low-data learning, and it works if the model can transfer knowledge from what it learned before.

The difficulty is that learning is usually noisy when you have tiny amounts of data. With a hundred examples, random noise in the labels, variations in the examples, and quirks of the small dataset can dominate. A model can easily memorize the few examples you give it without actually learning a generalizable pattern — this is called overfitting. How do you get a model to learn a reliable, general pattern from just a handful of examples? One path is through transfer learning: the model already learned to understand images and text from massive pretraining, so the hope is that this knowledge transfers to the new task even with few examples. Another path is through meta-learning, sometimes called learning to learn — the model is trained on many different small-data tasks during pretraining, so it learns strategies for learning quickly. A third path is through careful regularization — techniques that prevent the model from overfitting to the small dataset.

Research in this area focuses on making models that generalize from limited examples. Some approaches use prompting or in-context learning, where you show the model a few examples of the task and it learns to do it, all without updating the model's weights. This works surprisingly well with large enough base models. Others use parameter-efficient fine-tuning, techniques like adapters that add a small number of new parameters while keeping the main model frozen, so you do not overfit as easily. Some work builds models that can learn new categories of objects or new tasks with just a handful of examples by using techniques like prototypical networks, where the model learns to recognize new classes by comparing them to a learned prototype. Other work focuses on multimodal prompt learning, where both images and text are used as prompts to guide the model's behavior. The common goal is to build models that have enough learned knowledge to transfer to new contexts but remain flexible enough to adapt quickly to new domains with minimal data.

How the work breaks down

Learning from small datasets splits along several directions. Some work focuses on adapting models through prompting and in-context learning, where the model learns from a few examples without changing its weights. Others use parameter-efficient methods: instead of updating the entire model, they add only a small number of trainable parameters while keeping the main model frozen. Still others tackle specific challenges: making models work across domains with missing data, aligning vision and language to control behavior, or quickly generalizing to new tasks and categories. All these approaches share a goal: use what a model already learned from pretraining to perform well on new problems with minimal new data.

Prompt learning and in-context adaptation

The core challenge here is teaching models to learn new tasks just by showing them examples or giving them text instructions, without retraining. With only a handful of examples, a model needs to recognize the pattern and adapt its behavior on the fly. This is hard because it requires the model to have learned generalizable features during pretraining that it can apply to brand new tasks.

Meta-Adaptive Prompt Distillation for Few-Shot Visual Question Answering tackles visual question answering on new domains with only a few labeled examples. It uses prompt learning—text and images that guide the model—combined with distillation, a technique where a larger model teaches a smaller one what it learned. The paper shows a 21% improvement over pure in-context learning and 7.7% improvement over parameter-efficient fine-tuning, meaning that by carefully designing prompts and training the model to learn from them, you can adapt quickly without changing many weights. AlignedNorm proposes a simpler approach to prompt learning for vision-language models. Instead of complex designs, it uses a coupled prompt field—linked prompts for the text and vision parts—and matches the performance of more complicated methods on 15 datasets across 4 different tasks. The simplicity matters: it shows that sometimes straightforward prompt engineering is enough. Criterion-Conditional In-Context Learning examines how vision-language models respond to changing criteria—when the rules of what counts as a good answer shift. Most large models have a rigid boundary bias, meaning they struggle when evaluation criteria change slightly. The paper shows that training on multiple criteria during pretraining helps small models (7-billion-parameter scale) adapt to new evaluation rules and even surpass much larger proprietary models on this flexibility. SpecPL extends prompt learning into the frequency domain by disentangling spectral granularity—different frequency bands of image features. It acts as a plug-and-play booster for text-focused prompt learning baselines on 11 benchmarks, achieving 81.5% harmonic-mean accuracy. Together, these four papers show that prompt learning, when done carefully and adapted to new criteria, can transfer knowledge from pretraining to new tasks with minimal data.

Parameter-efficient fine-tuning and adaptation

When you have a small dataset but want to adapt a large pretrained model, retraining everything leads to overfitting because the model memorizes the few examples instead of learning generalizable patterns. Adding new parameters carefully—so most of the model stays frozen—is a proven way to adapt without memorizing the small dataset, because the frozen part holds the knowledge from pretraining and only the new small part learns from the limited examples. The challenge is doing this across multiple modalities (images and text) without requiring too many new parameters or too much computation.

Bridging Radiology and Pathology Foundation Models via Concept-Based Multimodal Co-Adaptation combines radiology (medical imaging) and pathology (microscopy slides) models. Instead of fusing the two modalities in an ad-hoc way, it uses concept-based adaptation: it finds shared concepts (like 'tissue health' or 'abnormality') that appear in both modalities and adapts both models to these shared concepts. The result: it adds only 0.15% new parameters (almost nothing) but outperforms fusion baselines because the concept alignment captures what both modalities have in common, achieving 0.903 AUC on TCGA-GBMLGG, a standard medical imaging benchmark. One Patch Doesn't Fit All addresses a different problem: large vision-language models, when processing native-resolution images, are slow because they divide entire images into patches of the same size, which wastes computation on unimportant areas and requires processing many redundant patches. The paper proposes adaptive patching—different image regions get divided into patches of different sizes depending on the region's content. This keeps most of the model frozen, adds minimal parameters, and achieves up to 2x throughput boost and 4x faster prefilling because small patches for detailed areas and large patches for boring areas reduce total computation. SPR (Structured Prompt Refinement Network) tackles multimodal learning when one or more modalities are missing—for example, text without images, or images without audio. Using only 0.8% trainable parameters (adding just a tiny refinement network), it beats earlier methods by 3.8% F1-score even when 90% of one modality is missing because the prototype-based approach can fill in missing information without trying to generate it from scratch. These three papers share a core insight: you can adapt multimodal models to new tasks or conditions with tiny parameter additions by being surgical about where and how you add parameters, because the bulk of the model's learning stays frozen and only the critical junction points change.

Multimodal grounding and behavioral control

Learning from small amounts of data is easier when you can guide the model's behavior using both visual and language signals. These papers focus on using images and text together to control what the model pays attention to and what it outputs. The challenge is doing this without hallucinating (making up details that are not in the image) and without overfitting to the few examples you have.

Automatic Stage Lighting Control uses Skip-BART (a variant of the BART sequence-to-sequence model with skip connections) to generate lighting design commands from stage descriptions. Unlike rule-based systems (if you have a certain type of scene, apply a preset), the model learns to generate lighting commands that sound natural and work well because it can see diverse example pairs (descriptions and lighting). It outperforms all rule-based baselines and comes close to real lighting engineers' choices, showing that learning from examples (in this case, descriptions paired with lighting commands) can match or exceed hand-written rules because the model captures subtle patterns rules-makers might miss. Language-Instructed Vision Embeddings (LIVE) addresses visual hallucination—when vision-language models make up details about images that are not really there. LIVE binds language instructions directly into the visual embeddings (the learned representation of the image), so text guides what the model attends to. It reduces hallucination by 34 points on MMVP (a hallucination benchmark) and outperforms much larger models on visual question answering because text grounding prevents the model from inventing details that were never in the image. Referring Multiple Regions with Large Multimodal Models uses contextual latent steering—gently nudging the model's internal representations based on context—to let a model point to multiple locations in an image when asked. Without fine-tuning or changing the model's architecture, it outperforms dedicated referring models because the steering approach is flexible enough to identify different regions in different contexts without retraining. API (Adaptive Prototype Imputation for Incomplete Multimodal Sentiment Analysis) handles sentiment analysis when some modalities are missing (no video, only text and audio). It builds prototypes—learned representative examples—for each modality and uses these prototypes to fill in missing information. By using prototypes rather than trying to generate the missing modality, it avoids the extra computational cost and stays lightweight because prototypes are simple lookups rather than complex generation. Together, these four papers show that coupling language and vision, using one modality to guide the other, helps models generalize from limited examples without hallucinating or overfitting because the guidance constrains what the model can attend to and output.

Temporal and multimodal reasoning from sparse data

Some learning tasks involve time series or three-dimensional data, where data is naturally sparse or expensive to collect. Models need to reason about change over time, relate different modalities (images, audio, 3D structure), and generalize from a few timesteps or examples. The challenge is that time-series and 3D data are high-dimensional and subtle, so models easily overfit.

TAMMs (Temporal-Aware Multimodal Models) learns to describe and forecast satellite image time series—how land changes over months or years. Unlike models that treat each image independently, TAMMs explicitly models temporal relationships, so it understands that a forest fire does not just appear but develops over time, which means it can capture the patterns of change even with limited examples. It beats specialist baselines on both describing what changed and predicting future images because temporal awareness captures how one image leads to the next, making the patterns more predictable from few examples. TASTE learns to represent spoken language by aligning speech to text—converting audio into a form aligned with text—so that the speech representation respects word boundaries. This reduces the sequence length (the number of discrete pieces the model has to process), making models faster and more efficient while preserving paralinguistic information (tone, emotion, emphasis) because word-boundary alignment removes redundancy without losing meaning. It beats other pre-trained speech models on speech continuation and likelihood tasks because by grounding speech in text, the model learns from both modalities and can generalize with less audio data. Test-Time Optimization of 3D Point Cloud LLMs (PGLLM) refines predictions about 3D data by using in-context guidance at test time. Instead of fine-tuning a large model, it gently adjusts predictions for each new 3D scene based on examples from that scene. It improves accuracy and stability with minimal computational cost on 3D datasets and when handling data that looks very different from what the model saw during training because test-time guidance adapts to the specific scene without altering the base model. Together, these three papers show that when data has temporal or spatial structure (time series, 3D structure), models that respect this structure can learn generalizable patterns from sparse examples because the structure constrains what patterns are likely.

Multimodal generation and architecture design

Some learning tasks require models to generate outputs (diagrams, video analyses) that combine multiple modalities in coordinated ways. Generalization from small datasets is hard because the output space is large and diverse. These papers introduce new datasets and architectural designs to make this possible.

Text2Arch creates a dataset of scientific architecture diagrams paired with natural language descriptions and formal code (DOT format). It allows researchers to train models to generate diagrams from text—a task requiring both language understanding and layout reasoning—because the dataset provides concrete examples of how text maps to visual structure. Fine-tuned models beat earlier approaches and match GPT-4o performance because with the right paired dataset (text + diagram + code), even modest models can learn the mapping from language to structure. V-LynX (Token Interface Alignment for Video+X LLMs) unifies audio-visual question answering, 3D reasoning, and high-frame-rate video understanding under a single architecture by aligning how tokens (units of sequence representation) from different modalities interact. It achieves top efficiency without requiring paired supervision (training data that explicitly pairs different modalities together) because the token alignment itself allows the model to learn how video, audio, and 3D data relate without needing every modality pair pre-aligned. Both papers show that the right architectural choice—how to represent and align different modalities—lets models learn from smaller datasets because the structure guides what patterns to look for, and a good structure makes patterns more obvious even with few examples.
