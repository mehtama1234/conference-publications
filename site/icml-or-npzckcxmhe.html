Scalable Conditional Independence Testing with Spectral Representations

Instead of testing if two variables are independent given a third by memorizing all their shapes, this paper learns a tiny set of numbers that captures the core relationship and tests with those.

Paper explainersAll themesRepresentation & Self-Supervised Learning

In science and statistics, we often need to know: given what we already know about Z, does knowing X tell us anything new about Y? This is conditional independence testing. Existing methods either make strict assumptions that don't hold in real data, or they use mathematical techniques (based on measuring relationships between all pairs of data points) that become slow when data is large or complicated. This paper shows how to solve both problems at once: learn a compact set of numbers that capture the core relationship using spectral methods and contrastive learning, then use that to build a fast, mathematically sound test.

Why testing for hidden relationships is stuck

In real science, a researcher measures three things: X (say, tumor appearance), Y (say, survival time), and Z (say, genetic markers). The question arises: does tumor appearance tell us anything about survival that genetic markers don't already explain? That is, are X and Y independent given Z? This is fundamental to figuring out causes from data, picking which measurements matter most, and building trustworthy models.

A beginner would try: split the data into groups by Z, then check if X and Y still correlate within each group. But real data is messy. X and Y may be continuous, Z may be high-dimensional (hundreds of genes), and the true relationship might not be linear or smooth. Existing approaches either assume the data has special structure (smoothness, low-rank shape, or known patterns), or they use kernel methods that store information about every pair of examples in memory — scaling terribly when the dataset grows.

So researchers face a dilemma: use a method that only works on data with restrictive assumptions, or use a method that becomes too slow to run.

The real move: Learn a compact spectral representation of the conditional relationship and test with a simple linear test statistic built from those learned features.

What the paper changes

What the paper changes

Instead of storing data-point pairs or hand-crafted distance functions, the paper learns feature maps (three of them, called u, v, w) that capture the leading spectral structure of the partial covariance operator. These features are learned once per dataset using a bi-level contrastive algorithm; then any test statistic built from them is both fast and theoretically sound.

The hidden quantity

The hidden quantity: partial covariance structure

measured quantity  =  Leading spectral patterns of conditional relationship

Before this paper, kernel-based CI tests did measure something concrete: the partial covariance operator, which is a mathematical object that encodes how X and Y co-vary after Z is accounted for. The problem was that they used the whole operator; this paper proposes to measure only the leading (most important) spectral patterns of that operator. Think of it like a photograph: you can store every pixel, or you can store a handful of important edges and shapes that let you reconstruct the key information.

The paper estimates this hidden quantity using a bi-level contrastive learning algorithm that minimizes a Hilbert-Schmidt norm loss. The reason these learned features work is that they capture enough information about the partial covariance operator to build a test statistic that is mathematically valid (controls false positives) and has power (detects real dependence), all without storing massive matrices.

Why it works

Why learning spectral representations makes testing faster and valid

The old kernel method solved a hard mathematical problem: given X, Y, Z, construct a test for conditional independence. It did this correctly but slowly, because the solution inherently stored information about every pair of data points.

This paper's core insight: the conditional independence property lives entirely in the top few spectral patterns of the partial covariance operator. That is, you don't need the full infinite-dimensional object; you only need the few largest patterns. By learning feature maps that capture those patterns via contrastive loss, the algorithm compresses the problem. The test statistic becomes a simple linear function of the learned features, so it runs in time proportional to data size, not data size squared.

Why is this mathematically valid? Because the paper's theory proves that if the learned features match the true spectral patterns (within an error bound), then the test statistic converges to the same limiting pattern as the full kernel test. So you get the same correctness guarantees but with scalable computation.

Math after the picture

The core equation

First in words:

Partial cross-covariance operator is the original covariance between X and Y, minus the part explained by Z.

Then the compact form:

Sigma_{XY·Z} = Sigma_{XY} - Sigma_{XZ} * Sigma_{ZZ}^{-1} * Sigma_{ZY}

Every symbol:

Sigma_{XY}how X and Y covary together
Sigma_{XZ}how X and Z covary together
Sigma_{ZY}how Z and Y covary together
Sigma_{ZZ}^{-1}the inverse relationship within Z
Sigma_{XY·Z}what remains of X-Y covariance after Z is accounted for
A tiny worked example with numbers
Imagine X and Y both correlate with Z (say, genes drive both tumor and survival).
Raw covariance: Sigma_{XY} = 0.6 (X and Y look related).
But Sigma_{XZ} = 0.8 and Sigma_{ZY} = 0.8, so their correlation through Z alone is 0.8 * 0.8 = 0.64.
Partial covariance: Sigma_{XY·Z} = 0.6 - 0.64 = -0.04 (nearly zero; X and Y are independent given Z).
The method learns features that represent this -0.04 pattern, not the full covariance matrices.

The partial operator measures conditional independence directly; learning its spectral features avoids storing the whole thing.

What can go wrong

What can go wrong

Learning is not perfect. If the contrastive algorithm fails to recover the true spectral patterns, the test loses power. The paper's theory requires representation error to be small enough; in practice, hyperparameter tuning and dataset size matter.
High-dimensional Z is still hard. When Z has hundreds of dimensions, the partial covariance operator itself becomes ill-conditioned; the method does not magic this away, it only avoids storing it explicitly.
Theory assumes sufficient samples. The asymptotic validity guarantees require the data size to be large relative to the feature dimension. On small datasets, the test may be unreliable.
Hyperparameters tuned carefully. The contrastive learning has a smoothing penalty strength, neural network architecture, and sample-split size as choices. The paper provides guidance and uses Bayesian optimization in experiments.
What a runnable demo should prove

What a runnable demo should prove

Build a synthetic dataset with X, Y, Z where the true conditional independence is known. For example, X and Y both depend on Z (genes), but are independent given Z (tumor and survival are independent once you control for genetic markers). Run the spectral CI test and compare its p-value to the true answer. Then vary the sample size and the signal strength to show that: (1) Type I error (false positives) stays at the chosen level (e.g., 5%) across different samples; (2) power (ability to detect a real dependence when it exists) rises as sample size increases; (3) computation time scales linearly, not quadratically.

Type I error = false positives at fixed alpha; Power = detection rate under alternative; Computation time = seconds per test

The demo must show that spectral learning recovers validity (5% false positive rate) while beating kernel methods in both power and speed.
