CURE: Context-driven Diffusion with Progressive Expansion

Generate diverse time series training data from a single source by splitting the pattern into meaning-carrying and noise-carrying pieces, then using a diffusion model to expand both pieces separately.

Paper explainersAll themesTime Series & Sequential

When you have only one real time series dataset, any model trained on it memorizes that one pattern and fails on new data that looks similar but not identical. This paper fixes the problem by splitting each time series into two pieces: the semantic structure (the true pattern) and the semantic-free noise (everything else). Then it uses a diffusion model (a generative system that learns to add and remove noise) to create many new time series that have the right semantic structure but different noise, because training on examples with the same underlying meaning but different surface details teaches the model to recognize the true pattern rather than memorizing a single example's specific quirks.

Zero assumption version

One dataset is not enough

Time series classification means looking at a sequence of numbers (like daily temperature readings or stock prices) and labeling it correctly. The problem: you have data from only one real-world source or domain. A model trained on this single dataset overfits, learning the exact quirks of that data rather than the underlying pattern. When the pattern appears in a new context (different time range, different sensor, different conditions), the model fails.

People tried to fix this by generating synthetic time series: add noise randomly, or use older generative models to create fake examples. The trouble is these fake examples either look too much like the original (low diversity) or introduce unrealistic noise that confuses the model (poor quality). Neither approach gives you diverse, clean synthetic data that preserves the true semantic structure.

The paper's move in one sentence. Split each time series into two separate pieces: the semantic structure (the pattern that determines the class label) and the semantic-free noise (everything else), then use a diffusion model guided by both pieces to generate diverse, high-quality synthetic time series.

The algorithm as a flow

What it actually does

Step 1: Split the representation

Use a neural network to take each time series and output two separate pieces: one that carries the semantic meaning and one that carries everything else.

Step 2: Retrieve similar patterns

For the semantic-aware piece, find other time series in the dataset that share the same class label, so you have reference patterns.

Step 3: Learn the noise piece with adversarial strategies

Train a system that generates plausible semantic-free contexts (the noise components) such that when you remove them, the pattern is still clear.

Step 4: Feed both to the diffusion model

Give the diffusion model both the semantic-aware context (from retrieval) and semantic-free context (from adversarial learning) as guides, so it generates new time series that preserve meaning but vary the details.

Step 5: Progressively update and filter

As training goes on, update the semantic-free contexts using a memory bank, and keep only the generated examples that sit at the decision boundary (the hardest examples), because training on the hardest examples forces the model to refine its decision logic instead of relying on easy patterns, which makes it more likely to generalize.

What the paper changes

What the paper changes

The paper does not change the time series itself directly. Instead, it changes the context used to guide the diffusion model. Normally, a conditional diffusion model is guided by a single class label. CURE adds two new guides: a semantic-aware context (retrieved real examples with the same meaning) and a semantic-free context (learned noise components that vary without changing the meaning). These dual contexts steer the diffusion model to generate data that is both faithful to the true pattern and diverse in its details.

the object it moves  =  the contexts that guide data generation
The hidden quantity

The boundary property: which generated examples matter most

measured quantity  =  boundary property

The paper introduces a measurement it calls the boundary property: for each synthetic time series generated by the diffusion model, how close is it to the decision boundary between the true class and false classes? Examples near the boundary are harder and more informative for training because they force the model to refine its decision-making.

The paper uses the boundary property to filter which synthetic examples to keep. It stores semantic-free contexts in a memory bank and updates them over time, selecting only the generated examples that sit near the boundary. This means the model trains on the hardest examples rather than easy ones, so it learns a clearer, more accurate pattern.

Why it works

Why it works: the causal chain

The core problem is that synthesizing time series from only one real source risks copying that source's quirks. The paper's key insight: split the time series into two pieces and learn them separately. The semantic-aware piece (the true pattern) is anchored to real examples with the same class label, so it stays faithful to the true pattern. The semantic-free piece (the noise) is learned adversarially, which means it is forced to stay uncorrelated with the class label—it can vary wildly without changing what the time series actually means.

When the diffusion model receives both pieces as context, it has a clear instruction: keep the true pattern (semantic-aware) but vary the details (semantic-free). This produces synthetic data that is diverse (because the semantic-free part varies) but reliable (because the true pattern is grounded in real examples). Training on this synthetic data teaches the model the real pattern, not the quirks of the single source.

Progressive refinement tightens this further. By updating the semantic-free contexts and filtering for boundary examples, the paper ensures that the model trains on hard examples that truly test its ability to classify correctly, not easy examples that are far from any decision boundary.

Math after the picture

The diffusion guidance equation

First in words:

The loss combines three terms: (1) the diffusion model's prediction error on the synthetic time series, (2) a penalty if the semantic representation drifts from the retrieved reference examples, and (3) a penalty if the semantic-free representation aligns with the class label (which would mean the noise is carrying meaning).

Then the compact form:

L = L_diffusion + lambda_s * MSE(s_gen, s_ref) + lambda_f * CE(class_pred(c_f), uniform)

Every symbol:

L_diffusionthe diffusion model's prediction error
s_genthe semantic-aware representation of the generated time series
s_refthe semantic-aware representation of the retrieved reference example
lambda_sweight controlling how tightly the generated data stays close to the reference pattern
c_fthe semantic-free representation (the noise component)
class_pred(c_f)prediction of the class label from only the semantic-free part
uniforma uniform distribution over all class labels
lambda_fweight controlling how much the noise is forced to be uncorrelated with class
A tiny worked example
Suppose the diffusion model generates a synthetic time series. It computes L_diffusion = 0.3 (how well the generation matches the expected pattern).
The semantic-aware part s_gen differs from the reference s_ref by an average difference of 0.1. With lambda_s = 1.0, this adds 1.0 * 0.1 = 0.1 to the loss.
The semantic-free part c_f leans toward predicting class label 2. When a classifier predicts one class instead of guessing uniformly at random, the penalty is 1.4. With lambda_f = 2.0, this adds 2.0 * 1.4 = 2.8 to the loss.
Total loss = 0.3 + 0.1 + 2.8 = 3.2. If the semantic-free part were neutral (guessing uniformly), the loss would drop to 0.4. Training prefers noise that is uncorrelated with class.

The three terms enforce that generated time series preserve the true semantic pattern while ensuring that the noise part is truly just noise, not a hidden carrier of meaning.

What can go wrong

What can go wrong

The semantic and semantic-free pieces are not actually disentangled. If the representation learning does not cleanly separate meaning from noise, the diffusion model receives conflicting guidance. The semantic-free part may leak meaning, or the semantic part may still carry domain-specific noise. This weakens the diversity and reliability of synthesis.
The adversarial training for semantic-free contexts does not converge. If the semantic-free part is not trained strongly enough to be uncorrelated with class, it remains entangled with meaning. Synthetic examples then carry spurious patterns that the model learns to rely on.
The memory bank becomes stale. If the semantic-free contexts are updated too slowly or too fast, the memory bank does not reflect the current state of training. This can cause the diffusion model to generate inconsistent or off-target examples.
Done right. When representation disentanglement is clean and adversarial training is stable, the semantic-free contexts stay truly uncorrelated with class. The diffusion model then generates time series that are diverse in noise but faithful to the true pattern, and the model learns to generalize.
What a runnable demo should prove

What a runnable demo should prove

Build a simple time series classification task with one real source dataset (for example, a subset of a standard benchmark). Train a model on: (1) only real source data, (2) real data plus simple random synthesis, and (3) real data plus CURE-generated data. Measure accuracy on a held-out test set from the same domain and separately on a shifted version of the dataset (rotate the time series, add realistic sensor drift, or use a different temporal range). The demo should show that CURE-trained models generalize to the shifted data better than the other two baselines, because CURE trains on diverse, faithful synthetic data rather than overfitting to one source or learning false patterns from low-quality synthesis.

generalization gain = accuracy_CURE_on_shifted - accuracy_baseline_on_shifted

The key moment is when the model trained on CURE data correctly classifies shifted or new time series that the model trained only on the real source fails on, proving that CURE teaches the true pattern rather than domain quirks.
