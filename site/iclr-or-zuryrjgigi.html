Topological Anomaly Quantification for Semi-supervised Graph Anomaly Detection

Instead of guessing which nodes are anomalies, measure them with graph-structure scores to pick the real suspicious ones.

Paper explainersAll themesGraph & Geometric Learning

When you only know which nodes are normal (not which are anomalies), you need to create fake anomalies to train your detector. But how do you know if the fake ones are actually believable anomalies? This paper proposes TAQ-GAD, which scores nodes by their structure—how connected they are to normal nodes and how isolated they are—then uses those scores to pick real suspicious nodes as training examples.

Zero assumption version

How to find weird nodes when you only know what normal looks like

A graph is a set of nodes (points) connected by edges (lines). In a network of users, nodes are people and edges are friendships. The detector's job: find nodes that break the normal pattern. The hard part: you only have labels for normal nodes, never for actual anomalies.

A beginner tries to invent fake anomalies: add random noise to normal node features, or shuffle connections around. This fails because the fake anomalies might not look weird in ways the real ones do. You end up training on a made-up pattern that doesn't match actual anomalies in the graph.

The core problem. Without knowing what real anomalies look like in the graph structure, fake ones mislead the detector.

The algorithm as a flow

What it actually does

Measure boundary score

For each node, count how many edges connect it to labeled normal nodes versus unlabeled ones.

Measure isolation score

For each node, check how strongly it connects to other nodes in its own structural neighborhood.

Score nodes by both metrics

Combine boundary and isolation into one anomaly score per node.

Select pseudo-anomalies

Nodes with high scores become training examples of anomalies.

Train detector on mixed graph

Use normal nodes and high-scoring pseudo-anomalies to train the anomaly detector.

What the paper changes

What the paper changes

The paper changes how you pick training anomalies: instead of random noise, use the graph structure itself to find nodes that look structurally suspicious.

the object it moves  =  pseudo-anomaly selection
The hidden quantity

How to measure whether a node is structurally weird

measured quantity  =  topological anomaly score

This is a number for each node that measures how structurally abnormal it is in the graph. It combines two parts: boundary score (how much the node sits at the edge of the labeled-normal region) and isolation score (how weakly it connects to nodes like itself).

The paper computes these by looking at each node's neighbors (the nodes it connects to) and counting how many are labeled normal versus not. A node with many unlabeled neighbors but few labeled ones gets a high boundary score. A node with few strong connections to similar nodes gets a high isolation score.

Why it works

Why measuring structure picks better training anomalies

Random fake anomalies don't teach the detector real anomaly patterns because they are not rooted in how the graph actually looks. A real anomaly in a friendship network might be someone with few mutual friends; a random fake might just be a person with shuffled friend IDs, which looks nothing like that.

By scoring nodes on boundary and isolation, the paper picks candidates that break the actual graph structure. A high-boundary node sits at the edge of the known-normal region—it could be an anomaly or a normal node in a different part of the graph, but it's a realistic structural oddity. A high-isolation node connects weakly to others like it, which is how real anomalies often appear: as loners or misfits in their local group.

Using these structurally plausible pseudo-anomalies trains the detector to spot the real patterns of abnormality in graph data. When it sees a real anomaly later, it recognizes the structural signature.

The topological anomaly score formula

First in words:

Anomaly score for node i equals the fraction of neighbors that are unlabeled (boundary score) plus a penalty for weak within-group connections (isolation score).

Then the compact form:

anomaly_i = (unlabeled_neighbors_i / total_neighbors_i) + (1 - avg_connection_strength_i)

Every symbol:

anomaly_ithe anomaly score for node i
unlabeled_neighbors_icount of neighbors with unknown labels
total_neighbors_itotal number of neighbors
avg_connection_strength_iaverage edge weight to similar nodes
A tiny worked example
Node A: 8 neighbors total, 5 are unlabeled, avg connection strength 0.8 -> boundary = 5/8 = 0.625, isolation = 1 - 0.8 = 0.2 -> anomaly_score = 0.825
Node B: 8 neighbors total, 2 are unlabeled, avg connection strength 0.9 -> boundary = 2/8 = 0.25, isolation = 1 - 0.9 = 0.1 -> anomaly_score = 0.35
Node A scores much higher (0.825 vs 0.35) because it has more unlabeled neighbors and weaker connections—structural signs of being an anomaly.

Higher scores mean more structural oddity because boundary and isolation both quantify ways nodes differ from the normal pattern, so the model selects high-score nodes as training anomalies because they match the real anomaly signatures in graph structure.

What can go wrong

What can go wrong

Wrong neighborhood definition. If you define connectivity wrong (count only direct neighbors instead of multi-hop, or weight by edge strength incorrectly), the isolation and boundary scores both miss real anomalies.
Insufficient labeled normal data. If the labeled normal set is tiny or unrepresentative, boundary scores become noise—almost all nodes look unlabeled, so scores don't discriminate.
Anomalies that look normal. Some real anomalies might sit deep inside normal-looking neighborhoods or have many normal-looking neighbors. The paper's topological measures can miss them because they are structurally camouflaged.
Done right. When labeled normal nodes are representative and anomalies have distinct structural signatures (isolated, or at boundaries), TAQ-GAD picks pseudo-anomalies that train the detector accurately.
What a runnable demo should prove

What a runnable demo should prove

Build a small graph of 100 labeled normal nodes and 50 true anomalies (hidden). Run TAQ-GAD to pick 50 pseudo-anomalies from unlabeled pool, then train a graph autoencoder to detect anomalies. Compare against a baseline that picks 50 random fakes. Measure how many true anomalies each detector finds.

recall = true_anomalies_detected / total_true_anomalies, precision = true_anomalies_detected / all_nodes_flagged

TAQ-GAD's structurally-selected fakes should enable recall and precision both above the random baseline by at least 20 percentage points because the pseudo-anomalies match the actual structural signatures of real anomalies, teaching the detector patterns it will actually see in practice instead of random noise.
