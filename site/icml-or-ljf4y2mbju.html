Contractive Anchor Resolvent Diffusion for Incomplete Multi-View Clustering

When data is scattered across views with missing pieces, use a high-order filter that amplifies shared structure and cancels out view-specific noise without filling in gaps.

Paper explainersAll themesGraph & Geometric Learning

Multi-view clustering means grouping items when you see each item from multiple angles (maybe text and images together). The hard part: when some views are missing, you lose the relational patterns that help you see which items belong together, because the graph that connects items becomes fragmented and incomplete. This paper proposes CARD, which treats the problem as a filter that sharpens consensus structure while suppressing noise—without having to guess the missing data.

Zero assumption version

Why missing views break clustering

When you have multiple views of the same items (a photo, its caption, its metadata), you can look at how items group in each view and combine that knowledge. But if some views are missing, the graph that connects items becomes fragmented. A naive approach fills in the missing parts by guessing—expensive and risky. Another approach blends views with simple averages, which acts like a gentle blurring filter: it helps, but it does not dig deep enough to separate what is truly shared (all views agree) from what is view-specific noise (just one view thinks so), because the blur treats all patterns the same regardless of whether they appear across multiple views or just one.

The deeper problem: simple fusion is a shallow filter. It treats all frequencies of structure equally. You want to crank up the signal on consensus and turn down the signal on quirks—but a shallow filter is not selective enough to do that well.

In one sentence. Use a high-order spectral filter (called resolvent diffusion) to amplify consensus structure and suppress view-specific noise across an anchor-induced hypergraph, without guessing missing data.

What the paper changes

The one thing that changes

The paper changes how you fuse information from multiple views. Instead of averaging or low-pass filtering (which treat all structure alike), it applies a high-order spectral filter—a rational function of the graph matrix that acts like a selective gate: it lets consensus-aligned frequencies through and blocks view-specific noise.

the object it moves  =  the filtering approach for fusing views
The hidden quantity

The hidden quantity: spectral selectivity

measured quantity  =  spectral selectivity (frequency pass-band)

A spectral filter is defined by which frequencies (patterns) it lets through. Imagine the graph as peaks and troughs—peaks represent consensus (all views agree on grouping), troughs represent noise (one view disagrees). A shallow filter (first-order) smooths everything equally. A high-order spectral filter is designed to boost the peaks and flatten the troughs, so the final signal is purer, because amplifying consensus patterns and suppressing noise patterns naturally separates true cluster structure from random disagreement.

The paper estimates this selectivity using a resolvent diffusion operator—a mathematical object that computes which modes are consensus and which are noise, then amplifies the ratio. The key is not computing this exactly for every missing piece; rather, it works only on the hypergraph of anchors and observed relations, keeping computation tractable.

Why it works

Why it works: from anchor graph to selective diffusion

This approach reformulates incomplete clustering as a spectral filtering problem. First, you build an anchor-induced hypergraph from only the data you have (no imputation). Each item connects to a set of learned anchors based on observed similarity. This hypergraph encodes the multi-view structure in a unified way: if consensus is strong, many items point to the same anchors; if one view is quirky, it pulls items away from those anchors.

Second, you apply a high-order diffusion operator (resolvent diffusion) to this hypergraph. This operator is a rational function of the graph matrix, which means it can be tuned to amplify some frequencies and suppress others. Consensus frequencies (where all views agree on grouping) naturally correspond to small eigenvalues; view-specific noise corresponds to large eigenvalues. The resolvent operator boosts the small eigenvalues (amplifying consensus), reducing the large ones (suppressing noise), which works because small eigenvalues drive slow, smooth diffusion that consensus patterns exhibit, while large eigenvalues drive rapid oscillations that noise produces. The result is a refined graph where the true cluster structure is now separated from the view-quirk muddle.

The resolvent diffusion filter

First in words:

The refined graph affinity is computed as (I + delta L)^{-1} where L is the hypergraph Laplacian and delta is a diffusion scale parameter. This rational function selectively boosts low-frequency (consensus) modes and suppresses high-frequency (noise) modes.

Then the compact form:

S_refined = (I + delta * L)^(-1)

Every symbol:

S_refinedthe cleaned-up graph after filtering
Ithe identity matrix (a mirror of the graph structure)
Lthe hypergraph Laplacian (encodes how items relate via anchors)
deltadiffusion scale parameter (controls how much filtering happens)
(I + delta * L)^(-1)resolvent operator (inverts the scaled Laplacian to suppress noise modes)
A tiny worked example
Imagine a small hypergraph with 5 items and 2 anchors. The Laplacian L encodes the graph structure.
Without filtering: S_raw has both consensus and noise.
Set delta = 0.5 (diffusion scale). Compute (I + 0.5 * L)^(-1) element by element.
Eigenvalues of L that are small (consensus modes): (I + 0.5 * small_lambda)^(-1) is close to 1, so they are preserved.
Eigenvalues of L that are large (noise modes): (I + 0.5 * large_lambda)^(-1) is small, so they are suppressed.
Result: S_refined has the same consensus structure but less view-specific noise.

Resolvent diffusion is a mathematically principled way to amplify consensus and suppress noise without filling in missing data.

What can go wrong

What can go wrong

Anchor quality matters. If the anchors are chosen poorly (e.g., all from one cluster), the hypergraph will not represent diversity. The filter then amplifies a skewed structure. The paper mitigates this by learning anchors end-to-end, but a bad initialization can harm results.
Diffusion scale delta is a tuning knob. Too small and the filter does almost nothing. Too large and it suppresses useful signal along with noise. Choosing delta requires held-out validation (trying a few values and picking the best). No theory tells you the right value ahead of time.
Very high missing rates can still hurt. If more than 80-90 percent of the data is missing, the observed anchors and hypergraph may be too sparse to reconstruct the true structure. The filter is selective, but it cannot create information that is not there.
Done right. When anchors are diverse, delta is tuned carefully, and missing rates are moderate (less than 70 percent), the resolvent diffusion filter reliably amplifies the consensus and produces cleaner clusters.
What a runnable demo should prove

What a runnable demo should prove

A simple demo with three objects (A, B, C) and three views (text, image, metadata). Randomly hide 50 percent of the views. Learn anchors and build the hypergraph. Apply resolvent diffusion with a few choices of delta. Measure clustering purity on the three objects (they should group correctly despite the missing data). Show that the filter with the right delta produces higher purity than naive averaging or no filtering.

purity = (sum of items correctly grouped to consensus) / (total items)

The key observation: resolvent diffusion cleanly separates consensus from noise even when half the data is missing. Naive averaging does not.
