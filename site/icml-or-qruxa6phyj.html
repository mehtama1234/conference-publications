GLAD: Bidirectional Alignment for Missing Graph Attributes

A diffusion-based method fills in missing features on graphs by learning to generate attributes that preserve the graph's structure.

Paper explainersAll themesGraph & Geometric Learning

Real-world graphs often have missing node features — think of a social network where some people have incomplete profiles. Existing methods try to predict these features using adversarial learning, but they get stuck in mode collapse, failing to explore all realistic possibilities. GLAD fixes this by using a diffusion model (a method that learns by gradually removing noise from corrupted data) to generate plausible attributes while guaranteeing the generated features stay consistent with the underlying graph topology.

Zero assumption version

Missing features on graphs

Many real-world networks have incomplete data. A citation graph might miss author affiliations, a molecular graph might lack atom properties, a social network might have incomplete user profiles. The naive approach is to train a model on the complete nodes and predict the missing attributes using a standard regression or classification network.

This fails in practice for two reasons. First, the missing attributes are often not deterministic — multiple valid answers exist. A missing author affiliation could be any of several plausible institutions. Second, existing adversarial methods (called GANs) that try to learn this uncertainty often collapse into predicting the same boring average answer for every missing node, and they can be unstable to train. They miss the full range of what is realistic.

The challenge in one sentence. Fill in missing graph features in a way that stays true to the graph's structure and explores all plausible possibilities, not just the average.

What the paper changes

What the paper moves

The paper changes the way missing node attributes are generated: instead of using a single adversarial network that predicts one answer per node, it uses a diffusion model that learns what plausible attributes are possible for each node, given both the graph structure and the existing features.

the object it moves  =  the generative process for missing features
The hidden quantity

The possibilities for features given graph structure

measured quantity  =  what attributes are realistic for a given graph

The hidden quantity the paper cares about is what possible sets of node features are realistic for a given graph structure. This is not a single answer; it is the set of all plausible possibilities — for a node with certain neighbors, what feature values make sense? A diffusion model estimates this by learning to reverse a noising process: it starts with random noise and learns what plausible feature values look like in the context of that specific graph.

The paper estimates this by training the diffusion model on nodes with complete features, learning which feature combinations are realistic for a given graph topology. Then, during sampling, it generates multiple samples for the missing nodes, ensuring diversity and fidelity to the graph.

Why it works

Why bidirectional alignment preserves structure

The core insight is that diffusion models are good at learning complex, multi-modal distributions (many different plausible answers), but without guidance they can drift away from what the graph topology allows. GLAD fixes this by adding two structure-preserving constraints.

First, during training, the model also tries to reconstruct the graph structure from the generated attributes. This forces the feature generation process to learn what attributes are consistent with the given topology. Second, during sampling, a structure-aware classifier steers each denoising step to keep the features aligned with the graph neighbors by guiding the model away from options that contradict the topology. The result is that the diffusion model explores a wide space of plausible features, but every sample it produces maintains strict topological consistency — no contradictions between the features and the graph edges.

Math after the picture

The diffusion objective with structure alignment

First in words:

minimize the negative log-likelihood of the generated attributes plus a penalty if the reconstructed graph does not match the original topology, plus guidance from a classifier that keeps samples aligned with neighbors

Then the compact form:

loss = -log p(X|G) + lambda * d(G, G_reconstructed) + guidance_term

Every symbol:

Xthe missing node attributes being generated
Gthe graph structure (edges and existing features)
p(X|G)the probability distribution of attributes given the graph structure
G_reconstructedthe graph structure decoded from the generated attributes
d(G, G_reconstructed)a distance measure between the original and reconstructed graphs
lambdathe weight controlling how strongly structure is preserved
guidance_termthe contribution from the structure-aware classifier steering denoising
A tiny worked example
Suppose for a node we start with random noise list [0.8, 0.2, 0.9].
The diffusion model denoises it step by step toward [0.1, 0.7, 0.3] (a realistic value from training data).
The classifier checks: does this feature match the neighbors? It computes a guidance signal saying yes, so denoising continues.
But if the model tries to denoise toward [0.9, 0.05, 0.95], the classifier says no — this contradicts neighbor features.
The guidance pulls the next denoising step toward [0.2, 0.6, 0.4] instead, keeping structure intact.
Final loss = -log(probability of [0.2, 0.6, 0.4] given graph) + small reconstruction penalty + classifier guidance pushing against misalignment.

The loss function combines three goals: generate realistic features (first term), keep the graph structure intact (second term), and ensure consistency with neighbors (third term). Training learns to balance all three.

What can go wrong

What can go wrong

Too much structure constraint. If the graph structure is corrupted or noisy, over-emphasizing structure preservation can force the model to generate implausible features just to match the bad edges. The balance between lambda and guidance strength matters.
Stale diffusion model. If the training data is not representative of the graph being completed, the diffusion model has learned wrong ideas about what features are realistic. Garbage in means garbage attributes out.
Slow sampling. Diffusion models require many denoising steps, making sampling much slower than a single-pass adversarial network. Sampling hundreds of times to get diversity is computationally expensive.
Done right. Train the diffusion model on representative complete graphs, set lambda to balance realism and structure consistency, and do multiple sampling runs to explore the full distribution of plausible attributes.
What a runnable demo should prove

What a runnable demo should prove

Build a simple graph completion task: create a citation network with 50 nodes and 100 edges where 20 nodes have missing author affiliations (the attributes). Train GLAD on the 30 complete nodes. Then sample 10 times from GLAD for each missing node and measure two things: first, does each sample's affiliation make sense (i.e., does the sampled graph structure match the original edges)? Second, do different samples give different but equally plausible answers, or does it collapse to the same answer each time?

structure_fidelity = fraction of samples where reconstructed edges match original graph; diversity = number of distinct attribute vectors generated per missing node

The demo succeeds if almost all samples have perfect structure fidelity (the graph stays intact), and each missing node gets at least 5 different plausible attributes instead of repeating the same prediction.
