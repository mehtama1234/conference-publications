Large Language Model Teaches Visual Students: Cross-Modality Transfer of Fine-Grained Conceptual Knowledge

LaViD transfers class-level conceptual knowledge from a language-only model to an image model by turning each visual class into a distribution over language-generated multiple-choice questions.

Paper explainersAll themesOther

Fine-grained visual recognition asks a model to tell apart classes that are visually close, such as bird species with small differences in beak shape, color pattern, or habitat cues. Large language models already encode many such conceptual distinctions from text, but they usually cannot teach an image model unless we also give paired image-text data or a vision-language teacher. LaViD removes that requirement. It asks a language-only teacher to write multiple-choice questions that separate classes conceptually, then records how each class answers those questions as a soft target distribution (a list of answer probabilities rather than one hard answer). The image student is trained not only on image labels but also on these class-level conceptual targets, so it learns which distinctions matter even though the teacher never saw images.

Zero assumption version

Image students need conceptual supervision, not only class IDs

In fine-grained classification, two classes can differ by subtle traits. Standard supervision gives the student only a class label, which says which category is correct but not which semantic distinctions separate nearby categories. Distillation from a stronger visual teacher can help, but that usually requires a vision-language model or paired multimodal data, both of which are expensive because another model that already links text and images has to be trained or supplied.

The paper asks whether a language-only teacher can still help, and the answer could be yes because the teacher can still describe class-level differences even without seeing any image. The challenge is obvious: a text model does not see images. So it cannot provide image-specific feature maps or per-image focus maps, which means maps of where the model looked. What it can provide is class-level conceptual structure. The paper turns that structure into a form an image student can train against.

The core problem. A class label says what the answer is, but it does not say which semantic distinctions the student should organize its features around.

The algorithm as a flow

What it actually does

Prompt the language teacher

Ask the language model to write multiple-choice questions that probe differences between classes.

Score each class on those questions

Map every class name to a soft answer pattern over the question options.

Attach the pattern to image labels

Whenever an image belongs to a class, use that class's concept pattern as an auxiliary training target.

Train the image student

Optimize the usual label loss together with a distillation loss that pushes the student toward the concept pattern.

Evaluate standard and worst-group accuracy

Check not only average classification but also whether the student relies less on spurious background cues.

What the paper changes

What the paper changes

The paper changes what the teacher sends to the student. Instead of sending visual features or image-text pairs, the teacher sends class-level semantic distinctions encoded as answer patterns to generated questions.

The hidden quantity

The hidden quantity: conceptual similarity between classes

measured quantity  =  Which classes differ for the reasons that matter

The class label alone hides the structure among classes. Two bird species may share most traits and differ on one detail, while two other species differ on several traits. A good student should represent those differences in proportion to how conceptually important they are.

LaViD exposes that hidden structure through question-answer patterns. If two classes answer the same generated questions similarly, their concept profiles stay close. If they answer differently on the traits that matter, their profiles separate. The student then receives a training signal that reflects not only the final class ID but also the conceptual neighborhood around that class.

Why it works

Why it works: class-level concepts survive the move from language to vision

The method works because many fine-grained class distinctions are semantic before they are visual. A language model may know that one species has a curved beak, another has a white eye ring, and a third lives in a marsh rather than a forest. It cannot point to the pixels in a given image, but it can still express which traits separate the classes. That class-level knowledge is exactly what the student lacks when trained only on class IDs.

The multiple-choice format matters because it turns open-ended language into structured supervision. Each question creates a fixed set of options, and each class receives a probability pattern over those options. The resulting target is richer than a one-hot label because it preserves uncertainty and partial overlap among classes. Classes that answer many questions similarly stay close in the distilled signal, while classes that differ on key traits separate cleanly.

The auxiliary loss matters because it changes what internal features the student is rewarded for keeping. If the student can classify a bird correctly only by background water or branch texture, the concept targets provide pressure against that shortcut because those backgrounds do not explain the teacher's question-answer pattern. That is why the paper reports gains not just in average fine-grained accuracy but also in worst-group accuracy on Waterbirds.

Math after the picture

The equation: label loss plus concept loss

First in words:

Training combines ordinary image classification with a second loss that asks the student to match the class-level concept profile supplied by the language teacher.

Then the compact form:

total_loss = label_loss + concept_weight * concept_distillation_loss

Every symbol:

total_lossthe score used to train the image student
label_lossthe ordinary loss for predicting the correct class from the image
concept_weighthow strongly the conceptual signal influences training
concept_distillation_lossthe mismatch between the student's output pattern and the teacher's class-level concept profile
A tiny worked example
Suppose the teacher asks whether a bird's beak is short, medium, or long.
For class A, the teacher profile is 0.1, 0.2, 0.7 over those three answers.
The student currently predicts 0.3, 0.4, 0.3 for images of class A.
The concept loss is high because the student is not emphasizing the long-beak trait enough.
Training shifts the student's features so that images of class A move closer to the teacher's class profile.

The exact loss form can vary, but the paper's structural move is to add a class-level conceptual target beside the usual class label.

What can go wrong

What can go wrong

The teacher can generate weak questions. If the multiple-choice questions do not separate classes in a clear way, the distilled concept profiles will add noise rather than structure.
Language knowledge may be incomplete or wrong. A language model can encode stereotypes, omissions, or factual mistakes about classes, and those errors can be transferred into the student.
Class-level signals miss image-specific details. Because the teacher never sees the image, LaViD cannot point to which pixels realize a trait in a particular example. The method helps by shaping class structure, not by supplying per-image localization.
Done right. Use carefully filtered concept questions, keep the ordinary image label loss active, and test worst-group performance to check whether the student is learning class-relevant distinctions instead of shortcuts.
What a runnable demo should prove

What a runnable demo should prove

Take a small fine-grained image dataset with classes that can be described in text. Ask a language model to generate trait-based multiple-choice questions for those classes, convert each class into a concept profile, and train two image students: one with labels only and one with labels plus LaViD concept loss. Then inspect both average accuracy and subgroup accuracy under a background shift. The demo should show that the concept-guided student separates nearby classes more cleanly because it was trained on the distinctions that define the classes, not only on image labels.

gain = concept_guided_accuracy - label_only_accuracy

The important result is that language can teach visual distinctions at the class level even when the teacher never receives images.
