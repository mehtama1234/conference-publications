CompassNav: Steering From Path Imitation to Decision Understanding In Navigation

CompassNav trains a navigation agent to score every available move, because choosing well in new places requires understanding the full decision set rather than copying one past route.

Paper explainersAll themesAgents & Tool Use

Many navigation agents are trained by replaying one expert route from start to finish. That teaches the agent what one good path looked like, but it does not teach why one turn is better than another when several turns are possible, because the rejected turns are never scored. CompassNav changes the training target. Instead of asking the model to copy a route step by step, it asks the model to judge all feasible actions at each step by how much closer each action gets the agent to the goal. That change matters because an agent that can rank choices can recover from mistakes, use alternate routes, and keep moving when the scene does not match the training trace exactly.

Zero assumption version

Copying one path leaves the agent brittle

Path imitation turns navigation into route replay. At each step the model sees one action marked correct and all other actions left unexamined. That is a weak lesson because the agent never learns whether the rejected actions were almost as good, clearly bad, or blocked only in that one scene.

Real navigation is a sequence of local choices under uncertainty. The agent may arrive at the same hallway from a slightly different angle, or it may miss one turn and need to recover. An imitation-only learner struggles there because it has stored route fragments instead of a rule for comparing choices.

The paper argues that the core missing skill is decision understanding: the agent should know how each feasible move changes distance to the goal. Once that signal is available, training can reward better decisions directly because the model is judged on the quality of its choice set, not on exact agreement with one recorded route.

The shift: Teach the agent to rank choices by goal progress, because ranking transfers to new routes while exact replay does not.

The algorithm as a flow

What it actually does

Build routes with full action labels

For each state, the dataset records all feasible moves and the remaining shortest-path distance after each move, so the model sees a graded decision table instead of one chosen action, because every action now carries an explicit quality label.

Warm start with supervised training

The model first learns from labeled examples because that gives it a stable policy before reward-based updates begin.

Compute certainty from the action gap

The system measures how far the best move is ahead of the second-best move, because large gaps mean the scene has a clear decision while small gaps mean several moves are close.

Apply a gap-aware reward

When the best move is clearly ahead, the reward is decisive. When several moves are close, the reward is softer so that the agent can explore without being over-punished.

Train the policy to rank moves well

Reinforcement updates favor choices that shorten the route because the reward is tied directly to goal progress rather than route copying.

What the paper changes

What the paper changes

The paper changes the supervision target from one expert action to a scored action set. That one change matters because the model is now trained to understand relative move quality, which is the core decision needed at test time.

The hidden quantity

The hidden quantity: action gap

measured quantity  =  Distance gap between the best and next-best move

At a navigation step, several moves may be available: go forward, turn left, turn right, or stop. Each move leaves a different remaining distance to the goal. The hidden quantity is the action gap, which is the difference between the best remaining distance and the second-best one.

This gap tells the trainer how certain the decision is. If one move cuts the remaining route much more than the others, the gap is large and the feedback should be strong because the correct choice is clear. If two moves are almost tied, the gap is small and the feedback should be softer because harsh punishment would teach false certainty where the scene truly allows more than one good continuation.

Why it works

Why ranking actions works better than route copying

A route trace is a narrow supervision signal. It says what the expert did, but it does not say how much worse the alternatives were. That makes learning fragile because the same local scene may admit several valid continuations, and the model is punished for not replaying the recorded one exactly.

CompassNav replaces that narrow signal with a full local comparison. At each step, the model evaluates every feasible move against a concrete target: how much route remains after taking that move. This helps because the agent can transfer the comparison rule to states that were never visited in the training trace. Even after a mistake, the agent can still ask which move now reduces remaining distance the most.

The gap-aware reward is the second key part. In clear-cut scenes, the method gives sharp feedback because one move is plainly better. In ambiguous scenes, it gives softer feedback so that near-tied actions are not treated as equally wrong. That balance improves exploration and stability because the reward matches the actual certainty of the navigation decision.

The decision-quality objective

First in words:

Total training objective combines supervised warm-start loss and reward-based policy loss, where the reward strength depends on how much better the best move is than the next-best move.

Then the compact form:

L_total = L_sft + lambda * L_rl, with reward(a) = f(d_second - d_best, d_a - d_best)

Every symbol:

L_sftsupervised warm-start loss on labeled navigation actions
L_rlreinforcement loss that favors higher-reward actions

A tiny worked example
Suppose three moves are available. After moving, the remaining route lengths are 4 steps, 5 steps, and 9 steps.
The best move leaves 4 steps and the next-best leaves 5, so the action gap is 1 step.
Because the gap is small, the trainer should treat the 5-step move as close to correct and the 9-step move as clearly poor.
Now consider another state where the choices leave 3 steps, 8 steps, and 10 steps.
Here the gap is 5 steps, so the reward can be much sharper because one move is clearly superior.
The paper uses this kind of certainty-aware feedback so that policy updates match the structure of the decision.

The formula matters only as a summary. The real idea is that reward depends on relative route quality, not on exact replay of one expert trace.

What can go wrong

What can go wrong

Distance labels can be wrong. If the shortest-path labels are inaccurate, the reward teaches the wrong decision because the policy is optimized against those labels.
The reward can become too soft. If nearly all scenes are treated as uncertain, learning slows because the agent stops receiving clear preference signals when one action really is better.
The action set may miss a feasible move. If the environment or annotation pipeline omits a valid action, the ranking target is incomplete, so the learned policy can appear confident while still lacking a useful option.
Done right: the agent learns recovery. When action labels are complete and reward sharpness matches decision certainty, the policy improves because it learns how each move changes remaining route length.

What a runnable demo should prove

Train one agent by path imitation only and a second agent with the paper's two-stage recipe: supervised warm start followed by reward-based updates with gap-aware feedback. Evaluate both on standard success rate and on a recovery test where the start state is shifted one move off the expert route.
