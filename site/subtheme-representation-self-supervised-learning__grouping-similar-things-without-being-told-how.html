Grouping similar things without being told how

Papers use clustering and prototype learning to organize data into meaningful groups by discovering natural patterns, without relying on human-provided category labels.

All themesField mapMathematicsAll explainers
What this is

Humans naturally cluster things: we recognize that apples and oranges are both fruits, or that a bicycle and a skateboard are both personal transport. Computers don't have this intuition. Clustering — grouping similar items without being told the categories upfront — is a fundamental task. Many real datasets have natural structure: similar documents cluster together, customer purchase behaviors group into profiles, proteins fold into families. If a model can discover these clusters without labels, it captures something real about the data's structure.

The challenge is defining 'similar' and 'cluster' without human guidance. Local clustering (grouping nearby points) is easy but fragile. Deep clustering tries to learn representations where clusters emerge naturally, but the model can collapse into trivial solutions: putting everything in one cluster, or creating many micro-clusters that do not reflect true structure. Papers use prototype learning (learn a set of cluster centers that represent the data) combined with self-supervised learning: the model compares each sample to prototypes, assigning it to the closest one, and simultaneously learns representations that make clusters more crisp. Some methods use consistency: if you apply different augmentations (slight changes) to the same image, the model should assign both to the same cluster.

Across 33 papers, researchers develop clustering objectives that avoid collapse, study how many clusters naturally exist in different datasets, and explore whether unsupervised clusters align with human-defined categories. Papers also ask how to update clusters over time as new data arrives, and how to handle data where there are many equally valid clusterings (e.g., images could be grouped by object type, color, or photographer style). The practical applications are strong: unsupervised data exploration, anomaly detection (points far from all clusters), and bootstrapping labels for downstream tasks.

How the work breaks down

Unsupervised clustering splits naturally into two main challenges: handling incomplete or partial views of data (when you see only parts of what you need), and discovering new clusters beyond what you already know about. Some work tackles multi-view clustering where a single item is described by multiple different angles or sensors, while other work focuses on generalized category discovery, which means finding both known groups and previously unseen ones in the same dataset. A third direction studies how to handle noisy or misaligned data, and a fourth explores how representations themselves should change to make clusters clear and natural.

Incomplete multi-view clustering foundations

When real data comes from multiple sources or viewpoints, you often have missing pieces. An image can be described by its pixels and its text caption, but sometimes the caption is missing. A medical sample might have genetic data and imaging data, but the imaging might not exist for all samples. Standard clustering assumes you see everything. The challenge is to discover clusters even when parts of the data are absent, without just guessing what the missing pieces are.

ARSL-IMVC addresses this by learning a shared hidden representation (a compressed encoding that captures patterns across all views) that captures what the different views have in common, then using that common space to drive clustering decisions. The key idea is that even if one view is completely missing for a sample, the learned representation can still position that sample correctly relative to clusters. Causal-Invariant Meta-Learning for unbalanced incomplete multi-view clustering goes further by detecting and correcting observation bias, which happens when certain views are missing not randomly but because of patterns in the data itself (for example, expensive tests might be skipped for certain patient groups). This method learns to weight views fairly despite the imbalance. Masked Multi-path Contrast improves clustering by treating missing values carefully: instead of pretending they do not exist, it masks them explicitly and learns a consensus view across all paths through the data. CorreGen takes a different angle by recovering what the true correspondence should be between samples across views, which helps it cluster well even when the views are noisy or misaligned. Finally, Confident Block Diagonal Structure uses the insight that if you organize the data by samples and views, the true cluster structure should appear as block patterns in that organization, and it can reconstruct missing values by respecting this block structure. Together, these five methods show that incomplete data is not impossible—you just need to model what is missing and use the structure you do see to fill the gaps.

These papers build on each other: the early ones learn from what is present, the middle ones explicitly model what is absent, and the later ones use geometric structure to guide both steps.

Fixing cluster collapse and spatial shape

One of the deepest problems in unsupervised clustering is collapse: the model learns a representation where everything looks the same, or breaks into tiny meaningless fragments. A model might put all samples in a single cluster (worst case), or scatter them into one micro-cluster per sample, neither of which reflects real structure. The root cause is that there is no external signal pushing back. In supervised learning, labels force the model to separate classes; in unsupervised learning, the model must learn to separate clusters by examining only the data's internal structure and shape.

Bures Generalized Category Discovery solves this by preserving the shape of the underlying manifold (the smooth surface in high-dimensional space where data naturally lives) rather than crushing it down. This means clusters stay spread out and distinct, because the method respects the natural shape of the data. CURE achieves this through consistency: if you apply random augmentations (small changes like cropping or color shift) to an image, and they still belong to the same cluster, the model learns a representation where similar samples stay together despite noise. This consistency loss directly prevents collapse because it forces samples to stay close to their neighbors. Multi-Scale Diffusion-Guided Graph Learning builds a neighborhood graph based on diffusion, which is a natural process for spreading information through a dataset. This approach reconciles two competing goals: consistency (samples in the same cluster should stay similar under change) and specificity (different clusters should actually be different). The diffusion naturally balances these by looking at multi-scale neighborhoods. Beyond Independence extends this by learning how different views correlate with each other, rather than assuming they are independent. When views are explicitly correlated, the model avoids spurious solutions that ignore whole views. All four methods address collapse by adding constraints that force the representation to be detailed and well-structured.

These approaches complement each other: shape methods preserve natural structure, consistency methods tie samples together, graph methods respect local neighborhoods, and correlation methods use multiple signals at once.

Category discovery with known and new classes

In real applications, you usually know about some categories but expect to find new ones. A model trained on known dog breeds should still discover a cat in the data. This is generalized category discovery: cluster the known categories correctly, and simultaneously find unseen clusters you have never encountered. The challenge is that without labels for the new categories, the model must use only the structure of the data to decide if something is known or new.

Adaptive Gaussian Expansion handles this by placing a learnable Gaussian distribution (a bell curve encoding the center and spread of a class) around each known class, then assigning unknowns to new clusters based on their distance from all known ones. The "adaptive" part means the Gaussians adjust their size and shape as new data arrives, so the boundary between known and new is not fixed but learned. PRISM tackles the harder case where the world keeps changing: new categories appear over time, and the known categories themselves might shift slightly in distribution. It learns progressively by reweighting samples to focus on the hardest cases and avoiding forgetting what it learned about known classes. PartCo improves discovery by using part-level correspondence: instead of treating a whole image as one unit, it finds similar parts (corners, edges, textures) across images, which gives finer-grained signals about whether two images are the same category or not. SpectralGCD does this efficiently by selecting which concepts (features) from a vision model are most useful for distinguishing known from new categories, then uses those concepts to drive clustering. All four methods work with real labels for known categories during training, but must generalize to unlabeled new ones—a fundamental asymmetry that these approaches handle by using consistency, spatial separation, or concept selection.

These methods operate at different granularities: object-level (Gaussian Expansion), time-level (PRISM), part-level (PartCo), and concept-level (SpectralGCD).

Multi-view and federated clustering at scale

When data is large, distributed, or sensitive, clustering must scale without centralizing everything or revealing private details. Federated learning means each person or organization keeps their data local and only shares model updates, not raw data. Multi-view clustering at scale means handling multiple data sources efficiently. These are independent challenges: your data might have millions of samples with multiple views, spread across many servers.

Federated Multi-view Clustering for Remote Sensing Data solves the privacy problem by letting each satellite or ground station train clustering locally, then aggregates those clusterings into one global model without sharing raw imagery. The efficiency comes from carefully choosing what information to communicate between sites. Asymmetric Multi-View Clustering with Hyperbolic Uncertainty Modeling uses a different mathematical space: hyperbolic space, which is a curved coordinate system where distances work differently than in flat space. In hyperbolic space, distant points become exponentially farther apart, so high-level and low-level clusters automatically stay separated even without additional constraints. This space allows uncertainty to be modeled directly, and is faster and clearer than standard flat coordinate systems when clusters have a natural hierarchy, because the coordinate system itself prevents collapsed layers. BASIL adds another dimension: it learns which features actually matter for clustering, which both speeds up computation and makes the clustering interpretable—you can see why items ended up together. Bipartite Graph Focusing for scRNA-seq Data handles the scale problem for biological data by using a selective focusing mechanism (which concentrates on the most relevant pairs) over a bipartite graph, achieving linear complexity even on hundreds of thousands of cells. Nonconvex Low-Rank Tensor Representation uses the structure of tensors (multi-dimensional arrays) to compress the representation while preserving clustering quality. Together, these five papers show that scale is not insurmountable if you use the right mathematical space, focusing mechanisms, feature selection, or decomposition.

They use complementary strategies: federation for privacy, hyperbolic space for hierarchy, feature selection for interpretability, graph focusing for efficiency, and tensor decomposition for compression.

From partial data to full understanding

A final set of methods focuses on bridging gaps: learning from sparse or partial signals, understanding why clusters form, and incorporating multiple modalities like image and text. The underlying question is how to turn incomplete or noisy signals into clustering decisions, and how to explain or validate those decisions.

Debiased and Denoised Projection Learning avoids the cost of imputing missing values by learning projections directly from the complete-data parts, then uses those projections to cluster everything. Explainable K-means Neural Networks brings interpretability to neural clustering: instead of a black-box deep model, it builds a learnable version of classic K-means that stays interpretable while gaining the flexibility of neural networks. Fairness-Informed Multi-View Clustering ensures that cluster sizes and properties are fair across different groups in the data, which prevents the model from over-representing some samples and under-representing others. Information-Theoretic Disentangled Representation Modeling uses conditional diffusion to generate missing views, but does this in a way that preserves information-theoretic properties (the mathematical bounds on what signals can carry), so the generation respects what the data can actually say. Neural Flow-Based Registration and Clustering solves a different problem: when functional data (like time series or curves) are not aligned, it first registers them (stretches and shifts them to align) then clusters them jointly. Relationship Alignment for View-aware Multi-view Clustering preserves the natural relationships between views: if two samples are similar in one view, they should stay similar in others, and clustering should respect these cross-view relationships. Smoothing Slot Attention improves object discovery by smoothing how the attention slots (learnable templates that selectively focus on different objects) evolve across iterations, preventing them from chasing noise or becoming unstable. Finally, Spatial Structure and Selective Text Jointly Support Image Clustering combines visual layout (where objects are in an image) with text descriptions, using a learned selector to pick which text features actually help. This works better than using all text features because irrelevant text noise would pull the clustering in wrong directions, so intelligent weighting of each mode makes the fusion actually work. These eight papers solve the problem of going from partial or heterogeneous data to full, interpretable clusters.

They connect structure (registration, relationships, layout) with learning (projection, diffusion, selection, smoothing) to build end-to-end systems.
