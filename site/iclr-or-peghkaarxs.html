Brain Graph Foundation Model

Train one brain model on many brain scan types at once by teaching it to spot matching patterns and fill in missing signals.

Paper explainersAll themesAI for Science

Brain scans measure how different brain regions talk to each other through patterns of activity. Most models learn from just one type of scan or one way of dividing up the brain. This paper trains a single model on dozens of brain scans, using many different brain maps (called atlases), so it learns patterns that work across many kinds of brains and brain disorders.

Zero assumption version

One model, one brain map—big data stays locked away

Brain imaging produces millions of scans. But each scan gets divided into regions using a specific brain atlas—a map that labels which parts are which. If a hospital uses atlas A and a research lab uses atlas B, those scans are incompatible. A model trained on atlas A cannot work on atlas B's data. So researchers throw away huge amounts of brain data.

A beginner might try: train separate models for each atlas. But that is wasteful—the brain's actual patterns do not change just because we drew the regions differently. The underlying signals are the same; only the lens changed.

The core problem. Train one model that works on any brain atlas by learning the shared patterns beneath all the different maps.

What the paper changes

What the paper changes

Most brain models train on brain regions as time-series sequences (activity over time) or as single averaged correlations per region. This paper converts brain scans into graph structures: each brain region is a node, and connections between active regions become edges. The entire model redesigns around this graph representation.

the object it moves  =  brain scan representation
The hidden quantity

The shared pattern across atlases

measured quantity  =  atlas-invariant brain structure

Even though different brain atlases draw boundaries in different places, the underlying relationships between active regions stay the same. This paper measures this hidden shared structure by teaching the model to spot when two graphs (one from atlas A, one from atlas B) represent the same person's brain activity, just carved up differently.

The model estimates this by learning an encoder that produces similar codes for matching brain patterns regardless of atlas, and different codes for different people. It does this through contrastive learning (saying this graph matches that graph) and masked learning (hiding a region and predicting it back from its neighbors).

Why it works

Why two teachers teach one encoder better

The paper runs two learning games in parallel on the same encoder. The first game says: 'here are two graphs from the same brain but different atlases—make their codes look alike.' The second game says: 'I hid some regions; predict them from their neighbors.' Each game pulls the encoder in the same direction. Contrastive learning finds what makes a brain unique; masked learning finds what brain structure is predictable from local context. Together they trap the encoder into learning the true shared structure beneath the atlas labels.

When a new disorder or atlas appears at test time, the encoder already knows that structure, so it adapts quickly with just a few examples. The atlas label tokens act like dial markings: the same encoder engine rotates to fit any atlas because the core brain relationships are encoded in the shared weights, not the atlas labels.

Math after the picture

The learning equation

First in words:

total loss equals contrastive loss (push matching graphs together) plus masked loss (predict hidden regions from neighbors), where both operate on the same encoder weights

Then the compact form:

L_total = L_contrastive + L_masked = (1/N) * sum_i ||encode(G_i) - encode(G_i')||^2 + (1/M) * sum_j ||region_j - predict(neighbors_j)||^2

Every symbol:

G_igraph from one subject-atlas pair
G_i'graph from the same subject, different atlas
encode(G_i)the model's code for graph G_i
region_jthe hidden region's true values
predict(neighbors_j)the model's guess based on neighboring regions
||...||^2squared difference (how far apart the codes are)
N, Mnumber of graph pairs and hidden regions
A tiny worked example
Two atlases measure the same brain: Graph-A (atlas A), Graph-B (atlas B).
Encode-A = 0.5, Encode-B = 0.4 (both from same brain, should be close). Difference squared: (0.5 - 0.4)^2 = 0.01 ✓ small.
Different brain: Graph-C = 0.9. Compare to Graph-A: (0.5 - 0.9)^2 = 0.16 ✓ large (good, they are different).
Mask region 3 in Graph-A. Regions 2, 4 (neighbors) are 0.7, 0.6. Predict region 3 ≈ 0.65. True value = 0.68. Error = (0.68 - 0.65)^2 = 0.0009 ✓ tiny.
Both losses push the encoder the same way: same-atlas pairs close, different people far, hidden regions predictable from neighbors.

The same encoder weights move to satisfy both constraints, learning brain structure that survives any atlas map.

What can go wrong

What can go wrong

Bad atlas choices break the sharing. If you include very different brain atlases that fundamentally disagree on region boundaries, the model cannot find shared structure. Pick atlases that neurologists agree measure the same underlying anatomy.
Imbalanced datasets bias the encoder. If one atlas has 1000 scans and another has 10, the encoder learns to favor the big atlas. Pre-training weights must balance data across atlases or the shared structure is skewed.
Artifacts in scans propagate through graphs. If a subject moved during scanning, the graph will have spurious correlations. The encoder will learn these artifacts as if they were real brain structure. Quality filtering before graph construction is essential.
Done right: balanced atlases, clean scans, two losses at once. Combine datasets carefully, filter for scan quality, and run contrastive and masked learning together on the same encoder. The multi-task setup is the win.
What a runnable demo should prove

What a runnable demo should prove

Build a tiny multi-atlas pre-trainer: take scans from two brain atlases (functional and anatomical). Convert each scan to a graph by computing region-pair correlations. Implement the contrastive loss (compute similarity between same-subject pairs from different atlases) and the masked loss (hide one region, predict from neighbors). Train the encoder on both losses for a few epochs. Then freeze the encoder and fine-tune a small head on a held-out disorder (say, five subjects with autism, five without). Measure accuracy on a test set of new subjects.

accuracy = (correct_predictions) / (total_test_subjects); generalization_gain = (multi_atlas_accuracy - single_atlas_accuracy)

The demo succeeds if multi-atlas pre-training achieves higher test accuracy than training from scratch on a single atlas, proving that shared structure learned from many atlases transfers to unseen disorders.
