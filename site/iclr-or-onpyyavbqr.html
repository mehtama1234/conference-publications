A Graph Meta-Network for Learning on Kolmogorov-Arnold Networks

Weight-space models can predict properties of Kolmogorov-Arnold Networks when designed to respect their graph structure and permutation symmetries, just as earlier weight-space models respected MLP symmetries.

Neural networks are just lists of numbers called weights. A weight-space model is a separate neural network that reads in those numbers and predicts something useful — like how well the original network will perform on a new task. This has worked for standard neural networks, but Kolmogorov-Arnold Networks (KANs) are a newer architecture with different internal structure. This paper shows how to design a weight-space model specifically for KANs by understanding their symmetries.

Zero assumption version

Predicting network performance from weights alone

Neural networks are just enormous collections of numbers (weights). If you have a trained network, you have all these numbers sitting right there. A natural question: can you predict how well that network will perform just by looking at the numbers, without running the network at all?

A beginner tries the obvious approach: flatten all the weights into one long list and feed it to a regular neural network (an MLP). This fails badly. The reason: a regular neural network cares about the order of its inputs. But in neural networks, shuffling the order of certain weights does not change what the network computes — you can swap two neurons in a hidden layer and the final output is the same. A naive MLP treats these equivalent weight arrangements as completely different inputs, so it wastes capacity learning that these shuffles do not matter.

Earlier methods solved this for standard MLPs by building graph representations that respect permutation symmetry — the property that swapping neurons should not change the prediction. But KANs are a new kind of architecture. No one had designed a weight-space model that respects their internal structure.

In one sentence. Design a weight-space model that accounts for Kolmogorov-Arnold Networks' unique computational structure and permutation symmetries.

What the paper changes

The architecture that reads weights

The paper changes how a weight-space model is structured. Instead of a standard neural network that treats weights as a flat list, WS-KAN processes the weights as a graph — recognizing that neurons in a KAN are arranged in a specific computational structure, and that swapping neurons within layers does not change what the KAN computes.

the object it moves  =  weight-space architecture
The hidden quantity

Permutation-invariant weight grouping

measured quantity  =  symmetry-respecting weight partition

In a neural network, certain subsets of weights can be freely rearranged without changing the function the network computes. For example, if layer 2 has three neurons, and layer 3 has four neurons, you can reorder the three neurons in layer 2 in any way and still have an equivalent network — the weights out of each layer 2 neuron just get permuted along with it. This property is called permutation symmetry.

The paper measures which weights fall into which symmetry groups and builds its weight-space model so it treats permutations within a group as the same input. It partitions the weights into sets that respect the graph structure of the KAN — where nodes (neurons) are units that can be swapped, and edges carry the functions that connect them. By grouping weights this way, the model learns faster and generalizes better, because it is not wasting effort on permutations that do not matter.

Why it works

How graph structure guides the weight-space learner

The core insight is a trade-off between flexibility and structure. A naive weight-space model is very flexible — it can learn any pattern in the weights. But it wastes this flexibility re-learning the same pattern for every permutation of the same network. By building the weight-space model to be symmetric, you constrain it in a smart way: it learns the pattern once and applies it to all permutations automatically.

Here is the mechanism: (1) Take the KAN weights and partition them into groups that respect the graph structure — neurons at the same layer can be permuted, so their outgoing weights belong to the same equivalence class. (2) For each equivalence class, the weight-space model processes the weights as an unordered set (using techniques that ignore order). (3) The model also reads the graph topology — which neurons connect to which — and combines this structure information with the weight values. (4) This combination of weight partitions plus graph structure makes the model permutation-invariant: if you permute neurons within a layer, the weight groups permute along with them, but the unordered processing and graph structure mean the model's output stays the same. (5) Because the model is now using the right structure, it learns the true pattern faster and makes better predictions.

The prediction formula

First in words:

The predicted accuracy equals a base value plus learned weights multiplied by features extracted from weight groups and graph structure

Then the compact form:

pred = b + sum_g w_g * f_g(weights_g, graph)

Every symbol:

A tiny worked example
Suppose a KAN has two symmetry groups (layer-1 weights and layer-2 weights).
Group 1 (layer 1): raw importance signals from 8 neurons → averaged = 0.6 on a 0-to-1 scale.
Group 2 (layer 2): raw importance signals from 4 neurons → averaged = 0.4.
Learned weight w_1 = 20 (layer 1 is highly predictive); w_2 = 5 (layer 2 less so).
Base b = 0.50 (typical accuracy before accounting for weights).
Prediction = 0.50 + 20*0.6 + 5*0.4 = 0.50 + 12.0 + 2.0 = 14.5 (rescale to a 0-100 accuracy scale: roughly 73% accuracy).
The point: weights in group 1 swing the prediction much more because they were learned to be more important.

The weight-space model learns different importance scores for different symmetry groups, so each group's contribution to the prediction is set by how predictive it actually is.

What can go wrong

What can go wrong

Overfitting to training tasks. If the training set of KANs is too small or not diverse enough, WS-KAN may learn spurious patterns that do not generalize to new architectures. The fix is to train on a large zoo of KANs with varied sizes and tasks.
Asymmetry in the training set. If all training KANs are heavily optimized or all are poorly trained, the weight-space model may learn that these are the only patterns it will see. Training on both well-trained and poorly-trained networks ensures the model works well across different starting conditions.
Changing KAN topology mid-training. The weight-space model learns to map graph structures to predictions. If you change the KAN structure (add layers, add skip connections), the symmetry groups change, and the model may not generalize well.
Done right. Build a large, diverse zoo of trained KANs covering many tasks, sizes, and training regimes. Then the weight-space model learns to generalize to new unseen KANs.
What a runnable demo should prove

What a runnable demo should prove

Create a simple test: (1) Train 20 small KANs on different tasks (addition, MNIST, simple classification). (2) Build your own weight-space model and WS-KAN, both trained to predict the test accuracy of these KANs. (3) Create 5 brand new KANs you did not train the weight-space model on, train them on new tasks, and measure their actual test accuracy. (4) Have both your naive model and WS-KAN predict the accuracy of these 5 new KANs. (5) Compare predictions to ground truth.

prediction_error = mean(|predicted_accuracy - actual_accuracy|) across 5 new unseen KANs

WS-KAN should have much lower prediction error than the naive model. This proves that respecting graph structure helps, because the weight-space model no longer wastes effort learning the same pattern for every permutation of the network — it learns the pattern once and applies it to all shuffles automatically.
