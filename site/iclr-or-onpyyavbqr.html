Learning on Kolmogorov–Arnold Networks via Graph Meta-Networks

To predict what a Kolmogorov-Arnold Network will do, build a graph picture of it and use a graph neural network that respects the network's hidden symmetries.

Paper explainersAll themesGraph & Geometric Learning

Kolmogorov-Arnold Networks (KANs) are a new kind of neural network that work differently from standard ones. When you want to guess what a trained KAN will do—like predicting how well it works on a new dataset—you need a weight-space model, a machine that learns from a network's internal numbers (weights). This paper shows that KANs have the same hidden structure as regular networks, and builds the first weight-space model designed specifically for them.

Zero assumption version

Why the straightforward approach fails

A weight-space model takes the weights (internal numbers) of a trained network and predicts something about it—its accuracy on a new task, or how fast it will train. The naive way to do this is to flatten all the weights into one long list and run it through a regular neural network. But this fails because it ignores the structure of the network you are studying. If you permute (rearrange) the neurons in the network without changing what it computes, the flattened weights look completely different, confusing the predictor.

Researchers recently figured out that regular neural networks have a hidden symmetry: swapping neurons in the same layer does not change what the network does. Weight-space models that respect this symmetry work much better because the prediction task becomes much simpler—the model can now recognize the same network even after neuron shuffling, instead of treating it as a brand new and unrelated one. But Kolmogorov-Arnold Networks are structurally different from regular networks—they use one-dimensional learnable functions instead of weight matrices—so no one had built a weight-space model tailored for them yet.

The challenge. Build a weight-space model for Kolmogorov-Arnold Networks that respects their unique structure and symmetries.

What the paper changes

The one thing this paper changes

Instead of flattening a KAN's weights into one long list and passing it to a regular neural network, the paper converts the KAN into a graph and runs a graph neural network (a model that reads relational structure) on it. This single change—from list-based to graph-based—is what makes the method work.

The hidden quantity

Permutation symmetry: the structure the paper measures

measured quantity  =  Whether two KANs compute the same function

Two KANs are functionally identical if one is just a reordering (permutation) of the neurons in the other—if you relabel the neurons but keep the wiring the same, the network still computes the same function. This symmetry means that the flattened weights of two identical-except-for-neuron-order KANs look completely different, causing naive weight-space models to fail.

The paper's key insight is that a graph representation automatically handles this. Because the graph only records which neuron connects to which, and what the connection does, swapping two neurons in the graph is the same as just relabeling nodes—the message-passing algorithm treats them identically. The paper proves that the graph representation is invariant (unchanged) under all neuron permutations that preserve the computation.

Why it works

Why the graph approach works

In a standard neural network, permuting neurons in the same layer does not change what the network computes—it is just a relabeling. A graph neural network is naturally invariant to such relabelings because message-passing between nodes does not depend on node order; it only depends on which nodes are connected and how.

A KAN differs from an MLP in that it uses learnable one-dimensional functions (splines) on each input-output pair instead of a weight matrix. But it has the same permutation structure: swapping two neurons in layer l does not change the function if you also swap their incoming and outgoing edges. The paper converts this structure into a graph: each neuron is a node, each spline becomes an edge with the spline's parameters (weights, knot locations) as features. A graph neural network then reads this graph by passing messages along edges. Because message-passing is order-agnostic, it respects the permutation symmetry. Meanwhile, a naive flattened approach loses the graph structure and treats any permutation as a new, unrelated network.

This design also enables the model to generalize to KANs of different widths or depths than it saw during training, because a graph neural network naturally scales to graphs of any size.

Math after the picture

The core equation

First in words:

For each edge from neuron q to neuron p in layer l, the edge features encode the spline function phi as a triple: the spline coefficients, the basis function coefficients, and the knot locations. The graph neural network updates each node's embedding by summing messages from its incoming edges, then feeds the updated embeddings to the next message-passing round.

Then the compact form:

e_p,q^l = [w_basis; p,q^l, w_spline; p,q^l, c_p,q^l] (edge feature) v_p^l <- aggregate( {message(v_q^l-1, e_p,q^l) for all incoming q} ) (node update)

Every symbol:

e_p,q^lthe edge feature: the learnable parameters of the spline from q to p in layer l
w_basis; p,q^lthe basis function coefficients (how each spline basis function contributes)
w_spline; p,q^lthe spline coefficient weights (scaling each basis)
c_p,q^lthe knot locations (where the spline control points sit on the input axis)
v_p^lthe node embedding for neuron p in layer l
aggregatesum or mean over all incoming edge messages
A tiny numeric example
Say a KAN layer has two input neurons (q=1,2) feeding to one output neuron (p=1).
Edge 1->1 encodes a spline with 3 basis functions: w_basis = [0.5, -0.3, 0.2], w_spline = [1.2, 0.8, -0.5], c = [0.0, 0.5, 1.0].
Edge 2->1 encodes: w_basis = [0.4, 0.1, 0.3], w_spline = [0.9, -0.6, 0.7], c = [0.1, 0.6, 0.9].
The graph neural network creates two edge-features: e_1,1 = [0.5, -0.3, 0.2, 1.2, 0.8, -0.5, 0.0, 0.5, 1.0] and e_1,2 = [0.4, 0.1, 0.3, 0.9, -0.6, 0.7, 0.1, 0.6, 0.9].
A message-passing layer computes: v_1^l = mean( [MLP(e_1,1), MLP(e_1,2)] ), aggregating information from both incoming edges.
If neurons 1 and 2 were swapped, the two edges would still be read and aggregated the same way, so the final embedding is unchanged—permutation invariance.

The edge features capture the spline function for each connection, and message-passing aggregates this information without regard to neuron order.

What can go wrong

What can go wrong

Deeper topologies still hard. While WS-KAN generalizes to wider KANs unseen during training, it struggles to generalize to much deeper architectures. The paper's authors note this as an open challenge.
Edge feature engineering is task-specific. The choice of which spline parameters to encode in the edge features may need tuning for different KAN variants or downstream tasks.
Scalability to very large KANs unclear. As KAN width and depth grow, the graph and message-passing computation cost rise. Performance on industrial-scale networks is not demonstrated.
Done right: respect the structure. When you design a weight-space model, always encode the architecture of the target network—not because it looks nice, but because the network's computation has a structure that permuting neurons does not change.
What a runnable demo should prove

What a runnable demo should prove

To verify that WS-KAN truly works, build a small model zoo: train 50 Kolmogorov-Arnold Networks on a simple task (e.g., MNIST classification), each with a different random seed or slightly different hyperparameters. For each network, compute its test accuracy and record its weights. Convert each KAN to a KAN-graph. Train WS-KAN on 40 of these networks to predict test accuracy from the KAN-graph. Then evaluate on the held-out 10 networks and on 5 additional KANs with wider hidden layers—never seen during training. The demo proves its value if the prediction error is low on both the held-out networks and the wider unseen architectures, confirming that the graph-based approach generalizes.

mean_absolute_error = mean(| predicted_accuracy - actual_accuracy |) on held-out KANs

The narrower the gap between predictions on seen-size KANs and wider unseen-size KANs, the more the graph approach has captured the true structure of KAN computation.
