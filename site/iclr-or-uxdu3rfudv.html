Language and Experience: Social Learning Between Humans and AI

Humans and AI agents learn faster by combining spoken advice with direct hands-on experience through shared world models.

Paper explainersAll themesAgents & Tool Use

When a human learns a new skill, they don't just watch and experiment—they ask questions and listen to advice from someone who already knows. AI systems today mostly learn from examples or rewards, ignoring the richness of natural language guidance. This paper builds a system where agents and humans share the same representation of how the world works, allowing language to act as evidence during learning.

Zero assumption version

The gap between learning from words and learning from doing

A person in a new situation learns in two ways: they try things and see what happens, and they ask advice from someone with experience. Both sources matter. But when we build AI agents, we usually give them one or the other—either they explore an environment directly and learn from rewards, or they read examples and get trained on a fixed dataset.

If you only let an agent explore blindly, it wastes time on risky mistakes. If you only feed it pre-made examples, it misses the chance to ask clarifying questions. The real puzzle: how do you make a machine that treats language advice the same way a human brain does—as real evidence about the world, not just a frozen pattern to imitate?

The method in one sentence: Use a language model to predict what kind of advice a human would give for any situation, then treat that prediction as evidence inside a Bayesian learning loop over the agent's world model.

What the paper changes

The one thing the paper changes

Instead of training an agent only on rewards or pre-made examples, the paper feeds natural language advice into the same learning machinery as direct experience. Both are treated as observations about the true state of the world.

the object it moves  =  linguistic evidence
The hidden quantity

The hidden quantity: belief state of the world model

measured quantity  =  The agent's evolving model of how the world works

Before learning, the agent has many possible theories about the rules of the game—which moves are safe, which buttons matter, where threats hide. As it explores, some theories survive and others die. This paper's key insight is that language advice also kills theories: if someone says 'avoid that corner,' you can use that to reject theories that say 'the corner is safe.'

The paper estimates this belief state by running Bayesian inference on a structured, executable world model—essentially a simulator that can be rewound and replayed. The agent updates its beliefs when either a real action reveals the world's true behavior, or when language predicts what an expert would advise in that situation.

Why it works

Why it works: fusing language into Bayesian learning

Human learning is fundamentally about filtering theories. You enter a new game, many rules could be true, and each action you take or advice you hear eliminates some possibilities and strengthens others. This paper models that process formally.

The trick is the language model. It gets trained to predict: given a situation and the advice-giver's beliefs, what guidance would they offer? Then during the agent's learning, the language model becomes a sensor—it reads the agent's internal model and says, 'if the world works this way, an expert would advise this.' The agent then compares that prediction to what a human actually says. When they match, the theory gets stronger, because a match means the model's current understanding aligns with what a knowledgeable person would predict—a sign the model is capturing real patterns. When they clash, the theory weakens, because mismatch signals the model is wrong about how the world works.

Because advice and direct experience update the same beliefs, they compound. A human tells you 'that wall hurts'—your model changes. Now when you encounter the wall, the surprise is smaller, and you learn less from that encounter because you already knew. Conversely, if you have no starting guess about whether something is true, a human's word acts as strong evidence, because the language model predicts that an honest expert would only advise you that way if it were actually true. This is why social learning speeds things up: humans compress hard-earned knowledge into words, and words can rewire a model almost as fast as repeated collisions.

Math after the picture

The equation: belief update from advice

First in words:

New belief in a theory equals old belief times how likely the observed advice is under that theory, divided by how likely the advice is overall.

Then the compact form:

P(theory | advice) = P(advice | theory) * P(theory) / P(advice)

Every symbol:

P(theory | advice)How much we believe this theory after hearing the advice
P(advice | theory)How likely an expert is to give this exact advice if this theory is true
P(theory)How much we believed the theory before the advice
P(advice)How likely this advice is overall, across all possible theories
A tiny worked example
Start: we think theory safe-left is true with probability 0.5, theory dangerous-left with probability 0.5.
An expert says 'go left is safe'.
If theory safe-left is true, an expert would definitely give this advice: P(advice | safe-left) = 1.0.
If theory dangerous-left is true, an expert would never give this advice: P(advice | dangerous-left) = 0.05.
P(safe-left | advice) = 1.0 * 0.5 / (1.0 * 0.5 + 0.05 * 0.5) = 0.5 / 0.525 ≈ 0.95.
P(dangerous-left | advice) = 0.05 * 0.5 / 0.525 ≈ 0.05.
After one sentence of advice, belief in safe-left jumped from 50% to 95%—what would take 20 crashes to learn from experience alone.

This is how words compress experience: when advice is surprising under wrong theories but expected under right ones, it reweights beliefs by a factor of 19—matching what would take many experiments to learn.

What can go wrong

What can go wrong

Misleading advice crashes the learner's model. If a human gives false advice—'that corner is always safe' when it actually has traps—the agent's belief state diverges from reality. It will make dangerous decisions based on false theories.
The language model's bias leaks into learning. If the pretrained language model is biased (e.g., it was trained on games where experts always say 'move right'), the agent inherits those biases as spurious evidence about the world.
Advice about invisible rules is wasted. If a human says 'collect the blue squares' but the world model has no way to represent colors or shapes, the agent cannot convert that advice into beliefs and simply ignores it.
Done right: human and model agree on representation. When humans and agents share the same executable world model and agree on what variables matter, advice cleanly translates into belief updates and learning accelerates.
What a runnable demo should prove

What a runnable demo should prove

Build a simple gridworld or video game where an agent learns to reach a goal. Measure how many attempts the agent needs to succeed alone versus with human advice. Show that the agent also learns to give useful advice back to new learners, and that human-to-agent teaching actually works (the human describes a strategy in words, the agent executes it).

Speedup = attempts_alone / (attempts_with_advice), should be > 2.0 for hard games

The key sign of success: an agent trained on advice learns to play games it has never seen by transferring abstract strategy hints from humans—and humans say the agent's explanations match what they would teach.
