Symmetry-Aware Bayesian Optimization via Max Kernels

When you are optimizing something with hidden symmetries, align similarities within symmetry orbits to learn faster.

Paper explainersAll themesOptimization

Bayesian Optimization is a method for finding the best setting of something when testing it is expensive (like tuning a robot's arm, or tuning wireless network antennas). When you know the objective has symmetries (for instance, a robot arm getting the same score after a 90-degree rotation as it did before), you can exploit those to reduce wasted experiments. This paper shows that the best way to do this is to measure similarity not by averaging across all symmetries, but by finding the single best alignment between two options within their symmetry orbits.

Zero assumption version

The waste in symmetric optimization

Imagine optimizing a wireless network where you want to place antennas to cover a town. Rotating the entire layout by 90 degrees gives you the same coverage. So your optimizer will test the original layout, then test a rotated version, then a mirrored version, wasting evaluations on things it should already know are equivalent.

A naive first attempt: just average over all rotated versions of each option when comparing them. But this dilutes the signal because the Bayesian Optimizer uses a similarity function (a kernel — a rule for how alike two points are) to learn which regions are promising; if a good placement scores 95 at angle 0 and 40 at angle 90, averaging gives 67.5—the same as a mediocre placement scoring 67.5 everywhere. The optimizer cannot distinguish them and wastes evaluations exploring both.

In one sentence. Instead of averaging a score across all symmetries, find the single best alignment between two options' symmetry versions.

What the paper changes

What the paper changes

The paper replaces the kernel — the function that measures similarity between two candidate solutions — with one that respects the best alignment within symmetry orbits, then projects it to obey mathematical rules.

The hidden quantity

The hidden quantity: orbit alignment quality

measured quantity  =  Best alignment within symmetry orbits

An orbit is the set of all versions of a solution you can get by applying symmetries. For two solutions, the max kernel measures their similarity by the best alignment pair between their orbits. If one antenna layout rotated 45 degrees matches another rotated 90 degrees very closely, the max kernel captures that high similarity directly.

The paper estimates this by computing the similarity between every pair of rotated versions, then taking the maximum. This keeps the signal sharp: if one placement is genuinely better for most rotations, its high scores do not get diluted by averaging.

Why it works

Why it works: signal preservation via alignment

Bayesian Optimization uses a Gaussian process to guess the shape of the objective. The kernel (similarity measure) teaches the process what closeness means. If you average similarities across all symmetries, you lose the sharp differences: a good placement that scores well under rotation 0 and poorly under rotation 90 averages to medium, indistinguishable from a mediocre placement that scores medium everywhere. The max kernel avoids this by saying: two options are as similar as their best-aligning pair. So a genuinely good placement stays sharply distinct from a mediocre one.

The catch: maximizing violates a mathematical rule called positive semidefiniteness, which the Gaussian process needs to make valid probability statements. The paper fixes this by projecting the max kernel onto the space of valid kernels using the Moore-Penrose pseudo-inverse. This is not fudging; it is finding the closest valid kernel to the max kernel. On the finite set of evaluated points, the projection preserves the max kernel exactly (no loss of information). Off that set, it smoothly interpolates. This means you get the sharp signal-preservation of max with the mathematical guarantees of a proper Gaussian process.

Math after the picture

The projected max kernel

First in words:

The kernel is computed by projecting the max-aligned kernel onto the valid mathematical space. On the points you have already evaluated, it exactly matches the max kernel. On new points, it interpolates smoothly.

Then the compact form:

k_max(x, x') = max_{g, g' in G} k_base(gx, g'x') [step 1: raw max] k_+(D)(x, x') = phi(x)^T phi(x') where phi(x) = K_+^(1/2) k_max(D, x) [step 2: projected form]

Every symbol:

x, x'two candidate solutions
g, g'symmetry operations (rotations, reflections, etc.)
k_basethe base kernel, which measures similarity directly
Gthe symmetry group (the set of all symmetries that preserve the objective)
k_maxthe max kernel: pick the best alignment
Dthe design set: all points evaluated so far
K_+the kernel matrix of the max kernel on D; the pseudo-inverse K_+^(-1) undoes it
phi(x)the feature representation; the product phi(x)^T phi(x') equals k_+(D)
k_+(D)the projected kernel: mathematically valid and sharp-signal-preserving
A tiny worked example: 1D antenna placement with mirror symmetry
Antennas at positions x=1 and x'=1 (same place): both can be mirrored at x=-1. Original positions score 0.8 agreement. Mirrored positions also score 0.8. Max alignment = 0.8.
Antennas at x=1 and x'=2 (different places): original pair scores 0.5, but when we mirror x'=2 to -2, it aligns poorly with mirrored x=-1 (score 0.2). Best pair is original: max=0.5.
Antennas at x=1 and x'=3 (far apart): no rotation helps; max=0.1. After projection to valid kernel space, the score stays roughly 0.1 (not much to project).
Because antenna problems often have many weak placements and few good ones, max kernels keep the signal sharp. Averaging would muddy all three examples toward 0.4.

The projection step ensures the Gaussian process can compute valid uncertainties, while keeping max-kernel's sharp signal on the points you have tested.

What can go wrong

What can go wrong

Symmetry group is wrong or incomplete. If you tell the optimizer that rotations are a symmetry but the true objective breaks under some rotations, the method will miss those breaks and misguide the search.
Base kernel is too weak for the objective. Max alignment works only if the base kernel (the similarity function you provide) actually captures relevant closeness in your problem. A bad base kernel makes max alignment useless.
Orbit size is exponentially large. If your symmetry group is huge (e.g., all possible permutations of 100 antenna positions), computing max over all pairs becomes prohibitively expensive.
Done right. Provide an honest symmetry group, a base kernel that fits your domain, and a manageable orbit size. Max-kernel projection will outperform averaging because it preserves sharp differences in quality across symmetries, letting the Gaussian process confidently guide the next evaluations toward good regions instead of averaging away the signal.

What a runnable demo should prove

Build a small Bayesian Optimization problem with obvious symmetry. For instance, minimize a 2D function that is invariant under 90-degree rotations (like distance from the center, or a radially symmetric gaussian). Set up three kernels: the base kernel alone, an average-over-orbits kernel, and the max-kernel-projected kernel. Run each optimizer for the same budget of evaluations (say, 50 function calls).
