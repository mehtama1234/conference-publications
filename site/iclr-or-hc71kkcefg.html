Naming to Learn: Class Incremental Learning with Unlabeled Data

When you have new images and their class names but no labels, you can extract good labels from the images themselves by looking at simplified representations and trusting the confident ones most.

Paper explainersAll themesRepresentation & Self-Supervised Learning

Real-world classifiers must learn new kinds of objects over time without forgetting old ones. Usually this requires someone to label every new image by hand. This paper tackles a more realistic case: you have the new images plus their class names, but no one has labeled which image belongs to which name. The trick is to generate and refine your own labels automatically using the images themselves, while carefully trusting some labels more than others.

Zero assumption version

Learning new classes without labeled data or forgetting old ones

Imagine you trained a model to recognize dogs and cats. Now a factory gives you 1000 images of a new animal, rabbits, but no one has marked which photo is a rabbit—you only know the class name. A naive approach: ask the already-trained model to label them (these are called pseudo labels, guesses from the old model), then train on those guesses. But the old model has never seen rabbits, so its guesses are wrong and noisy. When you train on bad labels, two disasters happen together: you learn incorrect patterns about rabbits, AND you forget what the model already knew about dogs and cats.

This is catastrophic forgetting in the unlabeled world—the model is caught between learning wrong things and losing right things, because the training signal itself is corrupted.

The method in one sentence. Shrink the images down to simpler patterns, use those patterns to pick the best pseudo labels, and weight each label by how confident you are it is correct.

The algorithm as a flow

What it actually does

Guess initial labels

Old model assigns each new image to a class name.

Simplify the images

Strip image features down to core patterns only, cutting out noise.

Refine the guesses

Train a classifier on the simplified features, use it to re-label images.

Weight by confidence

Give more influence to labels the classifier is sure about, less to uncertain ones.

Train the full model

Learn from weighted labels using squared-error loss; this pushes the model to match the good labels.

What the paper changes

The one thing the paper changes

The paper changes how much you trust each pseudo label—which is just a number between zero and one deciding the weight of that training example. For confident guesses, the weight stays high. For uncertain guesses, the weight drops, so wrong labels hurt you less.

the object it moves  =  pseudo-label weights
The hidden quantity

Pseudo-label confidence: which labels to trust

measured quantity  =  pseudo-label confidence score

The hidden quantity is a number for each image measuring how sure the simplified classifier is that its label guess is correct. A confidence score close to one means the classifier is very sure; close to zero means it is confused and guessing.

The paper estimates this by training a classifier on the reduced features and looking at the size of its output for the winning class. A big output means high confidence; a small output means the classifier thinks many classes are possible.

Why it works

Why reducing features and weighting labels stops forgetting

Simplifying the images by compressing features down to only essential patterns works because it throws away noise and outliers that mislead the classifier. The old model's confusion comes from irrelevant details like lighting and pose variations that have nothing to do with what animal it is. When you strip those away, the classifier sees only the real shape of each rabbit, so its guesses become more reliable—because the difference between a real rabbit and a dog is now stark and impossible to miss, so the classifier outputs a clear, high-confidence answer. The model then trains on signals that are closer to truth, not corrupted.

Weighted labels prevent forgetting because the model learns by trying to match labels, and if a label is wrong, training will pull the model away from correct knowledge. By downweighting uncertain labels, you reduce how much a bad guess can drag you backward—the confident labels pull the model forward toward the new class, while the uncertain ones whisper instead of shout. More importantly, downweighting a label that might be wrong about rabbits also means you are not overwriting your knowledge about dogs and cats, since the training force is gentler.

Math after the picture

The squared-error loss with confidence weights

First in words:

For each image i, the penalty is the confidence score times the squared gap between the model's answer and the refined label, summed over all images.

Then the compact form:

Loss = sum_i c_i * (y_pred_i - y_refined_i)^2

Every symbol:

Losstotal penalty across all images
sum_iadd up the penalties for each image
c_iconfidence score for image i (between 0 and 1)
y_pred_ithe model's numeric answer for image i
y_refined_ithe refined label for image i (a number representing the correct class)
(y_pred_i - y_refined_i)^2the squared gap—small if the model is right, large if wrong
A tiny worked example
Image 1: confidence 0.9, model predicts 2.1, true label 2.0 -> penalty = 0.9 * (2.1 - 2.0)^2 = 0.9 * 0.01 = 0.009
Image 2: confidence 0.2, model predicts 1.5, true label 2.0 -> penalty = 0.2 * (1.5 - 2.0)^2 = 0.2 * 0.25 = 0.05
Image 1 contributes a tiny penalty because the model is already right and we trust the label. Image 2 is wrong but we mistrust the label, so it contributes only a small penalty. Without confidence weighting, Image 2 would contribute 0.25, eighteen times more damage.

When a label is trustworthy and correct, the confidence weight lets the model learn strongly. When a label is trustworthy but wrong, that mistake still gets downweighted by the earlier refinement step.

What can go wrong

What can go wrong

Initial model is too wrong. If the old model has never seen anything remotely like the new class, even its reduced features might not distinguish the new class from old ones. The confidence scores become meaningless.
Dimensionality reduction throws out important signals. If you compress features too aggressively, you lose patterns that would let you separate the new class from old ones. The refined labels become inaccurate, and confidence weighting cannot save bad labels.
Class imbalance in pseudo labels. If the initial model guesses that most new images belong to one class, the refined labels inherit that imbalance. Even with confidence weighting, the model might learn a biased classifier.
Done right: use appropriate dimensionality, start from a strong pretrained model, and apply inter-class balance adjustment. The paper includes inter-class adjustment to reweight classes that appear too often or too rarely, solving the imbalance problem and allowing the method to work.
What a runnable demo should prove

What a runnable demo should prove

Build a small experiment: take a pretrained vision model, freeze it, and train on a standard dataset split into two tasks. Task 1 has labeled images of dogs and cats. Task 2 has unlabeled rabbit images plus the class name rabbit. Measure the classifier accuracy on old classes and new classes after learning Task 2.

Forgetting = (old class accuracy before task 2) - (old class accuracy after task 2)

The demo must show that with confidence-weighted pseudo labels, forgetting stays small (under 10 percent) while the new class accuracy reaches 75 percent or higher. Without weighting, forgetting should exceed 20 percent.
