Bures Generalized Category Discovery

Restore collapsed feature spaces instead of compressing them further to unlock open-world discovery.

Paper explainersAll themesRepresentation & Self-Supervised Learning

When a model learns from unlabeled images that mix known and unknown objects, it builds a feature space (a list of numbers for each image). Standard methods squeeze this space so tightly that different classes start piling on top of each other, making discovery impossible. This paper takes the opposite path: it restores the space to a healthy spread, where each group has its own breathing room. The fix is a few lines of code and works on any existing model.

Zero assumption version

Feature space collapse strangles discovery

When you want a model to find both familiar categories and brand-new ones in the same batch, you face a hard puzzle. A naive first attempt: force everything to cluster tightly, so the model learns to pack images with the same label close together. This works for known classes because the training signal is explicit—the labels tell the model which images go together, so tight clusters form easily. But on unknown classes, this method backfires completely. If you crush the feature space inward, you distort it like a crumpled piece of paper. Directions that should be independent get tangled. The spectrum of variations flattens. Unknown classes have nowhere to spread out; they land where known classes already are, completely indistinguishable. Why it fails: tight clustering reduces the number of independent directions available for the model to work with, so unknown classes cannot express their identity—they end up overlapping with known ones because there simply are not enough working directions to hold them apart.

The deeper issue: the model's internal numbers form a cloud. If that cloud has a lumpy, uneven shape—some directions with lots of spread, others pinched—clustering cannot fix it. You are forcing the model to build answers on top of an unbalanced foundation, like trying to find true north on a warped map. The more you compress, the more you destroy the underlying structure you actually need.

In one sentence. Conventional methods over-compress feature spaces until different classes become indistinguishable, blocking discovery of new ones.

The algorithm as a flow

What it actually does

Measure the spread

Look at the correlation matrix of tokens within each class (how the numbers for one group relate to each other).

Check against ideal

Compare the real correlations to an isotropic target (all directions equally spread, no preferred axis).

Quantify the gap

Compute Bures distance: the true distance between two correlation matrices.

Nudge toward ideal

Maximize the nuclear norm (sum of singular values), a practical surrogate that pushes spread without changing the model.

Unlock discovery

With balanced spread, class boundaries become sharp; unknown classes crystallize into their own regions.

What the paper changes

What the paper changes

The paper modifies the class-token covariance matrix: the mathematical object that captures how feature-numbers vary together within a class. Instead of compressing it, the method stretches it toward uniform spread across all directions.

the object it moves  =  class-token covariance structure
The hidden quantity

Isotropy: even spread in all directions

measured quantity  =  Isotropic spread in feature space

Isotropy means the same in all directions. An isotropic cloud of points looks round from every angle. In a feature space, isotropy is the health condition: each direction (each number in the list) has equal authority to distinguish classes. The paper measures this by looking at the von Neumann entropy of the correlation matrix (a number that measures how uniformly the variation is distributed across directions) and the eigenspectrum (which directions carry signal and which are flattened). A healthy eigenspectrum has many similar-sized peaks, with no one direction dominating and no flattened wastelands.

The paper estimates isotropy by comparing the actual covariance matrix of class tokens to an ideal isotropic one. The Bures distance is the true gap between them—not just a loose approximation, but a proper geometric measure that respects the natural shapes of these matrices.

Why it works

Why restoring balance unlocks discovery

Here is the chain. If the feature space is lumpy and collapsed, the decision boundaries between known classes are carved into an uneven, tilted space. An unknown class landing in this space immediately falls into a known class's cluster, because there is nowhere else for it to go. The directions that should separate it are flattened and carry no information.

When isotropy is restored, the space becomes balanced. All directions now carry roughly equal strength. Unknown classes can occupy genuinely different regions because there are enough working directions for them to occupy. The eigenspectrum becomes uniform, meaning no direction is wasted. This is why the paper says isotropy raises von Neumann entropy: entropy measures how spread-out and useful the variation is. Higher entropy means more real information available to distinguish classes. A direct consequence: cluster boundaries become sharper because all directions contribute equally to the answer.

The method maximizes the nuclear norm of stacked class tokens, a practical surrogate. Nuclear norm is the sum of singular values (the strengths of the independent directions in the data). Maximizing it favors configurations where all directions matter equally, which is exactly what isotropy requires, because if all directions are equal in strength, the sum of their strengths is maximized. The proof is that this surrogate is equivalent to the true Bures-distance minimization under a mild trace constraint (a constraint that keeps the overall scale reasonable).

Math after the picture

The equation: nuclear norm maximization as isotropy

First in words:

Maximize the sum of singular values of the stacked class-token matrix, under the constraint that the trace stays bounded.

Then the compact form:

max sum_i sigma_i(C) s.t. trace(C) <= tau

Every symbol:

sigma_i(C)the i-th singular value (strength of the i-th independent direction) in the covariance matrix C
sum_iadd up all the singular values
trace(C)the sum of diagonal entries, proportional to total variance
taua fixed bound on total variance (keeps scale in check)
Toy example: three directions in feature space
Lumpy space: singular values are [8.0, 4.0, 0.2]. Nuclear norm = 8.0 + 4.0 + 0.2 = 12.2. The first direction dominates (80% of all spread). Trace = 8 + 4 + 0.2 = 12.2, at our limit tau=12.
After isotropy: singular values become [4.5, 4.2, 4.1]. Nuclear norm = 4.5 + 4.2 + 4.1 = 12.8 (increased). Trace = 4.5 + 4.2 + 4.1 = 12.8, still within a slightly raised tau=13.
Mechanism: the nuclear norm went UP (12.2 to 12.8) because we redistributed the singular values. Now all three directions are nearly equal (each about 33% of spread), not one hogging 65%. That uniform spread across directions is isotropy. Maximizing nuclear norm under trace constraint naturally balances all directions to be equally strong.

The nuclear norm, bounded by trace, naturally pushes toward uniform singular values—which is exactly the balanced directions we need.

What can go wrong

What can go wrong

Trace constraint set too high. If tau is too loose, the method can push variance to extreme scales, defeating the goal. The trace must be carefully chosen to match the model's natural scale.
Only a few known classes in the batch. Covariance estimation needs enough tokens per class. Tiny batches with one or two examples per class give noisy, unreliable covariance matrices. Isotropy cannot fix poor input statistics.
Unknown classes at wildly different complexities. If unknown classes have intrinsically different variance (one is visually simple, another intricate), forcing uniform isotropy can flatten the simpler class. The method works best when classes are roughly equally complex.
Done right. With batch sizes over 30, well-chosen trace bounds, and similar complexity across classes, isotropy reliably boosts both known-class clustering and unknown-class emergence, because balanced directions give all classes equal footing to express their identity.
What a runnable demo should prove

What a runnable demo should prove

Take a standard image model (pretrained or not) and a benchmark like CIFAR-10 (split to known classes 0–4, unknown classes 5–9). Run the model without the isotropy fix and measure: how accurately does it cluster known classes, and how well does it separate unknown classes? Then apply the nuclear-norm maximization fix on the class-token covariance, and re-measure. The demo should show cluster purity (known classes stay tight) and unknown class separability (classes 5–9 do not land inside 0–4's clusters) both improving. A secondary win: feed the method a procedure to estimate class count (e.g., gap in sorted distances). The isotropy fix should make that estimate much more reliable because when all directions are equally balanced, they all vote equally for the true count, drowning out noise.

improvement = (unknown_separability_after - unknown_separability_before) + (class_count_error_before - class_count_error_after)

The demo proves that isotropy is not magic; it is simply making the space honest and balanced so that unknown classes have real room to exist.
