Active Exploring like a Pigeon: Reinforcing Spatial Reasoning via Agentic Vision-Language Models

The paper gives a vision-language agent a running map of objects and a checkable list of spatial claims so it can explore, test its own guesses, and learn from dense step-by-step feedback.

Paper explainersAll themesAgents & Tool Use

A vision-language agent often fails on spatial tasks because a single image does not tell it how objects relate after the camera moves. The usual setup asks the agent to answer from snapshots, so it forgets what it saw earlier and cannot check whether an intermediate guess about left, right, front, or rotation is even consistent. This paper makes the agent act, keep a scene map, and score intermediate spatial claims, because dense local feedback teaches the agent which moves improve the map and which moves break it.

Zero assumption version

Spatial reasoning fails when the agent cannot preserve scene structure

A spatial question such as 'is the mug behind the bowl after I turn right?' needs more than object names. The agent must keep track of where each object sits, how the camera moved, and which spatial relation should stay true after the move. If it only reads one frame at a time, it loses that structure.

Sparse task rewards make this worse. If the only signal comes at the final answer, the agent does not learn which exploration step improved the map and which step made the map worse. It sees success or failure too late, so learning is slow and unstable.

In one sentence. The agent needs a persistent scene map and step-level checks, because final-answer rewards alone do not teach careful spatial reasoning.

The algorithm as a flow

What it actually does

Observe the current scene

Detect objects and their rough positions and directions from the current view.

Write the update into a running map

Merge the new observation with earlier ones so the agent keeps one persistent scene description.

Generate checkable spatial claims

Turn relations such as left of, behind, facing, or rotated into small executable checks.

Score the current move

Reward moves that make the running map support more correct claims, because those moves improve spatial consistency.

Learn the exploration policy

Use those dense scores to train which viewpoints and action choices help answer the final question, because moves that raise check scores usually add the evidence needed for the final decision.

What the paper changes

What the paper changes

The paper changes the agent's internal state from a short-lived caption stream into a persistent scene map plus a bank of executable spatial checks. That change matters because the agent can now compare candidate moves by how much they improve the map, not only by whether the final answer happens to be right.

the object it moves  =  persistent scene map with executable spatial checks
The hidden quantity

The hidden quantity: map consistency

measured quantity  =  map consistency

Map consistency is the degree to which the running scene map agrees with all views collected so far and with the checked spatial claims. If the map says the chair is behind the table but a later view and the claim checker disagree, consistency drops.

This quantity is useful because it turns a vague spatial skill into a trainable signal. The agent does better when it explores views that reduce contradictions, because a more consistent map makes the final answer easier to read off.

Why it works

Why the map-and-check setup works

Spatial reasoning fails from a single frozen view because many relations are hidden by viewpoint. A move that reveals the side of an object or clears an occlusion is useful only if the agent remembers what it saw before. The persistent map fixes that, because each new observation updates one shared scene state instead of replacing the old one.

The spatial checks matter because they convert 'better understanding' into something the learner can score. If a move makes more claims verifiable, the agent gets reward by improving the evidence for left-right, front-back, and orientation relations. That is more informative than waiting for the final answer, because the learner sees which local choices created a cleaner map.

The two parts help each other because the map gives the checker a place to test claims across time, and the checks tell the learner which map updates are useful. Because of that loop, exploration becomes targeted: the agent seeks views that reduce contradiction and uncertainty instead of wandering through the scene.

Math after the picture

The equation for dense spatial reward

First in words:

Total reward combines final task success with the summed scores of intermediate spatial checks, so the agent is paid for map-improving moves before the episode ends.

Then the compact form:

total_reward = final_answer_reward + check_weight * sum_t assertion_score_t

Every symbol:

final_answer_rewardreward for getting the final spatial question right
check_weighthow strongly the learner values intermediate spatial checks
assertion_score_tscore at step t for how many checked spatial claims agree with the current map
total_rewardthe signal used to train the exploration policy
A tiny worked example
Step 1: the agent turns left, sees only part of the scene, and 1 checked claim holds. Intermediate score: 1.
Step 2: the agent moves closer, reveals the hidden object, and 3 checked claims hold. Intermediate score: 3.
Step 3: the agent turns again and introduces a contradictory pose estimate, so only 2 claims hold. Intermediate score: 2.
If the final answer is correct, final reward is 10 and the three check scores sum to 6.
With check weight 2, total reward is 10 + 2 * 6 = 22.
A path with the same final answer but weaker intermediate checks gets less reward, so training prefers moves that build a cleaner map.

Dense checks speed learning because the agent can tell which earlier move improved spatial understanding instead of waiting until the end.

What can go wrong

What can go wrong

Bad object grounding. If the vision system misreads object location or facing direction, the running map starts from the wrong state, so later checks reinforce a bad picture instead of a good one.
Weak spatial checks. If the executable checks are too shallow, the agent can game them without truly improving the scene map, because it only needs to satisfy easy local conditions.
Limited exploration budget. If the agent is allowed too few moves, it may never reach the views that resolve occlusion, so the map stays uncertain even with a good learning signal.
Done right. The method works best when object grounding is stable, the checked relations match the target task, and the agent is allowed enough movement to gather the missing evidence.
What a runnable demo should prove

What a runnable demo should prove

Build a small grid-world room with a few objects, object directions, and partial views. Ask questions such as 'after turning right, is the lamp behind the chair?' Let the agent choose camera moves, keep a running object map, and score small relation checks after each move.

Compare three setups: final-answer reward only, running map without checked relations, and running map plus checked relations. The last setup should learn faster because each useful view earns credit before the episode ends, and it should answer more spatial questions correctly because the shared map preserves evidence across moves.

answer_accuracy = correct_answers / total_questions and map_consistency_rate = verified_relation_checks / total_relation_checks

The demo should show that active exploration helps only when the agent can store what it found and score whether the new evidence made the spatial picture more coherent, because movement without memory and checks does not accumulate usable spatial evidence.
