Generating language and text

Papers on using diffusion and generative approaches to create text, including language models, speech synthesis, and music generation.

What this is

Most generative models today use autoregressive methods for text: predict the next word, given all previous words, then repeat (like autocomplete on your phone, but more complex). Diffusion models—the 'noisy to clear' approach that dominates image generation—are less common for text, but researchers are exploring them. The question is: can we generate text using the same mathematics as images? And if we do, does it have advantages or disadvantages compared to standard methods?

One reason this is interesting is that diffusion models work differently from autoregressive ones. Autoregressive models commit to each word in sequence—once they predict 'the,' that word is fixed and influences everything that follows, so if you choose wrong early, you can't recover. Diffusion models work in parallel across all positions: they gradually refine the entire sentence at once, like sculpting stone by removing material everywhere simultaneously. This could potentially allow the model to revise earlier words if later context suggests something different (rather than getting trapped by an early wrong choice), which might lead to better outputs. It might also allow different decoding strategies—instead of being locked into 'always pick the highest-probability next word,' you could search through multiple possibilities because you're not committing irrevocably at each step.

Papers here explore whether diffusion works for language at all (since most text uses autoregressive methods, diffusion is a natural next experiment), whether it's competitive with autoregressive methods, and whether the different generation process enables new capabilities (like better revision or more diverse outputs). The research is still early—text diffusion does not yet beat standard methods for most tasks—but the work here is mapping out what is possible. Some papers apply image-generation techniques (like flow matching) to text, which is interesting because it might give text generation new properties image generation enjoys (like multi-scale refinement or better diversity). Others use diffusion for specific text tasks like paraphrase (rewriting sentences differently) where having a different generation process might help because you can revise multiple parts of a sentence in parallel rather than being forced into a linear left-to-right path. And some work on combined problems: generating both image and text descriptions together, which requires bridging the gap between two very different types of data.

How the work breaks down

Generating text and language with diffusion and non-autoregressive methods splits into three directions: directly applying diffusion to text to see if it can match or beat the standard left-to-right approach, accelerating text generation by predicting multiple words at once instead of one at a time, and extending the same generative approach to related sequential data like music and structured symbols.

Diffusion for text generation

Standard text generation works left-to-right: predict the first word, then the second given the first, then the third given the first two, and so on (autoregressive). This commit-to-each-word-in-order approach can trap you: if you pick the wrong word early, all later words depend on that mistake. Diffusion models work differently — they start with noise everywhere and gradually refine all positions in parallel. Researchers are exploring whether this parallel refinement approach helps text, because it could allow the model to revise earlier words if later context suggests something different.

Logit-KL Flow Matching (a method that scores predictions while mixing sampling) takes a diffusion-like approach to text: it predicts words at all positions simultaneously but uses smart hybrid strategies (combining probabilistic sampling with model guidance) to decide which positions to lock in and which to keep refining. On text and code infilling tasks (filling in missing pieces), it beats non-autoregressive baselines in both perplexity (a measure of prediction quality) and downstream metrics (how well the generated text works for actual tasks). FS-DFM (fast text generation with few-step diffusion) takes the same idea of parallel refinement and makes it extremely fast: it generates 1024 tokens (a long passage) in just 8 sampling steps while matching the perplexity of autoregressive models that take 1024 steps. The speedup is 128 times faster, which means a model can produce long text at practical speeds.

Both papers show that diffusion-style parallel refinement can work for text and can be competitive with or faster than standard autoregressive methods, which means the parallel approach is a viable alternative strategy. They differ in their technique: Logit-KL uses a hybrid sampling strategy to navigate the discrete problem of picking words, while FS-DFM focuses on making the diffusion process run in fewer steps. Together they demonstrate that the 'refine everything at once' idea isn't just a curiosity — it's a real alternative to committing to each word in sequence, because both papers deliver competitive results and even speed advantages.

Tokenization as the bridge to generative models

Whether you're using autoregressive generation, diffusion, or any other generative approach, you first need to convert text or images into a sequence of tokens (discrete symbols the model can work with). This tokenization step is hard: if your tokens are too fine-grained, the sequence becomes impossibly long; if they're too coarse, you lose important details. Generative models are only as good as the tokens they inherit, which means that a poor token choice limits generation quality no matter how good the rest of the model is, so improvements in tokenization directly improve generation quality across the board.

Latent Denoising Makes Good Tokenizers (“Latent Denoising Makes Good Tokenizers”) improves tokenization by using a denoising approach within the tokenizer itself — it applies diffusion ideas inside the encoding step to create cleaner, more useful tokens. This technique boosts generation quality on six different generative models on standard benchmarks, which means the cleaner tokens work across many architectures. MUSE (“MUSE: Resolving Manifold Misalignment in Visual”) tackles a fundamental tradeoff: better tokens usually mean you lose the ability to reconstruct the original image perfectly, but better reconstruction usually means less abstraction for generation. MUSE breaks this tradeoff by aligning the token space using topological structure (organizing where tokens live in space to preserve relationships), so it achieves both the best-published image generation quality and better feature learning than its teacher model. Concept-Guided Tokenization (“Concept-Guided Tokenization: Closing the Gap Between”) bridges another gap — the difference between reconstructing the original image (rFID score) and generating new images (gFID score). By making tokenization concept-aware, it achieves strong numbers on both reconstruction and generation, plus text-to-image generation, which means tokens that capture concepts work for all three tasks. Hyperspherical Latents (“Hyperspherical Latents Improve Continuous-Token Autoregressive Generation”) improves continuous-token models (which predict real-valued numbers instead of discrete symbols) by organizing the latent space on a sphere rather than in flat space — the sphere structure naturally constrains token magnitudes and prevents the tokens from collapsing into fewer distinct points; this gives it sharper generation and even beats much larger models at smaller scales. WeTok (“WeTok: Powerful Discrete Tokenization for High-Fidelity”) achieves record-low reconstruction error and compresses images 768 times while keeping fine details, showing how far a well-designed tokenizer can go and demonstrating that tokenizer design is a bottleneck worth focusing on.

These papers all recognize that generative models are bottlenecked by the quality of their tokens. Each takes a different angle — denoising, topological alignment, concepts, sphere-space organization, or advanced compression — but all show that investing in tokenization pays dividends for every generative approach that comes after it.

Improving autoregressive generation

Autoregressive generation (predicting one token at a time, left-to-right) is the standard for language models and also works well for images, but it's not the end point: even autoregressive models have room for improvement through four directions that make them faster, more consistent, more searchable, or higher-quality. You can make them faster by predicting multiple steps at once without training on drafts, better by constraining the learning process to make predictions more consistent across the sequence, smarter by ordering tokens in a way that helps test-time search, or higher-quality by using guidance from coarser predictions.

Speculative Coupled Decoding (“Speculative Coupled Decoding for Training-Free Lossless”) accelerates image and video generation up to 4.2 times for images and 13.6 times for video without losing quality and without needing to train a separate draft model — it works by using a coupled pair of decoders that predict ahead speculatively and verify in parallel, so you get multi-step speedup without draft training overhead. reAR (“reAR: Rethinking Visual Autoregressive Models via”) improves the core training of autoregressive visual models by constraining token-by-token consistency — making sure predictions stay consistent across the sequence. This simple training fix cuts the ImageNet generation error (gFID) from 3.02 to 1.86, which means consistency matters, and with better tokenizers reaches 1.42, matching much larger diffusion models while using only 177 million model weights (the internal numbers the model learns), demonstrating that training discipline can match bigger models. Ordered Tokens (“(1D) Ordered Tokens Enable Efficient Test-Time”) reorganizes the sequence strategically: instead of a random order, it uses coarse-to-fine ordering (predict the rough outline first, then fine details). This enables pure search at test time without training a new model — you can explore multiple decoding paths because the order creates natural checkpoints, which means the token order itself is a parameter that affects search efficiency. Scaled Spatial Guidance (“SSG: Scaled Spatial Guidance for Multi-Scale”) works on the Visual AutoRegressive (VAR) models which predict in multi-scale order and improves them using guidance from coarser versions, because guidance from the coarse prediction helps refine the fine details; this boosts both image quality and diversity without slowing down generation.

These papers take autoregressive generation, which is known and reliable, and show how to make it faster, more consistent, more searchable, or higher-quality without changing the fundamental left-to-right structure, which means you don't need to replace autoregressive models — you can improve them strategically. The improvements compound: better training (reAR) reduces error by constraining consistency, better decoding (Speculative) adds speedup through speculation, better token ordering (Ordered Tokens) enables search through coarse-to-fine structure, or better guidance (Scaled Spatial) refines predictions through multi-scale context; each unlocks something new from the same core approach.

Sequential generation beyond text: music and structured sequences

Text generation receives the most focus, but the same generative techniques apply to other sequential data with similar properties: music (a sequence of notes and sounds), garments (a sequence of sewing instructions), or 3D structures (a sequence of mesh operations). These domains have their own challenges: music must maintain rhythm and harmony, garments must be buildable, 3D meshes must be topologically sound. Generative models must learn these domain-specific constraints alongside the general skill of predicting sequences.

BEAT (“BEAT: Tokenizing and Generating Symbolic Music”) tokenizes music symbolically using uniform time steps rather than event-based tokens, improving how well the model captures long-range patterns in music continuation and accompaniment because uniform timesteps make timing relationships explicit. The uniform timestep approach makes it easier to learn timing relationships because every note happens at a regular grid, not at arbitrary times, so the model sees time as a consistent dimension. SyncTrack (“SyncTrack: Rhythmic Stability and Synchronization in”) tackles a key problem in multi-track music generation: keeping different instruments in rhythm and synchronized with each other. By tracking rhythmic consistency across tracks, it improves multi-track quality by a large margin, measured by new metrics for inter-instrument rhythmic sync and beat consistency, which means explicit sync tracking helps the model maintain coherence. YuE (“YuE: Scaling Open Foundation Models for”) scales autoregressive generation to generate up to five minutes of music using trillions of tokens — matching or exceeding proprietary systems in musicality and vocal quality as of early 2025. This shows that the same left-to-right autoregressive approach that works for text can scale to very long-form music if done carefully and at the right scale.

Music generation differs from text in that humans perceive rhythm, harmony, and alignment across instruments immediately — a single out-of-sync note ruins the whole piece. These papers show that domain-specific tokenization (uniform steps for music), explicit constraint tracking (sync metrics), and aggressive scaling (five minutes of music) all help autoregressive generation work well beyond text, which means autoregressive generation succeeds in other domains when you align the tokenization and metrics to the domain's structure.

Speeding up and shrinking generative models

Once you have a trained generative model, the bottleneck often shifts to inference: generating the output takes a long time because you must do many sequential steps (in autoregressive) or many refinement steps (in diffusion). Faster decoding means the model becomes practical for real-time or interactive use, because latency is often the constraint that prevents deployment. Several techniques help achieve this, because they target different parts of the inference problem: using more efficient token representations shrinks the sequence so there's less to predict, predicting multiple tokens per step directly parallelizes work to avoid step-by-step latency, and using a smaller model that's almost as good but runs faster trades accuracy slightly for speed.

Data Provenance for Image Auto-Regressive Generation (“Data Provenance for Image Auto-Regressive Generation”) addresses a detection problem: how can you tell if an image was generated by an autoregressive model without watermarks? It works by exploiting patterns that autoregressive models leave in the image — the sequential generation order creates telltale correlations. This is a form of compression-aware detection: autoregressive models generate pixels or tokens in a specific order, and that order leaves statistical fingerprints. Autoregressive Image Generation with Masked Bit Modeling (“Autoregressive Image Generation with Masked Bit”) accelerates autoregressive image generation by using binary (bit-level) tokens instead of higher-level representations. Binary tokens are much more efficient to compress and faster to predict, and it achieves the best-published ImageNet quality (gFID 0.99) while reducing sampling cost. Visual Implicit Autoregressive Modeling (“Visual Implicit Autoregressive Modeling”) compresses autoregressive visual models by using implicit representations that are learned in a lower-dimensional space, reducing parameters by 38% and peak memory from 19GB to 8.5GB while maintaining quality (FID 2.16). This means you can run the same quality model on consumer hardware.

The three approaches work at different levels: detection via statistical analysis (“Data Provenance for Image Auto-Regressive Generation”), token efficiency via bit-level discretization (“Autoregressive Image Generation with Masked Bit”), and model compression via implicit spaces (“Visual Implicit Autoregressive Modeling”). All three show that there's efficiency left on the table in autoregressive generation — whether you're trying to detect it, speed it up, or fit it into memory.
