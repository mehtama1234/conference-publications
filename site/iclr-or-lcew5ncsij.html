Schrödinger Eigenfunction Method for Long-Horizon Stochastic Optimal Control

By learning the eigenfunctions of a quantum-like operator, you can plan optimal actions far into the future without the memory and time blowup that plagues normal long-horizon control methods.

Paper explainersAll themesRobotics & Control

Planning optimal actions over many time steps — like steering a robot arm toward a distant target — normally requires computer memory and time that grows with the length of the plan. This paper shows that when the forces acting on the system have a special structure (they point downhill from a peak, the way gravity pulls toward a valley), you can recast the planning problem as finding the natural vibration patterns of an operator from quantum mechanics. Learning those patterns with a neural network, using a corrected training objective, gives you control that stays accurate even for plans hundreds of steps into the future.

Zero assumption version

Long-horizon control explodes in memory and time

In random optimal control, you choose actions over time to minimize cost (or maximize reward) while the world has randomness in it. For instance, a robot planning 100 steps into the future needs to answer: if I do action now, will the state move closer to my goal after 100 steps? To compute this, normal methods simulate forward 100 times or build a tree of outcomes, both of which take memory and computation that grow with the horizon (the number of steps). At horizon 500, you are moving colossal amounts of data.

A beginner might try to just run the standard control algorithm — like dynamic programming or value iteration — but the algorithm slows down by a factor equal to the horizon each time you lengthen the plan. Worse, the quality of the answer deteriorates exponentially: errors in early decisions compound over time, and random fluctuations grow louder the further out you plan.

The core problem. Long-horizon random optimal control requires memory and time that scale with horizon T, and planning accuracy decays exponentially as T grows.

Detect the special structure

Recast as a PDE

What the paper changes

The single thing that changes

The paper changes the loss function used when training a neural network to learn the eigenfunctions (natural vibrations of the Schrödinger operator). Existing loss functions — whether physics-informed or variational — accidentally reweight the optimization in a way that biases you away from learning the dominant eigenfunction cleanly. The paper proposes a new 'relative loss' that strips away that hidden reweighting.

The hidden quantity

The hidden quantity: implicit reweighting bias

measured quantity  =  The unintended reweighting hidden in the loss

When you train a neural network to find an eigenfunction (a special function where applying the operator just scales it by a single number), you need a loss function — a measure of how wrong are you — to guide training. A natural choice is to make the loss small when applying the operator gives a result close to scaling the function. But this loss happens to implicitly reweight each point in space by the value of the function squared, biasing the optimization toward learning a warped version of the function instead of the true one.

The paper measures and names this bias: it is the stationary distribution of the uncontrolled system (where probability accumulates under the random walk). Existing variational and physics-informed neural network (PINN) losses all suffer from this reweighting. The relative loss removes it by dividing the operator result by the function value before comparing to the scaling number, eliminating the squared-function weighting entirely.

Why it works

Why this method works: connecting quantum operators to control

The magic starts with a mathematical fact: when the uncontrolled system (no action taken) has forces that point downhill from a peak, the Hamilton-Jacobi-Bellman equation — which is normally a complex nonlinear partial differential equation that encodes optimal control — becomes a simpler linear equation. That equation is governed by an operator, and under the gradient drift assumption, the operator has a discrete spectrum (like the energy levels of a quantum harmonic oscillator).

The eigenfunctions and eigenvalues of this operator encode the long-horizon control structure: the dominant eigenfunction gives you the control action, and because it is an eigenfunction, applying the operator just scales it by a single number — the solution does not change shape over time, only its overall magnitude. This is why you can compute optimal control far into the future without simulating: the eigenfunction structure is stable. No need to recompute or resimulate at each step; the eigenfunction works for all time.

However, learning this eigenfunction from data is tricky. The existing losses accidentally measure error in a weighted norm that favors high-probability regions (where the uncontrolled system naturally goes). That bias pulls the learned eigenfunction toward the wrong shape. The relative loss switches the measuring rod: instead of measuring the error in the natural weighted norm, it measures the error after dividing the operator result by the function value, in an unbiased norm, removing the hidden reweighting. With the correct loss, the neural network converges to the true eigenfunction.

Math after the picture

The equation: Schrödinger eigenvalue problem

First in words:

The relative loss for learning an eigenfunction: sum over all sample points of (operator applied to learned eigenfunction, divided by the learned eigenfunction, minus the learned eigenvalue) squared, plus a regularization term.

Then the compact form:

R_Rel(phi) = sum_i || (L phi_i / phi_i) - lambda ||^2 + alpha * R_reg(phi)

Every symbol:

Lthe operator (like a quantum Schrödinger operator for this system)
phithe learned eigenfunction (a neural network outputs this)
phi_ithe eigenfunction evaluated at sample point i
lambdathe learned eigenvalue (a number, trainable parameter)
L phi_i / phi_ithe operator applied and then scaled down by the eigenfunction value
alphathe weight controlling how much regularization to apply
R_rega regularization term (keeps the network from blowing up)
A tiny worked example
Suppose at point x=3: the true eigenfunction is phi(3)=2.0, eigenvalue is lambda=5.0.
The operator L phi(3) should equal 5.0 * 2.0 = 10.0 (by definition of eigenfunction).
With the relative loss: (L phi / phi) - lambda = (10.0 / 2.0) - 5.0 = 5.0 - 5.0 = 0. Error is 0.
If the network guesses phi(3)=1.9 instead: (L phi / phi) - lambda = (9.75 / 1.9) - 5.0 ≈ 5.13 - 5.0 = 0.13. Small error, guides correction.
Old loss would have measured ||L phi - lambda*phi||^2_weighted, which is biased by how often the system visits x=3. Relative loss treats all sample points fairly.

The relative loss eliminates the unintended weighting by dividing the operator result by the function value before comparing to the scaling number, making the learning problem unbiased.

What can go wrong

What can go wrong

Gradient drift assumption fails. If the uncontrolled forces do not point downhill from a potential (e.g., they swirl or have curl), the Schrödinger operator equivalence breaks down. The method does not apply to general nonlinear dynamics.
Neural network does not converge. Learning an eigenfunction is harder than supervised learning. If the network is too small, the regularizer (a term that keeps the network weights from blowing up) too strong, or the relative loss still has numerical issues at the edges of the state space, convergence can stall.
Terminal cost not captured. The dominant eigenfunction encodes the infinite-horizon cost. If the goal is a finite-horizon terminal cost (cost only at step T, zero elsewhere), a correction near the end is needed; ignoring this leaves the final actions suboptimal.
Done right. Combine the learned dominant eigenfunction with a second neural network that optimizes the terminal part (the last few steps). This hybrid approach combines the strengths: infinite-horizon structure from eigenfunction, finite-horizon flexibility from short-horizon optimization.

What a runnable demo should prove

Use a potential well as the uncontrolled drift (e.g., gravity pulling toward a target region). Implement the standard (biased) variational eigenfunction loss and the new relative loss on the same task. Train a neural network on each, learn the top eigenfunction, and generate control trajectories for horizons from 10 to 500 steps. Measure the average distance from goal at horizon 500 and the total computation time.
