AdS-GNN: Conformal-Equivariant Graph Neural Networks

A graph neural network that learns the same way whether you zoom in, stretch, or rotate the input data.

Paper explainersAll themesGraph & Geometric Learning

Neural networks usually break when you change the scale or angle of your input. This paper builds a network that recognizes the same patterns no matter how you transform the coordinates, using a trick from physics: it lifts your flat input data into a curved auxiliary space where angle-preserving transformations become simple rotations. The network then works in that curved space and extracts what it learned back to the original flat picture.

Zero assumption version

Why normal networks fail when the data changes scale or angle

When you build a standard neural network on point clouds (sets of coordinates), it treats each coordinate directly: point at (1, 2) means something different from point at (2, 4), even though one is just the other scaled twice. If you rotate the input, the network acts like it is a totally new picture.

A naive attempt: you could try to detect scale and rotation by hand, computing angles and distances, feeding those to the network instead. But this breaks in real tasks. Why? Because the hand-coded features miss the subtle patterns that shift smoothly under these transformations, and the network never learns that certain patterns are really just bigger or rotated versions of each other. You end up teaching the network separately for each scale and angle, wasting capacity.

The core problem: A standard neural network cannot tell that a small triangle and a large triangle are the same shape, rotated or scaled.

The algorithm as a flow

What it actually does

Lift each point

Take a coordinate in the flat input space and embed it as a point in Anti de Sitter space, using neighboring points to pick the right depth.

Compute distances

In AdS, measure the proper distance between points: this distance behaves correctly under angle-preserving transformations.

Message passing

For each node, aggregate information from neighbors using a learned function of that proper distance, the same way as a standard graph network.

Learn the network weights

Train the network on tasks; small nudges to the message functions let nodes capture patterns that do not shift under scale or rotation changes.

Extract back to flat space

Make predictions in AdS space, then apply the inverse lift to get final answers in the original flat coordinates.

What the paper changes

What changes: the distance metric

Standard graph neural networks compute distance directly in the input coordinate system, so a scaled or rotated input looks completely different. AdS-GNN instead computes distance in the lifted curved space, where angle-preserving transformations become simple rotations (isometries). The network learns in this transformed metric.

the object it moves  =  the distance metric between nodes
The hidden quantity

The conformal degree: how much each pattern scales

measured quantity  =  Conformal scaling degree

Conformal symmetries include not just rotations and translations but also scaling: multiplying all coordinates by a constant. When you zoom in on a pattern, its structure stays the same but its effective size changes. The paper calls this the conformal scaling dimension or conformal degree.

The network learns by gradually building up features at different scales in a unified way. During training, the network computes how each node's value changes under a scale transformation. This scaling degree is embedded in the depth coordinate of the lifted AdS space; patterns that are truly scale-invariant have a stable scaling degree across the trained network.

Why it works

Why lifting to AdS space makes angle and scale preservation automatic

Here is the deep reason. In flat Euclidean space, a scale transformation (multiply all coordinates by a number) looks like a very different operation than a rotation. Your network has to learn both separately. But in Anti de Sitter space, which is a curved higher-dimensional space, there is a mathematical fact: angle-preserving transformations in flat space correspond exactly to isometric transformations (distance-preserving rotations) in AdS space.

When you lift a point from flat space to AdS using a smart embedding (based on the depth coordinate z), you are placing it on a curved surface in higher dimensions. Now when the flat space gets rotated or scaled, the corresponding transformation in AdS is just a pure rotation. The network only sees rotations, which it already knows how to handle: if you use message passing that depends only on distances between nodes, rotations leave those distances unchanged, so the network behaves the same. This is why conditioning message passing on the proper distance in AdS (rather than naive coordinates) gives conformal equivariance for free.

Math after the picture

The lifted distance in Anti de Sitter space

First in words:

For two points lifted to AdS, the proper distance is the hyperbolic distance, computed using the Minkowski metric in the higher-dimensional AdS embedding. The key is that this distance is invariant under conformal transformations of the original flat space.

Then the compact form:

proper_distance_AdS = inverse_hyperbolic_cosine( (Y_i · Y_j) / (z_i * z_j) )

Every symbol:

Y_i, Y_jlifted coordinates of points i and j in AdS space
z_i, z_jdepth coordinates in AdS (computed from local neighborhood in flat space)
·inner product using the Minkowski metric of AdS
proper_distance_AdSthe distance between two nodes in AdS (stays the same under angle-preserving transformations)
Toy example: scaling a small triangle to double size
Original small triangle: node A at (0,0), B at (1,0), C at (0,1). AdS lift: z_0 = 0.5 (shallow), proper distance A-B = 1.4, A-C = 1.4.
Scaled triangle (x2): node A at (0,0), B at (2,0), C at (0,2). AdS lift: z_0 = 1.0 (deeper), proper distance A-B = 1.4, A-C = 1.4 (same!).
The deeper embedding automatically adjusts so distances stay the same. Network sees identical distances, learns triangle pattern once, applies it at any scale.

The depth coordinate z is not arbitrary; it is computed from the local neighborhood so that the curved space naturally accounts for the scale you are looking at.

What can go wrong

What can go wrong

Choosing the wrong depth coordinate. The z value for each point is computed from its neighbors. If the neighborhood is too small or the data is very noisy, the z value may not reflect the true local scale, and the network loses equivariance.
Computational cost of lifted space. Lifting to AdS requires higher-dimensional arithmetic and storing extra coordinates. On very large point clouds, this can be slower than a baseline GNN despite the theoretical benefits.
Non-conformal transformations in the data. If your data contains transformations that are not angle-preserving (like non-uniform stretching), conformal equivariance does not help, because the lifted AdS space only cancels angle-preserving changes. The network must learn these transformations the hard way, the same as any baseline network would.
Done right: combining lifting and proper distance. When the neighborhood computation works well and message passing conditions only on proper distance (never on coordinates), conformal equivariance is preserved.
What a runnable demo should prove

What a runnable demo should prove

Build a synthetic dataset: a simple shape (circle, triangle) at different scales and rotations. Train an AdS-GNN on the shape at one scale and rotation. Then test it on the same shape at 2x, 4x, and 8x scale, and at rotations the network has never seen. Measure classification accuracy or L2 reconstruction error. Compare to a baseline GNN trained on the same data.

generalization_gap = accuracy_trained_scale - accuracy_unseen_scale

AdS-GNN should keep the gap small and stable across scales, while a baseline GNN should show accuracy falling off sharply at new scales.
