Automatic discovery of neural mechanisms of cognitive errors

Train neural networks to copy human mistakes, not hide them, and their wiring reveals how brains make those mistakes.

Paper explainersAll themesAI for Science

Scientists want to know how brains make decisions and errors. The usual way is to build neural networks optimized for perfect task performance, then hope the wiring matches a real brain. This paper does the opposite: it trains networks to fail in the exact same ways humans fail, using generative models of the real messy behavioral data. The networks that learn to misbehave end up with architectures and dynamics that predict actual brain recordings.

Zero assumption version

The mismatch between ideal and real

To understand how a brain solves a task, neuroscientists record neural activity while humans or animals perform it. Then they build artificial neural networks and train them to perform the same task perfectly, hoping the network's internal wiring will look like the brain's. But real brains are not perfect. Humans and animals make systematic mistakes: a person trying to remember a red circle might accidentally report the position of a blue square they saw earlier. Networks trained for perfection never make those mistakes, so their wiring does not match the messy reality of actual brains.

The current process is painful: scientists must manually tweak the network architecture and training objectives for months, testing each idea and hoping it captures real behavior. Building a network that exhibits the same errors as a human requires guesswork.

The paper's move: Train networks to reproduce human errors by learning from data that includes those errors, using surrogate data generation and a diffusion-model-inspired training rule.

What it actually does

Collect behavioral data

Record humans or animals performing a task, including all their errors and variation.

Generate surrogate data

Use a generative model to expand the limited behavioral data into many synthetic trials, preserving error patterns.

Adapt diffusion training

Train RNNs using a loss borrowed from image-generation models, teaching networks to produce responses that match real behavior patterns.

Validate against real brains

Check whether the network's internal dynamics match recordings from actual animal brains during the same task.

What the paper changes

The single thing that changes

Instead of training networks on task-optimality (a mean-squared-error loss on the difference between desired and actual output), this paper trains networks to generate samples that match the actual recorded behavior, errors and all. The shift is from maximizing a correctness score to producing output that looks like what real humans or animals actually did.

The hidden quantity

The shape of real answers: single peak vs multiple peaks

measured quantity  =  Response shape (single vs multiple peaks)

When humans remember, sometimes they recall the target item and sometimes they accidentally recall a wrong item they saw. The response distribution is multimodal: it has multiple peaks, one for the correct item and one for each systematic error (like swap errors). A standard neural network trained for accuracy learns to collapse all responses toward the target, making the distribution unimodal (one peak). The paper measures whether the learned network reproduces the actual multimodal shape: is there a peak where humans make errors?

The paper estimates this by fitting the network's output samples to a behavioral model and computing the swap rate (what fraction of responses are swaps). It then compares this to the true swap rate from human data.

Paper reading. The paper measures p(x_response | context), the probability distribution over all possible responses given the task setup. A swap error means p(x_swap | target) is large.
Why it works

Why fitting errors fixes the wiring

Here is the core insight: a brain that makes systematic errors is performing a computation. If you train a network to reproduce that computation, its internal wiring must solve the same problem. When a network learns to swap items the way a human brain does, the pathways it uses to do the swapping must resemble the brain's swap machinery.

The diffusion-training trick makes this work. A diffusion model learns by starting with pure noise and gradually denoising it toward a real example, step by step. Here, the paper reframes the task: the RNN must learn to undo noise added to behavioral responses, in a way that matches the full shape of real behavioral data. This forces the network to discover solutions that match the actual response distribution, including all its error modes.

Because training data is scarce, the paper uses a surrogate generative model to expand real human behavior into synthetic trials, preserving error patterns. This gives the training process enough examples to learn the multimodal structure. A network trained on surrogate data alone learns to replicate errors. When validated against actual brain recordings, the dynamics match, because both the brain and the trained network solved the same problem: how to reproduce multimodal behavior.

The diffusion training loss

First in words:

Mean squared error between the RNN's denoised output and the true response, summed over all noise levels (timesteps) in the diffusion process.

Then the compact form:

L = sum_tau ||RNN(x_noisy, tau) - x_true||^2

Every symbol:

x_noisybehavioral response with noise added
tauthe noise level (timestep in denoising)
x_truethe actual recorded behavioral response
RNN(...)the network's output after trained to remove noise
A tiny worked example
Trial 1: target 90 degrees, network learns to output 90 (correct) at tau=0, swap to 180 at tau=1; loss per timestep = (90-90)^2 + (180-180)^2 = 0
Trial 2: target 90 degrees, network learns to output 120 (swap) at tau=0, target at tau=1; loss per timestep = (120-120)^2 + (90-90)^2 = 0
Network that learns both patterns captures both modes of the distribution. Task-optimal network would only learn mode 1, ignoring swap trials entirely.

The loss rewards the network for learning to reproduce all parts of real behavior, forcing it to discover the multimodal structure rather than collapsing to a single correct answer.

What can go wrong

What can go wrong

Surrogate data mismatch. If the generative model used to expand behavioral data does not capture true error patterns, the expanded dataset will teach the network the wrong mistakes. The network learns to replicate bad surrogates, not real behavior.
Not enough task data. If the original behavioral dataset is extremely small or unrepresentative, no surrogate model can rescue it. The method still requires some ground truth to expand.
Architecture assumptions. The paper assumes a biologically plausible architecture (dendritic trees, specific connectivity). If the true brain uses a fundamentally different computation, the network may fail to match even after fitting behavior.
Done right. When behavioral data is detailed enough and the surrogate model preserves error structure, the network learns to generate the same errors and matches real brain recordings in ways task-optimal networks never do.
What a runnable demo should prove

What a runnable demo should prove

Build a memory task where subjects report the color or position of an item they saw earlier, and record both their answers and their errors. Train two networks: one optimized for correctness, one using this paper's approach on data that includes recorded errors. Then measure: Does the error-trained network reproduce the human error rate? Does the error-trained network's internal activity patterns (when decoded as a representation of the target) match recorded animal brain data from the same task?

Prediction accuracy = fraction of brain recordings whose pattern is explained by error-trained network activity - fraction explained by task-optimal network activity

The error-trained network should show a large gap: because it learned to reproduce human mistakes, its wiring resembles the brain's wiring in ways task-optimal networks cannot match.
