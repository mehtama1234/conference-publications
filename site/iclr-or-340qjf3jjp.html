MHLA: Restoring Expressivity of Linear Attention via Token-Level Multi-Head

Keep the cheap cost of linear attention while recovering variety in the global summary by splitting the sequence into several head-wise summaries.

Paper explainersAll themesOther

This linear-cost sequence-mixing method is attractive because its cost grows gently with sequence length, but it often compresses too much information into one global summary. When that happens, different parts of the sequence start looking too similar and quality drops. MHLA fixes that by letting several heads build separate summaries over different parts of the sequence. This helps because each head can preserve a different pattern instead of forcing everything through one bottleneck, while the overall cost still scales linearly.

Zero assumption version

Cheap sequence mixing often collapses diverse sequence information into one summary

Self-attention (a method where each position compares itself with all other positions) gives high quality but becomes expensive on long sequences because the number of pairwise comparisons explodes. Linear attention (a cheaper variant that replaces the full comparison table with running summaries) avoids that explosion by updating those summaries in one pass.

The tradeoff is expressiveness. If one shared summary has to represent many different patterns at once, positions that should stay distinct begin to blur together. A vision patch about texture, a word about negation, and a video frame about motion may all compete for the same compressed summary, so the model loses the ability to keep separate global cues alive because that summary has only one mixed channel for all of them.

The paper's move. Make several head-wise summaries along the sequence so the cheap method keeps more diversity, because each head can carry a different global pattern.

The algorithm as a flow

What it actually does

Split the sequence into heads

Divide the representation into several parallel heads.

Build a linear summary inside each head

Each head accumulates its own running sequence information.

Use the head summary to update each position

Every position reads from the head-specific summary instead of one shared global bottleneck.

Concatenate the head outputs

Join the head results into one updated representation.

Repeat across layers

Stack the same structure so later layers can preserve higher-level global patterns.

What the paper changes

What the paper changes

The paper changes the summary mechanism inside linear attention. Instead of one shared sequence summary, it uses multiple head-specific summaries so the model can keep several distinct global signals alive because each head stores its own view of the sequence.

The hidden quantity

Summary diversity: the hidden quantity

measured quantity  =  how many distinct global patterns survive compression

The hidden quantity is summary diversity: after compression, do different positions still receive clearly different global information, or did the method flatten them into the same generic context? A model with poor summary diversity can be fast yet weak because it erased the distinctions needed for classification, language understanding, or generation.

MHLA improves summary diversity by letting each head keep its own running view of the sequence. That matters because one head can focus on one kind of long-range pattern while another head keeps a different one, so the final representation retains more variety without paying for all pairwise comparisons.

Why it works

Why head-wise summaries recover quality

Plain linear attention replaces the full interaction table with a compressed running state. That is fast, but if every position reads from the same compressed state, the model has only one channel for global sequence information. Different long-range patterns interfere with one another because they are forced into one shared memory.

MHLA widens that memory without giving up linear scaling. Each head builds its own summary over the sequence, so several global channels exist in parallel. This works because the heads can specialize: one head can preserve broad scene layout, another can preserve rare language cues, and another can preserve motion structure. The model no longer has to squeeze every long-range dependency through one narrow pipe.

The method keeps linear cost because each head still uses the cheap running-summary computation instead of rebuilding the full pairwise table. The improvement comes from better organization of the summaries, not from sneaking quadratic work back in, because the method adds parallel summaries rather than all pairwise comparisons.

Math after the picture

One summary per head

First in words:

For each head h, compute a separate linear-attention output from that head's sequence features, then join the head outputs. The separation is what preserves diversity.

Then the compact form:

output(i) = concat_h ( q_h(i) * S_h ) where S_h = sum_j k_h(j) * v_h(j)

Every symbol:

hthe head index
ithe current position being updated
ja position being accumulated into the head summary
q_h(i)the query for position i inside head h
k_h(j)the key for position j inside head h
v_h(j)the value for position j inside head h
S_hthe running summary stored by head h
concat_hjoin the head outputs into one final representation
A tiny worked example
Suppose there are two heads and three sequence positions.
Head 1 builds summary S_1 = 10 from cues about object layout.
Head 2 builds summary S_2 = 4 from cues about fine detail.
At position i, head 1 query weight is 0.6 and head 2 query weight is 1.5.
Head outputs are 0.6 * 10 = 6 and 1.5 * 4 = 6.
The final position representation uses both outputs, so it keeps two different global cues instead of one shared mixed summary.

The key change is not the running-sum form itself; it is that every head owns a different running sum.

What can go wrong

What can go wrong

Too few heads still bottleneck the summary. If the number of heads is too small, distinct sequence patterns will still collide because the model has not created enough parallel summary channels.
Head specialization can collapse. Different heads may learn nearly the same behavior if training does not encourage useful separation, so the theoretical diversity does not fully appear in practice.
Cheap attention is still an approximation. Some tasks may still prefer full pairwise comparison because certain dependencies need exact interactions that a compressed running summary cannot represent completely.
Done right. When heads specialize into different long-range roles, the model recovers much of full attention's strength because each head preserves a different slice of global structure.
