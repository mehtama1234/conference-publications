SiGMA: Learnable Scaling for Time Series

Use a learnable smooth scaling kernel instead of fixed jumping points when forecasting what happens next in a time series.

Paper explainersAll themesTime Series & Sequential

Time-series forecasting means predicting future values by looking at the past. A good model looks at the past at many different time scales at once: zoomed in to see minute-by-minute wiggles, zoomed out to see long-term trends. Existing methods zoom in by fixed jumps (every 2 hours, every 4 hours, every 8 hours), but this misses the right zoom levels for the specific data. SiGMA learns to zoom smoothly, picking the exact scales that work best for each moment.

Zero assumption version

Why fixed zoom levels fail

When you predict the next values in a time series (like stock prices or temperature), you need to understand patterns at different time scales. A change every hour tells you something different from a change every day. A naive model looks at only one zoom level, so it misses patterns hidden at other scales.

Existing multi-scale models try to fix this: they zoom in at fixed intervals (every 1 step, every 2 steps, every 4 steps, every 8 steps, and so on). But real data does not align with these magic numbers. If your true pattern repeats every 3 days, zooming at 2-day intervals means you always catch it at the wrong moment. The fixed jumps are a rigid cage that wastes computation looking at unhelpful scales and misses the helpful ones.

The paper's move. Learn to zoom smoothly at every distance, not jump at fixed points.

What it actually does

Load the historical data you want to forecast from.

What the paper changes

The single thing that changes

The paper changes how the model weights different time scales. Instead of turning scales on or off at fixed jumps, the model learns a smooth weighting curve (a smooth weight-assignment function that adapts to the data) that works for the specific data.

the object it moves  =  scale weighting curve
The hidden quantity

The hidden quantity: scale importance

measured quantity  =  scale importance curve

The paper measures something not obvious from the data: which past distances matter for predicting the future? A distance (3 steps back, 7 steps back, 100 steps back) might hold useful information or be noise. Instead of guessing (fixed scales), the paper lets the model learn how much each distance contributes — this is the scale importance curve.

SiGMA estimates this by fitting a learnable Gaussian kernel (a smooth bell-curve-shaped weight function) to each time series during training. The width and height of the bell curve adapt to capture exactly which distances the model needs. A narrow bell curve means only nearby steps matter; a wide curve means long-term patterns count.

Why it works

Why learning the kernel works

The problem with fixed scales is that you cannot change which scales matter. If the real pattern repeats every 3 days but you only zoom at 2-day and 4-day intervals, you are locked in. SiGMA learns the scaling curve through training: the model adjusts the curve shape to minimize forecast error, so it naturally discovers which distances matter for that specific data.

The curve is a smooth Gaussian function that peaks in the middle and falls off smoothly on both sides. The model learns its width (how spread out the curve is) and center (where it peaks). A narrow curve means only recent history matters (short-term forecasting). A wide curve means long history matters (catching slow trends). During training, the model adjusts these numbers (width and center) to minimize forecast error. This way, the model automatically tunes the zoom levels to whatever the data needs, not what an engineer guesses.

Math after the picture

The learnable Gaussian kernel

First in words:

For each distance d, the weight is a Gaussian: weight at distance d equals a peak value times e to the power of negative distance squared divided by twice the squared width. The peak and width are learned parameters that adjust during training.

Then the compact form:

w(d) = A * exp(-(d - mu)^2 / (2 * sigma^2))

Every symbol:

w(d)weight assigned to past distance d
Apeak amplitude, learned parameter
mucenter of the bell curve, learned parameter
sigmawidth of the bell curve, learned parameter
dhow many steps back you are looking
A tiny worked example
Say sigma = 2.0, A = 1.0, mu = 0.
Distance 0 (current): w(0) = 1.0 * exp(-(0 - 0)^2 / (2 * 2^2)) = 1.0 * exp(0) = 1.0.
Distance 2 (2 steps back): w(2) = 1.0 * exp(-(2 - 0)^2 / 8) = 1.0 * exp(-0.5) ≈ 0.606.
Distance 5 (5 steps back): w(5) = 1.0 * exp(-(5 - 0)^2 / 8) = 1.0 * exp(-3.125) ≈ 0.044.
Nearby distances matter a lot; far distances fade. The curve is smooth, no jumps.

The Gaussian kernel assigns a smooth, learnable importance to each past distance, replacing the rigid fixed scales.

What can go wrong

What can go wrong

Overfitting the kernel to one dataset. If a time series is short or noisy, the learnable Gaussian might fit the noise instead of the real pattern. Regular validation stops this, but you need enough data.
Kernel too wide or too narrow by accident. If training does not regularize the kernel parameters, they might lock into extreme shapes (very wide or a sharp spike) that do not generalize to new data from the same domain.
Computational cost if not implemented carefully. Computing the weight for every distance can be slow. SiGMA reports achieving speedups, likely through efficient kernel computation, but naive implementation could be wasteful.
Done right. Validate the kernel shape on held-out data, regularize the parameters properly, and use efficient computation. SiGMA reports faster training and lower memory use because the smooth Gaussian function is cheaper to compute than many fixed scales, and it avoids storing redundant scale representations.

What a runnable demo should prove

Measure forecast error on a held-out test set. The learned kernel should automatically center itself near period 7 and produce lower error. Visualize the learned kernel shape (the bell curve) — it should peak near the true pattern period, not at the fixed-scale points.
