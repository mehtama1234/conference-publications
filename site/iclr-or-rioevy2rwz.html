Towards Text-Mask Consistency in Medical Image Segmentation

Segment medical images by fixing the link between the written finding and the predicted mask, so the highlighted region matches what the report actually says.

Paper explainersAll themesMultimodal

Medical image segmentation marks the pixels that belong to a lesion, organ, or other target region. In a vision-language setting, the model should use both the image and a text description, such as a finding report or lesion prompt. The failure is that many systems produce a mask that does not fully agree with the text, especially when the text mentions several sites or several lesions. One reason is pretraining: medical reports reuse many phrases, so standard contrastive learning treats many semantically similar reports as negatives and pushes their representations apart even when they describe the same condition. Another reason is fusion: many models let vision dominate the cross-modal interaction, so text features do not get a strong path into the spatial prediction. C2Seg fixes both problems. It softens the contrastive targets so similar reports are not treated as hard negatives, and it adds a two-way attention block (a module that lets image features and text features reweight one another) where each modality guides the other in its own branch. That matters because the segmentation mask should not only cover plausible anatomy. It should cover the anatomy described by the text.

Zero assumption version

A good-looking mask can still contradict the report

In medical segmentation, the output is a mask: a yes-or-no decision for each pixel about whether that pixel belongs to the target. If the text says 'two lesions in the right lung' and the mask highlights one lesion on the left, the system failed even if the highlighted shape looks medically plausible. The problem is not only image understanding. It is agreement between the spatial output and the written description.

Two technical choices create the mismatch. First, standard contrastive pretraining pairs each image with its own report and pushes it away from all other reports in the batch. That assumption is too harsh for clinical language because many reports use nearly identical wording for similar findings. Pushing those reports apart damages cross-modal alignment, because the model is told that a semantically similar report should be treated as unrelated. Second, one-way fusion lets image features pull from text features, but it does not give text a strong route to shape the spatial map. The segmentation head therefore stays mostly vision-driven even when the text contains the disambiguating detail.

The paper's move. Use softer text supervision during pretraining and bidirectional fusion during segmentation, because the model must preserve medical meaning and inject that meaning into the pixel grid.

The algorithm as a flow

What it actually does

Pretrain image and text features

Encode the medical image and the accompanying report or prompt into feature sets used by the segmentation model.

Build soft text similarity targets

Use a frozen strong baseline to estimate which reports in the batch are semantically similar, so those pairs are not treated as hard negatives.

Learn aligned representations

Train contrastively with the soft targets, so the visual features stay compatible with several medically related text descriptions.

Fuse with two complementary paths

Run bidirectional attention where image-guided fusion and text-guided fusion both contribute to the joint feature map.

Gate the fused features and predict a mask

Use the attention gate to strengthen useful multimodal patterns before the decoder turns them into pixel labels.

What the paper changes

What the paper changes

C2Seg changes both the pretraining target and the fusion path. It replaces one-to-one contrastive supervision with cluster-aware soft supervision, and it replaces mostly one-way cross-modal fusion with a two-path design where language has its own spatially relevant route into the segmentation features.

the object it moves  =  text-to-mask consistency
The hidden quantity

The hidden quantity: semantic conflict inside the batch

measured quantity  =  How often the training loss says two similar reports should be pushed apart

The paper is really controlling semantic conflict in the contrastive loss. In a standard batch, every non-matching text is a negative example. In medical data, that rule is often wrong because many reports differ in patient identity or minor wording but describe the same anatomy or lesion type. When the loss pushes those reports apart, it teaches the image encoder that medically related findings should live far from each other in feature space.

Cluster-aware contrastive learning reduces that conflict by using soft similarity labels. A report that is very similar to the anchor report gets a mild penalty or no penalty instead of the full negative push. This matters because the model should reserve its separation power for genuinely different findings, not for near-duplicates created by clinical writing style.

Why it works

Why softer alignment and two-way fusion fix the mismatch

Contrastive pretraining is supposed to make matching image-text pairs close and non-matching pairs far apart. That works when non-matching pairs are truly unrelated. In medical language, that assumption breaks because the reports are repetitive. If two reports both describe a small right-lung lesion, pushing them apart tells the model that shared medical content is not important. C2Seg replaces the hard rule with a graded rule, so similar reports stay partly compatible. The result is a visual encoder that preserves medical semantics instead of learning arbitrary distinctions caused by phrasing.

The second fix is inside segmentation. A mask is spatial, so text has to influence which image locations become active. In one-way fusion, text often acts only as a weak modifier on top of strong image features. C2Seg gives each modality a dominant branch: one branch starts from image structure and pulls in text, while the other starts from text meaning and projects it into spatial features. That second path matters because the report can specify count, side, or lesion identity that is not obvious from shape alone.

The gate on top of the fused features matters because not every cross-modal interaction is useful. The gate raises the weight of feature combinations that consistently support the described target and lowers the weight of combinations that mix unrelated image regions with text tokens. The decoder then receives a feature map that is already filtered toward text-consistent spatial evidence.

Math after the picture

The training equation

First in words:

The method adds a soft-label contrastive loss to the segmentation loss, so alignment and pixel prediction are trained together.

Then the compact form:

L = L_seg + lambda * L_cluster

Every symbol:

Lthe full loss used to train the model
L_segthe segmentation loss that compares the predicted mask with the true mask
lambdaa weight that sets how strongly the alignment term matters
L_clusterthe cluster-aware contrastive loss, where similar reports are treated with soft targets instead of a hard negative label
A tiny worked example
Suppose one image report says 'two liver lesions' and another says 'multiple lesions in the liver dome.'
A hard contrastive loss would treat the second report as fully negative for the first image, even though their meanings overlap.
The soft-label loss assigns partial similarity instead, so the first image is not pushed far from the second report.
Later, when the segmentation head reads the phrase about lesion count and location, the fused features still carry that meaning.
That is why the final mask is more likely to cover the lesions named by the report instead of a generic suspicious region.

The exact shape of the soft loss can vary. The important part is that medical text similarity changes the penalty, so the model does not learn from false opposition, because reports with overlapping meaning no longer act as full-strength negatives.

What can go wrong

What can go wrong

The soft similarity labels are wrong. If the frozen baseline says two reports are similar when they actually refer to different findings, the model will keep incompatible cases too close. That weakens the contrastive signal because real negatives stop being separated.
The text is underspecified. If the report does not clearly name the target region, no fusion rule can force the right mask. The image branch will dominate because the text provides too little disambiguating information.
The text-led spatial path overfires. If the language branch injects broad activation (strong responses across many image locations) without enough spatial precision, the model may light up too many candidate areas because the wording is medically relevant but not tightly localized.
Done right. Use reliable soft similarity estimates, reports with enough detail, and a fusion module that preserves spatial structure. Then the text supplies meaning and the image supplies localization.
What a runnable demo should prove

What a runnable demo should prove

Build a segmentation benchmark where each image comes with a short target description and a ground-truth mask. Include cases with multiple lesions and mirrored anatomy, because those cases expose text-mask mismatch clearly. Compare a hard-negative contrastive baseline against C2Seg. For each prediction, score not only overlap with the ground-truth mask but also agreement with text facts such as side, count, and named structure. The demo should show that C2Seg reduces cases where the mask is medically plausible yet semantically wrong.
