Causal Structure Learning in Hawkes Processes with Complex Latent Confounder Networks

Recover causal links in event streams with hidden sources by alternating between two jobs: infer links among currently known processes, then add new latent processes only when the observed path patterns require them.

Paper explainersAll themesOther

A multivariate Hawkes process models systems where one event raises the chance of later events in the same process or in another process. If every driving process were observed, one could estimate those excitation links directly from event timing. Real systems are often only partially observed. Hidden subprocesses, meaning unobserved event sources, may trigger several observed streams at once, creating apparent direct links that are really confounding. This paper tackles that setting by connecting continuous-time event sequences to a limiting discrete-time causal model. That bridge matters because identifiability conditions are easier to state on a causal graph built from short time bins. The method then alternates between explaining the data with the currently known processes and introducing new latent subprocesses, meaning newly inferred hidden event sources, only when the path structure among observed processes cannot be explained otherwise. In that way, latent causes are treated as necessary structural additions rather than as arbitrary extra flexibility.

Zero assumption version

Why hidden event sources make causal recovery hard

In a Hawkes process, one event can increase the short-term rate of future events elsewhere. If process A and process B both spike after an unobserved process H fires, the observed data can look as if A causes B or B causes A even when neither direct link exists.

Most existing methods focus on observed processes only. They can estimate a graph over the visible streams, but that graph may mix direct excitation with shared hidden causes. The difficult part is not merely fitting more learned coefficients. The difficult part is deciding when the visible path pattern logically forces the existence of a latent subprocess and when the visible structure already explains the data.

The paper's move. Translate short-interval Hawkes dynamics into a discrete-time causal graph, derive path conditions for when latent subprocesses are identifiable, and then add latent nodes only when those conditions say they are needed.

The hidden quantity

measured quantity  =  the path pattern that cannot be explained without a latent subprocess

The main object is not a hidden node by itself. It is an observed dependency pattern whose graph paths violate what a fully observed model could produce. That unexplained path pattern is the evidence that a latent subprocess must exist.

This matters because one can always improve fit by adding hidden nodes freely. The paper avoids that trap by tying every latent addition to necessary and sufficient path conditions. A latent subprocess is therefore a structural explanation for a specific mismatch, not a generic extra coefficient block.

Why it works

Why the alternating latent search works

The continuous-time to discrete-time bridge is the foundation. Over very short intervals, Hawkes excitations can be represented through causal dependencies between interval counts. That gives the method a graph language for discussing identifiability instead of relying only on rate equations.

Once that graph view exists, the algorithm can separate two decisions. First it asks which observed links are currently supported. Then it asks whether the remaining path pattern is still impossible to explain without hidden sources. This separation matters because otherwise every unexplained dependency might be absorbed into direct observed links or into too many hidden nodes.

Alternation is necessary because the two decisions interact. Adding one latent subprocess can remove the need for several observed edges, and removing those edges changes later identifiability checks. Iterating until the graph stabilizes therefore turns latent discovery into a sequence of structural corrections rather than one uncontrolled joint fit.

A tiny worked example
Suppose hidden process H tends to trigger both observed processes A and B shortly afterward.
When time is binned finely, intervals containing A and B events show a dependency pattern that repeats across lags.
A graph over only A and B may need several direct links to mimic that pattern, yet the path condition still remains inconsistent with a fully observed explanation.
Adding H as a latent parent makes the path pattern coherent because both A and B can now inherit dependence from the same source.
The algorithm alternates until no remaining path pattern still demands a new hidden process.

The paper uses the small-bin graph limit to reason about identifiability, then carries that reasoning back to continuous-time event data.

What can go wrong

What can go wrong

Identifiability conditions may fail on sparse data. If events are too rare or the observation window is too short, the path patterns needed to distinguish direct excitation from latent confounding may not be estimated reliably.
The small-bin approximation still needs enough resolution. If time bins are too coarse, the discrete-time graph can blur causal ordering within an interval, which means the identifiability checks may use the wrong dependency picture.
Latent structure can remain ambiguous in harder networks. When several different hidden-node configurations explain nearly the same observed path pattern, the algorithm may need stronger assumptions or more data to distinguish them because the observed evidence does not separate those hidden explanations cleanly.
Done right. When the event data contain enough events and the identifiability conditions hold, the method can recover hidden and observed links clearly because each latent node is tied to a specific structural discrepancy.

What a runnable demo should prove

The demo should report observed-edge false positives, latent-node recovery, and overall graph accuracy across different event rates and observation lengths. A convincing result shows the latent-aware method replacing spurious observed links with the right hidden causes because the path tests identify when direct visible explanations are insufficient.
