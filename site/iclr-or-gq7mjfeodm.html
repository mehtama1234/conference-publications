Hierarchical Encoding Tree with Modality Mixup for Cross-modal Hashing

Find images and text together by building a tree that groups similar examples and gradually blends proxy versions of each.

When you search for images using text (or text using images), the model must understand both languages at once. Current methods treat images and text separately, then try to line them up, but this leaves a gap. This paper uses a hierarchy (a tree structure that sorts examples from general to specific) and gradually mixes fake versions of the examples to bring the two modalities into alignment.

Zero assumption version

Images and text sit in separate worlds

To find an image by typing words, or find text by showing a picture, the model must learn what images and text mean the same thing. Current methods encode images into numbers (think of a list tracking color, shapes, objects) and encode text into separate numbers (tracking word meaning). Then they try to rotate or scale one list to match the other.

But this direct matching fails because images show surfaces and objects while text talks about concepts and ideas. A photo of a sunset has light, colors, shapes; the caption 'alone in nature' is abstract. No amount of stretching closes that gap.

In one sentence. The paper builds a hierarchy to organize examples and uses progressive mixup to blend image and text versions, closing the semantic gap.

The algorithm as a flow

What it actually does

Build a hierarchy

Organize all image-text pairs into a tree using structural entropy (a measure of disorder) as the guide.

Create proxy samples

For each real pair, generate fake middle-ground versions that partially blend image and text.

Mix progressively

Train step by step, starting with mostly-real pairs and slowly adding more-blended versions.

Learn shared space

Encode both modalities to the same list of numbers so a text query distances match image indices.

Align globally

Add consistency learning so the full batch of images agrees with the full batch of text in meaning.

What the paper changes

What the paper moves

The paper changes how proxy samples are created and mixed during training. Instead of blending image and text representations randomly, it builds them hierarchically and introduces them in curriculum order.

the object it moves  =  proxy sample blending order
The hidden quantity

Hierarchical structural entropy

measured quantity  =  structural entropy of the tree

Structural entropy measures how disorganized a tree is. Low entropy means the tree cleanly separates different concepts; high entropy means groups are jumbled. The paper computes this for the hierarchy of image-text pairs to decide how to organize the proxy samples.

Each pair sits in a position in the tree. Pairs near the root are general; pairs deeper in branches are specific. Structural entropy tells the algorithm whether the tree is doing its job (bringing similar pairs together).

Darker means higher disorder. Specific leaf pairs contribute to entropy; a clean hierarchy has low entropy.

Plain reading. Structural entropy is a count of how mixed-up the groups are. Imagine sorting colored balls into bins — low entropy means balls of the same color cluster together, high entropy means colors are scattered.
Paper reading. The paper uses information-theoretic entropy on the tree structure to guide which pairs to group and in what curriculum order to introduce them.
Why it works

Why hierarchical mixup closes the gap

Image and text are too different to line up all at once, so the paper introduces them gradually. Start with real pairs (each actual image and its caption), which are obviously aligned. Then add fake pairs where part of the numbers come from the image and part from the text. Slowly, the encoding learns to bridge the gap because it must make sense of both at once.

The hierarchy ensures that early fake pairs are similar to their real neighbors, making the blend gentle. Deep in the tree, pairs are more specific, so blending them is harder but they have more examples to learn from. By curriculum (easy blends first, hard blends later), the encoding avoids getting stuck and converges to a shared space where both modalities express the same meaning. Global consistency learning then forces the entire batch to agree: all images should sit near all texts that describe them.

Math after the picture

The alignment cost

First in words:

Total cost equals the distance between proxy-blended image numbers and proxy-blended text numbers, plus a term that makes the full batch of images align with the full batch of text in overall direction.

Then the compact form:

L = sum_i ||encode_image(x_i) - encode_text(y_i)||^2 + lambda * consistency_loss(all_images, all_texts)

Every symbol:

encode_image(x_i)the image encoder output for example i, a list of numbers
encode_text(y_i)the text encoder output for example i, the same-length list
||...||^2squared distance: sum the squared differences between corresponding numbers
lambdahow much to weight the global alignment term relative to per-pair alignment
consistency_loss(...)a measure of whether the full batch's image-direction matches the full batch's text-direction
A tiny worked example
Pair 1: image encodes to [8, 3], text encodes to [7, 4]. Distance = (8-7)^2 + (3-4)^2 = 1 + 1 = 2.0
Pair 2: image encodes to [5, 9], text encodes to [6, 8]. Distance = (5-6)^2 + (9-8)^2 = 1 + 1 = 2.0
Per-pair alignment: 2.0 + 2.0 = 4.0. Global consistency penalty adds 1.5 (all texts pulled in one direction). Total: 4.0 + 1.5*lambda. If lambda=0.5, total = 4.0 + 0.75 = 4.75.

The equation directly measures how far image and text numbers sit apart, plus a term pulling the entire batch into agreement.

What can go wrong

What can go wrong

Hierarchy not stable. If the tree changes as the model trains, the curriculum breaks. Proxy samples meant to be easy become hard in the middle of training.
Curriculum too fast. If blended samples are introduced too quickly, the model does not have time to align on simpler pairs first and diverges.
Modalities still don't meet. If the hierarchy groups irrelevant pairs together (a dog image near a car caption), no amount of mixing will align them.
Done right. The hierarchy is built once at the start from entropy, curriculum is tuned to match typical training, and proxy samples are drawn from pairs that are already semantically close.
What a runnable demo should prove

What a runnable demo should prove

Build a tiny dataset of 100 image-text pairs (e.g., COCO captions or Flickr30K). Encode all images and texts to 128-dimensional vectors (a list of 128 numbers). Train a baseline where you rotate both encodings to line them up directly. Train HINT with a 5-level hierarchy built using entropy. Measure retrieval: for each image, rank all 100 texts by distance and check if the true caption is in the top 10. Count how many images retrieve their true text correctly.

retrieval_accuracy = (number of correct top-10 retrievals) / (total queries)

HINT should retrieve the correct text for at least 75% of images, while naive rotation stays below 65%. The gap proves that hierarchy and curriculum mixup close the semantic gap.
