PETRI: Learning Unified Cell Embeddings from Unpaired Modalities via Early-Fusion Joint Reconstruction

A transformer that learns a single shared cell representation by fusing images and gene expression together at the start and jointly predicting both modalities, even when cells are not paired.

Paper explainersAll themesAI for Science

Biologists want to combine two kinds of cell data at once: pictures (images of cells) and gene lists (which genes are active in each cell). The problem is, they usually do not know which picture matches which gene list. PETRI solves this by grouping cells from the same experiment and learning a shared language that describes both modalities together, even without pairing. It reconstructs both modalities at once, so the shared representation captures what both modalities agree on, and the method naturally learns where each modality is unique.

Zero assumption version

Matching two types of cell data is hard without manual labels

A biologist has two windows into a cell: a picture (the cell's shape, structures, stains) and a list of active genes (which genes are turned on right now). A smart thing to try is to say, 'I will find a picture of cell type A and match it to the gene list of cell type A, then train a model to link them.' The problem: they almost never know which picture is which gene list. They have a pile of pictures from Experiment 1 and a pile of gene lists from Experiment 1, but no name tag on each one saying 'this picture is cell #42 and this gene list is cell #42 from the same moment in time'.

Worse, even when a method tries to learn anyway (ignoring the missing pairs), it tends to learn either the image or the gene expression well, but not both together. The shared representation gets confused or lazy—it leans into whichever modality is easier, and the learned cell description throws away information from the other side.

The issue in one sentence. Standard methods either demand hand-matched pairs or learn separate, incomplete representations of each modality.

The algorithm as a flow

What it actually does

Group unpaired data

Collect all cells from Experiment 1 into a batch, pairing images and genes by experimental context alone.

Early fusion: concatenate at input

Turn the image into patches and the gene list into tokens (individual numbers representing gene activity).

Mask and process

Hide 25% of the image patches and 25% of the genes; the model weighs each piece to predict the hidden ones.

Reconstruct both

Predict the hidden image patches and the hidden genes from the visible ones.

Extract the shared embedding

Use the learned shared representation as the unified cell description.

What the paper changes

What changes: a single, multimodal cell representation

PETRI changes the cell embedding—the learned numerical description of what a cell is. Instead of having one vector (a list of numbers) for the image and a separate vector for the genes, PETRI builds one shared vector that speaks both languages at once.

the object it moves  =  unified cell embedding
The hidden quantity

The hidden quantity: multimodal alignment

measured quantity  =  information that both modalities agree on

PETRI learns what the image and genes have in common by reconstructing both from a shared intermediate representation. The shared embedding is not just a filing cabinet of facts from either side; it is a bottleneck that forces the transformer to extract only the overlapping signal—the structure that explains both the visual patterns and the gene activity together.

The paper measures this alignment indirectly: cells from the same experimental condition (e.g., treated with a drug) cluster together in the learned embedding, and sparse autoencoders applied to this embedding reveal concepts (like 'cell cycle phase' or 'stress response') that are interpretable and consistent across both images and genes. Alignment is strongest when a single learned concept predicts both the visual and gene-level behavior.

Why it works

Why early fusion and masked reconstruction work together

Standard fusion techniques concatenate learned summaries from separate 'image' and 'gene' models at the end. This is like asking two specialists to write separate reports and then gluing them together—they never have to agree with each other. Early fusion puts both modalities into the model from the start. This forces the model to find common ground immediately. When the image patches and gene tokens sit side by side in the same processing step, the model can directly learn which image patterns match which gene patterns, without needing hand-labeled pairs.

Masked reconstruction (hiding some data and predicting it) works because the visible data from one modality becomes the clue to predict the hidden data from the other. When a gene is hidden, the image patches must encode enough information to help predict it—because if the shared embedding does not capture the visual patterns that correlate with that gene, the reconstruction error will spike and the model will receive a teaching signal to fix it. When an image patch is hidden, the genes provide the signal in the same way. This mutual prediction requirement means the shared representation must capture both modalities' essential information, not just one. The result is a bottleneck that squeezes the cell description to only what both modalities agree on, while preserving the cell's unique biological state (the perturbation identity).

Math after the picture

The reconstruction loss: balance both modalities equally

First in words:

total loss equals the sum of (predicted image error plus predicted gene error), and the shared embedding is the learned representation that minimizes this total

Then the compact form:

L_total = L_image(pred_image, hidden_image) + L_genes(pred_genes, hidden_genes)

Every symbol:

L_totalthe total training error
L_imageerror in predicting the hidden image patches
L_geneserror in predicting the hidden genes
pred_imagethe transformer's guess for the hidden image patches
hidden_imagethe true image patches that were masked
pred_genesthe transformer's guess for the hidden genes
hidden_genesthe true gene values that were masked
A tiny worked example
Suppose hidden image patches have error 25 (measured in pixel-difference units).
Suppose hidden genes have error 0.8 (measured in prediction accuracy on a scale 0–1).
To make them comparable, scale the gene error to pixel units: 0.8 * 100 = 80.
Total loss = 25 + 80 = 105.
The transformer updates weights to shrink both losses together, so neither modality dominates.

Joint reconstruction forces the shared embedding to carry information about both modalities equally, avoiding the trap of ignoring one in favor of the easier prediction.

What can go wrong

What can go wrong

Masking too much hides the clue needed to predict. If you mask 80 percent of the data, the transformer has almost no visible signal to predict the hidden parts. The reconstruction fails, and the embedding learns nothing. The paper uses 25 percent masking as a balance.
Imbalanced loss weights favor one modality. If the image loss and gene loss have very different scales (e.g., image error is 0–255, gene error is 0–1), the larger one dominates training, and the embedding ignores the smaller one. Careful scaling is essential.
Unpaired data with no shared structure fails. PETRI assumes all cells in a batch come from the same experiment or condition, so they share a common biological context. If you mix images and genes from entirely different experiments with no overlap, the transformer has no shared structure to find, and the embedding becomes noise.
Done right: group by experimental context, scale losses, mask moderately. When cells are grouped by experiment (so some shared biological state is guaranteed) and losses are balanced, the embedding learns a stable, multimodal cell description.
What a runnable demo should prove

What a runnable demo should prove

A demo should generate or load a small unpaired dataset: 50 cell images and 50 gene lists from the same experiment, with no pairings given. Train PETRI's early-fusion transformer on masked reconstruction (hide 20–30 percent of each modality at random). After training, extract the shared cell embedding. Cluster these embeddings by a known cell attribute (e.g., cell cycle phase, or presence/absence of a drug treatment). Success means cells of the same type cluster tightly together in the embedding space, and that clustering quality is similar for both the image-sourced and gene-sourced cells in the same batch.

clustering_quality = (mean distance within-cluster cells) / (mean distance between-cluster cells), should be >= 0.3 (lower is tighter)

The demo makes it impossible to miss: one unified embedding predicts both images and genes better than learning them separately because the shared bottleneck forces the model to find the overlapping signal that explains both modalities, rather than specializing in one. Without pairing labels, this fusion of clues is the only way to learn a description that works for both.
