Flow-based Conformal Prediction for Multi-dimensional Time Series

Map prediction residuals into a simple Gaussian reference space conditioned on past context, then turn a fixed-probability ball in that space back into a prediction set for the next multivariate time-series outcome.

Paper explainersAll themesOther

Conformal prediction gives uncertainty sets with coverage guarantees, but standard forms assume exchangeability and often handle only one target value at a time. Time series break exchangeability because nearby residuals are correlated, and many real tasks predict several values at once. This paper learns a conditional flow, meaning an invertible map between probability patterns, that sends multivariate residuals into a Gaussian reference space while using a context encoder to summarize the past. Once residuals live in that reference space, the method can use a ball with known probability mass as the nonconformity threshold and map it back into a prediction set in the original output space. The result is a data-driven set shape that adapts to time dependence and dimension while keeping formal coverage results.

Zero assumption version

Why time-series uncertainty sets are hard

Conformal prediction usually works by checking how unusual a candidate output is relative to past calibration errors. That logic is simplest when the calibration points are exchangeable, meaning their order does not matter. Time series violate that assumption because residuals change with seasonality, local volatility, and recent history.

The second difficulty is dimensionality. If the next target is a whole vector, meaning a list of numbers predicted together, the uncertainty set is no longer a simple interval. A fixed rectangle or ellipse can be too loose in some directions and too tight in others because real residual shapes are often skewed and curved.

The paper tries to solve both issues at once. It lets the past context influence the residual error pattern, and it lets the prediction set take whatever shape the learned invertible map induces.

The paper's move. Learn a context-conditioned flow that transforms residuals into a Gaussian reference space, measure nonconformity there by radius, and map the chosen probability ball back to the original output space.

The algorithm as a flow

What it actually does

Train a base forecaster

Use any point predictor to estimate the next outcome from the recent time-series window.

Compute residuals

For each training example, subtract the point forecast from the true outcome to get a multivariate residual.

Encode context

Use a sequence encoder to summarize recent history so the residual model knows whether the series is stable, drifting, or volatile.

Learn an invertible flow

Train a conditional flow that maps residuals into a Gaussian reference pattern while preserving one-to-one correspondence.

Construct the prediction set

Take the reference-space ball with the target probability mass and transform it back through the inverse map to obtain the set for the next outcome.

The point forecast is visible, but the real object needed for uncertainty is the full residual error pattern after conditioning on recent history. That pattern changes over time. During stable periods it may be tight and nearly symmetric. During transitions it may widen, tilt, or become multi-directional.

The flow tries to make that hidden pattern simple in the reference space. If the map is good, then distance from the origin becomes a useful nonconformity score because equal radius means equal probability mass in the Gaussian space.

Why it works

Why the transformed-space ball works

The flow gives a coordinate system in which irregular residual clouds become easier to measure. In the original output space, one direction may be much more variable than another, and the allowable set may curve around the point forecast. After a good transformation, those complications are absorbed by the map itself, so a simple radius threshold in the Gaussian space can represent the desired probability mass.

Conditioning on context matters because time-series errors are not stationary. Recent observations tell the model whether the next residual should likely be small, large, or strongly correlated across dimensions. Without that context, calibration would mix quiet and volatile periods together and produce sets that are too wide in calm periods or too narrow during shifts.

Coverage comes from mass preservation under the invertible map. A ball that contains the target fraction of the Gaussian source pattern corresponds to a set in output space that contains the same mass under the transformed residual error pattern. That is why the method can use a flexible set shape without giving up formal coverage analysis.

The nonconformity score after transformation

First in words:

A candidate output is scored by taking its residual, transforming that residual into the Gaussian reference space, and measuring how far the transformed point lies from the origin. The prediction set contains all candidate outputs whose transformed residual radius is below the chosen threshold.

Then the compact form:

C_i(alpha) = { y : || psi^{-1}(y - y_hat_i | h_i) || <= r_(1-alpha) }

A tiny worked example
Suppose the next outcome has two coordinates and the point forecast is already fixed.
Candidate A produces a residual that maps near the origin in reference space, so its radius is small.
Candidate B produces a residual that maps far from the origin, so its radius is large.
If the target coverage is 0.95, the method accepts all candidates whose mapped radius stays below the 95 percent reference threshold.
The accepted candidates form a curved set in the original output space because the inverse flow bends the simple reference ball.

The set is easy to define in reference space because Gaussian balls have known probability mass, and it becomes flexible in output space because the inverse map can stretch and curve it.

What can go wrong

What can go wrong

The flow can fit the wrong residual shape. If the conditional map is poor, then radius in reference space no longer matches probability mass well, so the transformed set may waste volume or miss parts of the true error pattern.
Context encoding can miss regime shifts. If the encoder does not summarize recent changes well, quiet and volatile periods are mixed together, which weakens the main advantage over exchangeability-based calibration.
Very high-dimensional outputs remain expensive. As outcome dimension grows, learning and evaluating the invertible map gets harder, and set visualization or exact size computation can become awkward.
Done right. The method is useful when outputs are multivariate and residual shape changes with recent history, because fixed intervals and fixed ellipsoids cannot react to those shifts.
What a runnable demo should prove

What a runnable demo should prove

Build a two- or three-dimensional forecasting task with alternating calm and volatile regimes. Train a point forecaster, then compare three conformal layers: one with fixed ellipsoids, one with local weighted residuals, and one with the conditional flow map. Show the prediction set at several time points and color the true next outcome by whether it lands inside.

The demo should also animate the transformation between output space and reference space. That matters because the central idea is not only a new threshold but a learned change of coordinates that turns a hard set-design problem into a simple radius rule.
