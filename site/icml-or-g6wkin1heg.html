Accelerated and Stable Convergence with Anchored Generalized Optimistic Method

An update rule for min-max and related equilibrium problems that combines optimism with anchoring to get fast last-iterate convergence using one or two operator calls.

Paper explainersAll themesOther

Many machine learning problems are not plain minimization. In min-max games and monotone variational inequalities, the update must settle to a balance point where no local move can improve one side without worsening another, because the two sides are pushing against each other at the same time. Simple gradient descent (repeatedly moving in the direction that most reduces the current objective) can cycle around that point. Extragradient fixes some of the cycling but usually needs two operator evaluations per step. GOMA adds an anchor term to optimistic updates and gets stronger last-iterate guarantees because the optimistic part offsets rotational drift while the anchor keeps the trajectory from wandering, in both deterministic and random (noise-driven) settings.

Zero assumption version

Equilibrium problems can rotate instead of settling

In a min-max problem, one variable is trying to decrease an objective while another is trying to increase it. The resulting update field is often rotational. Move one variable a little and the best response of the other variable changes direction. Basic first-order methods can therefore keep orbiting the solution instead of approaching it step by step.

Extragradient uses a lookahead correction to reduce that orbiting, but it usually needs two operator evaluations each iteration. That extra cost matters in online and random settings, where each evaluation can be noisy or expensive. The challenge is to retain stability while also getting fast convergence of the actual iterate you keep at the end of training.

The hard part. The algorithm must cancel rotational drift without paying too much per step, and it must make the last iterate itself converge rather than only an average of iterates.

What the paper changes

What the paper changes

The paper changes the update rule used for monotone equilibrium problems. It takes a generalized optimistic method and adds anchoring inspired by Halpern iteration, which is a fixed-point method that repeatedly mixes the current iterate with a reference point. The added anchor introduces a stabilizing pull while the optimistic part handles the rotational structure of the operator field.

The hidden quantity

The hidden quantity: last-iterate equilibrium error

measured quantity  =  last-iterate equilibrium error

The paper measures progress with the squared norm of the operator at the current iterate. In plain terms, the operator is the update field produced by the equilibrium problem. If that field is large, the current point is still far from balance because the problem is still pushing strongly in some direction. If that field is near zero, the point is close to equilibrium.

This choice matters because many older guarantees focus on averages of iterates. Averages can hide oscillation: the average may look good even while the actual current point is still cycling. A last-iterate guarantee is stronger for practice because the algorithm returns one final point, not an average of every point it ever visited.

Why it works

Why optimism plus anchoring helps

Optimistic methods are useful in games because the update field often has short-term predictability. If the operator tends to rotate in a regular way, the previous operator value contains information about where the next push will point. Using that information cancels part of the rotational drift.

Anchoring adds a different effect. It keeps each iterate tied to a reference point through a scheduled mixture. This matters because optimism alone can still drift or amplify noise when the operator is random. The anchor supplies a stabilizing bias that shrinks over time, so early steps stay controlled while later steps can still approach the true solution.

The two-time-scale design is what lets the method claim both acceleration and stability. One schedule governs how aggressively the method follows the optimistic correction. Another governs how quickly the anchor weight fades. In the deterministic setting, this balance yields the stated fast decrease of last-iterate squared operator norm. In the random setting, the single-call form still converges under unbounded variance because the anchor prevents noise from causing unrestricted wandering.

Math after the picture

The equation: optimistic step plus anchor mixture

First in words:

Update the current point using an optimistic operator correction and a shrinking pull toward a fixed anchor point.

Then the compact form:

new_point = anchor_weight * anchor_point + remaining_weight * optimistic_update(current_point, previous_operator_value)

Every symbol:

new_pointthe next iterate produced by the method
anchor_weightthe amount of pull toward the anchor on this step
anchor_pointthe fixed reference point used to stabilize the iteration
remaining_weightthe part of the step assigned to the optimistic update
optimistic_update(current_point, previous_operator_value)the correction that uses recent operator information to reduce rotational drift
A tiny worked example
Suppose the current game update keeps turning the iterate clockwise around the solution.
The optimistic term uses the previous turn direction to offset part of the next clockwise push.
At the same time, a small anchor weight keeps the iterate from flying outward when the correction is noisy.
As the anchor weight shrinks, the method relies more on the corrected dynamics and less on the fixed reference point.

The exact paper method contains several related variants, but they all share the same structural idea: prediction for the rotation and anchoring for stability.

What can go wrong

What can go wrong

Anchor decays too slowly. If the anchor keeps too much weight for too long, the method can stay biased toward the reference point and approach the true equilibrium more slowly.
Anchor decays too quickly. If the stabilizing pull disappears before the optimistic term has enough reliable signal, noisy or rotational problems can destabilize the trajectory again.
Problem assumptions fail. The guarantees rely on monotonicity and Lipschitz continuity, which means the operator behaves in a controlled way. Outside that setting, the same schedule may not produce the claimed rates.
Done right. The method is strongest when the operator field is monotone, the schedules for optimism and anchoring are matched to the theory, and the application needs the last iterate itself to be reliable.

What a runnable demo should prove

Build a two-dimensional bilinear min-max game, which is a standard rotating test case. Run basic gradient descent, an extragradient baseline, and an anchored optimistic method. Track the current iterate and the norm of the game operator at every step.

The important plot is not only the path of the iterates but also the final-iterate residual over time. The anchored optimistic method should approach the center more directly and keep the residual decreasing, while the plain method circles. Then add random noise to the operator call and compare the single-call anchored variant against a single-call baseline without anchoring.
