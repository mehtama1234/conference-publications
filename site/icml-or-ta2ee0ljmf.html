Great Minds Think Alike: Contextual Tacit Communication for Decentralized LLM-Agent Cooperation

Coordinate decentralized agents without explicit messages by learning reusable local rules that push each agent toward the same joint objective.

Paper explainersAll themesAgents & Tool Use

This paper studies cooperation when several agents must act with partial information and direct messaging is costly or unavailable. A common failure is miscoordination: each agent picks a locally sensible move, but the moves clash because the agents never align on a shared plan. The paper proposes Contextual Tacit Communication, which learns coordination hints from past situations and stores them in a rule memory that each agent can consult before acting.

Zero assumption version

Why decentralized agents drift apart

In a decentralized setting, each agent sees only part of the world and chooses an action on its own. That is a problem because locally reasonable actions can still conflict when the team needs one joint plan.

Direct message passing can reduce that conflict, but it can also be expensive, blocked, or unreliable. The paper asks whether agents can coordinate with no explicit message action by learning context-dependent rules that make separate local decisions line up more often.

The paper's move in one sentence. Estimate where local choices disagree with the joint objective, turn those cases into compact cooperation rules, and retrieve the right rule later so each agent can act in step without sending a message.

The algorithm as a flow

What it actually does

Generate local candidate actions

Each agent proposes actions from its own partial view so the system can see what local planning would do on its own.

Score the team outcome

A joint value function scores how well the combined actions serve the shared task because team quality, not local comfort, is the real target.

Locate the mismatch

Find the action choices that most hurt the joint score so the method can identify where miscoordination actually occurred.

Store a tacit rule

Write a compact rule for that context and attach it to a retrieval memory so similar future cases can recall it.

Retrieve before acting

At execution time, fetch the most relevant rule and insert it into the prompt so each agent starts from a more coordinated local choice.

What the paper changes

What the paper changes

The paper changes how decentralized agents coordinate. Instead of sending explicit online messages, it uses stored context rules that bias each agent toward team-compatible actions.

the object it moves  =  the local decision rule used by each decentralized agent
The hidden quantity

The hidden quantity

measured quantity  =  how much one local action helps or hurts the joint plan in the current context

The key hidden quantity is the coordination effect of one agent's local action. That quantity is hidden because the action may look sensible from one partial view while still damaging the team once the other agents' unseen information is taken into account.

The paper estimates this effect by comparing local choices against a joint value score. That works because the joint score reflects whether the team actually moved toward the shared objective, so the system can attach a coordination lesson to the state that produced the mismatch.

Why it works

Why tacit rules can replace direct messaging in some settings

The method works when recurring situations create recurring coordination needs. If similar contexts appear many times, a stored rule can tell an agent which action usually fits the joint plan, so the agent does not need a new explicit message on every encounter.

The joint value score is important because it gives a target outside the agent's local view. By locating the local choice that hurt the team score, the system can build a rule that corrects the exact coordination failure instead of storing vague advice.

Math after the picture

A simple coordination correction score

First in words:

A local action is attractive when it earns local reward, but it should be downgraded when it lowers the team value. The rule memory should prefer actions with better corrected score.

Then the compact form:

corrected_value(action_i) = local_value(action_i) + joint_alignment(action_i, context)

Every symbol:

corrected_value(action_i)score used to compare one agent's local actions
local_value(action_i)how good action i looks from the agent's own partial view
joint_alignment(action_i, context)extra value when action i supports the team plan in the current context
A tiny worked example
Agent A can choose collect or block.
Collect looks slightly better locally, so local_value is 7 for collect and 6 for block.
The joint plan needs one agent to block, so joint_alignment is -3 for collect and +4 for block.
Then corrected_value(collect) = 4 and corrected_value(block) = 10.
The memory should favor block because it raises team quality even though the local view alone preferred collect.

The paper uses a more detailed procedure, but this compact score captures the central idea that local actions should be corrected by their effect on joint coordination.

What can go wrong

What can go wrong

The stored rule can be applied in the wrong context. If retrieval finds a superficially similar case that differs in one decisive detail, the agent may follow the wrong coordination habit because the memory generalized too broadly.
The joint score may be noisy. If the team-level evaluator is weak, the method can write bad rules because it misidentified which local choice actually hurt the team.
One-off situations may not benefit much. The approach depends on recurring contexts, so rare cases may still need direct communication because no useful rule has been stored yet.
Done right. The method is useful because it converts repeated coordination mistakes into reusable local guidance.
What a runnable demo should prove

What a runnable demo should prove

Build a small cooperative grid task where two or three agents must split roles under partial observability and direct communication is disabled. Compare plain decentralized planning against a version that stores context rules after training episodes, then retrieves those rules during later episodes.

The demo should show that the rule memory raises team completion while keeping overhead low because agents can reuse a compact coordination lesson instead of rediscovering the same team pattern every time.
