Beyond Rational Illusion: Behaviorally Realistic Strategic Classification

Model strategic feature manipulation with prospect-theory biases instead of assuming every agent computes a fully rational best response.

Paper explainersAll themesOther

Strategic classification studies predictors whose targets can react to the predictor itself. A loan applicant may change reported features to cross a score threshold; a platform user may alter observable behavior to gain access or avoid penalties. Standard models assume the agent is fully rational and chooses the feature change that maximizes expected utility exactly. This paper argues that deployment often violates that assumption because human decisions reflect loss aversion, reference dependence, and distorted judgments about probabilities. It defines a behaviorally realistic version of strategic classification and proposes Pro-SF, which rewrites the leader-follower interaction so the agent's response is guided by prospect theory. That matters because a classifier trained against an unrealistically rational response model can predict the wrong manipulations and therefore optimize for a world that users do not actually inhabit.

Zero assumption version

Strategic classification uses the wrong human model

In strategic classification, the classifier sets incentives and the person being classified may change observable features in response. Existing work usually assumes that person solves a clean optimization problem and picks the exact best feature manipulation after weighing cost and benefit objectively.

Behavioral economics shows that real people do not respond that way consistently. They react more strongly to losses than to equal-sized gains, judge outcomes relative to a personal reference point, and distort small or large probabilities. If the model ignores those patterns, it can mispredict who manipulates, how far they move, and which decision rule will emerge at equilibrium.

The paper's move in one sentence. Replace the strictly rational agent in strategic classification with an agent whose utility follows prospect-theory mechanisms, then learn the classifier against that more realistic response model.

What it actually does

Model how agents evaluate gains and losses asymmetrically, compare outcomes to a subjective reference point, and distort perceived probabilities.

What the paper changes

What the paper changes

The paper changes the response model of the strategic agent. Instead of assuming exact expected-utility maximization under objective probabilities, it uses a behaviorally biased utility model.

the object it moves  =  agent response utility
The hidden quantity

The hidden quantity

measured quantity  =  The agent's subjective utility for each possible manipulation

Observed feature changes reveal only the final action, not the internal valuation process that produced it. The critical hidden quantity is the subjective utility assigned to each possible manipulation after benefits, costs, reference points, and perceived probabilities are transformed by behavioral bias.

This hidden utility differs from objective utility. Two manipulations with the same expected payoff can be evaluated differently if one is framed as avoiding a loss, if one crosses a personal aspiration level, or if the person overweights a small chance of success. Pro-SF tries to model that internal ranking directly.

Why it works

Why prospect-guided responses change the learned classifier

A rational-response model can recommend a classifier that looks optimal only because it assumes agents chase expected payoff with perfect consistency. If real agents avoid losses more strongly than they pursue gains, then a threshold that appears harmless in the rational model may trigger much more defensive manipulation in practice. Reference dependence also matters because the same classification outcome can feel very different to two agents who start from different status quo expectations.

By fitting the classifier against a biased response model, Pro-SF shifts the training target from idealized manipulation to observed manipulation. That changes both prediction and policy. The predicted feature movement changes because subjective costs and distorted probabilities reorder the agent's options, and the optimal classifier changes because it is now responding to the manipulation pattern that those reordered options create.

Math after the picture

A behaviorally weighted response score

First in words:

A candidate manipulation is evaluated by taking the decision benefit relative to a reference point, applying asymmetric weighting to gains and losses, and combining that with a weighted view of success probability and manipulation cost.

Then the compact form:

U(a) = w(p_success(a)) V(benefit(a) - r) - C(a)

Every symbol:

U(a)the subjective utility of manipulation a
w(p_success(a))the distorted weight applied to the success probability of manipulation a
V(benefit(a) - r)the prospect-style value of the benefit relative to reference point r
rthe agent's subjective reference point
C(a)the cost of performing manipulation a
A tiny worked example
Suppose one feature edit gives a moderate chance of acceptance with cost 2.
A rational model may rank it above doing nothing because the expected gain exceeds 2.
Under prospect-style utility, the same edit can rank lower if failing to cross the threshold is felt as a loss from the agent's reference point and that loss is weighted heavily.
A second edit with slightly lower objective payoff can rank higher if it reduces the chance of that perceived loss more sharply.
The classifier that anticipates these rankings is different from the classifier trained on purely rational responses.

The paper uses prospect-theory ingredients rather than a single universal formula, but this expression captures the main change: objective payoff is filtered through subjective weighting before the agent responds.

What can go wrong

What can go wrong

Behavioral response settings, meaning the numbers that control loss aversion and probability distortion, may vary by population. Loss aversion and probability distortion can differ across groups, so one fitted response model may not transfer cleanly to a new deployment context.
Some manipulations are still hard to enumerate. If the system omits realistic feature edits from the feasible action set, then even a strong behavioral utility model cannot predict the manipulations that were left out.
Behavior can change after deployment. Agents may learn from the deployed classifier and from each other, which means their reference points or perceived costs can drift over time.
Done right. This framework is most useful when human strategic behavior is central to the task and when there is enough data to estimate the main behavioral response settings, meaning the numbers that govern the response model, with discipline.
What a runnable demo should prove

What a runnable demo should prove

Create a binary classification task where agents can edit one or two features at explicit costs to cross the acceptance boundary. Simulate one population with rational expected-utility responses and another with prospect-style responses that include loss aversion, reference dependence, and probability distortion. Train a standard strategic classifier and a Pro-SF-style classifier on the corresponding populations.

Compare predicted manipulations, realized acceptance rates, and deployment utility under each population. The demo should show that the behaviorally guided classifier wins on the biased population because it anticipates the manipulations that actually occur rather than the manipulations that a fully rational agent would choose.

deployment_utility = task_reward - manipulation_costs - decision_errors

The demo must separate objective payoff from subjective response, because that distinction is the paper's central reason for changing the strategic classification model.
