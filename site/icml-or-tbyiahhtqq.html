MLLM-4D: Towards Visual-based Spatial-Temporal Intelligence

Teach a multimodal language model to reason about 3D scene change over time from ordinary video by curating 4D instruction data and then rewarding spatiotemporal reasoning during post-training.

Paper explainersAll themesMultimodal

Current multimodal language models can describe frames, answer short visual questions, and summarize video clips, yet they still struggle with 4D understanding: reasoning about 3D structure and how that structure changes over time from only 2D RGB video. The main bottlenecks are data and training signal. Most existing instruction data describe static images or shallow video events, and common post-training objectives do not reward step-by-step spatial-temporal reasoning. MLLM-4D addresses both gaps. It repurposes stereo video sources into large instruction datasets that expose scene depth and temporal evolution, then post-trains an existing multimodal language model with supervised fine-tuning followed by reinforcement fine-tuning using spatiotemporal chain-of-thought prompts and rewards tailored to 4D reasoning.

Zero assumption version

Why 2D video question answering does not automatically give 4D reasoning

Answering a question about a frame is different from reasoning about the evolving 3D arrangement of objects across time. A model must infer depth, motion, occlusion, object permanence, and viewpoint change from image sequences that do not directly supply 3D coordinates. That requires a representation of scene state over time, not just local recognition.

Off-the-shelf multimodal language-model training data rarely force that behavior. Many samples ask for captioning, event naming, or simple temporal order. Those tasks do not require the model to track where objects move in three dimensions or how one change constrains another. As a result, the model can look competent on broad video benchmarks while still failing when asked where an object moved relative to another object after an occlusion, or which physical configuration must now hold because of an earlier motion.

The method in one sentence. Create large-scale instruction data that expose scene evolution from stereo video, then reward reasoning traces and answers that preserve spatial-temporal consistency.

The algorithm as a flow

What it actually does

Repurpose stereo video datasets.

Convert existing stereo video corpora into instruction data so the training set contains depth and motion cues without collecting a new raw video source from scratch.

Generate 4D supervision.

Create questions, answers, and reasoning traces about spatial relations, temporal evolution, and future consequences because those tasks force the model to track scene state rather than only recognize objects.

Run supervised fine-tuning first.

Teach the base multimodal language model the basic 4D task format and vocabulary before reinforcement fine-tuning begins.

Run reinforcement fine-tuning with GRPO.

Use Group Relative Policy Optimization so candidate reasoning traces and answers can be ranked against one another under spatiotemporal reward functions.

Evaluate on a dedicated 4D benchmark.

Measure whether the model can answer and reason about evolving 3D scenes from plain RGB input, not only from explicit depth sensors.

The hidden quantity

The hidden quantity

measured quantity  =  internal consistency of the model's evolving scene state

The hidden quantity is whether the model maintains a coherent internal account of the scene as time advances. A correct answer to one question can be produced by shortcut cues, but a sequence of spatial-temporal questions reveals whether the model has actually tracked where objects are, which motions occurred, and what relations now hold.

MLLM-4D trains that hidden state indirectly. The curated data force the model to produce reasoning traces about depth, motion, and temporal consequence. The reinforcement stage then rewards outputs that stay consistent with those constraints. Over time, the cheapest way for the model to earn reward is to carry forward a more faithful scene state, because inconsistent internal tracking leads to contradictions across the reasoning chain and the final answer.

Why it works

Why data curation plus reward shaping changes the model's behavior

The data curation stage matters because general video corpora do not naturally contain enough supervision about depth and state evolution. Stereo video provides additional cues about relative depth and motion that can be transformed into questions and explanations about 3D change. Once those cues are wrapped into instruction format, the model repeatedly sees tasks that require tracking scene state across time.

Supervised fine-tuning establishes the basic behavior: how to read the prompt style, how to answer spatial-temporal questions, and how to produce reasoning traces in the expected format. Reinforcement fine-tuning then changes the optimization target from simple imitation to preference for outputs that score well under spatiotemporal rewards. That matters because two answers can look similarly fluent while only one respects depth order, motion continuity, or temporal causality.

GRPO is a good fit because it compares groups of candidate outputs for the same prompt. A reward function can then choose the candidates whose reasoning and final answer remain most consistent with the scene evolution. That relative ranking signal pushes the model toward reasoning chains that preserve 4D constraints instead of rewarding surface fluency alone.

Math after the picture

Use relative reward within a candidate group

First in words:

A simple summary is to score several candidate outputs for the same prompt and update the model toward the candidates whose spatiotemporal reward is higher than the group average.

Then the compact form:

adv_i = r_i - (1 / G) * sum_j r_j

Every symbol:

r_ithe spatiotemporal reward for candidate output i
Gthe number of candidate outputs sampled for one prompt
sum_j r_jthe total reward across the candidate group
adv_ithe relative advantage used to favor better candidates inside the group
A tiny worked example
Suppose four candidate answers are sampled for one video question.
Their rewards for spatial-temporal consistency are 0.9, 0.6, 0.5, and 0.2.
The group average reward is 0.55.
The first answer gets relative advantage 0.35, while the last gets minus 0.35.
Training pushes probability toward the first answer because it preserved more of the scene's spatial-temporal constraints.

The full training objective is richer, but the central idea is group-relative preference for reasoning traces and answers that stay consistent with scene evolution.

What can go wrong

What can go wrong

Curated supervision can still contain shortcut cues. If many questions can be answered from one frame or from common language habits, the model may earn reward without building a true evolving scene state.
Reward design may miss some reasoning errors. A reward function can check several spatial-temporal constraints and still fail to penalize a subtle but important inconsistency, especially in long reasoning chains.
Stereo-derived data may not cover every video domain. If the source corpora underrepresent certain motions, viewpoints, or object interactions, the post-trained model may still struggle on those patterns at test time.
Done right. The method is strongest when question generation removes shortcut cases, the rewards check both final answers and reasoning traces, and the source videos cover varied scene dynamics.
What a runnable demo should prove

What a runnable demo should prove

Build a small RGB video benchmark with questions about object depth order, occlusion, future position after motion, and relation changes after camera movement. Fine-tune a base multimodal language model with supervised examples, then add a reinforcement stage that scores candidate outputs for spatial-temporal consistency.

The demo should compare answer accuracy and contradiction rate across multi-step question sets about the same clip. That second metric matters because a model that truly tracks an evolving scene state should answer later questions in a way that remains compatible with earlier events and earlier answers.

contradiction_rate = inconsistent_multi_step_answers / total_multi_step_question_sets

A convincing result is lower contradiction rate together with higher accuracy on depth-and-motion questions, because that indicates the model is maintaining a more coherent account of the scene over time.
