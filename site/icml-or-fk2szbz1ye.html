EquiCAD: Symmetry-Aware Learning for 3D Shape Classification

Recognize 3D shapes better by building a neural network that respects symmetries in how curves and surfaces are described.

Paper explainersAll themesGraph & Geometric Learning

3D shape recognition is critical for manufacturing inspection, design automation, and digital engineering—industries that rely on CAD (computer-aided design) files. These files describe shapes using boundary representations: precise curves and surfaces that define an object's surface. The challenge is that existing neural networks ignore a key property: these descriptions have symmetries. Rotating a shape does not change what it is, yet current methods treat the rotated version as a new shape to learn separately. EquiCAD builds a neural network that understands symmetry: it treats rotationally equivalent descriptions the same way, learning once instead of learning the same shape many times over.

Why symmetry goes to waste

A 3D CAD shape is stored as a boundary representation: a collection of curves and surfaces that bound a solid object. These descriptions have a mathematical property called symmetry: if you rotate the entire shape, the boundary description transforms in a predictable, regular way. A sphere looks the same when rotated; a cylinder rotated around its axis is still the same cylinder. Yet most neural networks do not know this. They treat a shape and its rotated version as completely separate inputs, forcing the network to learn the same features multiple times over.

A beginner might try a standard graph neural network (a model that learns from networks of connected points) or a 3D volumetric network that divides space into cubes and checks which ones are inside the shape. These methods can classify shapes, but they throw away information about symmetry. Training data for industrial shapes is expensive to collect. Without leveraging symmetry, the network wastes data: it learns to recognize a gear one way, then encounters the same gear rotated differently and must learn it all over again as a separate problem. The result is slower learning, lower accuracy on rare shapes, and models that do not generalize well to new manufacturing parts.

In one sentence. EquiCAD builds symmetry awareness directly into the network so that rotated shapes produce identical internal representations, cutting the learning burden.

The algorithm as a flow

What it actually does

1. Decompose boundary representation

Break each curve and surface into components using group-theoretic decomposition, extracting their rotation-aware descriptors.

2. Encode symmetry into features

Transform curve and surface descriptors so that rotations produce identical feature vectors (equivariance).

3. Build graph from boundary topology

Create a graph where nodes are curves and surfaces, edges connect adjacent elements, capturing the shape's topology.

4. Hierarchical message passing

Run graph neural network layers that propagate local symmetry-aware features to neighbors, building up global shape understanding.

5. Classify from global representation

Pool all local features into one global descriptor and pass it through a classifier to predict shape category or attributes.

What the paper changes

What the paper changes

EquiCAD changes what features the network extracts from curves and surfaces. Instead of learning arbitrary numbers that treat rotations as independent inputs, it builds features that transform predictably under rotation (a property called equivariance). When you rotate the shape, the features rotate by the same amount automatically. This is done using group-theoretic decomposition: the paper mathematically factorizes each curve and surface descriptor into rotationally irreducible components, then feeds those components into a neural network. The network then runs hierarchical message passing (a technique that sends information between curves and surfaces in the graph) to combine local symmetry-aware features into a global shape representation.

The hidden quantity

The hidden quantity: symmetry alignment score

measured quantity  =  Fraction of features that transform identically under rotation

The symmetry alignment score measures how much of the network's learned representation respects rotational symmetry. In a standard network, each feature value changes unpredictably when the input rotates. In EquiCAD, features should transform by a predictable rotation (a property called equivariance). The alignment score is the fraction of the network's internal numbers (weights and intermediate calculations) that maintain this equivariant structure versus ones that break it.

The paper enforces this by using group-theoretic constraints during learning: curve and surface descriptors are decomposed using representation theory (mathematical techniques that break complex objects into irreducible pieces), and the decomposition automatically ensures equivariance. During training, the network learns rotation-aware weight matrices that map equivariant inputs to equivariant outputs. The higher the alignment score, the fewer redundant rotations the network must learn, because a shape rotated by 5 degrees is automatically handled by the same feature transformation as a shape rotated by 90 degrees—the network learned the rotation law once, not once per angle. This means the network generalizes to unseen orientations automatically: it never needs to see every possible rotation angle during training.

Why it works

Why it works: learning once per shape class

The core insight is that rotational symmetry is free information: if the network knows that rotating a shape produces a rotated feature vector (not a random new feature), then it only needs to learn each shape once. Standard networks do not enforce this, so they waste training data. EquiCAD enforces rotational equivariance by building the network from group-theoretic building blocks. Each curve and surface is decomposed into irreducible representations (mathematical objects that cannot be broken into smaller symmetric pieces). When you rotate the original shape, these irreducible components rotate by predictable, fixed matrices. The network learns weight matrices that respect these rotation laws, so rotationally equivalent inputs automatically produce rotationally equivalent features.

This reduces learning burden sharply. Suppose a gear has four-fold rotational symmetry (rotated by 90 degrees four times returns to the original). A standard network must learn features separately for each 90-degree rotation. EquiCAD's equivariant network learns one feature set that transforms predictably under 90-degree rotation, automatically handling all four versions with one parameter set. Hierarchical message passing then combines these symmetry-aware features: local curve and surface features are sent to neighboring elements in the graph, building up a global representation. The final global representation is invariant (unchanged by rotation), so the classifier sees the same input for all rotations. The result is faster learning (fewer unique parameter sets to fit), better generalization (symmetry is learned from data once, not reinvented per rotation), and higher accuracy on rare shapes (because symmetry knowledge is transferred from common shapes to rare ones, via the equivariance structure).

A tiny worked example
Suppose a curve descriptor is a 3D vector x = [1.0, 0.0, 0.0] pointing along the x-axis.
Rotate 90 degrees around the z-axis: R·x = [0.0, 1.0, 0.0] (now points along y-axis).
Standard network: F[x] = [2.5, 3.1, 1.2]; F[R·x] = [5.2, 0.8, 2.1] (completely different).
Equivariant network: F_eq[x] = [2.5, 3.1, 1.2]; F_eq[R·x] = [3.1, 2.5, 1.2] (features rotated, not random).
Network learned: 'rotate features the same way.' Training learns this pattern from rotations in the training data; once learned, all new rotations are automatically handled.

Equivariance means the network's output rotates the same way as its input—no new learning needed for new angles.

What can go wrong

What can go wrong

Non-uniform scale or shear. Equivariance enforces rotational symmetry, but not scale or shear symmetry. If a CAD shape is stretched unevenly or sheared, the equivariant features break down. The network will misclassify if training used only uniformly scaled or unsheared shapes.
Partial or discontinuous topology. The boundary representation assumes connected curves and surfaces. If a shape has loose parts, multiple disconnected shells, or too few control points to describe it well, the graph construction fails or misses important structure. Message passing then propagates incomplete information.
Ambiguous irreducible decomposition. Some shapes may have symmetry groups that are hard to decompose cleanly (non-crystallographic symmetries, near-symmetries). The group-theoretic decomposition may produce artificial decompositions that do not match how the shape was actually drawn or manufactured.
Done right. When shapes have clear rotational symmetries, complete boundary descriptions, and uniform scaling, EquiCAD learns efficiently because the equivariance structure compresses learning (one rotation law instead of many), and it generalizes to unseen rotations and rare shape categories far better than standard networks, because the symmetry structure creates a strong inductive bias that works across all rotations and transfers knowledge across shape categories.
What a runnable demo should prove

What a runnable demo should prove

A minimal demo trains on a set of labeled CAD shapes (one orientation per class), then tests accuracy on the same shapes rotated to random angles not seen during training. It should compare EquiCAD against a standard graph neural network and a 3D convolutional baseline. Metrics: classification accuracy on rotated test sets and generalization gap (accuracy on original orientation minus accuracy on unseen rotations). The demo should include at least two shape categories with obvious symmetries (cylinders, cubes, gears) and two with less symmetry (asymmetric mechanical parts); this contrast shows that equivariance helps most where symmetry is strong because the inductive bias is tight for high-symmetry shapes but loose for low-symmetry ones. Code should load a small CAD dataset, extract boundary representations, run both methods, and plot accuracy curves versus rotation angle. The key proof: EquiCAD maintains constant accuracy across rotations (because equivariance handles all angles automatically), while standard networks drop off sharply (because they only saw one orientation during training).
