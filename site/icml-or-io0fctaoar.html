TopoDistill: Learning Topology for Causal Discovery

A method that teaches a neural network to embed time-series data so neighborhoods match reality, making it easier to discover which variables cause which.

Paper explainersAll themesTime Series & Sequential

To figure out which variable causes which in a time series (like temperature causing humidity), a classic method called convergent cross mapping reconstructs what the system looked like at past moments by stacking recent values into a high-dimensional point (an embedding: a list of numbers representing a moment). When data is noisy, this reconstruction gets muddled: points that should be neighbors become scattered, making it hard to tell causation apart from coincidence. TopoDistill teaches a small model to output numbers matching a stronger, fuller view of the system. Because the fuller view sees all variables at once, it preserves which points should be neighbors even when individual measurements are noisy, and TopoDistill transfers this knowledge to the smaller model. As a result, the small model's neighborhoods stay clean and causal links become visible even with noise.

Zero assumption version

Why reconstructing the past from fragments is hard

When you want to discover causation in a time series (a stream of measurements over time), the standard trick is this: at each moment, stack the last N measurements into a list (a vector, which is just a list of numbers), treat that list as a single point in high-dimensional space, and use distances between points to infer causal links. The theory says this works — if you stack enough history, you can faithfully reconstruct the system's inner state. But real data is noisy. When noise garbles the reconstruction, nearby points scatter and distant ones cluster randomly. The consequence is brutal: the distance-based neighborhoods that the algorithm depends on become unreliable. You can't tell which variable nudges which because the signal is buried.

A beginner might try to filter the noise away, or use more history. But filtering removes detail and history just stacks more noise. The real problem is structural: a single noisy view of a multidimensional system can't faithfully capture which points should actually be neighbors.

The core trouble. A noisy snapshot of a system's past states doesn't preserve which points should be neighbors, so distance-based causal discovery fails.

The algorithm as a flow

What it actually does

Train a global embedder

Feed the full multivariate signal (all variables together) into a neural network, which learns which points should be neighbors.

Train a delay embedder

Feed only time-lagged history (the classic stack) into a smaller neural network.

Match the neighborhoods

Measure which points are close in each embedding, then nudge the delay embedder so its neighborhood pattern matches the global embedder's.

Apply cross-mapping

Use the corrected delay embedder's output to discover causation, now with reliable neighbor information.

Discover causation

Points that are neighbors in the cleaned embedding yield true causal links, not noise correlations.

What the paper changes

What the method changes

TopoDistill changes how the delay embedder (the small network that stacks history) produces its output. Instead of passively stacking raw values with all their noise corruption, it actively learns a transformation that aligns its neighborhood structure to the cleaner, fuller view seen by the global embedder.

the object it moves  =  Delay embedder output
The hidden quantity

The hidden quantity: Neighborhood Alignment

measured quantity  =  Neighborhood Alignment

Neighborhood Alignment is a measure of how well the close points stay close between two different embeddings. Imagine two maps of the same city at different scales: the global embedder is a satellite view, the delay embedder is a street-level photo. Neighborhood Alignment asks: if two streets are neighbors in the satellite view, are they also neighbors in the street photo? If yes, the maps are well-aligned.

TopoDistill estimates this alignment by comparing the K-nearest neighbors (the K closest points) in each embedding. For each point, it finds its K neighbors in the global embedding and its K neighbors in the delay embedding, then measures how much they overlap. A high overlap means neighborhoods match; low overlap means they diverge. The paper uses this overlap score as the training signal: it nudges the delay embedder's weights until neighborhoods align.

Why it works

Why aligning neighborhoods fixes causation discovery

The core mechanism: convergent cross mapping discovers causation by asking 'if I know the neighborhood of a point in variable A's history, can I predict the current state of variable B?' This only works if neighborhoods are honest. Noise breaks neighborhoods by scattering points that should be close. TopoDistill heals this by forcing the delay embedder to align its neighborhoods to the global embedder, which sees all variables at once and thus knows which points actually belong together. When neighborhoods are aligned, the algorithm can reliably say 'these two history-points are close because they represent truly similar system states, not random noise,' and therefore 'if A's history predicts B, then A causes B.' Without alignment, that claim is unreliable.

Why the global embedder is stronger: it trains on the full multivariate signal (all variables together), so it naturally learns a space where points that should be neighbors actually are neighbors in physical causality. The delay embedder, by contrast, only sees stacked history of individual variables and must guess which points belong together from fragments. By distilling the global embedder's knowledge into the delay embedder, the method transfers this understanding down, making the smaller model's neighborhoods match reality even when trained on partial information.

The distillation objective

First in words:

Loss equals a mismatch penalty between the K nearest neighbors in the global embedding and the K nearest neighbors in the delay embedding, summed over all points.

Then the compact form:

L_distill = sum_i L_alignment(NN_global(x_i), NN_delay(x_i))

Every symbol:

L_distilltotal training loss for the delay embedder
x_ithe i-th point in the time series (stacked history at moment i)
NN_global(x_i)the K nearest neighbors of x_i in the global embedding space
NN_delay(x_i)the K nearest neighbors of x_i in the delay embedding space
L_alignmenta penalty function that counts mismatches between the two neighbor sets
A tiny worked example
Imagine a time-series point x_5 (history at moment 5).
Global embedder says x_5's 3 nearest neighbors are: x_3, x_7, x_9 (confidence: they are close in the full system view).
Delay embedder initially says x_5's 3 nearest neighbors are: x_2, x_5, x_8 (a noisy guess).
Overlap: only x_5 appears in both lists, so overlap = 1 out of 3.
L_alignment for x_5 = penalty for (3 - 1) = 2 mismatches.
The delay embedder's weights are nudged to change x_5's embedding so that x_3, x_7, x_9 move closer.
After training, delay embedder says x_5's neighbors are: x_3, x_7, x_8 (now overlap = 2, penalty shrinks).
After many updates, delay embedder converges: x_5's neighbors match the global view almost perfectly.

The loss pushes the delay embedder to rotate and scale its output space so that neighborhoods match what the global embedder learned.

What can go wrong

What can go wrong

Global embedder overfits to a small dataset. If the multivariate time series is short, the global embedder might memorize noise instead of learning which points should be neighbors. The distilled delay embedder then learns corrupted neighborhoods. Solution: regularize the global embedder or use a larger dataset.
Mismatch between global and delay embedder capacity. If the delay embedder is too small, it cannot even learn to match the global embedder's neighborhoods, no matter the training signal. Neighborhoods stay misaligned. Solution: increase the delay embedder's hidden layer size.
Non-stationary time series (the rules change over time). If the system's causal structure shifts over time (e.g., a valve opens halfway through), the global embedder learns a blended, confused view of which points should be neighbors. Distillation then teaches the wrong neighborhoods. Solution: split the data into stationary windows.
Done right: clean neighborhoods, honest causality. When the embedders are well-matched and the data is stationary, neighborhoods are stable and cross-mapping reliably identifies causal links even under significant noise.

Apply convergent cross mapping with classic time-delay embedding versus TopoDistill. Plot these as noise level increases from 0 to 50 percent. The demo should show that classic time-delay embedding's true positive rate crashes as noise rises (because neighborhoods scatter), while TopoDistill maintains high true positive rate and low false positive rate across all noise levels.
