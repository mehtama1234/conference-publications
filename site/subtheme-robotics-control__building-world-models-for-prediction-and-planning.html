Building world models for prediction and planning

Papers teaching robots to predict what will happen next in their environment and use those predictions to plan better actions—world models learn to simulate the physics of the scene.

What this is

A robot that can predict the future is much more capable than one that can only react to the present. If a robot pushes a block and can predict that it will slide across the table and fall off the edge, it can decide not to push so hard. If a robot predicts that a person will step into a crosswalk, it can brake preemptively. These predictions require a model of the world—an internal simulation of physics. The robot learns from experience: it watches what happens when it takes actions, and it builds a model that says 'if I push with force F at angle Θ, the object will move in direction D.' With such a model, the robot can reason about future outcomes without actually trying them.

The difficulty is that the world is complex and physics is hard. Real friction varies with materials and temperature. Objects deform in complicated ways. Multiple objects interact—one block hits another and they both move. Liquids splash and flow. Hair tangles. Cloth wrinkles. Simulating all of this requires detailed knowledge of material properties and numerical stability. Also, the robot's model is always incomplete and approximate. It sees the world through limited sensors. It does not know the exact mass of an object or the coefficient of friction. So the model is inherently uncertain, and that uncertainty grows as you predict further into the future, because small mistakes compound when you apply them repeatedly step by step. Errors compound—a small mistake about where an object is now becomes a large mistake about where it will be in five seconds.

Papers build world models using learned physics simulators—neural networks that predict the next state given the current state and an action. Some train these models on real robot data and in simulation, then use them for planning: the robot imagines taking different actions and uses the model to predict which one will succeed. Some use world models for control: instead of learning a direct mapping from observation to action, the robot learns a model and a separate 'imagination' module that uses the model to think about future actions. Some combine world models with other components: perception (estimate current state), world model (predict future states), reward model (evaluate which state is best), and planning (search over actions to find one that leads to good future states), so that all parts work together to make decisions. The goal across all these approaches is to give the robot the ability to think ahead.

How the work breaks down

Building world models breaks into two main directions: making the predictions visually stable and spatially correct (so the robot can trust what it imagines), and using those predictions to plan real actions that work in manipulation and driving. The challenge is that video-based predictions easily drift and become inconsistent across viewpoints, and planning with them requires the model to output actions the robot can actually execute.

Visually consistent predictions for manipulation

When a robot watches a video of itself pushing objects, the pixels jump around as the camera angle shifts or the prediction drifts slightly. If the robot's world model produces shaky, inconsistent videos, the robot can't trust what it predicts about where the object actually is. The deeper problem is that 2D pixels don't tell you the real 3D shape and position of things—they're just a projection. Two different viewpoints of the same scene will look different in pixel space, so a model trained to predict pixels gets confused when the camera moves.

The video generation paper tackles this by predicting actual 3D coordinates and shapes of objects, not just 2D pixels. It learns where objects will be in 3D space and what they will look like, then renders that prediction from any camera angle. This way, when the viewpoint changes, the prediction stays consistent because it's built from real 3D positions, not flickering pixels. The structured latent model goes further by learning to separate objects and their 3D properties (shape, position, orientation) explicitly. This makes predictions easier to interpret and means errors don't cascade—if the model gets one object's position slightly wrong, it doesn't corrupt the entire scene. Both papers show that learning actual 3D positions and shapes, rather than just predicting pixels, produces predictions that work across multiple cameras, which matters because real robots have several cameras and need to reason about scenes consistently.

Connecting predictions to robot actions

Predicting the future is only useful if you can use those predictions to decide what to do. The MoLA paper addresses a practical problem: the robot's action space—the set of moves it can make—is often complex and has structure. A robot manipulating objects might push with different forces, angles, and speeds, and these naturally cluster into patterns. If the world model has to output a single best action, it might miss the diversity of good solutions.

MoLA learns a mixture of action options from data—it discovers multiple ways to accomplish the same task. When planning, it doesn't commit to one action prediction; instead, it keeps multiple hypotheses alive and uses the world model to evaluate which action patterns lead to success. This matters because there are often several good ways to achieve a goal, and a smart robot should consider multiple possibilities rather than committing to the first one, because committing too early to a bad action wastes time and fails the task. The paper shows this approach improves both accuracy (the robot picks actions that actually succeed because it can choose the best from multiple options) and generalization (it works on new tasks and objects it hasn't seen, because by learning the underlying diversity of good actions rather than just one, the model captures generalizable patterns).

World models for autonomous driving

Driving is a long-horizon task where mistakes early in the prediction compound massively by the time you reach the goal. A car that slightly misjudges a turn might crash blocks away. The challenge is that driving requires reasoning about many possible futures—other cars might brake, pedestrians might step into the road—and the world model must capture uncertainty.

DeepSight addresses this by learning to predict long sequences of future states (positions, velocities, occupancy) in latent space—a compressed numerical representation learned by the model—rather than pixels. This lets the model avoid accumulating pixel-level drift and instead focuses on the information that actually matters for driving: where objects will be. The model doesn't predict pixels, so it doesn't get distracted by lighting changes or irrelevant details. MVISTA-4D takes a different angle by building consistent 4D worlds (space plus time) from multiple camera views and then inferring what action the robot should take to match that predicted future. It learns to separate the world's behavior from the robot's control, so when planning, it can search over actions to find ones that steer the predicted world toward the goal. Both papers handle the long-horizon nature of driving by structuring their predictions to remain coherent over many steps.
