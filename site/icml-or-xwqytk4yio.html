LIF Recurrent Memory Enables Long-Horizon Spiking Computation

A simple architecture lets spiking neural networks hold information over long time steps by using a few neurons as a memory circuit that the network learns to control.

Paper explainersAll themesRobotics & Control

Spiking neural networks are models that compute with discrete electrical pulses instead of continuous numbers, making them much more power-efficient. But they struggle to remember information across many time steps, because their internal storage (called the membrane potential) decays away naturally over time. This paper solves that by building a learnable memory circuit from simple neurons, which the network can switch on and off to retain what matters.

Zero assumption version

Why spiking networks leak information

A spiking neural network is a model where neurons fire electrical pulses at discrete time steps. Between pulses, each neuron has an internal voltage (membrane potential) that decays naturally over time. When you process a long sequence (like speech stretched across many frames), earlier information encoded in membrane voltages gradually disappears.

A beginner might try adding a neuron with a larger voltage decay so it forgets more slowly. But this creates a new problem: during training, you compute how to adjust the network weights by calculating gradients (which way to nudge each number to shrink errors). With slow decay across many steps, the gradient signal becomes vanishingly small by the time it reaches early time steps — it is like shouting into a canyon and hearing only silence by the end. The network learns almost nothing about what to do at the start of the sequence.

The core fix. Build a small circuit of neurons that acts as a memory, and let the network learn when to write to it, reset it, and read from it.

The algorithm as a flow

What it actually does

1. Normal spiking neurons process the input

At each time step, neurons compute pulses based on their membrane voltages.

2. A few neurons form the memory circuit

These special neurons have slightly longer memory than regular ones and sit in a tight feedback loop.

3. Recurrent connections reach back to the circuit

The rest of the network sends control signals (write/reset/read gates) to the memory circuit.

4. The circuit stores or forgets selectively

The control signals tell it when to hold a value stable and when to reset it.

5. Later neurons read from the stable memory

They use the preserved information to make accurate predictions even far into the sequence.

What the paper changes

What changes: the memory circuit

Instead of asking individual neurons to hold information, the paper builds a dedicated micro-circuit (a cluster of neurons that all feed into each other) that acts as the network's scratch pad. The rest of the network sends recurrent connections to this circuit — global feedback signals that say write this, hold that, or erase now.

The hidden quantity

The hidden quantity: sustained membrane voltage

measured quantity  =  Stable voltage in the memory circuit

The core quantity the paper exploits is the membrane voltage stored in the memory circuit neurons. In a normal neuron this voltage leaks to zero. In the memory circuit, it persists — the feedback loops and carefully tuned decay constants let earlier neural outputs (the firing patterns) stay alive even after many time steps.

The paper estimates this by measuring how much information from early in the sequence survives to time step 200 or 300. If voltages decay too fast, that information is lost. The paper's memory circuit keeps voltage levels stable by using recurrent feedback to periodically reinforce stored values, so the network's downstream layers can extract what they need.

Why it works

Why the architecture works: stable storage plus adaptive control

In a normal spiking network, each neuron decays independently, and training signals shrink as you trace backward through many time steps. The memory circuit fixes both problems at once.

First, the circuit neurons are wired into a tight loop where their outputs feed back into their own inputs. This recurrence keeps information circulating: a neuron's voltage does not decay to zero; instead, the recurrent loop reinforces it periodically. The neuron stays excited longer than it would alone.

Second, the rest of the network sends global control signals (routed through recurrent connections) to the memory circuit. These signals act as write/hold/read commands. When the network detects that an input symbol matters, it tells the memory circuit to hold onto it. When the symbol is no longer useful, it tells the circuit to reset. This selectivity ensures that only relevant information occupies the limited memory space.

Together, these two properties solve the leakage problem. The circuit holds information. The adaptive gates let the network decide what to store. And because the circuit has fewer, simpler neurons than alternatives like ALIF (adaptive leaky integrate-and-fire), it runs much faster and works better on real hardware.

Math after the picture

The memory voltage equation

First in words:

At each time step, a memory neuron updates its voltage by combining a decay of the old voltage, the input spike, and feedback from recurrent connections.

Then the compact form:

V_mem(t) = alpha * V_mem(t-1) + I_in(t) + recurrent_feedback(t)

Every symbol:

V_mem(t)Membrane voltage of memory neuron at time t
V_mem(t-1)Membrane voltage at the previous time step
alphaDecay constant (between 0 and 1; close to 1 means slow decay)
I_in(t)Input spike signal at time t
recurrent_feedback(t)Control signal from rest of network (write/hold/reset command)
A tiny worked example
Time 0: V_mem = 5, alpha = 0.9, I_in = 1, recurrent_feedback = 0. Then V_mem(1) = 0.9*5 + 1 + 0 = 5.5.
Time 1: V_mem = 5.5, alpha = 0.9, I_in = 0, recurrent_feedback = 2. Then V_mem(2) = 0.9*5.5 + 0 + 2 = 6.95.
Time 2: V_mem = 6.95, alpha = 0.9, I_in = 0, recurrent_feedback = 0. Then V_mem(3) = 0.9*6.95 + 0 + 0 = 6.26.
Without recurrent feedback, voltage would decay 5 -> 4.5 -> 4.05. With control signals (2.0 at time 1), it stays around 6 instead. That is how selective memory works.

Slow decay (alpha near 1) and recurrent feedback together keep the voltage stable; the network learns to send big control signals only when it needs to store something.

What can go wrong

What can go wrong

Circuit decays too fast. If alpha is too small, the memory circuit decays like any normal neuron, and you lose the benefit. The network must learn to keep alpha high enough.
Recurrent gates malfunction. If the network learns to send constant write signals or never send reset, the memory circuit becomes useless — either stuck or overflowing. Training must balance exploration and control.
Circuit neurons interfere with main computation. If the memory circuit is too tightly wired to the rest of the network, their dynamics can oscillate or amplify noise. Circuit neurons must be somewhat isolated.
Done right. The network learns to send brief, targeted control signals: write when an input symbol arrives, hold while processing, and reset when done. The memory circuit stays stable because recurrent feedback reinforces voltages, and it speeds up training because strong training signals propagate backward through time rather than shrinking to zero.
What a runnable demo should prove

What a runnable demo should prove

Build a spiking neural network with the memory circuit and train it on a synthetic long-sequence classification task. For instance, generate a sequence of 300 time steps, hide a random digit somewhere in the middle, and add noise to all other frames. The network must remember the digit and output it at the end. Compare three versions: (1) a plain spiking network with no memory circuit, (2) spiking with the memory circuit, and (3) a standard LSTM.

Accuracy = number of correct digit predictions / total trials

The memory circuit version should classify the digit nearly perfectly (above 90%) even with the digit buried 200+ steps back, while the plain spiking network collapses to random guessing and the LSTM works but uses vastly more power.
