Tensor learning with orthogonal, Lorentz, and symplectic symmetries

Neural networks that respect the hidden symmetries of tensor data learn faster and with fewer examples because they do not waste effort on solutions that disagree with those symmetries.

Paper explainersAll themesGraph & Geometric Learning

Many real-world datasets have built-in symmetries: spinning an object does not change its physics, rearranging time steps preserves the pattern in a time series, and swapping rows in a material's structure keeps the material's properties the same. Standard neural networks ignore these symmetries and learn them painfully from scratch. This paper shows how to build networks that automatically respect three important types of symmetry (orthogonal, Lorentz, and symplectic) so they work directly with tensors (multi-dimensional arrays of numbers) from materials science, time series, and theoretical computer science without learning the obvious.

Zero assumption version

The wasted effort problem

A neural network is a machine that learns by tweaking millions of numbers (called weights) to turn input data into correct answers. For simple datasets like photographs, this works well: the network gradually learns that certain pixel patterns mean 'cat' and others mean 'dog'. But many scientific datasets have built-in patterns that any correct answer must follow. For example: if you rotate an object in 3D space, its physical properties do not change. If you record the same time series twice but with different gaps between readings, the temporal structure stays identical. A standard network treats each rotation or time-rescaling as a completely new case, wasting effort learning the same pattern over and over.

A beginner might think: 'Just give the network more examples!' But that does not work well. The network has to discover from the examples themselves that rotating data should give the same answer — it must stumble through thousands of failed attempts before grasping this constraint. This is like asking someone to learn a language by trial and error instead of being told the grammar rules upfront. For tensors especially (multi-dimensional arrays), the search space is vast, and a network without symmetry guidance gets lost.

In one sentence. The paper builds networks that are forced to respect symmetries from the start, so they learn the actual task faster instead of re-discovering symmetries over and over.

What it actually does

Identify the symmetry

Recognize that the function you are learning respects a mathematical group (rotation, time-rescaling, or a symplectic transformation).

Build layers that preserve it

Design each network layer so that applying the symmetry to the input gives the same answer as applying it to the output: no contradictions allowed.

Combine with path signatures

For time series, layer in path signatures (a technique that records the shape of a curve without caring when you traverse it), which are automatically invariant to reparameterizations.

Train on tensors directly

The network learns on high-dimensional tensor data (materials, time sequences, structured data) without wasting capacity learning symmetries.

Measure improvement

Compare accuracy and sample efficiency: how many examples does the symmetry-aware network need versus a standard network?

The hidden quantity

Equivariance: the hidden quantity

measured quantity  =  Equivariance (how much symmetry is preserved)

Equivariance is a technical term that means: if you apply a transformation (spin, time-rescale, or a symplectic change) to the input, the output transforms in exactly the same way. It is different from invariance, which means the output does not change at all. A good equivariant network respects this property exactly: you cannot confuse it by applying symmetries. The paper measures equivariance by checking whether the network's learned weights obey mathematical constraints that force this property to hold.

The paper uses three types of equivariance: orthogonal (rotations and reflections in physical space), Lorentz (transformations that keep spacetime measurements consistent, used in physics when velocities are close to light speed), and symplectic (transformations that preserve the structure of energy and momentum, needed for Hamiltonian systems like planetary motion). For time series, it adds path signature invariance, which automatically stays the same no matter how you reparameterize the timeline.

Why it works

Why it works: the deep reason

A standard neural network treats each input as an independent puzzle. If you feed it a tensor and then feed it the same tensor rotated, the network cannot automatically see they are related — it has to learn from examples that rotation should not change the answer. This is inefficient because the network's weights get tuned for one orientation, then re-tuned for another, with no coordination.

The symmetry-aware network solves this by restricting which weights are even allowed. Instead of giving the network full freedom to learn anything, the paper bakes in mathematical constraints: certain weight combinations must relate in specific ways (dictated by the symmetry group). When you rotate the input, the constraints force the output to rotate in exactly the same way — this is not something the network learns, it is something the constraints guarantee. The benefit is twofold: (1) the network starts out respecting symmetries, so it never wastes effort learning obvious relationships, and (2) because the constraints reduce the space of possible solutions, the network converges faster and needs fewer training examples.

For time series, the paper combines this with path signatures: a technique that reads a sequence of points and records its shape in a way that does not depend on the time reparameterization (whether you recorded it in seconds or microseconds, the signature is the same). This layers invariance on top of equivariance, so the system stays the same no matter how densely you sample the data.

The equation: equivariant layer structure

First in words:

An equivariant layer computes output equals a weighted combination of symmetry-respecting basis functions applied to the input, where the weights themselves are constrained to preserve the group structure.

Then the compact form:

output_i = sum_j c_j * basis_j(g · input), where g is a group element and c_j are constrained weights

Every symbol:

output_ithe i-th component of the output tensor
sum_j c_jsum over basis functions, weighted by coefficients
basis_jorthonormal basis functions that are equivariant to the group action
g · inputthe input transformed by group element g (e.g. rotation by angle theta)
c_jlearned coefficients, constrained so that swapping g does not break the output
A tiny worked example
Suppose we have a 2D vector (x, y) and want rotation equivariance (group is SO(2), 2D rotations).
Standard approach: learn weights w1, w2, w3, w4 freely, compute output = w1*x + w2*y and output2 = w3*x + w4*y. If you rotate input 45 degrees, the network cannot guarantee output rotates 45 degrees — you have to learn it.
Equivariant approach: force w1 = w4 and w2 = -w3. This constraint ensures: if input rotates, output rotates by the same amount. Now the network's degrees of freedom are slashed (4 free weights -> 2 free weights), and it never contradicts itself.
Result: network converges faster because it is not exploring contradictory weight solutions.

The constraint that weight combinations respect the group ensures: applying a symmetry to the input gives an output that is transformed by that same symmetry, not something different.

What can go wrong

What can go wrong

Wrong symmetry group chosen. If you assume the data respects rotation but it actually respects reflection, the network will enforce the wrong constraint and perform worse than a standard network. The symmetry must match the real structure of the problem.
Overly restrictive constraints. Some problems have partial or approximate symmetries, not exact ones. Baking in a hard symmetry that only mostly holds will limit the network's flexibility and hurt accuracy.
Scalability to very large tensors. Computing the group action and building the basis functions is expensive for high-dimensional tensors. For very large data, the overhead can outweigh the benefit.
Done right. When the symmetry truly matches the data (materials with crystal structure, time series with reparameterization invariance, physics governed by conservation laws), the constrained network learns in a fraction of the time and generalizes to symmetric variants it has never seen.
What a runnable demo should prove

What a runnable demo should prove

Build a minimal example: take a dataset with known symmetry (e.g. a small set of 2D shapes that are invariant to rotation, or a time series that is invariant to time-rescaling). Train two networks side by side: one standard, one constrained with the correct symmetry group. Measure three things: (1) how many training examples does each network need to reach 90% accuracy, (2) how does each network perform on rotated/reparameterized variants of the test set that it has never seen, and (3) how many training steps (gradient updates) does each need?

sample_efficiency = (samples_needed_standard - samples_needed_equivariant) / samples_needed_standard; generalization_gap = accuracy_standard_on_symmetry_variant - accuracy_equivariant_on_symmetry_variant

The demo should make it impossible to miss: the symmetry-aware network reaches high accuracy with far fewer examples and generalizes gracefully to symmetries it has never explicitly seen.
