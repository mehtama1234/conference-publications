Learning from unlabeled data without labels

Papers use contrastive learning and self-supervised methods to train models on large unlabeled datasets by predicting parts of the data from other parts, avoiding the need for expensive manual labels.

What this is

The core insight is simple in concept but tricky in practice: if you have a piece of data, you can treat parts of it as a learning signal for other parts. Imagine a video — you hide one frame and train the model to predict it from the surrounding frames. Or an image where you mask out part of the picture and train the model to fill it in. These proxy tasks create a supervisory signal without any human having to label anything. The model learns to encode visual structure, temporal dynamics, or context because it needs those patterns to solve the reconstruction task.

The challenge is that proxy tasks can be gamed. A model could learn to predict masked pixels by memorizing local texture patterns without understanding objects or scenes. Researchers have discovered that contrastive methods work especially well: show the model two slightly different versions of the same image (by cropping, color shifting, rotating), and teach it that their representations should be similar, while random different images should be dissimilar. This forces the model to capture stable, semantic features rather than superficial details. But even this requires careful tuning — the temperature of the similarity comparison, the size of the batch, whether you use a memory buffer of past examples — all of these affect what the model learns.

Across the 115 papers in this subtheme, researchers explore variations: different proxy tasks (masking, contrastive, rotation prediction, clustering consistency), different architectures (CNNs, vision transformers — neural networks designed to process spatial images — and multimodal encoders), and different ways to combine tasks. Some papers ask whether you need pretraining at all versus just training on downstream tasks, or whether combining self-supervised pretraining with a small amount of labeled data beats either alone. The practical impact is large: models pretrained this way now outperform supervised learning on many benchmarks when downstream labels are scarce, because they have already discovered the foundational patterns in unlabeled data that don't require manual annotation.

How the work breaks down

The papers in this subtheme split along five natural lines because each tackles a different pressure point in self-supervised learning. First, papers improve the core contrastive learning machinery itself by finding better ways to construct negative pairs or sample data. Second, papers explore alternatives like masking or prediction, which simplify the machinery by eliminating the need for negative pairs. Third, papers apply self-supervised methods to specialized domains like audio, medical imaging, or video, because generic methods often fail when domain structure is different. Fourth, papers explain theoretically why these methods work at all, since the mechanisms are not obvious. Fifth, papers focus on making the methods faster or more memory-efficient, which matters because pretraining consumes weeks of GPU time.

Contrastive learning fundamentals and improvements

Contrastive learning is the workhorse of this subtheme: you show the model two slightly different views of the same data and train it to see their representations as similar, while different data should have different representations. The challenge is subtle: the model could solve this by ignoring all the details and outputting a constant, or it could learn to memorize surface-level patterns like texture. The papers here tackle the core question of which design choices matter and how to make the method work better, because small changes to the loss, sampling strategy, or batch construction can dramatically shift what the model learns.

The foundational theory paper on contrastive learning with natural images explains that optimal representations form sinusoid patterns whose frequencies can be computed mathematically; real neural networks trained with standard steps (gradient descent) actually learn these patterns, connecting theory to practice. Better Audio Transformer (BAT) achieves top performance by improving the preprocessing and pretraining recipe, showing that even small architectural choices compound. A paper on how probability conversion—called softmax, a technique that turns raw scores into probabilities—breaks at extreme values and fixes this numerical problem that causes InfoNCE (a contrastive loss) to underperform; the fix requires no extra learnable parts, yet consistently improves downstream tasks across vision benchmarks. Data Augmentation of Contrastive Learning explains augmentation (the random crops, color shifts, rotations) through a mathematical lens: effective augmentations can be learned by treating them as a noise generator, grounding the intuition that not all augmentations help equally. These papers form a progression: theory explains what works, then practice finds the technical gotchas and fixes them.

The Loss Is Not Enough explains that the loss function alone does not determine what a model learns; the batch composition and the encoder's architectural bias (which features it is predisposed to capture) matter equally because the full system, not just the loss, shapes what gets learned. Together, these papers show contrastive learning requires careful orchestration across loss, architecture, data sampling, and batch composition because each piece interacts with the others.

Masked modeling and shared prediction

An alternative to contrastive learning is masked modeling: hide part of the input and train the model to predict it. This sidesteps the need to construct positive pairs (two views of the same image) and negative pairs (different images), so it simplifies the machinery. The trade-off is that prediction tasks can be simpler than contrastive tasks—a model could learn to fill in masked pixels by memorizing textures without understanding objects. The papers here explore how to make prediction work as well as contrastive methods and what makes it fundamentally different, because understanding when each approach wins guides algorithm choice.

Rethinking JEPA (Joint-Embedding Predictive Architecture—a framework where a model predicts abstract representations of parts of the input from other parts) improves on V-JEPA by using frozen teacher networks instead of exponential moving averages, achieving better performance at the same compute cost and showing that students work well even with low-quality teachers because frozen networks reduce drift. Text-Conditional JEPA combines masked prediction with text supervision: instead of hiding parts of an image, the model learns from natural language describing it, which improves stability and scaling properties compared to pure contrastive methods because the text signal is richer and less ambiguous than visual analogs. Rectified LpJEPA learns sparse, non-negative representations (like a neural network with ReLU units that only output when activated) while maintaining the benefits of this joint prediction framework, achieving favorable tradeoffs between sparsity and performance because sparse models consume less memory and compute. Together, these papers show that prediction methods can match or exceed contrastive approaches, especially when combined with auxiliary signals like language or when targeting specific representation properties like sparsity because auxiliary signals and specific constraints guide learning.

Across this group, the main insight is that the task design matters less than once thought—what matters is ensuring the model must capture semantic structure to solve the task at all.

Domain-specific and multimodal self-supervised learning

Self-supervised methods were developed mostly on photographs (ImageNet), but real applications span audio, video, medical imaging, 3D point clouds, EMG signals from wearable devices, and more. The challenge in each domain is that the proxy task must exploit domain-specific structure without relying on labels. In audio, you might predict future frames from past frames, exploiting temporal continuity. In 3D point clouds, you exploit the fact that slightly perturbed copies of the same scene should have similar structure even when viewed from different angles. The papers here show how to adapt the core ideas to diverse modalities.

Animal behavioral analysis with transformer-based pretraining learns representations from unlabeled animal videos by predicting pose (where body parts are) and actions (what the animal is doing) jointly; this works across species because the proxy tasks exploit motion and structure that all animals share. AVEX combines self-supervised pretraining on animal vocalizations with supervised refinement on mixed bioacoustics plus general audio, showing that the two stages are complementary: pretraining on large unlabeled collections finds general sound patterns because diversity teaches the model to generalize, and supervised tuning adapts to a specific domain by focusing on the most useful patterns. AudioMosaic does contrastive masked audio representation learning, showing that audio models pretrained this way transfer across datasets and even domains better than generic audio models because domain-specific structure teaches richer features. The wireless signal recognition model (TS-DDAE) pretrains on raw signal data using a diffusion-based denoising autoencoder (a model that learns by first adding noise to signals then predicting how to remove it), achieving superior performance on downstream wireless signal classification because denoising forces the model to capture the signal structure. Multimodality as Supervision tests whether learning from raw multimodal data in the target environment (e.g., video clips from a specific city) beats pretraining on generic internet data (CLIP, DINOv2); it does, showing that domain-specific unlabeled data often outweighs generic pretraining at scale because local patterns are more specific than global ones. 3D point cloud representation learning (CLAP) handles geometric structure by learning representations that work well whether the view changes or the sensor is different, so models trained on one lidar type transfer to others because viewpoint-invariance requires understanding the actual 3D shape and structure. These papers share a theme: identify the structure unique to each domain, build a proxy task that exploits it, and the model learns richer representations than any generic approach.

The consistent finding is that domain-adapted SSL outperforms generic pretraining, especially when unlabeled data from the target domain is available, because domain-specific structure teaches faster and more efficiently than generic structure.

Theory and understanding of self-supervised learning

Theory papers ask: Why does self-supervised learning work? What causes collapse (the model outputting the same representation for everything)? How do contrastive and supervised learning relate? These questions matter because they guide which methods to try and where problems will arise. They also connect high-level mathematical intuitions to practical engineering choices.

Difficult Examples Hurt Unsupervised Contrastive Learning shows counterintuitively that removing hard examples from the training set increases downstream classification performance despite reducing sample size; this suggests contrastive learning relies less on diversity and more on signal clarity because clean signals teach faster than noisy signals. Dual Perspectives on Non-Contrastive Self-Supervised Learning proves that without a stop gradient (a technique that prevents weight updates from flowing backward to one copy of the network), non-contrastive methods always collapse because both copies converge to the same trivial solution; it characterizes the stable equilibria mathematically, connecting discrete optimization to geometric stability. On the Alignment Between Supervised and Self-Supervised Contrastive Learning finds that as scale increases, self-supervised and supervised contrastive learning representations become more aligned, even though the weights themselves diverge exponentially; the actual learned patterns are more stable than the underlying numbers because scale forces both methods toward the same high-level structure. Self-Soupervision mixes multiple SSL algorithms (masked autoencoders, momentum contrast, JEPA, others) into a single model by averaging their weights, and the mixture works better than any single ingredient because ensemble effects cancel out idiosyncratic failures. Understanding the Learning Phases in Self-Supervised Learning via Critical Periods identifies that SSL models have critical periods where intermediate checkpoints generalize better to new domains, while longer pretraining benefits accuracy on the original domain; this guides when to stop pretraining for specific downstream tasks because early stopping trades in-domain performance for out-of-domain generalization. A paper on how distributed self-supervised learning performs when data is non-uniform shows that masked image modeling degrades more gracefully than contrastive learning when data is heterogeneous (not identically distributed—meaning some nodes have imbalanced or skewed data—across nodes in federated learning), informing algorithm choice for distributed settings because masking is less sensitive to data shifts. Together, these papers demystify why the methods work and identify failure modes so that researchers can infer better algorithm design from understanding the mechanisms.

Across this group, the main insight is that self-supervised learning succeeds not because of any single component but because the combination of task, architecture, and sampling jointly forces the model to encode semantic structure, so understanding the whole system informs better algorithm design.

Efficiency, scaling, and practical optimization

Self-supervised learning is expensive: pretraining large models on billions of unlabeled images takes weeks on clusters of GPUs. The papers here tackle how to make it faster, use less memory, or maintain quality with fewer examples. One approach is to make the representation itself sparse (most dimensions are zero), which cuts compute because empty dimensions waste memory and computation. Another is to improve the data augmentation or batch construction so fewer iterations suffice because smarter sampling learns from fewer steps. A third is to design better scaling laws so researchers can predict performance before running expensive experiments because prediction avoids wasted runs on bad hyperparameters. Across all approaches, efficiency often reveals fundamental insights about what the model truly needs.

CSRv2 reduces dead neurons (dimensions the model never activates) from 80% to 20%, dramatically improving sparsity; with just two active dimensions per sample, it achieves 14% accuracy gain while delivering 7x speedup and up to 300x improvements in memory efficiency because fewer active dimensions means less data to store and compute. MoRA learns geospatial representations at scale by using mobility (human movement patterns) as the proxy task; it achieves 12.9% improvement on nine downstream tasks and demonstrates reliable scaling behavior because real-world structure in the domain trains better representations. Learning Sparse Visual Representations via Spatial-Semantic Factorization shows that as few as 16 sparse dimensions (selected features) capture both high-quality image reconstruction and strong semantic transfer to classification, revealing that most dimensions in standard representations are wasteful because only a few dimensions carry the important information. NeuCLIP improves CLIP training at scale by better estimating the normalization term that keeps loss values in a reasonable range; this matters most on billions of samples where numerical precision degradation compounds because accumulated numerical errors corrupt gradients. Procedural Pretraining warms up language model training with abstract, synthetic procedural data before switching to natural text; this achieves the same final loss with 55% to 86% of the original training data because procedural data teaches the model to generalize before seeing real data. Together, these papers show that efficiency gains come from understanding bottlenecks: redundant dimensions, naive batch construction, and numerical stability. Removing them can yield 10x to 100x speedups because each bottleneck compounds.

Across this group, the theme is that efficiency work is not just engineering—it often reveals insights about what the model actually needs to learn.
