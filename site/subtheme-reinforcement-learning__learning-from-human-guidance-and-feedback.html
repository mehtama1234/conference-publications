Learning from human guidance and feedback

Teaching agents by showing them examples of good behavior or asking them to prefer one action over another, without needing to specify rewards.

All themesField mapMathematicsAll explainers
What this is

Sometimes you don't have a clear reward signal. How much should a robot value a gentle grip versus a secure grip? There is no number for 'good behavior.' But humans can show it. Watch a human pick something fragile, and a robot can learn the pattern: 'this is the gentle motion I should copy, because humans use it for delicate objects.' Or ask a human to pick between two proposed actions — 'I prefer this one' — and the robot learns: 'that action is better than that one, so I should do more of it.' This is learning from human guidance, and it sidesteps the problem of having to define a reward function by getting the reward signal from human choices instead.

The challenge is that humans give noisy feedback. People make mistakes, get tired, and explain things differently. A robot watching a human might learn the wrong thing if the human was having a bad day. And if the human is being asked to choose between hundreds of options, they won't have time. Papers in this area use techniques like inverse reinforcement learning — figuring out what reward function the human must be optimizing for by watching their choices — or preference learning, where humans rank a small number of options and the system infers a reward model from those rankings.

This approach is important because it lets humans shape behavior without having to write a formula. A company can refine an AI system's decisions by saying 'I like this approach better' without explaining why. A robot learns collaborative tasks by watching and learning what partners prefer.

How the work breaks down

Learning from human feedback splits into five main directions because different problems call for different solutions. Imitation learning copies human demonstrations because that is the most direct signal—watch and repeat. Offline reinforcement learning with preferences collects human rankings because asking people to compare is easier than asking them to score. Combining reward signals with verification catches errors because some feedback is verifiable (math problems have right answers) and some isn't, so both matter. Improving data efficiency through better use of limited examples matters because human feedback is expensive to collect. Adversarial and co-training methods learn what humans optimize for because hidden patterns in choices reveal deeper goals than any single rating can.

Adversarial imitation learning from demonstrations

Adversarial imitation learning has a fundamental problem: when an agent watches human demonstrations, it can easily misunderstand the goal. The agent might copy irrelevant details (the human wore a blue shirt) instead of the actual skill (how to pick up an object gently). This causes errors that compound over time, as mistakes in one step lead to worse states in the next step. Papers in this group address this by using adversarial training or co-training to figure out what humans actually care about.

Latent Wasserstein Adversarial Imitation Learning works with very limited human data—sometimes just one or a few demonstrations—by learning in a latent space where the agent's behavior and human demonstrations can be compared more fairly. The Wasserstein distance ensures this comparison is stable, so the agent learns the real pattern even from minimal examples. The method achieves expert-level performance on robot control tasks. Near-Optimal Second-Order Guarantees for Model-Based Adversarial Imitation Learning provides theoretical proof that adversarial imitation learning can match the sample complexity of learning from direct rewards, meaning it's just as efficient as having a perfect reward signal written down. Provably Efficient Policy-Reward Co-Pretraining for Adversarial Imitation Learning improves on this by showing that if you pretrain both a policy and a reward model before using adversarial learning, you need fewer expert demonstrations—this co-training approach gives you the best of both worlds. Non-Adversarial Imitation Learning Provably Free of Compounding Errors addresses the core problem directly: instead of using adversarial training, it uses a value-flow mechanism that eliminates the compounding error problem entirely, achieving the same sample complexity as adversarial methods but without the instability of adversarial training.

Imitation learning with data augmentation and augmented representations

A key challenge in imitation learning is that human demonstrations are expensive and limited. Agents need to learn a skill from just a handful of examples, so they must extract every bit of information from each one. Data augmentation—creating more training examples from existing ones—and learning better representations can multiply the value of scarce demonstrations, because they make fewer examples do the work of many.

The return-matching approach tackles this by recognizing that successful imitation is really about matching not just individual actions, but the cumulative rewards that come from those actions. By learning what that reward flow looks like—the set of all possible cumulative values an agent might see—the method extracts more information from each example and requires far fewer demonstrations than standard behavioral cloning. Koopman-Assisted Trajectory Synthesis uses ideas from dynamical systems theory to augment the demonstration data: when you have a few expert trajectories, this method generates new ones by learning patterns in how the state evolves, so you can create more training examples without more human effort. The result is excellent performance even with narrow ranges of expert data. Consistent Zero-Shot Imitation with Contrastive Goal Inference solves a different angle: when you watch a human demonstration, you need to figure out what goal they were trying to reach, because the same action means different things depending on the goal. By using contrastive learning—comparing trajectories to understand which goals are easier or harder to reach—this method recovers what the human actually wanted. Noise-Guided Transport learns from extremely sparse data by treating the imitation problem as a transport problem: moving probability mass from random actions to expert actions. Even with just 20 transitions, this method succeeds on high-dimensional control tasks where data is nearly nonexistent.

Offline preference learning without reward functions

Humans are good at comparing two options—'I like this one better'—but bad at writing down numbers that describe how good a behavior is, so preference learning bypasses this weakness and uses what people are naturally good at. Offline preference learning lets systems train on past human feedback without ever defining a reward function, because you can infer good behaviors from choices rather than scores. The challenge is that human feedback is noisy and can lead the system astray if the learning process isn't careful, so the papers here solve this by being smarter about how comparisons translate to policy improvements, using ranking-based or regret-minimization approaches that tolerate errors better than reward-maximization.

Fine-tuning Behavioral Cloning Policies with Preference-Based Reinforcement Learning shows how to combine two sources of information smartly: start with a behavioral cloned policy learned from human examples, then use preference feedback to refine it. The paper proves theoretically that this two-stage approach needs less data than using either source alone, because the demonstrations anchor the policy near good behavior while preferences fine-tune it. A Regret Minimization Framework on Preference Learning in Large Language Models approaches preferences as a decision-making problem: instead of trying to maximize expected reward, minimize regret, which means you focus on avoiding bad choices. This perspective works better when you don't have a perfect reward model, since avoiding bad choices is safer than trying to optimize an imperfect learned signal. From Reward-Free Representations to Preferences connects two fields: reward-free RL (where you learn what matters without a reward function) with preference learning, showing that you can first learn task-independent representations, then use human preferences to point toward the right behavior. This cuts the preference feedback needed in half because the representations already capture the underlying structure. Offline Preference-Based Value Optimization uses a clever insight: instead of learning a reward model and then optimizing it, directly learn which values are consistent with human preferences. This sidesteps the error that comes from learning a wrong reward model first, reducing compounding errors. Preference-based Policy Optimization from Sparse-Reward Offline Dataset extends this to the hardest setting: when the recorded data has almost no reward signal. Using preference comparisons over trajectory segments, the method recovers good policies even when offline RL methods fail because trajectory-level feedback is more reliable than sparse numbers.

Combining reward models with verifiable signals

Sometimes you can verify whether an answer is right (a math problem has a correct answer) but you cannot see the reward during learning. The challenge is deciding when to trust a learned reward model and when to use direct verification signals. Methods in this group learn to combine both sources smartly.

Hybrid Reinforcement shows that when you have both a reward model (learned from human feedback) and a verifier (a checker that says 'this is correct' or 'this is wrong'), you should use both, not pick one. On mathematical reasoning tasks, hybrid combinations beat using just the reward model or just the verifier, because they reinforce each other: the verifier catches errors the reward model misses, and the reward model speeds up learning by giving stronger learning signals at each step. Towards High Data Efficiency in Reinforcement Learning with Verifiable Reward uses verification signals to train models faster on reasoning benchmarks. By focusing learning on verifiable checkpoints—steps you can actually check—the method trains 1.85x faster while using only 20% of the data. This works because verification gives you ground truth feedback, which is much more informative than a learned reward model. DenseGRPO converts sparse verification signals (you either get a problem right or wrong) into dense rewards by measuring progress toward solution, aligning feedback with each step of the denoising process used in flow matching. This turns a binary signal—correct or incorrect—into a continuous one that guides learning at every step.

Data-efficient offline learning and control

Offline reinforcement learning trains on recorded data without exploring further. The core problem is that the data comes from some old policy, not the one you are trying to learn, so naive methods fail—when you learn from old data, you are learning from a different situation. Recent work focuses on making this efficient even with imperfect recorded data, using constraints and peer influence rather than just pessimism.

Efficient Offline Reinforcement Learning via Peer-Influenced Constraint introduces a key insight: when learning from offline data, constraining the new policy to stay close to the recorded behavior (peer influence) can work better than the usual uncertainty penalties, so the method treats what the data already shows as a reliable anchor point rather than treating all unseen actions as equally bad. The method discovers that peer influence and uncertainty estimation interact in ways that improve sample efficiency on continuous control benchmarks, since together they keep learning stable while still exploring better options. MIRACLE applies imitation and reinforcement learning to a hard real-world problem: selecting cuts in integer programming solvers. The paper shows that combining behavioral cloning (copy what the expert solver does) with RL (learn to do better) achieves huge practical gains on standard benchmarks: 98.1% less memory use and 3.78x speedup, while solving problems that existing best-in-class solvers fail on 47-53% of the time. This works because behavioral cloning gives a strong starting point and RL refines that baseline—each method covers what the other misses, so together they accomplish what neither could alone. When Predictive Inverse Dynamics Outperform Behavior Cloning compares two ways to learn from demonstrations: directly copying actions (behavior cloning) versus predicting the change in state caused by an action. On navigation tasks, predicting dynamics requires five times fewer demonstrations because it's learning the mechanism, not memorizing examples, so the knowledge transfers to new situations that look different but follow the same rules. This is a fundamental insight: learning the cause-and-effect relationship generalizes better than pattern matching because the mechanism is stable even when the specifics change.
