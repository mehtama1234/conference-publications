Mitigating Hallucinations in Large Vision-Language Models via Causal Route Gating

When a vision-language model reads an image, it sometimes ignores what it sees and just makes up fluent-sounding text from old habits, but you can fix this by teaching the model to listen harder to the visual signal.

Paper explainersAll themesMultimodal

Large vision-language models can look at an image and describe it in words, but they often make up false details that sound real. This happens because the model has two internal pathways: one reads the image, and one relies on learned language habits. When these pathways compete for control of the final answer, the language habit often wins, drowning out what the image actually shows. This paper fixes it by giving us a way to turn down the text pathway just enough so the visual signal gets heard.

Zero assumption version

The image gets drowned out

Vision-language models are a hybrid: they take in an image as a grid of numbers (pixels), run it through a visual encoder to extract features, then feed those features alongside a stream of text tokens (the words so far) into a language model. The language model then predicts the next word. Sounds right. But something goes wrong: sometimes the model generates fluent-sounding descriptions of things that are not in the image at all.

A naive fix is to just feed the image in and trust it will dominate. It does not. Even when the visual tokens enter the model's attention mechanism (the internal routing system that decides what to pay attention to), they can lose control. Here is why: the language model was trained on billions of words before it ever saw images. It learned hard habits about what words usually follow each other. When those two signals clash—visual evidence says one thing, learned language habit says another—the habit often wins. The model predicts a hallucinated caption that follows linguistic logic but ignores what the camera recorded.

In one sentence. The model has two competing voices—visual evidence and learned text habits—and the text habit is so loud it drowns out what the image shows.

What the paper changes

The single lever: attention head routing

The paper changes one thing: inside each attention head (the mechanism that decides which past tokens matter for predicting the next word), it separates the visual route from the text route and adjusts how much each one contributes to the final prediction. Nothing else moves.

the object it moves  =  attention head text-route suppression
The hidden quantity

Route dominance: which signal actually decides the answer

measured quantity  =  Route dominance per token

The paper introduces an invisible but real quantity: for each output token, which pathway (visual or text) is calling the shots? This is not stored explicitly; it lives in the model's intermediate calculations. The paper estimates it efficiently using a one-forward/one-gradient trick: run the model once forward to get the prediction, then compute how much the prediction would change if you slightly tweaked the visual route vs. the text route. A big change means that route is in control.

By measuring this, the method can identify tokens where the text route is bullying the visual route, and only then suppress it. Other tokens are left alone.

Why it works

Why selective suppression works

Here is the causal chain. The model's attention heads are mixtures: information flows along multiple paths simultaneously. Some paths carry visual signals; some carry learned text habits (patterns learned from trillions of words). When a word is being predicted, all paths vote on what comes next. The problem: text habits are louder because they were learned from trillions of words; visual signals are newer and weaker. If the text route says 'red' with confidence 0.8 and the visual route says 'blue' with confidence 0.5, the final answer will lean toward red, even though the image contains blue.

Suppressing the text route does not mean erasing it. It means scaling its contribution down—say, from 0.8 to 0.3. This makes the visual route (0.5) louder than the text habit, because when the two numbers are compared to decide what the model says next, the visual signal now has more weight in the final answer. The model still remembers language structure (so captions do not become gibberish), but now the image can overrule the learned habit. Only tokens where text dominance is detected get this treatment, so tokens that need language structure keep getting it.

The equation: selective suppression

First in words:

The final prediction is a blend of the visual and text routes, but if the text route would override visual evidence too much, we scale the text route down by a chosen factor.

Then the compact form:

output = alpha * visual_route + (1 - alpha) * text_route where alpha is reduced when text_route_dominance > threshold

Every symbol:

visual_routehow much the image signal contributes to the next word
text_routehow much the learned text habit contributes to the next word
alphathe blend weight for visual contribution (between 0 and 1)
text_route_dominancehow much the text route would override visual evidence, measured via one-gradient
thresholdthe decision boundary for when text is dominating too much
A tiny worked example
Baseline: alpha = 1.0, so output = 1.0 * visual_route + 0.0 * text_route = pure visual.
But that loses grammar. Set alpha = 0.5 initially: output = 0.5 * 0.6 + 0.5 * 0.8 = 0.3 + 0.4 = 0.7.
Measure dominance: text_route_dominance = 0.8 / (0.6 + 0.8) = 0.57 (text is 57% of the decision).
If threshold = 0.5 and dominance > threshold, reduce alpha: alpha = 0.5 * 0.8 = 0.4.
New output = 0.4 * 0.6 + 0.6 * 0.8 = 0.24 + 0.48 = 0.72 (visual route now has slightly more say).

By adjusting the blend, visual evidence is given a chance to override learned habit only when the habit would otherwise completely dominate.

What can go wrong

What can go wrong

Threshold set too high. If the threshold for detecting dominance is too permissive, text is suppressed even when it should win, and the model loses important language structure. Captions become choppy or ungrammatical.
Gradient approximation breaks on unusual images. The method estimates route dominance from one forward pass and one gradient. If the image is very different from training examples, the gradient may not accurately reflect which route should win.
Computational cost when answering. Computing the gradient for each token adds time to answer generation. For applications that need instant replies, this may be prohibitive.
Done right. The paper carefully calibrates the threshold and validates the gradient approximation on five benchmarks, showing hallucination reduction without catastrophic loss of linguistic quality.
What a runnable demo should prove

What a runnable demo should prove

Build a vision-language model that describes two images: one where the visual content and language habit align (e.g., a red car), and one where they conflict (e.g., a blue car, but the model's learned habits say 'red' is more common). Without selective suppression, both images get hallucinated captions. With it, the conflicting image gets an honest description. Measure hallucination rate: false objects mentioned that are not in the image.

hallucination_rate = (count of fabricated objects) / (total object mentions)

The metric must drop visibly when selective suppression is active, proving the method lets the model see what is actually there instead of defaulting to learned habit.
