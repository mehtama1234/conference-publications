CMT: Mid-Training for Efficient Learning of Consistency and Flow-Map Models

Insert a lightweight middle training stage between pre-training and final flow-map training to build a stable, data-efficient shortcut that maps noisy pictures to clean ones in one step.

Paper explainersAll themesGenerative Models & Diffusion

Diffusion models take many small steps to turn random noise into a clean picture. Flow-map models try to learn the long jump all at once, skipping steps. But training this jump is unstable and expensive. This paper inserts a new middle stage that learns to follow the pre-trained diffusion model's path, creating a stable starting point for the final training.

Zero assumption version

Flow maps are expensive and unstable to train

Diffusion models clean up random noise in many small steps. A beginner might try to teach a new model to do the whole job in one step, using the diffusion model as a teacher. But this fails: the jump is too big, training crashes, and you waste enormous amounts of compute trying different tricks to stabilize it.

Even when you start from a pre-trained diffusion model (which has already learned a path), teaching the final jump still struggles. The model needs to match the diffusion path exactly, but there is no clear training target for what this should look like.

The paper's move: Insert a middle training stage that learns to follow the diffusion path step by step, before learning the final one-step jump.

The algorithm as a flow

What it actually does

Start with a pre-trained diffusion model

It already knows how to clean pictures in many steps.

Mid-training: learn to follow the path

Train the new model on points sampled along diffusion paths, map each point to the endpoint.

Build trajectory consistency

Every point on the diffusion curve gets mapped correctly, so the learned model respects the path shape.

Post-training: learn the one-step jump

Starting from this stable mid-trained initialization, train the final one-step map.

Result: sharp pictures in one step, less training cost

The mid-trained initializer is stable, so post-training converges quickly with fewer epochs needed, and overall uses 98 percent less GPU time and training data than baseline methods.

What the paper changes

The one thing the paper changes

The paper inserts a new training stage between two existing stages. Most papers change one algorithm or add one trick. This paper changes the pipeline structure itself: instead of going straight from diffusion pre-training to one-step post-training, it adds a middle phase that learns to map intermediate points.

The hidden quantity

The hidden quantity: trajectory alignment

measured quantity  =  How well the model matches the diffusion path

The paper measures a quantity that did not have a name before: trajectory alignment. It answers the question: does the trained model map each point along the diffusion path to the same clean endpoint? If yes, the model is aligned; if no, training will be chaotic.

The paper estimates this by taking points sampled from a pre-trained diffusion model's trajectory and training the new model to map each one directly to the clean endpoint. The loss function is designed so that points at different steps along the same trajectory pull the weights in the same direction, building consistency.

Why it works

Why the middle stage works

The diffusion model has already learned a smooth path from noise to clean. The problem is: the final one-step map has no clear target. Training flails because the weights do not know which direction to move.

CMT fixes this by sampling points along the diffusion path and asking the new model to map each to the clean endpoint. This is much easier: the target is unambiguous. Every sampled point on the path pulls the weights in the same direction. After mid-training, the model is aligned with the diffusion path, so the weights are already oriented correctly.

The final post-training then learns the one-step jump from a warm start. Instead of training from random or diffusion weights (which point in conflicting directions), it starts from aligned weights. Training is faster because the weights are already pointed the right way, so fewer steps are needed to reach convergence; it is more stable because the nudges during training (which way to shift each weight to improve the result) now all point in the same direction instead of canceling each other out; and it uses less data because the initialization is so much better that the final training completes without the usual iterations spent hunting for the right direction.

Math after the picture

The training equation

First in words:

The penalty is: sum over sampled points of (squared difference between what the model predicts and the clean endpoint), weighted by the noise level. Points at different noise levels all target the same clean image.

Then the compact form:

L_CMT = E_t E_{x_t ~ trajectory} [ w(t) * (f_theta(x_t) - x_0)^2 ]

Every symbol:

f_theta(x_t)the model's prediction when given a noisy point at level t
x_0the clean endpoint of this trajectory from the pre-trained model
w(t)a weight that scales the penalty based on noise level t
L_CMTthe total training penalty (lower is better)
A tiny worked example
Pre-trained diffusion generates a trajectory: x_T (pure noise) → x_15 (30% noisy) → x_5 (5% noisy) → x_0 (clean image).
Sample x_15 (noisy): model predicts 'dog', actual endpoint is 'dog'. Error = 0. Penalty = w(15) * 0^2 = 0.
Sample x_5 (less noisy): model predicts 'dog with blur', actual is still 'dog'. Error = small blur difference. Penalty = w(5) * 0.04 = 0.08.
Sample x_T (pure noise): model predicts 'blob', actual is 'dog'. Error = large. Penalty = w(T) * 2.0 = 8.0.
All three samples pull the model to predict the same x_0, building alignment. Post-training then learns the jump from these aligned weights.

Every point on the same trajectory teaches the model to map to the same clean endpoint, forcing the weights to stay aligned.

What can go wrong

What can go wrong

Mismatched trajectory samples. If the points sampled during mid-training do not come from the same pre-trained diffusion model, they point in different directions. The model cannot align. Fix: always use the same teacher model for sampling.
Noise-level weighting ignored. If you train all points equally, the model overweights easy (clean) points and ignores hard (noisy) ones. The alignment breaks. Fix: weight by noise level w(t) so all points contribute fairly.
Too much mid-training. If you train the middle stage too long, the model overfits to the pre-trained trajectories and cannot adapt to the final one-step task. Fix: use just enough mid-training to align, then stop.
Done right. Mid-training for 8 to 16 epochs on 10 million sampled trajectory points builds a stable initializer without overfitting. Post-training then converges in half the time.
