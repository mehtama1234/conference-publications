Theory of Minimal Weight Perturbations in Deep Networks and its Applications for Low-Rank Activated Backdoor Attacks

Derive how much a network's weights must change to force a chosen output change, then use that theory to explain when low-rank compression can activate hidden backdoors.

Paper explainersAll themesOther

This paper studies a precise question: if we want a neural network to change its output by a specified amount, what is the smallest change to the weights that can cause that effect? The answer matters for stability analysis and for security analysis. A small required perturbation means the network is sensitive at that layer. The paper derives exact formulas for single layers and compares them with broader multi-layer bounds based on Lipschitz constants, which are numbers that upper-bound how much an output can move when an input or learned weight moves. It then applies the theory to precision-modification backdoors, where a model appears benign at full precision but changes behavior after weight compression or low-rank approximation.

Zero assumption version

Why minimal perturbation size matters

A deep network can fail in many ways, but not all failures require a large weight change. Some outputs can be altered by a very small perturbation if the current layer activations, meaning the layer's current numeric outputs, align with a sensitive direction. Understanding that minimum matters because it tells us where the model is easy to manipulate and where it is more resistant.

This question becomes especially important for hidden backdoors, meaning malicious behaviors that are present but not visible during ordinary evaluation. A malicious model may behave normally at full precision and only reveal the backdoor after compression, reduced numeric precision, or low-rank approximation. To understand that behavior, we need a theory that links a desired output shift to the smallest weight change capable of producing it.

The paper's move. Solve the minimum-perturbation problem layer by layer, then use the solution to predict when compression-induced weight changes are large enough to trigger a hidden backdoor.

The hidden quantity

The hidden quantity

measured quantity  =  layer-wise perturbation margin

The hidden quantity is the perturbation margin: the smallest weight change that can produce a specified output change at a given layer for the current input. That margin is hidden because the network normally exposes only predictions, not how close each layer is to a chosen behavior change.

The paper shows that this margin depends on back-propagated margins, meaning how much downstream output change is still required after accounting for later layers, and on the current layer activations. If a layer's activations line up well with the needed change direction, the perturbation margin can be small. If they do not, much larger weight movement is required.

Why it works

Why the formulas explain compression-activated backdoors

A backdoor that activates after compression is not magic. Compression changes the weights, and those weight changes move the network to a different point in weight space. The paper asks whether that movement is large enough, in the right direction, to force a target output shift. Once the minimum required perturbation is known, compression becomes analyzable because it can be compared directly with that threshold.

The single-layer formulas matter because they isolate what drives sensitivity. A layer is easy to perturb when the current activations make the desired output direction easy to reach. In that case, a small weight modification can produce a large downstream effect. A layer is harder to perturb when the same desired change projects poorly onto the current activations, because then the weights must move more to compensate.

This directly explains low-rank activated backdoors. Low-rank compression does not add arbitrary noise; it projects the original weights onto a lower-dimensional structure. If that structured projection crosses the perturbation threshold for the backdoor direction while leaving ordinary predictions mostly intact, the model can remain accurate on clean data while switching behavior on the trigger pattern.

Math after the picture

Compare required movement with actual movement

First in words:

The theory computes a minimum perturbation norm for a chosen output change. Compression is safe with respect to that change only when the norm of the compression-induced weight modification stays below the minimum required norm.

Then the compact form:

safe_if compression_perturbation_norm is less than minimum_required_perturbation_norm

Every symbol:

compression_perturbation_normthe size of the weight change caused by compression or precision modification
minimum_required_perturbation_normthe smallest weight change that can produce the chosen output shift
safe_ifthe condition used to certify that compression cannot trigger that specific change
A tiny worked example
Suppose analysis of one layer shows that at least 0.40 units of weight movement are needed to flip the output toward the target backdoor class.
Now suppose low-rank compression changes that layer by 0.18 units.
Because 0.18 is below 0.40, this compression cannot activate that target shift through this layer alone.
If a stronger compression changes the layer by 0.47 units, the threshold is crossed.
At that point activation becomes possible, which is why the paper can derive compression limits below which the backdoor cannot appear.

The full paper derives exact expressions for the threshold in terms of activations and margins. This simplified statement captures the operational use of the theory.

What can go wrong

What can go wrong

Single-layer exact analysis may miss interactions across layers. The exact formulas are sharp for the analyzed layer, but a deep network can distribute a manipulation across several layers. In those cases the single-layer threshold gives only part of the full picture.
Bounds can be conservative. Network-wide sensitivity bounds are useful because they cover more cases, but they can overestimate the perturbation needed. A conservative certificate may declare some compressions unsafe even when activation would not occur in practice.
Backdoor behavior depends on the chosen trigger and target shift. The minimum required perturbation is specific to a selected output change. A certificate for one target direction does not automatically certify every other possible malicious behavior.
Done right. The paper is valuable when used as a layer-by-layer diagnostic tool that connects an actual compression procedure to a concrete activation threshold rather than to an imprecise claim that the network is fragile.
What a runnable demo should prove

What a runnable demo should prove

Train or obtain a small image classifier containing a planted latent backdoor that is inactive at full precision. Measure clean accuracy and trigger behavior before compression. Then apply several low-rank compression levels and compute the induced perturbation norm for the targeted layer.

The demo should compare those measured perturbations with the theoretical minimum threshold for the backdoor output change. A convincing result shows that the backdoor stays inactive below the threshold and becomes possible once compression pushes the layer past it, even if clean accuracy remains high.

activation_gap = compression_perturbation_norm minus minimum_required_perturbation_norm ; trigger_success = triggered_outputs divided by trigger_inputs

The core proof is that compression-induced behavior change is predictable from the perturbation threshold, not merely observed after the fact.
