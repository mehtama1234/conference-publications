GeoReward: Mitigating Contextual Variable Overestimation in Vision-Language Models for Cross-Market Preference Prediction

Train a preference model to focus on the small market-specific signals that decide which ad creative wins in each country.

Paper explainersAll themesMultimodal

A vision-language model can compare two ad images and say which one will get more clicks. The failure in this paper is that the model often locks onto the dominant signals in the image, such as the product itself, the main colors, or the large text blocks, and then ignores the tiny context cue that actually changes the answer: which market the ad is meant for. If the country label, which is one discrete text unit in the input sequence, is weak while the product signal is strong, the model may return the same choice for Korea, France, and Brazil even when the real click data says the preference flips. GeoReward is a reward model for market-specific preference prediction. It changes training in three places because the country cue is inserted into retrieval, into visual processing, and into the loss, so the score cannot be computed from dominant shared cues alone.

Zero assumption version

Why cross-market preference prediction breaks

The task sounds simple, because you show the model two ad creatives, give it the target country, and ask which creative will perform better. The catch is that most of the image content is shared across countries. The product category, layout, faces, and large text occupy many image regions, while the country name occupies only a few text positions. During training, the model sees far more evidence for the dominant shared cues than for the sparse market cue.

That imbalance creates contextual variable overestimation in reverse form: the model over-trusts the variables that appear everywhere and under-trusts the variable that changes the decision. When that happens, the model collapses to one global preference rule. It may learn that bright product close-ups usually win and then keep saying that rule is correct even when country-level click data shows that local style, background, or wording changes the result.

The paper's move in one sentence. Make the reward model see market-matched examples, modulate visual features with the country cue, and punish country-specific mistakes more strongly so the market label cannot be ignored.

The algorithm as a flow

What it actually does

Build a reward dataset.

Collect ad creatives and observed click performance across countries so the supervision is actual market preference rather than a guessed style label.

Retrieve market-aligned examples.

For each training case, fetch similar examples from the same or related markets because those examples show how preference changes under local context.

Inject the country cue into visual processing.

Use a lightweight adapter to change the image feature stream with the country representation so the model can score the same picture differently for different markets, because intermediate image features now carry market-specific weighting instead of only global visual content.

Train with a selective loss.

Upweight errors that show the model missed a country-specific preference flip because those are the mistakes caused by context neglect.

Use the reward model for optimization.

Score candidate creatives or guide fine-tuning of a generator so the produced backgrounds align with the target market.

What the paper changes

What the paper changes

The paper changes how a vision-language reward model assigns importance to input variables. Instead of treating the country cue as a small side input, it threads that cue through retrieval, visual feature modulation, and the loss function.

the object it moves  =  the reward model's weighting of market context versus dominant shared cues
The hidden quantity

The hidden quantity

measured quantity  =  market sensitivity of the preference score

The hidden quantity is how much the preference score changes when the market changes but the pair of ads stays the same. A good cross-market model should sometimes keep the same winner and sometimes flip it. The point is not to force a flip; the point is to make the model responsive when the data supports one.

GeoReward estimates that sensitivity indirectly. Market-aware retrieval shows the model nearby examples where the same product category can produce different winners in different countries. Context-guided modulation then pushes the country signal into the image feature stream, which is a learned list of numbers passed forward by the visual encoder. The selective loss raises the training cost of market-specific misses. That keeps the optimizer moving toward scores that react to the country cue, because those misses now contribute more to each model-weight update during training.

Why it works

Why the three-part design fixes the failure

Each part fixes a different point where the market cue can disappear. Retrieval fixes the data view. If a training batch contains only the current example, the model mostly sees the dominant shared content. When the batch also contains preference evidence from the same market, the model gets direct contrastive evidence that country matters because similar products can have different winners under different local settings.

Visual modulation fixes the feature path. The country cue is no longer read only at the very end. It changes intermediate image features, which are lists of numbers used by later layers to score the creative. That matters because the model can now increase the weight on image regions tied to local taste, background design, or wording style while suppressing regions that are informative globally but irrelevant for the current market.

Selective sensitivity loss fixes the training signal. Ordinary pairwise preference loss treats every mistake the same. GeoReward increases the penalty on mistakes where the model failed to react to a context variable that should have changed the winner. That creates a direct pressure to separate generic ad quality from country-conditioned preference. The three parts work together because retrieval supplies examples, modulation opens a path for the context signal, and the loss makes the optimizer keep that path active.

First in words:

A compact view is to start with ordinary pairwise preference loss and then add an extra term for cases where the winner depends on market context.

Then the compact form:

Every symbol:

A tiny worked example
Suppose ad A wins in France and ad B wins in Korea for the same product.
A weak model predicts A for both countries, so it gets one case right and one case wrong.
Under ordinary pairwise loss, that wrong case is just one more mistake in the batch.
Under GeoReward, the Korea miss gets extra weight because the mistake shows the model ignored the market variable.
Training then pushes the country-conditioned score for Korea toward B without changing the France score in the same direction.

The exact implementation has more detail, but the main idea is simple: market-sensitive errors carry extra training weight so the optimizer cannot settle for one global preference rule.

What can go wrong

What can go wrong

Retrieved neighbors can be noisy. If the retrieval step brings in examples that are not truly market-aligned, the model may absorb the wrong local signal because the added evidence points to a different preference pattern than the current case.
Country can stand in for hidden confounders. A country label may correlate with language, season, platform, or product mix. If those factors are not separated, the model may learn country-specific shortcuts rather than the actual cause of the click difference.
The context penalty can be too strong. If market-sensitive cases are over-weighted, the model may overreact and flip preferences too often because it starts treating weak country evidence as decisive.
Done right. The method works when retrieval quality is high, the country signal is grounded in real preference logs, and the loss weight is tuned. In that setting the model reacts to true local differences without inventing them, because the extra penalty is concentrated on real context-sensitive cases rather than on noisy ones.
What a runnable demo should prove

What a runnable demo should prove

Build a toy ad-preference dataset where the same product has different winning backgrounds in three markets. Train one reward model that sees only the ad pair and country label at the output head, and train another with retrieval, country-conditioned feature modulation, and an extra loss on market-sensitive pairs. Then hold the product constant and swap only the market label during evaluation.

The demo should show that the baseline often returns the same winner after a label swap while the GeoReward-style model changes its score only on the pairs whose observed winner truly depends on market context.

market_flip_accuracy = correct_context_driven_flips / total_context_driven_flip_cases

A convincing result is high accuracy on both same-market cases and flip cases, because that shows the model learned when the market should matter instead of forcing every example to change.
