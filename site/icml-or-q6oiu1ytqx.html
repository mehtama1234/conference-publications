Source-Free Open-World RF Fingerprint Identification

Maintain class separation in incremental RF fingerprint identification by forcing classifier outputs toward an orthogonal simplex structure and aligning new unlabeled streams to that structure without replaying old data.

Paper explainersAll themesOther

RF fingerprint identification classifies wireless devices from subtle hardware-specific signal distortions. In an open-world setting, new devices keep appearing, and in a source-free setting, old training data cannot be stored or revisited. That creates a stability-plasticity conflict: the system must preserve old classes while also carving out room for new ones. This paper addresses that conflict by imposing a rigid output arrangement based on an equiangular tight frame, which is a set of class directions with equal pairwise angles, and then aligning incoming unlabeled signals to that arrangement through several geometric constraints.

Zero assumption version

New devices arrive, old data are gone, and class boundaries collapse

RF fingerprints are weak device-specific patterns in transmitted signals. A classifier learns to map those patterns to device identities. In practice, new devices appear after deployment, and privacy or storage rules may prohibit keeping the original training signals.

Without old data, incremental training is fragile. If the model adapts too strongly to new signals, old class boundaries drift and old devices are forgotten. If the model resists change too strongly, new devices are absorbed into old classes and the system fails to discover them.

The paper treats this as an output-structure problem. If old and new classes can be forced into a well-separated arrangement in the classifier output space, new learning can expand without overwriting the old arrangement. The difficulty is doing that when the incoming stream is unlabeled and old examples are unavailable.

In one sentence. Build a classifier whose class directions are forced apart from the start, then align each new unlabeled stream to that fixed separation pattern instead of relearning boundaries from old data.

The algorithm as a flow

What it actually does

Construct class anchors

Assign each class a target output direction arranged with equal angular separation.

Train the current model toward those anchors

Push labeled source classes so their outputs collapse around their assigned directions.

Receive an unlabeled incremental stream

Read new RF signals without access to old stored examples.

Align the stream to the anchor structure

Use transport-based matching, progressive anchoring, and retained old subspaces to place new representations.

Update identities while preserving old separation

Expand the classifier using the fixed anchor pattern and the aligned stream statistics.

What the paper changes

What the paper changes

The paper changes the layout of classifier outputs. Rather than letting class prototypes drift wherever repeated loss-minimization updates place them, it imposes a fixed, maximally separated arrangement and updates new data to fit that arrangement.

the object it moves  =  classifier output arrangement
The hidden quantity

The hidden quantity: available separation room

measured quantity  =  available separation room

When classes are added over time, the real bottleneck is how much unused output-space room remains between old classes. If old classes already crowd each other, any new class will overlap one of them. The equiangular frame makes that room explicit by reserving equal angular spacing between class anchors.

That quantity is hidden because the data stream only reveals signals, not the future class layout needed to keep them distinct. By fixing the output arrangement in advance, the method turns future separation from an accidental by-product of training into an explicit design constraint.

Why it works

Why a fixed anchor structure helps source-free incremental learning

Forgetting happens when old class representations shift while adapting to new data. A fixed anchor arrangement resists that shift because old classes are always pulled back toward their assigned directions. The classifier does not have to rediscover where old classes belong after each update; that information is encoded in the output structure itself.

Open-world discovery is difficult because new signals arrive without labels. The alignment stage addresses this in three layers. Optimal transport, which is a matching procedure between two collections of probability mass, provides a soft assignment between unlabeled stream clusters and available anchor structure. Progressive anchoring then moves emerging clusters toward stable directions gradually instead of forcing a hard jump early. Reliable subspace retention keeps parts of the old representation map that are judged stable, so new learning does not overwrite all earlier signal structure.

These pieces work together because each solves a different failure mode. Anchor separation protects old classes, transport provides a way to interpret unlabeled new data, and retained old subspaces limit destructive drift. The result is a tradeoff where new devices can be integrated without replaying raw old signals.

Math after the picture

The anchor-and-alignment objective

First in words:

The loss has one part that pulls each known class toward its assigned anchor direction, one part that aligns new unlabeled clusters to the anchor structure, and one part that preserves selected old subspaces during adaptation. Together they keep class outputs separated while new stream data are absorbed.

Then the compact form:

total_loss = anchor_loss + transport_alignment_loss + retention_loss

Every symbol:

anchor_losspenalty when class outputs drift away from their assigned separated anchors
transport_alignment_losssoft matching cost between new stream clusters and the anchor structure
retention_losspenalty for damaging stable old representation subspaces
A tiny worked example
Suppose three old device classes already occupy three anchor directions with equal separation.
A new unlabeled stream arrives and forms two clusters in representation space.
The transport term gives soft weights saying cluster A is close to one unused anchor direction while cluster B is partly between two directions.
Progressive anchoring moves cluster A strongly toward its best anchor and moves cluster B more cautiously because its assignment is ambiguous.
The retention term prevents the update from rotating the old three class directions too much while those new adjustments are happening.

The loss is structured around separation and preservation. New data are not fit in isolation; they are fit subject to the requirement that old anchor margins remain usable.

What can go wrong

What can go wrong

The fixed anchor pattern can be too rigid. If the real RF classes are highly imbalanced or naturally arranged with uneven margins, forcing equal angular spacing may allocate space inefficiently. Some classes may need more room than the frame assigns.
Unlabeled clusters can be unreliable early on. The transport step assumes that clusters in the new stream are informative enough to match against the anchor structure. If the stream is noisy or mixed, the soft matching can steer adaptation toward the wrong anchors.
Subspace retention can preserve stale structure. Keeping old representation subspaces protects past classes, but it can also freeze nuisance patterns tied to old domains. Then the model resists useful adaptation to new channel conditions.
Done right. The framework is strongest when anchor separation is paired with reliable cluster structure in the incoming stream and when the retained old subspaces are filtered so only stable, class-relevant directions are preserved.
What a runnable demo should prove

What a runnable demo should prove

Create a synthetic RF identification benchmark with several initial device classes, then introduce additional classes in unlabeled batches while withholding the original raw data after the first stage. Compare a plain source-free fine-tuning baseline against an anchor-based classifier with soft cluster alignment. Measure old-class accuracy, new-class discovery score, and overlap between class centroids in output space. The anchor-based method should preserve larger margins between old classes because the output arrangement constrains where adaptation can move them.

retention = old_classes_correct_after_update / old_class_examples; discovery = correctly_separated_new_clusters / total_new_clusters

The demo should make it visible that preserving old identities is not only a memory issue. It is also a layout issue, and the fixed anchor structure changes that layout before new unlabeled data ever arrive.
