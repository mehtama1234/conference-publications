WaveSSM: Multiscale State-Space Models for Non-stationary Signal Attention

Use wavelet frames instead of polynomials to build memory models that see small, sharp changes in signals like heartbeats and speech.

Paper explainersAll themesTime Series & Sequential

Models that remember long sequences of data usually store the past using polynomial math — smooth curves that remember everything everywhere. But heartbeats, speech, and seismic data have sudden shifts and precise moments that matter. WaveSSM swaps the polynomial bases for wavelets, which are patterns designed to see localized bumps and dips. The result: a model that remembers both the long view and the precise moment things changed.

Zero assumption version

Polynomials are blurry on sudden changes

A state-space model is a machine that reads a sequence one step at a time and carries forward a compressed summary of everything it has seen. To decide what to keep and what to forget, it uses a projection operator — a mathematical rule that says: here is how to collapse the input stream into a stable memory state. The standard choice is a polynomial basis (sums of powers of the input, like x, x squared, x cubed). Polynomials have global support, meaning each piece of the polynomial curve influences every moment in time — a degree-3 polynomial is one smooth shape everywhere.

The beginner would assume global smoothness is good — it lets the model see long patterns. But signals like heartbeats, speech clicks, and seismic shakes have transient structure (sharp, brief events). A polynomial basis cannot represent these sharp moments cleanly without spreading the effect across time. A spike in one moment contaminates the memory of adjacent moments. When the spike's effect is spread across multiple memory slots instead of stored as one sharp event, the model cannot clearly mark that moment as distinctive, so it treats the spike as background noise rather than as an important event.

In one sentence. WaveSSM replaces polynomial projection bases with wavelet frames, which see transient events as crisp, localized pulses rather than smooth global curves.

What the paper changes

What the paper changes

The paper changes the projection basis from polynomial to wavelet. A projection basis is the mathematical rule that decides how to compress a sliding window of the signal into a single memory state (a list of numbers). Polynomials project onto smooth global curves; wavelets project onto localized, multi-scale bumps and dips. This single swap cascades through the whole state-space model.

the object it moves  =  projection basis (polynomial to wavelet)
The hidden quantity

The localization property

measured quantity  =  temporal localization of the basis

The hidden quantity is temporal localization: a measure of how narrowly each basis pattern concentrates in time. A polynomial like x squared smears its influence across the entire time window — it has infinite spread. A wavelet is designed to spike at one location and die out quickly on both sides — it has finite, bounded support. This localization is not directly measured by the model but is baked into the choice of basis; WaveSSM exploits it by swapping to wavelets that have strong localization for the frequency scales present in the signal.

The paper estimates which wavelets matter by letting the state-space model learn which wavelet scales and positions carry the most information about the next value in the sequence. Wavelets with high information content correspond to the sharp, transient events in the data.

Why it works

Why wavelet localization captures transients better

When a state-space model compresses a signal history into a fixed-size memory state, it must decide which details matter and which can be discarded. The projection basis is that decision rule. If you use a polynomial basis, the model is forced to represent the signal as a smooth curve. A sharp spike (a sudden jump in the signal value) cannot be represented sharply; instead, the polynomial wiggles on both sides of the spike to try to fit it. This spreading means the memory gets mixed signals: the spike leaks into the memory of the moments before and after, contaminating them. When the model tries to use this memory to predict the next value, it sees a blurry, ambiguous signal and must guess.

Wavelets solve this by design. A wavelet is a small, localized wave-pulse. You can build a complete basis from wavelets at different scales (coarse to fine) and positions (everywhere across the window). When a sharp spike appears, the fine-scale wavelets at that position produce large coefficients, while wavelets far from the spike produce small coefficients. The model's memory now holds a precise map: spike present at this location, at this scale, with this amplitude. There is no blurring. When the next value arrives, the model can consult this sharp memory to know exactly what kind of event just happened, which lets it predict the next value based on that clear context rather than guessing from noise.

Math after the picture

The projection equation

First in words:

A state vector at time t is the sum of each input value at a past time τ multiplied by the basis function value at that time, integrated over all past times. When you change from polynomial to wavelet basis, the basis functions change shape — from smooth global curves to localized bumps — so the state vector encodes different information.

Then the compact form:

h(t) = ∫ x(τ) * φ(t - τ) dτ

Every symbol:

h(t)the state (memory) at time t
x(τ)the input signal value at past time τ
φ(t - τ)the basis function: polynomial (global) or wavelet (localized)
∫sum over all past times
A tiny worked example
Suppose at time t=5 there is a spike (input x=10). Polynomial basis: the basis function φ(5-τ) is a smooth curve spread across τ=0 to τ=5, so the spike contributes 10 units spread across many past times in the state. Wavelet basis: the basis function φ(5-τ) is a sharp bump at τ=5, so the spike contributes its full 10 units at a single location τ=5 in the state. Later, when predicting x(6), the model using wavelets has a crisp signal (spike at τ=5); the model using polynomials has a blurry signal (spike smeared across τ=0..5). Crisper memory, better prediction.

Swapping the basis function from smooth polynomial to localized wavelet changes what the state remembers about sharp events.

What can go wrong

What can go wrong

Wavelets overfit to noise. If the signal is mostly noise (random jumps with no true transient structure), wavelets will fit the noise bumps as if they were real events, leading to overconfident but incorrect predictions. Regularization (gentle steering toward simpler models) is needed.
Wavelet choice matters. Different wavelet families (Daubechies, Morlet, etc.) have different localization-frequency tradeoffs. Picking the wrong wavelet family for your signal type gives poor results.
Slow on smooth signals. If the signal is genuinely smooth with no transients (e.g., temperature or stock price over days), a simpler polynomial basis may be faster and just as accurate, because wavelets waste capacity on localization that is never used.
Done right. Choose wavelets matched to the signal's expected transient scales; add modest regularization; compare to polynomial-basis baselines on your specific data before committing.
What a runnable demo should prove

What a runnable demo should prove

Build a simple state-space model on the PTB-XL dataset (a collection of thousands of heartbeat recordings as electrical signals). Implement two versions: one with a polynomial projection basis (call it S4-poly) and one with a wavelet basis (WaveSSM). Train both on the same data for the same number of steps. On a held-out test set, measure how well each model predicts the next heartbeat value one step ahead. The wavelet version should win by a noticeable margin (e.g., 10-15 percentage points in prediction accuracy), because the test signals still have the sharp, transient heartbeat peaks that the wavelet basis was designed to capture.

accuracy = (1 / N) * sum_i 1[predicted_value_i matches true_value_i category]

WaveSSM's win should be visible as higher accuracy on the heartbeat data. This proves that localized wavelet bases beat smooth polynomial bases on signals with transient structure, because wavelets preserve the sharp spike memory that the model needs to make correct predictions at the next time step.
