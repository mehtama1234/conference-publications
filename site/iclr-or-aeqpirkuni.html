BEAST: Learning from unlabeled animal video

When you have tons of unlabeled animal video but few labeled frames, stitch two learning tricks together—one that learns from incomplete pictures and one that learns from video flow—to pretrain a model that works well even with tiny labeled datasets.

Paper explainersAll themesRepresentation & Self-Supervised Learning

Studying animal behavior means watching endless video, but labeling every frame is impossibly slow. This paper shows how a single model can learn from raw unlabeled video by doing two learning tasks at once: predicting what's hidden in each frame, and linking similar frames across time. The result is a pretrained model ready to learn behavior analysis, pose, or action segmentation with just a handful of labeled examples.

The unlabeled video problem

Animal behavior labs film constantly—cameras roll for hours capturing mice, flies, or fish. But turning video into scientific answers requires labeling: marking where the animal's nose is, when it eats, which frames show threat-displays. A single dataset might have a thousand hours of video but only a hundred labeled frames.

A beginner would think: collect all your video, label as much as you can by hand, train a regular supervised model on those labeled frames. This fails because the model memorizes the tiny labeled set and flops on anything new. The core problem is not video—it is that labeled behavioral data is scarce everywhere.

In one sentence. BEAST learns a reusable video understanding backbone by training on raw unlabeled frames using two learning tricks run together.

What the paper changes

What the paper changes

The paper changes the starting point for a behavior-analysis model. Instead of training from random initialization using only your tiny labeled dataset, you start with a model that has already seen thousands of unlabeled frames and learned to recognize behavior and motion.

The hidden quantity

The hidden quantity: frame-to-frame coherence

measured quantity  =  Frame similarity under temporal drift

Behavior video has a natural rhythm: a mouse at rest stays at rest for many frames; a grooming sequence unfolds over seconds. The paper learns a hidden measurement called frame coherence—a score from 0 to 1 for how similar two frames are, based on the animal's position and action.

The temporal contrastive loss measures this by taking pairs of nearby frames (anchor and positive) and distant frames (negative). It pushes the model's representation of the nearby frames together and pulls the distant ones apart. Frames that are close in time get high coherence; frames far apart get low. The model learns this ranking by comparing unlabeled frames.

Why it works

Why stacking two learning tricks works

A single learning trick is enough to teach a model to predict one thing. Masked autoencoding teaches appearance: a model that predicts hidden pixels learns where the animal's body is, what texture its fur has, what the background looks like. But appearance alone misses motion—it does not know if the mouse is walking or turning.

Temporal contrastive learning teaches flow: it anchors the model to video continuity by teaching it that neighbor frames are alike. This guides the model to notice motion and behavior state, which appearance alone would miss.

Together, the two losses push the model to learn two complementary skills from the same unlabeled frames: what things look like, and how they move. This dual foundation is more useful for downstream tasks—pose estimation needs both texture and motion, behavioral feature extraction needs motion, action segmentation needs both. A model trained on both tasks gets a richer, more general starting point.

The combined loss equation

First in words:

Total loss equals masked autoencoding loss plus a weight factor times the temporal contrastive loss. The weight factor controls how much each task pushes on the model.

Then the compact form:

Loss_total = Loss_MAE + lambda * Loss_InfoNCE

Every symbol:

Loss_totalthe combined error signal sent back to update weights
Loss_MAEmean-squared error when the model predicts hidden patches
Loss_InfoNCEcontrastive error when neighbor frames are not pulled close enough
lambdaa dial from 0 to 1 that decides how much weight temporal learning gets
A tiny worked example
Frame batch: 8 frames from one video; 16 patches per frame; frames taken 10ms and 500ms apart.
MAE loss: 20 hidden patches get predicted wrong; squared error 0.04 each; total 0.80.
InfoNCE loss: 8 neighbor-frame pairs push too far apart; error 0.15 each; total 1.20.
If lambda = 0.5: Loss_total = 0.80 + 0.5 * 1.20 = 0.80 + 0.60 = 1.40.
Weights update to shrink both appearance error and temporal error; next batch starts fresher.

The loss weights the two learning goals equally because when one error signal is much larger than the other, the larger one dominates and the model ignores the smaller goal. By balancing them, both appearance and motion get equal votes in which direction to nudge the weights.

What can go wrong

What can go wrong

Wrong lambda weight If lambda is too high, the model chases temporal flow so hard that it ignores appearance details. If too low, it ignores motion and just memorizes static textures. This must be tuned on validation data per experiment.
Dataset-specific pretraining hidden by bad initialization Pretraining only on that specific lab's frames can overfit to that lab's lighting, cage setup, or camera angle. The paper mitigates this by starting from ImageNet pretrained weights, but generalization still depends on dataset diversity.
Short videos or fast motion breaks temporal windows The contrastive loss assumes frames close in time are behaviorally similar. In very fast-motion experiments (like high-speed flight video), 10ms might be enough time for large motion; the model may not recognize that frames are truly related.
Done right Choose lambda from validation sets; initialize from ImageNet; test on unseen animals or new experimental conditions to ensure the pretrained weights transfer.
What a runnable demo should prove

What a runnable demo should prove

Build a tiny BEAST pretrainer using one dataset (e.g., 500 unlabeled mouse frames). Train two models: one with both losses, one with only masked autoencoding. After pretraining, freeze the weights and fine-tune each on 50 labeled pose-estimation frames from a held-out split. Measure pose accuracy on a test set of 30 frames from new animals.

Improvement = (accuracy_BEAST - accuracy_MAE_only) / accuracy_MAE_only * 100 percent

BEAST should beat the single-trick baseline by 20-40 percent on the scarce-label task, proving that temporal learning adds real information when unlabeled video is plentiful.
