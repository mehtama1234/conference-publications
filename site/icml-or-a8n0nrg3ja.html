Do LLMs “Feel”? Emotion Circuits Discovery and Control

Find the internal components that consistently drive emotional expression in a language model, verify that they cause the effect, and then directly adjust those components to control the emotion of generated text.

Paper explainersAll themesInterpretability

This paper studies emotional expression in large language models from the inside. It does not ask whether the model has human feelings. It asks whether there are stable internal computations that push the model toward outputs read as joy, sadness, anger, fear, and other emotions across many contexts. The method first builds controlled prompts so the same event can be described with different emotional valence. It then extracts context-agnostic emotion directions, meaning directions in the model's internal activation space (the high-dimensional list of numbers inside a layer) that align with one emotion across many prompt contexts. After that, it identifies which neurons and attention heads (routing units that decide which earlier words matter) implement those directions locally, measures which sublayers matter most for the final emotional state, and joins those parts into global circuits. Because the parts are tested with ablation and enhancement, the paper can move from correlation to causal control.

Zero assumption version

Why prompt-level emotion control is shallow

A model can be told to answer in a happy or angry tone, but prompting alone does not reveal whether the same internal mechanism is being reused each time. The prompt might work in one context and fail in another because the model could be following superficial word associations instead of a stable internal computation.

If we want reliable control, we need more than output examples. We need to know whether the model contains context-agnostic components that encode emotional direction even when the scenario wording changes. Without that, emotion steering remains brittle because each new prompt may require a different trick.

The central question. Does a language model have reusable internal machinery for emotional expression, because only reusable machinery can be inspected and controlled systematically?

The algorithm as a flow

What it actually does

Construct controlled prompts

Use the SEV dataset so that scenario and event stay comparable while emotional valence changes, because that reduces confounding from unrelated prompt content.

Extract emotion directions

Compare internal activation patterns across emotions and keep the directions that repeat across contexts, because repeated directions are more likely to encode emotion rather than topic.

Locate local implementers

Identify neurons and attention heads, which are weighted routing units inside the network, that strongly contribute to those directions because local contributors reveal where the computation is built.

Run causal interventions

Ablate components by turning them down and enhance them by turning them up, because a true circuit should change the model's final emotion when its parts are edited.

Assemble global circuits

Measure each sublayer's influence on the final emotion representation and join the important local parts into a full path from early processing to output behavior.

What the paper changes

What the paper changes

The paper changes emotion control from an external prompting trick into an internal circuit intervention problem. Instead of asking the model politely to sound a certain way, it identifies and manipulates the model states that actually produce the emotional style.

the object it moves  =  the internal computation that drives emotional expression
The hidden quantity

The hidden quantity: the model's final emotion representation

measured quantity  =  the internal emotion representation before text is generated

The main hidden quantity is the model state that determines what emotional tone the output will carry before the final words are chosen. This state is hidden because users only see the generated text, not the intermediate activations that shape it.

The paper estimates this state by finding low-dimensional directions in activation space that stay aligned with one emotion across contexts. A direction here means an axis in a list of numbers: moving farther along that axis makes the internal state more consistent with one emotion. If the same axis recurs in many scenarios and direct interventions on components along that axis change the output emotion, then the axis is not just a statistical artifact.

Why it works

Why it works: stable directions plus causal tracing

The first piece is controlled comparison. If you compare prompts that differ in both topic and emotion, you cannot tell what the model is encoding. By holding the scenario structure steady and changing emotional valence, the paper makes the activation differences more attributable to emotion itself because fewer unrelated factors are moving at the same time.

The second piece is decomposition. A model's activation is a long list of numbers, and different computations can overlap inside that list. The paper extracts directions that consistently separate one emotion from others across contexts because those repeated directions are candidates for reusable emotion encoding. It then decomposes the contribution of neurons and attention heads to those directions. A neuron is one unit that outputs a single number inside a feedforward block, and an attention head is one routing unit that decides which earlier word pieces influence the current word piece. If the same units repeatedly contribute to the same emotion direction, they are plausible local implementers of the computation.

The third piece is causality. Correlated units are not enough. The paper ablates candidate components and checks whether the final emotion representation weakens; it enhances them and checks whether the representation strengthens. It also measures how much each sublayer changes the final emotion direction so that the local parts can be assembled into a global circuit. Direct modulation succeeds because the intervention is aimed at components that actually produce the emotion representation, not at prompts that only sometimes evoke it.

Math after the picture

The equation: emotion score from an internal direction

First in words:

A prompt's emotion score can be summarized by projecting the model's activation onto a learned emotion direction. Larger projection means the internal state aligns more strongly with that emotion.

Then the compact form:

emotion_score = activation · emotion_direction

Every symbol:

emotion_scorehow strongly the current internal state aligns with one target emotion
activationthe model's current layer state, represented as a list of numbers
emotion_directionthe learned direction that captures one emotion consistently across contexts
A tiny worked example
Take two prompts about the same event: one framed with joy and one framed with sadness.
Measure the layer activation for each prompt.
Find a direction that gives a high projection for joy prompts and a low projection for sadness prompts across many scenarios.
Now ablate a small set of neurons that heavily contribute to that direction. If the joy projection drops and the output becomes less joyful, those neurons were causal contributors.

The projection is not the whole method, but it captures the core readout: how much the current state points toward one emotion.

What can go wrong

What can go wrong

The dataset can still bias the directions. If the controlled prompts accidentally correlate emotion with topic words or syntax, the learned directions may mix emotion with those confounds because the extraction procedure can only separate what the dataset makes separable.
Circuits may vary across models. A circuit found in one architecture may not transfer directly to another, because different models can implement similar behaviors with different internal decompositions.
Strong control can reduce semantic fidelity. If the intervention is too large, the model may force emotional style at the expense of content accuracy, because the edited state can overpower other signals needed for faithful description.
Done right. Use tightly controlled prompts, verify every candidate with ablation and enhancement, and keep interventions within the range that changes tone without distorting the underlying answer.
What a runnable demo should prove

What a runnable demo should prove

Build a small interpretability pipeline on an open model. Create matched prompt sets where the scenario and event stay fixed while the target emotion changes. Record activations from several layers, learn one direction per emotion, and rank neurons and attention heads by contribution to those directions.

Then run three tests: readout accuracy on held-out contexts, ablation of top-ranked components, and enhancement of the same components during generation. The key result is that the top components should both predict and causally control emotional expression across new contexts, because that demonstrates a reusable circuit rather than a prompt-specific correlation.

control_success = correct_emotion_outputs / total_test_prompts ; causal_drop = emotion_score_before_ablation - emotion_score_after_ablation

The demo succeeds only if the same internal components matter across many prompt contexts and direct edits on those components predictably change the output emotion.
