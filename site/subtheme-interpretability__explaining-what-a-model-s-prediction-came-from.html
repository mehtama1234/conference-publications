Explaining what a model's prediction came from

When a model makes a decision, which inputs mattered most? These papers trace back through the computation to credit the right parts of the input for the output.

All themesField mapMathematicsAll explainers
What this is

When a model makes a prediction, we want to know why. If a language model generates the word 'happy' as the next token, which parts of the input influenced that choice? Was it a specific adjective two sentences back? A pattern in the overall sentiment? These papers compute importance scores: a number for each input element (word, pixel, etc.) telling how much that element contributed to the final answer. This is called attribution or explainability — the goal is to justify the prediction in terms of the input.

Attribution is tricky because causality in neural networks is tangled. Removing one input word changes many neurons, which affect many other computations downstream. Does the importance score measure the direct effect or the total effect? Different methods give different answers. Some use gradient-based methods: how much does the output change if we nudge the input slightly? Others use perturbation: mask inputs and see what breaks. The papers in this area refine these techniques and study when they work and when they fail. The use case is critical: in medicine or law, you need to explain decisions, and a model that points to the relevant evidence is more trustworthy than one that stays silent.

How the work breaks down

These papers split into five directions: how to compute importance scores from gradients (tiny adjustments to inputs to measure sensitivity); how to fairly distribute credit using game theory; how to trace what training data caused each behavior; how to understand what happens inside the model's computation; and how to verify that explanations are actually trustworthy.

Gradient and path-based importance

Importance scores can be computed by looking at gradients: when you nudge the input slightly, the output changes, and the size of that change tells you how much the input mattered. But gradients can be noisy because they only measure local sensitivity. These papers improve gradient-based methods by computing importance along paths that stay close to realistic inputs.

Manifold-Aligned Guided Integrated Gradients fixes a key problem: when you follow a straight path from a blank input to the real input, you pass through unrealistic intermediate states that don't reflect how the model actually works. Instead, the method stays close to inputs the model sees in practice, which means the computed importance scores are more faithful to how the real input influenced the output. Addressing divergent representations from causal interventions improves on causal intervention methods by reducing hidden pathways that activate incorrectly when you intervene. Dissecting Representation Misalignment in Contrastive Learning via Influence Function shows that the way you measure data impact matters more in vision-language models than in plain classifiers, because misalignment between images and text changes how importance flows, and the paper gives a better assessment method.

Shapley values for fair credit

Shapley values come from game theory: they distribute credit fairly among players in a coalition by asking 'what is each input's average contribution across all possible subsets of inputs?' This is theoretically sound but computationally expensive because you need to check exponentially many subsets. The papers here make Shapley values practical and more accurate by using faster algorithms and smarter sampling schemes, so they can scale to real problems.

TN-SHAP-G scales Shapley computation to large graphs by using tensor networks (nested rectangular-array decompositions) to break down the calculation, matching exact values where other methods fail. ShaplEIG reduces complexity from exponential to polynomial by exploiting the special structure of Shapley values and using elementary symmetric polynomials. An Odd Estimator for Shapley Values improves sampling efficiency by using a smarter weighting scheme. Exactly Computing do-Shapley Values computes causal Shapley values exactly with far fewer samples than before, because it only needs to check singleton interventions instead of all possible coalitions. PolySHAP improves on KernelSHAP (a sampling method) by incorporating interaction-aware polynomial regression, so the importance scores account for how inputs work together, not just in isolation. Priority-Aware Shapley Value adds structure: it allocates credit differently when one input must be decided before another, which reflects real-world constraints. TreeGrad-Ranker computes Shapley values for decision trees in linear time instead of the usual exponential time, while satisfying axiomatic properties that guarantees fairness. Verified SHAP scales exact SHAP computation to far larger feature spaces than before, providing a principled benchmark to evaluate whether approximate methods are working correctly.

Data influence and training attribution

Why does a model make a particular prediction? One answer traces back to training: which training examples caused the model to behave this way? These papers develop methods to compute this data influence: a score for each training example saying how much it pushed the model toward the output we see.

Evaluating Data Influence in Meta Learning gives closed-form formulas for how much each training task and instance affects the final model, which makes computation much faster for meta-learning problems. Bayesian Influence Functions for Hessian-Free Data Attribution scales influence computation to billion-parameter networks by avoiding the expensive Hessian matrix (a matrix of second-order derivatives). ExPLAIND unifies three types of attribution: model attribution (which parts of the network fired), data attribution (which training data caused it), and training attribution (when in training did it happen), revealing learning phases in grokking and pretraining. Influence Dynamics and Stagewise Data Attribution confirms that how data influences the model changes as it learns: early on, the model learns simple patterns, so early training data is influential; later, it learns complex concepts, so different data becomes important, and this aligns with known learning stages. Learning to Weight Parameters for Training Data Attribution improves attribution accuracy by learning which parameters matter most for determining training influence, which works across image classification, language modeling, and diffusion. Mechanistic Data Attribution shows causally that repetitive structural patterns in training data are what teaches the model in-context learning: by looking at induction heads (specific neurons that copy patterns), the paper directly traces them back to training examples. PINNfluence adapts influence functions to physics-informed neural networks, showing that influence patterns distinguish between well-trained and poorly-trained models, opening interpretability for scientific computing. Step-Resolved Data Attribution for Looped Language Models computes per-step influence in models that loop internally, giving you insights into which training data caused each step of the reasoning.

Understanding internal mechanisms

Neural networks are black boxes: we can't easily see what computation is happening inside. These papers reverse-engineer the internal mechanisms by looking at neurons, attention heads (parts of the network that weight which inputs to look at), and learned representations, then attributing those mechanisms back to training data or explaining what they do.

An In-Depth Study on Deep Learning Model Cloning defines when two models behave identically and proposes a method to detect clones, which helps trace whether models are reusing the same learned mechanisms because detecting copies reveals when the same computation pattern spreads across different models. Hallucination Begins Where Saliency Drops connects hallucinations in language models to saliency: when attention to the input drops, the model generates false information. By identifying where saliency decays, you can detect hallucinations and reduce them. DecodeShare identifies a hidden linear channel in large language models that controls which token (the next word the model picks) is chosen during generation; removing this channel dramatically hurts performance, proving it is causal and exploitable for steering. Discovering Interpretable Algorithms by Decompiling Language Models to RASP reverses the transformation: given a language model trained on algorithms like addition or sorting, the method reconstructs the algorithm as a readable program, making the computation transparent. Linear Mechanisms for Spatiotemporal Reasoning in Vision Language Models finds that vision-language models use simple linear combinations of features to reason about space and time; identifying these mechanisms shows where the model is weak. Singular Directions of Attention Heads Align with Features proves that the hidden structure of attention heads (their primary directions—the axes their transformations act most strongly along) correspond to semantic features the model learned, giving a sound method to identify what each head represents. Understanding the Emergence of Seemingly Useless Features in Next-Token Predictors discovers that features with extreme influence on future tokens relate to reasoning domains like code, stepping toward understanding how models organize abstract concepts.

Trusting explanations

Explanations are only useful if they are correct. These papers test whether explanations actually reflect why the model made a decision, whether they stay valid when inputs change slightly, and whether they work reliably across domains.

A model of errors in language models predicts when language models fail on repetitive tasks by modeling error accumulation, and validates the prediction across multiple models, grounding explanation methods in observable failure modes. Dyslexify: A Mechanistic Defense Against Typographic Attacks in CLIP improves defenses against attacks by identifying the mechanism (neurons) that cause the model to misclassify misspelled text, then training to activate those mechanisms less, which blocks adversarial attacks. Joint Data-Pattern–Informed Shapley Values for Sparse Counterfactual Explanations ensures that when you change an input to understand the output, the changed input still looks realistic according to how real data actually appears (its probability patterns), not just arbitrary; this matters because it makes explanations correspond to changes the model could actually encounter rather than unrealistic synthetic edits. Missingness Bias Calibration in Feature Attribution Explanations fixes a specific problem in medical domains: when you mask out features to test importance, some features naturally co-occur, and you accidentally mask related features too; the paper corrects for this bias across vision, language, and tabular medical data. Tracing and Reversing Edits in LLMs shows that when you modify a language model's weights to change behavior, you can recover what the original behavior was, meaning edits leave a traceable signature; this validates that interventions have causal content. What LLMs Explain Is Not What They Believe shows that LLM explanations are often insufficient because the model generates an explanation that sounds good but is weakly correlated with what the model actually uses internally to make the decision, and this problem doesn't improve with model size, so bigger models do not automatically give better explanations.
