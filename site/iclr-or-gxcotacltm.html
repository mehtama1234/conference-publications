Perturbed Dynamic Time Warping: Probabilistic Alignment Framework

Make time-series alignment differentiable and probabilistic by randomly perturbing warping costs, then averaging the best paths.

Paper explainersAll themesTime Series & Sequential

When comparing two time series (like two recordings of speech or stock prices), you often need to find which parts match, even if one is stretched or sped up. Dynamic Time Warping (DTW) solves this, but it is not smooth enough to use inside a learning system. This paper adds random noise to the costs and takes the average of the best paths, giving you a smooth version with a clear probability story.

Zero assumption version

Why alignment has no learning direction

When two time series have different speeds or lengths, you need to find which points match. A beginner might just line them up by position, but that fails when one is sped up — the first value of series A should not match the first value of series B if B is twice as fast.

Dynamic Time Warping fixes this: it searches for the best warping path (a way to match positions) by summing the costs along the path and picking the path with the smallest sum. This works perfectly for measuring distance, but it has one fatal flaw: the minimum operator (picking the best path) is not smooth, so you cannot compute which direction to nudge the inputs to lower the cost — there is no learning signal.

Soft-DTW smooths this problem by replacing the minimum with a soft-minimum (a blurred version that is smooth everywhere), making it possible to compute learning directions. But soft-DTW does not explain why this works — it lacks a probability story.

In one sentence. Add random noise to warping costs, take the average best path, and recover a smooth, probabilistic version of alignment.

The algorithm as a flow

What it actually does

Define warping paths

For each pair of time series, list all possible ways to match their positions.

Compute path costs

For each path, sum the distance between matched points.

Add random noise

Perturb each path's cost by a random amount drawn from a Gumbel distribution (a smooth random noise).

Take the expected minimum

For each noise sample, pick the lowest-cost path; then average the results across all samples.

Learn how to adjust inputs

The averaging step is smooth, so you can compute how to change the input series to lower the cost.

What the paper changes

What changes

The paper changes the alignment metric itself — the number that says how similar two time series are. Instead of using a crisp minimum-cost path, it uses a probabilistic average of paths.

the object it moves  =  alignment metric
The hidden quantity

Alignment skewness

measured quantity  =  path-weight skewness

Perturbed-DTW computes a probability distribution over all warping paths. Some paths get high probability (if their cost is low even after noise), and others get low probability. The skewness of this distribution (how much probability mass is concentrated in a few paths versus spread across many) tunes how strictly the alignment focuses on the best path versus considering alternatives.

Under Gumbel noise, this distribution has a particular shape. The paper generalizes to other noise types (generalized extreme value distributions), which change the skewness — a sharper distribution punishes weak paths more, while a flatter distribution lets multiple paths share probability.

Why it works

Why random noise makes alignment smooth

In standard DTW, the best path is a cliff: at one infinitesimal change, the best path switches from path A to path B with no learning signal at the boundary. This is the non-differentiability problem.

Perturbed-DTW adds independent random noise to each path's cost. With noise, a slightly-worse path sometimes becomes the best path (by luck), and the worst path sometimes wins. When you average across all noise samples, the winning path varies smoothly as you change the input. No cliffs, no jumps.

Why is Gumbel noise special? Under Gumbel perturbations, the average of the best paths (the expected minimum) exactly equals soft-DTW — a known smooth function. So the paper provides the missing why: soft-DTW emerges naturally from probability theory. By generalizing to other noise types, you get new variants with different alignment preferences (sharper or flatter distributions), offering control over how strictly paths are ranked.

The equation

First in words:

The perturbed-DTW value is the average of the minimum warping costs, where each cost is perturbed by adding independent random noise to each path.

Then the compact form:

perturbed_DTW = E_noise [ min_path (cost(path) + noise_path) ]

Every symbol:

perturbed_DTWthe alignment distance (what we compute)
E_noise [·]the average over all possible noise realizations
min_paththe lowest-cost path in that noise scenario
cost(path)the sum of distances along that warping path
noise_paththe random perturbation added to that path's cost
A tiny worked example
Suppose two time series have three possible warping paths with costs 10, 12, 15.
Without noise: best path costs 10, so DTW = 10.
Add Gumbel noise: sample 1 gives perturbations [-1, +0.5, +2], so noisy costs are [9, 12.5, 17]. Best is 9.
Sample 2: perturbations [+0.2, -1, +0.1], so costs [10.2, 11, 15.1]. Best is 11.
Sample 3: perturbations [+1, +1.5, -0.5], so costs [11, 13.5, 14.5]. Best is 11.
Average of best paths: (9 + 11 + 11) / 3 = 10.33. This is smoother than the hard minimum of 10.

By averaging, small changes in the input gradually shift which paths are best, creating smooth gradients.

What can go wrong

What can go wrong

Too much noise noise destroys alignment. If random perturbations are too large, they drown out the true cost differences, and any path looks equally good. Use noise scale calibrated to the typical cost range.
Too few samples underestimates the expected minimum. Averaging requires enough noise samples. With too few, the expected minimum will be noisy and unreliable. Use enough samples (or analytic formulas like Gumbel gives).
Wrong noise type for the task. Different noise distributions (Gumbel, Weibull, Frechet) produce different skewness. Pick one that matches how you want to weight tight versus flexible alignments.
Done right. Use Gumbel noise for the reference (soft-DTW) or other GEV families for tuned skewness; use enough samples; and calibrate scale to the cost range.
What a runnable demo should prove

What a runnable demo should prove

Write two time series (e.g., two sine waves with different speeds). Compute crisp DTW (no gradient), soft-DTW (smooth, but no reason why), and perturbed-DTW under Gumbel noise. Show that perturbed-DTW and soft-DTW give nearly identical results, proving the paper's claim that Gumbel noise recovers soft-DTW exactly. Then compute gradients with respect to the first time series and use them to nudge it closer to the second — this proves differentiability. Finally, show that switching to a different noise type (e.g., Weibull) changes the alignment skewness in a predictable way, favoring sharper or flatter path distributions.

alignment_error = |perturbed_DTW - soft_DTW|; gradient_norm = ||d(loss)/d(series)||

The demo must show that noise-based alignment is smooth (gradients exist), matches soft-DTW under Gumbel, and lets you tune skewness via noise choice.
