SynGR: Unleashing the Potential of Cross-Modal Synergy for Generative Recommendation

SynGR improves generative recommendation by forcing the model to use information that appears only when modalities are combined, not just whichever modality is easiest to exploit alone.

Paper explainersAll themesMultimodal

Generative recommendation predicts items as a sequence, often by generating item identifiers directly. When item text, images, and other signals are available, many systems fuse them by emphasizing agreement across modalities. SynGR argues that agreement is not the whole story. Important item properties can emerge only from the interaction between modalities, such as a product whose picture suggests one style while the text reveals a specialized use. The method is built to preserve that interaction by limiting dominance from any single modality and pushing the generator to use cross-modal dependence during decoding.

Zero assumption version

Alignment-only fusion misses item properties that exist only in combination

A recommendation model often sees several item views such as title, description, image, and user interaction history. Standard multimodal fusion tries to align these views so that shared meaning is emphasized. That helps when all useful information is already present in each modality separately, because agreement across views is then enough to recover the item property that drives the recommendation.

But many recommendation decisions depend on joint meaning that no single modality can express alone. A product image may show a formal shoe shape while the title reveals it is waterproof trail footwear. Either modality alone supports the wrong user match. The recommendation model needs the interaction between them. If one strong modality dominates the fusion process, the generator can get high training accuracy by leaning on that modality and ignoring the extra information created by combining them. SynGR is designed to block that shortcut.

Core problem. The best recommendation signal may live in the dependence between modalities, not in the shared part of each modality taken alone.

What the paper changes

What the paper changes

The paper changes the fusion target. Instead of rewarding the model mainly for agreement across modalities, it also rewards the model for preserving useful information that emerges only from their interaction.

The hidden quantity

The hidden quantity: emergent item semantics

measured quantity  =  emergent item semantics

Emergent item semantics are item properties that appear only after combining modalities. They are not just the overlap between image and text, and they are not just the leftover parts unique to each modality. They are properties that require both. For example, an image may show the physical design while the description states the operating context; together they define who actually wants the item.

SynGR treats this joint-only information as the missing piece in standard fusion. If recommendation depends on emergent semantics and the model is allowed to rely on one dominant modality, training may never recover them. The method therefore tries to make those semantics visible and useful during generation.

Why it works

Why constraining dominant modalities helps

The method works because a recommendation model will exploit the easiest predictive path available. If item text alone is already highly informative, the generator can optimize training loss by depending mostly on text and using image features only weakly. In that regime, any signal that exists only in the text-image interaction is unnecessary for the optimizer, so it gets ignored.

SynGR changes that incentive. By constraining overreliance on dominant modalities, it removes the easy one-view shortcut. The model must then preserve and use the information that only appears after modalities interact. This matters because the generator produces item identifiers step by step, and each generation step benefits from a representation that reflects deeper item meaning rather than only surface similarity.

The method also keeps the standard useful pieces of multimodal information: the shared part across modalities and the modality-specific details. The difference is that it does not stop there. Recommendation quality improves when the generator can combine all three sources, because each source removes a different ambiguity. Shared signal captures broad agreement, modality-specific signal captures unique details, and joint-only signal captures the interactions that actually change user preference.

Math after the picture

Balanced generative objective

First in words:

The model optimizes recommendation accuracy while adding a constraint that penalizes overdependence on any one modality and preserves cross-modal interaction signal.

Then the compact form:

total_loss = recommendation_loss + dominance_penalty - joint_signal_reward

Every symbol:

recommendation_lossthe ordinary sequence-generation loss for predicting the next item
dominance_penaltyextra cost when one modality explains too much of the decision by itself
joint_signal_rewardcredit for using information that appears only when modalities are combined
total_lossthe objective minimized during training
A tiny worked example
Suppose text alone predicts the target item fairly well, giving recommendation loss 0.7, but the model almost ignores image information.
Add a dominance penalty of 0.4 because one modality is carrying too much of the decision.
If the model learns a balanced fusion that uses the text-image interaction, recommendation loss drops to 0.6, dominance penalty drops to 0.1, and joint-signal reward rises to 0.3.
The new total becomes 0.6 + 0.1 - 0.3 = 0.4, which is better than 0.7 + 0.4 - 0.0 = 1.1, so training prefers the balanced solution.

The exact terms can vary by implementation, but the important pressure is clear: make one-view shortcuts less attractive and cross-modal interaction more useful.

What can go wrong

What can go wrong

The dominant modality is truly sufficient. If one modality already contains almost all task-relevant information, forcing extra cross-modal use can add noise instead of value. The method helps most when interaction signal is real, not assumed, because only then does the extra constraint recover information the dominant modality truly lacks.
Joint-only signal is estimated poorly. If the system cannot cleanly separate shared information from interaction-dependent information, it may reward the wrong features and make generation unstable.
User history and item modalities are misaligned. If the user behavior data and the multimodal item data refer to different item states or inconsistent catalogs, the model may invent false interactions that do not reflect real preferences.
Done right. The method is strongest when recommendation targets genuinely depend on multimodal interaction and the training data preserves accurate links between user behavior and item content.
What a runnable demo should prove

What a runnable demo should prove

Build a recommendation dataset where some target items can be identified from text alone, some from image alone, and some only from the combination of both. Train an alignment-only multimodal generator and SynGR on the same user sequences. Then slice evaluation by case type: text-sufficient, image-sufficient, and combination-required. Also measure how recommendation quality changes if one modality is ablated at test time.

interaction_gain = recommendation accuracy on combination-required cases with SynGR minus recommendation accuracy on the same cases with the alignment-only baseline

The demo should show that SynGR earns its advantage mainly where recommendation depends on the combined meaning of modalities, because that is the signal the method is explicitly trying to recover.
