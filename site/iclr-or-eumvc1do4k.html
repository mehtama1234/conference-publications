Spatial Forcing: Implicit Spatial Awareness for Robot Action Models

Guide a robot action model to understand 3D space by aligning its hidden layer representations with a 3D-aware teacher model.

Paper explainersAll themesRobotics & Control

Robot action models learn by watching images and predicting movements. But most are trained on flat 2D images only, so they do not understand real 3D space — where objects actually sit, how far away they are, or how to move around them. This paper shows how to teach a robot model spatial understanding by quietly steering its internal representations toward a teacher model that already understands depth, shape, and spatial position.

Zero assumption version

Robot models trained on flat images do not understand real 3D space

Today's best robot action models work like this: you show them a picture, tell them in words what to do (pick up the bowl), and they predict the arm movements. The model starts by learning from a vision-language model, which was trained on 2D internet images and text. That foundation works, but there is a hard limit: the vision model was trained on flat pictures, not 3D scenes, so it never learned where objects sit in real space.

A naive fix is to add depth cameras or lidar (3D sensors) to every robot. But that breaks in the real world: sensors are noisy, different robots have different hardware, and existing datasets do not have clean depth data everywhere. The other approach is to estimate 3D from 2D images using depth prediction models, but those estimators are not accurate enough and do not actually teach the robot model anything structural about space.

The real problem. A robot model trained only on 2D images never learns that the world is 3D, so it makes spatial mistakes when objects are far away, occluded, or in complex positions.

The algorithm as a flow

What it actually does

Step 1: Pass images through the robot model

Multi-view images from the robot camera enter the pretrained vision model. Each layer transforms the image into richer feature representations.

Step 2: Extract intermediate layer outputs

Pause at each layer inside the model and grab its output features. These are what the model currently encodes about the image.

Step 3: Pass the same images through a frozen 3D teacher model

A separate 3D foundation model (one trained on 3D data) processes the image and outputs features for depth, surface shape, and orientation.

Step 4: Align each layer toward the 3D teacher

For each intermediate layer, compute how different its features are from the 3D teacher output. A loss function measures this gap. Then use calculus to compute which weights caused the gap, and nudge them in the direction that shrinks it.

Step 5: Train the full robot model end-to-end

Combine the 3D alignment loss with the normal action prediction loss. The model learns actions while its internal layers grow spatially aware.

What the paper changes

The thing being changed: intermediate layer representations

A vision-language model has many layers stacked inside it. Early layers find edges and colors. Middle layers find shapes. Deep layers find semantic objects. Spatial Forcing targets the intermediate layers (the middle ones) and steers their numerical outputs toward features that encode depth, shape, and position — learned by a teacher model. It does not change the model architecture, just nudges the learned values inside existing layers to encode where objects sit in 3D space.

the object it moves  =  intermediate layer representations
The hidden quantity

The hidden quantity: spatial alignment error

measured quantity  =  spatial alignment error between layers

The paper measures how far apart the robot model's intermediate layer features are from the 3D teacher model's spatial features. This is the alignment error: a number that says how much depth and shape information is missing from each layer. High error means the layer is still mostly 2D-focused. Low error means the layer now encodes where objects are in 3D space.

The paper computes this by comparing pixel-level features from the robot model with pixel-level spatial representations from a 3D foundation model (like VGGT 3D). A two-layer neural network (MLP) reshapes dimensions, then a distance metric (similarity score or L2 norm — how far apart two lists of numbers are) measures the gap. During training, this alignment loss is computed and pushed backward through the layers to adjust weights and make each layer's outputs closer to the 3D teacher's.

Why it works

Why alignment teaches spatial understanding

A pretrained 3D foundation model (trained on real 3D data like point clouds or CAD models) has already learned what 3D space looks like: depth, surface curves, object tilt, and how things relate to each other in space. When you force the robot model's intermediate layers to match that 3D teacher, you are copying that knowledge about space into the robot model.

Here is the causal chain: the alignment loss measures mismatch. Computing which weights caused the mismatch (via calculus), the algorithm nudges the robot model's weights in the direction that reduces mismatch. As weights change, the layer's output representations shift toward the 3D teacher's output. Over thousands of training steps, the robot model's layers gradually encode the same spatial structure the 3D teacher already knows. By the time training finishes, the robot model understands where objects sit in 3D, even though it never saw explicit depth data. The final action prediction head then uses those spatially-aware hidden features to predict accurate arm movements in real 3D space.

Math after the picture

The alignment loss equation

First in words:

Total training loss equals the action prediction loss plus a weighted spatial alignment loss. The alignment loss is the average distance between the robot model layer features and the 3D teacher features, summed across all intermediate layers.

Then the compact form:

L_total = L_action + alpha * sum_i distance(MLP(x^V_i), f_3D(I))

Every symbol:

L_actionloss for predicting the correct robot action (standard training)
alphaweight that controls how strongly to pull toward 3D alignment
sum_isum over all intermediate layers i in the robot model
x^V_ifeature representation from layer i of the robot model
MLP(x^V_i)two-layer neural network that reshapes layer i to match teacher dimensions
f_3D(I)pixel-level 3D spatial features output by the frozen 3D teacher model
distance()how far apart two feature vectors are (cosine distance or L2 norm)
A tiny worked example
Say layer 10 outputs features [0.5, 0.3, 0.8, 0.2]. The 3D teacher outputs [0.6, 0.4, 0.7, 0.1].
After the MLP reshapes layer 10's output to match dimensions, we compute distance: sqrt((0.5-0.6)^2 + (0.3-0.4)^2 + (0.8-0.7)^2 + (0.2-0.1)^2) = sqrt(0.01 + 0.01 + 0.01 + 0.01) = 0.2.
If alpha = 0.1 and this is one of 20 layers, the contribution to the total loss is 0.1 * 0.2 = 0.02.
The algorithm then computes which of layer 10's weights caused this 0.02 penalty, and nudges them so next time it outputs something closer to [0.6, 0.4, 0.7, 0.1].
After many steps, layer 10 learns to encode the same spatial structure the teacher does.

The alignment loss pulls each intermediate layer toward the 3D teacher's spatial knowledge. A small alpha keeps the robot model focused on action accuracy because the action loss dominates and spatial alignment is gentle; a larger alpha forces faster spatial learning because spatial alignment becomes the dominant pressure.

What can go wrong

What can go wrong

Teacher model mismatch. If the 3D foundation model is trained on data very different from the robot's sensors (e.g., indoor CAD models but robot operates outdoors), the alignment pulls the robot model in the wrong direction. The robot learns spatial structure that does not match real environments.
Alignment dominates action loss. If alpha (the alignment weight) is too large, the robot model focuses entirely on matching the teacher and forgets to predict actions. The model learns perfect 3D awareness but useless actions.
Layer saturation. Early layers (shallow ones) already encode simple features. Forcing them too hard toward 3D can degrade their ability to extract edges and textures that later layers need. Constraining only middle-to-deep layers works better because those layers naturally encode shape and spatial layout without losing low-level detail.
Done right. Choose a 3D teacher trained on data close to the robot's domain. Set alpha so the action accuracy does not drop. Align only the middle layers (8-28 out of 32) where shape and spatial layout emerge naturally.
What a runnable demo should prove

What a runnable demo should prove

Train two robot models on the same robotic manipulation task (e.g., picking up objects from a table in simulation). One gets standard training only. The other gets Spatial Forcing with a 3D teacher. Run both on test tasks where the object is at different depths, occlusions, or angles. Measure success rate and the internal representation using a depth probe (train a simple classifier on the frozen robot model's layer outputs to predict depth; if the layer learned depth implicitly, accuracy will be high).

success_rate = (count of correct picks) / (total test trials); spatial_awareness_score = depth_probe_accuracy on intermediate layer representations

The key evidence: Spatial Forcing model succeeds on 3D variations that the baseline misses, and a depth probe on its middle layers shows it learned depth without any explicit depth training signal.
