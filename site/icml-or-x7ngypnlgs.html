Adaptive Memory Retention in Dynamic Graphs

A dynamic graph model that keeps useful information flowing across nodes while actively removing noise, using math inspired by physics systems that conserve energy.

Paper explainersAll themesGraph & Geometric Learning

Real-world networks change over time — social graphs grow, communication links appear and disappear, sensor readings arrive one frame at a time. The challenge is to learn patterns across these timesteps without letting noise pile up. This paper introduces LAMP, which adds a 'drain' mechanism that forgets less-useful information at each layer, letting the model see far into the past without drowning in accumulated junk.

The noise buildup trap

When you stack many graph layers, each one reads what previous layers computed and sends a message to neighbors. But here's the trap: at each layer, every node collects messages from all its neighbors, not just the useful ones. Useful messages carry real patterns; useless ones are random noise from that step. A naive model would just add all messages together, so noise from layer 1 feeds into layer 2, which adds its own noise, which feeds into layer 3... After ten layers, the noise is so loud that the real signal is buried.

Dynamic graphs make this worse. A node might receive a message from a neighbor that was relevant three timesteps ago but is stale now. A naive model would weigh it equally with fresh, recent information. So information accumulates without control — the model cannot distinguish signal from historical junk.

The core problem. Information flowing through graph layers accumulates noise over distance and time, making it hard for the model to learn stable patterns.

What the paper changes

What the paper changes

The paper adds a second, learnable pathway that actively forgets information. The first pathway is conservative: it preserves all information, designed by math to never distort the signal. The second pathway is dissipative: it learns what information is useless noise for your particular task and gradually removes it. Both run in parallel at every layer and timestep.

the object it moves  =  information retention
The hidden quantity

The hidden quantity: dissipation strength

measured quantity  =  learned dissipation rate

The dissipation strength is a number the model learns during training that controls how much to forget at each layer. A high number means aggressive forgetting — only the strongest signals survive. A low number means almost everything is kept. The paper does not prescribe this number; instead, it learns from data which signals matter for your task.

The model estimates dissipation by comparing what happens when you propagate information through a layer with and without the drain. If removing a signal changes the loss (the error on your task), that signal was important and dissipation should be low. If removing it does not change the loss, dissipation can be high — that information was noise anyway.

Plain reading. Think of a conversation in a busy room: some voices carry important information (your friend speaking), others are background chatter. Dissipation is the process of your brain learning to tune out the chatter and amplify the friend.
Paper reading. The paper sets up dissipation using antisymmetric matrices (square tables of numbers arranged so they flip sign when you flip them) and data-driven control, yielding a learned decay rate per layer that balances information retention with noise suppression.
Why it works

Why it works: conservative flow plus learned forgetting

The core move is to split information flow into two independent channels. The first channel is conservative: it is designed using math from physics (a special structure where numbers flip sign when you flip rows and columns) to preserve all information without distortion or leaking sideways. The second channel is dissipative: it learns which information matters for your task and removes the rest by reducing its strength at each layer.

Why does this avoid noise buildup? Because the conservative channel ensures no signal leaks or gets distorted, and the dissipative channel actively removes what is not useful. Layer by layer, useless information is reduced, so noise does not accumulate. Useful signals are preserved by the conservative channel and stay clear all the way to the output.

Math after the picture

The equation: conservative flow plus dissipative loss

First in words:

The change in node values at each timestep is the sum of a conservative part (which keeps information) and a dissipative part (which removes it). The conservative part is antisymmetric, meaning it does not let information leak sideways. The dissipative part is designed to be smooth and data-driven, learning what to forget.

Then the compact form:

dx/dt = A(x) + D(x, theta) where A is antisymmetric (conserves flow) and D is dissipative (removes learned-to-be-useless information)

Every symbol:

xthe node values (representation) at this timestep
dx/dthow the node values change over time (one step)
A(x)the conservative part: how messages flow without leaking, using antisymmetric math
D(x, theta)the dissipative part: how much each node value is reduced, learned from your data
thetathe learnable parameters that control which information to forget
A tiny worked example
Node A has value 10, representing a strong recent message.
Node B has value 2, representing weak noise from three layers back.
Conservative flow A(x) passes both through: node A stays 10, node B stays 2 (nothing lost).
Dissipation D(x, theta) learns that messages like B's are noise. It reduces B by 80% per layer.
After one layer: node A is still 10, node B drops to 2 * 0.2 = 0.4.
After two layers: node A is still 10, node B drops to 0.4 * 0.2 = 0.08 (nearly gone).
After three layers: node A is still 10, node B is 0.008 (truly vanished).
Node A's signal stays clear because it was never noise to forget; node B is gone because the model learned it does not matter for the task.

The conservative channel never leaks information sideways and preserves all flow; the dissipative channel learns to shrink whatever is not useful for your task.

What can go wrong

What can go wrong

Dissipation too aggressive. If the model learns to forget too much, it removes real signal along with noise. The model becomes unable to see long-range patterns because it is forgetting them.
Dissipation too weak. If the model does not learn to forget enough, noise still accumulates and swamps the signal. Stability is not improved.
Task mismatch. Dissipation is learned for one task. If you apply the trained model to a different task where 'noise' suddenly matters, the model fails because it discarded that information.
Done right. The model learns to distinguish real signal from noise for your task, forgets the noise, and keeps accurate representations ten or twenty layers deep without degradation.
What a runnable demo should prove

What a runnable demo should prove

Build a dynamic graph where you control the signal-to-noise ratio: create a toy graph where some messages carry a clear pattern (e.g., 'this node always connects to high-value neighbors') and others are random. Stack many layers. Measure how accurately the model recovers the true pattern after 3, 10, and 20 layers. Compare naive stacking (which accumulates noise) to LAMP (which dissipates it). The demo should make it impossible to miss that LAMP keeps accuracy stable while naive stacking crashes.

depth_stability = accuracy_at_layer_20 / accuracy_at_layer_3; a model with depth_stability close to 1.0 handles many layers well

The model should recover the true pattern even at layer 20, when naive stacking has become nearly random noise.
