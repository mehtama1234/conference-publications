Dimension-Free Multimodal Sampling via Preconditioned Annealed Langevin Dynamics

Preconditioned annealed Langevin dynamics keeps sampling quality stable as the problem grows to higher dimensions by rescaling which weights matter.

Paper explainersAll themesOptimization

To sample from a function with multiple peaks, algorithms like annealed Langevin dynamics gradually smooth out the peaks into a single hill, then slowly sharpen it back up to find all the original peaks. But as the problem grows bigger (more dimensions), errors tend to pile up and destroy the solution. This paper proves you can prevent that pileup by preconditioning: rescaling the smoothing to match the problem's natural shape.

Zero assumption version

Sampling gets noisier in high dimensions

Imagine you want to sample random points from a function with multiple peaks. A naive approach: take random steps with noise added each time, always sliding downhill when you go uphill. That works in 2D. But in 100D, the randomness gets so large that your sampler never settles into the quiet valleys between peaks.

Annealed Langevin dynamics is a smarter walk: first you mathematically blur all the peaks together into one smooth hill, then slowly sharpen the hill back up as you take steps. That forces the walker to explore all the original peak locations. But theory offers no guarantee it stays accurate as the problem grows to 1000D, 10000D. Mistakes pile up invisibly across all those dimensions.

In one sentence. This paper proves that rescaling the smoothing to match the problem's local shape stops errors from piling up across dimensions.

What the paper changes

What the paper changes

Annealed Langevin dynamics already exists. The paper modifies it by adding a preconditioner: a rescaling operator that adjusts how strongly each coordinate responds to the smoothing. This prevents errors from accumulating along coordinates with large curvature.

the object it moves  =  Preconditioner operator in annealed Langevin dynamics
The hidden quantity

Spectral decay: measuring how fast errors vanish

measured quantity  =  Spectrum decay rate of the preconditioner

The hidden quantity is the spectrum of the preconditioner: a list of strengths (called eigenvalues), one for each direction in the function. A fast-decaying spectrum means the first few directions are strongly rescaled, while later directions get weak rescaling.

The paper measures this by checking: does the preconditioner's spectrum decay fast enough that when you add up all the errors across directions, they do not blow up? If yes, dimension-uniform stability holds.

Plain reading. The preconditioner is like a volume knob that turns down differently on each radio channel. Some channels (important directions) get full volume, others (less important) get quiet. If the volume decay is steep enough, no single channel ever gets so loud that it breaks the speaker.
Paper reading. The spectrum of the preconditioner must decay sufficiently fast (e.g., exponentially) so that coordinate-wise error accumulation is controlled by a finite constant independent of problem dimension.
Why it works

Why rescaling by spectrum prevents error accumulation

Errors in a random walk grow like the square root of time. In D dimensions, you have D independent sources of error. Without correction, they add up: total error scales like sqrt(D times each error). That is why naive algorithms fail in high dimensions.

Annealing helps because it merges all peaks into a single smooth hill early on, so the walker cannot get stuck in a single valley—then as smoothing is gradually removed, the walker naturally spreads across all the true peaks. But if the function is bumpy in some directions and smooth in others, the bumpy directions still accumulate errors as you add more dimensions. Preconditioning fixes this by rescaling: strong rescaling on bumpy directions holds the walker steady there (since those directions are naturally noisy), weak rescaling on smooth directions lets it move freely. The key is spectral decay: if rescaling gets weaker fast enough (exponentially), then the total error across all dimensions stays bounded by a constant, independent of D, because the sum of all mistakes follows a convergent series that never exceeds a limit.

Math after the picture

The key equation and worked example

First in words:

Error-bound equation: total-error grows like sum-over-dimensions of (spectral-weight-i times coordinate-error-i), but if weights decay exponentially, the sum stays finite.

Then the compact form:

E[error] <= C * sum_{i=1}^{D} lambda_i * e_i

Every symbol:

E[error]Expected total error when sampling
CA constant independent of D (the number of dimensions)
lambda_iThe i-th spectral weight (strength of rescaling in direction i)
e_iThe error in direction i (grows as sqrt(time / dimension))
DNumber of dimensions in the problem
A tiny worked example with 6 dimensions
Suppose each direction has baseline error e_i = 0.1.
Without preconditioner, all lambda_i = 1, so total error = 1.0 * 0.1 * 6 = 0.6.
With preconditioner using exponential decay lambda_i = 2^(-i): lambda_1=1.0, lambda_2=0.5, lambda_3=0.25, lambda_4=0.125, lambda_5=0.0625, lambda_6=0.03125.
Total error = 0.1 * (1.0 + 0.5 + 0.25 + 0.125 + 0.0625 + 0.03125) = 0.1 * 1.96875 ≈ 0.197.
The sum converges even if you added more dimensions: adding dimension 7 with lambda_7=0.0156 adds only 0.00156 to the total.
Result: preconditioner shrinks error by 3x while keeping the error bounded as D grows.

Fast spectral decay means a finite sum of weighted errors replaces an unbounded accumulation.

What can go wrong

What can go wrong

Spectrum does not decay fast enough. If the preconditioner's spectrum decays slowly (e.g., polynomially instead of exponentially), errors still accumulate as D grows. The method requires fast decay.
Direction-guesses are badly biased. The paper assumes errors in your uphill-direction guesses are small and random. If your score model is systematically wrong (always too steep or always too shallow), preconditioning cannot fix that.
Smoothing covariance and preconditioner are mismatched. The spectral condition links the smoothing matrix to how bumpy the function is. If you choose them independently, you lose the dimension-uniform guarantee.
Done right. If the preconditioner spectrum decays fast, the smoothing covariance is well-tuned to the target, and scores are roughly accurate, the method samples from all peaks with bounded error regardless of dimension.
What a runnable demo should prove

What a runnable demo should prove

Build a simple 2D target: two bell-shaped peaks far apart, then embed it in 10D, 100D, 1000D by repeating the pattern in higher coordinates. Sample from each version using: (1) naive Langevin, (2) annealed Langevin alone, (3) preconditioned annealed Langevin with exponentially decaying spectrum. Measure the divergence (a mismatch score between the samples you drew and the true target bell-curves) for each method at each dimension. Plot it.

divergence = sum_{peaks} (sample-density at peak - true-density at peak) / true-density

The preconditioned method's KL should stay roughly flat across dimensions, while the others climb steeply.
