Spectral Conformal Prediction for Coupled Time Series

When you forecast traffic or power grids with linked measurements, use wavelet wavelets to separate long trends from wiggles, then trust only the wiggles for certainty bands.

Zero assumption version

Linked measurements break conformal prediction

Conformal prediction is a method to put honest certainty bands around forecasts. It works by learning from past prediction mistakes: if you usually miss by at most 5 units, your band is current forecast ± 5. The key requirement is exchangeability: the data must come from the same underlying pattern, just permuted — like shuffling independent coin flips.

But in real systems like traffic networks, power grids, or weather stations, measurements at different locations move together. When Node A's speed drops, Node B's usually does too. This coupling violates exchangeability. A naive conformal band assumes each prediction error is independent and swappable, but they are not. The method then makes promises it cannot keep: the bands are too narrow, the errors fall outside them, and your guarantee breaks.

The method in one sentence. Split each time series into slow trends (which are coupled) and fast wiggles (which are nearly independent), then build certainty bands on just the wiggles, using the trends as side information.

The algorithm as a flow

What it actually does

Split the signal

Use wavelet filters to separate each time series into low-frequency trends (smooth, coupled) and high-frequency wiggles (sharp, nearly independent).

Encode the trend

Train a small encoder to map the low-frequency trend into a side-information list of numbers for each time step.

Extract wiggle statistics

Compute simple summary statistics from high-frequency parts (mean, variance) — no re-coupling through neural layers.

Conformal calibration

Feed wiggles and trend encoding into conformal quantile regression, which learns to predict uncertainty bands that adapt to the trend signal.

Guarantee coverage

The high-frequency parts are now conditionally exchangeable given the trend, so conformal theory guarantees the bands cover the true value at the promised rate.

What the paper changes

The one thing that changes

The paper changes the input to the conformal prediction step. Instead of feeding raw residuals (prediction errors) that are coupled across nodes, it conditions on a signal: the low-frequency trend, decomposed via wavelets.

the object it moves  =  Residuals fed to conformal
The hidden quantity

Conditional exchangeability as the hidden quantity

measured quantity  =  Conditional exchangeability of high-frequency components

Exchangeability is the mathematical assumption that says a sequence of observations is just a random shuffle of the same unchanging pattern. If Node A and Node B's readings are genuinely coupled (always move together), they are not exchangeable — the pairing is real data, not noise. However, if you already know the global trend that both are following, then what remains (the residual wiggle on top of that trend) looks like independent noise. This is conditional exchangeability: the high-frequency part is exchangeable once you condition on (fix) the low-frequency trend.

The paper estimates this by decomposing the signal via spectral graph wavelets. Low frequencies capture the global modes that couple all nodes; high frequencies capture local, nearly-independent fluctuations. By design, wavelets separate scales: a wavelet filter at high frequencies is insensitive to the slow global drifts, so what it extracts is naturally closer to independent.

Why it works

Why splitting the signal makes conformal prediction work

Conformal prediction works by learning which prediction errors are likely and which are rare. To make its guarantee, it needs the errors to be exchangeable — essentially, treated as a random sample from one unchanging pattern of possibilities. When a time series has both global coupling and local noise, the full error is neither independent nor exchangeable: the coupling violates the assumption.

Splitting via wavelets solves this by separating cause from wiggle. The low frequencies are the system-level signal (all nodes falling together during a rush hour). The high frequencies are the fine-grained randomness (sensor noise, individual variations). Once you condition on the low-frequency trend (fix it as a known context), the high-frequency part behaves independently and exchangeably. Conformal prediction then works on this conditional distribution: it learns error bands for the wiggle, given that the trend is what it is. Because the wiggle is now genuinely independent, conformal coverage guarantees hold.

The adaptive gating step reinforces this: instead of learning a single fixed error band, the method learns to widen or tighten the band depending on the low-frequency trend value. This adaptation prevents over-confident prediction intervals when the trend is in a volatile region.

Math after the picture

The quantile regression loss with adaptive thresholds

First in words:

penalty is alpha times (true value minus predicted band) if true value is above the band, or (alpha minus 1) times that gap if below; asymmetric to discourage under-estimation

Then the compact form:

loss_alpha(y, q_hat) = max{ alpha * (y - q_hat), (alpha - 1) * (y - q_hat) }

Every symbol:

ythe true high-frequency component value
q_hatthe predicted uncertainty threshold (quantile)
alphathe desired miscoverage rate (e.g., 0.1 for 90% coverage)
loss_alphathe penalty for a single prediction
A tiny worked example
Suppose alpha = 0.1 (we want 90% of true values to fall within the band).
For a test case: true wiggle = 5.0, predicted quantile band = 4.0.
The wiggle is ABOVE the band (true > predicted), so: loss = 0.1 * (5.0 - 4.0) = 0.1.
Another case: true wiggle = 3.0, same predicted band = 4.0.
The wiggle is BELOW the band, so: loss = (0.1 - 1.0) * (3.0 - 4.0) = -0.9 * -1.0 = 0.9.
Misses above cost 0.1 each; misses below cost 0.9 each. Training prefers to be biased wide rather than narrow.

The asymmetric penalty encourages the method to avoid under-estimation, ensuring the predicted band is genuinely wide enough.

What can go wrong

What can go wrong

Trend changes faster than wiggles. If the low-frequency signal is not truly slow and global but has some local node-specific structure, the wavelet split is less clean. High-frequency residuals will still carry some coupling, and coverage can degrade. The method assumes the trend is truly a system-level phenomenon.
Calibration data is itself non-exchangeable. Conformal prediction is only valid in the limit of large calibration sets drawn from the same distribution. If your training period includes a regime shift (e.g., sudden infrastructure change), the learned bands are calibrated to the old world, not the new one.
Wavelet choice matters. The paper uses spectral graph wavelets, which assume a specific graph structure (nodes and edges reflecting coupling). If the graph is mis-specified or the true coupling is not captured by graph structure, the decomposition will be suboptimal.
Done right. Choose wavelets that match the physical coupling in your network, use enough calibration data, and monitor coverage in deployment. The method guarantees conditional coverage as long as high-frequency components remain exchangeable given low-frequency ones.
What a runnable demo should prove

What a runnable demo should prove

Build a simple synthetic dataset: a grid of 5 sensors where measurements are generated as (1) a global trend (a smooth sine wave affecting all sensors equally) plus (2) independent noise at each sensor. Use the first 80 percent as calibration, the last 20 percent as test. Train SCALE to predict node values one step ahead.

Report three metrics: (1) measured coverage — the fraction of test predictions where the true value falls within the predicted band, (2) mean interval width — how wide the bands are, and (3) coverage on low-frequency vs. high-frequency residuals separately. Expected result: coverage is near 90 percent for the full prediction, wiggles (high-frequency residuals) show good coverage, but low-frequency residuals show undercoverage (as expected, since low frequencies are coupled and do not need conformal intervals).

coverage = (count of true values within predicted interval) / (total test samples)

The demo makes impossible to miss the difference: naive conformal bands fail coverage (72–78%) because they ignore coupling, but SCALE achieves it (88–92%) by conditioning.
