Discrete Adjoint Schrödinger Bridge Sampler

Learn a discrete sampler by treating generation as a controlled random jump process from a source distribution to a target distribution and training the control with adjoint matching.

Paper explainersAll themesOther

Many modern samplers generate continuous values, but many real targets are discrete: symbols, categories, text pieces, or molecular choices. In discrete spaces, small perturbations do not produce usable derivatives, so methods that rely on smooth motion in continuous space do not transfer directly. This paper extends the Schrödinger bridge view of sampling to discrete state spaces. A Schrödinger bridge is a minimum-control path problem: start from a simple source distribution, meaning a weighted set of starting states, end at the target distribution, meaning a weighted set of desired final states, and pay as little control cost as possible along the way. The paper shows that the core adjoint matching idea does not depend on continuous coordinates. Under a cyclic group structure, meaning each discrete coordinate supports wrap-around addition within a finite set, the method can define reference jumps, learn control ratios, and alternate between a controller and a corrector to produce target samples with lower training cost than many discrete samplers.

Zero assumption version

Why discrete sampling is harder than continuous sampling

In continuous spaces, many sampler-training methods can ask how the output changes under a tiny movement. In discrete spaces, there is no smaller version of changing one category into another. A method therefore needs a different way to describe motion from simple samples to target samples.

The Schrödinger bridge formulation gives that description by turning sampling into path control. Instead of learning one direct jump from source to target, it learns how the probability of discrete jumps should change over time so that the whole random process ends at the target distribution with low control cost.

The paper's move in one sentence. Build a discrete random jump process with the right algebraic structure, then learn the bridge control by adjoint matching rather than by expensive pathwise optimization.

The algorithm as a flow

What it actually does

Choose a discrete reference process

Define a continuous-time Markov chain, meaning a random process that jumps between discrete states over time, with simple reference jump rates that are easy to simulate.

Impose a cyclic group state structure

Represent the state space so additions and differences stay inside the finite discrete set, because adjoint matching needs a consistent way to describe how one state changes into another under reference jumps.

Learn a controller

Train a model that changes the reference jump tendencies over time so the path gradually bends toward the target instead of wandering under the uncontrolled process.

Learn a corrector

Train a terminal correction model that ties the end of the path to the target distribution, because the controller alone can shape trajectories but still miss the exact final mass allocation.

Alternate the two updates and sample

Update controller and corrector in turn, then run the learned jump process with time discretization to generate target samples.

What the paper changes

What the paper changes

The paper changes where adjoint matching can be used. It shows that the core training idea can be reformulated for discrete jump processes, provided the state space and reference process are chosen so the needed ratios and shifted states remain well defined.

The hidden quantity

The hidden quantity

measured quantity  =  the optimal time-varying jump adjustment that turns the reference process into the target-reaching bridge

The sampler never observes this ideal control directly. It only sees source samples, target samples, and simulated paths under the current model. The hidden quantity is the jump adjustment that would make every intermediate move contribute to the right final target mass.

In discrete spaces this quantity is subtle because moving probability mass is about changing jump rates, not sliding points through coordinates. The controller and corrector split that job: one shapes the path law over time, and the other enforces the terminal relation to the target.

Why it works

Why the discrete bridge construction works

The reference process matters because it provides a baseline law over paths that is easy to simulate. The bridge then only has to learn how to tilt that law toward the target, not how to invent a path process from nothing.

The cyclic group structure matters because the method repeatedly compares a state with a shifted version of the same state. Those comparisons must stay inside the same finite state space or the required ratios are undefined. The wrap-around algebra gives a closed update rule for those shifted states.

Alternating controller and corrector updates matter because the bridge has two responsibilities. The path must move in sensible directions at intermediate times, and the final time must match the target distribution. If the method trains only the controller, the endpoint can drift. If it trains only the terminal correction, the intermediate path can become inefficient or unstable.

Math after the picture

The bridge control objective

First in words:

find jump control that reaches the target while paying small deviation cost from the reference process

Then the compact form:

min_u E[ integral control_cost(u_t, X_t) dt + terminal_cost(X_1) ]

Every symbol:

u_tthe time-varying control that changes jump tendencies at time t
X_tthe discrete state at time t along the random jump path
control_costthe penalty for deviating from the reference jump process
terminal_costthe penalty that enforces agreement with the target distribution at the final time
A tiny worked example
Suppose the reference chain jumps left or right with equal rate, but the target puts much more mass on states near the right side.
A learned controller increases rightward jump rates early in the path and decreases them later when enough mass has already moved.
If the controller pushes too hard, the control cost rises.
If it pushes too weakly, the terminal cost rises because the endpoint misses the target distribution.
Training searches for a balance where the target is reached without using unnecessarily strong jump distortions.

The discrete bridge view turns sampling into a controlled path problem, so the sampler is learned through path-cost tradeoffs rather than direct one-step prediction alone.

What can go wrong

What can go wrong

The state space may not fit the required algebra. If the discrete variables cannot be represented with the needed wrap-around structure, the shifted-state comparisons used by adjoint matching become hard to define cleanly.
The reference process may mix too slowly or too quickly. A very weak reference process fails to explore enough states, while a very strong one erases useful structure and forces the controller to undo too much random motion.
Alternating updates can fall out of sync. If the controller is much stronger than the corrector, or the other way around, one part may train on stale supervision from the other part because the alternating updates assume both components improve on a similar timescale.
Done right. Choose a reference jump law with good coverage, verify that the state encoding supports the required shifted-state operations, and balance the controller and corrector update schedule so both parts improve together because each component supplies supervision that the other component immediately reuses.

What a runnable demo should prove
