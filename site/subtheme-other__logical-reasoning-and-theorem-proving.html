Logical reasoning and theorem proving

Papers on making models reason step-by-step through logic puzzles, prove theorems, solve math, and identify errors in their own reasoning.

What this is

Neural networks are good at pattern matching but often fail at tasks that require step-by-step logical reasoning. If you ask a model to solve a math problem or prove a theorem or find a logical error in an argument, it needs to think through the steps methodically, not just pattern-match. This is different from recognizing an object in an image or translating a sentence. It requires the model to break a problem into smaller pieces, reason about each piece, and combine the results — and to recognize when a line of reasoning is wrong.

The challenge is that logical reasoning requires symbolic manipulation — keeping track of abstract rules and facts and applying them correctly. Neural networks work with numbers and patterns, not symbols. Teaching them to do logic requires giving them ways to represent logical statements, rules for applying those statements, and ways to verify that the reasoning is correct. You also need to handle incomplete knowledge — in the real world, you never have all the facts, so the model has to fill in gaps by reasoning about what might be true given what it does know, without jumping to conclusions.

Researchers combine symbolic reasoning with neural learning. Some train models to output step-by-step proofs, where each step is explained and can be checked. Some use neuro-symbolic architectures, where a neural network learns patterns while symbolic engines handle the logic. Some use transformers (a type of neural network that can handle sequences) in new ways, teaching them to reason through transformations of knowledge step by step. Some teach models to generate test cases or counterexamples to verify their reasoning. The goal is a system that thinks methodically, can explain its reasoning, and can recognize when it is stuck.

How the work breaks down

The work in this subtheme splits into five natural directions: proving theorems by learning from successful proofs and getting feedback; training models on diverse problem-solving patterns so they think through many different kinds of logic; building models that reason about relationships in space and abstract structure; using multiple smaller models together to solve complex math problems instead of trying to do it all in one big model; and exploring new neural architectures that can think symbolically rather than just pattern-matching.

Theorem Proving with Feedback

Teaching a neural network to prove theorems in formal systems like Isabelle requires the model to output chains of reasoning where each step is verifiable and correct. The challenge is that most proofs fail partway through: the model picks a wrong step and the whole attempt falls apart. The network needs both good data to learn from and feedback about which attempts work, so it can steer toward successful reasoning paths.

The Neural Theorem Proving paper addresses this by doing two things: first, it picks training data carefully, selecting proofs that are high-quality and likely to teach the model good reasoning. Second, it adds a verifier that checks each step and provides feedback, so the model learns what works and can adjust on the fly. This dual approach pushes the model from basic success to near-90% accuracy on hard proofs, because the model doesn't just memorize patterns—it learns to steer itself when it's about to go wrong.

Enhancing Neural Theorem Proving via High-Quality Proof Selection and Verifier Feedback
Fine-tuning on PSR-selected data achieves 84.8% Pass@64; with dynamic feedback-based optimization reaches 90.6% Pass@64, establishing new state-of-the-art for neural theorem proving in Isabelle.

Diverse Reasoning Patterns at Scale

Math reasoning problems—whether they're competition problems or step-by-step calculations—often have multiple valid paths to the answer. A model trained on only one way of thinking will miss others and get stuck. The real challenge is that adding diverse examples multiplies the data needed, and most datasets are expensive to create.

The Diverse Chains of Thought paper shows that with just 10 billion pieces of training text showing varied problem-solving examples, you can train a specialized mixture-of-experts model that learns many different reasoning approaches. The effect is large: the model improves 9.6% on hard competition math problems and gains an extra 7.8% headroom to improve further through learning. This matters because it proves you don't need massive data—you need *varied* data that shows the model multiple ways to think through the same problem.

Expanding Reasoning Potential in Foundation Model by Learning Diverse Chains of Thought Patterns
Only 10B-token data enables MoE model to improve 9.58% on AIME 2024-2025 and raise RL performance upper bound by 7.81%.

Spatial and Structural Reasoning

Some reasoning problems require thinking about how things relate in space or how parts connect to form larger structures. A person solving a spatial puzzle needs to hold a mental model—where is object A relative to object B?—and test whether their understanding fits all the clues. Algorithms for designing solutions also require understanding how components fit together in a design space.

Minimal Sufficiency in Spatial Reasoning attacks this head-on: it shows that you can make spatial reasoning accurate and interpretable by identifying only the information you truly need, filtering out noise. The model learns to show its reasoning path step by step, so you can see whether the model actually understands the spatial relationships or just got lucky.

Code Similarity for Algorithm Design takes the structural angle differently: when an LLM designs a new algorithm, it can search through many possibilities, but naive search wastes time on similar bad ideas. The paper shows that by measuring code diversity—distinguishing truly different approaches from minor variations—the model explores the design space better and finds better solutions. It also provides a tool to analyze what properties make an algorithm work; because the model can now see what makes a solution tick, it builds better algorithms next time.

Pursuing Minimal Sufficiency in Spatial Reasoning
Significantly improves accuracy and achieves state-of-the-art performance on challenging spatial reasoning benchmarks with interpretable reasoning paths.

Orchestrating Smaller Models

Running one giant model is expensive and slow. If you could split the work between smaller, faster models, each one focused on a specific type of problem, you might solve harder problems faster and cheaper because smaller models need less compute. The catch is coordinating them: which model tackles which piece? How do you combine their answers?

SLM-MUX (Small Language Model Multiplexer) solves this by building a router that sends each piece of the problem to the best small model for that task. On math problems, this mixture of small models beats a much larger model on some problems because each small model is specialized, and always improves over any single small model because multiple perspectives catch more cases. Why? Small models are fast and cheap to run, and they work best when each one focuses on a specific type of problem and they cooperate to handle the full range. Because reasoning systems can now solve problems faster and cheaper without losing accuracy, they become practical to deploy in real applications.

SLM-MUX: Orchestrating Small Language Models for Reasoning
SLM-MUX achieves up to 13.4% improvement on MATH, 8.8% on GPQA, and 7.0% on GSM8K, with two SLMs outperforming Qwen 2.5 72B on some benchmarks.

Alternative Neural Reasoning Architectures

Transformers (the neural networks used in ChatGPT and similar models) think left-to-right, reading and writing words in sequence. But logical reasoning sometimes benefits from thinking differently—maybe by considering multiple possibilities in parallel, or by building up knowledge symmetrically rather than just left-to-right.

A Biologically Plausible Dense Associative Memory explores reasoning using patterns inspired by how brains actually work. Instead of sequential processing, this approach stores and retrieves information in distributed patterns, which can hold an exponential amount of knowledge in a compact space. The brain's approach is different from a transformer, but it might handle certain reasoning tasks better because the knowledge is stored as relationships, not sequences.

Masked Diffusion Language Models (MDMs) take another angle: instead of predicting the next word in a sequence, they learn to fill in masked (hidden) words, considering context from all directions at once. This is fundamentally different from transformer thinking. The paper shows that MDMs can solve all the logical problems that step-by-step reasoning transformers can, and they have an advantage on certain types of logic problems (like recognizing regular patterns) because they reason symmetrically instead of left-to-right, which means they see the full context at every step. For problems where you need to see all the pieces before reasoning (like pattern recognition), this symmetric approach catches things left-to-right thinking misses.

A Biologically Plausible Dense Associative Memory with Exponential Capacity
Achieve exponential capacity in hidden units (provided visible units sufficiently larger) with distributed representations preserving class-discriminative structure.
On the Reasoning Abilities of Masked Diffusion Language Models
Shows MDMs can solve all problems CoT-augmented transformers can, with inherent efficiency advantages for certain classes like regular languages.
