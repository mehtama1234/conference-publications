Sinkhorn Normalization of Diffusion Kernels

Rescale any similarity matrix into a smooth operator that behaves like heat diffusion on irregular shapes.

Paper explainersAll themesGraph & Geometric Learning

When you want to smooth a signal (blur it gently based on neighbors), the best method on flat spaces is the heat equation from physics—it spreads information evenly and has strong guarantees. But on irregular shapes like point clouds or voxel grids, you do not have the structure to build that equation. This paper shows how to take any similarity measure and rescale it to act like heat diffusion, using a symmetric variant of the Sinkhorn algorithm.

Zero assumption version

Smoothing on irregular shapes breaks down

On a flat 2D grid or a smooth surface such as a sphere, the standard move is to use the Laplacian: take the average of neighbors, subtract your own value, and multiply by a tiny timestep. Repeat that many times and you get heat diffusion—the signal spreads outward in a predictable, well-behaved way. Mathematicians proved this works and what it does.

But on irregular data—a point cloud (scattered points in space), a sparse voxel grid (a checkerboard of filled boxes), or a mixture of Gaussians (overlapping bumps)—you cannot just use neighbors. Simple convolution kernels, which compute a weighted average based on how similar or close two points are, have a hidden bias: they treat the boundary of the shape differently than the interior. Points near the edge get penalized and treated as less important, even though they should count the same way.

You are left with a dilemma: use a principled operator (the Laplacian) that requires structure you do not have, or use simple kernels that work but carry invisible bias.

In one sentence. Rescale a weight table to act like heat diffusion, removing boundary bias on irregular shapes.

What the paper changes

The paper rescales the similarity or adjacency matrix (the table of how close pairs of points are) using a symmetric variant of the Sinkhorn algorithm. The goal is to rebalance that table so it acts like the heat diffusion operator, removing the hidden boundary bias.

The hidden quantity

Row-sum balance and spectral structure

measured quantity  =  Diffusion-like spectral properties

When a similarity kernel is applied naively on irregular data, each row (the weights assigned to a single point's neighbors) has a different sum. Points near boundaries get weaker total support. The hidden quantity this paper measures is whether the rescaled matrix retains the spectral properties of a true Laplacian—the pattern of eigenvalues and eigenvectors that determines how signals smooth and spread.

The paper estimates this by checking that after Sinkhorn rescaling, the rows and columns all sum to the same value (a property called balanced or doubly random: each row sums to one, each column sums to one), and verifying that the rescaled matrix's eigenvalues match the structure of heat diffusion.

Why it works

Why rescaling fixes boundary bias

Start with a similarity matrix: rows are points, columns are neighbors, entries are how similar or close they are. If you apply this directly to smooth a signal, each point's new value is a weighted average of neighbors. But on irregular shapes, high-similarity pairs (like two points very close in the interior) get strong weights, while boundary points have fewer close neighbors so their weights are weak and spread out.

The Sinkhorn algorithm rescales the matrix symmetrically: it multiplies each row and each column by a scaling factor chosen so all rows sum to the same value, and all columns sum to the same value. This is like saying: 'every point must send out total influence equal to every other point, and every point must receive total influence equal to every other point.' It forces balance.

Because the rescaling is symmetric (rows and columns balanced together), it does not just hide the imbalance—it removes the structural bias. The resulting matrix now has the mathematical signature of heat diffusion: its eigenvalues (the spectrum) match those of a Laplacian, which means signals smooth in a predictable, mathematically sound way. Interior and boundary are treated fairly.

Math after the picture

The Sinkhorn rescaling formula

First in words:

For each iteration, multiply each row by one scaling factor, then each column by another, such that all rows and columns sum to one. Repeat until convergence.

Then the compact form:

K_new = D_L K D_R, where K is the similarity matrix, D_L and D_R are diagonal scaling matrices chosen so row_sums(K_new) = column_sums(K_new) = 1

Every symbol:

Kthe original similarity or adjacency matrix (one entry per point-pair)
D_Ldiagonal matrix scaling the rows (each diagonal entry rescales one row)
D_Rdiagonal matrix scaling the columns (each diagonal entry rescales one column)
K_newthe rescaled doubly-random matrix after Sinkhorn
A tiny worked example with 3 points
Original similarity matrix K (rows sum to different amounts): row 1 sums to 10, row 2 sums to 7, row 3 sums to 13.
Goal: each row should sum to 1 (so normalize each row). After row-scaling: each row sums to 1.
But now columns have different sums. Apply column-scaling so each column also sums to 1.
Repeat row-scale, then column-scale a few times (usually converges in 20 iterations).
Result: a doubly random matrix where every row and every column sums to 1. This is symmetric in its treatment of all points.

The rescaling forces every point to send out the same total 'influence' and receive the same total 'influence,' removing the boundary bias that plagued the original similarity kernel.

What can go wrong

What can go wrong

Sinkhorn does not converge on very sparse matrices. If the similarity matrix is so sparse (mostly zeros) that some rows or columns have no connection to the rest, the algorithm can cycle forever or blow up. You need the matrix to be reasonably connected.
Rescaling changes the original similarity metric. The Sinkhorn normalization rebalances the kernel by design, so the rescaled weights no longer directly reflect the original similarity or distance. You are trading interpretability for fairness.
Computational cost grows with matrix size. For a point cloud with N points, the similarity matrix is N by N, and Sinkhorn takes many iterations. On very large datasets this can be slow.
Works best when input similarity is positive. The Sinkhorn algorithm assumes all entries are non-negative (no negative similarities). If your kernel has negative entries, you need a different approach.

Compare the smoothed result using the naive kernel versus the rescaled kernel. Visualize both side by side and measure the boundary bias: how much worse does the naive method do at boundary points compared to interior points? Show that Sinkhorn reduces this bias.

boundary_bias = (interior_smoothness_error - boundary_smoothness_error) / interior_smoothness_error, target: <5% (naive: >20%)

The demo makes it impossible to miss: with Sinkhorn, interior and boundary points smooth uniformly because row sums are balanced, making the operator treat all points fairly; without it, edges are visibly worse because the original kernel has weak boundary weight totals.
