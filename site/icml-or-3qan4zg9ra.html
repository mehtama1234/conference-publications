Spectral Structure in Attention: Why Trained Weights Collapse and Scale

Attention layers recover their learned patterns in a strict order by importance, creating predictable scaling laws and weight collapse.

Paper explainersAll themesLearning Theory

When you train an attention layer, its weight matrices do not fill up randomly—they show strange, reproducible patterns: most dimensions vanish, a few stay important, and some stick out as isolated outliers. This paper explains why. Using mathematical tools from physics, the authors show that attention layers learn by recovering one pattern at a time, strongest first, like unpacking a filing cabinet in order of importance. This ordered recovery creates predictable rules for how performance scales.

Zero assumption version

Attention weights hide their learning strategy

When you train a neural network with attention (the mechanism that lets a model focus on important parts of the input), something strange happens: the learned weights do not spread out evenly. Instead, most dimensions go to zero, a few stay strong, and a handful stand out as extreme outliers. This is reproducible and shows up everywhere, from small models to the largest language models. Yet nobody knew why.

A beginner might guess: maybe the optimizer just prefers simple, low-rank solutions by accident. But that does not explain the isolated outliers, or why the pattern is so consistent. The true reason turns out to be much deeper.

The mystery. Trained attention layers show low-rank collapse and spectral outliers, but the cause was unknown.

What the paper changes

What the paper changes

The paper changes how we think about the query and key matrices (the learnable weights that shape what the attention layer focuses on). Instead of treating them as a single block, standard training factorizes them—updates them separately—which turns out to have a hidden benefit: it induces a strong bias toward learning one strong pattern at a time, in order of importance.

the object it moves  =  factorized query–key training
The hidden quantity

The hidden quantity: spectral power

measured quantity  =  the strength and order of each feature

Every trained attention layer has a spectrum—a ranking of its dimensions from strongest to weakest. The paper names this precisely: the singular values (a list of numbers) of the product of query and key weights. Singular values measure how strongly each underlying feature fires. A high singular value means a strong feature; a low singular value means the feature is weak or unused.

The paper estimates these singular values by solving a theoretical model (using approximate message passing, a technique from physics), and shows that their order and their sizes follow a universal law: features are recovered one-by-one, strongest first, and the test error drops in steps as each new feature unlocks.

Why it works

Why it works: ordered feature recovery

The core mechanism is sequential recovery. The learning algorithm does not learn all features at once. Instead, it recovers them in a strict order: the strongest pattern first, then the next strongest, and so on. This order is determined by the structure of the training task—targets with power-law spectra (many weak features, a few strong ones) induce this ordered progression automatically.

Why? Because of the implicit bias induced by factorized training. When you update the query and key matrices separately, rather than directly updating their product, you add a hidden constraint: the solution must be low-rank in intermediate stages. This constraint naturally biases the optimizer toward learning one dominant feature at a time, in decreasing order of strength.

As each feature recovers, test error drops. The result is a predictable power-law scaling law: the slope and breakpoints of the learning curve are written into the task structure itself, not the architecture. This is why the same power-law patterns show up across different models and tasks.

Math after the picture

The scaling law equation

First in words:

The test error is determined by which spectral modes have been recovered so far. As you train longer (increasing the sample size or reducing regularization), each mode unlocks in turn, dropping the error by an amount tied to its strength.

Then the compact form:

e_test = E_z0,z_target [ sum_a ||sigma_target(sqrt(2)z0) - sigma_learned(sqrt(2)z)||^2_Frobenius ]

Every symbol:

e_testthe test error—how wrong predictions are on new data
sigma_targetthe activation function applied to the target (what the model should learn)
sigma_learnedthe activation function applied by the learned attention layer
z0, zrandom high-dimensional inputs drawn from a standard distribution
aindex over all sequence positions
A tiny worked example
Suppose a task has 3 spectral modes with strengths 10, 3, and 0.5 (power law).
After early training: only mode 1 (strength 10) is recovered. Test error = prediction_error_from_modes_2_and_3 ≈ 3 + 0.5 = 3.5.
After more training: modes 1 and 2 (strength 10 and 3) are recovered. Test error = prediction_error_from_mode_3 ≈ 0.5.
After full training: all modes recovered. Test error ≈ near zero (noise floor).
The error jumps at precise points—when each mode flips from unlearned to learned. This discrete progression creates the power-law scaling law.

The sum tracks the error across all positions in the sequence. As training progresses, more modes unlock in order, and the error drops in discrete steps—not smoothly.

What can go wrong

What can go wrong

High-dimensional regime required. The theory assumes the embedding dimension and sequence length are both very large. In small models (few hidden units), the finite-size effects dominate and the predictions may not hold.
Tied attention only. The analysis studies a simplified setting where the value matrix is the identity. Real transformers have separate, learned value matrices, which adds complexity the theory does not yet cover.
Synthetic tasks only. The theory is proven for synthetic attention-indexed models (idealized tasks built to match the attention structure). Natural language or vision tasks may violate the assumptions, so predictions may drift.
Done right: ordered recovery still visible. Even in realistic transformers, the low-rank collapse and spectral outliers persist, suggesting the mechanism is real even if the theory is incomplete. Use weight decay and factorized updates to enhance the effect.
What a runnable demo should prove

What a runnable demo should prove

Build a tiny single-head attention layer and train it on a synthetic task where the target can be expressed as a sum of 3 to 5 features with known strengths (e.g., a power-law spectrum like 10, 3, 1, 0.3). Track the singular values of the learned query–key matrix at each training step. Measure test error at the same steps. Confirm that: (1) singular values grow in the predicted order (strongest first), (2) test error drops in discrete jumps as each singular value emerges above a threshold, and (3) the relationship between which modes are learned and which modes remain unlearned matches the theory's prediction.

power_law_scaling_slope = log(e_test_early) / log(e_test_late), and number_of_discrete_error_jumps = count_of_steps_where_e_test_drops_more_than_threshold

The demo's main reveal: test error does not decrease smoothly. Instead, it is a staircase, with each step tied to a new singular value crossing its recovery threshold. This is the signature of ordered spectral recovery.
