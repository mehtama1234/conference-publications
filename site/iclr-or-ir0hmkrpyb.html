Stylos: Single-Forward 3D Stylization

A single-forward method that takes a content scene and style image, then applies artistic style uniformly across all viewpoints without retraining.

Paper explainersAll themesComputer Vision

Style transfer on 3D scenes usually requires retraining the model for each scene. Stylos instead uses a transformer that splits into two pathways: one pathway predicts where each 3D point should be located and how bright it is before styling, while the other pathway blends in the artistic style. A special loss keeps the style consistent across different camera angles while preserving the original shape.

Zero assumption version

Why old 3D style transfer is stuck

To stylize a 3D scene (make it look painted or sketched), old methods required you to optimize a separate model for every single scene, which is slow and fragile. You also needed the exact camera positions (poses) beforehand, which is not always available. A beginner might try: take a style image, run a style loss on each rendered view, and hope the results stay consistent. This breaks because each view trains independently, so the same shape gets styled differently from different angles, creating a patchwork effect.

The core problem is that views compete: if you stylize view A to match the style image, then view B of the same object ends up with conflicting surface patterns. The predicted positions and colors of each 3D point start to warp to satisfy both views, ruining the shape.

The method in one sentence. Stylos uses a transformer with two separate pathways: one pathway keeps the predicted 3D positions and base colors locked in place by attending to local neighborhoods, while a second pathway injects style information globally across all views at once, enforced by a 3D loss that compares aggregated features in voxel space instead of view by view.

The algorithm as a flow

What it actually does

Encode both images.

Content scene and style reference go through a shared feature extractor.

Split pathways.

Shape path attends to nearby pixels in the same view to preserve structure; style path pulls artistic cues from the reference to all views.

Blend at each voxel.

Style embeddings are assigned to each 3D point (Gaussian) based on both shape and style features.

Aggregate to 3D.

All rendered views contribute their features to a shared 3D voxel grid, so conflicts between views dissolve.

Compare statistics.

The loss compares aggregated voxel features to style statistics; a mismatch nudges training toward consistency.

What the paper changes

What the paper changes

Stylos replaces per-view, per-scene training with a single transformer run that takes unposed images as input. Instead of optimizing a neural field for hours per scene, the model immediately predicts 3D point locations, brightness, and style properties. The key shift is that training happens once on a dataset, then the model generalizes to brand-new scenes and styles when answering questions about new images (inference).

The hidden quantity

The hidden quantity: View-consistent style encoding

measured quantity  =  voxel style coherence

The paper measures how much the style is consistent across viewpoints. This is not a single number on each image; instead, it is a comparison of feature statistics in 3D voxel space. Every voxel (a small cube in the 3D scene) collects features from all camera angles that can see it. If those features match the pattern of colors and textures in the style reference, the voxel is styled. If they do not, the loss penalizes the discrepancy.

The paper estimates voxel coherence by rendering the scene from many angles, extracting deep features (from a pretrained vision model) for each rendered view, then fusing all those features into a single 3D grid. It then computes the mean and standard deviation (the statistics) of features in that grid and compares them to the style image's feature statistics.

Why it works

Why this works: the causal chain

The core problem is that if you optimize each view independently, they pull the predicted 3D points in conflicting directions. Stylos breaks this by forcing shape and style to be computed in separate pathways within the same transformer.

The shape pathway uses local neighborhood attention, which means each location attends to nearby pixels in the same view to predict its position and brightness. This local reasoning preserves the original structure. The style pathway uses global cross-attention, which means style information is pulled from the reference image and sent to all views at once. Because it is global, the same artistic signal reaches every view, eliminating conflicts.

The voxel loss seals the deal. Instead of comparing each view's rendering to the style (which reopens conflicts), the method aggregates all view features into a single 3D grid and compares that grid to style statistics. Because the loss operates on fused 3D data, not per-view 2D images, there is nowhere for view conflicts to hide. The training nudges features toward a single coherent pattern of colors and textures.

The equation and worked example

First in words:

The 3D style loss sums, over multiple feature layers, the squared distance between the mean features of the voxelized scene and the style reference, plus the squared distance between their variances.

Then the compact form:

L_sty_3D = (1/B) * sum_b sum_l alpha_l * (||mean(G_b_l) - mean(S_l)||^2 + ||variance(G_b_l) - variance(S_l)||^2)

Every symbol:

Bnumber of scenes in a batch
llayer index in the feature extractor (e.g. layer 1 through 5 of a vision model)
alpha_lweight for layer l, controls how much that layer contributes
G_b_lfeature map of the scene b at layer l, aggregated in voxel space
S_lfeature map of the style reference image at layer l
mean(...)average value of features across all voxels
variance(...)spread of features (how different they are from the average)
A tiny worked example
Suppose layer 3 has alpha_3 = 1.0. Scene voxels have mean color brightness 0.6, style reference has mean 0.5. Difference: 0.6 - 0.5 = 0.1. Squared: 0.01.
Scene voxels have color variance (spread) 0.08, style has 0.12. Difference: 0.08 - 0.12 = -0.04. Squared: 0.0016.
Layer 3 contributes 1.0 * (0.01 + 0.0016) = 0.0116 to the loss. Multiple layers sum up.
When loss is large, training adjusts the scene features. When loss shrinks, voxel style coherence is achieved.

The loss penalizes both mean and variance mismatches, so training makes the voxel features match the style not just in average brightness, but in how varied they are across the 3D space.

What can go wrong

What can go wrong

Weak shape signal in the content images. If the input images are blurry or poorly lit, the shape pathway cannot predict accurate 3D positions and base colors. The stylized result will look distorted.
Style reference does not match the content well. If the reference style is, say, a sepia tone and the content is a bright neon scene, the voxel features may be pulled in directions that hurt visual quality. The method does what it is told, not what looks best.
Small numbers of viewpoints in the input. With only one or two images, the shape prediction has little information to infer 3D positions and scales. Voxel aggregation cannot fuse consistent features from a single angle.
Shape and style pathways balance well. When the shape pathway is strong and the style loss weights are tuned, 3D positions are preserved even as style is applied. The two goals do not interfere.
What a runnable demo should prove

What a runnable demo should prove

Build a small experiment: take a 3D scene (e.g., a simple synthetic object or a real scene from a public dataset like CO3D). Render it from 4 different camera angles. Provide a style reference image (e.g., an oil painting or watercolor). Run Stylos on this input. Render the trained model from 8 new angles (angles the model never saw). Measure (1) how similar the style is across those 8 viewpoints (voxel coherence), and (2) how close the 3D shape stays to the original (RMSE of positions).

voxel_coherence = 1 - (mean_squared_error of voxel features across viewpoints / variance of target style features); geometry_preservation_error = sqrt(mean((predicted_position - original_position)^2)) for all voxels

The demo must show that unseen viewpoints produce the same style (coherence near 1.0) and the shape error is small (preservation near 0.0), proving that the voxel loss and dual pathways work together.
