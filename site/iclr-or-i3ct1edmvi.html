PHyCLIP: Hierarchy and Compositionality via Hyperbolic Factors

Instead of storing all meaning in one point, split it across multiple hyperbolic spaces, each capturing one concept family, then add their distances together.

Paper explainersAll themesRepresentation & Self-Supervised Learning

Vision-language models (like CLIP, which learns to match images and text) squeeze all meaning into a single list of numbers. Two structures matter: hierarchy (that 'dog' is a type of 'animal') and compositionality (that 'dog in a car' contains both a dog and a car). These pull in opposite directions in a single space, because moving 'dog' closer to 'animal' sacrifices the separation needed to compose 'dog' and 'car' independently. PHyCLIP avoids this conflict by splitting the list into separate list-spaces (hyperbolic spaces), one per concept family: Animals, Transportation, etc. Within each space, hierarchy emerges naturally along curved paths. Across spaces, distances add up like Boolean AND, so composites emerge without sacrifice.

Zero assumption version

One point cannot hold two kinds of meaning

Vision-language models learn by matching images and text. A naive approach stores each concept as a single number-list (called an embedding, just a list of numbers) and scores matches by distance. This works for many tasks.

The trouble: this single point must encode both hierarchy (dog is-a mammal is-a animal) and composition (a dog in a car is parts-of-dog plus parts-of-car). If you move the 'dog' point to be closer to 'mammal', you risk breaking compositional meaning. The two structures pull in opposite directions.

Existing attempts use hyperbolic space (a curved space, shaped like a saddle, where hierarchies fit naturally along paths, like a tree drawn on the saddle) or Boolean algebra (coordinate-wise logic: the concept-pair max includes both). Each handles one structure well, but mixing them in a single space is awkward.

One point holds two types of meaning poorly. PHyCLIP uses multiple hyperbolic spaces at once: each space handles one concept family's hierarchy, and the way distances add up across spaces creates composition.

The algorithm as a flow

What it actually does

Encode separately

An image or text becomes a list of numbers. Split this list into k pieces, one per concept family.

Place in hyperbolic space

Each piece sits in its own hyperbolic space, a curved saddle-shaped space where hierarchy is baked into distance.

Train within each space

Pull matching image-text pairs closer. Push mismatches apart. Enforce hierarchy rules: dog points stay inside a cone below mammal.

Measure cross-space composition

Total distance to a compound concept (dog in car) is the sum of distances within Animals-space and Transportation-space.

Inherit both properties

The model now respects hierarchy within each factor and composition via L1 addition, because that is how it was trained.

What the paper changes

The one thing that changes

Instead of embedding everything into one Euclidean space (flat, like a sheet of paper), the method embeds images and text into an L1-product metric space of multiple hyperbolic factors (multiple curved spaces whose distances add together).

The hidden quantity

The hidden quantity: Concept family signals

measured quantity  =  Concept family membership signal

The hidden quantity is which concept family each dimension of the embedding belongs to. In PHyCLIP, each hyperbolic factor captures one family: the animals family, the transportation family, etc. This separation is never explicitly labeled in the training data, but emerges naturally as the model learns.

The paper estimates it by initializing k hyperbolic spaces (k is a hyperparameter, typically 3-10) and during training, the contrastive loss pushes matching image-text pairs closer within each factor independently. The entailment loss (which enforces hierarchy rules like dog below mammal) applies separately to each factor. Over time, each factor self-organizes to specialize in one semantic family. This happens because the L1-product metric gives each factor independent movement: the Animals-factor can rotate and scale without affecting Transportation, because their distances add.

Why it works

Why it works: The real causal chain

The core insight is that hyperbolic spaces and Boolean logic each solve one half of the problem, and the L1-product metric bridges them. Hyperbolic space (a curved saddle-shaped surface) has a special property: distances grow exponentially as you move outward. This makes hierarchies natural: a point for 'dog' can nestle close to 'mammal', which sits close to 'animal', and the exponential growth keeps all three distinct, because each small outward step doubles the distance, so three nested nodes spread apart automatically despite being close in a Euclidean sense. When you enforce this via the entailment loss (a cone-shaped region that penalizes hierarchy violations), the model learns to place dog-like concepts inside the mammal cone, which sits inside the animal cone. All without explicit tree construction.

Composition is traditionally handled via Boolean operations (coordinate-wise max and min, like in order embeddings). The max of dog-coordinates and car-coordinates gives a point that inherits properties of both. This works because max is idempotent: max(dog, car) correctly includes the logic of being both. But in Euclidean space, coordinate operations are awkward with curvature.

PHyCLIP's key move: instead of forcing both structures into one curved space, it uses k independent hyperbolic factors. The distance between two embeddings is defined by adding up the distances within each factor independently. This means each factor contributes to the final distance like a Boolean AND. When training the contrastive loss, the model pulls 'a dog in a car' closer to both 'dog' and 'car' by moving both coordinate-chunks closer. Matching happens within-factor for hierarchy and across-factors for composition. The additive metric ensures that you cannot satisfy composition without satisfying hierarchy in each factor, because the loss penalizes distance in any factor.

Why this beats single-space approaches: hyperbolic-only models (like HyCLIP) can encode hierarchy but struggle with composition because curvature makes coordinate-wise operations nonlinear and unintuitive. Boolean-only models (like order embeddings) can encode composition but lose the hierarchical structure that makes partial matches work. PHyCLIP decouples these: each factor handles its own hierarchy independently, and addition across factors naturally encodes composition via Boolean logic. Because distance is the sum of independent hyperbolic distances, the model can greedily optimize each factor to be hierarchical without breaking others, and the total distance automatically respects composition.

Math after the picture

The equation: L1-product metric on hyperbolic factors

First in words:

The distance between two embedded points X and Y is the sum of hyperbolic distances within each factor. The overall training loss combines a contrastive loss (pull matching pairs closer across all factors) and an entailment loss (enforce hierarchy rules within each factor).

Then the compact form:

L_overall = L_cont + gamma * L_ent L_cont = sum of hyperbolic distances for mismatched pairs L_ent = sum over factors i of max(0, phi(x(i), y(i)) - eta*omega(y(i)))

Every symbol:

L_overallTotal training loss
L_contContrastive loss: penalizes distance between matching image-text pairs
L_entEntailment loss: penalizes hierarchy violations
gammaWeight balancing contrastive and entailment losses
x(i), y(i)Points in hyperbolic factor i
phi(x(i), y(i))Exterior angle between x and y in hyperbolic space
omega(y(i))Half-aperture of the hierarchy cone at point y
etaMargin hyperparameter controlling cone tightness
A tiny worked example
Consider a 4-way split (k=4 factors) for image 'dog in car' and text 'dog in car'.
Factor 1 (Animals): hyperbolic distance = 0.1 (dog close to dog, both under mammal)
Factor 2 (Transport): hyperbolic distance = 0.1 (car close to car, both under vehicle)
Factor 3 (Spatial): hyperbolic distance = 0.05 (in-context nearly matches)
Factor 4 (Color/texture): hyperbolic distance = 0.15 (minor visual details differ)
L1-product distance = 0.1 + 0.1 + 0.05 + 0.15 = 0.4 (low, good match)
Entailment loss: each factor enforces dog ⪯ mammal ⪯ animal via cone penalty. If dog point exits the cone, loss spike (e.g., cone penalty = 0.2 per violated hierarchy).
Total: L_overall = 0.4 + gamma * (sum of cone penalties) ≈ 0.4 + 2.0 * 0.3 = 1.0 (encouraging tight hierarchies and tight matches)

Each factor independently contributes hyperbolic distance via cone-shaped regions, and the additive metric ensures composition is automatic: low total distance requires all factors to align, enforcing both hierarchy within each and conjunction across families.

What can go wrong

What can go wrong

Choosing the wrong k (number of factors). If k is too small, distinct concept families get squeezed into the same factor, and hierarchy breaks within that factor. If k is too large, factors specialize redundantly and the model wastes capacity. The paper does not provide an automatic way to choose k; it must be set per dataset.
Curvature learning instability. Each factor has a learnable curvature parameter -alpha_i. If curvature gets too negative (hyperbolic space gets too extreme), numerical issues arise in hyperbolic operations. If it stays near zero (nearly flat), hierarchy does not fit naturally, and the cone penalty becomes uninformative.
Entailment cone overlap. In practice, if many concepts share partial definitions across families (e.g., 'cute' applies to animals, toys, and people), a single cone per factor may not capture the granularity needed. The cone is a single region in the factor, so overlapping hierarchies from different families are harder to resolve.
Done right: minimal data requirements and computational cost. The paper uses learnable curvature to adapt each factor, contrastive loss to drive matching, and entailment loss to enforce hierarchy. These standard techniques are stable if hyperparameters gamma and eta are tuned. Wall-clock overhead is negligible (dominated by the vision and text encoders, not the hyperbolic operations).
What a runnable demo should prove

What a runnable demo should prove

Build a small dataset: 50 images each labeled with two concept families (e.g., animal type + setting: dog-indoors, cat-outdoors, etc.). Encode images and labels using CLIP baseline and PHyCLIP with k=2 factors (one per family). On a held-out test set, measure zero-shot matching accuracy separately for: (1) hierarchy queries (is this image more like 'dog' or 'mammal'?) and (2) compositional queries (is this image more like 'cat indoors' or 'dog outdoors'?). The key: CLIP baseline will bias toward whichever family dominates training; PHyCLIP should balance both equally.

Hierarchy_accuracy = (correct_species + correct_family) / total | Composition_accuracy = (correct_concept_pair) / total | Balance = |Hierarchy_accuracy - Composition_accuracy|

PHyCLIP's demo must show that it can rank 'dog indoors' higher than 'cat indoors' for a dog image (composition), while also ranking 'dog' higher than 'mammal' correctly (hierarchy), without sacrificing one for the other.
