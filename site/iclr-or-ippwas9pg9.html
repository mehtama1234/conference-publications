Diffusion-LPO: Listwise Preference Optimization for Diffusion Models

Use ranked lists of images, not just pairs, to teach diffusion models what humans prefer.

Paper explainersAll themesComputer Vision

When humans rate images, they usually rank them in order (best to worst), not just compare pairs. Diffusion models learn via Direct Preference Optimization, which today only sees pairs. Diffusion-LPO captures the full ranking so the model learns a consistent preference order instead of isolated pair-by-pair lessons, because all images in a ranking are scored at once rather than independently.

Zero assumption version

Pairs lose information humans already gave you

Today, diffusion models learn what humans like by comparing pairs: show a human two images and ask which is better. But humans rarely think in pairs. They look at a set of images and rank them: best, second, third, worst. That ranking has more information than any single pair.

A naive approach would be to just pick pairs from the ranking and train on those. But this wastes the structure. If a human says Image A is best, Image B is second, Image C is third, you get three separate pairs: (A, C), (B, C), (A, B). Training on pairs ignores that A beats B beats C — that the whole group has a consistent order. The model learns each pair independently, so it could mistakenly make C look better than B in one step of training, even though it learned B beats C in an earlier step.

The method used today, pairwise DPO, has no built-in way to enforce that if A beats B and B beats C, then A must beat C. Each pair is trained separately without communicating with the others, so the model can end up with contradictory learned preferences, because one training step that moves the weights to make B beat C can undo a previous step that made A beat B.

In one sentence. Use human rankings of images, not just pair comparisons, to train the diffusion model with a consistent preference order.

The algorithm as a flow

What it actually does

Collect ranked images

For each caption, gather a set of generated images and have humans rank them best to worst.

Assign score to each position

The best image gets the highest score, the second gets lower, down to lowest for worst. The gaps follow the Plackett-Luce rule.

Penalize upsets

Compute a quality score for each image. If a lower-ranked image gets a higher score than a higher-ranked one, that contradicts the ranking, so add a penalty to force the model to fix it.

Train the diffusion model

Update the model so that given the caption, it produces images in the right order.

Repeat for all captions

Each ranked set teaches the model one consistent lesson: this caption produces this ranking of image quality.

What the paper changes

What the paper changes

The object is the training input: instead of pairwise preference data (two images at a time), Diffusion-LPO takes ranked lists. Given a caption, the model sees four or five images ranked by the human. That ranking is the new ground truth.

the object it moves  =  training input: pairs to ranked lists
The hidden quantity

Ranking consistency: which images violate the order

measured quantity  =  preference violation count

The hidden quantity is how many times the model generates images out of order compared to the human ranking. If the human says Image A is best and Image C is worst, but the model assigns C a higher score than A, that contradicts the ranking. The model is trained to minimize such contradictions.

Diffusion-LPO estimates this by computing a quality score for each generated image using the model's internal learned features and the Plackett-Luce rule. It then counts how many times a lower-ranked image gets a higher score than a higher-ranked image. During training, the model adjusts its internal numbers to reduce these violations until the scores match the human's ranking order.

Why it works

Why ranking works better than pairs

When training on pairs, the model learns one thing at a time: Image A is better than Image B. Nothing stops it from later learning that C is better than B in a different training step, because pairs are trained independently. The model sees no contradiction.

A full ranking says: best beats all four others, second beats all three below it, third beats just the worst. Diffusion-LPO enforces this entire structure at once. The mathematical rule (Plackett-Luce) says the bigger the rank gap, the stronger the preference, so the model puts energy into getting the biggest differences right first because the loss penalty is larger for violating big gaps than small ones. When the best image's score is boosted higher, it automatically helps beat every lower image, not just one pair, because the ranking compares best against all of them together.

The mechanism works like this: the model computes a quality score for each image. During training, violations (lower-ranked images scoring higher than higher-ranked ones) create a penalty. To reduce the penalty, the model updates its parameters so that scores line up: best gets the highest, second gets next highest, and so on. Because all images are scored at once, the model learns one consistent order, not a jumble of isolated pairwise lessons.

Math after the picture

The Plackett-Luce ranking objective

First in words:

The loss is the sum over all images of: minus log of (that image's score divided by the sum of all images ranked same or worse than it). This makes higher-ranked images push their own score up and the scores of all lower-ranked ones down simultaneously.

Then the compact form:

loss = sum_i [ -log( score_i / (score_i + sum_{j > i} score_j) ) ]

Every symbol:

score_ithe model's predicted quality score for image at rank i
iposition in the ranking (1 = best, 4 = worst)
sum_{j > i} score_jtotal score of all images ranked worse than position i
lognatural logarithm
Tiny worked example with four images
Suppose the model scores the four images: best=3.0, second=2.0, third=1.5, worst=0.5.
Loss for best (i=1): -log(3.0 / (3.0 + 2.0 + 1.5 + 0.5)) = -log(3.0 / 7.0) = -log(0.43) = 0.85.
Loss for second (i=2): -log(2.0 / (2.0 + 1.5 + 0.5)) = -log(2.0 / 4.0) = -log(0.5) = 0.69.
Loss for third (i=3): -log(1.5 / (1.5 + 0.5)) = -log(1.5 / 2.0) = -log(0.75) = 0.29.
Loss for worst (i=4): -log(0.5 / 0.5) = -log(1.0) = 0.0.
Total loss = 0.85 + 0.69 + 0.29 + 0.0 = 1.83. Lower loss means the ranking is more likely.

Each image's loss depends on how much higher it ranks than all lower images, so one well-placed change (making best higher) reduces loss for every comparison below it.

What can go wrong

What can go wrong

Ranking is noisy or inconsistent. If the human ranker is tired or the images are very similar, the ranking becomes arbitrary. The model will learn an arbitrary preference, just confidently. Use clear, distinct sets of images and multiple human raters.
The top image is not really that much better. The Plackett-Luce model assumes the ranking reflects true preference. If the best image only looks slightly better (due to random luck), the model will over-emphasize the tiny gap and learn brittle preferences.
Generalization beyond the exact ranking. If the model only memorizes the specific ranking of those four images for that exact caption, it will not generalize to a new caption. The model must learn the abstract rule of what makes a good image so that it transfers to new prompts and images. Check this by testing on held-out captions.
Done right. Use consistent human raters on clearly different images, and verify that the learned preferences transfer to new test captions and images from the same domain.
What a runnable demo should prove

What a runnable demo should prove

Build a minimal diffusion model that generates single-digit MNIST images conditioned on the digit label. Collect four versions of each digit (via Gaussian blur, rotation, noise, and downsampling). Have a human or rule-based ranker assign a preference order to each set. Train the model using pairwise DPO on some pairs and Diffusion-LPO on the full ranking. Measure how often the model generates images in the correct preference order when given a new label.

ranking accuracy = (number of test examples where model output respects human ranking order) / (total test examples)

Diffusion-LPO should achieve 85%+ ranking accuracy while pairwise DPO plateaus around 70%, because the full ranking forces consistency across all four images simultaneously.
