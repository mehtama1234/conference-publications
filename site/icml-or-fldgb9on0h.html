Transformers learn factored representations

Transformers pretrained to predict the next word learn to split their world into separate, independent parts stored in orthogonal corners of their memory.

Paper explainersAll themesInterpretability

A transformer (a neural model that reads text word by word and predicts the next word) builds a mental model of the world. This paper discovers that when the world has independent parts (like a ball's color and position), the transformer learns to store these parts separately, like filing things in different drawers instead of mixing them together. The researchers prove this happens in the model's memory: the parts live in perpendicular directions that never interfere with each other.

Zero assumption version

How does a transformer organize its thoughts?

A transformer is trained to guess the next word by reading text one word at a time. Inside, it builds up a big list of numbers (called a residual stream) that carries information forward. By the time it makes its final guess, that list contains everything the model knows about the sentence so far.

A naive guess: the transformer just tosses all the world's facts into one big jumbled pile—everything about the ball's color, its position, its speed, all mixed together like ingredients in a pot. A better guess: the transformer might learn to organize things by separating the world into independent parts. But how would it do this? And does it actually happen?

In one sentence: The transformer learns to store separate parts of the world (like an object's properties) in perpendicular memory directions that do not interfere with each other.

What the paper changes

What the paper changes

The paper does not change how transformers work. Instead, it measures the internal memory arrangement of a pretrained transformer. Specifically, it looks at which directions in the residual stream (the model's hidden memory list of numbers) light up to represent each part of the world, and whether these directions are perpendicular to each other—pointing in completely independent ways.

The hidden quantity

The dimensionality profile: how the model trades space for fidelity

measured quantity  =  Effective dimensionality per factor

The hidden quantity is the effective dimensionality: how many independent memory directions does the transformer actually use to represent each part of the world? If parts are independent, the model uses just one direction per part (low dimension). If parts are coupled by noise or dependencies, the model adds more dimensions to recover accuracy—trading memory size for faithfulness.

The paper estimates this by analyzing the activation patterns across many sentences: for each part (like color), it finds how many perpendicular directions the transformer uses to represent it. Independent parts cluster into tight, low-dimensional subspaces. Coupled parts scatter across more dimensions.

Why it works

Why transformers naturally learn factored storage

The core idea: a transformer minimizes prediction error (the gap between its guess and the true next word). To predict accurately, it must track all the parts of the world that matter. If the world's parts are independent, the transformer discovers that it can pack information most efficiently by storing each part in a separate memory direction. Why? Because overlap between storage directions causes interference: updating one fact accidentally corrupts another. Perpendicular directions have zero overlap, so changes are clean.

When two parts of the world are linked (say, the position and color of an object always move together), the transformer cannot use independent storage without losing accuracy. So it expands its memory: it adds extra dimensions that capture the coupling. This is a forced trade-off: fidelity costs space.

Over training, the model gradually discovers this arrangement. It starts with jumbled facts. As it processes more sentences, it notices which facts co-vary independently and which are linked. For independent facts, it carves out separate subspaces. The updates to the numbers naturally push toward perpendicular structure because perpendicular storage minimizes crosstalk.

Math after the picture

The formula for efficient storage

First in words:

For independent factors, total dimension = number of factors. For coupled factors, dimension grows beyond that base, proportional to the strength of coupling.

Then the compact form:

d_effective = d_base + lambda * C

Every symbol:

d_effectivehow many memory directions the model actually uses
d_basenumber of independent world parts (e.g., color, position, shape)
Ccoupling strength: how much two parts co-vary
lambdafidelity penalty weight: how much accuracy the model trades for dimension
A tiny worked example
Suppose the world has 3 independent parts: color, position, speed. Base dimension = 3.
If factors are truly independent, the model uses d_effective = 3 directions (one per part).
Now add coupling: color and position are linked (objects of certain colors tend to move fast). Coupling strength C is 0.4.
Model increases d_effective to 3 plus 2.0 times 0.4, which is 3.8, rounded to 4 directions to capture the link.
The model expands from 3 to 4 dimensions to preserve accuracy—a small but real fidelity cost.

When the residual stream stores independent parts in perpendicular subspaces, interference drops to zero because perpendicular directions never overlap—changing one direction cannot accidentally change another—so the model needs fewer total dimensions to represent all parts.

What can go wrong

What can go wrong

Causally linked factors deceive the model. If two parts of the world are always linked (cause and effect), the model cannot separate them into perpendicular directions without losing predictive power. It expands memory instead. If you measure the memory directions and find coupling you did not expect, the data itself may hide a causal link.
Context can reorder which directions are active. A single direction might represent color in one sentence and speed in another, depending on what the sentence talks about. The arrangement is not static. Measuring across all contexts smooths this out, but single-sentence interpretation can fail.
Noise obscures the true factorization. If the training data is noisy, the model cannot learn a perfectly factored representation. It trades accuracy for cleanliness. The discovered factors are not guaranteed to match the true world structure.
Done right: test on known synthetic worlds. The paper validates the theory by training on synthetic worlds where the true factors are known and controllable. This avoids ambiguity about what the true world structure really is.

What a runnable demo should prove

Build a tiny transformer and train it on a synthetic world with exactly 3 known, independent factors: color (red or blue), shape (circle or square), and size (big or small). The world generates sentences like the red circle is big. After training, measure the memory directions: extract the 3 subspaces representing each factor. Check: are they perpendicular? How many dimensions did the model actually use? Then add coupling: force color and shape to always co-occur (red things are always circles). Retrain and measure again. The model should expand its dimensionality to handle the coupling while maintaining prediction accuracy. Plot dimensionality against coupling strength and overlay the theory's prediction.
