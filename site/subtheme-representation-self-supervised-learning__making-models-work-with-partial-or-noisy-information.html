Making models work with partial or noisy information

Papers handle incomplete multi-view data, noisy labels, and uncertain signals by using mathematical frameworks like optimal transport and information theory to extract reliable patterns.

All themesField mapMathematicsAll explainers
What this is

Real data is messy. Sensors fail and produce incomplete readings, labels are imperfect or crowdsourced with disagreement, images are corrupted or occluded. A reliable model should not assume perfect data. When you have multiple incomplete views of the same object — like a video frame with one camera broken, or a medical scan missing one modality — the model needs to extract the signal while working around missing or contradictory information. Information theory and optimal transport provide mathematical frameworks to reason about this.

The challenge is that standard learning assumes all data points are equally reliable. When information is noisy or partial, the model can fit the noise instead of the signal, or it might overweight the few complete examples and miss patterns in partial data. Information-theoretic approaches ask: what is the minimum amount of information needed to solve this task? Optimal transport asks: how can I match partial observations in a way that minimizes the cost of transformation? These tools help design loss functions and algorithms that degrade gracefully when data is incomplete — the model continues to learn from what is available rather than collapsing into failure because some pieces are missing.

Across 16 papers, researchers develop methods for learning from multi-view data where some views are missing, noisy labels where annotators disagree, weak supervision where labels are indirect or imperfect, and corrupted inputs. Some papers focus on reliability: training in a way that does not overfit to artifacts in the data. Others develop theoretical bounds: proving that even with 30% missing data, certain algorithms will still find the true structure with high probability. The applications include medical imaging where patients may not have all scans, sensor networks with device failures, and learning from crowd-sourced annotations.

How the work breaks down

When real data is incomplete or unreliable, the core challenge is figuring out what to trust. The work in this subtheme splits into four directions: first, producing prediction sets that stay reliable even when data is hard to label (by carefully designing what counts as uncertainty); second, learning from multi-view data when some views are missing (by aligning what remains without forcing impossible matches); third, cleaning noisy labels before or during training (by spotting which annotations disagree with the underlying pattern); and fourth, using mathematical tools like optimal transport (a way to move data from one state to another while minimizing the cost of that movement) to reason about incomplete observations.

Prediction Intervals That Stay Valid

When you need not just a prediction but also an honest measure of how confident that prediction is, a prediction interval should tell you the true answer more often than not — even when data shifts or becomes harder to categorize. Standard approaches like confidence scores from neural networks do not give you this guarantee. These papers tackle the problem of building prediction sets that stay valid (technically: maintain coverage) across different domains and new data without requiring expensive retuning.

Adaptive Conformal Prediction uses a mixture-of-experts approach to produce prediction intervals customized to each input. Instead of one-size-fits-all intervals, it learns which expert (domain specialist) to trust for each new example based on similarity, then builds intervals that are both tight (narrow, not wastefully wide) and adaptive (narrower for easy examples, wider for hard ones) while keeping the coverage guarantee. Softmax is Not Enough (a method that improves on softmax, the standard way neural networks convert raw scores into confidence probabilities) observes that simple confidence scores alone capture only basic patterns and proposes a better nonconformity score that measures when an example breaks the training distribution's rules in more precise ways (by tracking not just whether it matches but how far from each category's boundary it lies), which helps the prediction set adapt to each example's true difficulty. Horseshoe Splatting applies these ideas to 3D scene rendering, where you not only need to predict what the scene looks like but also quantify uncertainty in the 3D shape reconstruction. It builds uncertainty maps that show which parts of the scene are hard to infer from the limited views available, while keeping rendering speed high.

These three papers stack: the first two improve how you measure uncertainty in classification, while the third shows the same logic applies to physical 3D problems where you reconstruct scenes from cameras, which means uncertainty quantification is not just a classification tool but something that helps whenever you must infer the world from incomplete observations.

Learning From Incomplete Multi-View Data

Many real datasets describe the same object from multiple angles or using multiple sensors. A patient's medical imaging might include X-rays, MRI, and CT scans. A video scene has multiple camera views. An object can be described by its appearance and its structural shape. When one or more views are missing — because a sensor failed or data was lost or not collected — the model must still extract the signal from what remains. The hard part is not just ignoring the missing view, but correctly combining the partial information across views without letting one noisy view overwhelm others.

Permutation-Consistent Variational Encoding solves multi-label classification when some views go missing and each object may belong to multiple categories. Rather than guessing or zeroing out the missing view, it learns to encode what is present in a way that is consistent regardless of which views show up. This allows the model to handle any subset of views at test time. Reliable Neighborhood-Aware Multi-View Outlier Detection spots when a data point is an outlier by checking it against multiple views simultaneously. Outliers often behave differently across views — they might look normal in one view but broken in another. By tracking neighbors across all available views and avoiding letting outliers poison your view alignment, the method stays stable even when some views are corrupted. Multi-View Fusion via Prototype-Anchored Unbalanced Optimal Transport uses a mathematical framework called unbalanced optimal transport to combine views. Unlike standard optimal transport which assumes you can match everything perfectly, unbalanced optimal transport lets you discard or downweight bad matches (atoms with high cost). This helps when data missingness is severe because instead of forcing broken alignments, the algorithm finds the best partial match with theoretical guarantees about how much cost you incur, which means you can continue learning even when multiple views are unavailable.

All three papers treat multi-view data as incomplete puzzles. The first learns one encoding that works across all possible subsets of views. The second and third focus on matching and fusing what remains without corrupting the signal through outliers or bad alignments.

Cleaning Noisy Labels

Annotators disagree. Crowds make mistakes. Labels obtained through weak supervision (like automatic systems that are imperfect, or users marking data under time pressure) contain errors. When you train a standard model on noisy labels, it memorizes the noise along with the true pattern. The model fits the contradictions and mislabelings, which tanks performance on test data where you hope the labels are cleaner. These papers each propose a way to identify which labels are likely wrong and either remove or repair them before or during training.

Label-Aware Noise Elimination focuses on fine-grained text classification where the boundary between nearby categories is fuzzy and annotators often disagree. It learns a label-aware representation that clusters examples that got similar category votes, then uses this clustering to spot examples that receive conflicting votes and are likely mislabeled. Human Uncertainty-Aware Data Selection in Visual Question Answering observes that when humans answer questions about images, some answers they give with confidence while others they guess. The paper proposes using the human uncertainty — did the annotator say 'I am confident' or 'I think so' — as a signal for which examples to rely on during training, and which to select for retraining. Federated Generalized Expectation-Maximization tackles the setting where you have decentralized data (stored on many devices) and want to fit a mixture model (a distribution made of several component clusters) without moving all data to one place. It extends the EM algorithm to work across distributed locations while handling the fact that the number of clusters is unknown, which means you cannot just assume away the noisy label problem. FedOpenMatch considers federated learning (decentralized) in the open-set setting, where training data contains classes you have seen, but test data includes previously unseen classes you never trained on. It applies semi-supervised learning and open-set classification to handle both missing labels and out-of-distribution examples scattered across devices.

These papers differ in scope: the first two focus on single-machine settings with different noise profiles (text annotation disagreement and visual question answering), while the last two scale to federated (decentralized) settings. All four share the insight that noise patterns are learnable — disagreement and human uncertainty are signals of where labels are weak.

Optimal Transport and Distribution Matching

Optimal transport is a mathematical tool that asks: if I have one distribution of things here and another over there, what is the lowest-cost way to rearrange the first into the second? You pay a cost for moving each thing, and you want to minimize total cost. This is useful for handling incomplete data because it lets you reason about matching partial observations without forcing every match. These papers use optimal transport ideas to solve practical problems around learning from imperfect measurements and data that has been distilled or corrupted.

Tree-sliced Sobolev IPM introduces a more efficient way to compute optimal-transport-based distance measures between distributions because previous methods were fast for one specific version of Sobolev (a mathematical way to measure smoothness) but slow for others. This makes all versions equally fast, which matters because you may not know in advance which version best captures your data's structure and relationships. GeoDM applies optimal transport to dataset distillation — the problem of compressing a large dataset into a smaller summary that trains models equally well. Instead of treating all feature distances as straight-line (Euclidean), it learns a shape-space that respects the data's actual structure, then uses optimal transport to match your synthetic distilled dataset to the real distribution under this learned shape-space so that models trained on the distilled data will perform well on new examples. Multi-View Fusion via Prototype-Anchored Unbalanced Optimal Transport (“Robust Multi-View Fusion via Prototype-Anchored Unbalanced”, also listed in the multi-view group) uses the unbalanced variant, which allows partial matches when complete matching is impossible because different views may have different missing-data patterns.

The three papers represent different uses of optimal transport: as a distance measure you compute efficiently, as a way to guide data compression while respecting learned structure, and as a framework for partial matching under missingness.

Spotting Outliers and Measuring Data Quality

Outliers — data points that do not fit the pattern — matter because they can corrupt learning if you treat them the same as typical data. But spotting them is hard when you do not have a clear definition of typical, or when the 'typical' pattern differs across domains and datasets. These papers develop outlier detection and data quality assessment that work across diverse settings without requiring you to retune models for each new domain.

UniOD is a universal outlier detector that handles 30 different benchmark datasets from varied domains with a single set of hyperparameters. It provides theoretical guarantees about detection performance and beats 17 existing baselines by learning a domain-adaptive representation that captures what 'normal' looks like in any given dataset, then flags points that deviate from that representation. Learning a Distance Measure from Information-Estimation computes a metric for measuring image quality — whether an image is blurry, corrupted, or clear — by computing distances based on how much information the image reveals about the underlying reality. This metric predicts human perceptual judgments of image quality better than standard supervised metrics because it directly measures what humans perceive rather than fitting fixed rules. Learning-To-Measure frames data quality assessment as active feature acquisition: when you have partial features (some measurements of an object are available, others are not), the algorithm decides which missing features to request to maximize your ability to measure and act on quality. It works in-context, adapting to each task without large retraining.

These papers handle different aspects of data quality: spotting when an example is an outlier globally, measuring whether each example is corrupted or degraded, and deciding which features to acquire to make quality judgments.

UniOD detects outliers across 30 benchmark datasets without any further hyperparameter selection or optimization, with theoretical guarantees and superior performance over 17 baselines, providing practical convenience and accuracy improvements.
