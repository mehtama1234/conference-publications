Adaptive Canonicalization: Making Standard Forms Smarter

Instead of forcing every input into one fixed standard shape, let the network pick which standard shape works best for each input.

Paper explainersAll themesGraph & Geometric Learning

Geometric neural networks need to handle rotations and reflections without learning them over and over. Most use canonicalization: a fixed rule that rotates or reorders every input into a single standard form before processing. The problem: this fixed rule creates sharp kinks during training and makes learning unstable, because when an input lands on a boundary, tiny changes can flip which standard form is chosen, creating sudden jumps in what the network sees. This paper shows how to let the network dynamically choose which standard form fits each input best, turning a rigid rule into a flexible, smooth decision.

Zero assumption version

The discontinuity trap

Geometric data (point clouds, molecular structures, graphs) have natural symmetries: a molecule still looks like the same molecule if you rotate it. A naive network would learn to recognize a rotated version as a different thing, wasting learning effort.

A common fix is canonicalization: before feeding any input to the network, apply a fixed rule to rotate it into one standard pose. For a point cloud, that might mean: always align the longest axis vertically. This way the network sees only one version.

But this fixed rule has a nasty side effect: tiny changes in the input can cause sudden jumps in which standard form it gets rotated to. Imagine a shape that sits right on the boundary—nudge it slightly and the rule picks a completely different alignment. This creates a sharp kink in how the network's output changes with the input, which makes smooth learning impossible.

The problem in one sentence. Fixed canonicalization rules create discontinuities (sudden jumps) during training, preventing stable learning.

The algorithm as a flow

What it actually does

Generate candidates

For each input, sample many candidate standard forms (e.g., try rotating to ten different alignments).

Score each candidate

Feed each candidate standard form into the network and measure: how confident is the network in its answer on this candidate?

Pick the best

Choose the one standard form that gives the highest confidence score.

Refine locally

Take a few nudges of step-by-step optimization to fine-tune that choice slightly.

Process forward

Process the input in its chosen standard form through the network's classifier, nudging the learned numbers to reduce errors.

What the paper changes

What the paper changes

The paper changes how the standard form is chosen. Instead of applying a pre-written rule, the network itself gets a say: the standard form that maximizes the network's confidence score is selected. This choice now depends on both the input data and the network's current learned state.

the object it moves  =  the standard form selection
The hidden quantity

The hidden quantity: network confidence

measured quantity  =  confidence (how sure the network is)

Confidence measures how much the network commits to its answer. For a classifier with two possible outputs, high confidence means the output probabilities are far from 50-50 (e.g., 95% for class A, 5% for class B). Low confidence means the probabilities are close to equal (e.g., 52% for A, 48% for B).

The paper uses this quantity as a compass: sample many standard forms, measure the network's confidence on each, and steer toward the one that gives the highest confidence. This is the hidden quantity that directs the choice. By maximizing confidence, the method finds a standard form the network trusts.

Why it works

Why it works: the confidence-as-compass story

Old canonicalization was rigid: one rule for all inputs. If that rule suddenly picked a different standard form, the network's input jumped discontinuously. New canonicalization is adaptive: the network's own judgment guides the choice, so nearby inputs lead to nearby choices.

Here is the causal chain. The confidence score is a smooth quantity: as the input changes a little bit, the network's confidence changes a little bit too, because neural networks compute smoothly. Because the choice of standard form now maximizes this smooth quantity, small input changes lead to small changes in which standard form is picked. No more sharp jumps. Training can proceed smoothly because the input path is no longer kinked. During training, tiny nudges to the learned numbers cause tiny changes to confidences, which cause tiny changes to which standard form is picked, which means the learning signal is stable and not whipped around by discontinuities.

Second, the paper proves this method is still symmetry-preserving: if two inputs are related by a symmetry (e.g., one is a rotated copy of the other), the network's output is identical. Why? Because each can find its own best standard form, but after canonicalization they end up in the same standard space, and identical-space inputs give identical outputs. The symmetry is respected end-to-end.

Math after the picture

The equation

First in words:

For each data sample, pick the standard form that maximizes the network's prediction score, then refine that choice with a few gradient descent steps.

Then the compact form:

R_best = argmax_R sum_i phi(x_i * R^T)

Every symbol:

Ra rotation matrix (a way to spin the points)
argmaxpick the rotation that makes the sum as large as possible
x_ithe i-th point's coordinates
phi(·)the network's confidence function (how sure it is)
sum_iadd up the confidence scores over all input points
R^Tthe rotation applied (transposed because of how matrices multiply)
A tiny worked example
Suppose we have 3 points and sample 4 candidate rotations for a molecule.
Rotation A: network confidence is 0.7 + 0.8 + 0.6 = 2.1
Rotation B: network confidence is 0.5 + 0.5 + 0.5 = 1.5
Rotation C: network confidence is 0.9 + 0.85 + 0.8 = 2.55
Rotation D: network confidence is 0.6 + 0.7 + 0.65 = 1.95
Pick Rotation C (highest sum equals 2.55), then refine with a few nudges of step-by-step optimization.

Maximizing confidence means the network picks the standard form where it is most sure of its answer.

What can go wrong

What can go wrong

Sampling cost. Trying many candidate standard forms costs computation. If you sample 100 rotations per input, you pay 100x the cost. The paper mitigates this by refining locally after picking the best candidate, avoiding redundant computation.
Local optima. The step-by-step refinement might get stuck in a local peak (a nearby good choice that is not the true best). Sampling more candidates first helps locate the global peak because trying more starting points lets you find more possible peaks before refining, but each extra candidate you sample requires computation, so more candidates means slower training.
Network immaturity. Early in training, the network's confidence scores are noisy and unreliable because the network has not learned much yet. The algorithm might pick a bad standard form based on poor signals. The paper does not fully address this; careful initialization of the network helps by seeding it with reasonable starting learned numbers so confidence scores are informative from the start.
Done right. With enough candidate samples and careful tuning, the method gives smooth training and symmetry-respecting models that generalize well to new data.
What a runnable demo should prove

What a runnable demo should prove

Build a simple point cloud classifier on a small dataset (e.g., 10 synthetic 3D shapes). Compare three approaches: (1) no canonicalization (naive baseline), (2) fixed canonicalization, (3) adaptive canonicalization. Train each and track: (a) training loss curve (should be smooth for adaptive, jerky for fixed), (b) accuracy on held-out rotated test shapes (should be high for adaptive), (c) the choice of standard form per input (should vary smoothly for adaptive, jump around for fixed).

smoothness = variance of standard-form changes across nearby inputs; generalization = accuracy on new rotations; stability = how much training loss oscillates per epoch

The demo should make it obvious: adaptive choices create smooth, stable training because the learning signal is continuous and not kinked by rule changes, and respect symmetries better because each input finds its own best form rather than being forced into one rigid mold.
