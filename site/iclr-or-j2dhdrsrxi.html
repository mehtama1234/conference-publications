Adaptive Canonicalization for Equivariant Networks

Instead of picking one fixed standard form for symmetric inputs, pick the form that makes the network most confident in its prediction.

Paper explainersAll themesGraph & Geometric Learning

Symmetry matters in machine learning: a molecule looks the same rotated in space, and a network should give the same answer. The problem is that when you force inputs into a single standard form (canonicalization), it creates jumps and breaks — like forcing a hinge to snap open or closed. This paper replaces that with adaptive canonicalization: the standard form changes with both the input and the network, chosen to make the network's confidence highest. The result is smoother, more reliable learning, because there are no sudden jumps to interrupt the learning direction nudges during training.

Zero assumption version

Canonicalization breaks continuity

A symmetry is when you can move or flip something without changing what it is. A molecule's identity does not change if you rotate it in 3D space. A network that understands symmetry should give the same answer for all rotations of the same molecule.

The old way is canonicalization: before feeding an input to the network, force it into one standard form. Take any rotated molecule, rotate it to a canonical orientation, and feed that to the network. This works in principle — every rotation becomes the same input.

But canonicalization has a hard problem: choosing the standard form is a discrete jump. Imagine you are rotating a molecule smoothly from one orientation to another. At certain angles, the canonical form snaps from one representation to a different one. The network sees this as a sudden jolt — the same smooth motion becomes a jump in the input space. This jolt breaks learning: gradients (the nudges that make the network improve) become noisy or zero, because a jump in input creates a sudden change in what the network sees, so the nudge direction becomes unreliable. The network struggles to learn smoothly, generalization suffers, and it is hard to prove the network can learn any function at all.

In one sentence. Hard jumps when picking a single standard form damage learning and prevent guarantees.

The algorithm as a flow

What it actually does

Recognize symmetry

Understand that many equivalent forms exist (rotations, reflections, eigenvector orderings).

Generate candidates

For the input, compute a few candidate standard forms.

Score by confidence

Feed each candidate through the network and see which one produces the highest confidence.

Pick the winner

Choose the form with the highest confidence as the one to use for this input.

Train once

Use that single form for training, so gradients flow smoothly from a continuous path.

What the paper changes

What the paper changes

The paper changes how the standard form is chosen. Instead of locking in one form for all inputs, the network picks its own form per input.

the object it moves  =  the choice of canonical form
The hidden quantity

Network confidence: the guide

measured quantity  =  predictive confidence

Predictive confidence is how strongly the network believes in its output. Imagine the network is deciding if a molecule is drug-like. Confidence is the certainty of that decision — close to 100% (high confidence) or close to 50% (unsure).

The paper uses confidence as a guide: when deciding which standard form to pick for an input, it scores each candidate form and chooses the form where the network expresses the highest confidence. This is mathematically sound because a well-trained network is most confident on inputs in its natural representation space.

Why it works

Why smoothness flows from adaptive choice

Here is why this works. When you fix the canonical form globally, you force a discrete snap: orbits (sets of equivalent forms) flip between two representations at certain angles, creating a jump discontinuity. The network sees this as a cliff edge — the gradient of loss becomes zero or undefined across the cliff.

Adaptive canonicalization removes the cliff. As you move smoothly through input space (rotating the molecule a tiny bit), the network's confidence smoothly favors one form over another, and the choice of form shifts smoothly too. No jump, no cliff. Gradients flow continuously, and the network can learn to distinguish patterns without interruption.

Theoretically, this gives strong guarantees: because the path is continuous, the network can learn any function (universal approximation). Because confidence is tied to the network's own learned beliefs, the method adapts to whatever the network has learned so far — it co-evolves with training.

The choice rule

First in words:

Standard form chosen to maximize network confidence. If f-theta is the network and x is the input, pick the form g of x that maximizes the network's belief in its output for that form.

Then the compact form:

g*(x) = argmax_g Confidence(f_theta(g(x)))

What can go wrong

What can go wrong

Circular dependence. The choice of form depends on the network, and the network depends on the form. Early in training, the network is random, so confidence scores are noise. Adaptive canonicalization works best after the network has learned patterns and confidence scores become reliable.
Computational cost. You must score multiple candidate forms per input. If there are many orbits (many equivalent forms), this adds overhead. For point clouds with many permutations, the cost can be high.
Choosing candidates poorly. The set of candidate forms must cover the symmetry group well. If you miss important forms, the method cannot pick them and you lose the benefit.
Done right. Use adaptive canonicalization when you have clear symmetries, enough training data for the network to learn confidence, and affordable candidate generation. The paper validates it on molecular graphs and point clouds.
What a runnable demo should prove

What a runnable demo should prove

Build a graph neural network on molecular data. Train it two ways: (1) with fixed canonicalization (rotate each molecule to a single canonical angle), and (2) with adaptive canonicalization (pick the angle by confidence). Log the training loss over time, the validation accuracy, and measure the smoothness of gradient flow (how much do gradients jitter between steps).

smoothness = average absolute change in gradient direction between consecutive steps

The demo must show that adaptive canonicalization produces lower gradient jitter (because the form is chosen smoothly) and better final validation accuracy (because smoother training leads to less noisy learning).
