Diversity Over Frequency: Rethinking Tool Use in Visual Chain-of-Thought Agents

Better visual reasoning comes from exploring more different action paths during training, not from forcing the agent to call tools more often.

Paper explainersAll themesAgents & Tool Use

Visual reasoning agents can call external tools to inspect local image regions or gather extra evidence. A natural guess is that more tool calls should produce better performance because extra evidence can help the agent resolve local uncertainty. This paper shows that the relationship is weaker than it looks. Agents often reduce tool use over training and still get better because training can improve the quality of their reasoning paths even while the final policy calls tools less often. The important factor is not raw tool-call count, but whether training preserves diverse reasoning rollouts instead of collapsing onto a narrow set of repeated behaviors.

Why more tool calls do not automatically mean better reasoning

In visual chain-of-thought systems, tools can zoom in, inspect regions, or provide local evidence. Because tools bring extra information, one might expect that encouraging more tool use would steadily improve performance. The paper finds that this is not what happens in harder tasks such as spatial reasoning and medical visual question answering.

The surprising observation is a tool-use collapse phenomenon: the agent gradually uses tools less often while still improving task accuracy. That means frequency alone is the wrong target. The real question becomes which training signal preserves useful exploration while the model learns when tools matter.

The paper's move in one sentence. Optimize for diverse rollout exploration rather than high tool frequency, because broad exploration helps the agent discover better reasoning strategies.

What the paper changes

What the paper changes

The paper changes the training target. Instead of treating tool frequency as the main sign of good reasoning, it treats diversity of explored action paths as the quantity worth preserving.

the object it moves  =  The exploration objective during visual-agent training
The hidden quantity

Rollout diversity: the hidden quantity

measured quantity  =  How many genuinely different reasoning and tool-use paths remain available during training

The hidden quantity is rollout diversity. Two agents can make the same number of tool calls, yet one may explore many distinct reasoning paths while the other repeats a narrow pattern with only superficial variation. Raw frequency cannot tell these cases apart.

The paper argues that diversity matters because training needs enough exploration to discover useful ways to combine local tool evidence with the full image context. If exploration collapses too early, the agent may settle on a narrow habit that gives decent scores but misses stronger strategies because those alternatives were never explored long enough to be learned.

Why it works

Why this works

Diversity-focused training helps because the agent needs broad exploration to discover strong reasoning plans. A narrow policy may call tools often, yet still fail to test better ways of combining local evidence with the global image because it repeats a small set of familiar paths.

An entropy term helps by resisting early collapse. That does not mean the final agent must use tools more. It means training spends longer exploring the action space, so the best surviving strategy is chosen from a richer set of candidates. Performance improves because the search process during training is better, not because tool frequency is higher.

A simplified diversity objective

First in words:

Train the agent for task success, but add an entropy bonus over action choices so that the policy does not collapse too quickly onto one narrow pattern of reasoning and tool use.

Then the compact form:

score_total = score_task + lambda * entropy(action_distribution)

Every symbol:

score_totalthe objective used during training
score_taskthe task-success part of the objective
lambdahow strongly diversity is encouraged
entropy(action_distribution)a measure of how spread out the agent's action choices remain
A tiny worked example
Suppose the agent has three possible next actions: inspect region A, inspect region B, or answer now.
A collapsed policy puts almost all probability on one action and rarely tries the others.
That policy has low entropy, so the diversity term is small.
A broader policy spreads probability across several useful actions and receives a larger entropy bonus during training.
The larger bonus matters because the agent keeps exploring longer and can discover stronger final strategies.

The real training details are richer, but the direct idea is simple: preserve exploration breadth while the agent is still learning.

What can go wrong

What can go wrong

Too much diversity can delay convergence. If exploration stays wide for too long, the agent may waste training effort on weak paths because the policy does not narrow down fast enough.
Tool collapse may still hide real problems. A drop in tool use is not always harmless because the agent may stop checking local evidence even when the task truly needs it.
Frequency is still useful as a diagnostic. The paper shows frequency is not the main target, but tracking it still matters because an unexplained drop can signal that the agent no longer consults evidence when it should.
Done right. Measure both exploration diversity and final task quality, and test tasks where tools really matter so that the method is judged on whether broader exploration leads to better reasoning.
What a runnable demo should prove

What a runnable demo should prove

Build a visual reasoning agent that can inspect local image crops before answering. Train one version with a reward for using tools more often and another version with a diversity bonus over action rollouts. Keep the base model, tasks, and tools fixed across both settings.

The demo should prove that rollout diversity is the more useful target because the diversity-trained agent reaches better final task performance even when its final tool-call count is lower than the tool-frequency-trained agent.

diversity_gain = final_score_diverse_training - final_score_tool_frequency_training ; collapse_gap = rollout_entropy_diverse_training - rollout_entropy_tool_frequency_training

A useful demo shows that the best training signal rewards broader search, not just more button presses.
