Do We Really Need Permutations? Impact of Width Expansion on Linear Mode Connectivity

Very wide networks can often be connected by a low-loss straight line even without neuron matching, because width makes the midpoint behave closer to an ensemble of the endpoint models.

Paper explainersAll themesOther

Two independently trained networks usually sit in different parameter settings, meaning different learned weight values, even when they solve the same task. If a straight-line interpolation between their weights keeps low loss, the models show linear mode connectivity. Earlier work argued that this usually requires a carefully chosen neuron permutation, since the hidden units in one model may not line up with the hidden units in the other. This paper tests a different explanation. It finds that width expansion alone can create linear connectivity, even with no permutation at all, once the output sharpness is calibrated by temperature. The reason is not just that wide networks provide more matching options. The paper argues that wide layers make the merged network approximate a weighted combination of the two endpoint computations. When that happens layer after layer, the midpoint prediction approaches an ensemble prediction, and ensembles are often low loss because each endpoint already solves the task well.

Zero assumption version

Why a straight line between two trained models usually fails

A neural network is built from many hidden units whose internal roles are not labeled. Two separately trained models may compute similar functions while storing them in different hidden-unit arrangements. Averaging their weights directly can therefore mix incompatible internal signals and create a poor midpoint model.

Permutation methods try to align those hidden units before interpolation. That view says the main obstacle is mismatch between unit identities. The paper asks whether that is the whole story. Maybe the obstacle also depends on width, because wide networks can average internal signals in a way that preserves useful endpoint behavior even when units are not explicitly matched.

The paper's move. Remove permutation matching and study width directly, because if widening alone creates a low-loss line then hidden-unit alignment is not the only reason linear connectivity appears.

The algorithm as a flow

What it actually does

Train two models of the same architecture.

Use independent training runs so the endpoints solve the task without sharing internal unit identities.

Widen the models.

Increase the number of hidden channels or units, because the paper tests whether width alone changes the shape of the interpolation path.

Interpolate weights directly.

Form points on the straight line between the two parameter settings, with no permutation search, because that isolates the effect of width.

Calibrate output temperature.

Rescale output sharpness, because raw averaging can make class probabilities too flat even when the class ordering is mostly preserved.

Measure how layer outputs combine.

Check whether each merged layer resembles an exponentially weighted combination of the corresponding endpoint layers, because that reveals why the straight line stays low loss.

The hidden quantity

The hidden quantity

measured quantity  =  how close the merged layer outputs are to a weighted sum of endpoint outputs

The important quantity is not only the final loss on the interpolation line. It is the internal behavior of each intermediate layer after weights are averaged. If those merged activations, meaning the layer outputs after applying the nonlinearity, stay close to a weighted blend of the two endpoint activations, then the whole network behaves closer to a prediction ensemble than to a broken hybrid.

That quantity matters because final low loss needs to survive every layer. A bad average in an early layer can distort all later computations. The paper's layerwise analysis says width helps the averaged model keep endpoint information alive across many layers because extra channels let mixed signals coexist instead of canceling immediately, which is why straight-line interpolation improves as networks widen.

Why it works

Why width can replace permutation

In a narrow model, averaging unmatched hidden units can cancel important signals. There are too few channels for the mixed representation to carry both endpoint computations at once, so the midpoint can lose class-separating information early in the network.

In a wide model, there is more room for redundant or overlapping computations. Weight averaging can preserve a useful portion of both endpoint pathways, so the merged activations remain close to a weighted mixture of the endpoint activations. That layerwise preservation matters because it prevents error from compounding across depth.

Temperature calibration handles the last mismatch. Even when the merged model gets relative class scores mostly right, the output confidence can be too weak or too sharp after interpolation. Rescaling the output with a temperature corrects that confidence profile, which is why the paper sees linear connectivity appear more clearly after calibration.

At an interpolation point, a layer output can be approximated by a weighted combination of the two endpoint layer outputs. If this holds through depth, then the final prediction stays close to an ensemble prediction.

A tiny worked example
Take two trained classifiers and average their parameters halfway.
If an early hidden layer in the merged model produces outputs close to half of model A's outputs plus half of model B's outputs, the next layer receives a coherent mixed signal.
If the same pattern holds in later layers, the final class scores stay close to what an ensemble of the endpoints would produce.
A wide model can support that preservation more often because it has enough channels to carry mixed information without immediate cancellation.
That is why midpoint loss falls as width increases in the paper's experiments.

The claim is about internal behavior along the interpolation line, not only about endpoint accuracy.

What can go wrong

What can go wrong

Very different endpoint functions may still resist averaging. If the two models solve the task with genuinely incompatible internal computations, widening may not be enough because the merged layers can still distort key intermediate signals.
Calibration fixes confidence, not broken representations. Temperature tuning can repair output sharpness only when the merged model already ranks classes reasonably well. It cannot rescue a midpoint whose earlier layers lost the right task structure.
The result depends on architecture and training regime. Some models include bottlenecks or normalization behavior that change how interpolation behaves, so width alone may not produce the same gains across all families.
Done right. When the architecture is wide enough and the output is calibrated, direct interpolation can stay low loss because the merged network acts much closer to a layerwise ensemble than to a random mixture of units.
