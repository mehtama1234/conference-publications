Interpretable Koopman Learning for Spatiotemporal Prediction

Predict complex fluid and weather patterns by learning how simpler features evolve over time, plus fixing the memory gaps that standard theory misses.

Paper explainersAll themesTime Series & Sequential

Real-world systems like weather and fluid flow change in complex, chaotic ways that are expensive to simulate accurately. The challenge is that you only have scattered, noisy measurements and a computational budget that won't allow running high-fidelity simulations. This paper shows how to learn a simpler mathematical model of these dynamics by watching how carefully chosen features evolve, then reconstruct the full system at any resolution or time horizon.

Zero assumption version

Predicting fluid flow, weather, and other spatial systems is slow and fragile

Systems like wind patterns, ocean currents, and chemical reactions evolve across space and time in ways governed by physics equations. To predict them, you can either run the full physics simulation (accurate but expensive, taking hours per prediction), or learn a statistical model from data.

A beginner would collect measurements at scattered points in space and time, then train a neural network to memorize the input-output patterns. This works if your data is dense and clean. But real-world data is sparse (you measure at only a few locations), noisy (sensors have errors), and irregular (measurements come at unpredictable times and places). The beginner's model sees gaps in the data and hallucinates answers. It also learns slowly because it must juggle millions of raw numbers without any structure.

The paper's move in one sentence. Instead of learning to predict raw system values, learn to predict how a small set of feature values evolve forward in time, treating the system's behavior as a linear (or near-linear) evolution of those features in a hidden space.

The algorithm as a flow

What it actually does

Encode partial observations

From scattered, noisy measurements, a learned encoder computes a small set of feature values.

Evolve features forward linearly

A simple linear transformation predicts what those features will be at the next time step.

Correct for memory effects

Add learned correction terms that remember past feature values, fixing errors from linear-only prediction.

Decode to full system

A learned decoder reconstructs the full system state (at any spatial resolution) from the corrected features.

Repeat recursively

Feed the decoded state back as input and repeat, predicting many steps ahead.

What the paper changes

What the paper changes

The paper changes the target of learning: instead of training to predict raw measurements or reconstructed pixels, train a neural network to predict how a learned low-dimensional set of feature values (just a list of numbers) evolves forward in time.

the object it moves  =  Feature evolution target
The hidden quantity

Non-Markovian memory: a hidden quantity that measures how much past history matters

measured quantity  =  Strength of past-step influence

A hidden quantity in this paper is how strongly past feature values (lists of numbers) influence future feature values. In standard Koopman theory, the assumption is that the next state depends only on the current state (called Markovian evolution, after a mathematician). But real systems often have memory: what happened several steps ago still affects today. The paper measures this by learning a set of learnable correction terms that capture this memory effect.

The Mori-Zwanzig formalism is a mathematical recipe that augments a pure linear evolution (which is Markovian) with additional memory terms that depend on the history. These terms are learned from data, so the paper automatically discovers how much and what kind of memory the system needs.

Why it works

Why it works: the causal chain

Standard Koopman theory says that any smooth system's behavior can be described as a linear transformation of learned features in a hidden space. If the system were truly linear, a single operation on the feature values (multiply each by a learned number and add them up) would predict all future states perfectly. But real fluid dynamics and weather are nonlinear—the future depends on the current state in a complicated way that is not just a weighted sum.

The paper's fix is twofold. First, it learns the feature space itself (called observation functionals in the paper). A neural network encoder maps raw, scattered measurements to a compact set of feature values (a list of numbers); a decoder maps that list back to full-field predictions at any resolution. This flexibility lets the paper sidestep the curse of fixed Koopman modes and scale to arbitrary measurement resolutions.

Second, it augments the linear evolution with memory correction. The Mori-Zwanzig formalism explains mathematically why linear evolution alone is insufficient: it introduces truncation error—the loss of information when you compress from infinite-dimensional dynamics down to a finite-dimensional feature space. The paper learns a set of correction terms that depend on past feature values, allowing the model to recover what was lost. This is why the model remains accurate even in very low-dimensional feature spaces and over long prediction horizons: the memory terms stitch together the forgotten dependencies.

Math after the picture

The mathematical form

First in words:

Next feature vector equals (linear transformation times current features) plus (correction terms summed over past feature vectors)

Then the compact form:

f_{t+1} = A * f_t + sum_{k=1}^{K} B_k * f_{t-k} + noise

Every symbol:

f_tfeature vector at time t (a list of numbers)
f_{t+1}feature vector one time step later
Alearned linear transformation matrix
B_klearned correction matrix for past time step k
Knumber of past steps to remember
sum_{k=1}^{K}add up the corrections for all remembered past steps
A tiny worked example with 3 features and 2 memory steps
Current feature vector: f_t = [2.0, 1.5, 0.8]
Previous steps: f_{t-1} = [1.9, 1.4, 0.7], f_{t-2} = [1.8, 1.3, 0.6]
Linear evolution: A * f_t = [[0.9, 0.1, 0], [0.05, 0.85, 0.05], [0, 0.1, 0.9]] * [2.0, 1.5, 0.8] = [2.01, 1.51, 0.80]
Memory term 1: B_1 * f_{t-1} = [[0.05, 0, 0], [0, 0.05, 0], [0, 0, 0.05]] * [1.9, 1.4, 0.7] = [0.095, 0.07, 0.035]
Memory term 2: B_2 * f_{t-2} = [[0.02, 0, 0], [0, 0.02, 0], [0, 0, 0.02]] * [1.8, 1.3, 0.6] = [0.036, 0.026, 0.012]
Sum: f_{t+1} = [2.01, 1.51, 0.80] + [0.095, 0.07, 0.035] + [0.036, 0.026, 0.012] = [2.141, 1.606, 0.847]
Result: the memory terms added 0.14 to the first feature, a small but important correction from the system's history.

The linear part makes the fast, direct changes; the memory correction terms capture delayed effects that a pure linear model would miss.

What can go wrong

What can go wrong

If the system has very long-range memory, using only K past steps fails. If the true system depends on events from 100 time steps ago, but the model only remembers the last 5, it will miss important causal links. The paper learns K from data, so it works best when the memory horizon matches the data.
If measurements are extremely sparse or misaligned in time, the encoder may fail to infer features. The learned encoder must extract meaning from noisy, scattered observations. If the observation pattern is too random or the noise level is very high, the encoder cannot learn a stable feature representation.
If the system undergoes a bifurcation or sudden regime change, linear evolution is no longer valid. The paper assumes that in the learned feature space, dynamics are approximately linear. If the system switches behavior (e.g., a fluid transitions from laminar to turbulent flow), the linear model cannot adapt instantly.
Done right: use memory length K and resolution-free decoding chosen from the data. The paper's framework is designed to find the right K and learn discretization-invariant encoders and decoders. This means the decoder learns how to reconstruct the system at any grid resolution or density, not just the resolution it was trained on—so it naturally scales to high-resolution predictions and long time horizons without retraining.
What a runnable demo should prove

What a runnable demo should prove

Build a small spatiotemporal system: simulate a one-dimensional advection-diffusion equation (a simplified model of a gas spreading and drifting in a pipe), or use a real small dataset like sea-surface temperature on a grid. Randomly sample 20% of grid points at each time step as your observations. Train the encoder-feature-evolution-decoder pipeline with and without memory terms. Measure prediction accuracy at 1, 10, 50, and 100 time steps ahead on a held-out test set.

Long-horizon RMSE = root-mean-square-error at time step 100

The critical insight: the model with memory correction stays accurate far longer than the model without it, even though both use the same number of learned features.
