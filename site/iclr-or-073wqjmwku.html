COMPACT: Composite Visual Teaching

Instead of randomly picking training images and questions, pick fewer images but write questions that layer multiple skills together, so each example teaches more.

Paper explainersAll themesDatasets & Benchmarks & Evaluation

Multimodal models (machines that read images and answer questions about them) are usually trained on huge datasets. COMPACT finds a smarter way: use far fewer training images, but write multi-layered questions for each one that demand multiple visual skills at once. The model learns faster from fewer examples because each complex question creates a bigger, more informative learning gap than a simple one.

Zero assumption version

The waste in random data collection

Today's multimodal models learn by reading thousands of images paired with text questions. But most of these pairs are simple: 'What color is this?' or 'Is there a dog?' The model learns quickly from the first few thousand, then learns slower from the rest. Yet datasets keep growing to a million examples because nobody knows which ones actually matter.

A beginner might try: 'Pick only the examples where the model guesses wrong.' But that is expensive — you have to train the model, see where it fails, then collect new data. You end up training many times.

The real problem. Most training images are paired with questions so simple they teach little. You waste data budget.

The algorithm as a flow

What it actually does

Start with one image

Pick an image from the full dataset.

Identify atomic skills

List basic visual tasks in this image: object detection, counting, scene understanding, spatial reasoning, color naming.

Compose them together

Write ONE multi-part question that asks for multiple of these skills at once, e.g., 'How many red cars are parked to the left of the building?'

Synthesize the text

Use a language model to generate a detailed, accurate answer combining all those skills.

Keep one per image

Use this composite example instead of ten simple ones, so dataset size drops 10x but learning per example jumps.

What the paper changes

What the paper changes

COMPACT does not change which images you use. It changes the questions paired with each image — from simple, single-skill questions to complex, multi-skill ones.

The hidden quantity

The hidden quantity: Skill compositionality

measured quantity  =  how many basic skills a question bundles

The paper's key insight is that not all questions are equally valuable. A simple question like 'What color?' teaches only one skill. A composite question like 'What are the colors of all vehicles on the left side of the image?' bundles object recognition, spatial reasoning, and color understanding in one example.

COMPACT measures this by identifying atomic visual capabilities (recognize objects, count instances, understand spatial layout, describe relationships, infer properties) and tracking how many of these a synthesized question demands. Questions that require three or four skills are worth more than ten questions each asking one skill.

Why it works

Why layering skills together teaches faster

A model learns by comparing its guess to the right answer and adjusting itself to close the gap. If the gap is small (a simple question the model almost gets right), the adjustment is tiny and slow, because the model is already close and has little to learn. If the gap is large and informative (a complex question that forces the model to strengthen multiple skills), the adjustment is bigger and better-aimed, because the model must move in multiple directions at once — object detection one way, spatial reasoning another, counting a third — all tied to the same answer.

COMPACT's mechanism: when you combine multiple skills in one question, you create a larger, more informative learning gap. The model cannot guess right by half-remembering just one skill — it must activate and tune object detection, spatial reasoning, counting, and color understanding together. That forces a big, coherent adjustment that sculpts interconnected structure faster, because all those skills reinforce each other in a single problem — the model tightens them together instead of learning each one in isolation over ten separate examples. So ten examples with composite questions teach the model more than one hundred simple ones.

The training efficiency equation

First in words:

data_reduction = (atomic_skills_per_question) × (accuracy_per_unit_data) / (baseline_accuracy_per_unit_data)

Then the compact form:

N_final = N_baseline / (sum_i skill_i * weight_i)

Every symbol:

N_finalnumber of training examples needed with COMPACT
N_baselinenumber of examples with simple random questions
skill_iwhether question i includes atomic skill i (0 or 1)
weight_ihow much that skill accelerates learning
A tiny worked example
Baseline: 100 training examples, each asking one simple skill (color naming or object detection).
COMPACT: 10 examples. Question 1 asks 'count objects AND describe colors' (2 skills). Question 2 asks 'objects AND layout AND relationships' (3 skills).
Average skills per COMPACT question: 2.5. If each skill reduces data needed by 40%, then 10 × (1 + 0.4 + 0.4 + 0.4 + 0.4) ≈ 30 effective example-units.
Result: 10 COMPACT examples teach as much as ~30 simple ones, so you can reach 100-example performance with 30-33 total examples, a 67% reduction. Real COMPACT achieves 90% reduction, meaning skills are higher-weight and/or synthesis is very precise.

The more skills a question bundles, the fewer total examples the model needs to learn all of them.

What can go wrong

What can go wrong

Synthetic answers can be inaccurate. If a language model writes a composite answer that contradicts the image, the model learns the wrong thing. Solution: use a strong base model to synthesize answers, and optionally have a human spot-check a sample.
Composing skills that do not cohere. If you force a question to ask for, say, object detection and sentiment analysis (which requires text in the image), you create an unnatural, ambiguous example. Solution: identify which atomic skills naturally co-occur in an image before composing them.
Losing simplicity for struggling models. If a model is already weak, jumping straight to complex composite questions can overwhelm it. It needs some easy examples to build basic skills first. Solution: gradually increase compositionality during training, or mix 80% composite with 20% simple.
Done right. Careful skill selection, accurate synthetic answers, and gradual compositionality ramp make COMPACT work well. When measured in real training runs (not theory), the paper shows 90% data reduction while holding performance steady.
What a runnable demo should prove

What a runnable demo should prove

Build a small visual instruction tuning setup: take a 10-class image dataset (e.g., CIFAR-10 scaled to higher resolution, or a simple image classification benchmark), and split it into two training pipelines.

Pipeline A (naive): randomly sample 1000 image-question pairs, each asking one simple skill ('What color is the main object?' or 'Is there a vehicle?'). Train a small multimodal model (e.g., CLIP-based) for a fixed number of steps. Measure accuracy on a held-out test set of complex questions that mix multiple skills.

Pipeline B (COMPACT): sample only 100 images, but synthesize 10 composite questions per image by hand or using a small language model (e.g., asking 'Count all red objects on the left of the image'). Train the same model for the same number of steps. Measure accuracy on the same complex test set.

The demo succeeds if Pipeline B (100 images, 1000 examples total, all composite) reaches at least 90% of Pipeline A's accuracy (1000 simple examples), proving that compositionality compresses data.

data_efficiency_gain = accuracy_compact_at_100k_examples / accuracy_baseline_at_1m_examples

If COMPACT data hits 100%+ of baseline accuracy with 10x fewer images, compositionality is the lever — questions that demand multiple skills teach faster because each one forces the model to align and tighten many skill-pathways in one coherent adjustment.
