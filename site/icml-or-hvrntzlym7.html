Agentic Model Predictive Questioning Control in Visual Design

Plan clarification questions over several rounds so that the agent improves final design alignment while keeping the user's answering effort low.

Paper explainersAll themesAgents & Tool Use

Visual design agents often ask clarification questions that maximize information gain without accounting for how hard those questions are for a user to answer. A-MPQC frames questioning as a receding-horizon control problem: it plans a short future sequence of questions, estimates both design alignment and user burden, asks the next best question, then replans after the user's reply so that the whole interaction stays useful without becoming tiring.

Zero assumption version

Why information-seeking alone is not enough

A design agent can ask many useful questions, but users still pay the cost of understanding and answering them. A question that reveals a lot may still be a poor choice if it is hard to answer, too open-ended, or badly timed.

Most clarification systems optimize only how much intent is uncovered. This paper adds user burden to the objective so that the agent chooses questions that improve final design quality without pushing too much work onto the user.

The paper's move in one sentence. Treat multi-round questioning as a control problem that jointly optimizes future design quality and the user's answering cost.

The algorithm as a flow

What it actually does

Estimate current uncertainty about user intent

Use the current prompt and earlier replies to identify which design choices are still unclear so that the next question targets the remaining ambiguity.

Generate candidate question sequences

Plan several possible short-horizon question paths because the best first question depends on what later questions it makes possible.

Score alignment and burden

Evaluate each candidate using predicted design improvement and predicted user effort so that the selected question balances both goals.

Ask the next question

Choose the first question from the best short-horizon plan so that the agent acts now while still reasoning about future interaction.

Replan after the reply

Update the plan after each answer because the user response changes both uncertainty and future burden.

The hidden quantity

The hidden quantity

measured quantity  =  Future value of asking one question now

A question can help in two ways: it can reveal intent directly, and it can make later questions simpler. That long-run value is hidden at the moment the question is asked because the future reply and later plan are still unknown.

A-MPQC estimates that future value with lookahead planning and a burden-aware reward. This matters because a slightly less informative question now may still be better if it sharply reduces future user effort.

Why it works

Why this works: ask questions that help now and simplify later interaction

The method works because clarification is sequential. A question should not be judged only by the immediate reply it brings. It should also be judged by how it changes the remaining ambiguity and the cost of the rest of the conversation.

Adding burden to the reward matters because a user can stop cooperating or give weak answers when questions are too demanding. Planning over a short horizon helps the agent front-load simple disambiguating questions so that later rounds can be shorter or more structured.

Math after the picture

Trade off design gain against user effort

First in words:

A simple summary is that the agent chooses the question plan with the highest predicted design gain minus predicted user burden. That tradeoff is the core of the paper because a question is useful only when the value of the answer justifies the effort required to obtain it.

Then the compact form:

plan_score = design_gain - burden_cost

Every symbol:

plan_scoreoverall value of a candidate short-horizon question plan
design_gainpredicted improvement in final design alignment from the answers
burden_costpredicted user effort needed to answer the questions in the plan
A tiny worked example
Plan A starts with an open-ended branding question.
Predicted design gain is 8 and burden cost is 6, so plan score is 2.
Plan B starts with a yes-no question about modern versus playful tone.
Predicted design gain is 6 and burden cost is 1, so plan score is 5.
The system asks Plan B's first question because the lower effort produces a higher overall plan score.

The real controller replans after each user reply, but this equation captures the paper's key idea that design quality and user effort are optimized together.

What can go wrong

What can go wrong

Burden estimates may be wrong. If the surrogate model misjudges what users find easy or hard, the controller can optimize the wrong cost and choose poor question formats.
Short-horizon planning can miss long-range effects. A receding-horizon plan may choose a locally easy question that blocks a better clarification path later because the lookahead depth is limited.
User intent may shift during the interaction. If the user changes preferences while answering, early plan assumptions become stale, so replanning helps by updating the next choices but cannot fully remove the inconsistency because the earlier questions were based on old preferences.
Done right. The paper is useful because it treats human effort as a first-class optimization target during clarification.
What a runnable demo should prove

What a runnable demo should prove

Build a visual-design assistant that must generate a page layout from an incomplete brief. Give it several question formats, including yes-no, multiple choice, and open response. Compare one-step information-gain selection against burden-aware short-horizon planning with replanning after each answer.

The demo should show that burden-aware planning reaches better final preference match with fewer difficult questions because early low-cost questions reduce ambiguity that would otherwise require longer explanations later. Track both final human preference ratings and a burden proxy such as response length or rejection rate.
