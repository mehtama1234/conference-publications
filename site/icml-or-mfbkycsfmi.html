On the Coordination of Value-Maximizing Bidders

When several auto-bidders are controlled by the same party, let only the coordinated bidder with the highest value pursue each auction so the group stops bidding against itself.

Paper explainersAll themesOther

Online ad platforms usually treat each auto-bidder as if it acts alone. This paper studies the case where several bidders or campaigns are actually coordinated by one manager. If all of them bid independently, they can drive up price for the same impression even though only one coordinated bidder can receive the slot. The paper analyzes a simple rule: for each auction, activate only the coordinated bidder with the highest value and keep the others out. That rule matters because it removes internal competition while preserving competition against outside bidders, so the coordinated group can meet Return-on-Spend targets, meaning value earned per unit of spend, with less self-inflicted waste.

Zero assumption version

Independent bidding breaks when the bidders share the same owner

Auto-bidding systems usually optimize one campaign at a time. That is reasonable if the campaigns belong to unrelated advertisers. It is wasteful when several campaigns are managed by the same advertiser or by the same third-party agent, because two coordinated campaigns may chase the same impression even though the group only wants the impression assigned once.

That internal clash harms both spend discipline and allocation quality. One campaign can raise the clearing price faced by another coordinated campaign, and the group can win the slot with the wrong internal bidder. The paper asks how much is gained by coordinating these bidders before they enter the external auction.

The paper's move in one sentence. For each auction, compare the coordinated bidders' values, keep only the highest-value coordinated bidder active, and let that bidder compete with everyone outside the group.

The algorithm as a flow

What it actually does

Estimate each coordinated bidder's value

For the current auction, compute how much value each managed bidder or campaign would get from winning.

Rank the coordinated bidders

Compare those values so the manager knows which coordinated bidder benefits most from this impression.

Activate only the top coordinated bidder

Suppress the rest of the coordinated bids because they can only raise the group's own payment without adding extra impressions.

Run the market auction against outsiders

Let the chosen bidder compete normally with outside bidders whose bids still determine whether the slot is worth buying.

Check group-level spend and return

Evaluate the total value and the Return-on-Spend target across the coordinated set because the point of the mechanism is group performance, not isolated campaign behavior.

What the paper changes

What the paper changes

The paper changes who is allowed to enter each auction from a coordinated set. Instead of letting every managed bidder submit a bid, it chooses one internal representative.

the object it moves  =  active coordinated bidder per auction
The hidden quantity

The hidden quantity

measured quantity  =  The highest-value coordinated bidder for the current auction

The market only sees submitted bids. The coordinator, however, also knows which bidder would create the most internal value if it won. That identity is the key hidden quantity because it determines which bid is genuinely useful and which bids are only internal noise.

Once that bidder is identified, the mechanism is simple. The other coordinated bidders no longer need to express their demand in this auction, because their presence does not create extra supply, extra impressions, or extra group value.

Why it works

Why removing internal bids raises group efficiency

The coordinated bidders are not independent sources of demand. If two of them bid for the same slot, the group has not discovered two separate opportunities; it has duplicated its own willingness to pay. That duplication can raise the price paid by the eventual coordinated winner because outside bidders react to a stronger auction and because internal bids can change who wins inside the group.

The one-active-bidder rule removes only the harmful part of competition. It keeps external market pressure, which is still needed to decide whether the impression is worth its price, but it deletes internal pressure, which only reshuffles money within the group's own objective. That is why the paper can show higher total value at a given spend target for broad classes of value-maximizing auto-bidders.

Math after the picture

The coordination rule

First in words:

Select the coordinated bidder with the largest value for the current auction and suppress the rest before bidding reaches the external market.

Then the compact form:

i* = arg max_i v_i ; active_bidders = { i* }

Every symbol:

i*the coordinated bidder chosen to represent the group in this auction
v_ithe value that coordinated bidder i would get from winning this impression
active_biddersthe subset of coordinated bidders that are allowed to bid externally
A tiny worked example
Suppose campaign A values the impression at 10, campaign B at 8, and campaign C at 6.
Independent bidding sends all three into the auction.
Coordination keeps only campaign A active because 10 is the largest internal value.
If the top outside bid is 7, campaign A still wins, but the group avoided letting B and C raise pressure for no extra gain.
The value collected by the group is still driven by campaign A's 10, while the internal overlap no longer distorts the bidding set.

The paper's theory is broader than this one-line rule because it studies RoS-constrained auto-bidders, but the core mechanism is the choice of a single internal representative.

What can go wrong

What can go wrong

The value estimates can be wrong. If the manager misranks the coordinated bidders, it may suppress the bidder that should have represented the group, so the mechanism inherits the quality of the value model.
Coordination may be limited by platform rules. Some ad systems may not let a manager freely suppress or merge bidder participation, which means the clean theoretical rule can be hard to implement exactly.
Group goals may not be purely additive. If campaigns have pacing rules, fairness requirements, or long-run brand goals, the highest one-shot value may not capture the full coordination objective.
Done right. This mechanism is most persuasive when coordinated bidders truly share an objective and when the manager can estimate per-auction value well enough to choose the right representative.
What a runnable demo should prove

What a runnable demo should prove

Simulate repeated second-price ad auctions with three coordinated campaigns and several outside bidders. Give each coordinated campaign its own value distribution and its own RoS target, then compare two policies: independent bidding by all campaigns and a coordination layer that keeps only the top-value coordinated bidder active in each auction.

Track total value, spend, RoS compliance, and the frequency with which more than one coordinated bid would have entered the same auction. The demo should show that value rises at the group level because the coordinator removes overlap that never produced additional impressions.

group_RoS = total_value / total_spend

The demo must make the internal-competition effect visible, because that is the reason a single active bidder can dominate independent coordinated bidding.
