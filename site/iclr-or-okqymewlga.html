Align Your Structures: Structure Pretraining for Molecular Dynamics

Split molecular dynamics generation into two stages: learn static structure shapes first, then learn how they move in time.

Paper explainersAll themesAI for Science

Generating the dance of atoms over time (molecular dynamics) is hard because there is very little real trajectory data. This paper solves it by training on two separate problems: first, learn what single molecular shapes look like from a huge dataset of static structures, then learn the timing and motion from the smaller trajectory dataset. Like learning to draw a face before learning to animate it.

Zero assumption version

Why directly learning molecular movies fails

A molecular dynamics trajectory is a movie: 100 frames showing atoms moving, bending, and rearranging. Each frame is a 3D snapshot of atomic positions and the atoms bonded together. You want to teach a neural network (a mathematical pattern-finder) to generate these movies from scratch, frame by frame, the way it generates image sequences.

A beginner would train one big model on trajectory data: give it one frame, predict the next frame, repeat. But there is almost no trajectory data available—labs run a few thousand real simulations, while millions of static structures (single snapshots) exist. The model is starving for examples.

Worse: each frame is its own puzzle. The network must learn to draw chemically plausible structures AND remember that atoms move smoothly from frame to frame. These are two separate problems competing for the model's learning focus. The model fails at both.

In one sentence. Instead of learning trajectories whole, first master static structures, then layer on temporal flow.

The algorithm as a flow

What it actually does

Step 1: Train a structure model

Use a diffusion model (a denoiser that learns to gradually add and remove noise) on millions of static molecular structures. It learns what valid bond angles and atom spacing look like.

Step 2: Freeze it

Lock the learned structure knowledge. Do not change these weights.

Step 3: Add temporal linking layers

Stack new trainable layers on top. These layers read the current frame and the previous frame and learn to blend them smoothly.

Step 4: Mix at every level

At each layer, interpolate: 70 percent frozen structure knowledge, 30 percent new temporal knowledge. As layers go deeper, the blend shifts.

Step 5: Train only on trajectories

Tune the temporal layers using the small trajectory dataset. The structure part already knows chemistry; the temporal part learns motion.

What the paper changes

What the paper changes

Instead of one model, the paper uses two models stacked together. The bottom model is a frozen structure denoiser (learned from static data). The top layers are new trainable temporal modules that learn to move structures smoothly. The paper changes how these two talk to each other: at each layer, a linear mixing dial blends the structure signal with the motion signal.

the object it moves  =  The mixing weights between frozen structure layers and new temporal layers
The hidden quantity

The temporal alignment signal

measured quantity  =  How much of each frame's structure gets kept versus replaced

The paper measures something called temporal consistency. This is not a noise level or a loss value—it is the degree to which consecutive frames are genuinely linked by plausible motion, not just random structural variations. When a bond angle changes by 2 degrees from frame to frame, that is consistent; if it jumps 45 degrees, it is broken.

The temporal interpolator enforces this by asking: does the structure model predict frame B's atoms look right? And do the temporal layers predict frame B flows smoothly from frame A? If both say yes, the interpolation succeeded.

Why it works

Why splitting the work makes it work

The structure model has learned from millions of examples what atoms bonded together should look like: certain angles are plausible, certain distances are physical. This knowledge is brittle if you try to teach it trajectory dynamics simultaneously—it gets drowned out by motion noise.

By freezing it, the paper says: this part of the model will never be allowed to break chemical rules. Every frame it generates will automatically satisfy bond constraints. Now the temporal layers only have to solve one problem: make frames flow into each other smoothly. The model can focus.

The linear interpolation (70 percent structure, 30 percent temporal) makes this work. Early layers get more structure guidance (they are close to the frozen layers); later layers get more temporal guidance (they are where motion decisions happen). This glues the two problems together without letting one cancel the other out.

The mixing equation

First in words:

temporal output equals alpha times structure output plus one-minus-alpha times temporal-attention output, where alpha decreases layer-by-layer

Then the compact form:

y_layer = alpha * structure(x) + (1 - alpha) * temporal(x, x_prev)

Every symbol:

y_layeroutput of this layer in the mixed model
alphablend weight: how much structure vs. temporal (decreases as layers go up)
structure(x)output from the frozen pretrained denoiser
temporal(x, x_prev)output from new attention layers that see current and prior frames
xthe current frame's atom coordinates and features
x_prevthe prior frame's atom coordinates and features
A tiny worked example
Layer 1 (bottom, close to structure): alpha = 0.7, so output = 0.7 * structure(x) + 0.3 * temporal(x, x_prev). Structure dominates.
Layer 3 (middle): alpha = 0.5, so output = 0.5 * structure(x) + 0.5 * temporal(x, x_prev). Equal weight.
Layer 6 (top, close to motion): alpha = 0.2, so output = 0.2 * structure(x) + 0.8 * temporal(x, x_prev). Temporal dominates.
Result: bottom layers enforce atoms stay bonded; top layers coordinate smooth transitions. Both constraints satisfied together.

The dial at each layer tunes how much the frozen structure knowledge should override the learned temporal flow, ensuring chemical realism and realistic motion.

What can go wrong

What can go wrong

Structure pretraining too weak. If the pretrained model has not learned chemistry well (e.g., trained on too few examples or on unclean data), then no amount of temporal layers will fix bad structures. The first stage is the foundation.
Temporal layers cannot recover from structure errors. Since the structure model is frozen, if it outputs a chemically impossible atom position, the temporal layers cannot correct it. Frozen parts are frozen.
The interpolation weights are fixed. The paper uses fixed alpha values (70, 50, 30 percent at different layers). If the dataset requires a different blend—say, more structure emphasis on certain frames—the method cannot adjust. A learnable alpha could adapt the blend per-frame, which might catch finer temporal variations, but would require more training and make the model larger and slower.
Done right: pretraining data is large and clean. If the conformer dataset is genuinely representative of real molecular shapes, and the trajectory dataset is accurate simulations, the method produces realistic movies.
What a runnable demo should prove

What a runnable demo should prove

Write a simple script that loads the pretrained structure model and the trained temporal interpolator. Feed it the first frame of a real trajectory (a snapshot of atom positions and bonds). Have the model generate the next 10 frames. Compare each generated frame to the real trajectory on three metrics: (1) Do generated atoms stay bonded to their partners or do bonds break? (2) Do atom positions drift smoothly or jump erratically? (3) Do the energies calculated from atomic positions fall within the plausible range or spike to infinity?

temporal_smoothness = average of (distance_moved from frame t to t+1) for all atoms. Lower variance = smoother. bond_preservation = fraction of bonds that stay within plausible distance in all frames. energy_validity = fraction of frames with energies in the range of real simulations.

A good demo makes it impossible to ignore that the generated trajectory moves like real atoms: smooth, chemically coherent, never teleporting or breaking bonds, because the pretrained structure model enforces chemical realism and the temporal layers enforce smooth transitions.
