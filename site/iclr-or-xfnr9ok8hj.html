Latent Wasserstein Adversarial Imitation Learning

Learn a robot's behavior from just a few state recordings by pre-training a map of how the world changes, then matching expert paths in that learned space.

Paper explainersAll themesReinforcement Learning

A robot usually learns by watching someone do a task and mimicking every movement. But that requires videos with both positions AND actions written down—hard to collect. This paper shows how to learn from just state recordings (like still photos), using a clever trick: first, learn what the world looks like from the inside (which moves lead where), then use that map to recognize expert paths even without seeing the expert's buttons.

Zero assumption version

The data collection bottleneck

Most imitation learning methods need many video clips showing an expert doing the task. Each clip must record both the world state (where the robot is, what it sees) AND the expert's actions (which button they pressed, how far they turned the wheel). Recording actions is hard—you need sensors in the controller, or you have to annotate videos by hand.

A beginner might think: just ignore the actions, use the state recordings alone. But then the robot has no way to connect state A to state B—it only sees still photos with no arrows between them. Without knowing which moves led to each photo, the robot cannot tell expert paths from lucky accidents.

The core trick. Pre-train a reward function using random state recordings, which teaches it which state-pairs are reachable; then use that knowledge to spot expert paths in state-only videos.

The algorithm as a flow

What it actually does

Stage 1: Pre-train the map

Use cheap random state recordings to train a value function (ICVF) that learns how nearby states are in the real world.

Stage 2: Freeze and extract

Extract the learned state-representation (the map itself), freeze it so it will not change.

Stage 3: Build a distance metric

In this frozen learned space, measure distance between state-pairs: close means reachable in one step, far means unreachable.

Stage 4: Adversarial matching

Train a discriminator to tell expert state-pairs from random state-pairs, using the learned distance metric.

Stage 5: Reinforce the policy

Feed rewards (from the discriminator) to a standard RL algorithm; policy learns to reproduce the expert's state sequence.

What the paper changes

The single object being moved

The paper changes one central thing: the distance metric you use to spot expert paths. Normally (in prior Wasserstein imitation learning), you measure how far apart two states are by their raw numbers—pixel differences, position coordinates. But the real world does not care about straight-line distance between those numbers; what matters is how many steps an action can move you. Two very different pixel-states might be one step apart in reality (a camera zoom and a position change look different but are reachable from each other), while two similar pixel-states might be impossible to jump between (two frames from different tasks).

The hidden quantity

The hidden quantity: dynamics-aware state distance

measured quantity  =  Reachability in the learned space

The paper introduces a hidden quantity it estimates: how far apart two states really are, measured in a way that respects how the world actually evolves. This is not Euclidean distance (straight-line pixel difference); it is reachability distance—how many steps it takes to get from one state to another.

The paper estimates this by pre-training an Intention Conditioned Value Function (ICVF) on random state recordings. ICVF learns an implicit embedding of each state by answering the question: if I want to reach state B starting from state A, is that feasible? By training on pairs from random walks, ICVF learns which state-pairs are one-step-apart. The learned representation encodes this implicit reachability; states that are reachable from each other cluster together, while unreachable states scatter apart. The paper then uses this learned space as the metric.

Why it works

Why it works: the causal chain

The core insight: if you have a good map of how the world works (which moves lead where), you can tell expert behavior from random behavior without ever seeing the expert's actions. Here is how it works step by step.

First, pre-training learns the map. The paper trains ICVF on random state recordings—cheap, easy to get. ICVF learns to predict reachability by seeing how random walks move through states. As a result, the model learns the implicit dynamics of the environment: from state A, what other states are one step away? The learned embedding captures this by arranging states so that reachable states cluster together in the representation space.

Second, the learned space becomes the ruler. In traditional Wasserstein imitation learning, you measure distance in the raw state space (pixel coordinates, sensor readings). But this distance does not respect dynamics—two visually different frames might be reachable in one step, while two visually similar frames might be impossible to connect. By switching to the learned space, you measure distance in a way that the environment understands. Distances in the learned space encode reachability.

Third, this makes expert paths visible, because expert state-sequences form a chain where each state is reachable from the previous one—the states are close together in the learned space—while random state-sequences jump around with each random state far from the others in terms of reachability. So in the learned space, expert paths show up as tight clusters, while random paths scatter. Because expert transitions are clustered close together while random transitions are spread far apart, they are easy to tell apart.

Fourth, the discriminator uses this. An adversarial discriminator is trained to tell expert state-pairs from random state-pairs, using the learned distance metric. Because expert states are now clustered (close in reachability), the discriminator easily learns to distinguish them. The discriminator becomes a reward signal: high reward for transitions that stay within the expert cluster, low reward for transitions that scatter.

Finally, RL follows the reward. A standard RL algorithm (TD3) uses the discriminator's rewards to train a policy. The policy learns to replicate the expert's state sequence by maximizing these rewards. Because the rewards are based on a dynamics-aware metric, the policy learns the right behavior even though it never saw the expert's actual actions.

Math after the picture

The equation: Wasserstein distance in learned space

First in words:

The paper optimizes a minimax objective: minimize over policy, maximize over discriminator. The discriminator predicts if a state-pair transition came from the expert or random behavior, in the learned embedding space. The loss uses the learned distance metric and gradient penalty to enforce the Lipschitz constraint.

Then the compact form:

min_π max_f E_(s,s') ~ d^π [f(φ(s), φ(s'))] - E_(s,s') ~ d^E [f(φ(s), φ(s'))] + λ * gradient_penalty

Every symbol:

f(φ(s), φ(s'))discriminator that scores state-pair transitions in the learned space
φ(s)learned embedding of state s from ICVF pre-training
d^πstate-pair distribution from current policy
d^Estate-pair distribution from expert demonstrations
λweight of gradient penalty to enforce Lipschitz constraint
Tiny numeric walkthrough
Expert state-pair A→B in learned space: distance 0.2 (close, reachable). Discriminator predicts score +0.8 (high confidence expert).
Random state-pair C→D in learned space: distance 2.1 (far, unreachable). Discriminator predicts score -0.7 (high confidence random).
Policy updates to maximize rewards on A→B-like transitions and minimize on C→D-like ones.
Gradient penalty keeps the discriminator smooth: prevents it from exploiting noise at the boundary.

The key difference from prior work: in the learned space, expert transitions are close (low discriminator loss) while random transitions are far (high discriminator loss), making the signal clean.

What can go wrong

What can go wrong

Bad pre-training data If the random state recordings do not cover the state space well, ICVF learns a poor map. Expert states might map to scattered regions, making them indistinguishable from random. Fix: ensure random data spans the environment.
Expert data is outliers If the expert operates in a part of the state space that random walks never visit, ICVF's embedding is undefined there. The learned metric breaks down for expert transitions. Fix: include at least one expert trajectory in the pre-training mix, or collect random data from the same region.
Noisy state observations If states are recorded with sensor noise (e.g., position jitter), the learned reachability distance gets blurred. Nearby states in the clean space become far in the noisy space. The discriminator cannot tell expert from random. Fix: add noise tolerance to ICVF training.
Done right When pre-training covers the state space, expert data comes from the same states the model has seen, and observations are clean, the learned metric is tight and discriminative. Expert paths stand out as recognizable chains even without action labels.
What a runnable demo should prove

What a runnable demo should prove

The demo should show that a robot can learn a continuous control task (e.g., reaching a target in a simulation) from a single expert state-only trajectory. It should run two scenarios: (1) LWAIL with the learned metric from ICVF pre-training, and (2) a baseline using raw Euclidean distance. The comparison should be stark: LWAIL succeeds (robot learns to reach the target), baseline fails (policy remains random or suboptimal).

Success rate = (times policy reaches target) / (total trials)

The demo must show that by learning how the world's states connect first, you can teach a robot from almost no expert data.
