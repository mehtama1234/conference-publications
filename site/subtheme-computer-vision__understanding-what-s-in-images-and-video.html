Understanding what's in images and video

Teaching models to recognize, locate, and segment objects in visual data—what things are, where they are, and their boundaries.

All themesField mapMathematicsAll explainers
What this is

This is the core of computer vision: teaching machines to recognize objects and understand scenes. The basic task is simple in principle but hard in practice: given a photo, identify what objects are in it, where they are located, and trace their exact boundaries. A cat sitting on a chair is three problems stacked together. First, detect the cat — find a box around it. Second, classify it — label that box 'cat.' Third, segment it — outline every pixel that belongs to the cat, pixel by pixel, so you know where the cat ends and the chair begins.

The challenge is that the same object looks completely different depending on viewpoint, lighting, scale, and occlusion. A cat's face from the front versus from the side are almost different creatures. Shadows make edges vanish. A tiny cat far away might have fewer pixels than a close-up whisker. Other objects hide parts of the scene. Real-world photos are messier than textbook examples: extreme angles, partial views, clutter. The model must learn to recognize the concept 'cat' despite all this variation. And it must do this not just for cats, but for hundreds or thousands of object classes in a single image.

Papers in this subtheme use deep neural networks trained on large labeled datasets to learn what features matter. Some focus on detecting boxes around objects as fast as possible, trading precision for speed. Others refine the boxes and add pixel-level segmentation masks. Some use two-stage pipelines: first find regions of interest, then classify and refine them. Others use single-stage detectors that predict everything at once. A few split the image into small tiles and learn which tiles relate to the same object by computing relationships between all pairs of tiles. The aim is always the same: extract precise, useful information about what is in the scene and where.

How the work breaks down

Finding objects in images splits naturally into four directions: making detectors faster and more accurate by redesigning how they predict boxes and classes; refining detection into pixel-level masks that know exactly where each object ends; scaling these methods to 3D scenes and video sequences where time and depth matter; and handling the real world where objects come in thousands of kinds we've never seen before.

Speed and Efficiency in Object Detection

The core challenge here is speed versus precision. A detector must find every object, pin down its location in a box, and label what it is. But real-world systems need to do this in milliseconds while keeping accuracy high. This means rethinking the detection pipeline itself—not just tweaking numbers but changing how the model organizes its thinking.

DETR-ViP improves the Detection Transformer, which replaces the old sliding-box method by treating detection as a direct prediction problem. Instead of scanning the image with thousands of candidate boxes, it asks: 'What objects exist, and where are they?' as a single question. The paper makes this work better by using discriminative visual prompts, which means each object class gets its own learned pattern to recognize, so the model learns more distinct features per category. This beats the old COCO benchmark by substantial margins, and more importantly, it works on small-data challenges like ODinW and Roboflow100 where training data is sparse.

Inlier-Centric Post-Training Quantization tackles a different bottleneck: after training a detection model, we compress its numbers to make it smaller and faster, so it runs on phones or edge devices. The trick is that most samples are easy—an inlier—but a few are hard; most bits of precision matter on edge cases. This method focuses compression effort on the easy cases, preserving full precision where it matters (the hard samples), and achieves consistent gains across camera-based and LiDAR-based detection without any labeled data for the compression step. OD3 (the dataset distillation work) attacks speed from another angle: instead of training on 118K images, can we create a tiny synthetic dataset that teaches the same detection task? It reaches 14% mAP50 improvement at just 1% of COCO's data, which means faster training because you see fewer images but learn the same patterns, enabling training on smaller devices. Interference-Isolated Elastic Weight Consolidation solves continual learning by preventing weight conflicts. When you train on new object classes, old and new weight gradients can fight each other and cancel out. By isolating these conflicts—letting old and new updates happen in separate subspaces—the model learns new classes without catastrophic forgetting where everything it learned before vanishes.

Pixel-Perfect Boundaries and Segmentation

Detection gives you a box, but real applications need to know the exact boundary of each object. Segmentation traces the pixel-by-pixel edge. The hard part is speed—tracing millions of pixels should not require seconds per image. The hard part also is generalization: a segmentation model trained on clean synthetic scenes often fails on real photos with crazy lighting, occlusion, and background clutter.

GOOD (Scene Layout Understanding for Shifted Domains) tackles the sim-to-real gap for 3D point clouds: synthetic training data is clean, but real LiDAR scans are messy, with different perspectives and occlusion patterns. Instead of pretending they're the same, it models how the scene layout differs between synthetic and real and learns to handle that shift. It outperforms the previous best by 1.93% on the hardest benchmark because it explicitly accounts for the shift rather than hoping the model ignores it. Johnson-Lindenstrauss Lemma Guided Network compresses the segmentation problem using a classic math principle—instead of processing the full image resolution, it projects to a lower-dimensional space, segments there, then maps back. This gives 26% better accuracy with 11x speedup on GPU and 48x on CPU, plus 24x less memory because you do the expensive segmentation work in a smaller, cheaper space, so the computation is faster and uses less RAM. QPrompt-R1 focuses on semantic segmentation (assigning every pixel a class label) when the model has never seen the domain before. It uses a relative query alignment trick: instead of asking 'is this pixel a car?', it asks 'is this pixel more car-like than that one?', which works better across domain shifts because relationships between pixels are more stable than absolute predictions—what class a pixel is depends on context, which survives domain change better than raw features. It runs at 54 FPS, fast enough for real-time video analysis. CoPRS (the reasoning segmentation work) adds another layer: it asks the model to explain why a region belongs to an object, using chain-of-thought reasoning. This thinking process actually makes the mask more precise—reasoning quality correlates with mask quality, so better explanation leads to better boundaries. Hierarchical Prototype Learning and SAM 3 both push segmentation toward foundation models that work on anything without retraining—SAM 3 doubles performance on unseen object categories by learning concepts, not just pixel patterns.

Understanding 3D Scenes and Video Streams

Videos and 3D scenes add two new dimensions: depth and time. A model must find objects not in one photo, but across frames or in full 3D space. This means tracking identities over time, understanding which pixels belong to the same object as it moves, and reasoning about spatial relationships in three dimensions. The challenge is that depth is ambiguous from a single image, and motion creates new occlusions and blur.

Fore-Mamba3D detects objects in 3D point clouds (like LiDAR from autonomous vehicles). Instead of processing all points equally, it focuses on foreground—the objects of interest, because background clutter wastes computation. It uses Mamba, a new efficient neural network design that processes sequences by memorizing and forgetting information like a state machine, without the slowdown that transformers have on long sequences. By fixing how dependencies work in this state machine (the causal dependency), it beats strong baselines on Waymo and nuScenes. SceneCOT takes 3D reasoning further: given a complex 3D scene (a room with furniture, people, objects), it asks the model to reason step by step: 'First, I see a table. On the table is a laptop. The laptop is to the left of a coffee cup.' This step-by-step reasoning is interpretable—you can read the steps and verify them—and it improves accuracy on reasoning benchmarks because each step grounds the next. NeRP3D improves 3D detection for autonomous driving by asking: should models see multiple viewpoints during pretraining? Testing both approaches, models that see diverse views during training actually generalize better to real autonomous driving scenes because they learn invariances—features that stay the same across viewpoint. Matting Anything 2 extends the segment-anything approach to video: given a query frame and some clicks or scribbles, segment the same object across all frames. It handles extreme viewpoint changes, occlusions, and appearance changes, validated on a new Natural Video Matting benchmark. 3D-RFT (Reinforcement Fine-Tuning) and VisionReasoner both combine reasoning with video understanding: instead of a single forward pass, the model can reason through the problem, correcting mistakes along the way. VisionReasoner gets 29.1% better detection on COCO and 22.1% better segmentation on ReasonSeg over a baseline, just by adding reinforcement-learning-trained reasoning loops because iteration allows error correction.

Finding Things That Hide or Look Fake

Some objects are hard to find because they camouflage—a chameleon on a leaf, a person in shadow, a texture painted to blend in. Others are hard because they are fake: deepfakes, AI-generated images, manipulated regions. Both require learning subtle patterns that distinguish real from unreal, or figure from ground.

S3OD (Towards Generalizable Salient Object Detection) achieves better cross-dataset performance by training only on synthetic data. Clean CGI has no camera noise, compression artifacts, or lighting accidents, so the model learns the fundamental patterns of saliency—what makes objects stand out—rather than latching onto spurious dataset-specific cues. This forces learned features to generalize, getting 20-50% error reduction in cross-dataset settings because real-world variety no longer surprises a model trained without clutter. BPL (Bias-only Pair-aware Learning) for deepfake detection takes a relational approach: instead of asking 'is this a fake face?', it asks 'is this face-pair consistent?', learning to spot the subtle discrepancies between forged and real because pairs encode more information than individual images. Breaking Manifold Continuity uses vector quantization—chunking the feature space into discrete regions—so a deepfake's features fall into holes that real faces don't occupy, creating clear separation. CODiff applies diffusion models (the same generative tech that makes images from text) to find camouflaged objects by learning the reverse: how would you generate this object? One-step diffusion makes it fast enough for real time by using only one sampling step instead of dozens, getting 22% MAE (mean absolute error) improvement on COD10K. Divide and Conquer uses multi-view evidence: if you flip, rotate, or adjust the image and detect the fake in multiple ways, you get calibrated confidence—the model tells you when it is uncertain, because agreement across views indicates real signal. HSIC Bottleneck improves transfer between different fake-generation families (diffusion models versus GANs versus 3D Gaussian Splatting) by learning a shared bottleneck. Exploring Specular Reflection Inconsistency works because diffusion models often fail to render consistent mirror reflections—real faces have reflection physics; fakes don't, so reflections expose forgery. VidGuard-R1 and VideoVeritas both detect AI-generated video by reasoning about perceptual cues: VidGuard uses reinforcement learning to explain detections, achieving over 95% accuracy with training because reasoning discovers failure modes. VideoVeritas adds a new MintVid dataset of 3K videos from nine generators, capturing the frontier of video forgery.

Open-World Detection Without Retraining

The classical assumption breaks down in the real world: you train on COCO (80 objects), then deploy on a drone video (millions of object types you've never seen). Open-vocabulary detection asks: given a text description of any object, can the model find it without retraining? The challenge is that the model must align visual features with language, and generalize to unseen categories by understanding semantic relationships.

Retain and Adapt handles the case where new object categories arrive after deployment. Instead of retraining the entire model (catastrophic forgetting) or freezing the old detector (no improvement), it auto-balances updates: modify weights just enough to learn new categories while keeping old knowledge intact, so old and new skills coexist. It supports inserting and removing task descriptions on the fly, in any order. DeCo-DETR improves open-vocabulary detection efficiency by decoupling cognition (understanding what things are) from localization (finding where they are). Text encoders are expensive, so it replaces them with a lightweight distilled version and applies knowledge from the text encoder only where it matters most, enabling real-world deployment on devices with limited compute. Object-level Semantic and Spatial Distillation extracts semantic relationships (cars are vehicles; vehicles move) and spatial patterns (near, inside, overlapping) from the base CLIP model and uses those as training signals, without needing the full text encoder when the model makes predictions. It reaches 49.2 AP50 on object categories not seen during training. PhaseAlign uses a phase-alignment trick from signal processing: instead of matching raw features to text embeddings, align their phases (directions), which is more stable when domains shift because phase relationships persist through different lighting and viewpoints. SpaCeFormer detects any 3D instance in a scene (person, chair, wall, floor) without seeing the class names in training. It's 2-3 orders of magnitude faster than earlier open-vocabulary 3D methods and finds 21x more masks, opening the door to real-time open-world robotics because it processes scenes at millisecond latency.
