ICDiffAD: Time Series Anomaly Detection via Controlled Diffusion

A diffusion model that detects abnormalities in time series data by learning to reconstruct normal patterns while carefully controlling the randomness at each step.

Paper explainersAll themesTime Series & Sequential

Time series anomaly detection faces a core problem: diffusion models (a type of generative model that learns by gradually adding and removing noise) excel at capturing normal patterns, but their randomness makes them unreliable for detecting what is abnormal. ICDiffAD fixes this by using two techniques: a scheduler that controls noise levels during learning, and a way to initialize generation from the input itself, balancing the model's flexibility with the accuracy needed for detection.

Zero assumption version

Why diffusion models struggle with time series anomalies

A diffusion model learns by watching data get progressively corrupted by noise, then learning to reverse the process—to clean the noise away step by step. For time series (sequences like stock prices or sensor readings over time), this works well at capturing what normal looks like. But here is the catch: randomness is baked into every step. Even when reconstructing the same input twice, the model gives slightly different outputs because it is sampling from a probability distribution at each step. For detecting anomalies, this variance is fatal—you can't reliably say whether something is abnormal if you get different reconstructions every time.

A naive approach would be to just accept this variance and hope the reconstruction error for true anomalies is always higher than the noise. It fails because the randomness in the reconstruction overshadows the signal you are trying to detect. Your detector becomes unreliable.

In one sentence. ICDiffAD uses two controls to tame randomness: a scheduler that manages noise intensity during learning, and a way to seed the generation from the input itself.

What the paper changes

The two controls being tuned

The paper changes two things. First, it introduces an SNR Scheduler—a schedule that controls the signal-to-noise ratio (a measure of how loud the signal is compared to noise) at each step of learning. Second, it uses an SNR Implicit Conditioning Mechanism, which means starting the reverse process from the input itself, partially corrupted, rather than from pure random noise. Together, these make reconstructions much less random while still capturing complex patterns.

The hidden quantity

Signal-to-noise ratio: the hidden control

measured quantity  =  Signal-to-noise ratio at each step

Signal-to-noise ratio, or SNR, is a number that measures how loud the true data is compared to the noise layered on top. A high SNR means the signal is clear; a low SNR means noise dominates. The paper's key insight is that controlling SNR directly during training tells the model exactly how much noise to expect at each stage, making learning predictable.

Traditional diffusion models use a fixed noise schedule (more noise at the start, less at the end), but ICDiffAD learns which SNR values work best at each step. When reconstructing for anomaly detection, the scheduler ensures that initializing from a partially corrupted input is consistent with how the model was trained—the model expects that level of corruption and handles it cleanly.

Why it works

Why controlling noise makes anomaly detection work

The core insight: diffusion models work by gradually peeling away noise, like a sculptor refining details. But this process comes at a cost—randomness. Every sample draws from a probability distribution (the pattern of how often each output occurs), so identical inputs produce slightly different outputs. For anomaly detection, this noise in the reconstruction is a catastrophe because you can't tell if high error means the input is abnormal or just that the randomness happened to mess up that sample.

ICDiffAD solves this in two parts. First, the SNR Scheduler makes training deterministic by controlling noise intensity precisely. The model learns: at this SNR level, here is what normal data looks like. Second, initializing from the input itself (corrupted to match the scheduled SNR) anchors the reconstruction to the input. The model does not have to imagine new data from scratch; it just learns what the input would look like if you removed the noise. Anomalous parts of the input cannot be cleaned up because the model has never seen that pattern in normal training data, so they remain garbled. Normal parts get cleaned crisply. The gap is now reliable because both normal and anomalous reconstructions are reproducible.

Why does this work mechanically? Diffusion models learn from data by computing gradients—directions to adjust the numbers inside the model to match observed patterns. When you control SNR, you teach the model the expected noise level at each step. When you initialize from the partially corrupted input, you are saying: assume this input is mostly normal with added noise; clean it up. The model either succeeds (it removes noise from normal patterns) or fails (anomalies stay corrupted). Because this process is not random—it follows a fixed path through learned rules—the result is reproducible and reliable.

Math after the picture

The reconstruction error formula

First in words:

reconstruction error equals the average squared difference between the input and the reconstructed output, computed only where reconstruction was faithful to the input signal

Then the compact form:

error = (1/N) * sum_t (input_t - reconstructed_t)^2 * confidence_t

Every symbol:

input_tthe original value at time step t
reconstructed_tthe cleaned output from the diffusion model at time step t
confidence_ta weight: 1 if SNR was high (signal clear), lower if SNR was low (noise high)
Nthe total number of time steps
A tiny worked example
Input: 10, 11, 9, 50, 12 (the 50 is an anomaly).
Reconstructed: 10.2, 10.8, 9.1, 47, 12.1 (normal parts cleaned, anomaly stays garbled).
Squared differences: 0.04, 0.04, 0.01, 9.0, 0.01.
If all confidence weights = 1: error = (0.04+0.04+0.01+9.0+0.01)/5 = 1.82.
Most of the error comes from position 4, the anomaly. Threshold: anything over 0.8 average error per point flags as anomalous.

The confidence weight prevents high SNR (clear signal) time steps from dominating; the error tells you something real only where the model had clear information to work with.

What can go wrong

What can go wrong

Schedule mismatch during testing. If the test SNR schedule does not match training, the model encounters noise levels it did not learn. The reconstruction becomes unreliable and anomalies are missed.
Initialization from pure noise instead of corrupted input. Reverting to standard diffusion (starting from random noise) reintroduces the original variance problem. The paper's benefit disappears.
Dataset with multiple anomaly types. If the training data is skewed (many samples of one anomaly type but not others), the model learns to expect those patterns. Other anomaly types may not be flagged.
Done right. The SNR scheduler is fixed consistently across training and testing; initialization always uses the corrupted input; training data covers a wide range of normal behavior. Under these conditions, anomalies stand out clearly and reproducibly.
What a runnable demo should prove

What a runnable demo should prove

Build a simple time series with known normal regions and planted anomalies (e.g., a sine wave with occasional spikes). Train ICDiffAD on only the normal regions using the SNR scheduler. Then run inference on new data, comparing ICDiffAD to naive diffusion. Reconstruct the same anomalous sample three times. With ICDiffAD, the reconstruction should be nearly identical each time and flag the spike reliably. With naive diffusion, the three reconstructions should differ noticeably and detection should be inconsistent (sometimes catching the spike, sometimes missing it).

F1 score = (2 * precision * recall) / (precision + recall); precision = correct detections / all detections; recall = correct detections / all real anomalies

The demo must make it unmissable that controlled noise gives reproducible detections while naive diffusion gives noisy, inconsistent results.
