Doubly-Regressing Approach for Subgroup Fairness

Train a model to be fair to small groups of people defined by multiple identity traits, using a smarter adversarial trick that needs only one referee instead of thousands.

Paper explainersAll themesAlignment, Safety & Fairness

When a model makes decisions about people, it should treat all groups fairly. But when you care about fairness for many traits at once (gender, race, age, etc.), the number of tiny subgroups explodes, making it impossible to measure fairness to each one without huge compute and unreliable estimates. DRAF solves this by focusing fairness efforts only on groups big enough to measure reliably, while still promising fairness on each trait individually.

Zero assumption version

The fairness wall with many traits

Imagine a model that approves loan applications. It should be fair to men, to women, to young people, to old people. If you add race, ethnicity, and immigrant status, you create two-to-the-fifth, or 32 possible subgroups (each combination of yes/no for five traits). Each subgroup has its own data: some have 1000 samples, some have 5. The tiny groups are like drawing conclusions from a coin flip—too noisy. Measuring fairness on all 32 separately requires checking 32 different fairness constraints. With 10 traits, you have 1024 subgroups. With 20 traits, over a million.

A naive beginner tries: make a separate fairness check for each subgroup, then train the model to satisfy all of them at once. This breaks badly: the computation explodes (you need hundreds of referee networks), and the estimates on tiny groups are garbage. The model may claim to be fair to a group of 3 people, but that's meaningless noise.

In one sentence. DRAF trains the model with a smarter referee that checks fairness only on subgroups large enough to trust, then uses a mathematical trick to promise fairness on each individual trait anyway.

The algorithm as a flow

What it actually does

Define trustworthy subgroup-subsets

Pick combinations of traits whose union has enough samples to measure fairness honestly.

Train with one referee

The model and referee train together: model tries to fool the referee, referee tries to catch unfairness in the chosen subgroups.

Referee predicts which subgroup each sample belongs to

Referee learns to spot patterns in how the model treats different trait combinations, not each tiny subgroup individually.

Update the model to reduce predicted unfairness

Model shifts its decisions to lower the referee's score on the reliable subgroups.

Fairness spreads to marginal traits

Because the reliable subgroups overlap across all traits, fairness on them guarantees fairness on each trait alone.

What the paper changes

The one thing that changes

The paper changes how you measure fairness during training. Instead of checking fairness on each individual subgroup separately, it measures fairness only on carefully chosen combinations of subgroups that have enough data to trust, then uses a mathematical guarantee to pass that fairness down to each individual trait.

the object it moves  =  fairness measurement
The hidden quantity

The hidden quantity: surrogate fairness gap

measured quantity  =  surrogate fairness gap

The paper introduces a hidden number it calls the surrogate fairness gap, which is a stand-in for real unfairness that is cheap to compute. Real fairness would require checking each of the 32 (or 1000, or 1 million) tiny subgroups. The surrogate instead asks: how much does a single referee network struggle to predict which subgroup each sample belongs to, using only the model's outputs? If the referee easily predicts the subgroup, the model is probably unfair (it makes different decisions for different groups). If the referee can barely tell, the model treats all groups similarly.

The paper measures this by training a referee network that takes the model's prediction score and tries to output which subgroup the person belongs to. The harder the referee's job, the more fair the model is. DRAF uses this one referee to check fairness on all the reliable subgroup-subsets at once, then updates the model to make the referee's job harder (spreading fairness across all traits).

Plain reading. Think of the referee as a fairness meter. If it easily spots which group you belong to from your loan decision, the model is unfair. If it is confused, the model treats all groups the same way.
Paper reading. The surrogate fairness gap is an upper bound on the supremum Integral Probability Metric (supIPM), which is the formal fairness measure. The paper proves that minimizing this surrogate is guaranteed to reduce true unfairness.
Why it works

Why this magic referee works

The core insight: if your model makes the same prediction for a young woman and an old woman, a referee trying to predict age from the decision will fail. Fairness on overlapping subgroups (young-women, old-women) forces fairness on the base trait (age). The paper uses this overlap. It picks subgroup-subsets that cover all traits, so fairness on the reliable ones automatically guarantees fairness on each trait individually. By training one referee to fail at predicting which reliable subgroup-subset each sample belongs to, the model learns to treat all underlying traits fairly without ever touching the tiny subgroups.

Why does this save computation? Instead of checking 32 (or 1024) fairness constraints, you train one referee. Instead of trying to measure patterns in groups of size 2 or 3, you only measure on groups of size 100+. The math guarantees that this cheaper measurement still enforces the real fairness you care about, because the paper proves that the surrogate fairness gap (referee accuracy on big groups) is an upper bound—when it shrinks, true unfairness must shrink too, even on the tiny groups you did not measure directly.

Math after the picture

The equation

First in words:

Model loss = (accuracy on task) + (lambda times unfairness penalty). The unfairness penalty is the referee's accuracy at predicting which reliable subgroup each sample belongs to, weighted by which predictions are least fair. Minimize this and the model improves accuracy while staying fair.

Then the compact form:

L = (1/n) sum_i loss(y_i, f(x_i)) + lambda * DR_surrogate(f), where DR_surrogate is the referee's weighted prediction accuracy on reliable subgroup-subsets

Every symbol:

y_itrue label for sample i (e.g., approve or deny)
f(x_i)model's prediction for sample i
loss()how wrong the prediction is (e.g., cross-entropy)
lambdahow much to prioritize fairness vs. accuracy
DR_surrogatethe referee's score at predicting subgroups (unfairness signal)
nnumber of training samples
A tiny worked example
Suppose we have 100 samples, accuracy loss = 25, referee accuracy on fair subgroups = 0.4 (it guesses correctly 40% of the time, meaning the model is somewhat unfair).
If lambda = 0.5, unfairness penalty = 0.5 * 0.4 = 0.2
Total loss = 25 + 0.2 = 25.2
Model adjusts to confuse the referee; next round referee accuracy drops to 0.2, penalty becomes 0.5 * 0.2 = 0.1
Total loss = 25 + 0.1 = 25.1 (improved), showing trade-off: as fairness improves, the fairness term shrinks.

The equation says: keep your task accuracy high, but also make it hard for a referee to tell which group someone belongs to by looking at your decision alone.

What can go wrong

What can go wrong

Chosen subgroup-subsets do not cover all traits. If you pick reliable subgroups carelessly and they miss some trait combination, fairness on the big groups does not spread to that trait. The paper's guarantee only holds if the subgroup-subsets actually overlap all the traits you care about.
Lambda set too high or too low. If you push fairness too hard, model accuracy crashes. If you ignore fairness, the referee learns to predict subgroups easily and fairness is lost. Tuning lambda is critical and data-dependent.
Tiny subgroups are still noisy estimates. Fairness on small subgroups is not guaranteed—only on the chosen reliable ones. If you later measure fairness on a different tiny subgroup, you may find unfairness lurking there. The method trades accuracy on all tiny groups for computational tractability and accuracy on reliable ones.
Done right. The method works best when you know which subgroups are reliable and which traits matter. Build a subgroup-subset plan, tune lambda on a validation set, and measure fairness on the groups you committed to at the start.
What a runnable demo should prove

What a runnable demo should prove

Build a binary classification task (e.g., loan approval with synthetic data) with 4 sensitive traits (gender, age, income-bracket, credit-score-bracket), creating 16 subgroups. Make a few subgroups tiny (2-5 samples) and others large (100+ samples). Implement three models: (1) baseline with no fairness, (2) naive method with separate referees for all 16 subgroups, (3) DRAF with one referee checking only the large subgroups. Measure the accuracy of the model, the compute time, and the fairness (using a referee's prediction accuracy) on both large and small subgroups.

fairness on large subgroups = (1 - referee accuracy on large subgroups); compute time = wall-clock seconds to train; accuracy = fraction of test cases predicted correctly

The demo must show that DRAF achieves fairness and accuracy within 20% of naive method but with 5-10x less compute, proving that one smart referee beats dozens of dumb ones.
