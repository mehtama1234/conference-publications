Detecting Stubborn Hallucinations via Gradient Sensitivity

Hallucinations sit in sharp, brittle spots in a neural network; jiggling the input slightly makes them shake much harder than real facts.

Paper explainersAll themesInterpretability

Large language models sometimes confidently say false things. The usual trick (watching how uncertain the model sounds) does not catch these stubborn hallucinations. This paper finds a better signal: real facts hide in flat, stable valleys, while hallucinations are perched on narrow, wobbly peaks. By shaking the input a little and watching how much the model's internal computations thrash around, you can tell the difference.

Zero assumption version

Why confidence tells you nothing

A language model (a program that predicts the next word by learning patterns from text) learns facts along with made-up things. When you ask it a question, it answers with some level of certainty. The problem: hallucinations (confident false claims) look identical to true facts from the outside. The model gives both the same confident tone.

A beginner might track how much the model hedges its bets (how spread out its confidence is across possible answers). But stubborn hallucinations break this: the model is dead certain, just wrong. So measuring uncertainty does not catch them.

The method in one sentence. Shake the input slightly and watch if the model's internal math gets jittery; hallucinations thrash, facts stay calm.

The algorithm as a flow

What it actually does

Start with a claim

Feed a question and the model's answer into the process.

Perturb the input

Inject small random noise into the word embeddings (the numbers encoding each word).

Run the model and measure

Compute the gradients (how much you would nudge each weight to change the output) with and without noise.

Compute sensitivity

See how much the gradients changed when you added noise.

Decide

High sensitivity means hallucination. Low sensitivity means stable fact.

What the paper changes

The single thing that changes

The paper measures the model's internal sensitivity (how much the direction and size of learning-step nudges shake when you jiggle the input). Facts keep their nudges steady; hallucinations send them wild.

the object it moves  =  sharpness of input-output sensitivity
The hidden quantity

The hidden quantity: How sharp or flat is this answer?

measured quantity  =  Gradient sensitivity to input perturbation

This is the size of the jitter in the learning nudges when you shake the input. A high sensitivity means the learning nudges are brittle and unstable; a low sensitivity means they stay calm and consistent.

The paper estimates it by adding small noise to each word embedding, recomputing the gradients, and measuring how much they changed. Think of it like stress-testing a structure by shaking it gently and watching how much the frame moves.

Why it works

Why perturbing inputs detects hallucinations

Real knowledge is learned through many examples, each teaching the model the same pattern from slightly different angles. This makes the learned fact survive any nudge: the internal computations land in a wide, gentle valley. If you nudge any piece of the input a tiny bit, the model's math stays calm because it was trained to handle small variations.

A hallucination is memorized differently. The model encounters one false claim and bakes it in deeply, creating a narrow, sharp peak. The weights adjust to recognize the exact phrase and nothing close to it. So when you perturb the input (add a little noise to the word embeddings), the model's internal math breaks catastrophically. The learning nudges explode because the model has no memory of similar input variations.

Measuring the gradient magnitude change detects this difference. Facts show small, steady gradients even when input is jittered. Hallucinations show large, wild swings.

Math after the picture

The sharpness equation

First in words:

The sensitivity is the average change in gradient magnitude when embeddings are perturbed by random noise. Larger changes mean sharper curvature, which signals hallucinations.

Then the compact form:

sensitivity = mean_over_noise_samples( || grad_with_noise - grad_no_noise || )

Every symbol:

grad_with_noisethe learning nudges computed after adding noise to word embeddings
grad_no_noisethe learning nudges with the original input
||the length of the vector (sum of squared changes, then square root)
mean_over_noise_samplesaverage across many runs with different random noise
A tiny worked example
Suppose the model has 3 weights and we run 2 noise samples.
Sample 1: grad_no_noise = [0.1, 0.2, 0.15], grad_with_noise = [0.11, 0.22, 0.16]
Change vector = [0.01, 0.02, 0.01], length = sqrt(0.01^2 + 0.02^2 + 0.01^2) = sqrt(0.0006) = 0.024
Sample 2: grad_no_noise = [0.1, 0.2, 0.15], grad_with_noise = [0.25, 0.5, 0.4]
Change vector = [0.15, 0.3, 0.25], length = sqrt(0.15^2 + 0.3^2 + 0.25^2) = sqrt(0.175) = 0.418
Sensitivity = mean([0.024, 0.418]) = 0.221
A fact might have all samples close to Sample 1 (sensitivity ~0.02). A hallucination would have all samples close to Sample 2 (sensitivity ~0.40). The gap makes hallucinations easy to spot.

Higher sensitivity means the learning nudges are jagged and unstable. Sharp peaks (hallucinations) produce high sensitivity; flat valleys (facts) produce low sensitivity.

What can go wrong

What can go wrong

Noise magnitude matters. If you add too much noise, even facts will show high sensitivity (it washes out the signal). Too little noise and you miss the sharpness entirely. The paper has to tune this carefully per model.
Model architecture changes the signal. A model trained with extra regularization (techniques that smooth out the weight valleys) will show low sensitivity everywhere, even for hallucinations. The method assumes the default training regime.
Hallucinations can live in flat regions too. Some false claims might be so common in training data that the model learned them broadly, landing in a shallow valley. Sensitivity alone will not catch these. It works best for memorized, one-off errors.
Done right, you combine signals. Gradient sensitivity is strongest when paired with other checks (semantic consistency, fact verification). It is one probe among many, not a complete solution.
What a runnable demo should prove

What a runnable demo should prove

Build a small test: take a large language model and gather 50 true facts and 50 confident hallucinations (things the model says with high confidence but are verifiably false). For each, perturb the input embeddings multiple times with small Gaussian noise, compute the gradient sensitivity each time, and plot a histogram. The demonstration should show two clear clusters: facts at low sensitivity, hallucinations at high sensitivity, with minimal overlap.

Hallucination detection accuracy = (correctly flagged hallucinations + correctly allowed facts) / total cases

The gap between the two histograms is impossible to miss: hallucinations shake wildly, facts barely budge.
