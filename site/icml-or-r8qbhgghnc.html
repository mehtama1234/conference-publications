Estimating the Empowerment of Language Model Agents

The paper measures how much control a language-model agent has over future world states, using that control as a task-agnostic way to judge capability across games, websites, and tool-use settings.

Paper explainersAll themesAgents & Tool Use

Benchmarks usually grade an agent against a fixed task, but that does not scale well and says little about what the agent can do outside that exact setup. This paper uses empowerment, which is the amount of influence an agent's actions have on future states, because an agent that can reliably steer the world into many distinct outcomes usually has broader capability than one whose actions barely change anything.

Zero assumption version

Task-specific evaluation misses broad agent control

A benchmark can tell you whether an agent solved one task, but it does not directly tell you how much the agent can shape its environment in general. Two agents may both fail the same benchmark for different reasons: one may have little control at all, while the other may have broad control but choose the wrong plan for that task.

Designing many custom benchmarks is expensive and slow. The paper asks whether there is a general quantity that tracks capability across settings. The proposed answer is influence over future states, because an agent that can push the world into many purposeful futures has more usable ability than one trapped in a narrow action range.

In one sentence. Instead of asking only whether an agent finished one benchmark, the paper asks how many different future states the agent can intentionally reach.

What the paper changes

What the paper changes

The paper changes the evaluation target from task completion alone to controllable future-state spread. The object being estimated is the agent's influence over what happens next.

the object it moves  =  future-state influence
The hidden quantity

The hidden quantity: controllable future spread

measured quantity  =  controllable future spread

Controllable future spread is how many genuinely different future states the agent can reach by choosing different actions from the same start. If every action sequence ends in almost the same place, the spread is low. If action choices reliably produce distinct outcomes, the spread is high.

This quantity is useful because it captures ability without tying evaluation to one benchmark goal. A capable agent often has higher spread because it can use tools, navigate websites, or alter game state in more purposeful ways.

Why it works

Why empowerment can evaluate agents across tasks

Task success is narrow because it grades one desired outcome. Empowerment is broader because it asks how much room the agent has to shape the future. If an agent can create many distinct useful states, it usually has more options for solving tasks than an agent whose actions barely move the environment.

This quantity works across domains because the underlying question is the same in each one: do different actions lead to different later states that the agent can intentionally control? In a text game that might mean reaching new rooms or inventory states. On a website it might mean navigating to different purchase or booking outcomes. In a tool setting it might mean producing different tool-side effects.

The estimate is especially helpful when benchmarks are expensive, because one control-oriented measure can complement many hand-built tasks. It does not replace task success, but it adds a reusable signal because an agent with more practical control over the world usually has more ways to reach the states a task requires.

Math after the picture

The equation for agent control

First in words:

Empowerment is high when the agent's chosen actions strongly determine which future state occurs, because action choice then carries a lot of information about the future.

Then the compact form:

empowerment = information_between_actions_and_future_states

Every symbol:

actionsthe action sequence chosen by the agent from the current state
future_statesthe later states reached after those actions play out
information_between_actions_and_future_stateshow much knowing the chosen actions tells you about which future state will occur
empowermentthe agent's estimated control over the future
A tiny worked example
Suppose an agent has three action sequences from the same start state.
If all three sequences end on the same page, then knowing the action tells you almost nothing about the future, so empowerment is low.
If each sequence ends in a clearly different page state, then the action almost determines the future, so empowerment is high.
Now compare two agents: agent A reaches one repeated outcome from most action sequences, while agent B reaches three distinct outcomes reliably.
Agent B gets higher empowerment because its choices produce a wider controllable future spread.
That higher score is useful because it explains why B often solves more downstream tasks: it has more reachable options to work with.

The equation is about control, not reward. An agent can have high empowerment even before a specific task goal is chosen.

What can go wrong

What can go wrong

Many futures are different but useless. An agent may create many distinct future states that do not help any real task, so empowerment alone can overestimate practical usefulness because the score counts control even when that control is pointed at unhelpful outcomes.
State comparison is weak. If the method cannot tell whether two future states are genuinely different, the estimate may merge distinct outcomes or split trivial variants, so the control score stops reflecting real capability.
Action sampling is narrow. If the rollout procedure explores only a small set of action sequences, the estimate may miss real control that the agent actually has.
Done right. Empowerment is most useful when future states are compared carefully and the estimate is read together with task success, because control and goal achievement answer different evaluation questions.
What a runnable demo should prove

What a runnable demo should prove

Build a simple text environment with several rooms, tools, and branching action choices. Measure how many distinct later states each agent can reach from the same start under short action sequences, then compare that control score with ordinary task completion.

A more capable agent should show both higher empowerment and better task success because its actions reach more distinct useful states. A brittle agent should show lower empowerment because many of its actions collapse to the same dead ends or repeated loops.

empowerment_proxy = distinct_future_states / sampled_action_sequences and task_success = solved_tasks / total_tasks

The demo should show that broad control is not the same as reward, but it is an important ingredient of general agent capability because more controllable futures give the agent more ways to complete downstream tasks.
