Unlocking the Essence of Beauty: Advanced Aesthetic Reasoning with Relative-Absolute Policy Optimization

Teach an image model to explain aesthetic judgments before scoring, then refine it with reinforcement learning that cares about both the right score for one image and the right ranking across images.

Paper explainersAll themesMultimodal

Aesthetic assessment is difficult for multimodal language models for two reasons. First, high-quality image-score-plus-explanation data is scarce. Second, aesthetic judgment is partly subjective, so one numeric target does not capture the full task. A model may assign a plausible score to one image while still failing to prefer the better image in a pair, because small per-image errors can still reverse the order between two close examples. Aes-R1 addresses both issues. It first builds structured reasoning data with AesCoT so the model learns to generate grounded explanations before producing a score, because the score is then tied to named visual evidence rather than to a bare number. Then it applies Relative-Absolute Policy Optimization, or RAPO, a reinforcement-learning objective that trains the model on two linked goals: match the score for each image and preserve ranking order across images.

Zero assumption version

Why aesthetic scoring needs more than a single regression target

If a model is trained only to predict a numeric aesthetic score, it can learn average scoring habits without learning the visual reasons behind them. That leads to brittle judgments because small dataset biases can shift the output score even when the model has not formed a clear view of composition, lighting, subject separation, color relations, or technical quality.

A second issue is that aesthetic evaluation is inherently comparative. Two images can both deserve decent scores, yet one is clearly stronger because viewers consistently prefer it when the pair is shown together. A model trained only on absolute targets may place them too close together or in the wrong order. That hurts ranking tasks because absolute calibration and pairwise preference are different constraints.

The paper's move. Teach the model to write a structured visual rationale first, then optimize both per-image score accuracy and cross-image ranking consistency.

The algorithm as a flow

What it actually does

Construct reasoning data

Use AesCoT to collect and filter chain-of-thought style explanations so the model sees examples of grounded aesthetic analysis before reinforcement learning starts, because the later reward stage needs a stable explanation format to build on.

Cold-start supervised tuning

Train the multimodal model to produce structured explanations and corresponding scores from images.

Compute absolute rewards

Reward outputs whose scores are close to target image scores because per-image calibration still matters.

Compute relative rewards

Reward outputs that preserve the correct order between image pairs because aesthetic judgment often appears as preference.

Update the policy with both signals

Apply reinforcement learning so the model improves its scoring and ranking behavior without discarding the explanation structure learned during cold start, because updates are anchored to the already tuned policy rather than starting from scratch.

What the paper changes

What the paper changes

The paper changes both supervision and optimization. It adds a structured reasoning stage before scoring, then replaces a single numeric objective with a dual objective that checks absolute score quality and relative ranking quality together.

the object it moves  =  Aesthetic reasoning plus joint absolute-relative reward
The hidden quantity

The hidden quantity: preference-consistent calibration

measured quantity  =  Whether the score scale and the ranking order agree

A model can look good on one metric while failing the real task if its score scale and ranking order disagree. For example, it may assign scores close to the dataset mean, which can lower average regression error, yet still reverse the order of two images that humans consistently separate. The hidden quantity is preference-consistent calibration: do the scores reflect both the right level and the right ordering?

RAPO makes this quantity visible by combining absolute and relative rewards. The absolute term keeps the score anchored to the dataset scale. The relative term checks whether score differences point in the right direction across images. That matters because aesthetic assessment is used both for assigning a score and for choosing among alternatives.

Why it works

Why this works: explanations tie scores to evidence, and ranking rewards fix scale-only training

The cold-start reasoning stage matters because an explanation forces the model to expose which visual properties it used. If the model must mention framing, contrast, subject isolation, or clutter before giving a score, the score is less likely to come from a memorized average. The filtered AesCoT data is important because low-quality rationales would teach the model to produce fluent but ungrounded aesthetic language.

The absolute reward alone is not enough because two wrong orderings can still have small numeric error. Suppose the ground-truth scores are 7.2 and 7.0, but the model predicts 6.9 and 7.1. Each individual prediction is close, yet the ranking is reversed. The relative reward fixes that failure because it directly checks pairwise order. This forces the model to care about score differences, not only about staying near the global mean.

Combining the two rewards matters because ranking alone would ignore score calibration. A model could learn the right order while spreading scores too widely or collapsing them too tightly. The joint objective prevents that split failure: one term anchors the scale, the other preserves preference direction. Reinforcement learning is a good fit because these feedback signals can be computed on generated explanations and scores without requiring a separate differentiable regression head for every preference relation.

A tiny worked example
Suppose image A has target score 8.0 and image B has target score 6.5.
The model predicts 7.7 for A and 7.4 for B. The absolute errors are small, so absolute reward is decent.
However, the score gap is too small and may fail preference judgments if the pair should be clearly separated. Relative reward lowers the total because the ordering signal says the model did not separate the pair strongly enough.
If the model instead predicts 7.9 for A and 6.7 for B, absolute reward stays high and relative reward rises because the order and the separation both align better with the labels.

The paper's full reinforcement-learning algorithm is more detailed, but this equation captures why the method needs both score accuracy and preference accuracy.

What can go wrong

What can go wrong

Curated rationales can encode narrow taste. If AesCoT filtering favors one photographic style or one annotator group too strongly, the model may learn a biased view of aesthetic quality because its reasoning examples reflect a limited range of preferences.
Pairwise rewards can be noisy. Human preference labels are subjective and sometimes inconsistent. If the relative signal is too noisy, policy updates can push the model toward unstable ranking behavior.
Generated explanations can drift from the actual score update. A language model may learn to write polished rationales that sound grounded while the reward is driven mostly by score terms. If explanation faithfulness is not checked, text quality can improve faster than judgment quality because polished language can satisfy style expectations without reflecting the visual evidence that actually drove the score.
Done right. Filter rationale data carefully, weight pairwise rewards against label noise, and audit whether explanation content matches the visual evidence that drove the score.
What a runnable demo should prove

What a runnable demo should prove

Build an aesthetic assessment benchmark with images, single-image scores, pairwise preferences, and a smaller set of human-written rationales. Compare three systems: score-only supervision, rationale-plus-score supervision, and the full Aes-R1 pipeline with RAPO. Keep the backbone constant.

The demo should report one score metric and one ranking metric, plus an audit of whether explanations mention visible evidence that matches human critique. The paper's claim holds if the full system improves both score and ranking while also producing better-grounded rationales, because that would show the method is not merely shifting to a different evaluation axis.
