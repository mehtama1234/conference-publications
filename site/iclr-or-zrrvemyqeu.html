WATS: Wavelet-Aware Temperature Scaling for Reliable Graph Neural Networks

A graph neural network learns wrong confidence on individual nodes, so this paper fixes it by using graph structure to learn node-specific confidence adjusters.

Paper explainersAll themesGraph & Geometric Learning

When a neural network (a program that learns patterns) predicts on graph data (connections between items), its confidence often lies: it says it is very sure when it is wrong. This breaks systems like disease spread prediction, where a wrong confident guess is dangerous. This paper fixes it by learning different confidence adjusters for each node based on how it sits in the graph structure.

Zero assumption version

The confidence lie

A graph neural network takes a graph (nodes connected by edges—think of connections between items like people or papers) and predicts a label for each node. It also outputs a confidence score saying how sure it is. The problem: the confidence is often garbage. The network might say "I am 95% sure this person will catch the flu," but when you look at 100 such predictions, only 60% actually caught it. That 95% was a lie.

Why does this happen? The network sees each node in context of its neighbors, so its decisions are not independent. Existing fixes try to adjust the network's confidence by averaging over neighbors (looking one step away in the graph) or by learning to weight neighbors. But graphs have hidden structure—some nodes sit in dense clusters, others are bridges between regions. One-hop (one step away) statistics miss this fine structure.

In one sentence. The paper assigns each node its own confidence adjuster, chosen by scanning the node's structural position in the entire graph.

The algorithm as a flow

What it actually does

Scan the graph with wavelets

Use graph wavelets to measure each node's local and distant structural features—how clustered it is, how bridge-like, how central.

Learn a temperature for each node

Feed the wavelet measurements into a small network to predict a temperature (a number between 0 and 1) for each node.

Rescale the raw scores

Take the network's raw score (the number before converting to probability) for each class and divide it by the node's temperature—this shrinks or expands the confidence.

Train on validation examples

Optimize the temperature predictor so that when you rescale, the network's stated confidence matches whether it was actually right.

Apply to new predictions

On new data, scan the graph once, compute temperatures, and scale all predictions without retraining the original network.

What the paper changes

What the paper changes

The paper does not change the network's weights or how it learns. It adds one thing after the network finishes: a small neural network that learns a temperature (a scaling factor between 0 and 1) for each node. This happens after training and uses no information from neighbors' predictions—only the structure of the graph.

the object it moves  =  node-specific temperatures
The hidden quantity

The hidden quantity: structural position

measured quantity  =  node structural fingerprint

The paper measures a hidden quantity for each node: its position in the graph's large-scale structure. This is not the node's direct features (which the network already has), and it is not the labels or predictions of neighbors. Instead, it is a structural signature that captures whether the node sits in a tight cluster, is isolated, acts as a bridge between regions, or has some other positional role.

The paper estimates this quantity using graph wavelets (a tool that measures how signals spread through graphs at different scales). By computing wavelets, WATS learns which nodes need higher confidence (because their structure makes the network more accurate) and which need lower confidence (because structural noise makes the network overconfident).

Why it works

Why it works: the causal chain

Here is why this works. Graph neural networks predict based on neighborhoods, but they do not know their own failure modes. A node in a tight cluster might have strong signals from neighbors and the network confidently predicts, but those strong signals can mislead. A node on a bridge might have conflicting signals, making the network oscillate between classes and output fake high confidence. Scanning the graph with wavelets reveals these patterns: wavelet features tell you which nodes sit in dense regions and which sit in noisy or conflicting neighborhoods.

Once you know a node's structural position, you can predict how wrong its confidence will be. A node in a dense, coherent cluster needs less correction—the network is probably right. A node in a transition zone needs heavy correction because the network is likely overconfident. By training a small network to predict these corrections from wavelet features, you learn a connection from structure to correction factor. Then on new predictions, you apply that correction to every node based on its structure, without touching the original network at all. The network does not have to retrain, and you never need the neighbors' predictions or outputs—just the graph shape.

The rescaling equation

First in words:

For each node, compute the wavelet features, feed them into a small network to get a temperature, then divide the network's raw score by that temperature.

Then the compact form:

p_calibrated(i) = softmax(logits(i) / temp(i))

Every symbol:

logits(i)the raw scores the network output for node i
temp(i)the temperature for node i, predicted from wavelets
softmaxconverts scaled scores into probabilities that add up to 1
p_calibrated(i)the final honest confidence
A tiny worked example
Node in a dense cluster: logits = [3.0, 1.0], temp = 0.8. Scaled = [3.0/0.8, 1.0/0.8] = [3.75, 1.25]. Softmax gives ~0.90 and ~0.10. (Small shrinkage.)
Node on a bridge: logits = [2.5, 2.3], temp = 1.5. Scaled = [2.5/1.5, 2.3/1.5] = [1.67, 1.53]. Softmax gives ~0.54 and ~0.46. (Big shrinkage.)
Dense node: network was right, confidence stays high. Bridge node: network guessed, divide by larger temp to lower the fake confidence.

Dividing by temperature is the core move: a big temperature means big shrinkage, correcting overconfident nodes.

What can go wrong

What can go wrong

Wavelets do not capture semantic meaning. If two nodes have the same structural position but predict very different labels, the wavelet cannot tell them apart. The temperature will be the same, and some predictions will still be confidently wrong. The paper mitigates this by tuning the wavelet scale, but it is a fundamental limit.
Temperature predictor overfits on small validation sets. The paper trains the temperature network on 10% of nodes. If the validation set is not representative (e.g., missing certain graph regions), the learned temperatures will not generalize. Re-validation on a different split can fail.
Graph structure changes, temperatures do not. If you add or remove edges in the graph, the wavelet measurements change, but you do not retrain the temperature predictor. Calibration accuracy will drift.
Done right: wavelets match the network's failure mode. If the network's mistakes correlate with structural position (e.g., it is overconfident on bridge nodes because conflicting signals mislead it), then node-specific wavelets fix exactly that. The mechanism is sound.
What a runnable demo should prove

What a runnable demo should prove

Build a small experiment on two or three graphs (e.g., Cora and Citeseer, standard test graphs where nodes are papers and edges are citation relationships). Train a basic graph neural network on node classification. Measure its confidence on the test set. Then apply WATS: compute wavelets for each node, train the temperature predictor on a held-out validation set, and rescale test predictions. Measure the calibration before and after.

Expected Calibration Error (ECE) = average over all nodes of |predicted_confidence - actual_fraction_of_correct_predictions|

The ECE should drop by at least 20% after WATS. If a node had 80% predicted confidence and was right only 50% of the time, its contribution to ECE was 30%. After WATS rescales it down, it should drop to maybe 15% or less.
