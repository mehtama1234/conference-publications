Machine Unlearning under Retain–Forget Entanglement

When a model forgets a data subset, it sometimes accidentally harms accuracy on similar retained data—this paper fixes that by protecting the distribution of losses, not just the average.

Paper explainersAll themesAlignment, Safety & Fairness

Machine unlearning is the process of making a model unlearn a subset of data it was trained on (e.g., delete sensitive records). The hard part: the data you want to forget often shares features with data you want to keep. A naive approach makes the model give wrong answers on the forget set, but does it without checking whether a neighboring, similar retained sample gets accidentally harmed. This paper detects and fixes that collateral damage.

Zero assumption version

The forgetting paradox: losing one thing without harming the similar.

Imagine a trained model that learned to recognize dogs and cats. Suppose you need to make it forget all pictures of a specific dog breed (the forget set). A beginner might simply show the model dog pictures and tell it: make these wrong. The model does—it learns to mislabel that breed.

But here is the trap: the dog breed is close to other dog breeds still in the kept data (they share fur patterns, ear shapes, body size). When the model distorts its internal knowledge to reject the forget breed, it often accidentally makes errors on the nearby kept breeds too. The shared features trap you: hurting one hurts the neighbor.

In one sentence. The paper separates the retained data into nearby and distant samples, protects the nearby ones differently, and uses a shape-preserving guard to keep the pattern of losses honest.

The algorithm as a flow

What it actually does

Partition the retained data.

Split kept samples into two buckets: those semantically close to the forget set, and those far away.

Phase one: aggressive unlearning.

Use constrained optimization to push loss up on the forget set, keeping accuracy on the distant bucket.

Measure the damage.

Check the loss distribution on the close-kept samples. Are they unevenly hurt?

Phase two: redistribute losses.

Apply weight updates shaped by Wasserstein distance to keep the loss shape consistent.

Result.

The forget set is mislabeled reliably, and close-kept samples retain their original loss profile.

What the paper changes

What the paper moves

The paper moves the loss distribution on the close-retained samples—not just its average, but its shape. In phase two, it applies careful weight nudges shaped by Wasserstein-2 distance to keep that distribution similar to the original.

the object it moves  =  Loss distribution shape
The hidden quantity

The hidden quantity: loss distribution shape.

measured quantity  =  Loss distribution shape on close-retained samples

A loss value tells you how wrong the model was on a single sample. Typically, methods only care about the average loss. This paper measures something deeper: the full profile of loss values—how many samples have low loss, how many have high loss, are they spread out or clustered? The shape matters because it tells you whether unlearning hurt all close samples equally or skewed some low and others high.

The paper estimates this shape by recording the actual loss value for each close-retained sample before and after unlearning. It then compares the two distributions using Wasserstein-2 distance, a mathematical measure of how different two distributions are. A smaller distance means the shapes stayed similar.

Why it works

Why it works: two-phase surgery on weight space.

In phase one, the augmented Lagrangian method is a feedback system. It increases the penalty on the forget set while keeping a hard constraint on the less-related retained accuracy. The Lagrangian multiplier automatically adjusts—if the constraint is violated, it turns up the penalty on the constraint term; if met, it turns it down. This balances the goal (make forget set wrong) against the side effect (do not break distant kept samples). After phase one, the close-retained samples are partially damaged because the model had to move its weights to misclassify the forget set.

In phase two, the model applies carefully shaped weight updates. Normally, the model nudges weights to reduce loss everywhere. But here, the update direction is bounded by Wasserstein-2 distance, which says: nudge weights only if it keeps the loss profile on close-retained samples similar to the original. This prevents the model from over-correcting some close samples while under-correcting others. The result: a balanced, honest loss distribution on the close-retained set, and strong unlearning on the forget set.

Math after the picture

The equation: constrained loss with distribution guard.

First in words:

In phase one, minimize the negative loss (maximize mislabeling) on the forget set, subject to keeping the loss on less-related retained samples constant. In phase two, add a term that penalizes shifts in the distribution of losses on close-retained samples using Wasserstein-2 distance.

Then the compact form:

Phase 1: min_theta (-L_f(theta)) subject to L_r_distant(theta) = L_r_distant(theta_0). Phase 2: theta_new = theta_old - alpha * grad_theta L_close(theta_old) where the step is regularized by W_2(P_close_before, P_close_after) <= epsilon.

Every symbol:

L_floss on forget set (samples to make wrong)
L_r_distantloss on distant retained samples (keep constant)
theta_0weights before unlearning
L_closeloss on close-retained samples (affected by forgetting)
W_2Wasserstein-2 distance (measure of distribution shift)
P_close_beforeloss distribution on close-retained before phase two
P_close_afterloss distribution on close-retained after phase two
epsilontolerance for distribution shift (hyperparameter)
A tiny worked example
Start: forget set (3 samples), close-retained (2 samples), distant-retained (5 samples).
Phase one: increase loss on forget set from [1.2, 0.8, 1.5] to [3.5, 3.8, 3.2]. Loss on distant stays at mean 0.5.
Phase one result: close-retained losses moved from [0.4, 0.6] to [0.9, 1.1] (mean same, but uneven).
Phase two: smooth close-retained to [0.7, 0.8] using Wasserstein penalty. Distribution now closer to original [0.4, 0.6].
Final: forget set firmly wrong [3.5, 3.8, 3.2], close-retained softly recovered [0.7, 0.8], distant untouched.

The Wasserstein distance penalty acts like a brake on the gradient step—it prevents phase-two updates that would distort the close-retained loss profile.

What can go wrong

What can go wrong

If the close-retained and forget sets are actually identical. The paper cannot protect what is being erased. If samples are labeled as both forget and close-retained, the constraints fight each other. Use careful semantic partitioning.
If the Wasserstein tolerance epsilon is too loose. The distribution guard becomes weak. Phase two applies larger weight nudges that reshape losses in any direction, not just protective ones. Set epsilon tightly relative to the expected distribution shift so the brake holds.
If the model has learned features orthogonal to the semantic split. Partitioning into close and distant only works if the model actually separates them. If a feature is entangled beyond semantic similarity, the two-phase approach leaves collateral damage.
Done right. Partition retained data using semantic similarity (e.g., shared class, distance in feature space), set Lagrangian and Wasserstein penalties based on a validation set, and check that forget-set loss is high and close-retained loss distribution matches the original.
What a runnable demo should prove

What a runnable demo should prove

Build a small classification model on CIFAR-10 (or a toy dataset). Train it fully. Pick one class as the forget set and divide the remaining classes into close (e.g., similar colors/shapes) and distant (e.g., unrelated). Apply the naive loss-increase unlearning and this paper's two-phase method in parallel. For each, measure: (1) accuracy on the forget set (should be low), (2) accuracy on close-retained samples (should be high), and (3) the Wasserstein distance between original and post-unlearning loss distributions on close-retained (should be small for this paper, large for naive).

Unlearning fidelity = (forget set error rate) / (close-retained accuracy drop + Wasserstein distance on close-retained). Higher is better.

The demo must make it impossible to miss: naive unlearning harms close neighbors, two-phase with Wasserstein protects them by keeping losses distributed the same way.
