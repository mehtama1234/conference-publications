ALIGNED: Adaptive Data-Knowledge Alignment in Genetic Perturbation Prediction

When a neural network and a rule-based system give different answers about how genes respond to mutations, pick a trusted source for each prediction rather than replacing one system with the other.

Paper explainersAll themesAI for Science

Predicting how a cell reacts when you change one gene is hard because scientists have two different sources of truth: real measured data, which is messy and incomplete, and old rulebooks about how genes connect to each other, which have mistakes and gaps. This paper proposes a hybrid system that uses both sources at once, picks which to trust for each individual gene, and refines the old rulebook as new data comes in.

Zero assumption version

Two worlds that keep contradicting each other

To predict what happens when you mutate a single gene in a cell, you need to know two things: real measured experiments on actual cells, and a rulebook of how genes regulate each other. But these two sources constantly disagree. Real measurements are noisy—they have typos, missing values, and occasional mistakes. The old rulebooks are incomplete and outdated—they were built from decades of smaller studies and miss entire pathways that exist in nature. A beginner would pick one and throw away the other: use only the data (ignore the rules) or use only the rules (ignore the contradictions). Both fail.

Using only data means you learn from incomplete, messy examples and drift away from biology. Using only rules means you ignore new evidence and get stuck repeating old mistakes. What you actually need is a system that listens to both, figures out which one is more trustworthy for each individual gene, and lets them update each other when the evidence is strong enough.

The challenge in one sentence. Build a system that blends neural learning from data with symbolic reasoning from knowledge bases, picks which source to trust gene-by-gene, and refines the knowledge base in real time.

The algorithm as a flow

What it actually does

Split inputs

Feed each mutation into both the neural network and the symbolic rule engine.

Route per gene

The adaptor (a small router network) decides for each gene whether to trust the data prediction or the rule prediction.

Measure agreement

Count how many genes are predicted the same way by both systems—this is balance.

Refine rules

When data strongly disagrees with rules, rewrite the rules to match the data.

Retrain and repeat

Use the new hybrid predictions to retrain the neural network. It now learns from both measured data and the refined rulebook, pulling information from both sources.

What the paper changes

What the paper moves

The paper changes how predictions are selected. Instead of running one predictor end-to-end, it runs both a neural and a symbolic system in parallel, then selects which prediction to trust for each individual gene output based on a learned router. It is a hard per-gene choice, not a blend, because a per-gene router learns faster than a global average—it can specialize: data on some genes, rules on others.

The hidden quantity

The hidden quantity: per-gene consistency

measured quantity  =  balanced consistency across data and rules

The paper introduces a hidden measurement called balanced consistency. It is the balance between two scores: how well the predictions match real measured data (data consistency), and how well they align with the rulebook (knowledge consistency). When one source is always right and the other always wrong, balance is zero. When both are equally trusted, balance is high. It is measured as a single number—the average of data consistency and knowledge consistency.

The paper estimates this quantity by running both the neural and symbolic systems on a held-out test set, then comparing: the hybrid predictions vs. actual measurements (data consistency), and the hybrid predictions vs. what the rulebook says (knowledge consistency). The adaptor network is trained to maximize balance rather than optimizing each source separately.

Paper reading. Balanced consistency is defined as the average of two macro F1 scores: F1 between predictions and test data, and F1 between predictions and the gene regulatory network knowledge base. It measures the extent to which the model remains grounded in both curated biological knowledge (learned from past research) and measured evidence.
Why it works

Why blending both sources and routing per-gene works

The core insight is that data and rules have different failure modes. Data is incomplete—it is missing pathways and genes that the rulebook has already learned. Rules are outdated—they encode mistakes and miss new pathways that appear in recent data. Neither is universally better. Instead, for each gene, one source is more reliable than the other, and the adaptor learns which one by looking at examples.

Here is the mechanism: the adaptor is a small neural network trained with reinforcement learning to maximize balance. It sees both the neural prediction and the symbolic prediction for each gene, and outputs a choice: trust the neural system or trust the symbolic system for this gene. The key is that it learns this choice per-gene, not globally. If gene A has noisy measurements and a solid rulebook entry, the adaptor learns to trust the rule for gene A. If gene B has measured data and no rule entry, it learns to trust the neural network for gene B. Over time, as more data arrives, the rulebook is rewritten: genes that the adaptor consistently chose from the data side get their rules updated to match what the data says. This closes the loop because the system now has a feedback path: data informs which rules to update, and those refined rules help train the neural network next time, pulling it toward biological truth.

This works because it avoids false choice. The hybrid system is no longer choosing between 'trust all data' or 'trust all rules'—it is learning the right balance per-gene and updating the rules from high-confidence data decisions. Each system gets better because the other one filters its weak examples: the neural network stops learning from noise (rules catch it), and the rules stop enforcing old mistakes (data corrects them).

Math after the picture

The balance equation

First in words:

The adaptor maximizes the probability of consistent predictions. It balances a term that checks if the hybrid prediction logically follows from the rulebook plus input, times a term measuring how likely the neural network thinks that prediction is.

Then the compact form:

max_f [ I(KB ∪ x |= f(x)) · p(y | x; f) ]

Every symbol:

KB ∪ xthe rulebook plus the input mutation
f(x)the neural network's prediction for this mutation
|=logically follows from (the prediction is consistent with the rulebook)
I(...)an indicator: 1 if consistent, 0 if not
p(y | x; f)how confident the neural network is in that prediction
A tiny worked example
Suppose a mutation x is input. The neural network predicts gene A will increase (f(x) says yes). The rulebook says via logical inference that gene A should also increase (KB ∪ x |= yes). Indicator I = 1, confidence p(y|x;f) = 0.9. Contribution: 1 × 0.9 = 0.9.
For gene B: neural predicts decrease, rulebook predicts increase. I = 0, confidence 0.7. Contribution: 0 × 0.7 = 0.
For gene C: neural predicts no change, rulebook is silent (consistent). I = 1, confidence 0.8. Contribution: 1 × 0.8 = 0.8.
The adaptor maximizes this sum over all genes, learning to pick high-confidence predictions where the system agrees internally.

The product of consistency and confidence means the adaptor learns to trust predictions where the neural and symbolic systems align and the neural network is confident.

What can go wrong

What can go wrong

Routing on noisy data. If the same gene has contradictory measurements in different experiments, the adaptor might flip between trusting the rule and trusting the data for the same gene. Result: unpredictable, inconsistent behavior.
Rulebook is fundamentally wrong. If the knowledge base has systematic errors that no amount of data can catch (e.g., it encodes an outdated regulatory pathway), the adaptor may still choose to trust it for genes where it looks confident. The system reinforces old mistakes.
Overconfidence in refinement. When the system refines the rulebook based on data, it may over-correct. A few noisy measurements in one experiment can rewrite a rule that was built from thousands of older observations. Balance can swing too far toward data.
Done right. The system works well when data and rules are both noisy but in different ways: measurement noise is random and averages out; rule errors are systematic. The adaptor learns to trust data on new genes (where rules are incomplete) and rules on core genes (where data is sparse). Frequent retraining and auditing of refined rules prevent drift.
What a runnable demo should prove

What a runnable demo should prove

Build a synthetic genetic network with 20 genes and 5 regulatory rules. Measure the genes under 10 mutations. Introduce 2-3 deliberate errors into the rulebook (e.g., a regulation is backwards, or a link is missing). Train a neural network on the data and initialize a symbolic system with the flawed rulebook. Run ALIGNED: measure data consistency (neural vs. real measurements), knowledge consistency (predictions vs. original rulebook), and balanced consistency (average). Track how many rulebook errors the system corrects after 5 iterations of alignment and refinement. Visualize per-gene routing decisions before and after refinement to show which source the adaptor learned to trust.
