Adaptive Data-Knowledge Alignment in Genetic Perturbation Prediction

When predicting how cells respond to genetic changes, a model works better if it learns from both data and known biology at the same time, fixing conflicts between them.

Paper explainersAll themesAI for Science

Predicting how cells respond to genetic perturbation (changes) is key to understanding what genes do. Current models either learn from data alone or use known biology alone, and neither explains itself well. ALIGNED shows that a model can learn to predict cell response while also revealing and fixing errors in existing biological knowledge by integrating both sources, even when they contradict each other.

Zero assumption version

Data and biology textbooks don't agree

When a scientist measures how cells respond to a genetic change (a perturbation), the real measurements are messy. Cells are noisy, experiments have mistakes, and some measurements are just plain wrong. At the same time, biologists have written down rules and interactions they discovered over decades: this gene activates that one, this protein blocks this pathway. But those rules are incomplete, outdated, or simply wrong too.

A naive approach picks one side: either (1) ignore the textbooks and train a machine learning model purely on data, which predicts well but gives no insight into why, or (2) hard-code the known biology and predict through it, which is interpretable but ignores new data and cannot fix bad rules. Neither handles the real problem: the data and the knowledge contradict each other, and you need both to get the answer right.

The method: Use a model with two parts (one that learns from data, one that uses known biology rules) and teach them to agree while fixing errors on both sides.

The algorithm as a flow

What it actually does

Set up two models in parallel

One learns patterns from measured data; the other encodes known biological rules.

Train them on overlapping predictions

Both models predict cell response to the same perturbations, and they score each other's predictions.

Measure disagreement

When predictions differ, flag the conflict and compute a score for how serious it is.

Update both models to agree

Adjust the data model weights and refine the biological rules so both converge to the same answer.

Validate against both sources

The final rules should match known biology and the predictions should match measured data.

What the paper changes

What changes: both the learned model and the knowledge base

The paper modifies two things: (1) the weights inside the neural network that learns from data, nudging them to match the biological rules, and (2) the rules themselves in the knowledge base, refining them to match the data.

The hidden quantity

The hidden quantity: balanced consistency

measured quantity  =  balanced consistency

The paper introduces a balanced consistency metric: a single score that measures how much the neural predictions agree with both the measured data and the known biological rules at the same time. It is balanced because it weighs both sources equally, preventing the model from simply ignoring the messy data or dismissing the incomplete rules.

The paper estimates this by counting how many predictions the neural model makes that are consistent with the data, and how many refined rules are consistent with those same predictions, then combining both into one agreement score.

Plain reading. Balanced consistency is a score from 0 to 1 that asks: do the neural predictions match both the measured data and the known rules? If yes, the score is high. If the model predicts well but violates known biology, or if it obeys the rules but ignores new data, the score is low.
Paper reading. The paper defines balanced consistency as the harmonic mean (or weighted average) of how well predictions align with measured observations from real experiments and how well they respect the symbolic knowledge base constraints.
Why it works

Why it works: two models teaching each other

The core idea is simple: a neural network and a symbolic knowledge base are two different kinds of models. The neural network is flexible and learns patterns from data, but it can hallucinate (make up false relationships). The knowledge base is explicit and interpretable, but it is incomplete and sometimes wrong. By training them together and forcing them to agree, each one constrains the other. The neural network learns to respect biological rules it would otherwise ignore, and the knowledge base gets refined to match what the data actually shows.

Here is the causal chain: when the data model and the rules model predict differently, the inconsistency is a signal that something is wrong. If you update only the neural weights to match the rules, you overfit to bad rules. If you update only the rules to match the data, you lose interpretability. So ALIGNED does both: it nudges the weights toward the rules (making the neural model more interpretable) and refines the rules toward the data (making the knowledge base more accurate). Balanced consistency ensures neither model dominates, so they meet in the middle.

The balancing equation

First in words:

The total loss is a weighted mix of how wrong the neural predictions are, how wrong the refined rules are, and a penalty for how much they disagree.

Then the compact form:

Loss = error_neural + error_rules + lambda * disagreement

Every symbol:

error_neuralhow far the neural predictions are from measured data
error_ruleshow well the refined rules match known biological principles
disagreementthe gap between neural and symbolic model predictions
lambdahow strongly to penalize disagreement (a tuning dial)
A tiny worked example
Scenario: neural model predicts gene X increases by 80%, symbolic model (based on rules) predicts 50%.
error_neural = 0.5 (half the distance to measured data, which says 90%)
error_rules = 0.3 (small; the refined rules are close to known biology)
disagreement = |80% - 50%| / 100% = 0.30
If lambda = 2, the loss = 0.5 + 0.3 + 2 * 0.30 = 1.4
On the next iteration, training reduces disagreement by refining the rules to say 70% and adjusting neural weights, making both models predict 75%. New disagreement = 0.05, loss drops to 0.5 + 0.3 + 2 * 0.05 = 0.9. Both models now agree more closely.

Higher lambda forces neural and symbolic models to agree, but too high a lambda prevents them from learning. The paper tunes lambda to balance accuracy and interpretability.

What can go wrong

What can go wrong

Stale biological knowledge. If the existing knowledge base has many errors, the neural model may waste effort trying to agree with false rules instead of learning from good data. The framework assumes the knowledge base is partially correct; if it is mostly wrong, the neural model will be pulled in the wrong direction.
Noisy or mislabeled data. If the measured data has many mistakes (mislabeled cell types, measurement noise), the refined rules will absorb those mistakes. The balanced consistency metric will not catch this; both models will agree on a wrong prediction.
Lambda tuning is critical. If lambda is too high, the model forces agreement at the cost of accuracy; if too low, it ignores the knowledge base. The paper must carefully tune this dial for each dataset, and there is no universal setting.
Done right. The framework works best when (1) the biological knowledge base is incomplete but mostly correct, (2) the data is noisy but generally reliable, and (3) lambda is tuned via validation on a held-out set. Then both models constrain each other productively.
What a runnable demo should prove

What a runnable demo should prove

A concrete demo would take a real gene perturbation dataset (e.g., gene knockouts in a cell line), a biological knowledge base (e.g., a manually curated gene interaction network), and show that ALIGNED converges to predictions that match the measured data and, at the same time, refines the knowledge base to remove known false edges and add missing ones. The demo should show three plots: (1) neural and symbolic predictions over training iterations, converging to agreement, (2) balanced consistency score rising, and (3) a before-and-after picture of the refined knowledge base, showing which rules were fixed.

balanced_consistency = 2 * (accuracy_on_data * accuracy_on_rules) / (accuracy_on_data + accuracy_on_rules)

The demo must make it impossible to miss that the two models start disagreeing, gradually align, and end up both accurate and interpretable—something neither could achieve alone.
