Zero assumption version

Picking the right training dataset is a guessing game

Multimodal language models (models that understand both images and text together) learn from huge datasets. When you want to teach one a new task, you have to pick which dataset to train on. Right now, people guess: 'That dataset looks similar to my task, so it will probably work.' But this guess fails constantly.

A beginner might reason: 'Text-heavy datasets help text tasks, vision-heavy datasets help vision tasks.' Yet the paper's experiments on 14 real datasets show this intuition is backwards—transfer jumps around unpredictably because what matters is not the broad category but the precise overlap between the dataset's examples and the target task, plus how much the model can learn from the dataset's complexity and diversity. The specific dataset matters far more than the broad category. You end up wasting time training on the wrong dataset and only finding out after weeks of compute.

The problem. You cannot predict in advance whether a dataset will help your model learn a new task; today's practice is to train on each candidate and measure performance after weeks of compute, so you waste time and money on bad choices because the training cost masks which dataset is truly useful.

What the paper changes

What the paper changes

The paper ranks datasets by a single score—a combination of three easy-to-measure numbers (model confusion, task similarity, internal diversity)—without training on any of them. Conventional practice trains on each candidate and compares real performance; DATAPROPHET does it once, upfront.

The hidden quantity

The hidden quantity: predictive influence

measured quantity  =  dataset influence on target performance

Influence is how much a dataset will raise your model's accuracy on the target task after you train on it. You cannot measure influence without training, but DATAPROPHET estimates it by combining three observable numbers: multimodal perplexity (how surprised the model is by each dataset), similarity to the target task (how much the dataset overlaps with it), and diversity (how varied the dataset's examples are from each other).

The paper measures whether this pre-training estimate actually predicts the real influence. It does: across 14 datasets, the predicted ranking correlates 86% with the ranking based on actual training results—strong enough to make dataset selection reliable without training.

Why it works

Why three numbers together predict usefulness

A dataset is useful if three things are true. First, the model should be somewhat confused by it (high perplexity), because confusion means the dataset teaches something new—if the model finds the dataset trivial (low perplexity), it learns nothing. Second, the dataset should overlap with the target task, because examples that share structure with your goal will transfer knowledge more reliably. Third, the dataset should be diverse (examples should not all look identical), because repetition teaches less than variety.

The magic is that these three numbers can be computed in seconds—you feed each dataset into the model once and measure confusion, check the overlap with your target without any training, and check example diversity by looking at the raw data. You never train on the dataset. Yet the ranking you get predicts the ranking you would have gotten after training with 86% accuracy. That is strong enough to make the right choice upfront.

Math after the picture

The scoring formula

First in words:

Predicted usefulness = a measure of perplexity + a measure of similarity + a measure of diversity

Then the compact form:

score_D = w1 * perplexity(D) + w2 * similarity(D, target) + w3 * diversity(D)

Every symbol:

score_Dthe usefulness score for dataset D
perplexity(D)how confused the model is by dataset D (higher = more to learn)
similarity(D, target)how much dataset D overlaps with the target task (higher = more transferable)
diversity(D)how varied dataset D is (higher = more examples to learn from)
w1, w2, w3weights that balance the three components
A tiny worked example
Dataset A: perplexity 8.2, similarity 0.7, diversity 0.6. Score = 1.0 * 8.2 + 2.0 * 0.7 + 1.5 * 0.6 = 8.2 + 1.4 + 0.9 = 10.5
Dataset B: perplexity 3.1, similarity 0.5, diversity 0.8. Score = 1.0 * 3.1 + 2.0 * 0.5 + 1.5 * 0.8 = 3.1 + 1.0 + 1.2 = 5.3
Dataset A scores higher, so we predict A will help the model more. After training, A does indeed reach higher accuracy on the target task.

The three components measure different reasons a dataset helps: it teaches new patterns (because confusion signals patterns the model has not yet learned), it overlaps with your goal (because shared structure accelerates learning), and it offers variety (because repetition plateaus quickly).

What can go wrong

What can go wrong

Perplexity alone is misleading. A dataset can confuse the model yet teach nothing useful if it is too far from the target. High perplexity without high similarity leads you astray.
Similarity without diversity wastes examples. If all examples in a similar dataset are nearly identical, the model learns only one thing repeatedly. Diversity matters as much as overlap.
Out-of-distribution datasets break the metric. If a candidate dataset is so different from anything the model has seen that perplexity is unreliable, the metric may not transfer.
Works best with well-curated datasets. The metric assumes datasets are reasonably clean and representative of their domain. Datasets with mislabeled examples or extreme noise can corrupt the scores.
