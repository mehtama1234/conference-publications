Training-Free Network Width via Neural Tangent Kernel

You can estimate the minimum network width needed for good generalization before training, by measuring the smallest eigenvalue of the Neural Tangent Kernel at initialization.

Paper explainersAll themesLearning Theory

Building a neural network requires choosing how many units (width) to include — but wider networks use more memory and compute. This paper shows you can predict the width you actually need by analyzing a mathematical tool called the Neural Tangent Kernel right at the start, before spending time training. The smallest eigenvalue (a single number extracted from that tool) tells you the minimum width where generalization performance stops improving.

Zero assumption version

Picking network width is a costly guess

Neural networks need a width (number of units per layer) chosen upfront. Too narrow and the network cannot learn the pattern; too wide and you waste memory and compute time. But you only discover how narrow is too narrow after training for hours or days.

A naive approach: train several networks at different widths and pick the best. But that defeats the point — you want to know the answer before you train at all.

The problem. You need to know the minimum width BEFORE training, when you have no information except the randomly initialized network.

What the paper changes

What the paper changes: the initialization

The paper does not change how networks train or what loss function you use. Instead, it provides a new way to read the initialization — a principled metric computed at the very start that predicts the width you need.

The hidden quantity

The hidden quantity: smallest eigenvalue of the Neural Tangent Kernel

measured quantity  =  minimum kernel eigenvalue

The Neural Tangent Kernel (or NTK) is a table that captures how sensitive the network output is to tiny changes in each weight, measured at initialization before any training. It is built from slopes (the rate of change) of the network function with respect to each weight.

The smallest eigenvalue of this matrix is a single number that acts as a bottleneck: it measures the weakest direction in which the network can respond to the data. The paper discovers that this number strongly predicts the minimum width at which generalization performance stops improving (called cardinal width).

Plain reading. Imagine a very narrow hallway (the smallest eigenvalue). A ball rolling down the hallway (the network output) must squeeze through the narrowest point, which limits how far it can roll. Widen the hallway and the ball can roll farther, because it is no longer stuck squeezing. The narrowness of the hallway at initialization tells you when the ball has enough room — beyond that width, squeezing is no longer the problem.
Paper reading. The NTK describes the shape of the loss surface around initialization — which directions lead downhill steeply and which lead down gently. Its eigenvalues identify those directions. The smallest eigenvalue bounds the information capacity — networks with stronger (larger) minimum eigenvalue can express more variation and require less width to reach their saturation point, because they have more independent learning channels.
Why it works

Why it works: the kernel tells you when a network is big enough

When a network is too narrow, its weights cannot move in enough independent directions to fit the data. The Neural Tangent Kernel at initialization reveals this bottleneck: the smallest eigenvalue tells you the weakest channel through which the network can learn.

As you widen the network, you add more weights and more independent learning directions. At some point, the width is sufficient — the weakest channel is no longer a bottleneck. Beyond this point, increasing width does not improve generalization, because the weak channel is no longer the limiting factor. This turning point is the cardinal width.

The paper shows that the smallest eigenvalue predicts this turning point without ever training. Because the eigenvalue captures the intrinsic information capacity of the random initialization, it acts as an early proxy for how much width you will need.

The equation: measuring the network's information bottleneck

First in words:

The smallest eigenvalue of the NTK matrix predicts cardinal width. Cardinal width is the minimum network width where test loss has saturated, divided by the data dimension.

Then the compact form:

lambda_min = smallest_eigenvalue(NTK_matrix) ; cardinal_width_pred = predict_from(lambda_min, data_dim, architecture)

A tiny worked example with illustrative numbers
Suppose you have 50 training samples and the smallest eigenvalue is 0.8.
For this data and architecture, the paper's formula predicts cardinal width = 256 hidden units.
You train two networks: one with 128 units (below cardinal width) and one with 256 units (at cardinal width).
Network at 128 units: test loss = 0.42 (not yet saturated).
Network at 256 units: test loss = 0.28 (saturated; going wider to 512 units gives test loss = 0.27, barely any improvement).
The prediction was correct — cardinal width is where the curve flattens.

The smallest eigenvalue acts as a measuring stick: larger eigenvalue means the network has a wider information channel, so it saturates at smaller widths.

What can go wrong

What can go wrong

The prediction assumes weight initialization is correct. If you use a non-standard initialization scheme or the weights are scaled unexpectedly, the kernel eigenvalue may not reflect the true information capacity.
Different architectures may have different mappings from eigenvalue to cardinal width. The paper tests on fully connected networks (each layer connected to all neurons in the next layer) and convolutional networks (layers that slide a small window over the input). Radically different designs (like transformer networks that process sequences) might not follow the same rule.
The prediction is for a specific loss function and dataset. If you change how you measure error (the loss function) or the type of task (e.g., predicting numbers instead of categories), you may need to recompute the prediction model.
Done right: measure the eigenvalue for your exact network and data. The method works when you use the same architecture, loss, and data pattern for both the eigenvalue computation and training.

What a runnable demo should prove

Build a simple dataset (e.g. MNIST or a synthetic 2D classification task). Train a small neural network (fully connected, 2-3 hidden layers). Vary the width (64, 128, 256, 512, 1024 units) and record test loss for each. Compute the Neural Tangent Kernel for the random initialization and its smallest eigenvalue. Plot the smallest eigenvalue against the width where test loss saturates. The demo should show a clear correlation.

The demo makes it impossible to miss: a single number computed before training predicts where the generalization curve flattens, because that number captures the network's internal learning capacity from the random initialization.
