DEGAP: Dynamic Entropy-Guided Attention Perturbation

A vision-language model hallucinates less by comparing its normal answer path to a perturbed version where visual attention is weakened at just the right depth.

Paper explainersAll themesMultimodal

Large vision-language models (a model trained to understand both pictures and text) sometimes ignore what it sees and invent answers based purely on language patterns. DEGAP fixes this by making the model run two parallel forward passes: one normal, one where visual attention (the mechanism that focuses on image regions) is slightly disrupted. By comparing these two branches, the model learns when it should trust the picture over language habit.

Zero assumption version

Language habit masks visual evidence

A large vision-language model learns two things: patterns in how humans use language (a language prior) and patterns in pictures (visual grounding). When it answers a question about an image, it can lean too heavily on the language prior.

A naive fix would be to ignore language and only look at the picture. But language patterns carry real signal—the model needs both. The real problem is telling when to trust the picture and when to trust the language. The model has no internal gauge of that choice.

In one sentence. DEGAP forces the model to compare its normal answer path (both language and vision) against a contrast path where vision is artificially weakened, so the difference reveals when the model was relying on language habit instead of the picture.

The algorithm as a flow

What it actually does

Forward pass one (normal)

Run the model on the image and question with all visual attention active.

Forward pass two (contrast)

Run the same image and question but artificially weaken visual attention at selected depths.

Measure internal confidence

At each layer, calculate entropy (uncertainty) of the model's intermediate scores.

Select perturbation layers dynamically

Perturb layers where entropy is low (the model is confident but may be overconfident).

Compare and decode

Subtract the perturbed logits (raw score for each word) from the normal logits; the difference steers the model away from pure language habit.

What the paper changes

What the paper changes

DEGAP modifies the attention weights inside the model during decoding (the phase when the model writes out its answer). Specifically, it weakens the visual attention connections at certain layers while keeping language attention unchanged.

the object it moves  =  visual attention weights
The hidden quantity

Entropy: how confident is the model?

measured quantity  =  Confidence-weighted entropy

Entropy is a number that measures how uncertain things are. If a model is very sure one word comes next, entropy is low. If all words seem equally likely, entropy is high. Here, entropy tells us whether the model is confidently picking one path or hedging across many possibilities.

DEGAP measures entropy at each layer and uses it to decide where to perturb. If entropy is already high (the model is uncertain), perturbation there will not help, because the model is already spreading its bets across many words—weakening visual attention won't change which word wins. If entropy is low (the model is overconfident), perturbation reveals whether that confidence is justified by the picture or by language habit, because a confident decision that drops sharply when vision is weakened was driven by language, not the image.

Why it works

Why weakening visual attention reveals hallucination

A vision-language model fuses language and visual signals through attention. Attention is a mechanism (a soft gate) that decides which parts of the image to look at. When the model hallucinates, it has learned language patterns so well that those patterns pull the answer even when the visual evidence contradicts them.

DEGAP's core insight: run the model twice. In the contrast run, visual attention is weakened at layers where the model is overconfident. This forces the model to answer using only language habit. If the contrast answer is very different from the normal answer, the model was relying on language habit in the normal path. If both paths agree, the answer is grounded in the picture. By comparing, the model learns to discount answers that lean too far on language alone.

Math after the picture

The contrastive decoding equation

First in words:

The next-word score is the normal branch score minus a scaled perturbed branch score. The scaling factor depends on the model's confidence at that layer.

Then the compact form:

score_final = score_normal - alpha * score_perturbed

Every symbol:

score_normallog-probability of a word under normal forward pass
score_perturbedlog-probability of a word when visual attention is weakened
alphaweighting factor (higher = trust the perturbation more)
score_finaladjusted score that the model uses to pick the next word
A tiny worked example
Scenario: model is choosing next word after 'The image shows a...'
Normal branch outputs score_normal for word 'circle' = 2.5 (likely)
Perturbed branch outputs score_perturbed for word 'circle' = 0.3 (unlikely when vision is weak)
This high contrast (2.5 - 0.3 = 2.2) signals the word 'circle' is vision-grounded.
For word 'logo': score_normal = 2.0, score_perturbed = 1.9
Low contrast (2.0 - 1.9 = 0.1) signals 'logo' is driven by language habit, not vision.
With alpha = 1.0: score_final for 'circle' = 2.5 - 0.3 = 2.2; score_final for 'logo' = 2.0 - 1.9 = 0.1.
Model picks 'circle' over 'logo', the vision-grounded answer.

The difference between branches acts as a filter: words that both branches agree on are vision-grounded; words only the normal branch likes are language habit and get downweighted.

What can go wrong

What can go wrong

Perturbation too weak. If visual attention is barely weakened, the contrast branch still uses enough visual signal and the difference between branches vanishes. The model learns no corrective signal.
Perturbation too strong. If visual attention is crushed to zero, the contrast branch may produce nonsense (random language), and the difference becomes so large it over-steers away from legitimate visual descriptions.
Wrong layers chosen. If the model perturbs layers that process language only, visual attention is unaffected and hallucination persists. Entropy guidance must correctly identify layers where language and vision interact.
Done right. Entropy-guided layer selection ensures perturbation hits layers where the model is overconfident about mixed signals. The difference between branches is stable and informative.
What a runnable demo should prove

What a runnable demo should prove

Write a short script that loads a vision-language model (e.g., a smaller CLIP-based model or a Qwen-VL setup) and an image where the model commonly hallucinates (e.g., confusing object color or mistaking an object category based on language bias). Run a forward pass with standard decoding to see the hallucination. Then implement DEGAP by calculating layer-wise entropy, selecting low-entropy layers, and running a perturbed forward pass where you scale down the visual attention weights by 50% at those layers. Compare the two branches and decode using the contrastive score. The demo should make it obvious that the perturbed branch outputs pure language habit, and the difference between branches steers the model toward the true visual content.

hallucination_rate = (count of wrong answers) / (total answers); show that DEGAP reduces this vs. standard decoding

The demo must show side-by-side: (1) standard model answer (hallucination), (2) perturbed-only answer (language bias alone), (3) DEGAP contrastive answer (vision-grounded). The human eye should see the model escaping language habit by comparing the two branches.
