ReaSyn: Exploring Synthesizable Chemical Space with Iterative Pathway Refinements

A generative model learns to build molecules from scratch while thinking through both assembly steps (bottom-up) and decomposition (top-down), iteratively editing pathways until the molecule is actually makeable.

Paper explainersAll themesAI for Science

Molecular generative models can produce molecules that have never been seen before, but the catch is that most of them are impossible to synthesize in a lab. ReaSyn solves this by teaching a neural network to think like a chemist: it generates the entire recipe (synthetic pathway) that proves a molecule is buildable, and it does this from two angles at once — bottom-up (assembling from simple blocks) and top-down (deconstructing the target into simpler pieces). Then it refines the recipe using edit operations (add a step, remove a step, swap a step) until it finds a path that works.

Zero assumption version

The synthesis gap: great ideas that cannot be built

Neural networks can generate molecules that have never been made before by learning patterns from known chemical structures. But there is a hard constraint: a molecule is only useful if chemists can actually synthesize it. Existing generative models ignore this constraint, producing molecules that are chemically impossible or impractical to make.

A beginner might try brute-force search: generate a molecule, check if it is synthesizable, if not, try another. This fails because the space of possible molecules is exponentially large — trillions exist, and a tiny fraction are synthesizable. The model wastes compute exploring dead ends. Worse, even if you find a synthesizable molecule, you have no proof of how to make it.

The core problem is that previous methods treat synthesis as a single-step constraint: does a molecule have a recipe? Instead, they should treat it as a compositional search problem: what are all the ways to build this molecule, and which one is easiest?

The insight. Instead of generating a molecule and hoping it is synthesizable, generate the entire synthetic pathway that proves it is buildable.

The algorithm as a flow

What it actually does

Encode the target molecule

A neural network reads the molecular structure and creates an internal representation.

Generate bottom-up pathway

The decoder produces a sequence of reaction steps, each adding a building block, until the target is assembled.

Generate top-down pathway

The same network generates a decomposition: starting from the target, breaking it into simpler precursors, step by step.

Refine with edits

A secondary model predicts insertion, deletion, and substitution operations on the entire pathway at once, improving realism.

Iterate the cycle

Repeat bottom-up, top-down, and editing multiple times until the pathway converges to a practical synthesis plan.

What the paper changes

What the paper changes

ReaSyn changes how the model generates: instead of sampling isolated molecules, it samples the entire synthetic pathway — the sequence of chemical reactions that produces the molecule. This is the object: the pathway, not the molecule alone.

the object it moves  =  Synthetic pathway sequences
The hidden quantity

Coverage of synthesizable space

measured quantity  =  Pathway diversity and reconstruction rate

The hidden quantity is how well the model covers the space of possible synthesis routes for a given molecule. A molecule might have dozens of ways to build it, each with different practicality. The paper measures this as reconstruction rate (does the method find a synthesizable version of the input?) and pathway diversity (how many different ways does it find to make the same molecule?).

ReaSyn estimates this quantity by iteratively sampling pathways from both directions (bottom-up and top-down) and measuring how many unique, realistic pathways it can generate before running out of new ideas. A pathway is realistic if the edit operations (insertions, deletions, substitutions) are all chemically plausible.

Why it works

Why bidirectional generation and iteration find better pathways

The mechanism has two levels. First, bottom-up and top-down generation: a molecule can be built in many ways, but only some are practical. A bottom-up view (starting from simple blocks, adding to reach the target) finds one set of feasible routes. A top-down view (starting from the target, decomposing toward simpler pieces) finds a different set. Because the two views make different assumptions about what is realistic, they explore different regions of the space. A single model trained on both directions learns to be flexible.

Second, the iteration: the pathways generated by the first pass are raw and often include unrealistic steps. The edit model (Edit Bridge) refines each pathway by predicting insertion, deletion, and substitution operations. These operations are trained on real chemical edit sequences, so they steer the pathway toward realistic transformations. By alternating between generative sampling and refinement, ReaSyn spirals toward high-quality pathways that the model increasingly trusts as synthesizable.

The edit refinement loss

First in words:

For each pathway, the edit model predicts the rates (probabilities) of insertion, deletion, and substitution at each position. The loss is the negative log-likelihood under a Bregman divergence, measuring how well the predicted edits align the unrefined pathway to the refined one.

Then the compact form:

L_edit = -sum_t log p(edit_op_t | pathway_t) using Bregman divergence

Every symbol:

edit_op_tthe edit operation (insert, delete, or substitute) at position t
pathway_tthe token or reaction at position t in the current pathway
p(edit_op_t | pathway_t)the predicted probability of that edit operation given the local context
Bregman divergencea divergence measure (like squared distance) that penalizes deviations from the target pathway
A tiny worked example of pathway edits
Unrefined pathway: Mol_A + Rxn_1 -> Mol_B + Rxn_2 -> Target (5 steps).
Refined pathway: Mol_A + Rxn_1 -> Mol_C + Rxn_new + Mol_B + Rxn_2 -> Target (6 steps).
The edit model predicts: at position 3, insert Rxn_new (prob 0.9). At position 2, substitute Rxn_1 with Rxn_1_alt (prob 0.6).
Loss for that step: -log(0.9) - log(0.6) ≈ 0.11 + 0.51 = 0.62. Averaging over all positions gives the total edit loss.
The model learns: when seeing Mol_A, then Mol_B directly, recognize that an intermediate step is missing; predict insertion.

The loss trains the edit model to learn which local changes in a pathway are chemically realistic. At test time, it iteratively refines raw sampled pathways into practical ones.

What can go wrong

What can go wrong

Pathways that sound good but are not synthesizable. The edit model is trained on real chemical data, but real data is finite. If a realistic-looking pathway contains a step that is rare or previously unseen in the training set, the model does not flag it. The pathway passes the model's check but fails in the lab.
Bidirectional training does not guarantee coverage. Bottom-up and top-down explorations are not exhaustive. If a practical pathway uses a building block or reaction rarely seen in training, both directions may miss it. Iteration refines, but it cannot find what was never sampled.
Iteration convergence to a local trap. Repeated editing can steer the pathway toward a locally plausible but globally suboptimal solution. If an early edit makes the pathway realistic-seeming but chemically inefficient, later iterations may lock into that trap instead of exploring alternatives.
Done right: use human-in-the-loop validation. In practice, ReaSyn is best paired with a final check by synthetic chemists or rule-based filters that catch edge cases. The model generates candidate pathways; humans or automated validators confirm they are truly synthesizable before lab synthesis.
What a runnable demo should prove

What a runnable demo should prove

A demo should show that the bidirectional generation + editing produces more diverse and accurate synthesis plans than a baseline single-direction model. Specifically: (1) take a target molecule from a held-out test set, (2) run the baseline (one direction only) and ReaSyn (both directions + editing), (3) count how many unique, realistic pathways each produces, (4) for each pathway, run a downstream validation model (or a synthetic chemist's rule set) that checks if the steps are chemically sound, (5) measure reconstruction rate (percentage of input molecules for which both systems find a synthesizable analog) and pathway diversity (average number of valid alternative routes per molecule). The key metric is that ReaSyn should have higher reconstruction rate and higher diversity without sacrificing path realism.

Reconstruction rate = (number of inputs with ≥1 synthesizable analog) / (total inputs). Pathway diversity = (total valid alternative pathways) / (inputs with ≥1 valid pathway). Realism rate = (pathways validated as chemically sound) / (all sampled pathways).

The demo succeeds if ReaSyn finds more molecules AND more routes per molecule, and those routes are validated as realistically synthesizable, outperforming both naive generation and previous synthesis-constrained methods.
