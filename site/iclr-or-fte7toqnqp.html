Inter-Agent Relative Representations for Multi-Agent Option Discovery

When many agents must coordinate, discover repeatable synchronized actions by measuring how far each agent drifts from the perfect team alignment point.

Paper explainersAll themesReinforcement Learning

Imagine five robots on a factory floor that need to work together but can only learn from trial and error. If each robot learns independently, they perform chaotic, uncoordinated motions. But if you can automatically discover a small set of pre-learned coordinated patterns that the robots can apply together, they suddenly cooperate well. This paper shows how to find those patterns by computing a virtual alignment point (the Fermat state) and using it to measure which state dimensions (features) show the most team-wide disagreement. The discovered patterns become reusable options (like a drill or a carry motion in a repertoire) that guide joint learning.

Zero assumption version

Independent agents fail to discover coordination

When you have multiple agents (robots, game characters, traders) learning together in one environment, a naive approach is to train each one separately. Each agent sees only its own view and ignores the others. But real coordination requires agents to synchronize their actions—to move together, wait for each other, or divide tasks in a pattern. Independent learning cannot find such patterns because each agent is only rewarded for its own progress, not for matching a teammate's motion.

A beginner might try to teach options (fixed action sequences) by hand or write reward signals that explicitly say 'sync up.' But this requires knowing ahead of time which synchronizations matter. In a complex multi-agent domain, you do not know. You need a method that automatically discovers which coordination patterns emerge from the structure of the agents' joint state space.

The paper discovers reusable coordinated actions automatically by finding which state dimensions show the most team-wide disagreement and building options around those dimensions. Discover coordinated multi-agent actions by measuring team misalignment on each state feature dimension and using those measurements to construct options that synchronize agent behavior.

The algorithm as a flow

What it actually does

Estimate the Fermat state

Train a neural network to predict the point of maximum alignment (minimum total distance between all agents).

Compute n-distance (multidimensional distance)

For each state dimension separately, measure how far each agent is from the Fermat state.

Build the graph Laplacian

Create a table of numbers that captures which state dimensions have high disagreement; its rankings identify dimensions by misalignment.

Derive intrinsic rewards

For each eigenvector (dimension), assign a reward signal: actions that reduce that dimension's spread are rewarded.

Train joint options

Train multi-agent policies where each option follows one eigenvector reward, building a library of coordinated behaviors.

What the paper changes

The object the paper moves

The paper changes how a team of agents represents their joint state. Instead of using the full joint state (which grows exponentially with agent count), it represents the state as a set of distances from each agent to the Fermat point, measured separately on each state dimension. This compressed representation preserves the information needed to detect and build coordinated behaviors.

the object it moves  =  state representation
The hidden quantity

The hidden quantity: spreadness

measured quantity  =  spreadness per dimension

Spreadness is a measure of how far apart agents are on a single state dimension. If all agents have the same value on dimension i, spreadness is zero (perfect alignment). If agents have wildly different values, spreadness is high. The paper estimates this by first learning the Fermat state (the point where agents are closest to each other on average), then computing how far each agent sits from that point along each dimension.

The paper estimates spreadness implicitly through the graph Laplacian rankings. It trains a neural distance approximator to predict how far each agent is from the Fermat state, then builds a mathematical table (graph Laplacian) from these distances. This table's internal structure naturally ranks state dimensions by their misalignment; dimensions with high importance scores have high spreadness.

Paper reading. Spreadness captures team-level misalignment on each state dimension; it is estimated by measuring how far each agent sits from the Fermat center on that dimension and then ranking dimensions using the graph Laplacian spectrum (a mathematical way to order them).
Why it works

Why this works: finding the right targets for synchronization

The core insight is that the dimensions where agents disagree most are exactly the dimensions where coordinated action will have the biggest payoff. If all agents already move in lockstep on dimension 1 (position x) but are chaotic on dimension 3 (rotation), then teaching agents to synchronize on dimension 3 is more valuable than on dimension 1.

The paper computes this automatically using the Fermat state. The Fermat state is the point closest to all agents on average—the virtual center of the team. Measuring how far each agent is from that center, on each dimension separately, reveals which dimensions have high disagreement. The graph Laplacian eigendecomposition then automatically ranks these dimensions, and the top eigenvectors become the basis for options. Each option is trained as a policy that minimizes spread on one eigenvector dimension. When the team learns these coordinated behaviors early, they form a foundation for solving downstream tasks together, because the agents now share synchronized patterns.

Math after the picture

The intrinsic reward formula

First in words:

For each state dimension ranked by misalignment (eigenvector e), the reward for a transition is how much that dimension's spread decreased. If the dimension was scattered before and the agents synchronized after, reward is high.

Then the compact form:

r_e(s, s') = e(s') - e(s)

Every symbol:

r_e(s, s')intrinsic reward for transitioning from state s to state s' following eigenvector e
e(s)the value of eigenvector e at state s (how much spread exists on that dimension in state s)
e(s')the value of eigenvector e at the next state s'
ean eigenvector of the Laplacian matrix (ranks a state dimension by team misalignment)
A tiny worked example
Suppose eigenvector e_1 measures spread on the position-x dimension. In the current state s, agents are far apart on x: e_1(s) = 0.6 (high spread).
The agents take an action that synchronizes their x positions. In the new state s', they are closer: e_1(s') = 0.2 (low spread).
Intrinsic reward = e_1(s') - e_1(s) = 0.2 - 0.6 = -0.4 (negative, but we train to maximize, so reducing spread is rewarded).
Alternatively, if we define r_e = e(s) - e(s') (spread decrease), then r = 0.6 - 0.2 = 0.4 (positive), and agents learn to minimize spread on this dimension.

The formula says that an action is good if it moves the team toward synchronization on the dimensions the paper identified as most important (high misalignment).

What can go wrong

What can go wrong

Fermat state estimation fails if agents are too dispersed. If the team is scattered so far apart that no single 'center' makes sense, the Fermat encoder may learn a meaningless average point. Mitigation: initialize with sampled trajectories from a structured policy, not pure randomness.
Eigenvectors may not align with task-relevant synchronization. The paper assumes that minimizing spreadness on high-misalignment dimensions leads to useful coordination, because reducing disagreement on a dimension where agents diverge most should teach them to sync. However, if a task only cares about one dimension of sync (e.g., staying in the same room), the method may discover options for dimensions that do not matter downstream, wasting compute on irrelevant synchronization.
Training options slows convergence early on. The paper noted slower initial convergence when using options; agents must learn when and how to apply them. This overhead only pays off if the downstream task strongly rewards coordination.
Done right: Fermat state is learned from random-policy rollouts. Pre-compute the Fermat state and eigenvectors from a large dataset (500k transitions) before any task learning. This grounds the method in the actual state-space structure, not task-specific rewards.
What a runnable demo should prove

What a runnable demo should prove

Build a simple multi-agent domain (e.g., two robots moving to a shared target). Train the Fermat encoder and distance decoder on 10,000 random joint-state pairs. Compute the 2D Laplacian eigenvectors. For the top two eigenvectors, train shallow option policies (a few episodes each) that treat the eigenvector value as intrinsic reward. Then train a downstream task learner that can select between the pre-trained options or raw actions. Measure the option-learning baseline (random options) vs. this paper's options.

Coordination gain = (task_success_with_options - task_success_without_options) / task_success_without_options * 100%

The demo must show that pre-trained Fermat-derived options reduce the steps needed to find a cooperative solution, and that the discovered options generalize to multiple task instances.
