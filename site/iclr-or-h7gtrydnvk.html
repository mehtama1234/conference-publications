No Labels, No Problem: Training Visual Reasoners with Multimodal Verifiers

Train visual reasoning models without labeled answers by using AI systems themselves as feedback teachers.

Paper explainersAll themesMultimodal

A robot needs to look at an image and answer questions like: 'Is the chair to the left or right of the table?' — that requires both spotting the objects correctly and understanding how they relate spatially. Building systems that do this well usually demands thousands of labeled (image, question, answer) examples. This paper shows how to skip the labels entirely by having a language model and a vision model act as teachers, giving the main model feedback on where it went wrong.

Zero assumption version

Visual reasoning without hand-made answers

Answering spatial questions about images is hard. The model must (1) find objects in the scene — 'where is the chair?' — and (2) compare them — 'is it left of the table?' If you train a model the old way, you collect thousands of images, write down the right answers by hand, and feed both the image and the correct answer to the model as examples. The model learns by comparing its guesses to your answers.

The problem: hand-writing thousands of answers takes people months. And what if the training images come from the internet, where objects and scenes are messy and varied? The model trained on one type of room may fail on another.

A beginner might try: 'Use a detector and a logical program.' Find chairs and tables automatically (say, with a trained object detector), then write simple rules like 'if chair_x < table_x then left.' This breaks because detectors make mistakes, and rules don't capture the nuance of real scenes — a chair partly hidden behind a table still counts as 'to the left' in how humans see it.

In one sentence. Train a model to answer spatial reasoning questions by letting a language model and a vision model grade its attempts, without any hand-written answers.

The algorithm as a flow

What it actually does

Step 1: The model breaks down the question

Given an image and 'Is the chair left of the table?', the model decomposes it into substeps: first spot the chair, then spot the table, then compare positions.

Step 2: Language verifier scores the reasoning

A language model reads the model's step-by-step reasoning and grades how correct and logical it is, giving a reward score (high if the steps make sense).

Step 3: Vision verifier finds false positives and false negatives

A vision model automatically shows the model examples of objects it fails on — chairs it missed, or wrong detections of the table — to harden the visual grounding.

Step 4: Reinforcement learning updates the model

The model adjusts its internal numbers to increase both verifier scores, because higher scores come from better reasoning and better object-spotting.

Step 5: Repeat on unlabeled image collections

No ground truth needed. Feed the model any large set of images and questions, and verifiers drive continuous improvement.

What the paper changes

What the paper changes

The object is the model's reasoning decomposition and visual grounding — the sequence of steps it generates and the boxes it draws around objects. Most training approaches either lock these in stone (a fixed program, no learning) or train them with hand-written answers (expensive). This paper trains both jointly, using verifiers as the only source of feedback.

The hidden quantity

The hidden quantity: Verification Signal

measured quantity  =  Verification signal strength

The hidden quantity is the verification signal — a score from both the language verifier ('did the reasoning steps make logical sense?') and the vision verifier ('did the model find the objects it claimed to find?'). Neither score is a ground-truth label; both come automatically from other AI systems.

The language verifier works by prompting a large language model: 'I decomposed this spatial question into these steps. Does my reasoning flow logically?' A score close to 1 means yes. The vision verifier uses automated hard-negative mining: it finds images and crops where the model's object detector is wrong (false positives like 'found a chair where there is none' and false negatives like 'missed the actual chair'), and measures how often the model fails on those deliberately tricky examples. A strong verification signal means both verifiers agree the model is reasoning well and finding objects accurately.

Why it works

Why verifier feedback trains better models

The core mechanism is feedback plus reinforcement learning. Here is how it works: (1) The model makes a guess — both a reasoning decomposition and object boxes. (2) Two verifiers grade independently: the language model checks if the reasoning is sound, the vision model checks if the detected objects are actually in the image. (3) Reinforcement learning adjusts the model's internal weights to increase both verifier scores. (4) Importantly, these scores are free. No human had to write the correct answer; the verifiers generate the signal automatically by design.

Why does this beat hand labels? Because verifiers were trained on enormous, diverse data, so they work well even on new scene types and questions. A language model trained on billions of words can judge whether a logical chain makes sense, even on scenes and questions it has never seen, because it learned deep patterns of logic. A vision model trained on huge datasets can spot objects with fewer failures than a small, hand-labeled training set, because it has seen more examples of objects in real contexts. As the model trains, it improves on both dimensions at once — reasoning becomes more coherent, and object detection becomes more accurate. And because verifiers are reusable (you do not retrain them), you can scale to millions of images without retraining or relabeling.

Hard-negative mining amplifies this. Instead of just showing the model examples where it got unlucky, the vision verifier actively finds the hardest cases — the chairs the model almost-detected but missed, the false alarms where the model saw a chair in a shadow. Training on these deliberate hard cases hardens the model faster than random examples, because the model is forced to learn the boundary between 'actually a chair' and 'looks like a chair but is not', which is where mistakes happen.

Math after the picture

The reward equation

First in words:

Total reward equals language verifier score plus vision verifier score, weighted by how confident each is.

Then the compact form:

R_total = w_lang * R_lang + w_vis * R_vis

Every symbol:

R_totalthe combined reward signal
R_langthe language verifier score (0 to 1, higher is better reasoning)
w_langhow much to weight the reasoning score
R_visthe vision verifier score (0 to 1, higher is better object detection)
w_vishow much to weight the grounding score
A tiny worked example
Suppose on one example: R_lang = 0.8 (the reasoning made sense) and R_vis = 0.6 (the object boxes were off).
Set w_lang = 0.5 and w_vis = 0.5 (equal weight).
R_total = 0.5 * 0.8 + 0.5 * 0.6 = 0.4 + 0.3 = 0.7.
RL now nudges the model's weights to increase R_total on the next attempt; if reasoning improves to 0.85 and grounding to 0.7, then R_total becomes 0.5 * 0.85 + 0.5 * 0.7 = 0.775 — the model gets better.

The model does not know the 'true' answer; it only knows the composite verifier score. RL steers toward higher scores, which happen to align with correct reasoning and grounding because verifiers are good judges.

What can go wrong

What can go wrong

Verifier collapse. If the verifiers are weak or noisy, the model may chase a false signal. If the language verifier gives high scores to illogical reasoning, the model learns to sound plausible without being correct. Mitigation: use verifiers trained on large, trustworthy datasets, and validate each verifier's own accuracy on held-out human-labeled data.
Hard-negative bias. Mining only the hardest false negatives can make the model overfit to rare, edge-case objects and miss common, easy ones. If the dataset is skewed (rare objects appear mostly in hard negatives), the model may learn backwards assumptions — it thinks rare objects are important and common ones are not.
Reward saturation. If the verifier scores plateau (both stay near 1.0), the RL signal vanishes and the model stops improving, even though it is not yet fully correct. The model needs enough signal variance to learn.
Done right. Combine verifiers thoughtfully: use independent language and vision signals so they do not reinforce each other's errors. Monitor verifier agreement (if they disagree, investigate). Validate on human-labeled held-out sets throughout training, and do not train only on verifier reward.
What a runnable demo should prove

What a runnable demo should prove

Build a visual reasoning model on a small set of unlabeled images (say, 200 pictures of rooms with furniture). Give it spatial questions like 'Is the lamp to the left of the sofa?' Without VALOR, train a baseline with hand-written answers (pretend you labeled 100 of the images). Run VALOR on the same 200 unlabeled images, using a free large language model and vision model as verifiers. After training, test both models on a held-out set of 50 human-labeled examples.

Accuracy = (correct_reasoning + correct_grounding) / (total_reasoning + total_grounding)

The demo must show that the unlabeled VALOR model matches or beats the hand-labeled baseline, proving that verifier feedback is a real substitute for manual supervision.
