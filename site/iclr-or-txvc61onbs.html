Why time-series gaps are hard to fill

Real-world time-series data (sensor readings, stock prices, weather) almost always has gaps. A naive first attempt: fill each gap with the average of its neighbors, or fit a single global polynomial to the whole sequence. The average is too boring and loses the wiggles. The global polynomial smooths everything flat and misses the local patterns that happened. You need a method that keeps global structure but adds back the local details without drifting away from what you actually measured.

The existing solutions work okay on small gaps but fail when many values are missing together, or when the data has both smooth long-term trends and sharp short-term changes. You need to learn the real shape from the data.

The challenge. Learn a trajectory from noise to the complete data that respects both global shape and local details, and never lets filled values drift away from observed points.

What it actually does

Initialize each missing value as random noise, each observed value stays known.

Learn a velocity field

A neural network predicts which way each value should move at each time step.

Blend trends and details

Multi-scale heads compute paths at different zoom levels, then a time-dependent gate mixes them.

Follow the velocity, then after each small step, project observed values back to ground truth.

Output complete data

What the paper changes

What changes: the velocity field

The paper learns a neural network that predicts the velocity (direction and speed of change) for each missing value at each time step, starting from noise and moving toward the final answer. The velocity field is computed at multiple scales simultaneously, then blended via a learned time-dependent gate.

The hidden quantity

Multi-scale alignment: keeping local details without global drift

measured quantity  =  scale mismatch (when coarse and fine predictions disagree)

The paper introduces multi-scale velocity heads, like looking at the data through lenses of different magnifications. The coarse head captures the big shape (the overall trend). The fine head captures small wiggles. If they move in conflicting directions, the filled data veers off course. The hidden quantity is the mismatch between what coarse and fine heads predict.

The paper measures this mismatch implicitly through the time-gated gate, which learns when to trust coarse paths versus fine paths at each moment. A mild anti-aliasing filter on the finest branch prevents it from overshooting, which would amplify mismatch and cause drift.

Why it works

How learning a velocity field fills gaps without drifting

The paper learns a neural network that predicts velocity (direction and speed of change) by training on sequences where some values are artificially hidden. The network sees the observed values and their time context (what came before and after) and learns to move the hidden ones toward plausible futures. Starting from noise, the network repeatedly nudges each missing value by a small amount guided by that predicted velocity, until the noise has become the final answer.

The problem: a single velocity field focused on global trends will oversmooth, losing local wiggles. A velocity field chasing every wiggle will chaotically drift. The paper's insight is to compute velocity at two scales (coarse for trends, fine for details), then learn a time-dependent gate that decides which one to trust at each moment. When the data is still noisy and chaotic, trust the smooth coarse signal. When the data is well-formed, the fine details are safe to add. At inference, after each integration step, the paper runs a data-consistency projection: it clamps every observed value back to ground truth, so no amount of learning can pull them away. This anchor prevents accumulated drift and keeps the filled trajectory honest.

The velocity learning equation

First in words:

The learning objective trains the velocity network to predict the true direction of change, restricted to missing-value coordinates only. The total loss sums the mismatch between predicted and actual velocity on every missing position, plus small penalty terms for numerical stability.

Then the compact form:

L_total = mean_over_missing_coords( ||v_pred(t, x_obs, mask) - v_true(t)||^2 ) + lambda_coarse * smooth_penalty_coarse + lambda_fine * smooth_penalty_fine

Every symbol:

v_predvelocity predicted by the neural network at time t
v_truetrue velocity: how much a value should move to reach ground truth
x_obsobserved values, used as context
maskbinary: which positions are missing
mean_over_missing_coordsaverage error only on coordinates we do not know
lambda_coarse, lambda_finestrength of smoothing penalties on each scale (small weights)
smooth_penaltydiscourages the velocity from jumping erratically between time steps
A tiny worked example
At time t=0.2, predicting value x_3 (missing):
v_pred = 1.5 (network says move 1.5 units per time step)
v_true = 1.3 (ground truth is 1.3)
Error = (1.5 - 1.3)^2 = 0.04
Sum errors for all 10 missing coordinates: 0.42 total velocity error.
Add smoothing: penalty_coarse = 0.01, penalty_fine = 0.02, lambdas = 0.1, 0.05.
Smoothing cost = 0.1*0.01 + 0.05*0.02 = 0.002
L_total = 0.42 + 0.002 = 0.422
Training nudges the network to reduce this error, learning to move missing values along realistic paths.

The network trains only on how to move missing values; after training, inference anchors observed values to prevent any drift, ensuring the filled data respects ground truth.

What can go wrong

What can go wrong

If the context window is too short. The self-attention network needs to see before-and-after context to understand the data's patterns. If the left or right history is missing, the velocity prediction becomes a guess.
If one scale dominates too much. If the time-gated gate learns to trust only the coarse signal, fine details are lost. If it trusts only the fine signal, the global trend drifts. The gate must learn balance.
If observed values are noisy. The data-consistency projection pins filled values to observed ground truth, but if those observations are corrupt or mislabeled, the filled sequence will inherit the corruption.
Done right. With good context, balanced multi-scale weighting, and clean observed data, the method fills large gaps accurately and runs fast enough for real-time applications.
What a runnable demo should prove

What a runnable demo should prove

Build a sequence of 100 simulated sensor readings over time, each following a smooth trend plus small random wiggles. Hide 30 consecutive readings in the middle (simulating a sensor failure). Train the TG-MSFM model on similar synthetic sequences, then ask it to fill the gap. Measure the mean squared error between filled and true values. Run three baselines: linear interpolation (connecting the gap with a straight line), global polynomial fit, and the paper's method. Show that the paper's method recovers both the overall shape and the local wiggles, while baselines either oversmooth or drift.
