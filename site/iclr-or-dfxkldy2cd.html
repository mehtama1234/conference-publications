Reasoning or Retrieval? Answer Attribution on Large Reasoning Models

Large reasoning models simultaneously use step-by-step reasoning and memorized answers, often letting memory shortcuts override genuine thinking.

Paper explainersAll themesInterpretability

Reasoning models are trained to show their work by writing out step-by-step thoughts before answering. But a new study discovered something surprising: the final answer often comes from something different than the reasoning. The model has a second hidden shortcut — it remembers answers it has seen before. This paper reveals that reasoning models exploit this shortcut during training, like a student who memorizes test answers instead of learning the material.

Zero assumption version

The gap between what the model says it thinks and what it actually does

Reasoning models write out their thinking step by step. A human reading the steps might believe the model figured out the answer by working through the logic. But recent work shows something strange: the final answer often contradicts what the model just reasoned about. If you change the reasoning to misleading ideas, the model still gives the same answer. This suggests the model is not actually following its own reasoning to decide.

The problem: a beginner might assume the model reads its own reasoning and picks an answer based on it. But what is actually happening? The model has learned two separate ways to generate answers. One is the reasoning pathway — writing careful steps. The other is faster and simpler: retrieve an answer from memory, because its weights store correct answers it has seen before and can fetch them instantly. Like a student taking a test who glances at a neighbor's paper instead of solving the problem, the model learns to exploit whichever pathway is easier because both get rewarded equally if they produce the right answer.

The hidden problem. Reasoning models use two competing pathways — genuine reasoning and memory shortcuts — and they exploit whichever works best, undermining true learning.

What the paper changes

The single thing the paper changes

The paper modifies how the model is trained. During reinforcement learning, after each training iteration normally done to improve reward, the model inserts a second step: unlearning, which works by training the model on corrupted memory answers to teach it to forget them. This step deliberately weakens the pathways that support memory retrieval by draining their signal, so the model cannot fall back on quick shortcuts anymore. The model learns to rely on reasoning instead because retrieval is no longer available.

The hidden quantity

Which pathway the model trusts: retrieval dominance

measured quantity  =  Retrieval dominance score

The hidden quantity is a number from 0 to 100 measuring how much the model relies on memory retrieval versus reasoning. When set up so memory fails but reasoning should still work, the model either answers correctly (reasoning-dominant, low score) or follows the corrupted memory (retrieval-dominant, high score).

The paper estimates this score by running experiments: poison the model's memory (teach it wrong answers), then ask questions. If the model gives wrong answers anyway, it is retrieval-dominant. Test the same model with misleading reasoning but correct memory; if it gives right answers, that also signals retrieval-dominant. The score accumulates across many questions in this setup. FARL measurement shows whether suppressing memory during training shifts dominance toward reasoning.

Why it works

Why the method works: forcing the model to choose one pathway

Inside the model, information flows through layers. At certain middle layers (around layer 12-16 in tested models), specialized network connections (called attention mechanisms — the parts of the model that select which pieces of information to focus on) decide whether to pass reasoning signals or switch to retrieval signals. This decision point is a bottleneck: the model must choose which pathway to trust.

During normal reward-based training, both pathways get rewarded if they produce right answers. The retrieval pathway is simpler and cheaper because its weights only need to store and match patterns from training data, no complex reasoning chains, so the model gradually strengthens it because easier solutions get adopted first. Reward signals do not distinguish between genuine reasoning and retrieval shortcuts.

FARL adds an unlearning step after each reward-training iteration. This step deliberately weakens the retrieval pathway by feeding the model corrupted memories (wrong answers) and training it to forget them. This is like drilling a student on trick questions so they learn not to memorize the trap answers. After unlearning, retrieval is no longer a viable shortcut because its signals are diluted. The decision point in the middle layers switches: reasoning becomes the cheaper option because it is now the only path that gives rewards consistently. The model learns to rely on thinking instead of lookups. Over many iterations, the model rewires toward genuine reasoning, and this reasoning generalizes better to new problems because reasoning learned from first principles adapts to new contexts, while memorization of specific answers does not.

Math after the picture

The training equation: balance reasoning and suppress retrieval

First in words:

Total training loss equals reward (for correct answers) plus a retrieval-suppression term (penalty for memorized wrong answers from the unlearning stage).

Then the compact form:

L_total = L_reward + beta * L_unlearn

Every symbol:

L_totalCombined training goal
L_rewardPenalty when model answer is wrong (from reinforcement learning)
L_unlearnPenalty for remembering corrupted memory answers (what to forget)
betaHow strongly to suppress retrieval (higher = more unlearning)
A tiny worked example
Model sees 100 questions in one training batch.
Reward training: 85 answered right (reward = 0), 15 wrong (reward penalty = 1 each), L_reward = 15.
Unlearning: on the same 100, model had memorized 8 wrong answers we planted. L_unlearn = 8.
Set beta = 2 (unlearning is twice as strong as reward).
L_total = 15 + 2 * 8 = 31.
Next batch: unlearning weakens retrieval pathway. Model now answers 88 correct. New L_total = 12 + 2 * 3 = 18.
Over iterations, retrieval shortcut fades; reasoning sharpens; loss improves.

The two terms push in opposite directions — reward pulls the model to memorize shortcuts, unlearning pulls it to forget them — creating a tug-of-war that gradually shifts weight toward reasoning.

What can go wrong

What can go wrong

Unlearning too weak. If the unlearning term (beta) is too small, retrieval shortcuts persist because the corrupted memory penalty is too weak to overcome the reward signal that still favors shortcuts; the model reverts to memory lookups and generalization does not improve.
Unlearning too strong. If beta is very large, the model forgets even useful general knowledge, not just shortcuts. Reasoning quality drops.
Corrupted memories are unrealistic. If the poisoned memory answers used in unlearning do not match real ways models fail, unlearning trains the model to ignore the wrong thing.
Balanced tuning. When beta is set appropriately (guided by holding-out validation questions), unlearning suppresses retrieval without erasing good general knowledge; reasoning flourishes.
What a runnable demo should prove

What a runnable demo should prove

A demo should take a reasoning model, train it on math or logic questions using standard reward-based training (baseline), then retrain an identical model using FARL (with unlearning). Test both on new questions in the same domain and on questions in a different domain. The visible proof: the FARL-trained model keeps reasoning quality high when the domain shifts, while the baseline drops. The baseline relied on domain-specific memory shortcuts; FARL forced genuine reasoning.

Generalization gap = (baseline accuracy on new domain) - (FARL accuracy on new domain); negative means FARL wins

If the demo works, the FARL model maintains reasoning when context shifts, proving it learned to think rather than memorize.
