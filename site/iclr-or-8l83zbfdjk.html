Conformal Prediction for Long-Tailed Classification

A method to wrap classifiers with honest uncertainty sets that treat rare classes fairly, even when training data is dominated by common classes.

Paper explainersAll themesOther

In real-world tasks like plant identification, a few species dominate the labeled data while thousands of rare species have almost no examples. Standard uncertainty methods either give huge, useless prediction sets or systematically ignore rare species. This paper introduces a way to build prediction sets that are honest about uncertainty (guaranteed to contain the true label at a chosen probability) while still keeping rare classes visible and sets small enough to be practical.

Zero assumption version

Uncertainty sets fail on long-tailed data

Conformal prediction is a wrapper around any classifier that produces a set of candidate labels instead of a single guess. If you ask 'what is this plant?' the model does not just say 'daisy' but gives a set like {daisy, buttercup, dandelion}. The point is that this set is guaranteed to contain the true label with, say, 90% probability—honest uncertainty, not just confidence scores.

But real-world data is long-tailed: millions of images of common plants (like daisies) but only dozens of rare species. When you train on this imbalanced data, the model learns the common classes well and barely learns the rare ones. Conformal prediction then faces a trap: if you ask for 90% coverage of a rare class, the method produces enormous sets (maybe listing 500 plant names) because the model was never taught to distinguish that rare species. If you shrink the set to stay practical, the rare classes get left out entirely.

A beginner might try to just add a weighting term during training to balance the classes. But this only helps if the model can actually learn the rare species—and with only a handful of examples, it cannot, because neural networks need many examples to reliably learn a category's features (background textures, petal shapes, colors). Conformal prediction is not about training harder; it is about being honest about what you do and do not know.

The trap in one sentence: Conformal prediction must choose between huge sets that always include rare classes or small, practical sets that often omit them entirely.

The algorithm as a flow

What it actually does

Start with imbalanced data

Training set has mostly common classes, few rare ones.

Train a standard classifier

Model learns to guess labels; learns common classes well, rare ones poorly.

Measure how confident the model is on each class

Compute prediction scores; note that model's scores for rare classes are naturally lower (because it saw fewer examples).

Adjust conformal thresholds by class prevalence

Make the threshold for rare classes stricter (lower), so more examples pass and rare classes stay in sets longer.

Output a prediction set

The set now includes all classes predicted to reach the adjusted threshold; both common and rare classes covered fairly.

What the paper changes

What the paper changes

The paper modifies the conformal prediction score function—the number that decides whether a candidate label goes into the final prediction set. Standard conformal uses the raw model output (a softmax probability). This paper proposes two tweaks: first, a prevalence-adjusted softmax that scales down the scores of common classes and scales up the scores of rare classes, because the model's raw confidence is artificially inflated for common classes (due to abundant training data) and suppressed for rare ones, so undoing this bias ensures all classes are judged fairly; second, a label-weighted method that allows smooth interpolation between fair coverage for all classes and practical set sizes.

The hidden quantity

The hidden quantity: Class-conditional coverage

measured quantity  =  Class-conditional coverage

Coverage means: 'How often does the prediction set contain the true label?' Standard conformal prediction aims for coverage that is the same across all examples on average—90% marginal coverage means the set is right 90% of the time, period. But on long-tailed data, this hides a problem: the coverage for rare classes might be 30% (the sets omit the true rare species most of the time) while common classes get 95% coverage. Class-conditional coverage breaks this down by class: 'What fraction of daisies get daisy in their set? What fraction of rare species X get X in their set?' This is what users actually care about—you do not want a method that cheats by ignoring rare species.

The paper estimates class-conditional coverage by splitting the data by class and measuring set accuracy per class. It then designs the prevalence-adjusted softmax to push rare-class coverage toward the target (e.g., 90%) while keeping common-class coverage at the target too, and ensuring the overall set size stays small enough to be useful.

Why it works

Why the method works: Adjusting for what the model was taught

The core insight is that conformal prediction works by asking 'is this label confident enough?' for each candidate. The 'confident enough' threshold is set so that, on average, the true label crosses it 90% of the time. But on imbalanced data, the model's confidence is skewed: it learned common classes well, so it is naturally more confident about them. When the method asks 'is this rare species confident enough?', the answer is often no, even for the true label—not because the label is wrong, but because the model was barely trained on that species.

The paper's move: instead of using the model's raw confidence, it first adjusts the confidence scores to undo the training imbalance. For common classes, lower the confidence a bit (make the threshold harder to reach). For rare classes, raise the confidence (make the threshold easier to reach). Now the threshold is fair—it asks each class 'given how much data you had, are you confident enough?' A rare species with 50 examples that reaches 60% confidence might be boosted to look like 80% confidence (because 60% confidence on 50 examples is impressive), while a common class with 1 million examples reaching 95% confidence might be deflated to 85% (because 95% is expected). With fair thresholds, all classes get into the set at roughly the same rate.

The paper also proposes a label-weighted variant that smoothly interpolates: you can dial up or down how much you enforce class-conditional fairness, trading it off against set size. This gives practitioners control—if your use case can tolerate small gaps in coverage between rare and common classes, you can get smaller sets.

Math after the picture

The prevalence-adjusted softmax equation

First in words:

Take the model's raw confidence for each class, divide by the square root of how many training examples that class had, then renormalize so all scores sum to 1. The higher this adjusted score, the more likely the label is in the prediction set.

Then the compact form:

adjusted_softmax_i = softmax_i / sqrt(count_i + 1)

Every symbol:

adjusted_softmax_iThe adjusted confidence for class i (used in conformal prediction)
softmax_iThe model's raw confidence score for class i (a number from 0 to 1)
count_iHow many training examples belong to class i
sqrt(...+1)Square root of the count plus a small constant (prevents dividing by zero for very rare classes)
A tiny worked example
Class A (daisy): 10,000 training examples, raw confidence 0.95. Adjusted = 0.95 / sqrt(10000 + 1) = 0.95 / 100 ≈ 0.0095.
Class B (rare species): 10 training examples, raw confidence 0.60. Adjusted = 0.60 / sqrt(10 + 1) = 0.60 / sqrt(11) ≈ 0.60 / 3.3 ≈ 0.18.
Despite lower raw confidence, Class B gets a higher adjusted score (0.18 vs 0.0095) because it was trained on far fewer examples. Both classes now reach the same threshold at roughly the same rate.

The square root is key: it is not proportional to the count, so a class with 100x more data gets only 10x lower score, leaving room for rare classes to compete.

What can go wrong

What can go wrong

Extremely rare classes (1-2 examples). Even with adjustment, a class with only 1 or 2 examples provides almost no signal to the model. The adjustment helps (it raises the conformal threshold for the rare class, making it easier to include), but the model's confidence remains near random because it was shown the class almost never, so even a boosted weak signal is still weak. The method cannot overcome complete lack of training data.
Changing the mix of classes at test time. If at test time the world has a different mix of classes (e.g., suddenly more rare species are common), the prevalence adjustment learned from training no longer applies. The method assumes the pattern of which classes are common stays the same between training and real use.
Very large imbalance ratios. If the ratio between most common and rarest class is in the millions (as in some genomics datasets), even the square-root adjustment may not fully level the playing field. The method works best with imbalance ratios up to hundreds or thousands.
Done right: measure per-class coverage. Before deploying, always measure coverage separately for each class (or at least bins of class frequency). This catches failures and validates that fairness assumptions hold.

Wrap it with both standard conformal prediction and prevalence-adjusted conformal prediction. Split test data by class frequency (common vs. rare). Measure coverage and set size for each group.
