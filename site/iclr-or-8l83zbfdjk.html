Conformal Prediction for Long-Tailed Classification

When rare classes exist, prediction sets must either small but miss rare labels, or huge but practical—this paper trades them smoothly by adjusting confidence thresholds per class prevalence.

Paper explainersAll themesOther

In real-world image datasets like plant identification, some classes (rare species) have dozens of training images while others (common weeds) have thousands. A basic predictor that says "the answer is one of these labels" (a prediction set) must guarantee coverage: the true answer is actually in the set at least 90% of the time. But in long-tailed data, this guarantee forces a cruel choice: make sets tiny so rare classes often drop out, or make sets huge (sometimes including every label) so rare classes stay in. This paper introduces a smooth middle path.

The Prediction Set Trap on Imbalanced Data

When you have a machine learning model trained on imbalanced data—lots of common examples, very few rare ones—you need to answer "What label(s) could the true answer be?" in a way that gives guarantees. A prediction set is a small list of candidate labels. To guarantee 90% coverage means: on the true test data, the right answer sits inside the prediction set at least 90% of the time.

The naive approach: pick a confidence score threshold and include all labels above it. This works fine on balanced data. On long-tailed data it breaks catastrophically. The model is rarely confident on rare classes (because it saw few examples), so when you tighten the threshold to keep set sizes small, rare-class examples fall out of the set—the model says "I have no confident guess" even when the rare class is the true answer. Flip the approach and loosen the threshold to get good coverage on rare classes, and common classes flood into the set. Sets explode to 100+ labels, making the predictor useless.

The core problem in one sentence. Simple confidence thresholds cannot simultaneously guarantee coverage on rare classes and keep prediction sets small.

The algorithm as a flow

What it actually does

Step 1: Count training class sizes

For each label, record how many training examples have that label. Call this the prevalence.

Step 2: Adjust confidence by prevalence

For rare classes (few training examples), lower the confidence bar so rare-class predictions enter the set. For common classes, raise it.

Step 3: Compute a new score per example

Instead of raw model confidence, use a score that already bakes in this class-by-class adjustment (the paper calls this prevalence-adjusted softmax).

Step 4: Calibrate on holdout data

On a small separate dataset, find the single threshold that gives 90% coverage overall. This threshold now works across all classes fairly.

Step 5: Make prediction sets

For each test example, include all labels whose adjusted scores exceed the threshold. Coverage is guaranteed across common and rare classes alike.

What the paper changes

What the Paper Changes

The paper changes the confidence score itself. Instead of the raw softmax output (how confident the model is), it uses a modified score that already includes information about class prevalence. Rare classes start with a boost—their scores are amplified—so a moderately-confident prediction for a rare class scores higher than the same raw confidence for a common class, because dividing by the square root of a small number (low prevalence) makes the result larger. This ensures rare-class predictions are not systematically downweighted.

The hidden quantity

Macro-Coverage: Coverage Averaged Fairly Across Classes

measured quantity  =  Macro-coverage (average per-class coverage)

The hidden quantity is macro-coverage—a single number measuring fairness. It is the average class-conditional coverage (the fraction of true rare-class examples inside the set, averaged with the fraction of true common-class examples inside the set, weighting each class equally). This is different from standard coverage, which is computed by averaging across all test examples: rare-class examples matter less because there are fewer of them. Macro-coverage counts each class equally.

The paper measures this by computing the coverage separately for each of the 1,081 classes (in Pl@ntNet), then averaging those numbers. A good method achieves macro-coverage close to 90% even on a severely imbalanced dataset.

Plain reading. Macro-coverage is the average of "how many rare-class examples got included in the set" and "how many common-class examples got included." If you give each class an equal vote, even if the rare class has only 2 examples and the common class has 2,000, that is macro-coverage.
Paper reading. Macro-coverage equals the average per-class coverage across all classes. Formally, it is the mean over classes y of (number of true y examples inside their prediction set) divided by (total number of true y examples).
Why it works

Why Adjusting by Prevalence Fixes the Problem

The model assigns a raw confidence score to each class (the output of the softmax function—a number between 0 and 1 saying how sure it is). On imbalanced data, the model is naturally less confident on rare classes, because it learned from fewer examples of them. A single global threshold fails: it is either too strict (rare classes fall below it) or too loose (everything passes).

The paper's move is to adjust the score before applying the threshold. A rare class's score gets a boost proportional to how rare it is. Mathematically, this is like saying: "I will trust this rare-class prediction more, because even though the model is only 60% confident, rare-class predictions are inherently noisier, so I should not hold them to the same 90% confidence bar I use for common classes." The boost is calibrated to class prevalence (how often the class appeared in training). With this adjusted score, a single threshold works fairly across all classes—rare-class examples stay in, common-class examples stay out, and sets stay manageable.

The final refinement: the paper also proposes a linear interpolation method (INTERP-Q) that blends two existing approaches. Instead of jumping between "small sets with poor rare-class coverage" and "huge sets with perfect rare-class coverage," you can smoothly dial between them using a single hyperparameter. This is useful when you want to tune the fairness-versus-practicality trade-off.

Math after the picture

The Adjusted Confidence Score

First in words:

Adjusted score for class y = raw model confidence for class y, divided by the square root of how often class y appeared in the training data, then scaled by a normalizing factor.

Then the compact form:

PAS_y(x) = softmax_y(x) / sqrt(prevalence(y))

Every symbol:

softmax_y(x)The model's raw confidence (0 to 1) that input x belongs to class y
prevalence(y)Fraction of training examples labeled as class y (between 0 and 1)
PAS_y(x)The prevalence-adjusted score—rarer classes get higher scores from the same raw confidence
sqrt(prevalence(y))The square root of prevalence acts as a leveler: dividing by a smaller number boosts the score more
A tiny worked example
Common class (cat): prevalence = 0.5 (half the training set). Raw softmax = 0.8. Adjusted score = 0.8 / sqrt(0.5) = 0.8 / 0.707 = 1.13.
Rare class (caracal): prevalence = 0.001 (one in a thousand). Raw softmax = 0.65. Adjusted score = 0.65 / sqrt(0.001) = 0.65 / 0.032 = 20.3.
Even though the caracal raw confidence (0.65) is lower than the cat (0.8), the adjusted score for caracal (20.3) is higher. The rare class gets a boost. Now a single threshold (say, 2.0) will include caracal predictions and filter out weak cat predictions.

The adjustment inverts class prevalence: rarer classes (small prevalence, small square root) get bigger boosts because dividing by a smaller number yields a larger quotient, and common classes get smaller boosts because dividing by a larger number yields a smaller quotient.

What can go wrong

What can go wrong

Calibration data required. The method needs a separate holdout dataset to find the right threshold. On very imbalanced data, holdout sets may have zero examples of ultra-rare classes, so coverage guarantees cannot be measured for those classes directly. The paper works around this by using the pattern of class frequencies from the training data as a proxy.
Still cannot guarantee per-class coverage on ultra-rare classes. If a class appears only once or twice in the calibration set, the method can achieve average (macro) coverage but not ironclad coverage for that specific class. The guarantee is mathematical at the population level, not per individual class.
Loses predictive power on extremely common classes. If one class dominates (99% of data), the adjustment favors rare classes, and prediction sets for common-class examples may grow slightly. This is the intended trade-off, but it is real.
Done right. The method is applied to a properly-trained base model (like ResNet-50), on a calibration set that has at least a handful of examples per class. Coverage is checked on a test set drawn from the same distribution (including the long-tailed class distribution).
What a runnable demo should prove

What a runnable demo should prove

Download Pl@ntNet-300K (or a simpler imbalanced dataset like CIFAR-10 artificially skewed). Train a ResNet-50 classifier. Split off a calibration set and a test set. Apply the paper's prevalence-adjusted softmax score and threshold calibration. On the test set, compute per-class coverage: for each class, what fraction of true examples of that class got included in the prediction set? Compare the per-class coverages on rare classes (bottom 10% by prevalence) versus common classes (top 10%). The demo succeeds if macro-coverage (the average) is close to 90%, and the per-class coverages do not vary wildly between rare and common classes. Also report the average prediction set size: it should be small enough to be useful (under 5 labels on a 1,000-class dataset) even while achieving high rare-class coverage.

Macro-coverage = (coverage of rare classes + coverage of common classes) / 2. Set fairness = std dev of per-class coverage. Avg set size = mean number of labels in each prediction set.

The impossible trade-off vanishes: you get both fair coverage across classes and small, practical prediction sets.
