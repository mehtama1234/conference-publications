Nonlinear Attention for All-in-One Image Restoration

Image restoration under mixed, unknown damage needs attention mechanisms that can reshape pixel values and track what kind of damage is happening.

Paper explainersAll themesComputer Vision

When a photo is blurry, noisy, underwater, or medical-scan dark, a restoration model must guess what broke it and fix it. Real images have mixed, unknown damage. This paper reveals two problems in widely-used attention (a mechanism that picks which part of an image matters most): the output is trapped as a blend of the input, and the model has no place to remember what kind of damage it is facing. The fix is minimal: add a nonlinear reshape step and a global memory slot.

Zero assumption version

All-in-one restoration is harder than single-task repair

Image damage comes in many flavors: blur (motion or camera shake), noise (random specks), rain, underwater haze, medical scanner artifacts. A single-task model learns to fix one kind. But real-world images have mixed, unknown damage, and a naive model trained on them splits its focus—it learns a mediocre blur fixer and a mediocre noise fixer, bad at both.

A beginner might try: make the model big enough to remember solutions to all damage types. But there is a hidden constraint. Restormer (a popular backbone) uses attention: a mechanism that looks at every pixel, scores which ones matter, and blends them together. The problem is the blend is trapped. Mathematically, attention's output is always a linear combination (a weighted average) of its inputs. That means the model cannot reshape pixel values in new ways—it can only shuffle and combine what was already there. It is like trying to build a car from a pile of wheels: you can rearrange, but you cannot make an engine.

The core bottleneck. Attention keeps outputs trapped as blends of inputs, and the model has no slot to encode what damage it is handling.

What the paper changes

What the paper changes

The paper upgrades attention's value path from a pure blend to a blend-then-reshape pipeline, and adds a global token (a learnable vector, just a list of numbers, that travels through the model) that carries damage-context information. Both changes are minimal and independent of the overall model architecture.

The hidden quantity

Degradation-awareness: the hidden quantity

measured quantity  =  degradation context signal

The hidden quantity is how much information the model has encoded about what kind of damage is in the image. Before this paper, attention had no explicit place to store this. The global spatial token is a learned slot that collects hints about blur, noise, underwater haze, or medical artifacts as the image is processed.

The paper measures degradation-awareness indirectly: it observes that models with the global token learn to separate images by damage type (using spectral statistics and separability measures, which are statistical tests of how cleanly the model's internal representations cluster by damage class).

Why it works

Why two small changes fix attention

Attention normally works like this: score each pixel's importance, then output a weighted average of pixel values. The problem: a weighted average of the input values can never produce a pixel value outside the range of the input. If input pixels range from 0 to 100, the output is stuck between 0 and 100. For restoration, this is crippling: the model cannot brighten a dark region beyond what was already there, and it cannot invent colors from scratch. Adding a nonlinear function (like a learned neural network layer) after the average breaks this cage. Now the output can be stretched, inverted, or remapped. The model can turn a dim average into bright output if the damage was darkness.

The second change is the global spatial token. This is a learnable vector (a list of numbers) that travels through all the attention layers. As the model processes the image, each layer can read and write to this token. It acts like a digital sticky note: the model writes hints about damage type (this looks like rain; this zone is underwater), and later layers read these hints to adjust their repair strategy. Without this slot, the model cannot remember—each layer sees pixels in isolation and must independently guess what damage to fix. With the global token, the model builds a consistent story about the image and fixes damage accordingly.

The nonlinear value transform equation

First in words:

output equals a learned nonlinear function applied to the weighted blend of input values, plus a projection of the global degradation token

Then the compact form:

v_out = f(sum_i alpha_i * v_i) + W_global * global_token

Every symbol:

alpha_iattention weight for input i (how much that pixel matters)
v_ipixel value i from the input
sum_i alpha_i * v_ithe standard linear blend (weighted average)
f(·)a learned nonlinear function (e.g., a small neural layer)
W_globala learned projection matrix
global_tokenthe learnable degradation-context vector
A tiny worked example
Input pixels near a noisy region: v1=50, v2=55, v3=52 (values around 50-55).
Attention weights: alpha1=0.3, alpha2=0.5, alpha3=0.2 (nearby pixels matter most).
Linear blend: 0.3*50 + 0.5*55 + 0.2*52 = 15 + 27.5 + 10.4 = 52.9 (average, trapped in input range).
Nonlinear function f(52.9) applies a learned sigmoid-like stretch: f(52.9) = 75 (noise is suppressed; output is brighter).
Global token signals noise: global_token=[0.8, 0.3] encodes 'this is noise damage'.
W_global adds a correction: W_global * [0.8, 0.3] = 10 (extra brightening for noise).
Final output: 75 + 10 = 85 (stronger restoration than the input range allowed).

The nonlinear function and global token together let the model reshape and contextualize the attention blend.

What can go wrong

What can go wrong

Nonlinear function must be learned carefully. If the nonlinear function is too complex, it may overfit to training damage types and fail on new, unseen damage. The paper keeps it minimal (a small learned layer), which forces the model to learn a general reshaping rule.
Global token requires stable attention. If attention weights are noisy or unstable, the global token receives conflicting signals about damage type and becomes confused. Stable attention is essential.
Mixed damage can confuse the degradation slot. If an image has both blur and rain, the global token must encode both hints. If the model was trained only on single-damage images, it may not learn to combine damage signals.
Done right: modest overhead. The nonlinear function is a small learned layer (negligible internal numbers to tune), and the global token is a single vector per image. The paper reports computational cost stays nearly flat.
What a runnable demo should prove

What a runnable demo should prove

Build a minimal all-in-one restoration model on a test dataset with four damage types: artificial blur, Gaussian noise, underwater color shift, and medical scanner bias. Train two versions: one with standard Restormer attention (linear value path only), one with the paper's nonlinear value transform and global token. Measure restoration quality (e.g., peak signal-to-noise ratio, PSNR) separately for each damage type. The demo should show that the modified model restores all four damage types better because it can reshape pixel values and remember damage context, and that the improvements are roughly balanced—not just better at one damage type and worse at another, which would suggest the global token is learning to favor one damage type over others.

restoration gain = (PSNR with nonlinear + global) - (PSNR baseline Restormer), measured per damage type

The demo must make clear that the nonlinear function and global token are not magic—they are minimal, interpretable additions that let attention reshape values and remember what damage type it is facing.
