CauchyNet: Compact and Data-Efficient Learning using Holomorphic Activation Functions

Use complex-valued reciprocal features to fit spike-like regression targets with far fewer hidden units, because those features already match the algebraic shape of sharp rational signals.

Paper explainersAll themesOther

Many regression problems are easy almost everywhere and hard at a few locations where the target changes very fast or nearly blows up. Standard real-valued multilayer perceptrons can fit that behavior, but they often need wide layers and many samples because their basis functions do not naturally resemble reciprocal singularities. CauchyNet starts from a different primitive. Each hidden unit is built from shifted reciprocal terms in the complex plane, meaning it uses numbers with real and imaginary parts together. The paper proves that finite sums of these Cauchy kernels, meaning reusable response shapes centered at chosen bias values, are dense in the space of continuous functions on compact sets, and then shows that the network can realize those sums with a small number of trainable parameters, meaning learned numerical settings.

Zero assumption version

Why spike-like regression is awkward for standard networks

A spike-like target has small values over much of the input domain and very large curvature near a few narrow regions. Near-singular rational functions and gap-filling tasks with missing coordinates have this pattern. A standard real-valued network can approximate them, but it often spreads the job across many hidden units because each unit contributes a smooth bump or kink rather than a reciprocal response centered near a pole.

That mismatch increases width and data demand. The model must combine many units to create one sharp local change, and it must place those units carefully near the hard region. This paper asks whether the hidden units should use a feature family that already contains reciprocal behavior, so the network does not need to synthesize that pattern indirectly.

The central move. Use hidden units built from products of shifted reciprocal factors, because reciprocal structure matches the targets that are hardest for ordinary smooth activation functions, which are the formulas that turn one hidden value into the next.

The algorithm as a flow

What it actually does

Represent inputs in a complex-valued hidden layer.

Allow hidden computations to use numbers with real and imaginary parts so reciprocal responses can be positioned flexibly around the input domain, because the extra degree of freedom lets the model place response centers more precisely.

Apply shifted reciprocal features.

Each hidden factor responds like one over a shifted input term, which creates sharp changes near selected locations without needing many separate bends.

Multiply factors inside a unit.

Products let one unit encode multivariate interactions, so narrow structures depending on several coordinates can be represented directly.

Linearly combine the hidden responses.

Output weights add the useful reciprocal responses together, which gives a compact approximation to the target function.

Train for the intended regime.

Use the model on regression tasks with sharp rational behavior or missing-input reconstruction, because those settings benefit most from reciprocal hidden features.

The hidden quantity

measured quantity  =  alignment between the hidden basis and the target singular structure

The hidden quantity is how well one hidden unit shape matches the hard local behavior of the target function. If the basis is poorly aligned, the network needs many units to approximate one narrow feature. If the basis is well aligned, one unit can carry most of that local structure.

CauchyNet raises that alignment by placing reciprocal centers near the difficult regions. The complex bias values decide where those centers sit, and the output weights decide how strongly each one contributes to the final prediction.

Why it works

Why reciprocal features can shrink the network

Approximation quality depends on the basis functions that the hidden layer makes available. If the target contains reciprocal or near-singular behavior, then a basis containing reciprocal factors can express that behavior with short expansions. A standard multilayer perceptron can still approximate the same function, but it must build the shape from many smooth pieces because its units do not carry reciprocal structure on their own.

The density theorem matters because it shows this is not only a hand-crafted niche model. Finite sums of Cauchy kernels can approximate any continuous target on a compact domain, which means the model keeps broad approximation power while specializing its hidden basis. The network is not trading universality for task fit. It is changing the route to the approximation.

The product form inside each unit matters in multiple dimensions because many hard targets are not sharp along only one coordinate. A product of reciprocal factors can place sensitivity along several coordinates at once, so the unit can represent a localized interaction pattern instead of one one-dimensional edge.

A tiny worked example
Suppose the target jumps sharply near x = 0.1 and is calm elsewhere.
A standard smooth unit centered far away contributes only a broad bend, so many such units must be combined to create a narrow spike near 0.1.
A reciprocal feature with center b = 0.1 responds strongly exactly near that location.
Two or three well-placed reciprocal centers can cover the hard region, while broad smooth units may need many more pieces to create the same local shape.

This expression is the model's core advantage: the unit itself carries the right local algebra for rational spikes.

What can go wrong

What can go wrong

The method is not aimed at every regression problem. On smooth or piecewise-affine targets, reciprocal features may offer little advantage because the target does not need singular structure and ordinary networks already match the function class well.
Optimization in the complex domain can be delicate. If reciprocal centers move too close to observed inputs, responses can become numerically large, so training may need careful initialization or regularization, which means adding constraints that discourage unstable parameter values, to keep those centers in useful regions.
Interpretation depends on center placement. A compact network only appears when the learned centers land near the important local features, because poorly placed reciprocal units lose the approximation advantage and behave like wasteful basis functions.
Done right. The method is strongest when the target really contains narrow rational structure, because then the hidden basis and the regression task are closely aligned.
What a runnable demo should prove

What a runnable demo should prove

Create three regression tasks: one smooth sinusoid, one rational target with a sharp pole-like region, and one missing-input reconstruction task. Train a standard multilayer perceptron and a compact CauchyNet with matched training budgets. Sweep hidden width and record test error.

The demo should show where the compactness claim comes from. CauchyNet should need fewer hidden units on the rational and gap-filling tasks because its units already carry reciprocal structure, while the advantage should narrow or disappear on the smooth task.
