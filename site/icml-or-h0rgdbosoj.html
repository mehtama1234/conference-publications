FRACTAL: Fractional recurrence for temporal sequences

A state space model that uses fractional math to remember both distant context and recent changes simultaneously, which existing models cannot do.

Paper explainersAll themesTime series and sequential

Most sequence models face a choice: focus on recent details or remember long-ago context. This paper introduces FRACTAL, which uses a fractional recurrence operator (a mathematically tuned way to forget) that lets a model do both at once. It works because the fractional math smoothly mixes sharp and slow updates, so the model captures both the recent spike and the distant baseline, yielding higher accuracy on long-sequence benchmarks.

The trade-off that stops sequence models

When a model reads a long sequence such as a stock price over months, it faces a hard choice. If it emphasizes recent prices, it catches sudden crashes but forgets what the baseline was six months ago. If it tries to remember everything equally, the signal from recent changes drowns in old noise.

Existing state space models (a family of models that compress history into a hidden state—a summary number or list encoding everything seen so far) use a fixed forgetting rule. Some update recent changes heavily but lose long-range context; others preserve long-range patterns but blur short-term spikes. No single rule does both.

The paper's answer in one sentence. Use a fractional forgetting rule that smoothly tunes how much the model cares about recent details versus distant patterns, and let the model learn this tuning from data.

The algorithm as a flow

What it actually does

Start with a memory summary

Incoming data updates a hidden state (a summary list encoding everything seen so far).

Apply fractional weighting

Old entries decay using a fractional power law, not integer steps. The decay is smooth, not sudden.

Tune the exponent

A single learned parameter controls whether to emphasize recent details (exponent near 1) or preserve long-range structure (exponent near 0.5).

Combine both scales

The state now contains both rapid local signals and slow global trends, mixed in one update.

Predict next value

Read off the mixed state to forecast the next price, weather, or sensor reading.

What the paper changes

What changes in the update rule

The core update step that refreshes the hidden state uses a fractional power operator instead of a polynomial. This single change lets the decay rate curve smoothly between two extremes rather than jump between them.

The hidden quantity is the spectrum—a measure of how much the model stores information about each timescale (fast changes, slow trends, very-slow patterns). Classic state space models have two local peaks: one for fast details, one for slow trends, but nothing in between. FRACTAL's fractional rule fills in the spectrum smoothly, preserving both scales without gaps.

The paper estimates this by analyzing the mathematical eigenvalues (the special numbers that define how fast the memory decays). With fractional exponents, these eigenvalues no longer cluster at just two points; they spread across a continuous range, encoding multi-scale structure.

Why it works

Why fractional decay solves the trade-off

Fractional operators interpolate smoothly between two behaviors. In ordinary calculus, powers are integers: first, second, and so on. But fractional calculus defines what a power of 0.7 or 0.5 means. Applied to forgetting, a fractional decay rule smoothly blends sharp local updates (which forget quickly) with slow global updates (which forget gradually).

Here is why this matters: when you read a stock price spike in fresh data, fractional decay says: update the very-recent part of the state sharply, but also gently nudge the month-ago part. This way the model captures both the spike and the context, neither drowning out the other. The learned exponent parameter then tunes where on this spectrum the model focuses, per task.

Math after the picture

The fractional recurrence equation

First in words:

State at time t equals the old state weakened by a fractional power, plus the new input scaled by how much the state can change.

Then the compact form:

h_t = A^alpha * h_{t-1} + B * x_t

Every symbol:

h_tthe hidden state (summary of all history) at time t
h_{t-1}the hidden state from the previous time step
A^alphaa scaling factor raised to a fractional power alpha; alpha is tuned during training and controls how fast the old state fades
alphaa learned parameter between 0 and 1; close to 1 means remember longer, close to 0 means sharp recent focus
Ba scaling factor that weighs the new input before adding it to the state
x_tthe new data arriving at time t
A tiny worked example: tracking a stock price over 4 days
Day 1: price 100. State starts at 0. New state is 1 to power 0.75 times 0 plus 1 times 100, which is 100.
Day 2: price 102 (small change). State is 0.75 to power 0.75 times 100 plus 1 times 102, roughly 79 plus 102 equals 181. Old memory fades to 79, new data added fully.
Day 3: price 101 (reversal). State is 0.75 to power 0.75 times 181 plus 1 times 101, roughly 143 plus 101 equals 244. Still carries day-1 memory at 79 divided by 100 of original.
Day 4: price 150 (spike). State is 0.75 to power 0.75 times 244 plus 1 times 150, roughly 193 plus 150 equals 343. State encodes: recent spike (150) plus residual context (193). If alpha were 0.3 (sharper), day-1 fades faster; if 0.9 (slower), day-1 stays strong. Model learns right alpha for the data.

The fractional exponent alpha controls whether the old state fades sharply (low alpha, focused on recent spikes) or slowly (high alpha, preserving long trends).

What can go wrong

What can go wrong

Exponent too close to 0. If alpha drops too low, the state updates too sharply and the model becomes myopic, forgetting patterns that emerge over days. Training must steer the exponent to stay in a reasonable range.
Exponent too close to 1. If alpha creeps toward 1, the old state barely fades, and new data has almost no effect. The model becomes stuck on initial conditions and cannot adapt to concept drift (when the underlying pattern changes over time).
Numerical precision on fractional powers. Computing a scaling factor to a fractional power like 0.7 is harder than integer powers; if computed carelessly, small rounding errors can cascade, especially on sequences longer than a few thousand steps.
Done right. The paper uses carefully chosen mathematical decompositions and structures to make fractional powers stable and fast to compute. Experiments show FRACTAL remains stable on sequences of 10,000 plus steps.
What a runnable demo should prove

What a runnable demo should prove

Build a toy sequence model (a small state space model with a learned fractional exponent) on a synthetic temporal task: predicting whether a slowly-drifting mean will reach a threshold in the next 50 steps, given noisy observations. The threshold-detection requires both recent noise filtering and awareness of the slow drift. Show that FRACTAL's learned exponent adapts: it learns to set alpha higher on datasets where drift is slow (preserving old context) and lower on datasets where noise-spikes are common (focusing on recent data). A model with a fixed exponent will fail at least one condition.

accuracy_on_drift_detection = (predictions_correct_threshold) / (total_predictions)

The fractional exponent adapts the model's timescale sensitivity per task—neither classic model can do this without retraining the entire architecture.
