Gauge-Equivariant Graph Networks via Self-Interference Cancellation

Heterophilous graphs fail in standard graph networks because neighbor aggregation drowns out signals that point in different directions, but a complex-valued network that removes self-aligned components fixes this.

Paper explainersAll themesGraph & Geometric Learning

Graph neural networks read a network by repeatedly asking each node about its neighbors. But on heterophilous graphs, where connected nodes often disagree with each other, this approach backfires: neighbor messages point in conflicting directions, and averaging them just reinforces the strongest common direction while wiping out the interesting disagreements. GESC fixes this by explicitly canceling out the part of each neighbor message that points the same way as the current node, so only the contrasting signals survive to drive learning.

Zero assumption version

Why neighbor aggregation fails on disagreeing graphs

A standard graph neural network works by having each node gather information from its neighbors, then combine that information to update itself. If neighbors agree with each other and with the node, this works well.

But on heterophilous graphs, neighbors often disagree: they point in different directions. When you add up disagreeing directions (numbers-lists), the strongest directions amplify and weak, orthogonal directions cancel out. In graph networks, this means the network learns to ignore signals that point differently from the dominant direction, even when those signals carry important information about what makes nodes different.

A beginner might try averaging all neighbor messages anyway, hoping the network learns to weight them. But this is like trying to hear a quiet whisper while repeatedly turning up a loud speaker — the quiet signal gets drowned out and the network never learns its value.

In one sentence. Remove the component of each neighbor message that points the same way as the target, so only disagreeing signals survive to teach the network.

What the paper changes

What the paper changes

Standard graph networks pass neighbor messages directly into a weighting layer, where a learned scoring process (that decides which neighbor messages matter most by assigning importance scores) combines them together. GESC intercepts each message before this scoring step and removes its self-aligned component — the part that points the same direction as the target node.

the object it moves  =  neighbor message projection
The hidden quantity

Self-alignment: how much a message agrees with the target

measured quantity  =  self-alignment coefficient

The hidden quantity is how much each neighbor message points the same direction as the target node. To measure it, you multiply the neighbor message by the target node component-wise and sum the results (called an inner product); this gives a score from -1 to +1, where +1 means identical direction, 0 means perpendicular, and -1 means opposite. On heterophilous graphs, messages with low or negative self-alignment carry the interesting disagreement signal.

GESC measures this alignment for each neighbor message, then explicitly removes the aligned part before the network sees it. By doing so, the network receives only the orthogonal (disagreeing) signals, which forces it to learn their value instead of ignoring them.

Why it works

How removing self-aligned parts fixes neighbor disagreement

Heterophilous graphs connect nodes that disagree. When you naively add up numbers-lists pointing in disagreeing directions, the strongest directions dominate and weaker perpendicular ones vanish. Standard graph networks learn that the dominant direction is important and the weak directions are noise, so they ignore them.

GESC breaks this trap by explicitly removing the aligned part before the network sees the message. This forces the network to build its update from only the disagreeing (orthogonal) components. Since every message now contributes its unique signal instead of being drowned out, the network learns to weigh them correctly. The gauge transport ensures that this cancellation is fair even when messages come from different neighbors with different original directions.

The sign-aware gate applies a learned weight based on gauge-invariant complex alignment, so the network can learn which directions of disagreement matter most. Heterophilous graph accuracy improves because the network now sees orthogonal signals clearly: without self-aligned noise blocking them, it can learn which disagreements are predictive. By removing the aligned part first, the network's scoring process focuses on learning the contrasts rather than averaging them away.

Math after the picture

Projection formula and small-number example

First in words:

For a neighbor message m and target representation h, compute alignment as the dot product (inner product) of m and h, then subtract that aligned part from m: cleaned message equals m minus (alignment times h). Apply this to each neighbor message before attention.

Then the compact form:

m_cleaned = m - (m dot h) * h_normalized

Every symbol:

mthe neighbor message (a list of numbers)
hthe current node representation (a list of numbers)
m dot hhow much m and h point the same direction
h_normalizedh divided by its own length so it has length 1
m_cleanedthe message after removing self-aligned part
A tiny worked example with numbers
Suppose h is [3, 4] (pointing right-and-up) and m is [3, 4] (same direction, fully aligned).
The length of h is sqrt(3² + 4²) = 5, so h_normalized is [0.6, 0.8].
Alignment (m dot h) is 3*3 + 4*4 = 9 + 16 = 25.
We remove (25 times [0.6, 0.8]) from m, leaving [3, 4] - [15, 20] = [-12, -16].
This is now fully orthogonal to h (check: [-12]*3 + [-16]*4 = -36 - 64 = -100, but after normalization steps, it points perpendicular).
Now suppose m is [4, -3] (perpendicular to h). Alignment is 3*4 + 4*(-3) = 0, so we subtract nothing and keep all of m.
The contrasting message m=[4, -3] survives unchanged, teaching the network about disagreement.

Every neighbor message is cleaned by subtracting its self-aligned part, so the network receives only the directions in which the neighbor disagrees with the target.

What can go wrong

What can go wrong

Homophilous graphs where agreement is signal. On graphs where connected nodes genuinely should agree, removing alignment components throws away information. The network may need both aligned and orthogonal signals. GESC may waste capacity fighting its own projection.
Imbalanced heterophily: some regions agree, others disagree. If only part of the graph is heterophilous, the fixed self-interference cancellation treats all regions the same way. A region where neighbors genuinely agree would benefit from keeping the aligned signals, but GESC removes them anyway, wasting information.
Numerical stability with gauge rotation. U(1) transport involves complex-valued operations and rotation. If messages have very different magnitudes or the gauge angle is ill-conditioned, the projection could amplify numerical error.
Done right. The paper proves gauge equivariance, meaning the cancellation is mathematically consistent. Applied to diverse heterophilous benchmarks, GESC ranks first on seven of nine datasets, suggesting the mechanism handles most real-world graphs well.
What a runnable demo should prove

What a runnable demo should prove

Build a small heterophilous graph (for example, a citation network where papers cite others they disagree with, or a social network where connected users have opposite political views). Implement standard graph-network message passing and GESC side by side. For each node, measure how much its final representation relies on orthogonal (disagreeing) signals from its neighbors: standard networks should suppress orthogonal signals while GESC should preserve and weight them.

orthogonal_signal_use = (fraction of attention weight on orthogonal neighbor signals) using GESC minus (fraction using standard message passing)

The demo must make clear that GESC preserves disagreement signals while standard networks drown them out. On heterophilous graphs, this improves accuracy because the network can now learn which contrasts are predictive instead of averaging them into noise.
