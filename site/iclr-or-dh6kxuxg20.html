Knowledge Distillation for LLMs through Residual Learning

Instead of copying the teacher model's answers, a student model learns to spot where the teacher goes wrong and fix it.

Paper explainersAll themesOther

When you shrink a large language model down to fit on a phone, the smaller model loses capability. A clever trick is to have the smaller model learn by watching the bigger one, but the bigger model can be wrong too. This paper flips the game: the student does not copy the teacher's mistakes, but learns to recognize and correct them, improving beyond what the teacher can do.

Zero assumption version

The copycat trap

A large language model is accurate but too slow and heavy to run on phones. You want to train a smaller model to answer like the big one. A student model watches the teacher and copies how it answers.

But here is the trap: the teacher is not perfect. If the teacher gets a physics question wrong, the student learns that wrong answer too. When the student then faces a new, slightly different question, it does not know how to adapt, because it learned to mimic the teacher's mistake, not to understand the right concept.

The copycat trap. Standard distillation copies the teacher’s knowledge, including its errors, which binds the student to the teacher’s mistakes instead of helping it generalize beyond them.

The algorithm as a flow

What it actually does

Compress teacher knowledge

Run teacher predictions through a learned compressor to squeeze them into simpler signals.

Train student on differences

Student learns to predict the gap between teacher and correct answer, not the teacher itself.

Combine with ground truth

Student also learns from real correct answers so it is not stuck mimicking the teacher.

Handle expert mixtures

If teacher has multiple experts, blend their outputs smartly before sending to student.

Cross-vocabulary bridges

When teacher and student use different word systems, a learnable bridge maps words between them.

What the paper changes

What the paper changes

Standard distillation trains the student to copy the teacher’s output. This paper changes the learning target: instead, the student learns the residual, which is the difference between what the teacher produces and what is actually correct.

the object it moves  =  The learning target
The hidden quantity

The residual: teacher gap minus truth

measured quantity  =  Teacher-to-ground-truth gap

The paper measures a single hidden quantity: how far off is the teacher from the correct answer. This is the difference between the teacher’s prediction and the ground-truth label, in the compressed (simplified) representation space.

The student does not learn the teacher’s prediction. Instead, it learns to predict this gap. Because the gap is smaller and often more regular than the teacher’s full prediction, the student can learn it more cleanly and with less noise.

Why it works

Why residuals unlock better generalization

Standard distillation trains the student to match the teacher everywhere, which amplifies the teacher’s weak spots. If the teacher is wrong about a concept, the student locks in that wrong understanding. The student then fails on new examples that expose the gap.

Residual learning flips the incentive. The student only learns where the teacher disagrees with ground truth. On correct predictions, the gap is zero, so there is nothing to learn. On wrong predictions, the student learns to produce the correction. Because the student is also trained directly on ground-truth labels, it learns the right concepts independently too. The result: the student does not get trapped by the teacher’s errors.

Math after the picture

The residual learning equation

First in words:

Student loss equals weight times (student compressed output minus teacher compressed output) squared, plus standard supervised loss on ground-truth labels.

Then the compact form:

L = alpha * ||S_proj(x) - (T_proj(x) - y)||^2 + beta * CE(S(x), y)

Every symbol:

S_proj(x)student model's compressed representation for input x
T_proj(x)teacher model's compressed representation for input x
ycorrect ground-truth label or representation
S(x)student model's final prediction
CE(S(x), y)cross-entropy loss: standard classification loss between student output and true label
alphaweight on residual loss
betaweight on supervised loss
A tiny worked example
Teacher predicts class prob 0.6, ground truth is 1.0, compressed teacher output is 2.0, compressed truth is 4.0.
Residual target = 4.0 - 2.0 = 2.0 (student must learn to add 2.0 to teacher to match ground truth).
Student predicts compressed residual as 1.8, error = (1.8 - 2.0)^2 = 0.04, scaled by alpha = 0.5 gives loss 0.02.
Meanwhile, supervised term learns from real labels, beta * loss_supervised ensures student does not drift from truth.
Result: student learns the teacher’s gap, not its errors.

The residual loss teaches the student to recognize and correct the teacher’s mistakes, while supervised loss anchors the student to ground truth so it is not dependent on the teacher’s knowledge.

What can go wrong

What can go wrong

Bad compressor ruins the residuals. If the compressor is poorly trained, the compressed representations lose essential information. Then the residual becomes garbage, and the student learns nothing useful.
Teacher and student too different. If teacher and student architectures are very different, even the correct residual in one representation space may not transfer to the other. The alignment breaks.
Misaligned word systems. When teacher and student use different word systems, the connection between words breaks. If alignment is wrong, the residual is computed between mismatched concepts and misleads the student.
Done right: learn both residuals and ground truth. Combine residual loss with direct supervision so the student is doubly anchored to correctness, not just the teacher.
What a runnable demo should prove

What a runnable demo should prove

Build a simple classification task (e.g., digit or image recognition). Train a teacher model on it, let it make mistakes on a held-out set. Train a student on (1) standard distillation and (2) residual learning with ground truth. Test both on new data. The student trained with residuals should outperform standard distillation, especially on examples where the teacher was wrong, because it learned to spot and fix those errors instead of copying them.

Gap freedom = (residual student accuracy) - (standard distillation accuracy)

The residual-trained student must show higher accuracy than the distillation-only baseline, particularly when the teacher prediction diverges from ground truth, because the residual student learned what to add or subtract to correct the teacher, while the standard student locked in the teacher's mistake.
