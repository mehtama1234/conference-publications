FlowMAP: Flow Matching for Generalizable Agent Planning

Plan by learning how the whole distribution of promising states should move toward good task outcomes, then co-train the acting policy so that its behavior follows that planned movement.

Paper explainersAll themesAgents & Tool Use

Agent planning often breaks when the environment shifts. A planner may work in one reward pattern, one transition rule, or one observation style and then fail when any of those change. FlowMAP studies that failure at the level of the full state population. Instead of planning one path at a time, it learns a continuous transport rule that moves a broad state population toward better task-conditioned regions, then co-trains a policy so that actual interaction follows the same direction.

Zero assumption version

Why planners fail under shifting conditions

Many planning methods assume that the world seen during training is close to the world seen at test time. That assumption fails in agent settings where the observations, transition behavior, or objectives drift over time. A plan that looks good under one set of dynamics can push the agent into weak regions once the environment changes.

The deeper issue is that ordinary planning often focuses on a few candidate trajectories. When the environment shifts, those narrow plans accumulate error because they do not model how the full set of reachable states should move. The paper argues that planning should guide an entire state population toward high-value regions, not only choose one path.

The paper's move. Learn a planning-time transport field over states, then train the acting policy to follow that transport so that planning remains useful under shifts.

The algorithm as a flow

What it actually does

Represent the current state population

Treat the agent's possible states as a population rather than as one exact point.

Learn a transport field

Train a continuous movement rule that says how each part of that population should shift toward better task-conditioned states by following the transport direction that leads to higher-value regions.

Bias the field with value information

Weight the movement toward regions that promise stronger long-term return so that the transport does not drift into merely reachable but weak areas.

Co-train the acting policy

Update the policy so that its real interaction causes the state population to move in the same direction as the planning field.

Plan under shifts

Use the learned transport rule at planning time because a state-population guide is less brittle than one narrow trajectory.

What the paper changes

What the paper changes

The paper changes planning from path selection to state-population transport. Instead of asking only which single route looks best, it asks how the whole set of plausible agent states should move toward regions with higher value under the current task.

the object it moves  =  the planning target from one path to a moving state population
The hidden quantity

The hidden quantity

measured quantity  =  whether the state population is moving toward better task regions

A planner can produce a good-looking action sequence while the actual interaction still drifts into poor regions. The hidden quantity is the direction of the whole state distribution: is the agent population moving toward high-value parts of the task space or away from them?

FlowMAP tries to expose that quantity by learning a transport field directly. Value information matters because not every reachable region is useful. Policy co-training matters because a transport rule is only valuable if the real policy can induce a similar shift during interaction.

Why it works

Why this works

A single planned trajectory can fail badly after a shift because every small prediction error compounds along the route. Distribution transport is less fragile because it plans a direction for a broader set of states. If part of the population moves differently than expected, the plan can still steer the mass toward a useful region rather than losing everything on one route.

Value-guided transport is the second key piece. Pure transport could move states smoothly without moving them toward success. FlowMAP attaches value information so that transport favors regions that promise stronger return. That matters because the planner should not only preserve continuity; it should preserve task quality.

Policy co-training ties planning to action. A separate planner can produce beautiful transport maps that the acting policy never realizes. Joint training reduces that gap because the policy is updated to create state transitions that match the planned transport. The planner becomes more deployable by construction because acting and planning learn the same movement pattern.

Math after the picture

The planning objective

First in words:

Learn a movement field whose transport both matches the desired future state distribution and favors regions with high long-term value, while also training the policy to induce the same movement during interaction.

Then the compact form:

planning_objective = transport_match + alpha * value_guidance + beta * policy_alignment

Every symbol:

planning_objectivethe total learning goal for the planner-policy system
transport_matchhow well the learned movement field carries the current state distribution toward the target distribution
value_guidancehow strongly the transport prefers high-return regions
policy_alignmenthow closely policy-driven interaction matches the planned movement
alphaweight on the value-guidance part
betaweight on the policy-alignment part
A tiny worked example
Suppose an agent can start from three nearby states after a small environment shift.
A narrow planner chooses one route that scores well in the old setting but fails from two of the three starts.
FlowMAP learns a movement field that pushes all three starts toward one higher-value region that remains useful after the shift.
If transport match is 6, value guidance is 3, policy alignment is 2, and alpha = beta = 1, then the total objective score is 11.
Training increases that score by improving both where the distribution moves and whether the real policy can produce the same movement.

The actual paper uses a richer continuous-time objective, but this summary captures the point that planning quality depends on transport quality, value direction, and policy agreement together.

What can go wrong

What can go wrong

Bad value estimates misdirect transport. If the value signal is wrong, the transport field may consistently push the state population toward regions that look promising in training but are weak in reality.
Policy alignment may lag behind planner quality. The planner can learn a useful transport rule faster than the acting policy can realize it, so performance may still suffer because real transitions keep missing the planned movement until policy training catches up.
Very large shifts can invalidate the learned transport. If the new environment changes the reachable state space too drastically, a transport rule learned earlier may no longer map to the regions that matter.
Done right. The method is strongest when the planner can estimate useful value direction and when the acting policy is trained closely enough to realize the same movement under shifted conditions.
What a runnable demo should prove

What a runnable demo should prove

Build a small grid or navigation world where the observation pattern, transition noise, or goal location changes between training and test. Compare a narrow trajectory planner against a FlowMAP-style planner that learns transport over the state population and co-trains the policy.

Evaluate both systems before and after the shift. Log not only final return but also where the state population moves over time, because the paper's claim is about distribution movement rather than about one handpicked route.

The demo should show that the stronger planner is the one whose policy keeps moving the population toward useful regions after the world changes because that movement preserves value under the shift.
