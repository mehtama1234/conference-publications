Connecting neural networks and classical algorithms

Modern approaches unify neural learning with classical optimization methods (mirror descent, proximal, Newton). How do you combine their strengths for speed and reliability?

What this is

Machine learning researchers use two toolkits: neural networks, which are fast at learning patterns from data, and classical optimization algorithms (like mirror descent, proximal methods, Newton's method), which have strong mathematical guarantees about when they work. Neural networks work but nobody fully understands why, so you cannot predict when they will fail. Classical algorithms are slower but come with proofs about when they succeed, so you trust them. A modern question is: can you combine them to get both speed and understanding? Take the speed and adaptability of neural learning and the guaranteed convergence of classical methods?

The challenge is that these two worlds use different languages. Classical methods assume you have a smooth loss function and can compute exact gradients. Neural networks work even when gradients are noisy or approximate. Classical theory gives convergence rates—the algorithm reaches a good solution after a certain number of steps. Neural networks have no such guarantees but work in practice. Bridging them requires translating between these languages and finding abstractions that both can use.

Papers take several paths. Some implement classical algorithms using neural networks as building blocks: use a network to learn a descent direction, then step along it the way classical methods prescribe, so you get the neural network's speed and the classical algorithm's proof. Others add structure from classical optimization into neural architectures: design layers that implement mirror descent or proximal operations, so the network inherits the mathematical properties of classical algorithms and you understand how it works. Some papers analyze neural networks using tools from classical theory: prove that a particular network architecture converges at the same rate a classical algorithm would, assuming certain conditions hold. Others use classical preconditioning (scaling the problem so gradients are more uniform) to speed up neural training because uniform gradients converge faster. A few learn to optimize: train a neural network that takes a problem as input and outputs good hyperparameters (learning rate, momentum, etc.) for that problem, so you get speed from learning and adaptation. The theme is unification: seeing neural learning and classical optimization as two instances of a broader framework.

How the work breaks down

The papers address five core questions about connecting neural learning and classical optimization. How do you adapt classical methods to modern problem classes and keep convergence proofs? How do you build classical algorithms inside neural layers to inherit guarantees? How do you add hard constraints to neural training? How do you design online learning algorithms with low regret? How do you apply algorithm structure to specific domains?

Adapting classical methods to modern problem classes

Classical optimization theory gives us convergence rates—guarantees about how quickly an algorithm reaches a good solution. But the classical algorithms were designed for smooth, well-behaved loss functions. Real modern problems like extreme classification (predicting rare events) and AUC maximization (ranking problems) have loss functions that don't fit these assumptions. The challenge is: can we prove convergence for these harder problem classes?

A method for Compositional Entropic Risk Minimization (“A Geometry-Aware Efficient Algorithm for Compositional”) proves that a specially designed algorithm converges at the classical rate even for these difficult composite losses that combine multiple objectives. It understands the structure of the problem—how the losses connect and interact—and uses that structure to take smarter steps. It works on extreme classification and risk-minimization problems that classical methods would struggle with. DADA: Dual Averaging with Distance Adaptation (“DADA: Dual Averaging with Distance Adaptation”) goes further: it works for multiple problem classes at once—smooth functions, Lipschitz functions, Hölder-smooth functions, and quasi-self-concordant functions—without needing to set any tuning knobs yourself. Instead of one algorithm per problem class, you get one algorithm that automatically switches between strategies.

Neural layers that implement classical optimization

One way to unify neural networks and classical methods is to build neural layers that compute what classical optimization would compute. Linear programming solvers find the best choice subject to linear constraints; this is a well-studied classical problem with fast algorithms. The idea: what if a neural network layer could solve a linear program internally, as part of the network's computation? Then the network would inherit the solver's guarantees about finding the right answer.

Design Linear Constrained Neural Layers with Implicit Convex Optimization (“Design Linear Constrained Neural Layers with”) creates a neural layer that solves constrained optimization problems inside. It derives exact mathematical formulas for the layer's output—the solution to a convex problem—rather than approximating. This lets you use the layer in graph matching (finding corresponding nodes between two graphs) and portfolio allocation (choosing which assets to buy) while knowing the answer is mathematically optimal. Lightweight and Interpretable Transformer via Unrolling of Mixed Graph Algorithms for Traffic Forecast (“Lightweight and Interpretable Transformer via Unrolling”) takes a different classical technique—graph algorithms for flow and routing—and unrolls them into transformer layers. The result: a network that forecasts traffic with far fewer learnable weights than standard transformers because it bakes in the graph structure that traffic inherently has, so it doesn't need to discover what's already known from classical algorithms.

Constraints and penalties in neural training

Real-world problems often have hard constraints: you cannot recommend loans to people who fail credit checks, or send traffic through roads that are under construction. Handling constraints in neural networks is difficult because training works by taking small weight-adjustment steps, and small steps might violate hard constraints. Classical optimization has two weapons: penalty methods (add a large cost if you violate the constraint) and proximal methods (solve a constrained sub-problem at each step). Can neural networks use these?

MoSSP: A Momentum-Based Single-Loop Stochastic Penalty Method for Nonconvex Constrained DC-regularized Optimization (“MoSSP: A Momentum-Based Single-Loop Stochastic Penalty”) proves that a penalty-based approach converges to a KKT point—the mathematical definition of a constrained optimum—even when the loss is nonconvex (has multiple local minima). It uses momentum, a neural network speedup trick, to accelerate the penalty method. A Penalty Approach For Differentiation Through Black-box Quadratic Programming Solvers (“A Penalty Approach For Differentiation Through”) takes this further: it makes quadratic program solvers (classical algorithms) trainable via weight updates. You can now embed a solver as a layer in a neural network and train the whole network end-to-end. DisjunctiveNet: Neural Symbolic Learning via Differentiable Convexified Optimization Layers (“DisjunctiveNet: Neural Symbolic Learning via Differentiable”) combines both: it uses differentiable convex optimization to enforce hard logical constraints (disjunctions: this OR that must be true) inside a neural network. The network learns to make predictions that automatically satisfy the constraints, not by penalizing violations but by design.

Online learning with regret bounds

Online learning is a setting where an algorithm sees data one example at a time and must make decisions without knowing the future. An adversary can give you the worst data in the worst order. Classical theory measures failure by regret: how much worse did you do than the best fixed strategy in hindsight? The challenge is achieving low regret while adapting to the problem—some loss functions are smooth (small changes to the input cause small changes to the output), others are not. Classical methods have different convergence rates for different problem classes.

A Linearly Convergent Proximal Subgradient Algorithm for Sparse Portfolio Optimization with Transaction Cost (“A Linearly Convergent Proximal Subgradient Algorithm”) proves linear convergence—the algorithm reaches the optimum exponentially fast—using a property called the Kurdyka-Łojasiewicz property, which is a classical idea applied to portfolio problems with transaction costs. CLASP: Online learning algorithms for Convex Losses And Squared Penalties (“CLASP: Online learning algorithms for Convex”) achieves logarithmic regret for strongly convex problems, the best possible rate, but adds a squared penalty term that enforces constraints online. Discounted Online Convex Optimization: Uniform Regret Across a Continuous Interval (“Discounted Online Convex Optimization: Uniform Regret”) adapts to an unknown discount factor—the future doesn't matter equally to the present—by running multiple experts with different assumptions and combining their decisions. Logarithmic Switching Regret for Online Convex Optimization (“Logarithmic Switching Regret for Online Convex”) extends logarithmic regret to a harder setting where you can switch strategies multiple times; it works for exponentially concave and strongly convex losses. Optimal Anytime Algorithms for Online Convex Optimization with Adversarial Constraints (“Optimal Anytime Algorithms for Online Convex”) adds constraints to the online setting: at each step you must satisfy a constraint chosen adversarially, and you want to minimize regret and constraint violation together. It achieves regret that grows by the square root of time for all times, not just at the end.

Algorithm unrolling and specialized applications

Beyond general optimization, papers show how to apply classical algorithm ideas to specific domains. EEG (brain electrical signals) classification, nonlinear system modeling, and image reconstruction all have domain-specific classical structure. The idea is to unfold classical algorithms step-by-step as neural network layers, so the network solves a domain problem using algorithm-inspired architecture.

Lightweight Transformer for EEG Classification via Balanced Signed Graph Algorithm Unrolling (“Lightweight Transformer for EEG Classification via”) unrolls a graph algorithm—the balanced signed graph method for partitioning data—into transformer layers. Brain signals naturally partition into regions, so baking this in reduces parameters dramatically compared to standard transformers, which means faster training and less data needed. QPKO: Differentiable QP-Embedded Deep Koopman Framework for Modeling Nonlinear Systems (“QPKO: Differentiable QP-Embedded Deep Koopman Framework”) embeds quadratic programming—a classical solver—into a Koopman framework, which is a classical technique for analyzing nonlinear dynamics. The result is a network that models how systems evolve over time with better accuracy because it respects what classical theory knows about system dynamics, and faster training because it doesn't have to learn patterns that the classical technique already explains. Trainable Nonexpansive Denoisers for Contractive Image Reconstruction (“Trainable Nonexpansive Denoisers for Contractive Image”) creates image reconstruction layers that are provably contractive—each step brings you closer to the true image by mathematical design. This comes from classical proximal operator theory and guarantees the algorithm converges globally, not just to a local bad solution, because the structure forces it to improve at every step.
