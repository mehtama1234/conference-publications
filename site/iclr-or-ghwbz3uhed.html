LiveResearchBench: Benchmarking Deep Research Systems

A real-world test suite that measures whether AI agents can do deep research by gathering citations from live websites and writing trustworthy reports.

Paper explainersAll themesDatasets & Benchmarks & Evaluation

AI systems can now search the web and write reports, but we have no rigorous way to grade whether they are actually trustworthy. This paper builds LiveResearchBench, a collection of 100 real research questions that require agents to dig through hundreds of websites and cite every claim they make. It introduces DeepEval, a scoring system that checks whether a report's facts are traceable back to real sources. The benchmark reveals which systems excel and which ones fabricate.

Zero assumption version

Why we cannot yet trust AI to do deep research

Imagine asking an AI to research a topic: where should grocery stores go in your town? What is the latest ruling on a new tax? What is the state of research in photosynthesis? The AI reads the web and writes a long report. But how do you know if it is true? If the AI just makes up facts, you have no way to catch it unless you read every website yourself. The catch: you wanted the AI to do the reading for you.

Current benchmarks do not measure this real problem. They either test narrow domains (like only science questions), pose ambiguous queries (so two researchers would answer differently and disagree on what is correct), or assume the AI can find all answers in its training data, not live websites. None of this matches what actually happens when you ask for deep research in the real world.

The problem in one sentence. We have no rigorous way to measure whether an AI agent can research a real question across live websites and cite every claim truthfully.

The algorithm as a flow

What it actually does

Define the benchmark

Collect 100 real research questions from daily life, business, and academia that require live information.

Run the agents

Ask different AI systems to research each question and produce a long-form report with citations.

Verify citations

For each claim in the report, check whether it points to a real source and whether the source actually says that.

Measure report quality

Score the report on coverage (did it find enough information?), accuracy (are the facts right?), and traceability (can readers trust each claim?).

Rank the systems

Compare which agents researched well, which hallucinated, and what methods work best.

What the paper changes

The one thing the paper measures

The paper does not change how agents work. Instead, it measures one thing: whether an agent's report, when you follow its citations, actually holds up. The measurement system itself is the innovation.

the object it moves  =  citation-grounded report quality
The hidden quantity

Citation traceability: the hidden quantity

measured quantity  =  Citation traceability (how often a claim's source backs it up)

Citation traceability is a measure of trustworthiness: if I read claim X in the report and click its citation, does the source actually support that claim? It is not just whether a link exists; it is whether following the link finds the real evidence for what was stated. An agent might cite a website, but the actual sentence on that website could say something different or even contradict the claim. Traceability asks: could an honest reader verify this?

The paper estimates traceability by hand: human reviewers read each cited claim, jump to the source, and mark whether the source truly backs it up. They use a rubric so that two reviewers grading the same report would agree on the score.

Why it works

Why measuring deep research correctly matters

The benchmark works because it aligns the test with reality. Real research questions are ambiguous until you look them up (you do not know the answer in advance), they require fresh information (your training data is stale), and success is unambiguous once you check the sources. By curating 100 real tasks and defining citation traceability as the goal, the benchmark forces agents to actually research, not guess.

DeepEval works because it breaks grading into layers: first, did the agent find sources at all? Second, do those sources match the claims? Third, is the overall report coherent and thorough? This multi-level scoring reveals which systems are genuinely researching and which are pattern-matching or fabricating. An agent might get lucky on one claim but fail consistently when forced to cite everything.

Math after the picture

Scoring a research report

First in words:

trustworthiness = (citations verified / total claims) times (average citation accuracy) times (overall report coherence), each scaled 0 to 100

Then the compact form:

trust_score = (v / c) * acc * coh where v = claims with verified citations c = total claims acc = average accuracy of those claims (0-100) coh = report coherence (0-100)

Every symbol:

vnumber of claims where the cited source actually supports the claim
ctotal number of factual claims in the report
accaverage accuracy: how closely cited sources match the stated claims (0=none match, 100=all match perfectly)
cohreport coherence: does the report read as a unified argument, or is it scattered? (0=rambling, 100=well-organized)
A tiny worked example
Report A: 30 claims, 25 have citations, of those 20 are accurate (80% accuracy), report coherence is 85%.
trust_score_A = (25/30) * 80 * 85 / 10000 = 0.833 * 80 * 0.85 = 56.6 out of 100
Report B: 20 claims, 18 have citations, of those 18 all are accurate (100% accuracy), report coherence is 90%.
trust_score_B = (18/20) * 100 * 90 / 10000 = 0.9 * 100 * 0.9 = 81 out of 100
Report B scores higher because each verified claim is accurate and the report is well-organized, even though it has fewer claims.

A report earns a high trustworthiness score only if the agent cited its sources, those sources actually back the claims, and the overall report is coherent and complete.

What can go wrong

What can go wrong

Hallucinated citations. An agent cites a website that does not exist or a quote it never read. This happens when the agent predicts what sources should exist rather than checking what it actually found. The benchmark catches this: the evaluator tries to verify the citation and finds nothing.
Outdated information. The agent's training data is months old, but the question requires current information (e.g., latest stock price, new court ruling). The agent answers from memory, not live search, and the answer is wrong. The benchmark requires live web search, so this fails immediately.
Over-inference from sources. A website says event X happened in June. The agent claims X happened because of reason Y, even though the website never mentions Y. The citation appears to exist but does not actually support the claim. The evaluator catches this by reading both the claim and the source carefully.
Done right: multi-step verification. The agent searches, finds a source, reads it carefully, and only writes the claim if the source says it. Before submitting, another agent re-checks: does this source really say this? This redundancy kills hallucination and over-inference, raising trustworthiness scores by 20-30 points.
What a runnable demo should prove

What a runnable demo should prove

Build a small research task: ask an AI to find current information on one real question (e.g., a recent news event, a policy change, a scientific finding). Have the agent produce a report with citations. Then, before checking any source yourself, predict: which claims will be true when you verify them? Which citations will be hallucinated? Now check each source. How many of your predictions were wrong? This shows you the gap between what the agent claims and what is actually true—the exact gap LiveResearchBench measures at scale.

citation_accuracy = (claims_with_verified_sources / total_claims) * (average_match_score), where match_score = 1 if source fully supports claim, 0.5 if partial, 0 if contradicts

The demo should make it obvious: asking an agent to cite sources and then checking those sources reveals whether the agent is researching or confabulating.
