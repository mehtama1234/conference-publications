Beyond ReLU: Bifurcation, Oversmoothing, and Topological Priors

Deep graph networks fail because node features collapse to identical values, but a math trick using bouncy activation functions can force them to stay different.

Paper explainersAll themesGraph & Geometric Learning

Graph neural networks learn by passing messages between connected nodes, iterating to build richer representations. But deep networks break: after many rounds, all node features become nearly identical, like everyone whispering the same phrase. This paper uses bifurcation theory, a tool from physics for understanding when stable states suddenly become unstable, to prove that swapping ReLU (a rule that keeps positive numbers unchanged and flips negatives to zero) for a bouncy one can mathematically prevent that collapse and keep features distinct.

Zero assumption version

Why deep graph networks break

A graph neural network is a model that takes a graph (nodes connected by edges) and learns a vector (just a list of numbers) for each node. It does this by iterating: each node reads its neighbors' vectors, averages or mixes them, applies an activation function (a simple nonlinear rule), and updates its own vector. This happens layer by layer, usually 2-10 times.

The problem is depth. After 20 or 50 layers, all node vectors converge to nearly the same values, even when the original graph has very different structure. This is called oversmoothing. A node in a star hub ends up with almost the same vector as a node at the edge of the network. The model has lost the ability to distinguish different parts of the graph, so predictions fail.

A beginner's first try: just use deeper networks. But experiments show the problem gets worse the deeper you go. Another try: add skip connections (let each node remember its previous vector). This helps a little, because it lets nodes hold onto distinct information from earlier layers, but it does not stop the averaging from pulling everything toward the center—only slows it down.

The core trap. When a graph network learns by smoothing vectors between neighbors, the stable resting state is for all vectors to become identical. Depth pushes the network toward that state.

What the paper changes

The one thing that changes

The paper replaces ReLU, the most common activation function in graph networks, with a non-monotone (bouncy) activation function that reverses direction instead of staying flat. This single swap is the technical move.

the object it moves  =  activation function
The hidden quantity

Stability of the homogeneous state

measured quantity  =  distance from the collapse point

The paper measures a quantity called the stability eigenvalue (how much the homogeneous state tries to pull nearby vectors back toward itself). In standard graph networks with ReLU, this eigenvalue is large and positive, making homogeneity a strong attractor. The paper's theory predicts exactly how changing the activation flips this eigenvalue, destabilizing collapse.

The hidden quantity is really this: given a fully converged node vector (where all nodes are identical), if you perturb one node slightly, does the network pull it back or push it away? ReLU always pulls back. A bouncy activation can push away, breaking the trap.

Why it works

Why the bouncy activation stops collapse

In each layer of a graph network, each node averages its neighbors and applies an activation. With ReLU (flat for negative inputs, linear for positive), the averaging dominates: neighbors pull the node toward the group average. Deep networks iterate this, so all vectors converge to the center.

A non-monotone activation (one that bends both up and down) has a different slope in different regions. The mathematics of bifurcation theory says: when the activation slope changes sign, the stable fixed point (the attractor) becomes unstable, and new stable points appear nearby. This means the network can no longer hold all vectors at the same value. It must split into multiple stable patterns, each locally stable but distinct from each other.

The paper proves this mathematically using Lyapunov-Schmidt reduction, a technique that extracts the dominant behavior near a fixed point. The theory even predicts the amplitude (size) of the emerging patterns, so you can initialize the network to exploit this effect immediately.

The bifurcation equation

First in words:

The stability of the homogeneous fixed point depends on the slope of the activation function. When we replace the slope (a real number lambda) with one that changes from positive to negative, the eigenvalue governing convergence flips sign. The paper tracks this using the tangent vector equation for the iteration map.

Then the compact form:

f_new(x) - f_old(x) where f has slope that reverses: df/dx(x_0) > 0 for ReLU, df/dx(x_0) < 0 for bouncy activation at the fixed point x_0.

Every symbol:

xa node feature vector
f_old(x)ReLU applied to x
f_new(x)the new non-monotone activation applied to x
x_0the homogeneous fixed point (all nodes identical)
df/dxthe slope of the activation (its derivative)
A tiny numerical example
Suppose all node vectors converge to 0.5 (the homogeneous fixed point). At that point, ReLU has slope 1. At 0.5, a bouncy activation has slope -0.3.
The iteration eigenvalue with ReLU: 1 (positive, stable). With bouncy: -0.3 (negative, unstable).
A negative eigenvalue means nearby perturbations grow instead of shrinking, so the fixed point repels vectors. The network must find new stable patterns away from 0.5.

When the activation slope flips from positive to negative, the network's tendency to collapse reverses. Instead, it must split into distinct stable patterns.

What can go wrong

What can go wrong

Choosing the wrong bouncy activation. Not all non-monotone functions trigger a bifurcation at the scale you need. The paper derives which shape works; using a random bouncy function will not.
Ignoring the predicted amplitude scale. The theory predicts a specific size for emergent patterns. If you initialize too large or too small, the network may not converge to the stable patterns and may collapse anyway.
Applying to graphs where structure is already clear. On graphs where few layers suffice, ReLU works fine. The bifurcation fix shines in deep networks where oversmoothing would normally kill performance.
Done right. Use the paper's prescribed activation family, follow the derived initialization scheme, and apply to deep graph networks on large graphs. Emergent stable patterns then preserve node distinctness and prevent feature collapse.
What a runnable demo should prove

What a runnable demo should prove

Build a simple graph (e.g., a random graph with 20 nodes and 30 edges). Initialize it with small random vectors for each node. Run the network for 30 layers using ReLU, measuring how much the node vectors differ from each other at each layer. Then run the same setup with the paper's bifurcation-aware activation, using the paper's initialization scheme. Plot the variance (how spread out node vectors are) across layers.

variance_across_nodes(layer_k) = mean((v_i - mean_v)^2 for all nodes i), where v_i is the feature vector of node i at layer k.

With ReLU, variance should collapse to near zero by layer 20. With the bifurcation activation, variance should plateau and remain well above zero, proving the paper's theory prevents collapse.
