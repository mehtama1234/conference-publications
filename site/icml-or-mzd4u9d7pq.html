Once-for-All: Scalable Simultaneous Forecasting via Equilibrium State Estimation

Forecast multiple interacting systems all at once by estimating their shared equilibrium state, then predicting how far each system drifts from that state.

Paper explainersAll themesTime Series & Sequential

When hospitals, banks, and governments make decisions, they must predict what happens in related systems at the same time. A hospital predicts patient infections and staffing needs together; a bank predicts interest rates and currency pairs together. Today, systems are predicted one at a time, which is slow and misses how they influence each other. This paper introduces a faster approach: estimate where all systems would naturally settle if left undisturbed, then predict each system as a deviation from that stable point. This is faster because predicting small deviations requires far fewer calculations than predicting absolute values from scratch, and one shared equilibrium avoids redundant work across systems.

Why predicting multiple systems together is hard

Hospitals track infections spreading through different wards. Banks track currencies that move together. Climate models track temperature and rainfall linked across regions. Each system affects the others, so predictions should account for those links.

The naive way: feed each system's history into a separate predictor. System A gets predicted, then system B, then system C. This breaks because the predictor for B does not know what A actually predicted — it only sees B's past data. More fundamentally, running three separate predictors is slow. As you add more systems (ten wards, fifty currency pairs), the time balloons.

The core problem. Predicting many linked systems one at a time is both slow and blind to how the systems influence each other.

The algorithm as a flow

What it actually does

Step 1: Gather the current state

Read the most recent values for all systems simultaneously.

Step 2: Estimate equilibrium

Compute the stable resting point all systems would reach if forces stopped pushing them.

Step 3: Encode deviations

Measure how far each system sits from its equilibrium now.

Step 4: Run single prediction pass

Feed all deviations into one model that forecasts how each gap closes or grows.

Step 5: Recover full forecasts

Add predicted deviations back to equilibrium to get the final system values.

What the paper changes

What the paper changes

Instead of running separate forecasters for each system, the paper collapses them into a single pass that predicts the deviation of each system from its equilibrium state. The key move is shifting from forecasting absolute values to forecasting deviations from a shared anchor point.

the object it moves  =  Prediction target: deviation from equilibrium
The hidden quantity

The equilibrium state: where systems rest

measured quantity  =  Equilibrium state across all systems

Equilibrium is the stable resting point each system would naturally settle into if forces stopped pushing it. In currency trading, equilibrium is the long-term exchange rate; in epidemiology, it is the steady-state infection level in the absence of new outbreaks. It is not a number that changes; it is the underlying attractor that all systems gravitate toward.

The paper estimates equilibrium by analyzing the historical data of all systems together. Since equilibrium captures the shared structure linking the systems, estimating it once and then predicting deviations from it avoids redundant work. The model learns that currency pairs typically sit near certain ratios to each other, or that infections and staffing levels relate in stable ways. Once you know the equilibrium, predicting deviations is far simpler than predicting absolute values from scratch.

Why it works

Why equilibrium forecasting works

The core reason this is fast: when you predict one system at a time, each predictor must learn the full system behavior from scratch — what temperature does, how staffing responds, where they settle. That requires many numbers to adjust (the weights of the model) and many calculations. But all systems share a common equilibrium. By estimating equilibrium once upfront, you factor out the shared structure. Now each system's predictor only needs to learn how it deviates from that shared anchor, a much simpler task. Simpler tasks mean fewer calculations.

Why it is accurate: deviations from equilibrium are smaller and more stable than raw values. Raw values can swing wildly; deviations are bounded. A smaller signal is easier to predict accurately, because noise does not overwhelm it. Plus, linking all systems to a single equilibrium forces the model to learn their actual interdependencies — staffing does not move independently of infection rate. The shared anchor makes those links explicit.

The deviation equation

First in words:

Each system's future value equals its equilibrium plus the change in how far it sits from equilibrium.

Then the compact form:

y_i(t+1) = e_i + d_i(t+1)

Every symbol:

y_i(t+1)predicted value of system i at next time
e_iequilibrium state of system i
d_i(t+1)predicted deviation of system i from equilibrium at next time
A tiny worked example with exchange rates
Suppose the equilibrium exchange rate USD/EUR is 1.10 (long-term average).
Today USD/EUR is 1.15 (deviation = +0.05 above equilibrium).
The model predicts this deviation shrinks by 0.02.
Forecast: y(tomorrow) = 1.10 + (0.05 - 0.02) = 1.13.
Compare to old way: predict 1.13 directly from time-series alone.
Here, the model only learned how deviations decay (a 1D signal), not the full exchange rate behavior.

Forecasting deviations is simpler because they are smaller and more stable than raw values.

What can go wrong

What can go wrong

Wrong equilibrium estimate. If the historical data is too short or nonstationary, the equilibrium estimate drifts. A shifting equilibrium (for instance, climate change altering long-term temperature levels) breaks the assumption that each system's resting point stays the same.
Systems with no shared resting point. Some systems are chaotic or have no stable attractor. The method assumes all systems gravitate toward equilibrium. If a system is in a chaotic regime or driven by random shocks, deviations never settle, and predictions fail.
Heavy perturbations overwhelm the signal. Large sudden shocks (pandemic outbreak, stock crash, natural disaster) can push systems far from equilibrium. The model is trained on small deviations; extreme deviations may exceed the range it learned.
Done right. The paper demonstrates the method on currency exchange rates and COVID-19 spread modeling — both have stable equilibria that deviate predictably under normal conditions.
What a runnable demo should prove

What a runnable demo should prove

Build a toy scenario with 5-10 interacting systems (e.g., populations of predators and prey that reach a Lotka-Volterra equilibrium; or temperature, humidity, and atmospheric pressure that have stable relationships). Seed them with synthetic history data. Compute the equilibrium from the history. Then, for a held-out test period, predict each system's behavior using the equilibrium deviation method. Measure forecast error (mean absolute error or RMSE). Compare against predicting each system independently with a simple ARIMA or feed-forward model.

Speedup = time_old / time_new; Accuracy = root_mean_squared_error(pred, actual)

The demo must show both metrics improve: time falls dramatically (5-50x speedup for 10+ systems) and accuracy stays comparable or better because the model learned cross-system structure from the shared equilibrium anchor.
