Humans and Agents Teaming Up

Papers about how humans and AI agents can work together better — like clarifying what the human wants or dividing responsibilities.

All themesField mapMathematicsAll explainers
What this is

The smallest subtheme here focuses on agents that work with humans rather than alone. An agent and a human can complement each other: the agent is fast at certain tasks and never gets tired or bored, while the human is creative, can judge context and ethics, and can catch the agent when it is about to make a mistake. These papers explore how to structure collaboration so both are actually helpful. A human might clarify an ambiguous request, provide feedback when the agent fails, take over when the problem is outside the agent's capability, or validate a decision before the agent executes it.

The tricky part is interaction design. If the agent is too autonomous, the human gets surprised by unexpected actions or feels like a passenger. If the agent is too dependent and asks the human for approval on everything, it becomes a burden and wastes the human's time and attention. Also, humans and agents have very different ways of thinking and operating — the agent can process thousands of possibilities per second, while the human reasons about fuzzy high-level goals. Bridging that gap in a collaboration requires careful thought about communication, handoff points, and trust.

Papers in this space focus on human-in-the-loop systems where the agent and human trade control and information. Some explore how agents should ask for help or clarification when uncertain, which matters because the human can catch a misunderstanding early and steer the agent right instead of letting it pursue a bad plan to its end. Others focus on explaining agent decisions to humans in ways the human can understand and verify, which builds trust and lets the human spot mistakes before they cause harm. Some papers tackle how to learn from human feedback — when the human corrects the agent or points out a mistake, the agent should adapt so it does better next time. The goal is partnerships where the human's judgment and the agent's speed combine into something more capable than either alone.

How the work breaks down

Human-agent collaboration breaks down into two fundamental challenges: first, setting up the interaction so the human and agent can actually work together — deciding who does what and how to handoff control — and second, bridging the communication gap so the agent understands what the human really wants and the human can trust what the agent does. Papers here tackle interaction design for collaboration, learning user intent quickly and efficiently, and building systems that humans can understand and rely on.

Building Collaborative Frameworks

When an agent and a human can talk to each other during a task, they often outperform the agent working alone — because the human can redirect the agent when it starts to make mistakes — but you have to build the interaction right. If the agent never asks for help, it goes off on tangents because it commits to wrong interpretations without checking. If it asks for every decision, it drains the human's time and focus because frequent interruptions are exhausting. The challenge is designing when the agent should ask, what it should ask, and how to measure whether the collaboration is actually better, because that's how you know whether your interaction design actually improves the outcome or just slows things down.

Collaborative Gym addresses this head-on: it builds a framework where agents can pause and ask clarifying questions, and measures whether real humans actually prefer the result. The results are striking — humans and agents working together achieve an 86% win rate versus the agent alone in Travel Planning, 74% in table analysis, and 66% in research-related work, because real users found the agent's clarifications helpful and guided it toward their actual goal. Interactive Agents for underspecified software engineering takes a similar approach: when a software engineering task has vague or incomplete requirements, an agent that asks clarifying questions jumps from baseline performance to 74% success because the human's clarification removes the ambiguity that was forcing wrong choices. Both papers show the same insight: good collaboration beats pure autonomy because the human catches misunderstandings early before the agent invests effort in the wrong direction.

Discovering and Clarifying Intent

Humans often don't know exactly what they want at the start — they explore, refine, and change their mind. An agent that just asks 'What do you want?' won't get a good answer because the human hasn't worked out their actual need yet. Instead, smart agents should narrow down the space of possibilities through back-and-forth dialogue, asking the human targeted questions that eliminate confusion quickly so the human doesn't waste mental effort thinking through all options. The trick is doing this efficiently so the human doesn't get tired of answering.

Topological Active Inference cuts straight to this problem: given N possible tasks the human might want, the agent can narrow it down by asking smart questions that split the remaining possibilities roughly in half each time — like a binary search. This gives logarithmic interaction complexity, meaning the number of questions grows with the log of the number of possibilities instead of linearly, so discovering intent stays fast even with many options. The agent keeps working even if the human's answers are noisy or inconsistent. DiscoverLLM flips the usual workflow: instead of the human stating their intent and then the agent executing it, the agent actively discovers the intent through interaction. The payoff is clear: users complete tasks 40% faster with shorter conversations, while task quality actually goes up by over 10%, because discovering intent during the task lets the agent learn what the user actually needs instead of locking in on an early misunderstanding, and user satisfaction improves — the system learns not just how to follow orders but what the orders should be in the first place.

Topological Active Inference for Task Disambiguation
Reduces effective hypothesis space from N sampled solutions to K latent intents with logarithmic interaction complexity O(log K); resolves user intent with fewer turns and robustness to noisy feedback.

Trust Through Consistency and Transparency

In safety-critical settings like healthcare, an agent's mistakes can harm people. Users need two things: first, the agent has to be consistent (if it made the right call once, it should make the right call the next time), and second, the human needs to understand why the agent did what it did so they can spot mistakes before they happen. Both are hard because language models can give the right answer sometimes and a wrong answer other times, even for the same input.

The EHR Database Agents paper reveals a hard truth about current systems: they get the right answer 90-95% of the time in best-effort tries (measuring the best try out of 5), but when you require consistency across multiple attempts (same answer all 5 times), the success rate plummets to 35-60%. This is dangerous in healthcare databases because the same user query should generate the same safe answer every time. Fix the Mind takes a different angle: it shows how AI can pinpoint exactly where a human's understanding is wrong — what misconception is blocking them — instead of just giving a generic explanation. When an AI system guides students by diagnosing the specific gap in their thinking, it corrects 90% of misconceptions. Both papers teach that trust isn't just about getting the answer right; it's about consistency and making the reasoning transparent enough for the human to verify it.
