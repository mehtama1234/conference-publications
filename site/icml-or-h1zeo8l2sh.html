Perceptual Flow Network for Visually Grounded Reasoning

Train a vision-language reasoner to build useful visual trajectories by separating perception from reasoning and rewarding perception steps that support the final answer.

Paper explainersAll themesMultimodal

Large vision-language models often answer from language habits instead of from the image. They may mention the most common object relation or the most common scene interpretation even when the pixels support a different answer. One response has been to force the model to follow trajectories from external visual experts, such as detectors or geometric trackers. That can reduce hallucination, but it can also teach the wrong lesson because those experts are optimized for geometric precision, not for helping the reasoning process answer the question. PFlowNet changes the training target. It separates perception, meaning the step that chooses and updates visual evidence, from reasoning, meaning the step that forms the answer from that evidence. It then trains the perceptual trajectory with reinforcement learning, meaning trial-and-feedback optimization, using rewards that score not only answer correctness but also whether the perception path remains visually reliable and reasoning-relevant. The model is therefore pushed to gather the right evidence for the question instead of merely imitating a geometric expert.

Zero assumption version

Why visually grounded reasoning needs more than maximum likelihood

Standard maximum likelihood training rewards the final text sequence when it matches the target answer, but it says little about the internal visual path the model used before producing that answer. If the correct answer appears often with a common wording pattern, the model can succeed during training without learning to inspect the decisive image evidence. That produces language bias and visual hallucination at test time.

Using visual experts as supervisors partly addresses this, yet those experts usually optimize a narrower goal such as exact point alignment or object localization. A reasoning system does not need the most precise geometric path in every case. It needs the path that exposes the evidence required for the question. The paper's claim is that perception should be judged by its utility for reasoning as well as by its visual faithfulness.

The paper's move in one sentence. Train the visual evidence path with rewards tied to answer utility and visual faithfulness instead of forcing it to copy an external geometric expert.

The algorithm as a flow

What it actually does

Build a perception module

Generate a visual trajectory, meaning a sequence of attended regions or evidence updates, that summarizes what the model chooses to inspect in the image.

Condition reasoning on that trajectory

Use the selected visual evidence as the basis for the answer module, so reasoning is explicitly tied to what perception collected.

Score trajectories with several rewards

Measure answer success, visual reliability, and reasoning usefulness, because a trajectory is only valuable when it stays faithful to the image and supports the task.

Shape learning with nearby geometric support

Use vicinal geometric shaping, meaning extra guidance from nearby plausible geometric paths, so the learner is nudged toward stable visual behavior without being forced to copy one rigid expert trace.

Optimize with reinforcement learning

Update the perception policy from reward feedback, which means the model learns which evidence-gathering paths tend to produce grounded correct answers.

What the paper changes

What the paper changes

The paper changes the target of supervision for visual trajectories. Instead of asking the model to imitate a fixed expert path, it asks whether the chosen path produces grounded reasoning.

the object it moves  =  the visual trajectory used before answer generation
The hidden quantity

The hidden quantity

measured quantity  =  the usefulness of a perceptual trajectory for the reasoning task

The hidden quantity is not simply whether a visual trajectory looks geometrically tidy. The real quantity is whether that trajectory exposes the evidence that the answer needs. A path can be geometrically neat and still miss the relation that decides the question.

PFlowNet tries to estimate that usefulness through rewards. If a trajectory repeatedly produces correct answers while remaining visually faithful, the model receives a strong signal that the path is serving the reasoning problem. If the path is visually plausible but does not support the answer, or if it produces the answer by drifting away from the image evidence, the reward weakens.

Why it works

Why decoupling perception from reasoning helps

When perception and reasoning are fused into one opaque step, training cannot tell whether a mistake came from looking at the wrong place or from drawing the wrong conclusion from the right place. Decoupling exposes that boundary. The perception module chooses evidence, and the reasoning module uses it. That separation matters because reward signals can then target the evidence path itself.

Multi-dimensional rewards are useful because grounded reasoning has several failure modes. A path may lead to the right answer for the wrong reason, which is a reliability problem. It may stay visually consistent but miss the key clue, which is a utility problem. It may focus on visually salient details that are irrelevant to the question. Scoring several dimensions gives the learner a richer target than answer accuracy alone.

Vicinal geometric shaping stabilizes training because pure reward learning can wander among many poor perception paths early on. Nearby geometric guidance narrows the search to visually reasonable regions while still allowing departures from the expert path when those departures support reasoning more directly.

A plain reward view

First in words:

The learning signal combines several reward parts. One checks whether the final answer is correct. Others check whether the trajectory stays visually faithful and whether it provides evidence that supports the reasoning process.

Then the compact form:

total_reward = answer_reward plus visual_reliability_reward plus reasoning_utility_reward plus shaping_reward

Every symbol:

answer_rewardreward for producing the correct final answer
visual_reliability_rewardreward for staying tied to valid visual evidence in the image
reasoning_utility_rewardreward for collecting evidence that helps the answer process
shaping_rewardextra guidance from nearby plausible geometric paths
total_rewardthe full reward used in reinforcement learning
A tiny worked example
Suppose the question asks which object is blocking the doorway.
A trajectory that looks mostly at the floor may still produce the common answer chair from language habits, but its visual reliability and reasoning utility stay low.
A trajectory that attends to the doorway region and nearby object edges gets higher utility because it exposes the deciding evidence.
If that second path also matches the image content closely, its visual reliability reward stays high.
Reinforcement learning then increases the chance of taking evidence paths like the second one.

The paper is not only using reward learning. It is changing what is rewarded, because trajectories that help reasoning while staying grounded in the image give the model direct feedback about which evidence paths support correct answers.

What can go wrong

What can go wrong

Reward design can miss important failure modes. If the reward does not penalize a certain hallucination pattern, the model may find a shortcut that scores well without becoming truly grounded.
Reinforcement training can be unstable. Early reward estimates may be noisy, so the perception policy can drift unless the shaping term and reward scales keep learning in a reasonable region.
Visual experts are still needed indirectly. The method avoids rigid imitation, but the shaping term still depends on useful geometric support, so poor support signals can weaken training.
Done right. The approach is strongest when the main failure is not missing visual capacity but misdirected supervision, because then reward-based trajectory learning can redirect the model toward evidence that matters for reasoning.

What a runnable demo should prove

Use a benchmark where questions depend on a specific visual relation or small region. Compare three systems: plain likelihood training, rigid trajectory imitation from a visual expert, and PFlowNet. Log the perceptual trajectory, the final answer, and the reward components for each example.

The demo should show cases where the expert trace is geometrically neat but not useful for the question. A convincing result shows that PFlowNet shifts the learned weighting toward the evidence that decides the answer because the reward is tied to grounded reasoning rather than to geometric precision alone.
