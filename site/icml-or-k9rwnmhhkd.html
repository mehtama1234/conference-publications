Dimensional Collapse in Transformer Attention Outputs

Attention outputs live in a smaller space than they appear to, so teaching a model to decode them works better if features are aimed at that actual space, not random directions.

Paper explainersAll themesInterpretability

Large language model layers look like they use all of their dimensions equally, but the outputs from the attention mechanism (the part that scores which earlier words matter most for each position) are actually squeezed into a smaller region of possibility space. When you train a sparse dictionary (a set of detectors, each aimed at one pattern) to find what is happening in this attention output, most detectors learn nothing because they point the wrong way. This paper shows you can fix that by aiming the detectors at the actual region where attention output lives.

Zero assumption version

Sparse dictionary learning ignores the shape of the space

A sparse dictionary is a set of detectors, each one learns to recognize a single pattern hidden in the model's internal numbers. To train it, you pick random starting directions for each detector and let the model learn from there. This works fine if patterns are spread evenly across all directions. But they are not.

Attention outputs turn out to be confined to a much smaller region—about 60 percent of the full space, with the other 40 percent completely empty. So most random detectors point into the void. They never see anything real. They become dead features—wasted patterns that never activate. In large sparse dictionaries (1 million detectors), 87 percent just sit there useless.

The problem in one sentence. Random starting directions for feature detectors miss the actual subspace where attention lives, wasting most detectors as dead features.

The algorithm as a flow

What it actually does

Measure the shape of attention outputs

Decompose real numbers from the attention layer using principal component analysis to find which directions matter most.

Find the active subspace

Count how many independent directions carry most of the information; for attention, it is only about 60 percent of available dimensions.

Initialize feature detectors into that subspace

Place the starting directions of all detectors along the principal components observed from the real data.

Train the sparse dictionary normally

From this aligned start, the model learns to recognize patterns without wasting features on empty directions.

Measure the improvement

Count how many features activate on real data; dead features disappear because aligned features now point at regions with real signals.

What the paper changes

The one thing that changes

The paper changes the starting directions of feature detectors in sparse autoencoders. Instead of random initialization, features are initialized along the principal components (the main directions of variation) of what the attention mechanism actually produces across many examples.

the object it moves  =  feature initialization directions
The hidden quantity

The hidden quantity: Effective dimensionality

measured quantity  =  effective dimensionality (percentage of full space actually in use)

Effective dimensionality measures how many independent directions a set of numbers from each layer actually uses. If the numbers produced by a layer are confined to just a few directions, the effective dimensionality is low. You measure it by looking at principal components: take all the outputs, break them down into directional parts (the main ways they point), and count how many parts carry most of the information. For attention outputs across many layers and models, this number hovers around 60 percent, meaning 40 percent of the space is wasted.

The paper measures this using a standard technique that breaks down data into its main directions of change. As effective dimensionality drops, dead features increase, because random initialization wastes features on those empty directions. Aligning to the active subspace fixes the mismatch.

Plain reading. The first few directions (like the most important word, the strongest feeling, the dominant topic) capture most of what attention outputs say. The remaining directions add almost nothing.
Paper reading. Effective dimensionality is formalized as the number of principal components needed to recover 99 percent of the variance, or via Roy and Vetterli's definition: the ratio of squared Frobenius norm to largest singular value squared.
Why it works

Why aligning to the subspace fixes the dead feature problem

When features are randomly initialized, each detector starts pointing in an arbitrary direction. In a low-dimensional subspace, most of those directions miss the region where actual outputs from the layer live. The detector never sees a signal that matches its learned pattern. It remains dormant (dead). It does not learn to recognize anything.

By initializing features along the principal components of the actual outputs from each layer, you ensure that every detector starts pointed toward the region where something real happens. The model then learns fine-tuning adjustments to each feature from that good starting point. Features that start in the active subspace learn real patterns. Features that start in the empty space no longer waste capacity.

This is similar to putting a fishing net into the water where the fish actually are, rather than spreading it randomly across the ocean. The alignment does not solve the hidden patterns directly, but it moves the learning process into the right region of space.

The alignment equation

First in words:

decoder weights projected to active subspace: W decoding equals principal components times learned coefficients

Then the compact form:

W_D := U_k * C, where U_k are top k principal components and C are learned per-feature coefficients

A tiny worked example
Say attention outputs are lists of 4 numbers, but only 2 main directions carry information.
Direction 1 points (1, 0, 0, 0) with 90 percent of total variation.
Direction 2 points (0, 1, 0, 0) with 8 percent of total variation.
Old random init: one feature starts (0.1, 0.2, 0.8, 0.9). It points into the empty third and fourth dimensions. Dead.
New aligned init: same feature starts (0.8, 0.2, 0, 0), which is 0.8 times direction 1 plus 0.2 times direction 2. It now sits in the active plane. Alive.

The projection anchors features into the active subspace, so learning refines real directions rather than wasting capacity on empty space.

What can go wrong

What can go wrong

Misalignment if the dataset is different. Principal components are computed from a sample of the layer outputs. If you train on different data, the active subspace may shift, and features may again drift into empty directions.
The subspace is not fixed forever. As the model is fine-tuned or adapted, the region where attention outputs live may change. Initialization alignment helps most at the start of training, because once training begins, the model adjusts features beyond their starting directions.
Overhead of computing principal components. Decomposing the layer outputs requires a pass through the model on a representative dataset. This cost is small relative to the gain but not free.
Done right, features stay alive. When initialization aligns to the observed active subspace, the learning problem becomes well-posed: features start in the region where something real happens, and they learn patterns rather than remain dormant.
What a runnable demo should prove

What a runnable demo should prove

Train two sparse autoencoders on Llama-3.1-8B attention outputs, each with 1 million features. Initialize the first one randomly (the old way). Initialize the second one by projecting random features onto the top 2400 principal components of the activation distribution (the new way). Train both on the same data for the same number of steps. Count how many features in each never activate on a held-out test set.

dead_fraction = (number of features that never activate) / (total features); show this before and after
