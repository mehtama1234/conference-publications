Running models efficiently

Making models faster and smaller so they can run on phones and edge devices without losing accuracy or requiring expensive hardware.

All themesField mapMathematicsAll explainers
What this is

Multimodal models are enormous. To connect images and text, you need a capable image encoder (a deep neural network that understands images) and a language model (a neural network trained on vast text), and then something to fuse them together. Put together, these models can have billions of parameters — settings that need to be stored and computed. A large model might weigh several gigabytes, which won't fit on a phone or even a laptop. Yet the world wants multimodal AI everywhere: on mobile devices, in apps, at the edge where data is generated. Running a model efficiently means either making it smaller, making it faster, or both, without losing too much accuracy — because users expect instant responses and low power drain, so the model has to do more work with less compute.

The tension is fundamental. A bigger model usually learns better because it has more capacity to memorize patterns and generalize from them. But size comes with a cost: slower computation, higher memory usage, and more energy drain. For a phone app, battery life matters. For a data center with millions of requests, speed matters — if you can halve the time per request, you can serve twice as many users with the same hardware. There is a tradeoff space: you can compress the model by removing or shrinking layers, use quantization to store numbers in lower precision (using fewer bits), or use techniques like knowledge distillation where a smaller model learns to imitate a larger one. But each technique has tradeoffs: smaller can mean loss of understanding, and the model might fail on hard cases.

Researchers in this area are building models that are smart about what they compute. Some use techniques where only important parts of the input are processed in detail, and less-important parts are handled more cheaply. Others design models that work in stages: a fast but rough first pass, then a more detailed second pass only if needed. Some train models specifically to be small and fast from the start, using special training objectives that penalize size. The goal is the same across all approaches: get a model that fits in a phone, runs in milliseconds, and still understands images and text well enough to be useful.

How the work breaks down

Running multimodal models on phones and edge devices requires solving a core tension: larger models understand better because they have more capacity to memorize patterns, but this size costs too much to compute on constrained hardware. Researchers attack this problem in five main directions. Some focus on compression—making the model smaller by removing parts or using lower precision numbers, which directly reduces memory and computation. Others use distillation, where a smaller model learns to copy a larger one's behavior, avoiding the need to discover patterns from scratch. Many design efficient architectures that are smart from the start, using techniques like adaptive routing where the model decides which parts of the input truly need detailed processing, so easy cases don't waste computation. Some train models to think efficiently, reducing unnecessary computation when the model is running by breaking the work into stages or using sparse computations that skip irrelevant parts. And several tackle the data side—using smaller datasets and better training signals means the model learns more from less, because concentrated data teaches patterns with fewer examples, which translates to smaller deployable models that need less capacity.

Removing unnecessary pieces and connections

When a multimodal model processes an image and text together, it converts them into a stream of pieces—small numerical units it can process. Larger images create more pieces; more pieces mean more computation and memory. The core problem is that not all pieces matter equally. Some carry visual detail; others are redundant. Removing unnecessary pieces before they waste compute is the main idea.

The positional preservation embedding (PPE) paper improves how pieces stay aligned after removal by keeping coordinate information intact. When you remove pieces, the remaining ones can lose track of their positions in the image—like scrambling the coordinates of points in a photo—because the spatial relationships are encoded in the piece order. PPE preserves this coordinate information with embedding vectors (learned numerical representations) attached to each piece. These vectors encode the piece's original location in the image, which lets the model look up and recover the spatial context that was lost during removal. Knowing the original coordinates lets the model reason about distance and adjacency—whether two regions were next to each other or far apart. When a model understands spatial relationships, it answers questions like whether the cat is to the left of the dog correctly, and it can locate objects when given a text description. PPE gains 2-5% accuracy on vision-language tasks without adding learned weights because the coordinate embeddings preserve spatial structure that would otherwise be lost.

Task-related piece removal takes a different angle: it looks at what the model is actually trying to do and removes pieces irrelevant to that task. On benchmarks like TextVQA and VQA, it cuts pieces by a substantial amount with almost no accuracy loss. Semantic distribution consistency (ConsMSA) uses only 10% of pieces on sentiment analysis while staying accurate by preserving the statistical structure of what each modality is saying.

MARC combines memory with reinforcement learning to decide which pieces to keep, particularly for video where frames can be highly repetitive. VisionPulse goes further, keeping only 5% of visual pieces at each reasoning step while shortening reasoning chains by over 10%, proving that for reasoning tasks most visual detail is wasted compute. Nüwa specifically protects spatial integrity—the positions and relationships between objects—when removing pieces, gaining 7% to 47% on grounding tasks that require knowing where things are.

Teaching small models from large ones

Teaching a small model to act like a large one works by having the small model learn from the large model's outputs. Instead of training from scratch, the small model watches how the large model answers questions and copies that behavior. This works because the large model has already figured out useful patterns; the small model just needs to memorize them, not discover them.

Piece distillation with information monitoring compresses audio-visual models drastically: it uses 94% fewer learned weights while keeping 96.9% of performance on event recognition and 96.5% on segmentation. Not all layers need equal compression because some layers are redundant while others are irreplaceable. The method checks how much information each layer carries and compresses more aggressively where the model repeats itself, less where information is irreplaceable.

Piece-interaction distillation (beyond-next-piece-alignment) improves on standard teaching by 2.6% and produces a 2-billion-weight model that outperforms a standard 7-billion-weight model because it teaches more than just answers. The trick is teaching the small model not just what answers the large model gives, but why—how different parts of the input connect to produce that answer—which helps the small model generalize better to new cases. Zooming without zooming teaches a small model fine-grained perception by focusing on important image regions during training, so when the model runs it has learned to recognize which regions matter and can skip low-value areas, running faster without tools.

Efficient architectures and sparse processing

Some models are designed from the ground up to be small and fast, not compressed afterward. This means training objectives that explicitly penalize size or techniques that skip unnecessary work during inference. The core idea: if you reward a model for thinking efficiently while learning, it learns efficient habits.

Active perception (ACTIVE-o3) gives models the ability to look at images strategically—zooming into small dense objects when needed, ignoring empty space. Instead of processing every pixel equally, the model actively decides where to look, much like human eyes. This preserves understanding of small objects and domain-specific cases while cutting computation.

Spectral-progressive thought flow reduces computation and memory by up to 2.1x for reasoning by breaking the thinking process into stages: a rough pass over the full problem, then deeper reasoning only on key parts. SketchThinker-R1 takes this further, cutting reasoning cost by 64% without losing answer accuracy by training the model to focus on sketches of the problem—rough outlines that guide which parts to reason about carefully.

ST-SimDiff for video understanding balances what changes frame-to-frame against what stays the same. Videos are repetitive; processing every frame fully is wasteful. By explicitly modeling similarity and difference, the model can encode one frame in detail and then cheaply update it for the next frame, substantially cutting computation while keeping accuracy. SpatioLM achieves physical spatial reasoning efficiently by training specifically on spatial tasks, so the model learns representations that support spatial thinking from the start rather than forcing a general model to do spatial tasks at the last moment.

Lower precision and targeted adaptation

Storing model weights (the learned numbers) in lower precision—using 4 bits instead of 8, for example—shrinks the model because fewer bits per weight means less memory, and speeds up computation because moving and processing smaller numbers is faster. The main risk is that lower precision loses information, because 4 bits can represent fewer distinct values than 8 bits, so some weights get rounded to nearby values and the model behavior changes. The challenge is deciding which parts can use lower precision and which need to stay precise so accuracy doesn't drop too much.

DVD-Quant stores video diffusion model weights in lower precision after training, achieving 2x speedup. Diffusion models are expensive to run because they iteratively refine outputs; halving speed matters a lot. By using lower precision without retraining on data, it shows that this approach can work even when you cannot run a full training session.

MoRA (missing-modality low-rank adaptation) solves a different efficiency problem: when one modality (say audio) is missing, multimodal models often fail. MoRA adds only 0.11% of learned weights—tiny adaptations that redirect computation—and achieves 5.24% accuracy gains in missing-modality cases while cutting inference time to 26% of the full model. UniLIP achieves comparable results to much larger models with only 1–3 billion weights, handling image understanding, generation, and editing all in one small model by using shared representations.

Smart routing and selective processing

Smart routing and early stopping let models skip computation for easy cases. If the model can confidently answer a question by looking at just part of the input, why process everything? These techniques learn to route different inputs to different internal pathways—some inputs take a fast shortcut, others need full processing.

Dynamic and asymmetric routing cuts computation by 40% and internal memory cache by 46% across spatial reasoning benchmarks while preserving accuracy. Asymmetry matters: different modalities and layers need different levels of processing. Text might flow through quickly while images need more detailed analysis.

Dual latent memory routing (vision-language reasoning version) learns which pathways to take with minimal added weights, reducing pieces needed while handling diverse reasoning tasks. The dual-latent version for multi-agent systems breaks scaling walls, achieving 2.7–5.4% accuracy gains while cutting piece usage by 21–44%. Focus plan generation (dive into the scene) solves visual hallucinations by generating a focus plan—deciding where to look first—rather than processing all details equally. This cuts computational cost while making the model more truthful about what it sees.

Hyperbolic anchor distillation improves how models learn from examples in the prompt by mapping examples to positions in hyperbolic space where similar items are naturally closer, which makes the model naturally focus on similar examples since they cluster together and the model can pick neighbors easily. Shared latent queries (SLQ) for retrieval work without modifying the large model at all—frozen models stay frozen while new retrieval layers learn from cross-modal signals. This is more efficient than retraining the whole model because the large model's internal weights are locked and won't change, so you only need to compute gradients for the small new layers. Budget-aware piece compression (UHR-BAT) is specialized for high-resolution remote sensing, where images are kilometer-scale but only query-critical details matter. It allocates a piece budget and learns to spend pieces where the image has detail the query cares about, so queries about water only pay for fine details in the water areas, not the entire image.
