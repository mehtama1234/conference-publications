In plain terms

Imagine you're reading a sentence and you get to the word 'bank'. Does it mean a riverbank or a financial institution? You look back at the whole sentence to find clues. You probably weight the nearby words more than distant ones—'river' close by shifts the meaning one way, while 'money' shifts it another. Attention is exactly this: a mechanism that looks at all available context and decides which parts deserve your focus.

The problem attention solves is about focus under abundance. A model sees hundreds or thousands of pieces of data—words in a sentence, pixels in an image, time steps in a sequence. It cannot treat them all equally. Some matter for the current decision; others are noise. Before attention, models had to guess which data to remember based on fixed rules. Attention instead asks the data itself: 'Given where I am right now, which of you should I pay attention to?' The answer is always context-dependent, always learned from examples.

Here's how it works in three steps. First, the model creates a set of questions, called queries. Second, it compares those questions against all available data, called keys. The comparison produces a raw score that says 'how relevant is this piece of data to this question?'. Third, it uses those scores to decide how much of each piece of data—the values—to actually use. High scores pull in more of that data; low scores pull in less. The beauty is that these scores are soft, not hard: every piece of data contributes, but to different degrees.

The equation
A=\mathrm{softmax}(QK^T/\sqrt{d})V
QThe queries—what the model is currently asking for or trying to pay attention to.
KThe keys—the labels or summaries of all available data, so the model can check relevance.
VThe values—the actual data the model will use, weighted by how relevant it turned out to be.
K^TThe keys rotated or flipped in a specific way (mathematicians call this transposing), so the comparison has the right shape.
dThe dimension or size of each query and key—roughly how many numbers describe them. Used to keep scores at a sensible scale.
\mathrm{softmax}A function that turns raw scores into weights. It makes all weights add up to 1 and keeps them between 0 and 1, so high scores push toward 1 and low scores push toward 0, but nothing goes negative.
AThe attention output—the weighted blend of all the values, where the weights came from comparing queries to keys.
Worked example
A tiny query matching problem
Say Q = [1, 0] (one query), K = [[1, 0], [0, 1]] (two keys).
Raw scores = Q · K^T = [1, 0] · [[1, 0], [0, 1]]^T = [1, 0] · [[1, 0], [0, 1]] = [1, 0].
Divide by √d: [1, 0] / √2 ≈ [0.71, 0]. Softmax([0.71, 0]) ≈ [0.67, 0.33].
If V = [[2], [4]], output = 0.67 · 2 + 0.33 · 4 ≈ 2.67.
Why it shows up

Attention appears in 184 papers across the corpus because it solves a fundamental problem: in most modern ML pipelines, you have too much data to process equally, and the right subset to use depends on context. A language model must decide which earlier words help predict the next one, so that it can understand that the word 'bank' means something different after 'river' than after 'money'. A vision model must decide which image regions are relevant to recognizing an object, so it can focus computation where it matters most. A time-series forecaster must decide which historical time steps matter for the next prediction, so it uses signals instead of noise. In every case, attention lets the model learn which data to emphasize because the papers show that teaching it this skill—rather than hard-wiring attention patterns—leads to better results.

The seed equation distills the mechanism into four ideas working together. Comparing queries to keys via dot product reveals compatibility. Dividing by the dimension's square root keeps scores from exploding when the numbers representing data points (vectors, or lists of coordinates) are large. Softmax turns scores into usable weights. And multiplying by values completes the lookup. This four-part chain appears in transformer models (neural networks built from attention blocks), visual recognition systems, sequence-to-sequence translation, and diffusion-based image generation—anywhere a model needs to route information based on relevance.
