Neural Control: Adjoint Learning Through Equilibrium Constraints

A robot learns to control floppy objects by treating each shape as a solution to a physics equation and computing gradients without replaying all the iterations.

Paper explainersAll themesRobotics & Control

When a robot bends a rope or strip to a target shape, the shape itself is determined by solving physics equations—not by a simple formula. Unlike typical learning where one action produces one result, here the same bend can create different shapes depending on history. The paper shows how to learn controller actions by computing gradients that flow backward through these equilibrium equations using adjoints (a calculus trick), avoiding the memory cost of replaying all solver iterations.

Zero assumption version

Bending things breaks normal learning

When a robot controls a rope, strip of cloth, or any soft object, the result shape is not just a function of the controls applied—it depends on solving a physics equation for static equilibrium. The same boundary condition (same tug on the ends) can yield different midpoint shapes depending on which way the strip was bent previously.

A naive learner would try to backpropagate gradients (compute how to adjust the controller) by replaying every iteration of the physics solver that found each shape. This is ruinously expensive: each solver step must store its state in memory, and the backward pass must recompute or unroll thousands of steps.

The core fix. Compute gradients by differentiating the equilibrium equations themselves using adjoints, avoiding the unrolled solver iterations, while still using the actual converged shapes for the forward rollout.

What the paper changes

What the method changes

The paper changes how gradients are computed when the forward pass solves implicit equations. Instead of storing and replaying solver iterations, it computes proxy gradients by differentiating the equilibrium conditions themselves. The forward rollout still solves the full physics to convergence—it just computes the backward gradients differently.

The hidden quantity

The proxy adjoint: sensitivity to controls

measured quantity  =  trajectory-dependent proxy gradient

At each step during learning, the method tracks a hidden quantity: how much the shape at that step would change if the control were nudged slightly. Normally this would require replaying the entire solver. Instead, the adjoint approach computes this by satisfying a special equation (the adjoint equation) that relates error propagation without needing to unroll iterations.

The paper estimates this proxy gradient by treating the equilibrium equations as constraints and using the implicit function theorem: if position x satisfies physics equations as a function of control z, then how x changes with z is given by differentiating those equations, not by differentiating the solve process.

Why it works

Why adjoint equations beat solver unrolling

In standard backprop through a solver, you must save the state at each iteration and replay forward steps in reverse. With a converged equilibrium, the final shape satisfies a physics equation (shape and control must satisfy the physics constraint for static equilibrium). The implicit function theorem tells us how much shape changes when control changes, and this can be computed from the equilibrium equation itself without ever replaying the solver: the sensitivity is found by solving an adjoint equation backward from the loss.

The equilibrium condition itself (not the path to reach it) determines what gradients must be. By differentiating the equilibrium condition with respect to controls, the method computes gradients that are consistent with the actual optimizer trajectory but without the memory and compute overhead of unrolling Newton or conjugate-gradient iterations.

Receding-horizon continuation anchors this further: instead of planning one long horizon from an ambiguous starting state, the method plans in short segments, converges to an equilibrium, then re-anchors and replans from that realized point. This prevents the optimizer from drifting into a different (multistable) configuration during long horizons.

Math after the picture

The adjoint equations for implicit control

First in words:

loss equals terminal error plus running errors; adjoint a traces loss-sensitivity backward through states; effective adjoint d combines state and control adjoints; control gradient is continuous operation times effective adjoint

Then the compact form:

L = phi(x_K, z_K) + sum_k w_k * ell(x_k, z_k); d_L/d_u_k = Delta_lambda * B_k^T * d_k; d_k = g_{k+1} + S_k^T * a_{k+1}

Every symbol:

Ltotal loss (error from goal)
phi(x_K, z_K)terminal loss at final step K
ell(x_k, z_k)running loss (error from goal) at step k
w_kweight for running loss at step k (0 if only terminal loss)
d_L/d_u_kgradient of loss with respect to control u at step k
Delta_lambdastep size in continuation (how far controls move per step)
B_khow control affects dynamics at step k
d_keffective continuation adjoint (combined sensitivity)
g_{k+1}sensitivity of loss to boundary control at next step
S_ksensitivity matrix (how shape x changes with control z)
a_{k+1}sensitivity of loss to position at next step
S_k^Ttranspose of sensitivity (maps position gradient to control gradient)
A tiny worked example
Suppose we want the rope midpoint at position 5, and currently it is at position 3, so error is 2.
At step k, control gradient d_u_k includes term B_k^T * d_k, where B_k is how much the next shape changes per unit control (say B_k = 0.8).
If the effective adjoint d_k = 0.5 (meaning a change of 1 in this state causes 0.5 units of loss change), then d_u_k includes 0.8 * 0.5 = 0.4.
If we nudge control by 0.1, the rope shifts by 0.8 * 0.1 = 0.08, and loss changes by roughly 0.4 * 0.1 = 0.04 less (closer to target).
This gradient was computed without replaying any solver iterations, just differentiating equilibrium equations.

The equilibrium constraint embeds the physics: only shapes that satisfy the physics equation get the right proxy gradients, and adjoints flow these gradients backward without unrolling the solver.

What can go wrong

What can go wrong

Discontinuous branches. If the equilibrium has sharp bifurcations (sudden jumps to a different configuration), the proxy adjoint assumes smoothness and may give stale gradients. Fix: receding-horizon re-anchoring detects and corrects branch switches.
Ill-conditioned equilibrium matrices. If the equilibrium has a direction where shape barely responds to control nudges (near-singular sensitivity), the adjoint equations become numerically unstable and gradients are unreliable. Fix: add damping to the solver or detect and skip ill-conditioned steps.
Long horizons without re-anchoring. If controls drift gradually, the optimizer may assume the wrong branch for later steps. Fix: shorten horizon and always replan from a newly solved equilibrium.
Done right. Short planning horizons (5–10 steps), solve equilibrium to tight tolerance at each anchor, check that the sensitivity (how shape responds to control) is well-behaved numerically, use receding-horizon replanning to re-anchor to realized configurations.
What a runnable demo should prove

What a runnable demo should prove

Build a simple deformable strip simulator (a few points connected by springs and bend-stiffness constraints). Initialize the controller as a neural network that takes a step counter (continuation value) and outputs a boundary displacement. Solve the strip equilibrium under that displacement (finding the midpoint position). Compute loss as the squared distance from a target midpoint position. Run gradient-free (SPSA) and adjoint-based (Neural Control) optimizers for a fixed number of forward evaluations, and plot loss vs. optimization step. The demo proves adjoint learning converges much faster because every gradient points downhill; you should see adjoint reach target loss in fewer steps.
