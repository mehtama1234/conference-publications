A Few Flipped Votes Break LLM Rankings

The rankings of top AI models shift radically when you remove just a tiny fraction of human preference votes, showing the rankings are fragile.

Paper explainersAll themesDatasets & Benchmarks & Evaluation

We vote to rank things all the time: which movie is best, which phone to buy, which AI model to trust. The paper shows that AI model rankings from popular tools like Chatbot Arena are shaky. A mere 0.003% of votes—about one vote in thirty thousand—can flip which model sits in first place. The paper gives a fast way to find exactly which votes matter most, and shows which ranking systems are more stable.

Zero assumption version

Ranking models by votes is unreliable

Right now, AI labs and researchers use simple voting systems to rank large language models. Users pit two models against each other, pick a winner, and the system tallies votes. Thousands of votes later, a ranking emerges: this model is number one, that one is number two. It feels solid.

But here is the catch: the ranking might not be. If you remove just a handful of votes—the ones that went a particular way—the entire top-ten order can collapse and reshuffle. The model that looked second might leap to first. The leader might drop. This means the ranking you see today is not a true measure of which model is actually better, because it depends entirely on those few outlier votes; if those votes vanish or were entered by mistake, the whole ranking flips.

The core problem in one sentence. Model rankings shift dramatically when a tiny fraction of votes disappear, so we cannot trust the order we see.

What the paper changes

What the paper changes

The paper changes the vote weights: it finds which votes are most influential and marks them as fragile. Not by removing them permanently, but by asking: if I remove this exact vote, what happens to the rank?

the object it moves  =  vote influence weight
The hidden quantity

The hidden quantity: vote influence

measured quantity  =  vote influence: how much a single vote tilts the ranking

Every vote in the ranking system has an influence score. A vote from someone who always picks the same model, or who picks an outlier winner, has high influence—removing it reshuffles the ranks. A vote from someone whose pick matches the crowd has low influence—removing it barely moves the needle. Influence is hidden because you do not see it in the raw tally; you only find it by running the test.

The paper estimates influence by a fast algorithm: for each vote, it computes how much the ranking changes if you remove it. Votes that cause big rank shifts get flagged as high-influence. The method runs quickly because it uses math to skip testing every single vote; instead it targets the dangerous ones.

Why it works

Why the method works

Here is the mechanical reason the method finds the fragile votes. A ranking system uses a mathematical model called Bradley-Terry. It assigns each model a strength score. When two models compete, the model with the higher strength score is predicted to win more often. The ranking is just the models sorted by strength, highest first.

Now suppose you remove one vote—say, a vote where model A beat model B. That vote had nudged model A's strength up and model B's strength down, so removing it nudges them back. If model A's strength was only barely above model C's before, this nudge flips the ranking: C might leap over A. The method finds which votes, if removed, cause the biggest strength shifts. Because strength shifts directly determine ranking order, finding votes that shift strength is the same as finding votes that flip ranks.

Why does this work fast? Because the method does not try every possible subset of votes to remove. Instead, it uses calculus: for each vote, it asks mathematically, 'how fast does the ranking change as I wiggle this vote's weight?' Votes with steep slopes matter more. Calculus gives you the answer instantly by taking a derivative, rather than running thousands of test removals one by one, so it is millions of times faster than brute force.

Math after the picture

The ranking equation

First in words:

probability model A beats B equals A's strength divided by (A's strength plus B's strength); the ranking is all models sorted by strength, highest first; the influence of a vote is the change in ranking order when that vote's contribution to strength is removed

Then the compact form:

P(A beats B) = s_A / (s_A + s_B); rank = sort by s in descending order; influence_i = d(rank) / dw_i

Every symbol:

s_Astrength score for model A
s_Bstrength score for model B
P(A beats B)the predicted probability model A wins a matchup
rankthe sorted order of all models by strength
influence_ihow much the ranking changes when vote i's weight shifts by 1
dw_ia small change in vote i's contribution
A tiny worked example with three models and nine votes
Suppose model A, B, and C each get 3 votes: A beats B, A beats C, B beats C.
Bradley-Terry computes strengths: s_A = 3, s_B = 2, s_C = 1. Ranking is A, B, C.
Now ask: what if we remove the one vote where A beat B?
Strength A drops slightly: s_A = 2.8 (because it loses one win). Strengths refit.
New ranking might be: still A, B, C if the drop is small. Influence of that vote on rank is zero.
But what if we remove votes differently and s_A drops to 1.9? Now B (2) ranks higher than A. Ranking flips to B, A, C.
That vote (A beats B) has high influence because removing it flips the top two. The method flags it.

The ranking order is determined entirely by strength scores, so finding votes that most alter strength is finding votes that most shift the ranking.

What can go wrong

What can go wrong

Adversarial vote injection. If someone deliberately adds votes to game the system before the audit, those votes will register as normal, not flagged as problematic, until you rerun the stability test.
Correlated votes from the same person. If one rater submits many votes that all push the same model to the top, removing any one of them has small effect, but removing all of them flips the rank. The method finds this, but does not distinguish intentional coordination from genuine agreement.
Small sample sizes. If the ranking is based on only one hundred votes total, removing even one changes the percentages dramatically, and every ranking becomes fragile. The method works but the ranking itself is unreliable to begin with.
Done right. Rerun the stability audit every time you add new votes, and investigate the high-influence votes to see if they are genuine or suspicious. Use the results to decide how much to trust the current ranking.
What a runnable demo should prove

What a runnable demo should prove

Build a toy ranking system with fifty votes ranking five models. Add ten unusual votes that all rank one model unexpectedly high. Show that removing those ten votes flips the top-three order. Then show that removing ten random votes does almost nothing to the rank. The demo proves that not all votes are equal: the method correctly identifies which ones matter most to the final rank.

rank_shift = number_of_top_k_models_that_changed_position_after_removing_votes / k

The demo must make it impossible to miss: a single person's lopsided set of votes can crown the wrong model as number one.
