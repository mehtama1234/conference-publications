Attention Smoothing Is All You Need For Unlearning

To make a language model forget specific facts, smooth its attention weights by turning up the temperature dial, which spreads the model's focus away from the tokens it used to memorize.

Paper explainersAll themesAlignment, Safety & Fairness

Large language models memorize and can leak sensitive or copyrighted information. Retraining the whole model from scratch is too expensive. But existing methods that try to make the model forget something do a poor job: the model either forgets and starts babbling nonsense, or forgets so little that it still remembers the secret. This paper shows a simple, reliable way: increase the temperature in the softmax operation of the attention mechanism to flatten the attention weights, which directly breaks apart the token-to-token associations (who talks to whom) that hold the memorized knowledge together.

Zero assumption version

Models leak memorized secrets, and forgetting breaks them

A language model trained on text learns not just the skills (writing, reasoning, translation) but also memorizes specific facts, exact phrases, and private information from its training data. If someone asks a trained model questions about facts in the forget set (say, a copyright holder's book or a person's medical record), it can retrieve and repeat them. Simply retraining the whole model from scratch on everything except the secret data is too slow for a model with billions of adjustable weights.

The naive approach: take the original model and adjust the weights to make it output wrong answers on the forget-set questions (using a forget loss), while a retain loss keeps it smart on everything else. This fails because attention in the model has learned strong, direct connections between tokens that encode the facts. Weakening those connections through gradient-based forgetting alone is unstable: the model either learns the forget loss by producing gibberish on all related questions (destroying utility), or the lexical and semantic associations in attention persist and the secret still leaks out. Simply retraining from scratch costs billions of dollars.

The method in one sentence: Increase the softmax temperature in the attention mechanism to flatten the weight distribution, which disrupts the token associations holding the memorized facts together, while keeping the model coherent on normal tasks.

The algorithm as a flow

What it actually does

Step 1: Start with trained model

The original model has learned strong attention patterns binding tokens in memorized facts.

Step 2: Create forget-teacher

Copy the model and increase softmax temperature in every attention layer to flatten token weights.

Step 3: Distill from smoothed teacher

Train the original model to mimic the forget-teacher's outputs on forget-set questions only.

Step 4: Preserve retain performance

Add a retain loss on normal data alongside the unlearning loss, because without it the model would only train to match the forget-teacher and lose all other knowledge.

Step 5: Result

Model forgets the facts but stays coherent because it still has the base structure and syntax.

What the paper changes

What the paper changes

The paper modifies the softmax operation (the calculation that turns raw attention scores into weights that sum to 1) inside every self-attention layer. Specifically, it divides the attention scores by a temperature value tau before applying softmax, which stretches or squashes the input distribution. When tau is large, this flattens the softmax output so all tokens receive nearly equal weight instead of a few tokens dominating.

the object it moves  =  Softmax temperature in attention
The hidden quantity

The hidden quantity: Lexical-semantic attention association strength

measured quantity  =  Attention concentration (entropy)

Attention concentration is a measure of how peaked or flat the attention distribution is. In the original model, a few token-pairs have very high attention (close to 1.0) and the rest near zero; this concentration is low entropy. A memorized fact lives in these tight associations. By raising temperature, the distribution flattens: all tokens get similar weight (0.08, 0.09, 0.07...), which is high entropy. The paper assumes that disrupting this concentration directly weakens the memorized associations.

The paper measures this by training on the forget set and monitoring whether the model can still retrieve the factual information. Lower concentration (higher entropy in attention) should mean weaker recall of the forget-set facts. The method does not explicitly compute entropy but uses KL divergence between the original model and the temperature-smoothed model as a proxy for how different the attention is.

Why it works

Why it works: Breaking associations without gibberish

The core insight is that memorized facts live as tight associations in attention. When you ask 'Who is the president?' the token 'president' has learned to attend strongly to the token 'Bob' during pre-training. This learned pattern is stored in the attention weights (the adjustable numbers that decide how much each token attends to each other token). A memorized fact is not a single weight value; it is a web of these token-pair associations.

Raising the softmax temperature before computing attention spreads that focus out. Instead of 'president' attending 90% to 'Bob' and 5% to other tokens, it now attends 20% to 'Bob' and 20% to every other token. This flattening happens in every layer, so the associations that let the model reconstruct the fact are disrupted all at once. Importantly, this does not destroy the model's general ability to write coherent sentences, because syntax (the rules for word order and structure) is learned and spread across many parameters in a way that survives attention disruption in shallow layers (earlier layers). Functional tokens (articles, prepositions, common words) have number-lists that stay stable and survive shallow-layer attention disruption.

The unlearning works by distillation: the student model (the original) is trained to match the forget-teacher (the smoothed version) on forget-set inputs. This forces the student to adopt the flattened attention patterns. Meanwhile, a separate retain loss keeps the model learning on normal data, so it does not forget everything. The trade-off is stable because the mechanism is precise: you flatten exactly the associations that bind the fact, not random parts of the network.

Math after the picture

The equation: Attention with temperature

First in words:

Attention equals softmax of the query-key product divided by temperature, times the value vectors. KL divergence between student and teacher outputs, plus retain loss on normal data.

Then the compact form:

Attention(Q, K, V; tau) = Softmax(Q K^T / tau / sqrt(d_k)) V L = E_(x,y)~D_F [ KL(theta || theta_tau) ] + lambda E_(x,y)~D_R [ L_R(y|x; theta) ]

Every symbol:

Q, K, VQuery, Key, Value vectors derived from the input tokens
tauTemperature (scaling factor; tau > 1 flattens the softmax)
d_kDimension of the key vectors (e.g., 64)
SoftmaxFunction that turns raw scores into weights summing to 1
thetaParameters (weights) of the student model being trained
theta_tauParameters of the forget-teacher with temperature smoothing applied
KL(...)Kullback-Leibler divergence (distance between two probability distributions)
D_FThe forget set (data to be unlearned)
D_RThe retain set (data whose performance must be preserved)
L_RRetain loss (e.g., language modeling loss on normal data)
lambdaHyperparameter balancing forgetting vs. retention
A tiny worked example
Original attention scores for 'president' attending to tokens: [10, 8, 2, 1, 1, 9, 2, 1, 1, 3, 1, 1]
With tau=1.0 (no smoothing): Softmax gives [0.85, 0.10, 0.01, 0.005, 0.005, 0.01, 0.005, 0.005, 0.005, 0.01, 0.005, 0.005]
→ High concentration: 'president' focuses heavily on two tokens.
With tau=2.0 (high smoothing): Scaled scores [5, 4, 1, 0.5, 0.5, 4.5, 1, 0.5, 0.5, 1.5, 0.5, 0.5]
→ Softmax gives [0.15, 0.10, 0.08, 0.07, 0.07, 0.12, 0.08, 0.07, 0.07, 0.09, 0.07, 0.07]
→ Low concentration: weight spreads evenly, old dominance is gone.

Dividing by a larger tau compresses the input to softmax, making the output more uniform. This flattens the token associations that encode memorized facts while preserving the model's ability to write coherent text.

What can go wrong

What can go wrong

Temperature too low. If tau is close to 1, the flattening is too mild and memorized associations survive. The model still leaks the secret.
Temperature too high. If tau is very large, the attention becomes so flat that it forgets useful associations needed for basic grammar and semantics. The model produces gibberish on normal tasks, not just forget-set questions.
Applied too broadly. If you smooth attention on retain-set data as well as forget-set data, the model loses general utility. The method works because smoothing is applied only to the forget set during distillation.
Done right. Tune tau on a holdout forget-set validation set, apply smoothing only in the distillation loss on D_F, keep a strong retain loss on D_R, and verify that the model produces coherent sentences on both forget and normal prompts.
What a runnable demo should prove

What a runnable demo should prove

Build a tiny language model (or fine-tune a small pre-trained one) and inject a few memorized facts (e.g. 'X was born in Y' for 10 people or facts). Split facts into forget and retain sets. Train the model on all of them, then unlearn the forget set using Attention Smoothing. Run two tests: (1) ask the model to complete 'X was born in' for each person and measure whether it still outputs Y (memorization score); (2) measure perplexity (how surprised the model is) on a set of normal sentences (a sample from Wikipedia or a standard benchmark) to verify it still understands language.

Memorization = count(correct completion for forget-set facts) / total forget-set facts Normal-language perplexity = exp(cross_entropy loss on normal text) Utility loss = perplexity after unlearning / perplexity before

A successful demo shows high memorization (>90%) before unlearning, drops to near zero after ASU, while normal-language perplexity stays close to pre-unlearning (within 5%), and output on forget-set prompts remains grammatical (not gibberish).
