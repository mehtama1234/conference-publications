Securing Multi-Agent Systems Against Corruptions via Node Contribution Backpropagation

Detect malicious agents in multi-agent systems by tracing backward from the final answer to measure how much each agent pushed the decision.

When a group of AI agents work together to solve a problem, a single corrupted agent can poison the whole team if nobody notices. This paper proposes a defense that works by drawing a map of which agent talked to which, then running numbers backward from the final answer to measure each agent's influence, revealing who is lying.

Zero assumption version

Poison in the pipeline

When one AI agent solves a problem by consulting other agents (asking them questions and using their answers), a single corrupted agent can poison the whole group. The corrupt agent sends false information, honest agents believe it because they have no way to detect the lie, and the false information gets mixed into the final decision. Nobody can trace where the wrong conclusion came from.

A naive first try: just watch for wild answers. If agent Carol says something totally different from everyone else, flag her. But this fails because a clever attacker can make small, believable tweaks that sound true enough that nobody notices, yet steer the final answer in the wrong direction. You also cannot catch corruption hidden inside how agents talk to each other; you only see the final answer and the public claims, not the internal influence.

In one sentence. This paper traces backward from the final answer to measure each agent's pull on the decision and catches who pushed it the wrong way.

The algorithm as a flow

What it actually does

Map the conversation

Reconstruct the chat history as a directed acyclic graph (a map with one-way arrows).

Score each link

Ask an independent LLM: did this agent's message push the final answer yes or no? Assign +1, 0, or -1 to each message.

Backward propagation

Starting from the final answer, multiply the link scores backward through the graph to compute each agent's total push.

Find the outliers

Compare each agent's contribution to the group median; those far outside the middle are suspects.

Repair and restart

Remove the malicious agent's messages and re-run the group decision.

What the paper changes

What the paper changes

The paper changes how you detect malicious agents: instead of watching for suspicious final answers, it measures each agent's contribution to the decision by running numbers backward through the conversation graph.

the object it moves  =  agent contribution scores
The hidden quantity

Agent contribution: the pull each agent exerts on the final answer

measured quantity  =  contribution score per agent

The contribution score is a single number for each agent that says: if we flipped this agent's answer from yes to no, how much would the final decision shift? A score of +1 means the agent pulled hard toward yes; -1 means they pulled hard toward no; 0 means they barely mattered.

The paper estimates it by doing a backward pass: start with the final answer (yes or no), then multiply backward through the communication graph. Each link between agents gets a signed score (from an independent LLM verifier) that says whether that message pushed toward yes (+1), no (-1), or was neutral (0). Multiplying these scores backward accumulates the total influence of each agent.

Why it works

Why it catches the liar

A malicious agent's influence travels forward through the graph: their false message affects other agents, who relay it onward, amplifying the lie. By tracing backward from the final answer, you accumulate all the paths by which that lie flowed in. A small lie that the liar whispered quietly may have gotten amplified through relay agents, so its cumulative effect is large. The backward pass catches this amplification because it sums over all paths and shows how much weight that agent's voice carried in the final decision.

The paper uses an independent LLM to score each message link: did this agent's statement push the final answer toward yes, no, or neither? This score is local to each link and can be done offline, so the defense does not require retraining. Then multiplication backward integrates all the path flows: if three relay agents each amplified the liar's message by a factor of 0.5, the backward pass multiplies 0.5 * 0.5 * 0.5, showing the liar's total effect.

Math after the picture

The formula for agent contribution

First in words:

each agent's total contribution is the product of all message scores on the paths from that agent to the final decision, summed across all such paths

Then the compact form:

C_i = sum over all paths p from agent i to final answer of ( product of g_ij for each edge j in path p )

Every symbol:

C_icontribution score for agent i (ranges from -1 to +1)
g_ijsigned score for message from agent i to agent j, computed by LLM as -1, 0, or +1
path pa sequence of messages from agent i through relay agents to the final answer
productmultiply all the scores together along the path to see cumulative effect
sumadd up effects across all paths the agent's words could have taken
A tiny worked example
Suppose agent Carol sends one message to agent Bob, who relays to final answer.
Carol-to-Bob message scores +1 (pushed toward yes). Bob-to-final scores +1 (also toward yes).
One path: Carol -> Bob -> Final. Product of scores: 1 * 1 = 1. Carol's contribution: 1 (she pulled hard toward yes).
Agent Alice sends to Carol and Carol-to-Bob score is +1, but Alice-to-Carol scores -1 (pushed toward no).
Alice's path: Alice -> Carol -> Bob -> Final. Product: -1 * 1 * 1 = -1. Alice's contribution: -1 (she pulled toward no).
Group median of all five agents' contributions is near zero (honest agents). Carol at +1 and Alice at -1 are far from median, so both are flagged as suspects.

The backward pass accumulates the cascade: a small lie amplified through relays shows up as a large contribution score, so you catch both direct liars and indirect influence.

What can go wrong

What can go wrong

Collusion of multiple liars. If two malicious agents coordinate their lies (both push in the same direction), their combined contribution looks normal to the group median because the majority is still honest. The defense assumes at least half the agents are truthful; if half or more are corrupt, detection fails.
Imperceptible perturbations. A malicious agent can make tiny, believable edits to their message (reword a phrase, add a qualifier) so the independent verifier LLM still scores it as mostly toward the right answer, but the cumulative effect across many tweaks steers the group subtly. The margin widens to 10% on such attacks, but detection is not perfect.
High-variance group decisions. If honest agents genuinely disagree and produce widely different contributions (e.g., some push toward yes, some toward no, by honest disagreement), the average becomes too spread out to use as a comparison. The defense confuses legitimate disagreement for corruption because all agents look like outliers.
Done right. Use the method on well-structured tasks where honest agents are more likely to agree, apply a majority threshold (flag only if over half agents are suspect, and majority are clear outliers), and retrain the verifier LLM on your domain to ensure fair scoring.
What a runnable demo should prove

What a runnable demo should prove

Build a five-agent team (using a small LLM or rule-based agents). Give them a factual question (e.g., What is the capital of France?). Inject one agent with a false instruction (always vote London). Run the team decision, then run the backward propagation. Measure the contribution score of the corrupt agent versus honest ones. Verify that the corrupt agent's score is a large outlier, remove it, and re-run: the group should now answer correctly.

Detection accuracy = (true positives + true negatives) / (total agents tested); Repair accuracy = correct answer rate after removing flagged agents

The demo should make it impossible to miss: with the corrupt agent, the group votes wrong and that agent's contribution score is a stark outlier; without it, the group votes right and all remaining contributions are balanced.
