Off-Policy Evaluation with Strategic Agents via Local Disclosure

When people change their observable features in response to a policy, use local explanations to recover what their features looked like before manipulation and then evaluate the policy with a two-part estimator that stays valid if either the response model or the outcome model is right.

Paper explainersAll themesOther

Off-policy evaluation asks a clean question: if we had used a different decision rule, how well would it have worked? Standard methods assume the observed features are exogenous, meaning they are not changed by the policy itself. That assumption breaks in strategic settings. Loan applicants, students, sellers, or workers may modify the features the system sees after they infer how the policy behaves. Once that happens, logged data no longer show the original state that the alternative policy would have acted on. This paper introduces a way to recover that missing structure. By giving local disclosure, meaning a post-hoc explanation of which nearby decision boundary or rule mattered, the system reveals enough information for the analyst to infer pre-strategic covariates, meaning the agents' features before they adapted. The paper then combines that response model with a two-part estimator that stays valid if either the response model or the outcome model is correct.

Zero assumption version

Strategic behavior breaks ordinary off-policy evaluation

In ordinary off-policy evaluation, you observe a feature vector for each agent, meaning the recorded list of input values for that agent, the action chosen by the logging policy, and the outcome. You then reweight or model those samples to estimate how another policy would perform.

With strategic agents, the observed feature vector is already policy-shaped. An applicant may take a course, change a portfolio, or rearrange reported information after learning what the system rewards. The observed data therefore combine the agent's original state with a strategic response to the current policy. If you ignore that shift, the counterfactual estimate is biased because the candidate policy would have acted on a different pre-response state.

The method in one sentence. Use post-hoc local disclosure to uncover enough of the pre-strategic state to model agent responses, then plug that model into a two-part policy-value estimator so one component can correct the other if either model is accurate.

The algorithm as a flow

What it actually does

Log decisions and disclosures

Store the action, outcome, observed post-response features, and the local explanatory information shown to each agent.

Model strategic response

Estimate how agents move from pre-strategic covariates to observed post-strategic covariates after seeing the disclosed local rule.

Infer hidden originals

Use the response model to estimate the distribution, meaning the weighted set of plausible original covariates, that could have produced each observed case.

Fit outcome and policy terms

Model outcomes under actions and compute importance weights for the target policy using the recovered original-state distribution.

Apply the two-part estimator

Combine the model-based prediction and the reweighting correction so the estimate stays valid if one of those pieces is right.

What the paper changes

What the paper changes

The paper changes the interface between policy and subject. Explanations are not treated only as a transparency feature. They become a data-collection device that reveals structure about how agents responded, which then makes off-policy evaluation possible in a one-shot strategic setting.

the object it moves  =  the information logged for policy evaluation
The hidden quantity

Pre-strategic covariates

measured quantity  =  pre-strategic covariates (the agent features before adaptation to the policy)

These original features are the missing variables that ordinary off-policy evaluation needs. Without them, you only see the manipulated endpoint. Local disclosure makes recovery possible because it tells you which nearby aspect of the decision rule the agent had reason to react to.

The paper assumes the cost sensitivity of changing features follows a conditional log-normal distribution, where log-normal means a positive random quantity whose logarithm follows a normal bell-shaped law after conditioning on observed information. That assumption gives a tractable response model. Once you can estimate how costly feature changes are for each agent type, you can back out which original states were plausible.

Why it works

Why disclosure can repair identification

Strategic response creates information asymmetry. The agent knows the starting point and the cost of moving features; the evaluator sees only the end result. That is why ordinary logged data are insufficient. A target policy estimate built on those data confuses genuine population differences with changes induced by the current policy.

Local disclosure reduces that asymmetry. When the system reveals the relevant threshold, margin, or influential local factors for the current decision, the agent's observed movement becomes interpretable. The response model can then connect the observed endpoint to a distribution over original states, because the move is now anchored to a known local decision pattern, meaning the nearby arrangement of decision directions and thresholds.

The two-part estimator adds protection against misspecification. If the inferred response distribution is slightly wrong but the outcome model is right, the estimate can still be consistent. If the outcome model is rough but the weighting term is right, it can still be consistent. That is why the combined estimator is preferable to relying on only one model component.

Math after the picture

The two-part value estimate

First in words:

policy value equals an average of predicted outcomes under the target policy plus a correction term that reweights observed outcomes by how likely the target policy would choose the logged action under the recovered original-state distribution

Then the compact form:

V_hat = (1 / n) * sum_i [ m_hat(x_i^0, pi_target) + w_hat_i * (y_i - m_hat(x_i^0, a_i)) ]

Every symbol:

nthe number of logged samples
x_i^0the recovered pre-strategic covariates for sample i
pi_targetthe policy whose value we want to estimate
m_hatthe fitted outcome model
a_ithe logged action for sample i
y_ithe observed outcome for sample i
w_hat_ithe estimated importance weight comparing target and logging behavior under the recovered original state
A tiny worked example
Suppose one sample has predicted target-policy outcome 0.60 from the recovered original state.
The observed outcome is 0.80, the model's prediction under the logged action is 0.50, and the importance weight is 0.5.
Its contribution is 0.60 + 0.5 * (0.80 - 0.50) = 0.75.
A second sample has predicted target-policy outcome 0.40, observed outcome 0.20, logged-action prediction 0.30, and weight 1.0, so contribution is 0.40 + 1.0 * (0.20 - 0.30) = 0.30.
Average those contributions over all samples to estimate target policy value.
The correction term matters because it repairs errors in the outcome model using observed outcomes reweighted by the recovered original-state distribution.

The estimate has two chances to be right, which is why the paper uses this two-part form instead of only prediction or only reweighting.

What can go wrong

What can go wrong

The disclosure signal is too weak. If the explanation reveals little about the local decision rule, many different original states remain compatible with the same observed endpoint. Recovery then stays ambiguous.
The response model is wrong. The conditional log-normal cost assumption may fail for some domains. If strategic effort has a very different shape, the recovered original-state distribution can be distorted.
Disclosure changes behavior itself. Explanations can alter future adaptation incentives. If agents respond differently because of the disclosure regime, the analyst must model that interaction directly instead of treating disclosure as passive.
Done right. Choose disclosures that reveal local policy structure without exposing irrelevant details, validate the response model on domains with known strategic movement, and monitor whether the explanation interface changes adaptation patterns.
What a runnable demo should prove

What a runnable demo should prove

Simulate a strategic classification setting such as lending or admissions. Generate original covariates, let a logging policy act, let agents move features according to a cost model, and record both the observed endpoint and the local disclosure shown to each agent. Hide the original covariates from the estimator.

Then compare three evaluators on a target policy: a naive evaluator that uses observed features directly, a model-based evaluator without disclosure, and the disclosure-based two-part method. Because the simulator knows the true original state and true target value, you can measure bias exactly.

value_bias = | estimated target value - true target value |

The demo should show that the disclosure-based estimator wins because it reconstructs the missing pre-strategic information instead of pretending the observed endpoint was exogenous.
