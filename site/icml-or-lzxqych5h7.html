Conditional Diffusion Sampling

Use parallel tempering to reach a good starting distribution, then apply an exact conditional transport SDE so multimodal sampling needs fewer expensive density evaluations than running tempering alone.

Paper explainersAll themesOther

Sampling from an unnormalized distribution, where unnormalized means you can evaluate a density up to a constant but cannot integrate it exactly, is difficult when the target has many separated modes. Parallel tempering handles this by running several replicas at different temperatures and swapping states so the sampler can cross energy barriers, but that costs many density evaluations. Diffusion-style samplers build a continuous bridge from a simple reference to the target, yet they usually need a learned score model. Conditional Diffusion Sampling combines the two ideas. It derives conditional interpolants with an exact random differential equation, where random means the path contains random noise, so no neural approximation is needed. Parallel tempering is used only to sample the hard initialization distribution, and then the exact transport SDE moves those samples toward the target.

Zero assumption version

Why multimodal targets are still costly to sample

A multimodal target has several high-probability regions separated by low-probability barriers. A local Markov chain can spend a long time inside one mode because proposed moves that cross the barrier are unlikely to be accepted. Parallel tempering addresses this with multiple temperatures, but it keeps paying for many chains and many swaps.

Diffusion-based sampling offers a different route: define a transport process from an easy reference to the target. The usual price is that you must train a score model for that transport. This paper asks whether the transport can be written in closed form, so the sampler keeps the continuity of diffusion methods without paying for neural training.

The central move. Use parallel tempering only where global exploration is hard, then switch to an exact conditional diffusion transport because short transport time makes the required initialization distribution cheap enough to sample.

The algorithm as a flow

What it actually does

Define a short conditional bridge.

Choose a finite transport time between an initialization distribution and the target so the resulting SDE has tractable dynamics.

Derive the transport SDE exactly.

Use the conditional interpolant construction to obtain a closed-form random differential equation, so the sampler does not need a learned score model.

Sample the initialization with parallel tempering.

Run tempering only long enough to obtain draws from the nontrivial initialization distribution because this is the stage that handles mode exploration.

Transport the samples toward the target.

Simulate the exact SDE from those initial draws so the path refines each sample into the target distribution.

Trade off initialization cost against transport time.

Use sufficiently short diffusion time so the initialization distribution is close enough to the reference that tempering cost stays moderate.

What the paper changes

What the paper changes

The paper changes sampling from a single-method design into a two-stage design that separates global mode exploration from local transport to the target.

The hidden quantity

The hidden quantity

measured quantity  =  initialization mismatch

The key hidden quantity is how far the initialization distribution is from the target at the moment the transport SDE starts. If that mismatch is large, the transport stage must do a long and difficult correction. If the mismatch is small, a short transport can finish the job cheaply.

CDS manages that mismatch by choosing a short diffusion horizon and by asking parallel tempering to sample only the corresponding initialization distribution rather than the full target. The abstract's main theoretical claim is that this initialization becomes cheaper for sufficiently short times, because short-time bridges stay closer to the simple reference law and therefore require less global exploration before transport begins.

Why it works

Why the two-stage sampler can beat either ingredient alone

Parallel tempering is strong at global exploration because high-temperature chains cross barriers that would trap a cold chain. Its weakness is that it keeps paying for this machinery even after global mode coverage has been achieved. Diffusion transport has the opposite profile. Once a sample is in the right region, a continuous bridge can refine it efficiently, but a poor initialization can make that bridge expensive or unreliable.

CDS combines the strengths in sequence. The first stage obtains a distribution that already covers the relevant modes. The second stage then applies exact local transport to correct the remaining mismatch. This works because the transport dynamics are available in closed form, so no score network has to be trained or approximated.

The short-time argument matters because the initialization distribution depends on the chosen bridge time. For sufficiently short times, that distribution is easier to sample than the full target, while still being close enough that the exact SDE can finish the transport. The paper's claimed advantage is exactly this balance: spend just enough tempering effort to reach a good start, then stop paying for full tempering.

A tiny worked example
Suppose the target has two modes separated by a high barrier.
A plain local sampler started in mode A rarely reaches mode B.
Parallel tempering can produce samples that visit both modes, but it keeps several chains running the whole time.
CDS uses tempering only long enough to produce draws from q_T that already cover both modes.
The exact SDE then moves each draw a short remaining distance into the final target, so the expensive global exploration stage stops earlier.

The exact bridge is the paper's main technical advantage because it removes the need for a trained diffusion score model.

What can go wrong

What can go wrong

The initialization can still be costly. If the short-time initialization law remains hard to sample for a given target, then the first stage can dominate cost and erase the advantage over full tempering.
Short transport time may be a delicate setting. If the transport horizon is too short, the initialization may be easy but the second stage may not correct enough mismatch. If it is too long, the initialization becomes harder to sample.
Exact transport does not remove discretization error. The SDE is exact in continuous time, but any implementation still simulates it with finite steps, so numerical error can enter if the step size is too coarse.
Done right. The method is strongest on multimodal targets where mode exploration and local transport are separable jobs, because then each stage can specialize in the part it handles best.
What a runnable demo should prove

What a runnable demo should prove

Use a two-dimensional mixture target with several separated modes and only unnormalized density access. Compare three samplers under the same density-evaluation budget: parallel tempering, a diffusion-style sampler with learned score approximation, and CDS. Measure mode coverage, sample quality, and total density evaluations.

The demo should also sweep the transport horizon T. It should show that an intermediate short horizon works best because the initialization remains cheap enough to sample, while the exact transport still has enough time to correct the remaining mismatch.
