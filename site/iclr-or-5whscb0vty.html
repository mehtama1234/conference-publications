Eikonal-Constrained Hierarchical Quasimetric Reinforcement Learning

A hierarchical goal-reaching method that treats distances as consistently expandable paths, letting agents plan across complex spaces without explicit reward design.

Paper explainersAll themesReinforcement Learning

Goal-conditioned reinforcement learning asks a robot: reach this goal, no rewards needed. The problem is that learning how far any state sits from the goal is hard when paths twist and loop. This paper reformulates the distance calculation using a mathematical principle from physics (the Eikonal equation, which governs how fronts propagate through space), then stacks it into levels: rough paths at the top, refined details below. The agent needs only example states and goals (no full trajectories). Because the smooth-field principle describes how distance must work in any space, the learned map works in new areas the agent has never seen.

Zero assumption version

Why distance learning is stuck

In normal reinforcement learning, a designer writes a reward function: +1 for reaching the goal, −1 for each step. But rewards are brittle—they are tied to one task. Goal-conditioned RL tries to be smarter: instead of a reward, the agent learns a value function—a map from any state to how close it sits to a given goal. Once that map is learned, the agent can reach any goal by following the map downhill.

The problem: in worlds with obstacles and long corridors, the true distance is not obvious. If you naively train on unrolled trajectories (the full path from a state to its goal), you have to see many trajectories to cover the space, and if the world changes, those trajectories are useless. A beginner might try: learn distances from whatever trajectories you have. But that breaks when paths are unseen—the agent confidently makes up distances and walks off cliffs.

The method in one sentence. Treat distance as a smooth field (like how sound propagates from a speaker) rather than a sum of discrete steps, then split learning into layers—rough global paths first, then local tweaks.

What the paper changes

The one thing the paper changes

The paper changes how the agent learns to estimate distance. Instead of summing up step-by-step costs from a trajectory, it learns distance as a continuous smooth field that respects the Eikonal principle: the gradient (slope) of the distance map always points in the direction of the shortest path, and has constant magnitude. This replaces a discrete, trajectory-dependent calculation with a smooth, space-consistent one.

the object it moves  =  distance field from discrete to smooth
The hidden quantity

The consistency principle: Eikonal constraint

measured quantity  =  how much the distance field violates the Eikonal principle

The Eikonal equation is a mathematical rule from physics: the magnitude of the slope of distance equals 1 everywhere (assuming unit-speed travel). Intuitively, if you draw circles around the goal at distance 1, 2, 3 steps, the perpendicular from any point to the next circle should be the same everywhere, because distance expands uniformly like a ripple. This is the hidden quantity the paper measures: for each state, how much does the learned distance slope deviate from magnitude 1?

The paper enforces this by penalizing violations: if a state's distance gradient has magnitude 0.7 or 1.3 instead of 1, that penalty goes into the learning signal. This forces the distance map to be internally consistent and generalizable, because a consistent map works the same way in new regions.

Why it works

Why hierarchy and smooth distance work together

A smooth distance field (from the Eikonal equation) alone is not enough when the world is complicated. Imagine a robot in a building with many rooms: a single smooth function cannot capture both the coarse structure (which room? through which doors?) and the tight details (navigate the corner). So the paper stacks two layers. The coarse layer learns rough distances across large regions—it can afford to be sloppy because it is only covering a mile, not an inch. Once that crude map is learned, the fine layer works locally: it refines distances where the coarse layer is wrong, especially near obstacles. Together, they form a quasimetric—a distance measure—that is both globally consistent (from the coarse layer) and locally accurate (from the fine layer).

Why does this win? Because the coarse layer only needs sampled states and goals, not full trajectories. A trajectory is expensive—it commits to one path. A sampled state is just a point in space. Each additional sample teaches the coarse layer independent information (a new region of the map), whereas each trajectory overlaps with previous paths and teaches redundant information, so sampled-point learning needs fewer total samples. The Eikonal constraint glues them together: the smooth field principle forces the agent to infer unseen distances correctly by analogy to seen ones. Hierarchy reduces data cost by splitting the task (coarse is faster to learn), and smoothness enables generalization because the same internal structure—distance expands uniformly—holds in new areas too.

Math after the picture

The Eikonal constraint written down

First in words:

total loss equals the distance prediction error, plus a penalty for Eikonal violations, plus a smaller penalty for any rough-fine layer disagreement

Then the compact form:

L = MSE(V_predicted, target_distance) + lambda_eik * sum_states ||∇V(s)|| - 1 ||^2 + lambda_hier * ||V_coarse(s) - V_fine(s)||^2

Every symbol:

V_predictedthe agent's current guess for distance from state to goal
target_distancethe true distance (estimated from sampled data)
∇V(s)the slope of the distance map at state s (direction and steepness)
||∇V(s)||how steep the distance is (its magnitude)
lambda_eikhow strongly to enforce Eikonal smoothness
lambda_hierhow much to keep coarse and fine layers agreeing
||·||^2squared size (turn every deviation into a penalty)
A tiny worked example
Suppose at state A: predicted distance is 5.0, true distance is 5.0, gradient magnitude is 0.95 (should be 1.0).
MSE loss: (5.0 - 5.0)^2 = 0.0 (prediction is spot-on).
Eikonal violation: |0.95 - 1.0| = 0.05, squared = 0.0025, times lambda_eik = 10 gives penalty 0.025.
If coarse layer said 4.8: hierarchy penalty |5.0 - 4.8|^2 = 0.04, times lambda_hier = 5 gives 0.2.
Total for state A: 0.0 + 0.025 + 0.2 = 0.225. The Eikonal and hierarchy penalties steer learning toward consistency, even when prediction is exact.

The Eikonal term forces the map to be everywhere consistent (like a real distance), and hierarchy decomposes the task so coarse learning is fast and fine learning is precise.

What can go wrong

What can go wrong

Very complex dynamics break the Eikonal assumption. The Eikonal principle assumes distance is smooth and expands uniformly. In chaotic systems, or worlds where optimal paths loop back on themselves (like a spiral staircase), the assumption breaks. The paper notes this limitation: the coarse-layer approximation can mask these breakdowns locally, but the fine layer still has to learn them independently, so hierarchy reduces but does not eliminate the problem.
Choosing the right layer boundary is not automatic. The method requires deciding which states belong to the coarse layer and which to the fine layer. Poor choices mean the coarse layer misses key bottlenecks, forcing the fine layer to learn the whole problem again.
Eikonal penalty must be tuned carefully. Set lambda_eik too high and the agent learns a smooth field that ignores the goal. Too low and it memorizes paths again. The right balance is task-dependent.
Done right: combine with data from diverse goals. When the training set includes many different goal types and the world is roughly navigable, the smooth field principle works: the agent learns structure once and reuses it for all goals.
What a runnable demo should prove

What a runnable demo should prove

Build a maze or robotic navigation task where the agent sees only a subset of the full state space during training. Give it a sampled set of state-goal pairs (no full trajectories). Measure: (1) how many examples does the agent need to reach 90% success on training goals? Compare to trajectory methods. The sampled-point method should converge in fewer examples because each point is independent. (2) Can it reach new goals in unseen regions of the maze correctly? (3) Does the learned distance map generalize to new mazes with different layouts?

success_rate = (goals_reached_in_unseen_area) / (total_unseen_goals), samples_to_convergence = how many state-goal samples needed before 90% success on train goals

The demo must show that without memorizing any trajectory, the agent reaches goals in completely new areas, and does it with fewer training samples than methods that learn trajectories explicitly.
