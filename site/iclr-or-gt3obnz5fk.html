AliTok: Aligned Tokenizer for Autoregressive Image Generation

Make image tokens predictable by training them one-at-a-time instead of all-at-once.

Paper explainersAll themesGenerative Models & Diffusion

When a model generates images one piece at a time, each new piece should depend only on the pieces that came before it. A piece (called a token in ML: a small encoded unit of the image) gets created this way. But standard image encoders create pieces by looking at the whole image at once, which means later pieces contain information from future patches, breaking this prediction chain. AliTok fixes this by adding a causal decoder (a decoder that only reads previous pieces) during encoder training, forcing the encoder to organize all the context it needs inside each piece's history.

Zero assumption version

The Tokenizer-and-Sequential-Predictor Mismatch

Image generation happens in two stages. First, a tokenizer shrinks an image down to a sequence of small encoded units called tokens (like turning a photo into a short code). Second, a sequential predictor learns to guess each token using only the tokens that came before (this is called autoregressive: building the sequence one step at a time, using only history). A beginner might assume: if the tokenizer does its job well, the predictor will be easy to train. But this breaks because standard tokenizers use bidirectional encoders, which look at the entire image to decide what each token should be. Later tokens peek at future patches, creating information that leaks forward. When a sequential predictor then tries to guess token 5 using only tokens 1-4, it is missing important context that the tokenizer had when it created token 5, because token 5 was built with a sneak peek at patches 6, 7, 8. The model keeps guessing wrong because the tokenizer is not playing fair.

You could try retraining the tokenizer from scratch with new rules, but that is slow. Or you could fiddle with the sequential predictor to guess better, but the fundamental problem stays: the token sequence was designed by a bidirectional process (looking at all patches), not a forward-only process (looking at only earlier patches). The sequential predictor is built to guess one token at a time from earlier tokens, but the encoder put information about future patches into current tokens because it could see the future. This is a permanent mismatch that no post-hoc tuning can fix.

In one sentence. AliTok retrains the existing tokenizer encoder under the constraint that it must reconstruct patches using only its own token plus earlier tokens, forcing it to hide all future information inside each token.

The algorithm as a flow

What it actually does

Start with bidirectional encoder and decoder

Standard tokenizer built by training on whole images, both directions allowed.

Plug in a causal decoder

Replace the decoder with one that sees only the current token plus earlier ones.

Freeze encoder and decoder, train only the encoder

The encoder must learn to compress the image into tokens that work under this new asymmetric loss.

Add prefix tokens and auxiliary loss

First row of patches has no history; extra prefix tokens prime it with context.

Retrain a new decoder on the frozen tokens

Second stage decoder (bidirectional again) reads the causal tokens to improve reconstruction detail without breaking generation, because the encoder is locked.

What the paper changes

What the paper changes

AliTok changes the token dependency structure: instead of all tokens built from the whole image at once, tokens are retrained so they can be reconstructed one-at-a-time using only their causal history plus the decoder's access to earlier tokens.

The hidden quantity

Causal predictability: how much can you guess from the past

measured quantity  =  causal predictability

Causal predictability measures whether a token's content can be rebuilt using only information available up to and including that token. A token has high causal predictability if the decoder can reconstruct its patch using (1) the token itself and (2) only earlier tokens. A token has low causal predictability if you need to peek at later tokens to fill in the details. Standard tokenizers score low because they were built with full-image context. AliTok's tokens score high because the training loss explicitly penalized the encoder if later tokens held information not in the causal chain.

The paper estimates causal predictability by measuring reconstruction loss under the causal decoder constraint. When the loss is low, the token sequence is highly predictable. The autoregressive model benefits directly: each token it predicts carries the right kind of information, because the tokens were built that way.

Why it works

Why forcing a causal decoder remakes the encoder

Here is the core insight: an encoder is trained by adjusting its weights to shrink the loss (the error between what it produced and what we wanted). The loss measures how well the decoder can reconstruct patches from tokens. When the decoder is bidirectional, the encoder learns to pack information anywhere in the tokens because the decoder will read the whole sequence. But when you swap in a causal decoder that forbids reading future tokens, the same encoder produces terrible reconstructions because its tokens do not carry the right information at the right place. The loss then forces the encoder to reorganize: it learns to move context earlier so each token is usable. Information that was hidden in token 7 gets pushed into tokens 1-6, because token 7 can only read tokens 1-7. After enough weight adjustments, the encoder settles into a new pattern where each token is self-contained within its causal history. This is not a new encoder; it is the old encoder relearned under asymmetric loss.

The prefix tokens solve a boundary problem. The first row of image patches has no earlier tokens to learn from. Without help, the causal decoder would fail on the first row because there is no history to draw from. The prefix tokens (extra learned number-lists) provide fake history, guided by an auxiliary loss that ensures they help reconstruction. The two-stage strategy then keeps this predictable token structure but reintroduces a bidirectional decoder in stage 2 to polish details without breaking generation (because the encoder is frozen, and the sequential predictor only reads the frozen tokens).

The causal reconstruction loss

First in words:

Total loss equals reconstruction loss plus perceptual loss plus quantization loss plus adversarial loss plus auxiliary loss on prefix tokens.

Then the compact form:

L_total = L_mse + L_perc + L_quant + L_adv + L_aux

Every symbol:

L_msemean squared error between original patch and reconstructed patch
L_percperceptual loss measuring visual detail agreement
L_quantloss from rounding tokens to discrete codes
L_advadversarial loss encouraging realistic reconstructions
L_auxauxiliary loss on prefix tokens, guiding them to provide context for first row
A tiny worked example
Suppose an image has 256 patches arranged in 16×16 grid. Stage 1 trains with causal constraint.
Token 50 is in row 4. It can use tokens 1-50 for reconstruction but cannot peek at tokens 51-256.
Old bidirectional encoder would pack patch-51 info into token 50. Reconstruction loss is low.
Causal decoder cannot read token 50 into patch 51 (wrong direction). Loss spikes on reconstruction of patches 51+.
Backprop nudges encoder: push patch-51 info into tokens 51+ instead. Token 50 focuses on patches 1-50.
After retraining, token 50 is predictable: autoregressive model can guess it from tokens 1-49.

The total loss forces the encoder to hide each patch's information inside (or before) its own token position, breaking bidirectional dependencies.

What can go wrong

What can go wrong

First-row artifacts without prefix tokens. The causal decoder sees only the current patch and history. For the first row, there is no history. Without prefix tokens, the decoder reconstructs the first row poorly because it is flying blind. This creates visible stripes or blur in generated images. AliTok fixes this by adding extra learned prefix number-lists that stand in for missing history.
Reconstruction quality drops if only stage 1 is used. Retraining the encoder under causal constraint helps generation but can degrade fine details because the token space is reshaped. AliTok's stage 2 (retraining a bidirectional decoder on frozen encoder and codebook) restores detail without breaking generation, because the encoder is locked, and the autoregressive model never reads the stage-2 decoder.
Autoregressive model still requires careful training. AliTok makes tokens predictable but not automatic. The sequential predictor must be trained on the token sequences. If learning rate or architecture is wrong, generation still fails. The alignment is necessary but not sufficient.
Done right. Train stage 1 with causal decoder and prefix tokens, then stage 2 with frozen encoder. Sequential predictor then learns a clear, predictable token sequence. Generation is 10 times faster than diffusion because the sequential predictor only needs to run prediction (when the finished model answers a question) once per image position, whereas diffusion requires 50-100 iterative denoising steps, and it reaches the best-known fidelity scores because tokens carry both predictability and detail.
What a runnable demo should prove

What a runnable demo should prove

Build a small image tokenizer on a toy dataset (e.g., a 32x32 crop set). Train the encoder under two conditions: (1) with a bidirectional decoder (standard), and (2) with a causal decoder (AliTok). For each, measure how well an autoregressive model can predict token sequences over a fixed number of training steps. Optionally: sample from both autoregressive models and measure visual fidelity via a lightweight metric (e.g., L2 distance between reconstructed crops and originals).

Token prediction accuracy = (number of correct next-token predictions) / (total predictions)

A causal-trained tokenizer will show faster accuracy growth in the autoregressive model compared to a bidirectional tokenizer, because tokens are predictable from the start.
