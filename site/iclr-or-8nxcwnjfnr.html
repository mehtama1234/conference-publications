EvoPresent: Self-Improving Presentation Agents

A self-improvement agent learns to score and adjust presentation aesthetics, so presentations can iterate toward better visual and narrative quality.

Paper explainersAll themesAgents & Tool Use

Academic papers live or die by how well they are presented. But making a great presentation by hand takes skill: the slides need to look good, tell a coherent story, and keep viewers interested. This paper introduces EvoPresent, an agent that watches presentations, grades their aesthetics, spots problems (like cluttered slides or weak narration), and suggests fixes. Then it tries again. The agent improves through repeated self-correction because each score tells it whether the last change moved in the right direction, so it learns which edits work.

Zero assumption version

Why presentations stay bad

Today, when you use software to create a slide deck or video presentation automatically, the output is predictable: text crammed into corners, images placed randomly, and narration that recites facts without drama. The software made something, but nobody wants to watch it.

A beginner might try to improve this by adding more rules: Make text bigger. Use brighter colors. But rules are rigid. One rule breaks another. And most importantly, you have no way to judge whether your fix actually made things better, because aesthetic quality is vague and context-dependent. There is no objective score, so the system has nowhere to aim.

The real stuck point. An automated presentation system cannot improve itself without a reliable way to measure whether it succeeded, because without measurement, any change is equally likely to make things worse, so there is no signal to learn from.

What it actually does

A trained neural model scores a slide presentation on aesthetics: layout clarity, color harmony, visual balance, text readability.

Identify defects

The model flags specific problems: overcrowded text, misaligned elements, weak color contrast.

Agent receives feedback

The agent sees the score and the defect list, and knows: this presentation scored 3 out of 10 aesthetically.

What the paper changes

What the agent changes

The agent modifies the presentation itself: slide layouts, text content and size, color choices, image placement, and the script that a virtual character reads aloud. Each iteration changes these elements based on feedback from the aesthetic scorer.

the object it moves  =  Presentation slides, visuals, and narration
The hidden quantity

The hidden quantity: presentation aesthetic score

measured quantity  =  Aesthetic coherence and visual quality

Aesthetics in presentations is normally invisible and unmeasurable. This paper gives it a concrete name and measure: the aesthetic score. It captures how visually balanced a slide is, how readable the text, how well colors harmonize, and how clear the visual hierarchy — whether the slide guides the viewer's eye to what matters.

PresAesth (the neural model) estimates this score from a presentation's visual features. It also performs two related tasks: identifying specific defects (cluttered layout, weak contrast, unclear narration) and comparing two presentations to say which one is more aesthetically pleasing. All three tasks train together.

Why it works

Why self-correction via scoring actually works

The core insight: an agent cannot improve something it cannot measure, because without a measurement, it has no way to know whether a change moved toward the goal or away from it. If you say 'make the presentation better' but offer no score, the agent has no signal to learn from and will thrash randomly, because every change is equally likely to succeed or fail.

By giving the agent a reliable aesthetic score (from PresAesth), the agent gains a clear goal. Every change can be judged: Did the score go up? If yes, keep that kind of change. If no, try something different. Over many rounds, the agent learns which tweaks move the score in the right direction, because the feedback is immediate and unambiguous. It builds intuition about what makes presentations work.

The score must be high-quality and reliable. The paper shows that if the scorer is noisy or biased, the agent learns bad habits and stalls, because it is optimizing for the wrong target. But with a well-trained scorer, the agent reliably improves itself, even starting from poor presentations. The multi-task training (scoring + defect detection + comparison) makes PresAesth effective because it learns from multiple angles at once. Different viewpoints catch errors that a single viewpoint would miss.

The aesthetic reward signal

First in words:

The agent uses PresAesth's score as a reward signal in reinforcement learning. Formally, the agent learns a policy (a strategy for editing slides) that maximizes expected aesthetic score, where the score comes from multiple evaluation tasks.

Then the compact form:

Score = weighted_sum(aesthetics_task_score, defect_detection_task_score, comparison_ranking_task_score)

Every symbol:

aesthetics_task_scoreDirect rating of a single presentation on a 0-10 scale
defect_detection_task_scoreHow well the model identifies specific visual problems
comparison_ranking_task_scoreHow well the model ranks two presentations by quality
weighted_sumCombine the three scores, giving each one appropriate importance
A tiny worked example
Presentation A: aesthetics rating 4/10, defect detection accuracy 0.7, ranking task accuracy 0.6.
Combined (equal weights): (4 + 7 + 6) / 3 = 5.7 out of 10.
Agent adjusts: removes clutter (improves aesthetics to 6), improves layout consistency (defect accuracy rises to 0.85), clearer visual hierarchy (ranking accuracy rises to 0.8).
New combined score: (6 + 8.5 + 8) / 3 = 7.5 out of 10.
Agent sees the improvement and learns: this kind of change (simplify, align, emphasize) boosts the score.

The multi-task score ensures the agent learns balanced improvement: not just high ratings, but actually fixing real defects and winning comparisons against alternatives.

What can go wrong

What can go wrong

Scorer is noisy or biased. If PresAesth itself is poorly trained, it gives bad feedback. The agent then learns to game the bad scorer, making presentations that score high but look worse to humans, because the agent optimizes for whatever signal it receives. The paper shows this explicitly: a bad scorer leads to no real improvement because the agent chases the wrong target.
Agent gets stuck optimizing one narrow metric. If the score only measures text size, the agent will make all text huge and wreck the layout. The multi-task training helps: scoring + defect + comparison together prevent narrow optimization, because balancing three different viewpoints prevents the agent from chasing a single proxy that diverges from real quality. But if the weights are wrong, one task can dominate and unbalance improvement.
Narration and visuals drift apart. The agent adjusts slides and narration separately. If they lose sync (e.g., the voice describes a diagram that no longer appears), the presentation becomes confusing. The model must jointly optimize all modalities.
Done right: multi-task, well-trained scorer. When PresAesth is trained on diverse presentations with real human feedback, and the agent is given all three tasks (score, defect, rank) with balanced weights, presentations reliably improve across many rounds, because the aligned feedback signal and balanced objectives eliminate both noise and narrow gaming.
What a runnable demo should prove

What a runnable demo should prove

Take a real academic paper. Generate an initial presentation automatically (minimal effort). Let EvoPresent iterate for 5 rounds. Measure the aesthetic score at each step. Also ask humans: does this presentation tell the story clearly? Is it engaging? Does it guide your eye to the key claims?

Improvement = aesthetic_score_round_5 - aesthetic_score_round_1; Human preference rate = fraction of judges who prefer round 5 over round 1

The demo must show that the aesthetic score climbs monotonically (or mostly monotonically) with each iteration, proving the feedback loop works and the agent is learning from its scores. It must also show human judges agree the later presentations are genuinely better to watch, because correlation between algorithm and human judgment validates that PresAesth is capturing real quality.
