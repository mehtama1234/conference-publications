Brain Networks Are More Than Pairwise Connections

Current neural network models, called graph neural networks or GNNs, work by treating the brain as a set of individual neurons linked by edges. Each edge is a connection; the model passes messages along edges. One neuron fires, and the message travels to its neighbors.

But brain neurons do not just talk in pairs. Multiple neurons fire together in chains: A fires, then B receives it and fires, then C receives from B and fires. Or they form groups: three or more neurons activate together, not from separate pairwise interactions. A beginner tries to handle this by adding more edges or training for longer, but this misses the real structure. The algorithm sees static pairwise connections when it should see directed chains and higher-order groups.

So existing models fail to capture what makes brain activity distinctive: the directed flow of information (some connections are one-way) and the way neurons team up in groups of three, four, or more.

The fix. Build a neural network that treats neurons as building blocks in a directed higher-order structure—a simplex set. Because chains and groups are now explicit structures the model sees, the learning algorithm can assign importance scores and select which ones to use, fixing the core problem that pairwise edges miss the real flow.

The algorithm as a flow

What it actually does

Step 1: Build the structure

Take the active neurons at each moment and form all possible chains and groups where direction matters.

Step 2: Define relations between units

Specify which chains and groups touch each other (e.g., two triangles sharing an edge, or a chain feeding into a group).

Step 3: Route through relations

For each unit, compute which relations are most informative and pass messages along the selected paths only.

Step 4: Update features across the structure

Each unit learns new features from its incoming chains and groups, weighted by the routing decision.

Step 5: Classify or decode

The final layer reads the enriched features and makes a prediction (e.g., which brain state, which stimulus).

What the paper changes

What the Paper Changes

Standard graph networks pass messages along edges (pairwise). This paper routes messages along chains and higher-order groups (simplices), including directed flow. The routing is learned: for each unit, a gating function (a small decision network) picks which chains and groups to listen to, so important structure gets more signal and noise gets filtered.

the object it moves  =  routing paths through directed chains and groups
The hidden quantity

The Hidden Quantity: Directed Relation Importance

measured quantity  =  which chains and groups matter most

When neurons fire, not all relationships are equally informative. Some chains carry strong signals, others are noisy. Same for groups. The paper measures a hidden quantity: the importance score for each directed chain or group. This score answers: how much does the model's accuracy drop if this chain or group is removed? High score means removing it hurts, so the chain or group carries real information about brain state. Low score means the signal is noise. The model uses this to weight each relation's messages: important chains get more say in the next layer, noisy ones get muted.

The method estimates this via a gating function—a tiny neural network that scores each relation (chain or group) for each neuron. High score means the model learns to route information through that path; low score means mute it. The gating is part of the training, so importance scores adapt as the model learns.

Why it works

Why It Works: Structure Lets the Model See Real Flow

Neurons in the brain are not isolated; they work in hierarchies. A single neuron firing tells you less than a chain where one fires, then the next, then the next—the sequence carries information. A group of three neurons co-activating encodes information that three separate pairs miss. Standard graph networks flatten this: they only know edges.

By lifting the network into a simplicial set (a structure where chains and groups are explicit), the learning algorithm can now ask: does this chain carry signal? Does this group? The gating mechanism learns to route—to say yes to informative paths and no to noise. This works because the model is not trying to detect chains and groups from edge signals alone; the structure is already there, and the model just learns which ones matter. For brain data specifically, this works because the brain naturally has this hierarchy: neurons form local circuits, circuits form brain regions, regions coordinate. The directed aspect (flow from one neuron to the next is different in reverse) is critical because neural signals are often one-way.

The math ensures permutation equivariance: if you reorder the neurons (or simplices), the computation is the same. This guarantees the model learns real structure, not arbitrary orderings.

The Core Equation

First in words:

For each unit at layer l, compute new features by taking incoming messages from all relations, score each relation's importance, and aggregate the high-scoring ones.

Then the compact form:

X^{l+1} = phi( X^l, sum over relations R { gate_R(X^l) * message_R(X^l) } )

Every symbol:

X^lfeatures of all units at layer l
X^{l+1}updated features at layer l+1
Ra directed chain or group (a relation)
gate_R(X^l)importance score for relation R (between 0 and 1)
message_R(X^l)information passed along relation R
phia learned nonlinearity (e.g., ReLU)
sum over relations Rweighted sum across selected relations
A tiny worked example
Suppose one unit has incoming messages from 3 relations: chain A→B, group A∧B∧C, and edge A–B.
Chain A→B message: [0.8, 0.6], gate score: 0.9 → weighted: [0.72, 0.54]
Group A∧B∧C message: [0.5, 0.7], gate score: 0.7 → weighted: [0.35, 0.49]
Edge A–B message: [0.3, 0.4], gate score: 0.2 → weighted: [0.06, 0.08]
Sum: [0.72+0.35+0.06, 0.54+0.49+0.08] = [1.13, 1.11]
Apply nonlinearity phi: activation ~[1.13, 1.11] → output ~[1.13, 1.11] (after ReLU).
High-scoring relations (chain, group) dominate; low-scoring edge (0.2) contributes little.

Each relation's message is weighted by its learned importance score, so the network learns to mute noise and amplify signal.

What can go wrong

What Can Go Wrong

Mismatch between network structure and brain organization. If the active neurons at each time step do not actually form chains or groups with clear sequence or grouping (e.g., all neurons fire simultaneously with no hierarchy), the model gains no advantage over simpler methods. The paper works on data where such structure exists.
Imbalanced routing (some relations overloaded). Early in training, the gating can collapse: all messages route through a few relations, others are zeroed out. This hurts performance. The paper adds a regularization term (load balancing) to prevent it, but if that penalty is tuned wrong, routing can still fail.
Computational cost grows with group size. As the number of possible chains and groups increases (e.g., in larger brains), message passing becomes expensive. Routing helps by pruning unimportant relations, but pathological cases (fully connected neurons) can still be slow.
When routing and load balancing are tuned correctly. The model learns to route selectively, focusing on chains and groups that genuinely predict brain state, and computational cost stays reasonable.
