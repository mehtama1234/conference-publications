Sparse Imagination for Efficient Visual World Model Planning

Skip most image patches during forward prediction to let robots plan in real-time, training the model to work with random subsets so it generalizes to any sparsity level.

Paper explainersAll themesRobotics & Control

Robots need to imagine future moves before deciding. The standard way is to process every piece of a camera image, but that takes too long on tiny computers. This paper trains the robot's prediction model to work with only random pieces of the image at a time, letting the robot choose how many pieces to keep based on available compute. The model learns to make good predictions even when some patches are missing.

Zero assumption version

Planning on a tiny computer hits a speed wall

Robots predict the future by running their image through a neural network (a mathematical model trained to recognize patterns). Each image is broken into many small square patches, like pixels on a checkerboard. A typical approach feeds all patches into a transformer (a model that learns which parts matter by comparing each patch to all others), and this whole process takes hundreds of milliseconds. On a robot with limited battery, tiny memory, and no GPU, this is too slow. By the time the robot finishes imagining a move, the world has changed.

A beginner might try: drop a random patch and hope the model still works. But the model was trained on complete images, so it falls apart when patches vanish. It cannot find the objects or reason about where things will move. Attention maps (the model's way of deciding which patches matter) suddenly point to empty space. The robot becomes blind to sparse input.

In one sentence. Train the model using random groups of patches so it learns to predict reliably from any sparse subset the robot needs.

The algorithm as a flow

What it actually does

Extract patches from camera image

Pre-trained DINO encoder breaks image into 196-400 square patches, frozen to stay stable.

Randomly select which patches to use

Drop patches randomly when the model runs to match available compute, reducing from 196 to 50 or 100.

Pass only selected patches through transformer

Transformer predicts next image using only the kept patches, skipping comparisons with dropped ones.

Train using grouped attention strategy

During learning, split patches into random groups; patches only attend within their group, building flexibility.

Let robot choose sparsity level at runtime

Same trained model: 10% patches for instant planning, 50% for more accuracy, 100% if time permits.

What the paper changes

The thing that moves: which patches get processed

The paper changes which image patches are fed into the prediction model. Normally all 196 patches from a frozen encoder go to the transformer. Here, a random subset (50, 100, or any number) skips the transformer entirely. The model predicts the next state using only the kept patches.

the object it moves  =  image patch selection
The hidden quantity

The hidden quantity: prediction accuracy under patch dropout

measured quantity  =  accuracy when patches are missing

This is the model's ability to predict accurately when arbitrary patches are missing. Most models rely on attention connecting every patch to every other, so dropping patches breaks spatial reasoning. The paper's core trick lets the model infer the missing pieces' effects from the remaining ones.

The paper measures this during training by using randomized grouped attention (patches only see others in their random group, simulating sparse input), then testing on held-out videos whether the model predicts the next image correctly when some patches are dropped. If the model predicts accurately even when 70% of patches are missing, the robot can safely drop 70% at runtime to save compute, because the model has already learned to handle that sparsity level during training.

Why it works

Why it works: learning to fill in gaps beforehand

The core trick is training, not testing. The paper does NOT simply drop patches at test time. Instead, during training, it groups the patches into random subsets and teaches the transformer to only attend within each group (a group only sees other patches in the same group, not the world). By randomizing the groups across training steps, the model learns a shared internal language where each patch can infer neighboring patches' effects without explicitly attending to them. It builds redundancy: if patch 5 (top-left corner) usually connects to patches 4 and 6, then when patch 4 vanishes, patch 5 still encodes what it learned about the top-left.

When the model runs (at test time), you apply the same dropout randomly, but now the model is ready. Its learned features are no longer brittle; they encode spatial relationships implicitly. Attention maps no longer point to missing patches because the model has internalized spatial neighborhoods. The result is high prediction accuracy even with 70-90% patches dropped, and fast inference because the attention computation (comparing many patches to many patches) is smaller.

Math after the picture

Equation: prediction loss with sparse patches

First in words:

The model is trained to minimize mean squared error between predicted patch tokens and actual next-frame tokens, computed only over the selected (non-dropped) patches. At test time, the dropout rate is set by the robot based on its compute budget.

Then the compact form:

L = mean_squared_error(predicted_tokens_sparse, target_tokens_sparse) where sparse selection is applied both at training (via grouped attention) and at inference (via random dropout)

Every symbol:

predicted_tokens_sparsethe model's guess for the next image, using only kept patches
target_tokens_sparsethe actual next image patches (ground truth, same sparse subset)
mean_squared_errorsum of squared differences between guess and truth, divided by number of patches
grouped attention during trainingmasks that limit each patch to see only others in its random group
random dropout at test timethe robot chooses how many patches to keep (50%, 70%, 90%, etc.)
A tiny worked example
Suppose we keep 4 patches out of 16 (25% retention).
Predicted next frame for those 4: [0.2, 0.5, 0.8, 0.3].
Actual next frame for those 4: [0.3, 0.5, 0.7, 0.4].
Errors: [0.1, 0.0, 0.1, 0.1].
Squared errors: [0.01, 0.00, 0.01, 0.01].
Mean squared error: (0.01 + 0 + 0.01 + 0.01) / 4 = 0.0075.
Same loss computation as full attention, but 4x fewer patches means 16x fewer attention operations.

The math is simple: only the kept patches contribute to the error signal. The genius is in training—by exposing the model to random groups during learning, it develops features that generalize to any sparse subset at test time.

What can go wrong

What can go wrong

Encoder quality is the ceiling. The frozen DINO encoder determines which patches contain useful information. If DINO misses fine details (say, small object edges), sparse selection cannot recover them. Sparse imagination amplifies encoder blindness.
Grouped attention is not free at training. Training with grouped attention slows convergence and adds memory overhead (storing random group masks for every step). The speedup only appears at test time.
Some tasks need every patch. Precision-demanding tasks (like threading a needle or stacking tiny blocks) may not tolerate 70% dropout. The paper tests on locomotion and grasping; YMMV on assembly.
Done right: the speedup scales with sparsity. If you drop 70% of patches, attention compute shrinks roughly 50x (since comparing patches against each other scales quadratically with count). Real robots gain real latency wins.
What a runnable demo should prove

What a runnable demo should prove

Build a tiny visual prediction model on a standard dataset (e.g., MuJoCo robot reaching or Atari frames). Train it normally on all patches for 10k steps, then retrain with randomized grouped attention (50% dropout during training) for 10k steps. At test time, roll out trajectories while varying the dropout rate: 0%, 25%, 50%, 70%, 90%. For each dropout rate, measure (a) prediction loss on held-out video frames and (b) task success rate if using the predictions for planning (e.g., picking an object).

degradation = (accuracy_at_50pct_dropout - accuracy_full) / accuracy_full * 100% [should be <10% for grouped-attention model, >50% for baseline]

The demo must make it obvious that grouped attention during training is the only reason sparse inference works; naive dropout fails hard.
