HARP: Hallucination Detection via Reasoning Subspace Projection

A model's hidden thinking can be split into two pure parts: the words it will say, and the reasoning underneath; filtering down to reasoning alone makes hallucination detection much cleaner.

Paper explainersAll themesInterpretability

Large language models generate text by building up internal thought across many layers, but sometimes they hallucinate—saying things that are not true or justified. HARP shows that a model's hidden states live in a mathematical space with two distinct parts: one that encodes what words to use (semantic), and one that encodes internal reasoning steps. By extracting only the reasoning part and discarding the semantic noise, HARP detects which answers are real knowledge and which are made-up, with far fewer false alarms.

Zero assumption version

Why hallucination detection is hard

When a large language model answers a question, it builds up a hidden state—an internal number-list that changes as it processes each word. That hidden state contains everything: the vocabulary it is pulling from, the surface words, the grammar, AND the actual reasoning about the facts. A naive detector looks at the hidden state as a whole to guess if an answer is hallucinated, but it gets confused because it cannot tell whether a strong signal is saying the right thing confidently or confidently saying something wrong.

Existing methods measure things like how smoothly the model's confidence flows (Perplexity) or how jumbled the internal word-probabilities are (Entropy), but these signals mix together the semantic noise (vocabulary choices, phrasing style) with the real reasoning underneath. The result: high false-alarm rates, especially when the model is trained on one dataset and tested on another.

The core problem in one sentence. Hidden states contain both semantic signal (word choices) and reasoning signal (actual knowledge), mixed together so tightly that you cannot tell a confident hallucination from a correct answer.

The algorithm as a flow

What it actually does

Step 1: Collect and analyze the Unembedding layer

Take the matrix that converts hidden states into word probabilities; run a factorization (SVD) to find its basis directions (core directions in the number-space).

Step 2: Identify semantic and reasoning basis directions

The factorization reveals which directions point to word-choice (semantic) and which to reasoning; keep the reasoning directions.

Step 3: Gather hidden states from all layers

As the model processes the question, collect its internal state at each step; shallow layers are mostly semantic, deep layers mostly reasoning.

Step 4: Project hidden states onto reasoning subspace

Strip away the semantic noise by keeping only the reasoning component; discard the 95% that is semantic chatter.

Step 5: Train a simple detector on these clean features

Use a classifier (e.g. logistic regression) to learn which reasoning patterns mean true knowledge vs. hallucination.

What the paper changes

The thing the method changes

Before HARP, the detector used the whole muddy hidden state. HARP throws away the semantic part and keeps only the reasoning part—shrinking the feature from thousands of numbers down to a few dozen, with 95% noise removed.

the object it moves  =  Hidden state becomes reasoning subspace projection
The hidden quantity

The hidden quantity: Reasoning subspace content

measured quantity  =  Reasoning-to-semantic ratio

HARP measures which fraction of each hidden state belongs to pure reasoning (knowledge and logic) versus pure semantics (word choices and phrasing). In mathematical terms, hidden states lie in a vector space (just a list of numbers); HARP decomposes this space into two perpendicular pieces: one that Unembedding uses to output words, and one that Unembedding ignores. The reasoning piece is the ignored part—the internal thinking that does not drive the current token (the next word) choice.

The paper estimates this split using Singular Value Decomposition (SVD), a standard algebra tool that factors the Unembedding matrix into its core directions. By applying SVD to the output layer's parameters, the paper finds exactly which input directions the output layer responds to (semantic subspace) and which it does not (reasoning subspace). The more a hidden state points into reasoning directions, the cleaner the hallucination signal. A token is the word or piece of a word that the model outputs one at a time.

Why it works

Why filtering reasoning makes hallucinations obvious

When an LLM hallucinates, it is often because the semantic part of the hidden state is very smooth and confident—it picked words fluently and generated plausible-sounding text. But the reasoning part is weak or incoherent—there is no actual knowledge backing it up. By discarding the semantic part, you remove the false confidence that makes hallucinations deceptive. What remains is pure reasoning signal: does this answer follow from the facts the model saw? Real knowledge shows up as strong, coherent reasoning directions. Hallucinations show up as weak, tangled ones.

Why is SVD the key? The Unembedding layer (the final matrix that converts hidden states to word scores) has been trained to predict the next token; if a hidden direction strongly predicts the next word, the output layer has learned to respond to it. Those are semantic directions. Directions the output layer ignores are reasoning directions—internal scratchpad that the model uses for multi-step thought but does not immediately express. By factorizing the output layer, HARP reads off this distinction without training anything new. It is like reading the model's own blueprint.

The projection formula

First in words:

Clean reasoning feature equals the original hidden state projected onto the reasoning basis vectors

Then the compact form:

h_reasoning = sum_i (h · v_i) * v_i, where v_i are reasoning basis vectors from SVD(W_unemb)

Every symbol:

hthe hidden state at some layer (a list of numbers)
v_ione reasoning basis vector (found by factoring the output layer)
h · v_ihow much this hidden state points in the direction v_i
(h · v_i) * v_ithe reasoning component in that direction
W_unembthe output layer's parameter matrix (converts hidden to word scores)
SVDa matrix factorization that finds the most important directions
A tiny worked example
Suppose a hidden state h = [8, 2, 6, 1, 9, 0, 5, 3, 7, 4, 1, 2] (12 numbers).
SVD of Unembedding reveals 3 reasoning basis vectors: v1, v2, v3 (the directions the output layer does not use).
Project onto v1: h·v1 = 2.1 (this hidden state has a medium-strong component in direction v1).
Project onto v2: h·v2 = 0.8 (weak component in direction v2).
Project onto v3: h·v3 = 1.5 (medium component in direction v3).
The reasoning projection h_reasoning = 2.1*v1 + 0.8*v2 + 1.5*v3 (a small clean vector, 3 numbers instead of 12).
A hallucination would show very weak or noisy projections (h·vi ≈ 0 or scattered); a true answer would show a consistent, strong one.

The projection multiplies how much the hidden state points in each reasoning direction, then sums them; the result is smaller (fewer numbers) and cleaner (noise gone).

What can go wrong

What can go wrong

The model was not trained honestly. If the LLM is fine-tuned to output plausible-sounding text even when reasoning is weak, the reasoning subspace itself may be corrupted. HARP assumes the Unembedding layer honestly reflects what the model knows.
Shallow questions need shallow reasoning. On trivial factoid questions, the reasoning subspace may carry almost no signal—the model solved it in the embedding layer (the step where the model converts words into numbers at the start). HARP needs questions hard enough that the model genuinely reasons.
SVD finds the output layer's view, not ground truth. The reasoning subspace is defined by what the Unembedding layer ignores. If the model encodes some real reasoning in directions the output layer happens to use, HARP loses it.
Done right. On datasets where the model must actually reason (TriviaQA, open-ended QA), HARP detects 92+ percent of hallucinations with near-zero false alarms.
What a runnable demo should prove

What a runnable demo should prove

Build a simple hallucination detector: (1) Load a model and its Unembedding layer. (2) Compute SVD on the Unembedding matrix; extract basis vectors for the first 50% of singular values (semantic) and the last 50% (reasoning). (3) For a test question, run the model and collect hidden states at layers 5 and 15. (4) Project each hidden state onto the reasoning basis; use these projections as features for a classifier. (5) Train the classifier on a small labeled set (true vs. false answers) and measure accuracy on a held-out test set. (6) Compare against a baseline that uses the whole hidden state. The demo should show that reasoning-only features achieve 90%+ accuracy while baseline features achieve ~70%.

accuracy = (true positives + true negatives) / (all predictions); hallucination detection rate = true positives / (true positives + false negatives)

The demo proves that removing semantic noise with a single matrix factorization step makes hallucinations unmistakable.
