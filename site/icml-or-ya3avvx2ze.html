CoGe-GCD: Reframing Generalized Category Discovery with Compositional Generalization

A vision model learns to reuse learned pieces to recognize new category combinations it has never seen before.

Paper explainersAll themesComputer Vision

Most visual recognition systems learn categories one at a time. But the real world mixes labeled examples (cats you have seen) with unlabeled ones (things you have not named yet), and new things are often new combinations of old pieces. CoGe-GCD teaches a model to reason like a human: reuse the building blocks it learned from familiar categories to recognize which new combinations are genuinely new categories versus just variations on known ones.

Zero assumption version

Why mixing labeled and unlabeled data is hard

When a model sees labeled images (dogs, cats) and unlabeled ones mixed together, it faces a puzzle: which unlabeled ones belong to known categories, and which belong to categories no one has named yet? A naive approach treats each unlabeled image in isolation, looking at raw pixel features. But the real world does not work that way. A new animal is usually a combination of features you have already seen: it might have a cat face, dog ears, and a new fur pattern. The model should recognize those parts and reason about the combination.

Existing methods fail because they treat each image as a blob of numbers (where different parts of the image, called patches, are treated as separate slices) without structure. They do not learn that images are built from reusable pieces, so when they encounter a mix of those pieces they have not seen before, they cannot extrapolate.

The core insight. The model should learn a small library of visual primitives from the labeled data, then use that library to understand and organize unlabeled images.

The algorithm as a flow

What it actually does

Learn primitives from labeled data

Model builds a small vocabulary of reusable visual pieces from labeled categories.

Assign each patch to primitives

For every image patch, the model decides which primitives are present (competitive assignment: pick winners, not all).

Refine using neighbors

Nearby patches talk to each other and share what they learned, improving each other's understanding.

Measure geometric structure

Model checks if primitive combinations make sense spatially (if all patches agree on the same primitives, or do they disagree).

Calibrate for new combinations

Model learns to adjust its confidence when it sees new primitive combinations it has not seen in labeled data.

What the paper changes

What the paper changes: patch representations

Existing methods treat each image as an unstructured blob of numbers. CoGe-GCD changes this by structuring the numbers: instead of one feature per patch, it maps each patch to a small set of primitives (the learned vocabulary). This is the core shift that lets the model reuse what it learned from labeled categories.

the object it moves  =  patch-to-primitive assignments
The hidden quantity

The primitive consistency signal

measured quantity  =  Primitive coverage and coherence

When patches in an image are mapped to primitives, they either agree (many patches point to the same primitives, meaning the object is coherent) or disagree (patches point to different primitives, meaning the object is complex or unusual). CoGe measures this using a simple idea: if most patches in a region consistently map to the same small set of primitives, the image is organized and understood. If patches scatter randomly across the vocabulary, the image is confusing.

The paper estimates this by looking at which primitives are active (used) in each image, then checking if nearby patches use similar primitives. When agreement is high, the model has a clear understanding; when agreement is low, the image is unusual or belongs to an unnamed category.

Why it works

Why reusing primitives helps extrapolate

When the model maps image patches to a small vocabulary of primitives, it stops treating each image as unique and starts treating it as a combination of reusable pieces. This has two consequences. First, the model can now organize unlabeled images into coherent groups: images that share the same primitives naturally cluster together, and the model can separate them by which primitives they use. Second, when the model encounters a combination of primitives it has not seen before (e.g., cat face with dog body), it has a framework to understand it: these pieces are known, so their combination is also understandable, even if that exact mix is new.

The geometric calibration step ensures that when primitives appear in spatial arrangements the model has not seen in labeled data, the model does not guess blindly. It learns that the confidence for identifying a category should account for whether this primitive pattern was common in labeled data, not just whether the primitives exist. This lets the model correctly estimate how many unnamed categories exist and assign unlabeled instances to the right groups.

Math after the picture

The assignment and calibration equation

First in words:

For each patch, compute the strength of connection to each primitive, then pick the most confident ones, then adjust confidence based on whether this primitive mix has been seen before.

Then the compact form:

confidence_j = base_score_j * (1 + gamma * similarity_to_known_mixes)

Every symbol:

confidence_jfinal belief that image belongs to category j
base_score_jraw score computed from primitive assignments for category j
gammahow much to trust that this exact primitive mix is known (learned parameter)
similarity_to_known_mixeshow similar this image's primitives are to combinations seen in labeled data
A tiny worked example
Image has primitives: fur=strong, face=strong, ears=medium.
Category cat base_score = 0.8 (matches fur+face+ears pattern).
This primitive mix appeared in 9 of 10 labeled cats, so similarity_to_known_mixes = 0.9.
With gamma = 0.5: confidence_cat = 0.8 * (1 + 0.5 * 0.9) = 0.8 * 1.45 = 1.16 (clamped at confidence 1.0).
If primitive mix never seen before: similarity_to_known_mixes = 0.1, confidence_cat = 0.8 * 1.05 = 0.84 (lower, uncertain).

The equation encodes the idea that familiar primitive combinations get a stronger score boost, because they were common in labeled data, while primitive mixes not seen in labeled data get a smaller boost, because the model has less reason to trust them are real known categories.

What can go wrong

What can go wrong

Vocabulary too small. If the primitive vocabulary has too few entries, different categories will share too many primitives, and the model cannot distinguish them.
Primitives are not reusable. If primitives are highly specific to single categories (e.g., one primitive only for giraffes), the model fails at compositional reasoning.
Spatial structure is ignored. If the model does not account for where primitives appear (only whether they appear), it fails to reject images where primitives are arranged wrong.
Done right. When the vocabulary is well-sized, contains generic reusable pieces, and spatial calibration is learned, the model accurately handles both labeled categories and unnamed ones.
What a runnable demo should prove

What a runnable demo should prove

Build a toy dataset: 4 labeled categories (each using 2 learned primitives in different combinations), then 6 unlabeled images (4 from labeled categories, 2 from unnamed categories that mix the labeled primitives in a new way). The demo should show: (i) the model maps each patch to primitives consistently, (ii) primitive assignments for the 2 unnamed images are coherent but different from the 4 labeled images, (iii) the model correctly predicts all 4 labeled images as known and both unnamed images as belonging to no named category, (iv) if you swap primitives in a labeled image (e.g., swap fur and face features), the model no longer recognizes it confidently.

accuracy_known = (labeled_images_correctly_ID_as_known) / (total_labeled) ; accuracy_novel = (unlabeled_novel_correctly_ID_as_unknown) / (total_unlabeled_novel)

The key proof is that primitive reuse enables generalization: combinations the model has not seen in labeled data are recognized as coherent new categories because the primitives are reused, rather than mistaken for noise or forced into an old category, because each primitive mix has a clear signature.
