Initialization Schemes for Kolmogorov-Arnold Networks: An Measured Study

Show that the starting values in spline-based Kolmogorov-Arnold Networks strongly shape whether training stays stable and whether the model can use its extra flexibility.

Paper explainersAll themesOther

Kolmogorov-Arnold Networks, or KANs, replace the usual fixed nonlinear step in a neural network with a learned spline function on each connection. That gives the model more freedom, but it also creates a harder training problem because every connection now has function-shape settings as well as connection strengths. The paper studies how to choose the starting values for those settings. This is not a cosmetic choice. If the starting functions are too large, too flat, or poorly scaled across layers, the model begins training in a regime where updates are unstable or uninformative. The paper compares theory-guided schemes related to LeCun and Glorot initialization with a tunable power-law family and shows that initialization is a first-order factor in KAN performance.

Zero assumption version

Why KANs are unusually sensitive to starting values

In a standard multilayer network, the nonlinear function is fixed, so initialization mainly sets the connection weights. In a spline-based KAN, each edge also carries a learned activation shape, meaning the curve that maps one incoming value to one outgoing value. That adds flexibility but also adds more ways for the signal scale to drift.

If the starting scales are wrong, early-layer outputs can shrink toward zero or explode across layers. When that happens, learning slows or becomes unstable because later updates are reacting to badly scaled internal signals rather than to the real task structure.

The paper's move. Design KAN initialization around variance control and training dynamics, because these models must stabilize both connection strengths and learned activation shapes from the first step.

What the paper changes

What the paper changes

The paper changes the default assumption that KAN initialization is a minor detail and treats it as a design choice that determines whether spline-based learning starts in a usable regime.

The hidden quantity

The hidden quantity

measured quantity  =  signal scale at initialization across layers and spline functions

The hidden quantity is the scale of the internal signals right after initialization: how large activations, spline outputs, and update sensitivities are before learning has corrected anything.

This quantity drives training quality because KANs have more trainable pieces per connection than ordinary networks. If the initial signal scale is off, the learned spline functions can start in flat or extreme regions, and then the model either barely changes or changes too violently. The paper uses training curves and Neural Tangent Kernel diagnostics to see which initializations keep that scale in a useful range.

Why it works

Why initialization matters so much in KANs

A KAN connection does more than multiply by a weight. It also passes the signal through a learned spline, so the starting scale affects both the signal amplitude and the part of the spline that is active. A poor start can place many inputs in regions where the spline response is nearly flat or too steep.

LeCun-style and Glorot-style rules matter because they aim to keep variance under control as signals move forward through layers. In KANs that idea must cover the spline coefficients as well as the usual weights. When the balance is right, one layer does not distort the scale handed to the next.

The power-law family matters because wider KANs do not always follow the same scale rule as smaller ones. A tunable exponent lets the starting scale change with model width, which can preserve stable training in large models where a fixed heuristic breaks down.

The Neural Tangent Kernel analysis matters because it exposes whether small weight updates at initialization can produce output changes that the optimizer can actually use. If that local sensitivity is too weak or too erratic, optimization struggles before the model has learned anything useful.

Math after the picture

Variance preservation view

First in words:

A good initialization keeps the spread of signals entering one layer close to the spread leaving that layer, so depth does not cause values to collapse or blow up.

Then the compact form:

scale_ratio = output_variance / input_variance

Every symbol:

input_variancehow spread out the incoming layer values are at initialization
output_variancehow spread out the outgoing layer values are after the initialized KAN transformation
scale_ratioa summary of whether the layer shrinks, preserves, or amplifies signal scale
A tiny worked example
Suppose one layer receives values with variance 1.0.
If the initialized KAN layer outputs variance 0.1, repeated layers will quickly crush the signal.
If it outputs variance 10.0, repeated layers will make the signal unstable.
If it stays near 1.0, later layers receive a workable scale.
The initialization schemes in the paper differ mainly in how well they keep this ratio near balance across widths and tasks.

The full study also checks local training sensitivity, but variance balance gives the first-principles reason initialization matters.

What can go wrong

What can go wrong

A good rule on one width may fail on another. KAN scaling changes with architecture size, so a fixed initialization heuristic can drift out of range as the model becomes wider.
Task-specific sweeps may overfit the rule. An initialization tuned on a narrow benchmark can look strong there but may not transfer if another task drives very different input scales.
Spline flexibility can hide bad starts temporarily. A KAN may appear to learn at first while carrying unstable internal scales that later hurt convergence or generalization.
Done right. The strongest initialization keeps layer variance balanced, preserves useful local sensitivity for optimization, and stays well scaled as architecture width changes.
What a runnable demo should prove

What a runnable demo should prove

Build a small spline-based KAN and train it on one synthetic function-fitting task and one simple partial differential equation surrogate task. Compare three starts: baseline, Glorot-style, and one tuned power-law scheme. The demo should log layer output variance, loss curves, and final fit quality for several widths. It should also show whether wider models remain trainable under each rule.
