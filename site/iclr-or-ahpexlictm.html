Cooperative Sheaf Neural Networks

A graph neural network that lets nodes independently choose which neighbors to listen to and which to send to, avoiding information loss over long distances.

Paper explainersAll themesGraph & Geometric Learning

Graph neural networks pass information between connected nodes layer by layer, but they face two problems: over time, all nodes end up with similar representations (oversmoothing), and information gets lost when traveling through long paths of nodes (oversquashing). This paper introduces a new way to model how nodes cooperate with their neighbors by treating each direction of communication separately, letting nodes selectively attend to distant nodes while ignoring noise in between.

Zero assumption version

Nodes get stuck in similarity and lose long-distance information

In a standard graph neural network, each node learns a short representation (a list of numbers). When you stack many layers, nodes repeatedly share these numbers with their neighbors. Over many rounds, all the node representations start to look the same — they blur into each other. This is called oversmoothing. At the same time, if you need information from a node far away (10 hops, 20 hops), that information has to travel through every intermediate node. Each step compresses it a little more, until it gets lost or distorted. This is called oversquashing.

A naive first attempt would be to just use more layers, but that makes oversmoothing worse. Another try is to sum up information from neighbors symmetrically (treat left and right equally), but in many real networks (who follows whom on social media, who cites whom in papers, who directs a workflow to whom) the direction matters — you listen differently to incoming info than you send out. Classic graph neural networks treat the direction as symmetrical, missing this key asymmetry.

The paper's answer in one sentence. Let nodes send information on outgoing edges and listen on incoming edges using separate learned direction maps, so they can pick exactly which neighbors matter and skip the rest.

The algorithm as a flow

What it actually does

Set up direction maps

For each node, learn two learnable maps: a source map (controls what you send out) and a target map (controls what you listen to).

Project features through maps

When sending to a neighbor, multiply your features by your source map. When receiving, multiply their features by your target map.

Compose diffusion across both directions

Use two graph operators (out-degree and in-degree Laplacians, which score how central each node is in outgoing/incoming graphs) applied one after the other.

Enable selective listening

If your target map is zero, you ignore all neighbors. If a neighbor's source map is zero toward you, you get no info from them. This zeros-out useless edges.

Stack layers to reach far nodes

Each layer lets information travel two more hops, so 3 layers reach nodes 6 hops away while still ignoring clutter in between.

What the paper changes

The one thing that changes

The paper replaces the symmetric sharing rule (treat all neighbors the same) with separate learned linear maps for sending and receiving. In graph math, these maps act on the in-degree and out-degree Laplacians (which measure how central nodes are in incoming vs. outgoing graphs). By splitting these, nodes gain independent control over cooperation.

the object it moves  =  Direction maps for sending and receiving
The hidden quantity

The hidden quantity: listening control

measured quantity  =  Listening control

The paper measures a hidden quantity: whether a node can choose to listen to one neighbor while ignoring all others on the path to it. This is the core fix — in standard networks, if node J sends to node I through intermediate nodes, I must receive from all of them together. In CSNN, the learned source and target maps can suppress intermediate nodes entirely.

The paper uses Propositions 4.1 and 4.2 to formalize this: if your target map is zero, you don't listen to anyone. If a neighbor's source map toward you is zero, no info flows from them. This zeros-out useless connections, letting each node's receptive field (the set of nodes it can receive from) become selective instead of symmetric.

Why it works

Why separating send and listen fixes both problems

Standard graph neural networks treat every edge the same way from both directions. In reality, sending your state to a neighbor (what you broadcast) is different from receiving info from a neighbor (what you pay attention to). By learning separate maps for each direction, nodes gain fine-grained control. When node I receives from node J through intermediate nodes, it can multiply J's signal by its learned target map (the weight on that neighbor) and multiply each intermediate's signal by their source maps — choosing which neighbors to absorb and which to skip.

This breaks the oversquashing bottleneck because long-distance information can now travel a direct path: node J's features get multiplied by J's source map, then by I's target map toward J, then by the graph operator that measures their distance. Intermediate nodes don't squeeze or blur the signal if their maps are tuned to pass it through. At the same time, nodes stop blurring into each other because they are no longer forced to blend all their neighbors symmetrically — each node tunes its target and source maps to extract unique, non-averaged information.

The paper formalizes this via two graph operators (in-degree and out-degree Laplacians) composed together, which together define how information flows through the directed graph. The composition lets each node control both what it broadcasts (source) and what it absorbs (target), so nodes stay distinct and long-range paths stay clear.

Math after the picture

The update rule

First in words:

New features equals the transpose of the in-degree Laplacian times the out-degree Laplacian times the feature vectors, plus a learned linear transformation and a nonlinearity.

Then the compact form:

X_t+1 = σ( (L_in^F)^T * L_out^F * X_t * W + b )

Every symbol:

X_tfeature vectors of all nodes at layer t (a table: rows are nodes, columns are feature dimensions)
L_out^Fout-degree Laplacian with source maps (measures node centrality in directed outgoing graph)
L_in^Fin-degree Laplacian with target maps (measures node centrality in directed incoming graph)
(L_in^F)^Ttranspose of in-degree Laplacian (flip rows and columns)
Wlearned weight matrix (maps combined Laplacian outputs to new feature space)
blearned bias (offset added after the transformation)
σnonlinearity function (element-wise, e.g. ReLU: zero out negatives)
A tiny worked example
Suppose node 1 has features [1.0, 2.0] and node 2 has features [3.0, 0.5].
Node 1's source map (what it sends) is [[1, 0], [0, 0.5]] — amplifies first feature, dampens second.
Node 2's target map (what it listens for) is [[0.8, 0], [0, 1.0]] — favors second feature.
Standard graph would blend: 0.5*(1.0, 2.0) + 0.5*(3.0, 0.5) = (2.0, 1.25) for both nodes.
CSNN routes: node 1 sends [1.0, 1.0] (via source map), node 2 listens for [2.4, 0.5] (via target map).
The Laplacians then weight these by graph centrality. Result: node 2 receives distinct directional signal, not blended average.

The composition of transposed in-degree and out-degree Laplacians encodes the asymmetric choice each node makes about what to send and receive.

What can go wrong

What can go wrong

Maps can collapse to zero. If source or target maps are not regularized, they may learn to be zero (ignore all neighbors). This speeds up training but kills information flow. The paper avoids this by initializing maps as orthogonal (evenly spread) and learning multiplicative scaling on top.
Oversquashing on very deep networks. Even with selective attention, extremely deep networks (40+ layers) can still lose information. Each layer lets info travel 2 hops, so reaching nodes 80 hops away requires careful tuning.
Directed graphs with dense out-degrees. If a few nodes have many outgoing edges (fan-out), their source maps become high-dimensional and hard to learn. The Laplacian will scale them by their out-degree, which can amplify noise.
Done right. Learned orthogonal maps (Householder reflections) ensure no direction collapses. Composing in- and out-degree Laplacians balances broadcasting and listening. Experiments show this scales to long-range benchmarks.
What a runnable demo should prove

What a runnable demo should prove

Build a small synthetic directed graph where one node far away (8+ hops) has a unique, important signal. Nodes in the middle have noise (random features). Train a standard graph neural network and CSNN side by side. Measure: (1) does node I at the end recover the distant node J's signal, or does it get lost in middle noise? (2) do the learned source/target maps zero out the noisy middle nodes while preserving the direct J-to-I connection? (3) how much longer (in layers) do node representations stay different from each other (avoid oversmoothing) in CSNN versus standard GNN, because selective tuning of maps prevents forced blending?

signal_recovery = (learned_feature_I · actual_distant_signal_J) / (learned_feature_I · middle_noise)

If CSNN's signal recovery is 5x higher than standard GNN, the demo confirms that selective attention lets each node tune which neighbors to listen to, unblocking long-distance information.
