Learning from rewards and feedback

Papers using reinforcement learning and reward-shaping techniques to train robots to improve their behavior through trial and error—the challenge is defining useful reward signals and making learning stable.

What this is

Another way to teach robots is to let them learn by trial and error, the way a child learns to walk or throw a ball. You define a reward—a number that tells the robot how well it did. If the goal is to pick up a cup, the robot gets a high reward when it touches the cup, and a higher reward when it grasps it. The robot tries many different actions, and over time, it learns which actions lead to higher rewards. This is called reinforcement learning. The appeal is that you do not have to provide demonstrations; you just have to define what success looks like. The robot will figure out its own way to get there.

The challenge is defining a useful reward signal and making the learning stable. If the reward is too simple ('just grab the object'), the robot learns a brittle policy that works in one exact situation but fails if the object is slightly different or in a different place. If the reward is complex, you have to specify dozens of details, and robots optimize the reward you gave them, not the goal you intended. Worse, reinforcement learning is slow. A robot in the real world cannot try 10,000 failed actions to learn one good skill—each failure is costly, and each trial takes time. So researchers try to speed it up using simulation, where they can run thousands of trials per second. But then the robot learns in simulation, and when you put it in the real world, the physics is slightly different and the policy fails. This 'reality gap' is enormous in robotics.

Papers here tackle the problem from multiple angles. Some use reward shaping—giving the robot intermediate rewards for progress, so it learns faster. Some use hierarchical learning—teaching the robot to learn simple skills first (grasp), then build on them (grasp and lift). Others use feedback from humans—as the robot learns, a person occasionally corrects it or gives it hints, speeding up learning massively. Some work to bridge the reality gap by training in simulation in a way that the learned policy transfers better to real robots. A few use prediction as a shortcut: instead of learning what reward a real action gives, the robot learns to predict what will happen, and uses that prediction to pick actions without actually trying them as many times.

How the work breaks down

The work on learning from rewards and feedback splits across five main directions because each addresses a different bottleneck. How to shape rewards to guide learning faster—because sparse feedback slows progress. How to learn models of the world that predict what happens next, so a robot can plan without endless trial-and-error—because physical experiments are expensive. How to learn from human feedback or demonstrations—because raw reinforcement learning needs thousands of trials. How to handle the gap between simulation and reality—because robots fail when trained only in simulation. And how to build policies that work across many different tasks and environments—because real deployments face constant variation.

Shaping rewards to steer learning

One of the core challenges in reinforcement learning is that the robot gets almost no guidance while learning. If the reward signal is too simple (just binary success or failure at the end), the robot learns slowly because it rarely gets any signal telling it whether it is making progress. The solution is reward shaping: giving the robot smaller rewards along the way, like a coach offering feedback during practice instead of only at the final goal line.

BFM-Zero demonstrates this by training a humanoid robot to learn behaviors from scratch in the real world—it shows that a robot can learn to walk, reach, and adapt to new tasks without any pre-trained knowledge, using reinforcement learning with no demonstrations. Master Skill Learning with Policy-Grounded ties reward shaping and exploration together using language models to propose intermediate rewards that guide learning toward complex skills. SARM (Stage-Aware Reward Modeling) breaks long tasks like folding a shirt into stages, so the robot gets rewarded for completing each stage in order rather than only for the final perfect fold. Focus-Then-Contact shows how to use affordance hints (what the environment offers in terms of what actions are possible) to speed up learning on contact-heavy manipulation tasks, which means the robot learns faster because it gets early feedback on whether it is using the right part of the world. Together, these papers show that carefully structured reward signals turn slow, random exploration into focused learning paths.

Learning to predict and plan with world models

Instead of learning by trial and error on every action, a robot can learn a model of the world—a learned predictor that says 'if I take action A in state S, what happens next?' Once the robot has an accurate model, it can plan ahead mentally, testing actions in imagination before moving in the real world. This vastly cuts down learning time because the robot can run thousands of imagined trials per second in simulation.

ExoPredicator learns abstract models that let robots predict how objects and goals relate in manipulation tasks, then uses those predictions to plan reaching new objects or completing new goals that the model has never seen before. Sparse Imagination uses a learned world model to imagine rollouts efficiently—instead of imagining the full video of what will happen, it predicts only the parts of the future that matter for the task (sparse predictions), cutting inference time drastically while keeping task success high. DDP-WM (Disentangled Dynamics Prediction) learns to separate different aspects of the world dynamics (object motion, physics, etc.) so that the model stays accurate even when things change; it plans with model predictive control and improves success rate from 90% to 98%. Predicting What Matters learns to predict future semantic masks—which parts of the visual scene the robot should pay attention to—rather than predicting raw pixel values, so world models generalize better across visual variations. These papers all work toward the same goal: give robots a mental simulator so they can think before they act.

Bridging simulation and reality

A major bottleneck in robot learning is the reality gap: a robot trained in perfect simulation often fails in the real world because the real physics is slightly different—friction changes, objects are heavier, the camera sees different lighting. Researchers tackle this by either making simulation more accurate or by training policies that can handle these differences, which means the robot learns to work even when conditions are not perfect.

Contact-guided Real2Sim builds a real-world motion tracking system from single camera video, so you can replay real human actions in accurate simulation. This dramatically cuts down the failure rate in reinforcement learning because the simulated robot now moves like the real robot. Cerebellar-Inspired Residual Control adds a learned compensation layer (inspired by how the brain's cerebellum corrects motor errors) that learns to fix problems when the robot gets faults—it improves performance by 66% on some tasks even when the robot has broken actuators, which means the robot can adapt on the fly when something breaks. Exo-Plore works with exoskeleton control where human biomechanics are uncertain; it learns a control policy inside a human-aligned simulation so the final behavior generalizes to real people with different body shapes and walking patterns. All three show different angles on the same idea: learn to adapt when theory and reality do not match perfectly.

Learning from human guidance and demonstrations

Reinforcement learning from scratch is sample-inefficient: the robot needs thousands of failures to learn one skill. A faster path is to learn from human examples (demonstrations) or from human feedback (corrections) that steer learning, which means the robot does not have to discover everything by accident. This combines the strengths of both: the human provides a starting point, and the robot learns to refine and adapt it.

Model Predictive Adversarial Imitation Learning combines two ideas: learn a reward function from human demonstrations using inverse reinforcement learning, then use a model predictive controller to plan actions under that learned reward. DataMIL selects which examples from large robot datasets are most informative so the robot learns from fewer but higher-quality demonstrations; it improves success on real-world manipulation by focusing on the data that matters. Fourier Features Let Agents Learn High Precision Policies shows that adding a mathematical technique that represents positions as repeating patterns (Fourier features) helps imitation learning capture finer details in how humans move, which means high-precision positioning tasks become learnable from the same data because the model can now represent small position differences. Uncertainty-Guided Exploration and Stable Planning learns from both demonstrations and trial-and-error, using uncertainty estimates to decide when to explore (try something new) and when to exploit (use what you know); it beats pure learning approaches and achieves real-world sim-to-real transfer. These papers show that human knowledge bootstraps robot learning.

Adapting policies across embodiments and environments

Real robot deployment requires policies that work across many scenarios: different objects, different placements, different robots with different body plans. Transfer learning—where a policy learned on one task or robot adapts to another—is essential because you cannot train from scratch for every variation.

From Seeing to Experiencing shows a navigation policy pretrained on large visual datasets can be fine-tuned with reinforcement learning to handle real embodied navigation; it maintains generalization to new environments while becoming more interactive. CE-Nav trains a local navigation controller on one robot (quadrupeds, bipeds, drones) and adapts it to others with minimal retraining, and it works in the real world. Empowering Multi-Robot Cooperation uses sequential world models that robots can share, so when multiple robots learn together, they cooperate predictively—dividing roles and anticipating each other's actions. Demystifying Robot Diffusion Policies reveals that diffusion-based policies often just memorize training action chunks; the paper proposes a simpler lookup-table alternative that works as well, challenging the assumption that complex methods are necessary. TrajTok shows how to tokenize trajectories for behavior generation (breaking trajectories into specific discrete chunks that capture action patterns) in a way that stays consistent across examples and works reliably, winning a Waymo challenge. Together, these papers address the practical reality that deployed robots must be flexible across many real-world situations.
