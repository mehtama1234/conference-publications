Manifold Residual Block for Few-Shot Whole Slide Images

Preserve how features cluster naturally by splitting the linear layer into a frozen anchor and a trainable thin residual.

Paper explainersAll themesComputer Vision

Few-shot whole slide image (WSI) classification fails because standard linear layers twist the natural shape of feature clusters that foundation models learned during pretraining. This paper proposes a simple fix: split the linear layer into two pathways—a fixed random layer that acts as an anchor and preserves the original cluster shape, and a trainable thin layer that makes small task-specific tweaks. The combination keeps the natural structure intact while adapting to new tasks.

Zero assumption version

Standard linear layers scramble how features cluster

Pathology foundation models learn to group semantically similar features tightly together, as if they live on a smooth wrinkled sheet packed into high-dimensional space. This clustering is intentional: contrastive pretraining (like CLIP) pushes different classes far apart; self-distillation (like DINO) keeps similar examples close. The model's entire learned structure depends on this arrangement.

Few-shot learning poses a double bind. You have only a handful of labeled examples, so you cannot train a new linear layer from scratch. A naive approach: take the pretrained features and train a simple linear layer on top. But a trained linear layer does not care about clusters. It twists and stretches feature space to minimize loss on your few examples, even if that destroys the original cluster structure. In few-shot settings, this destruction is catastrophic: the layer learns an overly complex mapping that obliterates all the cluster patterns the foundation model built during pretraining.

In one sentence. Replace the standard linear layer with a block that decouples into a frozen anchor that preserves clusters and a trainable thin residual that adapts.

The algorithm as a flow

What it actually does

Step 1: Diagnose the problem

Measure the curvature of features before and after a standard linear layer—the layer increases curvature, distorting the manifold.

Step 2: Design a frozen anchor

Use a random fixed layer (a grid of random numbers) as a baseline that approximately preserves cluster structure without ever training.

Step 3: Add thin residual pathway

Train a thin additional layer (using far fewer trainable numbers) on top of the frozen layer for task-specific adjustments.

Step 4: Combine them

The output is the frozen anchor output plus the residual: no distortion, plus small learned adjustments.

Step 5: Train only the residual

Since the anchor is frozen, the residual is easier to fit on few examples—less overfitting risk.

What the paper changes

What the paper changes

The paper replaces every standard linear layer in the multiple instance learning model with the Manifold Residual (MR) block. Instead of one trainable layer that can scramble clusters freely, the MR block gives you two pathways: a frozen random layer that holds cluster structure intact, and a trainable thin layer that makes small task-specific adjustments.

the object it moves  =  Linear layer
The hidden quantity

Cluster distortion—how much the layer scrambles feature groups

measured quantity  =  How much the layer spreads apart feature clusters

As features flow through a neural network, the natural clusters can spread apart. If features start packed tightly (like marbles in a bag), cluster distortion measures how much the layer pushes them apart and scrambles their grouping. The paper quantifies this by computing the intrinsic dimension of the feature space (how many independent directions the clusters span) and measuring how much it changes after a linear layer.

The paper shows that a vanilla trained linear layer increases cluster distortion by a large amount. A random fixed layer increases it less. The MR block—combining frozen anchor plus thin residual—increases it even less while still adapting to the new task. The paper does not fully explain why random layers preserve clusters, but the experiments demonstrate it holds across multiple datasets and models.

Why it works

Why preserving clusters helps few-shot learning

When you have only a handful of examples, overfitting is the enemy. A trainable linear layer with millions of trainable numbers can memorize noise. It will do whatever it takes to minimize error on those few samples, even if that destroys the cluster structure you inherited from pretraining. By contrast, a frozen random layer has no trainable numbers—it cannot memorize. It is a fixed passthrough that preserves the original cluster arrangement while gently smoothing out extreme feature values.

The thin residual pathway is the innovation: it is trainable, but thin (low-rank, meaning it has far fewer numbers than a full linear layer). Because of its thinness, it cannot fit arbitrary noise or scramble clusters. Instead, it can only learn small corrections—task-specific tweaks on top of the cluster-preserving anchor. This two-stage design gives you the best of both: cluster preservation from the frozen layer, and task-specific adaptation from a thin learner that is far less prone to overfitting.

A tiny worked example
Input has 512 feature numbers. Frozen layer B is 512×512 (preserves clusters). Residual layers U and V are each 512×4 (rank 4, very thin).
Vanilla linear layer trains a 512×512 layer—262,144 trainable numbers, high overfitting risk.
MR block: B x uses 0 trainable numbers (frozen). The residual U and V together need 512×4 plus 512×4 equals 4,096 trainable numbers. About 64 times fewer.
On a handful of examples, training 4,096 numbers is much safer than training 262,144. The thin pathway can only tweak, never scramble the clusters.

The frozen anchor acts as a cluster guard; the thin residual adds small task-specific tweaks without scrambling the original feature groups.

What can go wrong

What can go wrong

Frozen layer initialization is poor. A random layer with bad initial values might not preserve clusters at all. The paper shows the method works across standard initialization schemes, but a truly bad random layer could fail. In practice, simple random initialization works fine.
Residual rank is set too high. If the thin residual has too many trainable numbers (rank r gets close to the full layer width), it regains the ability to memorize and scramble clusters, defeating the whole purpose. The paper keeps r much smaller than full width.
The foundation model has weak clusters. This method assumes the pretrained features have already learned good cluster structure. If the foundation model was trained poorly or on unrelated data, there are no clusters to preserve, and the method cannot help—because the frozen layer can only protect what already exists, it cannot create good structure where there is none.
Done right: clusters preserved, task adapted, overfitting reduced. Experiments show the MR block achieves the best few-shot results across multiple datasets and models, while using far fewer trainable numbers than standard baselines.
What a runnable demo should prove

What a runnable demo should prove

Build a simple few-shot classification task: take a pretrained feature extractor (e.g., a pathology foundation model or a standard vision model), extract features from a labeled dataset, then select only a handful of examples per class (5-shot or 10-shot). Train three readout heads on these few examples: (1) a vanilla linear layer, (2) the MR block, and (3) a layer with the same number of trainable numbers as the MR block. Measure accuracy on a held-out test set from the same classes. Also measure how many of the original cluster structure remains intact in each case (compute the intrinsic dimension or use tangent space analysis).

few_shot_accuracy = (correct predictions on 5-shot examples) / (total test examples); cluster_preservation = dimension_before - dimension_after (lower is better)

The demo must show that the MR block achieves higher accuracy than the vanilla layer on the few-shot task, while using fewer trainable numbers and preserving more of the original feature clusters than a capacity-matched baseline—because the frozen anchor prevents the thin residual from scrambling clusters, overfitting shrinks, and the few examples can now focus on small task-specific tweaks instead of memorization.
