Once-More: Continuous Self-Correction for Large Language Models via Perplexity-Guided Intervention

Intervene during generation at doubtful next-word choices so the model corrects itself before small mistakes snowball into a bad answer.

Paper explainersAll themesOther

Long generation often fails because a small early mistake pushes later words in the wrong direction, and the error compounds before any correction arrives. Once-More intervenes during generation instead of waiting until a full draft exists. It watches for doubtful next-word decisions, mixes in feedback from verifiers, and redistributes the next-word scores before the mistake is emitted. This helps because correction happens at the moment the path can still be changed cheaply.

Zero assumption version

Early generation mistakes can compound long before a final draft is reviewed

A language model produces text one next word at a time. If it chooses a weak next word early, later choices are conditioned on that mistake, so the answer can drift, repeat itself, or reason from a false premise.

Many self-correction methods wait until a substantial draft has already been written. By then, the answer may be far from the right path, and a later revision has to repair a large amount of bad text. That is wasteful because the cheapest time to fix a wrong turn is before it becomes the base for many later steps.

The paper's move. Detect doubtful next-word choices while generation is still in progress and steer them immediately using verifier feedback, because early course correction prevents later drift.

The algorithm as a flow

What it actually does

Generate the next-word scores

At each step, compute the model's score spread over possible next words.

Measure uncertainty

Check whether the current next-word choice looks doubtful under the model's own score spread.

Query verifiers when needed

Use external feedback signals to judge whether the current path looks promising.

Redistribute the next-word scores

Shift probability mass toward words that better match the verifier feedback, because that makes the chosen next word follow the stronger branch.

Continue generation on the corrected path

Emit the adjusted next word and repeat at the following step.

What the paper changes

What the paper changes

The paper changes when and how self-correction happens. Instead of correcting a finished or half-finished draft, it modifies the next-word decision itself while text is being produced.

the object it moves  =  next-word decision path
The hidden quantity

Trajectory stability: the hidden quantity

measured quantity  =  how resistant the generation path is to early drift

The hidden quantity is trajectory stability: once the answer starts, how likely is it to stay on a correct path instead of drifting after one weak choice? A model with poor trajectory stability can look fine at the first few steps but fail badly later because every new word inherits earlier mistakes.

Once-More improves trajectory stability by acting at uncertain steps. That matters because uncertain steps are exactly where one bad choice can redirect the whole answer, so steering them early has outsized impact on the final result.

Why it works

Why continuous intervention helps

Text generation is path dependent. Every next word becomes part of the context for later words, so an early mistake can trigger a cascade of later mistakes. A late-stage corrector has to undo many downstream consequences at once.

Once-More works earlier. It watches the model's next-word uncertainty and uses verifier feedback to reshape the score spread before the next word is chosen. This is effective because it changes the branch point itself, not just the later symptoms of a bad branch.

The intervention is continuous rather than one-shot. That matters because long answers may have several dangerous branch points, not just one. Repeated small corrections can keep the answer on a good trajectory with lower cost than throwing away a long bad draft and starting over, because each correction happens before later text has to be regenerated.

Math after the picture

Redistributing the next-word scores

First in words:

Take the model's original next-word scores and add a correction term from verifier feedback, then normalize the result into a new probability distribution.

Then the compact form:

p_new(w) proportional to p_base(w) * exp(alpha * feedback(w))

Every symbol:

wa candidate next word
p_base(w)the model's original probability for word w
feedback(w)the verifier's score for how good word w looks on the current path
alphahow strongly verifier feedback changes the next-word choice
p_new(w)the corrected next-word probability after intervention
A tiny worked example
Suppose the model gives three candidate next words: A at 0.50, B at 0.30, and C at 0.20.
The verifier thinks B fits the reasoning path best, so feedback(A) = 0, feedback(B) = 1, feedback(C) = -1.
Set alpha = 1.
Adjusted unnormalized scores become 0.50 * exp(0), 0.30 * exp(1), and 0.20 * exp(-1), which are about 0.50, 0.82, and 0.07.
After normalization, B becomes the top next-word choice, so the answer follows the stronger path before a mistake is emitted.

The correction term does not rewrite the whole answer; it nudges the next branch point toward better continuations because the next-word choice is where the path can still change cheaply.

What can go wrong

What can go wrong

Bad verifier feedback can steer the model the wrong way. If the verifier misjudges a branch point, the system may reinforce the wrong next word and push the answer farther from the truth.
Intervening too often can overconstrain generation. If every mildly uncertain step triggers a strong correction, the answer may become rigid or repetitive because the natural flexibility of generation is suppressed.
Cheap uncertainty signals can miss subtle errors. Some wrong paths look confident locally, so uncertainty alone may not flag them and they can slip through without intervention.
Done right. When uncertainty detection and verifier feedback are well calibrated, continuous intervention helps because it corrects weak branch points before they expand into long wrong trajectories.
