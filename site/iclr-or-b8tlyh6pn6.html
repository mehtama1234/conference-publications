Distributional Equivalence in Latent-Variable Causal Models

When two different causal stories produce the same observed data, you cannot tell them apart without knowing which constraints survive data estimation.

Paper explainersAll themesLearning Theory

Causal discovery means learning what causes what from observed data. The hard part: some hidden causes (ones you cannot measure directly) create false ambiguity — different causal stories look identical when you can only see the measured things. This paper introduces edge rank constraints, a graphical test that identifies when two different causal maps are truly equivalent (produce identical patterns in measured data) versus different. This lets you finally build the first causal-discovery method with no structural assumptions.

Zero assumption version

Why hidden causes make causal discovery ambiguous

Causal discovery means learning the direction of influence (who affects whom) from measured data. If you measure three things — say, a person's caffeine intake, heart rate, and alertness — you want to know: does caffeine cause higher heart rate, or does the person's natural alertness cause both?

The real difficulty: hidden causes (things you cannot observe). Perhaps stress is the true culprit — it drives caffeine consumption and heart rate together. Without measuring stress, you see spurious correlation. The person's caffeine and heart rate move together, but neither actually causes the other; they are both caused by hidden stress.

Older discovery methods avoided this by imposing strong constraints — rules like 'hidden causes can only touch these observed variables' or 'the graph must have this shape.' But these assumptions throw away real problems that do not fit the mold. A method without structural assumptions would be far more useful — but to build one, you need to know: when two completely different causal maps (with hidden causes, possibly with cycles like A points to B which points back to A) actually produce identical observed data, so you cannot tell them apart no matter how much data you collect?

The core challenge. Two different causal graphs with hidden variables can produce the same observed data. Without knowing which ones are truly equivalent, you cannot design a discovery method that does not accidentally impose hidden assumptions.

The algorithm as a flow

What it actually does

Estimate how hidden causes blend together

Use overcomplete ICA (blind source separation, a technique that unscrambles mixed signals) to figure out how each hidden cause contributes to each measured variable.

Check edge rank constraints

For each potential edge in a causal graph, the paper's graphical criterion tests whether the strength patterns in how hidden causes blend together are consistent with the graph.

Find an irreducible representative

Simplify the graph by removing redundant hidden causes, reducing to a canonical form.

Traverse the equivalence class

Given one valid causal graph, compute all other graphs that satisfy the same rank constraints and produce identical patterns in the measured data.

Recover the model from data

The glvLiNG algorithm combines rank-constraint checking with matroid-based imputation to recover a causal model up to equivalence, without structural assumptions.

What the paper changes

What the paper changes

The paper does not change the observed data or the hidden causes themselves. Instead, it changes what you can infer: which causal graphs you recognize as equivalent. Prior work relied on strong assumptions (e.g., 'causes you do not measure (latent causes) cannot form cycles', or 'unmeasured causes can only touch specific measured variables') that ruled out many real causal structures. This paper removes those assumptions entirely by replacing them with a purely graphical criterion based on edge rank constraints.

The hidden quantity

Edge rank constraints: the hidden quantity

measured quantity  =  Rank patterns in how hidden causes blend together

When hidden causes combine into observed data, they do so through weighted connections from each hidden cause to each observed measurement. If a hidden cause has weak influence on some observed variables, the rank (the 'effective dimensionality') of certain strength patterns will be low. If it has strong influence, ranks will be high. The paper's insight: the rank patterns in these weighted connections exactly encode which causal edges can exist without producing different patterns in your measured data.

The paper estimates these weighted connections directly from data using overcomplete independent component analysis (ICA), a technique that unscrambles mixed signals. It then checks whether the rank pattern in the estimated connections is consistent with candidate causal graphs. Two graphs are equivalent if and only if all their edge rank constraints are identical and are satisfied by the data.

Why it works

Why rank constraints identify equivalence

At its core, the mechanism is about uniqueness: what can you recover from the measured data patterns alone? When you measure three variables but suspect one hidden cause, the measured covariance (how much they move together) is produced by that hidden cause mixing through weighted connections. Different hidden-cause structures — different causal graphs — can produce the same measured covariance if their strength patterns have the same rank structure.

The paper's key move: instead of checking whether two full causal graphs produce identical data (computationally hard), it checks only the rank patterns in the mixing matrix. Rank is a coarser property — it survives perturbations and is stable under estimation — making it a practical and theoretically sound criterion. Two causal graphs with different edge rank constraints must produce different observed distributions (under mild regularity assumptions). Two graphs with identical edge rank constraints might be equivalent, and the paper provides an algorithm to traverse all such equivalent graphs.

Why this works mechanically: independence constraints (conditional independencies) alone are insufficient to pin down causal structure when latent variables are present, because latent causes create dependencies that look like direct causation. Rank constraints add orthogonal information: they tell you not just which variables move together, but also whether the dimensionality of that coupling is consistent with a particular causal structure. This additional structure is precisely what was missing from earlier latent-variable causal discovery.

Math after the picture

The rank constraint equation

First in words:

For each edge from hidden cause L to observed variable X, the rank of the submatrix of the mixing matrix restricted to columns in L and rows in X must equal the full rank for the edge to exist. Formally: a graph edge exists if the corresponding submatrix has rank equal to the number of hidden causes involved.

Then the compact form:

rank(Q_{X,L}) = |L| iff edge L→X exists

Every symbol:

Qthe mixing matrix (hidden causes to observed variables)
Q_{X,L}the submatrix of Q for observed variables X and hidden causes L
rank(Q_{X,L})the effective dimensionality of that submatrix
|L|the number of hidden causes in the set L
iffif and only if (both directions must hold)
A tiny worked example
Suppose we have 2 hidden causes (L = 2) and 3 observed variables. The mixing matrix Q is 3×2.
For edge L₁→X₁ to exist: rank(Q_{1,1}) must equal 1 (full rank for a single cause). If Q[1,1] = 0.5, rank is 1, edge exists.
For edge L₁→X₂ to exist: rank(Q_{2,1}) must equal 1. If Q[2,1] = 0.3, rank is 1, edge exists.
If Q is [[0.5,0.2],[0.3,0.4],[0.1,0.6]], then rank(Q_{[1,2],[1]}) = rank([[0.5],[0.3]]) = 1, so both L₁→X₁ and L₁→X₂ can exist.
If instead Q[1,1] = 0 and Q[2,1] = 0, then rank(Q_{[1,2],[1]}) = 0, and L₁ cannot reach X₁ or X₂ directly; the edge structure must reflect this.

The rank of submatrices in the mixing matrix encodes which causal edges are possible; two graphs are equivalent if they require identical rank patterns.

What can go wrong

What can go wrong

Faithfulness assumption fails. The method assumes that the observed distribution faithfully reflects the causal structure — that is, conditional independencies in the data correspond exactly to d-separations in the graph. In finite samples or with misspecified models, faithfulness can break, and the algorithm may recover a graph that does not reflect true causality.
ICA estimation error propagates. The algorithm first estimates the mixing matrix via ICA, a step prone to error in finite data, especially when latent causes are correlated. If the estimated ranks are wrong, the subsequent rank-constraint checks will be misleading, leading to incorrect equivalence classes.
Identifiability is only up to equivalence. The method recovers models up to distributional equivalence. Within the equivalence class, you cannot distinguish between genuinely different causal graphs without additional information (interventions, domain knowledge, temporal structure).
Done right: use rank constraints as a structural criterion. When faithfulness holds and ICA is accurate, rank constraints provide a purely graphical test that does not depend on assuming a particular parametric form. Because the rank patterns survive across many different latent-variable causal models, the method can discover structure without artificially restricting the space of possible graphs.
What a runnable demo should prove

What a runnable demo should prove

A proof-of-concept demo should start with a synthetic causal graph with latent variables (e.g., 2 hidden causes, 4 observed variables, at least one cycle). Generate data from this graph. Then, use the glvLiNG algorithm to recover the equivalence class. The demo should show: (1) the true graph is recovered as one member of the equivalence class; (2) all other members of the equivalence class produce data that is statistically indistinguishable; (3) graphs outside the equivalence class produce measurably different distributions (in terms of rank patterns). A second demo could show the algorithm's limits: add noise, reduce sample size, and measure how rank estimates degrade.

Equivalence accuracy = (true graph recovered in equivalence class) AND (all members of computed class have identical rank patterns) AND (external graphs differ in at least one rank constraint)

The demo must make clear that rank constraints successfully partition the space of causal graphs into equivalence classes, and that the method recovers this partition from data without imposing structural assumptions.
