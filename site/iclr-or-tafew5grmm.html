AMLRIS: Alignment-aware Masked Learning for Referring Image Segmentation

During training for referring image segmentation, ignore pixels whose visual content does not line up with the referring phrase, so bad pixel-level supervision stops steering the model.

Paper explainersAll themesMultimodal

Referring image segmentation takes an image and a phrase such as 'the person in the red jacket' and predicts the exact pixels belonging to that target. Standard training assumes every labeled pixel inside the target mask is equally helpful. This paper argues that assumption is wrong. Some pixels are weakly aligned with the phrase even when they belong to the correct object. A phrase may identify the object through one attribute, one part, or one relation, while many other target pixels provide no support for that phrase. If the loss treats all pixels the same, those poorly aligned regions inject misleading updates. AMLRIS fixes this by measuring pixel-level alignment between the visual features and the referring text, then masking out pixels whose alignment falls below an adaptive threshold during training. The architecture stays the same at inference time (the stage when the trained model is used for prediction). The change is only in what training focuses on. That matters because the model should learn from the parts of the object that actually disambiguate the referent, not from every pixel inside the mask regardless of whether the phrase points to it.

Zero assumption version

Some labeled target pixels still push training the wrong way

In referring image segmentation, the model must decide which object the phrase names and then delineate that object at the pixel level. A full target mask says which pixels belong to the object, but it does not say which of those pixels are informative for matching the phrase. For the phrase 'the man holding a tennis racket,' the pixels showing the hand-racket relation may be decisive, while a large patch of jeans is not. Yet standard losses treat both regions as equally strong evidence for the language-image match.

This creates noisy updates. A weakly aligned pixel can still receive a positive training signal because it lies inside the object mask, even though its visual feature is shared by many other objects or gives no clue about the referent. When enough such pixels accumulate, the model learns broad objectness instead of phrase-specific alignment. That hurts generalization because the system becomes less sensitive to the actual wording of the query.

The paper's move. Estimate which target pixels are genuinely supported by the referring phrase, then train on those pixels more than on the rest, because not every foreground pixel carries the same alignment value.

What the paper changes

What the paper changes

AMLRIS changes the training signal at the pixel level. It does not redesign the network. Instead, it changes which target pixels count as reliable evidence for matching the phrase to the image.

The hidden quantity

The hidden quantity: referent alignment per pixel

measured quantity  =  How much a pixel actually supports the referring phrase

The key quantity is not whether a pixel belongs to the ground-truth object. It is whether that pixel helps identify the object named by the phrase, because the task is to pick the referred object rather than any object of the same type. A sleeve pixel may belong to the correct person, but if several nearby people wear similar sleeves, that pixel is weak evidence for the phrase. A hand touching a racket may be stronger evidence because the relation appears in the text.

AMLRIS estimates this quantity with a phrase-image similarity map. High similarity means the local visual feature is strongly tied to the text. Low similarity means the pixel is likely to be generic, ambiguous, or inconsistent with the referent description. Training should trust the first kind more than the second kind because the purpose of the task is phrase-conditioned segmentation, not generic foreground extraction.

Why it works

Why filtering pixels helps

Segmentation losses work by comparing predicted mask values with the target mask at each pixel. When every target pixel is trusted equally, the model receives many positive updates from regions that are not diagnostic for the phrase. Those updates bias the visual features toward common object patterns, because generic pixels occur more often than the small regions that carry the distinguishing relation or attribute.

AMLRIS interrupts that bias by computing alignment before the loss is applied. If a pixel has low similarity to the phrase, the method treats that pixel as unreliable for the current sample. The pixel may still belong to the object, but it is not useful evidence for the language-image match. Removing it from the loss matters because the remaining updates come from regions that actually explain why this object, rather than a nearby object, is the target.

The adaptive threshold matters because different phrases rely on different cues. A phrase about color may align with a broad clothing region, while a phrase about an interaction may align with a small contact region. A fixed threshold would overfilter some samples and underfilter others. The sample-specific threshold keeps enough evidence for each phrase while still suppressing the most misleading pixels.

Math after the picture

The training equation

First in words:

The mask learning loss is multiplied by an alignment-based pixel mask, so only reliable regions contribute fully to the update.

Then the compact form:

L = sum_i M_i * L_i

Every symbol:

Lthe total segmentation loss for one sample
ia pixel or local region index
M_ithe alignment-aware mask value for pixel i; high for reliable phrase-aligned pixels and low or zero for unreliable ones
L_ithe ordinary per-pixel loss comparing the model's prediction with the target label at pixel i
A tiny worked example
Suppose the phrase is 'the child holding the kite.'
Pixels on the hand and kite string may get high mask values because they express the relation named in the phrase.
Pixels on a large patch of pants may get low mask values because they belong to the child but do not help separate that child from others.
The loss then learns more from the relation region than from the generic clothing region.
That is why the model becomes better at resolving the phrase, not merely at filling the object silhouette.

The paper's idea is selective trust. Pixel labels are kept, but only the phrase-aligned subset is allowed to shape the update strongly.

What can go wrong

What can go wrong

The similarity map is inaccurate. If the phrase-region similarity scores are noisy, the method may discard the very pixels that carry the key evidence. Then the filtered loss becomes worse than the original loss because it trains on the wrong subset.
The threshold is too aggressive. If too many pixels are masked out, the model may learn only tiny local cues and lose the full object boundary. That hurts final segmentation because precise contours still require broad spatial coverage.
The phrase names diffuse properties. Some phrases refer to large appearance regions rather than compact cues. In those cases, strong masking can remove useful support because the discriminative evidence is distributed across much of the object.
Done right. Use a reliable alignment map and a threshold that removes only the least informative pixels. Then the model still sees the object while learning mainly from the regions that justify the phrase.
What a runnable demo should prove

What a runnable demo should prove

Take a referring image segmentation dataset with phrases that depend on relations, colors, and small distinguishing parts. Train one baseline with the normal full-mask loss and one model with alignment-aware masking. For each sample, visualize the similarity map, the filtered pixels, and the final mask. The demo should show that AMLRIS removes weakly aligned target regions during training and that this produces better performance when the phrase must distinguish between nearby similar objects, because the remaining updates are concentrated on the regions that actually separate the target from distractors.
