Manipulation as in Simulation: Accurate Geometry Perception

Learn a neural model that cleans up noisy depth camera readings so robots trained on perfect simulated depth can work on real robots without retraining.

Paper explainersAll themesRobotics & Control

Robots learning to manipulate objects from simulation do great when the depth camera is perfect. But real depth cameras are noisy and inaccurate. This paper teaches a neural model to fix that gap: it learns what the real camera's noise looks like, then predicts what the true depth should be. Once trained on paired data from simulation, the cleaned-up depth lets robot policies generalize directly from virtual training to real robots.

Zero assumption version

Depth cameras read 3D distances but real ones are inaccurate

Robots learn manipulation skills in simulation, where depth cameras are perfect: a table 50 centimeters away reads 50.0. But real depth cameras are not. They add noise, misread reflective surfaces (like shiny metal or water), and struggle with thin objects like wires or flat blades. A policy trained on clean simulated depth fails on real noisy depth.

A naive approach: add noise to the simulation during training, then hope the robot learns to ignore it. But this only works if the noise model matches reality. If the noise is wrong or the real camera has systematic errors (seeing 48 when the true distance is 50), the policy fails.

The gap in one sentence. Train a neural model to predict what the true depth is, given what the camera read and what it looks like (the RGB image).

The hidden quantity

The hidden quantity: Camera model fidelity

measured quantity  =  Noise model accuracy

The paper measures how well the simulated noise model matches the real camera's errors. If the model predicts the real camera will read 51 when true depth is 50, but the real camera reads 48, the noise model is off. The better the simulation matches reality, the less the neural model has to correct for, because the task becomes simpler — learning to invert a known error is easier than guessing what unknown errors are.

The paper estimates this by training the neural model on paired simulation data (noisy depth and RGB image together predict true depth), then testing it on real depth frames where ground truth is measured or inferred from multiple views. Accuracy is the difference between predicted depth and true depth.

Why it works

Why learning a camera model fixes the sim-to-real gap

The core idea is that a robot policy does not need to handle all camera noise, only the specific noise pattern it learned with. If that pattern matches reality, the policy succeeds. The problem is that naive noise injection (Gaussian blur, random numbers) does not match how real cameras fail.

A real camera fails in specific ways: it is off on reflections, it misses thin objects, it drifts at certain distances. By simulating exactly those failures, paired with the clean depth, the neural model learns to invert them. Given a noisy real image and depth, the model asks: what is the true depth that would cause a camera with this noise pattern to produce what I see now? The answer is the cleaned depth. When the noise model is accurate, this inversion works perfectly.

The learning and prediction formula

First in words:

Depth prediction = minimize average squared error between predicted depth and true depth, learned on paired sim data. At test time, given raw depth and RGB, predict true depth.

Then the compact form:

L = mean((depth_pred - depth_true)^2) where depth_pred = CDM(RGB, depth_raw, weights)

Every symbol:

depth_predThe depth the model predicts is true
depth_trueThe actual true depth from simulation ground truth
depth_rawThe noisy reading from the real camera
RGBThe color image paired with the depth
CDM(...)The neural model's output given inputs
weightsLearnable numbers inside the model, adjusted during training
LThe loss: how wrong the model was
A tiny worked example
Frame 1: raw depth = 49.5cm, RGB = table surface, true depth = 50.0cm. Model predicts 50.1cm. Error = 50.1 - 50.0 = 0.1. Squared = 0.01.
Frame 2: raw depth = 47.8cm (bad reading), RGB = reflective metal, true depth = 50.0cm. Model predicts 50.2cm. Error = 0.2. Squared = 0.04.
Frame 3: raw depth = 51.2cm, RGB = dark surface, true depth = 50.0cm. Model predicts 49.9cm. Error = 0.1. Squared = 0.01.
Average loss = (0.01 + 0.04 + 0.01) / 3 = 0.02. Model adjusts weights to lower this loss on the next batch.

The model minimizes error on paired data, learning which patterns in the RGB and raw depth signal the presence of noise; at test time it inverts that signal to predict true depth.

What can go wrong

What can go wrong

Noise model does not match reality. If the simulated camera's noise is wrong, the CDM learns to correct for the wrong errors. On real robots with different camera hardware, it fails. Solution: make sure the simulated noise model is accurate for the real camera you plan to use.
Scenes the model has never seen before. The CDM learns from objects and scenes in simulation. If a real manipulation task involves a material or scene type (highly reflective paint, underwater objects, extreme distances) never seen in training, the CDM cannot predict. It guesses, and depth is wrong.
Depth is wrong when occlusions change. If the robot's hand occludes part of the depth map during manipulation, the CDM must infer occluded depth from context. This is hard and sometimes fails, leading to collisions.
Works when noise is learnable. The CDM works because real camera noise is systematic and predictable from the image content. If noise were truly random (independent of what the camera sees), no model could learn to fix it. Fortunately, real cameras fail in specific ways tied to the image, making them learnable.
What a runnable demo should prove

What a runnable demo should prove

Build a simulation where a depth camera has tunable noise parameters (blur, systematic offset, missing reflections, thin-object failures). Train a robot manipulation policy on clean simulated depth. Then: (1) apply the same noise to test depth, show the policy fails. (2) Train a CDM on paired noisy and clean depth from the same simulation. (3) Use the CDM to clean test depth, show the policy succeeds. This proves the camera model recovers the sim-trained policy's capability.

generalization_gap = (sim_success_rate) - (real_success_rate_without_CDM). Target: gap < 5% with CDM.
