Learning from Historical Activations in Graph Neural Networks

When a GNN processes a graph layer by layer, HistoGraph learns which layers hold the most useful information for each node, instead of just using the final layer.

Paper explainersAll themesGraph & Geometric Learning

Graph neural networks build node descriptions by passing information between neighbors across many layers. A problem: deeper layers smooth out unique details as information gets recycled too many times, and the final pooling step ignores all the useful middle layers. HistoGraph fixes this by learning to score each layer (high score if that layer holds useful information for a node, low if it is redundant), and assembling a weighted blend from the whole history.

Zero assumption version

The pooling shortcut that throws away half the work

When a GNN processes a graph, each layer refines the node descriptions by mixing information from neighbors. Early layers learn local patterns, like which nodes cluster together. Deeper layers learn global patterns, like which parts of the graph are central. But at the end, the pooling step (turning all node descriptions into one graph-level prediction) looks only at the final layer. This is wasteful: those early and middle layers built genuinely useful information, but it is discarded.

In deep networks this gets worse. Layers can start to look too similar—each layer outputs nearly the same numbers as the last because the information keeps recycling. Researchers call this over-smoothing. It erases the unique signatures that made early layers valuable.

The method in one sentence. HistoGraph learns scoring weights that pick the most useful layer for each node, then combines all those picks into a richer graph representation.

The algorithm as a flow

What it actually does

Step 1: Collect the history

Save every node's representation from every layer as it is computed.

Step 2: Layer-wise scoring

For each node, use final-layer representation as a query; compute scores over all saved historical layers; weighted sum picks the most informative mix.

Step 3: Normalize carefully

Balance layer contributions using signed normalization so early layers are not drowned out by uniform averaging.

Step 4: Node-wise scoring

Treat the fused per-node representations as a new graph; nodes score neighbors to refine features with global context.

Step 5: Graph descriptor

Average across nodes to form one final fixed-size summary for the entire graph, ready for downstream classification.

What the paper changes

What the paper changes

Instead of reading only the final-layer node descriptions into the pooling operation, HistoGraph ingests the entire sequence of node descriptions across all layers. Each node carries its own history, and learned scoring weights pick which parts matter most.

The hidden quantity

The hidden quantity: layer importance

measured quantity  =  layer-wise scoring weights

Each node needs a score for every layer in the network: how much of that layer's description should contribute to the final representation? HistoGraph learns these scores via attention. High score means that layer captured something real and unique; low score means it was redundant or over-smoothed. Early layers often get non-zero scores because they encode local structure. Middle layers get scores based on what they add. Deep layers get low scores if they have over-smoothed.

The paper measures this by computing attention patterns across layers (shown in Figure 2 of the paper) and verifying that early layers retain non-zero attention despite being deep in the network. Feature distance diagnostics confirm that HistoGraph keeps nodes more distinct across layers than standard methods.

Why it works

Why it works: preserving the diverse signals

Early layers in a GNN capture local neighborhoods—which nodes are close together, which small patterns repeat. Deep layers mix and recombine this local information to capture global structure—which clusters of nodes form, which roles a node plays in the bigger graph. If you only use the final layer, you lose the early local patterns. If over-smoothing has kicked in, the final layer is a blurry average of everything.

HistoGraph's layer-wise attention solves this by asking: for each node, which layer had the sharpest picture? Instead of discarding layers 1 through 4, it learns attention scores for each. A node that needs strong local context gets high weight on early layers; a node that benefits from global patterns gets high weight on deep layers. This adaptive selection works because different nodes play different roles in the graph.

The normalization step (dividing by a sum of weights) matters because without it, the scores can grow unbounded and one layer can shadow all others, recreating the original problem. With normalization, all layers remain in the conversation. Then the final node-wise scoring step lets nodes refine each other's fused descriptions, adding spatial awareness to the layer-wise mix. The result: a richer, more diverse representation that retains both local and global signals.

Math after the picture

The equation: weighted layer sum

First in words:

For each node, the final embedding is the sum of all historical layers, each scaled by a learned attention weight. Then node-wise attention refines this. The layer-wise sum is: node embedding = weight for layer 0 times layer 0 output, plus weight for layer 1 times layer 1 output, and so on.

Then the compact form:

h_v = sum_l ( alpha_l * x_v^(l) )

Every symbol:

h_vfinal embedding for node v
alpha_llearned attention weight for layer l
x_v^(l)node v's representation at layer l
sum_lsum over all layers from 0 to L-1
Tiny worked example: a 3-layer network
Node 5 has three saved representations: layer 0 = [0.2, 0.8], layer 1 = [0.5, 0.5], layer 2 = [0.9, 0.1].
HistoGraph learns scoring weights: alpha_0 = 0.6, alpha_1 = 0.1, alpha_2 = 0.3.
Final node description = 0.6 times [0.2, 0.8] plus 0.1 times [0.5, 0.5] plus 0.3 times [0.9, 0.1].
Component-wise: [0.12, 0.48] plus [0.05, 0.05] plus [0.27, 0.03] equals [0.44, 0.56].
Layer 0 (local) dominated; layer 1 contributed little; layer 2 (global) added some polish. Same node, 3 layers, one adaptive blend.

The equation shows how each node picks its own blend of layers; normalization keeps all layers in play, and the learned weights (alpha_l) adapt per-node based on what that node needs.

What can go wrong

What can go wrong

No normalization: unbounded weights. If you remove the division-by-sum step, attention weights can grow without limit. One layer dominates, and you are back to ignoring others. Ablation shows accuracy drops from 97.8% to 74.5% on PROTEINS.
Missing layer-wise attention: uniform averaging. If all layers are weighted equally, over-smoothed deep layers poison the mix with their blurred, redundant signals. Ablation shows accuracy drops to 78.6%. Adaptive selection is essential.
Missing node-wise attention: no spatial refinement. Nodes are isolated during the layer aggregation. Without spatial attention to model interactions, final representations lose context about the graph structure. Accuracy drops to 80.8%.
Done right: all three pieces together. Normalization + layer-wise + node-wise scoring create a balanced system that adapts to each node and dataset. On deep networks (32, 64 layers) the speedup is dramatic: over 90% faster than standard pooling while improving accuracy, because the two-stage design avoids the expensive all-pairs node scoring at every layer—layer-wise scoring happens once, node-wise scoring happens once, for a total cost much lower than stacking full attention across all layers.
What a runnable demo should prove

What a runnable demo should prove

Build a 5-layer GNN on a small graph classification task (like PROTEINS: 1113 graphs, classifying protein function). Train two models side by side: (1) standard pooling (last layer only), and (2) HistoGraph pooling. Save layer outputs during the forward pass, so you can inspect which layers HistoGraph attends to. Visualize the attention weights per node to show that early layers get non-zero scores, proving they contribute despite being deep.

improvement = (histograph_accuracy - standard_pooling_accuracy) / standard_pooling_accuracy

The demo must make it impossible to miss that early layers recover useful information, and that deep networks suffer less blurring when node descriptions from all layers are preserved instead of thrown away.
