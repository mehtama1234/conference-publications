Dissecting Multimodal In-Context Learning

Transformers learn to associate information across modalities by copying labels from matching examples, but they do it unevenly—the secondary modality (like captions) learns from very few examples when trained on diverse primary data (like images).

Paper explainersAll themesMultimodal

Modern transformers can learn new tasks from a handful of examples inside a single prompt—this ability is called in-context learning. But when a transformer sees both images and text, how does it learn to link them together? This paper traces the hidden wiring: transformers use an induction mechanism (a built-in pattern-matching circuit) to find examples that look similar and copy their labels. The asymmetry is the surprise: the secondary modality (e.g., text descriptions) requires far less diversity than the primary modality (e.g., the image collection) for this to work.

Zero assumption version

Multimodal transformers work, but we do not know how they learn across modalities

When you train a transformer on pairs of images and captions, the model learns to associate them—give it a new image and it can generate a caption. But inside the transformer, how does this association actually happen? Is it a mystery or a mechanism we can trace?

A beginner might guess that each modality (vision, language) develops separate pathways and they somehow merge at the end. But this breaks because the model needs to learn associations from just a few examples, and random merging would need a lot of alignment. The real question is: what wiring does the model discover to link new images and captions in a single prompt?

The core question. How does a transformer learn to match a new image to a new caption label using only a handful of in-context examples?

What the paper changes

The one thing this paper traces

The paper does not propose a new method—it reverse-engineers an existing one. It reveals that transformers, when trained on multimodal data, automatically develop a hidden mechanism (a built-in wiring) that matches examples and copies their labels across modalities. The object is: attention patterns that find similar earlier examples in the context and relay their labels to the new input.

the object it moves  =  attention patterns that match and copy labels
The hidden quantity

Learning asymmetry: how much complexity each modality needs

measured quantity  =  modality complexity asymmetry

The paper measures a surprising asymmetry: when training on multimodal data, the secondary modality (e.g., captions) requires much lower data complexity than the primary modality (e.g., images) for in-context learning to emerge. Complexity here means diversity—how many different distinct types of data the model sees.

They discover this by controlling the statistics of synthetic data: training on high-diversity images but low-diversity captions still allows the transformer to learn the cross-modal link in-context. This challenges the intuition that both modalities need equal training richness.

Why it works

How transformers copy labels across modalities

The transformer builds two linked attention patterns. The first scans the primary modality (images) to find which earlier examples resemble the current input, comparing low-level features like color and shape. This is the matching head—a pattern-comparison circuit. Once it identifies the matching earlier example, the second pattern grabs the label attached to that example. Because the matching head does the hard work of finding the match using varied image features, the secondary modality only needs to store the association—it does not need its own diversity to learn the link. The primary modality's high diversity makes the matching reliable; the secondary modality just tags along.

Critically, both modalities refine their circuits together during training: the visual matching circuit and the caption-copying circuit co-evolve. But the visual side carries the load of learning to discriminate examples, so the caption side can be learned from fewer distinct types.

Math after the picture

The induction scoring mechanism

First in words:

For each prior example in the context, compute a similarity score based on how much its image resembles the current input image. Normalize these scores so they sum to one (they become weights). Then take a weighted sum of the prior captions using these weights. The transformer learns both the similarity scoring function and when to use it.

Then the compact form:

output_label = sum_j weight_j * prior_caption_j, where weight_j = softmax_j(similarity(current_image, prior_image_j))

Every symbol:

output_labelthe predicted caption for the new image
weight_jhow much attention to pay to example j, ranges from 0 to 1
prior_caption_jthe caption label of the j-th example in context
similaritya learned function comparing current and prior image features
softmax_jturn raw similarity scores into weights that sum to one
A tiny worked example
Suppose we have three prior examples: (dog image, 'dog'), (cat image, 'cat'), (dog image, 'dog')
New input: a dog image we have not seen before.
Similarity scores: dog-to-new-dog = 8.0, cat-to-new-dog = 1.5, dog-to-new-dog = 7.5
Softmax weights: 8.0/(8+1.5+7.5) = 0.47, 1.5/(8+1.5+7.5) = 0.09, 7.5/(8+1.5+7.5) = 0.44
Output: 0.47 * 'dog' + 0.09 * 'cat' + 0.44 * 'dog' = strong vote for 'dog' (0.91 probability)

The learned similarity function (built from attention patterns) ignores caption complexity and relies entirely on image features, which is why the secondary modality can learn from few examples.

What can go wrong

What can go wrong

Modality imbalance inverted. If the primary modality has low diversity and the secondary modality has high diversity, multimodal induction learning breaks. The induction mechanism cannot match examples if the primary modality lacks discriminative features.
Position-encoding method delays circuit formation. The paper finds that RoPE (a way of labeling where each word sits in the sequence) can delay the emergence of matching circuits, requiring more training time, because RoPE's encoding makes it harder for attention to directly compare positions between examples. Models using other position-labeling methods develop in-context learning faster because their encodings make position comparisons more direct.
No direct cross-modal similarity. The mechanism only works if both modalities describe the same underlying concepts. If captions describe things the images do not show (or vice versa), the induction circuit fails because matching is impossible.
Done right: balanced architecture. The circuit works when the primary modality provides high feature diversity (many distinct types), the secondary modality provides label associations, and both are aligned on the same concepts. The model then learns in-context associations from just a few examples.
What a runnable demo should prove

What a runnable demo should prove

Build a small transformer on synthetic data: generate 50 random images (each is a pattern: striped, dotted, solid; in red, blue, or green). Create labels with low diversity: only 3 captions (red, blue, green). Train on 100 image-caption pairs. At test time, present three in-context examples and a new image, then measure whether the model predicts the correct caption. The experiment proves the asymmetry: this low-diversity caption setup succeeds because the image diversity is high.

test_accuracy = (correct_predictions) / (total_new_images)

The demo must show that accuracy exceeds 75 percent even though captions have only 3 types, proving that multimodal induction learning relies on primary modality diversity, not balanced data complexity.
