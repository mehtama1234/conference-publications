ZeroDiff: Zero-Shot Time Series Reconstruction via Informed-Prior Diffusion

Train on observed locations to reconstruct measurements at unobserved locations by learning to fix the errors in a naive guess using diffusion.

Paper explainersAll themesTime Series & Sequential

You have weather sensors at certain city locations that measure temperature, but not at many nearby places where no sensors exist. A naive approach directly predicts temperature at unobserved places based on the available data, but it tends to produce overly smooth, middle-of-the-road guesses that miss both the coldest and warmest spots. ZeroDiff fixes this by constructing a rough first guess from available signals, then learning to identify and correct the systematic errors in that guess using a diffusion process—a technique that iteratively refines noisy outputs into sharp, accurate predictions.

Zero assumption version

Measuring where you have never measured

Time series data—sequences of measurements over time—often come from physical sensors. A city might measure temperature at five sensor locations but need to know what the temperature is at hundreds of other places. The obvious first attempt is to train a model that reads all available information (weather patterns, nearby readings, season, time of day) and predicts the missing value at an unmeasured location.

This naive approach has a fatal flaw. Without any actual ground-truth measurements from those unmeasured locations, the model has no signal to pull toward the true extremes. Instead, it learns to predict the statistical average—smooth middle values that underestimate both heat waves and cold snaps. The model sees many average days during training and learns to hedge its bets, producing predictions that are correct on average but miss the actual shape of the real phenomena.

The problem in one sentence. Naive models predict smooth average values at unmeasured locations because they have never seen the true extremes there.

The algorithm as a flow

What it actually does

Build an informed prior (a starting guess based on available data)

Use only the available signals to make a rough, often-smooth first guess at unmeasured locations.

Observe the error signature

At the locations where you do have real measurements, compare the naive guess to the truth.

Learn the error pattern

Train a diffusion model to recognize and predict how far off the naive guess is, using only the observed error patterns.

Reverse the diffusion process

Start with the naive guess at unmeasured locations; iteratively refine it to correct for the learned error pattern.

Output sharp, realistic predictions

The result captures extremes and realistic variability instead of averaging everything toward the middle.

What the paper changes

What the paper changes

The paper modifies the initial guess at unmeasured locations. Instead of using the naive prediction directly, it treats that prediction as a starting point for an error-correction loop. A separate model learns to predict how large the systematic error is and then subtracts it away.

the object it moves  =  Error-correction signal
The hidden quantity

The error signature: where and how much the naive guess is wrong

measured quantity  =  Reconstruction error pattern

The hidden quantity is the systematic error left by the naive model at unmeasured locations—the difference between a smooth average-like prediction and the true sharp, variable value. At observed locations, you can measure this error directly by comparing the naive prediction to the real measurement. At unmeasured locations, you cannot see the truth, but the diffusion model learns the error pattern from the observed locations and generalizes it to the hidden ones.

The paper estimates this error by training a diffusion model—a process that repeatedly adds random noise to the error and learns to subtract it back out. This teaches the model where errors are large and where they are small, and what the texture of realistic correction looks like.

Why it works

Why it works: learning the true shape from limited ground truth

A naive model generalizes from the data it has seen. Since it has never seen real values at the unmeasured locations, it has no signal pulling it toward extremes there. It learns a smooth, average prediction because averaging is the safest strategy when you have no ground truth to guide you.

ZeroDiff reverses this by using the locations you DO have ground truth for. At those observed locations, the model can see exactly how wrong the naive guess is—too cold, too hot, too middle-of-the-road—and measure the error. It then trains a diffusion model on these errors. A diffusion model works by repeatedly adding noise to a signal and learning to remove it; during training, it sees hundreds of error patterns and learns what realistic corrections look like. When you apply this learned pattern to unmeasured locations, it applies the same style of correction the observed-location errors suggest: if the error signature says values tend to be more extreme than the naive guess, the correction will push predictions upward and downward accordingly.

Error patterns tend to be portable across locations. The reasons a naive model undershoots extremes at one location are often the same reasons it undershoots at nearby locations—local geography, seasonal patterns, feedback loops. By learning the error texture from observed spots, the model generalizes that texture to unobserved ones.

The correction formula

First in words:

The reconstructed value at an unmeasured location equals the naive guess plus the learned error correction, where the diffusion model iteratively refines the error estimate by gradually removing added noise.

Then the compact form:

y_unobs = y_naive + epsilon_learned, where epsilon_learned is predicted by diffusion: z_t = z_t-1 - sigma_t * grad_z L(z_t) + noise_t

Every symbol:

y_unobsthe final prediction at an unmeasured location
y_naivethe initial smooth guess from exogenous data
epsilon_learnedthe learned error correction, estimated by diffusion
z_tthe noise estimate at diffusion step t
sigma_thow much of the noise gradient to apply at step t
grad_z L(z_t)the direction to shrink the noise (learned from observed-location errors)
A tiny worked example
Observed location A: real temperature 82, naive guess 70, error = 12.
Observed location B: real temperature 58, naive guess 70, error = -12.
Unmeasured location C: naive guess 72.
Diffusion model sees errors ranging from -12 to +12; learns that average absolute error is about 11.
At unmeasured location C, diffusion predicts error around +10 (following the learned pattern).
Final prediction at C = 72 (naive) + 10 (correction) = 82, capturing the likely extreme instead of the safe middle.

The diffusion model learns where errors hide in the error signature from observed data; it then applies that learned texture of correction to unmeasured locations.

What can go wrong

What can go wrong

Error pattern does not generalize. If the unmeasured locations have fundamentally different causes or constraints than the observed ones, the error signature will not transfer. For example, if you trained on sensor errors at low elevations and try to predict at a high mountain site with different weather physics, the learned correction will misfire.
Observed data are not representative. If the observed locations cluster in one region (e.g., all sensors in one city neighborhood), the error pattern learned there may not reflect errors at distant unmeasured places.
Diffusion model overfits to noise. If the observed error samples are few or noisy, the diffusion model may learn noise texture instead of real systematic error, leading to wild, unrealistic corrections at unmeasured locations.
Done right. ZeroDiff works best when observed locations are spread across the region of interest, the error patterns have consistent causes, and there is enough observed data for the diffusion model to distinguish true signal from noise.
What a runnable demo should prove

What a runnable demo should prove

Build a small synthetic time series with a known ground truth at both observed and truly unobserved locations. Hide the true values at some locations. Train a naive model on the observed locations. Compute its errors there. Train ZeroDiff's diffusion correction on those errors. Apply it to the hidden locations. Measure whether the corrected predictions capture extremes better than the naive baseline, because the diffusion model learned that extremes at observed locations require large upward or downward corrections—so it applies those learned adjustments to unmeasured locations as well, whereas the naive model has no signal telling it to move away from the average.

Extreme capture = (fraction of peaks and valleys that the model predicts within 10 percent of true value) / (fraction that the naive model captures within 10 percent)
