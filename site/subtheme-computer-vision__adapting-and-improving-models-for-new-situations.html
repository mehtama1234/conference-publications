Adapting and improving models for new situations

Making vision models work reliably when the data shifts from training to the real world, or when they encounter new domains or tasks.

All themesField mapMathematicsAll explainers
What this is

A model trained on one dataset often fails on another. Train a face recognition system on photos from the internet and it might fail on security camera footage, which has different lighting, angles, and image quality. Train an object detector on sunny outdoor images and it fails in snow or rain. This domain shift — the mismatch between training data and real-world data — is one of computer vision's most practical problems. The research question is: how can we make models work reliably when data changes between training and deployment without retraining from scratch on expensive new labeled data?

The difficulty is that models learn superficial patterns, not deep concepts. A detector trained on synthetic rendered images learns to respond to digital artifacts and perfect shadows, not the features that matter for real photos. A model trained on one city learns city-specific cues, not what 'car' really is. When the data distribution shifts — new lighting, new camera, new domain — these superficial patterns fail. Simply collecting more labeled data is expensive and never covers all possible variations. Ideally, a model should adapt on its own, either by using unlabeled data from the new domain or by learning in a more generalizable way in the first place.

Researchers tackle this from several angles. Some use transfer learning: train a model on a large source dataset, then fine-tune it on a small amount of labeled target data. Others use domain adaptation: learn a mapping between source and target domains so that features become domain-invariant. Some use self-supervised learning on unlabeled target data — solve a task like predicting masked image patches to learn representations without labels. Others focus on test-time adaptation: during deployment, let the model update its internal settings (like how it normalizes pixel statistics) based on the stream of real data it sees, so it gradually adjusts to the new distribution. A few use meta-learning: train the model to adapt quickly to new tasks with few examples. The goal is generalization: models that work in messy reality, not just in controlled settings.

How the work breaks down

When models face new data in the real world, they need several different strategies to keep working. Some models update themselves during deployment by watching the data they encounter. Others are built from the start to work with very little labeled data or to handle multiple types of input. Still others focus on learning efficiently from scratch, or being small and fast while staying accurate. Each approach tackles a different facet of the same core problem: making vision systems reliable when things change.

Test-time adaptation without retraining

When a model is deployed in the real world, it often encounters data that looks different from what it was trained on—different lighting, different camera angles, different image quality. Stopping to retrain from scratch is impractical. The solution is test-time adaptation (TTA): let the model adjust itself as it runs, based on the actual data it sees, without needing new labels. The challenge is doing this without the model forgetting what it learned or drifting too far from its original behavior.

Prototype-based Test-Time Adaptation of Vision-Language Models improves CLIP's accuracy on 10 different domains by 3.7 percentage points—boosting it from 65.64% to 69.38%—by adjusting the decision boundaries to match the new data distribution while keeping inference fast (92% of original speed). Blocking the Leakage introduces a projection technique that keeps the model from drifting in unexpected directions during long-term adaptation, so it remains stable even after seeing thousands of test examples. Multi-Label Test-Time Adaptation with Conditional Confidence Scoring learns confidence scores for each prediction so it can weigh different classes appropriately in the new domain, improving accuracy from 57.31% to 69.22% on a standard benchmark. D²O: A Dual Debiasing Operator works by removing two separate sources of bias—one from styling and one from the environment—making it especially effective for visual style shifts while also helping in other scenarios. ZeroSiam avoids a common failure mode called collapse, where test-time adaptation causes predictions to focus obsessively on a single class, and keeps the model stable across both vision and language tasks including tiny models that usually suffer from this problem. Together, these papers show that test-time adaptation can fix domain mismatch without labeled data, but only when the method carefully preserves the model's original knowledge while adapting to local shifts.

Learning from very little labeled data

Real-world tasks often require learning from just a handful of labeled examples—medical imaging with rare diseases, actions in new videos, or new classes appearing online. Training from scratch requires thousands of labeled images. Few-shot learning asks: can a model learn a new class from just 5 or 10 examples by leveraging everything it learned before? The core insight is that models should learn a good geometric structure in their feature space so that new examples naturally fall into the right clusters without retraining.

Exploiting Low-Dimensional Features for Few-shot Whole Slide Image Classification solves the problem for medical images by recognizing that features from a whole-slide image naturally have structure with just a few underlying patterns, and learning a classifier that works in that constrained space. This cuts the number of separate learned model weights needed while getting strong results on medical image datasets. Understanding Dataset Distillation via Spectral Filtering reveals that the core mechanism of distillation (compressing a large dataset into a tiny synthetic one) works by matching frequency-specific patterns, and proposes a curriculum approach that gradually covers both blurry and sharp features—so the synthetic data captures all the information a model needs. SkelHCC: A Hyperbolic CLIP-Driven Cache Adaptation Framework for Skeleton-based One-Shot Action Recognition adapts a pretrained vision-language model for action recognition by working in a special type of curved space, which naturally preserves relationships between actions even with just one labeled example per class. From Perception to Planning: Evolving Ego-Centric Task-Oriented Spatiotemporal Reasoning via Curriculum Learning learns to reason about long sequences of events with a curriculum (starting on easier examples and progressing to harder ones) and reaches 92.4% accuracy on logical reasoning and 88.2% on fine-grained visual details with surprisingly few examples. These papers converge on a lesson: learning efficiently from little data depends on using the right structure or curriculum, not just collecting more examples.

Handling new domains and data distribution shifts

A model trained to recognize faces in outdoor photos often fails on security camera footage—the lighting is different, the poses are different, the resolution is lower. This is domain shift: the training data and deployment data come from different distributions. Simple retraining is expensive. The research question is: how can we detect and correct for these shifts without collecting new labeled data? Some approaches use unlabeled data from the new domain; others find features that work across domains; still others notice when the model is starting to fail and adapt selectively.

Identity-Free Deferral For Unseen Experts solves a specific but important case: when multiple experts (humans or systems) label data differently, and you encounter a new expert at test time. By removing the model's dependence on knowing which expert made a prediction, it generalizes much better to new experts—improving accuracy on medical imaging and ImageNet benchmarks substantially. Breaking the Synthetic-Real Domain Shortcut for Training-Free Generative Replay-based Class Incremental Learning addresses the case where new classes arrive over time (learning new categories without forgetting old ones). By not relying on synthetic data that looks too much like the original training domain, it avoids shortcuts and keeps learning even without storing old examples. FiSeR: Fine-Grained Source Representations for Cross-Domain AI Image Detection learns features specifically tuned to detect AI-generated images across different domains and artistic styles, gaining +10.22 accuracy on average when tested on new domains, and adapts quickly with just a few labeled examples from the new domain (+10.6 to +17.4 gain). Resolution as a Direction: Vector-Panning Feature Alignment for Cross-Resolution Re-Identification solves the mismatch when a model needs to recognize people across surveillance cameras that have different resolutions—instead of expensive super-resolution, it learns a direction in feature space that maps low-resolution features into a shared space, achieving the best results efficiently. Test-time Video-Text Retrieval: Benchmarking and Adapting for Query Shifts adapts to the case where queries from users change their phrasing or style (a common real-world problem), improving how well it works across six different types of query shifts. Scale-Aware Domain Harmonization for Domain Adaptation Person Search recognizes that people at different scales (close to camera vs. far away) look different across domains and harmonizes these appearances, achieving 82.3% mean average precision on a challenging benchmark. The common thread: recognizing what specifically changed in the new domain and adapting just those aspects, rather than retraining from scratch.

Multi-modal and multi-sensor adaptation

Real-world vision systems often combine information from multiple sources: different cameras, radar and lidar, thermal and visible light, or compressed and uncompressed video. Each sensor or data source has its own quirks and imperfections. The challenge is building models that work across these different modalities and adapt when the mix of sensors changes or the quality shifts.

Benchmarking and Enhancing VLM for Compressed Image Understanding addresses a practical reality: images on the internet are compressed (JPEGs, video codecs, etc.), which introduces artifacts and quality loss. A vision-language model trained on perfect uncompressed images often fails on real compressed images. This paper finds that while model capacity cannot be changed after training, the overfitting to training details can be reduced through a universal adaptor—improving performance by 10-30% across varying compression levels and codecs. DRFusion: Drift-Resilient Temporally Consistent Infrared–Visible Video Fusion fuses information from two different camera types (one sensing heat, one seeing visible light) in video sequences. The trick is keeping the fused output smooth over time while adapting to drift—when one sensor slowly degrades or the lighting changes. MAC-NeRF: Motion-Aware Curriculum Learning for Dynamic LiDAR NeRFs learns 3D scenes from lidar point clouds in dynamic environments (moving cars and pedestrians). Since moving objects complicate the learning, it uses a curriculum approach, first learning from static regions, then progressively incorporating motion—achieving the best results on realistic driving datasets. PVDepth: Panoramic Video Depth Estimation via Spatiotemporal Adaptation estimates depth (distance) in panoramic video, which wraps 360 degrees around the viewer. This requires adapting to the unique properties of panoramic cameras while keeping depth estimates consistent frame-to-frame. Together, these papers show that multi-modal learning requires not just combining signals but adapting each one to the specific characteristics of its sensor.

Building efficient and adaptable models

Real-world deployment requires models that are small, fast, and cheap to run, because slow models delay results and consume more power. But adaptation and efficiency often pull in opposite directions: efficient models are smaller and lack the flexibility to adapt, while adaptable models tend to be large and slow. These papers find ways to build models that are both efficient and can adjust to new tasks or domains without losing speed, so they can be deployed in phones and edge devices.

RF-DETR: Neural Architecture Search for Real-Time Detection Transformers automatically designs a detector architecture that is small enough to run in real time while still beating larger models—the first real-time detector to surpass 60 average precision on the COCO benchmark. AnyUp: Universal Feature Upsampling addresses a common need in many vision tasks: taking low-resolution features from a model and upsampling them to higher resolution while preserving the semantic meaning (what different regions mean). By designing an upsampler that works across different types of features and different tasks, this generalizes better than task-specific approaches. FOVI: A biologically-inspired foveated interface for deep vision models mimics how human eyes work: paying high focus to a small central region and low focus to the periphery. By computing high resolution only where the model looks carefully and low resolution in the periphery, it uses only a fraction of the usual pixel budget—achieving similar accuracy with much faster inference and using far fewer pixels. Hystar: Hypernetwork-driven Style-adaptive Retrieval via Dynamic SVD Modulation solves the problem of retrieving images based on both content and style across many different visual styles by using a small network that generates weights for the main network, adapting to each style efficiently without retraining. The result is top performance on multi-style retrieval benchmarks while keeping the model parameter-efficient. These papers share a principle: efficiency comes from adapting computation to the actual problem, whether by designing the right architecture, focusing processing on the most informative regions, or using small meta-networks to generate adaptive parameters.
