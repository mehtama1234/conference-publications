VDW-GNNs: Vector diffusion wavelets for geometric graph neural networks

A graph neural network using wavelets that understand data on curved surfaces instead of flat grids.

Zero assumption version

Curved data needs curved tools

A graph neural network is software that learns from data arranged as nodes (points) and edges (connections between them). It works great for social networks, chemistry, and computer circuits — flat problems. But wind on Earth is not flat: the air velocity at each location points in a direction, and that direction changes as you move over the curved surface of the planet. Same with nerve activity in a brain: each neuron at position X has activity pointing in some direction in 3D space.

A standard graph network processes numbers at each node. When it encounters directional data (a vector, a list of numbers that point somewhere), it either throws away the direction information by only keeping the size, or it treats the direction as extra numbers and loses the fact that it is a direction on a curved surface. A beginner tries to add rotation-aware steps to the network, but there is no principled way to do it: which rotations matter? How does rotating the input data change how the network responds? The network becomes fragile — a simple rotation of the input breaks its learned patterns.

In one sentence. Use wavelets that understand how surfaces curve so direction vectors blend correctly between neighbors.

What the paper changes

What the paper changes

The paper replaces the simple filters in a standard graph network with wavelets (a family of small, bumpy wave-shaped filters) built from vector diffusion maps, which are custom-designed to understand how surfaces curve. These wavelets treat direction vectors correctly when the surface is not flat.

the object it moves  =  wavelets for curved data
The hidden quantity

The hidden quantity: directional alignment

measured quantity  =  directional alignment score

Directional alignment is a number that measures how much a direction vector at one point points in a similar direction to neighboring vectors when you account for the way the surface curves. A high score means neighboring vectors point roughly the same way; a low score means they point different ways. The paper's wavelets learn to measure this alignment by comparing how direction vectors change as you move across the curved surface.

The wavelets estimate alignment by taking a direction vector at one node, smoothing it out using a wave-shaped blur that bends to follow the curve, and measuring how much signal survives the blur. If neighbors all agree on direction, most signal remains; if neighbors conflict, the signal fades away.

Paper reading. Directional alignment is measured by the eigenvalues of the vector diffusion operator, which computes overlap of direction vectors using a smooth-blob transition (a mathematical tool called a heat kernel — a way to smooth and spread signals gradually across the surface) on the curved surface.
Why it works

Why it works: matching the curve's shape

A standard graph network treats every connection the same way, never checking whether the surface curves sharply or stays flat. When data is directional, this is broken: a direction vector cannot just tilt anywhere; it must tilt only within the plane that is tangent to the surface at that point (the plane that hugs the curve locally). Vector diffusion wavelets solve this by encoding the curve's shape directly into the filters themselves.

Here is the mechanism: the wavelets are built by taking a mathematical operator that slides direction vectors along the surface in tiny steps (diffusion on the curved space), extracting the patterns this operator most strongly preserves (its eigenvectors), and making wavelets from those patterns. These wavelets now inherently know the curve. When the network applies a wavelet to a vector, it automatically rotates the vector only within its local tangent plane and measures how well it aligns with neighboring vectors also rotated into their tangent planes. Result: if you rotate the input data by a small angle, the output changes by a small angle too. If you rotate by 45 degrees, the output rotates 45 degrees. The network is tied to the true shape of the surface.

The payoff is that predictions do not break when you change perspective. A wind-field measurement rotated globally to a different compass direction will still match the learned pattern. A neural recording from a tilted brain will still align with patterns learned from upright recordings. The network has learned what is really there (the flow of wind or nerve activity), not spurious features that depend on how the data is oriented.

Math after the picture

The equation: diffusion wavelets for vectors

First in words:

The wavelet filter applied to a vector at position i uses an eigenvector of the diffusion operator, scaled by an exponential decay factor, to combine that vector with its neighbors.

Then the compact form:

psi_j(x) = exp(-lambda_j * t) * phi_j(x)

Every symbol:

psi_j(x)the j-th wavelet, a filter function evaluated at position x
lambda_jthe j-th eigenvalue of the diffusion operator, measures how fast this pattern fades
tthe scale or time parameter — larger t = more blurring
phi_j(x)the j-th eigenvector of the diffusion operator, points in a stable direction on the curve
A tiny worked example
Suppose at point A there is a direction vector pointing "north" (size 1). A neighbor B also points north.
Wavelet with eigenvalue 2, scale t=1: exp(-2 * 1) * 0.5 overlap = 0.135 * 0.5 = 0.07 (fades quickly).
Wavelet with eigenvalue 0.5, scale t=1: exp(-0.5 * 1) * 0.5 overlap = 0.606 * 0.5 = 0.30 (fades slowly).
Low-eigenvalue wavelets preserve strong directional alignment; high-eigenvalue wavelets detect fine details.

Wavelets with small eigenvalues capture persistent alignment; those with large eigenvalues detect rapid changes.

What can go wrong

What can go wrong

Wrong curve shape inferred. If the data does not actually lie on a smooth curved surface (e.g., it is noisy, sparse, or has holes), the diffusion operator learns a wrong curve model. Wavelets built from a wrong shape will not help because they will rotate vectors in the wrong plane and measure alignment against the wrong baseline, yielding worse predictions than standard methods.
Incompatible data types. The method assumes direction vectors at each node. If the data is scalar (one number per point), vector wavelets offer no advantage over standard wavelets.
Computational slowness. Computing eigenvectors of the diffusion operator and building wavelets is expensive on large graphs. Scaling to millions of nodes becomes impractical.
Done right. Use VDW-GNNs on moderate-sized datasets with direction information (wind, flow, neural patterns) where the surface is smooth and has enough data points per region.
What a runnable demo should prove

What a runnable demo should prove

A demo should take a small point cloud with direction vectors at each point (e.g., a sphere with vectors pointing outward, or a 3D curve with vectors tangent to it), train a standard graph network and a VDW-GNN on it to predict a property (like whether a point is near an edge). Then, rotate the entire input data by 45 degrees and test both models. The standard network should lose accuracy; the VDW-GNN should keep the same accuracy.

rotation_stability = accuracy_on_rotated_data divided by accuracy_on_original_data

A ratio near 1.0 proves the network learned what is really happening on the surface, not tricks that break under rotation.
