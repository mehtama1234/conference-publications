Visual Flow: Stopping Hallucination Snowballing in Multi-Agent Vision

In a chain of agents looking at the same image, hallucinations from one agent get amplified by the next, but relaying the original image data (not just text) between agents and forcing attention back to it stops this spiral.

Paper explainersAll themesAgents & Tool Use

When multiple AI agents work together to understand an image—like one agent spotting objects and passing that info to another agent for further analysis—hallucinations (false details the model makes up) from the first agent can snowball. Each following agent adds its own hallucinations on top, amplifying the problem. The paper shows that agents over-rely on text descriptions passed between them and ignore the actual image pixels the further down the chain they are. By passing the image data itself (specific, carefully chosen pieces of it) between agents and forcing the models to look at those pieces again, hallucinations stop growing.

Zero assumption version

The Hallucination Snowball

A single large vision model can look at an image and describe it. But when multiple models work in a chain—Agent 1 sees the image and says what it thinks, Agent 2 gets only Agent 1's text description and analyzes that, Agent 3 gets only text from Agent 2—something bad happens: false details made up by Agent 1 get written into the text, and Agent 2, seeing only the text, treats those false details as real and builds on them, and Agent 3 does the same. The hallucinations grow with each step.

A beginner might think: just give all agents the original image. But that is not the problem. When the full image is available, agents still ignore it. Instead they trust the text summary from the previous agent more than looking at the image themselves. The text is convenient and confident-sounding. By the time data reaches Agent 3 or Agent 4, agents have stopped looking at the image at all—they just read the text chain.

The core issue. Agents in a chain gradually stop looking at the image and trust only the text descriptions passed between them, so hallucinations from early agents multiply.

The algorithm as a flow

What it actually does

Identify visual relay tokens

Find the image-patch pieces that preserve real visual evidence best and get focused on early.

Relay tokens instead of text only

Pass those token pieces between agents alongside the text, not just text summaries.

Reallocate focus in downstream agents

When agents receive messages, force them to put more weight on the visual tokens again.

Reduce text-over-image bias

Agents now read both visual evidence and text, balancing them instead of trusting text alone.

Hallucinations stay local

False details made up by one agent do not amplify through the chain because downstream agents ground in real image pixels.

What the paper changes

What the paper moves

The paper changes what gets passed between agents. Instead of only text descriptions, it includes a small set of specific image-token embeddings (the learned numeric representations of image patches) along with text, and it tells downstream agents to put more weight on those image pieces.

The hidden quantity

The Hidden Quantity: Which Image Patches Matter Most

measured quantity  =  Visual focus persistence score

The paper identifies a hidden quantity: which image patches (small pieces of the image) get focused on strongly by the vision model in early layers of analysis but then get ignored in later layers or in downstream agents. These are the patches that best preserve visual truth but get buried under text summaries. The paper calls these 'visual relay tokens'—patches with a single sharp focus peak in the middle layers, meaning they carry real visual info, not noise.

The paper measures this by analyzing which tokens have a unimodal (single-peaked) focus profile and show strong signal preservation. It then selects a small subset based on this score and passes them between agents explicitly, reactivating focus on them in each downstream agent.

Why it works

Why Visual Flow Works

The paper identifies the root cause: when information flows between agents as text only, each agent builds its summary based on what the earlier agent said, and if that text contains a hallucination, it gets treated as fact. But if you send along the original image-token embeddings (the learned numeric descriptions of image patches) that caused the first agent's visual analysis, the second agent has two inputs to process—the text and the actual image data.

In a neural network, raising the weight of certain tokens means their outputs are multiplied by larger numbers when computing the model's final answer, so they contribute more to what the model predicts. Here, the second agent receives both the false text and the true image data with the image tokens weighted more strongly. This forces a direct competition: the model must produce outputs that satisfy both inputs, but when text and image contradict each other (as they do because of the hallucination), the model cannot satisfy both perfectly. The learning algorithm resolves this by pulling the model's internal state toward the input with higher weight—the image tokens. So the model's learned responses start matching reality instead of the hallucination because the image evidence contributes more strongly to the answer. When Agent 3 receives messages from Agent 2, this mechanism repeats: visual tokens are there with raised weight, so Agent 3 also learns to match the real image. The hallucination was stuck in text from Agent 1, but never got reinforced into Agents 2 or 3's learned behaviors, so it stops spreading.

The Attention Reallocation Equation

First in words:

The new attention weights to the relay tokens are increased by adding a learned importance score per token, scaled by the visual persistence strength, then normalized so all attention weights sum to 1.

Then the compact form:

a_realloc = softmax( a_original + alpha * v_token )

Every symbol:

a_originaloriginal attention weights before reallocation
a_reallocreallocated attention weights after ViF
alphascaling strength for the visual boost (a learned number)
v_tokenvisual relay token importance score (0 to 1)
softmaxa normalization that turns any numbers into fractions summing to 1
A tiny worked example
Token A (a relay token): a_original=0.05, v_token=0.8, alpha=2.0 -> boost = 2.0 * 0.8 = 1.6 -> a_realloc numerator = 0.05 + 1.6 = 1.65
Token B (text token): a_original=0.85, v_token=0.0, alpha=2.0 -> boost = 2.0 * 0.0 = 0 -> a_realloc numerator = 0.85 + 0 = 0.85
Token C (other visual): a_original=0.10, v_token=0.3, alpha=2.0 -> boost = 2.0 * 0.3 = 0.6 -> a_realloc numerator = 0.10 + 0.6 = 0.70
Sum before softmax: 1.65 + 0.85 + 0.70 = 3.20. After softmax normalization: Token A = 1.65/3.20 = 52%, Token B = 0.85/3.20 = 27%, Token C = 0.70/3.20 = 22%.
The relay token A was ignored (5% before) and is now attended heavily (52% after), forcing the agent to read the real image data.

The formula raises attention weight to visual relay tokens by adding a bonus based on how much real information they preserve, then renormalizes so the agent must pay more attention to the image.

What can go wrong

What can go wrong

Choosing the wrong relay tokens. If the selected visual tokens do not actually contain real information (e.g. they are noisy patches or represent hallucinated details themselves), reallocation will reinforce the wrong visual signal and the hallucination will still snowball, just in a different form.
Alpha too high or too low. If the scaling factor (alpha) is too weak, visual tokens get barely more attention than before and the effect is negligible. If alpha is too strong, visual tokens dominate and the model ignores necessary context from text, breaking reasoning that requires both image and language.
Relay tokens becoming stale. If an agent changes how it interprets or describes the image, passing old relay tokens from the first agent may represent outdated information, causing later agents to ignore relevant new insights.
Done right. When relay tokens are chosen from real visual information (patches that are not hallucinated), alpha is tuned to balance image and text, and tokens are refreshed when agent reasoning changes how the image is described, hallucination snowballing is reliably prevented across deep agent chains.
What a runnable demo should prove

What a runnable demo should prove

Build a chain of three vision-language model agents analyzing the same image. Agent 1 writes a description with an intentional hallucination (e.g. 'there is a dog on a chair' when no dog is present). Agent 2 reads Agent 1's text and answers a follow-up question about the dog. Agent 3 reads Agent 2's response and answers another question. Without ViF, Agent 2 and Agent 3 will treat the hallucinated dog as real. With ViF, pass selected image tokens (patches that represent what is really in the image, not the hallucination) alongside each message, and reallocate downstream agent attention to those tokens. Measure the fraction of follow-up answers that correctly note the dog is not present.

Hallucination_propagation = (answers_repeating_hallucination_without_ViF - answers_repeating_hallucination_with_ViF) / answers_repeating_hallucination_without_ViF

The demo must show that with visual relay tokens and reallocation, downstream agents stop amplifying the hallucination and instead ground their answers in what is actually visible in the image.
