Unified Vision–Language Modeling via Concept Space Alignment

vSONAR maps images and videos into the same number space as text and speech, so one model can caption and question-answer across 200 languages without retraining.

Paper explainersAll themesMultimodal

Most vision-language models treat images, videos, and text as separate problems, requiring different training pipelines and learning nothing about languages they have not seen. vSONAR solves this by fitting images and videos into an existing shared space where 200 languages and 37 speech languages already live. Once they share that space, a single model can read and speak about images in Armenian or Swahili as well as it does in English.

Zero assumption version

Vision-language models are trapped in their training languages

Today, when you build a model that understands images and writes captions, you teach it in English (or whatever language you have video captions in). If you want it to caption videos in Spanish, Chinese, and Polish, you need three separate training runs, each with its own labeled data. That is expensive and fragile: each model knows only its one language pair.

A beginner might think: why not just swap out the text decoder and keep the image encoder? Because the image encoder outputs a list of numbers (an embedding) that speak only image-language, and the Spanish text words speak Spanish-language numbers. They have no shared grammar. You cannot decode an image embedding into Spanish words without retraining the whole thing.

The hidden cost: languages with lots of captions train good models. Low-resource languages (Swahili, Tagalog, Tamil) get left behind because there is not enough data to train a separate vision-language model. The model cannot borrow knowledge from English.

In one sentence. vSONAR rewires the image encoder to speak the same numerical language as text, so one model handles images and captions in any of 200 languages without retraining for each.

The algorithm as a flow

What it actually does

Start with SONAR, a pre-trained text embedding space

SONAR is a finished coordinate system where text in 200 languages lives.

Take a pre-trained vision encoder (e.g., from an existing image model)

It outputs image embeddings, but they are in a different coordinate system.

Train a small alignment layer to map images into SONAR coordinates

The alignment layer is a learnable rotation and scale; it nudges image embeddings to overlap text embeddings.

Use a latent diffusion decoder (a generative model in the shared space) to produce text

Given image embeddings in SONAR space, the decoder writes captions in any of the 200 languages.

Test on captioning and question-answering across 62 languages

The model generalizes to languages it rarely or never saw paired with images during training.

What the paper changes

The one thing that changes

The paper modifies the image encoder's output: instead of speaking its own numerical language, it is rotated into SONAR's shared multilingual space. That single change — wrapping the vision encoder with a learnable alignment layer — is the move.

the object it moves  =  Image embedding space orientation
The hidden quantity

The alignment loss: how well image numbers match text numbers

measured quantity  =  Cross-modal alignment error

The hidden quantity is how far off an image embedding sits from the nearest text embeddings with the same meaning. When you show the model a photo of a dog and a caption 'dog' in English, the image and text embeddings should point in nearly the same direction in the shared space.

vSONAR measures this by taking image-caption pairs (or text-image-text triplets) and penalizing the distance between embeddings that should match. A small distance means good alignment; a large distance means the rotation is not working. During training, the alignment layer twists and scales until images and captions occupy the same neighborhoods in SONAR coordinates.

Why it works

Why mapping images into text-space lets one model speak 200 languages

The core insight is that languages are not separate worlds; they are different ways to point at the same ideas. SONAR already maps 200 languages into one coordinate space — 'dog' in English, 'perro' in Spanish, and 'chien' in French are clustered in the same direction. The model has already learned that Chinese and Polish are just different dialects of the same 'meaning-space.'

When you rotate the image encoder into that same space, images now speak the same dialect. A photo of a dog is no longer 'English-dog' or 'Spanish-dog' — it is just 'dog', a point in the shared coordinate system. The decoder, which already knows how to turn points in SONAR space into text in any of the 200 languages, can now generate 'perro' or 'chien' or 'xiao gou' from that same image embedding.

Most importantly, the alignment layer learns generic visual patterns (what a dog is, how dogs vary), not language-specific ones. The language knowledge is entirely in the pre-trained SONAR decoder. So when the model encounters a low-resource language like Tagalog with few image captions, it can lean on the visual knowledge learned from English data and the language knowledge learned from Tagalog text-only data, borrowed through the shared space.

Math after the picture

The alignment loss and the shared space

First in words:

alignment_loss = sum over mismatched pairs of distance_squared(image_embedding, text_embedding), where distance is measured in SONAR space.

Then the compact form:

L_align = (1/N) * sum_i || R(v_i) - t_i ||^2

Every symbol:

R(v_i)the rotation layer applied to image embedding v_i
t_ithe text embedding in SONAR space for the matching caption
||·||^2squared distance: the sum of squared differences in each dimension
Nthe number of image-text pairs in a batch
L_alignthe total alignment error for this batch
A tiny worked example
Suppose image embedding v_1 = [1.0, 0.5] and its matching text embedding t_1 = [1.1, 0.4].
After rotation R, we get R(v_1) = [0.95, 0.6] (the layer nudged the image closer to the text).
Distance squared: (0.95 - 1.1)^2 + (0.6 - 0.4)^2 = (-0.15)^2 + (0.2)^2 = 0.0225 + 0.04 = 0.0625.
A mismatch pair, say image dog and text cat: distance squared = 3.5 (large).
The loss penalizes mismatches 3.5 / 0.0625 = 56x harder, so training aligns matching pairs and pushes apart noise.

The rotation layer R learns to shrink distances for matching modalities, so images and captions occupy the same neighborhoods in the shared coordinate system.

What can go wrong

What can go wrong

Alignment layer too weak: the rotation does not fully map images into text-space. If the alignment loss is not optimized well, image embeddings sit halfway between their own dialect and the text dialect. Captions become generic or mix languages. Fix: increase training time or weight the alignment loss more heavily.
Training only on high-resource languages: the shared space becomes biased toward English. If alignment training uses only English image-caption pairs, the rotation optimizes for English. Low-resource languages get projected into the margins. Fix: mix balanced image-caption pairs across multiple languages during alignment training.
Mismatch between vision encoder and SONAR dimensions. If the image encoder outputs 768 dimensions but SONAR uses 1024, the rotation layer has to learn a non-square mapping, which can hurt generalization. Fix: pre-train the vision encoder in a SONAR-compatible dimension, or use a learned projection layer with gentle steering (add a small penalty that nudges the mapping toward simpler, smoother changes).
Done right: alignment is learned on balanced data across languages, the rotation layer has smooth regularization, and the pre-trained SONAR decoder is frozen (not retrained). Freezing the language decoder ensures that multilingual knowledge is preserved; only the visual-to-linguistic bridge is learned. This keeps low-resource languages anchored to high-resource language knowledge.
What a runnable demo should prove

What a runnable demo should prove

Build a minimal version: take a pre-trained CLIP image encoder (outputs embeddings), a pre-trained mBERT text encoder (trained on 104 languages), and a learned rotation layer that maps CLIP embeddings into mBERT space. Train the rotation layer on 100 English image-caption pairs. Then test on 10 Spanish image-caption pairs (data the alignment layer never saw) and 10 low-resource-language pairs (e.g., Tamil or Amharic, languages mBERT has learned from text alone). Measure alignment error and downstream caption accuracy.

alignment_error = mean( ||R(image_embedding) - text_embedding||^2 ); caption_bleu = bleu_score(generated_caption, reference_caption) for 10-language test set.

The demo should show that alignment error on unseen languages is nearly as low as on English, proving that rotation into a shared space generalizes across languages without retraining.
