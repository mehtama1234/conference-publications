Mechanistic Independence: A Principle for Identifiable Disentangled Representations

A model can recover hidden causes by measuring how each one acts on the data, without needing to assume anything about how they occur overall.

Paper explainersAll themesRepresentation & Self-Supervised Learning

Machine learning models often learn tangled representations — one hidden number mixes multiple hidden causes together. This paper proposes that we can untangle them by looking at which cause acts on which part of the data, rather than guessing what the hidden causes look like overall. This insight holds even when causes are mixed nonlinearly and the mixing cannot be reversed.

The tangled code problem

When a model learns from images, it discovers hidden patterns in the data. Ideally each pattern represents ONE thing — one object shape, one lighting condition, one texture. But in reality, a single hidden neuron often encodes multiple causes mixed together. If one neuron fires for both "orange color" and "ball shape," you cannot tell them apart.

A naive fix: assume each cause lives in a specific corner of the hidden space, and then use mathematics to separate them. But this requires guessing the shape of the hidden pattern — which cause is rare, which is common, how they interact. Real data does not obey such guesses. The paper shows: if you commit to a specific hidden pattern (the way causes occur together), the causes can still be tangled even if you solve your math problem perfectly.

In one sentence. This paper shows how to untangle hidden causes by looking at which one acts on which output, without assuming anything about how the causes occur overall.

What it actually does

Pick an independence criterion

Choose a rule for what "independent acts" means: support-based (disjoint outputs), sparsity (each cause touches few outputs), or higher-order.

Map the action graph

Figure out which hidden cause acts on which observed output, building a connection network.

Identify connected components

Treat the action graph as a network; each cause is one connected piece.

Prove invariance

Show that this action graph stays the same even if how the causes occur overall changes or causes become dependent.

Extract cause subspaces

Once causes are identified, recover the space each cause lives in, even if mixing is nonlinear or irreversible.

What the paper changes

What the paper changes

The paper shifts what we measure to decide if causes are separate. Instead of checking the hidden density (how often each cause occurs), it checks the causal footprint: which outputs each cause touches.

the object it moves  =  the measurement of independence
The hidden quantity

Mechanistic independence: the action signature

measured quantity  =  which output each hidden cause acts on

Every latent cause (hidden factor of variation) has a signature: the set of outputs it influences. For example, one cause might only affect color channels, while another affects shape contours. These signatures do not overlap if the causes are mechanistically independent.

The paper uses three types of signatures: support-based (the exact set of outputs touched), sparsity-based (how few outputs are touched), and higher-order (patterns in which outputs cluster together). All three lead to identifiability — meaning the causes stay separable no matter how often each cause occurs overall.

Why it works

Why looking at actions separates causes

Suppose you have three hidden causes and a nonlinear mix that blurs them together. If you guess how the causes occur overall and try to reverse the mix, you might fail because the nonlinearity is not invertible. But if you ask "which outputs does each cause touch?", you get a structural fact independent of invertibility.

Here is why: a cause that only affects outputs 1, 3, and 7 will never mix its effect with a cause that only affects outputs 2, 4, 6. The action graph is a structural fact about the mixing, not a guess about probability. Even if you change how often each cause fires, the action graph stays the same. That invariance is the key: mechanistic independence persists across all patterns with the same sparse mixing structure.

The independence equation

First in words:

A latent cause is identified if its action set (which outputs it influences) is disjoint from every other cause's action set. In graph terms: each latent cause is a connected component.

Then the compact form:

If support(cause_i) ∩ support(cause_j) = ∅ for all i ≠ j, then each cause is identifiable as a connected component in the bipartite graph (latent, observed).

Every symbol:

support(cause_i)the set of observed outputs that cause i influences
∩intersection (the shared outputs)
∅the empty set (no overlap)
bipartite grapha network with two layers: latent causes on one side, observed outputs on the other, with edges where cause touches output
A tiny worked example
Cause A: acts on outputs {pixel 1, pixel 5, pixel 9}.
Cause B: acts on outputs {pixel 2, pixel 6, pixel 10}.
Cause C: acts on outputs {pixel 3, pixel 7, pixel 11}.
No pixel is touched by two causes. Each cause is its own connected component.
Result: the three causes are separable even if we do not know how they occur overall or how nonlinearly they mix.

This equation says: causes are separated by which outputs they touch, not by probability guesses.

What can go wrong

What can go wrong

Causes that touch the same outputs. If two hidden causes always co-fire and thus touch the exact same outputs, mechanistic independence cannot separate them. The method identifies connected components; a tangled pair is one component.
Sparsity breaks under entanglement. If the true mixing is very dense (every cause touches almost all outputs), sparsity-based criteria fail. Higher-order criteria may still work, but require richer data.
Learning the action graph from finite data. The paper identifies when causes are separable in principle; learning which outputs each cause touches from finite samples is a separate, harder problem.
Done right. When the action graph is sparse and truly disjoint, mechanistic independence provably recovers the latent subspaces up to scale and permutation.
What a runnable demo should prove

What a runnable demo should prove

Build a synthetic dataset with three known latent causes (e.g., rotation angle, brightness, horizontal position). Mix them nonlinearly into 100 observed outputs (e.g., pixels). Make sure cause A only affects pixels 1-30, cause B affects 31-60, cause C affects 61-100 (disjoint supports). Train a model to reconstruct the outputs. Then map which latent units move which output groups. Verify that the identified causes match the ground truth structure.

structure_recovery = (number of correctly paired cause-output groups) / (total cause-output pairs)

The demo must show that without knowing how causes occur overall, we recover the right causes purely from their action signatures.
