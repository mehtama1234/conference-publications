Hidden Profile: Multi-Agent LLM Collective Reasoning

Multi-agent language models fail to explore what others know but haven't yet said, and a structured question-and-answer protocol fixes it.

Paper explainersAll themesAgents & Tool Use

When you put multiple language models in a group to solve a problem, you might expect them to share information and think together. But the paper finds they actually fail badly: the group gets only 30% right when facts are spread across members, versus 80% right when one model has all the facts. The core failure is that agents do not reason about what the other agents have learned but have not yet mentioned.

Zero assumption version

The World Before

When you have a group of people solving a hard problem and each person knows a different piece, you need them to share what they know. A beginner might think: build a language model that can take input from multiple agents and just combine their outputs. But that does not work.

The hidden trap is that agents do not naturally ask or reason about unspoken information. Suppose Agent A sees fact 1, Agent B sees fact 2, and the right answer needs both. If Agent A outputs a partial guess and Agent B only listens passively, Agent A's guess becomes the shared false anchor. Now Agent B agrees with it (thinking that is what most of the group believes) instead of surfacing the fact that makes the guess wrong. The models fall into premature agreement on partial evidence.

The core failure. Multi-agent language models do not reason about the information that other agents possess but have not yet revealed.

What the paper changes

What the paper changes

The paper changes the communication protocol—the rules for how agents take turns and what they are asked. Instead of letting agents freely chat and converge wherever they land, the structured protocol asks each agent to state what they know about each topic before the group makes a joint decision.

the object it moves  =  Communication protocol
The hidden quantity

The Hidden Quantity: Information Asymmetry Awareness

measured quantity  =  Hidden information asymmetry awareness

This is the one thing the paper measures but the agents do not naturally track: whether an agent reasons about facts that other group members know but have not yet said out loud. In a normal group conversation, when someone stays silent, they might be holding back a key fact, or they might just have nothing to add. Humans intuitively reason about this—we ask quiet teammates what they think. Language models do not.

The paper estimates this by watching what agents say and comparing it to what they could have known. If an agent makes a claim without first asking others what they know, the paper marks that as a failure to recognize information asymmetry. When the structured protocol asks each agent to speak first, it forces the agents to surface facts they had but never mentioned, and the paper measures how many previously unspoken facts now appear in the conversation.

Why it works

Why It Works: The Real Reason

Language models are trained on examples where all the information they need is already in the input. They do not learn to proactively ask about missing pieces or to reason about what other minds might know. When you put multiple models together without structure, each model sees only the claims that others have already said, and it responds based on those. If the first agent makes a guess with incomplete evidence, the second agent sees that guess and treats it as shared knowledge—even though the second agent might have evidence that contradicts it.

A structured protocol works because it changes the input each agent sees. Instead of just seeing claims already made by others, the protocol makes each agent state what it knows about each specific topic before any joint decision is made. This surfaces facts that would otherwise remain silent. Once all the facts are on the table—stated by each individual agent—the final decision-making step has access to the full picture, not just the fragments that happened to be spoken first.

inputEach agent receives its individual facts
stepStructured protocol: ask each agent to state what they know about each topic
stepAll agents see all individual facts, now explicitly spoken
stepJoint reasoning on complete evidence, not just the claims already spoken
outputCorrect group decision
Math after the picture

The Equation: Collective Accuracy

First in words:

Group accuracy equals the fraction of tasks where the joint decision matches the true answer, measured as the number of correct joint decisions divided by the total number of tasks.

Then the compact form:

collective_accuracy = (number of correct joint decisions) / (total number of tasks)

Every symbol:

collective_accuracythe fraction of problems the group solves correctly, from 0 (all wrong) to 1 (all right)
correct joint decisionthe group's final answer matches the ground truth
total number of taskshow many problems the group attempted
A tiny worked example
Suppose 100 tasks, each graded as the group right or wrong.
Without structure: the group gets 30 tasks right. Accuracy = 30 / 100 = 0.30 (30%).
With structured protocol: the group gets 82 tasks right. Accuracy = 82 / 100 = 0.82 (82%).
The improvement is 82% - 30% = 52 percentage points, because facts can now surface.

Collective accuracy rises when all agents reveal their facts before the group decides, because the final decision rests on complete evidence instead of partial claims.

What can go wrong

What can go wrong

Larger groups still struggle. The paper shows that as you add more agents, even the structured protocol's benefit shrinks. With 5 agents instead of 2, the gains are smaller. This suggests there is an upper bound on how much structure alone can fix.
Model size does not guarantee collective reasoning. Bigger models do not always do better in groups, because collective reasoning requires understanding what others know but have not said—a skill that is independent of general model size. Gemini-2.5-Flash, a smaller model, outperforms some larger models at this specific task because it has learned better reasoning about group dynamics, not because it has more internal settings.
Static structure may not cover all reasoning types. The protocol tested in the paper works for the Hidden Profile task (finding a shared truth from distributed clues). Different group reasoning tasks might need different protocols.
Protocol works across model families. The structured communication protocol improves reasoning consistently across multiple frontier models, not just one, because the problem it solves is fundamental to how language models process group information: each model, regardless of its training, will respond to what it sees in the input. By forcing all facts to surface before decision-making, the protocol fixes the input for every model equally.
What a runnable demo should prove

What a runnable demo should prove

Build a small experiment with 3 language models and a simple task: each model learns one different clue, and the task requires all three to answer correctly. First, run the group with free-form conversation. Measure how often they get the answer right. Then, run the same group with a structured protocol: ask each model in turn what it knows about each topic before any decision is made. Measure accuracy again. The demo should make it impossible to miss that structure brings hidden facts into the light.

improvement = (accuracy_with_protocol - accuracy_without_protocol)

When facts are forced to surface by the protocol, the group's final reasoning has access to the truth, and accuracy jumps.
