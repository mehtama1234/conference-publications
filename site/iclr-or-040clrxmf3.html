Provably Explaining Neural Additive Models

For a special kind of neural network that adds up individual features, you can now find the smallest set of input numbers you actually need to make a prediction, and prove you found the real minimum.

Most machine learning explanations are guesses. They say what matters, but you cannot verify they are right. This paper shows how to find the truly smallest set of input numbers a Neural Additive Model depends on, and prove that is the smallest possible. The trick works because these models are built by adding up predictions from each input separately, which is simpler than jumbled networks.

Why explaining models is hard

When you use a machine learning model to make a decision, you want to know: which input numbers actually mattered? A doctor wants to know if the model used the blood pressure or just the weight. A loan officer wants to know if the model flagged too many people by age alone.

Older explanation methods try to guess which inputs matter by testing them one at a time. But this is slow and fragile. For a model with 100 inputs, you would have to check all two to the power of 100 different combinations in the worst case, which is impossible.

Worse, most explanation methods give up and only find a subset that is small but not the smallest. You get an answer that works, but you never know if there is a smaller answer hiding somewhere.

The problem in one sentence. Existing methods cannot find the truly smallest set of inputs that explain a prediction, and proving you found the real minimum seems to require checking far too many combinations.

The algorithm as a flow

What it actually does

Build a lookup table for each input

For every single input, precompute all possible outputs if only that one input varies.

Sort inputs by predictive strength

Rank which inputs change the output the most, from strongest to weakest.

Add inputs greedily while checking

Start with the strongest input, then add the next strongest, stopping as soon as the prediction stays unchanged.

Stop when adding more changes nothing

As soon as a new input contributes nothing, you have found the minimal set.

Prove this is minimal

By the structure of these additive models, if this combination works, it is the smallest possible.

What the paper changes

What the paper changes

The paper changes how you search for the minimal set of inputs. Instead of checking all two to the N combinations or doing random sampling, it uses the special structure of Neural Additive Models: the fact that they add up predictions from each input separately.

The hidden quantity

The cardinality of an explanation

measured quantity  =  explanation cardinality

Cardinality is simply a fancy word for the count or size. In this paper, it means: how many input numbers do you need to include in your explanation? Smaller is better, because it means fewer things matter.

The paper measures this by testing whether the model still makes the same prediction when it only looks at a chosen set of inputs and ignores all the others. The algorithm counts up how many inputs it had to include before the prediction stayed the same.

Why it works

Why it works: the special structure of additive models

Neural Additive Models are built in a straightforward way: they compute a separate prediction from each input number, then add all those predictions together. This structure is the key. Because predictions are added, not jumbled, you can precompute what each input contributes to the total.

The algorithm exploits this by first ranking inputs by how much they change the output. It knows that a weak input will never be necessary for a minimal explanation, so it can skip testing combinations that include only weak inputs. This eliminates the vast majority of the exponentially many combinations without ever checking them.

Once inputs are ranked, the algorithm adds them one at a time from strongest to weakest, verifying each step. As soon as an additional input changes nothing, you stop. Since the model is additive, if this set of inputs produces the correct output, then no smaller set can, because removing any input in the set would drop the contribution from that input to zero. This guarantee comes from the structure, not from luck.

The formula and a worked example

First in words:

A Neural Additive Model output is the sum of individual univariate predictions. The algorithm finds a minimal subset S such that the model output given only inputs in S equals the true output given all inputs.

Then the compact form:

y = sum_i f_i(x_i) where each f_i is a univariate function. Find minimal S such that sum_i_in_S f_i(x_i) = sum_i f_i(x_i)

Every symbol:

ythe model's prediction
f_ithe function that turns input i into a contribution
x_ithe value of input i
Sthe minimal set of input indices needed
sum_i_in_Sadd up only the contributions from inputs in set S
A tiny worked example
Say the true prediction is: age contributes 0.3, income contributes 0.5, credit score contributes 0.2, total = 1.0
Algorithm tests: age alone (0.3) is not enough. Age + income (0.8) is not enough.
Age + income + credit (0.3 + 0.5 + 0.2 = 1.0) matches the true prediction. Stop.
Minimal set is age, income, credit. Remove any one and the output drops. This is the smallest.

Because additive models just sum contributions, the algorithm can find the true minimum without testing all subsets.

What can go wrong

What can go wrong

Only works for additive models. If you use a normal neural network that jumbles inputs together, this algorithm does not work. You need the additive structure where predictions from each input sum cleanly.
Needs to precompute tables for each input. The initial preprocessing step builds a table for every single input. If you have millions of inputs or the model is slow to run, this step itself becomes expensive.
The minimal set might still be large. Even though the algorithm finds the true minimum, that minimum might include many inputs. The model might genuinely depend on fifty features, which is not a useful explanation anymore.
Done right. Use this algorithm only when the model is Neural Additive, you can afford the preprocessing, and you need a proof of minimality. For other models or time constraints, use sampling-based methods, which sacrifice the proof but skip the expensive preprocessing step.
