Distilling and transferring what models learn

Papers compress large pretrained models and transfer their knowledge to new domains through knowledge distillation and diffusion models, making powerful representations accessible on limited devices.

All themesField mapMathematicsAll explainers
What this is

Large models trained on billions of weights are effective but expensive to run. A smartphone or an edge device cannot run a model that requires gigabytes of memory and thousands of arithmetic operations per prediction. Knowledge distillation is the answer: train a small 'student' model to mimic a large 'teacher' model, capturing the essential patterns in a compact form. The teacher model is often self-supervised pretrained on huge unlabeled datasets, and the student inherits that knowledge without ever seeing the original data — the teacher has already distilled the patterns into its weights.

The difficulty is that small models cannot physically represent everything a large model knows. A 1-million-weight model cannot learn as much as a 1-billion-weight model. So the distillation process involves strategic choices: what information from the teacher is most important to preserve? How should the student's output distribution be compared to the teacher's? Should you distill layer by layer or just final outputs? Diffusion models add another dimension: some papers use diffusion-based distillation, where the student learns to denoise in a different way than the teacher, or where distillation itself becomes a denoising process. The quality loss is unavoidable, but well-done distillation can recover 80-95% of the teacher's performance in a model 10x smaller.

Across 17 papers, researchers develop distillation techniques for self-supervised models, study what knowledge transfers and what does not, and explore whether distillation across domains or architectures is possible. Papers also study domain transfer: can a model trained on general internet images learn representations that transfer to a specific domain like medical imaging or satellite photos? The practical value is clear: it enables on-device AI by reducing memory footprint, reduces computational costs because prediction becomes faster, and makes good representations accessible to resource-constrained applications like mobile phones or IoT sensors that could never run a model with billions of weights.

How the work breaks down

Work in this subtheme splits into five directions: making models smaller through compression, preserving knowledge as models learn continuously on new data, distilling teacher knowledge across different domains and tasks, building lightweight specialized models from pretrained foundations, and improving how distillation itself works by changing what gets transferred or how representations are shaped.

Compressing representations into smaller storage

When a learned model is stored or transmitted, it takes up a lot of space because each weight is stored as a floating-point number. This makes it hard to deploy models on phones or edge devices where storage is limited because they have megabytes of memory, not gigabytes, so you need techniques to shrink the learned representations into fewer, smaller numbers without erasing the knowledge. These papers tackle the problem of shrinking what a model has learned without losing too much quality.

CrossQ reduces token storage by 64 times: when a model learns to represent text passages as dense vectors for search, CrossQ quantizes those vectors — converting the floating-point numbers into much smaller integers. The trick is that different tokens need different levels of detail, so it adapts the quantization per token based on what the retrieval task actually needs, keeping 98% of the original performance while using 64 times less storage.

Token Graphs rethinks sentence representations entirely. Instead of storing all words equally, it builds a graph of relationships between important tokens and drops 90% of the less important tokens without harming accuracy because those tokens carry little information for the task. This means a sentence representation uses 20 times fewer weights to store and runs 100 times faster than fine-tuning methods so that deployment on small devices becomes practical and affordable in real systems.

IVQ compresses audio and multimodal data by using a binary tree structure (inspired by the I Ching symbol system) to build small codebooks that represent patterns. It gets better quality from smaller storage than other vector quantization methods because the tree structure lets it use different levels of detail in different parts of the data, which matters for systems that stream audio or work on limited bandwidth so they need compact representations.

Preserving knowledge while learning new tasks

When a pretrained model learns a new task, it often forgets what it learned before — called catastrophic forgetting. This is the core problem these papers solve: how to add new knowledge without erasing the old.

MaRS uses a frozen pretrained model and carefully expands the number of learnable slots (small adapters that plug into the model). When learning a new task, it uses a two-stage process: first, it learns what the task needs; then it distills the original knowledge back in using a contrastive loss (a learning signal that compares the new model's outputs to the frozen original). The result is that what the original model knew stays intact while the model picks up new skills.

CompSLOT takes the same principle — using slots as learnable modules plugged into a frozen foundation model — and packages it as a general tool that works with different continual learning methods. It reduces catastrophic forgetting by learning concepts (high-level semantic ideas) instead of low-level details, which transfer better across tasks. A small number of concept-level slots can cover many tasks without interfering with each other because concepts are abstract enough to apply broadly.

Distilling knowledge across domains and architectures

Knowledge distillation normally assumes the teacher and student see the same data from the same domain. But what if you want to transfer knowledge to a completely different setting — medical imaging instead of natural images, or 3D scene understanding instead of 2D — or combine multiple teachers? These papers extend distillation to harder, more practical scenarios.

DomED solves domain generalization by redesigning how an ensemble of teachers distills into one student. Instead of just copying the teacher's predicted class, it makes the student match the teacher's uncertainty estimates (how confident the teacher is) across multiple domains. When the teacher is less certain on a domain it has never seen, the student learns to be less certain too because uncertainty is a more honest transfer of knowledge than a confident prediction, which helps it handle new domains better.

GeoPurify distills knowledge for 3D scene segmentation where the test data might come from a completely different sensor or environment than training. It uses spatial relationships in the 3D space (where objects are positioned relative to each other) to distill only the most important information from the teacher to the student. By focusing on these spatial relationships rather than raw visual details, the knowledge transfers even when the visual domain shifts, and it reaches top performance with only 1.5% of the usual training data.

Multimodal Dataset Distillation combines multiple image-text teacher models and distills them into a single smaller student. It does this in phases, first distilling one teacher then another, so the student learns the most useful parts from each. This cuts storage in half while keeping 9.5% more accuracy than training on the original data.

DomED: Redesigning Ensemble Distillation for Domain Generalization

Building lightweight models for specialized domains

A pretrained foundation model is trained on generic data and knows many things, but is too large for real applications. The challenge is taking that generalist knowledge and creating a small, specialized model that works well on one domain — medical imaging, imbalanced datasets, or audio — without the overhead of the original model.

Reconstruct Anything starts with a lightweight foundation model trained to solve a general imaging problem: turning corrupted or incomplete images into clean ones. It works across medical imaging (filling in missing tissue regions), low-photon imaging (images taken in near-darkness), and microscopy (super-resolution). The model transfers across these very different domains because the underlying task — inferring missing information — is the same. Fine-tuning on a new domain takes only a few examples because the model has already learned to reconstruct.

Active Learning with Foundation Model Guidance uses a pretrained foundation model as a teacher to guide which examples to label. On imbalanced datasets (where some classes are rare), active learning usually fails because it cannot tell what a rare class looks like. But the foundation model has seen diverse data and can guide annotation toward underrepresented classes, saving 50% of labels while keeping performance stable.

SPEAR is a unified framework for self-supervised learning on speech and audio. Instead of building separate models for different audio tasks, it distills knowledge from pretrained audio teachers into one compact model. It beats the largest teacher model on most tasks while being much smaller.

Improving distillation mechanisms and architectures

The core of knowledge distillation is deciding what to transfer from teacher to student because only some parts of what the teacher knows will fit into the student. These papers innovate on that transfer process itself: what information matters most and should be kept in focus (not everything can be copied), how to measure similarity between teacher and student (which determines what the student learns by trial and error), and what architectural changes help distillation work better (because some designs make knowledge flow more easily from teacher to student).

Cutting the Skip redesigns vision transformer architectures by removing skip connections (shortcuts in the network structure). This sounds like it would break training, but the paper shows a training technique that stabilizes it. Without shortcuts, each layer learns more detailed representations because it has to process the full signal rather than just a small correction, so the learned features capture more structure. The representations transfer better to dense prediction tasks like segmentation because they encode richer spatial information.

Differentiable JPEG-based Input Perturbation adds a twist: it intentionally corrupts the student's input in a learnable way (using JPEG compression artifacts) so the student must be more discriminative to still match the teacher's outputs. This amplifies what the student learns, improving accuracy by up to 4%, and it costs little extra computation.

Distilling Linearized Behavior distills an abstract property: when a task-adapted model behaves linearly (meaning you can mix multiple task-adapted models like ingredients in a recipe), the student inherits that property without seeing the original pretraining data. This matters because it lets you compose multiple fine-tuned models on vision and language tasks.

SiNGER distills not just outputs but clearer, more interpretable representations. Instead of forcing the student to match the teacher's internal feature vectors directly, it shapes the student's representations so different concepts are kept separate instead of mixed together. The result is student models that learn representations humans can actually understand while still reaching top downstream performance.

Cutting the Skip: Training Residual-Free Transformers
Demonstrates the first method enabling stable training of skipless vision transformers that outperform residual baselines on dense prediction tasks while learning richer hierarchical representations.
Differentiable JPEG-based Input Perturbation for Knowledge Distillation Amplification via Conditional Mutual Information Maximization
Improves student accuracy by up to 4.11% while remaining computationally lightweight and compatible with standard KD pipelines.
Distilling Linearized Behavior into Non-linear Fine-Tuning for Effective Task Arithmetic
Distilled model inherits linearization properties for task arithmetic without inference overhead, achieving effective composition across vision and language.
