ExpAlign: Expectation-Guided Vision-Language Alignment for Open-Vocabulary Grounding

Ground open-ended category names to image regions by softly aggregating token-region evidence, so the model can learn fine alignment without dense region-word labels.

Paper explainersAll themesMultimodal

Open-vocabulary grounding asks a model to localize categories and phrases it was not trained with fixed detector labels for. The difficulty is supervision: image-level text can say that an object is present without telling the model which region and which word token (one vocabulary item in the text) should match. Global sentence summaries are too coarse because they smear all words together, while large token-fusion stacks are expensive and often rely on extra labels. ExpAlign starts from a multiple-instance view of the problem: the right match may be one region among many and one word token among many. Its Expectation Alignment Head computes soft token-region evidence and pools it with expectation-style weighting, so the model learns which regions and which words should matter because the highest pooled matches keep contributing to the training signal even without a separate word-to-box annotation signal.

Zero assumption version

Why weakly supervised grounding needs finer alignment than sentence matching

Suppose a caption says 'a child holding a red umbrella near a bus stop.' A sentence-level summary can confirm that the image and caption are related, but it does not tell the model which region corresponds to 'child,' which to 'umbrella,' or which word should dominate the match for a given proposal box. That weak signal is often enough for coarse retrieval and not enough for grounding.

Explicit word-region supervision solves that ambiguity but is expensive to collect. Heavy token-level fusion modules try to infer it implicitly, yet they add cost and still need a stable learning signal. The core problem is to aggregate many possible token-region matches into one training signal without collapsing all word detail into one sentence summary and without needing full dense annotations.

The method in one sentence. Compute token-region similarities, pool them with a soft expectation rule that can select the useful matches, and then constrain those matches across scales and box overlap so alignment stays stable.

The algorithm as a flow

What it actually does

Compute token-region similarities.

Compare each text token with each candidate image region so the model has fine-grained evidence because each word can support a different box instead of being folded into one sentence-level score.

Apply expectation alignment pooling.

Softly weight the similarity table to emphasize likely token-region matches while keeping uncertainty when several matches remain plausible.

Select strong positive evidence.

Use top-scoring region-token interactions as multi-positive supervision so more than one region can support the category when the scene is ambiguous or repeated.

Enforce cross-scale consistency.

Check that the same object stays aligned across feature scales because unstable matches across resolutions indicate that the pooling signal has drifted.

Enforce overlap-aware consistency.

Constrain proposals using their overlap and spatial relations because boxes that describe the same instance should not receive incompatible alignments.

What the paper changes

What the paper changes

The paper changes the alignment head used for weakly supervised grounding. Instead of collapsing text and image into one global score, it learns a soft matching rule over tokens and regions and constrains that rule so it stays consistent.

the object it moves  =  the vision-language alignment module for grounding
The hidden quantity

The hidden quantity

measured quantity  =  expected match responsibility between each word token and each region

The hidden quantity is responsibility: for a given phrase, how much each region should count as the evidence for that phrase. In weak supervision that responsibility is not labeled. The model must infer it from the joint pattern of region scores and caption content.

Expectation pooling estimates that hidden assignment softly rather than forcing an early hard choice. That matters because an object can occupy several overlapping proposals, multiple words can refer to the same region, and some words in the sentence are irrelevant to a given box. The soft responsibilities become the internal explanation for why a region is considered a match.

Why it works

Why expectation pooling works under weak supervision

Weak supervision says that somewhere in the image there is evidence for the text, but it does not specify where. Multiple-instance learning is a natural fit because the training label applies to a bag of regions rather than to one known region. ExpAlign improves that formulation by making the bag soft at the token level. Each token can distribute its support across several plausible regions, and each region can receive support from the most relevant tokens.

This soft assignment avoids two common errors. A global sentence summary erases which word matters for which region. A hard top-one assignment commits too early and can lock onto a wrong proposal. Expectation pooling keeps several candidates active while the model is still uncertain. That yields a more informative learning signal from weak labels because training updates depend on the full table of plausible matches instead of on one winner only.

The consistency constraints matter because soft assignments can drift. Multi-scale consistency checks whether the same object keeps similar alignments across feature resolutions. Overlap-aware consistency checks whether overlapping boxes receive compatible support. Those constraints stabilize the hidden assignments, so the alignment head learns object-level grounding rather than noisy token-region coincidences.

Math after the picture

Pool region evidence with normalized token-region weights

First in words:

A compact view is to turn token-region similarities into normalized responsibilities and then sum the similarities under those responsibilities.

Then the compact form:

score(r, text) = sum_t alpha_(r,t) * s_(r,t)

Every symbol:

rone candidate image region
tone text token
s_(r,t)the raw similarity between region r and token t
alpha_(r,t)the normalized responsibility weight for token t on region r
score(r, text)the pooled alignment score used for grounding
A tiny worked example
Suppose a region is compared with the tokens 'red' and 'umbrella.'
Their raw similarities are 0.4 and 0.9.
After normalization, the responsibility weights are 0.3 for 'red' and 0.7 for 'umbrella.'
The pooled score becomes 0.3 times 0.4 plus 0.7 times 0.9, which equals 0.75.
That score is high because the region matches the object word strongly and still gets some support from the attribute word.

The paper adds additional terms for multi-positive and consistency training, but the heart of the method is this soft responsibility pooling over token-region evidence.

What can go wrong

What can go wrong

Soft pooling can stay too diffuse. If many regions receive similar responsibility, the alignment score can become blurry and the detector may fail to commit to the right box.
Consistency terms can reinforce an early mistake. If the initial high-scoring proposal is wrong, multi-scale and overlap consistency can spread that mistake across related boxes and scales.
Long phrases with relational words remain hard. Words such as 'behind' or 'next to' depend on more than one region. A token-region table centered on one box can still struggle when the phrase meaning is mostly relational.
Done right. The method is strongest when proposal quality is decent, the soft weights are sharp enough to isolate objects, and the consistency losses are tuned so they stabilize rather than spread noise.
What a runnable demo should prove

What a runnable demo should prove

Build a weakly supervised grounding setup with captions and region proposals but no word-to-box labels. Compute token-region similarities, pool them with expectation weights, and compare the result against a sentence-level baseline that uses one global text summary per image.

The demo should include categories and phrases that were not part of a fixed detector label set, plus repeated objects and long-tail nouns. It should visualize the token responsibilities on proposals so it is clear whether the method is isolating the right region-word matches rather than merely scoring whole-image relevance.

responsibility_concentration = max_t alpha_(r,t)

A convincing result is stronger grounding on rare categories with concentrated token responsibilities, because that shows the model extracted fine alignment from weak supervision rather than from dense manual labels.
