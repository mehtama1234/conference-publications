Safe Continuous-Time Multi-Agent Control via Epigraph Form

Instead of checking safety rules at each step, embed them into a smooth mathematical shape that deep learning can fit.

Paper explainersAll themesReinforcement Learning

Multi-agent teams (robots, drones, traders) live in time that flows continuously, not in ticks. But teaching them to obey safety rules like collision avoidance in this smooth world is hard: safety constraints create sharp corners that deep learning struggles with. This paper straightens those corners into smooth slopes using an epigraph (a shape from convex math), then teaches the agents using a neural network that speaks the language of continuous math.

Zero assumption version

Why discrete time breaks with safety rules

Most robot learning treats time as a checklist: decide, then wait 10 milliseconds, then decide again. This tick-by-tick view works when the task is just 'accumulate reward', but breaks when rules like 'never touch the wall' are in play.

A beginner's first try: handle the constraint by adding a penalty to the score — if you hit the wall, subtract 100 points. But this creates a sharp corner in the score curve: on one side of the wall the score drops sharply; on the other it is flat. Deep learning networks need smooth, continuous curves to learn from, so a sharp corner confuses the learning process. The network tries to fit a smooth curve through the corner and either overshoots (allows collisions) or undershoots (forbids safe moves), because once a curve crosses the corner in data, the network must guess which smooth path fits best — there is no ground truth. The training is wobbly and never stable.

In one sentence. The paper wraps safety rules into a smooth shape using an epigraph (turning a corner into a slope), so deep learning can learn a stable, constraint-respecting controller in continuous time.

The algorithm as a flow

What it actually does

Reframe the problem

Turn discrete-time learning into a continuous flow, keeping safety rules as inequalities.

Smooth the constraint

Use the epigraph trick: rewrite 'cost ≤ z' and 'return ≥ z' as a single smooth surface.

Fit a neural network to the surface

Train two networks (one for cost, one for return) to match the epigraph shape using PDE residuals.

Find the optimal helper z

For each state, solve for the z value that satisfies both constraints at once.

Train the policy without z

Use the learned value surface to nudge the agent's actions toward the goal while respecting safety.

What the paper changes

What the paper moves

The paper does not change the agents or the physics. It changes how the learning rules are written: instead of checking safety at each snapshot in time, it wraps the safety rules into a single smooth mathematical object (the epigraph surface) that the neural network learns all at once.

The hidden quantity

The auxiliary variable z

measured quantity  =  The optimal constraint level z*

The paper introduces a hidden quantity: a free variable z that sits between the cost constraint and the return goal. For each state, there is one best value of z that balances both — this is z*. It is not part of the policy (the agent does not see it), but it shapes the learning surface the network fits.

The paper estimates z* by solving an optimization problem at each rollout: find the smallest z such that the cost is not violated AND the return goal fits below z. This z* anchors the neural network training, ensuring that the learned value surface respects both requirements simultaneously.

Why it works

Why the epigraph trick works

Discontinuities happen when one rule dominates others. A sharp penalty for hitting the wall means the score has a corner: just outside the wall the penalty is zero, just inside it jumps to −100. A neural network trained on a corner struggles because it cannot follow the curve smoothly.

The epigraph reformulation flips the view. Instead of asking 'what is the score?', it asks 'what is the smallest z such that cost ≤ z AND return ≥ z?' This z-based view turns two competing goals (keep cost low, keep return high) into one smooth surface. The paper trains two networks: one learns when cost is violated (a confidence curve), the other learns the return (another confidence curve). The networks predict continuous, smooth surfaces. Then the learning algorithm finds z* — the level where these two surfaces meet. Because the networks output smooth curves, their meeting point moves smoothly too, with no kinks.

This smooth learning surface is fed into a standard actor-critic loop (the agents learn a policy by following the direction of steepest improvement). Because the surface has no corners, these improvement directions point consistently and honestly, training is stable, and the final policy respects both the task goal and the safety rules.

Math after the picture

The epigraph equation

First in words:

constrained value equals the smallest z such that both the maximum of constraint-violation and return-minus-z are non-positive

Then the compact form:

z* = min { z in R | max{V_cons(x), V_ret(x) - z} <= 0 }

Every symbol:

z*the optimal auxiliary variable: the smallest budget that fits both goals
V_cons(x)the constraint network's prediction of how much cost is violated at state x
V_ret(x)the return network's prediction of cumulative future reward at state x
max{...}take the worse of the two (constraint or return-gap); it must be non-positive
A tiny worked example
State: two agents 2 units apart, wall 1 unit away. Safety says cost ≤ 5.
V_cons(x) = 7 (cost is violated by 2 units). V_ret(x) = 20 (reward expectancy).
Try z = 15: max{7, 20 - 15} = max{7, 5} = 7 > 0. Does not work; constraint still violated.
Try z = 25: max{7, 20 - 25} = max{7, -5} = 7 > 0. Still does not work; cost pushes it over.
Try z = 30: max{7, 20 - 30} = max{7, -10} = 7 > 0. Still violated.
Reality: if V_cons(x) stays 7, z must be at least 7 to even satisfy max <= 0, but that eats into return. The agents learn to move to safer states where V_cons shrinks, lowering the required z, freeing up budget for return.

The paper's key move is that z* couples the two networks: the policy is forced to find actions that lower the constraint network's prediction, not just chase reward.

What can go wrong

What can go wrong

Constraint boundary misalignment. If z* is clipped outside its natural range (too tightly bounded), the network cannot find states that actually satisfy the constraint. The agents learn to violate safety rules silently.
Cost network fails to predict collision risk. The cost network is just a neural network; if the training data rarely shows collisions, it will not learn to predict them. The z* value stays low and constraints are never checked.
Return network drifts away from reality. If the return network overfits to noise in the data, it predicts inflated reward values. z* then becomes unreliably high, allowing constraint violations.
Done right. Both networks are trained on balanced batches that include rare constraint-violation events. The z value is free to move, and the policy is re-evaluated on held-out safe scenarios.
What a runnable demo should prove

What a runnable demo should prove

Build a 4-agent formation task on a continuous time horizon. Agents start in a line 1 meter apart, with a wall 2 meters ahead. The goal is to reach a target 5 meters away while never touching the wall (cost penalty is zero if no collision, cost penalty is one if any agent is within 0.5 meters of the wall). Train the epigraph-based controller. Train a naive baseline by adding a fixed penalty for constraint violations. Run both for 500 episodes and record: (1) how often each violates the wall constraint, (2) the final distance to the target, (3) the smoothness of the value function over state samples.

constraint_violations = count(min_distance < 0.5m) / total_steps; reward_earned = final_distance_to_target; smoothness = variance of value gradient over 100 random state pairs

The epigraph method must have near-zero constraint violations and smooth learning curves because the smooth epigraph surface provides consistent directions of improvement without corners, whereas the baseline's sharp penalty creates conflicting signals that destabilize training.
