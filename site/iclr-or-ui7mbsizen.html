Dyslexify: Surgically Removing Typographic Attention

CLIP misclassifies images with injected text because a few attention heads specialize in extracting that text, and you can delete those heads to defend the model without retraining.

Paper explainersAll themesInterpretability

A CLIP model reads images by passing information through many layers. At each layer, there are parts that focus on different regions of the image (we call these attention heads — they are simple look-here / look-there decisions). When an image contains overlaid text, a small cluster of these heads at the later layers wake up and extract that text, passing it along to the decision center. This paper finds these typographic heads through careful measurement, then surgically deletes them. The result is a model that still sees normal pictures clearly but ignores injected text — all without retraining.

Zero assumption version

CLIP falls for text overlaid on images

CLIP is a model that jointly understands images and text by learning to link pictures to descriptions. It has been adopted for safety-critical tasks like medical diagnosis and content filtering.

But CLIP has a hidden weakness: if you draw or paste text onto an image, CLIP notices the text and often forgets what the image actually depicts. A CLIP trained to recognize healthy skin might see the word 'cancer' painted on a photo and classify it as cancer — purely from the text, not the image. This is called a typographic attack.

A beginner might think: just fine-tune the model on examples with text on them. But fine-tuning is expensive, slow, and often damages the model's ability to see normal pictures correctly. You need a way to stop the text extraction without breaking the underlying vision.

The paper's move in one sentence. Find the specific attention heads that extract text from images, then delete only those heads and leave everything else untouched.

The algorithm as a flow

What it actually does

Step 1: Measure which heads care about text

For each attention head, check its spatial attention pattern on images with overlaid text.

Step 2: Assign each head a typographic score

Score reflects whether the head consistently focuses on text locations, not general image regions.

Step 3: Select the smallest set of heads to delete

Greedily pick heads that defend against text attacks without hurting normal image accuracy.

Step 4: Ablate (permanently remove) those heads

Modify the model's forward pass to skip the selected heads' computation.

Step 5: Verify the result

Test that the dyslexified model rejects text attacks while still recognizing normal images.

What the paper changes

The single thing being changed

The paper changes the attention heads in the vision encoder. Specifically, it identifies which heads carry typographic information (which layers and which head indices) and permanently removes their computation from the forward pass.

the object it moves  =  attention heads
The hidden quantity

Typographic attention bias

measured quantity  =  typographic attention score

This is a number assigned to each attention head that measures how much that head focuses on text-containing regions when the image has overlaid text. It is not about whether the head 'understands' text semantically; it is purely about where the head's attention looks spatially.

The paper computes this by showing each attention head a dataset of images with text pasted on them, then examining the focus pattern. If the head consistently aims its focus at the text region (high spatial concentration on text pixels), it gets a high typographic attention score. If it spreads its focus evenly or ignores the text region, it scores low.

Why it works

Why removing these heads eliminates text attacks

CLIP's vision encoder is a stack of layers. Each layer has two kinds of sub-layers: attention heads (which look at different parts of the image and focus information) and feed-forward layers (which process that focused information). In the early layers, attention heads are generalists — they look at broad image features. But in the later half of the model, a handful of heads evolve to be specialists in extracting text.

When a typographic attack (text overlaid on an image) comes in, these specialist heads spring into action, gather the text information, and pass it forward as the 'semantic signal' to the decision layer. The rest of the model then acts on that text signal instead of the image signal.

Dyslexify identifies these specialist heads (via the typographic attention score), then cuts them out of the model entirely. When text is present, those heads no longer fire. The information flow is broken at the source. Normal images still work because the other heads and layers continue to process visual features; the text-specialist heads were redundant for normal vision. The early, generalist heads and the later non-specialist heads carry enough image information that removing a few specialist heads does not blind the model to normal pictures.

Math after the picture

How the typographic attention score works

First in words:

For each head, compute an incremental accuracy gain on text-attack images minus the accuracy loss on normal images.

Then the compact form:

typographic_score = gain_on_typo_dataset - alpha * loss_on_normal_dataset

Every symbol:

gain_on_typo_datasetaccuracy improvement when you add this head to the circuit, on images with text
loss_on_normal_datasetaccuracy drop when you add this head to the circuit, on normal images
alphaa penalty weight to balance text robustness against normal vision
A tiny worked example
Head A on normal images: model gets 95% correct both before and after including this head. Loss = 0%.
Head A on text-attack images: model gets 40% correct without the head, 65% with the head. Gain = 25%.
Typographic score for Head A = 25% - 0.5 * 0% = 25 (high score, strong candidate for text extraction).
Head B on normal images: model gets 95% correct without, 92% correct with the head. Loss = 3%.
Head B on text-attack images: model gets 40% correct without, 42% correct with. Gain = 2%.
Typographic score for Head B = 2% - 0.5 * 3% = 0.5 (low score, not a text specialist).
Dyslexify selects Head A for ablation because it has high text gain and near-zero normal loss.

Heads with positive typographic scores specialized on text; heads with negative scores either hurt defense against text or damage normal vision, so they are left alone.

What can go wrong

What can go wrong

Over-ablating. If you delete too many heads or the wrong heads, the model loses important vision capabilities. The paper guards this by checking that normal image accuracy stays within 1 point of the baseline.
Adversarial adaptation. An attacker might study how Dyslexify works and craft adversarial text that does not trigger the typographic heads, or manually hide text in unexpected image regions. The current approach assumes the attack remains standard typographic injection.
Model-specific circuits. The typographic heads are specific to a given vision encoder architecture and scale. A different model (e.g., ViT-L instead of ViT-B) will have different circuits, so you must re-identify and re-ablate for each new model.
Done right: train-free and safe. When applied carefully to the correct model, Dyslexify requires no finetuning, no retraining, and no learning rate tuning — it is a one-time surgical intervention.
