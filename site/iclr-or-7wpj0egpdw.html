AMiD: Knowledge Distillation for LLMs with alpha-mixture Assistant Distribution

When a small language model learns from a large one, the teacher's full next-word chance table can be too sharp and unstable. This paper mixes teacher and student views into an assistant target that is easier for the student to learn from.

Paper explainersAll themesOther

Knowledge distillation trains a smaller model to imitate a larger teacher. For language models, the output space is huge, so most next-word chances are tiny. That creates unstable training because the student is pushed to match a very spiky target it may not be able to represent. Earlier work softened the target with hand-designed assistant targets, but each method picked one fixed recipe. This paper turns that idea into a family. It introduces an alpha-mixture assistant target that smoothly blends teacher and student information, then studies which discrepancy measure should compare the student to that assistant target.

Zero assumption version

Why direct imitation of a large teacher is hard

A teacher language model assigns a chance to every possible next word. The correct word may get a large value while many other words get values close to zero. A small student cannot always match that fine-grained table.

When training compares the student directly against the teacher, the near-zero values can create unstable updates because tiny changes in very small chances can still produce large penalties. The student then spends effort on details it cannot represent well.

Several earlier methods inserted an assistant target between teacher and student, but each used a particular fixed construction. That left no unified way to choose how much the assistant target should lean toward the teacher or toward the student.

Core move. Instead of forcing the student to copy the teacher's sharp next-word table directly, build an intermediate target whose sharpness can be tuned to the student's capacity.

The algorithm as a flow

What it actually does

Run teacher and student on the same prefix.

Both models produce a next-word chance table for the same partial text.

Construct an assistant target.

Use the alpha setting to choose how much the target resembles the teacher and how much it reflects the student's own table.

Choose a discrepancy suited to that target.

The paper studies a family of comparison rules and connects them to the assistant construction so training pressure matches the chosen target.

Train the student against the assistant target.

The student receives a smoother and more attainable signal, because the target is no longer fixed at the teacher's sharpest form.

Tune alpha for the student size.

Smaller students may need more smoothing because they cannot fit a very sharp target, while stronger students can lean closer to the teacher because they can absorb finer distinctions.

What the paper changes

What the paper changes

The paper changes the target used in language-model distillation. Instead of one fixed assistant target, it defines a continuous family controlled by alpha and pairs it with a matching family of discrepancy measures.

the object it moves  =  the distillation target between teacher and student
The hidden quantity

The hidden quantity

measured quantity  =  how sharp the training target is relative to what the student can fit

The hidden quantity is target sharpness mismatch. If the target is much sharper than what the student can reproduce, training becomes noisy and wasteful because the student keeps chasing details at the tiny end of the chance table.

The assistant target reduces that mismatch. By tuning alpha, the target can stay informative while avoiding penalties dominated by near-zero chances.

Why it works

Why an assistant target steadies distillation

Direct distillation treats every entry in the teacher's next-word table as a target to be copied. For large language models that table is extremely long, and most entries are very small. A small student cannot fit all of those details. That mismatch creates unstable pressure because the loss still reacts to countless tiny entries.

The assistant target fixes that by reshaping the target before comparison. Alpha controls how far the target moves away from the raw teacher table. When alpha is chosen well, the student still learns the teacher's ranking and uncertainty pattern where it matters, but it is not punished as strongly for tiny differences it cannot represent. That is why the method can improve both final accuracy and training stability.

Math after the picture

Assistant target interpolation

First in words:

The method forms an assistant target by mixing teacher and student next-word chance tables with a control value alpha. Training then minimizes a comparison loss between the student and that assistant target.

Then the compact form:

assistant_target = mix_alpha(teacher_table, student_table), and distillation_loss compares student_table to assistant_target

Every symbol:

teacher_tablethe teacher's next-word chance values
student_tablethe student's next-word chance values
alphathe setting that controls how strongly the assistant target leans toward teacher or student
assistant_targetthe blended target used for distillation
distillation_lossthe comparison loss used to train the student
A tiny worked example
Suppose the teacher gives top-word chances of 0.80, 0.10, 0.05, and 0.05.
Suppose the student gives 0.45, 0.25, 0.15, and 0.15.
A direct target forces the student toward 0.80 on the top word immediately.
An assistant target with a middle alpha might produce something closer to 0.62, 0.17, 0.10, and 0.10.
That target still points the student toward the teacher, but it does so with a shape the student can track more smoothly.

The exact formula depends on the chosen assistant family and discrepancy rule, but the basic purpose is constant: tune the target shape to the student's capacity.

What can go wrong

What can go wrong

Alpha can be set too low. If the assistant target leans too far toward the student, distillation becomes weak because the target no longer carries enough information from the teacher.
Alpha can be set too high. If the assistant target stays too close to the teacher, the original sharpness mismatch returns because the student again faces a target it cannot fit well.
The chosen comparison rule may not match the target family. A poorly paired loss can waste the smoothing benefit because it still magnifies the wrong parts of the chance table.
Done right. The method works when alpha and the comparison rule are tuned together, because then the assistant target stays informative while matching the student's capacity.
What a runnable demo should prove

What a runnable demo should prove

Take a teacher and several smaller students on a next-word prediction task. Compare direct distillation against several fixed assistant targets and against AMiD with alpha sweeps. Track both validation loss and a simple training-stability score such as the variance of the batch loss over time.

The demo should show that the best alpha shifts with student size, because the right amount of smoothing depends on how much target sharpness the student can absorb.

stability_score = variance_of_batch_loss_over_training

The decisive result is not just lower loss, but lower loss together with steadier training, because the paper's claim is about matching the target to the student's capacity.
