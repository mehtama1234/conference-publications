Uni-X: Mitigating Modality Conflict with a Two-End-Separated Architecture for Unified Multimodal Models

Uni-X keeps image-specific and text-specific processing at the input and output ends of the network, while sharing only the middle layers where the two modalities have already been converted into more compatible semantic representations.

Paper explainersAll themesMultimodal

A unified multimodal model built on one shared next-step generator and one shared layer stack that mixes information across positions is attractive because it can handle text understanding, image understanding, and image generation in one architecture. The problem is that raw images and raw text produce very different update signals during training. If all layers are shared, those signals can pull the same learned numbers in incompatible directions, especially near the early layers that process low-level input statistics and near the late layers that produce modality-specific outputs. Uni-X isolates those conflict-heavy ends and shares only the middle region, where the representations are more abstract and more semantically aligned.

Zero assumption version

Fully shared multimodal layer stacks are asked to solve incompatible low-level jobs

A single shared layer stack is often trained on both images and text. That design asks the same early layers to process image patch statistics and text text-piece statistics, even though those inputs have different local structure, different frequency patterns, and different positional behavior. It also asks the same late layers to produce outputs for both language generation and image generation, even though those output probability patterns are organized differently.

When the same learned numbers receive updates from both modalities, the updates can point in different directions. This is a gradient conflict, meaning one training batch pushes a learned number one way while another batch pushes it another way. If that conflict is strong, optimization wastes steps cancelling one modality with the other instead of improving both. The paper finds that the conflict is strongest near the shallow and deep ends of the network, and weaker in the middle layers.

The paper's move. Uni-X keeps separate image and text layers at both ends, shares only the middle, and thereby reduces cross-modality conflict where it is strongest.

What the paper changes

What the paper changes

Uni-X changes where sharing of learned numbers happens inside a unified multimodal model. It does not reject sharing altogether. Instead, it moves sharing away from the ends of the stack and concentrates it in the middle layers, where image and text processing are more semantically compatible.

the object it moves  =  the placement of shared learned numbers across the layer stack
The hidden quantity

The hidden quantity: cross-modality gradient conflict by layer

measured quantity  =  layerwise gradient conflict

The paper's diagnosis depends on measuring how strongly image and text updates disagree inside each layer. A gradient is the direction that shows how changing one learned number would change the training loss. If image and text gradients point in similar directions, sharing that layer is reasonable. If they point in opposite directions, sharing forces the optimizer to trade one modality against the other.

Uni-X uses this layerwise pattern as an architectural clue. Strong conflict near the front means the modalities should have separate entry processing. Strong conflict near the back means they should also have separate output decoding. Milder conflict in the middle suggests that those layers are where shared semantic fusion can happen without large mutual cancellation.

Why it works

Why sharing only the middle layers helps

Early layers deal with modality-specific statistical structure. For text, they organize discrete symbol sequences and local lexical context. For images, they organize continuous spatial patterns over patches or compressed image codes. Forcing one learned number set to serve both jobs wastes capacity because those jobs require different filters and different output statistics. Separate front ends let each modality create a cleaner intermediate representation before any sharing begins.

Late layers face a similar issue from the opposite direction. To generate text, the model must map hidden states into probabilities over vocabulary items. To generate images, it must map hidden states into image units or compressed image codes with another organization. Sharing those final transformations again creates conflict because the decoding targets differ. Separate back ends let each modality finish its own output mapping without distorting the other modality's decoder.

The middle layers are the most natural place to share because they operate after low-level modality idiosyncrasies have been reduced and before modality-specific decoding has started. At that point the network can focus on semantic content such as object identity, relation structure, and textual meaning. Sharing there allows cross-modal transfer while avoiding the strongest optimization conflict at both ends, because the representations have become more alike but the modality-specific output mapping has not yet begun.

Math after the picture

The sharing rule

First in words:

Split the full depth into three regions: image-specific front layers, shared middle layers, and modality-specific back layers.

Then the compact form:

full_stack = front_image_or_text + shared_middle + back_image_or_text

Every symbol:

full_stackthe complete layer sequence of the unified model
front_image_or_textthe early modality-specific layers for image inputs or text inputs
shared_middlethe central layers shared across modalities
back_image_or_textthe late modality-specific layers for image outputs or text outputs
A tiny worked example
Suppose a 12-layer model is split as 3 front layers, 6 shared middle layers, and 3 back layers.
An image input uses image-specific layers 1 to 3, then shared layers 4 to 9, then image-specific output layers 10 to 12.
A text input uses text-specific layers 1 to 3, then the same shared layers 4 to 9, then text-specific output layers 10 to 12.
The two modalities share the semantic middle while avoiding full sharing at the conflict-heavy ends.

The exact split can vary, but the principle is to align sharing with low-conflict layers rather than with the full stack.

What can go wrong

What can go wrong

The middle may still carry residual conflict. If the shared region starts too early or ends too late, image and text updates can still disagree enough to slow training, because the semantic alignment may not have happened yet.
Too little sharing wastes cross-modal transfer. If the separated ends are too large, the model becomes closer to two loosely connected networks and gives up the main benefit of a unified multimodal model.
The split point may depend on scale. A layer boundary that works at one model size may not be best at another size, because the depth at which semantic alignment emerges can shift with capacity and training data.
Done right. The architecture works best when the shared region begins after modality-specific low-level processing and ends before modality-specific decoding becomes dominant.
What a runnable demo should prove

What a runnable demo should prove

Build a small unified image-text model with three variants: fully shared layers, no sharing, and a two-end-separated variant with a shared middle. Train all three on a paired image-text task that includes both understanding and generation.

During training, log disagreement between image and text updates to learned numbers by layer, along with final task scores. The important evidence is that the fully shared model shows larger disagreement at the ends, the two-end-separated model lowers that disagreement, and the lowered disagreement coincides with stronger joint performance because the shared layers are now focused on semantic fusion instead of low-level conflict resolution.

layer_conflict = average disagreement between image-update direction and text-update direction for a given layer

The core claim is established if separating the high-conflict ends improves joint training while preserving a useful shared semantic middle, because the shared layers then handle more compatible semantic updates instead of incompatible low-level or decoding updates.
