On Group Relative Policy Optimization Collapse in Agent Search: The Lazy Likelihood-Displacement

This paper explains why GRPO training for search agents can quietly reduce confidence in all answers and then crash, and it adds a selective penalty that prevents that drift.

Paper explainersAll themesAgents & Tool Use

Tool-using search agents are often trained with reinforcement learning so that they learn multi-step question answering with retrieval and external actions. Group Relative Policy Optimization is attractive in this setting because it is simple and converges quickly in many cases. Yet practitioners observe a recurring failure: training first looks stable, then answer confidence falls on both correct and incorrect responses, update sizes grow, and learning collapses. This paper identifies that failure pattern as Lazy Likelihood-Displacement. The central observation is that the model can lower the likelihood of nearly everything instead of learning to separate good and bad behavior. Once confidence drops broadly, the optimization signal becomes unstable. The proposed fix, LLDS, penalizes only the harmful drops and only on the responsible response positions so that useful learning can continue without broad suppression.

Why GRPO training can collapse in search agents

A search agent should gradually assign more probability to answer paths that use tools well and reach correct conclusions. In practice, GRPO training can do something weaker and more dangerous. Instead of raising confidence on good answers and lowering it on bad ones, the model starts lowering confidence on both. The policy becomes uncertain across the board.

That broad confidence drop is harmful because low-confidence outputs produce unstable updates. Once the system enters that regime, later training steps can amplify the problem instead of correcting it. The paper's first contribution is to show this process clearly and to treat it as a distinct failure mode rather than generic instability.

The move. Detect and resist broad harmful drops in response likelihood, and add a selective penalty only at the response positions causing the drop so that useful policy improvement can continue without collapse.

The algorithm as a flow

What it actually does

Track response likelihood during training.

Measure whether the policy is assigning more or less probability to its sampled responses so that broad harmful decline becomes visible early.

Identify Lazy Likelihood-Displacement.

Mark the regime where both good and bad responses lose likelihood because that is the signature of the collapse mechanism described in the paper.

Activate LLDS only on harmful decreases.

Apply the extra penalty only when a response likelihood decreases, because the goal is to stop harmful decay without blocking healthy policy change.

Target only the responsible response positions.

Apply the extra penalty to the specific positions that caused the drop so that the intervention stays focused instead of flattening the whole response.

Continue RL training with stabilized updates.

Train the search agent as usual, but now broad confidence decay is restrained so later updates remain usable.

What the paper changes

What the paper changes

The paper changes GRPO training from a passively monitored process into one that explicitly guards against broad harmful likelihood decay during search-agent reinforcement learning.

The hidden quantity

The hidden quantity: confidence separation

measured quantity  =  the gap between confidence on useful responses and confidence on poor responses

The key quantity is confidence separation. Healthy learning should increase the gap between strong and weak behavior. Collapse begins when that gap fails to grow and overall confidence starts shrinking instead.

Lazy Likelihood-Displacement is dangerous because it hides inside aggregate reward improvement for a while. A run can appear acceptable even as the model reduces confidence broadly. By measuring likelihood movement directly, the paper reveals the early warning signal before complete collapse.

Why it works

Why it works

Collapse starts because the optimization process can satisfy local pressure by shrinking response likelihood broadly rather than by making fine-grained distinctions between strong and weak behaviors. That broad shrinkage lowers confidence, which then makes later updates more volatile.

LLDS helps because it does not resist all change. It only responds when likelihood moves in the harmful direction. That matters because some responses should become less likely during learning. The paper's intervention targets only the decreases that contribute to the broad unhealthy drift.

The position-level focus matters because different parts of a response do different work. Penalizing only the positions responsible for the damaging drop preserves more useful learning signal than a blanket rule would. That is why the method can stabilize training without simply freezing the policy.

Math after the picture

The selective preservation rule

First in words:

Add an extra penalty only when the current policy lowers the likelihood of a sampled response position compared with the earlier policy.

Then the compact form:

LLDS = sum_t max(0, log p_old(y_t) - log p_new(y_t))

Every symbol:

ta response position
y_tthe sampled response content at position t
p_old(y_t)the earlier policy's probability for that response position
p_new(y_t)the current policy's probability for that response position
max(0, ...)keep only harmful decreases and ignore increases or unchanged values
A tiny worked example
Suppose one response position had old log probability -1.0 and new log probability -1.6.
The drop is 0.6, so this position contributes 0.6 to LLDS because the new policy became less confident.
Suppose another position had old log probability -1.4 and new log probability -1.1.
That is an increase, so its LLDS contribution is 0 because the rule only penalizes harmful decreases.
The training step is therefore nudged away from broad confidence loss without blocking positions that improved.

The rule is selective by design because the paper wants to stop unhealthy broad decay, not stop learning altogether.

What can go wrong

What can go wrong

The warning signal can be missed. If likelihood movement is not monitored carefully, the unhealthy decay may already be advanced before intervention begins because reward alone can hide the failure pattern.
Too much preservation can slow learning. If the extra penalty is set too strongly, the policy may resist needed change because some bad responses really should become less likely.
Tool-use errors can still limit final quality. Stable RL does not guarantee strong search behavior by itself, so weak retrieval or poor search actions can still cap performance because the policy is only as good as the behavior it is learning.
Done right. The method works when harmful broad confidence decay is detected early and the preservation rule is applied selectively, because that keeps updates stable while still allowing policy improvement.
