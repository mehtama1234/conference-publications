Self-Organization in Multi-Agent Systems

Instead of teaching agents a fixed graph or hiring a judge, let agents build their own communication links on the spot by scoring each other's answers and routing information from the best responders.

Paper explainersAll themesOther

When you have multiple AI models answering a hard question, you face a puzzle: how should they share and refine their answers without a teacher or a preset communication plan? Most methods use fixed communication patterns or hire another model to judge which answer is best. This paper shows a simpler way: agents score each other's answers right there in the conversation, then form a custom communication graph so information flows from the strongest responders to others. No training needed, no external judge, no pretrained patterns.

Zero assumption version

Multi-agent systems without a guide

When you run multiple AI models together to solve a hard problem (like a reasoning puzzle or math question), each model can produce a different answer. A naive approach is to ask all models to contribute equally or to use a fixed communication pattern that never changes. The problem: some models' answers are better than others, but the system has no way to learn which ones or to steer information toward the best ones because it cannot see what each model actually produced in this round. You can try hiring another model to judge quality, but that adds a new moving part that can be wrong. You can try training which edges should connect models, but that requires supervision and slows things down.

The core stuck point: static graphs miss the fact that the best responder changes from problem to problem, and training a separate judge adds complexity that drowns out the benefit of having multiple models in the first place.

In one sentence. Agents generate answers, score each other in real time using a fairness principle, and build a custom communication graph to amplify the best responses.

What the paper changes

What the paper changes

The paper replaces the fixed or learned communication structure with a fresh one built from each problem's actual answers. Instead of a static template graph or edge weights trained by reinforcement learning, agents dynamically form a directed acyclic graph (a one-way flow structure with no loops) based on how well their current responses align.

The hidden quantity

The hidden quantity: Shapley contribution score

measured quantity  =  Shapley-value-inspired contribution score

This is a fairness principle borrowed from cooperative game theory. The idea: an agent's contribution is measured by how much its answer boosts the alignment of the group, because when an agent's response pulls the group's average in a good direction, it has added information. Imagine a coalition of agents; the more they agree on a good answer, the higher the utility. Each agent's Shapley score measures its role in that agreement. The paper uses an efficient approximation rather than the full Shapley calculation, making it lightweight.

The paper estimates this score by ranking agents by how closely their response aligns with the group average response embedding (a numerical fingerprint of each answer). High alignment means high contribution; low alignment means the agent is adding noise.

Plain reading. Each agent's score tells you how much that answer pulls the group's view toward a good solution. If two agents agree on a strong answer, both get high scores because they reinforce each other. If one agent disagrees with everyone, its score is low.
Paper reading. The Shapley value decomposes the coalition's utility among its members. The paper approximates it by measuring how close each agent's response embedding sits to the group's average embedding, ensuring ranking stability even under noisy responses.
Why it works

Why it works: amplifying correctness through alignment

Here is the core: if multiple agents independently solve the problem and happen to find the correct answer, their responses will be very similar to each other (high cosine similarity). This high similarity pushes them to the top of the contribution ranking. The paper then routes information from these high-scoring agents down to the weaker ones, so the weaker agents can see what consensus looks like and adjust their answers. The mechanism is not voting or averaging; it is a cascading influence structure.

Why is this better than a fixed graph? Because the best responder changes with the problem. A math question might need Model A; a logic puzzle might need Model B. By measuring actual responses, the system automatically identifies who to trust on this problem, not on average.

The mathematics guarantee this: if at least two agents produce the correct answer, it becomes strictly more likely to receive high contribution scores than any incorrect answer. This is because the correct answer's embedding will be closer to the group centroid than wrong answers (assuming independence). The framework then amplifies this by making that high-scoring response the root of the communication graph.

The contribution score formula

First in words:

contribution_score_n = how_similar_agent_n_is_to_the_average_of_all_agents

Then the compact form:

phi_n = Shapley_approximation(n) = cosine_similarity(embedding(R_n), average(all_embeddings))

Every symbol:

R_nthe response from agent n
embedding(R_n)a numerical fingerprint of the response (how the words cluster in meaning)
average(all_embeddings)the center point of all responses in meaning-space
cosine_similaritya measure of overlap: 1.0 means perfect agreement, 0.0 means unrelated
A tiny worked example
Agent A produces: 'The answer is 42.' Embedding: [0.8, 0.3, 0.9, 0.2].
Agent B produces: 'The result is 42.' Embedding: [0.79, 0.31, 0.88, 0.21].
Agent C produces: 'I think it is 99.' Embedding: [0.2, 0.8, 0.1, 0.9].
Average embedding: [0.59, 0.47, 0.63, 0.44].
Similarity of A to average: 0.8*0.59 + 0.3*0.47 + 0.9*0.63 + 0.2*0.44 = 0.944. (high)
Similarity of B to average: 0.79*0.59 + 0.31*0.47 + 0.88*0.63 + 0.21*0.44 = 0.934. (high)
Similarity of C to average: 0.2*0.59 + 0.8*0.47 + 0.1*0.63 + 0.9*0.44 = 0.744. (low)
Agents A and B are consensus-builders; Agent C is an outlier. A and B set the root.

Agents whose answers align with the group's meaning get high scores and sit higher in the communication graph, so their influence reaches others first.

What can go wrong

What can go wrong

Unreliable agents produce hallucinations that break agreement. If agents are unreliable and produce different made-up facts, they may have low group alignment even if they are all wrong. The system can then pick the wrong consensus. This is why the paper emphasizes it works best with models that are at least somewhat reliable.
Single correct answer among many wrong ones. If only one agent gets the right answer and the rest are wrong, the correct answer may not align with the group average. The contribution score is lower, so it does not reach the root. The framework relies on at least two agents finding the correct answer to amplify it.
Long-horizon tasks fail silently. For tasks that need many reasoning steps, an agent may start correctly but drift into hallucination mid-reasoning. Scoring by final embedding does not catch mid-task failure, so a partially correct answer might score high by accident.
Multiple correct answers reinforce each other. When a task has true multiple valid solutions (like interpretive questions), SELFORG correctly identifies and amplifies each one. The communication graph adapts to the problem.
What a runnable demo should prove

What a runnable demo should prove

Build a dataset of hard questions (math, reasoning, coding) where weak language models (like Qwen-7B or smaller) would normally fail. Run three weak models in parallel and collect their independent answers. Compute Shapley scores for each using cosine similarity of embeddings. Form the communication graph. Run a refinement round where lower-ranked agents read higher-ranked responses and generate a new answer. Measure final accuracy on the benchmark.

accuracy_improvement = accuracy_with_selforg - accuracy_without_selforg

The demo must show that weak models improve by 10-20 points in accuracy when routed toward high-scoring peers because they see a concrete high-quality example to align with, and that the improvement is largest exactly when weak model accuracy is lowest (where other methods fail because they cannot identify the good answer).
