IBMA: Information Bottleneck-Based Multimodal Alignment

Apply the information bottleneck to both fused and modality-specific features so each modality keeps task-relevant content, drops private noise, and aligns with the complementary modality without restrictive assumptions about how hidden features are distributed.

Paper explainersAll themesMultimodal

Multimodal learning works best when text, image, audio, or other modalities contribute complementary evidence about the same task. The difficulty is that each modality carries two kinds of information at once: signal that matters for the task and nuisance variation that belongs only to that modality, such as background texture, sensor artifacts, or wording quirks. If the model fuses everything indiscriminately, noise from one modality contaminates the joint representation. IBMA addresses that by extending the Information Bottleneck principle, meaning the rule that a representation should retain task-relevant information while compressing irrelevant detail, to both the fused representation and the modality-specific ones. It also derives an efficient upper bound for the bottleneck objective that does not assume a fixed shape for the hidden feature spread, so the method is not forced to treat all learned features as Gaussian just to make optimization convenient.

Zero assumption version

Why multimodal fusion often keeps the wrong information

When a model processes two modalities, it usually learns one encoder per modality and then combines the resulting features. That sounds straightforward, but the features contain a mix of useful and useless content. For example, an image encoder may capture visual clutter that has no bearing on the label, while a text encoder may preserve stylistic phrasing that is unrelated to the task. If the model fuses those features without control, the combined representation becomes larger but not cleaner.

Existing multimodal bottleneck methods partly address this by applying compression to the fused representation. That is incomplete because the fused feature is built from modality-specific features that may already be polluted. If those earlier features are misaligned or noisy, the fused bottleneck is trying to clean the problem late instead of early.

A second limitation is methodological. Many variational bottleneck methods assume a simple hidden-feature spread, often Gaussian, because that makes the math tractable. But the real learned feature spread may not follow that form. If the bound is built around a bad assumption, the training objective can become a poor proxy for the information the method actually wants to control.

The main change. Compress and align each modality before and during fusion, then optimize a bottleneck objective that does not require an unrealistic parametric assumption on the hidden feature values.

What the paper changes

What the paper changes

The paper changes where and how the information bottleneck is enforced. It moves the bottleneck from only the fused representation to both the fused representation and the modality-specific ones, and it replaces a restrictive variational assumption with an objective that does not depend on a fixed shape for feature values.

The hidden quantity

The hidden quantity

measured quantity  =  task-relevant shared information inside each modality

The main hidden quantity is the part of each modality that actually helps predict the task and is consistent with the complementary modality, because only that shared predictive content should survive compression and fusion. That quantity is not directly labeled. The model sees only raw inputs and task supervision, so it has to infer which parts of an image feature list or text feature list are shared task signal and which parts are modality-private noise.

IBMA makes that quantity easier to isolate by combining two pressures. The bottleneck pressure removes excess information that does not improve prediction, because features that do not help the task are penalized for taking up representation capacity. The alignment pressure keeps the semantic content that remains compatible across modalities. Together they favor features that are both predictive and mutually informative. This is stronger than fusion alone because the model is encouraged to clean each modality before the joint representation is formed.

Why it works

Why local bottlenecks plus alignment help

The Information Bottleneck principle says a good representation should be sufficient for prediction but otherwise compressed. In multimodal learning, that principle must operate at more than one level. If only the fused representation is compressed, the encoders may still pass large amounts of private noise forward, forcing the fusion block to undo a problem that already happened. By applying the bottleneck to modality-specific features, IBMA pushes each encoder to build a compact task-focused representation before fusion.

Alignment matters because compression alone can remove useful complementary information. The model therefore does not merely shrink each feature list; it also encourages image and text representations to agree on shared semantics. That agreement acts as a filter. Features that help prediction and are semantically consistent across modalities are preserved, while idiosyncratic modality-only patterns become easier to discard because they are neither predictive nor supported by the other modality.

The upper bound that avoids a fixed shape for feature values matters on the optimization side. Variational bottleneck methods often become practical by imposing a simple parametric form on the hidden distribution, meaning the way hidden feature values are spread. IBMA avoids that dependency, so the training objective is less tied to a potentially false modeling assumption. This makes the bottleneck term more faithful to the actual learned features and easier to deploy with standard training that follows the loss slope, because the optimization no longer depends on fitting the wrong reference pattern.

The objective in words

First in words:

Minimize prediction loss plus bottleneck penalties on each modality and on the fused representation, while adding an alignment term that keeps modality-specific features semantically consistent.

Then the compact form:

L = L_task + beta_f * I(Z_f; X) + sum_m beta_m * I(Z_m; X_m) + lambda * L_align

Every symbol:

Lthe total training objective
L_taskthe supervised prediction loss
I(Z_f; X)information retained by the fused representation about the inputs
I(Z_m; X_m)information retained by modality m about its own input
beta_fstrength of the bottleneck on the fused representation
beta_mstrength of the bottleneck on modality m
L_alignthe alignment loss that makes modality-specific features semantically consistent
lambdaweight of the alignment term
A tiny worked example
Suppose an image-text classifier predicts product sentiment.
The image feature includes useful packaging cues plus irrelevant background colors.
The text feature includes useful opinion words plus writing-style quirks.
A modality-specific bottleneck reduces sensitivity to background colors and style quirks because they do not help the label.
The alignment term keeps the image representation of damaged packaging close to the text representation of negative opinion because both indicate the same task signal.
The fused representation then receives cleaner evidence from both sides and predicts better with less redundancy.

The paper's contribution is not the existence of information terms alone, but the decision to apply them at both modality-specific and fused levels with a practical bound that avoids strong hidden-feature-distribution assumptions.

What can go wrong

What can go wrong

Over-compression can remove complementary signal. If the bottleneck weights are too strong, the encoders may discard modality-specific cues that are genuinely useful even if they are not shared.
Alignment can force false agreement. Some tasks need each modality to contribute distinct evidence. If the alignment term is too dominant, the model may oversimplify by making the modalities too similar.
Estimating bottleneck terms remains approximate. Even with a distribution-free upper bound, the optimization still relies on variational estimation, so the information terms are controlled indirectly rather than measured exactly.
Done right. The method is strongest when modalities contain both shared semantics and private noise, because that is exactly where local compression and alignment solve a real representational problem.
What a runnable demo should prove

What a runnable demo should prove

Build a two-modality classification task where each modality contains one useful signal and one distractor. For example, one modality can include the correct class cue plus random background clutter, and the other can include the correct class word plus irrelevant stylistic variation. Compare three systems: plain fusion, bottleneck only on the fused representation, and IBMA.

The demo should show that IBMA retains the label-relevant content while reducing sensitivity to the distractors. It should also show that the modality-specific feature lists become more semantically aligned on the task-relevant dimensions rather than on incidental details.

alignment_gain = task_accuracy_with_distractors_removed - task_accuracy_with_distractors_present

A convincing outcome is strong accuracy with low dependence on distractors, because that demonstrates the model kept the information that matters and compressed what does not.
