Opponent Shaping in LLM Agents

ShapeLLM studies whether one language-model agent can change how another agent learns by choosing actions that alter the other agent's future updates.

Paper explainersAll themesAgents & Tool Use

When two learning agents interact repeatedly, each action does two jobs at once. It affects the current round, and it changes what the other agent learns from that round. That second effect matters because an agent may choose a move that looks costly now if it causes the other side to become easier to exploit later, or easier to coordinate with later. This paper asks whether language-model agents can do that kind of learning control, even though earlier opponent-shaping methods were built for smaller reinforcement-learning systems with tools that do not fit large next-word models well. ShapeLLM adapts model-free opponent shaping to this setting and shows that language-model agents can alter each other's learning path in both competitive and cooperative repeated games.

Zero assumption version

Why ordinary multi-agent learning misses the real lever

In repeated games, each agent usually asks a short question: which move gives me the best payoff now? That misses an important lever because today's move also becomes training data for the other player. If your action changes what the other side learns, then you can influence not only the current reward but also the opponent's future policy.

That idea is called opponent shaping. It is well studied in reinforcement learning, but older methods often require higher-order derivatives, task-specific architecture hooks, or costly calculations that do not fit large next-word models well. The open problem is whether language-model agents can shape one another through interaction alone when those older tools are unavailable.

The paper's move in one sentence. ShapeLLM chooses actions partly for their effect on the opponent's next learning step, so that one language-model agent can steer another toward later behavior that is easier to exploit or easier to coordinate with.

The algorithm as a flow

What it actually does

Step 1: Put two learning agents in a repeated game

Run many rounds of games such as Prisoner's Dilemma, Matching Pennies, Chicken, and Stag Hunt so that both agents can adapt over time.

Step 2: Estimate how today's action changes the opponent's next update

Approximate the effect of the current interaction on the other agent's learning step, because shaping depends on future policy change rather than only current reward.

Step 3: Add that future effect to the acting agent's objective

Score candidate actions by combining immediate payoff with the value of steering the opponent's next behavior.

Step 4: Let the opponent train from the new interaction

Update the co-player from the round outcome so that the shaping signal has a real path into later play.

Step 5: Measure long-run game outcomes

Check whether the shaping agent drives competitive games toward exploitable outcomes or cooperative games toward joint-gain outcomes.

What the paper changes

What the paper changes

The paper changes the agent objective. Instead of optimizing only for immediate round payoff, ShapeLLM also values how an action changes the opponent's next learning step.

the object it moves  =  Action choice with opponent-learning effects
The hidden quantity

The hidden quantity: influence on the opponent's next update

measured quantity  =  how much my action changes the other agent's next policy update

The key quantity is not the round reward by itself. It is the derivative-free influence of one agent's action on the opponent's next training step. If that influence is strong and predictable, then one player can choose actions that alter what the other player becomes later.

In competitive games, influence is useful because it can move the co-player toward a policy that loses more often. In cooperative games, influence is useful because it can move both sides toward a stable high-payoff pattern. ShapeLLM succeeds when it can estimate and exploit that influence reliably enough to change the learning path over many rounds.

Why it works

Why it works

Repeated games create a feedback loop because every interaction becomes part of the other agent's training history. That means the acting agent can benefit by selecting moves that create favorable lessons for the co-player. ShapeLLM works by making that lesson-creation effect part of the acting agent's decision rule.

This matters because standard myopic play can miss profitable long-run strategies. A move that gives a slightly lower reward now may still be best if it causes the opponent to adopt a later policy that is easy to exploit or easy to synchronize with. By accounting for the next-update effect, ShapeLLM can trade a little current reward for a better future interaction path.

The method is adapted for language-model agents by avoiding machinery that depends on exact higher-order update calculations through the opponent. That keeps the approach usable for large next-word models while still preserving the core causal idea: choose current actions partly by how they teach the other side.

Math after the picture

The shaping objective

First in words:

Choose the current action that maximizes immediate reward plus the value of how that action changes the opponent's next policy update.

Then the compact form:

a_t* = argmax_a [ r_t(a) + beta * V_after(opponent_update(history_t, a)) ]

Every symbol:

a_t*the action chosen at round t
r_t(a)the immediate payoff from taking action a at round t
betathe weight placed on future shaping value
opponent_update(history_t, a)the opponent's next learning step after seeing the current history and action
V_after( )the future value of the opponent policy after that update
history_tthe interaction history available at round t
A tiny worked example
Suppose one action gives reward 5 now, but it teaches the opponent to keep defending, so later rounds stay hard.
A second action gives reward 4 now, but it causes the opponent to switch toward a pattern that can be exploited later.
If the future value of that switch is 3 and beta is 1, then the second action scores 4 + 3 = 7.
The first action may score only 5 + 0 = 5 because it does not change the opponent in a useful way.
ShapeLLM picks the second action because the full objective values long-run influence.

The point of the equation is that a current move is judged partly by the next policy it causes in the other agent.

What can go wrong

What can go wrong

The estimate of opponent influence may be noisy. If the agent cannot tell how the co-player will update, the shaping term becomes unreliable because a current move may teach the wrong lesson.
The opponent may adapt too quickly. If the other agent changes policy in unstable ways, long-run steering becomes hard because yesterday's teaching signal no longer predicts tomorrow's response.
Competitive shaping can conflict with cooperative goals. A shaping rule that works well for exploitation may hurt joint welfare because it pushes the game toward one-sided outcomes instead of shared high-payoff behavior.
Done right. The method works when repeated interaction creates a stable learning signal and the agent can estimate how current actions change the opponent's next update.
What a runnable demo should prove

What a runnable demo should prove

Build a small repeated-game setup with two language-model agents and at least one competitive game plus one cooperative game. Compare ordinary round-by-round play against a shaping-aware policy that scores actions using both current reward and estimated effect on the other side's next update. Plot the opponent's policy over time. The demo should show that the shaping-aware agent changes that policy trajectory because it selects moves that teach a different lesson.

shape_gain = long_run_payoff_with_shaping - long_run_payoff_without_shaping; path_shift = distance(opponent_policy_T, baseline_opponent_policy_T)

The demo must make clear that the gain comes from altering the other agent's learning path, not from a one-round trick.
