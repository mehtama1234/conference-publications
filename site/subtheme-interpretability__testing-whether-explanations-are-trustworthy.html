Testing whether explanations are trustworthy

Many interpretation methods claim to explain models, but do they? These papers test whether explanations actually capture how models work or just sound convincing.

All themesField mapMathematicsAll explainers
What this is

Imagine a model that's good at predicting but gives explanations that sound plausible but are wrong. It might point to random parts of the input and claim they caused the output. To a human reader, the explanation might sound convincing, but it's false. This is a real danger: if we rely on interpretability methods that are themselves unreliable, we gain false confidence in a broken model. These papers ask a hard question: how do we know an explanation actually captures what the model is doing?

One approach is adversarial testing: design cases where you know the true explanation and see if the method finds it. Another is mechanistic verification: trace through the computation step-by-step to see if the highlighted inputs actually cause the output via the paths the explanation claims. A third is consistency: do different explanation methods agree? These papers also benchmark explanations against simpler proxy models. If the explanation helps a simple model achieve similar accuracy, that's evidence the explanation captures real structure, because a simpler model that learns from the same explanations will also need those explanations to be true in order to match the complex model's behavior. The goal is to move interpretation from an art (that sounds reasonable) to a science (that provably works).

How the work breaks down

This subtheme splits into five main directions. First, papers test whether explanations actually predict model behavior—do they help a simpler model match the complex one, or do they just sound plausible?—because if an explanation is false, relying on it creates false confidence. Second, some papers hunt for broken explanations, showing when standard methods fail and why, so we can audit methods before deploying them. Third, some mechanically verify explanations by tracing computation step by step, which means checking inside the actual model to see if highlighted parts truly cause the output. Fourth, papers learn to generate explanations that are trustworthy by construction, rather than trying to explain a model after the fact. Fifth, some develop domain-specific explanation methods for graphs, time series, and other structures that have special properties.

Testing explanations behaviorally

The core question: if an explanation actually captures what a model is doing, it should help us predict the model's behavior, because explanations that truly identify important features can be used to reproduce the model's decisions. One simple test is this: take the explanation and use it to train a smaller, simpler model. If the explanation is faithful, the simple model should match the complex model's predictions on cases where the explanation applies, since they are following the same logic. But if the explanation is fake—plausible-sounding but wrong—the simple model will fail, because it is trying to learn from false information. These papers tackle the real difficulty: explanations that sound convincing to humans often don't hold up under this behavioral test.

Faithfulness Under the Distribution (testing explanations on realistic cases) takes a hard look at how we measure faithfulness in the first place. Many prior approaches perturb inputs (remove parts, add noise) to see if the explanation's highlighted regions actually cause the model's decision. But these perturbations often push the input far outside the realistic range of examples the model saw during training, breaking the model's learned patterns. This paper proposes evaluating explanations only on realistic cases the model actually encountered, producing dramatically more reliable judgments, because unrealistic test cases don't tell us whether explanations work in practice. Chain-of-Thought Reasoning Reveals that even frontier LLMs show unfaithful reasoning paths—up to 13% of production models don't actually follow the steps they write out; the best models drop this to under 0.04%. A Positive Case for Faithfulness flips the question: instead of asking if explanations fool humans, ask if they help predict what the model will do next, because this tests whether the explanation captures actual decision-making patterns rather than just sounding good. The paper shows self-explanations improve prediction accuracy (11-37% gains), and also catch egregiously misleading explanations (5-15% are actively wrong), so false explanations become detectable. Learning for Highly Faithful Explainability goes further by proving an explanation method can be optimal across multiple faithfulness metrics simultaneously, while producing explanations that outperform existing techniques, demonstrating that perfect fidelity is achievable. Directly Optimizing Natural Language Explanations achieves extreme behavioral fidelity: a model trained on the explanations can simulate the original model with 85% accuracy and recover its outputs with 99% accuracy, beating GPT-4o and human explanations by 15%, which means the explanations preserve nearly all the decision-making logic.

Catching and auditing bad explanations

Not all explanations that look reasonable are actually reliable. These papers systematically find cases where standard explanation methods break down or produce actively misleading results. The danger is subtle: an explanation might be wrong in ways that are hard to spot by eye, but could cause serious harms in high-stakes domains like medical diagnosis or criminal justice.

GNN Explanations that do not Explain uncovers failure modes in graph neural network explanation methods, showing these methods can produce confident but useless explanations. The paper proposes a reliable auditing mechanism to catch both intentionally malicious explanations and cases where the method simply degenerates silently. Bridging Explainability and Embeddings exposes spurious correlations that models have learned—patterns that feel real but are actually just statistical noise. For example, one concept reduced ImageNet accuracy by 95% when removed (suggesting the model relied on it), but when probed directly, it turned out to be a spurious shortcut. In medical settings, the paper found clinical shortcuts that cause dangerous false negatives—the model learned to ignore a critical symptom based on some unrelated artifact in the data. Out-of-Distribution Evaluation of Chess Transformers (testing the model on unfamiliar board positions) checks whether a model's reasoning actually works when conditions change. The paper tests a chess model on unfamiliar board configurations it never saw during training. The model shows reliable rule-based reasoning (generating legal moves even in new positions), but its strategic reasoning breaks down and underperforms simple symbolic AI algorithms that follow hard-coded rules.

Mechanically verifying explanations

Another way to test explanations is to trace the actual computation inside the model and see if the highlighted parts actually cause the output through the paths the explanation claims. This requires getting inside the model's internals, which is harder but more certain than behavioral tests alone.

From Concepts to Components shows that within a transformer, certain attention modules are responsible for specific concepts (semantic features the model tracks). The paper finds that these module-concept links remain stable even after fine-tuning, suggesting the model has genuinely modular structure, not just statistical patterns. Provably Explaining Neural Additive Models (NAMs) gives exact, minimal explanations: it finds the smallest set of input features needed to explain a decision and proves this set is optimal. The explanations are not approximations; they are mathematically complete. Compressed Sensing for Capability Localization takes a surgical approach: erase just a few task-specific attention heads (as few as five) and watch capability-specific performance degrade by 60%. This reveals that the model's abilities are localized to specific, identifiable components, not spread diffusely across the entire network. Query Circuits uncovers the sparse internal pathways (circuits) a language model uses to answer questions. Remarkably, only 1.3% of the model's connections are needed to recover 60% of performance on challenging benchmarks, and these circuits can be extracted and studied directly.

Learning trustworthy explanations

Instead of reverse-engineering explanations from a trained model, some papers build explanation-ability into the model from the start, or learn explanations via a principled process that ensures trustworthiness, because explanations built into the model are automatically faithful to its reasoning.

Divide and Abstract improves performance by 8.6x and advances reasoning accuracy by 57.8% through structured decomposition and abstraction. By teaching the model to build intermediate explanations as part of its reasoning process, the explanations become intrinsic to the solution, not added retroactively, so they capture the actual steps the model took. The Value of Information in Human-AI Decision-making shows that when explanations are chosen to maximize information value (not just plausibility), human-AI teams make better decisions on real tasks like medical imaging and deepfake detection, improving error reduction compared to non-AI-assisted choices, because humans can trust and act on genuinely informative explanations. Learn from A Rationalist distills explanations from a teacher model into a student. The teacher reasons step by step (providing intermediate rationales), and the student learns to predict these rationales. This forces the student to build a similar internal reasoning process, not just memorize outputs, since memorization without understanding the steps cannot generalize to new examples. The method works with different neural architectures like BERT and vision transformers, making it broadly applicable. TT-Sparse learns sparse rule models that transform exactly into compact Boolean formulas. Because the model outputs formulas directly (not approximations), the explanations are provably complete, which means every case is fully explained. The approach achieves superior predictive performance while remaining interpretable on datasets across binary classification, multiclass, and regression.

Temporal and graph-structured explanations

Graphs and time series are fundamentally different from images or text: they have structure (connections between entities, causal dependencies over time) that must be preserved in explanations, because an explanation that ignores the structure cannot be trusted. These papers develop explanation methods that respect this structure and verify they actually work.

Training-free Counterfactual Explanation for Temporal Graphs asks: which past events caused this outcome? For models on dynamic networks, the paper finds explanations with guarantees on temporal correctness and supports queries about what happened when, because causal order matters—an event in the future cannot cause the past. Towards the Explainability of Temporal Graph Networks uses memory backtracking to trace which historical facts influenced the prediction, then attributes them fairly across time steps. The method outperforms baselines across nine datasets in node prediction, link prediction, and graph classification, which demonstrates the approach correctly identifies what matters. Unified Time Series Explanations amortizes explanation into a lightweight learned process: instead of expensive computation per instance, the model learns expert explanations that can be quickly retrieved at test time, because this saves computational cost while preserving accuracy. The method is validated against ground truth (cardiologist labels on ECG data), ensuring medical accuracy, so explanations align with human expertise. Hierarchical Causal Abduction applies causal reasoning to model predictive control systems. By using domain-specific structure to trace causality, it improves explanation accuracy by 53% over LIME and achieves 0.88 accuracy across three control applications, because modeling the actual causal structure of the system is more accurate than generic approaches. Self-Consistency Improves the Trustworthiness of GNNs ensures graph explanations are internally consistent: if the explanation says node X depends on nodes Y and Z, then perturbing Y and Z should predictably change the output, which tests whether the explanation actually describes real dependencies. Optimizing for this self-consistency improves explanation quality across multiple benchmarks, because consistency indicates the explanation captures genuine patterns.
