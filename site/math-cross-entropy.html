In plain terms

Imagine you are teaching a model to recognize handwritten digits. You show it a picture that is actually the number three. The model looks at it and says: I am 50% sure it is three, 30% sure it is eight, 15% sure it is five, and 5% sure it is two. The model got it right—it picked three as the most likely—but it was not very confident. How would you tell the model it should be more confident? You need a number that says: your guess was okay, but not great. That number is called the loss.

This formula turns the model's confidence scores and the true answer into a single loss number. Low loss means the model was confident and right. High loss means the model was confused or wrong. By computing this loss on thousands of examples, then adjusting the model to make the loss smaller, you teach the model to make better and better guesses. This is the standard way to measure how much the model's belief distribution (what it thinks) differs from the real distribution (what is actually there).

The equation
L=-\sum_i y_i \log p_i
LThe loss, a single number measuring how wrong the guess is. Lower is better.
y_iThe true label indicator—it equals 1 if the correct answer is option i, and 0 otherwise.
p_iThe model's predicted probability for option i, a number between 0 and 1.
logThe natural logarithm, which penalizes small probabilities very harshly.
\sum_iAdd up all the terms for every option i to get the total loss.
Worked example
A 3-option classification example
True answer: Cat (y_cat=1, y_dog=0, y_bird=0)
Model predicts: cat 70%, dog 20%, bird 10%
L = -(1·log(0.7) + 0·log(0.2) + 0·log(0.1))
L = -log(0.7) = 0.357 (lower loss, model was confident)
Why it shows up

This formula appears in nearly every machine learning model because almost all models make probabilistic guesses—whether they are recognizing images, translating text, generating images with diffusion, or routing information through decision trees. Whenever a model must pick one option out of many or predict a probability, it measures how far off the model is. It is differentiable, meaning you can compute how to adjust the model's weights to reduce it, which is why it powers every training loop where you adjust the model step by step. From language models to computer vision to robotics controllers choosing actions, this is the standard cost function that lets you compute the direction to change each weight so the loss shrinks.

The reason this works so well is that it combines two insights: first, only the probability of the true answer matters (all other terms vanish because wrong answers contribute zero), and second, using the logarithm makes the loss explode when the model gives low confidence to the truth. A model that says the true answer has 90% probability incurs barely any penalty, but one that says 10% gets a much larger penalty. This forces the model to be confident in its correct predictions, not just guessing correctly by accident. That asymmetry is what makes this formula so effective at teaching models.
