Modeling Covariate Transition for Efficient Estimation of Longitudinal Treatment Effects in Randomized Experiments

Estimate treatment effects over time by modeling how post-treatment covariates and intermediate outcomes evolve, so randomized experiments can answer not only whether treatment works on average but also when it starts and how long it lasts.

Paper explainersAll themesOther

A randomized experiment usually reports one average treatment effect at the end of the study. That number is useful, but it hides timing. A treatment may act immediately and fade, or it may act slowly and persist. Once outcomes and covariates evolve over time, ordinary regression adjustment no longer uses all available structure. This paper adds a transition model for the evolving post-treatment covariates and intermediate outcomes. A transition kernel, meaning a rule that gives the next-step probability distribution, which is the rule assigning probabilities to possible next states, given the current state and treatment, becomes the central object. With that object in place, the estimator can track longitudinal treatment effects under static treatment regimes and can reach the semiparametric efficiency bound, which is the lowest possible asymptotic variance among regular estimators under the model assumptions.

Zero assumption version

Why average treatment effects miss the time structure

In a randomized trial, regression adjustment uses pre-treatment covariates to reduce estimator variance. That helps when the goal is one final average effect, because baseline covariates explain part of the endpoint variation even without modeling the full trajectory. It says much less when the scientific question is temporal: when does the treatment start to act, through which intermediate outcomes, and how long do the effects persist.

The hard part is that post-treatment covariates change over time. They are not fixed nuisance variables. They are part of the mechanism through which treatment can influence later outcomes. If an estimator ignores those transitions, it discards information that can reduce variance and separate early from late effects. This paper models the transitions directly so the time path becomes part of the estimator rather than background noise.

The central move. Represent evolving post-treatment states with transition kernels, because the full treatment effect path depends on how those states propagate information forward through time.

The algorithm as a flow

What it actually does

Start from a randomized experiment under a static regime.

Treat assignment as randomized and fixed over time so identification does not depend on untestable treatment-selection assumptions after baseline.

Track intermediate outcomes and post-treatment covariates.

Record the evolving state at each time because later outcomes depend on the path, not only the baseline.

Model state transitions with kernels.

Estimate how the current state and treatment determine the next-step distribution so the longitudinal path can be summarized probabilistically.

Build a regression-adjusted estimator for each time point.

Use the transition model inside the adjustment step so the estimator borrows information from the whole trajectory and reduces variance.

Report the effect path with large-sample uncertainty summaries.

Produce time-indexed treatment effects together with asymptotic normality, which means the estimator approaches a normal distribution after proper scaling in large samples.

The hidden quantity

The hidden quantity

measured quantity  =  future effect propagation through evolving covariates

The key hidden quantity is how today's state affects tomorrow's outcome under treatment and control. You cannot see that propagation from one cross-sectional comparison because the same observed endpoint can arise from different timing patterns.

The transition kernel estimates that propagation. Once the next-state law is modeled, the estimator can trace how treatment shifts the state path over time and how those state shifts feed into later outcomes. That is what turns one endpoint effect into a longitudinal effect curve.

Why it works

Why transition modeling reduces variance and reveals timing

Randomization already identifies average treatment effects, but identification is not the same as efficiency. If you ignore informative post-treatment trajectories, you leave variance reduction on the table because later outcomes can often be predicted much better once the evolving state is known.

A transition kernel lets the estimator use that information systematically. At each time step, it summarizes how treatment and current covariates move the process forward. Those summaries improve regression adjustment because the estimator conditions on the relevant evolving state rather than only on baseline measurements.

The same structure reveals timing because it links one period to the next. A treatment effect that is absent at time 1 but appears at time 3 must pass through the transition system somehow, either through delayed state changes or through accumulation across periods. Modeling transitions makes that mechanism visible in the estimator instead of hiding it inside one endpoint average.

Estimate effects through the transition law

First in words:

A simple summary is that the next-period state depends on the current state and treatment through a transition kernel, and the treatment effect at later times is computed by propagating those transitions forward under the two treatment arms.

Then the compact form:

next-state distribution = K_t(current state, treatment) ; effect at time t compares propagated outcomes under treatment and control

A tiny worked example
Suppose a streaming platform changes its recommendation system for the treatment group.
At week 1, watch time barely changes, but the treatment raises the number of saved shows.
At week 2, saved shows increase return visits, and return visits then increase watch time.
A final-week average sees only the endpoint gain.
A transition model shows that the early saved-show shift is the mechanism carrying the effect into later watch time.

The important change is that intermediate states are treated as part of the estimand's information path, not as disposable side variables.

What can go wrong

What can go wrong

The transition model can be misspecified. If the kernel omits important state features or uses the wrong functional form, the variance reduction can weaken and finite-sample bias can appear because the adjustment no longer tracks the real longitudinal dynamics.
Long trajectories need enough data. As the number of time points grows, the state process becomes harder to estimate precisely, so small experiments may not support a detailed transition model without regularization, which means adding constraints that keep the fitted transition from chasing sample noise, or dimension reduction.
Static regimes limit the scope. The paper studies fixed treatment assignment over time, so additional work is needed before the same estimator can handle adaptive or time-varying treatment policies.
Done right. The estimator is most valuable when post-treatment states genuinely mediate later outcomes, because that is when transition-aware adjustment uses information that endpoint-only methods ignore.
What a runnable demo should prove

What a runnable demo should prove

Simulate a randomized experiment with six time points, one intermediate covariate, and one final outcome. Design the treatment so it first changes the covariate and only later changes the outcome through that covariate. Compare a baseline-only regression adjustment estimator against a transition-aware estimator.

The demo should report time-specific treatment effect curves and confidence intervals. It should show that the transition-aware estimator has tighter intervals because it uses the observed state path, and that it correctly reveals the delay between the first state change and the later outcome effect.
