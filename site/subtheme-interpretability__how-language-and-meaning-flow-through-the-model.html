How language and meaning flow through the model

Models transform words into abstract concepts and back. These papers track how semantic information moves through layers, how syntax gets separated from meaning, and where translations happen.

All themesField mapMathematicsAll explainers
What this is

Language models process text token by token — one chunk at a time — and each token is first converted into a numerical vector called an embedding (a list of numbers that represents the token in a way the model can work with). As the token flows through layers, this vector is transformed, mixed with information from surrounding tokens, and gradually becomes something richer. By the final layers, the same token's representation has absorbed context: 'bank' in 'river bank' is represented differently from 'bank' in 'the bank is closed.' This research asks: where and how does this transformation happen? At what layer does the model separate the surface form (spelling, word order) from the meaning?

The core challenge is that language has layers of structure: sound, syntax (grammar), and semantics (meaning). A model has to build all three and coordinate them. Do early layers extract syntax while later layers add meaning? Or does it happen all at once? Some research uses probing classifiers — attaching a small auxiliary model to read out hidden states and asking, 'if I measure at this layer, can I predict the part of speech?' Others track how specific token positions influence each other through attention. By building this map, researchers understand how language gets parsed and reassembled inside the model, which matters for spotting errors or biases introduced during that processing.

How the work breaks down

The work splits into five directions: measuring where tokens transform from surface form to meaning (which layers extract grammar vs. semantics), tracking how syntax and semantics separate during processing, understanding how multimodal models fuse vision and language, discovering which neurons implement language-specific behaviors, and probing how the arrangement of numbers in the model's hidden layers relates to what it does.

Surface form vs. meaning: where the split happens

One of the deepest questions in interpretability is when a model stops dealing with surface form — spelling, word order, which language a token is in — and starts working with abstract meaning. This is hard because both happen inside layers, hidden from view. The only way to know is to design careful experiments that isolate grammar from meaning and measure which parts of the network care about each.

Negative Pre-activations Differentiate Syntax shows that certain neurons (those that activate when they go below zero) specifically handle grammar: disabling them breaks grammatical performance but leaves other tasks intact. This is a clean dissociation — proof that syntax is stored separately from meaning. How Do Language Models Speak Languages identifies a specific sub-circuit of neurons responsible for picking which language to generate in, and shows that fine-tuning just that circuit (0.019% of all neurons) reduces unwanted code-switching by over 20% while changing almost nothing else. LinguaMap goes further by systematically searching for the layer-by-layer language features: it finds which layers are language-specific and which layers are shared across all languages, then shows that tuning only 3-5% of the network weights in the right layers gives you 98% language consistency without retraining everything. Multilingual Routing in Mixture-of-Experts reveals that expert networks route different languages to different neurons — early and late layers specialize by language because the model needs different strategies for different languages, while middle layers work with language-neutral concepts that all languages share, and steering this routing at runtime improves accuracy by 1-2% because you can guide the model toward better language choices. Syntax vs. Semantics: How Transformers Learn Deep Dependencies shows that syntax (like tracking a noun through a sentence) gets suppressed by default in neural networks, but Chain-of-Thought reasoning bypasses this suppression, and using a topology-aware training objective can get 2x larger improvements than standard training because it aligns the network's structure with how language actually works.

Token and layer positions: the shape of meaning

Meaning is stored as vectors — lists of numbers — and the structure of those vectors contains information about what the model knows. Research in this group asks: can we read off what the model is thinking by looking at these number-lists? Do tokens with similar meanings cluster near each other in the vector space? As information flows through layers, does it stay in the same arrangement or jump around? Understanding how these vectors are positioned tells us whether the model is actually building up intricate meaning or just memorizing patterns.

A Geometric Relation of the Error shows that the spatial layout of tokens in the model's internal space matches the real structure of the problem it's solving — when the model works on chess, tokens cluster by piece type and board region, reflecting the actual game structure. This means internal arrangement is not arbitrary; it encodes real concepts. From Associations to Activations compares two ways of measuring if the model understands something: behavior-only tests (what the model chooses to output) versus looking directly at internal states. The key finding: looking at the internal state arrangement predicts behavior better than just asking what the model would associate, which means internal structure is the ground truth, and behavior is a consequence of that structure. Abstraction Induces the Brain Alignment shows that when a layer's internal representations are more abstract (measured by how many dimensions are needed to describe them), that layer aligns better with brain recordings (fMRI and ECoG) because abstract representations pack more meaning into fewer dimensions, and this alignment improves during training when the model learns more detailed meaning. Bridging Functional and Representational Similarity provides a framework for connecting three different ways of measuring if the model understands: function (what does it do), structure (how are vectors arranged), and reconstruction (can we decode meaning from the vectors). It unifies these views. The Truth Lies Somewhere in the Middle shows that when the model generates text, meaning is not concentrated in any single output token — it is spread across all the tokens it generates. Pooling all the tokens together gives a stronger signal than looking at just the final token because you capture the full picture rather than one snapshot.

Measuring and controlling hidden structure

Now that we can see what is happening inside layers, the next question is: how do we measure it reliably? And once we measure it, can we steer the model's behavior by editing what we find? These papers tackle the measurement and control side of interpretability.

Expand Neurons, Not Parameters shows that widening the network — giving it more neurons to work with — makes it solve Boolean logic tasks and CLIP image classification better, even when you keep the total number of weights constant. This suggests the network needs space to express different concepts because each neuron can specialize in a narrow task. Concept Heterogeneity-aware Representation Steering (CHaRS) finds that you can steer model behavior not just by moving all representations the same way, but by moving different clusters of concepts in different directions. This works better than global steering because concepts are not all the same; some are tied together while others are independent. Confidence is Not Universal shows that models calibrate differently on different tasks — what makes the model confident on one task does not transfer to another task because different tasks require different thresholds. But when you break down calibration by task, you can transfer it. This matters for safety: you need task-specific measurements, not one universal confidence score. Decoupling Dynamical Richness from Representation Learning shows how to measure whether a network's representations are actually learning to represent the world or just memorizing patterns. The metric captures when grokking happens (when a network suddenly starts generalizing after memorizing) because it detects when representations shift from brittle to flexible. Semantic Regexes provides a way to write down descriptions of what individual neurons do using simple patterns (like regular expressions for code), and shows that these patterns are as accurate as natural language descriptions but more consistent and concise because they are formal.

Multimodal fusion: vision and language together

Language models can now see images, and the question is: when a model processes an image and text together, what is actually happening? How does the image information flow into language processing? Do vision and language get processed separately and then merged, or do they mix throughout? These papers investigate the internal mechanics of multimodal models.

Reading Images Like Texts reveals that vision-language models process images in two stages: first they extract attributes (colors, shapes, positions), then they use those attributes to figure out what things mean (what the objects are, what is happening). The spatial reasoning can be improved by scaling positional encodings, suggesting the model uses position as a scaffold for understanding layout. A Comprehensive Information-Decomposition Analysis of Large Vision-Language Models breaks down how different models combine vision and language. It finds two different types of tasks (some need vision and language to depend on each other, others need mostly language knowledge) and two different model strategies (some models fuse vision into the language pipeline early, others keep language dominant and use vision only when needed). Visual Instruction Tuning — the process of training the model on image-caption pairs — is key to learning how to fuse. Large Vision-Language Models Get Lost in Attention exposes a startling finding: if you replace the learned attention weights (the mechanism that connects tokens and pixels) with random Gaussian noise, the model performs just as well or better. This means current models are not using attention well — they are wasting it because the attention has not learned to focus on the right connections. Sparse CLIP shows that you can make the vision-language model more interpretable by removing redundant features (using sparse autoencoders), and this actually improves downstream performance while making it clear which visual features matter. Towards Understanding Modality Interaction in Multimodal Language Models uses information theory to show that reasoning tasks require vision and language to depend on each other, but knowledge tasks can mostly use language alone, and visual features dominate in multimodal systems, sometimes creating a bottleneck.

Editing and controlling learned knowledge

The final step is to turn measurement into action: once you find where a piece of knowledge or behavior is stored, can you edit it? Can you make the model forget something, learn something new, or change how it behaves? This matters for safety, fixing errors, and adaptation.

Precise and Interpretable Editing of Code Knowledge identifies which neurons store knowledge about code and shows you can edit specific facts (like what a function does) by changing individual neurons, with direct correspondence between what you change and what the model forgets or learns. ReasonEdit demonstrates that when you want to edit a vision-language model's behavior, telling it the human reasoning behind the edit (not just the target output) works far better — the model generalizes the edit to new examples it has never seen because it understands the reasoning. The GNN Explainer paper moves from explaining by showing input features to explaining by showing learned patterns in the network. This provides a different and deeper kind of explanation. Exploring Interpretability for Visual Prompt Tuning shows how to explain what each layer of a vision model is doing and why it makes the choices it does, matching or beating the accuracy of the original model while being fully interpretable. The CoT Encyclopedia builds an encyclopedia of how reasoning models think — it catalogs the different reasoning strategies a model uses, predicts what strategy it will use for a new problem, and can improve performance and safety by steering toward better strategies.
