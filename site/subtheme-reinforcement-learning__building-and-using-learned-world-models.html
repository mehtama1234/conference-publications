Building and using learned world models

Training agents to learn a model of how the world works, then using that model to plan actions or simulate outcomes without constantly trying things in the real world.

All themesField mapMathematicsAll explainers
What this is

A world model is a learned simulation of how things work. Show it an image and current speed, and it predicts the next image. Show it a robotic arm's joint angles and the force it applies, it predicts where the arm moves. If the learner can build an accurate model of the world, it doesn't have to try every action in the real world — it can try thousands of actions in simulation first, then run only the promising ones for real. This matters because simulation is fast and failures are free (virtual objects don't break), so it saves time and prevents real-world damage.

Building accurate models is hard because the world is complex and high-dimensional. A video frame is thousands of pixels, and predicting how they change requires understanding physics, lighting, occlusion, and rare events. Early predictions are usually blurry and wrong, which wastes time in simulation because the agent trains on a false world. The learner improves the model with each new observation by adjusting its predictions to match what actually happened, so accuracy grows over time when the agent actively explores and collects new experience to fix errors. The trick is balancing two goals: improve the model fast enough that simulation predictions are accurate enough to be useful (so the agent doesn't waste time practicing skills that won't work in reality), but also don't get trapped in a loop where the model's systematic errors consistently teach the agent bad actions that fail when transferred to the real world (because the agent learned to do well in a false simulation). Papers here tackle model learning, planning strategies that work even with imperfect models, and deciding when to go back to real-world trials to fix model errors.

World models let reinforcement learning scale to tasks that would be too expensive to learn from scratch in the real world, which means researchers can tackle harder problems. A robot can learn reaching in simulation before touching physical objects. A game agent can plan millions of move-ahead sequences without playing millions of games.

How the work breaks down

Building accurate world models is hard because the world has too many pixels and random changes, and predicting wrong wastes the agent's practice time in simulation. The papers split across five directions: learning models that handle the pixel complexity directly using diffusion, building models with cleaner action representations so planning is simpler, learning from offline data without trying things in reality, planning and replanning strategies that work even when the model is imperfect, and combining multiple specialized models for different tasks or environments.

Diffusion models for action generation and planning

Diffusion models—generative models that gradually refine random noise into samples—have become a popular way to represent action policies and world dynamics. The core problem is that actions and next states can happen in many different ways, and standard neural networks struggle to capture all the different ways a task can be done or a world can evolve. Diffusion offers a flexible way to model these varied outcomes, but it's slow (many refinement steps) and can produce actions that don't work well with the world model.

Ada-Diffuser learns diffusion in a compressed representation space, which means working with fewer numbers and thus making predictions faster while keeping them accurate for robotic tasks (using latent inference—inference means predicting from a learned compressed form). Contractive Diffusion Policies steer diffusion trajectories away from regions outside the training data during planning, because such regions often contain nonsensical predictions, so policies work better when data is scarce (preventing trajectories that don't match the training data). Horizon Imagination halves the number of refinement steps needed while keeping control quality the same, using a focused denoising schedule. How Does the Lagrangian Guide Safe Reinforcement Learning through Diffusion Models? grounds diffusion in formal safety constraints so the agent balances reward with safety guarantees. Improving Diffusion Planners by Self-Supervised Action Gating learns which actions are actually feasible by checking them against the world model's energy, skipping useless refinement steps. Lagrangian Perturbation Diffusion Steering adds RL training directly on top of diffusion trajectories in the compressed space, improving sample efficiency on manipulation and real-robot tasks. Reinforcing Diffusion Models by Direct Group Preference Optimization trains the diffusion policy 20 times faster by aligning it to human preference feedback rather than doing slow step-by-step refinement. Sample-Efficient Diffusion-based Reinforcement Learning with Critic Guidance integrates a value function (critic) to steer diffusion toward high-value actions, achieving real-world robotic results. TreeGRPO uses tree search during training to explore many trajectories in parallel, which finds better diffusion refinement paths because it can compare more options, speeding up the overall training loop. Trust-Region Diffusion Policies runs diffusion policies in parallel on many environments at once and keeps updates conservative to prevent catastrophic forgetting, working well on humanoid control.

These papers all work around the same core tension: diffusion is expressive but expensive, so they focus on reducing compute (Horizon Imagination, Reinforcing Diffusion), adding structure to guide planning (Contractive, Gating, Lagrangian), and scaling across tasks (Trust-Region).

Learning interpretable and disentangled action spaces

World models work better when actions are represented in a form that makes sense because then the model can predict what each action does without getting confused—not raw continuous muscle commands or image pixels, but something in between that the model can predict cleanly. The challenge is that learning this representation is automatic and unsupervised; the model must figure out what abstraction level works for the world it observes.

DiLA: Disentangled Latent Action World Models separates latent actions into independent factors (latent meaning learned internal representation), which means each factor can be predicted without interference from the others, improving both what the model predicts and what the policy learns downstream. Mixture-of-World Models uses multiple separate model experts, each specializing in one skill or one part of the state space (e.g., moving fast vs. turning), so the agent picks the right expert for the current task rather than asking one model to do everything. Co-Evolving Latent Action World Models builds the action representation and the world model at the same time instead of one then the other, so they evolve together and converge faster. Multi-view Consistent Latent Action Learning learns a shared action representation across multiple camera angles, making actions transfer even when the view changes. Olaf-World: Orienting Latent Actions for Video World Modeling explicitly structures latent actions to match different control interfaces (e.g., steering wheels, joysticks), so actions transfer to new robots with minimal retraining.

All these papers aim to make the action space interpretable and broken down into independent pieces, which directly makes planning easier because the model's predictions stay accurate and transfer across contexts.

Learning from offline data without real-world trials

In many settings, agents cannot freely explore the real world—a physical robot might break, clinical trials are expensive, or the environment is already locked. Offline reinforcement learning trains only on historical data, but world models tend to drift: the agent practices in simulation based on a slightly wrong model, learns policies that fail in reality, and gets stuck in a false world. The challenge is predicting long horizons accurately without the feedback of real rollouts to correct errors.

ADM-v2: Pursuing Full-Horizon Roll-out in Dynamics Models keeps predicting far into the future (many steps ahead) while staying accurate by carefully managing how uncertainty grows and by distilling the rollout experience back into the policy in a stable way. Efficient Reinforcement Learning by Guiding World Models with Non-Curated Data learns from messy, uncleaned offline data (not just expert demonstrations) by letting the world model itself decide which experiences to learn from, reducing sample waste. Fast and Highly Expressive Policy Learning for Offline Reinforcement Learning via Bootstrapped Flow Q-Learning generates actions in a single forward pass instead of iterating, cutting compute dramatically while maintaining accuracy. Long-Horizon Model-Based Offline Reinforcement Learning Without Explicit Conservatism reaches very long horizons (hundreds of steps) by learning how the policy's errors accumulate over time, rather than forcing the policy to stay close to the data distribution. One-Step Flow Q-Learning: Addressing the Diffusion Policy Bottleneck also does single-step generation, matching multi-step diffusion quality while being orders of magnitude faster. Scalable Offline Model-Based RL with Action Chunks handles massive datasets (100 million transitions) by predicting action sequences rather than single steps, so the model works at a coarser timescale and makes fewer mistakes. Towards Bridging the Gap between Large-Scale Pretraining and Efficient Finetuning for Humanoid Control trains on massive simulated data first then fine-tunes on small real-world data, combining simulation efficiency with real feedback.

These papers all solve the same core problem: offline learning requires the model to stay calibrated over many steps, so they either reduce rollout length (single-step), learn from imperfect data, or structure predictions at a higher level (action chunks).

Planning and replanning when models are imperfect

Even with a learned world model, the agent still has to plan: take the model and search ahead to find actions that lead to high reward. But the model is imperfect, so search can get stuck in false valleys (actions that look good in simulation but fail in reality), and replanning each step is expensive. The core challenge is making planning work reliably even when the model is wrong.

From Observations to Events: Event-Aware World Models recognizes that simple pixel prediction misses important structure—a ball rolling or a robot touching a wall are discrete events—so the model learns to predict these milestones explicitly, making planning more reliable. Bayes Adaptive Monte Carlo Tree Search for Offline Model-based Reinforcement Learning uses tree search (exploring many action sequences in parallel in simulation) and updates its belief about the model as it observes rollout results, so it gradually corrects model errors. Deep SPI: Safe Policy Improvement via World Models runs the world model forward many times with different random seeds to estimate how uncertain each prediction is, then plans conservatively by avoiding high-uncertainty regions. Dream-MPC: Gradient-Based Model Predictive Control with Latent Imagination directly optimizes action sequences using gradients through the model, refining them step by step to reach high reward in the learned compressed space. Langevin Rollout Optimization for Modelic Reinforcement Learning generates action rollouts by simulating a noisy trajectory, then steadily removes the noise, guiding the trajectory toward high reward. Parallel Gradient-Based Planning speeds up gradient-based planning by running many search trajectories in parallel (using gradient descent—the algorithm of taking small steps downhill to optimize) and coordinating their updates. RiskZero: Plan More to Risk Less with a Learned Model accounts for worst-case outcomes during planning, so the agent doesn't get surprised by low-probability failures. Temporal Straightening for Latent Planning reshapes the learned latent space to make gradients useful for planning, so optimization doesn't get stuck. The Surprising Difficulty of Search in Model-Based Reinforcement Learning focuses on a subtle problem: even if the model predicts accurately, search can overfit to the model's quirks, so simple bias corrections during search matter more than model accuracy.

These papers all recognize that the model will be wrong somewhere, so they either make planning work with error (conservative planning, uncertainty estimates), or they focus on planning algorithm details (search bias, trajectory smoothing) that hide model imperfections.

Multi-task and transfer learning with world models

A single task is tractable, but real agents face many tasks across time: a robot learns reaching, then pushing, then climbing; a game agent adapts to different levels; a navigation robot handles different buildings. Training one world model per task wastes data and compute, but a single model that tries to handle everything often fails because tasks use different parts of the world. The challenge is sharing knowledge across tasks without one task breaking the model for another.

Adaptive Quasimetric Mapping learns a topological map using far fewer landmarks (waypoints) by using adaptive distance metrics that are learned not fixed, so the representation scales to large environments. Learning Dynamics Feature Representation via Policy Focus learns what parts of the world matter for planning by focusing on dynamics features (features meaning aspects or properties of how things change) relevant to the current task. Mixture-of-World Models (also in the action space group) allocates different model experts to different tasks, letting specialized models coexist. One Model for All Tasks: Leveraging Efficient World Models in Multi-Task Planning trains a single model efficiently by using online learning to adapt on the fly, matching specialized single-task models while staying smaller. TaskLoom: Weaving Knowledge Across Tasks in World Models shares knowledge hierarchically—low-level world patterns are shared, high-level task structure is separate—making fast adaptation to new tasks possible. Learning Disentangled Multi-Agent World Model for Decentralized Control extends this to multi-agent settings where the model must separate each agent's effect on the world. Learning Massively Multitask World Models for Continuous Control targets dozens of tasks at once by using task codes (learned numerical codes that identify task identity) to steer the model's predictions, keeping the model compact. Learning Task-Sufficient World Models by Combining Agentic Exploration and Structured Modeling explores intelligently to collect data that matters for the current task, then uses that data to build minimal models capturing only what's needed. Learning to Be Uncertain: Pre-training World Models with Horizon-Calibrated Uncertainty learns how confident to be at different prediction horizons, so transfer to new tasks gets the right uncertainty bounds. Object-Centric World Models from Few-Shot Annotations learns world dynamics at the level of tracked objects rather than pixels, which means the model focuses on what objects are present and how they move, and thus generalizes across visual appearance changes because it doesn't depend on surface textures.

All these papers solve task variety by either splitting the model (multiple experts), making it task-aware (identifiers, hierarchies), or learning at a higher abstraction level (objects, dynamics features) that transfers broadly.
