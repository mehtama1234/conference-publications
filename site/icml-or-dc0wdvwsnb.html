Verbalized Bayesian Persuasion

Extend Bayesian persuasion from numeric toy settings to dialogue settings by letting language agents send messages while a game solver checks the strategic constraints.

Paper explainersAll themesAgents & Tool Use

Bayesian persuasion asks how a sender should reveal information to influence a receiver's action. Classic treatments usually write the whole problem in numbers, which makes the math clean but limits the range of situations that can be studied. This paper moves the setting into dialogue. It lets language agents play the sender and receiver, while a solver enforces the strategic rules needed for persuasion to remain well defined.

Zero assumption version

Why classic persuasion models stop at toy settings

Information design begins with ordinary communication. A recommender, a public official, or a diplomat chooses what to say because that message can shift someone else's action. Classic persuasion theory studies this effect carefully, but it often encodes states, signals, and actions in small numeric games.

That abstraction is useful for theory, yet it leaves a gap when the interaction is an actual conversation. Real dialogue includes wording choices, partial disclosure, and multi-stage exchanges. The paper asks whether strategic persuasion can be studied in language without losing the formal structure of the original game.

The paper's move in one sentence. Map Bayesian persuasion into a mediator-augmented dialogue game where language agents speak, while a game solver checks commitment and obedience constraints behind the scenes.

The algorithm as a flow

What it actually does

Define a dialogue persuasion game

Represent the sender, receiver, hidden state, and possible actions in a setting where messages are written in language.

Use language agents for the dialogue

Let one agent play the sender and another play the receiver so that the interaction can express richer strategies than a small signal table.

Add a mediator and solver

Use a solver to enforce commitment and obedience conditions because strategic persuasion requires those constraints to remain valid.

Search for effective message policies

Iteratively improve the sender's language strategy while checking whether the receiver would still follow it, because a persuasive message is only useful when it changes action without breaking obedience.

Test on real dialogue scenarios

Evaluate the framework on recommendation, law-enforcement, and diplomacy tasks where the state and messages both affect the final action in a concrete way.

What the paper changes

What the paper changes

The paper changes the form of Bayesian persuasion. Instead of a small numeric signaling scheme, the sender's policy becomes a language policy that is still anchored by formal strategic constraints.

the object it moves  =  the sender's information-revelation policy in a dialogue game
The hidden quantity

The hidden quantity

measured quantity  =  how much of the true state should be revealed in language

The central hidden quantity is the message policy over the true state. The sender knows the state, but the best message is rarely full disclosure or full concealment. The sender needs the right amount and style of revelation to guide the receiver toward the preferred action.

That choice is hard in dialogue because wording matters. The framework handles this by keeping the strategic side explicit. The solver checks whether the receiver still has a reason to obey, so the language policy is optimized within the same logic that classical persuasion uses.

Why it works

Why this works: let language express the strategy while the solver protects the game

A pure dialogue system can generate persuasive messages, but it may ignore whether those messages fit the strategic assumptions of the game. A pure game solver can enforce the assumptions, but it cannot represent varied language acts. The paper combines them so that each part does what it is good at.

That combination helps because the language agent can explore nuanced messages while the solver rejects policies that break commitment or obedience. In this way, the framework can handle real dialogue scenarios without giving up the formal discipline that makes persuasion theory useful.

Math after the picture

Choose the message policy that helps the sender while preserving obedience

First in words:

A compact summary is to maximize the sender's expected payoff over message policies, subject to the condition that the receiver still prefers to follow the recommended action after hearing the message.

Then the compact form:

best_policy = argmax_policy sender_payoff(policy) subject to obedience(policy)

Every symbol:

best_policythe sender message policy that the framework is searching for
sender_payoff(policy)the sender's expected payoff under that message policy
obedience(policy)the condition that the receiver still wants to follow the recommendation
policya rule that maps the hidden state to a language message
A tiny worked example
Policy A always gives the same vague message, so the receiver learns little and often ignores the recommendation.
Its sender payoff is low because the receiver's action rarely changes in the desired direction.
Policy B reveals the right evidence for each state while keeping the recommendation believable.
Its sender payoff is higher because the receiver now has a reason to follow the suggested action.
The framework prefers Policy B because it improves the sender's objective without breaking obedience.

The paper solves a broader equilibrium problem, but this statement captures the central idea that persuasive messages must both help the sender and remain followable for the receiver because the receiver must still prefer the recommended action after hearing the message.

What can go wrong

What can go wrong

Language evaluation can be brittle. A solver can check strategic conditions, but the quality of the message wording may still vary in ways that are hard to score automatically.
Real people may react differently from the modeled receiver. A persuasion policy that works for the receiver model may fail with humans because real judgments and trust patterns can differ.
Multi-stage dialogue grows complex quickly. As the number of stages increases, the search over valid message policies can become harder because future reactions depend on earlier wording choices.
Done right. The framework matters because it brings persuasion theory into dialogue without abandoning the strategic constraints that define the problem.

What a runnable demo should prove

Build a small persuasion environment with one sender, one receiver, and a hidden state, then run it in natural-language settings such as recommendation letters or public statements. Compare plain language prompting against a verbalized-persuasion system that also checks commitment and obedience with a solver.

The demo should log the hidden state, the produced message, the receiver's action, and whether the strategic constraints were satisfied. The solver-guided system should achieve a better sender payoff because it searches only among message policies that the receiver still has reason to follow.
