Spatially Informed Autoencoders for Interpretable Visual Representation Learning

Instead of learning pixel brightness, SI-VAE learns where objects are located and how they cluster together using a statistical lens.

Paper explainersAll themesRepresentation & Self-Supervised Learning

When you train a model to compress images into numbers, today's models typically focus on pixel color and brightness. This paper shows that if you instead ask the model: where are things in this picture and how do they bunch together? then the learned numbers become interpretable and work better for spatial reasoning because they encode which spatial patterns are attractive, repulsive, or independent — information directly tied to the structure in the images. The trick is to teach the model using a statistics principle called point processes, which measures attraction and repulsion between locations.

Zero assumption version

Pixel brightness is not the real story

A standard image compressor (called a variational autoencoder or VAE — a model that squeezes a picture into a list of numbers) learns by watching pixels. It asks: what color is each spot? But if your real question is: where are the things in this image and do they like to huddle or spread out, then learning pixel colors alone misses the point.

A beginner might try: just train a VAE and hope the squeezed numbers capture spatial patterns. This fails because the VAE has no reason to care about where objects are — it is already doing well by memorizing brightness.

In one sentence. SI-VAE teaches the model to learn by predicting spatial patterns instead of pixel brightness.

The algorithm as a flow

What it actually does

Extract locations from image

Find all the places where objects sit (the ground truth)

Encode into numbers

Compress the image into a list of numbers that capture its learned patterns

Predict point-process score

For each location, predict how likely it is based on all other locations nearby

Compare to reality

Measure the gap between predicted likelihood and actual pattern, then nudge the numbers to shrink the gap

Generate new patterns

Use the learned numbers to sample plausible new spatial arrangements

What the paper changes

What the paper changes

Instead of rewarding pixel accuracy, SI-VAE rewards spatial-pattern accuracy. The learning target shifts from pixel brightness to whether the model's scoring function correctly predicts where objects actually sit.

The hidden quantity

Spatial intensity: how the paper measures what it learns

measured quantity  =  Conditional intensity (likelihood of an object at each location)

The hidden quantity is the conditional intensity — a number that says, given all the objects I see nearby, how likely is there an object right here? It is a plain probability: between 0 and 1. A high number means this spot is likely to have an object (attracted to its neighbors), a low number means it is unlikely (repelled or independent).

SI-VAE estimates this quantity using a statistical principle called the Papangelou formula, which is just a way of asking: for each location, what is the probability of finding an object there given the pattern around it? The model learns a neural function that outputs this probability for every point in the image.

Why it works

Why it works: spatial learning beats pixel learning

Standard VAE learns pixel values because that is what the loss function rewards. Pixel loss is easy to measure (just compare brightness), but it does not capture spatial structure.

SI-VAE flips the reward. Instead of asking the model to predict pixel intensity, it asks the model to predict whether each location will have an object given the pattern of nearby objects. This is a harder question — it forces the model to learn relationships and spatial correlations. Because the spatial question is tied directly to real spatial structure in the data, the compressed numbers end up encoding which patterns are attractive, repulsive, or independent. Once the model learns this structure, it can generate new spatial arrangements that obey the same rules, even on data it has never seen (zero-shot learning).

In short: pixel learning focuses on the wrong target and learns noise; spatial learning focuses on the structure and learns interpretable patterns.

Math after the picture

The equation: Papangelou likelihood

First in words:

negative log of (product over all locations of the probability model predicts an object there, if the ground truth says object there, times probability model predicts no object, if ground truth says empty)

Then the compact form:

loss = -sum_i [ log(lambda(x_i)) for x_i in observed locations ] - sum_j [ log(1 - lambda(u_j)) for u_j sampled from background ]

Every symbol:

lambda(x_i)the model's predicted likelihood of an object at location x_i
x_ia location where an object actually sits (from ground truth)
u_ja location sampled from background (where no object sits)
lognatural logarithm, converts probability into a loss scale
losserror: low loss means predictions match ground truth
A tiny worked example
Suppose the image has objects at locations x1=10 and x2=20. Background samples at u1=5, u2=15, u3=25.
Model predicts: lambda(10)=0.9, lambda(20)=0.85, lambda(5)=0.2, lambda(15)=0.3, lambda(25)=0.1.
Loss from observed: -[log(0.9) + log(0.85)] = -[-0.105 - 0.163] = 0.268.
Loss from background: -[log(0.8) + log(0.7) + log(0.9)] = -[-0.223 - 0.357 - 0.105] = 0.685.
Total loss = 0.268 + 0.685 = 0.953. Model learns to predict high likelihood at true objects and low likelihood at empty spots.

The loss penalizes wrong predictions: high lambda at empty spots (wasting probability) or low lambda at objects (missing them).

What can go wrong

What can go wrong

Needs ground-truth locations. SI-VAE requires you to label where objects are in the training images. If location labels are noisy or sparse, the model cannot learn spatial patterns cleanly.
High-density or overlapping objects confuse the method. If objects crowd together or overlap, defining a single location for each object becomes ambiguous, and the point-process model breaks down.
Non-stationary patterns are hard to learn. If spatial patterns differ wildly across the image (e.g., clustered in one corner, random elsewhere), SI-VAE learns an average and predicts poorly on the extremes.
Done right: spatial labels are clean and patterns are consistent. When object locations are accurately marked and spatial structure is stable (e.g., cell nuclei in microscopy), SI-VAE learns efficiently and generates realistic new patterns.
