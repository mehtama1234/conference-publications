Problem

Full retraining is too slow for many adaptation needs. The model may need to infer a task, personalize a reward, update fast weights, or improve prompts while it is already deployed.

Approaches

The papers use test-time training, support-example graph inference, hyperparameter-conditioned paths, bandit task inference, task-vector projection, natural-language reflection, and preference transfer.

Connecting read

This is a control theme: adaptation is useful only when the system knows what to change, what to preserve, and how much evidence is enough.

FIRST PRINCIPLES

The core problem

A deployed model sees new evidence after training: a user's preferences, a support set, a task trajectory, a new hyperparameter setting, or a failed prompt. The adaptation question is how to turn that evidence into behavior change without overwriting the base system.

The papers here make adaptation local. Some adapt at inference time without parameter updates. Some alter fast weights or output distributions. Some preserve reasoning format while merging instructions. Some use reflection and search to improve prompts. The common shape is bounded change under limited evidence.

SYNTHESIS

Three adaptation patterns

1. Inference-time adaptation turns local evidence into temporary behavior

test-time control

These papers avoid full retraining by using support examples, task inference, fast weights, or hyperparameter-conditioned paths at inference time.

ICLR 2026OpTI-BFM
OpTI-BFM connects behavior foundation model task inference to upper-confidence linear-bandit algorithms with regret bounds. It treats task identification as exploration under uncertainty. The model should try actions that identify the task while still controlling regret, rather than assuming the task is known from the prompt.
ICLR 2026MF-GIA
MF-GIA performs inference-time graph prediction from support examples without raw modality access or parameter updates. The important constraint is deployment realism: the system may only receive pre-encoded features and labels. Adaptation has to align support evidence on the fly without opening the original modalities or changing weights.
ICLR 2026HTI
HTI learns conditional output-distribution paths across hyperparameter settings to adapt models without retraining. It turns hyperparameter movement into a learned map through output space. That gives adaptation a continuous control surface instead of a new training job for every setting.
ICLR 2026In-Place TTT
In-Place TTT adapts final-projection fast weights at inference time with a next-token-prediction-aligned objective. It uses the current context as training signal while the model is running. The change is temporary and local, which is exactly why it can help long contexts without committing to a permanent fine-tune.

2. Continual control must preserve the behavior format that still works

preservation

Adaptation can damage useful behavior. These papers explicitly preserve reasoning formats, preference schemes, or future-agent improvement paths while allowing change.

ICLR 2026RAIN-Merging
RAIN-Merging projects instruction-tuned task vectors away from thinking-token feature subspaces to preserve long-reasoning model format. The problem is that instruction adaptation can accidentally destroy the internal or textual format that reasoning relies on. Projection makes preservation part of the merge rule.
ICLR 2026P-GenRM
P-GenRM transfers preferences from similar users and scales individual scoring schemes at test time. Personalization cannot wait for full new reward-model training for every user. The paper treats preference adaptation as borrowing structure from nearby users while keeping the scoring scheme individual.
ICLR 2026Huxley-Goedel Machine
Huxley-Goedel Machine uses a clade-inspired CMP metric to guide coding-agent development toward stronger future descendants. It frames continual agent improvement as lineage control. The question is not only whether today's agent is strong, but whether the development path creates descendants with better capabilities.

3. Reflection and search can improve behavior without gradient training

trajectory search

The final pattern treats adaptation as a search process over prompts or behaviors, using natural-language reflections as the evidence that guides the next attempt.

ICLR 2026GEPA
GEPA uses natural-language trajectory reflection and Genetic-Pareto search to improve prompts with fewer rollouts than GRPO. It turns failures into textual search guidance. Instead of gradient-updating a policy, the system edits the prompt population toward better tradeoffs using reflective evidence from trajectories.
FIELD READ

What this theme says about ICLR

The theme says adaptation is becoming lighter, more local, and more controlled. Models are expected to shift behavior from context, support examples, task traces, and user preference without erasing the base capabilities that made them useful.

For the gym work, this matters because agents should not only be evaluated after static training. A useful benchmark may need to measure whether the agent can adapt from its own trajectory, learn a user's scoring rule, or preserve reasoning format while improving task behavior.
