A Relationship with the Chiba–Nishizeki algorithm We provide a thorough explanation of the algorithm by Chiba and Nishizeki (1985), state some of its properties which are important for our architecture and describe how the algorithm inspired our GNN architecture. Description of the Chiba–Nishizeki algorithm.The algorithm by Chiba and Nishizeki (1985) obtains as input an undirected, unweighted graphG= (V, E) and it returns a list of all triangles inG. Now the algorithm iterates over all neighborsw∈N(u) and checks if w∈N(v); if this is the case then it returns that (u, v, w) is a triangle.
