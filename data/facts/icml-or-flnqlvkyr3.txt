Backdoor Attacks on Agent Systems Backdoor attacks in machine learning have traditionally targeted models directly, through training data poisoning, parameter manipulation, or trigger-based input distributions that induce malicious behavior while preserving perfor- mance on clean inputs (Li et al., 2025a; Wu et al., 2025; Yu et al., 2025). SkillTrojan departs from these threat models by targeting the execution layer of coding agents. Given a user query q∈ Q, the model uses m to select and invoke actions in A as part of normal problem solving. We assume the underlying language model and its training data are trusted and unmodified. We focus on attacks that exploit the skill abstraction layer—namely, the combination of persistent natural-language instructions and executable scripts that are reused across queries. Concretely, when trig- gered, fragment emitters write small encoded fragments to a run-local intermediate channel that is available to the agent’s execution context (e.g., tool return values and the tool-call trajectory log, or a run-scoped scratchpad).
